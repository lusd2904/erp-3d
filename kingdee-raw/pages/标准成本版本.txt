ID: 标准成本版本
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E6%88%90%E6%9C%AC%E7%89%88%E6%9C%AC

====== 1 功能说明 ======

标准成本版本设置可以设置默认版本、影响成本卷算的因素。
 
====== 2 使用前提 ======

无。 

====== 3 功能路径 ======

【成本管理】—>【标准成本分析】—>【基础数据】—>【标准成本版本设置】

====== 4 字段说明 ======


===== 4.1 单据头 =====


| **字   段**           || **说 明**                        |
| 版本号                 || 当前版本的编码。                       |
| 名称                  || 当前版本的名称。                       |
| 是否默认                || 是否作为默认的标准成本版本。                 |
| 是否使用简化BOM           || 简化bom是新的BOM展示方法，勾选后能提升性能，建议勾选  |
| 考虑子项物料的生效日期         || 勾选后卷算时考虑子项物料的生效日期              |
| 展示跳层件               || 勾选后多级成本查询将展示跳层件                |
| 考虑供料方式              || 勾选后当时子项的供料方式为委托方供料，则不参与卷算      |
| 通用或报价BOM仅卷算标准工费     || 勾选后卷算时仅取标准工时和费率，不取委外加工价目表      |

===== 4.2 影响因素 =====


| **字   段**     || **说 明**                 |
| 准备工时          || 人员准备工时、机器准备工时是否影响成本卷算。  |
| 变动损耗率         || 物料清单上的变动损耗率是否影响成本卷算。    |
| 成品率           || 物料清单上的成品率是否影响成本卷算       |
| 固定损耗          || 物料清单上的固定损耗是否影响成本卷算。     |

====== 5 操作说明 ======

默认版本只有一个，将新的版本设置为默认时，上一个默认版本自动设置为非默认。
