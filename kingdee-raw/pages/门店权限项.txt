====== 门店权限项 ======
====== 1.功能概述 ======
功能简介：这里可以按角色设置对pos的操作权限


====== 2.字段说明 ======

**Pos功能权限**
^ 字段           ^ 说明                                                                        ^
| 收银权          | 是指控制服务员是否可以进行收银业务操作，开启后，POS端收银按钮将可操作，反之则无操作权。                             |
| 清机权          | 是指控制服务员是否可以进行清机业务操作，开启后，POS端清机按钮将可操作，反之则无操作权。                             |
| 转更权          | 是指控制服务员是否可以进行收银业务操作，开启后，POS端转更按钮将可操作，反之则无操作权。                             |
| 取消账单权        | 是指控制服务员是否可以进行取消账单业务操作，开启后，POS端消单按钮后取消埋脚即可取消帐单，反之则无操作权。                    |
| 取消埋脚权        | 是指控制服务员是否可以进行取消埋脚业务操作，开启后，POS端消单按钮将可操作，反之则无操作权。                           |
| 打印结账单权       | 是指控制服务员是否可以进行打印结账单业务操作，开启后，POS端结账后会弹出打印结账单进行打印操作，反之则无操作权。                 |
| 查看前台报表权      | 是指控制服务员是否可以进行查看pos报表业务操作，开启后，POS端报表按钮将可操作，反之则无操作权。                        |
| 点菜权          | 是指控制服务员是否可以进行点菜操作，开启后，POS端点菜按钮将可操作，反之则无操作权。                               |
| 已点食品招待权      | 是指控制服务员是否可以进行对已点食品招待操作，开启后，POS端招待按钮将可操作，反之则无操作权。                          |
| 是否有招待限制权     | 是指控制服务员是否是否有招待限制权，开启后，could上用管理员账号进去设置员工招待信息，pos才能有招待权限，反之则没有该招待权限。       |
| 分单权          | 是指控制服务员是否可以进行分单操作，分单是应顾客要求把一个房台的菜分到另一个房台。，开启后，POS端分单按钮将可操作，反之则无操作权。       |
| 下单权     | 是指控制服务员是否可以对菜品进行下单操作，开启后，POS端修改扣炖量按钮将可操作，反之则无操作权。                                |
| 取消权    | 是指控制服务员是否可以对菜品进行取消操作，开启后，POS端取消按钮将可操作，反之则无操作权。                                              |
| 招待权    | 是指控制服务员是否可以对菜品进行招待操作，开启后，POS端招待按钮将可操作，反之则无操作权。                                                  |
| 全单折权     | 是指控制服务员是否可以对菜品进行全单折扣操作，开启后，POS端全单折按钮将可操作，反之则无操作权。                                                   |
|取消原因权 |是指控制服务员是否可以进行取消原因操作，开启后，POS端取消原因将可操作，反之则无操作权。 |
|支付方式权 |是指控制服务员是否可以在付款时操作支付方式，开启后，POS端支付方式将可操作，反之则无操作权。 |
| 修改已点食品数量权    | 是指控制服务员是否可以进行修改已点食品数量操作，开启后，POS端改数量按钮将可操作，反之则无操作权。                        |
| 修改食品价钱权      | 是指控制服务员是否可以进行修改已点食品价格操作，开启后，POS端改价钱按钮将可操作，反之则无操作权。                        |
| 暂停食品权        | 是指控制服务员是否可以进行暂停食品操作，开启后，POS端暂停按钮将可操作，反之则无操作权。                             |
| 服务权          | 是指控制服务员是否可以开台，开启后，POS端服务员可以开台，反之则无操作权。                                    |
| 免服务费权        | 是指控制服务员是否可以免服务费操作，开启后，POS端免服务费按钮将可操作，反之则无操作权。                             |
| 折扣权          | 是指控制服务员是否可以打折操作，开启后，POS端折扣率按钮将可操作，反之则无操作权。                                |
| 全单折扣权        | 是指控制服务员是否可以免费服务费操作，开启后，POS端全单折按钮将可操作，反之则无操作权。                             |
| 取消已点食品权      | 是指控制服务员是否可以取消已点食品操作，开启后，POS端点菜界面取消按钮将可操作，反之则无操作权。                         |
| 转房权          | 是指控制服务员是否可以转房操作，开启后，POS端免转房按钮将可操作，反之则无操作权。                                |
| 锁台权          | 是指控制服务员是否可以锁台操作，开启后，POS端锁台按钮将可操作，锁台后可以点菜但不能结账，反之则无操作权。                    |
| 解锁权          | 是指控制服务员是否可以解锁房台操作，开启后，POS端解锁按钮将可操作，反之则无操作权。                               |
| 免房费权         | 是指控制服务员是否可以免房费操作，开启后，POS端免服务费按钮将可操作，反之则无操作权。                              |
| 免最低消费权       | 是指控制服务员是否可以进行免最低消费操作，开启后，POS端免最低消费按钮将可操作，反之则无操作权。                         |
| 特殊付款         | 控制对应支付方式是否需要此特殊付款权限才可以进行支付选择。                                             |
| 就餐超时         | 配合OptIsDinerOverTime选项使用,控制对应员工是否可以修改就餐超时时间.                              |
| POS会员存款      | 是指控制服务员是否可以进行POS会员存款操作，开启后，POS端会员存款按钮将可操作，反之则无操作权。                        |
| 是否有取消招待食品权   | 是指控制服务员是否可以有取消招待食品操作，开启后，POS端免转房按钮将可操作，反之则无操作权                            |
| 下班转更报表权      | 此权限需要配合OptIsEmpTrunReport选项使用，用于在转更界面显示收银员工下班报表。                          |
| POS会员信息权     | 是指控制服务员是否可以查询会员信息操作，开启后，POS端会员信息界面按钮将可操作，反之则无操作权。                         |
| 自行修改菜式名称权    | 此权限需要配合OptIsAUInputFoodName选项使用，在点菜界面控制是否可以修改食品名称。                        |
| 是否有减少人数权     | 需要配合OptIsMamNumAddInput选项使用，在修改人数据时控制是否可以减少人数的修改。                         |
| 是否有修改人数权     | 是指控制服务员是否可以修改帐单人数，点击对应“房台”=》点击“人数”按钮。                                     |
| 房费折扣权        | 是指控制服务员是否可以对房费进行折扣，折扣房费后不能对食品进行折扣。                                        |
| 修改扣炖量权       | 是指控制服务员是否可以修改扣炖量操作，开启后，POS端修改扣炖量按钮将可操作，反之则无操作权。                           |
| 印暂时单权        | 是指控制服务员是否可以打印暂时单是操作。                                                      |
| 并台权          | 需要配合OptIsMergerRoomPur选项使用，用于控制对应员工是否可以并台操作。                              |
| 钱箱权          | 需要配合OptFoodHaveDrawer选项使用，控制对应员工是否可以打开钱箱操作。                               |
| 大类折扣折        | 是指控制服务员是否可以操作大类折扣，开启后，POS端免大类折扣按钮将可操作，反之则无操作权                             |
| 酒席权限         | 需要配合OptFeastPurpContrl选项使用,控制是否可以处理酒席功能。                                  |
| 修改记菜员权       | 需要配合OptHaveOrderEmp选项使用,用于控制是否可以修改当前帐单的记菜员信息。                             |
| 修改账单类型权      | 需要配合OptISHaveBillType选项使用,控制对应员工是否可以修改帐单类型。                               |
| 关系统权         | 需要配合OptIsCloseSysPurp选项使用,控制关闭系统时是否需要这个权限控制。                              |
| 送单权          | 需要配合OptSendVisible选项使用,控制对应员工进入点菜界面后是否可以进行送单操作。                           |
| 会员存款负数权      | 控制会员存款时是否可以输入负数操作。                                                        |
| 账单重印权        | 是指控制服务员是否可以进行点菜操作，开启后，POS端点菜按钮将可操作，反之则无操作权。                               |
| 分项优惠         | 需要配合OptIsCampscheme选项使用,控制员工是否有分项优惠操作权                                    |
| POS会员扣款规则修改  | 是指控制服务员进行会员支付时是否可以修改会员的扣款规则                                               |
| 收银长短款权       | 是指控制服务员是否可以输入金额操作，开启后，POS端全单折按钮将可操作，反之则无操作权。                              |
| 外卖订单异常清机权    | 需要配合OptIsEndCheckTakeout选项使用,在清机时如果检查到有外卖订单未导入到系统,则通过此权限控制是否可以进行继续清机操作.。  |
| 预定管理权        | 是指控制服务员是否可以操作预定管理(预订系统)。                                                  |
| 酒席预定（查看）     | 是指控制服务员是否可以酒席预定操作，开启后，酒席预定查看按钮将可操作，反之则无操作权                                |
| 酒席取消（查看）     | 预订系统中使用，控制员工是否可以取消酒席订单。                                                   |
| 酒席取消（修改)     | 预订系统中使用，控制员工是否可以修改酒席订单。                                                   |
| 酒席查询（查看）     | 预订系统中使用，控制员工是否可以查看酒席订单。                                                   |
| 酒席查询（修改）     | 预订系统中使用，控制员工是否可以查询修改酒席订单。                                                 |
| 打开钱箱         | 是指控制服务员是否可以进行打开钱箱业务操作，开启后，POS端钱箱按钮将可操作，反之则无操作权。                           |
