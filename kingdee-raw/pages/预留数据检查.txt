======1 预留数据检查======
=====1.1 功能概述=====
计划运算是以运算开始时获取的需求及供应数据为对象的计算，当计划运算过程中参与计算的需求或供应发生变化时，就会导致生成的预留关系出现异常，包括预留数量不正确，预留对象的业务状态不正确等。

=====1.2 使用前提=====

启用【预留】

=====1.3 功能路径=====

进入【生产制造】—>【计划管理】—>【报表分析】—>【预留数据检查】

======2. 字段说明======

=====2.1 查询结果=====

|  **字段**  |  **说明**                   |
|  供需类型    | 1、显示单据是需求还是供应             |
|  异常类型    | 1、显示单据预留异常属于数量异常还是单据状态异常  |
|  单据名称    | 1、显示单据的名称                 |
|  单据编号    | 1、显示单据的编号                 |
|  行号      | 1、显示单据的行号                 |
|  物料编码    | 1、显示单据的物料编码               |
|  物料名称    | 1、显示单据的物料名称               |
|  规格型号    | 1、显示单据的规格型号               |
|  基本单位    | 1、显示单据的基本单位               |
|  业务数量    | 1、显示单据的需求数量或供应数量          |
|  预留数量    | 1、显示单据的预留数量或被预留数量         |
|  检查详情    | 1、显示单据的检查详情               |

======3. 功能操作 ======

**修复预留**
 
点击表头“修复预留”会修复查询结果中的单例预留关系

**释放预留**

点击表体”释放预留”会释放选中的表体单据的预留关系
