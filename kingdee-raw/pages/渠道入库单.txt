ID: 渠道入库单
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B8%A0%E9%81%93%E5%85%A5%E5%BA%93%E5%8D%95

**功能说明：**

用户所有渠道入库处理、渠道入库单处理情况查询以及历史渠道入库记录查询；

**功能路径：**

【我的进销存】->【渠道入库单】

**使用前提：**

拥有自行管理库存权限的渠道或门店

**字段说明：**

渠道入库单显示字段说明

| **名称**   | **字段说明**                                 |
| 出库单表头字段                                            ||
| 渠道入库单编号  | 自动生成                                     |
| 销售组织     | 系统自动携带渠道档案的销售组织，锁定不可编辑                   |
| 单据类型     | 根据上游单据，关联选择单据类型。单据类型有普通入库单、盘盈入库单、初始化入库单  |
| 业务类型     | 关联业务类型，业务类型有普通入库、盘盈入库、初始化入库、退货入库         |
| 入库方式     | 有手工入库、自动签收、手工签收，此处设置默认为手工签收              |
| 入库渠道     | 用于按入库渠道增加库存                              |
| 供货方类型    | 渠道，或者组织                                  |
| 供货方      | 渠道名称或者组织名称                               |
| 状态       | 状态值有：保存、提交、重新审核、审核                       |
| 出库单表体字段                                            ||
| 商品名称     | 要出库的商品名称                                 |
| :::      | 列表显示时，显示形式为：商品编码+商品名称+规格型号               |
| 商品编码     | 根据选择的商品系统自动返回                            |
| 规格型号     | 根据选择的商品系统自动返回                            |
| 计量单位     | 根据选择的商品系统自动返回                            |
| 入库数量     | 手工填写                                     |
| 仓库       | 入到那个仓库，默认为入库渠道的默认仓库                      |
| 价格       | 根据当前渠道对应的的结算渠道从可销售商品接口中获取。               |
| 金额       | 金额=入库数量*价格                               |
| 来源单据编号   | 记录渠道出库单上游单据的单据编号，手工创建的渠道出库单则为空           |

**操作说明：**

1、进入渠道入库单页面，允许操作有新增、删除、提交、审核、反审核、刷新、导入、导入模版等操作
  * 新增：新建渠道出库单；
  * 删除：只有单据状态为保存或重新审核的渠道出库单才能删除；
  * 提交：可以保存之后提交或直接提交，提交后更新单据状态为提交；
  * 审核：只有单据状态为提交的渠道出库单才允许审核。审核之后，系统会自动扣减对应出库商品的库存；
  * 反审核：只有单据状态为审核的渠道出库单才允许反审核。反审核之后，系统会自动增加对应出库商品的库存；
  * 导入：按【导入模版】整理相关数据，将渠道入库单直接导入。刚导入的渠道入库单默认为保存状态；
  * 导入模版：选择相关渠道入库单，作为整理导入渠道入库单的模版参考数据。若未渠道入库单，刚导出空模版；
 
2、新增渠道入库单，填写相关信息，保存或提交即可
