====== 1 功能概述 ======


反写主要用于处理单据之间的关联关系，目标单生成之后，源单的某些属性将会被改变；这种关联关系表现为某些数值的增减或某种字段值的改变。

我们将这种下游单据生成后，改变上游单据某些属性的配置过程，以定义规则的形式展现，并称之为定义反写规则。

反写规则的创建类似于基础资料，例如打开反写规则新增界面，输入配置内容保存即可创建反写规则。而应用有几种方式：
  * 反写规则配置界面勾选【适用于全部自由流程】，则该规则保存成功后则自由流程的数据流转可以调用此反写规则；
  * 反写规则配置界面勾选【适用于全部业务流程】，则该规则保存成功后则业务流程的数据流转可以调用此反写规则；
  * 在业务流程设计器的连线上中引用反写规则，则表示仅数据处于该业务流程中流转时才调用此反写规则。

注：自由流程是相对于业务流程抽象的一个概念名词，它的含义是只创建单据转换规则管控两两单据之间的流转关系，不为其设计业务流程管控多单之间的流转。这样的单据数据流转关系，我们称为数据走自由流程。

====== 2 操作步骤 ======


1.入口：进入【流程中心】→【业务流程】，打开反写规则列表界面，点击【新增】按钮。

2.打开反写规则编辑界面，设置基本信息； 
  * 主要是选择上游单据、下游单据。表示【下游单据】在一定情况下会反写【上游单据】。 

3.设置反写的执行时机； 
  * 反写执行时机受到【条件】、【操作】的共同控制，当条件与操作都满足时，反写规则才能被执行； 
  * 条件：表示在什么条件下执行当前反写规则； 
  * 操作：表示在下游单据进行何种操作时执行当前反写规则。 

4.设置反写的目标字段及其字段值的数据来源； 
  * 从上游单据选择此次需要反写的字段，并且通过编辑反写值计算公式、反写模式配置反写值以何种模式写入目标字段。 

5.设置反写多源单的分配规则； 
  * 单据转换支持分录合并，所以需要定义跨级反写多行源单数据时反写值的分配规则以及分配上限的计算方法。 
  * 例如，【采购订单→收料单→入库单】的流程中，【收料单→入库单】的连线上添加反写规则，入库单需跨级反写采购订单，且设置分配规则=自上而下。 
  * 采购订单有三张，采购01、采购02、采购03，分别记录采购数量=“10、20、30”，批量下推收料单，分录合并为一行，并记录收料数量=60。当收料单下推入库单时，入库数量=40，入库单【入库数量】需要反写采购订单中的【累计入库数量】为40。 
  * 入库数量40来源于三张采购订单， 该场景其分配上限可以设为“【采购数量】-【累计入库数量】”，此时采购01可分配10，采购02可分配20，采购03可分配30。依据自上而下分配，反写【累计入库数量】时采购01为10、采购02为20、采购03为10。 

6.设置关闭控制以及超额判断； 
  * 关闭控制：实际是与单据转换规则的选单条件策略搭配使用。达到关闭控制的条件时，可以改变上游单据指定字段的状态值（例如【行关闭】字段=已关闭），而选单条件策略针对此字段配置选单条件【行关闭=已关闭】，这样满足关闭控制的数据行会被控制不允许继续单据转换了。 
  * 超额控制：当反写规则执行时满足超额控制条件，则终止此次反写事务。单据的一次保存、审核等操作可能会触发多条反写规则执行，将多条反写规则执行视作一个事务。如果其中任意一条反写规则执行时满足超额控制条件，则终止此反写事务，此次保存或审核操作会因超额而执行失败。 

7.最后保存并启用反写规则。

**注：反写规则设置中涉及不少计算公式、比较条件等。通常，在使用数量字段、金额字段进行相关反写设置时，请注意数量字段之间应是基于同一计量单位、金额字段之间应是基于同一币种。例如，数量字段建议使用【类型=基本单位数量】的字段，该类字段与【类型=基本计量单位】配套使用。具体内容请参见[[k3cloud:流程中心:业务流程:业务流程专题:单位换算|单位换算]]的介绍。**

====== 3 字段说明 ======
===== 3.1 基本信息 =====

  - 标识：必录项，编辑反写规则的标识。 
  - 名称：必录项，编辑反写规则的名称，多语言文本字段。 
  - 上游单据：选择单据，作为反写时的目标单据。
  - 下游单据：选择单据， 作为反写时的取数来源单据。 
  - 描述：编辑反写规则的描述内容。 
  - 自动适用自由流程：表示使用自由流程的单据（即没有指定任何业务流程）通过单据转换生成此下游单据时，则允许执行此反写规则。  
  - 自动适用全部业务流程：表示此反写规则无需配置在业务流程连线上，使用业务流程的单据允许执行此规则。 
===== 3.2 反写 =====

1. 条件：设置反写规则执行的前提条件，为空表示没有约束条件。
 
2. 操作：支持选择两种操作：保存、审核。 
  * 保存：此下游单据保存时，执行反写规则。当保存的下游单据被删除，则会执行此反写规则的逆过程，确保反写数据的准确性。 
  * 审核：此下游单据审核时，执行反写规则。当审核的下游单据被反审核，则会执行此反写规则的逆过程，确保反写数据的准确性。 
 
3. 反写上游单据字段：选择上游单据中的字段作为反写的目标字段。
 
4. 反写模式：设置反写计算公式结果值写入反写目标字段的模式。 
  * 累加：将反写计算公式结果值累加到反写目标字段当前值。 
  * 扣减：将反写计算公式结果值从反写目标字段当前值扣减。 
  * 覆盖：将反写计算公式结果值覆盖反写目标字段当前值，该模式主要用于非数值型字段的反写。 
 
5. 反写计算公式：使用下游单据字段编辑计算公式，作为反写的来源数据。
  * 允许选择下游单据字段，表示将此字段值作为反写的来源数据。
 
6. 多源单分配规则：支持选择两种分配规则：自上而下、按权重分配。主要是在单据转换的数据出现分录合并后，进行跨级反写才需要用到。 
  * 自上而下：反写值从上到下依次自动分配，一行数据分配到上限后再分配下一行数据。 
  * 按权重分配：以单据转换时源单多行分录可分配上限之间的权重作为依据，自动分配各行分录的反写值。 
 
7. 分配上限：设置可分配上限的计算公式，为跨级反写分配提供数值依据。通过此公式计算，可以知道每行分录反写的可分配数。

8.反写回退值：反写模式=覆盖时，此选项可设置。目的是为了下游单据反审核或删除时，将反写上游单据字段进行自动回退，置为本选项指定的值。

===== 3.3 关闭控制 =====

  - 行关闭条件：设置行关闭的判断条件。 
  - 行关闭字段：可以选择上游单据中单据体（包括子单据体）的【单据状态】类型字段。
  - 行关闭状态值：表示行关闭条件成立则将【行关闭字段】的状态值置为【行关闭状态值】；  
  - 行未关闭状态值：表示行关闭条件不成立则将【行关闭字段】的状态值置为【行未关闭状态值】； 
  - 整单关系策略：设置整单关闭的判断依据，提供2种策略：“任一行关闭时，关闭整单”、“全部行关闭时，关闭整单”。  
  - 整单关闭字段：可以选择上游单据中单据头的【单据状态】类型字段。

===== 3.4 超额判断 =====

1. 超额控制级别：控制级别分为三种：禁止超额、允许超额一次、允许超额。 
  * 禁止超额：表示严格控制，不允许超额。超额检查公式成立，则判断为已超额。常用的超额控制使用此级别。 
  * 允许超额一次：表示依据次数控制超额，只允许超一次。 
  * 允许超额：表示不做超额检查。 
 
2. 超额检查公式：公式成立则表示满足超额条件 

3. 超额提示信息：编辑文本内容，作为超额判断成立时的提示信息。

====== 4 操作说明 ======

  - 新增：打开反写规则新增界面，编辑反写规则保存即可，状态=“草稿”。 
  - 打开：打开选中的反写规则修改界面。不支持批量修改。
  - 复制：复制选中反写规则的设置，打开反写规则新增界面。 
  - 启用：启用反写规则，启用成功则状态=“正常”；状态=“草稿”“禁用”的规则可以进行启用操作。
  - 禁用：禁用反写规则；状态=“正常”的规则可以进行禁用操作。
  - 删除：删除选中的反写规则；状态=“草稿”的规则才能删除。支持批量删除。

====== 5 应用场景 ======

===== 5.1 跨级反写 =====

A->B->C,A单下推生成B单,再从B单下推生成C单，生成C单时需要反写A单的这种情况我们称之为跨级反写。跨级反写的配置非常简便，只需要创建一条反写规则下游单据=C单，上游单据=A单，然后参照前文描述的反写规则设计操作步骤完成相关设置即可，系统会依据关联关系表自动从C单追溯到A单执行相关反写。

===== 5.2 同组反写 =====

以销售流程为例，销售订单可以走流程【销售订单→销售出库单】，也可以【销售订单→发货通知单→销售出库单】。销售订单有2张直接下游单据发货通知单、销售出库单，假定销售订单有100个，下推走发货通知单的已有30。此时销售订单直接下推销售出库单，希望可下推数量=100-30=70。即销售单据的多个分支单据共用销售单据的总数值，这些直接下游单据我们称之为同组单据，反写过程称为同组反写。

以上面的销售流程为例，业务流程设计需注意下列地方。
  * 【销售订单→销售出库单】的业务流程连线添加反写规则，设置可描述为销售出库单保存操作时将销售出库数量值以累加模式反写销售订单的【已关联数量】。 
  * 【销售订单→发货通知单】的业务流程连线添加反写规则，设置可描述为发货通知单保存操作时将发货通知数量值以累加模式反写销售订单的【已关联数量】。 
  * 即同组反写的场景，需要将同组单据（销售出库单、发货通知单）在反写时都累加到上游订单的同一个字段。

===== 5.3 按比例关闭 =====

通过单据转换可以反复下推生成下游单据，但是实际应用中需要对与单据转换在数值上进行控制，当上游单据的控制数量（也可以是金额）已全部转换生成下游单据后，将上游单据的对应数据关闭，控制不允许继续下推，这种处理称为关闭控制。

在企业实际应用中常常出现不同组织或部门中单位不一致的情况，通过单位换算可能就会带来细小的误差。例如，假定采购订单中大米的单位以吨计，入库单中大米的单位以包计（1包=10千克），由于生产过程中的损耗，实际库存中只有99包。这样的情况下对于关闭条件并不是一种等于关系，而是控制在一定范围内都可以视作达到关闭条件。即按比例条件进行关闭控制。

假定以【采购订单→入库订单】为例，要求采购订单中累计入库数量达到采购数量的98%时，则控制采购订单该行数据关闭，不允许继续下推操作或选单操作。
  - 采购订单需要进行控制的单据体中添加一个单据状态字段，命名为“业务关闭”，并添加2个状态值分别为“正常”“已关闭”； 
  - 在【采购订单→入库订单】对应单据转换规则的【选单条件策略】中，添加一行条件，“业务关闭=正常”，表示“业务关闭”字段的状态值等于正常的数据行，允许通过单据转换操作携带数据，不符合的数据在单据转换时自动被过滤； 
  - 在【采购订单→入库订单】对应反写规则的【关闭控制】中，设置关闭条件为“累计入库数量>=采购数量*98%”，行关闭字段选择“业务关闭”，行关闭状态值选择“已关闭”，行未关闭状态值选择“正常”。 
  - 当入库单反写采购订单后，若累计入库数量<采购数量*98%时，对应行的“业务关闭”字段被设置为“正常”。反写规则执行过程中，当累计入库数量>=采购数量*98%时，则将对应行的“业务关闭”字段设为“已关闭”。已关闭的数据再次进行单据转换时会自动被过滤。

===== 5.4 按比例超额 =====

供应商送来材料的数量超过了采购下单数量，此时入库单【入库数量】会超过上游单据采购订单【采购数量】，这种场景叫做超额。

下游单据控制数量刚好超过上游单据的只是超额的一种特殊情况，根据企业实际应用，系统提供超额比例控制。即下游单据可以超过上游单据，但是允许超出的部分是控制在一定比例范围。

以【采购订单→入库单】的流程为例，要求入库数据最多允许超出采购订单数量的20%，则设计步骤如下：
  - 打开对应的反写规则，选择【超额判断】页签。 
  - 超额控制级别选择【禁止超额】。 
  - 然后设置超额检查公式为“已入库数量>采购数量×1.2”；表示已入库数量超过采购数量达到20%，则超额判断成立，将终止此次操作的执行。 
  - 最后可以自定义超额判断成立时弹出的提示信息内容。 若超额提示信息为空时，表示使用系统的默认提示信息。
