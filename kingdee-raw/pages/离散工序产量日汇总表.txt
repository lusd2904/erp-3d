ID: 离散工序产量日汇总表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A6%BB%E6%95%A3%E5%B7%A5%E5%BA%8F%E4%BA%A7%E9%87%8F%E6%97%A5%E6%B1%87%E6%80%BB%E8%A1%A8

**应用场景**

生产工序执行生产场景，帮助车间主管清晰掌握每个工单，每种产品，各工序的完工、合格、废品、良品率情况，用户可自定义时间段，满足对统计期间的不同需求。

**功能路径**

【生产制造】-->【车间管理】-->【报表分析】

【智慧车间MES】-->【智慧车间】-->【报表分析】


**过滤条件**

快捷页签：按加工组织、产品、生产订单、作业、加工车间、班组、操作工、班次、设备、统计维度，过滤数据；

时段设置页签：按长度、单位、个数，过滤数据；

**快捷过滤**

^  字段   ^  说明                                                                                       ^
| 加工组织  | 1.可选择用户有权限的具有工厂职能的组织；多选。\\ 2.加工组织修改后变更加工车间的值列表                                            |
| 产品    | 1.过滤条件加工组织=使用组织\\ 2.[物料]数据状态=已审核\\ 3.[物料]禁用状态=否\\ 4.[物料.基本页签]物料属性=自制\\ 5.支持多选             |
| 生产订单  | 根据加工组织过滤，\\ [单据类型.参数设置]启用工序跟踪=是\\ [单据类型.参数设置]柔性生产=否\\ [生产订单]数据状态=已审核\\ 列表按生产订单编号降序排列      |
| 作业    | 1.过滤条件加工组织=使用组织\\ 2.[作业.其他]审核状态=已审核\\ 3.[作业.其他]禁用状态=否\\ 4.支持多选                            |
| 加工车间  | 1.过滤条件加工组织=使用组织\\ 2.[部门.部门属性]部门属性=基本生产部门；\\ 3.[部门.其他]审核状态=已审核\\ 4.[部门.其他]禁用状态=否\\ 5.支持多选  |
| 班组    | 1.过滤条件加工组织=使用组织\\ 2.[班组.其他]审核状态=已审核\\ 3.[班组.其他]禁用状态=否\\ 4.支持多选                            |
| 操作工   | 1.过滤条件加工组织=[员工-单据头]使用组织\\ 2.[员工]审核状态=已审核\\ 3.[员工]禁用状态=否\\ 4.支持多选                          |
| 班次    | 1.过滤条件加工组织=使用组织\\ 2.[班次.其他]审核状态=已审核\\ 3.[班次.其他]禁用状态=否\\ 4.支持多选                            |
| 设备    | 1.过滤条件加工组织=使用组织\\ 2.[设备.其他]审核状态=已审核\\ 3.[设备.其他]禁用状态=否\\ 4.支持多选                            |
| 统计维度  | 加工车间；班组；班次；操作工；设备                                                                         |

**时间设置**

长度：数值，1-366；

单位：日、周、月；

个数：数值，1-366；

**报表字段**

^  字段          ^  说明                 ^
| 统计日期.完工数量    | [工序汇报-分录行]完工数量      |
| 统计日期.合格数量    | [工序汇报-分录行]合格数量      |
| 统计日期.废品数量    | [工序汇报-分录行]废品数量      |
| 统计日期.良品率(%)  | （合格数量 / 完工数量）*100%  |
