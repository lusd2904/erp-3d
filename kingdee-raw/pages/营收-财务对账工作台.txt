===== 1.功能概述 =====
营收-财务对账工作台统计分析实际营收与财务记账中账单数、金额的差异
====== 2.使用前提 ======
  * 存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据
  * 实际营收与财务记账存在差异
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【财务集成】→【营收-财务对账工作台】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、显示隐藏列

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
====== 5.报表字段说明 ======
^ 字段           ^ 说明          ^
| 组织           | 组织          |
| 营业日期         | 门店营业日期      |
| 营业汇总-账单数     | 营业汇总总账单数    |
| 营收-财务记账-账单数  | 财务记账账单数     |
| 营业汇总-金额      | 营业汇总金额      |
| 营收-财务记账单-金额  | 财务记账总金额     |
| 差异金额         | 营收与财务记账差金额  |
| 差异状态         | 1.有；2.无     |

====== 6.报表操作说明 ======
1、报表提供冻结列设置、打印、引出功能、补录记账数据。

2、报表提供按表头的【组织】汇总合计【数量】、【金额】。

3、可以通过勾选【选项】中的参数，不显示分录行的合计、小计
