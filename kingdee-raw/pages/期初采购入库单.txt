====== 1功能概述 ======

期初采购入库单是初始化期间特殊的采购入库单，用于记录系统初始化前已经入库但未开发票的入库单数据，期初采购入库单可以生成应付单，用于期初暂估处理。

====== 2使用前提 ======


业务组织、供应商、物料、单位、币别、仓库、税率等基础资料已经建立； 
库存组织已经启用； 
====== 3功能路径 ======


【供应链】－>【采购管理】－>【初始化】－>【期初采购入库单】

====== 4字段说明 ======


  
===== 4.1基本字段 =====
==== 单据类型 ====

期初采购入库单的单据类型，从入库单单据类型基础资料中选择
==== 业务类型 ====

期初采购入库单对应的业务类型
==== 收料组织 ====

入库的业务组织，必须是库存组织，从业务组织基础资料中选择
==== 库存组 ====

进行入库的库存小组，必须是收料组织下的库存组
==== 需求组织 ====

物料的需求组织
==== 采购组织 ====

负责的采购组织
==== 采购组 ====

负责的采购组
==== 采购员 ====

负责的采购员
==== 其他字段 ====

|字段||说明|
|单据编号||期初采购入库单的单据编号，编号必须唯一，符合编号规则|
|入库日期||期初采购入库单的单据日期，|
|供应商||来料的供应商，从供应商基础资料中选择，需按采购组织+业务类型过滤。|
|仓库部门||入库的部门，必须是收料组织下的部门|
|仓管员||进行入库的仓管员，必须是库存组下的仓管员|
|采购部门||负责的采购部门|
|单据状态||期初采购入库单的单据状态|
 
===== 4.2表头供应商字段 =====
 

|字段||说明|
|供货方||来料的供货方，从供应商的地点资料中选择，一般从上游采购订单携带过来|
|供货方地址||携带供货方地点对应的地址|
|供货方联系人||携带供货方地点对应的联系人|
|结算方||来料的结算方，从供应商的地点资料中选择，一般从上游采购订单携带过来|
|收款方||来料的收款方，从供应商的地点资料中选择，一般从上游采购订单携带过来|

===== 4.3表头财务信息字段 =====
==== 结算组织 ====

物料的结算组织，默认等于需求组织
==== 货主类型 ====

物料的所有权性质
==== 货主 ====

物料的所有权
 
==== 其他字段 ====

|字段||说明|
|结算方式||物料的结算方式，默认为供应商的结算方式|
|结算币别||物料的结算币别，默认为供应商的结算币别|
|付款条件||物料的付款条件，默认为供应商的付款条件|
|本位币||收货组织所属核算组织对应的默认本位币|
|汇率类型||汇率的类型，从汇率类型资料选择|
|汇率||外币交易的汇率，根据结算币别和业务日期从汇率表获取|
|金额||按结算币别计量的整单汇总金额|
|税额||按结算币别计量的整单汇总税额|
|价税合计||按结算币别计量的整单汇总价税合计|
|金额（本位币）||按本位币计量的整单汇总金额|
|税额（本位币）||按本位币计量的整单汇总税额|
|价税合计（本位币）||按本位币计量的整单汇总价税合计|
|含税||勾选表示以含税单价为准，不勾选表示以单价为准。|

====== 5操作说明 ======


  - 期初采购入库单的单据状态说明，请参考单据状态通用说明
  - 期初采购入库单没有业务操作。

====== 6业务说明 ======


  - 期初采购入库单不会更新库存，不影响库存数据。
  - 期初采购入库单手工录入批号，不自动生成批号，会更新到批号主档。
  - 委外类型的期初采购入库单不会进行倒冲领料操作。
