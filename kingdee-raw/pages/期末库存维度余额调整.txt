====== 期末库存维度余额调整 ======
===== 发布说明 =====
补丁号：PT-146884
，上线日期：2021年8月6日

===== 功能概述 =====
用于调整物料在同一个核算维度下不同库存维度的期末结存金额异常的问题，如下图：
^ 物料    ^ 仓库    ^期末数量 ^ 期末单价  ^期末金额  |
| A001  | 原材料仓  |    10 |     1 |    10 |
| A001  | 半成品仓  |    20 |   2.5 |    50 |
| 合计    |       |    30 |     2 |    60 |

===== 操作流程 =====

:!:由于期末库存维度余额调整出单是针对期末余额，因此调整单类型为“期末余额调整单”，出单后如果进行核算，将会自动删除这部分调整单，如果这些调整单生成了凭证，核算会中断。
  * 存货核算期末关账—>核算—>期末库存维度余额调整—>存货核算期末结账—>生成凭证

===== 关键应用 =====
  * 出单
  * 反出单

{{::期末库存维度余额调整.png?1200|}}

===== 出单规则 =====
  * 此功能会以物料核算维度的单价乘以库存维度数量计算出正常的期末余额，再通过出单的方式将实际库存余额调整为这个正常的期末余额。库存维度调整的金额不会影响存货期末余额，核算维度调整的金额会影响存货期末余额。

^  库存维度数量  ^ 核算维度单价  ^ 是否允许出单  ^ 调整单类型    ^ 调整单调整原因     ^ 调整单来源类型       ^ 是否需要生成凭证  ^
| 无        | 零       | 允许      | 期末余额调整单  | 期末核算维度余额调整  | 期末核算维度余额调整产生  |  是        |
| 有        | 零       | 不允许     |          |             |               |           |
| 有        | 正单价     | 出单      | 期末余额调整单  | 期末库存维度余额调整  | 期末库存维度余额调整产生  |  否        |
| 有        | 负单价     | 不允许     |          |             |               |           |

 

===== 字段说明 =====
^  字段              ^  说明                            ^
| 期末数量             | 取存货收发存汇总表（按库存维度显示）时，库存维度的期末数量  |
| 库存维度期末单价         | 取存货收发存汇总表（按库存维度显示）时，库存维度的期末单价  |
| 库存维度期末金额         | 取存货收发存汇总表（按库存维度显示）时，库存维度的期末金额  |
| 核算维度期末单价         | 取存货收发存汇总表（按核算维度显示）时，库存维度的期末单价  |
| 按核算维度期末单价重算期末余额  | 期末数量*核算维度期末单价                  |
| 金额差异             | 库存维度期末金额-按核算维度期末单价重算期末余额       |
