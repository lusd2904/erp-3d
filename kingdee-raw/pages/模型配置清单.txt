====== 1模型配置清单 ======
=====1.1 功能概述=====
配置清单记录了用户当时配置的模型编码、变量值以及配置的完成情况，同时允许客户在配置清单修改变量进行二次配置。    
=====1.2 使用前提=====
无
===== 1.3功能路径 ===== 
进入【生产制造】—>【工程数据】—>【模型配置】—>【模型配置清单】
====== 2 字段说明 ======
^  **字段**  ^  **说明**        ^
|  编码      | 显示当前配置清单的编号    |
|  模型编码    | 显示产生当前结果的模型    |
|  物料编码    | 显示配置生成的物料编码    |
|  辅助属性    | 显示配置生成的辅助属性    |
|  BOM版本   | 显示配置生成的BOM版本   |
|  状态      | 显示配置的结果        |
|  变量值     | 显示当前配置的变量及变量值  |


====== 3 业务说明 ======
====配置====
支持对配置清单变量值进行编辑，然后进行二次配置。
====引入====
支持配置清单引入，然后批量生成配置结果。
