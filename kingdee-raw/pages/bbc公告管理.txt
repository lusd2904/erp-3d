ID: bbc公告管理

**功能说明：**

用于企业或渠道商做宣传、发布公司新闻、促销活动、服务信息等。

**功能路径：**

【B2B】->【公告】->【公告列表】

**使用前提：**

所属渠道为企业或直接渠道允许发布

**字段说明：**
| **字段**   | **字段说明**                              |
| 基本信息                                            ||
| 公告编码     | 系统按一定规则自动生成的编码                        |
| 公告主题     | 必填；显示在前台公告的标题                         |
| 公告状态     | 取值范围包括：创建、已保存、已提交、已审核、重新审核、已发布、取消发布；  |
| :::      | 根据不同的状态会有不同的处理结果                      |
| 公告分类     | 关联公告分类表                               |
| :::      | 可以新增、删除、编辑相关分类                        |
| 发布日期     | 默认系统当前日期                              |
| 详细介绍                                            ||
| 详细介绍     | 公告内容的详细介绍说明                           |
| :::      | 支持上传图片说明、支持上传附件                       |
| 发布信息                                            ||
| 发布B2C用户  | 勾选后公告将发布给B2C商城用户                      |
| 发布B2B用户  | 勾选后公告将发布给B2B所有门户用户                      |
| 序号       | 系统自动生成流水号                             |
| 渠道类型编码   | 关联渠道类型表，F8浏览选择                        |
| :::      | 根据选择的渠道类型编码，发布给不同的渠道                  |
| 渠道类型名称   | 关联渠道类型表，F8浏览选择                        |
| :::      | 根据选择的渠道类型编码，系统自动携带                    |
| 创建人      | 根据创建时的登录用户，系统自动记录                     |
| 创建时间     | 根据创建时的系统时间，系统自动记录                     |
| 发布人      | 根据发布时的登录用户，系统自动记录                     |

	
**操作说明：**
  - 新增公告：进入公告列表，点击【新增】按钮即跳转至公告新增页面。填写相关信息
  - 发布公告：新增的公告默认是未发布，需要手工点击发布。发布后，对应的发布渠道BBC商城前台可查看到公告。公告的发布日期为点击发布后取的系统即时日期；
  - 取消发布：会将发布状态置为否，对应的发布渠道BBC商城前台将不再看见公告；
  - 删除：只有未发布的公告才允许删除，已发布的公告删除时提示【发布中的公告不允许删除】并删除失败；
  - 查看公告：在公告列表里选择对应的公告双击即可查看公告详情
