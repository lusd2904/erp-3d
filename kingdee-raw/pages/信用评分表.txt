ID: 信用评分表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BF%A1%E7%94%A8%E8%AF%84%E5%88%86%E8%A1%A8

信用评估模型是针对所评估的对象建立起来的一系列因素及其打分标准，其最后结果反映为信用评分，通过信用评分用量化的数值来体现所评估对象的信用风险。使得评估结果可量化，评估过程更加全面、客户、统一，从而评估结果也更具说服力。 

信用评分结果将直接应用在客户的信用档案和信用控制中，企业根据一定时间内客户的信用等级状况分别采取不同的信用控制方式，使得信用管理更加科学有效。
 

  * 使用前提:

设置信用评估指标 

设置信用评估等级 

设置信用评估模型 

创建信用评分

  * 字段说明

| **字段名称**       || **字段说明**                                                                                                                        |
| 评估组织           || 取创建评分表选定的评估组织，不允许修改。                                                                                                            |
| 客户             || 取创建评分表选定的评估组织，不允许修改。一个客户生成一张评分表。                                                                                                |
| 评估模型           || 取创建评分表选定的评估模型，不允许修改。                                                                                                            |
| 综合得分           || 等于各明细评估指标“权重得分”的合计。不允许修改。                                                                                                       |
| 评估等级           || 显示综合得分自动与信用评估等级设置进行匹配后的结果                                                                                                       |
| 更新信用档案检查规则     || 1、勾选该选项则如果信用评分更新信用档案，按评估等级设置的信用检查规则同步更新档案中的信用检查规则。\\ 2、如不勾选该选项，则不更新检查规则。\\                                                      |
| 评估指标编码         || 1、用户选择的评估方案的表体“指标编码”字段；\\ 2、按指标编码组层级层层展开，一直层层展开到明细级指标。\\                                                                        |
| 评分标准           || 1、评估指标对应的评分标准。\\ 2、将评估指标表体评分标准明细多行展示为这里的一个行。\\                                                                                  |
| 指标分值           || 携带用户选择的评估方案的表体“指标分值”字段值；锁定不允许修改。                                                                                                |
| 系统评分           || 1、根据信用预置评估指标，取系统中对应数据，并自动匹配信用评估指标分值，并把匹配到的指标设置中的评分返回到系统评分字段。\\ 2、系统预留插件接口，支持用户自定义评估指标在系统取值规则。\\                                 |
| 评分人评分          || 1、根据向导选择的评分部门、评分人动态展示。\\ 2、显示为评分人（XX部门，XX员工）\\ 3、只有明细级指标才允许录分值，上级组的分数等于明细指标分值和。\\ 4、允许用户手工录入，该行分值控制不能大于该行指标分值。\\                |
| 平均分            || 等于各评分人录入分值的平均分。                                                                                                                 |
| 最终评分           || 1、根据评分向导参数“最终评分人”及“最终得分默认等于平均"选项决定,如二个选项同时勾选,则最终得分默认等于平均分。\\ 2、只有明细级指标才允许录分值，上级组的分数等于明细指标分值和。\\ 3、允许用户手工录入，该行分值控制不能大于该行指标分值。\\  |
| 权重%            || 1、携带用户选择的评估方案的表体“权重”字段值；锁定不允许修改。                                                                                                |
| 权重得分           || 1、等于各明细级指标最终评分/指标分值*权重*100\\ 2、综合得分等于各明细指标权重得分之和。\\                                                                             |

  * 操作说明：

系统最多预置五个评估人评分列，用户评分权限由字段授权控制。评估人评分列支持用户自定义列，平均分计算公式可由用户根据评估人数量自定义。 

系统预留插件接口，支持用户自定义评估指标取系统数据进行评分。系统预置二个可系统评分的评估指标，取数逻辑如下：

逾期应收天数（天）＝系统日期-应收单上最小到期日

逾期应收比例（%） ＝ ∑（到期日<系统日期 的未核销应收款－未核销收款单＋未核销退款单）/ ∑（未核销应收款－未核销收款单＋未核销退款单）

信用评分表单据表体列支持冻结列操作，默认至“指标分值”列冻结。 

信用管理系统参数【信用评分更新信用档案】。勾选该参数，则信用评分后，将评分结果更新对应的信用档案。
