ID: 订单签收
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%AE%A2%E5%8D%95%E7%AD%BE%E6%94%B6

**功能说明：**

对已发货的订单进行收货签收

**功能路径：**

【我的订单】->【订单签收】

**使用前提：**

具有签收的权限且存在已发货待签收的订单

**字段说明：**

订单签收页面显示字段说明：
| **名称**  | **字段说明**                             |
| 表头                                            ||
| 订单编号    | BBC订单编号                              |
| 订单日期    | BBC订单日期                              |
| 表明细                                           ||
| 商品      | 显示商品编码+商品名称+规格型号                     |
| 计量单位    | BBC订单订货单位                            |
| 订单数量    | 来源BBC订单.分录订货数量                       |
| 已签收数量   | 来源BBC订单.分录已签收数量                      |
| 本次签收数量  | 默认携带订单数量-已签收数量                       |
| :::     | 系统已控制：已签收数量+本次签收数量要小于等于订单数量，否则编辑无效。  |
| 本次拒收数量  | 默认为0，可以修改                            |
| 是否补货    | 默认为否                                 |
| 补货数量    | 如果是否补货=是，则可以编辑，并且补货数量默认等于本次拒收数量。     |
| :::     | 如果为否，则不允许编辑                          |
| 备注      | BBC订单的订单备注                           |

**操作说明：**
  - 用户进入签收页面；
  - 系统显示我的待签收的订单，展示界面如下面的【订单签收界面】，具体的信息取数如下面的【订单签收展示信息】。
  - 用户确认本次签收数量、拒收数量、补货数量、是否补货，用户客户修改，数量之间有控制逻辑，具体参考下面的【订单签收展示信息】。
  - 用户确定以上数据无误，勾选订单，点击“确认收货”。
  - 系统只对已勾选的，并且本次签收数量不大于0的记录做签收。
  - 系统进行签收处理，即系统自动生成签收记录（即渠道入库单）。具体请参看【签收确认处理】
