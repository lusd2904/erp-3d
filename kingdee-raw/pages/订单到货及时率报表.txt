====== 1功能概述 ======


订单到货及时率查询报表主要用于查询采购订单准时交货的情况，根据交货日期和入库/收料日期之间的关系判断订单是否逾期交货，计算出逾期天数，逾期交货数量和交货及时率

====== 2使用前提 ======


存在实际发生的业务数据 

====== 3功能路径 ======


【供应链】－>【采购管理】－>【报表分析】－>【订单到货及时率】

====== 4报表过滤条件 ======


过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
下面针对快捷过滤页签字段进行详细说明

  * 报表快捷过滤字段说明 

| 过滤条件     | 说明                                                   |
| 采购组织     | 支持多选，合法值范围：具采购职能的组织机构                                |
| 起始日期     | 当前所查询数据的起始日期                                         |
| 供应商      | 当前查询数据的供应商范围                                         |
| 订单编号     | 当前查询数据的订单范围                                          |
| 物料分组     | 当前查询数据的物料分组范围                                        |
| 物料       | 当前查询数据的物料范围                                          |
| 采购员      | 当前查询数据的采购员范围                                         |
| 业务类型     | 当前查询数据对应的业务类型范围，目前支持物料采购，暂不支持资产、费用采购                 |
| 单据状态     | 当前查询的采购订单对应的单据状态\\ 提供选项：“全部”、“已审核”、“创建”、“审核中”“重新审核”  |
| 行状态      | 当前查询的采购订单对应的行状态\\ 提供选项：“全部”、“已完成”、“未完成”              |
| 是否逾期     | 当前查询的采购订单的逾期情况\\ 提供选项：“全部”“是”“否”                     |
| 以入库日期为准  | 以订单的交货日期和入库日期之间的关系计算                                 |
| 以收料日期为准  | 以订单的交货日期和收料日期之间的关系计算                                 |
| 允许延期天数   | 输入允许延期的天数，在计算逾期时加上允许延期天数                             |


====== 5报表字段说明 ======


  * 表头字段 

|字段|说明|
|采购组织|报表数据来源的采购组织范围|
|日期范围：|报表数据的起止日期|
|供应商范围|报表数据的供应商范围|
|物料范围|报表数据的物料范围|
|物料分组范围|报表数据的物料分组范围|
|采购员范围|报表数据的采购员范围|
|订单编号范围|报表数据的订单编号范围|

  * 表体综合字段 

| 字段      | 说明|   
| 供应商编码   | 订单到货及时率的供应商编码.|   
| 供应商名称   | 根据供应商编码带出供应商名称.|   
| 物料编码    | 订单到货及时率的物料编码.|   
| 物料名称    | 根据物料编码带出物料名称|   
| 规格型号    | 物料编码对应的规格型号|   
| 辅助属性    | 物料对应的辅助属性|   
| 单位      | 物料对应的采购单位|   
| 物料分组编码  | 订单到货及时率的物料分组编码|   
| 物料分组名称  | 根据物料分组带出的物料编码|   
| 采购员编码   | 订单到货及时率的采购员编码|   
| 采购员名称   | 根据采购员编码带出的采购员名称|   
| 订单编码    | 订单到货及时率的订单编码|   
| 订单类型    | 根据订单编码带出的单据类型|   
| 单据状态    | 根据订单编码带出的单据状态|   
| 行状态     | 根据订单编码带出的行状态|   
| 订单数量    | 根据订单编码带出的订单数量|  
| 交货日期    | 根据订单编码带出的交货日期|   
| 交货及时率   | 1、过滤条件勾选“以入库日期为准”、订单未关闭时\\ 交货及时率=（入库日期 < =交货日期）的数量/订单数量\\ 2、过滤条件勾选“以收料日期为准”、订单未关闭时\\ 交货及时率=（收料日期 < =交货日期）的数量/订单数量\\ 3、过滤条件勾选“以入库日期为准”、订单关闭时\\ 交货及时率=（入库日期 < =交货日期）的数量/入库总数量\\ 4、过滤条件勾选“以收料日期为准”、订单关闭时\\ 交货及时率=（收料日期 < =交货日期）的数量/收料总数量|   
| 是否逾期    | 当逾期交货数量大于0，是否逾期为“是”，当逾期交货数量小于等于0，是否逾期为“否”|   
| 逾期交货数量  | 1、过滤条件勾选“以入库日期为准”时\\ 订单关闭，入库总数量-（入库日期 < =交货日期）的数量\\ 订单未关闭，交货日期>=系统日期,逾期数量为0\\ 订单未关闭，交货日期<系统日期，订单总量-（入库日期 < =交货日期）的数量，可以为负\\ 2、过滤条件勾选“以收料日期为准”\\ 订单关闭，收料总数量-（收料日期 < =交货日期）的数量\\ 订单未关闭，交货日期>=系统日期,逾期数量为0\\ 订单未关闭，交货日期<系统日期，订单总量-（收料日期 < =交货日期）的数量，可以为负|
| 准时交货数量  | 订单数量-逾期交货数量|   
| 逾期天数    | 1、过滤条件勾选“以入库日期为准”时，是否逾期为“是”时\\ 订单关闭，入库日期-交货日期，\\ 订单未关闭，系统日期-交货日期\\ 2、过滤条件勾选“以收料日期为准”\\ 订单关闭，收料日期-交货日期，\\ 订单未关闭，系统日期-交货日期|   

====== 6报表操作说明 ======


报表提供冻结列设置、打印、引出功能
