====== 电子回单补打申请单 ======
=====1 功能说明 =====
  * 电子回单点击补打可自动生成电子回单补打申请单。
  * 支持补打电子回单。

=====2 操作前提 =====

已经进行了银企互联设置并且已经测试通过。

=====3 功能路径 =====

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单补打申请单】

=====4 字段说明 =====
| **字段**     || **说明**               |
| 单据编号       || 自动生成电子回单补打申请单的单据编号。  |
| 收付组织       || 电子回单的组织。             |
| 申请人        || 补打申请人。               |
| 申请日期       || 补打申请日期。              |
| 补打事由       || 补打事由。                |
| 是否已打印      || 是否已打印。               |
| 交易日期       || 电子回单对应的业务交易日期。       |
| 银行账号       || 电子回单上的银行账号。          |
| 账户名称       || 电子回单上的账户名称。          |
| 金额         || 电子回单上的金额。            |
| 电子回单名称     || 电子回单名称。              |
| 打印次数       || 电子回单已打印次数。           |

=====5 操作说明 =====

详细说明如下：

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单】，选择电子回单，点击补打，自动生成电子回单补打申请单。
