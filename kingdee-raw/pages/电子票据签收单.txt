====== 电子票据签收 ======
=====1 功能说明 =====
  * 网上银行增加电子票据签收单。
  * 支持对接银企平台进行电票签收。
  * 支持通过电子应收票据生成出纳模块应收票据。

=====2 操作前提 =====

银企互联设置并且开通电票接口。



=====3 功能路径 =====

【财务会计】—>【网上银行】—>【日常处理】—>【电子票据签收】

【财务会计】—>【票据管理】—>【电子票据】—>【电子票据签收】

{{:123.png?400|}}


=====4 字段说明 =====
| **字段**       || **说明**            |
| 票据类型         || 银行承兑汇票或商业承兑汇票    |
| 电票状态       || 电票签收状态。      |
| 票据号码       || 银企平台回传的票据号码。       |
| 出票人全称        || 电票对应的出票人全称。      |
| 出票人账号           || 电票对应的出票人账号。           |
| 收款人全称           || 电票对应的收款人全称。        |
| 收款人账号         || 电票对应的收款人账号。     |
| 承兑人全称     || 电票对应的承兑人全称。       |
| 承兑人开户银行     || 电票对应的承兑人开户银行名称。       |
| 票面金额           || 付款金额减去收款金额。       |
| 单据编号       || DZPJQSD+8位系统流水号。      |
| 关联应收票据        || 电票下推生成应收票据流水号。    |


=====5 操作说明 =====

  * 主控台菜单【财务会计】-【网上银行】-【日常处理】下增加【电子票据签收】二级功能菜单，点击【电子票据签收】进入电子票据签收单列表
  * 点击【查询待签收票据明细】
  * 选择对应银行账号（用户有查看权限的、使用组织=当前组织、勾选支持网银且未禁用的银行账号）
  * 列表勾选电子票据明细，点击签收后，自动生成电子票据签收单，签收单的回复意见更新为“签收”，同时自动提交银企平台，更新提交银行状态为“提交”，并自动同步“银行处理状态”和“银行返回信息”
  * 回复意见为签收且银行处理状态为交易成功的电子票据签收单，当交易状态更新为成功时，自动下推生成创建状态的应收票据。
