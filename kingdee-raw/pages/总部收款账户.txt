====== 1.总部收款账户 ======

===== 1.1 功能概述 =====

  * 功能界面定位：餐饮门店管理-门店订货管理-基础资料-总部收款账户 
  * 支持微信支付方式
  * 配置的支付Appid 和支付key联系总部人员
  * 一个收款账户可以设置多个使用门店

===== 1.2 字段说明 =====
^ 字段       ^ 说明           ^
| 编码       | 唯一值，自动生成     |
| 充值方式     | 支持微信，支付宝     |
| 微信公众号    | 充值方式为微信则需要   |
| 名称       | 自定义          |
| 支付AppId  | 支付宝或者微信提供的   |
| 支付Key    | 支付宝或者微信提供的   |
| 收款组织     | 设置哪个组织进行收款   |
| 门店       | 收款账户适用门店     |
| 部门       | 收款账户适用部门     |
| 门店地址     | 门店的地址，有组织携带  |
