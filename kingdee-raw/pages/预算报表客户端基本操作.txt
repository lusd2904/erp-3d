 ====== 根节点菜单 ====== 

^ 功能项                ^ 操作说明                                                                                                                                                                                                         ^
| 【保存】               | 保存当前打开报表文件的未保存的数据。                                                                                                                                                                                           |
| 【全部保存】             | 保存当前所有打开报表文件未保存的数据。                                                                                                                                                                                          |
| 【引入引出】             | 引出当前打开的报表至本地存放，支持PDF、EXCEL2007两种格式。                                                                                                                                                                          |
| 【按引入模板引出EXCEL】     | 已经填充了模板样式方案的预算报表（模板），按导入模板导出到excel文件（文件内容、单元格备注信息、单元格取数公式）。\\ 允许用户在导出的excel中进行以下操作：调整列的先后顺序、按列排序、删除不需要的多余行、单元格设置计算公式(带星号的列切勿删除)。                                                                             |
| 【按引入模板引入EXCEL】     | 将按引入模板引出的excel文件，编制预算数后（也可维护备注、取数公式信息），导入到系统预算报表。\\ **支持excel文件新增维度组合行的导入。**                                                                                                                                 |
| 【按引入透视表模板引出EXCEL】  | 所见即所得的引出样式。引出为交叉透视表样式。                                                                                                                                                                                       |
| 【按引入透视表模板引入EXCEL】  | 将引出的透视表样式模板，编辑后引入。                                                                                                                                                                                           |
| 【打印】               | 打印当前打开的报表文件。                                                                                                                                                                                                 |
| :::                | 【显示报表属性设置】：报表打印，页眉页脚显示所设报表属性，如报表编码、创建人、创建时间、审核人、审核时间等。\\ 在显示报表属性界面，将需要打印显示的报表属性，【插入】到页眉页脚相应位置。\\ 如:  在页脚显示报表审批人、审批时间。\\ 注意：所插入的报表属性，如${AuditorID.Name}（审核人.名称），仅为具体的属性值信息。建议按需增加说明描述，如审核人：${AuditorID.Name}  |
| 【打印预览】             | 预览当前打开的报表文件。在预览界面，可进行【页面设置】操作。                                                                                                                                                                               |
 ====== 开始菜单 ======

^ 菜单组     ^  功能路径                   ^  操作说明                                                                                                                                                                                                                                                                                                                ^
| 文件      | 【开始】→【保存】               | 保存当前打开报表文件的未保存的数据。                                                                                                                                                                                                                                                                                                   |
| :::     | 【开始】→【全部保存】             | 保存当前所有打开报表文件未保存的数据。                                                                                                                                                                                                                                                                                                  |
| 编辑      | 无效                      | 允许将一个或者多个单元、区域，置为无效。\\ 系统不存储无效单元格数据，即：预算数为空。\\ **应用场景**\\ 在预算表层面，置为无效的单元格，数据库层面不存储该无效单元格数据，表现为预算数为空。与预算控制规则的预算数为空通过/不通过匹配使用。\\ 在实际数报表层面，置为无效的单元格，数据库层面不存储该无效单元格数据。与预算执行分析类报表，包含实际数报表查询时，系统默认以实际数报表数据为准的应用。                                                                                                           |
| :::     | 生效                      | 重新激活无效的单元格。                                                                                                                                                                                                                                                                                                          |
| :::     | 显示备注                    | 单元格存在备注信息的，以特殊背景色显示。                                                                                                                                                                                                                                                                                                 |
| 数据      | 【开始】→【公式取数参数】           | 单元格定义取数公式时，如公式中涉及通用参数，则可不用设置，而在【公式取数参数】统一设置。\\ 预算取数公式（BGdata、SJdata、预算汇总表取数）涉及相关参数有：\\   * 币别、预算方案、预算组织、控制规则、年度、开始期间、结束期间；\\   *【 包含未审核预算报表】：BGdata取预算数是否包含未审核预算表数据、预算汇总表获取目标组织预算表数据时，是否包含未审核预算报表；\\   *【SJdata取数时，以控制规则中维度范围/维度过滤优先】：预算控制规则如已设置了控制维度的维度范围（维度过滤），是否以该范围/过滤为基础，进行实际数的获取。否则，SJdata取数时不考虑维度范围（维度过滤）设置。  |
| 报表批量填充  | 【开始】→【报表批量填充】→【样式方案填充】  | 在预算模板中选择并填充模板样式方案                                                                                                                                                                                                                                                                                                    |
| :::     | 【开始】→【报表批量填充】→【样式方案修改】  | 在预算模板中对已填充的模样样式方案进行修改。                                                                                                                                                                                                                                                                                               |
| :::     | 【开始】→【报表批量填充】→【维度值填充】   | 对已填充的样式方案，进行具体维度值的填充。                                                                                                                                                                                                                                                                                                |
| 预算汇总    | 【开始】→【预算汇总】→【汇总表设置】     | 选择汇总模板样式方案。确定需要展示的周期及年期信息。（仅非周期性汇总表---从预算汇总菜单入口）\\ 数据范围设置：\\ 1.预算数为空不显示。可有效过滤数据为空的预算维度。\\ 2.包含预算调整数。                                                                                                                                                                                                                 |
| :::     | 【开始】→【预算汇总】→【汇总表样式方案】   | 根据需要，修改已选汇总样式方案设置。                                                                                                                                                                                                                                                                                                   |
 ====== 编辑菜单 ======

【插入】→【工作表】：插入一张新工作表。

【插入】→【函数】：显示取数公式列表，由于该部分功能内容比较多，因此将单独作为一个小节详细介绍。详细请参考：[[预算取数公式]]。


 ====== 数据菜单 ======

【重算表页】：重算当前所选表页。

【全部重算】：重算当前报表所有表页。

【终止计算】：终止当前的重算操作。

 ====== 审阅菜单 ======

对预算报表及预算模板进行提交、审核、反审核操作。

 ====== 工具菜单 ======

【公式取数参数】：对整表进行公式取数参数的设置，包括预算相关的预算方案、预算组织，总账相关的取数账簿，以及公用参数币别、年度、开始期间、结束期间、开始日期、结束日期等的设置。用于当单元格公式未设置公用参数时，系统在重算时，从公式取数参数中统一获取。

 ====== 单元格备注 ======

由于预算报表客户端基于类似透视表控件搭建，该控件无法录入除数值之外的字符，特提供了备注录入框，用于编辑和维护单元格的备注信息。

可通过引出到excel（按引入模板引出方式），批量查看和维护备注信息。

 ====== 操作技巧 ======
  - 删除单元格内容：【Backspace】键。
  - 支持从EXCEL复制数据到预算报表。
  - 按需调整维度列宽、数据列的宽度，系统保存宽度调整。
  - 预算表字体大小调整。位置：各类型报表列表界面（如果预算编制台、预算模板等），【工具栏】-【选项】-【选项】-【选项设置】-【业务参数】：报表单元格缩放比例
