====== 1.外卖对账工作台-账单 ======
===== 1.1 功能概述 =====
外卖账单对账工作台是外卖账单对账的核心单据，外卖账单对账是指第三方平台（美团/饿了么） 的平台账单单号，外卖渠道与POS账单的外卖账单号，外卖渠道匹对的过程。外卖账单对账支持多个组织，多个日期同时对账。
===== 1.2 字段说明 =====
| 字段名称         | 字段说明                                     |
| 对账           | 点击对账会自动匹配外卖订单与POS账单中符合条件的数据生成已审核状态的对账记录  |
| 订单来源渠道       | 包括饿了么外卖和美团外卖                             |
| 门店POS外卖订单笔数  | 统计符合订单来源渠道的POS账单数                        |
| 平台外卖订单数      | 统计下载或者导入的美团/饿了么外卖订单数                     |
| 门店POS外卖金额    | 统计符合订单来源渠道的POS外卖金额                       |
| 平台外卖订单金额     | 统计符合订单来源渠道的平台外卖金额                        |
| 差异对账金额       | 平台外卖订单金额与门店POS外卖金额的差值                    |
| 自动对账金额       | 门店POS外卖订单和平台外卖订单符合条件的金额总和                |
| 确认对账金额       | 已审核状态的外卖订单对账记录单的确认对账金额总和                 |
| 差异状态         | 包括无差异已审核，有差异未审核，有差异已审核，无差异未审核，未对账五种状态    |
| 查看明细         | 点击明细界面跳转到外卖订单对账记录单界面                     |
