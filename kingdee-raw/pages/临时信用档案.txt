ID: 临时信用档案
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%B4%E6%97%B6%E4%BF%A1%E7%94%A8%E6%A1%A3%E6%A1%88

临时信用档案是指企业在特定时间段范围内，需在原来授信基础上增、减信用额度，满足企业促销、铺货等业务需求。

  * 使用前提:

信用档案已建立；

  * 功能路径:

【供应链】－>【信用管理】－>【信用授予】－>【临时信用档案】

  * 字段说明：

| **字段**     || **说          明**                                                                                             |
| 授信组织       || 用户可选择需进行信用控制的组织。如已选单信用档案，则携带选择的信用档案的相应内容.                                                                    |
| 对象类型       || 信用控制的对象类型。由系统参数“信用控制对象选项”决定该字段可选的内容。如已选单信用档案，则携带选择的信用档案的相应内容.                                                |
| 信用对象       || 根据对象类型字段内容，由用户手工录入或F8调用对应基础资料。如：对象类型为“客户”，则信用对象显示客户基础资料；如对象类型为“销售员”，则信用对象显示销售员基础资料。如已选单信用档案，则携带选择的信用档案的相应内容  |
| 授信部门       || 信用对应的授信部门.如已选单信用档案，则携带选择的信用档案的相应内容                                                                           |
| 源单编号       || 选择的信用档案的单据编号                                                                                                 |
| 信用对象       || 携带选择的信用档案的信用对象，允许多选                                                                                          |
| 信用额度       || 设置信用对象的临时授信额度。增加信用额度用正数表示，减少信用额度用负数表示。用户的授信额=信用档案额度+临时授信额度。                                                  |
| 单笔限额       || 增加单笔额度用正数表示，减少单笔额度用负数表示。                                                                                     |
| 逾期天数       || 增加逾期天数用正数表示，减少逾期天数用负数表示。                                                                                     |
| 逾期额度       || 设置信用控制允许的逾期额度                                                                                                |
| 生效日期       || 临时信用档案的生效日期。                                                                                                 |
| 失效日期       || 临时信用档案的失效日期                                                                                                  |

  * 操作说明:

1 选单功能
 
临时信用档案不能新增行，行数据由选单的信用档案携带。

信用特批，特批额度、单笔限额、逾期额度、逾期天数均以信用档案设置额度+临时信用档案额度（已生效未失效）去判断。

2 业务说明:

通过录入临时信用档案，可临时增加或减少信用控制对象(包括客户、销售员和销售部门等)的信用额度。当临时信用档案过期时，则客户丧失了这部分临时变更的额度。

“信用可用额度余额”=“信用额度”+“临时授信额度”-“已使用信用额度”
