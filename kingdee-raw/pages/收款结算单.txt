====== 收款结算单 ======

=====1 功能说明 =====
  
记录企业资金总部集中对外收款。可以按结算明细下推收款单或付款退款单。

主要适应于集团总部集中对外收款，不同结算组织或者不同往来单位结算。

=====2 操作前提 =====

1、系统已启用。

2、定义了资金组织、收付组织、结算组织、单据类型、客户/供应商/部门/员工、币别、汇率体系、结算方式、收付款用途、银行、银行账号等基础数据。

3、如果是通过票据类结算方式收款，则还需要先维护了应收票据数据。

=====3 功能路径 =====

【财务会计】—>【资金管理】—>【日常处理】—>【收款结算单】

=====4 字段说明 =====

====4.1 收款结算单单据头 ====
 
包括的主要页签：基本页签、其他页签，具体内容如下所示：

===4.1.1 基本页签 ===

| **字段**      || **说明**                                                                           |
| 单据类型        || 单据类型为收款结算单                                                                       |
| 单据编号        || 收款结算单的编号。\\ 当【单据类型】定义为自动编号时，在保存时，系统自动生成单据编号；\\ 当【单据类型】定义为手工编号时，请在本栏位手工输入单据编号。\\  |
| 资金组织        || 录入执行本次收款的收付组织。                                                                   |
| 业务日期        || 收款业务发生的日期，也是财务入账时该笔业务所属财务期间的依据。                                                  |
| 付款单位类型      || 选择实际付款的对方单位类型。                                                                   |
| 付款单位        || 录入实际付款的对方单位。                                                                     |
| 收款金额        || 由系统根据表体的收款金额自动计算收款结算单整单收款金额。                                                     |
| 实收金额        || 由系统根据表体的实收金额自动计算收款单整单的实收金额。                                                      |
| 币别          || 显示本次收到款项所对应的币别。                                                                  |
| 本位币         || 显示本次收款的资金组织所对应的默认核算体系的核算组织默认的会计政策的本位币。                                           |
| 汇率类型        || 显示本次付款的资金组织所对应的默认核算体系的核算组织默认的会计政策的汇率类型。                                          |
| 汇率          || 收款单原币到本位币的汇率。根据对应的系统参数确定是否允许手工修改。                                                |
| 收款金额本位币     || 显示收款结算单整单的收款金额的本位币。                                                              |
| 实收金额本位币     || 显示收款结算单整单的收款金额的本位币。                                                              |
| 已结算金额       || 表体结算明细结算金额合计                                                                     |
| 未结算金额       || 表头实收金额减表头已结算金额                                                                   |



====4.2 收款结算单单据体====
包括的主要页签：明细页签、结算明细页签、账号页签具体内容如下所示：

===4.2.1 明细页签 ===
| **字段**     || **说明**                                      |
| 结算方式       || 选择录入收款业务对应的结算方式。                            |
| 收款金额       || 本次应收的金额。                                    |
| 手续费        || 本次收款业务发生的手续费。                               |
| 实收金额       || 由系统自动计算本次收款业务企业实际收到的金额。                     |
| 我方银行账号     || 如果本次收款业务是通过银行类的结算方式进行结算，则需要录入款项所收入的我方银行账号。  |
| 现金账号       || 如果本次收款业务是通过现金类的结算方式进行结算，则可以录入款项所对应的现金账号。    |
| 票据流水号      || 录入当前收款单要引用的应收票据的票据流水号。                      |
| 票据金额       || 显示所引用的应收票据的票面金额。                            |
| 可用票据余额     || 显示所引用的应收票据当前未被引用的票面余额。                      |
| 票据（包）号        || 显示所引用的应收票据的票据号。                             |
| 结算号        || 银行收款处理的结算号。                                 |
| 备注         || 录入本次收款业务的备注信息。                              |

===4.2.2 结算明细页签 ===

| **字段**     || **说明**                        |
| 结算组织       || 本次收款的结算组织。                    |
| 往来单位类型     || 选择与企业发生债权债务或者收付款往来关系的对方单位类型。  |
| 往来单位       || 录入与企业发生债权债务或者收付款往来关系的对方单位。    |
| 结算方式       || 可选内部结算方式，默认集中结算。              |
| 结算金额       || 录入结算组织占用本次付款金额                |
| 备注         || 录入结算组织本次收款业务备注信息              |

===4.2.3 账号页签===
|**字段**||**说明**|
|我方银行账号||录入我方收款的银行账号。|
|我方账户名称||显示我方收款银行账号对应的账户名称。|
|我方开户行||显示我方收款银行账号对应的开户银行。|
|对方银行账号||录入对方付款的银行账号。非必录信息。录入后将有助于系统根据此信息自动进行银行存款对账勾对。|
|对方账户名称||录入对方付款的银行账户名称。非必录信息。录入后将有助于系统根据此信息自动进行银行存款对账勾对。|
|对方开户行||录入对方付款的开户银行。非必录信息。录入后将有助于系统根据此信息自动进行银行存款对账勾对。|







=====5 操作说明=====

1、【收款结算单】—>【下推】—>收款单，下推生成收款单。

2、【收款结算单】—>【下推】—>付款退款单，下推生成付款退款单

3、【收款结算单】—>【业务查询】—>【勾对记录】，查询收款结算单对应的银行存款对账勾对记录。

4、【收款结算单】—>【业务查询】—>【应收票据】，查询收款结算单所引用的应收票据。
