===== 调整分录模板 =====

**功能说明**

设置调整分录模板主要用于当调整在每期的分录格式和调整依据相对固定时，每期直接调用模板来做调整分录，以减少手工录入的工作量。类似总账中“模式凭证”的作用。

**其他说明**

在调整分录中使用AdjustData取数公式，主要用于取调整之后的数据。

**操作说明**

打开【财务会计】－>【合并报表】－>【合并准备】－>【调整分录模板】功能，新增调整分录模板。

**字段说明**

| 字段            || 说明                                                                                                                                                                                                                                                 |
| 调整类型       |   | 提供了报前调整、集团调整，分别应用于报表中的调整分录、合并方案的调整分录生成。                                                                                                                                                                                                            |
| 模板类别          || 设定该模板属于哪一种调整类型，系统预置了：权益调整、其他调整。                                                                                                                                                                                                                    |
| 摘要            || 对调整分录的简要说明。                                                                                                                                                                                                                                        |
| 项目代码、项目名称     || 选择要调整的报表项目。                                                                                                                                                                                                                                        |
| 项目数据类型        || 选择要调整的数据类型。\\ 此数据类型判定此行数据会传递到工作底稿的哪个报表，期末数会传递到资产负债表，本年累计数会传递到利润表。                                                                                                                                                                                  |
| 借贷方向          || 借方/贷方/条件判断\\ 其中选择“条件判断”时，【借贷方向】确定规则为：贷方合计-借方合计>0，则为借方；贷方合计-借方合计<0，则为贷\\ 方；\\ 其中选择“条件判断”时，【数据来源】系统默认=借贷差额。且【调整数】系统默认=ABS（贷方合计-借方合计）。                                                                                                                |
| 数据来源          || 数据来源=“被投资公司”，仅在当模板类别=“权益调整”可选择使用。\\ 当模板类别=“权益调整”，提供三种来源：本组织/被投资公司/借贷差额；\\ 当模板类别=非“权益调整”，提供两种来源：本组织/借贷差额。                                                                                                                                           |
| 调整数           || 可以手工录入要调整的金额，或设置项目取数公式来取数，以便于用户从其他项目取数来作为调整的依据。\\ 项目取数公式支持以下函数：\\ ACCTITEMHBS、ACCTITEMHZS、CR_AcctItem、AdjustData、Elimreport。\\ 其中ACCTITEMHBS、ACCTITEMHZS的合并范围参数为空时，此参数默认为取数来源所在合并范围。                                                               |
| 股权分段计算        || 勾选，对此行分录的调整数公式定义中的FX*EPS进行分段计算，适用本年累计数分段计算。\\ 公式定义的格式只支持FX*EPS()、####+-FX*EPS()+-####、FX*EPS()+-FX*EPS()，其中FX为单一函数，####为任意数值或公式。\\ 分段计算逻辑：[FX(Nn)-FX(N2-1)]*EPS(Nn)+FX(N2-1))*EPS(N1-1))；从本年1期间为开始期间，其中FX为函数取数结果 Nn为合并当期，N1,N2......为本年的股权变动日所在期间  |
