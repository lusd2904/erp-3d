====== 电子票据背书 ======
=====1 功能说明 =====
  * 网上银行增加电子票据背书单。
  * 由出纳模块付款单/付款结算单/收款退款单发起申请，生成电子票据背书单。
  * 通过电子票据背书单提交银企平台，更新票据状态，实现星空和银企平台一体化。

=====2 操作前提 =====

银企互联设置并且开通电票接口。


=====3 功能路径 =====

【财务会计】—>【网上银行】—>【电子票据】—>【电子票据背书】

【财务会计】—>【票据管理】—>【电子票据】—>【电子票据背书】

{{:image_20220317152211.png?400|}}

=====4 字段说明 =====
| **字段**       || **说明**            |
| 付款组织         || 付款单的付款组织    |
| 背书日期         || 付款单的业务日期    |
| 票据类型       || 银行承兑汇票和商业承兑汇票      |
| 票据号码       || 付款单应收票据页签的票据号       |
| 电票状态       || 银行处理状态返回值      |
| 票面金额           || 对应应收票据的票面金额       |
| 背书人全称       || 付款单的付款组织      |
| 背书人账号       || 票据收款银行账号     |
| 背书人开户行行号       || 票据收款银行账号的开户行联行号     |
| 被背书人全称       || 付款单上的收款单位     |
| 被背书人账号       || 收款单位基础资料财务信息中的默认银行账号     |


=====5 操作说明 =====

  * 主控台菜单【财务会计】-【网上银行】-【电子票据】-【电子票据背书】二级功能菜单，点击【电子票据背书】进入电子票据背书单列表
  * 也可通过主控台菜单【财务会计】-【票据管理】-【电子票据】-【电子票据背书】二级功能菜单，点击【电子票据背书】进入电子票据背书单列表
  * 首先通过付款单/付款结算单/收款退款单结算方式选择应收票据背书
  * 在付款单/付款结算单/收款退款单应收票据背书页签选择“应收票据”票据流水号，并勾选银企背书
  * 付款单/付款结算单/收款退款单提交审核后点击“下推”按钮，选择“电子票据背书单”
  * 维护对应背书单信息，信息完成后，对电子票据背书单提交审核，在业务操作上进行“电子票据背书”（此操作为把背书信息提交至银企平台进行票据背书）
  * 电子票据提交银企背书完成后，返回银企背书信息同时原有系统的票据状态则由“为空”变为“背书”，并生成应收票据背书结算单
