====== 管理政策 ======

**1、功能概述**

用于集中定义分货、建议订货计算、目标分解等业务体系的管理政策；

**2、功能路径**

【BBC业务中心】→【网点】→【管理政策】

**3、使用前提**

营销关系树、分货商品分类；

**4、字段说明**

视管理体系应用的业务体系不同，需要填写的字段资料也不同，主要分为以下几部分

基本信息

^ 字段名称   ^ 说明                                                                                                                     ^
| 编码     | 通过编码规则生成，唯一，必填；                                                                                                        |
| 政策名称   | 手工编辑，必填；                                                                                                               |
| 管控体系   | 由用户选择，选择范围为：分货体系、建议订货体系、业务目标体系、导购目标体系，必填；\\ 系统根据所选体系不同，界面上显示的内容不同；                                                     |
| 营销关系树  | 由用户从营销关系树中选择； 不同体系的管理政策对营销关系网的要求不同，系统为用户弹出的可选范围会排除不符合已选管控体系业务要求的营销关系树；\\ 用户要判断一棵树是否符合业务要求，可以在营销关系树管理功能中使用相应的检查功能进行检查；  |
| 启用     | 取值范围为是，否；默认为否；                                                                                                         |

执行计划（目前只有分货体系和建议订货体系的管理政策有此部分内容）

^ 字段名称    ^ 说明                                                                    ^
| 开始时间    | 执行计划的开始时间；\\ 可编辑，必填；                                                  |
| 结束时间    | 执行计划的结束时间；\\ 可编辑，必须大于开始时间，必填；                                         |
| 执行间隔    | 执行间隔时间；\\ 默认为1，可编辑，必填；                                                |
| 间隔单位    | 执行间隔时间单位；\\ 由用户选择，选择范围为：秒、分钟、小时、天、月、年；默认为天                            |
| 执行时间    | 表示执行计划的下一次执行时间；\\ 第一次由用户手工输入，必须在开始时间和结束时间范围之内；后面由执行计划执行完之后，自动根据计划写入；  |
| 上次执行情况  | 系统在计划执行完之后，写入本次执行结果；                                                  |

商品范围（目前只有分货体系和建议订货体系的管理政策有此部分内容）

^ 字段名称       ^ 说明                            ^
| 商品分类编码     | 由用户选择用于分货用途的已启用的商品分类；         |
| 商品分类名称     | 根据商品分类编码携带；                   |
| 分货计算方案     | 对建议订货体系的管理政策有效，计算方案内置，不可自定义；  |
| 最大可订货计算方案  | 对建议订货体系的管理政策有效，计算方案内置，不可自定义；  |

**5、操作说明**

新增：用于新增管理政策；

删除：用于删除管理政策；

禁用：禁用管理政策；

启用：启用管理政策；
