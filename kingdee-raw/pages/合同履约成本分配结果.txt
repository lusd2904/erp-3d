====== 合同履约成本分配 ======
===== 发布说明 =====
补丁号：PT-146899
，上线日期：2021年12月16日,灰度发布，需要用户在BOS中发布此功能并进行功能授权

===== 功能概述 =====
根据财会（2017）22号的规定（财政部关于修订印发《企业会计准则第14号——收入》的通知），用户可以将于符合准则要求的相关费用计入合同履约成本，在销售业务完成时，将其结转至主营业务成本。
此功能可满足用户将费用应付单金额，按照“客户”等销售出库单上的维度字段生成“合同履约成本”的结转凭证的需求，并能提供相关报表分析。

===== 关键应用 =====
  * 合同履约成本分配
  * 合同履约成本反分配
  * 合同履约成本分配结果表
  * 报表分析（此版本暂不支持）
  * 应付单审核时自动分配（此版本暂不支持）
  * 提供多种分配权重：数量、金额、毛重、体积、自定义分配标准

^ 分配标准  ^ 来源              ^
| 数量    | 销售出库单的基本单位数量    |
| 金额    | 销售出库单的总成本(本位币)  |
| 毛重    | 物料基本信息页签：毛重     |
| 净重    | 物料基本信息页签：净重     |
| 体积    | 物料基本信息页签：体积     |
===== 单据范围 =====

^ 单据名称   ^ 可选条件                ^
| 应付单    | 未勾选“计入成本            |
| :::    | 立账类型="业务应付"、"财务应付"  |
| :::    | 可分配金额不为零            |
| 销售出库单  | 仅限参与核算的单据           |
