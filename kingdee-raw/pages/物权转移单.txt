====== 1功能概述 ======


物权转移单是VMI物料物权转移的标志，并作为后续应付的依据。

====== 2使用前提 ======


  - 定义退料单的单据类型、供应商、采购组织、库存组织、结算组织、币别、物料、单位等基础资料 
  - 按实际采购业务流程设置采购参数以及仓库资料 
====== 3功能路径 ======


【供应链】－>【采购管理】－>【VMI业务】－>【物权转移单】

====== 4字段说明 ======


===== 4.1表头基本字段 =====
==== 单据类型 ====

物权转移单的单据类型
==== 业务类型 ====

物权转移单的业务类型，根据单据类型携带
==== 货主类型 ====

物权转移的货主类型，3.0锁定为业务组织
==== 货主 ====

物权转移后的货主，为业务组织
==== 采购组织 ====

物权转移业务对应的采购组织
==== 库存组织 ====

物权转移业务对应的库存组织
 
==== 其他字段 ====

====== 5操作说明 ======


  - 3.0中物权转移单只支持查询,不支持手工新增、修改、提交、撤销、反审核等操作
