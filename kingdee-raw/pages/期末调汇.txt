====== 1.功能说明 ======

本功能主要用于对账簿内外币核算的科目在期末自动计算汇兑损益，生成汇兑损益结转凭证及期末汇率调整表。

**操作前提**

期末调汇必须满足下列条件才能执行调汇操作：

1) 账簿已经结束初始化；
2) 币别基础资料中已启用外币；
3) 账簿科目表中存在已启用期末调汇的科目。


**功能路径**

【财务会计】→【总账】→【期末处理】→【期末调汇】

====== 2.字段说明 ======

^ 参数           |^ 说明                                                                                                                                        ^
| 执行方式         || 手动：用户选择一个或多个期末调汇方案，通过点击【执行】按钮手动执行方案。\\ 自动：按方案中设置的执行频率，定时执行期末调汇方案。                                                                         |
| 执行频率         || 设置期末调汇方案的自动执行频率。                                                                                                                          |
| 执行人          || 执行方式设置为“自动”时，需要指定执行人。生成凭证的制单人为该执行人。                                                                                                      |
| 凭证日期方式       || 指定当前方案生成的期末调汇凭证的日期获取方式。                                                                                                                   |
| 汇兑损益科目       || 设置发生的汇兑差异转入的损益科目，一般为财务费用科目，该科目必须是最明细级科目。参与期末调汇的会计科目及核算维度下的汇兑差额转入汇兑损益科目。\\ 汇兑损益科目下设核算维度时，支持指定核算维度，未指定核算维度时会根据被调汇科目的核算维度对应结转。               |
| 汇兑损益科目方向     || 自动判定：调汇类型为“汇兑损失”时将汇兑差异计入汇兑损益科目的借方，否则，计入汇兑损益科目的贷方。                                                                                         |
| 调汇科目方向       || 自动判断：调汇科目的调整值无论正负均以蓝字列示；\\ 科目相同方向：调汇科目的记账方向始终为其科目属性定义的方向，当调整值与科目方向相反时则以红字金额列示；\\ 科目相反方向：调汇科目的记账方向始终为其科目属性定义的方向的反方向，当调整值与科目方向相同时则以红字金额列示。  |
| 调汇类型         || 汇兑收益：只对调汇后将产生汇兑收益的科目或核算维度进行调汇；\\ 汇兑损失：只对调汇后将产生汇兑损失的科目或核算维度进行调汇；\\ 汇兑损益：对所有参与期末调汇的科目或核算维度进行调汇。                                             |
| 汇率设置         || 设置期末调汇时使用的汇率类型及从汇率体系获取汇率时使用的日期。                                                                                                           |
| 调汇科目设置       || 设置当前方案包括的调汇科目，支持指定科目调汇。                                                                                                                   |
| 暂存保存失败的凭证       || 选中此项，生成的凭证保存失败时自动进行暂存。              |
| 余额为负不调汇       || 选中此项，仅对期末余额与科目本身的余额方向一致的科目或核算维度进行调汇。              |

====== 3.操作说明 ======

  * 执行：用户可以选择一个或多个期末调汇方案执行，每个方案单独生成一张期末调汇凭证。
  * 禁用、反禁用：禁用或反禁用选中的期末调汇方案。
  * 联查凭证：用户选择一个或多个期末调汇方案后点击【联查凭证】按钮，系统将展示相关方案生成的凭证列表。
  * 向导式期末调汇：调用向导式期末调汇功能，指引用户分步完成期末调汇工作。
====== 4.其他说明 ======

1）执行期末调汇方案时，系统会对调汇账簿进行调汇前相关检查，检查通过后，会根据方案中的凭证选项、调汇类型、汇率设置和调汇科目设置等进行调汇操作，调汇完成后，系统将自动生成期末调汇记账凭证。

2）在某些特殊场景下需要将不同调汇科目的汇兑差异计入不同的汇兑损益科目或使用不同的汇率进行调汇，可以通过建立多个指定调汇科目的调汇方案来实现。

3）支持给汇兑损益科目指定核算维度或指定部分核算维度，未指定的核算维度系统会根据调汇科目的核算维度自动对应结转。如果调汇科目和汇兑损益科目的核算维度不存在对应关系时，建议给汇兑损益科目指定核算维度或将汇兑损益科目的相关核算维度的必录类型设置成可选。
