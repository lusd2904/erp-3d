======1 多组织预测冲销======
=====1.1 功能概述=====
预测冲销可以将预测单与现有的销售订单、组织间需求单进行关联冲销，修正预测单的需求数量。预测单与冲销单据可以建立多组织映射关系。
=====1.2 使用前提=====

  * 定义【物料】
  * 维护【销售订单】
  * 维护【预测单】
  * 维护【组织间需求单】
  * 维护【预测冲销方案】
  * 生产计划参数：启用多组织预测勾选时，该功能可用。预测冲销与多组织冲销两个功能互斥。

=====1.3 功能路径=====

进入【生产制造】—>【计划管理】—>【预测冲销】—>【多组织预测冲销】

======2. 字段说明======

=====2.1 冲销范围页签===== 
|  **字段**              |  **说明**                                                                                |
|  预测冲销方案              | F8过滤 使用组织=当前组织下的预测冲销方案                                                                 |
|  供应组织为空的单据自动按供应规则拆分  | 默认为不勾选，用于控制读取预测单和冲销单据时出现供应组织为空时是否自动按供应规则进行拆分                                           |
|  冲销开始日期              | 默认等于系统日期，可手工修改，冲销开始日期不能大于冲销结束日期；系统根据此时间段过滤预测单。\\ 冲销开始日期不可早于当前系统日期\\                    |
|  冲销结束日期              | 根据冲销方案的冲销周期自动计算冲销完成日期，可手工修改，冲销周期的设定应该与展望期近似相同，不应该小于展望期太多，否则容易造成计划单据的遗漏；系统根据此时间段过滤预测单。  |

=====2.2 冲销对象-来源单据页签=====
|  **字段**  |  **说明**                                                                                    |
|  订单编号    | 显示冲销单据的单据编号，目前显示的是销售订单或组织间需求单的单据号                                                          |
|  分录号     | 显示冲销单据的分录号                                                                                 |
|  客户      | 如果冲销单据是销售订单，则显示销售订单的客户                                                                     |
|  物料      | 显示冲销单据的物料                                                                                  |
|  供应组织    | 显示来源单据上的供应组织，如果数据为空，则根据“范围选择”中的参数“供应组织为空的单据自动按供应规则拆分”决定是否进行数据拆分还是携带空值。                     |
|  原数量     | 显示销售订单的分录的库存单位数量，组织间需求单的基本单位数量                                                             |
|  数量      | 如果源单没有经过供应规则拆分，则数量应该等于原数量，不允许修改。如果经过了拆分，则相同订单编号+分录号的数量之和应该等于原数量，可以手工调整拆分比例，但分录行之和一定等于原数量。  |
|  要货日期    | 显示源单的分录的要货日期                                                                               |
|  订单状态    | 显示源单的订单状态，显示的数据受冲销方案上参数“未审核来源单据参与冲销”控制。                                                    |

=====2.3 冲销对象-预测单页签===== 

|  **字段**  |  **说明**                                                                               |
|  预测单     | 显示预测单的单据编号                                                                            |
|  分录号     | 显示预测单的分录号                                                                             |
|  客户      | 显示预测单分录的客户                                                                            |
|  物料      | 显示预测单分录的物料                                                                            |
|  原数量     | 显示预测单分录的基本单位数量                                                                        |
|  数量      | 当预测单没有经过供应规则拆分时，数量=原数量，不允许修改；当预测单经过拆分，则相同预测单+分录号的数量之和=原数量，可以手工调整拆分比例，但是分录行之和一定等于原数量。  |
|  预测开始日期  | 显示预测单分录的预测开始日期                                                                        |

=====2.4 冲销结果页签===== 
|  **字段**  |  **说明**                                                                  |
|  源单类型    | 显示目前参与冲销的单据，目前支持：销售订单/预测单/组织间需求单                                         |
|  源单编号    | 参与冲销的单据编号                                                                |
|  源单分录    | 参与冲销的源单分录                                                                |
|  单据状态    | 显示冲销的单据分录状态                                                              |
|  物料      | 显示冲销的单据物料                                                                |
|  基本单位    | 显示冲销物料的基本单位                                                              |
|  需求数量    | 来源于冲销对象页签中的数量。\\ MRP取数时：\\ 1、预测单：需求数量-已冲销数量-执行数量；\\ 2、其它单据：需求数量-已执行数量\\  |
|  冲销数量    | 预测单显示累计已被冲销数量，其它单据显示累计已冲销预测的数量                                           |
|  已执行数量   | 销售订单：数量-剩余未出数量；预测单：执行数量；组织间需求单：数量-剩余需求数量；                                |
|  需求日期    | 显示冲销对象中的要货日期或预测开始日期                                                      |


======3. 操作说明======

**直接冲销** 

点击直接冲销按钮，用户可以跳过冲销对象选择过程，所有符合要求的单据直接进行预测冲销，冲销完成后直接打开冲销结果。 

**交互冲销** 

点击下一步，系统根据冲销方案和冲销开始/结束时间过滤显示冲销单据和预测单，在此可以勾选取消参与冲销的单据。但是如销售订单是由预测单下推生成的，即使没有勾选，系统也会按销售订单与预测单的单据转换默认形成冲销关系。 

======4. 业务说明======

**冲销对象** 

  * 销售订单：根据选择的预测冲销方案中“冲销单据来源组织”，查找销售订单来源组织；根据找到的组织，读取这些组织的所有销售订单。

参与冲销的销售订单的来源单据不能是预测单；暂存状态的或已作废、已关闭的销售订单不参与冲销；销售订单分录的要货日期在冲销结束日期前的已审核的销售订单参与冲销；如果勾选“未审核销售订单参与冲销”，符合时间范围的未审核销售订单也要参与冲销。

销售订单的供应组织为空时的数据赋值逻辑：货主（有工厂/采购职能）->库存组织（有工厂/采购职能）->销售组织（有工厂/采购职能）；

  * 预测单：根据选择的预测冲销方案中的“预测单来源组织”对应过滤预测单的预测组织过滤预测单。

预测单可冲销数量=预测数量-执行数量；预测开始日期早于冲销结束日期的已审核且可冲销数量大于0预测单参与冲销；预测结束日期晚于冲销开始日期的已审核且可冲销数量大于0预测单参与冲销。

  * 组织间需求单：根据选择的预测冲销方案中“冲销单据来源组织”，查找组织间需求单需求组织；根据找到的组织，读取组织间需求单（组织间需求单.供应组织 in 预测单来源组织）

**冲销算法** 

  - 首先执行“单据.供应组织”不为空的单据冲销预测单的供应组织完全匹配的预测。
  - 再执行“单据.供应组织”为空的单据冲销预测单的供应组织为空的预测。
  - 最后执行 “单据.供应组织”不为空的单据冲销预测单的供应组织为空的预测。
  - 注意：单据.供应组织为空，不能冲销预测单.供应组织不为空的记录！
