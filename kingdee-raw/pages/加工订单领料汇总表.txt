======1   加工订单领料汇总表=======
=====1.1 报表功能=====

1.加工订单领料汇总表能够使用户能及时地了解加工订单的整体领料情况。

2.加工订单领料汇总表支持按照产品/车间/单据类型等多维度，进行查询加工订单的整体领料情况。


======2. 字段说明======
=====2.1 快捷过滤 =====

^  **字段**  ^  **说明**                                              ^
|  加工组织    | 1.定义报表查询的组织范围；\\ 2.必须具有加工职能，有且只能录入一个组织。              |
|  计划开工日期  | 1.加工订单分录行的计划开工日期；\\ 2.定义报表查询的计划开工日期范围。               |
|  计划完工日期  | 1.加工订单分录行的计划完工日期；\\ 2.定义报表查询的计划完工日期范围。               |
|  加工车间    | 1.加工订单的表体分录的加工车间；\\ 2.定义报表查询的加工车间范围。                 |
|  加工订单    | 1.加工订单的单据编号；\\ 2.定义报表查询的加工订单范围。                      |
|  产品编码    | 1.加工订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。                   |
|  单据类型    | 1.加工订单的单据类型；\\ 2.定义报表查询的加工订单的单据类型。                   |
|  业务状态    | 1.加工订单分录行的业务状态；\\ 2.包含：下达、开工、完工、结案，结算五个选项。           |
|  领料比例    | 1.加工订单分录行的领料比例；2.定义报表查询的加工订单领料比例范围。                  |
|  挂起状态    | 加工订单分录行的挂起状态。                                        |
|  物料控制项   | 1.用于确定报表中进行领料套数计算的物料范围；\\ 2.包含：所有物料、非倒冲物料、关键物料三个选项。  |
|  汇总类型    | 1.报表进行汇总的分类依据；\\ 2.包含：产品，车间+产品两个选项。                  |
=====2.2 报表字段 =====
^  **字段**    ^  **说明**                                                       ^
|  产品编码      | 加工订单表体分录对应的【物料编码】                                             |
|  产品名称      | 加工订单表体分录对应的【物料名称】                                             |
|  规格型号      | 加工订单表体分录对应的【规格型号】                                             |
|  加工单位      | 物料上的加工单位，                                                     |
|  计划加工数量    | 1.加工订单表体分录的【数量】；\\ 2.若加工订单分录的单位和物料的加工单位不一致，需要进行单位换算。          |
|  合格品入库数量   | 1.加工订单表体分录的【合格品入库数量】字段值；\\ 2.若加工订单分录的单位和物料的加工单位不一致，需要进行单位换算。  |
|  不合格品入库数量  | 1.加工订单表体分录的【不合格品入库数量】字段值；\\ 2.若加工订单的单位和物料的加工单位不一致，需要进行单位换算。   |
|  返工品入库数量  | 1.加工订单表体分录的【返工品入库数量】字段值；\\ 2.若加工订单的单位和物料的加工单位不一致，需要进行单位换算。   |
|  计划领料套数    | 为完成加工加工计划，预计需要领取的原材料套数。                                       |
|  已领套数      | 为完成加工加工计划，实际已经领取的原材料套数。                                       |
|  领料比例      | 领料比例=（已领套数/计划领料套数）*100%                                       |
