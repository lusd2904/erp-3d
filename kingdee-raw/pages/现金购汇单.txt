====== 现金购汇单 ======
=====1 功能说明  =====
记录现金购汇业务。

=====2 操作前提=====
定义了收款组织、单据类型、现金账号以及币别基础资料。

=====3 功能路径=====
【财务会计】—>【出纳管理】—>【日常处理】—>【现金购汇单】

=====4 字段说明=====
| **字段**     || **说明**                                   |
| 单据类型       || 单据类型为现金购汇单                               |
| 单据编号       || 现金购汇单的单据编号。                              |
| 收款组织       || 执行现金购汇的收款组织。已启用出纳系统                      |
| 业务日期       || 购汇业务发生的日期。是财务入账时业务所属财务期间的依据。             |
| 本位币        || 显示本次收款的收款组织所对应的默认核算体系的核算组织默认的会计政策的本位币。   |
| 汇率类型       || 显示本次收款的收款组织所对应的默认核算体系的核算组织默认的会计政策的汇率类型。  |
| 备注         || 录入转账备注信息。                                |
| 结算方式       || 现金业务类型的结算方式                              |
| 转入现金账号     || 款项转入的现金账号，不必录。                           |
| 转出现金账号     || 款项转出的现金账号，不必录。                           |
| 转入币别       || 录入所购外汇对应的币别。                             |
| 转入汇率       || 原币到本位币的汇率。根据对应的系统参数确定是否允许手工修改。           |
| 转入金额       || 录入实际转入的金额。                               |
| 转出币别       || 录入购汇所支付金额对应的币别。                          |
| 转出汇率       || 原币到本位币的汇率。根据对应的系统参数确定是否允许手工修改。           |
| 转出金额       || 录入实际转出的金额。                               |

=====5 操作说明 =====

1、用户通过新增现金购汇单，处理现金购汇业务。
