====== 生产退料请检单 ======

生产退料请检单，用于处理生产车间已领余料退回或不良物料的检验申请。

对于生产退料检验的物料，在退回仓库前，由生产人员根据生产用料清单生成生产退料请检单对车间的材料提出请检，经过检验后，根据质量情况分别以不同的库存状态退到仓库。


**使用前提**

生产退料请检，物料-质量页签下，【生产退料检验】勾选；

**功能路径**

【质量管理】－>【质量管理】－>【生产退料请检单】

**字段说明**

  *  表头

| **字段**     || **说明**                                                                |
| 单据类型       || 生产退料请检单的单据类型；\\ 系统预设有：生产退料请检单                                         |
| 单据日期       || 制作请检单的日期，新增时，默认显示当前系统日期；\\ 用户可对日期进行修改。                                |
| 生产组织       || 若当前登陆组织具有生产职能，默认取当前组织；否则为空 ；\\ 可选择有生产职能的组织                            |
| 收料组织       || 若当前登陆组织具有库存职能，默认取当前组织；否则为空 ；\\ 可选择有库存职能的组织                            |
| 生产车间         || 调用部门基础资料。\\ 合法值范围：已审核、未禁用的部门属性是基本生产或辅助生产的部门                        |
| 库存组        || 业务组类型为“库存组”的业务组                                                       |
| 单据状态       || 由系统根据单据操作自动标识\\ 暂存：暂存；\\ 保存：创建；\\ 提交：审核中；\\ 审核通过：已审核；\\ 反审核：重新审核。     |

  * 明细页签

| **字段**     || **说明**                                                             |
| 序号         || 由系统按分录顺序递增显示1、2、3…，为自动生成，锁定                                        |
| 物料编码       || 携带源单物料编码，不可修改和手动新增  |
| 物料名称       || 根据物料编码携带其物料名称                                                      |
| 规格型号       || 根据物料编码携带其规格型号                                                      |
| 单位         || 默认携带源单位，可修改；                                                      |
| 数量         || 请检数量，取单位精度；                                                        |
| 仓库         || 请检物料所在的仓库；                                                         |
| 仓位         || 仓库启用仓位管理时，仓位才需要维护且必录。                                              |
| 库存状态       || 请检物料所在仓库里的库存状态；                                                    |
| 批号         || 可录入批号主档中存在的批号、手动录入或者通过“获取批号”按钮生成新的批号                                                    |
| 生产车间        || 携带生产用料清单的生产车间                                                     |
| 工序号      || 携带生产用料清单的工序号                                                    |
| 作业     || 携带生产用料清单的作业                                                   |


  * 库存页签

| **字段**     || **说明**                                                                                               |
| BOM版本      || 物料在库存属性控制中启用了“BOM版本”，该字段可维护且必录。\\ 否则，灰显不可维护。 可选择物料对应的审核状态的BOM版本；                                     |
| 辅助属性       || 启用辅助属性的物料，可以录入辅助属性值；                                                                                 |
| 保质期单位      || 携带物料中的保质期单位                                                                                          |
| 保质期        || 携带物料中的保质期                                                                                            |
| 货主类型       || 携带源单货主类型 1.修改货主类型时，影响货主字段；\\ 2.取值范围：组织、供应商、客户。                                                       |
| 货主         || 携带源单货主，货主为物料所有权的持有者；\\ 1.货主类型为业务组织时，货主取业务组织；\\ 2.货主类型为供应商时，货主取供应商；\\ 3.货主类型为客户时，货主取客户。               |
| 保管者类型      || 物料的保管者的类型，包含供应商、业务组织和客户                                                                              |
| 保管者        || 保管者为物品保管权的所有者\\ 1.保管者类型为业务组织时，保管者取业务组织：\\ 2.保管者类型为供应商时，保管者取供应商；\\ 3.保管者类型为客户时，保管者取客户。                |
| 生产日期       || 物料启用保质期管理时，该字段允许维护，否则锁定 1、从批号主档携带；2、手工录入。源单是生产领料单和生产补料单时携带源单的生产日期。                                   |
| 有效期至       || 启用保质期管理的物料，该字段可维护；生产日期<有效期至<=生产日期+保质期（按天计算），生产日期修改，自动更新有效期至=生产日期+保质期（按天计算）；源单是生产领料单和生产补料单时携带源单的有效期至  |
| 计划跟踪号      || 物料计划策略为MTO，可编辑，否则不可编辑                                                                                |
