====== 实物类别 ======


====== 1 功能说明 ======

实物类别是对实物资产进行分类，同一类型的实物资产可分为一个类别。实物类别也是员工领用资产时进行智能匹配分配资产的依据。


====== 2 功能路径 ======

【资产管理】-->【人人资产管理】-->【基础资料】-->【实物类别】


====== 3 主要字段说明 ======

^ 字段名       ^ 说明                                            ^
| 创建组织      | 默认携带当前组织，不允许修改。                               |
| 使用组织      | 默认携带当前组织，不允许修改。                               |
| 编码        | 实物类别的编码。                                      |
| 名称        | 实物类别的名称，用户输入。                                 |
| 启用智能匹配    | 默认不勾选，勾选后则该实物类别启用智能匹配，在资产领用单提交时进行智能匹配分配实物资产。  |
| 匹配条件      | 来源于资产卡片上的字段，可根据此字段设置智能匹配时实物资产的排序依据。           |
| 匹配方式      | 包含升序和倒叙两种方式。                                  |
| 来源字段      | 根据字段进行模糊智能匹配，来源字段主要是人人资产下资产领用单上的申请资产名称和备注。    |
| 匹配字段      | 根据资产卡片上的资产名称，资产卡片上实物信息页签的规格型号与备注进行匹配。         |
| 智能匹配实物明细  | 根据所选的实物类别可联查到该类别下包含的实物资产明细。                   |



====== 4 操作说明 ======

新增实物类别，操作步骤：
  - 【资产管理】–>【人人资产管理】–>【基础资料】–>【实物类别】下点击新增；
  - 在单据新增界面可输入名称，勾选启用智能匹配，设置智能匹配规则下的排序字段，设置字段智能匹配下的匹配字段；
  - 单击保存按钮完成人人资产实物类别的保存；
  - 单击提交按钮完成人人资产实物类别的提交。


====== 5 使用说明 ======
  - 新增实物类别，设置匹配规则与匹配字段后，启用智能匹配。
  - 在实物类别批量指定中，可对已有的所有实物资产进行批量指定实物类别。
  - 员工新增人人资产的资产领用单，选择实物类别，输入申请的资产名称与数量。
  - 提交资产领用单，系统根据该实物类别下的所有实物资产，对未领用完的实物资产，按照实物类别所设置的匹配字段进行智能匹配，符合匹配结果的实物资产有多个的情况下，按照匹配规则下的排序依据分配实物资产至资产领用单上。
  - 智能匹配采用字段匹配的情况下，根据一定的算法进行判断，计算出最接近用户申请的资产，对于用户输入的资产名称与资产卡片的资产名称相差较大的情况下，匹配结果准确性可能会存在一定的偏差。
