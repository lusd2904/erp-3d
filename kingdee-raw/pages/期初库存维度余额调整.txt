====== 期初库存维度余额调整 ======
===== 发布说明 =====
补丁号：PT-146911
，上线日期：2022年5月19日
===== 功能概述 =====
用于调整物料在同一个核算维度下不同库存维度的期初结存金额异常的问题，如下图：
^ 物料    ^ 仓库    ^期初数量 ^ 期初单价  ^期初金额  |
| A001  | 原材料仓  |    10 |     1 |    10 |
| A001  | 半成品仓  |    20 |   2.5 |    50 |
| 合计    |       |    30 |     2 |    60 |

===== 操作流程 =====

  * :!:期初库存维度余额调整—>选择出单维度—>点击出单
  * :!:如果当期做了期初库存维度余额调整，但是需要进行反结账修改前期存货数据时，请自行判断是否需要删除当期做的期初库存维度余额调整单

===== 关键应用 =====
  * 出单
  * 反出单

{{:期初库存维度余额调整.png?1200|}}

  * 出单产生的调整单类型设置

{{:出单类型设置.png?1200|}}

===== 出单规则 =====
  * 此功能会以物料核算维度的单价乘以库存维度数量计算出的核算维度期初余额，再通过出单的方式将实际库存维度的余额差额在各个库存维度中进行调整

^  库存维度数量  ^ 核算维度单价  ^ 是否允许出单  ^ 调整单类型  ^ 调整单调整原因     ^ 调整单来源类型       ^ 是否需要生成凭证  ^
| 无        | 零       | 允许      | 自定义    | 期初核算维度余额调整  | 期初核算维度余额调整产生  |  是        |
| 有        | 零       | 不允许     | | | | |
| 有        | 正单价     | 出单      | 自定义    | 期初库存维度余额调整  | 期初库存维度余额调整产生  |  否        |
| 有        | 负单价     | 不允许     | | | | |

 

===== 字段说明 =====
^  字段              ^  说明                            ^
| 期初数量             | 取存货收发存汇总表（按库存维度显示）时，库存维度的期初数量  |
| 库存维度期初单价         | 取存货收发存汇总表（按库存维度显示）时，库存维度的期初单价  |
| 库存维度期初金额         | 取存货收发存汇总表（按库存维度显示）时，库存维度的期初金额  |
| 核算维度期初单价         | 取存货收发存汇总表（按核算维度显示）时，库存维度的期初单价  |
| 按核算维度期初单价重算期末余额  | 期末数量*核算维度期初单价                  |
| 金额差异             | 库存维度期初金额-按核算维度期初单价重算期初余额       |
