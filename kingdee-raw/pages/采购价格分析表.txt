====== 1功能概述 ======

采购价格分析表用于查询物料的采购当前的价目表信息，折扣信息，并可展示单据的历史采购价格信息，并能依据历史采购价格对下一期采购价进行预测。

====== 2使用前提 ======

存在实际发生的业务数据

====== 3功能路径 ======

【供应链】－>【采购管理】－>【报表分析】－>【采购价格分析表】

====== 4报表过滤条件 ======

过滤条件区域包括页签：快捷、条件、排序、显示隐藏列。
  - 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间
  - 条件页签：为快捷页签的补充，支持同一字段的分段区间并集
  - 排序页签：设置报表显示界面数据的排序方式
  - 显示隐藏列页签：可设置报表显示界面字段列是否隐藏
下面针对快捷过滤页签字段进行详细说明

报表快捷过滤字段说明
^ 字段           ^ 说明                                           ^
| 业务组织         | 用于筛选采购订单范围，选择相应单据主业务组织                       |
| 价格来源         | 包括采购订单和采购发票，采购入库单，应付单（暂估模式：财务应付单；业务模式：业务应付单），默认：采购订单                |
| 取价维度         | 可选项：物料，物料+供应商，在取订单或发票时，通过取价维度确定取价匹配单据，默认：物料  |
| 平均价类型        | 算术平均价，移动平均价，默认移动平均价                          |
| 取价范围（月）      | 取价单据时间范围                                     |
| 单据状态         | 指定选取的单据状态，默认：已审核                             |
| 物料字段         | 需要查询的物料编码，必输                                 |
| 供应商字段        | 输入供应商范围或编码，用于查询对于单据                          |
| 价格预测回溯范围（月）  | 设定价格预测回溯的单据日期范围。默认12月                        |
| 含税价          | 是否去含税价                                       |
| 业务类型         | 单据的业务类型，默认：标准采购订单                            |
| 存货类别         | 物料存货类别                                       |

表体综合字段
　　　　　　　
^ 字段       ^ 说明                                                                                                                             ^
| 最近采购价    | 查询区间的最近一次采购单据的采购价格，若勾选含税，取含税价，不勾选则取单价 排除单价为0值                                                                                  |
| 最高价      | 查询区间的采购单据的采购最高价格，若勾选含税，取含税价，不勾选则取单价 排除单价为0值                                                                                    |
| 最低价      | 查询区间的采购单据的采购最低价格，若勾选含税，取含税价，不勾选则取单价， 排除单价为0值                                                                                   |
| 平均价      | 查询区间的采购单据的采购价格，根据平均价类型计算平均价值，若勾选含税，取含税价，不勾选则取单价 排除单价为0值，移动平均价计算公式：(x1w1+x2w2+……+xnwn)/(w1+w2+……+wn)， 算术平均价计算公式：(a1+a2+…+an)/n  |
| 采购量最大价格  | 查询期间内单次采购数量最大的价格，排除单价为0值                                                                                                       |
| 采购量最小价格  | 查询期间内单次采购数量最小的价格，排除单价为0值                                                                                                       |
| 年度最大价格   | 按截止时间的对应年度查询本年度采购最大价格，依据筛选条件的含税价取值。 排除单价为0值 从截止时间的年度1月1日，至12月31日                                                               |
| 年度最小价格   | 按截止时间的对应年度查询本年度采购最小价格，依据筛选条件的含税价取值。 排除单价为0值 从截止时间的年度1月1日，至12月31日                                                               |
| 年度平均价    | 按截止时间的对应年度查询本年度采购平均价格，依据筛选条件的含税价和平均价类型计算。 排除单价为0值 从截止时间的年度1月1日，至12月31日                                                         |
| 预测价格     | 依据参数中设定的价格预测回溯范围中设定的时间长度，查询区间的单据价格，采用一次线性回归预测算法计算下一期采购预测价格。                                                                    |
