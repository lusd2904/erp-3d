 ====== 报表项目 ====== 

**功能说明**

报表项目是报表系统的基础，如同我们日常记账时需要科目一样。报表项目的设置完全依据企业管理与分析的需要而设置，企业需要什么样的报表，就可以将报表上的所有项目指标对应设置为报表项目。

**功能路径**

【财务会计】→【报表】→【基础资料】→【报表项目】

**操作说明**

系统预设了新会计准则的报表项目。报表项目不需要进行审核等流程控制，保存即可被报表模板或报表引用。
 ====== 字段说明 ======
| 字段          || 说明                                                                                                                                                                                                                 |
| 项目编码        || 报表项目的编码，唯一标识，手工录入。                                                                                                                                                                                                 |
| 项目名称        || 报表项目的名称，手工录入。\\ 如：利润表中指标“一、营业收入”，该指标的项目名称为：“营业收入”。                                                                                                                                                                 |
| 项目类别        || 报表项目的分类，需要在报表项目类别界面进行新增才能被选择到。下拉列表选择已存在的报表项目类别。                                                                                                                                                                    |
| 报表显示名称      || 报表项目在报表中的显示内容，手工录入。如：利润表中指标“一、营业收入”，该指标的报表显示名称为：“一、营业收入”。                                                                                                                                                          |
| 自定义属性       || 不同于项目类别的又一种分类，方便报表项目的检索用。\\ 手工录入。                                                                                                                                                                                  |
| 计算项/文本项     || 当报表项目有数据值，则为“计算项”，即：需要通过取数计算，可用于后期数据分析。\\ 当报表项目仅仅是报表上的一个分类显示项，则为“文本项”。\\ 如：资产负债表中“流动资产:”，仅仅是报表的分类。                                                                                                                 |
| 取数类型        || 如果项目是计算项，需要确定取数来源类型。科目：选择科目表、科目。\\ 选择的科目，将在“报表批量填充”功能中，系统自动填入ACCT函数的科目参数；\\ 现金流量项目：选择现金流量项目基础资料。选择的现金流量项目，将在“报表批量填充”功能中，系统自动填入ACCTCASH函数的现金流量项目参数；\\ 项目合计：选择报表项目。选择的项目，将用于“报表批量填充”，系统自动将报表项目转换为当前表页中的该项目所在的单元格名称；  |
| 关系表达式       || 选择了科目/现金流量项目/报表项目后，点击【插入】按钮填入关系表达式文本框。\\ 与科目/现金流量项目/报表项目间可用“+”“-”符号进行关联。                                                                                                                                           |

 ====== 关系表达式查验 ====== 

**功能说明**

检查选择中的报表项目，其关系表达式的科目、现金流量项目、报表项目是否存在于系统

**功能路径**

【财务会计】→【报表】→【基础资料】→【报表项目】→【业务操作】→【关系表达式查验】

**操作说明**

勾选一个或多个报表项目，点击【关系表达式查验】，检查完成后出现检查结果提示。
