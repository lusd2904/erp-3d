====== 1功能概述 ======


设置货源清单

====== 2使用前提 ======


定义采购组织、供应商、物料、单位等。
====== 3功能路径 ======


【供应链】－>【采购管理】－>【货源与价格管理】－>【货源清单】

====== 4字段说明 ======

===== 4.1基本信息 =====

==== 采购组织 ====

货源清单适用的采购组织
==== 其他字段 ====

|字段||说明|
|编码||货源清单的编码，编码必须唯一|
|名称||货源清单的名称|
|失效||货源清单是否失效|
|描述||指货源清单的补充说明|
===== 4.2其他 =====

|字段||说明|
|创建人||指创建货源清单的用户|
|创建日期||指创建货源清单的日期|

==== 配额比例 ====

==== 辅助属性 ====

====== 5操作说明 ======
===== 5.1失效与反失效 =====
  * 当采购管理策略发生变化时，用户可以在列表或者单据界面对货源清单进行失效操作。 
  * 失效操作是针对货源清单整单的操作。 
  * 只有未失效的货源清单才能产生作用。 
  * 用户数字列表项目可以对已失效的货源清单进行反失效操作。 

===== 5.2业务失效与业务反失效 =====
  * 当采购管理策略发生小幅度变化时，用户可以在列表或者单据界面对货源清单进行业务失效操作。 
  * 失效操作是针对货源清单分录行的操作。 
  * 只有未业务失效的货源清单分录才能产生作用。 
  * 用户可以对已业务失效的货源清单进行业务反失效操作。
