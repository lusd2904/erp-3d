=====物料别供应商质量比较表=====

**功能描述**

企业按物料+供应商统计某段时间的供货情况，便于分析、对比供应商供应某种物料质量状况。

**过滤条件**

“快捷”页签：快捷页签为报表常用过滤条件的设置界面。

“条件”页签：进一步设置过滤条件的设置界面。

“排序”页签：可按照用户关心的选项，设置报表中明细行的排列顺序。

“显示隐藏列”页签：设置报表显示什么字段及显示顺序。

“分组汇总”页签：设置分组汇总字段。

**快捷过滤**

| **字段**     || **说明**                                                                                                                                            |
| 来源组织       || 1、具有工厂职能的业务组织；\\ 2、可多选；                                                                                                                           |
| 质检组织       || 1、具有质检职能的业务组织；\\ 2、可多选；\\ 3、如果没有选择质检组织，表示质检组织为空或者质检组织为任何组织。                                                                                       |
| 日期         || 即当前所查询的业务内容发生的起止日期，包括起始日期和截止日期\\ 1、采购收料单的单据日期的起始日期与截止日期范围；\\ 2、检验单的质检完成日期的起始日期与截止日期范围；\\ 3、起始日期不能大于截止日期，用户过滤界面点击【确定】按钮时判断，并给出提示【截止日期必须大于等于起始日期】。  |
| 供应商        || 来源组织下的审核未禁用的供应商                                                                                                                                   |
| 物料编码       || 来源组织下的审核未禁用质量页签的【来料检验】为勾选的物料；                                                                                                                     |
| 单据状态       || 1、提供选项：创建、审核中、已审核、重新审核\\ 2、默认全部                                                                                                                   |
| 业务类型       || 1、提供选项：采购检验、委外检验；\\ 2、支持多选                                                                                                                        |
| 汇总依据      || 1、提供选项：物料+供应商、供应商、物料；\\ 2、根据汇总依据汇总统计检验单数量、以及合格率 |
| 仅显示汇总行      || 1、汇总依据为供应商或者物料时可修改，可勾选；\\ 2、参数勾选后根据汇总依据，仅显示汇总（小计）行 |
**报表字段**

| **字段**     || **说明**                                                                                                                                                                                                                    |
| 供应商        || 1、从符合条件的采购收料单取“供应商”；\\ 2、从符合条件的来料检验单取“供应商”；\\ 3、从符合条件的不良品处理单取“供应商”。                                                                                                                                                       |
| 物料编码       || 1、单据日期在过滤条件中起始日期和截止日期范围内，已审核的采购收料单分录的物料编码；\\ 1.1、物料的【来料检验】勾选；\\ 2、取质检完成日期在过滤条件中在起始日期和截止日期范围内的来料检验单分录的物料编码；\\ 2.1、来料检验单分录的检验结果不为“保留”；2.2、来料检验单分录的使用决策_挑选（全检）数量<>“检验数量”；\\ 3、取审核日期在过滤条件中在起始日期和截止日期范围内的有源单的来料不良品处理单分录的物料编码；  |
| 物料名称       || 携带物料的【物料名称】                                                                                                                                                                                                               |
| 规格型号       || 携带物料的【规格型号】                                                                                                                                                                                                               |
| 单位         || 取值顺序：\\ 1、物料的“采购单位”；\\ 2、物料的“基本单位”                                                                                                                                                                                        |
| 来料数量       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的采购收料单分录（Σ实收数量）                                                                                                                                                                      |
| 检验数量       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件件的来料检验单其使用决策中没有勾选【不良处理】的{(Σ(接收数+让步接收数+判退数+工废数+料废数))+符合条件的紧急放行不存在下游来料检验单的采购收料单分录的（Σ实收数量）}相同来源组织+业务类型+物料+供应商，符合条件的不良品处理单(Σ(让步接收数+判退数+工废数+料废数))                                     |
| 接收数量       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的来料检验单（Σ使用决策_接收数）+符合条件的紧急放行不存在下游来料检验单的采购收料单分录的（Σ实收数量）                                                                                                                                |
| 让步接收数量     || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的来料检验单其使用决策中没有勾选【不良处理】的（Σ使用决策_让步接收数）+符合条件的不良品处理单的（Σ使用决策_让步接收数）}                                                                                                                 |
| 判退数量       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的来料检验单其使用决策中没有勾选【不良处理】的（Σ使用决策_判退数）+符合条件的不良品处理单的（Σ使用决策_判退数）}                                                                                                                    |
| 合格率%       || 合格率%=（接收数量/检验数量）*100%                                                                                                                                                                                                     |
| 接收率%       || 接收率%={（接收数量+让步接收数量）/检验数量}*100%                                                                                                                                                                                            |
| 收料批数       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的采购收料单分录数                                                                                                                                                                            |
| 检验批数       || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的（来料检验单分录数）                                                                                                                                                                          |
| 不合格批数      || 过滤条件中在起始日期和截止日期范围内：相同来源组织，根据汇总依据汇总统计符合条件的来料检验单检验结果为“不合格”的分录数                                                                                                                                                                 |
| 批次合格率       || 批次合格率=【（检验批数-不合格批数）/检验批数】*100%                                                                                                                         |
| 来源组织       || 1、从符合条件的采购收料单取“收料组织”；\\ 2、从符合条件的来料检验单取“源单组织”；\\ 3、从符合条件的不良品处理单取“源单组织”                                                                                                                                                     |
| 质检组织       || 从符合条件的来料检验单取“质检组织”从符合条件的不良品处理单取“质检组织”                                                                                                                                                                                     |
| 业务类型       || 1、从符合条件的采购收料单的业务类型取值：\\ 1.1、采购收料单为“标准采购”，业务类型为“采购检验”；\\ 1.2、采购收料单为“标准委外”，业务类型为“委外检验”；\\ 2、从符合条件的来料检验单取“业务类型”；\\ 3、从符合条件的不良品处理单取“业务类型”                                                                                     |
