ID: 成本管理系统参数
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%88%90%E6%9C%AC%E7%AE%A1%E7%90%86%E7%B3%BB%E7%BB%9F%E5%8F%82%E6%95%B0

存货系统参数设置增加了存货核算功能应用的灵活性，参数的选择直接会影响存货核算的成本结果。因此一旦设置好参数后，不要轻易变更。

======1 功能路径 ======


【成本管理】－>【存货核算】－>【参数设置】－>【成本管理系统参数】


======2 参数说明 ======
=====2.1 基本参数 =====


^ 参数名称              ^ 参数说明                                                                                                                                                                                             ^
| 期末结账结转核算明细过程数据    | - 在核算应用参数中有勾选“写成本计算过程”的前提下，如果勾选，则可在“存货核算明细报告”中查询历史期间的成本核算过程。\\   - “写成本计算过程”参数在“出库成本核算”及“成本计算"的向导页中，勾选后，系统将在在核算过程中保存成本价的计算过程。\\   - 先进先出法核算下务必勾上“写成本计算过程”和“期末结账结转核算明细过程数据”，方便查看先进先出法的取价过程和分析成本。  |
| 核算单据查询成本后维护不更新余额  | - 在核算单据查询中修改核算单据成本以后，会自动更新后台余额表，如果勾选此参数，则不更新，可减少维护成本后的刷新及等待时间。\\   - 修改完之后需要勾选"出库核算不更新已修改成本的核算单据成本”参数再做核算。\\   - 更多详细情况请查看：[[https://vip.kingdee.com/article/913|外部链接]]                          |
| 存在负库存允许结账         | - 严格来讲负库存是不合理的业务，但出于某些特殊场景，存在库存管理允许负库存，那成本期末结账相应的也需提供负库存允许结账。\\   - 先进先出法不允许负库存允许结账，此参数对先进先出法核算无效。                                                                                               |




=====2.2 存货核算参数 =====
^ 参数名称                    ^ 参数说明                                                                                                                                                                                                                                                                                                                                                   ^
| 应付单与发票核销产生的差异计入存货成本     | - 参数介绍：应付单与发票存在差异时，通过应付开票核销会生成调整的应付单，此参数就是决定这部分差异是否需调整存货成本，系统默认进行调整。勾选时，应付单和发票之间的核销差异计入存货成本，不勾选时，应付单和发票之间的核销差异不计入存货成本。此参数对与启用了应付暂估冲回模式同样生效，即勾选时，暂估应付单与财务应付单之间的核销差异计入存货成本。不勾选时，暂估应付单与财务应付单之间的核销差异不计入存货成本。                                                                                                                                               |
| :::                     | - 应用场景：材料采购按标准成本/计价成本进行核算，采购入库单关联的应付单按照标准成本价/计划成本价确认材料入库成本，应付单与发票核销的差额计入总账采购成本差异，月末再依据材料耗用情况，将采购成本差异余额结转至损益。勾选此参数就可以满足这种业务场景。                                                                                                                                                                                                                          |
| :::                     | - 注意事项：改参数对历史数据不生效。例如：未勾选此参数的情况下，审核了发票或者财务应付单，采购入库核算后，又勾选了此参数。这个时候，也不会重新计入成本。                                                                                                                                                                                                                                                                          |
| 采购应付单审核时自动进行入库成本核算      | - 参数介绍：该参数的作用是决定采购入库单（采购退料单）、物权转移单下推采购应付单审核时是否自动调用采购入库成本核算，若勾选该参数，采购应付单审核时根据单据间勾稽关系自动核算入库成本；若不勾选该参数，采购应付单审核时只建立单据间勾稽关系而不会自动核算入库成本。大批量审核采购应付单时，不勾选该参数可以提高审核的效率。                                                                                                                                                                                         |
| :::                     | - 注意事项1：因金蝶AI星空支持多核算体系多会计政策的成本核算，此参数只对默认会计核算体系默认会计政策下的核算组织入库成本核算生效，其他的需执行入库成本核算统一核算。                                                                                                                                                                                                                                                                    |
| :::                     | - 注意事项2：当前核算期间，审核本期间内的应付单（入库单/退料单/物权转移单）                                                                                                                                                                                                                                                                                                               |
| 存在负库存时允许结账              | - 该参数决定当前会计期间存在负库存时是否能结账。期末结账时若检查当期存在负库存，勾选该参数，则允许结账；不勾选该参数，则不允许结账，必须先清理负库存。从财务管控的角度来看，建议不使用该参数！                                                                                                                                                                                                                                                       |
| 赠品、不良品、废品单据成本为零时允许结账    | - 参数介绍：成本核算时，如果存在零成本单据的情况，合法性检查报告会给予警告提示，相应在期末结账时会对零成本单据进行检测不允许结账，勾选这个参数则允许当单据上勾选“赠品”或者物料的库存状态为“不良品”、“废品”的单据成本为零时允许结账。                                                                                                                                                                                                                                 |
| :::                     | - 关联知识：金蝶AI星空《零成本管理解决方案》，请点击：[[https://vip.kingdee.com/questions/148040/answers/174765|外部链接]]                                                                                                                                                                                                                                                           |
| 核算后不反写单据列表成本            | - 参数介绍：在单据量大的情况下，核算过程中，将成本价反写到单据上会消耗太多性能。勾选此参数可以提高核算性能。默认不勾选，勾选后只是不再反写单据体上的成本价和总成本字段，在单据列表中也看不到总成本和成本价，但不影响凭证生成。                                                                                                                                                                                                                                       |
| :::                     | - 应用场景：想要提升核算速度，不需要在单据列表中查看成本价和总成本。                                                                                                                                                                                                                                                                                                                    |
| 核算完成后进行组装拆卸单零成本单据批量核算   | - 参数介绍：启用了产品成本核算模块，当同一个物料既有组织拆卸任务又有生产业务时，改造后的核算逻辑仍然无法一次性算出成本。勾选此参数，在成本计算以后再次调用“其他存货核算”保存功能，按照核算出的组装拆卸出库成本计算组织拆卸入库的成本。                                                                                                                                                                                                                                  |
| :::                     | - 应用场景：有组装拆卸业务和生产业务，同时又启用了产品成本核算需要勾选此参数。                                                                                                                                                                                                                                                                                                               |
| 期末结账不检查组织间交易单据是否生成      | - 参数介绍：为了防止组织间交易单据的缺失，在结账时增加对组织间交易单据的检查。用户可在组织间结算模块进行检查，存货模块不勾选此参数，以节省结账时间。                                                                                                                                                                                                                                                                            |
| :::                     | - 应用场景：关账前，当期所有组织间结算单据已经生成，结账检查耗用在检查“组织间交易单据是否生成”的时间较长。                                                                                                                                                                                                                                                                                                |
| :::                     | - 关联知识：“组织间结算模块检查”是否生成组织间交易单据的功能介绍：[[https://vip.kingdee.com/questions/17005|外部链接]]                                                                                                                                                                                                                                                                    |
| 按核算组织显示存货类别             | - 参数介绍：当物料在核算组织的存货类别与其下级业务组织不一致时，报表按物料在核算组织下的存货类别显示。                                                                                                                                                                                                                                                                                                   |
| :::                     | - 应用场景：a、当用户采用报表对账，且需要按照存货类别进行核对时;  b、同一个核算组织下不同业务组织，物料有不同的存货类别。当有上面两种情况时，就会出现同一物料多个存货类别，导致明细核对不上。勾选此参数后，报表全部按照核算组织下的存货类别显示，即可解决这种问题。                                                                                                                                                                                                                  |
| :::                     | - 注意事项：如果以存货类别作为科目的核算纬度，物料已经使用务必不要再修改“存货类别”。                                                                                                                                                                                                                                                                                                           |
| 出库序列退货方向单据参与加权计算        | - 参数介绍：勾选后，出库序列的退货方向的单据的数量和金额会纳入成本核算，影响出库成本。                                                                                                                                                                                                                                                                                                           |
| :::                     | - 应用场景：应用场景及使用介绍，请点击：[[https://vip.kingdee.com/article/12460|外部链接]]                                                                                                                                                                                                                                                                                    |
| :::                     | - 关联知识：了解出库序列退货方向单据，请点击：[[https://vip.kingdee.com/questions/16989/answers/22180|外部链接]]                                                                                                                                                                                                                                                                 |
| 销售退货单通过退货通知单和获取销售出库单成本  | - 参数介绍：勾选后，解决销售出库单下推退货通知单，再由退货通知单下推销售退货单时，销售退货单无法取销售出库单成本的问题。如果同时勾选“不取源单成本”，此参数仍然有效。                                                                                                                                                                                                                                                                   |
| :::                     | - 应用场景：更多应用知识，请点击：[[https://vip.kingdee.com/article/13416|外部链接]]                                                                                                                                                                                                                                                                                       |
| 采购入库调整单生成出库成本调整单        | - 参数介绍：通过出库成本调整单对自动生成的期初入库成本调整金额进行调整。调整的金额根据参数进行处理                                                                                                                                                                                                                                                                                                     |
| :::                     | - 应用场景：更多应用知识请点击：[[https://vip.kingdee.com/article/12287|外部链接]]                                                                                                                                                                                                                                                                                        |
| 采购费用自动分配标准设置            | - 参数介绍：费用应付单分录行勾选“计入成本”，并勾选入库单据审核时会自动进行采购费用分配，支持按入库数量和金额两种方式进行分配。                                                                                                                                                                                                                                                                                      |
| :::                     | - 应用场景：业务人员在收到采购费用发票时，在应付单上选择采购费用相关的入库单。不需要再在“采购费用分配界面”进行采购费用分配。                                                                                                                                                                                                                                                                                       |
| 核算日期排序方式                | - 参数介绍：用户如果选择先进先出法或者移动平均法进行核算，业务单据按照选择的排序方式进行出库核算。提供：“业务日期+创建日期”和“业务日期+审核日期”两种排序方式，其中业务日期为短日期（年月日），创建日期和审核日期为长日期（年月日时分秒）。默认为“业务日期+审核日期”。                                                                                                                                                                                                               |
| :::                     | - 应用场景：当采用“业务日期+创建日期”进行核算单据排序时，如果存在补单情况容易造成负库存，此时修改为“业务日期+审核日期”可以解决这种原因导致的负库存问题。                                                                                                                                                                                                                                                                       |
| :::                     | - 注意事项：先进先出法可启用参数：启用先进先出法按当期入库顺序取价。                                                                                                                                                                                                                                                                                                                    |
| 不取源单成本                  | - 参数介绍：勾选此参数后，由库存单据下推生成的出库单据在核算时不再取源单成本                                                                                                                                                                                                                                                                                                                |
| :::                     | - 应用场景：请点击：成本管理系统参数：[[https://vip.kingdee.com/article/182419|外部链接]]                                                                                                                                                                                                                                                                                    |
| 生产月末在制转移本期转入取上期转出成本     | - 参数介绍：由于生产月末在制转移的领料单与退料单没有原单关系，无法直接获取退料单成本。为了保证在制金额的一致，可启用此参数。                                                                                                                                                                                                                                                                                        |
| 允许核算组织内调拨单成本不一致         | - 参数介绍：1.1 当勾选时，允许异价调拨，逻辑与现在系统一致，用户可以手工修改同一个核算组织内的分步式调出单、调入单成本。1.2 当不勾选时，不允许异价调拨。同一期间：用户不可以手工修改同一个核算组织内的分步式调出单、调入单成本的时候，同步相关联的分步式调出单和调入单。不同期间：分步式调出单和调入单不在同一期间，不允许维护调入方向（分步式调入单、分步式调出单（退货））的单据成本。                                                                                                                                                      |
| :::                     | - 应用场景：经常会有用户修改了分步式调出单或者调入单成本，忘记修改另一方的成本，又没有生成凭证，导致存货对账差异。因此，标准产品增加此参数，并在“合法性检查报告”中增加了对“算组织内调拨单成本不一致”的检查，帮助用户杜绝这种问题。如果本身就有异价调拨业务的企业用户，可以保持勾选这个参数，允许异价调拨。                                                                                                                                                                                               |
| 零成本单据参与加权计算             | - 参数介绍：当勾选此参数时，特定的入库单据零成本会参与加权计算。此参数为管理中心级，需要用管理员权限进行选择。单据包括：1.1 不同核算范围下的零成本直接调拨单（入库）、分布调拨入库单、分步式调出单（退货）、批号调整单（入库）、库存状态转换单（入库）； 1.2 零成本组装拆卸入库单 ；1.3 移动平均法下的出库单据                                                                                                                                                                                        |
| :::                     | - 应用场景：为了解决存在循环调拨，保证出库价格不偏低，当上述入库单据是零时，核算过程中首次加权不会把零成本的入库单据纳入加权计算。但同时也会影响正常的零成本场景，例如：赠品入库以后，从一个核算范围调拨到另一个核算范围， 调拨入库没有参与加权，此时如果勾选此参数，零成本的调拨入库就会参与加权计算。                                                                                                                                                                                                  |
| 启用先进先出法按当期入库顺序取价        | - 参数介绍：不启用这个参数的情况下，先进先出法会按照入库和出库的先后顺序进行取价，一旦出库单据前的账面结存不够，就无法取价，导致核算报错“存在账面负结存”。启用该参数后，出库单据将在当期同一库存维度中的入库单据里依照入库先后顺序取价（不考虑入库单据是否在出库单据之后），对于账面负结存的检查也只结存当期期末的实际结存。                                                                                                                                                                                       |
| :::                     | - 应用场景：做单不规范，出入库单据顺序混乱，导致按照先进先出法核算并提示账面负结存的场景。                                                                                                                                                                                                                                                                                                         |
| 先进先出法嵌套取价规则             | - 参数介绍：包含“自动打断”和“自动跳过”两种选择。仅当勾选了“启用先进先出法按当期入库顺序取价”时显示。                                                                                                                                                                                                                                                                                                 |
| :::                     | - 应用场景：勾选“启用先进先出法按当期入库顺序取价”时，先进先出法下，退货类单据属于入库序列，因此会发生出库单据取其下推的退货入库单据的成本，例如：销售出库单下推的销售退货单，销售退货单取销售出库单成本，但是销售出库单又会按照先进先出法取到其下推的销售退货单的成本。这样就发生了嵌套。如果勾选“自动打断”，则系统断开掉这种原单关系，退货单成本则需要手工维护。如果勾选“自动跳过”，则销售出库单取价时会跳过销售退货单取下一张入库单的成本。销售退货单仍然保留与销售出库单的原单关系，取销售出库单的成本价。销售退货单的成本会被销售出库单之后的出库单扣减。虽然选择“自动跳过”可以减少手工维护的工作量，但实际上不符合先进先出的取价逻辑了。这种发生嵌套的情况也是常发生在做单不规范的情况下。  |
| 结账时自动调整异常余额             | - 参数介绍：让用户选择在结账的时候是否进行异常余额调整，支持“不调整”和“调整核算维度异常余额”两种方式，选择“不调整”则在结账时不自动调整，选择“调整核算维度异常余额”则会在结账时，自动将存货收发存汇总表中核算维度无数量有金额的余额进行出单。                                                                                                                                                                                                                            |
| :::                     | - 应用场景：1、做完异常余额出单后，重新核算系统自动删除了异常余额调整单的情况；2、月末要做存货跌价准备，把无数量有金额的存货余额出单调整后，跌价计提库存金额与存货收发存汇总表一致                                                                                                                                                                                                                                                            |
| 生产退料单通过生产退料请检单取源单成本     | - 应用场景：生产领料单下推生产退料请检单，再通过生产退料请检单下推生产退料单的业务，在成本核算的时，生产退料单可以获取关联生产领料单的成本。                                                                                                                                                                                                                                                                                |
| 委外退料单通过委外退料请检单取源单成本     | - 应用场景：委外领料单下推委外退料请检单，再通过委外退料请检单下推委外退料单的业务，在成本核算的时，委外退料单可以获取关联委外领料单的成本。                                                                                                                                                                                                                                                                                |


=====2.3 产品成本核算参数 =====
^ 参数名称                         ^ 参数说明                                                                                                                                                                                                                                                                                                ^
| 副产品投入材料成本计算依据                | - 参数介绍：主联副产品在成本计算之前需对材料成本进行分摊，副产品采用定额核算，副产品耗用材料成本=数量*单位定额，主联副耗用的直接材料首先扣减副产品的成本然后按照主联副产品组分配权重在主产品和联产品之间进行分摊。这里副产品的数量支持两种来源：投入产量和完工产量。                                                                                                                                                                |
| :::                          | - 应用场景：两者应用注意事项请参考帖子：[[https://vip.kingdee.com/article/17885|外部链接]]                                                                                                                                                                                                                                 |
| 主联产品普来源及分配标准                 | - 参数介绍：主联副产品来源有两种可选：订单（制造）和产品组（成本）。当主联副产品来源为“订单（制造）”时，对应的分配标准可选： 1）空值时，主联产品的材料成本按生产订单中的权重进行分配； 2）当选择了具体的“费用分配标准”时则按具体的费用分配标准进行材料成本的分配；当主联副来源为产品组（成本）时，分配标准灰显不可选，分配权重来源于成本模块的产品。                                                                                                                     |
| :::                          | - 关联知识：更多应用知识请点击：[[https://vip.kingdee.com/article/181680|外部链接]]                                                                                                                                                                                                                                    |
| 普通列表项目车间投入产出数据来源             | - 参数介绍：在启用车间作业成本的情况下，车间投入产出表新增按“工序计划单”获取来源，该参数默认选择按“工序汇报单”获取来源。客户可以根据自身业务来选择获取来源，如果出现工序委外，工序协同的情况，此时没有工序汇报单，系统无法获取对应的投入产出数据，就可以选择工序计划单作为获取来源。                                                                                                                                                       |
| 在产品按用料清单分配设置                 | - 参数介绍：1）“按用料清单不考虑退补料”。选择这个参数的意思是在生产订单没有完工之前退补料不按用料清单分配，全部计入在产品中，等完工之后才会计入本期完工。2）“按用料清单考虑补料”。选择这个参数的意思是在生产订单没有完工之前补料按用料清单在在产品和完工产品之间分配，退料全部计入在产品中，等完工之后才会计入本期完工。3）“按用料清单考虑退料”。选择这个参数的意思是在生产订单没有完工之前退料按用料清单在在产品和完工产品之间分配，补料全部计入在产品中，等完工之后才会计入本期完工4）“按用料清单考虑退补料”。选择这个参数的意思是在产品分配标准选择按用料清单时需考虑生产退补料单。  |
| :::                          | - 注意事项：该参数默认选择为按用料清单不考虑退补料。                                                                                                                                                                                                                                                                         |
| 嵌套计算                         | - 参数介绍：1）中断提示：立即中断核算，提示嵌套单据，用户可选择业务处理或者在核算单据查询中手工维护成本后再进行核算。2）成本暂估：不中断核算进程，根据成本暂估来源，自动进行暂估。                                                                                                                                                                                                         |
| :::                          | - 应用场景：当发生嵌套业务时，选择核算过程中的处理办法。                                                                                                                                                                                                                                                                       |
| 共耗材料不参与费用分配                  | - 参数介绍：当简单生产领料单不录生产对象时会做为共耗材料参与费用分配，数据量大的情况下影响性能；其他出库单表体中“参加费用分配”默认勾选，需要通过BOSIDE放开字段去掉勾选才能不参与费用分配，操作不方便。如果勾选此参数，以上两种情况的共耗材料都直接不再参与费用分配，不用单独再去设置。此参数默认不勾选。                                                                                                                                           |
| 简单生产无期末在产不结转                 | - 参数介绍：勾选该参数，针对简单生产期末在产品数量、金额均为0的产品，不结转到下期初。该产品在下期有入库时，重新计算累计完工值。                                                                                                                                                                                                                                   |
| 退料方式为“退料并扣款”的委外采购退料单不退回委外订单  | - 应用场景: 委外产品在入库以后，发现供应商责任的不良品，企业需要通过委外采购订单退料并扣除委外加工费，材料成本部分由企业自身承担。退料后，这部分产品不需要再进行返工生产入库，仅做为普通退料并结算加工费，可有效解决此类业务造成的委外入库负单价的问题。                                                                                                                                                                      |
| :::                          | - 详细介绍：[[https://vip.kingdee.com/article/42560306905022464|外部链接]]                                                                                                                                                                                                                                   |
| 启用退库业务手动维护模式                 | - 应用场景：针对退库大于入库，且出现负单价时，可启用此参数手工维护退库单成本。                                                                                                                                                                                                                                                            |
| :::                          | - 详细介绍：[[https://vip.kingdee.com/article/46252426199105536|外部链接]]                                                                                                                                                                                                                                   |
| 简单生产共耗材料对应成本项目               | - 参数说明：简单生产领料单、简单生产退料单生产对象为空时优先从此处获取对应的成本项目，为空的情况下默认为“直接材料”。                                                                                                                                                                                                                                        |
| :::                          | - 应用场景：适用于其他出库单、简单生产领料单和简单生产退料单做为共耗材料分配时，成本项目统一为间接材料，方便管理报表分析取数。                                                                                                                                                                                                                                    |
| 关闭全产品管理数据追踪                  | - 参数说明：该参数为数据中心级，仅管理员有权限，默认不勾选。不勾选的情况下销售出库单、销售退货单审核成本会自动产品维度信息，方便进行全产品数据分析，如产品维度利润分析表中的期间费用是通过该产品维度匹配生成的。                                                                                                                                                                                           |
| :::                          | - 应用场景：不需要进行全产品分析、销售数据量大，结账或者核算性能较差的场景建议勾选该参数。                                                                                                                                                                                                                                                      |

======3 操作说明 ======


设置参数后，请选择“核算组织”及“会计政策”进行保存。
