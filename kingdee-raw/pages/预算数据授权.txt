ID: 预算数据授权
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E7%AE%97%E6%95%B0%E6%8D%AE%E6%8E%88%E6%9D%83

**功能描述**

通过预算管理数据授权，实现用户使用在预算编制、调整、分析以及实际数报表时，对以下数据的使用权限实现授权约束：部门级预算组织、预算维度、预算方案、预算模板。

支持面向角色/用户设置数据授权控制。

**功能路径**

【预算管理】-【预算数据授权】-【预算数据授权】

**数据授权生效说明**

  * 与金蝶AI星空.基础平台提供的数据权限逻辑一致。角色/用户设有数据授权，则该角色/用户权限范围受限，否则不受限。
  * 预算数据授权的设置，实现以下功能的数据授权控制：

^ 功能大类   ^ 功能明细      ^
| 预算编制   | 组织模板查询    |
| :::    | 预算编制台     |
| :::    | 预算汇总表     |
| 预算调整   | 预算调整单     |
| :::    | 预算调剂单     |
| 预算分析   | 预算数据查询    |
| :::    | 所有预算执行分析  |
| 实际数报表  | 实际数模板     |
| :::    | 实际数报表     |

** 字段说明 **

^  字段                                                                                                                                                                               |^  说明                                                                                                                                                          ^
| 数据授权范围  | 在设置数据授权范围时，请按需对提供的授权对象（部门级预算组织/预算维度/预算方案/预算模板）进行使用范围进行设置。\\ 常见需要数据授权的对象为：部门级预算组织、预算维度。\\ 数据授权对象未设置使用范围，默认为所有范围。 \\ 预算数据授权的保存，要求至少对部门级预算组织/预算维度/预算方案/预算模板，其一进行数据权限范围的设置。                                                                                                                                                                ||
| :::     | 部门级预算组织                                                                                                                                                                  | 按需选择需要数据授权控制的部门级预算组织。\\ 未设置时，默认为所有组织都有权限。\\ **说明：**组织级预算组织，直接来源于用户组织权限。                                                                                      |
| :::     | 用户关联员工所属部门                                                                                                                                                               | 选中时，当前登录用户关联员工对应的部门范围、员工对象，为当前用户的部门级预算组织权限范围、部门维度数据的权限范围、员工维度数据的权限范围。\\ 支持任意来自于部门基础资料、员工基础资料的预算维度。                                                           |
| :::     | 默认包含所有下级                                                                                                                                                                 | 选中时，用户拥有某部门级组织权限，则自动拥有该组织下，所有下级组织权限。                                                                                                                         |
| :::     | 预算维度                                                                                                                                                                     | 按需对需要数据授权的预算维度，设置各维度的使用范围。\\ 可通过维度范围/维度过滤进行范围的设置。\\ 未设置时，默认为所有预算维度都有权限。\\ 当选中用户关联员工所属部门时，系统自动添加部门维度到预算维度，并禁止设置，即：此时部门维度的范围来自于用户关联员工所属部门范围。系统自动添加的部门维度，允许删除。  |
| :::     | 预算方案                                                                                                                                                                     | 按需对需要数据授权的预算方案。\\ 未设置时，默认为所有预算方案都有权限。                                                                                                                        |
| :::     | 预算模板                                                                                                                                                                     | 按需对需要数据授权的预算模板。\\ 未设置时，默认为所有预算模板都有权限。                                                                                                                        |
| 用户和角色                                                                                                                                                                             || 选择用户/角色。                                                                                                                                                     |


**特殊说明**
  - 组织级预算组织，直接来源于用户组织权限。
