====== 质量参数设置 ======

质检过程的宽严度、细化程度及控制方式，在企业不同的质检环节有着不同的需求， 金蝶云 通过参数设置实现多种需求。

**功能路径**

1、【基础设置】－>【基础资料】－>【单据类型】－>【单据类型】－>【检验单】


**字段说明**

| **字段**                    || **说明**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 启用整体抽样检验                  || “启用整体抽样检验”勾选，在检验单显示【整体抽样】检验的页签，记录检验过程中整体抽样方案及检验结果信息；否则，在检验单中不显示【整体抽样】页签                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 启用缺陷记录                    || “启用缺陷记录”勾选，在检验单显示【缺陷记录】的页签，记录检验过程中发现的缺陷信息；否则，在检验单中不显示【缺陷记录】页签                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 启用检验项目检验                  || 启用检验项目检验”勾选，在检验单显示【检验项目】检验的页签，用户可以更精确的记录每个检验项目的检验数据及检验结果；否则，在检验单中不显示【检验项目】页签                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 启用检验项目抽样方案                || “启用检验项目抽样方案”勾选，在检验单【检验项目】页签下显示新的窗口-【抽样检验】，用于检验项目的抽样检验；否则，在检验单【检验项目】页签下不显示窗口【样本检测值】                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 启用样本检测值                   || “启用样本检测值”勾选，在检验单【检验项目】页签下显示新的窗口-【样本检测值】，用于录入样本对应检验项目的检测值，通过检测值，系统自动判定检测结果；否则，在检验单【检验项目】页签下不显示窗口【样本检测值】                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 启用合并检验                    || “启用合并检验”没有勾选，不进行合并检验"；“启用合并检验”，勾选：\\ A、来料检验，对多条（供应商+物料+批号+BOM版本+计划跟踪号+辅助属性+生产日期）相同的采购收料单行系统自动合并检验数量进行检验，并将检验结果的“接收_数量”、“让步接收_数量”“判退-数量”按照比例或自上而下的原则分摊到源单中。\\ B、产品检验，对多条（单据类型+生产车间+物料+批号+BOM版本+计划跟踪号+辅助属性）相同的生产汇报单行，系统自动合并检验数量进行检验，并将检验结果的“接收_数量”、“不良_数量”、“报废_数量”、“返工_数量”、“返修_数量”按照比例或自上而下的原则分摊到源单中。\\ C、自制工序检验， 对多条（生产订单+物料+工序号）相同的工序汇报单行，系统自动合并检验数量进行检验，并将检验结果的“接收_数量”、“不良_数量”、“工废_数量”、“料废_数量”按照比例或自上而下的原则分摊到源单中。\\ D、库存检验， 对多条（物料+库存维度相同包括批号+BOM版本+计划跟踪号+辅助属性+生产日期）相同的库存请检单行，系统自动合并检验数量进行检验，并将检验结果的“接收_数量”、“不良_数量”、“报废_数量”按照比例或自上而下的原则分摊到源单中。  |
| 检验单审核时自动质检完成              || “检验单审核时自动质检完成”勾选，当审核检验单时，同时将【分录明细】中的“质检状态”自动执行至“质检完成”                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 检验单审核时自动质检开始              || “检验单审核时自动质检开始”勾选，当审核检验单时，同时将【分录明细】中的“质检状态”自动执行至“质检开始”                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 检验单反审核时自动反质检完成            || “检验单反审核时自动反质检完成”勾选，当反审核检验单时，同时将【分录明细】中的“质检状态”自动反执行至“计划”                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 检验单上从质检方案携带的检验项目不允许修改     || 如果QA制定的质检方案在执行过程中不允许修改则需勾选此参数，勾选后，生成检验单携带质检方案过来的检验项目及对应的指标不可编辑                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 检验单确定辅助属性                 || 启用辅助属性的物料，在检验过程中确定辅助属性值。目前仅支持产品检验和来料检验在检验过程指定辅助属性。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 检验单按序列号拆分分录               || 启用序列号的物料，在检验过程中，每一个序列号物料对应一个检验报告，即每一个序列号物料对应一个检验单的分录，目前仅支持产品检验和来料检验按序列号拆分分录。                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 质检完成允许修改检验项目              || 参数勾选，检验单质检完成后可以编辑检验项目，补充检验项目相关信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 质检完成校验辅助属性必录              || 参数勾选，检验单可以在质检完成后再补录辅助属性值。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 退货检验合格默认勾选判退              || 参数勾选，针对退货检验，使用决策为接收时也自动勾选判退。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 检验单分单依据                   || 多张检验单的源单一起下推生成检验单时，按分单依据生成一张单或多张单 \\ 1、不分单：多张检验单的源单一起下推生成检验单，生成一张检验单；\\ 2、按质检组分单：多张检验单的源单，多个物料一起下推检验单，按物料资料中指定的质检组，相同质检组的多个物料分到一张检验单上，方便按质检组处理本组的检验单。\\ 3、按质检员分单：多张检验单的源单，多个物料一起下推检验单，按物料资料中指定的质检员，相同质检员的多个物料分到一张检验单上，方便按质检员处理自己的检验单。                                                                                                                                                                                                                                                                                                            |
| 不合格默认使用决策                 || 当检验单录入不合格数量，使用决策表体自动增加一行不合格品，使用决策取此处设置                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 采购检验不合格默认使用决策             || 当业务类型为采购检验的来料检验单录入不合格数量，使用决策表体自动增加一行不合格品，使用决策取此处设置                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 委外检验不合格默认使用决策             || 当业务类型为委外检验的来料检验单录入不合格数量，使用决策表体自动增加一行不合格品，使用决策取此处设置                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 自动生成检验单质检组织获取顺序           || 自动生成检验单时支持按照以下组织顺序获取质检组织： \\ 1、当前组织＞来源组织＞委托质检组织；\\ 2、来源组织＞当前组织＞委托质检组织；\\ 3、来源组织＞委托质检组织＞当前组织；                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 自动生成检验单单据状态               || 支持设置自动生成检验单的单据状态，可选择：创建、提交、审核                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 启用自定义使用决策                 || 支持增加自定义的二开使用决策，并且按标准产品的使用决策数量汇总反写源单                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 自动生成不良品处理单                || 参数勾选，检验单质检完成后或者审核后，使用决分录勾选不良品处理的数量支持自动生成不良品处理单                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |


2、【基础管理】－>【参数设置】－>【质量管理】－>【参数信息】


**字段说明**


| **字段**              || **说明**                                                                                                      |
| 按源单数量权重反写源单         || “按源单数量权重反写源单”勾选（管理员登录才可以修改此参数），且在单据类型勾选合并检验后，合并检验按源单数量权重反写。                                                 |
| 自上而下反写源单            || “自上而下反写源单”勾选（管理员登录才可以修改此参数），且在单据类型勾选合并检验后，合并检验按自上而下反写源单。检验结果使用决策对应的数量反写源单时，依次按接收数量、让步接收数量、判退数量、样本破坏数量顺序反写。  |
| 二次检验严格携带源单信息        || 针对二次检验，参数默认勾选，参数勾选时二次检验严格携带源检验单的质检方案和验项目相关信息；参数不勾选时二次检验携带物料设置的质检方案和检验项目。                                    |
| 启用物料来源质检规则          || 参数勾选后检验单生成时（来料检验），优先获取物料来源质检规则的质检方案和抽样方案。                                                                   |
| 自动计算                || 针对调整型抽样检验，检验单质检完成后（来料检验），当满足转换条件时自动转换物料来源质检规则的当前严格度。                                                        |
| 物料来源质检规则不区分供应来源     || 参数勾选，物料来源质检规则的供应商可不录，查找物料来源质检规则不再区分供应商仅按照物料+使用组织过滤。                                                         |
| 执行库存物料复检到期查询        || 参数勾选，库存物料复检到期查询按执行计划自动生成请检单，按照参数设置的过滤方案自动请检符合条件的库存物料。                                                       |
