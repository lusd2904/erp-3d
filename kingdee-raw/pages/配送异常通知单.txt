======1. 配送异常通知单 ======

===== 1.1 功能概述 =====

配送异常通知单是处理由于质量不合格、价格不正确等因素，或与门店要货或合同的相关条款不相符等原因，销货单位需将销售货物退回的业务通知单据。该单据通过各项审核后，再进行退货业务，完成退货流程。

===== 1.2 关键字段 =====



| 字段名称    | 字段说明                                                        |
| 异常多收    | 实收数量-应收数量的差值                                                |
| 异常少收    | 应收数量-实收数量的差值                                                |
| 异常金额    | 异常数量（多收/少收） * 单价                                            |
| 异常处理    | 多收的配送异常通知单会生成审核状态的配送补货单，少收的配送异常通知单会生成创建状态的配送退货单             |
| 选单      | 有异常数量的门店收货单                                                 |
| 异常处理状态  | 包括已处理和未处理，当点击异常处理按钮时，生成了配送退货单（多收）或者配送补货单（少收）时，异常处理状态会变成已处理  |
