====== 1.支付宝交易账单 ======

===== 1.1 功能概述 =====
营业对账的原始流水，可以通过新增，接口上传，导入三种方式

===== 1.2 字段说明 =====
^ 字段         ^ 说明                     ^
| 单据类型       | 支付宝交易账单                |
| 营业日期       | 门店产生交易流水的日期            |
| 营业组织       | 门店产生交易流水的组织            |
| 单据编号       | 唯一值，允许自动生成和手工输入        |
| 支付金额       | 支付的笔数总和                |
| 支付笔数       | 支付的笔数                  |
| 收款账户       | 设置支付宝交易账单的账户           |
| 结算方式       | 支持结算方式类别包含支付宝的         |
| 支付宝订单号     | 产生的订单号，由支付宝生成，对账的字段之一  |
| 商户订单号      | 产生的商户订单号，由支付宝按照一定规则生成  |
| 商户号        | 每个商户都有自己的商户号           |
| 子商户号       | 每个商户可以包含多个子商户号         |
| 业务类型       | 产生流水的类型                |
| 商品名称       | 商品的名称                  |
| 创建时间       | 流水产生的时间                |
| 完成时间       | 支付完成的时间                |
| 门店编号       | 门店的编号                  |
| 门店名称       | 门店名称                   |
| 操作员        | 操作员账号                  |
| 终端号        | 设备号                    |
| 对方账户       | 客户的账号                  |
| 订单金额       | 订单的金额                  |
| 商家实收       | 商家实际收到的金额              |
| 支付宝红包      | 支付宝红包金额                |
| 集分宝        | 集分宝的金额                 |
| 支付宝优惠      | 支付宝的优惠金额               |
| 商家优惠       | 商家优惠金额                 |
| 券核销金额      | 券核销的金额                 |
| 券名称        | 券的名称                   |
| 商家红包消费金额   | 商家红包消费金额               |
| 卡消费金额      | 卡上实际支付的金额              |
| 退款批次号/请求号  | 退款的流水号                 |
| 服务费        | 服务费金额                  |
| 分润         | 分的利润                   |
| 备注         | 填写备注                   |
| 收入来源       | 收入的来源渠道                |
