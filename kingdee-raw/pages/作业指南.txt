======1  作业指南=======
=====1.1 功能概述=====

自行添加图片、文档、视频形式的作业指南，用于指导具体作业操作，如土豆切丝指南、盒饭包装指南等。

=====1.2 使用前提====

需要预先配置好文件服务器。

=====1.3 功能路径====
【餐饮加工管理】－>【加工订单管理】－>【作业指导】－>【作业指南】。

======2 字段说明======


*标注为必填字段
^  **字段**  ^  **说明**                                     ^
|  *创建组织    | 1.选择组织过滤时只有在当前组织内可见    |
|  *指南名称    | 1.输入手册的名称         |
|  版本  | 1.输入手册的版本      |
|  审核人  | 1.当前审核用户。      |
|  应用车间    | 1.点击可查看到在本组织中建立的车间，选择对应车间填入          |
|  *使用组织    | 1.但前手册使用的组织               |
|  *指南类型    | 1.可选择图片，视频，PDF文件      |
|  文件编号    | 1.可填入文件的编码         |
|  发布时间    | 1.可选择发布的时间                               |
|  应用工序    | 1.本组织下维护的工序都可以选择的到；   |
|  指南编码    | 1.保存时自动生成；     |
|  指南文件    | 1.可在本地向云端上传文件；     |
|  编制人      | 1.可填写指南编制人；     |
|  应用产品    | 1.组织下的所有审核物料可选择；     |
|  指南描述    | 1.可简要输入想要描述的内容；     |
