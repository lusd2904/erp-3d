====== 1.历史物料用量要货 ======

===== 1.1 功能概述 =====

  * 通过历史物料用量要货的计算维度满足企业企业不同的预估要货需求。根据历史同期时间范围内：最近一天要货、上周同期、上月同期、上年同期、固定日期等要素计算门店的要货需求，生成预估要货单。
  * 历史物料用量要货是用于门店参考自己以往的某一个时间段的要货情况对后期的要货数量进行预估的过程.
  * 生成的物料预估要货单根据物料的配送和自采属性选择下推的单据。
  * 只具有配送属性的物料预估要货单只能下推到门店要货申请单；只具有自采属性的物料预估要货单只能下推到采购申请单/采购订单。

===== 1.3 使用前提 =====
**使用前提：需要门店要货申请，采购申请单，采购订单**

======1.4 字段说明======

| **字段**          | **说明**                                |
| 要货组织            | F8选择预估要货的组织 。                         |
| 要货日期            | 门店预估要货的日期。                            |
| 最近一天要货          | 根据要货组织最近一天的要货申请单的要货物料和数量生成历史同期数据。     |
| 上周同期            | 根据要货组织上周同一星期的要货物料和数量汇总生成历史同期数据。       |
| 上月同期            | 根据要货组织上月同一天的要货物料和数量汇总生成历史同期数据         |
| 上年同期            | 根据要货组织上年同一天的要货物料和数量汇总生物历史同期数据         |
| 固定时间            | 根据设定的固定时间，要货组织在同一天的要货物料和数量汇总生成历史同期数据  |
| 生成预估要货单      | 点击生成物料预估要货单                           |
| 生成预估要货单（汇总）   | 点击生成汇总的物料预估要货单                        |

===== 1.5 业务说明 =====
  * 在历史物料用量要货中增加物料分组，来精确选择某类物料，根据选择的物料过滤数据。
  * 计算历史同期数据；
  * 根据历史同期数据生成物料预估要货单。
