ID: 供应商注册资料
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BE%9B%E5%BA%94%E5%95%86%E6%B3%A8%E5%86%8C%E8%B5%84%E6%96%99

====== 1 功能介绍 ======
供应商注册资料的列表，包含当前用户查询权限范围内的所有供应商注册资料。

====== 2 功能路径 ======
【供应商协同平台】->【基础资料】->【供应商注册资料列表】

====== 3 字段说明 ======
^ 字段     ^ 说明                     ^
| 编码     | 由系统自动生成                |
| 供应商编码  | 供应商对应的编码，可手工维护         |
| 修改人    | 修改该供应商资料的人员            |
| 创建人    | 供应商的创建人员               |
| 创建日期   | 供应商的创建日期               |
| 修改日期   | 供应商资料的修改日期             |
| 描述     | 对该供应商的描述               |
| 名称     | 供应商的名称                 |
| 数据状态   | 供应商的数据状态：暂存、创建、审核中、已审核或重新审核  |
| 禁用状态   | 该供应商是否被禁用               |
| 手机     | 供应商对应的联系人的联系方式         |
| 简称     | 供应商的简称                 |
| 审核人    | 审核该供应商的人员              |
| 审核日期   | 审核该供应商的日期              |
