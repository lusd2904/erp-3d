ID: 许可控制
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%AE%B8%E5%8F%AF%E6%8E%A7%E5%88%B6

**功能说明：**

用户系统注册许可用户及实际使用许可的详情信息

**功能路径：**

【系统】—>【系统设置】—>【许可控制】

**使用前提：**

无

**字段说明：**

| **名称**     | **字段取数说明**                     |
| 许可类型       | 有2种类型：正式版、演示版                  |
| :::        | 正式版只能通过购买的方式，演示版可以申请临时许可       |
| 许可生效/失效日期  | 许可时间范围                         |
| 购买模块       | 目前有三个模块：业务中心、分销门户、门店门户         |
| 中心注册用户数    | 申请或购买BBC业务中心的后台用户许可总数          |
| 中心占用用户数    | 有效期内BBC后台用户的活跃用户数(近期登录过系统的用户)  |
| 门户注册用户数    | 申请或购买BBC分销门户的前台用户许可总数          |
| 门户占用用户数    | 有效期内BBC前台用户的活跃用户数(近期登录过系统的用户)  |

**操作说明：**

  - 门户注册用户数包含了分销门户和门店门户的用户数，即所有门户用户数的总和；
  - 占用用户数不能大于注册用户数，否则超过用户数的用户无法再启用。
