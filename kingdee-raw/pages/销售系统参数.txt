====== 销售管理系统参数 ======

通过系统参数的设置，控制和管理业务，以达到企业的管理目标。

===== 1 参数说明 =====

系统提供不同层级的参数设置：

  * 与整体有关的参数，在销售管理系统参数下，参数影响整个业务组织的使用。
  * 单据类型层级的参数，在系统单据类型下设置：如启用交货计划，可以根据不同的单据类型启用。
  * 单据参数，在系统管理单据参数配置中设置：如控制反审核人与审核人一致。
  * 操作相关的参数，在单据列表或界面，选项下设置：如提交后自动审核等。

| 启用客户物料对应表            || 启用后，销售单据才显示和使用【客户物料编码】【客户物料名称】。                                                                                                                       |
| 控制发货数量               || 用于控制发货、出库的数量不超过销售订单的限定的数量范围。没有启用参数时，允许超过订单数量发货；启用参数后，系统控制销售出库时，数量不允许超过订单数量的上限。                                                                        |
| 业务组数据隔离              || 启用后，则同一个业务组内的人员可以相互查询单据，不同业务组的单据则隔离。使用业务组隔离的前提是，业务员对应用户上，需要设置好联系对象。详细可参考：https://vip.kingdee.com/article/163342502764812032                           |
| 业务员资料按组织隔离           || 启用后，维护业务员资料上，不允许看到其他组织的销售员或业务员，只能看到当前用户所在组织的销售员或业务员。                                                                                                  |
| 模拟报价单执行自动关闭          || 勾选，则模拟报价单下推完报价单后即关闭；不勾选，则模拟报价单可以多次下推报价单                                                                                                               |
| 发货检验合格自动出库           || 勾选后，发货检验流程，发货检验完成后自动生成销售出库单。                                                                                                                          |
| 退货检验后自动退货            || 勾选后，退货检验流程，检验完成后自动生成销售退货单。                                                                                                                            |
| 合同启用CRM数据规则          || 销售合同、销售合同执行明细表、汇总表受此参数影响。不启用参数时，这些单据和报表默认不采用CRM数据规则，可以查询到当前用户及其他人的合同和数据；启用参数时，这些单据和报表采用CRM数据规则，默认按当前用户隔离，当前用户只能查询到自己的数据，通过配置CRM数据规则可以查询到其他数据规则范围的数据。  |
| 销售订单的BOM版本字段携带规则     || 按主产品：物料资料生产页签设置了是主产品时，则订单上就会携带此物料的BOM版本；按启用BOM：物料资料的物料维度上设置了启用BOM时，则订单上会携带此物料的BOM版本；不携带：销售订单无法确定BOM时可设置不携带，销售订单即时没有BOM版本，计划运算时也会自动获取BOM版本。            |
| 单据转换强制携带上游汇率         || 勾选后，销售流程单据，上游单据的汇率强制默认携带到下游单据。                                                                                                                        |

| 显示锁库菜单，预留菜单不显示          || 数据中心级参数，需要管理员登录在系统参数设置中设置。该参数主要是在启用预留的情况下，销售订单又要用锁库时使用。                                                       |
| 订单锁库预留数量不统计强预留的生产订单     || 销售订单列表的锁库/预留标识自动包含了“锁库部分、预留库存部分、以及生产订单强预留部分”。勾选参数，则锁库、预留标识字段仅包含锁库部分、预留库存部分。不包含强预留的生产订单部分。                     |
| 销售订单手工关闭时字段释放锁库         || 销售订单未执行关闭，也就是未完全发货的情况下，如果要手工关闭订单，勾选参数的情况下，系统会把销售订单的锁库信息自动释放。                                                  |
| 销售订单锁库信息携带到发货通知单        || 勾选参数时，订单锁库的仓库、仓位等信息，在销售订单下推发货通知单时会按锁定的仓库、仓位携带至通知单上。不勾选的情况下，发货通知单是携带销售订单上的仓库等信息，到下游出库环节时再通过批号拣货自动获取锁库信息到出库单上。  |
| 仅按锁库数量携带                || 是“销售订单锁库信息携带到发货通知单”参数子选项，勾选该选项，只携带订单的锁库数量到发货通知单 ，没有锁库的剩余数量不在发货通知单另分一行展示。                                      |
| 按订单仓库携带锁库信息             || 勾选该选项，如果订单上录入了仓库、仓位信息，订单锁库时，按订单上录入的仓库、仓位信息进行锁库                                                                |

| 寄售结算仅匹配结算日期之前的调拨单             ||勾选参数时，寄售结算单上匹配调拨单时，仅会匹配结算日期之前的未结算的调拨单；没有勾选参数时，寄售寄售单上可以匹配所有日期范围内未结算的调拨单。                                                            |

| 根据可销范围控制单据查询权限     || 设置该参数后，查询单据列表时，系统按可销范围的设置来控制能查看的单据范围。                                                                                                                                                                                             |

===== 3 销售价格参数 =====

| **参数及选项**             || **说明**                                                                                                       |
| 价格参数                  || 详细说明可参考。https://vip.kingdee.com/article/182115                                                               |
| 单据名称                  || 支持销售报价单、销售合同、销售订单、销售出库单、寄售结算单、或自定义单据进行最低限价控制。                                                                |
| 单据类型                  || 可以按不同的单据类型区别控制。                                                                                              |
| 限价控制强度                || 支持3种强度，不予控制、预警提示、禁止交易                                                                                        |
| 控制时点                  || 用于设置，单据在什么时候进行限价控制                                                                                           |
| 检查价格来源                || 为[强制价目表]定价时，系统会检查单据上的价格必源于价目表，意味着单据上的所有价格都需要有定价来源。                                                           |
| 特批控制                  || 单据在限价控制时点，由设置的密码特批人进行密码特批进行后续操作                                                                              |
| 自动应用优先级取价             || 勾选参数，则销售订单上自动应用按优先级进行取价。没有勾选，则订单上按客户默认携带价目表                                                                  |
| 物料无价目表定价时，不清空当前价格  || 勾选该参数时，按价目表自动匹配取价时，如果当前分录行无价目表定价，且已维护价格，不清空当前分录行已维护的价格。                                                          |
| 物料无价目表定价时，不清空当前价格  || 勾选该参数时，按价目表自动匹配取价时，如果当前分录行无价目表定价，且已维护价格，不清空当前分录行已维护的价格。                                                          |
| 按客户物料价目表匹配取价     || 勾选该选项，如果价目表中维护了客户物料对应信息，匹配取价时，也按单据上物料客户物料对应与价目表上的客户物料对应信息匹配取价                                                |
| 获取折扣时直接携带折扣表折扣率       || 当应用折扣表时，折扣表只按折扣率定折扣；单据上希望直接获取折扣率，而不是根据折扣额倒算折扣率时，可以应用该参数。                                                     |
| 自动获取销售折扣      || 勾选该选项，系统自动按物料匹配有效期范围内最新的折扣信息获取到折扣率字段上                                                     |
| 限价控制获取价目表的最低限价        || 不勾选参数时，系统限价控制是根据单据上获取到的价目表、和最低限价来控制的；如果用户价格和最低限价更新比较快，比如在录入单据时，价目表的最低限价又发生了变化，此时需要按最新的变化的价目表获取最低限价。则可勾选该参数。  |
| 取最新订单价格更新订单已有价格       || 当在业务单据上应用获取最新订单价格时，如果订单上有手工录入的价格，那么获取的最新价格是否覆盖已有价格。                                                          |



===== 4 套件业务参数 =====

| **参数及选项**                   || **说明**                                                                                                             |
| 套件业务参数                      ||                                                                                                                    |
| 启用套件管理                      || 勾选该选项，销售系统启用套件业务，单据上显示产品类型字段，可以选套件父项、套件子项及标准产品，进行套件业务或标准产品销售                                                       |
| 单据保存时套件父项自动展开子项             || 勾选该选项，按选择的单据上父项的BOM版本自动按BOM带出父项下级子项，推荐选择销售订单，有利于后续计划运算的准确性                                                         |
| 按单据上BOM校验父子项整套数量            || 按单据上的BOM校验父子项齐套及齐套数量                                                                                               |
| 按上下游套件关系发货                  || 按单据上游套件父子项关系发货（出库），只校验上下游物料父子关系携带，不判断齐套数量。如果勾选销售订单，则是按销售订单上的BOM版本校验订单父子项齐套及齐套数量                                    |
| 套件子项支持取价                    || 勾选该选项，套件子项含税单价或单价放开锁定性，支持录入价格或价目表取价                                                                                |
| 子项价格不参与订单金额合计               || 勾选该选项时，在销售订单上子项金额不统计到订单的金额合计。此参数只对销售订单明细有效。                                                                        |
| 子项数量不参与订单数量合计               || 勾选该选项时，在销售订单上子项数量不统计到订单的数量合计。此参数只对销售订单明细有效。                                                                        |
| 不强制整套退货                     || 不勾选该选项，则套件退货需要整套父子项退货不支持部分子项退货。勾选该选项，则退货流程支持部分子项退货                                                                 |
| 不成套出库携带套件父项                 || 该选项适于子项不成套出库或退货业务，勾选该选项，如果父项产品已和部分子项在第一次出库已出完，剩余子项再出库会携带一行套件父项为0的分录，便于父项成本归集计算，为了父项成本归集计算的准确性，有不成套出库或退货业务，建议勾选该选项  |
| 销售订单/发货通知单父项行终止联动终止对应子项     || 勾选该选项，销售订单或发货通知单父项行终止可联动终止对应子项分录行                                                                                  |
| 无源单销售退货保存自动展开     || 勾选该选项，手工新增的销售退货保存时套件父项按录入的BOM版本自动展开子项                                                                                 |
| 修改套件父项不联动更新子项数量    || 勾选该选项，修改套件父项数量，不按BOM版本子项匹配的数量自动重刷子项数量                                                                               |
