====== 应收单 ======


====== 1 功能说明 ======

应收单是对销售应收的管理。

====== 2 字段说明 ======

^ 字段名   ^ 说明                                ^
| 业务日期  | 业务日期必须大于结账日期，如果没有结账日期则必须大于等于启用日期。  |
| 单据类型  | 系统预设多种单据类型：标准应收单、资产调拨应收单、费用应收单、转销应收单，用户可以根据企业情况进行增加。  |
| 结算组织  | 应收单的主业务组织，只有启用了应收款管理系统的组织才可以作为结算组织。  |
| 收款组织  | 该笔应收业务的收款组织，会决定下推的收款单的收款组织。  |
| 收款条件  | F8可以选择系统里的收款条件，应收单根据该收款条件自动计算收款计划。  |
| 到期日  | 到日期通过收款条件计算而来，基本页签的到期日与收款计划页签的第一行到期日保持一致。  |
| 到期日计算日期  | 默认为业务日期，可以手工修改，系统根据该字段和收款条件自动计算到期日。  |
| 按含税单价录入  | 勾选该选项，说明以含税单价为计算标准；不勾选该选项，则以单价为计算标准。企业的实际业务中可能存在不同的报价方式，用户可以根据每单的实际情况对该选项进行选择。  |
| 立账类型  | 当应收为业务应收模式时，立账类型为业务应收；当应收为暂估应收模式时，立账类型为暂估应收或财务应收。  |
| 价外税  | 勾选该选项，税额计算为价外税计算的逻辑；不勾选该选项，税额计算为价内税计算的逻辑。  |



====== 3 操作说明 ======

===== 3.1 快速新增 =====

通过点击【应收单快速新增】菜单可以实现应收单的快速新增。在该功能下，系统分类展示出所有还未生成应收单的销售出库单、销售退货单和销售订单，使用户集中、快速的生成应收单。

===== 3.2 自动生成 =====

  - 如果勾选“出库单审核时自动生成应收单”，则在出库单审核时，会自动生成应收单，生成的应收单如果必录字段完整，则为创建状态，如果必录字段不完整，则为暂存状态。
  - 如果勾选“应收单审核时自动生成销售发票”，则在应收单审核时，系统会根据客户基础资料中的发票类型自动生成增值税专用发票或者普通发票。 

====== 4 业务说明 ======

===== 4.1 多日期管理 =====

通过应收单的收款计划页签，系统支持一张应收单多到期日的管理，用户可以根据自己的管理需求，针对应收单设置不同的到期日及不同到期日的应收金额。

===== 4.2 客户的多方交易 =====

系统支持客户多方交易的场景，即客户的结算方、订货方、收货方和付款方可以不同。 

===== 4.3 内部结算 =====

内部结算的应收单必须通过供应链的组织间结算清单下推生成，而不能手工新增。内部结算的应收单表头的会计核算体系字段不为空，而一般的应收单该字段为空。

应收单上的会计核算体系字段默认隐藏，如果用户有内部结算的业务，可以通过单据类型将该字段放开。
