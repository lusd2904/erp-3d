====== 批量创建消耗汇总表 ======
====== 1功能概述 ======


企业消耗掉供应商的物料后，需要定期进行消耗统计，确定数量、价格等商务信息作为后续应付业务的依据。本节着重说明如何创建消耗汇总表。

====== 2使用前提 ======


  - 定义退料单的单据类型、供应商、采购组织、库存组织、结算组织、币别、物料、单位等基础资料 
  - 按实际采购业务流程设置采购参数以及仓库资料 
====== 3功能路径 ======


【供应链】－>【采购管理】－>【VMI业务】－>【批量创建消耗汇总表】

====== 4创建步骤 ======


创建汇总表步骤包括三步：设置汇总条件、中间结果展示与修改、创建完成及结果查看。

  - 第一步：设置汇总条件，包括设置创建消耗汇总表的基本规则，设置消耗单据的取数范围 
  - 第二步：中间结果展示及修改，按照第一步的创建方案，展示即将生成的消耗汇总表的明细信息，用户可在此步进行编辑，并勾选最终需要生成消耗汇总表的明细记录。只有勾选了的分录才会最终生成消耗汇总表。 
  - 第三步：将第二步选择的明细记录按照采购组织、消耗组织、结算组织、库存组织、供应商、币别等进行分单，并按照参数进行明细汇总生成消耗汇总表表体汇总页签。 
下面针对设置汇总条件进行详细说明

====== 5字段说明 ======
汇总条件设置

===== 采购组织 =====
         
 统计消耗汇总的采购组织，与消耗组织需存在委托采购关系                                                                                     
===== 集中结算  =====
        
 是否集中结算，勾选的话由采购组织指定唯一结算组织，不勾选则由消耗组织自行分散结算                                                                       
===== 结算组织 =====
         
 后续与供应商进行结算的组织                                                                                                  
===== 结算时点 =====
         
 取消耗单据的时点，分为出库结算和完工结算两种\\ 出库结算，所有的消耗单据都以物料出库日期作为统计汇总的时点 \\ 完工结算，生产相关单据，包括生产领料单、委外领料单等以相应的生产订单的完工日期作为统计汇总的时点     
===== 价格来源 =====
         
 消耗汇总统计时物料的取价来源，分为采购价目表和采购订单两种\\ 采购价目表，物料的取价来自于采购组织下最近的有效供应商价目表 \\ 采购订单，物料的取价来自于采购组织下供应商的采购订单，两者会进行数量匹配，不能重复取价  
===== 消耗组织 =====
         
 需要统计VMI消耗的组织，只能选择与采购组织需存在委托采购关系的组织   

===== 其他字段 =====

| 字段           || 说明                                                                                                             |                                                                          |
| 供应商          || 需要统计VMI物料消耗的供应商，只能选择采购组织下的供应商                                                                                  |
| 日期，至         || 统计消耗汇总的日期范围                                                                                                    |
| 生产订单编码，至     || 统计消耗汇总的生产订单范围                                                                                                  |
| 委外订单编码，至     || 统计消耗汇总的委外订单范围                                                                                                  |
| 产品编码，至       || 统计消耗汇总的产成品范围                                                                                                   |
