ID: 商品分类标准
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E5%88%86%E7%B1%BB%E6%A0%87%E5%87%86

**功能说明：**
基于不同平台为方便管理，按平台将商品制定不同的分类标准

**功能路径：**
【商品】->【商品分类标准】

**使用前提：**
无

**字段说明：**
| **名称**      | **字段说明**                         |
| 分类标准编码  | 根据编码规则自动生成                   |
| 分类标准名称  | 手工填写                         |
| 主分类     | 包含‘是’、‘否’两种状态                |
| 描述      | 手工填写                         |
| 启用状态    | 勾选\未勾选，默认为勾选启用状态             |
| 系统预设    | 只有系统预置的资料为是，否则均为否            |
| 操作      | 允许进行新增、修改、删除、启用、禁用、刷新、搜索等操作  |


**操作说明：**

  -   点击【新增】按钮弹出编辑页面，录入名称、描述信息，启用状态默认为是
  -   点击【保存】按钮，系统自动生成编码，新增一条商品分类标准信息
  * 修改：双击商品分类标准，进入详细信息页面，修改保存相关数据
  * 删除：选择相应分类标准，点击【删除】按钮，删除此行
