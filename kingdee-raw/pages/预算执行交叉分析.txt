ID: 预算执行交叉分析
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E7%AE%97%E6%89%A7%E8%A1%8C%E4%BA%A4%E5%8F%89%E5%88%86%E6%9E%90

**功能描述**

提供交叉分析样式的预算执行分析。


**功能路径**

【管理会计】-【预算管理】-【预算分析】-【预算执行交叉分析】

** 过滤条件 **
^ 字段                  ^ 说明                                                                                                                                         ^
| 预算方案                | 选择需要查询预算进度所在的预算方案                                                                                                                          |
| 预算控制规则              | 选择需要查询预算进度所使用的控制规则                                                                                                                         |
| 预算币别                | 选择需要查询的币别                                                                                                                                  |
| 本位币                 | 选择需要查询的本位币                                                                                                                                 |
| 预算组织                | 选择需要查询的一个或者多个预算组织\\ 预算组织可选的内置条件:\\ 当前预算方案下，控制规则对应样式方案分发对应组织是否已编制报表以及多组织预算表中包含的预算组织。                                                        |
| 预算周期                | 选择需要查询的预算周期类型                                                                                                                              |
| 预算年度                | 选择需要查询的预算年度                                                                                                                                |
| 预算期间                | 选择需要查询的预算期间                                                                                                                                |
| 行/列维度               | 设置交叉分析表需要显示的行/列维度。\\ 【转到列维度】/【转到行维度】：将预算维度，调整到对方维度区域。\\ 【重置】：重置将行/列维度设置，恢复到初始。\\ 【汇总】：未选中“汇总”，则该预算维度将罗列在分析表。选中“汇总”，则该预算维度将被汇总，不作为分析表的罗列项。  |
| 数据类型                | 设置交叉分析表需要显示的项目数据类型（预算业务类型）。                                                                                                                |
| 选项：包含已提交未审核的实际执行单据  | 选中时，获取已执行的实际数时，包含已提交未审核的实际执行单据。\\ 否则，只包含已审核单据。                                                                                             |
| 选项：显示预算调整数          | 选中时，预算调整数单独显示。否则只显示调整后的预算数。                                                                                                                |
| 选项：预算和实际数都为零，不显示    | 在满足过滤条件的前提下，预算数和对应实际数都为零时，该数据行不显示。                                                                                                         |
| 选项：显示预算数为空的数据行      | 在满足过滤条件的前提下，预算数为空（也就是没有编制预算数）时，如果存在实际发生数，也正常显示该数据行。                                                                                        |
| 选项：仅显示原始预算数         | 选中时，预算数仅显示原始预算数，即不包含预算调整数，且预算执行分析，也基于该原始预算数的对比。                                                                                            |
 


** 报表字段 **
^  字段      ^  说明                                                                                    ^
| 预算数      | 未选中【显示预算调整数】时，显示为预算数。该预算数包含原始预算数+预算调整数。\\ 选中【仅显示原始预算数】时，预算数=原始预算数，不含调整数。               |
| 预算原始数    | 选中【显示预算调整数】时，显示本列。                                                                     |
| 预算调整数    | 选中【显示预算调整数】时，显示本列。                                                                     |
| 调整后预算数   | 选中【显示预算调整数】时，显示本列。调整后预算数=原始预算数+预算调整数                                                   |
| 申请占用     | 过滤条件所选预算控制规则，【控制单据】.【预算影响类型】=“申请占用”的单据，统计该单据相应项目数据类型的【单据字段】金额。\\ 已关闭的单据，不在【申请占用】统计范围。  |
| 申请冲回     | 过滤条件所选预算控制规则，统计单据相应项目数据类型的【单据下推回写/冲销源单字段】金额。                                           |
| 预算执行     | 过滤条件所选预算控制规则，【控制单据】.【预算影响类型】=“预算执行”的单据，统计该单据相应项目数据类型的【单据字段】金额。                         |
| 执行冲回     | 过滤条件所选预算控制规则，【控制单据】.【预算影响类型】=“预算冲回”的单据，统计该单据相应项目数据类型的【单据字段】金额。                         |
| 实际执行     | 【申请占用】-【申请冲回】+【预算执行】-【执行冲回】                                                            |
| 可用预算     | 【预算数】/【调整后预算数】-【实际执行】                                                                  |
| 预算执行进度%  | （实际执行/调整后预算数）%                                                                         |



**其他说明**
  - 点击【联查预算执行明细】，联查预算执行明细表。
  - 由于交叉分析表，基于交叉表控件实现，导致小计行和总结行的【预算执行进度%】无效。
  - 已作废的单据，不在实际执行单据统计范畴。
