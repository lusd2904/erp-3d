ID: 离散工序在制品统计表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A6%BB%E6%95%A3%E5%B7%A5%E5%BA%8F%E5%9C%A8%E5%88%B6%E5%93%81%E7%BB%9F%E8%AE%A1%E8%A1%A8

**应用场景**

帮助车间主管掌握各车间、产品工序在制品数量情况，了解生产进度，帮助分析瓶颈环节，预测生产任务能否按计划完成，以便合理调度，保证生产顺利进行。

**功能路径**

【生产制造】-->【车间管理】-->【报表分析】

【智慧车间MES】-->【智慧车间】-->【报表分析】

**过滤条件**

快捷
^  字段        ^  说明                                                                                                                                               ^
| 生产组织       | 1.可选择用户有权限的具有工厂职能的组织；支持多选\\ 2.生产组织修改后变更生产车间的值列表。                                                                                                  |
| 生产车间       | 所选生产组织下的审核的基本生产车间；可以多选                                                                                                                            |
| 加工组织       | 1.可选择用户有权限的具有工厂职能的组织；支持多选\\ 2.加工组织修改后变更加工车间的值列表。                                                                                                  |
| 加工车间       | 所选加工组织下的审核的基本生产车间；可以多选                                                                                                                            |
| 工作中心       | 1.加工组织下已审核的工作中心。\\ 2.可以多选\\ 3.加工组织变化时，清空工作中心                                                                                                      |
| 作业         | 1.所选加工组织下的审核的作业；可以多选\\ 2.加工组织变化时，清空作业                                                                                                             |
| 产品         | 所选加工组织下的审核的物料                                                                                                                                     |
| 生产订单       | 用户有权限的生产组织下的生产订单，单据类型.启用工序跟踪=是  且  柔性生产=否\\ 分录行状态=下达、开工、完工\\ 列表按生产订单编号降序排列                                                                        |
| 工序计划       | 用户有权限的生产组织下的工序计划\\ 工序计划对应生产订单.单据类型.启用工序跟踪=是  且  柔性生产=否\\ [工序计划-单据头].单据状态=已审核\\ [工序计划.工序列表-分录行].委外=否\\ [工序计划.工序列表-分录行].状态=开工 或 完工\\ 列表按工序计划单号降序排列  |
| 在制品数量为零显示  | 勾选：在制品数量=0，报表显示\\ 不勾选：在制品数量=0，报表不显示                                                                                                               |

**报表字段**
^  字段     ^  说明                                                        ^
| 数量      | [工序计划.工序列表-分录行]工序数量                                        |
| 转入数量    | [工序计划.执行情况.转移数量]转入数量                                       |
| 合格数量    | [工序计划.执行情况.汇报数量]合格数量                                       |
| 废品数量    | [工序计划.执行情况.汇报数量]废品数量                                       |
| 返修转出数量  | [工序计划.执行情况.汇报数量]返修转出数量                                     |
| 工序盘点差异  | [工序计划.执行情况.工序数量]工序盘点差异                                     |
| 在制品数量   | 计算公式：转入数量 - 合格数量 - 废品数量 - 返修转出数量+工序盘点差异，在制品数量<0时，整行数据黄色显示  |
