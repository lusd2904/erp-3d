======1  生产订单执行明细表=======
=====1.1 报表功能=====

1.生产订单执行明细表能够使用户能及时地了解各生产订单的执行情况。

2.生产订单执行明细表支持按照产品/车间/单据类型等多维度，进行查询生产订单的执行情况。

======2. 字段说明======

=====2.1 快捷过滤 =====
^  **字段**  ^  **说明**                                     ^
|  生产组织    | 1.定义报表查询的组织范围；\\ 2.必须具有生产职能，有且只能录入一个组织。     |
|  下达日期    | 1.生产订单分录行的下达日期；\\ 2.定义报表查询的下达日期范围。          |
|  计划开工日期  | 1.生产订单分录行的计划开工日期；\\ 2.定义报表查询的计划开工日期范围。      |
|  计划完工日期  | 1.生产订单分录行的计划完工日期；\\ 2.定义报表查询的计划完工日期范围。      |
|  单据类型    | 1.生产订单的单据类型；\\ 2.定义报表查询的生产订单的单据类型。          |
|  生产订单    | 1.生产订单的编号；\\ 2.定义报表查询的生产订单范围。               |
|  生产车间    | 1.生产订单表体分录的生产车间；\\ 2.定义报表查询的生产车间范围。         |
|  产品编码    | 1.生产订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。          |
|  挂起状态    | 生产订单分录行的挂起状态。                               |
|  业务状态    | 1.生产订单分录行的业务状态；\\ 2.包含：下达、开工、完工、结案，结算五个选项。  |
=====2.2 报表字段 =====
^  **字段**    ^  **说明**                                         ^
|  产品编码      | 生产订单表体分录对应的【物料编码】。                              |
|  产品名称      | 生产订单表体分录对应的【物料名称】。                              |
|  规格型号      | 生产订单表体分录对应的【规格型号】。                              |
|  生产单位      | 取物料生产页签的生产单位。                                   |
|  计划生产数量    | 生产订单分录中计划生产的数量。                                 |
|  汇报数量      | 生产订单分录汇报的产品数量\\ 汇报数量=生产订单汇报选单数量                 |
|  请检数量      | 生产订单分录关联所有汇报单的检验选单数量之和                          |
|  检验数量      | 生产订单分录关联所有汇报单的检验数量之和                            |
|  完工数量      | 1.生产订单分录中完工入库的产品数量；\\ 2.完工数量=合格品入库数量+不合格品入库数量。  |
|  合格品入库数量   | 符合过滤条件的生产订单分录中合格品入库的数量。                         |
|  不合格品入库数量  | 符合过滤条件的生产订单分录中不合格入库的数量。                         |
|  返工品入库数量   | 符合过滤条件的生产订单分录中返工品入库的数量。                         |
|  计划完成百分比   | 计划完成百分比=完工数量/计划生产数量*100%。                       |
|  合格率       | 1.合格品入库数量占入库数量的比重；\\ 2.合格率=合格品入库数量/完工数量*100%。   |
|  产品类型      | 生产订单分录行的产品类型，包含主产品和联副产品。                        |
