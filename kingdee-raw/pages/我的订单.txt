ID: 我的订单
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%88%91%E7%9A%84%E8%AE%A2%E5%8D%95

**功能说明：**

用户下单后，通过我的订单可以查询订单的状况，以便进行处理和跟踪。

**功能路径：**

【我的订单】->【我的订单】 

**使用前提：**

无

**字段说明：**
订单显示字段
| **名称**  | **字段取数说明**                                           |
| 序号      | 系统流程水号，自动生成                                          |
| 订单编号    | 按编码规则生成的订单编号                                         |
| 订单日期    | 创建订单时的日期                                             |
| 销售组织    | 进行订货的默认内部组织                                          |
| 订单金额    | 订单所有商品的价税合计，总金额                                      |
| 单据状态    | 根据订单处理情况更新，包含值范围为保存、提交、审核、打回、关闭、部分发货、已完成             |
| 签收状态    | 根据订单是否签收来改变签收状态值                                     |
| :::     | 已发货未确认收货之前签收状态均为未开始                                  |
| :::     | 已发货部分确认收货时签收状态为部分签收                                  |
| :::     | 订单所有商品发货完成且确认收货完成则为已签收                               |
| 操作      | 提供物流跟踪、删除、撤单、付款、签收                                   |
| 物流跟踪信息  | 销售出库单审核后会将物流公司、物流单号等反写到BBC订单。若系统已接入快递100，则可以跟进物流过程。  |

手工新增时的订单字段与下达订单字段一样

**操作说明：**
新增手工单：
  - 打开我的订单或BBC订单查看页面，点击【新增】按钮；
  - 填写订单相关信息
  - 信息填写好后，【保存】或【提交】即可。保存状态下的订单保存在本地并未提交至订货方，允许编辑修改。【提交】后的订单已提交至订货方，故不能修改。

**订单查看：**
  * 全部订单：包含了所有订单状态的订单，点击具体订单可以查看订单详情；
  * 待确认：只显示提交之后需要进行确认的订单
  * 待审核：显示提交或确认之后需要进行审核的订单
  * 待发货：只显示审核之后需要进行发货的订单
  * 待签收：只显示提交之后需要进行签收的订单
  * 已关闭：显示手工关闭的订单
