ID: 委外工序进度表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A7%94%E5%A4%96%E5%B7%A5%E5%BA%8F%E8%BF%9B%E5%BA%A6%E8%A1%A8

**报表功能**

按供应商查询每个委外任务的进度，可以查询到供应商结余，供应商返回的质量状况。

**功能路径**

【生产制造】－>【车间管理】－>【报表分析】－>【委外工序进度表】

**过滤条件**

“快捷”页签：快捷设置生产组织、计划开始日期、计划结束日期、供应商、作业、生产订单编号、工序计划单号、产品编码、工序状态等基本过滤条件。

“排序”页签：可按照用户关心的选项，设置报表中明细行的排列顺序。

“显示隐藏列”页签：设置报表的字段是否显示以及显示顺序。

**快捷过滤**

| **字段**         || **说明**                                                            |
| 生产组织           || 1.选择要统计的生产组织；\\ 2.用户有权限的具有工厂职能的组织，只能选单个组织。默认为登录组织；查询工序计划表头的生产组织；  |
| 计划开始日期         || 查询工序计划分录的开工日期                                                     |
| 计划结束日期         || 查询工序计划分录的完工日期                                                     |
| 供应商            || F8生产组织委托采购组织下的供应商，查询工序计划分录的供应商                                    |
| 作业             || F8生产组织下的作业，查询工序计划分录的作业                                            |
| 生产订单编号         || F8生产组织下的生产订单，查询工序计划所属的生产订单                                        |
| 工序计划单号         || F8生产组织下的工序计划，查询工序计划单据号                                            |
| 产品编码           || F8生产组织下的物料，查询工序计划所生产的的物料                                          |
| 工序状态           || 工序计划分录状态                                                          |
| 显示结存数量为0工序     || 是否显示委外工序的供应商结余等于0的记录，委外发出-委外接收-返修转出数量<>0                          |
| 查询总结余          || 不考虑时间，查询供应商处还有多少结余                                                |

**报表字段**

|供应商编码||工序委外供应商编码|
|供应商名称||工序委外供应商名称|
|产品编码||工序委外产品编码|
|产品名称||工序委外产品名称|
|规格型号||工序委外产品的规格型号|
|序列号||工序计划序列号|
|工序号||工序计划分录中工序号|
|作业||工序计划分录中委外作业名称|
|计划开始日期||工序计划中的计划开始日期|
|计划结束日期||工序计划中的计划结束日期|
|计量单位||生产订单的计量单位|
|工序数量||按生产订单计量单位显示工序数量|
|委外发出(转入)||工序计划中委外工序的转入数量|
|委外接收(转出)||工序计划中委外工序的转出数量|
|合格数量||工序计划中委外工序的合格数量|
|工废数量||工序计划中委外工序的工废数量|
|料废数量||工序计划中委外工序的料废数量|
|结存数量||工序计划中委外工序的转入数量-转出数量-废品数量-返修转出数量|
|委外周期||工序计划中委外工序的最晚的转出类型转移单单据日期 - 最早转入类型的转移单单据日期，工序状态=完工时不显示|
|工序状态||工序计划中委外工序的工序状态|

**操作说明**

系统支持查询结果的打印、引出和刷新等通用操作，用户可以点击菜单的【选项】按钮，设置查询的数据列为零是否显示、数据列尾零是否显示以及查询时是否首先弹出过滤界面等。
