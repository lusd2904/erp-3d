====== 电子回单 ======
=====1 功能说明 =====
  * 是企业所有通过银企互联方式直接下载的电子回单的留档。
  * 为了用户操作简便，系统支持下载、查询、打印电子回单。
  * 用户可以通过电子回单匹配交易明细和业务单据。

=====2 操作前提 =====

已经进行了银企互联设置并且已经测试通过。

=====3 功能路径 =====

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单】

=====4 字段说明 =====
| **字段**       || **说明**            |
| 单据编号         || 自动生成电子回单的单据编号。    |
| 业务单据类型       || 匹配到的业务单据的类型。      |
| 业务单据编号       || 匹配到的业务单据编号。       |
| 业务参考号        || 交易流水里的业务参考号。      |
| 币别           || 电子回单币别。           |
| 银行           || 银行账号对应的银行。        |
| 银行账号         || 电子回单要下载的银行账号。     |
| 银行账户名称       || 银行账号对应的账户名称。      |
| 借方（付款）金额     || 电子回单上的付款金额。       |
| 贷方（收款）金额     || 电子回单上的收款金额。       |
| 金额           || 付款金额减去收款金额。       |
| 电子回单编号       || 下载到的电子回单的编号。      |
| 交易流水号        || 匹配成功的交易明细的流水号。    |
| 关联标记         || 银企传值，与交易明细做匹配用。   |
| 验证码          || 电子回单验证码。          |
| KD标识         || 通过银企付款的单据会有KD标识。  |

=====5 操作说明 =====

电子对账单与银行系统进行交互的业务操作，详细说明如下：

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单】—>【下载银行对账单】，下载所需要日期范围的银行电子回单。

也支持通过“执行计划列表”中的“自动下载电子回单”任务，定时自动下载电子回单。
