====== 分析查询方案 ====== 

**功能说明**

在H5卡片式主页，提供预算排行分析。为准确的获取目标预算业务的执行排行，需要进行过滤条件的配置，即：分析查询方案。

**功能路径**


【管理会计】-【预算管理】-【基础资料】-【分析查询方案】


 ====== 字段说明 ======

** 查询设置 **
^  字段      ^ 说明                                                                             ^
| 预算方案     | 选择一个需要查询的预算方案                                                                  |
| 预算控制规则   | 选择一个需要查询的预算控制规则                                                                |
| 币别       | 选择一个需要查询的预算币别                                                                  |
| 本位币      | 如果预算控制规则，为控制本位币时，需要选择一个查询的本位币                                                  |
| 预算组织     | 选择需要查询的一个预算组织                                                                  |
| 选项：包含下级  | 选中后，根据所选预算组织，展示预算组织及其下级预算组织的预算执行汇总数。                                           |
| 预算周期     | 选择需要查询的预算周期类型                                                                  |
| 预算年度     | 选择需要查询的预算年度                                                                    |
| 预算期间     | 选择需要查询的预算期间                                                                    |
| 选项：当前期间  | 选中后，预算年度、期间，允许为空。\\ 选中后，预算年度、期间，系统自动根据当前系统时间，根据预算日历（预算方案关联），找到系统时间对应的预算年度、期间。  |
| 项目数据类型   | 选择需要查询的一个项目数据类型                                                                |
| 预算业务类型   | 选择需要查询的一个预算业务类型                                                                |
| 预算维度     | 选择需要查询的一个预算维度                                                                  |


**其它说明**

系统内置包含已提交未审核单据。

**操作说明**

分析查询方案成功审核后，需要通过[[分析方案分配]]，将分析方案分配到“预算执行排行”分析对象。
