====== 1、报表功能 ======

多账簿核算维度汇总表以报表的形式展示出对明细维度的汇总分析，并且提供了任意角度分析、过滤、实时显示，并可保存查询方案的特点，特别适合在线数据分析、数据采集与决策分析使用。

多账簿核算维度汇总表既支持在集团层面查看多账簿的数据，也可以查看单账簿的数据。

====== 2、过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置会计年度期间、科目和核算维度范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。
^ 过滤项               |^ 说明                                                                 ^
| 账簿隶属关系            || 设置账簿隶属关系                                                           |
| 合并层级              || 设置账簿隶属关系的节点，可以选择到最明细账簿；账表根据该项展示相应层级的数据。                            |
| 使用核算维度组合查询        || 选中此项，核算维度查询界面为核算维度组合选择界面，用户设置多个核算维度查询；反之，核算维度查询界面只能选择某个核算维度查询。     |
| 核算维度组合            || 选中“使用核算维度组合查询”，用户可设置多个核算维度组合成新的核算维度进行查询。                           |
| 核算维度              || 设置查询的核算维度。                                                         |
| 核算维度编码            || 设置查询的核算维度范围。                                                       |
| 显示禁用核算维度          || 选中此项，核算维度查询范围能显示已禁用维度；反之，则不能显示已禁用维度。                               |
| 显示小计              || 选中此项，报表按照用户选择的小计类型进行显示，可按核算维度小计、科目小计。                              |
| 跨期小计              || 选中此项，报表在所选期间内只提供一个小计数，不再按照会计年度期间小计。                                |
| 分页显示              || 选中此项，报表按照用户已经选择的核算维度进行分页显示，可查询每个核算维度分页下的汇总信息。                      |
| 分页核算维度            || 如果是单核算维度查询，默认就以该维度分页；如果是多核算维度查询，用户可选择以某个核算维度分页。                    |
| 仅显示期初不为零且本期无发生额的记录     || 选中此项，只显示余额不为零且查询期间没有发生额的核算维度汇总数据。  |
| 余额方向与科目余额方向一致     || 选中此项，余额的显示方向与科目设置的余额方向相同，可能出现余额为负数的情况。否则，当余额为负数时，在科目余额的相反方向以正数显示。  |

====== 3、操作说明 ======

  * 系统支持多账簿核算维度汇总表联查多账簿核算维度明细账，用户选择需要联查的记录，点击菜单的查看明细账按钮联查核算维度明细账信息。
  * 系统支持跳转功能，用户点击“跳转”按钮调用分页账表目录，通过双击任意行来实现快速跳转到指定分页。
