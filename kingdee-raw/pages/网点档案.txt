====== 网点档案 ======

**1、功能概述**

用于维护管理参与渠道营销业务的各个节点（营销网点）的档案资料；例如：处理总公司向分公司，向业务员，最后到门店层层分货业务时，总公司、分公司、业务员、门店就是营销网点，必须定义它的网点档案；

营销网点只是一个管控节点，并不具体处理业务，网点档案下必须维护营销人员，营销人员才是具体处理业务的操作员；

**2、功能路径**

【BBC业务中心】→【网点】→【网点档案】

**3、使用前提**

根据要创建的营销网点的网点类型不同，决定必须要先维护组织、部门、业务组、渠道或营销人员；

**4、字段说明**

^ 字段名称    ^ 说明                                               ^
| 编码      | 通过编码规则自动生成，唯一；                                   |
| 名称      | 手工编辑，必填；                                         |
| 网点类型    | 可取值为所有网点类型；                                      |
| 对应组织    | 必填；\\ 可取值为：用户组织权限范围内的组织；                         |
| 对应部门    | 网点类型为“部门”时必填；\\ 可取值为：组织权限范围内所有已审核未禁用且未生成过网点的部门；  |
| 对应业务组   | 网点类型为“业务组”时必填；\\ 可取值为：组织权限范围内所有未禁用且未生成过网点的业务组；   |
| 对应渠道    | 网点类型为“渠道”时必填；\\ 取值范围为：组织权限范围内所有未禁用且未生成过网点的渠道；    |
| 对应营销人员  | 网点类型为“渠道”时必填；\\ 可取值为：组织权限范围内所有未禁用且未生成过网点的营销人员；   |
| 启用状态    | 可取值为：未启用、已启用、已禁用；默认为“未启用”；                       |
| 国家      | 中国                                               |
| 省份      | 可取值为：当前选中国家下所有省份；                                |
| 城市      | 可取值为：当前选中省份下所有城市；                                |
| 区/县     | 可取值为：当前选中城市下所有区/县；                               |
| 街道/乡镇   | 可取值为：当前选中区/县下所有街道/乡镇；                            |
| 街道地址    | 手工编辑；                                            |
| 详细地址    | 手工编辑；                                            |
| 经度      | 手工编辑；                                            |
| 纬度      | 手工编辑；                                            |

**5、操作说明**

查看：用户只能查看其组织权限范围内的营销网点；

新增：用于手工新增营销网点；

ERP组织导入：批量导入组织生成营销网点；

ERP部门导入：批量导入部门生成营销网点；

ERP业务组导入：批量导入业务组生成营销网点；

渠道导入：批量导入渠道生成营销网点；

营销人员导入：批量导入营销人员生成营销网点；

删除：删除未启用且未被营销关系树引用的营销网点；

禁用：禁用营销网点，营销网点的启用状态变成“已禁用”，营销网点不可以被其它业务引用，且不能编辑；

启用：启用营销网点，营销网点的启用状态变成“已启用”，营销网点可以被其它业务引用，且不能编辑；

撤销启/禁用：撤销启/禁用营销网点，营销网点的启用状态变成“未启用”，营销网点可编辑；

更新网点组织：如果生成营销网点的渠道或者营销人员的所属组织发生了变化，可以通过更新网点组织操作更新最新的网点对应组织信息；
