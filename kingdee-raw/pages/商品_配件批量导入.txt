ID: 商品_配件批量导入
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81_%E9%85%8D%E4%BB%B6%E6%89%B9%E9%87%8F%E5%AF%BC%E5%85%A5

**功能说明：**

用于批量导入维护商品档案或配件档案

**功能路径：**

【商品】->【商品档案】->【商品档案】

**使用前提：**

无

**字段说明：**

  * 批量上传商品图片的导入模版字段说明如下：

| **数据库字段名**                                    | **字段名称**            | **导入字段填写说明**               |
| FGOODSID                                      | 主键                  | 全部设为0，系统自增长                |
| FENABLE                                       | *必录*启用状态            | 默认为0，1表示启用                 |
| FNUMBER#Unique                                | *必录*商品编码#唯一         | 按编码规则编码或直接取物料编码            |
| FNAME#2052                                    | *必录*商品名称#中文(简体/中国)  | 物料编码                       |
| FPROPERTY                                     | 商品性质                | 没用，按模板拷贝，全部设置为0            |
| FSPECIFICATION#2052                           | 规格型号#中文(简体/中国)      | 请把规格型号和图号合并放到规格型号，并用/隔开。  |
| FSHORTNAME#2052                               | 简称#中文(简体/中国)        |                            |
| FSELLERID#Number#T_ESS_SELLER#FSELLERID       | 商家#关联表编号            | 直接填写SELLER-1               |
| FCLASSID#Number#T_ESS_GOODS_CLASS#FCLASSID    | 商品分类#关联表编号          | 对应商品分类的分类编码                |

**操作说明：**

批量导入商品/配件：

批量导入商品和配件时，导入操作与模版等基本一致。只是通过字段标识了是商品还是配件

  - 进入商品档案页面，点击【导入模版】，将商品档案批量导入模版下载下来；
  - 根据模版要求整理相关的数据；
  - 点击【导入】，选择已维护好的图片批量导入数据，点击【确定】；
  - 若全部数据导入成功，则会提示导入成功；若存在数据错误，则会提示第几行记录导入失败，并提示失败的原因；

**模板使用说明**

需要填写商品表、B2B商品表、B2C商品表三个表，商品图片表支持图片批量导入

  - 下载的模板内页签名为实体的标识，请不要更改。
  - 下载的模板内列名为实体字段的标识，请不要更改。
  - 下载的模板内列名标识【#Unique】的唯一性字段。
  - 下载的模板内列名标识【#Number#表名】的为关联字段，需要填写对应主表的【编号】。
  - 下载的模板内列名标识【#2052(或其它语言)】的为多语言表字段。
  - 标注蓝底和(*)为必录项，必须要填写。
