====== 1.交易对账记录单列表 ======

===== 1.1 功能概述 =====
显示交易对账完成后的明细

===== 1.2 字段说明 =====
^ 字段         ^ 说明                                ^
| 单据编号       | 由交易对账自动生成                         |
| 营业组织       | 对账的组织                             |
| 营业日期       | 对账的营业日期                           |
| 结算方式       | 包括微信/支付宝                          |
| 对账日期       | 对账的时间                             |
| 对账人        | 对账时登录系统的用户名                       |
| 自动对账金额     | 自动对账的金额（能够匹配对账字段配置的金额）            |
| 确认对账金额     | 财务人员最终确认的金额                       |
| 差异状态       | 有差异或者无差异                          |
| 交易流水号      | 第三方产生的交易流水号                       |
| 第三方支付单编号   | 第三方支付的单据编号                        |
| POS账单单据编号  | POS账单的单据编号                        |
| POS账单编号    | POS账单的账单编号                        |
| 第三方支付时间    | 微信/支付宝支付的时间                       |
| POS账单结账时间  | POS账单结账的时间                        |
| 第三方支付金额    | 微信/支付宝支付的金额                       |
| POS账单结算金额  | POS账单结算的金额                        |
| 自动对账金额     | 每一行自动对账的金额，默认取第三方支付金额             |
| 差异状态       | 是否有差异                             |
| 确认对账金额     | 财务人员最终确认的金额                       |
| 差异说明       | 简单说明差异的原因，比如缺少POS账单数据或者缺少第三方交易数据  |
