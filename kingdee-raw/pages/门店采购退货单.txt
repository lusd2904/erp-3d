====== 1.门店采购退货单 ======

===== 1.1 功能概述 =====
供应商的货物经过检验不合格或生产过程发现的不合格需要退给供应商，退料单就是记录退料信息的业务单据。详细业务说明参见采购退料业务。
===== 1.2 字段说明 =====
==== 1.2.1 表头明细字段 ====
^ 字段名称             ^ 字段说明                                 ^
| 物料编码             | 退料单分录的物料编码，从物料的基础资料中选择               |
| 物料说明             | 物料的说明，在业务类型为“资产”时显示                  |
| 物料名称             | 指物料的名称，根据物料编码携带                      |
| 规格型号             | 指物料的规格型号，根据物料编码携带                    |
| 物料类别             | 指物料的类别，根据物料编码携带                      |
| 库存单位             | 物料的库存单位，只能选择与基本单位存在固定换算率的计量单位        |
| 实退数量             | 实际的退料数量                              |
| 补料数量             | 需补货的数量，补货方式为“创建补货订单”时才允许编辑且不能大于实退数量  |
| 扣款数量             | 需扣款的数量，不能大于退料数量                      |
| 仓库               | 物料的退料仓库，只能选择退料组织下的仓库                 |
| 仓位               | 若仓库有仓位管理，则表示物料的退料仓位，从仓库对应的仓位列表中选择    |
| 库存状态             | 退料物料的库存状态，从仓库可选的库存状态中选择              |
| 辅助属性             | 如果物料启用辅助属性，则表示物料的辅助属性                |
| 描述               | 辅助描述                                 |
| 是否赠品             | 标识物料是否赠品                             |
| 计价单位             | 物料的计价单位                              |
| 计价数量	按计价单位计量的数量  |                                      |
| 采购单位	物料的采购单位     |                                      |
| 采购数量	按采购单位计量的数量  |                                      |

===== 1.3 业务说明 =====
**一、	库存查询**

退料单上支持库存查询功能，直接调用库存数据，具体库存查询的规则同采购申请单，请参考采购申请单 

**二、	补货处理**

退料单支持补货处理，补货规则同退料申请单，请参考退料申请单 

**三、	即时库存更新**

退料单会按照库存参数【库存更新方式】影响库存数据，规则如下 
  * 退料单【库存状态】字段为空时不更新库存，不为空时更新库存 
  * 退料单更新库存量以【实退数量】为准 
  * 保存、反作废、审核时扣减库存，删除、作废、反审核时增加库存，具体以【库存更新方式】为准
**四、	退料单批号相关业务**
  * 退料单行操作菜单上提供批号相关操作，有以下二种 
  * 批号库存，以批号为维度查询物料库存 
  * 批号主档，查询当前物料的批号主档
**五、	退料单单据转换**

退料单可以直接下推采购订单，也可以在采购订单界面选单退料单生成采购订单，实现关联业务的转化，转化的规则如下： 

  * 在采购订单界面选单时，可选择的退料单列表界面默认只过滤出符合上面条件的退料单 
  * 选择多张退料单合并生成采购订单时，供应商、退料组织、采购组织、结算币别相同的分录才能合并到一张采购订单上 
  * 退料单下推采购订单时，退料单的字段关联携带到采购订单上 
  * 采购订单的【数量】不能大于【补料数量】-【关联数量】，否则采购订单无法保存、反作废 
  * 采购订单保存、反作废时，累计反写退料单【关联数量】，作废以及删除时需要相应扣减数量
