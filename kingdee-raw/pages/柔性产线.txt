ID: 柔性产线

**功能概述**

柔性产线相对于传统大批量生产线具有单件流、人性化、空间利用率高等特点，更能适应小批量、多品种、个性化的生产需求。

**功能路径**

【工程数据】－>【工艺路线】－>【柔性产线】

【智慧车间MES】－>【智慧车间】－>【工艺建模】－>【柔性产线】

**字段说明**

**基本信息**

| **字段**        || **说明**                                                                                                |
| 生产类型          || 生产类型选择柔性生产后，可维护产线排程信息；                                                                                |
| 排产依据          || 工序计划/节拍产能，用于定义柔性产线进行订单排程时，使用工序计划的活动量公式，还是使用产线的节拍能力，来编制订单有限产能计划；提示：标准产品暂时只支持使用工序计划模式，后续考虑放开按产线节拍能力排程；  |
| 节拍产量、节拍时间     || 用于定义柔性产线的产能信息；                                                                                        |
| 总节拍数          || 原料从投入产线到产出经过的总节拍数；                                                                                    |

**MES参数**

^ **字段**                        ^ **说明**                                                                                                                                               ^
| **上料**                        |                                                                                                                                                      |
| 序列号关键件物料上料                    | 用于既启用“生产追溯序列号”又启用“批次管理”的关键物料上料；                                                                                                                      |
| 批次关键件物料投料方式                   | 定义智慧终端组装关键件绑定时的批次物料投料方式，分为上料和扫描；\\ 如果选择上料，则通过批量上料、倒扣的方式进行绑定和控制；\\ 如果选择扫描，则通过扫描方式绑定；\\ 优先根据产线.MES参数进行控制，若为空则根据车间管理参数进行判断（兼容版本升级）                      |
| 批次物料条码规则                      | 定义批次物料条码规则，为空时条码默认为批号；                                                                                                                               |
| 上料防错类型                        | 按物料品种粗放防错：上料时只进行物料品种的防错，不进行上料数量是否充足的防错；\\ 按品种及数量精细防错：上料时既进行物料品种防错，同时进行上料数量是否充足的防错；                                                                   |
| SMT上料校验飞达   PT[7.7.0.202108]  | 柔性产线.MES参数页签 增加参数“SMT上料校验飞达”，复选项，默认为否；\\ 站位表  保存取消Feeder规格型号必录；\\ 生产SMT上料表，保存增加校验：柔性产线.SMT上料校验飞达=是，Feeder规格型号 必录；柔性产线.SMT上料校验飞达=否，Feeder规格型号 不校验必录；  |
| **关键件防错**                     |                                                                                                                                                      |
| 扫描校验领料                        | 若物料启用序列号.库存管理=是，该参数勾选后，对应序列号必须领料后才允许扫描绑定；不勾选，则不进行校验。                                                                                                 |
| 根据出库单分录扫描关键件                  | 是，允许先扫描出库单分录条码，然后在“关键件扫描”界面扫描关键件条码；同时“扫描校验领料”=是； \\ 否，不允许扫描出库单分录条码；                                                                                  |
| 出库条码规则                        | 指定出库单条码规则，并按规则生成条码；\\ 为空默认为“生产领料单编号-行号”或“生产补料单编号-行号”；                                                                                                |
| 按投入物料指定批次倒冲                   | 勾选：按照工序汇报单.投入物料分录指定的批次，进行倒冲；不勾选：按照通用倒冲逻辑进行倒冲；                                                                                                        |
| **其他**                        |                                                                                                                                                      |
| 超时自动报工                        | 柔性产线投料完成后，当计时时长>= 柔性工艺路线.加工工时+ 超时时长 时，系统自动报工；\\        超时时长 = 柔性工艺路线.加工工时 ×  超时自动报工比例；\\        超时时长 = 0 时，不进行超时自动报工，避免影响首检、不良汇报等其他操作。               |
| 包装作业推送方式                      | 按用户：当前任务在该产线完全由当前用户负责的场景；\\        按站点：当前任务在该产线由当前产线不同人员负责的场景，例如：多班次交接班加工。                                                                           |
| 手动扫描汇报完工自动推送任务                | 结合订单排程使用，上一生产订单完工后，根据排程序号推送优先级最高（排程序号越小优先级越高）的生产任务；                                                                                                  |
| 非首序扫描自动查找任务（非包装作业）            | 是：非首序的普通作业任务，扫描已经绑定SN，自动查找工单任务；\\ 否：非包装作业，手动选择工单任务后，再进行扫描汇报；                                                                                         |
| 非首序切单自动发送换型请求（设备联网）           | 是，中间工序切换工单任务自动发送换型请求；\\        否，中间工序手动发送换型请求；注意：首序=是 ，手动发送换型请求；                                                                                     |

其它字段说明，见[[工作中心]]。
