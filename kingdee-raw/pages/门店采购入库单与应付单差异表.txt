====== 1.门店采购入库单与应付单差异表 ======

===== 1.1 功能概述 =====
显示门店采购入库单与应付单的差异的报表
可以查看已经审核的采购入库单哪些没有下推应付单，已经金额是否
===== 1.2 字段说明 =====
^ 字段    ^ 名称            ^
| 入库数量  | 采购入库单上的入库数量   |
| 入库单价  | 采购入库单上的入库单价   |
| 入库金额  | 采购入库单上的入库金额   |
| 应付数量  | 应付单的应付数量      |
| 应付单价  | 应付单的应付单价      |
| 应付金额  | 应付单的应付金额      |
| 差异数量  | 入库数量 - 应付数量   |
| 差异单价  | 入库单价 - 应付单价   |
| 差异金额  | 入库金额 -  差异金额  |
