====== 1.盘点方案模板 ======

===== 1.1 功能概述 =====

盘点方案模板支持临时盘点，日盘，月盘，周盘四中模式，同时支持后台自动生成物料盘点作业表的后台执行计划。
需要在物料中设置   
  * 日盘，每天盘点
  * 周盘：每周第几天盘点（第4天表示周四），只能输入1~7
  * 月盘：每月第几天盘点（28表示第28号），只能输入1~31
  * 周盘/月盘是，设置后面的第几天的同时还需要勾选周/月前面的勾选框后才会生效
===== 1.2 字段说明 =====
^ 字段名称           ^ 字段说明                                                                                                               ^
| 模板类型           | 支持日盘，月盘，周盘和临时盘点                                                                                                    |
| 启用自动计划         | 自动计划---设置自动计划，就启动该方案参与后台服务，服务执行时，该方案如有符合条件时则生成物料盘点作业表。停止自动计划---则停止该方案，不参与后台服务计算。模板类型为临时盘点，不可启动自动计划，其他类型的，可启动自动计划。  |
| 物料盘点作业表        | 生成盘点作业表---手工点击生成盘点作业表，则生成盘点作业表。查询盘点作业表，则跳转到该方案生成的物料盘点作业表。按生成时间先后顺序，倒叙排序。                                           |
| 零库存参与盘点        | 则获取库存表中的库存为0的物料；                                                                                                   |
| 物料盘点作业表允许增加物料  | 允许在盘点作业表上手工新增行，手工录入物料                                                                                              |
| 禁用物料不参与盘点      | 生成的物料盘点作业表中过滤去掉本组织已经禁用的物料                                                                                          |
| 实盘数            | 物料盘点作业表中的实盘数默认等于账存数或者默认为0                                                                                          |
| 盘点范围           | 点方案中设置盘点范围，物料盘点作业表根据盘点方案中设置的盘点范围来过滤生成                                                                              |
| 分单规则           | 盘点方案中设置分单规则，根据分单规则生成不同的物料作业表                                                                                       |
