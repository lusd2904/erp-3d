====== 食品类别列表 ======
====== 1.功能概述 ======
查看、维护、新增食品类别信息。为食品信息管理提供了分类管理功能，可以按照类别控制食品、点餐、打印、显示等功能。建立食品时必须有食品类别，且食品类别需要分配到对应门店方可使用。

====== 2.字段说明 ======

^ 字段        ^ 说明                             ^
| 部门        | 食品类别所属部门（云店通发布至商户平台时，部门也携带发布）  |
| 最大折扣率     | 该类别最大可以打折的比率                   |
| 点菜笔ID     | 点菜笔设备上编号                       |
| 分类        | 该食品类别的分类（菜品、酒水、半锅底、全锅底、油炸）     |
| IPAD显示模式  | 在iPad上显示的模式（普通类别、推荐、酒水）        |
| IPAD显示次序  | 在iPad上显示的顺序                    |
| POS显示     | 是否在前台营业POS上显示                  |
| 点菜笔显示     | 是否在点菜笔设备显示                     |
| IPAD显示    | 是否在iPad设备显示                    |
| 发布O2O状态   | 是否已经发布O2O                      |
====== 3.食品类别新增界面说明 ======
基本页面
在基本页面设置食品类别的基本信息，包括食品类别的所属部门、显示顺序、最大折扣率、类别分类、税率、厨显工作站等。标有星号“*”的输入框为必填项。
