====== 1功能概述 ======

供应商是金蝶云系统的核心基础数据，也是采购管理系统运行的重要业务资料。

====== 2使用前提 ======


  - 业务组织、币别等基础资料已经建立；
  - 基础资料分配策略已经设置；


====== 3功能路径 ======


【供应链】－>【采购管理】－>【货源与价格管理】－>【供应商】

或【基础设置】－>【基础资料】－>【供应商】
====== 4字段说明 ======
===== 4.1关键字段 =====
==== 4.1.1创建组织 ====

指供应商的创建组织
==== 4.1.2使用组织 ====

指使用供应商的业务组织

==== 4.1.3国家 ====

供应商所在的国家，从国家基础资料中选择

==== 4.1.4地区 ====

供应商所在的地区，从地区基础资料中选择

==== 4.1.5通讯地址 ====

供应商所在的地区的通讯地址

==== 4.1.6邮政编码 ====

供应商所在的地区的邮政编码

==== 4.1.7采购组 ====

指负责采购业务的小组，从业务组类型为采购的业务组里面选择

==== 4.1.8汇总公司 ====

指供应商的上级公司，从供应商基础资料中选择

==== 4.1.9默认价目表 ====

指供应商默认的价目表,从供应商对应的价目表中选择

==== 4.1.10默认折扣表 ====

指供应商默认的折扣表,从供应商对应的折扣表中选择

==== 4.1.11供货方 ====

指供应商的供货地点

==== 4.1.12VMI业务 ====

指供应商是否可以进行VMI业务

==== 4.1.13启用供应商协同 ====

指供应商是否启用供应商协同产品

==== 4.1.14对应客户 ====

  - 指与供应商存在结算关系的客户，从客户基础资料中选择。
  - 供应商在创建组织下，当维护了【财务信息】下的【对应客户】字段后，保存时自动将当前供应商赋值到选择的客户基础资料的【对应供应商】字段。
  - 供应商在创建组织下创建后，分配时会自动携带当前供应商上维护的【对应客户】字段到分配组织下，分配后自动将分配组织的供应商对应携带到其【对应客户】的客户基础资料的【对应供应商】字段。
  - 供应商分配后，在创建组织下反审核修改【对应客户】字段，保存时会自动将修改的值携带到分配组织，修改后分配组织下的供应商的值能自动携带到其【对应客户】的客户基础资料的【对应供应商】字段下。
  - 在供应商中删除【对应客户】字段后，已携带到客户上的【对应供应商】会被自动清空。

====== 5操作说明 ======
===== 5.1分配与取消分配 =====
  * 供应商为分配型的基础资料，需要在组织间分配，用户可用在单据或者列表界面进行分配。 
  * 只有分配给了相关的业务组织后，业务组织才能够使用。目标组织可用依据权限设置对分配过来的供应商进行修改操作。 
  * 用户也可用对已经分配的供应商取消分配。 
  * 用户可以在供应商列表中对供应商的分配信息进行查询。 
===== 5.2禁用与反禁用 =====
  * 当供应商发生异常情况时，用户可以在列表或者单据界面对供应商进行禁用操作。 
  * 供应商被禁用后不能进行任何的业务操作。 
  * 用户可以对已禁用的供应商进行反禁用操作。 

===== 5.3冻结与反冻结 =====
  * 当供应商的某些业务发生异常情况时，用户可以在列表或者单据界面对供应商进行冻结操作。 
  * 冻结操作提供了申请，订单，收货，退货，入库，发票，付款，询价，共八项选项。 
  * 供应商被冻结后不能进行对应的的业务操作。 
  * 用户可以修改供应商的冻结选项以及对已冻结的供应商进行反冻结操作。

===== 5.4联系人维护 =====
  * 供应商联系人是独立的基础资料，需要单独维护。 
  * 供应商联系人是联系对象的一部分，所有联系人都可以在联系对象中查看。 
  * 联系人可以在供应商资料上手工维护，也可以通过【供应商列表】－【选项】－【引入】－【引入供应商联系人】批量导入供应商联系人。


====== 6供应商协同平台 ======


  - 功能说明
在供应商【商务信息】中，勾选“启用供应商协同”。勾选后，该供应商才可以访问供应商协同门户和处理供应商协同业务。
  * 字段说明

启用供应商协同:是否启用供应商协同的功能，包括访问供应商协同门户和处理供应商协同业务。

  * 功能操作
  - 进入 供应链—采购管理—货源与价格管理—供应商列表。
  - 选择某个供应商，在供应商【商务信息】中，勾选“启用供应商协同”。
  * 业务说明
  - 不同的供应商，对企业的重要程度不一样，是否具备在线协同的能力也不一样。
  - 可按供应商分别设置是否启用供应商协同平台，实现对供应商的差异化管理。
