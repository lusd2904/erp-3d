ID: 按订单退货
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8C%89%E8%AE%A2%E5%8D%95%E9%80%80%E8%B4%A7

**功能说明：**

客户按已收货的订单进行申请退货。直接关联订单生成退货申请单

**功能路径：**

【退货】->【按订单退货】

**使用前提：**

存在收货记录的订单

**字段说明：**

表头-基本信息	
| **名称**   | **字段说明**                                                      |
| 退货申请编号   | 根据编码规则自动生成                                                    |
| 申请日期     | 默认取系统当前日期                                                     |
| 单据类型     | 按订单退货、拒签订单退货，根据来源订单默认选择对应的单据类型。无源单退货手工选择单据类型；                 |
| :::      | 可编辑，必填；                                                       |
| :::      | 单据类型值包括：企业商品退货申请单、渠道商品退货申请单、企业配件退货申请单、渠道配件退货申请单               |
| 业务类型     | 根据单据类型确定业务类型，根据业务类型和单据类型表确定。                                  |
| :::      | 目前包含如下业务类型：企业销售退货、渠道销售退货、企业保内配件退货、渠道保内配件退货、企业保外配件退货、渠道保外配件退货  |
| 单据状态     | 取值范围为：保存、提交、已确认、审核、打回、部分退货、已完成、手工关闭。                          |
| :::      | BBC门户提交退货申请单则为提交状态；                                           |
| :::      | 企业确认退货申请单则为已确认状态；                                      |
| :::      | 分录部分退货则为部分退货；                                                 |
| :::      | 分录全部退货完成则为已完成；                                                |
| :::      | 全部分录关闭则为手工关闭；                                                 |
| 签收状态     | 取值范围为：未开始、部分签收、已签收、无需签收。                                      |
| :::      | 签收之前状态为未开始；                                                   |
| :::      | 全部签收为已签收；                                                     |
| :::      | 虚拟退货或无实物签收为无需签收。                                              |
| 供货方类型    | 表示由谁供货，类型可能为渠道，或者组织                                           |
| 供货方      | 表示具体的供货方，为组织ID，或者渠道ID                                         |
| 联系人      | 退货处理的联系人。默认为渠道业务员，可修改                                         |
| 联系电话     | 根据联系人直接携带                                                     |
| 备注       | 退货申请单备注信息，手工填写                                                |
| 销售组织     | 默认携带上游单据的销售组织，无订单退货手工编辑。可编辑；                                  |
| 退货渠道     | 订单的订货渠道                                                       |
| 表体-明细信息                                                                 ||
| 名称       | 字段说明                                                          |
| 商品名称     | 选择退货商品的商品名称                                                   |
| 商品编码     | 根据商品ID，获取商家ID                                                 |
| 商品SKU    | 选择退货商品的商品SKU                                                  |
| 规格型号     | 选择退货商品的规格型号                                                   |
| 计量单位     | 携带退货商品的计量单位                                                   |
| 基本单位     | 携带退货商品的基本计量单位                                                 |
| 订单数量     | 默认携带来源订单的订单数量                                                 |
| 申请退货数量   | 输入申请退货的数量                                                     |
| 标准单价     | 商品发布的标准单价                                                     |
| 实际单价     | 实际单价=标准单价*（1-折扣率）                                             |
| :::      | 按订单退货可直接携带订单的标准单价                                             |
| 折扣率      | 暂无用处，后面促销时用到。默认为0                                             |
| 折扣额      | 默认为0                                                          |
| 价税合计     | 价税合计=申请退货数量×实际单价                                              |
| 签收状态     | 取值范围为：未开始、部分签收、已签收、无需签收。                                      |
| :::      | 签收之前状态为未开始；                                                   |
| :::      | 全部签收为已签收；                                                     |
| :::      | 虚拟退货或无实物签收为无需签收。                                              |
| 行处理状态    | 取值范围为：保存、提交、已确认、审核、打回、部分退货、已完成、手工关闭。                          |
| :::      | 门户提交退货申请单对应状态为提交；                                                 |
| :::      | 需要确认的退货申请单确认后，状态为已确认；                                         |
| :::      | 退货申请单审核通过，状态为审核；                                              |
| :::      | 退货申请单分录行打回，状态为打回；                                             |
| :::      | 若分录的累计签收数量（基本单位）<申请退货数量（基本单位），状态为部分退货；                        |
| :::      | 若分录的累计签收数量（基本单位）= 申请退货数量（基本单位），状态为已完成；                        |
| :::      | 手工关闭分录，状态则为手工关闭。                                              |
| 备注       |                                                               |

**操作说明：**
  - 进入按订单退货，选择申请退货的订单
  - 勾选好订单之后，点击退货申请
  - 确认或编辑修改退货申请单信息，提交
