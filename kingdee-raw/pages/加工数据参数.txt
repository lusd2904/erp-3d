======1.加工数据参数=======
=====1.1 功能概述=====

企业在销售、研发、生产过程中都有可能对产品提出各种变更需求，并将变更通知下发至各执行部门。变更通知单起到记录并下发变更的原因、变更内容及变更影响的作用。

=====1.2 使用前提=====

定义【物料】

定义【产品BOM】

=====1.3 功能路径=====

【餐饮加工管理】－>【加工基础数据】－>【参数设置】－>【加工数据参数】

======2. 字段说明======
===== 2.1 基本参数 =====
| 字段名称        | 字段说明                       |
| 损耗率处理方式     | 有两种方式：1/(1+损耗率)，1/(1-损耗率)  |
| BOM重复检查     | 有“是”“否”两种方式，选择是会校验BOM的重复性  |
| 重量换算关系      | 支持净重与毛重两种方式                |
| 换算类型        | 支持固定与浮动两种方式                |
| 批量维护已审核BOM  | 勾选则支持批量维护，不勾选则不支持批量维护      |
| BOM展开算法     | 支持精确计算和容错计算两种情况            |
| 新增子项的生效日期   | 支持系统日期与指定日期                |

======3. 操作说明======
====新增子项==== 
 

 变更类型为“立即变更”、“从指定日期”时，可进行新增子项操作。 
====修改子项==== 

变更类型为“立即变更”、“从指定日期”、“用完旧料”时，可进行修改子项操作。

变更类型为“从指定日期”时，不可修改被替代物料与替代物料；
变更类型为“用完旧料”时，不可修改普通替代的替代物料，不可修改组合替代的被替代料与替代料。

====删除子项==== 

变更类型为“立即变更”时，可进行删除子项操作。

删除子项时，如果被删除分录存在替代料，替代料会被一并删除。

====失效子项==== 

变更类型为“立即变更”、“从指定日期”时，可进行失效子项操作。

失效子项时，如果被删除分录存在替代料，替代料会被一并失效。

====更新用量清单==== 

ECN勾选“更新用料清单”时，可进行用料清单同步更新。 
 

====变更影响分析==== 

点击“变更影响分析”时，可查询变更单的影响单据。 

====指定升级的BOM版本==== 

有些企业BOM版本号中包含一定的信息，需要人为的指定BOM版本号；

如果工程变更单勾选了【版本升级】，且指定了升级后的BOM版本，工程变更单生效后，产生的新的BOM版本号为指定的BOM版本号。
