====== 电子票据开票 ======
=====1 功能说明 =====
  * 网上银行增加电子票据开票单。
  * 支持对接银企平台，通过付款单直接提交银企进行开票操作。
  * 支持通过电子票据开票直接生成出纳模块应付票据。

=====2 操作前提 =====

银企互联设置并且开通电票接口。


=====3 功能路径 =====

【财务会计】—>【网上银行】—>【电子票据】—>【电子票据开票】

【财务会计】—>【票据管理】—>【电子票据】—>【电子票据开票】

=====4 字段说明 =====
| **字段**       || **说明**            |
| 开票组织         || 付款单的付款组织    |
| 票据类型       || 银行承兑汇票和商业承兑汇票      |
| 电票状态       || 银行处理状态返回值      |
| 票据号码       || 银企平台回传的票据号码       |
| 票面金额           || 付款单明细实付金额       |
| 出票人全称        || 开票组织      |
| 出票人账号           || 使用组织=开票组织且勾选支持网银的银行账号           |
| 收款人全称           || 收款单位名称        |
| 收款人账号         || 对应收款单位基础资料维护的默认银行账号     |
| 承兑人全称     || 票据类型=“银行承兑汇票”，默认携带出票人开户银行，票据类型=“商业承兑汇票”，默认携带出票人名称       |
| 承兑人开户银行     || 票据类型=“银行承兑汇票”，默认与付款银行相同，票据类型=“商业承兑汇票”，默认携带出票人付款银行       |


=====5 操作说明 =====

  * 主控台菜单【财务会计】-【网上银行】-【电子票据】-【电子票据开票】二级功能菜单，点击【电子票据开票】进入电子票据开票单列表
  * 也可通过主控台菜单【财务会计】-【票据管理】-【电子票据】-【电子票据开票】二级功能菜单，点击【电子票据开票】进入电子票据开票单列表
  * 当付款单结算方式为银行承兑汇票或商业承兑汇票时，付款单明细页签可勾选“银企开票”复选框
  * 付款单提交审核后，下推电子票据开票单
  * 在电子票据开票单上维护对应的票据信息即可，对电子票据开票单进行提交审核
  * 电子票据开票单审核后进行“出票登记”，出票后，后续可进行“提示承兑”、“提示收票”、“撤销出票”等操作；
  * 银企状态返回出票成功后，电子票据开票单自动生成应付票据（可通过电子票据开票单下查应付票据）即完成对供应商的开票操作；
