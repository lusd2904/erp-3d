======1  委外订单执行汇总表=======
=====1.1 报表功能=====

1.委外订单执行汇总表能够使用户能及时地了解委外订单的整体执行情况。

2.委外订单执行汇总表支持按照产品/委外供应商/单据类型等多维度，进行查询生产订单的执行情况。


======2. 字段说明======

=====2.1 快捷过滤 =====
^  **字段**  ^  **说明**                                  ^
|  委外组织    | 1.定义报表查询的组织范围；\\ 2.必须具有委外职能，有且只能录入一个组织。  |
|  下达日期    | 1.委外订单分录行的下达日期；\\ 2.定义报表查询的下达日期范围。       |
|  计划开工日期  | 1.委外订单分录行的计划开工日期；\\ 2.定义报表查询的计划开工日期范围。   |
|  计划完工日期  | 1.委外订单分录行的计划完工日期；\\ 2.定义报表查询的计划完工日期范围。   |
|  单据类型    | 1.委外订单的单据类型；\\ 2.定义报表查询的委外订单的单据类型。       |
|  委外订单    | 1.委外订单的编号；\\ 2.定义报表查询的委外订单范围。            |
|  委外供应商   | 1.委外订单分录的供应商；\\ 2.定义查询报表的供应商范围。          |
|  产品编码    | 1.委外订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。       |
|  业务状态    | 1.委外订单分录行的业务状态；\\ 2.包含：下达、完工、结案，结算五个选项。  |
|  汇总依据    | 1.报表进行汇总的分类依据；\\ 2.包含：产品，供应商+产品两个选项。     |

=====2.2 报表字段 =====

^  **字段**  ^  **说明**               ^
|  委外单位    | 物料的委外单位。              |
|  计划生产数量  | 委外订单表体分录的【数量】之和。      |
|  采购执行数量  | 委外订单表体分录的【采购执行数量】之和。  |
|  入库数量    | 委外订单表体分录的【入库数量】之和。    |
