====== 1 功能描述 ====== 

当数据库服务器与应用服务器分开部署时，数据中心注册便于将存放在数据库服务器上的数据中心注册到应用服务器上，另外，还提供了反注册功能，当不再使用该数据中心时，可以反注册该数据中心。

**功能路径**

【数据中心列表】 

====== 2 字段说明 ======

===== 2.1 数据库服务器信息 =====

==== 2.1.1 数据库服务器 ====
定义当前数据库服务器的机器名称或者数据库服务器IP地址； ​

==== 2.1.2 实例名 ====

采用默认实例名即可；

==== 2.1.3 端口 ====

采用默认端口即可；

==== 2.1.4 数据库管理员 ====

输入数据库服务器管理员名称，数据库管理员用户将会使用模板创建数据中心；

==== 2.1.5 管理员密码 ====

输入数据库服务器管理员密码；

===== 2.2 数据库用户 =====

==== 2.2.1 数据库用户 ====
输入数据连接用户的帐号，数据库服务器中必须存在这个账户； ​
 ​
==== 2.2.2 密码 ====

输入数据连接用户的帐号密码；​

===== 2.3 数据中心 =====

==== 2.3.1 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.3.2 其他字段 ====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； ​


====== 3 功能操作 ======

===== 3.1 注册Oracle数据中心  =====  
  
注册Oracle管理中心需先在Oracle系统自带工具创建用户，然后再使用系统的注册Oracle数据中心功能。

在【数据中心列表】中，点击工具栏【注册】按钮组的下拉子按钮【注册Oracle数据中心】，如果管理中心是Oracle类型的，直接点击工具栏【注册】按钮，即可打开“注册Oracle数据中心”的界面。

  Oracle数据中心注册过程如下：
    
  1、输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码，输入后，可以进行【测试连接】确保输入信息有效。
  
  2、选择数据库用户，包括数据库用户和密码。
  
     数据库用户需录入Oracle数据库中已存在的用户名及其密码，并且该用户必须是注册数据中心对应的用户，而不能是注册管理中心对应的用户，输入后，可以进行【测试连接】确保输入信息有效。
     
  3、输入数据中心相关信息，包括数据中心代码、名称等。
  
  4、在注册界面中，确认相关信息后，点击【注册】按钮，即可注册管理中心。


 
===== 3.2 反注册数据中心  =====   
 
在【数据中心列表】中，选中注册的数据中心，点击工具栏【反注册】按钮，系统即可进行反注册。 

 
====== 4 其他说明 ======   
 
  - 数据中心注册成功后，在管理中心主页的列表界面会增加一条数据中心记录，可供选择登录和使用。 
  - 可以对已注册的数据中心进行反注册操作，反注册后将不在列表中显示，用户也不能登录及使用该数据中心，反注册后不会删除数据库实体。 
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。
