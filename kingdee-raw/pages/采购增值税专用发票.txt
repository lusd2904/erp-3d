====== 采购增值税专用发票 ======


====== 1 使用前提 ======

公共资料已设置，包括供应商、币别、结算方式、物料、费用项目、单位、采购部门、采购组、采购员、组织信息、账簿信息、汇率体系等。

====== 2 功能路径 ======

【税务管理】－>【发票管理】－>【采购发票】

====== 3 字段说明 ======

主要字段说明

^ 字段名      ^ 说明                                                                                              ^
| 业务日期     | 定义当前业务发生的日期；默认取当前日期。                                                                            |
| 发票号      | 填写向供应商收取的纸质发票上的发票号码，便于查询和对账。                                                                    |
| 发票日期     | 填写向供应商收取的纸质发票上的发票日期，便于查询和对账。                                                                    |
| 按含税单价录入  | 采购增值税专用发票字段。定义不同的报价方式。若勾选，报价为含税单价，录入含税单价，相关金额字段根据含税单价换算；若不勾选，报价为不含税单价，录入不含税单价，相关金额字段根据不含税单价换算。  |
| 税额       | 采购增值税专用发票、采购普通发票、进项费用增值税发票、进项费用普通发票字段                                                           |
| 可抵扣税额    | 采购增值税专用发票、采购普通发票、进项费用增值税发票、进项费用普通发票字段                                                           |
====== 4 操作说明 ======

===== 4.1 选单 =====

  * 第一步，在采购发票-新增界面点“选单”，弹出选择单据的窗口，选择应付单点“确认”；
  * 第二步，在弹出的应付单列表中勾选要生成发票的应付单，然后点“返回”，回到采购发票的新增界面；
  * 第三步，采购发票的字段会从应付单自动携带过来，可以修改单价、数量等；
  * 第四步，点击“保存”。

===== 4.2 应付单下推 =====

  * 第一步，进入【财务会计】－>【应付款管理】－>【采购应付】－>【应付单列表】；
  * 第二步，在列表中勾选要生成发票的应付单点 “下推”，弹出选择单据的窗口，选择采购发票，点“确认”；
  * 第三步，若只生成一张发票，系统返回采购发票的新增界面，字段从应付单自动携带过来，可以修改单价、数量等，点击“保存”；若生成多张发票，系统返回的界面分成上下两部分，上面是发票的列表，下面是采购发票的新增界面，可以通过点击“上一行”、“下一行”查看和修改多张发票的内容，修改完成后点击“生成全部”或在新增界面一一点击“保存。

说明：应付单下推发票可以选择按明细分录合并或者不按明细分录合并。

===== 4.3 应付开票核销 =====

应付单与发票可以进行核销，具体请参照应付开票核销。

===== 4.4 电子发票开具 =====

支持采购增值税专用发票反向开具报废产品收购专票

  * 支持资源回收企业反向开具报废产品收购发票[[https://vip.kingdee.com/knowledge/697542548583313664]]
====== 5 业务说明 ======

===== 5.1 不同发票逻辑说明 =====

采购增值税专用发票、进项费用增值税发票的税额采用价外税的逻辑；进项费用普通发票的税额采用价内税逻辑，采购普通发票支持价内价外两种计算逻辑。
