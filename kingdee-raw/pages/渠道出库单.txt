ID: 渠道出库单
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B8%A0%E9%81%93%E5%87%BA%E5%BA%93%E5%8D%95

**功能说明：**

用户所有渠道出库处理、渠道出库单处理情况查询以及历史渠道出库记录查询；

**功能路径：**

【我的进销存】->【渠道出库单】

**使用前提：**

拥有自行管理库存权限的渠道或门店

**字段说明：**

渠道入库单显示字段说明

| **名称**   | **字段说明**                                       |
| 出库单表头                                                    ||
| 渠道出库单编号  | 系统自动生成                                         |
| 供货渠道     | 系统自动取当前登录渠道，锁定不可修改                             |
| 要货渠道     | 下拉选择，从渠道档案中过滤出渠道档案.订货渠道=当前渠道的记录。               |
| 单据类型     | 根据上游单据关联选择单据类型，单据类型有下级渠道出库、门店开单出库、盘亏出库         |
| 业务类型     | 关联业务类型，业务类型有渠道出库、商用开单出库、O2O开单出库、政采开单出库、零售开单出库  |
| 出库日期     | 出库日期                                           |
| 状态       | 状态值有：保存、提交、重新审核、审核                             |
| 业务员      | 关联渠道的职员，如果BBC订单有，则自动携带，手工新增时，下拉选择供货渠道的职员。      |
| 终端消费者会员  | 参考零售开单的。                                       |
| 备注       | 渠道出库单手工备注                                      |
| 出库单表体                                                    ||
| 商品名称     | 要出库的商品名称                                       |
| :::      | 列表显示时，显示形式为：商品编码+商品名称+规格型号                     |
| 商品编码     | 根据选择的商品系统自动返回                                  |
| 规格型号     | 根据选择的商品系统自动返回                                  |
| 计量单位     | 根据选择的商品系统自动返回                                  |
| 出库数量     | 手工填写，可正可负，负数表示退货。                              |
| 仓库       | 默认为供货渠道的默认仓库                                   |
| 标准单价     | 根据可销售商品表返回                                     |
| 实际单价     | 默认等于标准单价，可修改单价                                 |
| 价税合计     | 价税合计=出库数量*实际单价                                 |
| 来源单据编号   | 记录渠道出库单上游单据的单据编号，手工创建的渠道出库单则为空                 |

**操作说明：**

1、进入渠道出库单页面，允许操作有新增、删除、提交、审核、反审核、刷新等操作
  * 新增：新建渠道出库单；
  * 删除：只有单据状态为保存或重新审核的渠道出库单才能删除；
  * 提交：可以保存之后提交或直接提交，提交后更新单据状态为提交；
  * 审核：只有单据状态为提交的渠道出库单才允许审核。审核之后，系统会自动扣减对应出库商品的库存；
  * 反审核：只有单据状态为审核的渠道出库单才允许反审核。反审核之后，系统会自动增加对应出库商品的库存；
 
2、新增渠道出库单，填写相关信息，保存或提交即可
