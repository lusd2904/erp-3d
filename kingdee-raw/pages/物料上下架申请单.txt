====== 1.物料上下架申请单 ======
===== 1.1 功能概述 =====

物料上下架申请单是设置物料的上架或者下架的情况，如果物料设置了下架并且执行状态为已执行，则该物料无法进行要货，配送等供应链的流程

===== 1.2 关键字段 =====

| 字段名称   | 字段说明                                                         |
| 申请类型   | 支持上架和下架两种类型                                                  |
| 执行日期   | 当上下架申请单中有物料已到执行时间，物料已变更状态，则此申请单不可反审核。若此申请单中没有物料已到执行之间，可反审核。  |
| 执行状态   | 包括已执行和未执行两种                                                  |
| 行作废状态  | 包括正常和已作废。当物料未到执行日期，可进行作废操作。当物料已到执行日期，且已执行，则不可作废              |
