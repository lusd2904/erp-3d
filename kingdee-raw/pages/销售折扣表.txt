====== 销售折扣表 ======

===== 1 功能概述 =====
折扣表设定销售折扣信息，提供整单折扣和行折扣，基于数量、单价和金额的折扣等多种折扣方式。

===== 2 使用前提 ===== 

定义组织资料、客户、销售业务员及物料、价目表资料。


===== 3 功能路径 =====  
【供应链】－>【销售管理】－>【价格管理】－>【折扣表】

 
===== 4 字段说明 =====  
1、表头字段：
| **字段**     || **说明**                                                                                                                                    |
| 销售组织       || 折扣表对应的销售组织，可F8选择具有销售职能的组织。                                                                                                                |
| 折扣对象       || 折扣对象是物料时，则按物料来定义折扣；当折扣对象是物料分组时，表体按物料分组定义折扣，单据上获取折扣时根据物料所属的分组，自动获取折扣。                                                                      |
| 生效日期       || 折扣表的生效日期                                                                                                                                  |
| 失效日期       || 折扣表的失效日期                                                                                                                                  |
| 限定客户       || 默认为空。系统提供选项“空”、“客户”、“客户类别”。当选择为“空”时，表头“适用客户”页签不显示且不可用；选择“客户”或“客户类别”时，表头“适用客户”页签可用，按客户或客户类别设定折扣表适用的客户或客户类别。                                |
| 限定销售员      || 默认为空。系统提供选项“空”、“销售员”、“销售组”、“部门”。选择为“空”时，表头“适用销售员”页签不显示且不可用，当选择“销售员”、“销售组”、“部门”时，表头“适用销售员”页签可用，按“销售员”或“销售组”或“部门”设定折扣表适用的“销售员”或“销售组”或“部门”。  |

2、表体字段：
| **字段**     || **说明**                                                                                      |
| 物料编码       || 当表头折扣对象选择“物料”时，该字段可维护，手工录入或F8选择物料编码。                                                        |
| 物料名称       || 根据物料编码携带                                                                                    |
| 物料分组编码  |   | 维护物料分组，按组定义折扣                                                                               |
| 折扣类型       || 默认“折扣”，提供选项“折扣”、“附加”。当选择“折扣”时，折扣为打折折扣，当选择“附加”时，折扣为附加折扣。                                     |
| 计算方式       || 默认“折扣率”，提供选项“折扣率”、“折扣额”。当选择“折扣率”时，折扣额字段不可编辑，按折扣率计算单据上的折扣额。当选择“折扣额”时，折扣率字段不可编辑，直接携带折扣额到单据上。  |
| 单位         || 物料的销售计价单位。                                                                                  |
| 折扣依据       || 默认“数量折扣”，提供选项“数量折扣”、“金额折扣” 。当选择“数量折扣”时，“从”、“至”字段录入的数量值；当选择“金额折扣”时，“从”、“至”字段录入的金额值。          |
| 从…至        || 录入折扣数量或金额的上下限范围                                                                             |
| 折扣率        || 折扣比率                                                                                        |
| 折扣额        || 折扣金额                                                                                        |
| 自动应用折扣     || 默认勾选。如勾选该选项，则单据上选择折扣表后，系统自动更新单据表体的折扣明细表，并自动计算折扣额；如果不勾选，则必须手动取折扣；                            |


 
 
===== 5 操作说明 =====  

1、默认折扣表功能
如果销售折扣表选择了【限定客户】并勾选了【默认折扣表】时，则此折扣表更新至客户基础资料中，成为该客户的默认折扣表。

2、分发与取消分发功能
请参考价目表设置的操作说明。

3、分发查询 
【供应链】->【销售管理】->【价格管理】->【销售折扣表】->【业务操作】->【分发查询】，可以查看目标组织、创建组织、分发人、分发日期等信息。

4、失效与取消失效功能 
请参考价目表设置的操作说明。

===== 6 应用注意事项 =====
  * 折扣表按物料分组定义折扣时，在单据上系统支持按物料所在组获取折扣。
  * 在同一折扣组内，物料的计量单位可能不同，同一个物料也会存在多个计量单位，因此系统会判断单据上物料的计价单位需要与物料资料上的计价单位一致，才能获取到该物料所属分组的折扣。
