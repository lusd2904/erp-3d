====== 1.配送管理参数设置 ======

===== 1.1 功能概述 =====

定义配送系统参数，在数量、补货、限价控制等方面设定配送规则。
配送参数设置后可以修改，以参数修改时间为时间点，只影响参数修改后新增的单据。


===== 1.2 关键字段 =====

| 参数                                                               | 选项                      | 参数说明                                                                                                                                                                                                                               |
| 允许超申请数量配送(取物料收发上线)                                               | 布 尔                     | 用以控制能否超要货申请下达配送出库。\\ •	勾选，配送出库数量不受要货申请数量的控制，出库数量允许超过申请数量（取物料收发上线）\\ •	不勾选，配送出库数量超过要货申请数量时不允许保存。                                                                                                                                    |
| 配送退货时自动创建补货申请                                                    | 布尔                      | 用以控制补料方式为【创建补料订单】的退料单审核时是否自动生成补料要货申请。\\ •	勾选，则退料单审核时自动生成补货要货申请。\\ •	不勾选，则退料单审核时不自动生成补货要货申请。                                                                                                                                        |
| 配送限价控制强度                                                         | •	不予控制\\ •	预警提示\\ •	强制  | 用以控制配送出库单据保存时价格超出限价控制的处理方式。\\ •	不予控制，则不检查价格即允许单据保存。\\ •	预警提示，则检查发现单据价格不在价格上下限中时，进行提示，用户确认后可以保存。\\ •	强制，则检查发现单据价格不在价格上下限中时，单据不允许保存。                                                                                                 |
| 要货汇总有货配送自动生成配送出库单                                                | 布尔                      | 用以控制要货申请汇总单审核后，可配送数量是否自动生成配送出库。\\ •	勾选，则要货申请汇总单审核时自动生成配送出库单。\\ •	不勾选，则要货申请汇总单审核时不自动生成配送出库单。                                                                                                                                        |
| 要货汇总采购物料生成自动\\ •	采购申请单\\ •	采购订单                                  | 布尔                      | 用以控制要货申请汇总单审核后，需采购数量是否自动生成采购申请单/采购订单。\\ •	勾选，则要货申请汇总单审核时自动生成采购申请单/采购订单。\\ •	不勾选，则要货申请汇总单审核时不自动生成采购申请单/采购订单。                                                                                                                        |
| 要货汇总加工物料自动生成\\ •	加工计划单\\ •	加工订单                                  | 布尔                      | 用以控制要货申请汇总单审核后，需加工数量是否自动生成加工计划单/加工订单。\\ •	勾选，则要货申请汇总单审核时自动生成加工计划单/加工订单。\\ •	不勾选，则要货申请汇总单审核时不自动生成加工计划单/加工订单。                                                                                                                        |
| 配送价优先来源\\ •	优先配送价目表\\ •	优先库存平均价\\ •      只取配送价目表\\ •    只取库存平均价  | 布尔                      | 用以控制配送出库时配送价的来源。\\ •	勾选优先配送价目表，则如果同时存在配送价目表和库存平均价，则配送出库时优先取从[[配送价目表|配送价目表]]取价。\\ •	勾选优先库存平均价，则如果同时存在配送价目表和库存平均价，配送出库时优先取[[即时库存|即时库存明细]]的参考单价\\ •       勾选只取[[配送价目表|配送价目表]]，则如果未设置配送价目表，则不取价 \\ •       勾选只取库存平均价，则如果没有库存平均价，则不会取价  |
| 自制物料备料计算原料需求生成\\ •	门店要货申请单\\ •	采购申请单                             | 布尔                      | 用来定义自制物料备料计算原料的下游单据；\\ 	勾选门店要货申请单，自制物料的原料需求会生成门店要货申请单\\ 	勾选采购申请单，自制物料的原料需求会生成采购申请单                                                                                                                                               |
| 配送出库单审核时自动生成门店收货单\\ •	创建\\ •	提交\\ •	审核                           | 布尔                      | 配送出库单审核时自动生成门店收货单\\ 	如果不勾选，则配送出库单审核时不会自动下推门店收货单\\ 	勾选创建，则配送出库单审核时会自动下推保存状态的门店收货单\\ 	勾选提交，则配送出库单审核时会自动下推审核中状态的门店收货单\\ 	勾选审核，则配送出库单审核时自动下推已审核状态的门店收货单\\ （三种状态是在门店设置默认仓库的前提，否则是暂存状态）                                              |
| 是否显示金额为0的单据                                                      | 布尔                      | 	门店订货单、门店收货单、门店退货单、采购入库单、采购退货单的金额为0时，根据总部配送管理参数中：提示金额为0单据及控制强度，给予对应得控制和交互\\ 	支持预警提示，不予控制，禁止交易三种类型\\ 	禁止交易时，当单据金额为0时，不可提交\\ 	预警提示时，当单据金额为0时，是否提交；用户点击“是”，则提交单据。用户点击“否”，则返回上一个页面。\\ 	不予控制时，当单据金额为0时，则不予控制，直接提交                  |
