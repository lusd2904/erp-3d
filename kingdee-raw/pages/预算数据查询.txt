ID: 预算数据查询
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E7%AE%97%E6%95%B0%E6%8D%AE%E6%9F%A5%E8%AF%A2

**功能描述**

查询预算数以及预算调整数。


**功能路径**

【管理会计】-【预算管理】-【预算分析】-【预算数据查询】

**过滤条件**

^ 字段             ^ 说明                                                                                         ^
| 预算方案           | 选择需要查询预算进度所在的预算方案                                                                          |
| 模板样式方案         | 选择需要查询的预算模板样式方案                                                                            |
| 预算组织           | 选择需要查询的一个或者多个预算组织                                                                          |
| 预算周期           | 选择任一样式方案中包含的预算周期                                                                           |
| 预算年度           | 选择需要查询的年度                                                                                  |
| 预算期间           | 选择需要查询的期间                                                                                  |
| 预算币别           | 选择需要查询的币别                                                                                  |
| 项目数据类型         | 选择需要查询的预算业务类型（项目数据类型）                                                                      |
| 预算维度过滤         | 选择需要查询的具体预算维度，不设置时，系统默认查询样式方案对应所有维度                                                        |
| 预算维度过滤         | 选择需要查询的具体预算维度，不设置时，系统默认查询样式方案对应所有维度。                                                       |
| 选项：显示综合本位币     | 选中时，显示本位币预算列                                                                               |
| 选项：以××作为预算本位币  | 在选中显示综合本位币选项的前提下，允许设置以任意币别作为预算本位币。\\ 系统自动将满足条件的预算数，从【预算币别】换算为目标本位币。\\ 换算汇率来源于预算方案.预算汇率类型。  |
| 选项：包含未审核报表     | 选中时，包含未审核的预算报表。                                                                            |



**报表查询**
^ 字段            |^ 说明                                                                                                                                                  ^
| 组织类型          || 当前预算组织的组织类型：组织/部门                                                                                                                                   |
| 预算周期          || 预算周期                                                                                                                                                |
| 预算年度          || 预算年度                                                                                                                                                |
| 预算业务类型        || 预算业务类型                                                                                                                                              |
| 项目数据类型        || 项目数据类型                                                                                                                                              |
| 预算维度          || 维度值组合\\ 显示具体维度以及维度值\\ 维度值属性的显示：在模板样式方案中，设置维度显示属性设置。在报表中的维度值，除了显示值名称，还会显示维度的具体属性。\\ 如：在模板样式方案中，对产品维度设置显示属性：编码/规格型号。则在分析表中，产品维度显示为：智能手机/PH011005/M60  |
| 原币      | 原始数  | 原币预算数\\ 不显示调整数时，该列为原始预算数与预算调整数的汇总数。\\ 显示调整数时，该列仅为原始预算数。                                                                                             |
| :::     | 调整数  | 原币预算调整数                                                                                                                                             |
| 本位币     | 原始数  | 本位币预算数\\ 不显示调整数时，该列为原始预算数与预算调整数的汇总数。\\ 显示调整数时，该列仅为原始预算数。                                                                                            |
| :::     | 调整数  | 本位币预算调整数                                                                                                                                            |
