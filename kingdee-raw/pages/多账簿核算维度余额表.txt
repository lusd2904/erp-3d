====== 1、报表功能 ======

多账簿核算维度余额表用于帮助用户进行核算维度余额的分析，主要展示核算维度的期初余额、本期发生、本年累计发生以及期初余额数据。

多账簿核算维度余额表既支持在集团层面查看多账簿的数据，也可以查看单账簿的数据。

====== 2、过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置会计年度期间以及核算维度范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。
^ 过滤项               |^ 说明                                                                 ^
| 账簿隶属关系            || 设置账簿隶属关系。                                                          |
| 合并层级              || 设置账簿隶属关系的节点，可以选择到最明细账簿；账表根据该项展示相应层级的数据。                            |
| 科目                || 选择要查看的科目。                                                          |
| 核算维度              || 设置查询的核算维度。如果指定了科目，则只能选择科目关联的核算维度；反之，可以选择具有查询权限的所有核算维度查询。           |
| 核算维度次级         || 核算维度所关联的基础资料存在分组时，支持按次级查看。\\ 核算维度次级为0时只显示最明细的核算维度的数据，次级为1时显示1级核算维度的汇总数据，依次类推。  |
| 核算维度编码            || 设置查询的核算维度范围。                                                       |
| 显示禁用科目            || 选中此项，可查询已禁用会计科目的相关核算维度余额数据。                                        |
| 包括未过账凭证           || 选中此项，查询结果包含未过账凭证的金额数据。                                             |
| 显示禁用核算维度          || 选中此项，核算维度查询范围能显示已禁用维度；反之，则不能显示已禁用维度。                               |
| 余额为零不显示           || 选中此项，余额为零的核算维度不显示。                                                 |
| 显示发生额为零的记录        || 选中此项，查询结果显示发生额为零的核算维度。                                             |
| 余额方向与科目余额方向一致     || 选中此项，余额的显示方向与科目设置的余额方向相同，可能出现余额为负数的情况。否则，当余额为负数时，在科目余额的相反方向以正数显示。  |
| 非明细级核算维度的余额合并在一个方向	     || 选中此项，按核算维度级次查询时非明细核算维度分组的余额根据其下级维度及分组的余额汇总后，如果既有借方余额又有贷方余额，需要以借贷方的差额列示。没有选中时，非明细核算维度分组的期初余额和期末余额根据其下级维度及分组的借、贷余额分别汇总求得。|

====== 3.操作说明 ======

  * 系统支持核算维度余额表联查核算维度明细账，用户选择需要联查的记录，点击工具栏的查看明细账按钮联查核算维度明细账信息。

  * 全部展开\全部收起：一键展开或收起所有节点，节点数较多时比较耗时，需慎用。
