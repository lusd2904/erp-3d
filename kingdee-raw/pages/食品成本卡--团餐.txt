====== 1.食品成本卡--团餐 ======
===== 1.1 功能概述 =====

记录每份食品的重量，计算每份食品的成本价，并进而计算过每份食品的毛利率情况。应用于食堂网点报餐单，获取食品的成本，售价，毛利率

{{::团餐管理3.png?400|}}
===== 1.2 字段说明 =====

^ 字段名称  ^ 字段说明                               ^
| 标准分量  | 设置团餐中该食品每份的重量                      |
| 份量单位  | 设置该份量的单位                           |
| 成本    | 显示该标准份量食品的成本，不支持编辑，只能通过计算后反写       |
| 售价    | 设置该标准份量食品的售价                       |
| 毛利率   | 成本/售价                              |
| 占比    | 设置该成本卡下每个物料占整体食品的比例，所有食品的占比和为100%  |
| 参与计算  | 如果勾选参与计算则才会用于成本卡的计算                |
| 成本单价  | 成本单价取的采购价目下，该物料设置的价格               |
| 成本金额  | 成本金额 = 成本单价 * 净料数量                 |
