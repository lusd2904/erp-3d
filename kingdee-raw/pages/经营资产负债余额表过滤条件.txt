====== 经营资产负债余额表过滤条件 ======
在“快捷”页签，用户选择需要查询的经营账簿、利润中心、经营单元、经营科目、开始期间、结束期间、起始业务日期。其他过滤页签为系统通用设置，可设置字段列的显示隐藏属性。

快捷页签主要过滤项目说明 

| **过滤项**       || **说明**                                          |
| 经营账簿          || 选择查询哪个经营账簿，单选。                                  |
| 利润中心          || 选择查询哪个利润中心，单选。                                  |
| 经营单元         || 选择查询哪个经营单元，多选。                                 |
| 经营科目          || 选择需要查询的资产负债类经营科目，多选。                            |
| 开始期间          || 选择要查询数据的起始期间。                                   |
| 结束期间          || 选择要查询数据的结束期间。                                   |
| 业务日期          || 选择要查询数据的起始日期。                                   |
| 至             || 选择要查询数据的结束日期。                                   |
| 显示经营科目        || 勾选此项，报表将按经营科目展示，并且可选择展示经营科目的级次。                 |
| 经营科目级次        || 可选1、2，选择1则只显示一级经营科目，选择2则显示一级和二级经营科目，为空则显示全部级次。  |
| 包含内部分摊的费用     || 勾选此项，报表展示的数据将包含交易类型为内部分摊的流水账。反之，不勾选则不包含。        |
| 按利润中心合并       || 勾选此项，报表将按利润中心汇总显示数据。                            |
