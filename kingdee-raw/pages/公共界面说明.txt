====== 3. 公共界面说明 ======

===== 3.1 过滤界面概述 =====

金蝶AI星空食神餐饮中央配送系统中所有单据列表的过滤界面都大同小异，因此本章着重讲解过滤界面的公共部分，后期如果个别表有差异的话，在相应表的介绍时会详细说明，过滤界面通常用于列表中，用户可以根据自己的需要对单据列表的数据进行筛选，符合条件的数据将会显示，这样有利于用户查看数据。本章节以食品成本卡列表的过滤界面为例进行讲解，大家在后面单据列表使用过滤功能时可以参考本章进行学习和查看。
==== 3.1.1 功能概述 ====

过滤界面主要包括方案的创建，条件过滤设置，高级过滤设置，排序设置，显示隐藏列五个部分。下面会对每个部分进行详细得讲解。


**一、方案的创建界面**


方案的创建界面在整个过滤界面的左边，通常每一个过滤界面都会有一个缺省方案，该方案是系统默认的，用户也可以自己设置方案，点击另存或者复制按钮即可设置自己想要的方案。在另存方案界面，用户需要设置方案名称以及共享设置，如果设置了共享所有用户，那么设置的方案其他用户登录系统的时候也能看到，如果另存的方案不设置共享，那么该方案只有当前用户可见。
在方案创建界面的最下方，有一个下次以此方案自动进入的选择框，默认不勾选，如果用户勾选的话，下次打开单据列表时会自动根据设置的方案查询数据而不会显示过滤界面。


 
**二、条件过滤设置界面**


条件过滤设置界面用户可以设置过滤的组织，默认会当前组织。在条件过滤中中间有个新增行，删除行等按钮，用户可以根据自己的需要选择某个字段过滤，里面有版本号，创建组织，使用组织，创建人，修改人，创建日期等列表中所有的字段。
条件过滤设置界面有数据状态和禁用状态设置，数据状态包括全部，暂存，创建，审核中，已审核，重新审核六中状态，用户可以设置不同的数据状态过滤符合条件的数据；禁用状态包括全部，是，否三种。
   

 
** 三、高级设置**


高级设置界面跟条件设置过滤界面的一致，用户可以设置列表中的每个字段进行过滤想要的数据。



**四、排列设置**


过滤界面排列设置是用来设置不同单据的显示顺序的，列表中的每个字段都可以设置排序方式，升序或者降序。


 
**五、显示隐藏列**


由于列表中字段比较多，所以不能所有的字段都显示出来，客户可以设置自己想要显示的字段以便更直观的查看数据。


 


==== 3.1.2 关键字段说明 ====

^ 字段名称        ^ 说明                      ^
| 保存          | 方案修改后保存                 |
| 另存          | 重新生成一个新的方案              |
| 复制          | 复制一个已有的方案进行修改           |
| 重置          | 把方案的设置恢复到默认状态           |
| 下次以此方案自动进入  | 勾选后打开列表会自动按照方案的信息过滤出数据  |


===== 3.2 单据及列表的公共字段说明 =====

==== 3.2.1 功能概述 ====

单据列表的公共字段说明是把本章中后面的所有单据列表的公共按钮进行说明，本文后面涉及到的列表只描述特有的字段，不会对公共的字段进行重复讲解。

==== 3.2.2 关键字段说明 ====

| 字段名称        | 说明                          |
| 过滤          | 具体功能详见3.1中的过滤界面概述           |
| 刷新          | 页面会更新                       |
| 新增          | 新增一个资料                      |
| 删除          | 删除选择的资料                     |
| 提交          | 对创建状态的资料提交                  |
| 审核          | 对审核中状态的资料审核                 |
| 禁用          | 禁用选中的资料，禁用后无法使用             |
| 反禁用         | 对禁用的资料实行反禁用，反禁用后可以使用        |
| 分配          | 总部创建资料分配到各个门店               |
| 自动分配方案      | 设置分配方案，创建资料后会自动分配           |
| 取消分配        | 对分配的资料进行取消（门店对应的资料不是已审核状态）  |
| 分配查询        | 对已经分配的门店进行查询                |
| 未分配查询       | 可以查询到该资料哪些门店没有分配            |
| 设为默认版本      | 把资料设置为默认的版本                 |
| 打印          | 跟打印机关联后可以打印相关信息             |
| 预览          | 查看打印之前的数据显示是否正确             |
| 引入          | 引入EXCEL表的资料信息               |
| 引入模板设置      | 设置要引入的模板                    |
| 引出格式设置      | 对于引出的格式进行设置                 |
| 按列表引出数据     | 按照列表的字段引出下载资料数据。            |
| 按引出模板引出数据   | 引出的数据是按照引出模板的格式             |
| 按引入模板引出数据   | 引出的数据是按照引入模板的格式             |
| 库存查询        | 查看当前组织中选中物料的库存信息            |
| 批号主档        | 查看启用批号管理的物料的所有批号信息          |
| 批量填充        | 输入某一行点击该按钮会复制该值到后面的输入行中     |
| 获取批号        | 获取当前物料的批号信息                 |
| 整单关闭/整单反关闭  | 点击整单关闭则该单据无效，点击反关闭则恢复使用状态   |
| 财务收单/财务反收单  | 点击财务收单则表示该单据纳入财务核算中，反之亦然。   |
