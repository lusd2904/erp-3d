======1 安全库存设置======
=====1.1 功能概述=====
安全库存是为防止未来物资供应或需求的不确定性因素（如大量突发性订货、交货意外中断或突然延期等）而准备的缓冲库存。

通过安全库存设置，可以快速批量维护物料的安全库存。

=====1.2 功能路径=====

进入【生产制造】—>【计划管理】—>【参数设置】—>【安全库存设置】

======2. 字段说明======
|  **字段**  |  **说明**      |
|  创建组织    | 显示物料的创建组织    |
|  使用组织    | 显示物料的使用组织    |
|  物料编码    | 显示物料的物料编码    |
|  物料名称    | 显示物料的物料名称    |
|  BOM版本   | 显示物料的BOM版本   |
|  计划跟踪号   | 显示物料的计划跟踪号   |
|  辅助属性    | 显示物料的辅助属性    |
|  计量单位    | 显示物料的基本单位    |
|  安全库存量   | 维护物料的安全库存量   |
|  再订货点    | 维护物料的再订货点    |
|  经济订货批量  | 维护物料的经济订货批量  |
|  最大库存    | 维护物料的最大库存    |

======3. 操作说明======
**批改**

点击“批改”可以对选中的物料的安全库存等数量进行批量修改。

**引出/引入**

通过引出修改再覆盖引入可以实现安全库存的批量设置。
