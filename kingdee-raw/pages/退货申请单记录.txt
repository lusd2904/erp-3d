ID: 退货申请单记录
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%80%80%E8%B4%A7%E7%94%B3%E8%AF%B7%E5%8D%95%E8%AE%B0%E5%BD%95

**功能说明：**

用户退货申请的处理情况查询以及历史退货记录查询；

**功能路径：**

【退货】->【退货申请记录】

**使用前提：**

无

**字段说明：**

| **名称**  | **字段说明**             |
| 表头                            ||
| 单据编号    | 退货申请单单据编码，系统自动生成     |
| 退货日期    | 创建退货申请单的日期           |
| 单据状态    | 显示当前退货申请单的单据状态       |
| 签收状态    | 显示当前退货申请单的签收状态       |
| 表明细                           ||
| 商品编码    | 显示商品编码+商品名称+商品规格型号   |
| 订单数量    | 退货申请单对应的订单的商品订货数量    |
| 申请退货数量  | 退货单申请退货数量            |
| 累计退货数量  | 已经处理退货出库的数量          |
| 来源订单号   | 退货申请单上游单据编码，一般是订单编号  |

**操作说明：**

1、对应不同的退货申请记录，选择不同的过滤页签
  * 待审核：过滤处理需要审核的退货申请单，只支持撤单处理；
  * 待发货：过滤处理已审核待发货的退货申请单，只支持退货出库处理；
  * 待签收：过滤查看已发货待签收的退货申请单，只允许查询不允许任何操作；
  * 已关闭：过滤查看已手工关闭的退货申请单，不允许任何操作；
  * 所有退货申请单：包含了全部当前登录渠道申请的退货单，对于不同间接状态的退货申请单允许做不同的操作。
2、操作处理，用户可以对退货申请单进行删除、撤单、导出、查询、发货处理
  * 删除：退货申请单的单据状态为保存、打回或手工关闭时才可以删除，其他的状态不允许删除。
  * 撤单：退货申请单.的单据状态为已提交或已确认时，才可以撤单处理，其他的状态不允许撤单。
  * 退货：退货申请单的单据状态为审核时，显示退货，点击退货按钮进入渠道入库单退货流程。
  * 导出：导出EXCEL。
  * 关键字查询，在输入框中输入“牛奶”，则表示查询商品包括牛奶 或者 商品编号包括牛奶 或者 订单编号包括牛奶的订单，查询范围是所有退货申请单。
  * 时间段查询，提供当天、一周以内、一月以内、三个月以内、指定时间范围的查询，查询范围是对当前选定的页签。比如当前是在待签收页签，如果选择当天，则表示当天待签收的退货申请单。
