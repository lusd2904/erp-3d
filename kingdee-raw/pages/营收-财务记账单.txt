======1.功能概述======
营收-财务记账单统计分析组织的食品销售情况、部门营收情况和计税情况等
======2.使用前提======
存在实际发生的业务数据，并通过门店数据交换上传账单数据
======3.功能路径======
【餐饮门店管理】→【门店营业分析】→【财务集成】→【营收-财务记账单】
======4.报表过滤条件======
过滤条件区域包括页签：高级、条件、显示隐藏列、排序

  * 高级页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 排序页签：报表显示字段排序

======5.报表字段说明======
^ 字段       ^ 说明       ^
| 营业组织     | 具体营业门店   |
| 账单价税合计   | 账单计税之和   |
| 服务费价税合计  | 服务费计税之和  |
| 账单税额     | 账单计税金额   |
| 服务费税额    | 服务费计税金额  |
| 食品编码     | 食品编码     |
| 食品名称     | 食品名称     |
| 食品类别     | 食品类别     |
| 部门       | 部门       |
| 销售数量     | 销售数量之和   |
| 价税合计     | 价税合计之和   |
| 不含税金额    | 不计税金额    |
| 税额       | 计税金额之和   |
======6.报表操作说明======

1、报表提供冻结列设置、打印、引出功能。

2、报表提供按表头的【组织】、【营业日期】汇总合计营收记账单

3、报表提供过滤->分组汇总，在报表中对分组字段进行小计且对【数量】、【金额】、【进位差】进行合计，其中分组字段包括：组织、营业日期、星期、时段、楼层名称、房台名称、收银员名称等

4、可以通过勾选【选项】中的参数，不显示分录行的合计、小计 。
