====== 1.报表功能 ======

系统提供多账簿明细分类账查询功能用于按账簿隶属关系或账簿查询各科目的明细分类账账务数据，可以按照各种币别或者某一币别查询明细账；也可以按所有币别多栏式查询明细账；还提供了按非明细科目输出明细分类账的功能；同时，用户还可以查询核算维度的科目明细账。

====== 2.过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿隶属关系或账簿，设置会计年度期间以及科目范围等基本过滤条件。“更多选项”页签包含一些非常用选项。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。

^ 过滤项                 |^ 说明                                                                              ^
| 账簿隶属关系              || 设置账簿隶属关系                                                                        |
| 合并层级                || 设置账簿隶属关系的节点，可以选择到最明细账簿，账表根据该项展示相应层级的数据。                                         |
| 按科目分页显示             || 选中此项，账表按科目分页显示；反之，则不分页，所有科目数据在一页显示。                                             |
| 显示对方科目              || 选中此项，显示科目的对方科目。                                                                 |
| 只显示明细科目             || 选中此项，报表取数时，只显示账簿中的明细科目数据；反之，则按科目级别分别显示。                                         |
| 无发生额不显示             || 选中此项，查询结果中无发生额的科目，系统不予显示。                                                       |
| 余额为零且无发生额不显示        || 选中此项，查询结果中余额为零且没有发生额的科目，系统不予显示。                                                 |
| 显示核算维度明细            || 选中此项，核算维度的相关选项才可用。查询结果显示科目的核算维度信息。                                              |
| 核算维度                || 设置查询的某个核算维度或者所有核算维度。选择“所有类别多核算”时，系统查询时不限制科目的核算维度范围，取所有核算维度。                     |
| 核算维度编码              || 设置查询某个核算维度的编码范围。                                                                |
| 仅显示核算维度明细           || 当勾选“显示核算维度明细”和“只显示明细科目”时，该选项才有效。选中此项，当科目挂核算维度时，查询结果只显示该科目最明细核算维度的数据信息。          |
| 连续核算维度范围查询          || 默认选项，选中此项，则选择起始核算维度后，账表按所选核算维度编码范围内的所有核算维度查询。                                   |
| 非连续核算维度范围查询         || 选中此项，账表按所勾选的核算维度查询。                                                             |
| 使用核算维度组合查询          || 选中此项，核算维度查询界面为核算维度组合选择界面，用户设置多个核算维度查询；反之，核算维度查询界面只能选择某个核算维度查询。                  |
| 核算维度组合              || 选中“使用核算维度组合查询”，用户可设置多个核算维度组合成新的核算维度进行查询。                                        |
| 从未使用不显示             || 选中此项，科目启用后但无业务发生则不显示。                                                           |
| 按明细科目列表显示           || 选中此项，当前级别的科目及其下属科目以列表形式显示；反之，科目分页仅显示当前级别的科目数据。需要注意的是，该选项与“只显示明细科目”互斥，二者只能勾选其一。  |
| 显示期间合计              || 选中此项，查询结果显示整个查询期间的合计数。                                                          |
| 显示无发生额的期间合计         || 选中此项，查询结果显示所有期间的合计，包括无业务发生的期间。                                                  |
| 不显示凭证信息（总分类账样式）     || 选中此项，查询结果只显示合计信息不显示凭证信息。                                                        |
| 自动继承上条分录的摘要         || 选中此项，当凭证分录行的摘要为空时自动显示上条非空摘要；反之，自动显示凭证第一行的摘要。                                    |
| 余额方向与科目余额方向一致       || 选中此项，余额的显示方向与科目设置的余额方向相同，可能出现余额为负数的情况。否则，当余额为负数时，在科目余额的相反方向以正数显示。               |

====== 3.操作说明 ======

  * 系统支持财务账证表一体化查询，用户可以通过查看凭证菜单查看明细分类账记录对应的凭证。
  * 明细分类账支持跳转功能，点击“跳转”按钮调用分页账表目录，用户通过双击任意行来实现快速跳转到指定分页。



====== 4.业务说明 ======

系统在显示科目的对方科目信息时，对于非一借一贷凭证，如果凭证分录中存在红字负数金额，系统在判断对方科目前，先将红字负数金额转换为相反方向的正数金额。对于多借多贷的凭证，系统根据科目的金额优先匹配原则确认对方科目。
