====== 1.功能说明 ======

使用基础平台参数配置，配置全员用户使用的参数，使得系统的操作与体验更符合全员用户的操作习惯，提高操作效率。


**功能路径**

基础平台参数配置路径：【参数设置】→【基础管理】→【基础平台】→【基础参数】


====== 2.参数说明 ======

^ 参数名称                     ^ 参数说明                                                                                                          ^
| 不启用表格边框线                 | 用户打开的列表、报表、单据体等表格会显示边框线，如启用，则所有用户生效；如不启用，则以用户在本地配置的设置为准                                                       |
| 客户端启用旧版首页                | 默认新用户是新版首页，如勾选启用，所有用户都会切换到旧版首页。                                                                               |
| 取消客户端链式请求                | 默认启用客户端链式请求，如若个别情况需要关闭链式请求，可勾选该选项。                                                                            |
| 启用页面水印                   | 如需定义页面水印，可勾选该参数，进行个性化的定制，并设置透明度。                                                                              |
| Html5字段布局默认为固定块（重新登录生效）  | 可按照客户定制的字段布局排版，启用后所有单据在默认情况下都会按照字段本身所调整的固定坐标位置显示出来，具体体验可参考https://vip.kingdee.com/article/244507315830149632  |
| 切换到旧版工作台                 | 工作台有更新，如果用户想要用回旧版可勾选该参数。                                                                                      |
| 隐藏客户端新版首页编辑              | 新版主页支持用户编辑，如果不希望用户个性化编辑，可勾选该参数。                                                                               |
| 关闭个性化推荐                  | 若您不想接受个性化推荐服务，可勾选该参数，关闭后，本产品将不再向您展示个性化推荐内容（包括个性化广告推荐内容），您看到的推荐内容将与您的偏好相关度降低。                                  |
| 查看禁用组织数据                 | 勾选参数后，业务单据允许查询已禁用组织列表数据。                                                                                      |
| 禁用表格整行复制                 | 勾选参数后，用户在本地配置中不显示“启用整行复制”选项，其功能也不生效。                                                                          |
| 禁用块选择                    | 勾选参数后，所有表格右键将禁用块选择功能。                                                                                         |
| 启用跨站请求伪造（CSRF）校验         | 勾选参数后，动态表单请求发送的CSRF-Token参数将生效，用于对数据进行跨站请求伪造校验。                                                               |
| 仅允许Administrator用户登录     | 启用参数后，其他用户将暂时无法登录系统使用。一般用于管理员运维系统或实施重大的功能等（比如：启用加密），避免其他用户使用系统产生错误数据。                                         |
| Html5表格的列宽布局关闭自动充满       | 勾选后，调整表格的总列宽小于页面宽度后，再次打开表格，不再自动充满页面，若用户调整了列宽，则以用户调整为准。                                                        |
| 启用上传图片压缩                 | 勾选参数后，上传图片后会影响图片的清晰度。                                                                                         |
| 禁止拖拽隐藏的单据体字段自动保存         | 勾选参数后，单据体中拖拽掉字段，在关闭单据将不会自动保存，再次打开，拖拽掉的字段会显示出在原来的位置上。                                                          |
| 启用菜单栏字体大号模式              | 勾选参数后，列表和单据体的功能菜单字体会显示成大字号，并有加粗的效果。                                                                           |
| 停用所有流式布局                 | 勾选参数后，将停用所有的流式布局设置，单据打开的显示效果将和客户端基本一致。                                                                        |
| 功能菜单显示宽度                 | 可设置175到500，值越大，那么功能菜单的支持显示的字数就越多，比如设置200，可支持菜单显示的名称有12个中文汉字，更多的话会显示...                                        |
| 主控台菜单显示模式                | 修改后，仅对新用户或未切换显示模式的用户才会按照这里设置的参数显示菜单。                                                                          |
| 启用协同云（重新登录后生效）           | 勾选参数后，完成协同云集成配置，即可体验协同云功能，包括协同门户、协同云消息、智能协同云应用。                                                               |
| 分配操作的分配数据提交失败，不产生分配记录    | 勾选参数后，在基础资料分配过程中，基础资料分配到指定组织生成的分配记录，提交或审核失败后，不会保留使用组织的分配记录。                                                   |
