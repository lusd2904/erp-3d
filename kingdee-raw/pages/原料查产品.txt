======1 原料查产品=======
=====1.1 报表功能=====

物料清单反查指从BOM的底层物料向上查看产品结构，查看一个物料都用到哪些产品上，把产品结构的最底层与最终产品连接起来。

  * 反查1层是指自底向上扫描一级产品结构，列出使用一个零件的每个父项，常用于确定一个组件的变化时，哪些物料受到影响。计划人员可以用单级上查来识别由于组件推迟交货或损坏而受影响的装配件。 
  * 多级反查是指自底向上扫描所有级次的产品结构，提供了解父项及其所需组件这种复杂网络关系的一种简单方法，列出使用一个零件的每个父项以及父项的父项直至最终产品，常用于确定一个组件的变化时，哪些物料或产品受到影响。 

=====1.2 使用前提=====
定义【产品BOM】


=====1.3 功能路径=====
进入【食品加工管理】—>【产品数据管理】—>【产品bom查询】—>【原料查产品】

======2. 字段说明======

=====2.1 BOM展开选项 =====
^  **字段**  ^  **说明**                                      ^
|  使用组织    | 指定查询物料清单的使用组织。                               |
|  物料编码    | 指定查询的物料编码。                                   |
| BOM版本    | 指定查询的BOM版本。                                  |
|  展开层级    | 设定BOM向下展开层级，默认值为1；\\ 展开层级为空时，BOM多级展开。        |
|  需求日期    | 设定BOM子项的适用范围，默认为当前日期；\\ 为空时不按生/失效日期对子项进行过滤;  |
|  需求数量    | 计算子项用量时的父项数量，默认为1。                           |

=====2.2 父项页签 =====
|  **字段**  |  **说明**                                                                                                    |
|  BOM层级   | 子项物料在所属的BOM下的层级;支持树形展开及收缩。                                                                                 |
|  物料编码    | BOM的【父项物料编码】。                                                                                              |
|  物料名称    | BOM的【物料名称】。                                                                                                |
|  规格型号    | BOM的【规格型号】。                                                                                                |
|  BOM版本   | BOM的【BOM编号】。                                                                                               |
|  父项单位    | BOM的【父项物料单位】。                                                                                              |
|  子项类型    | BOM中的该子项的【子项类型】。                                                                                           |
|  用量类型    | BOM中的该子项的【用量类型】。                                                                                           |
|  子项单位    | BOM中的该子项的【子项单位】。                                                                                           |
|  用量:分子   | BOM中的该子项的【用量:分子】。                                                                                          |
|  用量:分母   | BOM中的该子项的【用量:分母】。                                                                                          |
|  用量      | 【用量类型】为“变动“时，用量=上层子项物料的【用量】*【用量:分子】/【用量:分母】；\\ 【用量类型】为“阶梯”时，【用量】按阶梯用量取值；\\ 【用量类型】为“固定”时，=【用量:分子】/【用量:分母】。  |

=====2.3 替代物料—主物料 页签 =====
^  **字段**  ^  **说明**                                                                                                                               ^
|  项次      | 主物料在BOM中的项次。                                                                                                                          |
|  优先级     | 主物料的优先等级。                                                                                                                             |
|  替代策略    | 物料替代的控制策略，包含：混用替代、手工替代、整批替代。\\ 混用替代：主物料和替代物料同时作为供给和预计量；\\ 供给比例由库存和预计量决定；\\ 手工替代：按照用户指定的供给比例，产生需求量；\\ 整批替代：满足同一笔需求时，要么使用主物料，要么使用替代物料。  |
|  替代方式    | 物料替代的控制策略，包含：替代和取代；\\ 替代：需求无法满足时，产生主物料的供给；\\ 取代：需求无法满足时，产生替代物料的供给                                                                     |
|  优先级     | 被替代物料的优先等级 MRP计算时，物料计算的优先等级；数值越小，优先级越高。                                                                                               |
|  物料编码    | 被替代物料的编码被替代物料的物料属性只能为自制类、外购类或委外类物料。                                                                                                   |
|  物料名称    | 被替代物料的名称。                                                                                                                             |
|  规格型号    | 被替代物料的规格型号。                                                                                                                           |
|  物料属性    | 被替代物料的物料属性。                                                                                                                           |
|  辅助属性    | 启用辅助属性管理的物料，可设置辅助属性。　                                                                                                                 |
|  BOM版本   | 被替代物料的BOM版本。                                                                                                                          |
|  单位      | 被替代物料的单位。                                                                                                                             |
|  分子      | 被替代物料的分子。                                                                                                                             |
|  分母      | 被替代物料的分母。                                                                                                                             |
|  替代主料    | 替代主料的作用：在MPS/MRP计算时，按照替代主料的供给来判定是否产生替代。主物料有且只能有一个替代主料。                                                                                |

=====2.4 替代物料—替代物料=====
^  **字段**  ^  **说明**                                  ^
|  优先级     | 替代物料的优先等级 MRP计算时，物料计算的优先等级；数值越小，优先级越高。   |
|  替代物料编码  | 替代物料的编码替代物料的物料属性只能为自制类、外购类或委外类物料。        |
|  物料名称    | 替代物料的名称。                                 |
|  规格型号    | 替代物料的规格型号。                               |
|  物料属性    | 替代物料的物料属性。                               |
|  辅助属性    | 启用辅助属性管理的物料，可设置辅助属性。　                    |
|  单位      | 替代物料的单位。                                 |
|  分子      | 替代物料的分子。                                 |
|  分母      | 替代物料的分母。                                 |
|  生效日期    | 物料替代生效日期；同一组替代物料的生效日期相同；生效日期只能小于等于失效日期。  |
|  失效日期    | 物料替代失效日期；同一组替代物料的失效日期相同；失效日期只能大于等于生效日期。  |
