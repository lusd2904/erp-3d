**采购费用分配**

采购费用分配是指将物料采购所发生的费用，如运费、关税等计入采购入库的存货成本。存货核算系统是指将采购费用应付单的金额分配到入库单（退料单）上。

**使用前提**

入库单（退料单）必须已与标准应付单钩稽。

**功能路径**

【成本管理】－>【存货核算】－>【存货核算】－>【采购费用分配】

**字段说明**

| **表头字段**  | **说     明**                                                                               |
| 清空        | 清空当前已过滤出的钩稽双方的单据                                                                          |
| 应付单       | 弹出应付单查询窗口，设置条件过滤出本次需要分配的采购费用应付单（分录行必须已勾选“计入成本”）。屏蔽分配状态为已分配的采购费用应付单。                       |
| 库存单据      | 弹出库存单据查询窗口，设置条件过滤出本次需要分配的目标入库单及退料单。                                                       |
| 分配        | 选择好需要参与费用分配的目标单据后，点击该按钮进行采购费用分配处理                                                         |
| 查看单据      | 下拉选择项：应付单、库存单据、钩稽日志。                                                                      |
|           | 1、选择应付单，可以联查调出应付单；                                                                        |
|           | 2、选择库存单据，可以联查调出入库单、退料单；                                                                   |
|           | 3、选择钩稽日志，该功能和“钩稽日志查询”调出的界面一样，弹出钩稽日志供过滤分配记录。                                               |
| 分配类型      | 包括标准采购费用分配及标准委外费用分配。标准采购费用分配处理采购费用分配给普通采购业务的入库单（退料单）；标准委外采购费用分配处理采购费用分配给委外加工业务的入库单（退料单）。  |
| 分配标准      | 1、数量：取参与分配库存单据分录行的实收数量（库存单位数量），分配权重=分录行实收数量/∑各分录行实收数量                                     |
|           | 2、金额：取参与分配库存单据分录行的总成本，分配权重=分录行金额/∑各分录行总成本                                                 |
|           | 3、毛重：取参与分配物料基本信息中的毛重作为分配权重，分配权重=毛重*分录行数量。如果毛重单位非基准单位将会换算成基准单位重量                           |
|           | 4、净重：取参与分配物料基本信息中的净重作为分配权重，分配权重=净重*分录行数量。如果净重单位非基准单位将会换算成基准单位重量                           |
|           | 5、体积：取参与分配物料基本信息中的体积作为分配权重，分配权重=体积*分录行数量。如果体积单位非基准单位将会换算成基准单位体积                           |
|           | 6、自定义分配权重：手工输入各分录行的分配权重，为大于0的数值。                                                          |

**操作说明**

进入采购费用分配，先选择分配类型及分配标准，再选择需分配的采购费用应付单及分配对象入库单（退料单），点击“分配”，将应付单上的金额按费用项目分配到入库单（退料单）成本中。若要取消分配，在钩稽日志查询中选中分录行点“反勾稽”取消分配结果。

**业务说明**

  *   支持应付单与入库单（退料单）一对一，一对多，多对一，多对多的分配方式；
  *   支持库存单据整单选择。
