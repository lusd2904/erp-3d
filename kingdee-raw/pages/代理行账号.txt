=====代理行账号=====
=====1 功能说明=====    
想在系统内进行境外支付业务，通过代理行完成，则需要先维护基础资料——代理行账号。如不涉及境外支付，则无需维护。

付款单、收款退款单、付款结算单勾选境外支付，勾选代理行完成时，需在单据上选择填写。提交银行时会传给银企
=====2 功能路径====

【财务会计】—>【网上银行】—>【系统设置】—>【代理行账号】

=====3 字段说明====

| **字段**         || **说明**                                                       |
| 编码          || 基础资料编码                     |
| 代理行名称         || 代理行名称                                        |
| 代理行账号         || 代理行账号                                        |
| SWIFT Code         || 代理行Swift Code                                            |
| 国家/地区       || 代理行所在国家或地区                                            |
| 代理行地址         || 代理行地址                                           |
| 描述         || 文本，自定义录入                                           |
