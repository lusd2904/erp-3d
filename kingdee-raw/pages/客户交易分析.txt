====== 客户交易分析 ======

===== 1 功能描述 ===== 

反映一定时间内客户交易次数、交易总金额、最近一次交易时间间隔等情况


**使用前提**

  * 有相应的销售业务单据数据


===== 2 字段说明 =====

**过滤界面字段**

| **字段名称**     || **说明**                        |
| 业务组织         || 为具备销售职能的组织，允许多选。              |
| 日期           || 默认系统当前日期；用户可设置和选择其他日期。        |
| 统计来源         || 包含销售订单、销售出库单、应收单              |
| 来源状态         || 包括全部、已审核、未审核；意味着统计来源单据是哪个状态。  |
| 显示0交易客户      || 勾选该选项，显示过滤时间范围内未发生交易的客户       |




**报表展示字段**


| **字段名称**     || **说明**                 |
| 币别           || 取当前销售组织的本位币币别          |
| 购买次数         || 按交易单据数取数，一张单据算一次       |
| 购买总金额        || 取统计单据价税合计本位币合计         |
| 平均购买金额       || 平均购买金额=购买总金额/购买次数      |
| 最近一次购买日期     || 取统计单据离系统日期最近一张单据的单据日期  |
| 时间间距         || 最近一次交易单据日期与系统日期的时间间隔   |


===== 3 报表操作说明 =====
  * 报表提供冻结列设置、打印、引出功能。
  * 按单个组织统计的时候，如果销售组织对应核算体系没有本位币，统计数据就不出来。
