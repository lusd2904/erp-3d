======1 供应商产线日产量 ======

=====1.1 功能概述 =====
供应商产线日产量用于定义委外供应商产线的产能，维护产线人/机数量、计划工时、所能生产的产品及每种产品的单件工时及日产量。
后续排产过程中因标准产能不足需要临时调整产线的资源数或计划工时，记录产能变动过程。

=====1.2 功能路径 =====

【生产制造】－>【日排产】－>【委外排产】－>【供应商产线日产量】。

====== 2 字段说明 ======
===== 2.1 表头常规信息===== 
^  **字段**  ^  **说明**                            ^
| 创建组织     | 创建产线日产量的组织，具有生产职能的组织才可以创建产线日产量。  |
| 使用组织   | 指使用产线日产量的业务组织，具有生产职能的组织才可以使用产线日产量。     |
| 产线编码   | 产线的编码     |
| 产线名称   | 产线的名称     |
| 供应商  | 产线所在的委外供应商     |
| 人/机数量  | 产线标准的资源数，可是操作员工，也可以是机台。     |
| 计划工时（时）  | 产线标准的每日工作时长，以小时为单位。     |

===== 2.2 表体基本信息===== 
^  **字段**   ^  **说明**                                                                                                                                                      ^
|  序号       |表体分录自然序号                                                                                                                       |
|  物料编码   | 排产的产品物料的编码。                                                                                                                                |
|  物料名称     | 物料的名称。                                                                                                                                                     |
|  规格型号     | 物料的规格型号。                                                                                                                                              |
|  单位     | 物料的单位，默认取生产单位。   | 
|  单件工时（时）     | 加工一个单件产品的工时，以小时为单位。   | 
|  日产量     |加工一种产品的日产量，日产量=(人/机数量*计划工时)/单件工时，系统计算的日产量可以修改，修改不会反算其他几个数量。   | 
|  最小排产批量     |加工一种产品的最小的排产量，排产时按最小排产批量，最大化经济产能，且可避免排产出现过多小数尾差的情况。   | 
|  生效日期     |产线或产品如果存在生命周期管理，在生效日期范围内使用 。 | 
|  失效日期     |产线或产品如果存在生命周期管理，失效后不可使用 。 | 
|  备注     |备注信息。 | 

===== 2.3 表体产能变动记录===== 
^  **字段**   ^  **说明**                                                                                                                                                      ^
| 日期       |产能变动的日期                                                                                                                     |
| 调整人/机数量       |调整产能后的人/机数量                                                                                                                     |
| 调整工时      |调整产能后的工时                                                                                                                     |
| 调整比例     |调整产能后日产量与原日产量的比例                                                        |
