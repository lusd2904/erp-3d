====== 加工冲倒领料工作台 ======
=====1.1 功能概述 =====
在倒冲领料工作台中，可查看各加工汇报单、工序转移单、加工入库单的倒冲领料情况。

对于没有生成或者足额生成倒冲领料单的加工汇报单、工序转移单、加工入库单，可以生成或按差额补生倒冲领料单。

=====1.2 使用前提 =====
定义【物料清单】
维护【加工订单】
维护【加工汇报】/【加工入库单】



=====1.3 功能路径 =====


【餐饮配送与加工】－>【餐饮加工管理】－>【加工领料】－>【加工冲倒领料工作台】


====== 2 字段说明 ======
===== 2.1 基本信息===== 
^  **字段**      ^  **说明**                                                                                                          ^
|  加工组织        | 1.可选择已审核、未禁用且有权限的加工组织 \\ 2.删除、修改加工组织后，清空车间、产品编码、子项编码字段                                                           |
|  车间          | 选择【加工组织】下的【车间】                                                                                                   |
|  来源单据        | 选择按照【加工汇报单】、【工序汇报单】、【工序转移单】还是按照【加工入库单】查询                                                                                 |
|  倒冲标识        | 选择倒冲标识：全部、未完成、已完成、已关闭、已超量                                                                                          |
|  订单编号        | F8选择加工组织下状态为下达、开工、完工、结案的加工订单分录                                                                                   |
|  产品编码        | F8选择加工组织下已审核未禁用勾选了“可为主产品”的物料；                                                                                    |
|  单据编号        | 1.若来源单据为“加工汇报单”，选择加工组织下已审核的加工汇报单分录；\\ 2.若来源单据为“加工入库单”，选择加工组织下已审核的加工入库单分录；\\ 3.若来源单据为“工序转移单”，选择加工组织下已审核的工序转移单分录；\\ 4.若来源单据为“工序汇报单”，选择加工组织下已审核的工序汇报单分录。  |
|  子项编码        | F8选择加工组织下已审核未禁用的物料；                                                                                              |
|  单据日期        | 结束日期不为空时，须大于开始日期                                                                                                 |
|  交互倒冲        | 若倒冲方式是“交互倒冲”，可以选择“按库存数量”还是“按应倒冲数量”生成倒冲领料单；当选择按“按应倒冲数量”，支持零库存、负库存产生倒冲领料单                                          |
|  包括已结案的加工订单  | 选择是否考虑已结案的加工订单                                                                                                   |

====== 3 操作说明 ======
====生成==== 

点击【生成】按钮，生成对应的倒冲领料单。 

====倒冲关闭==== 

点击【倒冲关闭】按钮，可以手工关闭选择的加工汇报单/生成入库单/工序汇报单/工序转移单，不再生成倒冲领料。
