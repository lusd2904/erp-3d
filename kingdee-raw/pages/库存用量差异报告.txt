====== 1.库存用量差异报告 ======

===== 1.1 功能概述 =====
显示库存实际用量与理论用量的差异的报表

===== 1.2 字段说明 =====
^ 字段名称      ^ 字段说明                                                                         ^
| 期初库存      | 查询日期的起始日期前一天的库存结存数。起始日期前最近一次库存关账时的实际结存数+关账日到本次查询起始日期止的入库数—关账日到本次查询起始日期止的出库数  |
| 本期收入      | 查询日期内的入库数，不包含盘盈数量                                                            |
| 本期发出      | 查询日期内的发出数，不包含盘亏数量。盘盈：查询日期内的盘盈数量                                              |
| 盘亏        | 查询日期内的盘亏数量                                                                   |
| 理论结存      | 期初+收入—发出                                                                     |
| 实际结存      | 期初+收入-发出+盘盈—盘亏                                                               |
| 实际用量      | 期初+收入-结存                                                                     |
| 理论用量      | 查询日期范围内的食品销售清单展开的的物料数量                                                       |
| 差异        | 实际用量-理论用量                                                                    |
| 金额        | 最新入库价*数量                                                                     |
| 实际用量单据范围  | 生产领料单/简单生产领料单/其它出库单/分布式调出单/食品材料耗用单/报损出库 /盘亏单/直接调拨单                           |
| 期初单价来源    | 期初加权平均价、最新入库成本价、最新出库成本价、期末加权平均                                               |
| 收入发出单价来源  | 成本价，组织间结算价，期初单价来源                                                            |
| 存货类别      | 取物料的存货类别                                                                     |
| 盘盈单       | 实际耗用等于其他所有出库单据数量-盘盈单数量                                                       |
