====== 1功能概述 ======


供应商交货及时率查询报表主要用于查询供应商所有订单的准时交货的情况，根据交货日期和入库/收料日期之间的关系判断订单是否逾期交货，可以根据批数和数量进行查询，查询逾期交货批数/数量和交货及时率的情况。

====== 2使用前提 ======


存在实际发生的业务数据 

====== 3功能路径 ======


【供应链】－>【采购管理】－>【报表分析】－>【供应商到货及时率】

====== 4报表过滤条件 ======


过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
下面针对快捷过滤页签字段进行详细说明

  * 报表快捷过滤字段说明 

| 过滤条件     | 说明                        |
| 采购组织     | 支持多选，合法值范围：具采购职能的组织机构     |
| 起始日期     | 当前所查询数据的起始日期              |
| 供应商      | 当前查询数据的供应商范围              |
| 订单编号     | 当前查询数据的订单范围               |
| 以入库日期为准  | 以订单的交货日期和入库日期之间的关系计算      |
| 以收料日期为准  | 以订单的交货日期和收料日期之间的关系计算      |
| 按送货批数    | 按供应商下单批数统计                |
| 按送货数量    | 按供应商的下单总数量统计              |
| 允许延期天数   | 输入允许延期的天数，在计算逾期时加上允许延期天数  |

====== 5报表字段说明 ======


  * 表头字段 

|字段|说明|
|采购组织|报表数据来源的采购组织范围|
|供应商范围|报表数据的供应商范围|
|物料范围|报表数据的物料范围|

  * 表体综合字段 

| 字段      | 说明                                                                       |
| 供应商编码   | 供应商到货及时率的供应商编码.                                                           |
| 供应商名称   | 根据供应商编码带出供应商名称.                                                          |
| 物料编码    | 供应商到货及时率的物料编码.                                                            |
| 物料名称    | 根据物料编码带出物料名称                                                             |
| 规格型号    | 物料编码对应的规格型号                                                              |
| 辅助属性    | 物料对应的辅助属性                                                                |
| 到期订单批数  | 1、过滤条件选择“按送货批数”时显示\\ 2、取供应商在该物料下的总的订单数                                   |
| 逾期交货批数  | 1、过滤条件选择“按送货批数”时显示\\ 2、取供应商再该物料下是否逾期为是的订单数（如何计算是否逾期查看【订单到货及时率】报表）        |
| 准时交货批数  | 1、过滤条件选择“按送货批数”时显示\\ 2、取供应商在该物料下是否逾期为否的订单数（如何计算是否逾期查看【订单到货及时率】报表）        |
| 交货及时率   | 1、过滤条件选择“按送货批数”时显示\\ 准时交货批数/到期订单批数\\ 2、过滤条件选择“按送货数量”时显示\\ 准时交货数量/到期订单数量  |
| 到期订单数量  | 1、过滤条件选择“按送货数量”时显示\\ 2、取供应商在该物料下的总的订单数量                                  |
| 逾期交货数量  | 1、过滤条件选择“按送货数量”时显示\\ 2、入库日期或收料日期>交货日期的数量                                 |
| 准时交货数量  | 1、过滤条件选择“按送货数量”时显示\\ 2、入库日期或收料日期<=交货日期的数量                                |
====== 6报表操作说明 ======


报表提供冻结列设置、打印、引出功能
