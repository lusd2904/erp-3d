======多维经营对比分析表过滤条件 ======
在“快捷”页签，用户选择需要查询的经营账簿、利润中心、经营单元、经营科目、会计期间、起始日期、结束日期、币别基本过滤条件。其他过滤页签为系统通用设置，可设置字段列的显示隐藏属性。

快捷页签主要过滤项目说明 

| **过滤项**                 || **说明**                                          |
| 综合条件     | 经营账簿          | 选择查询哪个经营账簿，单选。                                  |
| :::      | 经营科目          | 选择需要查询的资金经营科目，多选。                               |
| :::      | 不显示经营科目       | 控制是否显示经营科目。                                     |
| :::      | 仅显示相同经营单元对比分析  | 勾选时只显示相同参照经营单元和对比经营单元数据，不勾选时可以显示所有参照经营单元和对比经营单元数据。  |
| 参照条件     | 组织架构         | 选择需要对比的组织架构版本。                                    |
| :::      | 利润中心           | 选择需要对比的利润中心。                                     |
| :::      | 经营单元           | 选择需要对比的经营单元。                                     |
| :::      | 开始期间          | 选择需要对比的开始期间。                                    |
| :::      | 结束期间          | 选择需要对比的结束期间。                                    |
| :::      | 开始日期          | 如果不按期间对比，可以选择任意开始日期。                            |
| :::      | 结束日期          | 如果不按期间对比，可以选择任意结束日期。                            |
| :::      | 按利润中心汇总       | 勾选时按利润中心汇总显示，不勾选时按经营单元显示                         |
| 对比条件     |组织架构         | 选择需要对比的组织架构版本。                                     |
| :::      | 利润中心           | 选择需要对比的利润中心。                                     |
| :::      | 经营单元           | 选择需要对比的经营单元。                                     |
| :::      | 开始期间          | 选择需要对比的结束期间。                                    |
| :::      | 结束期间          | 选择需要对比的结束期间。                                    |
| :::      | 开始日期          | 如果不按期间对比，可以选择任意开始日期。                            |
| :::      | 结束日期          | 如果不按期间对比，可以选择任意结束日期。                            |
| :::      | 按利润中心汇总       | 勾选时按利润中心汇总显示，不勾选时按经营单元显示                         |
