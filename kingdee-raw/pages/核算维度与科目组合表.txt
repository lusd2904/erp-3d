====== 1.报表功能 ======

核算维度与科目组合表提供了核算维度与会计科目二维组合报表，既可以反映指定类别的核算维度所涉及的所有或多个会计科目的发生额及期初期末余额，又可以反映指定会计科目对应的所有或多个核算维度发生情况及余额。

核算维度与科目组合表支持数值为零显示为空。

核算维度与科目组合表支持联查核算维度明细账。

====== 2.过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置会计年度期间、科目和核算维度范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。
^ 过滤项                  |^ 说明                                                                                                                                                                                                        ^
| 报表样式                 || 系统提供“核算维度与科目组合”、“科目与核算维度组合”及“核算维度组合表”三个选项，\\ 选择“核算维度与科目组合”时，可以查询到以核算维度为行、会计科目为列的二维报表；\\ 选择“科目与核算维度组合”时，可以查询到以会计科目为行、核算维度为列的二维报表；\\ 选择“核算维度组合表”时，必须使用核算维度组合查询，可以查询到以会计科目及核算维度组合中的第一个核算维度为行，其他核算维度为列的二维报表。  |
| 连续核算维度范围查询           || 默认选项，选中此项，则选择起始核算维度后，账表按所选核算维度编码范围内的所有核算维度查询。                                                                                                                                                             |
| 非连续核算维度范围查询          || 选中此项，账表按所勾选的核算维度查询。                                                                                                                                                                                       |
| 使用核算维度组合查询           || 选中此项，核算维度查询界面为核算维度组合选择界面，用户设置多个核算维度查询；反之，核算维度查询界面只能选择某个核算维度查询。                                                                                                                                            |
| 显示包含维度组合中任一维度的科目     || 选中此项，按核算维度组合的并集查询（显示满足维度组合中任一条件的科目数据）；反之，按核算维度组合的交集查询。                                                                                                                                                    |
| 核算维度                 || 设置查询的核算维度。如果指定了科目，则只能选择科目关联的核算维度；反之，可以选择具有查询权限的所有核算维度查询。                                                                                                                                                  |
| 核算维度级次               || 核算维度所关联的基础资料存在分组时，支持按次级查看。\\ 核算维度次级为0时只显示最明细的核算维度的数据，次级为1时显示1级核算维度的汇总数据，依次类推。                                                                                                                             |
| 核算维度编码               || 设置查询的核算维度范围。                                                                                                                                                                                              |
| 核算维度编码不显示            || 选中此项，不显示核算维度编码。 |

| 包括未过账凭证              || 选中此项，查询结果包含未过账凭证的金额数据。                                                                                                                                                                                    |
| 只显示明细科目              || 选中此项，核算维度与科目组合表按明细科目的方式输出。                                                                                                                                                                                |
| 科目编码不显示              || 选中此项，会计科目编码在报表中不显示。                                                                                                                                                                                       |
| 显示发生额为零的记录           || 选中此项，查询结果显示发生额为零的核算维度。                                                                                                                                                                                    |
| 余额为零不显示              || 选中此项，余额为零的核算维度不显示。                                                                                                                                                                                        |
| 按科目方向计算合计            || 不勾选此项，合计数为简单求和；勾选此项，按业务逻辑计算合计（借贷方科目余额相抵后求和、 多级科目或维度的金额不重复统计），不支持拖动表头。                                                                                                                                     |

| 显示从未使用过的科目           || 选中此项，查询结果包含从未使用过的科目。                                                                                                                                                                                      |
| 不显示小计                || 选中此项，按维度组合查询时不显示小计行。                                                                                                                                                                                      |

====== 3.操作说明 ======

系统支持核算维度余额表联查核算维度明细账，用户选择需要联查的记录，点击工具栏的查看明细账按钮联查核算维度明细账信息。
