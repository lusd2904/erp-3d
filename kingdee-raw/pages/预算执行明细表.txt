ID: 预算执行明细表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E7%AE%97%E6%89%A7%E8%A1%8C%E6%98%8E%E7%BB%86%E8%A1%A8

**功能描述**

基于预算控制规则的预算执行明细分析。（查询预算执行的实际单据列表，联查单据）


**功能路径**


【管理会计】-【预算管理】-【预算分析】-【预算执行明细表】

** 过滤条件 **
^ 字段                  ^ 说明                                              ^
| 预算方案                | 选择需要查询预算进度所在的预算方案                               |
| 预算控制规则              | 选择需要查询预算进度所使用的控制规则                              |
| 币别                  | 选择需要查询的币别                                       |
| 本位币                 | 选择需要查询的本位币                                      |
| 预算组织                | 选择需要查询的一个或者多个预算组织\\ 允许选择任意组织PT132327            |
| 预算周期                | 选择需要查询的预算周期类型                                   |
| 预算年度                | 选择需要查询的预算年度                                     |
| 预算期间                | 选择需要查询的预算期间                                     |
| 项目数据类型              | 选择需要查询的项目数据类型                                   |
| 预算业务类型              | 选择需要查询的预算业务类型                                   |
| 单据范围                | 选择需要查询的执行单据类型（从所选预算控制规则中罗列，系统默认所有单据）            |
| 预算影响类型              | 选择需要查询的预算影响类型，系统默认所有影响类型                        |
| 预算维度过滤              | 选择需要查询的具体预算维度，不设置时，系统默认查询控制规则下对应所有维度。           |
| 选项：包含已提交未审核的实际执行单据  | 选中时，获取已执行的实际数时，包含已提交未审核的实际执行单据。\\ 否则，只包含已审核单据。  |
 


** 报表字段 **
^  字段 说明                                                                                                                                              ||
| 预算组织          | 预算组织                                                                                                                                 |
| 组织类型          | 当前预算组织的组织类型：组织/部门                                                                                                                    |
| 预算年度          | 预算年度                                                                                                                                 |
| 预算期间          | 预算期间                                                                                                                                 |
| 预算影响类型        | 来源：预算控制规则.控制单据.【预算影响类型】设置                                                                                                            |
| 控制单据          | 单据名称                                                                                                                                 |
| 单据编号          | 单据编号                                                                                                                                 |
| 单据日期          | 来源：预算控制规则.控制单据.单据日期字段设置                                                                                                              |
| 预算业务类型        | 预算业务类型                                                                                                                               |
| 项目数据类型        | 项目数据类型                                                                                                                               |
| 预算维度          | 维度值组合\\ 显示具体维度以及维度值\\ 维度值属性的显示：在模板样式方案中，设置维度显示属性设置。将在报表中显示维度的具体属性。\\ 如：在模板样式方案中，对产品维度设置显示属性：编码/规格型号。则在报表中，产品维度显示为：智能手机/PH011005/M60  |
| 单据发生数         | 来源：预算控制规则.具体某控制单据.控制数据.【单据字段】的设置\\ 当预算影响类型=【预算冲回】时，单据发生数=-【单据字段值】                                                                    |
| 单据下推回写/冲销源单数  | 来源：预算控制规则.具体某控制单据.控制数据.【单据下推回写/冲销源单字段】的设置                                                                                            |
| 关闭释放          | 取数来源：已关闭的申请占用类单据。\\ 【单据发生数】-【申请冲回】                                                                                                   |
| 实际执行数         | 单据发生数-(单据下推回写/冲销源单数)                                                                                                                 |
| 单据状态          | 单据状态                                                                                                                                 |
| 备注信息          | 预算控制规则已设置备注信息对应的单据字段。                                                                                                                |



**其他说明**
  - 选中任意行，点击【单据联查】，可直接打开所选行对应的单据界面。
