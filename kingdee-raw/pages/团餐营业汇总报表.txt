====== 1.团餐营业汇总报表 ======

===== 1.1 功能概述 =====
记录每个营业网点的营业收入排名，成本排名，利润排名，实际总营业收入，实际总费用，外包档口收入，运营档口提单等字段。详细记录每个食堂网点的营业数据，方便营业者进行分析和决策。

===== 1.2 字段说明 =====
^ 字段名称     ^ 字段说明              ^
| 食堂网点     | 团餐营业汇总报表的组织       |
| 营业收入排名   | 在所有组织中排名          |
| 成本排名     | 计算成本的排名           |
| 利润排名     | 利润的排名             |
| 利润率排名    | 统计过滤的所有组织的利润率排名   |
| 用餐人次排名   | 统计过滤的所有组织的用餐人次排名  |
| 实际总营业收入  | 该组织所有收入的总和        |
| 实际总费用    | 当前组织所有费用的总和       |
| 外包档口收入   | 团餐营业数据的外包档口收入     |
| 运营档口提点   | 团餐营业数据的运营档口提点     |
| 实际收入     | 总营业收入-总费用         |
| 用餐人数     | 取营业数据的用餐人数总和      |
| 利润       | 收入-成本             |
| 利润率      | 利润/成本             |
| 应收账款余额   | 营业数据的应收账款-应付账款    |
|          |                   |
