[[经营会计#内部分摊|<<返回经营界面]]


====== 1.功能说明 ======
本功能主要用于查询经营费用分摊明细情况。


**功能路径**

【管理会计】－>【经营会计】－>【内部分摊】－>【经营费用分摊明细表】。
====== 2.字段说明 ======


^ 字段         |^ 说明                                                                                                                    ^
| 经营账簿     || 选择需要查询的账簿。                                                                                |
| 经营组织架构     || 自动获取经营账簿和期间对应的组织架构版本。                                                                                |
| 经营期间     || 选择需要查询的会计期间。                                                                                |
| 分摊方利润中心     || 选择需要查询的分摊方利润中心。                                                                                |
| 分摊方经营单元     || 选择需要查询的分摊方经营单元。                                                                                |
| 查询方式     || 可选按单据范围或者按费用分摊方案。                                                                                |
| 来源单据     || 选择按单据范围查询时，可选需要查询的来源单据类型和具体单据范围。                                                                               |
| 费用分摊方案     || 选择按费用分摊方案查询时，可选需要查询的费用分摊方案或总账科目引入方案。                                                                                |
| 仅显示未分摊     || 勾选后，仅显示查询范围中“分摊完成”为否的单据。                                                                                |
| 仅显示未入账     || 勾选后，仅显示查询范围中“是否入账”为否的单据。                                                                                |
| 分摊结果包含负数内部分摊经营流水     || 勾选后，显示经营流水账分摊发送方生成的负数费用分配结果单和负数经营流水账。                                                                               |


====== 3.操作说明 ======

经营费用分摊明细表选中单据行可联查对应的来源单据，费用分配结果单，经营流水账。
