===== 1.功能概述 =====
营业账单定时处理任务用于数据清洗，数据上传存在差异时，可以重新生成营业账单
====== 2.使用前提 ======
存在实际发生的业务数据，通过门店数据交换或门店日结上传账单数据，数据与日结小票打印不一致时，可以重新生成营业账单
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【财务集成】→【营业账单定时处理任务】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：高级、条件、显示隐藏列、排序

  * 高级页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 排序页签：报表显示字段排序
====== 5.报表字段说明 ======
^ 字段        ^ 说明             ^
| 组织        | 组织机构           |
| 任务状态      | 1.准备状态；2.停止状态  |
| 计划开始时间    | 重新上传时间         |
| 计划结束时间    | 上传结束时间         |
| 执行间隔时间    | 上传间隔时间：分，天，周等  |
| 最近一次执行情况  | 最后一次上传时间，上传情况  |

====== 6.报表操作说明 ======
1、报表提供打印、引出功能。

2、报表提供按表头的【组织】和【营业日期】重新上传营业账单数据

3、可以通过勾选【选项】中的参数，控制数值的显示 。
