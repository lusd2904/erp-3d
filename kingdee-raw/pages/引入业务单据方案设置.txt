[[经营会计#经营流水账来源设置|<<返回经营界面]]



====== 1.功能说明 ======

本功能主要用于设置业务单据生成经营流水账，区分收入、支出和转账业务。


**功能路径**

【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【引入业务单据方案设置】。
====== 2.字段说明 ======


| **位置**       || **字段**   | **说明**                                          |
| 表头基本信息       || 经营账簿     | 选择要生成经营流水账的经营账簿。                                |
|              || 经营单元    | 选择业务单据要生成经营流水的经营单元。                            |
|              || 生成流水账方式    | 可选同一行分录来源单据一对一或者同一行分录来源单据全部汇总，默认选择同一行分录来源单据一对一。                            |
|              || 分录合并    | 勾选时，经营流水账相同（收支科目+收支科目核算维度+资金科目+资金科目核算维度+分摊方/内部交易方+摘要）分录合并。          |
| 收入支出来源       || 是否引入     | 需要引入的则必须勾选此项。                                   |
|              || 来源单据     | 选择需要生成经营流水账的单据。                                 |
|              || 分录条件     | 可以来源单据设置分录条件。                                   |
|              || 交易类型     | 设置生成流水的交易类型                                     |
|              || 收支类型     | 设置生成流水的收支类型。                                    |
|              || 经营科目     | 选择生成经营流水账对应的经营科目。支出类型可选为费用类经营科目，收入类型可选收入类经营科目。  |
|              || 账户       | 根据收支类型选择对应的资金账户。                                |
|              || 经营单元来源    | 选择经营单元来源于单据对应的哪个字段，经营单元来源字段必须和定义经营单元权限对象类型一致。    |
|              || 经营单元结算物料  | 设置经营单元结算物料来源，用于内部交易和结算价目表的物料对应。                  |
|              || 日期来源     | 设置经营流水账业务日期来源于单据日期。                             |
|              || 内部交易划分   | 同一张来源单据需要设置生成对外交易和内部交易时，需要设置内部交易生成条件。           |
| 收入支出子单据体     || 单位       | 设置交易价单位来源。                                    |
|              || 数量       | 设置交易数量来源。                                   |
|              || 单价       | 设置单价来源。                              |
|              || 币别       | 设置币别来源。                                         |
|              || 原币金额     | 设置经营流水账金额来源。                                    |
|              || 备注       | 设置经营流水账备注来源 。                                   |
|              || 内部交易方    | 设置内部交易对方经营单元来源 。                                 |
| 转账来源         || 是否引入     | 需要引入的则必须勾选此项。                                   |
|              || 来源单据     | 选择需要生成经营流水账的单据。                                 |
|              || 分录条件     | 可以来源单据设置分录条件。                                   |
|              || 转入经营科目   | 设置生成流水的收支类型。                                    |
|              || 转出经营科目   | 选择生成经营流水账对应的经营科目。                               |
|              || 经营单元来源    | 选择经营单元来源于单据对应的哪个字段，经营单元来源字段必须和定义经营单元权限对象类型一致。    |
|              || 经营单元结算物料  | 设置经营单元结算物料来源，用于内部交易和结算价目表的物料对应。                  |
|              || 日期来源     | 设置经营流水账业务日期来源于单据日期。                             |
|              || 内部交易划分   | 同一张来源单据需要设置生成对外交易和内部交易时，需要设置内部交易生成条件。           |
| 转账来源子单据体     || 单位       | 设置内部交易价单位来源。                                    |
|              || 数量       | 设置内部交易数量来源。                                   |
|              || 单价       | 设置单价来源的经营单元内部结算单价。                              |
|              || 币别       | 设置币别来源。                                         |
|              || 原币金额     | 设置经营流水账金额来源。                                    |
|              || 备注       | 设置经营流水账备注来源 。                                   |
|              || 内部交易方    | 设置内部交易对方经营单元来源 。                                 |

====== 3.操作说明 ======

打开【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【引入业务单据方案设置】功能，管理和维护引入业务单据方案。
