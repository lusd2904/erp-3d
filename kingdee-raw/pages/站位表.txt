======1 站位表 ======
=====1.1 功能概述=====
站位表是使用SMT上料防错的基础信息，用于对需上料物料与产线、贴片机位置、上料物料、轨道、飞达规格型号、用量进行定义，建立基础资料。

=====1.2 使用前提=====
定义【组织】【物料】【柔性产线】【柔性产线与物料关系】【飞达规格型号】
===== 1.3功能路径 ===== 

【智慧车间MES】—>【智慧车间】—>【SMT上料】—>【站位表】

====== 2 字段说明 ======
表头
^  ** 字段**  ^  **说明**                               ^
|  产品编码     | 创建站位表物料的编码。                              |
|  产品名称     | 创建站位表物料的名称。                              |
|  规格型号     | 创建站位表物料的规格型号。                          |
|  站位表版本   | 站位表版本标识，支持系统自动生成或自定义。          |

常规
^  ** 字段**  ^  **说明**                               ^
|  产线             | 指定该物料站位表使用的柔性产线                  |
|  贴片机位置       | 指定该物料站位表使用的贴片机位置。              |
|  贴片机型号       | 指定该物料站位表使用的贴片机型号。              |
|  程序名称         | 指定该物料站位表使用的程序名称。                |

明细
^  ** 字段**  ^  **说明**                               ^
|  Table     | 上料物料所处版面。                             |
|  轨道      | 上料物料使用轨道。                             |
|  物料编码  | 上料物料编码。                             |
|  物料名称  | 上料物料名称。                             |
|  规格型号  | 上料物料规格型号。                             |
|  Feeder规格型号      | 上料物料使用飞达规格型号。                             |
|  子项单位      | 上料物料单位。                             |
|  用量：分子    | 确定上料物料与创建物料数量关系。                             |
|  用量：分母    | 确定上料物料与创建物料数量关系。                             |
|  吸嘴型号      | 上料物料对应吸嘴型号。                             |
|  位置          | 上料物料对应零件位置。                             |
|  零件方向      | 上料物料对应零件方向。                             |
