ID: 返利政策
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E6%94%BF%E7%AD%96

**功能概述：**根据企业营销策略，推动市场销售，制定返利政策对客户的实际销售情况进行返利。

**使用前提：**已经设置返利模式资料

**功能路径:** 【电商与分销】－>【返利管理】－>【返利政策】－>【返利政策】

**字段说明：**返利政策表头—基本信息

|**字段**||**说          明**|
|返利政策编码||系统自动生成或是手工填写返利政策编码|
|返利组织||F8选择，范围为有权限的结算属性的业务组织|
|返利主题||手工填写|
|返利内容||手工填写|
|返利累进方式||包括两种返利累计方式：全额累进方式、超额累进方式|
|币别||默认为申请组织的本位币|
|返利模式||下拉框选择，范围为基本资料中维护的返利模式。选择不同的返利模式后可以进行不同的返利政策信息维护|
|返利周期类型||根据返利模式显示其周期类型|

返利政策表头—参与组织

|**字段**||**说          明**|
|销售组织编码||F8选择，范围为用户权限范围内的销售组织|
|销售组织名称||根据销售组织编码携带销售组织名称|

返利政策表头—参与客户

|**字段**||**说          明**|
|客户编码||F8选择，范围为返利组织下的所有客户资料|
|客户名称||根据客户编码携带客户名称|
|客户类别||F8选择，范围为基础资料中维护的客户类别|
|客户类别编码||根据选择的客户类别携带客户类别编码|

返利政策表体—返利信息
（列表字段是根据表头所选返利模式定义的属性字段进行显示的）

| **字段**     || **说          明**                                                                                                                                                             |
| 返利周期       || 根据表头的返利周期类型进行返利周期的选择                                                                                                                                                         |
| 组号         || 每个分组代表一种具体返利实例，同一组的产品是可以进行组合返利政策的定义；若不属于组合返利场景，可以使用不同组号进行设置。\\ 例如，定义组合返利时，购买A、B、C三种商品，购买一种或多种数量达到返利条件时则进行返利，ABC三个商品就应该在同一个组号下；\\ 若购买A或B或C必须每一种都达到10 个才有赠送，则A、B、C应设置在不同的组号下。  |
| 物料分组       || 用于按产品分类定义返利实例，与物料编码字段互斥，即一行分录只能按物料组或是按物料明细定义返利内容                                                                                                                             |
| 物料编码       || 用于按产品定义返利实例，与物料分组字段互斥，即一行分录只能按物料组或是按物料明细定义返利内容                                                                                                                               |
| 物料名称       || 根据物料编码携带出物料名称                                                                                                                                                                |
| 规格型号       || 根据物料编码携带出物料规格型号                                                                                                                                                              |
| 计量单位       || 根据物料编码携带出物料的销售计量单位                                                                                                                                                           |
| 购买数量       || 以购买数量为返利条件时，填写最小购买数量。同一个组号，系统会自动将购买商品的购买数量置为相同。\\ 例如，购买A、B、C三种商品，组合数量达到500个时返利，则A、B、C三个商品的购买数量栏均为500。                                                                        |
| 购买金额       || 以购买金额为返利条件时，填写最小购买金额。同一个组号，系统会自动将购买商品的购买金额置为相同。                                                                                                                              |
| 指标数量       || 按年度或月度指标完成率为返利条件时，以购买数量为返利条件时，填写指标数量                                                                                                                                         |
| 指标金额       || 按年度或月度指标完成率为返利条件时，以购金额量为返利条件时，填写指标数量填写指标金额                                                                                                                                   |
| 指标完成率      || 按指标完成率为返利条件时，填写指标数量或指标金额的完成率，根据完成率进行返利政策的执行                                                                                                                                  |
| 赠品         || 赠品实物返利时，对赠送的物料在本行置为赠品状态                                                                                                                                                      |
| 赠送数量       || 当本行物料为赠品时，填写赠品的赠送数量                                                                                                                                                          |
| 赠送基数       || 用于定义返利返还形式为返赠品时，赠送基数（如每买100个就赠送1个赠品，则基数为100）                                                                                                                                 |
| 返利方式       || 折扣返利时，选择产品的折扣方式，选项包括：折扣率、折扣额两种。                                                                                                                                              |
| 返利率%       || 折扣方式为折扣率则填写产品折扣率                                                                                                                                                             |
| 单位返利额      || 折扣方式为折扣额则填写产品的单位折扣额                                                                                                                                                          |
| 备注         || 用于填写备注信息                                                                                                                                                                     |

**操作说明：**
  * 审核与反审核功能-只有审核后的返利政策为有效的政策，可以进行执行，对审核状态的返利政策可以进行反审核，反审核后可以进行重修改提交后再次审批。
  * 失效与取消失效功能-用户可以通过手工失效功能将返利政策进行失效；也可以通过取消失效功能，将返利政策恢复使用。
