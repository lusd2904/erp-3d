ID: 我的会员
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%88%91%E7%9A%84%E4%BC%9A%E5%91%98

**功能说明：**

显示当前渠道登记的会员并且允许新增、编辑修改会员

**功能路径：**

【会员中心】->【我的会员】

**使用前提：**

无

**字段说明：**

| **名称**   | **字段说明**                            |
| 会员编号     | 由系统规则自动生成                           |
| 会员名称     | 手工填写                                |
| 手机       | 手工填写                                |
| 电子邮件     | 手工填写                                |
| 电话       | 手工填写                                |
| QQ       | 手工填写                                |
| 会员种类     | 金自定义会员类型                    |
| 会员等级     | 根据会员自动携带                            |
| 会员来源     | 网店/直营门店/分销渠道/分销门店                   |
| 分销渠道/门店  | 自动默认为当前渠道ID，锁定不允许修改                 |
| 业务员      | 选择当前渠道档案的关联业务员                      |
| 年龄段      | 以上资料从辅助资料进行定义，在界面上自动获取和显示  |
| :::      | 与《客流登记》使用共同的辅助资料                    |
| 身形       | 以上资料从辅助资料进行定义，在界面上自动获取和显示  |
| :::      | 与《客流登记》使用共同的辅助资料                    |
| 锻炼频度     | 以上资料从辅助资料进行定义，在界面上自动获取和显示  |
| :::      | 与《客流登记》使用共同的辅助资料                    |
| 受伤史      | 手工填写                                |
| 国家       | 从B2C的地区信息表中选择，默认为中国                 |
| 省份       | 根据国家过滤                              |
| 城市       | 根据省份过滤                              |
| 区/县      | 根据城市过滤                              |
| 产品安装流水号  | 用于填写商品售后安装卡信息                       |
| 详细地址     | 手工填写                                |
| 已购买产品    | 以上资料从辅助资料进行定义，在界面上自动获取和显示  |
|          | 与《客流登记》使用共同的辅助资料                    |
| 会员喜好列表                                        ||
| 爱好       | 以上资料从辅助资料进行定义，在界面上自动获取和显示  |
|          | 与《客流登记》使用共同的辅助资料                    |

**操作说明：**
  -   在辅助资料列表维护相关会员资料
  -   进入BBC商品前台【会员中心】->【我的会员】，新增填写相关会员资料，然后保存即可；
  -   查看我的会员列表，列表内允许刷新、新增、删除等操作。
