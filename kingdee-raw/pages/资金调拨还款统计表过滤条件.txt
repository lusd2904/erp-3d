====== 资金调拨还款统计表过滤条件 ======
在“快捷”页签，用户选择需要查询的借出组织、借入组织、结算方式、币别、起始日期、结束日期等基本过滤条件。其他过滤页签为系统通用设置，可设置条件、高级、字段列的显示隐藏属性

快捷页签主要过滤项目说明 
| **过滤项**       || **说明**                              |
| 借出组织          || 资金调拨的调出组织                           |
| 借入组织          || 资金调拨的调入组织                           |
| 结算方式          ||资金调拨的币别，可为空，为空查询所有币别|
| 币别            || 资金调拨的币别，可为空，为空查询所有币别                  |
| 起始日期          || 业务日期的查询开始日期                        |
| 结束日期          || 业务日期的查询结束日期                        |
| 本日            || 本日，快捷录入起始日期、结束日期                    |
| 本周            || 本周，快捷录入起始日期、结束日期                    |
| 本月            || 本月，快捷录入起始日期、结束日期                    |
| 包含未审核单据       || 查询数据，是否要包含未审核的资金调拨单、调拨还款单           |
| 显示本位币         || 是否显示本位币。勾选时，显示借入组织本位币、显示借出组织本位币不锁定  |
| 显示借入组织本位币     || 选中此项，报表显示借入组织本位币金额列；反之，则不显示。        |
| 显示借出组织本位币     || 选中此项，报表显示借入组织本位币金额列 ；反之，则不显示。       |
