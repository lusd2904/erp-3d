====== 1.功能说明 ======

定义日常业务使用的结算方式。

====== 2.字段说明 ======
== 1）基本 ==

^ 字段         |^ 说明                                                                                                 ^
| 结算方式类别     || 系统定义如下结算方式类别：现金、支票、商业承兑汇票、银行承兑汇票、本票、汇兑、信用证、委托收款、托收承付、汇票、银行汇票、电子支付、光票托收、承兑交单、远期付款交单、即期付款交单、票汇、信用卡。  |
| 业务分类       || 可以下拉选择：银行业务、现金业务。                                                                                  |
| 承担方        || 手续费的承担方，通过下拉选择：本方、对方。                                                                              |
| 支付方式       || 手续费的支付方式，可以下拉选择单独扣缴、定期扣缴、直接扣缴、缴存现金。                                                                |
| 默认结算方式     || 勾选此参数，出纳收款单、付款单、收款退款单、付款退款单结算方式自动取默认值                                                              |
{{:结算方式_1.png?direct&400 |}}

== 2）餐饮 ==

^ 字段          ^ 说明                 ^
| POS排列序号     | POS端显示排列顺序         |
| 非营收         | 是否是营收收入；勾选即为非营收收入（云店通已启用）  |
| 自动弹出钱箱      | 勾选后，POS前端自动弹出钱箱    |
| 是否在移动POS显示  | 是否显示               |
| 类别默认结算方式    | 是否是结算方式类别下的默认结算方式  |

{{:结算方式_2.png?direct&400 |}}

====== 3.操作说明 ======

系统预设了几种比较通用的结算方式，用户可编辑预设结算方式。如果用户还有其它的结算方式，可以在系统中自定义。
