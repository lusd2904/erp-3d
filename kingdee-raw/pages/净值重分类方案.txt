 ====== 净值重分类方案 ====== 

**功能说明**

设置报表项目需要根据不同科目相加减后的结果进行重分类的计算公式，比如合同负债与合同资产、递延所得税负债与递延所得税资产、应收账款与应付账款的重分类。

**功能路径**

【财务会计】→【报表】→【基础资料】→【净值重分类】

**操作说明**

查阅社区知识https://vip.kingdee.com/article/210422588345247744


 ====== 字段说明 ======

| 字段           || 说明                                          |
| 编码           || 报告维度的编码，唯一标识，手工录入。                          |
| 名称           || 报告维度的名称，手工录入。                               |
| 描述           || 文本编辑，手工录入                                   |
| 净值正数         || 单选项，表达式明细维度计算结果为正数计入的报表项目                   |
| 净值负数         || 单选项，表达式明细维度计算结果为负数计入的报表项目                   |
| 项目数据类型       || 单选项，系统预置的期末数、年初数，对应科目取数类型定义为Y、C             |
| 科目表达式        || 科目取数公式                                      |
| 科目表/科目       || 科目表达式计算元素，选择插入到科目取数公式                       |
| 核算维度         || 科目表达式计算元素，选择插入到科目取数公式                       |
| 主维度          || 科目表达式存在不同科目的核算维度不同时，需要选择主维度，主维度来源于表达式的核算维度  |
| 关联维度         || 选择与主维度对应匹配的核素维度，关联维度来源于表达式的核算维度             |
| 关联维度对应字段     || 主维度与关联维度的具体映射项                              |
