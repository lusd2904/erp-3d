ID: 费用报销系统参数
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E6%8A%A5%E9%94%80%E7%B3%BB%E7%BB%9F%E5%8F%82%E6%95%B0

**功能概述**：
  - 系统进行日常业务处理之前，需要确认以下系统参数是否符合企业实际业务的需求。当然，在系统使用过程中，也可以根据实际需求的变化修改这些系统参数的设置。
  - 功能路径：【财务会计】－>【费用报销】－>【参数设置】－>【费用报销系统参数】。
**基本参数说明**：
| 类别     | **参数**                               || **说明**                                     |
| 基本选项     | 业务单据的汇率允许手工修改                                                          ||控制费用报销的业务单据（包括费用申请单、出差申请单、费用报销单、差旅费报销单、费用转移单）上的汇率字段是否允许用户手工修改。 该参数默认不勾选。                                                                                                         |
| :::      | 借款/报销付款应用付款申请流程                                                        || 默认选中该选项。\\ 选中时，申请借款的申请单以及申请付款的报销单，在成功审核后，系统自动下推生成付款申请单，再由付款申请单，下推付款单。\\ 不选中时，申请借款的申请单以及申请付款的报销单，在成功审核后，可直接下推付款单。                                                                 |
| :::      | 自动产生付款申请单                                                              ||勾选借款/报销付款应用付款申请流程时，才可对该选项进行编辑，默认选中该选项。选中时，申请借款的申请单以及申请付款的报销单，在成功审核后，系统自动下推生成付款申请单，再由付款申请单，下推付款单。\\ 不选中时，申请借款的申请单以及申请付款的报销单，在成功审核后，当参数勾选“借款/报销付款应用付款申请流程”，可手工下推付款申请单，未勾选则可下推付款单。  |
| :::      | 自动下推付款申请单状态创建/提交                                                       ||选择创建时，报销单/申请单审核自动产生的付款申请单为创建的；选择提交时，报销单/申请单审核自动产生的付款申请单自动提交走到审批，为审核中的状态。                                                                                                         |
| :::      | 费用明细/汇总表实现部门数据隔离                                                       ||此参数默认不勾选。\\ 不勾选时，费用汇总表过滤界面的参数“费用承担部门”为可选，用户根据需要选择一个或者多个费用承担部门进行过滤。\\ 勾选时，“费用承担部门”灰显，默认为登录用户所在部门。                                                                                 |
| 结账控制     | 申请单未审核不允许关账                                                            ||勾选该参数，关账时间范围内如果存在未审核的申请单（包括费用申请单、出差申请单）则不允许关账；不勾选该参数，关账时间范围内如果存在未审核的申请单时允许关账。\\ 如果不勾选该参数，则关账后如果需要将该未审核的单据审核，则必须将申请日期修改为未关账的日期。\\ 该参数默认不勾选。      |
| :::      | 报销单未审核不允许关账                                                            ||勾选该参数，关账时间范围内如果存在未审核的报销单（包括费用报销单、差旅费报销单）则不允许关账；不勾选该参数，关账时间范围内如果存在未审核的申请单时允许关账。\\ 如果不勾选该参数，则关账后如果需要将该未审核的单据审核，则必须将申请日期修改为未关账的日期。\\ 该参数默认不勾选。                                      |
| :::      | 转移单未审核不允许关账                                                            ||勾选该参数，关账时间范围内如果存在未审核的费用转移单则不允许关账；不勾选该参数，关账时间范围内如果存在未审核的申请单时允许关账。\\ 如果不勾选该参数，则关账后如果需要将该未审核的单据审核，则必须将申请日期修改为未关账的日期。\\ 该参数默认不勾选。                                                    |
| :::      | 反关账时校验总账结账状态                                                           ||勾选该参数，则费用报销反关账的时候会校验关联的总账账簿是否结账，若结账，则不允许反结账。\\ 如果不勾选该参数，则费用报销反关账不校验关联的总账账簿的结账状态。\\ 该参数默认不勾选。                                                                                     |
| 其他选项     | 报销单同步其他应付单时机                                                           ||默认选中“审核”项。\\ 选中“提交”时，则在报销单提交状态时同步生成提交状态的其他应付单。\\ 选中“审核”时，则在报销单审核时同步生成审核状态的其它应付单。                                                                                                 |
| :::      | 报销单审核时自动生成进项费用增值税发票                                                    ||默认不勾选。\\ 勾选时，报销单审核时自动生成进项费用增值税发票。\\ 不勾选时，审核不产生下游发票，需手工下推。                                                                                                                        |
| :::      | 借款/报销付款审核时自动生成付款单                                                      ||勾选该参数，则借款、报销单审核后会自动产生出纳付款单 |
| :::      | 借款是否其他预付                                                               || 默认不勾选。\\ 勾选时，申请单产生的付款单上的“是否其他预付” 标识会自动勾上；“是否其他预付”标识的付款单在与其他应付单进行核销时，自动产生核销单；用户可通过核销单生成凭证（借：其他应付 贷：其他预付）。                                                                         |
| :::      | 申请单/报销单付款时，结算方式不带默认值                                                   ||默认不勾选。此时结算方式如BOS中有配则带BOS中配置的缺省值；如没有配，则带上一次的结算方式（无上一次的则带基础资料结算方式处勾选的默认结算方式，没有勾选默认结算方式，则是空白必录）\\ 勾选时，结算方式为空白必录。                                                                    |
| :::      | 报销单税率不通过费用项目携带                                                         || 默认不勾选。勾选时，报销单更改费用项目时不清空税率税额。                                                                                                                                                     |
| :::      | 申请单合并下推报销单携带源单明细信息                                                     ||选择此项，则申请单合并下推报销单也会将源单信息一一带到报销单明细上。                                                                                                                                               |
| :::      | 点击退款生成提交状态的付款退款单                                                       ||勾选，则在申请单上点击退款生成的付款退款单自动提交走流程；否则，生成创建状态的付款退款单。                                                                                                                                    |
| :::      | 点击退款需要弹框输入退款信息                                                         ||勾选，则在申请单上点击退款，会弹出退款账号信息的填写；否则，生成付款退款单。                                                                                                                                           |
| :::      | 不允许反审核已关帐的单据                                                           ||勾选，已关账的单据不允许反审核；否则允许反审核。                                                                                                                                                         |
| :::      | 可用借款余额按费用承担组织取数                                                      ||该参数勾选，可用借款余额则是按费用承担组织取数，否则，是取所有组织的可用借款余额。                                                                                                                                                        |
| :::      | 事由申请单报销次数一次/多次                                                      ||选择一次，事由申请单报销一次之后不允许再次报销；选择多次，可以无限制次数报销。                                                                                                                                                       |                                                                                                                                      
| 我部门单据列表  | 当前员工主任岗位所属部门                                                           ||选择此项，则单据列表仅过滤主任岗位所属部门对应的单据列表。                                                                                                                                                    |
| :::      | 当前员工所有岗位所属部门                                                           ||选择此项，则单据列表仅过滤当前员工所有岗位所属部门对应的单据列表。                                                                                                                                                |
| 差旅标准     | 启用差旅标准（该组织为承担组织）                                                       ||勾选，则差旅费报销单（2019新政）单据受差旅标准的控制，保存时会校验是否超标                                                                                                                                          |
| :::      | 差旅标准控制提示且填写超标说明/严格控制                                                   || 选择提示且填写超标说明，则超标时进行提示且要求填写超标说明，单据方可保存；选择严格控制，则只要超标单据就不允许保存。                                                                                                                       |
| 收票选项     | 收票业务组织设置费用承担组织/申请组织/付款组织                                               ||选择哪个组织，收票相关纳税人识别号等的校验都根据这个组织来。                                                                                                                                                   |
| 核销参数     | 费用报销特殊业务核销允许的金额差异范围从（）到（）                                              ||用于控制费用报销手工核销中手工特殊核销的金额差异范围。                                                                                                                                                      |
**掌上报销参数说明**：
| **参数**                        || **说明**                                                                                                                                                                           |
| 移动端选项：使用旧版掌上报销                || 用于掌上报销轻应用。控制是否使用旧版掌上报销轻应用（V2.0）。                                                                                                                                                 |
| 移动端选项：上传原图附件                  || 用于掌上报销轻应用。控制用户上传的附件是否保存为原图。                                                                                                                                                      |
| 移动端选项：批量下推                    || 用于掌上报销轻应用。启用后可支持同时选择多张单据进行下推。                                                                                                                                                    |
| 移动端选项：新增时不删除默认分录行             || 用于掌上报销轻应用。控制新增单据时是否需要保留系统默认的新分录行。                                                                                                                                                |
| 移动端选项：出差申请报销规则                || 用于掌上报销轻应用。控制出差申请单下推到下游单据时的规则。                                                                                                                                                    |
| 移动端选项：不显示发票入口                 || 用于掌上报销轻应用。启用后会将智能收票的“发票新增”和选择发票的入口隐藏。                                                                                                                                            |
