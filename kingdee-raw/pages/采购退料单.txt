====== 1功能概述 ======


供应商的货物经过检验不合格或生产过程发现的不合格需要退给供应商，退料单就是记录退料信息的业务单据。详细业务说明参见采购退料业务。

====== 2使用前提 ======


  - 定义单据类型、供应商、业务组织、币别、物料、单位、仓库、仓位等基础资料 
  - 按实际采购业务设置采购参数 
  - 如果进行批号、序列号管理，还要设置批号规则和序列号规则
====== 3功能路径 ======


【供应链】－>【采购管理】－>【退料处理】－>【采购退料单】

====== 5操作说明 ======


  - 退料单单据状态说明，请参考单据状态通用说明
  - 退料单只有作废与反作废一种整单单据操作

作废操作类似于采购申请单，这边就不复述，请参考采购申请单

====== 6业务说明 ======


===== 6.1库存查询 =====
 
退料单上支持库存查询功能，直接调用库存数据，具体库存查询的规则同采购申请单，请参考[[采购申请单]]

===== 6.2补货处理 =====
 
退料单支持补货处理，补货规则同退料申请单，请参考[[退料申请单]]

===== 6.3即时库存更新 =====
 
退料单会按照库存参数【库存更新方式】影响库存数据，规则如下

  - 退料单【库存状态】字段为空时不更新库存，不为空时更新库存 
  - 退料单更新库存量以【实退数量】为准 
  - 保存、反作废、审核时扣减库存，删除、作废、反审核时增加库存，具体以【库存更新方式】为准 
===== 6.4退料单批号相关业务 =====

退料单行操作菜单上提供批号相关操作，有以下二种

  - 批号库存，以批号为维度查询物料库存 
  - 批号主档，查询当前物料的批号主档
===== 6.5退料单单据转换 =====
 
退料单可以直接下推采购订单，也可以在采购订单界面选单退料单生成采购订单，实现关联业务的转化，转化的规则如下：

  - 单据状态为“已审核”，【补料方式】为“创建订单补货”且【补料数量】大于【关联数量】的退料单才能转换采购订单   
  - 在采购订单界面选单时，可选择的退料单列表界面默认只过滤出符合上面条件的退料单 
  - 选择多张退料单合并生成采购订单时，供应商、退料组织、采购组织、结算币别相同的分录才能合并到一张采购订单上  
  - 退料单下推采购订单时，退料单的字段关联携带到采购订单上 
  - 采购订单的【数量】不能大于【补料数量】-【关联数量】，否则采购订单无法保存、反作废 
  - 采购订单保存、反作废时，累计反写退料单【关联数量】，作废以及删除时需要相应扣减数量

====== 7供应商协同平台 ======


===== 7.1功能说明 =====

  - 企业的采购退货单审核后，供应商可以在供应商协同中查询。
  - 供应商可以对采购退料单进行确认。
  - 对数据进行严格过滤，仅显示该供应商的采购退料单。

===== 7.2功能操作 =====

  - 供应商登录供应商协同平台，进入 供应商协同—交货协同—采购退料单，设置过滤条件，查询相关数据。
  - 供应商可以对采购退料单进行确认。
===== 7.3业务说明 =====

  - 通过供应商对采购退货单的确认操作，来明确供应商确实已收到采购退货单。
  - 供应商及时了解采购退货情况，便于财务核算和对账。
