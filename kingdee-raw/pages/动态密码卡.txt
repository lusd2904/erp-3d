====== 1 功能描述 ====== 
安全管理中提供了动态密码卡，主要为了进一步加强用户密码的管理，以避免用户静态密码被攻破或盗用的危险。

**系统特性**
  - 通过动态密码卡获取动态密码，对用户密码更有安全保障，降低被攻破的风险； 
  - 一人一卡实现一对一的管理； 
  - 动态密码卡的应用加强登录系统的管理，特别是互联网上的应用保障； 
  - 动态密码卡的校验集成到金蝶云产品，无需单独安装和配置。

**使用前提**
  - 购买了动态密码卡；
  - 购买动态密码卡的许可（无站点控制）；
  - 获取动态密码卡的引入文件（向供应商索取，EXCEL格式）。

**功能路径**
【系统管理】→【系统管理】 →【动态密码卡管理】

 ====== 2 功能操作 ======
  - 引入：引入动态密码卡文件，引入时会校验文件合法性，如果不合法则不能引入； 
  - 删除：可以对所选动态密码卡记录进行删除，若动态密码卡已绑定用户，则不能删除，需要先取消绑定用户再执行删除；允许批量删除动态密码卡；
  - 禁用和反禁用：1）可以对动态密码卡进行禁用和反禁用；2）若用户已绑定了动态密码卡，禁用动态密码卡后，该用户不能使用这个动态密码卡登陆金蝶云系统；3）动态密码禁用后，可以取消绑定，但不能绑定用户；4）允许批量禁用和反禁用动态密码卡；
  - 绑定用户：对用户绑定动态密码卡，已经绑定了动态密码卡的用户不能重复绑定； 
  - 取消绑定：对动态密码卡取消绑定用户，若动态密码卡已绑定用户，则不能重复绑定，需先取消绑定用户；允许批量取消绑定动态密码卡； 
  - 同步时间：用来同步处理动态密码卡与其服务器的时间，以避免出现时间差的情况造成密码不一致； 
  - 引出：可以按列表引出动态密码卡。 

====== 3 操作流程 ======
===== 3.1 购买许可和动态密码卡 =====
  - 需要先向金蝶软件有限公司订购金蝶云的动态密码卡许可和动态密码卡，金蝶软件有限公司接到订购信息后，将动态密码卡的引入文件发给客户；
  - 金蝶云动态密码认证许可（特性许可，无站点数控制）；
  - 动态密码卡是按每个卡独立收费，且需要每个用户对应一个密码卡。
 
===== 3.2 确定使用范围 =====
  - 需要确定使用动态密码的数据中心；
  - 需要确定哪些用户使用动态密码卡。 

===== 3.3 启用动态密码卡 =====
   - 登录管理中心，选择数据中心启用动态密码身份认证方式。
  - 选择【设置】→【认证方式】，打开认证方式界面，针对所选的数据中心启用“动态密码身份”。
  - 启用后，用户登录界面即会显示“动态密码身份”的认证方式。

===== 3.4 引入动态密码卡 =====
   - 系统管理员在数据中心中引入动态密码卡；
  - Administrator用户登录金蝶云，选择【基础管理】→【系统管理】 →【动态密码卡管理】→【动态密码卡】；
  - 在动态密码卡列表，将获取的动态密码卡的引入文件引入。

===== 3.5 绑定用户 =====
 需对每个动态密码卡绑定用户，有两种设置方式：

==== 3.5.1 直接绑定用户 ====
动态密码卡引入后，在列表中选择未绑定用户的动态密码卡记录，然后点击【绑定用户】，F8选择需要绑定的用户。

==== 3.5.2 用户选择 ====
  - 用户直接选择动态密码卡，打开用户界面，在“个人信息”页签中，选择动态密码卡，点击用户【保存】按钮，即完成用户的动态密码卡设置。
  - 可以手工删除动态密码卡的内容，保存用户后，则取消了用户的动态密码卡设置。

===== 3.6 应用动态密码登陆系统 =====
  - 用户登录时，选择认证身份=动态密码卡，使用动态密码卡获取动态密码，输入动态密码，金蝶云校验通过后即可登陆系统。
  - 密码在使用过一次后就失效，下次登录时的再次获取新密码，以确保密码安全。

===== 3.7 限制使用动态密码 =====
  - 默认情况下，启用动态密码卡的数据中心中，绑定动态密码卡的用户都可以使用动态密码卡登录。
  - 若需要特别限制某些用户的登录，也可以在用户列表中，选择一个或多个用户，通过【业务操作】—【设置认证方式】，取消勾选“动态密码卡身份”，来限制某一或某些用户使用其他登录方式登录金蝶云系统，实现不同用户的不同控制。
