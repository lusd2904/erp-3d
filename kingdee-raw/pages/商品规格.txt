ID: 商品规格
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E8%A7%84%E6%A0%BC

**功能说明：**

根据商品的一些特殊属性，设定不同的商品规格

**功能路径：**

【商品】->【商品规格】

**使用前提：**

无

**字段说明：**

| **名称**    | **字段取数说明**                                |
| 规格编码      | 根据编码规则自动生成                                |
| 规格名称      | 手工填写                                      |
| 前台展示类型    | 文字/图片，手工选择                                |
| 描述        | 手工填写                                      |
| ERP辅助属性   | 用于将商品规则与ERP辅助属性建立对应关系                     |
| 启用状态      | 勾选\未勾选，默认为勾选启用状态                          |
| 规格值名称     | 手工填写                                      |
| 规格别名      | 手工填写                                      |
| ERP辅助属性值  | 用于将规格明细与ERP辅助属性值列表建立对应关系                  |
| 关联图片      | 手工添加                                      |
|           |                                           |
| 操作        | 允许进行新增、修改、删除、启用、禁用、导出模板、导出数据、导入、刷新、搜索等操作  |

**操作说明：**

  - 点击【新增】按钮弹出编辑页面，录入名称，描述、选择前台展示类型，启用状态默认为是；
  - 点击【新增行】，录入规格值名称、规格别名，点击【选择图片】上传规格图片；
  - 点击【保存】按钮，系统自动生成编码，新增一条商品规格信息；
  - 点击【导出模板】按钮，自动导出商品规格的模板；
  - 点击【导入】按钮，选择导入文件，导入商品规格信息；
  - 点击【导出数据】按钮，导出所选商品规格信息
  * 修改：双击商品规格，进入详细信息页面，修改保存相关数据
  * 删除：选择相应规格，点击【删除】按钮，删除此行
  * 搜索：输入规格名称或编码进行搜索
