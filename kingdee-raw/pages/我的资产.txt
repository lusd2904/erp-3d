====== 我的资产列表 ======


====== 1 功能概述  ======

资产卡片实物信息“保管人”为当前用户关联员工的资产明细，一个资产编码一条明细。

支持列表界面选择资产明细新增资产退转单、处置申请单。

====== 2 操作前提  ======

  - 有人人资产工作台查看权限。

====== 3 功能路径  ======

【员工服务】-->【人人资产】-->【我的资产工作台】-->【人人资产工作台】


 ====== 3 主要字段说明 ======

| **字段**     || **说明**                                                                       |
| 资产编码       || 已审核未处置的资产卡片，资产卡片-实物信息：“数量”>0且“保管人”为当前员工的资产编码。                                |
| 资产名称       || 资产编码对应的资产卡片-基本信息：“资产名称”值。                                                    |
| 资产类别       || 资产编码对应的资产卡片-基本信息：“资产类别”值。                                                    |
| 规格型号       || 资产卡片-实物信息：资产编码对应的“规格型号”值。                                                    |
| 数量         || 资产卡片-实物信息：资产编码对应的“数量”值。                                                      |
| 计量单位       || 资产编码对应的资产卡片-基本信息：“计量单位”值。                                                    |
| 保管人        || 当前用户对应的员工。                                                                   |
| 资产位置       || 资产卡片-实物信息：资产编码对应的“资产位置”值。                                                    |
| 条形码        || 资产卡片-实物信息：资产编码对应的“条形码”值。                                                     |
| 货主组织       || 资产编码对应的资产卡片-基本信息：“货主组织”值。                                                    |
| 资产组织       || 资产编码对应的资产卡片-基本信息：“资产组织”值。                                                    |
| 卡片编码       || 资产编码对应的资产卡片-基本信息：“卡片编码”值。                                                    |
| 个人资产状态     || 列表枚举值：使用中、转移中、退库中、处置中。员工领用后为使用中，存在未完成转移单为转移中，存在未完成退库单为退库中，存在处置申请且资产处置前为处置中。  |

====== 4 操作说明 ======

1、人人资产工作台-我的资产，资产卡片上：

点击转移，携带卡片资产信息打开资产退转单新增界面，单据类型为人人资产转移单。

点击退库，携带卡片资产信息打开资产退转单新增界面，单据类型为人人资产退库单。

点击处置，携带卡片资产信息打开处置申请单新增界面。

2、我的资产列表，选择“个人资产状态”为使用中的资产，点击转移、退库、处置功能进行相应新增操作。

====== 5 特殊说明 ======

  - 【资产管理】-->【固定资产】-->【资产卡片】列表，提供“变更”保管人功能，只有全部领用（可领用数量=0）或全部未领用的资产编码允许变更保管人，变更后，“个人资产状态”为使用中，保管人个人资产列表可查询。
  - 全部未领用的资产编码变更保管人后，自动更新为全部领用（可领用数量=0）。
  - “个人资产状态”值为使用中的资产，允许进行转移、退库、处置操作。
  - “个人资产状态”值为转移中、退库中、处置中的资产，不允许进行转移、退库、处置操作。
