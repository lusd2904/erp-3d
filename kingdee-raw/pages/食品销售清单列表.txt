====== 1.食品销售清单 ======

===== 1.1 功能说明 =====

食品销售清单是反应门店食品的销售情况的列表，可以通过数据交换销售报数，食品销售清单接口，以及POS账单接口上传自动生成。食品销量清单是销量预测计算助手的原始数据来源。食品销售清单单据类型包括员工清单和食品销售清单，类型分为正常单和取消单。

===== 1.2 字段说明 =====
^ 字段名称  ^ 字段说明                                                 ^
| 单据类型  | 分为食品销售清单以及员工餐清单                                      |
| 数据来源  | POS账单生成、接口生成、POS上传，手工录入                              |
| 类型    | 正常单与取消单                                              |
| 是否清机  | 如果勾选，表示已经清机，默认勾选                                     |
| 下推    | 下游单据为食品材料耗用单                                         |
| 更新数据  | 需要根据不同的POS账单类型生成食品销售清单。员工餐的生成员工餐清单，其他非员工餐的，生成食品销售清单  |

===== 1.3 业务说明 =====
  * 食品销售清单生成时，先去判断该食品是否有对应的食品成本卡，如有默认的食品成本卡，则根据默认的食品成本卡展开物料。                                                     
  * 如未找到默认的食品成本卡，则判断该食品是否是由物料转为食品的，如是，则去找对应的物料展开，食品的销售数量，则是物料的用量。		
  * 食品销售清单列表排序规则改为营业日期+单据编号排序
  * 上传食品销售清单中加入出品取消数量	
  * POS账单上传时，每次上传成功后，将数据形成一个数据包，调用更新数据功能，将POS账单数据汇总合并生成食品销售清单。同步生成，并返回生成结果消息。POS账单反审核时，校验是否生成食品销售清单。若已生成时，不可反审核。提示：已生成食品销售清单，请先删除食品销售清单！手工删除食品销售清单及POS账单时，控制必须删除当日所有POS账单和食品销售清单。当删除食品销售清单时，同时删除与POS账单的关联标识			
  * POS账单生成食品销售清单按账单类型分单。类型为员工餐的，生成单据类型为员工餐的食品销售清单。其他类型的POS账单，全部生成单据类型为食品销售清单
  * 食品销售清单列表中，点击更新数据时，需要根据不同的POS账单类型生成食品销售清单。员工餐的生成员工餐清单，其他非员工餐的，生成食品销售清单			
  * POS账单生成食品销售清单按类型分单。正数合并生成类型为正常单。负数合并生成类型为取消单。但是招待、出品取消的，按照正常单生成。  
  * 食品销售清单列表上，更新数据之后，食品销售清单数量与POS账单不一致。原因是客户存在出品取消的单，而食品销售清单未考虑出品取消   

===== 1.4 委托扣库 =====

1.管理员登录后台系统，在组织业务关系中设置委托扣库（销售-扣库)-受托扣库（扣库-销售）

{{::委托扣库.png?400|}}

2.食品销售清单/食品报损单生成食品材料耗用单时，发料组织根据组织业务关系获取
              
  * 普通列表项目数字列表项目没有设置业务委托关系：材料出库时，默认发料组织与出品组织/报损组织一致，发料仓取出品部绑定的部门仓库，无论仓库是否设置了对应组织，都获取出品部绑定的仓库

  * 设置了业务委托关系，仓库设置了对应组织：则出品组织/报损组织为食品销售组织，发料组织为 受托扣库的组织；仓库获取出品组织与仓库对应组织一致的仓库

  * 设置了业务委托关系，仓库未设置对应组织：则出品组织/食品报损组织为食品销售组织，发料组织为受托扣库的组织；仓库获取发料组织下的物料的默认仓库，若物料未设置仓库，不允许下推
