====== 1.配送费计算规则 ======
===== 1.1 功能概述 =====
  * 功能界面定位：餐饮配送与加工总部配送管理基础资料配送费计算规则
  * 设置配送方式选择门店配送时，配送费的计算规则
  * 设置标准收费数量为2，单位为kg,收费金额为10，每续件1，加收金额为3，则表示该订单的重量小于等 2kg时10元，每超过1kg，则加收 3元
===== 1.2 字段说明 =====
	^          ^                             ^
| 生效日期     | 自行选择日期                      |
| 失效日期     | 自行选择日期，但是失效日期必须大于等于生效日期     |
| 标准收费数量   | 数值型                         |
| 标准单位     | 从计量单位列表中选择                  |
| 标准收费金额   | 数值型                         |
| 每续件      | 超出标准收费数量的配送件                |
| 加收金额     | 超出标准收费数量加收金额                |
| 规则-生效日期  | 默认取单据头的日期，日期范围不可大于单据头的日期范围  |
