ID: 下游退货管理
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%8B%E6%B8%B8%E9%80%80%E8%B4%A7%E7%AE%A1%E7%90%86

**功能说明：**

退货管理用于用户已经收货后的退货以及历史退货记录查询，及
上级渠道对下级渠道的退货处理等。

**功能路径：**

【退货】->【下游退货管理】

**使用前提：**

当前登录的渠道具有下级渠道

**字段说明：**
| **名称**  | **字段说明**            |
| 表头                           ||
| 申请单编号   | 退货申请单单据编码，系统自动生成    |
| 申请单日期   | 退货申请单的单据日期          |
| 单据状态    | 显示当前退货申请单的单据状态      |
| 签收状态    | 显示当前退货申请单的签收状态      |
| 表明细                          ||
| 商品编码    | 显示商品编码+商品名称+商品规格型号  |
| 订单数量    | 退货申请单对应的订单的商品订货数量   |
| 已签收数量   | 上级渠道累计退货入库数量        |
| 已退数量    | 下级渠道累计退货出库数量        |
| 申请退货数量  | 退货单申请退货数量           |
| 实际价格    | 退货商品对应的实际销售单价       |
| 价税合计    | 退货商品对应的实际价税合计       |
| 签收状态    | 退货签收状态，与订单的签收状态类似   |

**操作说明：**

1、进入下游退货管理，根据需要选择处理不同的订单
  * 所有退货申请：显示所有供货方类型为渠道且供应方为当前登录渠道的退货申请单。只允许查看；
  * 待审核：显示所有供货方类型为渠道、供应方为当前登录渠道且退货申请单的单据状态为提交状态的退货申请单。允许审核、打回、刷新操作；
  * 待入库：显示所有供货方类型为渠道、供应方为当前登录渠道且下游渠道已发货而未签收的退货申请单。允许退货入库、刷新操作；
2、勾选对应的订单进行处理，当退货申请单的单据状态为已完成时，则表示退货申请已完成。
