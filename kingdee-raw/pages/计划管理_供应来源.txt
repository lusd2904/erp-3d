======1 供应来源======
=====1.1 功能概述=====
在企业运作过程中，某些产品或中间件会不同的方式进行供应。通过定义物料的供应来源，计划员可以在计划运算时直接得到不同投放类型的计划订单而不再需要手工维护计划订单。

=====1.2 使用前提=====

  * 定义【物料】
  * 定义【组织业务关系】  

=====1.3 功能路径=====

 进入【生产制造】—>【计划管理】—>【基础数据】—>【供应来源】

======2. 字段说明======

=====2.1 常规页签===== 

|  **字段**  |  **说明**                       |
|  编码      | 1、供应来源的编码                     |
|  名称      | 1、供应来源的名称                     |
|  生效日期    | 1、供应来源的生效日期                   |
|  失效日期    | 1、供应来源的失效日期\\ 2、失效日期不得小于生效日期  |
|  需求组织    | 1、供应来源需求的产生组织                 |

=====2.2 阶梯设置=====
|  **字段**  |  **说明**                                                                                                                                         |
|  供应组织    | 1、供应组织为具有采购或生产职能的组织\\ 2、供应组织必须与需求组织存在组织委托关系 \\ 3、供应组织不可重复                                                                                       |
|  供应比例    | 1、百分数显示；\\ 2、所有行供应比例之和为100%                                                                                                                     |
|  生产比例    | 1、百分数显示；\\ 2、同一行生产比例、采购比例、委外比例之和为100%                                                                                                           |
|  采购比例    | 1、百分数显示；\\ 2、同一行生产比例、采购比例、委外比例之和为100%                                                                                                           |
|  委外比例    | 1、百分数显示；\\ 2、同一行生产比例、采购比例、委外比例之和为100%                                                                                                           |
|  供应规则    | 1、选择供应组织后可以维护\\ 2、需求组织与供应来源相同时不可维护\\ 3、需求组织不具有库存职能时，用户选择跨组织入库后提示“需求组织不具有库存职能，不可选择跨组织入库”；\\ 4、供应组织不具有库存职能时，用户选择跨组织领料后提示“供应组织不具有库存职能，不可选择跨组织领料”；  |
|  货主规则    | 1、选择供应组织后可以维护\\ 2、决定货主的取值；  |


======3. 操作说明======


**指派** 

点击指派按钮，在弹出窗口中可以选择物料，返回后会将当前供应来源指派给选择的物料。
