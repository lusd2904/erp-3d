**功能概述**

用于查询生产订单工时完成情况。

**路径**

进入【生产制造】—>【车间管理】—>【报表分析】—>【生产订单工时对比分析表】

**字段说明**

| **字段**     || **说明**                                                                                   |
| 生产组织       || 生产订单的生产组织                                                                                |
| 下达日期       || 生产订单下达日期                                                                                 |
| 生产订单       || 生产订单号                                                                                    |
| 订单行号       || 生产订单行号                                                                                   |
| 产线         || 生产订单产线                                                                                   |
| 物料编码       || 生产订单物料                                                                                   |
| 物料名称       || 物料名称                                                                                     |
| 规格型号       || 规格型号                                                                                     |
| 单位         || 生产物料基本单位                                                                                 |
| 订单数量       || 生产订单基本单位数量                                                                               |
| 工序号        || 工序计划工序号    PT141347补丁开始提供                                                                |
| 序列号        || 工序计划序列号      PT141347补丁开始提供                                                              |
| 作业         || 工序计划作业                                                                                   |
| 实际完工数量     || 按订单、分录、作业分组：sum(工序计划的合格)                                                                 |
| 工单定额       || 1、按订单、分录、作业分组：\\ 2、sum(（工序计划.加工活动.基本量）*实际完工数量+工序计划.准备活动.基本量+工序计划.拆卸活动.基本量) \\ 3、按分钟显示换算  |
| 工单实际       || 1、按订单、分录、作业分组：\\ 2、sum(工序计划.加工活动.已汇报量+工序计划.拆卸活动.已汇报量+工序计划.准备活动.已汇报量)\\ 3、按分钟显示换算         |
| 时间单位       || 分钟                                                                                       |
