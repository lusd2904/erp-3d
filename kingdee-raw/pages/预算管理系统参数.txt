**功能描述**

预算管理系统相关的系统参数设置。

目前版本仅**系统管理员用户登录**才可进行预算管理系统参数设置。

路径【基础管理】-【公共设置】-【参数设置】-【参数设置】：预算管理节点。

**功能路径**

【系统管理】-【参数设置】-【参数设置】

**参数说明**
^  **参数**                              |^  **说明**                                                                                                                                                                                                                                                                                                                                                                          ^
| 预算控制参数   | 启用预算控制                     | 对【数据中心】启用预算控制。系统默认未启用。启用后，相关单据才可受预算控制检查。                                                                                                                                                                                                                                                                                                                                         |
| :::      | 对审核中的单据保存，使用提交是的控制强度       | 未选中，采用保存时的控制强度。选中，则使用提交时的控制强度。\\ **应用场景**\\ 受控单据在审批流、工作流中，审核人因需修改了单据，此刻的单据保存是根据提交时的控制强度，还是保存时的控制强度。                                                                                                                                                                                                                                                                              |
| :::      | 预算控制单据列表                   | **本列表仅提供查询，无需用户编辑**。\\ 如需更新，需在预算控制规则中操作。\\ 只有在启用预算控制的前提下，在预算控制规则审核（反审核）时，系统自动更新单据控制列表。                                                                                                                                                                                                                                                                                           |
| 预算编制参数   | 在工作流/审批流中，允许审批人修改预算报表      | 在审批人在处理工作流/审批流任务时，允许该审批人直接打开预算报表并根据实际需要修改预算数。                                                                                                                                                                                                                                                                                                                                    |
| :::      | 报表保存时自动导出并上传为附件            | 该功能主要用于预算表的移动端审批。\\ 勾选时，预算报表保存完成，系统自动将当前报表引出并上传到附件管理。\\ excel交叉表格式：与预算报表展现一致，所见即所得。可增加显示取数公式列和备注列。\\ excel列表格式：该格式等同于预算报表客户端中的“按引入模板引出excel”。即引出内容中，包含取数公式列和备注列。\\ excel默认格式：控件自带引出，与预算报表展现一致，所见即所得。无法显示取数公式以及备注。\\ pdf格式：该格式等同于预算报表客户端中的“引出PDF格式”。                                                                                                                              |
| :::      | 已分发预算表未完编，仍允许预算组织切换到执行中状态  | 勾选后，在预算方案监控中，系统将不再检查预算组织下需要编制的预算表是否完编，即，预算表即使未编制，或者未完编，仍然可以切换期间到执行中状态。\\ **应用场景1**：项目预算，第一年即完成该项目的总体预算编制。以后年度不在需要编制。\\ **应用场景2**：费用预算已完编，但采购预算由于其他原因一直未能完成编制，为保证企业日常业务的正常运行，需要将预算组织切换到执行状态。\\ **特殊说明**\\ 在勾选本选项的前提下，允许在已执行期间，对已创建的预算表进行正向操作（保存、提交、审核）。                                                                                                                           |
| :::      | 非周期性预算汇总表提交后，禁止反审核预算报表     | 为保证预算汇总表的数据与取数来源预算表数据的一致性。\\ 勾选该选项，预算汇总表提交后，禁止该汇总表取数来源预算表反审核操作。                                                                                                                                                                                                                                                                                                                  |
| :::      | 周期性预算汇总表提交后，禁止反审核预算报表      | 为保证预算汇总表的数据与取数来源预算表数据的一致性。\\ 勾选该选项，预算汇总表提交后，禁止该汇总表取数来源预算表反审核操作。                                                                                                                                                                                                                                                                                                                  |
| :::      | 选项：HTML5模式下，启用在线报表编辑       | 预算管理的在线报表编辑，基于葡萄城提供的Spread JS纯前端表格控件搭建。\\ 由于控件提供商（葡萄城）的要求和约束，目前仅公有云租户、以及192.*或172.*开头的星空用户，均可直接启用在线报表编辑（原因：公有云客户域名相同*. ik3cloud.com，192.*或172.*，其相关许可已由我们在研发阶段申请，并预置到标准产品出厂）。\\ 私有云客户，如有在线编辑的需求，请及时联系金蝶客服或者直接KSM提单（需求类），提供企业名称、企业金蝶AI星空的访问**域名**（务必提供域名地址，而非IP地址）、许可文件的接收邮箱，以进行控件许可的申请。                                                                                           |
| :::      | 启用多窗口打开预算报表                | 勾选时，每打开一个报表，即打开一个预算报表客户端。                                                                                                                                                                                                                                                                                                                                                        |
| 预算调整参数   | 预算维度组合仅来源于预算报表             | 勾选时，预算调整单、预算调剂单能够调整的维度值组合，仅允许调整预算报表中存在的维度值组合。\\ 多用于权责管控严格的企业。\\ （建议配合维度值填充功能权限使用）                                                                                                                                                                                                                                                                                                |
| :::      | 调整、调剂，启用预算控制检查             | 勾选时，调整、调剂受预算控制约束。包括：调整单、调剂单、调整表。\\ 如：调整后的预算数 不能小于 已实际发生数。                                                                                                                                                                                                                                                                                                                        |
| :::      | 创建的调整表，保留原预算表的金蝶取数公式       | 勾选时，即基于预算表创建的预算调整表中，保留原预算表中的金蝶公式。\\ **应用场景**\\ 销售费用预算表中，通过BGDATA公式取了销售预算中的数据，则说明在对销售预算进行调整的时候，应该影响和相应去调整销售费用预算表。此时，建议保留单元格BGDATA公式。以便在对销售预算调整后，系统可以自动通过取数公式获取最新的销售费用预算数。\\ 不勾选时，即基于预算表创建的预算调整表中，由系统自动清除单元格中的金蝶公式（单元格取数源于纯金蝶公式）。\\ **应用场景**\\ 预算表中，通过BGDATA或者SJDATA或者ACCT公式取了上年预算数或者上年实际数，作为本年预算编制的初始数据。即本年预算数，默认情况下直接取的是上年预算数或者实际数。在编制时，在该初始数据的基础上，根据今年实际需求修改。此时，不应保留单元格金蝶取数公式。  |
| :::      | 编辑留痕，默认背景色                 | 在预算调整表中，以设置的指定背景色亮显被编辑的单元格。                                                                                                                                                                                                                                                                                                                                                      |
| 历史版本参数   | 已作废：预算控制提示不显示使用详情          | 选中时，受控单据上的预算控制提示将不再显示预算使用详情。\\ 一般用于，企业不希望普通员工了解预算编制详情。                                                                                                                                                                                                                                                                                                                           |
| :::      | 已作废：SJdata函数取数来源于：预算执行分析   | *版本过度临时参数*\\ 勾选时，SJdata取数来源于预算执行分析表。\\ 勾选时，除支持原SJdata取数逻辑外，还支持任意第三方本位币的换算。                                                                                                                                                                                                                                                                                                       |
