====== 其他请检单 ======

其他请检单，适用于其他检验物料，比如零星的杂项的物料的检验申请。

特别是针对需要启用序列号检验的其他检验物料需要通过其他请检单录入序列号，携带到检验单。


**使用前提**

物料-质量页签下，【其他检验】勾选；


**功能路径**

【质量管理】－>【质量管理】－>【其他请检单】

**字段说明**

  *  表头

| **字段**     || **说明**                                                             |
| 单据类型       || 其他请检单的单据类型；\\ 系统预设有：其他请检单                                          |
| 单据日期       || 制作请检单的日期，新增时，默认显示当前系统日期；\\ 用户可对日期进行修改。                             |
| 申请组织       || 基础资料组织，默认取当前组织；已审核未禁用的组织                                           |
| 部门         || 已审核未禁用的部门，且部门使用组织等于录入的申请组织                                         |
| 仓管员        || 基础资料业务员，定义为仓管员的业务员。                                                |
| 库存组        || 基础资料业务组，业务组类型为“库存组”的业务组                                            |
| 单据状态       || 由系统根据单据操作自动标识\\ 暂存：暂存；\\ 保存：创建；\\ 提交：审核中；\\ 审核通过：已审核；\\ 反审核：重新审核。  |

  * 明细页签

| **字段**     || **说明**                                                                                       |
| 序号         || 由系统按分录顺序递增显示1、2、3…，为自动生成，锁定                                                                  |
| 物料编码       || 物料编码可选择申请组织下【其他检验】勾选的物料                                                                      |
| 物料名称       || 根据物料编码携带其物料名称                                                                                |
| 规格型号       || 根据物料编码携带其规格型号                                                                                |
| 单位         || 1、计量单位中与物料的基本单位存在固定换算关系的计量单位；\\ 2、物料的单位换算中与物料的基本单位存在固定换算关系的计量单位；\\ 3、计量单位已审核，非禁用，默认为物料的库存单位  |
| 数量         || 请检数量，取单位精度；                                                                                  |
| 仓库         || 请检物料所在的仓库；                                                                                   |
| 仓位         || 仓库启用仓位管理时，仓位才需要维护且必录。                                                                        |
| 批号         || 1、可手工录入，物料启用批号管理时，可录入，可从批号主档返回；\\ 2、可通过库存查询返回                                                |
| 需要检验       || 携带物料其他检验的值                                                                                   |




  * 库存页签

| **字段**      || **说明**                                                                                 |
| BOM版本       || 物料在库存属性控制中启用了“BOM版本”，该字段可维护且必录。\\ 否则，灰显不可维护。 可选择物料对应的审核状态的ＢＯＭ版本；                       |
| 辅助属性        || 启用辅助属性的物料，可以录入辅助属性值；                                                                   |
| 保质期单位       || 携带物料中的保质期单位                                                                            |
| 保质期         || 携带物料中的保质期                                                                              |
| 货主类型        || 1.修改货主类型时，影响货主字段；\\ 2.取值范围：组织、供应商、客户。                                                  |
| 货主          || 货主为物料所有权的持有者；\\ 1.货主类型为业务组织时，货主取业务组织；\\ 2.货主类型为供应商时，货主取供应商；\\ 3.货主类型为客户时，货主取客户。        |
| 保管者类型       || 物料的保管者的类型，包含供应商、业务组织和客户                                                                |
| 保管者         || 保管者为物品保管权的所有者\\ 1.保管者类型为业务组织时，保管者取业务组织：\\ 2.保管者类型为供应商时，保管者取供应商；\\ 3.保管者类型为客户时，保管者取客户。  |
| 生产日期        || 生产日期修改，自动更新有效期至=生产日期+保质期（按天计算）                                                         |
| 有效期至        || 启用保质期管理的物料，该字段可维护；生产日期<有效期至<=生产日期+保质期（按天计算）                                            |
| 计划跟踪号       || 物料计划策略为MTO，可编辑，否则不可编辑                                                                  |

  * 执行页签

|**字段**||**说明**|
|检验选单数量||关联检验单的数量|
|检验数量||完成检验的数量|
