=====阿米巴核算维度利润表过滤条件 ======
在“快捷”页签，用户选择需要查询的经营账簿、经营科目、会计期间、起始日期、结束日期基本过滤条件。其他过滤页签为系统通用设置，可设置字段列的显示隐藏属性。

快捷页签主要过滤项目说明 

| **过滤项**   | **说明**                         |
| 经营账簿      | 选择查询哪个经营账簿，单选。                 |
| 经营科目      | 选择需要查询的资金经营科目，多选。              |
| 开始期间      | 选择需要查询的开始期间。                   |
| 结束期间      | 选择需要查询的结束期间。                   |
| 开始日期      | 如果不按期间查询，可以选择任意开始日期。           |
| 结束日期      | 如果不按期间查询，可以选择任意结束日期。           |
| 核算维度组合    | 选择需要查询的核算维度。                   |
| 核算维度显示设置  | 可选名称、编码、编码+名称                  |
| 按期间分组显示   | 勾选时按期间汇总分组显示，不勾选时按查询时间全部汇总显示。  |
