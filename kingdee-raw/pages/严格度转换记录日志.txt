====== 严格度转换记录日志 ======

**功能描述**



严格度转换日志记录用来统计物料来源质检规则的严格度转换记录。可根据物料和供应商查找转换记录。


**过滤条件**


“快捷”页签：快捷页签为报表常用过滤条件的设置界面。

“显示隐藏列”页签：设置报表显示什么字段及显示顺序。


**快捷**


^       ^                               ^
| 字段    | 说明                            |
| 查询组织  | 物料来源质检规则的使用组织（检验单的质检组织）       |
| 转换日期  | 1、严格度转换计算的日期  2、起始日期不能大于截止日期  |
| 物料    | 基础资料物料（审核未禁用），支持多选            |
| 供应商   | 基础资料供应商（审核未禁用），支持多选           |

**报表字段**

报表表体字段：

^          ^                          ^
| 字段       | 说明                       |
| 本次转换记录数  | 本次严格度计算满足转换条件的转换记录数量     |
| 转换日期     | 严格度转换计算日期                |
| 组织       | 物料来源质检规则的使用组织（检验单的质检组织）  |
| 供应商      | 物料来源质检规则的供应商             |
| 物料编码     | 物料来源质检规则的物料编码            |
| 物料名称     | 物料来源质检规则的物料规格型号          |
| 转换前严格度   | 转换前的严格度                  |
| 转换后严格度   | 转换后的严格度                  |
| 计算检验单编号  | 本次严格度转换计算包含的检验单编号        |
