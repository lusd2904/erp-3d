======1  生产领料差异汇总表=======
=====1.1 报表功能=====

1.生产领料差异汇总表能够使用户能及时地了解，生产中各子项物料在任意车间或者任意生产订单之中的整体领料情况。

2.生产领料差异汇总表支持按照物料/车间/物料种类等多维度，查询物料的领用情况的。

======2. 字段说明======
=====2.1 快捷过滤 =====

^  **字段**  ^  **说明**                                              ^
|  生产组织    | 1.定义报表查询的组织范围；\\ 2.必须具有生产职能，有且只能录入一个组织。              |
|  计划开工日期  | 1.生产订单分录行的计划开工日期；\\ 2.定义报表查询的计划开工日期范围。               |
|  计划完工日期  | 1.生产订单分录行的计划完工日期；\\ 2.定义报表查询的计划完工日期范围。               |
|  生产车间    | 1.生产订单的表体分录的生产车间；\\ 2.定义报表查询的生产车间范围。                 |
|  生产订单    | 1.生产订单的单据编号；\\ 2.定义报表查询的生产订单范围。                      |
|  产品编码    | 1.生产订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。                   |
|  物料编码    | 1.进行生产加工的子项物料的编码；\\ 2.定义报表查询的产品编码范围。                 |
|  物料控制项   | 1.用于确定报表中进行领料套数计算的物料范围；\\ 2.包含：所有物料、非倒冲物料、关键物料三个选项。  |
|  倒冲类型    | 1.用于确定报表中倒冲物料的统计范围；\\ 2.包含：开工时倒冲、汇报时倒冲、入库时倒冲三个选项。    |
|  单据类型    | 1.生产订单的单据类型；\\ 2.定义报表查询的生产订单的单据类型。                   |
|  业务状态    | 1.生产订单分录行的业务状态；\\ 2.包含：下达、开工、完工、结案，结算五个选项。           |
|  挂起状态    | 生产订单分录行的挂起状态。                                        |
|  汇总类型    | 1.报表进行汇总的分类依据；\\ 2.包含：产品，车间+产品两个选项。                  |

=====2.2 报表字段 =====
^  **字段**    ^  **说明**                                               ^
|  物料编码      | 生产订单表体分录对应生产用料清单分录的【物料编码】字段值                          |
|  物料名称      | 生产订单表体分录对应生产用料清单分录的【物料名称】字段值                          |
|  规格型号      | 生产订单表体分录对应生产用料清单分录的【规格型号】字段值                          |
|  倒冲时机      | 生产订单表体分录对应生产用料清单分录的【倒冲时机】字段值，包含开工时倒冲、汇报时倒冲、入库时倒冲三个选项  |
|  BOM编号     | 生产订单表体分录对应生产用料清单分录的【BOM编号】字段值                         |
|  辅助属性      | 生产订单表体分录对应生产用料清单分录的【辅助属性】字段值                          |
|  发料组织      | 生产订单表体分录对应生产用料清单分录的【发料组织】字段值                          |
|  仓库        | 生产订单表体分录对应生产用料清单分录的【仓库】字段值                            |
|  仓位        | 生产订单表体分录对应生产用料清单分录的【仓位】字段值                            |
|  产品编码      | 生产订单表体分录对应的【物料编码】字段值                                  |
|  产品名称      | 生产订单表体分录对应的【物料名称】字段值                                  |
|  产品规格型号    | 生产订单表体分录对应的【规格型号】字段值                                  |
|  产品单位      | 【产品编码】对应的物料的生产单位                                      |
|  计划生产数量    | 生产订单分录的计划生产的数量                                        |
|  汇报数量      | 生产订单分录的汇报数量【合格数量+不合格数量+返修数量+报废数量+返工数量】之和              |
|  合格品入库数量   | 生产订单分录的合格品入库数量                                        |
|  不合格品入库数量  | 生产订单分录的不合格入库数量                                        |
|  返工品入库数量   | 生产订单分录的返工品入库数量                                        |
|  子项物料单位    | 子项物料对应的库存单位，                                          |
|  应领数量      | 为了完成生产加工应该领取的物料数量                                     |
|  已领数量      | 为了完成生产加工已经领取的物料数量                                     |
|  领料差异数     | 领料差异数=【应领数量】-【已领数量】                                   |
|  应倒冲数量     | 按照倒冲规则，倒冲物料应该扣减的库存数量                                  |
|  已倒冲数量     | 按照倒冲规则，倒冲物料已经扣减的库存数量                                  |
|  倒冲差异数     | 倒冲差异数=【应倒冲数量】-【已倒冲数量】                                 |
