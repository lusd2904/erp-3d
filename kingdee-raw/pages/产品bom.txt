====== 1 产品BOM ======
=====1.1 功能概述=====
产品BOM(Bill of Materials)简称BOM，是生产制造系统的一个基础数据，用来表达组成某个制成品所需要的原材料、零部件或半成品等的组成结构关系。
BOM反映了产品的组成结构，表明了产品各个层次物料的从属关系和数据关系。

=====1.2 使用前提=====
定义【物料】

定义【单位】

定义【组织】

定义【作业】（可选）

定义【仓库】（可选）

定义【仓位】（可选）

定义【供应商】（可选）

定义【客户】（可选）

定义【物料替代】（可选）

定义【流程、重复生产线】（对于生产线生产物料必选）

定义【流程、重复生产线工位】（对于生产线生产物料必选）
===== 1.3 功能路径 ===== 

进入【餐饮加工管理】—>【加工基础数据】—>【产品清单】—>【产品BOM】

=====2.2 联副产品页签 =====

^  **字段**  ^  **说明**                           ^

=====2.4 子项明细页签 =====

^  **字段**   ^  **说明**                                                                                                                                                      ^
|  项次       | 属于同一组替代关系物料的项次相同；\\ 新增BOM分录时，项次依次递增。                                                                                                                         |
|  子项物料编码   | 子项物料的编码。\\ 子项物料编码不能与父项物料编码相同。                                                                                                                                |
|  物料名称     | 子项物料的名称。                                                                                                                                                     |
|  规格型号     | 显示指定的子项物料的规格型号。                                                                                                                                              |
|  供应组织     | 指定供应原材料的供应组织，建议存在委托加工关系时，再维护。                                                                                                                                |
|  子项BOM版本  | 供应组织下的BOM版本。\\ 注意：供应组织维护后，此字段才可以修改。                                                                                                                          |
|  物料属性     | 显示指定的子项的物料属性。\\ 注意：当父项的物料属性是“外购”时，子项只可以是外购件。                                                                                                                 |
|  子项类型     | 指定BOM子项的子项类型，包含：标准件、替代件、返还件。                                                                                                                                 |
|  供应类型     | 指定当前子项生成计划订单的“投放类型”                                                                                                                                          |
|  子项单位     | 指定BOM子项的单位。                                                                                                                                                  |
|  用量类型     | 指定计算子项用量时，根据何种方式进行计算：\\ 固定：子项需求量与父项需求量无关，不论多少父项需求量，子项用量都是固定的；\\ 变动：子项需求量与父项需求量线性相关，计算时，按父项需求量的多少，按比例计算子项需求用量；\\ 批量：子项需求量与父项需求量非线性相关，父项需求量在不同区间内，子项需求量取不同的值。  |
|  用量：分子    | 【用量：分子】/【用量：分母】表示生成单位父项物料所需的子项物料的数量。\\【用量：分子】一般录入子项相对于父项的用量。                                                                                                 |
|  用量：分母    | 【用量：分母】一般录入父项的用量。                                                                                                                                            |
|  固定损耗     | 与父项物料用量无关的子项物料的损耗。                                                                                                                                           |
|  变动损耗率    | 与父项物料用量成比例关系的子项物料的损耗比例。                                                                                                                                      |
|  跳层       | 勾选后，BOM展开时展开为下级子项。                                                                                                                                           |

=====2.7 物料控制页签 =====

^  **字段**   ^  **说明**                                                                                                                   ^
|  发料方式     | 子项物料的发料方式；取值范围：直接领料/直接倒冲/调拨领料/调拨倒冲/不发料。父项物料如果是生产线生产模式，则子物料的发料方式只能是“调拨倒冲、发料”。                                              |
|  倒冲时机     | 【发料方式】为“调拨倒冲”/“直接倒冲”时，可维护；取值范围：汇报倒冲/入库倒冲。父项物料如果是生产线生产模式，则倒冲时机再次设置无效，倒冲时点都是在汇报倒冲。                                          |
|  发料组织     | 录入子项的发料组织。发料组织必须具有库存职能。                                                                                                   |
|  默认发料仓库   | 录入子项物料的默认发料仓库。                                                                                                            |
|  默认发料仓位   | 录入子项物料的默认发料仓位。                                                                                                            |
|  超发控制方式   | 控制子项物料是否允许超发；包含：允许超发、最小发料批量和不允许超发。                                                                                        |
|  最小发料批量   | 仓库发放物料的最小数量，一般为该物料的最小包装数量。                                                                                                |
|  是否发损耗    | 控制生产投料时是否考虑损耗。                                                                                                            |
|  提前期偏置时间  | 指子项物料的投料时间相对第一道工序开工时间的偏置。录入负数时，表示第一道工序开工前子项物料就要准备好。                                                                       |
|  时间单位     | 提前期偏置时间的单位。支持：天、时、分、秒。                                                                                                    |
|  是否关键件    | 控制子项是否为关键件。                                                                                                               |
|  工序       | 录入子件的领用工序；必须为正整数。                                                                                                         |
|  作业编码     | 指定子项物料在哪个作业中被使用到。                                                                                                         |
|  位置号      | 指定子项物料的插件位置。                                                                                                              |
|  货主类型     | 指定子项物料的货主类型；取值范围：业务组织/客户/供应商。                                                                                             |
|  货主       | 货主为物料所有权的持有者。1.货主类型为业务组织时，货主取业务组织。2.货主类型为供应商时，货主取供应商。3.货主类型为客户时，货主取客户。                                                    |
|  可替换      | BOM分类为配置BOM时，可维护；【可替换】勾选，则表示在产品配置时，该物料可以被其他物料替换。                                                                          |
|  可修改      | BOM分类为配置BOM时，可维护；【可修改】勾选，则表示在产品配置时，该物料的用量、损耗、发料组织等信息可以修改。例如电脑中的内存。                                                        |
|  可选择      | BOM分类为配置BOM时，可维护；【可选择】勾选，则表示在产品配置时，该物料不是产品的必备料件，用户可以根据客户需求决定是否需要该物料。例如电脑中的显卡。                                             |
|  替代策略     | 物料替代的控制策略，包含：混用替代、手工替代、整批替代。混用替代：主物料和替代物料同时作为供给和预计量；供给比例由库存和预计量决定；手工替代：按照用户指定的供给比例，产生需求量；整批替代：满足同一笔需求时，要么使用主物料，要么使用替代物料。  |
|  替代方式     | 物料替代的控制策略，包含：替代和取代；替代：需求无法满足时，产生主物料的供给；取代：需求无法满足时，产生替代物料的供给；净需求比例：需求无法满足时，按替代方案中的净需求比例产生主物料和替代物料的供给                       |
|  替代优先级    | MRP计算时，物料计算的优先等级；                                                                                                         |
|  替代主料     | 替代主料的作用：在MPS/MRP计算时，按照替代主料的供给来判定是否产生替代。                                                                                   |
|  净需求比例    | 替代方式选择“净需求比例”时允许维护                                                                                                        |
|  辅助属性     | 启用辅助属性管理的物料，可设置辅助属性。影响计划时必录。　                                                                                             |
|  拆卸成本比例   | 产品进行拆卸时，原材料成本在总成本中所占的比例。                                                                                                  |
=====3.1 替代设置=====

在物料清单中设置标准件的替代关系。

1. 配置件作为子项，不允许设置替代关系；

2. 特征件作为子项,，不允许设置替代关系；

3. 特征件的子项，不允许设置替代关系；

4. 返还件不能设置替代料；

5. 虚拟件不能设置替代料。

=====3.2 替代删除===== 

删除产品BOM中标准件的替代关系。 

=====3.3 同步更新=====
点击同步更新，可以更新在制的生产/委外用量清单和计划BOM。
