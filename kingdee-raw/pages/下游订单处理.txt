ID: 下游订单处理
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%8B%E6%B8%B8%E8%AE%A2%E5%8D%95%E5%A4%84%E7%90%86

**功能说明：**

上级渠道对下级渠道的订货订单处理

**功能路径：**

【我的订单】->【下游订单处理】

**使用前提：**

当前登记用户渠道为直接渠道

**字段说明：**

下游订单处理显示字段说明
| **名称**  | **字段说明**                                         |
| 表头                                                        ||
| 编号      | B2B渠道订单编号                                        |
| 日期      | 渠道订单下单日期                                         |
| 要货渠道    | 要货渠道，一般为下级渠道或下级渠道对应的门店                           |
| 状态      | 下游订单单据处理状态，与订单状态一致                               |
| 总数量     | 订单所有分录商品数量的汇总                                    |
| 总金额     | 订单所有分录价税合计的汇总                                    |
| 单据类型    | B2B渠道订单或渠道配件订单                                   |
| 表明细                                                       ||
| 商品编码    | 携带渠道入库单明细对应字段                                    |
| :::     | 显示商品编码、名称、商品规格、图片等                               |
| 计量单位    | 订单销售单位                                           |
| 批准数量    | 当前登录渠道批准订货数量                                     |
| 订单数量    | 上级渠道申请订货数量                                       |
| 实际单价    | 渠道订货时实际销售的价格                                     |
| 金额      | 企业发给渠道订货的标准价格                                    |
| 未发货数量   | 未发货数量=批准数量 – 已发货数量。                              |
| 库存数量    | 当前登记渠道对应行商品的即时库存数量                               |
| 行状态     | 与单据状态类似，记录每一行商品的处理状态。包括：保存、提交、审核、打回、关闭、部分发货、已完成  |
| 操作      | 记录显示允许对单据行的具体操作                                  |

**操作说明：**
  - 进入下游订单处理页面
  - 对应不同的订单处理，选择不同的过滤页签
  - 进入选择不同的过滤页签，勾选需要处理的订单，点击操作即完成处理；

过滤页签说明：
  * 待确认：过滤处理需要确认的订单，支持打回、关闭处理；
  * 待审核：过滤处理需要审核的订单，支持打回、关闭处理；
  * 待发货：过滤处理已审核待发货的订单，可支持关闭处理；
  * 所有订单：包含了全部下游渠道或门店申请提交的订单，只查询而不允许做任何操作；
