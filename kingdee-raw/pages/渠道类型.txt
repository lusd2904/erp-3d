ID: 渠道类型
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B8%A0%E9%81%93%E7%B1%BB%E5%9E%8B

**功能说明：**

对渠道进行区分，渠道可以区分为不同的类型，不同的渠道类型，可能有些不同的属性，方便进行扩展

**功能路径：**

【渠道】->【渠道类型】

**使用前提：**

无

**字段说明：**

| **名称**  | **字段取数说明**                     |
| 类型编码    | 根据编码规则自动生成                     |
| 类型名称    | 手工填写                           |
| 启用状态    | 勾选\未勾选，默认为勾选启用状态               |
| 启用扩展属性  | 勾选\未勾选，默认为未勾选状态，勾选后显示类型扩展属性模块  |
| 类型属性表                                   ||
| 属性名称    | 手工填写                           |
| 输入方式    | 选择\输入，手工选择                     |
| 属性值类型   | 字符\数字，手工选择                     |
| 属性值     | 当输入方式=选择时，手工填写                 |
| 排序      | 手工填写                           |
| 是否必填    | 勾选\未勾选                         |
| 操作      | 保存、修改、新增、删除、启用、撤销启用、刷新、搜索      |

**操作说明：**
  - 点击【新增】按钮弹出编辑页面，录入名称，勾选启用状态；
  - 启用类型扩展属性：勾选启用扩展属性，点击【新增行】，录入属性名称，选择输入方式、属性值类型，当输入方式=输入时，不需要输入属性值；当输入方式=选择时，手工输入属性值以逗号分隔。录入排序信息，选择是否必填
  - 点击【保存】按钮，系统自动生成编码，新增一条渠道类型信息
  * 修改：双击渠道类型，进入详细信息页面，修改保存相关数据
  * 删除：选择相应渠道类型，点击【删除】按钮，删除此行
