======智能容器管理======

======1.功能概述======
1.用于维护智能容器的单据，可以统一的管理中央厨房中的容器
======2.字段说明======
^ 字段  ^ 说明  ^
| 编码 |  保存时自动生成  |
| 名称 |  保存时自动生成  |
| 容器类型 |  在辅助资料的容器中维护，默认气体容器 液体容器 固体容器  |
| 盛装类型 |  在辅助资料的容器中维护，默认通用，特定  |
| 容器单位 |  可以选择已有单位  |
| 容器数量 |  可以录入零或正整数  |
| 容器编号 |  输入数字  |
| 容积 |  可输入0或正整数  |
| 皮重 |  可输入0或正整数  |
| 最大载重 |  可输入0或正整数  |
| 最高温耐受 |  可输入整数  |
| 最低温耐受 |  可输入整数  |


======标准盛装信息==== 
^ 字段  ^ 说明  ^
| 物料编码 |  选择已有物料编码  |
| 物料名称 |  选择物料编码后自动填充 |
| 计量单位 |  选择物料编码后自动填充 |
| 满载数量 |  在辅助资料的容器中维护，默认通用，特定  |
| 辅助单位 |  可以选择已有单位  |
| 辅助满载数量 |  可以录入零或正整数  |
