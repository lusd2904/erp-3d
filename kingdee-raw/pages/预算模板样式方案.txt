ID: 预算模板样式方案
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E7%AE%97%E6%A8%A1%E6%9D%BF%E6%A0%B7%E5%BC%8F%E6%96%B9%E6%A1%88

通过预算模板样式方案，定义预算报表的报表样式。同时，提供了模板样式方案版本管理。
将报表样式作为基础资料管理，提高重用性。

**功能路径**

【管理会计】-【预算管理】-【预算模板】-【预算模板样式方案】

**操作前提**

预算日历、预算业务类型、项目数据类型、预算维度基础资料已准备完成。

**主要字段说明**
^  位置 界面元素                               |^  功能说明                                                                                                                                                                                                                                                                                                                                                                                    ^
| 表头         | 预算日历                       | 选择预算模板报表将使用的预算日历                                                                                                                                                                                                                                                                                                                                                                         |
|            | 报表周期                       | 选择预算模板报表的预算周期类型                                                                                                                                                                                                                                                                                                                                                                          |
|            | 报表包含周期                     | 选择预算模板报表中包含几个预算周期类型。如：周期类型选择年报，而该报表中包含了月度和年度的预算数。则，勾选包含周期：年+月                                                                                                                                                                                                                                                                                                                            |
|            | 业务类型                       | 选择预算报表中包含的预算业务类型。如：在一张预算表中，同时完成费用预算额和费用支出预算额的预算编制                                                                                                                                                                                                                                                                                                                                        |
|            | 选项：多组织预算表                  | 系统自动将预算组织添加到行维度。如：由一个预算组织（编制组织）一次性完成多个组织（受控组织）预算的编制。                                                                                                                                                                                                                                                                                                                                     |
|            | 主题风格                       | 设置预算表的默认颜色主题风格。                                                                                                                                                                                                                                                                                                                                                                          |
|            | 显示属性在维度前                   | 维度的显示属性，显示在维度名称之前，还是之后。                                                                                                                                                                                                                                                                                                                                                                  |
|            | 显示属性和维度分开显示                | 维度的显示属性，以独立列的形式在报表中显示。\\ 仅支持H5在线编辑。                                                                                                                                                                                                                                                                                                                                                      |
| 行/列维度 页签   | 行维度/列维度                    | 选择预算报表的行、列维度。当报表包含了多个周期类型，则系统自动将预算日历添加到列维度，且不允许删除。\\ **目前仅支持最大8个维度，其中最多允许5个辅助资料维度。**                                                                                                                                                                                                                                                                                                     |
|            | 显示属性                       | 设置维度值除显示维度值名称外，还需要显示其他的属性。如：物料维度的编码、规格型号等。在预算模板或者报表中，填充维度值后，显示效果为“物料名称/物料编码/规格型号”。即：原单元格中仅显示名称信息，设置显示属性后，除名称外，还在该单元格显示其他属性信息。                                                                                                                                                                                                                                                            |
|            | 选项：是否主维度                   | 用于主维度预算报表。一个模板样式方案，仅允许设置一个预算维度为预算报表的主维度。\\ 注意：当设置了主维度的模板样式方案，已编制相应主维度预算表，则模板样式方案中主维度设置不允许修改。                                                                                                                                                                                                                                                                                             |
|            | 关联维度、关联维度字段 选项：显示小计        | 对属性维度，设置其关联维度以及字段。如，对费用项目分组设置关联维度费用项目；对上级部门设置关联维度部门；对物料分组、存货类别、物料属性设置关联维度物料。\\ **应用场景**\\ 企业编制预算时，往往涉及多个预算维度，如费用项目、费用项目分组；部门、上级部门；物料、物料分组、存货类别、物料属性等。即：基础资料维度及其相关属性维度。\\ 在维度值填充时，只需要设置基础资料维度值即可，其属性维度，由系统自动携带。提高维度值填充设置工作效率。                                                                                                                                                             |
|            | :::                        | 对属性维度，设置其关联的维度、以及对应的维度字段。\\ 对费用项目分组维度，设置关联费用项目维度，设置对应维度字段为单据头.分组字段。                                                                                                                                                                                                                                                                                                                      |
|            | 选项：显示小计                    | 允许对行维度中的预算维度，设置是否显示小计行。在预算报表/预算模板中显示设置效果。                                                                                                                                                                                                                                                                                                                                                |
|            | 选项：显示总计                    | 允许设置是否显示总计行。仅所有行维度均勾选显示总计行，相应预算报表/预算模板显示总计行。即：只要有一个行维度设置为不显示总计行，即总计行不显示。                                                                                                                                                                                                                                                                                                                 |
| 项目数据类型 页签  | 项目数据类型+预算业务类型              | 选择预算报表中包含的数据：项目数据类型+预算业务类型。\\ 如：预算数-采购预算。                                                                                                                                                                                                                                                                                                                                                |
|            | 自动计算列                      | 选中自动计算列，在取数公式设置中，可使用当前模板样式方案的项目数据类型作为计算项。\\ 实现当前项目数据类型列（计算列）的单元格计算公式的自动填充。\\ 填充的单元格计算公式，效果如：E5=C5*D5。\\ 在模板(报表)中，自动填充为表页内的跨单元格取数的计算公式。\\ 单元格计算公式，参与计算的计算项一旦被修改，计算单元格的结果值即时更新。\\ 但目前暂无法支持跨表页，跨报表取数。                                                                                                                                                                                       |
|            | 预算表取数公式                    | 通过取数公式的设置，用于预算报表（预算模板）单元格取数公式的系统自动批量填充。\\ **应用场景**：\\ 1.下年预算的编制。下年预算在本年预算上浮一定百分比的基础上编制。（批量取上年预算表数据BGDATA）\\ 2.月度预算的编制。月度预算基于年初年度预算的基础上编制。（批量取年度预算表数据BGDATA）\\ **例如**：\\ 如要取预算数使用BGdata。在对BGdata设置维度组合参数时，维度组合参数必须默认为空。具体维度值，将在报表中进行维度值填充时，系统自动填充。\\ **其它说明**\\ BGdata函数，大部分参数允许为空，为空时，由系统根据当前报表公式取数参数设置以及报表属性，自动传入。详见[[预算取数公式]]。                                                         |
|            | 实际数取数公式                    | 通过取数公式的设置，用于实际数报表单元格取数公式的系统自动批量填充。\\ **应用场景**：实际数报表，批量取总账凭证数据。（ACCT）\\ 一般使用ACCT取来自总账凭证的实际数。ACCT函数的设置与BGdata类似。系统自动处理科目下挂核算维度的填充。                                                                                                                                                                                                                                                         |
|            | 辅助编制区域                     | 在预算表中，有些区域（列）仅仅只用于辅助计算/输出最终的预算结果。\\ 即：为了更合理快捷的进行预算编制，而需要的一些参考和计算基础，这些区域中的数据不会被用于后续的预算控制以及预算执行分析。则，这些数据列应纳入辅助编制区域。\\ 比如：以前年度实际数----用于下年预算编制的参考。\\ 比如：对整行预算的说明性文字----方便领导对这笔预算进行审核审批。\\ **注意**\\ 辅助编制区域，目前不支持辅助编制区域的后续应用，如预算汇总、预算控制、预算分析。                                                                                                                                                  |
|            | 取数公式设置（预算表取数公式、实际数报表取数公式）  | 目前支持ACCT、ACCTCASH、BGDATA、SJDATA函数，维度参数的自动填充（基于维度值填充选择）。\\ **自动填充的条件**： 函数中维度参数为空。\\ 【举例】acct下挂核算维度，应保持为空，即不设置。\\ 【举例】bgdata维度值组合，应保持为空，即不设置。\\ **不参与填充的维度**：选择哪些维度不需要填充到单元格取数公式。\\ 【举例】\\ 预算表中，因预算汇总查询需要，往往会增加分类用的维度，如费用预算表中，1级费用项目，2级费用项目，费用项目明细，这里，1级2级费用项目往往只适用于预算编制的汇总查询，或者后续的汇总控制。\\ 如相应实际数均来源于总账凭证时，在实际数报表通过ACCT取数时，科目只下挂了费用项目这个核算维度，故需要在设置实际数取数公式时，需设置1级费用项目、2级费用项目不参与取数公式的自动填充。  |


**操作说明**
  * 模板样式方案版本管理：
  - 为保证模板样式方案的通用性，以及企业实际业务按需调整的必要性，提供了系统内置的模板样式方案版本管理。
  - 打开任意模板样式方案，在工具栏中点击【版本管理】，进入“模板样式方案版本管理列表”界面。
  - 当模板样式方案被引用（预算模板/预算报表），修改除方案名称、行维度+列维度+项目数据类型组合未变、项目取数公式外的任意设置，系统将自动生成新版本的模板样式方案。
  - 如：企业在一起费用预算管控时，只控制到了部门和费用项目，在实施了一段时间之后，随着实际管控需求，需要在原基础上在增加员工维度。
  * 目前版本，当前样式方案未包含多报表周期前提下，行维度或者列维度设置时可为空。样式方案保存时，系统自动在为空的行/列维度，增加添加预算日历。


**其它说明**
  * 预算数据区域与辅助编制区域：

^ 编制区域名称  ^ 系统应用特征                                                         ^
| 辅助编制区域  | 只是用于辅助编制，其并不参与行维度（比如预算日历）的分组汇总，辅助编制区域的项目数据类型，是单独罗列在预算数区域之前和之后  |
| 预算数区域   | 参与行维度分组汇总，且绝对可以用于后续的预算控制以及预算执行分析                               |
