ID: bbc系统参数
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=bbc%E7%B3%BB%E7%BB%9F%E5%8F%82%E6%95%B0

**功能说明：**

系统级参数设置，管理整体系统的参数

**功能路径：**

【系统】—>【系统设置】—>【系统参数】

**使用前提：**

无

**字段说明：**

全局参数：
|**名称	**|**字段说明**|
|价格精度|价格显示、计算等的精度控制|
|数量精度|数量显示、计算等的精度控制|
|金额精度|金额显示、计算等的精度控制|

B2B参数：
| **名称	**            | **字段说明**                                       |
| PC商城名称             | PC版自定义的商城名称                                    |
| 微商城名称              | 自定义微商城名称                                       |
| 商城库存显示             | 选择不同的库存显示方式会直接影响显示至前台。库存显示方式包括：                |
| 订货支付方式             | 前台创建订单时，会根据勾选不同的支付方式而显示选择                      |
| :::                | 支付方式包括有：在线支付（先款后货）、线下支付（先款后货）、货到付款、先货后款        |
| 订货配送方式             | 前台创建订单时，会根据勾选不同的配送方式而显示选择                      |
|                    | 配送方式包括有：第三方物流配送、客户自提、公司配送、配送点配送                |
| 启用可用量查询            | 用于前台是否可以查看商品可用量                                |
| 及时库存查询地址           | 即时库存查询链接访问地址                                   |
| 启用建议订货量查询          | 用于在商品使用分货后，门户订货时商品显示建议订货量                      |
| 启用最大订货量控制          | 用于在商品使用分货后，门户订货时商品显示最大可订货量，且下单时订货量不允许超出最大订货量   |
| 下单时允许使用促销          | 用于直接渠道在下单时是否系统自动匹配促销政策                         |
| 商品的排序规则            | 用于在门户上显示的商品是按哪一种方式排序，提供三种方式                    |
| 商品订货价格显示           | 用于在门户上的订货商品显示的售价是显示发布价还是显示销售价目表价格              |
| 下单从销售价目表/折扣表取价     | 用于直接渠道在订货下单时，是否重新获取商品价格，支持从销售价目表实时取价           |
| (仅从销售价目表取价）        | 若下单重新获取价格，不需要取折扣表，则勾选此项                        |
| 显示下游渠道余额           | 用于多级渠道订货时，下级向上级订货是否检查其余额                       |
| 订单商品（非赠品）价格为0可以提交  | 用于直接渠道订货时，订货商品若单价为0，是否允许提交订单                   |
| 订货商品重复控制           | 用于在门户订货时，订单上的商品是否不允许重复，或是只做提示预警                |
| 是否允许用户维护收货地址       | 用于是否控制渠道商在门户上自行新增和修改收货地址信息                     |
| 门户只显示所在组织发布的商品     | 用于在多组织按渠道等级发布商品的场景下，订货渠道只能按默认所属销售组织进行商品的查看和使用  |
| 允许一键退货             | 启用后，BBC退货可以使用一键退货按钮完成BBC订单的确认以及退货商品的退货出库       |
| 订单确认时允许修改订货方       | 用于直接渠道或间接渠道下单时在单据页面是否允许选择其它供货方                 |
| 订货是否需要维护顾客信息       | 用于下订单时备注本单采购的顾客信息等，不启用时页面不显示相应字段               |
| 销售开单是否允许修改单价       | 用于门店开单时，是否可以修改商品携带的市场销售价                       |
| 门店开单时会员信息是否必录      | 用于门户销售开单时，是否一定要录入消费者的信息                        |
| 门店是否允许按法人范围查看库存    | 用于门店在库存不足时是否可以查看同一法人下其它门店的库存情况                 |

**操作说明：**

  - 进入系统参数页面，修改相关参数；
  - 保存，查看参数修改后的效果。
