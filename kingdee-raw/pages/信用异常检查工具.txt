 * 功能概述
帮助用户定期检查异常信用，排查异常信用数据，并指导用户在出现异常后，按有效的方法进行信用重算或操用。

 
  * 使用前提

启用信用控制

 
  * 功能路径

【供应链】－>【信用管理】－>【信用检查】－>【信用异常检查工具】

  
 * 操作说明

字段说明：

| **字段**                                     || **说明**                                                             |
| 信用单据是否存在上下游关联关系丢失                          || 检查信用占用表中，是否存在信用单据上下游关联关系丢失 。                                       |
| 信用单据没有按信用检查规则更新信用额度                        || 检查信用占用表中，是否存在信用单据重复更新信用额度或应该更新信用额度，但没有更新信用额度或不需更新信用额度，但也更新了信用额度 。  |
| 设定客户信用档案，上下游单据客户不一致，信用额度未能正确更新             || 检查信用占用表中，是否存在信用单据上下游销售客户不一致，导致上下游单据占用信用额度未能正确释放 。                  |
| 设定部门+客户信用档案，上下游单据信用部门或客户不一致，信用额度未能正确更新     || 检查信用占用表中，是否存在信用单据上下游销售客户或销售部门不一致，导致上下游单据占用信用额度未能正确释放 。             |
| 设置客户信用档案，应收和收款核销双方的客户是否一致                  || 检查信用占用表中，是否存在应收和收款核销双方的客户不一致导致信用额度释放不正确 。                          |
| 设定部门+客户信用档案，应收和收款核销双方的客户+销售部门是否一致          || 检查信用占用表中，是否存在应收和收款核销双方的客户或销售部门不一致导致信用额度释放不正确 。                     |
| 检查信用重算日期前是否存在未核销的单据                        || 检查信用表中，是否存在初始化日期或重算日期之前未核销的信用单据 。                                  |
| 单据信用占用额是否和实际应占用信用一致                     || 检查单据当前信用更新的金额跟实际应该更新的金额之间是否存在差异，如有不一致，在信用检查明细中把单据展示出来。             |
| 应收启用暂估时，信用管理是否勾选【暂估应收与财务应收按核销关系处理信用占用】  || 检查应收系统启用暂估应收时，信用是否勾选用应收时，【暂估应收与财务应收按核销关系处理信用占用】         |
