====== 手工日记账 ======
=====1 功能说明 =====
  
正常的收付款业务通过收付单据自动登账到日记账，但少部分收付款业务是直接在总账新增凭证，然后通过凭证复核登账生成手工日记账，或通过新增手工日记账登账到日记账。

支持手工新增或者通过凭证复核生成。


=====2 操作前提 =====

1、系统已启用。

2、定义了收付组织、账薄、币别、汇率体系、结算方式、收付款用途、银行、银行账号、现金账号等基础数据。

3、如果是通过凭证复核登账，需要先设置[[登帐设置|登帐设置]]和[[科目对应表设置|科目对应表设置]]

=====3 功能路径 =====

【财务会计】—>【出纳管理】—>【日记账】—>【手工日记账】

=====4 字段说明 =====

====4.1 单据头基本页签 ====
| **字段**      || **说明**                                                                           |
| 单据类型        || 选择录入手工日记账单据类型名称。根据业务类型的不同，手工日记账的单据类型分为两类：现金日记账、银行存款日记账。                          |
| 单据编号        || 手工日记账的编号。\\ 当【单据类型】定义为自动编号时，在保存时，系统自动生成单据编号；\\ 当【单据类型】定义为手工编号时，请在本栏位手工输入单据编号。\\  |
| 业务日期        || 业务发生的日期，也是财务入账时该笔业务所属财务期间的依据。                                                    |
| 收付组织        || 录入执行本次手工日记账的收付组织。                                                                |
| 账薄          || 录入本次手工日记账所对应的账薄。                                                                 |
| 会计期间        || 显示账薄对应的当前会计期间。                                                                   |
| 科目          || 录入本次手工日记账所对应的科目，当单据类型为现金日记账时，只能录入现金科目；当单据类型为银行存款日记账时，只能录入银行存款科目。                 |
| 币别          || 录入本次手工日记账所对应的币别。                                                                 |
| 借方金额        || 显示整单的借方金额合计                                                                      |
| 贷方金额        || 显示整单的贷方金额合计。                                                                     |
| 借方金额本位币     || 显示整单的借方金额合计的本位币。                                                                 |
| 贷方金额本位币     || 显示整单的贷方金额合计的本位币。                                                                 |
| 本位币         || 显示所选账簿的记账本位币。                                                                    |
| 汇率类型        || 显示本次收付组织所对应的默认核算体系的核算组织默认的会计政策的汇率类型。                                             |
| 汇率          || 原币到本位币的汇率。根据对应的系统参数确定是否允许手工修改。                                                   |

|**字段**||**说明**|
|结算方式||选择录入本次业务对应的结算方式。|
|借方金额||本次业务的借方金额。|
|贷方金额||本次业务的贷方金额。|

|对方科目||录入本次业务所对应的对方科目|
|对方银行账号||录入对方付款的银行账号。非必录信息。录入后将有助于系统根据此信息自动进行银行存款对账勾对。|
|对方账户名称||录入对方付款的银行账户名称。非必录信息。录入后将有助于系统根据此信息自动进行银行存款对账勾对。|

|摘要||录入本次业务的摘要信息。|

=====5 操作说明 =====

1、【手工日记账】—>【业务操作】—>【复核记账】，选择手工新增凭证，登账生成手工日记账。具体说明请查看[[复核记账|复核记账]]

2、【手工日记账】—>【业务操作】—>【引入】，设置引入条件，引入符合条件的凭证生成手工日记账。具体说明请查看[[引入日记账|引入日记账]]

3、手工日记账是支持新增的，与总账手工录入的现金、银行存款凭证对应。
