ID: 固定资产盘点方案
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9B%BA%E5%AE%9A%E8%B5%84%E4%BA%A7%E7%9B%98%E7%82%B9%E6%96%B9%E6%A1%88

资产盘点是固定资产管理的一项重要工作，为了确保公司财产安全，需要定期对公司固定资产进行盘点。建立盘点方案用来确定盘点范围及具体盘点项目。


====== 1 操作前提 ====== 
资产卡片已审核
====== 2 字段说明 ======
| **字段**     || **说明**                                                     |
| 盘点方案编码     || 定义盘点方案的编码。                                                 |
| 盘点方案名称     || 定义盘点方案的名称。                                                 |
| 资产组织       || 选择需要进行盘点的资产组织                                              |
| 货主组织       || 选择需要盘点的货主组织，只能选择到与资产组织建立了托管关系的组织。为空，表示与资产组织建立托管关系的所有货主组织。  |
| 资产类别       || 需要盘点的资产类别范围，为空，表示盘点所有资产类别的资产。                              |
| 卡片编码       || 需要盘点的卡片编码范围，为空，表示盘点所有卡片的资产。                                |
| 使用部门       || 需要盘点的使用部门范围，为空，表示盘点所有卡片的资产。                                |
| 资产位置       || 需要盘点的资产位置范围，为空，表示盘点所有卡片的资产。                                |
====== 3操作说明 ======
===== 3.1新增盘点方案 =====
操作步骤：
  - 单击**固定资产-->盘点方案**，进入盘点方案列表界面；
  - 单击**新增**按钮，打开盘点方案新增界面；
  - 输入需要盘点的资产组织和货主组织等信息；
  - 单击**保存**按钮完成盘点方案的保存。

===== 3.2盘点方案审核 =====
盘点方案进行提交、审核操作后，单击生成盘点表，系统自动按照盘点方案定义的盘点内容和范围生成资产盘点表。 

===== 3.3盘点方案反审核 =====
盘点方案如果未生成资产盘点表，允许进行反审核操作，单击反审核即完成盘点方案的反审核。反审核的盘点方案允许修改或删除。
