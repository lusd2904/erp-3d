===== 1.功能概述 =====
清机交班报表是统计一段时间内组织每天的营业明细情况，包括账单金额、消费人数、食品类别的销售金额、部门出品数量分析、部门营业金额分析、结算方式的收入金额等

====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据

====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【营业报表分析】→【清机交班报表】

====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、条件、排序、显示隐藏列

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集
  * 排序页签：报表显示字段排序
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏

====== 5.报表字段说明 ======
^ 字段        ^ 说明                    ^
| 预付金额      | 所付定金金额                |
| 结算方式      | 结算方式名称                |

| 客付金额（换算）  | 客付金额（换算）=客付金额（原币）*汇率  |
| 找赎        | 各结算方式找赎金额之和           |
| 收款金额      | 收款金额=总收取的金额           |
| 编码        | 部门编码                  |
| 名称        | 部门名称                  |
| 下单数量      | 账单食品下单数量              |
| 下单金额      | 账单食品下单金额              |
| 取消数量      | 账单食品取消数量              |
| 取消金额      | 账单食品取消金额              |
| 销售数量      | 销售数量=下单数量-取消数量        |
| 销售收入      | 销售收入=下单金额-取消金额        |
| 赠送数量      | 账单食品招待数量              |
| 赠送金额      | 账单食品招待金额              |
| 优惠金额      | 优惠金额                  |
| 服务费       | 服务费                   |




====== 6.报表操作说明 ======
1、POS清机上传数据后，此报表要用金蝶AI星空客户端才可以查看

2、报表提供冻结列设置、打印、引出功能。

3、报表提供按表头的【组织】、【部门】、【楼层】、【营业日期】汇总合计【数量】、【金额】等营业信息。

4、报表根据条件筛选展示信息有结账时间、账单数、消单数、人数、食品费、服务费、房费、优惠金额、收入金额、开票金额、按结算方式统计笔数、客付金额、找赎、收款金额，部门出品数量分析、部门营业金额分析、会员存款、会员消费、盲交统计、预付订金统计、渠道来源统计
