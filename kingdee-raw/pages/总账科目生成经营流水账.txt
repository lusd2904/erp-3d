====== 1.功能说明 ======

本功能主要用于总账科目生成经营流水账，并显示执行的结果。

使用前提

引入总账科目来源方案已设置；

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【总账科目生成经营流水账】。
====== 2.字段说明 ======


| **字段**    | **说明**                                                                                                                                       |
| 经营账簿        | 选择要生成经营流水账的经营账簿。                                    |
| 当前期间      | 生成经营流水的当前期间。                                        |
| 执行方式      | 选择生成经营流水账的方式，可以为覆盖或追加，默认为追加。                                      |
| 检查项      | 执行生成时，显示需要的检查项。                                         |
| 状态    | 执行生成经营流水账时，显示需要的检查项结果。                                                       |
====== 3.操作说明 ======

经营流水账生成结束后显示执行的结果。 并弹出总账科目生成经营流水账报告，显示本次执行总账科目引入的具体情况。
