====== 工作流参数设置 ======
返回参数设置[[参数设置| 参数设置]]
===== 功能概述 =====

  * 工作流参数设置提供了与流程运行相关的几个参数，一般企业在工作流正式上线前需要确认系统参数。特别说明：工作流参数和组织无关，必须由administrator用户进行设置，一般有管理员权限的用户进行设置也不生效.
===== 参数说明 =====

系统参数说明
==== 1.流程处理模式 ====

工作流流程处理模式提供了两种模式：消息队列和同步。

  * 消息队列：流程提交后，任务后台排队处理。推荐使用。
  * 同步：流程提交后，任务即时处理。
==== 2.工作流发送使用虚拟邮箱 ====

工作流审批节点和消息节点都支持邮件的方式通知流程参与人，目前工作流邮件支持三种模式发送：

2.1不勾选工作流发送使用虚拟邮箱：工作流邮件发送由上一步处理人的邮箱发送；
   配置：
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【邮件服务器设置】，设置邮件服务器。 
  * 流程参与人在【个人信息】-【邮箱设置】中设置用户信息、服务器信息和登录信息。

2.2勾选工作流发送使用虚拟邮箱，虚拟帐户设置选择【单个帐户】：此时工作流邮件发送用同一的帐户发送，使用于整个企业使用一个虚拟帐户的情况；
    配置：
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【邮件服务器设置】，设置邮件服务器 
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【邮件虚拟帐户设置】，设置虚拟帐户 
  * administration登录，【基础管理】-【公共设置】-【参数设置】中工作流参数设置，选择虚拟帐户
2.3勾选工作流发送使用虚拟邮箱，虚拟帐户设置选择【多个帐户】：此时工作流邮件发送根据接收人对应设置的虚拟帐户进行发送；
    配置：
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【邮件服务器设置】，设置邮件服务器 
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【邮件虚拟帐户设置】，设置虚拟帐户 
  * administration登录，【基础管理】-【公共设置】-【邮件设置】-【虚拟帐户用户设置】，设置虚拟帐户和用户的对应关系
==== 3.邮件审批 ====

   * 启用邮件审批：勾选，支持工作流发送超时提醒邮件中点击链接进行任务审批；不勾选，则不支持邮件审批功能。
  *  服务器地址：勾选启用邮件审批后会自动填充登陆地址，无需手工输入。
  *  审批有效时间：工作流发生超时提醒邮件中的任务链接的有效时间，从收到邮件开始计时，超过该时间后，点击链接无法进行任务审批。
  *  审批链接类型：邮件审批打开任务处理界面的类型支持Html5和SilverLight两个；
==== 4 流程运行 ====


===  4.1.勾选允许指定下一步处理人时，参与人必须人工指定 ===

  * 勾选选项：在审批节点选择了允许指定下一步处理人时，下一步处理人信息展示为空，控制必须由任务处理人指定参与人后，流程才可继续运行；审批节点未选择允许指定下一步处理人时，下一步处理人会解析出来且不允许选择 
  * 不勾选选项：在审批节点选择了允许指定下一步处理人时，下一步处理人信息解析下一个节点的处理人，无需再次手工选择
== 4.2.单据列表记录多级审核信息 ==

  * 勾选，单据的过滤界面-条件页签会出现【多级审核信息】复选框，勾选该复选框后，显示隐藏列页签会显示多级审核信息字段：审核人、审核时间，勾选后，单据列表显示该字段信息；
  * 不勾选，单据列表过滤界面的条件页签上不出现【多级审核信息】复选框，不能在单据列表显示审核信息；
== 4.3.记录流程处理过程中的详细日志，以便追踪分析出错原因 ==

  * 勾选，流程处理过程中的详细日志会写在log文件和流程日志中（流程管理中心下可查看），当流程出现问题时，可以查询使用；
注意：正常运行时可不勾选，在流程有问题时可勾选使用。


== 4.4.流程任务撤销回本人 ==

该选项用来控制在已办列表上撤销时，撤回给节点处理人，不再重新解析该节点的所有处理人。
  *    勾选，撤销任务时撤回给处理人
  *   不勾选，撤销任务时撤回给该节点的所有参与人

== 4.5.审批路线不显示自动审核 ==

该选项控制审批路线中自动审核的节点不显示自动审核字样
  *    勾选，审批路线不显示自动审批字样
  *   不勾选，审批路线显示自动审批字样

== 4.6.启用流程预测 ==
  * 勾选后，流程发起后，会有专门的执行计划对流程进行预测，查看流程图，即将运行的节点会显示预测解析的处理人；
  * 如果提交流程后立刻查看流程图，会立刻进行预测。

== 4.7.默认驳回给参与人 ==
  * 勾选后，驳回到目标节点时所有参与人都收到待办。
  * 不勾选，驳回到目标节点时，仅有处理人收到待办。

== 4.8.流程管理中心启用组织隔离 ==
  * 勾选后，用户在流程管理中心仅能看到有权限的组织下的流程实例和待办列表；
  * 不勾选，用户只要有流程管理中心权限，就可以查看所有组织下的流程实例和待办列表；

== 4.9.允许归档已完成的流程实例 ==
  * 强制勾选，归档X月前完成的流程数据，X小于等于3，如果值过大，会导致历史数据多影响信息中心的查询性能；

== 4.10.批量提交流程识别到复杂混合提交时，自动切换“逐个单据提交且无交互确认” ==
  * 勾选后，批量提交流程时，若识别到本次提交单据涉及多个组织、多个版本、流程审批与传统审批等同时混合提交场景时，会应用此参数逻辑；
  * 但是，此参数启用后，提交过程中如有触发警告交互确认的单据会视作提交失败，需要后续单独提交进行“是与否”的警告交互确认后决定是否提交流程。
  * 不勾选，则只能同一组织单据批量提交流程。

==== 5.信息中心 ==== 
=== 5.1任务列表按单据分组显示 ===

该选项控制信息中心-待办列表、已办列表的任务显示
  *    勾选，待办、已办列表的任务按关联的单据进行分目录展示
  *   不勾选，待办、已办列表不分组展示

== 5.2任务处理弹出成功信息 ==
  * 勾选后，任务处理点提交后该节点关联的操作如果有成功提示信息会弹出来，前提是任务处理后需要保留在当前界面，如果任务处理后关闭或自动跳到下一任务则不弹出。

== 5.3使用新版H5端任务处理 ==
  * 勾选后，H5端任务处理界面打开使用新样式，右边显示审批面板和审批路线，可以关闭，关闭后显示完整单据，点审核菜单可以打开该面板。


====6.消息通知====

===  6.1.流程超时提醒通知显示：超时提醒标题 ===
  * 勾选，流程节点发送超时提醒信息时有超时提醒字样
  * 不勾选，流程节点发送超时提醒信息时没有超时提醒字样

==  6.2.流程邮件通知取消显示：工作流消息标题 ==


  * 勾选，流程消息节点发送的邮件标题中会有工作流消息字样
  * 不勾选，流程消息节点发送的邮件标题中不会有工作流消息字样

== 6.3.流程邮件通知取消显示【发送人】标题 ==
  * 勾选后，工作流发送的邮件主题上不会显示发送人
== 6.4.超时发流程消息 ==
  * 勾选后，流程节点超时提醒只要有勾选任何一种提醒方式，都会同时发流程消息；
  * 不勾选，则超时提醒不会发流程消息；

=====7.流程设计 ====
==== 7.1流程设计条件设置基础资料显示所有组织的基础资料 ====
  * 勾选后，流程设计中心-条件设置-基本条件上基础资料的查询界面显示所有组织的基础资料；
  * 不勾选，则仅显示当前登陆组织的基础资料；
