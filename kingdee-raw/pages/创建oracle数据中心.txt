====== 1 功能描述  ======

数据中心是业务数据的载体，支持SQL Server和Oracle两种数据库类型，并可以按数据中心设置系统时区。

**功能路径**

【数据中心列表】

====== 2 字段说明 ======


===== 2.1 数据库服务器信息 =====

==== 2.1.1 数据库服务器 ====
定义当前数据库服务器的机器名称或者数据库服务器IP地址； ​

==== 2.1.2 实例名 ====

采用默认实例名即可；

==== 2.1.3 端口 ====

采用默认端口即可；

==== 2.1.4 数据库管理员 ====

输入数据库服务器管理员名称，数据库管理员用户将会使用模板创建数据中心；

==== 2.1.5 管理员密码 ====

输入数据库服务器管理员密码；

===== 2.2 数据库用户 =====

==== 2.2.1 使用现有用户 ====
  - 数据库用户：输入数据连接用户的帐号，数据库服务器中必须存在这个账户； ​
  - 密码：输入数据连接用户的帐号密码； ​
==== 2.2.2 新建用户 ====

  - 数据库用户：输入数据连接用户的帐号，数据库服务器中尚不存在这个账户；
  - 密码：输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户；
  - 确认密码：新增用户需要输入确认密码；
  - 默认表空间：需指定一个默认表空间；
  - 临时表空间：需指定一个临时表空间；​

===== 2.3 数据中心 =====

==== 2.3.1 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.3.2 系统时区 ====
定义数据中心的系统时区，数据中心保存后系统时区将不再允许修改；

==== 2.3.3 默认语言 ====

默认为中文简体，下拉选择中文繁体和英文，数据中心保存后默认语言将不再允许修改；

==== 2.3.4 其他字段 ====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； ​
  - 数据中心类别：提供了标准业务库、标准BOS库； ​

====== 3 功能操作 ======

===== 3.1 登录管理中心平台 =====

在管理中心的登录界面，使用Administrator，登录到管理中心后，可在主页进行数据中心的创建。
    ​

=====3.2 创建Oracle数据中心 =====

在【数据中心列表】，点击工具栏【创建】按钮组的下拉子按钮【创建Oracle数据中心】，如果管理中心是Oracle类型的，直接点击工具栏【创建】按钮，即可打开“创建Oracle数据中心”的向导界面。

Oracle数据中心创建共分三步，具体创建过程如下：

  第一步：输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码；
  
  第二步：选择数据库用户，可以选择“使用现有用户”或“新建用户”，这两种方式分别介绍如下：
  
       1、选择“使用现有用户”，需要输入Oracle数据库中已存在的用户名及其密码。
     
          注意采用“使用现有用户”方式需要提前使用Oracle系统自带工具创建用户，在Oracle数据库中创建用户后，应授予该新建用户DBA的权限，还需为新建用户关联数据库表空间，以保证该用户创建出来的数据中心各个功能正常；
        
       2、选择“新建用户”，需输入在数据库中新建的用户名称、密码以及确认密码，还需选择默认表空间和临时表空间。
     
  第三步：设置数据中心的基本信息、语言、日志中心。
  
        1、数据中心基本信息，包括：数据中心代码、名称、类别、数据库文件路径等内容；
  
           注意：请根据需要勾选“允许执行计划任务”，勾选启用后，当前数据中心相关后台服务才能定时执行。
  
        2、语言，设置当前数据中心的默认语言，一般是中文（简体/中国）；
  
        3、日志中心，设置日志中心的存放路径，勾选选项“创建日志中心”，那么在创建业务数据中心时，会同时在此路径下面创建日志库。​
  
完成上面所有步骤后，点击【创建】按钮，系统即可完成数据中心的创建工作。


===== 3.3 登录数据中心 =====

  - 每个数据中心都有一个预设的系统管理员用户，用户名：Administrator。
  - 初次登录时，会弹出提示“需要使用200MB本地磁盘空间做缓存，请确认”，点击【确定】后，虽然会占用部分空间，但可以提高系统使用性能和运行速度。

====== 4 其他说明 ======

  - 用户名在SQL Server下Administrator不区分大小写，Oracle下必须是Administrator，区分大小写且要求首字母大写。
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。
