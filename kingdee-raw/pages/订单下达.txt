ID: 订单下达
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%AE%A2%E5%8D%95%E4%B8%8B%E8%BE%BE

**功能说明：**

用于一级渠道向企业、二级渠道向一级渠道选择商品订货或配件订货。根据渠道用户的购物清单生成订货单。

**功能路径：**

【购物车】->【下单】

**使用前提：**
具有订单的权限 且
可以向上级订货的直接渠道或间接渠道

**字段说明：**
| **名称**     | **字段说明**                                 |
| 收货地址       | 必填，订货方的收货地址                              |
| 支付方式选择     | 必填，根据当前渠道的订货模式确定                         |
| :::        | 如果是向企业订货：则支付方式根据参数显示                     |
| :::        | 如果是指定渠道订货：则支付方式不显示，后台自动设置为先货后款，表示不需要处理。  |
| 配送方式选择     | 必填，根据参数显示和选择                             |
| 期望到货日期     | 必填，选择日期                                  |
| 单据类型       | 快速订货时隐藏，界面不显示，根据当前渠道的订货模式确定              |
| :::        | 如果是向企业订货：则设置为B2B企业订单/B2B企业配件订单           |
| :::        | 如果是指定渠道订货：则设置为B2B渠道订单/B2B渠道配件订单          |
| :::        | 手工BBC单时，显示并允许编辑修改；                       |
| 业务类型       | 根据单据类型过滤，用户可修改。                          |
| 订货渠道       | 自动默认当前渠道，锁定不可修改                          |
| 收货渠道       | 系统默认为当前渠道的档案的收货渠道，锁定不可修改                 |
| 供货方        | 系统自动填写，根据当前渠道的订货模式确定                     |
| :::        | 供货方类型=组织，则供货方自动选择为购物车中携带的销售组织。           |
| :::        | 供货方类型=渠道，则供货方自动选择为当前渠道的档案的订货渠道字段。        |
| 供货方类型      | 前台不显示，系统自动填写，根据当前渠道的订货模式确定               |
| :::        | 如果是向企业订货：供货方类型=组织                        |
| :::        | 如果是指定渠道订货：供货方类型=渠道                       |
| 订单备注       | 手工录入                                     |
| 商品明细信息                                               ||
| 商品         | 从购物车携带，订购的商品                             |
| 数量         | 从购物车携带，可以允许修改                            |
| 标准单价/实际单价  | 从购物车携带                                   |
| 折扣额/折扣率    | 促销时使用                                    |
| 价税合计       | 价税合计=批准数量×实际单价－折扣额                       |
| SKUID      | 从购物车携带，隐藏不显示                             |
| 规格         | 从购物车携带，商品的规格型号                           |

**操作说明：**
  - 加入购物车后，点击【下单】，跳转至编辑订单页面
  - 填写订单相关信息，提交订单
