ID: 签收记录
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%AD%BE%E6%94%B6%E8%AE%B0%E5%BD%95

**功能说明：**

对订单进行签收进行查询和显示

**功能路径：**

【我的订单】->【签收记录】

**使用前提：**

具有订单签收权限

**字段说明：**

签收记录显示的信息

**名称**	**字段说明**
| 表头                         ||
| 单据编号  | 渠道入库单单据编号           |
| 签收日期  | 取对应渠道入库单的审核日期       |
| 签收方式  | 签收方式分为自动签收和手工签收     |
| :::   | 自动签收：系统自动签收         |
| :::   | 手工签收：手工审核渠道入库的签收    |
| 表明细                        ||
| 商品    | 携带渠道入库单明细对应字段       |
| :::   | 显示商品编码、名称、商品规格、图片等  |
| 计量单位  | 渠道入库时的入库单位          |
| 签收数量  | 渠道入库单明细里的入库数量       |
| 拒收数量  | 签收时手工拒签数量           |
| 是否补货  | 签收补货时使用             |
| 补货数量  | 签收补货时使用             |
| 订单编号  | 显示为BBC订单编号          |

**操作说明：**
  - 用户点击签收记录菜单；
  - 系统显示签收记录信息，可以点击入库单编号与订单编号查看相关的入库单详细信息和BBC订单的详情信息。
