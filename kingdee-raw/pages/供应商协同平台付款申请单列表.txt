====== 1 功能介绍 ======
企业付款之前如果需要先进行申请，付款申请单即能实现该功能。供应商协同平台可通过付款申请单列表查看对应的付款申请单。
====== 2 功能路径 ======
【供应商协同平台】—>【财务协同】—>【付款申请单列表】
====== 3 字段说明 ======
^ 字段      ^ 说明                                                  ^
| 单据类型    | 付款申请单单据类型名称。根据业务类型的不同，付款申请单的单据类型不同                  |
| 单据编号    | 付款申请单的编号                                            |
| 往来单位类型  | 与企业发生债权债务或者收付款往来关系的对方单位类型                           |
| 往来单位    | 企业企业发生债权债务或者收付款往来关系的对方单位                            |
| 收款单位类型  | 实际收款的对方单位类型                                         |
| 收款单位    | 实际收款的对方单位。实际收款方与往来关系方不一定是相同的                        |
| 币别      | 本次支付款申请项所对应的币别                                      |
| 结算币别    | 本次应付的结算币别                                           |
| 应付金额    | 由系统根据表体的应付金额自动计算整单应付金额                              |
| 申请付款金额  | 由系统根据表体的申请付款金额自动计算的申请付款金额                           |
| 付款组织    | 执行本次付款申请的付款组织                                       |
| 结算组织    | 执行本次付款申请的结算组织                                       |
| 采购组织    | 本次委托付款申请的采购组织                                       |
| 采购部门    | 本次付款申请业务对应的采购部门，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件  |
| 采购组     | 本次付款申请业务对应的采购组，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件   |
| 采购员     | 本次付款申请业务对应的采购员，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件   |
| 结算方式    | 付款业务对应的结算方式                                         |
| 付款用途    | 付款申请金额对应的用途                                         |
| 对方银行账号  | 对方银行账号                                              |
