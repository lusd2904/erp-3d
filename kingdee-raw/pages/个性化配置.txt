====== 1.功能说明 ======

使用个性化配置，配置个人用户使用的参数，使得系统的操作与体验更符合个别用户的操作习惯，提高操作效率。

**功能路径**

个性化参数配置路径：【右上方个人头像】→【我的设置】→【个性化配置】


====== 2.参数说明 ======

^ 参数名称                      ^ 参数说明                                                                                                                           ^
| 不启用表格边框线                  | 勾选参数后，表格将隐藏横向的边框线。                                                                                                             |
| 客户端启用旧版首页（需重新登录）          | 勾选参数，重新登录后，客户端将使用旧版首页，不勾选将采用新版首页。                                                                                              |
| 启用整行复制（Ctrl+C）（带标题或不带标题）  | 勾选参数后，在表格选中多行，使用快捷键（Ctrl+C）进行复制，可带标题或不带标题进行多行内容的复制。                                                                            |
| 禁止快捷键（F5）刷新数据             | 勾选参数后，在列表按快捷键（F5），将不会进行表格数据的刷新。                                                                                                |
| 用户界面放大X%（需重新登录）           | 勾选参数，配置放大的百分比后，重新登录，界面所有元素将会进行放大处理。                                                                                            |
| 列表点击不清除选中行                | 勾选参数后，在列表进行行的选中，点击右边不会清空之前选中的行。                                                                                                |
| 列表数字列复制不携带格式              | 勾选参数后，在列表复制数字字段，将不携带格式。                                                                                                        |
| 表格启用渐变效果                  | 勾选参数后，表格将会有渐变效果，拖动滚动条会很流畅，如若去掉勾选，拖动滚动条将略微会有点卡。                                                                                 |
| 列表分组                      | 勾选参数后，右键某字段的列头，可以这个字段作为分组显示。                                                                                                   |
| 列表选择列固定                   | 勾选参数后，列表选择列将固定样式为左，不支持拖动，显示在最左边。                                                                                               |
| 只读单元格自动换行                 | 勾选参数后，表格的只读单元格的高度，将会随着内容，变化行高，确保内容全部显示。                                                                                        |
| 表格选中行弹出Tips               | 勾选参数后，选中行的全部字段，鼠标放在字段的上方，都可以弹出Tips。                                                                                            |
| 列头多选过滤                    | 勾选参数后，点击列头小漏斗过滤，可选多个值。                                                                                                         |
| 关闭登录时区提示                  | 勾选参数后，登录时区不一致的提示将不再提醒。                                                                                                         |
| 心跳事件携带提交数据                | 勾选参数后，可解决单据体录入时偶发小数点等录入不起作用的问题。                                                                                                |
| 日期字段禁用滚轮效果                | 勾选参数后，所有日期字段，点击编辑值后，就不再支持通过滚动鼠标滚轮修改值。                                                                                          |
| 不可编辑字段显示边框线               | 勾选参数后，不可编辑字段显示边框线，提升数据的可读性。                                                                                                    |
| 关闭客户端最小化到系统托盘             | 勾选参数后，点击右上角关闭客户端，默认最小化到系统托盘。                                                                                                   |
| 数字字段录入不显示尾零               | 在单据中的数字字段，由于受到精度的影响，数字字段一般小数点后都有多个零，在录入过程中也默认会显示尾零；但尾零数量较多时，可能会对录入数字造成一些干扰，因此需要在录入过程中不显示尾零。                                    |
| 启用页签初次切换渐进效果              | 启用渐进效果后，数据行会一行行逐渐显示出来，形成一个渐进显示的动画效果。这可以提高数据填写的效率，并使得操作更加便捷。                                                                    |
| 启用表格过滤条件显示                | 勾选参数后，使用表头小漏斗过滤，会自动在左下方生成对这个过滤的说明和描述。                                                                                          |
| 打印无需提示                    | 勾选参数后，打印将不会再提示，数据已输出到打印机。                                                                                                      |
| 使用本地打印机设置                 | 勾选参数后，打印会以打印机的首选项中的设置（纸张设置等）为准。                                                                                                |
| 使用图形预览                    | 勾选参数后，对预览内容换行的位置，避免该行后面出现空白的问题。                                                                                                |
| 计算硬边距                     | 如打印的效果由于没有考虑硬边距，导致不理想，可勾选该参数，试试效果。详情可查阅：[[https://vip.kingdee.com/knowledge/476389427150020608|打印支持计算硬边距（仅GUI桌面应用）]]           |
| 启用后台打印                    | 一般勾选这个参数，可加快打印的响应速度，但是如若一个用户打印时也会出现交替打印的问题，该参数不要勾选。                                                                            |
| 预览打印为普通窗口                 | 勾选参数后，预览打印为普通窗口，可支持拖动和调整窗口大小。                                                                                                  |
| 预览内容自适应窗口                 | 勾选参数后，预览的内容将采用自适应窗口。                                                                                                           |
| 使用微软字体打印                  | 勾选参数后，将使用微软字体打印，可避免部分场景下打印慢，以及打印成PDF，无法拷贝复制PDF中的文字等问题。详情可查阅：[[https://vip.kingdee.com/knowledge/598458319522317824|使用微软字体打印]]  |
