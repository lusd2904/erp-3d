===== 1.功能概述 =====
食品销售明细静态报表是统计分析营业日期内门店的营业明细情况，包括部门、楼层、房台信息、食品名称、下单数量、下单金额、取消数量、取消金额、取消理由等
====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换上传账单数据
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【食品报表分析】→【食品销售明细静态报表】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总、排序

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
  * 排序页签：报表显示字段排序

====== 5.报表字段说明 ======
^ 字段      ^ 说明                     ^
| 组织      | 门店名称                   |
| 食品编码    | 食品编号，可查询具体食品信息         |
| 食品部门    | 食品所属部门，可按部门统计分析部门营业情况  |
| 食品类别    | 食品分类，可按类别统计食品信息        |
| 营业日期    | 营业日期（清机日期）             |
| 时段      | 就餐时段，如午市，晚市            |
| 账单编号    | 账单编号，如：0028            |
| 楼层编码    | 楼层编号，可查询就餐楼层           |
| 房台编码    | 房台编号，可查询就餐房台           |
| 下单员工编码  | 订单下单员工编号，可查询员工信息       |
| 操作时间    | 订单下单时间                 |
| 平均单价    | 平均单价                   |
| 下单数量    | 食品实际下单数量合计             |
| 下单金额    | 食品实际下单总额=数量X单价         |
| 取消数量    | 食品取消数量                 |
| 取消金额    | 食品取消金额                 |
| 招待理由    | 招待理由                   |
| 优惠金额    | 食品优惠金额                 |
| 折扣金额    | 食品打折金额                 |

====== 6.报表操作说明 ======
1、报表需要数据清洗后才能查阅（可设置报表数据清洗定时执行）

2、报表提供打印、引出功能。

3、报表提供按表头的【组织】、【营业日期】等统计分析食品的销售情况，包括下单数量、取消数量、取消理由等

4、报表提供过滤→分组汇总，在报表中对分组字段进行统计分析，其中分组字段包括：组织、营业日期、食品类别、食品编码、食品部门等

5、可以通过勾选【选项】中的参数，控制数值的显示 。
