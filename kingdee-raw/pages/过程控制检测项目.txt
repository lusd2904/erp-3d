**功能概述**

用于定义定义生产过程记录和质量检测对象。

【补丁7.5.1.202010】提供

**功能路径**

【智慧车间MES】－>【智慧车间】－>【过程及检测记录】－>【过程控制检测项目】


**字段说明**

如图：

{{::sfs_工序过程检测_过程控制检测项目.png?1000|}}

表头
| **字段**     || **说明**                                                                                                                          |
| 创建组织       || 对应的创建组织                                                                                                                         |
| 使用组织       || 对应的使用组织                                                                                                                         |
| 编码         || 对应的编码                                                                                                                           |
| 名称         || 对应的检测项目名称，该字段支持折行显示                                                                                                             |
| 组别         || 基础资料分组，建议合理对数据做分组                                                                                                               |
| 分析方法       || 分析方法共三种：\\        定量分析：可量化的指标，数值类型，记录检测值和检测结果（PASS/FAIL）\\        定性分析：不可量化的指标，只记录检测结果（PASS/FAIL）\\        其他分析：备注类型指标，仅记录备注信息  |
| 检测类型       || 区分检测结果记录和生产过程记录                                                                                                                 |
| 单位         || 定量检测项目对应的计量单位，F8计量单位                                                                                                            |
| 精度         || 定量检测项目对应的小数精度                                                                                                                   |
| 重点检查       || 确定是否需要重点检查，复选框                                                                                                                  |
| 数据类型       || 当分析方法=“其他分析”时，用于定义字段值类型，包括“文本、短日期、长日期、时间”；\\ HMI端列表录入时，对于日期和时间类型的字段会弹出“日期或时间选择器”；                                               |
