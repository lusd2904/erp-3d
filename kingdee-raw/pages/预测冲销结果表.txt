======1 预测冲销结果表======
=====1.1 功能概述=====

预测冲销结果：冲销结果表用表格展示冲销后的结果及对应关系。

=====1.2 使用前提=====

  * 维护【预测单】
  * 维护【销售订单】

=====1.3 功能路径=====


进入【生产制造】—>【计划管理】—>【预测冲销】—>【预测冲销结果表】

======2. 字段说明======
=====2.1 过滤条件=====

|  **字段**  |  **说明**        |
|  查询组织    | 维护查询的组织        |
|  销售订单    | 维护销售订单的单据范围    |
|  要货日期    | 维护销售订单的要货日期范围  |
|  预测单     | 维护预测单的单据范围     |
|  预测开始日期  | 维护预测单的预测开始日期   |
|  预测结束日期  | 维护预测单的预测结束日期   |
|  物料编码    | 维护物料的查询范围      |

=====2.2 表头=====

|  **字段**  |  **说明**        |
|  查询组织    | 显示查询的组织        |
|  销售订单    | 显示销售订单的单据范围    |
|  要货日期    | 显示销售订单的要货日期范围  |
|  预测单     | 显示预测单的单据范围     |
|  预测开始日期  | 显示预测单的预测开始日期   |
|  预测结束日期  | 显示预测单的预测结束日期   |
|  物料编码    | 显示物料的查询范围      |

=====2.3 表体=====

|  **字段**       |  **说明**                    |
|  销售订单编号       | 1.显示参与冲销的销售订单的单据编号         |
|  客户           | 1.显示销售订单的客户                |
|  销售订单行号       | 1.显示参与冲销的销售订单的行号           |
|  订单状态         | 1.显示参与冲销的销售订单的状态           |
|  预测单号         | 1.显示参与冲销的预测单的单据编号          |
|  预测单行号        | 1.显示参与冲销的预测单的行号            |
|  物料编码         | 1.显示参与冲销的销售订单分录的物料编码       |
|  物料名称         | 1.显示物料的物料名称                |
|  规格型号         | 1.显示物料的规格型号                |
|  基本计量单位       | 1.显示物料的基本计量单位              |
|  冲销数量         | 1.显示冲销的数量                  |
|  执行数量         | 1.显示预测单下推销售订单的数量           |
|  销售订单未冲销数量    | 1.未冲销数量=销售订单分录数量-冲销数量      |
|  预测单未冲销数量     | 1.未冲销数量=预测单分录数量-冲销数量-执行数量  |
|  销售订单的累计出货数量  | 1.显示销售订单出货数量               |
|  需求日期         | 1.显示销售订单分录的要货日期            |
