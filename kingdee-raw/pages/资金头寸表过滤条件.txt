====== 资金头寸表过滤条件 ======
在“快捷”页签，用户选择需要查询的结算组织、币别，设置起始日期、结束日期基本过滤条件。其他过滤页签为系统通用设置，可设置字段列的显示隐藏属性。

当按收付组织过滤时，过滤出收付组织所有外部银行账号和内部账户的资金头寸数据。

当按结算组织过滤时，过滤出结算组织所有内部账户的资金头寸数据。

快捷页签主要过滤项目说明 

| **过滤项**      || **说明**                                 |
| 收付组织         || 选择查询哪个收付组织的报表，支持多选。                    |
| 结算组织         || 选择查询哪个结算组织的报表，支持多选。                    |
| 币别           || 选择要查询哪个币别的报表，支持多选。                     |
| 起始日期         || 选择要查询数据的起始日期。                          |
| 结束日期         || 选择要查询数据的结束日期。                          |
| 本日、本周、本月     || 快速设置要查询的起始日期、结束日期。                     |
| 包含未审核单据      || 选中此项，报表取数时，会统计未审核的收付款单据；反之，则不统计。       |
| 显示本位币        || 选中此项，报表会显示各行项目对应的本位币信息；反之，则不显示。        |
| 显示发生额        || 选中此项，报表会显示各行项目对应的本期收入、本期支出信息；反之，则不显示。  |
| 显示币别小计       || 选中此项，报表会显示同一币别的现金及银行存款合计数据；反之，则不显示。    |
| 显示本位币合计      || 选中此项，报表会按本位币合计显示在最末行。                  |
