======1.功能概述======
服务员业绩汇总报表统计分析员工编码部门、下单数量、取消数量、下单金额、取消金额、提成金额
======2.使用前提======
存在实际发生的业务数据，并通过门店数据交换上传账单数据
======3.功能路径======
【餐饮门店管理】→【门店营业分析】→【绩效报表分析】→【服务员业绩汇总报表】
======4.报表过滤条件======
过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总、排序

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
  * 排序页签：报表显示字段排序
======5.报表字段说明======
^ 字段    ^ 说明              ^
| 组织    | 组织名称            |
| 员工编码  | 员工编码            |
| 员工名称  | 员工名称            |
| 部门编码  | 员工的所属部门编码       |
| 部门名称  | 员工所属的部门名称       |
| 下单数量  | 食品下单数量          |
| 取消数量  | 食品下单数量          |
| 销售数量  | 销售数量=下单数量-取消数量  |
| 下单金额  | 食品下单金额          |
| 取消金额  | 食品取消金额          |
| 销售金额  | 销售金额=下单金额-取消金额  |
| 提成金额  | 员工的提成金额         |

======6.报表操作说明======
1、报表提供打印、引出功能。

2、报表提供按表头的【组织】、【营业日期】等统计分析服务员的业绩情况

3、报表提供过滤→分组汇总，在报表中对分组字段进行统计分析员工业绩，其中分组字段包括：组织、员工编码

4、可以通过勾选【选项】中的参数，控制数值的显示
