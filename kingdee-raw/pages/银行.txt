======银行 ======
=====功能说明=====

管理和维护企业具体的开户银行，一般是各大银行具体的分行或者支行。

=====功能路径=====

【财务会计】—>【出纳管理】—>【基础资料】—>【银行】

=====字段说明=====
主要字段说明
^  位置  ^  字段     ^  说明                         ^
| 基本   | 创建组织    | 创建当前银行基础资料的业务组织。            |
|      | 编码      | 当前开户银行的编码。                  |
|      | 名称      | 当前开户银行的名称，一般是各大银行的某分行或者支行。  |
|      | 使用组织    | 使用当前开户银行的业务组织。              |
|      | 描述      | 对当前开户银行基础资料的备注信息。           |
|      | 银行      | 启用银企平台才可以选择到,没启用不需要填写       |
|      | 省       | 启用银企平台才可以选择到                |
|      | 市       | 启用银企平台才可以选择到                |
|      | 地区      | 启用银企平台才可以选择到                |
|      | 选择银行网点  | 启用银企平台才可以选择到                |
|      | 联行号     | 选择银行网点自动携带                  |
|      | 地区码     | 选择银行网点自动携带                  |
|      | 地区名     | 选择银行网点自动携带                  |
|      | 银行地址    | 当前开户银行的地址信息，选择银行网点自动携带      |
===== 操作说明=====
银行默认为共享型基础资料，所有有权限的业务组织均可以使用。
