====== 组合经营科目 ======
====== 1.功能说明 ======

通过加减乘除表达式实现多个经营科目或者按一定比例组合成组合经营科目，实现特定组合的经营指标数据分析，以便帮助管理人员做经营决策。

**操作前提**

已定义经营账簿、核算体系、会计日历、经营科目。

**功能路径**

【管理会计】→【经营会计】→【基础设置】→【组合经营科目】

====== 2.字段说明 ======

^ 字段     ^ 说明                  ^
| 编码     | 组合经营科目的编码。          |
| 名称     | 组合经营科目的名称。          |
| 经营科目表  | 组合经营科目的来源。          |
| 显示位置   | 组合经营科目在利润表显示的位置。    |
| 显示顺序   | 设置同一个位置多个组合经营科目排序。  |
| 复合公式   | 选择经营科目表的经营科目设置表达式。  |
| 公式描述   | 组合经营科目公式描述。         |
====== 3.操作说明 ======
可以对组合经营科目禁用，已禁用的组合经营科目可以反禁用。
