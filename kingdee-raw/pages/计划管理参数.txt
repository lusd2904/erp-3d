======1 计划管理参数======
=====1.1 功能概述=====
计划管理参数定义了工厂具体在执行业务及计划运算过程中计划层面的相应控制。

=====1.2 功能路径=====

进入【生产制造】—>【计划管理】—>【参数设置】—>【计划管理参数】

======2. 字段说明======

|  **字段**                       |  **说明**                                                                                                                                                                                                                            |
|  启用预留                         | 用户如果没有勾选【启用预留】\\ 1)单据中的预留类型隐藏不可维护；\\ 2)预留综合查询不可用；\\ 3)计划方案中预留相关参数隐藏不可维护；\\ 4)优先级参数隐藏不可维护；\\ 5)计划向导中隐藏优先级计算按钮；                                                                                                                      |
|  占用低优先级预留控制层级                 | 1、【启用预留】为“否”的时候不可维护；\\ 2、单选，选项如下：\\ 1）不控制：用户选择不控制时，当发生预留被占用时，不弹出提示信息；\\ 2）警告：用户选择警告时，当发生预留被占用时，弹出警告及提示信息；\\ 3）严格控制：用户选择严格控制时，当发生预留被占用时，弹出交互式提示，是否继续执行，如果选择否则不会继续出库。                                                                |
|  计划运算是否保留预留关系                 | 1、【全部保留】：计划运算完，强/弱预留均保留；\\ 2、【仅保留强预留】：不管是锁库、手工创建、还是计划运算产生的强预留均保留，弱预留不保留\\ \\ 该参数与计划方案中的预留释放方式的区别：\\ 【预留释放方式】决定了运算前就存在的预留关系是否先释放掉然后再开始本次计划运算；\\ 【计划运算是否保留预留关系】决定了本次计划运算完之后存在的预留关系要不要保留下来（正常情况下每次计划运算都会产生预留关系，该参数决定预留关系是否会自动删掉）。 \\  |
|  计划运算以下需求的强/弱预留不保留            | 1、【安全库存】：如果勾选，则表示计划运算完，安全库存产生的强/弱预留均自动删除；如果“安全库存需求优先级”参数设置为“最高”，一般不建议勾选安全库存预留不保留，否则安全库存的需求可能得不到优先供应；\\ 2、【预测单（手工预留除外）】：如果勾选，则预测单本身物料及根据其BOM多级展开涉及的物料需求除了手工创建的预留保留之外，其他方式产生的预留（不管是强预留还是弱预留）都会在计划运算后自动删掉。                            |
|  启用动态需求优先级                    | 1、【启用预留】为“否”的时候不可维护；\\ 2、启用动态需求优先级时，可以进行需求优先级的动态计算；\\ 3、未启用动态需求优先级时，组织优先级不可维护；\\ 4、未启用动态需求优先级时，优先级计算公式不可维护\\ 5、未启用动态需求优先级时，不可进行优先级计算；                                                                                              |
|  安全库存需求优先级                    | 1、可选“最低”或“最高”，默认最高\\ 2、设置计划运算时安全库存的需求优先级                                                                                                                                                                                           |
|  计划运算时库存供应日期记录系统日期            | 1、勾选时，MRP运算库存的供应日期取计算当天0时(在MRP运算相关报表中会有体现）\\ 2、未勾选时，MRP运算库存的供应日期默认为1993年(在MRP运算相关报表中会有体现）                                                                                                                                          |
|  例外信息调整-生成采购订单变更单的状态          | 1、【审核】：通过例外信息调整产生的采购订单变更单状态为“审核”状态\\ 2、【保存】：通过例外信息调整产生的采购订单变更单状态为“创建”状态                                                                                                                                                            |
|  例外信息调整-生成生产订单变更单的状态          | 1、【审核】：通过例外信息调整产生的生产订单变更单状态为“审核”状态\\ 2、【保存】：通过例外信息调整产生的生产订单变更单状态为“创建”状态                                                                                                                                                            |
|  例外信息调整-生成委外订单变更单的状态          | 1、【审核】：通过例外信息调整产生的委外订单变更单状态为“审核”状态\\ 2、【保存】：通过例外信息调整产生的委外订单变更单状态为“创建”状态                                                                                                                                                            |
|  启用多组织预测冲销                    | 1、勾选参数后启用多组织冲销\\ 2、使用ATO方案必须启用多组织冲销                                                                                                                                                                                                |
|  考虑寄售调拨                       | 1、启用“考虑寄售调拨”后，在计划运算时会将寄售类销售订单的调拨作为出库进行考虑。                                                                                                                                                                                          |
|  计划运算不考虑跳层件的库存/预计入库           | 1、勾选后计划运算直接展开跳层件，并且计划BOM再次计算时跳层件子项不还原                                                                                                                                                                                              |
|  供需单据上指定的BOM版本未审核或已禁用时计划运算终止  | 勾选时，若运算考虑到的需求单据或供应单据上指定的具体的BOM版本为未审核、或者已禁用状态时，运算直接终止。该参数对选单运算和全局运算都生效。                                                                                                                                                             |
|  选单运算获取物料范围检测到物料无有效BOM时       | 选单运算时，根据获取到的物料范围做BOM完整性检查，当应该有BOM的物料没有已审核的BOM或BOM已禁用时，根据参数判断计划运算是否继续：\\ 【严格控制】：直接终止运算；\\ 【警告】：弹出提示信息，用户可选择继续运算或终止；\\ 【不控制】：不弹提示也不终止，直接继续运算                                                                                         |
|  全局运算获取物料范围检测到物料无有效BOM时       | 全局运算时，对系统中所有的物料做BOM完整性检查，当应该有BOM的物料没有已审核的BOM或BOM已禁用时，根据参数判断计划运算是否继续：\\ 【严格控制】：直接终止运算；\\ 【警告】：弹出提示信息，用户可选择继续运算或终止；\\ 【不控制】：不弹提示也不终止，直接继续运算                                                                                          |


======3. 操作说明======
**清除预留**

点击“清除预留”会清空系统中所有的预留关系，适用于预留关系出现大量异常数据的场景。
