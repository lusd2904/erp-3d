**功能概述**

在日常会计工作中，难免会发生各种差错或账实不符的情况；为了保证会计记录的正确性，就有必要进行对账。对账的内容主要包括账证核对、账账核对、账实核对。此处的对账功能主要是账账核对，即总账与各业务系统明细账之间的核对。

**使用前提**

对账方案已设置。

**功能路径**

【财务会计】－>【智能会计平台】－>【对账管理】－>【对账】

**字段说明**

| **字段**       || **说明**                                                                                    |
| 账簿           || 选择对账的账簿，总账数据以该条件进行过滤，业务报表以账簿对应的核算组织进行过滤。                                                  |
| 对账方案         || 选择对账的方案，总账和业务报表以该条件进行过滤和展示。                                                               |
| 年度、期间        || 选择对账的年度和期间，总账和业务报表以该条件进行过滤。                                                               |
| 币别           || 选择对账的币别，总账和业务报表以该条件进行过滤。                                                                  |
| 包含未过账凭证      || 是否包含未过账凭证，总账以该条件进行过滤。                                                                     |
| 总账期初余额       || 当对账项目的余额方向为借方时，总账期初余额=借方科目的期初余额-贷方科目的期初余额；\\ 当对账项目的余额方向为贷方时，总账的期初余额=贷方科目的期初余额-借方科目的期初余额。  |
| 总账本期增加       || 当对账项目的余额方向为借方时，总账本期增加=借方科目的借方发生+贷方科目的借方发生；\\ 当对账项目的余额方向为贷方时，总账本期增加=贷方科目的贷方发生+借方科目的贷方发生。   |
| 总账本期减少       || 当对账项目的余额方向为借方时，总账本期减少=借方科目的贷方发生+贷方科目的贷方发生；\\ 当对账项目的余额方向为贷方时，总账本期减少=贷方科目的借方发生+借方科目的借方发生。   |
| 总账期末余额       || 总账本期余额=总账期初余额+总账本期增加-总账本期减少。                                                              |
| 业务系统期初余额     || 业务报表的期初余额。                                                                                |
| 业务系统本期增加     || 业务报表的本期增加。                                                                                |
| 业务系统本期减少     || 业务报表的本期减少。                                                                                |
| 业务系统期末余额     || 业务系统本期期末=业务系统本期期初+业务系统本期增加-业务系统本期减少。                                                      |


**业务说明**

 

当总账和业务系统的本期增加或本期减少数有差异时，系统提供【本期发生额差异分析】的关联操作，分析并列示可能导致差异的原因，具体如下：

  * 单据未生成凭证：业务报表的数据均来源于单据，若这些单据若未生成凭证，可能会造成差异。 
  * 单据生成的凭证不包含指定科目：对账方案中指定的会计科目与组成业务报表的单据生成的凭证科目应该是一致的，若单据生成的凭证科目不包含指定科目而是其他科目，可能会造成差异。 
  * 凭证手工录入：业务报表的数据来源于单据，单据通过智能会计平台生成凭证，这样二者的数据是一致的；若对账科目的凭证为手工录入（含自动转账、期末调汇和结转损益等来源系统为总账的凭证），可能会造成差异。 
  * 凭证的来源单据不是指定单据：业务报表的单据是既定的，例如应收款明细表来源于应收单、其他应收单、收款单、收款退款单、应收核销单等；若对账科目的凭证不是来源于这些单据，而是由其他单据生成的，也有可能会造成差异。

 存货对账增加两项新的差异分析项：
   * 单据与业务凭证金额匹配：若“过滤出来的单据”的金额与业务凭证金额不一致（明细金额差异或者合计金额差异有一项不一致，即视为不通过），则检查结果为不通过；反之则通过。此处的校验规则为：按单据的出入库序列、调拨方向、存货类别及对账设置的科目与业务凭证进行比较，单据出入库序列为“出库”且调拨方式为“普通”时 业务凭证的存货科目金额应在贷方（出库序列但调拨方向为“退货”时应生成贷方负数的存货凭证分录），同理出入库序列为“入库”且调拨方向为“普通”时业务凭证存货科目金额应在借方（退货方向应生成借方负金额的存货凭证分录）。若对账关联科目对应的业务凭证借方或者贷方金额与单据对应出入库序列金额不一致则体现在明细差异列，若业务单据总金额与凭证总金额不同，则显示合计金额差异。  
   * 业务凭证与总账凭证金额匹配：若过滤出来的总账凭证金额与业务凭证金额不一致，则检查结果为不通过；反之则通过。此处的校验规则为：总账凭证关联业务凭证后按关联对账科目借贷金额差异进行计算，如存在差异则相应的总账凭证显示在差异明细项目中，差异结果明细直接调用总账凭证列表并显示对应的总账凭证。

特别要说明的是除了上述分析项，还有其他原因会导致对账差异，例如手工修改业务系统生成的凭证的科目和金额、对账方案设置错误以及其他异常，这些情况系统没有办法控制，需要进一步的人工分析。
