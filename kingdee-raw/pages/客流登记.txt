ID: 客流登记
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AE%A2%E6%B5%81%E7%99%BB%E8%AE%B0

**功能说明：**

用于进店客流记录、查询

**功能路径：**

【会员中心】->【客流登记】

**使用前提：**

渠道类型为门店

**字段说明：**
| **名称**   | **字段说明**                 |
| 所属门店*    | 当前登记门店，系统自动取值            |
| 进店日期*    | 系统默认取当前时间                |
| 进店人数*    | 手工输入                     |
| 进店客户类型*  | 辅助资料定义，在界面上自动获取和显示  |
| 进店时间段*   | 辅助资料定义，在界面上自动获取和显示  |
| 进店批次     | 手工输入                     |
| 接待业务员*   | 当前门店BBC后台维护的业务员          |
| 购买动机*    | 辅助资料定义，在界面上自动获取和显示  |
| 意向产品*    |辅助资料定义，在界面上自动获取和显示  |
| 意向型号     | 手工填写                     |
| 业务类型*    | 辅助资料定义，在界面上自动获取和显示  |
| 客户信息                               ||
| 老客户      | 基础资料的会员信息             |
| 客户姓名*    | 手工填写                     |
| 性别       | 男/女                      |
| 手机       | 手工填写                     |
| 电话       | 手工填写                     |
| 年龄段      | 辅助资料定义，在界面上自动获取和显示  |
| 关注竞品列表                             ||
| 竞品       | 辅助资料定义，在界面上自动获取和显示  |
| 客户喜好                               ||
| 喜好       | 辅助资料定义，在界面上自动获取和显示  |
| 意向状态                               ||
| 跟进状态     | 跟进中、成交、失败、不买了            |
| 原因分析     | 辅助资料定义，在界面上自动获取和显示  |
| 跟进记录                               ||
| 跟进日期     | 手工选择                     |
| 跟进内容     | 手工填写                     |
| 客户意见     | 手工填写                     |

**操作说明：**
  - 在辅助资料列表维护相关的客流登记基础资料
  - 进入BBC商品前台【会员中心】->【客流登记】，新增填写相关客流登记信息，然后保存即可；
  - 查看我的客流登记列表，列表内允许刷新、新增、删除、跟进处理等操作。
