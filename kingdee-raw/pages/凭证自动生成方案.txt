ID: 凭证自动生成方案
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%87%AD%E8%AF%81%E8%87%AA%E5%8A%A8%E7%94%9F%E6%88%90%E6%96%B9%E6%A1%88

**功能概述**

凭证自动生成方案用于设置用户希望自动生成凭证的账簿、单据、凭证制单人，以及自动生成凭证选项。

**使用前提**

账簿、科目表、凭证模版已定义。

**功能路径**

【财务会计】－>【智能会计平台】－>【账务处理】－>【凭证自动生成方案】

**字段说明**


| **字段　**      || **说明**                                                                                                                                       |
| 自动生成凭证选项     || 设置自动生成凭证选项：单据审核自动生成凭证、定时生成凭证。                                                                                                                |
| 凭证制单人选项      || 设置凭证制单人选项，系统支持按方案指定、按账簿指定、按单据指定三个选项。                                                                                                         |
| 执行频率         || (1)只有在自动生成凭证选项为"定时生成凭证"才可以进行设置和选择，若自动生成凭证选项为"单据审核自动生成凭证"，则此处灰显且不可操作；(2)执行频率一共有三个选项：月、周、天。                                                    |
| 执行时间设置       || (1)当执行频率为月时，执行时间可以选择月份中的具体某一天的对应指定时间；(2)当执行频率为周时，执行时间的指定天数取值范围为1-7；(3)当执行频率为天时，执行时间只能选择一天中的对应时间，有效范围为0 -24 时的时间范围。                           |
| 选择账簿         || 选择要生成凭证的账簿，可多选。                                                                                                                              |
| 执行方式         || (1)若自动生成凭证选项为"单据审核自动生成凭证"则此处只能选择单据生成业务凭证或者单据同时生成业务凭证和总账凭证；(2)若自动生成凭证选项为"定时生成凭证"则此处可以选择单据生成业务凭证、业务凭证生成总账凭证单据同时生成业务凭证和总账凭证。                    |
| 未来期间数         || 选择要自动执行凭证生成的期间，可选当前期间或总账允许未来期间数。                                                                                                                              |
| 选择单据         || (1)按指定账簿选择需要生成凭证的单据，可多选。此处显示的单据为指定账簿存在适用凭证模版的单据。(2)未被选中的单据在当前方案保存后自动删除，若需要再次编辑方案并添加其它单据，可通过新增行或者自动加载按钮选择需要的单据。                               |
| 总账凭证生成方式     || 选择业务凭证生成总账凭证的方式，系统支持一对一、全部汇总和匹配汇总。\\ 一对一是指一张业务凭证生成一张总账凭证。全部汇总是多张业务凭证汇总生成一张总账凭证。匹配汇总是满足匹配条件的多张业务凭证汇总生成一张总账凭证；满足匹配条件是指这些业务凭证对应的来源单据上的匹配字段值相同。  |
| 匹配字段         || 若生成方式为【匹配汇总】，则在此定义匹配的字段。                                                                                                                     |


**业务说明**

1、只有启用状态的凭证自动生成方案才可以参与自动或者定时生成凭证服务：(1)若自动生成凭证选项为"单据审核自动生成凭证"，则具备审核功能的单据在单据被审核时自动调用凭证生成服务并执行凭证生成，凭证生成结果可通过选中对应的方案联查其"凭证自动生成记录"，然后通过"凭证自动生成记录"联查对应的凭证生成报告。(2)若自动生成凭证选项为"定时生成凭证"，则系统自动按照方案指定的生效时间后台执行凭证生成，凭证生成结果查看方法同自动生成凭证选项为"单据审核自动生成凭证"的相关方案。

2、凭证自动生成方案的自动生成凭证选项为"定时生成凭证"时，需在管理中心将对应账套启用"允许执行计划任务"，否则即使启用了相关方案，系统也不会执行凭证生成服务。

3、定时自动执行方案执行手工执行。（2022年6月份补丁增加的）

4、支持相同（账簿+来源单据）允许执行时间中【小时】和【分钟】不相同设置多个定时自动生成凭证方案。（2022年9月份补丁增加的）

5、支持选择其中一个账簿下的来源单据设置批量填充到其他账簿。（2022年3月份补丁增加的）

6、凭证自动生成方案支持设置期间范围，可选当前期间或总账允许未来期间数。（2023年3月份补丁增加）
