===== 外币折算方案 =====

**功能说明**

将下级子公司或者子集团的外币报表折算为币别与母公司记账本位相一致的报表。

**操作前提**

在合并控制下，进行外币折算之前，请检查并保证以下信息完整：

1. 参加折算的个别报表（含抵消表）都已接收；

2. 折算使用的汇率类型，在当前期间下存在原币与目标币别的汇率记录。

3. 折算使用的项目外币折算方案中所包含的报表项目，已覆盖本次要折算报表中包含的报表项目；

4. 参加折算的报表，存在报表数据的单元格都存在ITEM公式；

5. 动态罗列表的折算，不支持按历史汇率折算的项目，故需检查并保证参加折算的动态罗列表中不存在按历史折算的项目；

6. 按历史汇率折算的项目，在“项目变动记录”中已做严格的记录和维护，并保证项目变动记录中的数据与账面数据一致。

**字段说明**

^ 页签        ^ 界面元素                ^ 说明                                                                                                                                                                                                                                                                       ^
| “折算选项”页签  | 项目折算方案              | 选择项目外币折算方案。                                                                                                                                                                                                                                                              |
| :::       | 汇率类型                | 选择汇率体系中汇率类型资料。                                                                                                                                                                                                                                                           |
| :::       | 折算目标币别              | 选择币别资料。                                                                                                                                                                                                                                                                  |
| :::       | 历史汇率折算公式            | 提供2种计算方法：\\ 1.按项目变动记录计算；\\ 2.按报表项目变动额计算。                                                                                                                                                                                                                                 |
| :::       | 跨表页函数REF（取外币折算后金额）  | 当报表中存在ref跨表页取数时，请勾选本选项。\\ 系统将取相应表页单元格折算后的金额。                                                                                                                                                                                                                             |
| :::       | 差异项目公式设置            | 【折算差异项目】：选择报表项目，主要针对资产负债表的恒等式“资产=负债+所有者权益(股东权益)”，在折算过程产生的差异额（资产-负债-所有者权益），记入“外币折算差额”项目。\\ 支持多个折算差异项目。                                                                                                                                                                    |
| :::       | 跨表页函数REF（取外币折算后金额）  | 当报表中存在ref跨表页取数时，请勾选本选项。\\ 系统将取相应表页单元格折算后的金额。                                                                                                                                                                                                                             |
| :::       | 不参加折算的数据类型          | 选择“自动取数设置”且“数据属性=金额”的项目数据类型。选择哪些数据类型的报表项目不参加折算，而直接去已折算后的数据。\\ 该类数据类型的报表项目单元格取数逻辑来源于【项目数据类型】属性【自动取数设置】-【表达式】。\\ 本功能用于：\\ 一些数据类型的特殊性，比如：“年初数”，年初折算过，一般年内不变，无需重复折算，直接取折算后的年初数即可；“上期数”，上期已经折算过，本期无需折算，直接去上期折算后的金额即可；\\ 所以，建议在定义折算方案时，将这些不需要折算的数据类型单独挑出来，由系统自动完成对应报表项目数据的取数。  |
| “折算范围”页签  | 报表类型                | 所有类型：包括已接收的所有个别报表（含抵消表）、下级合并范围上报的合并报表/汇总报表和已创建的调整报表。\\ 非调整报表：包括已接收的所有个别报表（含抵消表）、下级合并范围上报的合并报表/汇总报表，已创建的调整报表不在折算范围。\\ 仅调整报表：仅包括已创建的调整报表。\\ 优先调整报表：优先折算已创建的调整报表（对应原个别报表/抵消报表/合并报表/汇总报表不折算），对于未创建调整报表的个别报表（含抵消表）/汇总报表/合并报表也参加折算。                                            |
| :::       | 公司                  | 选择哪些组织/合并范围参加本次折算。\\ 为空时，默认所有公司（包括合并范围）都需要参加折算。                                                                                                                                                                                                                          |
| :::       | 报表模板                | 选择哪些报表模板（产生的报表）参加本次折算。\\ 为空时，默认所有报表都需要参加折算。                                                                                                                                                                                                                              |
| :::       | 币别                  | 选择哪些币别（报表）参加本次折算。\\ 为空时，默认所有币别的报表都需要参加折算。                                                                                                                                                                                                                                |
