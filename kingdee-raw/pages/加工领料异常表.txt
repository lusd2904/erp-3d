======1  加工领料异常表=======
=====1.1 报表功能=====
1.加工领料异常表能够使用户能及时地了解加工过程中物料使用异常的情况。

2.加工领料异常总表支持按照物料/车间/单据类型等多维度，查询物料的使用异常的情况。

======2. 字段说明======
=====2.1 快捷过滤 =====
^  **字段**  ^  **说明**                                            ^
|  加工组织    | 1.定义报表查询的组织范围；\\ 2.必须具有加工职能，有且只能录入一个组织。            |
|  下达日期    | 1.加工订单分录行的下达日期；\\ 2.定义报表查询的下达日期范围。                 |
|  加工车间    | 1.加工订单表体分录的加工车间；\\ 2.定义报表查询的加工车间范围。                |
|  加工订单编号  | 1.加工订单的单据编号；\\ 2.定义报表查询的加工订单范围。                    |
|  产品编码    | 1.加工订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。                 |
|  物料编码    | 1.进行加工加工的子项物料的编码；\\ 2.定义报表查询的产品编码范围。               |
|  物料控制项   | 1.用于确定报表中纳入领料分析的物料范围；\\ 2.包含：所有物料、非倒冲物料、关键物料三个选项。  |
|  单据类型    | 1.加工订单的单据类型；\\ 2.定义报表查询的加工订单的单据类型。                 |
|  挂起状态    | 对应加工订单分录行的挂起状态。                                    |
|  业务状态    | 1.对应加工订单分录行的业务状态；\\ 2.包含：下达、开工、完工、结案，结算五个选项。       |
|  汇总类型    | 1.报表进行汇总的分类依据；\\ 2.包含：物料，车间+物料两个选项。                |
=====2.2 报表字段 =====
^  **字段**   ^  **说明**                               ^
|  物料编码     | 加工订单表体分录对应加工用料清单的【物料编码】               |
|  物料名称     | 加工订单表体分录对应加工用料清单的【物料名称】               |
|  规格型号     | 加工订单表体分录对应加工用料清单的【规格型号】               |
|  单位       | 加工订单分录行对应加工用料清单的子项分录的物料加工页签的【库存单位】    |
|  来料不良退料数  | 加工加工过程中，因为来料品质导致的不良品的原材料数量            |
|  作业不良退料数  | 加工加工过程中，因为制程缺陷或者人员操作等问题，导致的不良品的原材料数量  |
|  补料数量     | 为完成加工计划，额外领取的物料的数量                    |
|  报废数量     | 加工加工过程中，因为各种原因导致原材料报废的数量              |
|  产品编码     | 加工订单表体分录对应的【产品编码】字段值                  |
|  产品名称     | 加工订单表体分录对应的【产品名称】字段值                  |
|  产品规格型号   | 加工订单表体分录对应的【产品规格型号】字段值                |
