====== 1.报表功能 ======

核算维度明细账经常用于进行核算维度分类汇总后的明细查询，如显示在建工程项目所涉及的所有科目的明细值，有利于企业了解核算维度的明细情况，利于决策和业绩考核。核算维度明细账可以与核算维度分类总账进行联查对账，二者可互相联查。方便用户进行即时账务检查。

支持按非连续核算维度范围查询。

当不按核算维度分页显示时支持核算维度分列显示。

支持多个科目合并显示。

支持显示汇率字段。
====== 2.过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置会计年度期间、科目和核算维度范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。
^ 过滤项              |^ 说明                                                                             ^
| 连续核算维度范围查询        || 默认选项，选中此项，则选择起始核算维度后，账表按所选核算维度编码范围内的所有核算维度查询。                                        |
| 非连续核算维度范围查询        || 选中此项，账表按所勾选的核算维度查询。                                      |
| 使用核算维度组合查询       || 选中此项，核算维度查询界面为核算维度组合选择界面，用户设置多个核算维度查询；反之，核算维度查询界面只能选择某个核算维度查询。                 |
| 核算维度组合           || 选中“使用核算维度组合查询”，用户可设置多个核算维度组合成新的核算维度进行查询。                                       |
| 核算维度             || 设置查询的核算维度。                                                                     |
| 核算维度次级           || 核算维度所关联的基础资料存在分组时，支持按次级查看。\\ 核算维度次级为0时只显示最明细的核算维度的数据，次级为1时显示1级核算维度的汇总数据，依次类推。  |
| 核算维度编码           || 设置查询的核算维度范围。                                                                   |
| 显示禁用核算维度         || 选中此项，核算维度查询范围能显示已禁用维度；反之，则不能显示已禁用维度。                                           |
| 只显示明细核算维度        || 选中此项，只显示最明细级别的核算维度。                                                            |
| 核算维度无发生额不显示      || 选中此项，没有发生额的核算维度不显示。                                                            |
| 核算维度从未使用不显示      || 选中此项，核算维度已启用但无业务发生额的不显示。                                                       |
| 余额为零且无发生额不显示     || 选中此项，余额为零且无发生额的核算维度不显示。                                                        |
| 按核算维度分页显示        || 选中此项，账表按核算维度分页显示；反之，则不分页，所有核算维度数据在一页显示。                                        |
| 核算维度分列显示        || 选中此项，核算维度编码和名称分列显示；反之，则不分列，编码和名称显示在一列。                                        |
| 显示禁用科目           || 选中此项，查询结果包含已经禁用会计科目的金额数据。                                                      |
| 包括未过账凭证          || 选中此项，查询结果包含未过账凭证的金额数据。                                                         |
| 多个科目合并显示        || 选中此项， 查询结果中某个核算维度显示多个科目的明细数据时， 不区分科目显示期初余额、本期合计、本年累计，而是将三个数据汇总后显示在相应的位置。                                   |
| 不显示无发生额的期间合计        || 选中此项，无发生额的期间不显示本期合计及本年累计。|
| 按计量单位组默认单位核算     || 选中此项，数量金额辅助核算的会计科目对应明细数据单位取值来源为----科目选择的计量单位组对应的默认计量单位；否则，报表按科目所选计量单位进行核算。     |

====== 3.操作说明 ======

  * 系统支持核算维度分类明细账联查核算维度分类总账，用户选择需要联查的记录，点击菜单的查看总账按钮联查核算维度分类总账信息。用户还可以通过【查看凭证】菜单查看核算维度明细账记录对应的凭证。 
  * 系统支持跳转功能，用户点击“跳转”按钮调用分页账表目录，通过双击任意行来实现快速跳转到指定分页。
