**功能概述**

用于设定生成凭证的过程中，对生成方式的控制方法和策略。
参数的取值定义后，允许再次修改。修改后对以往凭证不做修改，仅对未来生成的凭证产生影响。

**功能路径**

【财务会计】－>【智能会计平台】－>【参数设置】－>【智能会计平台参数】。

**参数说明**

| **参数**                  || **说明**                                                                                                                                                                                                                                               |
| 尾差允许范围                  || 控制业务单据生成凭证时尾差的允许范围；对于范围内的尾差，系统将自动进行调整。                                                                                                                                                                                                               |
| 尾差调整方式                  || 控制业务单据生成凭证时尾差的调整方式；默认为“调整至金额最大的分录行”。                                                                                                                                                                                                                 |
| 尾差调整科目                  || 若尾差调整方式为“调整至固定科目”，则在此处定义固定科目。                                                                                                                                                                                                                        |
| 凭证顺序生成方式                || 控制业务凭证生成总账凭证时，总账凭证的凭证号排序方式；可选项分为：来源单据.凭证日期、来源单据.单据编号、凭证日期。默认勾选来源单据.凭证日期。                                                                                                                                                                             |
| 凭证分录排序方式                || 控制生成总账凭证分录排序，可选项：不排序、先借后贷；设置不排序时生成凭证分录按凭证模板分录排序，设置先借后贷时生成总账凭证分录按借借贷贷排序。                                                                                                                                                                              |
| 汇率不一致时合并生成凭证            || 控制业务凭证生成总账凭证时，业务凭证的多条分录行合并成总账凭证的一条分录行是否受汇率相同的限制。默认不勾选。                                                                                                                                                                                               |
| 单价不一致时合并生成凭证            || 控制业务凭证生成总账凭证时，业务凭证的多条分录行合并成总账凭证的一条分录行是否受单价的限制。默认不勾选。                                                                                                                                                                                                 |
| 删除总账凭证同时删除业务凭证          || 勾选此项，用户删除总账凭证时，系统将自动删除对应的业务凭证。默认勾选。                                                                                                                                                                                                                  |
| 总账凭证的分录行合并              || 此参数控制业务凭证的多条分此参数控制业务凭证的多条分录是否合并生成总账凭证的一条分录，默认勾选。\\ 勾选时则判断合并项包含凭证模板、业务分类行号、科目、核算维度、币别、借贷方向、汇率类型、（汇率）、（摘要）、（单价）、结算方式、结算号、业务编号全部一致时则合并；----括号的合并项有参数控制。\\ 不勾选时，则完全不合并，业务凭证的一行分录对应总账凭证的一条分录。\\ 注意：如果是不同类型单据合并生成总账凭证则合并项不包含凭证模板和业务分类行号，如应付单和付款单合并生成总账凭证。  |
| 摘要不一致时合并生成              || 用于控制业务凭证的多条分录合并生成总账凭证的一条分录时是否要受摘要的限制。默认不勾选。\\ 勾选时，则合并项排除摘要，摘要不同可以合并，前提是其他合并项必须相同，见“总账凭证分录合并”参数说明。\\ 不勾选时，则合并项包含摘要，摘要相同则允许合并。                                                                                                                         |
| 摘要不一致合并规则               || 摘要不一致合并规则用于控制业务凭证生成总账凭证时，业务凭证的多条分录行只摘要不同合并成总账凭证的一条分录行，该总账凭证分录行中摘要的取值方式；\\ 可选：显示固定摘要、显示第一行摘要、显示最后一行摘要、显示所有分录行摘要，默认为“显示固定摘要”。\\ 若选中“显示所有分录行摘要”，则凭证生成时按总账凭证摘要字段长度限制自动截取。\\ 若选中“显示固定摘要”，则需要定义固定摘要。当摘要不同合并分录取固定摘要。                                        |
| 借贷方向不相同分录合并             || 用于控制业务凭证生成总账凭证时，业务凭证的多条分录行合并成总账凭证的一条分录行是否受借贷方向的限制。默认不勾选\\ 勾选时，合并项排除借贷方向，借贷方向不同可以合并；\\ 不勾选时，则合并项包含借贷方向，借贷方向相同则允许合并。\\ （此参数是2022年9月份补丁增加的）                                                                                                             |
| 自动覆盖异常的业务凭证             || 勾选该参数，执行生成总账凭证时会自动覆盖上次生成的异常的业务凭证，重新生成业务凭证，并进一步生成总账凭证。不勾选，则不覆盖。                                                                                                                                                                                       |
| 凭证生成自动覆盖正常的业务凭证         || 用于控制单据生成业务凭证，是否覆盖已有的正常业务凭证。\\ 勾选时，单据存在无修改过的正常业务凭证，单据执行凭证生成按凭证模板重新生成业务凭证。\\ 不勾选时，单据存在正常业务凭证，单据生成凭证则直接取已有的业务凭证生成总账凭证。\\ （此参数是2022年6月补丁PT-146915增加的）                                                                                                    |
| 凭证生成结果展示                || 凭证生成结果展示支持：“显示凭证生成报告”、“显示凭证列表”、“显示凭证生成报告和凭证列表”三个选项，参数默认选中“显示凭证生成报告”。勾选“显示凭证列表”时，若生成的总账凭证只有一张则直接弹出凭证修改界面，多张时显示总账凭证列表。                                                                                                                                 |
| 核算维度存货类别按物料对应核算组织取值     || 用于控制科目挂了核算维度存货类别取物料上的存货类别，凭证生成和对账是取账簿核算组织物料的存货类别，还是取单据上使用组织物料的存货类别。\\ 勾选时，凭证生成和对账，科目核算维度取账簿核算组织的物料上的存货类别（需要把物料分配到账簿核算组织）。\\ 不勾选时，凭证生成和对账，科目核算维度取单据上所选组织的物料上的存货类别（如果单据上所选组织的物料没有分配到账簿核算组织下级组织，则核算维度获取不到）\\ 主要适用核算组织和下级组织的存货类别不一致的情况                   |
| 凭证生成和对账取单据使用组织的物料       || 用于控制按存货类别区分科目，即凭证模板科目影响因素设置不同存货类别对应不同的科目，因素来源取物料上的存货类别，以及业务报表对账过滤条件设置物料存货类别，凭证生成和对账是取账簿核算组织物料的存货类别，还是取单据上使用组织物料的存货类别。\\ 勾选时，则凭证生成和业务报表对账取单据使用组织的物料的存货类别；\\ 不勾选时，则凭证生成和业务报表对账取账簿核算组织下的物料存货类别（需要把物料分配到账簿核算组织）；\\ 主要适用核算组织和下级组织的存货类别不一致的情况              |
| 汇总生成凭证失败所有单据不生成总账凭证     || 勾选参数时，生成总账凭证方式为全部或匹配，汇总生成总账凭证，其中一张单据生成凭证失败则其他单据都不允许生成总账凭证。                                                                                                                                                                                           |
| 凭证生成自动指定现金流量            || 勾选参数时，如果凭证模板没有设置现金流量项目则凭证生成的科目取科目的预设项目。                                                                                                                                                                                                              |
