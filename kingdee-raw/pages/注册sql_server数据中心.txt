====== 1 功能描述 ====== 

当数据库服务器与应用服务器分开部署时，数据中心注册便于将存放在数据库服务器上的数据中心注册到应用服务器上，另外，还提供了反注册功能，当不再使用该数据中心时，可以反注册该数据中心。

**功能路径**

【数据中心列表】 

====== 2 字段说明 ======

  - 数据中心代码：输入1-100个字符； 
  - 数据中心名称：输入1-100个字符； 
  - 数据库服务器：定义当前数据库服务器的机器名称； 
  - 数据库服务器用户：输入数据库服务器用户名称； 
  - 数据库服务器密码：输入数据库服务器用户密码； 
  - 数据中心实体：选数据库服务器已有的数据中心实体。 



=====  2.1 数据库服务器 ===== 
定义当前数据库服务器的机器名称或者数据库服务器IP地址。
 
=====  2.2 数据库链接用户 ===== 

==== 2.2.1 身份验证 ====

支持SQL Server身份验证和Windows身份验证。
  - 若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
  - 若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码；

==== 2.2.2 登录名 ====

输入数据连接用户的帐号； 

==== 2.2.3 密码 ====

输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户； ​

===== 2.2 数据中心 =====


==== 2.2.1 数据库实体 ====
系统自动生成数据中心实体名称，可以根据需要调整名称； ​

==== 2.2.2 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

===== 2.2.3 其他字段 =====

  - 数据中心代码：输入1-100个字符；
  - 数据中心名称：输入1-100个字符； 
 ​

====== 3 功能操作 ======

===== 3.1 注册SQL Server数据中心 =====

在【数据中心列表】中，点击按钮组的下拉按钮【注册SQL Server数据中心】，如果管理中心是SQLServer类型的，直接点击工具栏【注册】按钮，即可打开“注册SQL Serve数据中心”界面进行操作。

  SQL Sever数据中心注册过程如下：
  
  1、输入数据库服务器。
  
  2、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到数据中心。
  
     数据库连接用户支持SQL身份验证和Windows身份验证两种方式。
     
     1）若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
     
     2）使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
     
     3）若选择SQL Serve身份验证，请输入SQL Serve数据库用户名和密码。
     
  3、输入数据中心基本信息，包括数据中心代码、名称、数据库实体等内容。
  
     注意数据中心实体必须选择数据中心类型的数据库实体，不能选择管理中心类型的数据库实体。
     
  4、在注册界面中，确认相关信息后，点击【注册】按钮，系统即可完成SQL Server数据中心的注册工作。



  
===== 3.2 反注册数据中心  =====   
 
在【数据中心列表】中，选中注册的数据中心，点击工具栏【反注册】按钮，系统即可进行反注册。 

 
====== 4 其他说明 ======   
 
  - 数据中心注册成功后，在管理中心主页的列表界面会增加一条数据中心记录，可供选择登录和使用。 
  - 可以对已注册的数据中心进行反注册操作，反注册后将不在列表中显示，用户也不能登录及使用该数据中心，反注册后不会删除数据库实体。 
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。
