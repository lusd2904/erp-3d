====== 单据常规属性列表 ======

| 属性名称          || 属性描述                                                                                                                         |
| 唯一标识          || 设置单据的全球唯一标识符，可以通过自动生成或者手工输入方式添加。                                                                                             |
| 名称            || 设置单据的名称，包括英文、简体和繁体三种语种。                                                                                                      |
| 标题            || 设置单据窗口标题名称，包括英文、简体和繁体三种语种。                                                                                                   |
| 主键字段名         || 设置单据对应的物理数据表的主键的字段名。                                                                                                         |
| 主键字段类型        || 设置单据对应的物理数据表的主键的字段类型。                                                                                                        |
| 单据类型字段        || 设置相同单据的不同类型。                                                                                                                 |
| 表单插件          || 设置表单和服务器的插件，扩充、完善单据的功能。                                                                                                      |
| 列表插件          || 设置列表插件。                                                                                                                      |
| 操作列表          || 从系统内置的操作类型中选取单据操作。                                                                                                           |
| 缺省快捷过滤字段      || 设置快捷查询栏缺省字段及条件。                                                                                                              |
| 附件菜单控制        || 设置单据状态控制附件新增界面工具栏按钮锁定性方案。                                                                                                    |
| 表单构建插件        || 设置插件配置信息。                                                                                                                    |
| 列表双击事件        || 设置当双击序时簿时触发的扩展服务。                                                                                                            |
| 子系统           || 设置单据所属的子系统名称。                                                                                                                |
| 用户参数对象        || 设置用户参数模板。                                                                                                                    |
| 权限对象          || 设置单据的权限项。                                                                                                                    |
| 模版            || 设置是否为基类单据。                                                                                                                   |
| 过滤窗口业务对象      || 设置序时簿过滤界面类型。                                                                                                                 |
| 功能特性          || 设置功能特性。                                                                                                                      |
| 高度            || 设置单据的显示宽度。                                                                                                                   |
| 宽度            || 设置单据的显示宽度。                                                                                                                   |
| 布局名称          || 默认布局名称。                                                                                                                      |
| 每页显示行数        || 设置列表界面每页显示的最大行数。                                                                                                             |
| 显示标题          || 设置单据界面是否显示单据标题。                                                                                                              |
| 显示菜单          || 设置单据菜单集合中的工具条可见性。                                                                                                            |
| 菜单集合          || 设置单据上的工具栏按钮。                                                                                                                 |
| 列表菜单          || 设置单据列表的工具栏按钮。                                                                                                                |
| 子领域           || 默认业务领域。                                                                                                                      |
| 编码规则          || 设置单据编号生成规则（支持将单据上的文本字段、日期字段、查找字段、流水号和常量等进行组合形成编码规则）。                                                                         |
| 列表条件格式化       || 设置序时簿界面的单据行颜色（前景色和背景色）。                                                                                                      |
| 是否支持分发        || 设置是否支持分发。                                                                                                                    |
| 写操作日志         || 设置是否写操作日志。                                                                                                                   |
| 单据关联配置        || 设置单据转换字段关联关系。                                                                                                                |
| SL客户端插件类      || 设置SL客户端插件类。                                                                                                                  |
| 控制字段权限        || 控制运行时是否支持设置单据字段权限。                                                                                                           |
| 控制权限          || 设置是否需要进行单据权限控制。                                                                                                              |
| 数据规则列表        || 设置数据规则类型。                                                                                                                    |
| 默认套打模板        || 设置默认套打模板。                                                                                                                    |
| 列表业务对象        || 设置列表业务对象。                                                                                                                    |
| 帮助上下文标识       || 设置运行时F1调用帮助文档。                                                                                                               |
| 不使用单据类型过滤     || 设置是否使用单据类型过滤。                                                                                                                |
| 快速录单视图        || 设置单据快速录单界面视图。                                                                                                                |
| 单据类型参数对象      || 设置单据类型参数对象。                                                                                                                  |
| 单据状态字段        || 设置单据的状态对应的字段                                                                                                                 |
| 组织变更服务插件      || 设置组织变更服务插件                                                                                                                   |
| 列表默认过滤方案      || 设置列表默认过滤方案                                                                                                                   |
| 列表默认排序字段      || 设置列表默认排序字段                                                                                                                   |
| 允许单元格切换事件     || 设置是否允许单元格切换事件                                                                                                                |
| 支持批量插入        || 数据层提供了两种方式插入数据：逐行插入和批量插入。未勾选时，表示采用逐行插入到数据库。不同版本的数据库在不同的数据量下，哪种插入方式最优是需要专业人员判断的。如果使用有误可能引起表阻塞，插入慢等问题。因此，建议在专业人员分析下再决策调整写入方式。  |
| 序事簿业务对象       || 单据以列表界面进行数据展示时所使用的业务对象，目前平台提供了两种标准列表对象，普通列表，树形列表，用户也可以封装自定义的列表对象                                                             |
| 禁止自定义控件下载     || 设置是否禁止下载自定义控件                                                                                                                |
| 汇总取最大精度       || 设置汇总时是否取最大精度                                                                                                                 |
| 禁用布局编辑        || 设置是否禁用布局编辑                                                                                                                   |
| 检测插件          || 设置检测插件                                                                                                                       |
