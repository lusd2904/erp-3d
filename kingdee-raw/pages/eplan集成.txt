====== Eplan集成概述 ======
   Eplan集成主要是将Eplan图纸作为文档资料导入到Cloud PLM系统中，并且提取图纸的相关属性建立文档组结构，实现图纸与物料一体化的集成
   帮助您在产品设计中更方便的跟Cloud PLM系统进行数据交换，从而提高设计效率，有效的保证了设计图纸的正确性，并根据图纸指导产品结构的搭建。
====== EPLAN集成操作手册 ======
===== 1. 基本配置 =====
==== 1.1 文件类型 ====
   功能路径：
   【PLM】→【系统建模】→【文件类型列表】
{{:1.1eplan文件类型.png|}}

   功能说明：
   【后缀名配置】
   配置Eplan集成导入PLM系统所支持的文件类别，Eplan文件类型只支持ELK作为后缀的文件
   【数据对应关系】
   维护图纸属性与系统文档属性的对应关系
   物理文件字段：与图纸上的属性名称一致，用于提取图纸属性。
   系统属性字段：是物料属性字段，应用于物料匹配和界面呈现。
   必填项：控制某一字段导入和检入时必填 
   一般字段：表示物料属性；
   BOM字段：表示BOM关系属性。
   别名：配置了别名后，在导入、检入页面显示的就是别名，而不是系统字段名

   注意：
   读取数据以物理文件字段为准，反写数据以物理文件属性标识为准

===== 3. 集成操作 =====
==== 3.1 集成工具登录、注销和打开系统 ====
  - 打开PLM客户端，右键→【CAD】→【登录PLM】，在弹出的登录界面上输入用户名和密码，确定后登录。此处登录并不是打开PLM系统，而是集成工具跟PLM建立连接。 
  - 选择菜单【CAD】→【注销PLM】，注销登录系统的用户 
  - 选择菜单【CAD】→【打开PLM】，弹出我们的PLM系统登录界面，输入用户名和密码即可登录金蝶云，进入PLM系统进行操作。
==== 3.2 物料匹配 ====
  - 点击【PLM菜单】→【物料匹配】，根据EPLAN文件类型里的数据对应关系读取元器件的物理文件字段属性值，显示对应的系统属性字段。
  - 在物料匹配页面可以根据条件去匹配物料库里的物料，从而将匹配到的物料属性值写入到该页面，保存后反写回图纸。

{{:3.2.1物料匹配界面.png|}}

   说明：
   查询条件：条件字段来源于EPLAN文件类型数据对应关系里配置的一般字段；
   是否交集：当查询条件选择了多个字段时，默认是以“或”去查询，勾选了是否交集后，则多个字段以“且”去查询物料；
   是否跳过已匹配：勾选后，重复点击匹配时已匹配的行就不会重新进行匹配； 
   是否模糊匹配：勾选了后就是用查询条件去模糊查询物料。
   “是否交集”与“是否模糊匹配”互斥，选择其中一个，另一个置灰。

{{:3.2.1多个物料匹配结果.png|}}
   匹配结果说明：
   通过查询条件只匹配到一个物料时，整行会变成绿色，提示已匹配
   通过查询条件匹配到多个物料时，整行变成黄色，会提示“请在匹配物料字段中选择”。在匹配物料列里点击后按空格键，会出来匹配到的物料或者点击放大镜图标，在弹出的列表中选择。
   物料匹配页面保存关闭后再次打开，已匹配的行默认是黑色字体，重新匹配才会刷新颜色，跳过已匹配的行也不会变颜色。

== 3、Eplan文档导入 ==
  点击【PLM菜单】→【导入文档】，弹出导入文档页面
  在导入页面选择业务类型和文件夹，同时选择产品物料
  导入成功后，根据导入页面的数据解析文档及其结构，同时创建BOM，默认展开装配体图纸的第一层结构

{{:3.3.3导入界面.png|}}

  解析图纸生成BOM结构说明：
  EPLAN 集成的文档形成 3 层结构
  1）根物料：该 EPLAN 项目对应的挂载物料，可以是物料和产品，可以新建或选择；
  2）电缆：该类器件以长度计量，放在第二层，挂载在项目下；
     箱体：位置标志，所有器件都会在箱体内部安装和工作，箱体（导入时取高层代号标识）作为非标准器件放在BOM 的第二层，挂载在根物料下，导入时为“新建状态”；
  3）器件：器件是电气器件库的标准器件，事先在 PLM 物料库维护好之后，挂载在第三层，归属于安装的箱体。

  导入规则：
  1）电子集成图纸导入物料索引默认为物料编码，不可更改
  2）系统中不允许存在相同名称的图纸（包括后缀）；
  3）从物理文件中获取的BOM 信息，并按照Eplan的数据对应关系配置将数据填充到界面中。当BOM 数据（除物料编号的其他属性）和系统中的物料属性不一致时，不做比对和更新动作，以系统的为准；
  4）第一次文档导入后，再进行第二次文档的导入，如果用户不清除缓存，系统会记忆第一次导入系统的文件夹位置；
  5）导入后系统会创建物料BOM 关系并与工程文件和原理图建立相关对象关系；
  6）高层代号进入系统时是“新建物料”状态，其业务类型跟随产品物料的业务类型、编码是组合而成“产品物料编码_高层代号结构标识”，均为系统默认生成，无法更改；
  7）Eplan本身会生成PDF，在图纸导入系统时，PDF也一并上传至电子仓。但PDF不会在文档库显示，支持浏览PDF；
  8）在上传文档成功之后，实现图纸物料强关联，从而查到该物料挂载的BOM物料清单，同时在设计BOM库中，已生成挂载在上传物料的BOM极其子BOM关系

  以下情况无法成功导入：
  1）选择父物料本身已存在BOM；
  2）Eplan图纸在此之前已在PLM中进行过导入文档操作；
  3）元器件在系统中无对应物料，在导入界面会提示“物料不存在”。

  注意：
  1）选择的业务类型必须关联Eplan文件类型；
  2）在Eplan文件类型的数据对应关系里配置了对应关系，则在导入、检入页面会显示对应的系统字段；
  3）BOM关系随对应的文档一起导入，导入文档后，在设计BOM库中可以看到对应的BOM关系。

==== 3.4 查找文档 ====
点击【PLM菜单】→【查找文档】，在打开的查询窗口上，可以按照一定的条件对PLM系统内的文档进行查询。查找文档页面显示*.ZW1后缀的文档

{{:3.4查找文档.png|}}
  【检出】将选中的文档检出到工作目录（在【工作中心】>【个人设置】里设置）；
  【标记检出】只将文档设置为检出状态，不会下载文档；
  【撤销检出】撤销文档的检出状态
  【打开文档】以只读的方式下载文档并打开，也可以双击打开文档。
==== 3.5 导入到项目输出 ====
点击【PLM菜单】→【导入到项目输出】，选择项目，会自动带出项目的输出文件夹，点击导入后，会把图纸导入到文档库的同时把导入页面的所有文档关联到项目的输出

{{:3.5导入到项目输出.png|}}
==== 3.6 导入到任务输出 ====
点击【PLM菜单】→【导入到任务输出】，选择任务，会自动带出任务的输出文件夹，点击导入后，会把图纸导入到文档库的同时把导入页面的所有文档关联到任务的输出里

{{:3.6导入到任务输出.png|}}
==== 3.7 标记检出 ====
点击【PLM菜单】→【标记检出】，根据当前Eplan打开文档名称从系统中找到对应图纸，标记检出

{{:3.7标记检出.png|}}
==== 3.8 检入文档 ====
点击【PLM菜单】→【检入文档】，对已经处于检出状态的当前文档进行检入操作，更新文档内容并取消文档检出状态标识恢复文档正常状态，同时会升一个版次

{{:3.8检入文档.png|}}
  检入规则：
  1）检入时，子物料判断规则满足导入规则；
  2）检入不会更新物料的属性；
  3）不允许修改文档的文件名称；
  4）检入后更新关联的BOM；
  5）检入时，如果发现原理图没有产品物料，则允许新建/选择产品物料重新构建；如果发现有产品物料但却没有BOM，则检入后创建BOM；
  6）BOM处于已归档（对应生命周期无权修改）/在流程中/被检出状态，如果修改了图纸中的BOM关系属性或修改了结构，则不允许检入，未修改则允许检入。
