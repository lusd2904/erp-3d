====== 功能说明 ======


成本计算单可以从不同角度查看产品成本计算结果数据。 

====== 功能路径 ======


【成本管理】—>【产品成本核算】—>【报表分析】—>【成本计算单】

====== 字段说明 ======


| **字   段**     || **说 明**                          |
| 核算体系          || 当前成本计算单对应的核算体系。                  |
| 核算组织          || 当前成本计算单对应的核算组织。                  |
| 会计政策          || 当前成本计算单对应的会计政策。                  |
| 开始会计年度        || 当前成本计算单对应的开始会计年度。                |
| 结束会计年度        || 当前成本计算单对应的结束会计年度。                |
| 开始会计期间        || 当前成本计算单对应的开始会计期间。                |
| 结束会计期间        || 当前成本计算单对应的结束会计期间。                |
| 业务类型          || 当前成本计算单对应的工单生产类型。                |
| 成本中心          || 当前成本计算单对应的成本中心。                  |
| 工单编号          || 当前成本计算单对应的工单编号。                  |
| 产品编码          || 当前成本计算单对应的产品编码。                  |
| 成本项目          || 只显示所选的成本项目明细。                    |
| 费用项目          || 只显示所选的费用项目明细。                    |
| 显示方式          || 当前成本计算单对应的显示方式。                  |
| 汇总依据          || 当前成本计算单对应的汇总依据。                  |
| 多期间汇总展示       || 勾选依赖“汇总依据”，勾选后汇总展示“本期投入”、“本期完工”  |

快捷页签主要过滤项目说明
