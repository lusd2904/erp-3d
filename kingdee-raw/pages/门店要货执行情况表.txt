====== 1. 门店要货执行情况表 ======

===== 1.1 功能概述 =====
完整的配送业务会经过多个环节，涉及多个部门。管理人员跟踪配送业务过程时需要查询与要货单相关的业务单据明细，检查数据的准确性，发现可能存在的错误，门店要货执行明细表即是跟踪门店要货执行明细单报表。


===== 1.2 字段说明 =====

^ 字段      ^ 说明                       ^
| 要货组织    | 取门店要货申请单的申请组织            |
| 物料编码    | 显示门店要货申请单的物料             |
| 物料类别    | 该物料的分组信息                 |
| 是否直拨    | 该物料上设置的是否允许直拨            |
| 是否统配    | 该物料上设置的时候允许统配            |
| 加工车间    | 自制物料可以在门店要货申请汇总的设置加工车间   |
| 要货数量    | 门店要货申请的申请数量              |
| 批准数量    | 门店要货申请汇总的批准数量            |
| 收货数量    | 门店收货单的应收数量               |
| 剩余收货数量  | 配送出库单的发货数量 - 门店收货单的实收数量  |
| 异常数量    | 门店收货单的应收数量-实收数量          |
| 退货数量    | 门店退货单的退货数量               |
