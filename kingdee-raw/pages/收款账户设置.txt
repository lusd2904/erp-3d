====== 1.收款账户设置 ======

===== 1.1 功能概述 =====
  * 设置门店营业对账和门店外卖管理的收款账户信息，支持美团，饿了么，微信，微信支付，支付宝，线上支付宝等多种支付方式。
  * 选择美团或者饿了么结算方式时，收款账户字段显示为名称，编码，结算方式，执行定时下载任务，账户标识，账户秘钥，账单服务器地址，账单到账间隔天数，第三方中台，第三方中台标识，第三方中台服务器地址，外卖平台服务器地址，外卖订单到账间隔天数，组织，第三方平台门店id
  * 选择微信/支付宝的结算方式时，收款账户字段显示为名称，编码，结算方式，执行定时下载任务，设置子账户和秘钥，账户标识，账户秘钥，账单服务器地址，账单到账间隔天数，原始单字段，区分方式，区分条件
  * 把金蝶云餐饮提供给企业的账户在Cloud收款账户页面进行相应的配置。主要包括结算方式，账户标识，账户秘钥，以及该账户所要绑定的组织，一个账户可以同时绑定多个门店。
  * 收款账户中除了账户标识和账户秘钥，还需要设置每个门店支付流水的区分条件设置
  * 客户通过收款账户来设置不同平台的账户信息
  * 多个门店可以设置同一个收款账户
  * 不同的支付平台可以使用相同的收款账户

===== 1.2 字段说明 =====
^ 字段          ^ 说明                                        ^
| 名称          | 自定义，唯一值                                   |
| 编码          | 支持手工录入和自动生成                               |
| 结算方式        | 支持微信支付，支付宝，美团，饿了么，线上支付宝，微信等               |
| 执行定时下载任务    | 如果勾选则会按照设置的时间定期下载结算方式设置原始单据信息（后台设置了定时任务）  |
| 设置子账号标识和密钥  | 如果勾选则在一个账户标识下设置多个子账户标识和密钥                 |
| 账户标识        | 收款账户的标识，获取方法参考[[门店线上对账操作流程|门店线上对账操作流程]]   |
| 账户秘钥        | 收款账户的密钥，获取方法参考[[门店线上对账操作流程|门店线上对账操作流程]]   |
| 账单服务器地址     | 下载原始账单时自动填充                               |
| 账单到账间隔天数    | 微信/支付宝是1天，美团/饿了么默认3天，指的是资金从平台到个人账户的时间差    |
| 原始单字段       | 下载微信/支付宝原始单时设置不同门店的区分条件，用于分单              |
| 区分方式        | 下载微信/支付宝原始单时设置不同门店的区分条件，用于分单              |
| 区分条件        | 下载微信/支付宝原始单时设置不同门店的区分条件，用于分单              |
| 第三方中台       | 美团/饿了么外卖第三方平台，目前支持餐行键，智龙                  |
| 第三方中台标识     | 美团/饿了么外卖第三方平台的标识                          |
| 第三方中台服务器地址  | 美团/饿了么外卖第三方平台的服务器地址                       |
| 外卖平台服务器地址   | 美图或者饿了么的地址                                |
| 外卖订单到账间隔天数  | 订单产生的数据和获取数据的时间间隔                         |
