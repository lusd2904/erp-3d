====== 1.功能说明 ======

阿米巴初始化录入分两种情况进行处理：

第一种是经营账簿的启用时间是会计日历所在会计年度的第一个期间，只需录入各个经营科目的初始余额。

另外一种是经营账簿的启用时间非会计年度的第一个期间时，此时需录入截止到经营账簿启用期间的各个经营科目的本年累计收入、本年累计支出、和各个经营科目的初始余额。

**操作前提**
 
经营账簿、经营科目、阿米巴单元、汇率以及核算维度等相关基础设置已完成。


**功能路径**

【管理会计】→【经营会计】→【初始化】→【阿米巴初始化录入】

====== 2.字段说明 ======

^ 字段         |^ 说明                                       ^
| 经营账簿       || 选择需要录入初始数据的经营账簿。                         |
| 币别         || 根据经营账薄自动携带出来，不可以选择。                      |
| 汇率         || 系统默认值为币别对应经营账簿默认汇率类型的汇率。                 |
| 经营科目       || 根据经营账薄自动携带出来，不可以选择。                      |
| 阿米巴单元      || 系统根据经营账簿对应的阿米巴组织架构进行选择录入。                |
| 经营科目       || 系统根据经营账簿对应的经营科目表的范围显示所有经营科目。用户录入明细经营科目。  |
| 本年累计收入     || 用户录入阿米巴单元对应的经营科目自年初至初始设置时止的收入累计发生额。      |
| 本年累计支出     || 用户录入阿米巴单元对应的经营科目自年初至初始设置时止的支出累计发生额。      |
| 期初余额       || 用户录入阿米巴单元对应的经营科目的期初余额。                   |
| 核算维度       || 当经营科目分类挂核算维度时，用户录入经营科目相关核算维度的初始数据。       |
====== 3.操作说明 ======

  * 核算维度初始数据录入

经营科目如果挂了核算维度核算，阿米巴初始化录入允许录入对应核算维度的初始数据。点击经营科目的核算维度栏的单元格，系统弹出核算维度初始数据录入界面。用户在该界面录入数据，用户点击该界面的工具栏菜单【批量填充】，可以批量录入核算维度初始数据。


====== 4.其他说明 ======

初始数据录入工作可以和日常单据录入工作同时进行，只要在期末处理前关闭初始化即可。
