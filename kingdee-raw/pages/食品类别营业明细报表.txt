===== 1.功能概述 =====
食品类别营业明细报表按帐单编号展示食品各大类的销售额和净售金额。
====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【食品类别报表分析】→【食品类别营业明细报表】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总、排序

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
  * 排序页签：报表显示字段排序

====== 5.报表字段说明 ======
^ 字段      ^ 说明               ^
| 组织      | 组织名称             |
| 营业日期    | 营业日期（清机起始日期）     |
| 市段      | 就餐时间，如午市、下午和晚市等  |
| 账单编号    | 账单编号，如00028      |
| 楼层编码    | 楼层编码             |
| 楼层名称    | 楼层名称             |
| 房台编码    | 房台编码             |
| 房台名称    | 用户使用房间区域名称       |
| 开台时间    | 开台时间             |
| 结账时间    | 结账时间             |
| 食品类别合计  | 食品各类别收入金额合计      |
| 销售收入合计  | 食品各类别折后金额合计      |
====== 6.报表操作说明 ======

1、报表提供打印、引出功能。

2、报表提供按表头的【组织】、【营业日期】等统计分析各个账单编号中食品类别的销售金额和净现金金额

3、报表提供过滤→分组汇总，在报表中对分组字段进行统计分析，其中分组字段包括：组织、营业日期

4、可以通过勾选【选项】中的参数，控制数值的显示 。
