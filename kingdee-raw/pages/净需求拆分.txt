======1 净需求拆分======
=====1.1 功能概述=====
在企业运作过程中，某些半成品会按照不同的BOM版本生产，亦或某些材料按照不同的供应商来进行采购。
通过设置净需求拆分规则，可以在计划运算生成计划订单前按照提前设定的规则进行净需求的拆分。

=====1.2 使用前提=====

  * 定义【物料】
  * 定义【BOM版本】
  * 定义【辅助属性】
  * 定义【供应商】  

=====1.3 功能路径=====

 进入【生产制造】—>【计划管理】—>【基础数据】—>【净需求拆分】

======2. 字段说明======

=====2.1 常规页签===== 

|**字段**|**说明**|
|编码|维护净需求拆分规则的编码|
|名称|维护净需求拆分规则的名称|
|供应组织|维护净需求拆分规则的供应组织|
|物料编码|维护净需求拆分规则的物料编码|
|数据状态|维护净需求拆分规则的数据状态|


=====2.2 供应明细页签=====
|  **字段**  |  **说明**                                    |
|  BOM版本   | 维护供应组织下的BOM版本                              |
|  辅助属性    | 维护物料的辅助属性                                  |
|  供应商     | 维护供应组织下的供应商                                |
|  比例      | 维护拆分的相对比例\\ 如两行的拆分比例分别是2和3，则按照40%和60%进行拆分  |
|  类型      | 维护净需求拆分后的供应类型                              |
|  生效日期    | 维护拆分明细的生效日期\\ 净需求拆分时，根据净需求的需求日期来判断拆分规则是否生效                                |
|  失效日期    | 维护拆分明细的失效日期\\ 净需求拆分时，根据净需求的需求日期来判断拆分规则是否生效                                |
