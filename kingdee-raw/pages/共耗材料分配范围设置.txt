ID: 共耗材料分配范围设置
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%B1%E8%80%97%E6%9D%90%E6%96%99%E5%88%86%E9%85%8D%E8%8C%83%E5%9B%B4%E8%AE%BE%E7%BD%AE

====== 功能说明 ======

用于解决其他出库和简单生产的共耗材料。主要解决以下问题：
  * 完工产品分配到的共耗材料费用与其生产周期匹配。比如设置耗用周期为1天，则当天领用的共耗材料在当天完工产品中分配。
  * 按共耗材料设置不同的费用分配标准，比如共耗材料A、B、C分别按面积、周长、重量分配。

====== 功能路径 ======

【成本管理】—>【产品成本核算】—>【分配标准设置】—>【共耗材料分配范围设置】

====== 字段说明 ======

主要字段说明

===== 单据头 =====
^ 字段     ^ 说明                                     ^
| 编码     | 当前共耗材料分配范围设置的方案的编码。                    |
| 名称     | 当前共耗材料分配范围设置的方案的名称。                    |
| 核算体系   | 当前共耗材料分配范围设置的对应的核算体系。                  |
| 核算组织   | 当前共耗材料分配范围设置的对应的核算组织。                  |
| 会计政策   | 当前共耗材料分配范围设置的对应的会计政策。                  |
| 发送方设置  | 当前共耗材料分配范围设置的发送方是按物料/存货类别/物料分组中的某一类设置  |
| 接收方范围  | 当前共耗材料分配范围设置的接收方是按物料/存货类别/物料分组中的某一类设置  |

===== 单据体 =====

^ 字段      ^ 说明           ^
| 发送方     | 指定对应的发送方     |
| 费用分配标准  | 指定对应的费用分配标准  |
| 接收方     | 限定对应的接收方     |
| 材料耗用周期  | 限定材料耗用周期     |

====== 操作说明 ======

  * 按“核算体系+核算组织+会计政策”设置，发送方范围设置，从物料、存货类别、物料分组中选择一种。接收方范围设置，从空（指全部范围）、物料、存货类别、物料分组中选择一种，支持多选基础资料。
  * 此处设置的费用分配标准，优先级高于费用分配标准设置。
  * 费用分配标准为完工入库数量、完工入库数量（辅助单位）及其复合分配标准时，允许设置材料耗用周期。规则：当设置材料耗用周期为1天时，当天共耗领料分配给当天的入库产品，比如领料日期为1月3日，则可分配产成品的入库日期为（1月3日0点， 1月4日0点），以此类推，耗用结束日期最大不超过当前期间的结束日期。
  * 费用分配标准为其他时，支持设置不同于费用分配标准设置_共耗材料的分配标准。
