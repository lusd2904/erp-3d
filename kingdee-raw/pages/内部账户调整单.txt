====== 内部账户调整单 ======

=====1 功能说明 =====
    
当企业存在不同组织之间的代收代付业务时，组织之间需要根据内部账户进行还款，或者内部账户之间进行抵消的业务

=====2 操作前提 =====

定义了收付组织、单据类型、银行、银行账号、币别及内部账户基础资料。

=====3 功能路径 =====

【财务会计】—>【出纳管理】—>【日常处理】—>【内部账户调整单】

=====4 字段说明 =====

====4.1 单据头字段说明 =====
| **字段**      || **说明**                                                                                                              |
| 单据类型        || 选择录入内部账户调整单单据类型名称。根据业务类型的不同，单据类型分为两类：内部账户收入调整单和内部账户付款调整单据类型。\\ 注意：根据不同的业务类型需要选择不同的单据类型，不同的单据类型在后续业务处理上遵循不同的业务处理规则。  |
| 单据编号        || 内部账户调整单单据编号                                                                                                         |
| 开设组织        || 需要调整的内部账户开设组织                                                                                                       |
| 内部账户        || 需要调整的内部账户                                                                                                           |
| 对应组织        || 内部账户对应组织                                                                                                            |
| 业务日期        || 调整日期                                                                                                                |
| 币别          || 调整币别                                                                                                                |
| 本位币         || 显示本次调整的开设组织所对应的默认核算体系的核算组织默认的会计政策的本位币。                                                                              |
| 汇率类型        || 显示本次调整的开设组织所对应的默认核算体系的核算组织默认的会计政策的汇率类型。                                                                             |
| 汇率          || 调整的原币和本位币的汇总                                                                                                        |
| 调整金额        || 由系统根据表体的调整金额自动计算整单调整金额。                                                                                             |
| 调整金额本位币     || 显示调整金额的本位币                                                                                                          |

====4.2 单据体字段说明 =====
|**字段**||**说明**|
|结算方式||选择录入调整业务对应的结算方式。|
|银行账号||如果本次调整业务是通过银行类的结算方式进行结算，则需要录入开设组织调整的银行账号。|
|现金账号||本次调整业务是通过现金类的结算方式进行结算，没有现金账号不需要录|
|调整金额||本次调整金额|
|调整金额本位币||本次调整金额本位币|
|手续费||手续费|
|手续费本位币||手续费本位币|
|结算号||银行结算号|
|摘要||录入本次调整业务的摘要信息。|
|对方银行账号||如果本次调整业务是通过银行类的结算方式进行结算，则需要录入对应组织调整的银行账号。|
|对方现金账号||本次调整业务是通过现金类的结算方式进行，没有现金账号不需要录|

=====5 操作说明 =====
1、单据类型为内部账户付款调整，单据审核后内部账户金额减少，开设组织金额减少，对应组织金额增加。

2、单据类型为内部账户收款调整，单据审核后内部账户金额增加，开设组织金额增加，对应组织金额减少。
