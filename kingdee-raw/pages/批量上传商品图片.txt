ID: 批量上传商品图片
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%89%B9%E9%87%8F%E4%B8%8A%E4%BC%A0%E5%95%86%E5%93%81%E5%9B%BE%E7%89%87

**功能说明：**

用于维护商品档案时，批量导入上传商品图片

**功能路径：**

【商品】->【商品档案】->【商品档案】

**使用前提：**

无

**字段说明：**

  * 批量上传商品图片的导入模版字段说明如下：

| **数据库字段名**                            | **字段名称**  | **导入字段填写说明**                                                                                                                                     |
| FPKID                                 | 主键        | 全部设为0，系统自增长                                                                                                                                      |
| FCREATORID                            | 创建人       | 默认为0                                                                                                                                             |
| FMODIFIERID                           | 修改人       | 默认为0                                                                                                                                             |
| FCREATEDATE                           | 创建日期      | 导入时可默认为1900-01-01 00:00:00.0，可修改                                                                                                                 |
| FMODIFYDATE                           | 修改日期      | 导入时可默认为1900-01-01 00:00:00.0，可修改                                                                                                                 |
| FCOMPANYID                            | 公司地址      | 直接填0                                                                                                                                             |
| FIPADDRESS                            | IP地址      | 直接填0                                                                                                                                             |
| FPICTUREADDRESS                       | 图片地址      | 1、建立一个目录/upload/image/，如测试环境目录的物理地址是放在D:\kingdee\BBC\upload\image下\\ 2、做好的图片拷贝到/upload/image/目录下，该目录可以存在子目录\\ 3、导入格式统一为：/upload/image/+子目录+图片名称  |
| FGOODSID#Number#T_ESS_GOODS#FGOODSID  | 主表#关联表编号  | 填写商品编码                                                                                                                                           |

**操作说明：**

批量导入商品图片：

与商品档案导入操作一样，属同一个导入模版中不同的页签信息

  - 进入商品档案页面，点击【导入模版】，将商品图片批量导入模版下载下来；
  - 根据模版要求整理相关的数据，图片维护信息在商品档案批量导入模版的第二个页签。该上传的模版数据可以与商品档案信息一起整理或根据已有商品档案补充商品图片信息；
  - 点击【导入】，选择已维护好的图片批量导入数据，点击【确定】；
  - 若全部数据导入成功，则会提示导入成功；若存在数据错误，则会提示第几行记录导入失败，并提示失败的原因；
