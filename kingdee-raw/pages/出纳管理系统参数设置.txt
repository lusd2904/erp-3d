======出纳管理系统参数设置=====
应用系统进行日常业务处理之前，需要确认以下系统参数的值是否符合企业实际业务的需求。当然，在系统使用过程中，也可以根据实际需求的变化修改这些系统参数的设置。
^  位置   ^  参数                             ^  说明                                                                                ^
| 基本参数  | 出纳管理业务单据的汇率允许手工修改               | 控制出纳管理的业务单据（包括收款单、收款退款单、付款单、付款退款单、应收票据、应付票据）上的汇率字段是否允许用户手工修改                      |
|       | 存在未审核的单据时不允许结账                  | 控制出纳管理系统存在当期未审核的业务单据时，系统是否允许结账                                                    |
|       | 业务单据生成的凭证未过账不允许结账                  | 勾选该参数，通过出纳管理业务单据生成的凭证在总账模块未过账时，出纳模块不允许结账                                                    |
|       | 结算组织与收付组织相同时，需要录入内部账户           | 如果不勾选该参数，只有结算组织与收付组织不同时，单据上才需要录入内部账户；勾选该参数，则结算组织与收付组织相同时，单据上也需要录入内部账户             |
|       | 不可以手工新增银行账号                     | 勾选该参数，则必须通过开户申请单来下推银行账号                                                           |
|       | 应收单审核时自动生成收款单                   | 勾选该参数，应收单审核时自动生成收款单                                                                |
|       | 应付单审核时自动生成付款单                   | 勾选该参数，应付单审核时自动生成付款单                                                                |
|       | 收付款按源单页签明细生成                    | 勾选该参数，应收单下推生成收款单的明细页签分录行与源单明细分录行一一对应；应付单下推生成付款单的明细页签分录行与源单明细分录行一一对应                |
|       | 付款余额控制强度                        | 付款余额控制强度包括：禁止付款、预警提示、不予控制                                                          |
|       | 付款余额控制点                         | 付款余额控制点包括：审核、保存                                                                    |
|       | 内部账户可选类型                        | 收付款单据选择内部账号的选择类型包括：收付组织开设、资金组织开设、资金/收付组织开设                                         |
|       | 取消勾对人必须与勾对人一致                   | 勾选该参数,则取消勾对银行勾对记录时,判断取消勾对人与勾对人必须一致                                                 |
|       | 出纳和资金单据审核更新供应商、员工、客户基础资料的银行信息   | 勾选该参数，付款单、收款退款单、付款结算单审核时，会将账号页签的对方银行信息更新至供应商、员工、客户基础资料中的银行信息                       |
|       | 新增收款单优先携带客户基础资料里的销售部门和销售组       | 勾选该参数，新增收款单，销售部门和销售组优先携带客户基础资料里的销售部门和销售组，不勾选该参数，新增收款单，销售部门取销售员对应的部门，销售组取销售员对应的业务组  |
|       | 付款申请单审核自动生成付款单或者收款退款单           | 勾选该参数，付款申请单审核自动生成付款单，退款申请单审核自动生成收款退款单                                              |
|       | 付款单/收款退款单提交银行时需要第三方消息验证码          | 控制付款单或者收款退款单提交银行时是否需要输入第三方消息验证码进行验证，提高付款安全性                                          |
|       | 业务单据是否登账                        | 设置是时，出纳管理的业务单据和资金管理的单据自动登账，设置否时不登账，手工日记账不受此参数影响                                   |
|       | 付款业务单据审核业务日期更新为系统日期             | 勾选参数，付款单、收款退款单、付款结算单审核业务日期自动更新为系统日期。                                               |
|       | 零售、现销应收单审核时自动生成收款单              | 勾选参数，零售、现销应收单审核时自动生成收款单                                                           |
|       | 收付款按源单费用项目汇总生成                  | 勾选参数，申请单（其他应付单）下推的付款单明细页签分录携带源单明细费用项目                                             |
|       | 现购应付单审核自动生成付款单                  | 勾选此参数，现购入库单下推生成的应付单审核自动生成付款单。                                                      |
|       | 移动销售收款生成收款单状态                   | 可选创建、提交和审核，移动收款生成收款单单据状态按此参数设置控制                                                   |
|       | 重复业务支付预警，检查范围（天）                | 勾选此参数，设置检查天数，存在相同付款账号、付款金额和对方收款账号相同时单据保存提醒                                         |
|       | 预收不检查未出库金额                | 勾选此参数，订单已出库后还可以进行预收，预收额可大于未出库金额；不勾选此参数，订单预收金额必须小于等于订单未出库金额                 |                        
|       | 银行存款对账勾对对账单业务日期必须大于等于业务单据的业务日期  | 勾选此参数，银行存款对账时，对账单业务日期必须大于等于业务单据的业务日期才能勾对                                           |
