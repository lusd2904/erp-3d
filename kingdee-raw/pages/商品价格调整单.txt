======商品价格调整单 ======

===== 功能概述 =====

  * 零售商品价格需要进行永久调价，调价对象包括：零售价、会员价、以及门店供货价；
  * 零售商品价格调整可以定义具体的调价范围：按照组织过滤对应的门店；
  * 商品价格调整可以反写到商品资料的条形码页签的价格中
  * 商品价格调整单支持，选择商品同时带出多个条形码的价格记录，同时对一个商品编码，多个条形码进行调价。

**应用场景**
  * 零售门店需要永久调整商品零售价、会员价或供货价；
  * 指定某一个日期开始进行价格调整
**操作路径**

零售管理—>价格促销—>商品价格调整单

**字段说明**

^ 名称     ^ 字段说明                                        ^
| 商品编码   | 取商品-商品编码                                    |
| 条形码    | 取商品-条形码页签-条形码字段                             |
| 商品名称   | 取商品-商品名称                                    |
| 规格     | 取商品-基本页签-规格型号                               |
| 单位     | 取商品-条形码页签-计量单位字段                            |
| 原售价    | 取商品-条形码页签-零售价字段                             |
| 新售价    | 手工编辑金额字段                                    |
| 原会员价   | 取商品-条形码页签-会员价字段                             |
| 新会员价   | 手工编辑金额字段                                    |
| 原供货价   | 取商品-条形码页签-门店供货价字段                           |
| 新供货价   | 手工编辑金额字段                                    |
| 备注     | 文本字段                                        |
| 最高销售价  | 取商品-零售特性页签-最高销售价，新售价修改范围需要控制在最高销售价及最低销售价之间  |
| 最低销售价  | 取商品-零售特性页签-最低销售价，新售价修改范围需要控制在最高销售价及最低销售价之间  |
