===== 1.功能概述 =====
时段按小时统计结账金额、帐单数、累计账单数、平均结账金额、累计结账金额、时段营业占比、TC百分比（时段内帐单次数/总账单数）、人数、累计人数、人均消费、堂食TC、堂食结账金额、外卖TC、外卖结账金额、外带TC、外带结账金额、累计人均消费等
====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【营业报表分析】→【时段营业额报告】

====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总、排序

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
  * 排序页签：报表显示字段排序

====== 5.报表字段说明 ======
^ 字段        ^ 说明                                    ^
| 门店编码      | 门店编码                                  |
| 门店名称      | 门店名称                                  |
| 时段        | 统计时段                                  |
| 结账金额      | 各时段账单交易额之和                            |
| 账单数       | 时段内的账单数                               |
| 累计账单数     | 累积账单数                                 |
| 平均结账金额    | 平均结账金额=结账金额/账单数                       |
| 累计结账金额    | 累积交易金额                                |
| 累计平均结账金额  | 累计平均结账金额=累计结账金额/累积账单数                 |
| 时段营业占比    | 时段结账金额占总金额比例，时段营业占比=时段内结账金额/总结账额*100  |
| TC百分比     | 时段内账单次数/总账单数                          |
| 人数        | 消费人数                                  |
| 累积人数      | 累积人数                                  |
| 人均消费      | 人均消费=结账金额/人数                          |
| 堂食TC      | 堂食TC=账单数-外卖TC-外带TC                    |
| 堂食结账金额    | 堂食结账金额=结账金额-外卖结账金额-外带结账金额             |
| 外卖TC      | 外卖账单数                                 |
| 外卖结账金额    | 外卖结账金额                                |
| 外带TC      | 外带账单数                                 |
| 外带结账金额    | 外带结账金额                                |
| 累计人均消费    | 累积人均消费=累积结账金额/累积人数     |

====== 6.报表操作说明 ======
1、报表提供冻结列设置、打印、引出功能。

2、报表提供按表头的【组织】、【时段】等汇总时段的账单数、结账金额、时段营业占比和TC百分比等

3、报表提供过滤→分组汇总，在报表中对分组字段进行小计且对【账单数】、【金额】进行合计，其中分组字段包括：门店编码、门店名称、时段。

4、可以通过勾选【选项】中的参数，不显示分录行的合计、小计 。
