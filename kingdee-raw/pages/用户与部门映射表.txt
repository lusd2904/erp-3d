====== 1.用户与部门映射表 ======

===== 1.1 功能概述 =====
用户与部门映射表是用于移动端按照部门进行组织隔离，用户可以按照部门来进行要货

设置后移动端登录门店移动订货时，该用户只能看到设置的部门

{{:image_20210324151050.png?200|}}


===== 1.2 字段说明 =====
^ 字段    ^ 说明            ^
| 方案编码  | 手工录入，编码唯一     |
| 方案名称  | 手工录入          |
| 用户编码  | 从用户列表中选择      |
| 用户名称  | 由用户编码携带，不可编辑  |
| 移动电话  | 由用户信息携带，不可编辑  |
| 所属组织  | 从组织列表中选择      |
| 部门编码  | 选择该组织下的部门     |
| 部门名称  | 部门编码携带，不可编辑   |
| 部门仓库  | 有部门列表携带，必录    |
