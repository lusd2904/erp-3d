======1 生产SMT上料表列表 ======
=====1.1 功能概述=====
在生产订单上料表组合了多个站位表，在PDA上料时校验，同时作为完工冲销的依据。

=====1.2 使用前提=====
定义【组织】【站位表】【生产订单】
===== 1.3功能路径 ===== 

【智慧车间MES】—>【智慧车间】—>【SMT上料】—>【生产SMT上料表列表】

====== 2 字段说明 ======
上产SMT上料表具体单据

基本信息
^  ** 字段**  ^  **说明**                               ^
|  单据编号     | 生产SMT上料表单据编号。                                |
|  组织     | 生产SMT上料表对应生产订单加工组织。       |
|  产线     | 生产SMT上料表对应生产订单使用产线。                |
|  生产订单编号     | 生产SMT上料表对应生产订单编号。                |
|  生产订单行号     | 生产SMT上料表对应生产订单行号。                |
|  产品编码     | 生产SMT上料表对应生产订单行物料编码。                |
|  产品名称     | 生产SMT上料表对应生产订单行产品名称。                |
|  规格型号     | 生产SMT上料表对应生产订单行规格型号。                |
|  生产订单数量     | 生产SMT上料表对应生产订单数量与单位。                |
|  作业     | 生产SMT上料表对应生产订单所属作业。                |
|  生产订单状态     | 生产SMT上料表对应生产订单行状态。                |
|  单据状态     | 生产SMT上料表单据状态。                |

上料表信息
指定或新增站位表，通过按钮生成站位明细
^  ** 字段**  ^  **说明**                               ^
|  站位表版本      | 使用站位表版本  |
|  贴片机位置      | 使用站位表版本对应贴片机位置。               |

|  程序名称        | 使用站位表版本对应程序名称。                 |

上料表明细
^  ** 字段**  ^  **说明**                       ^

| 启用        | 所选站位表上料物料是否启用。                |
| 上料状态      | 显示所选站位表上料物料上料状态，待上料、已上料、已下线。  |
