ID: 加入购物车
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8A%A0%E5%85%A5%E8%B4%AD%E7%89%A9%E8%BD%A6

**功能说明：**

与线上商城（如淘宝、京东等）的购物车功能一致

**功能路径：**

【订货】->【快速订货】 ->【加入购物车】或者

【订货】->【配件订货】->【加入购物车】

**使用前提**：

无

**字段说明：**
订货页面展示字段说明：
| **字段**  | **字段说明**                                  |
| 商品图片    | 显示商品的主图                                   |
| 商品名称    | 显示商品名称                                    |
| 商品价格    | 商品的销售价：取商品发布表的价格，具体逻辑，请参考后台的【渠道可销售商品信息表】  |
| :::     | 商品的市场价：取商品档案的市场价                          |
| 库存量     | 取商品发布表的库存量                                |
| 展示品牌    | 根据展示的商品，列出相应的商品品牌                         |
| 展示商品标签  | 根据展示的商品，列出相应的商品便签                         |
| 销售组织    | 界面不显示，但需要记录商品的发布组织，以便加入购物车时携带             |

购物车展示字段说明：
|**名称**|**字段说明**|
|销售组织|关联销售组织表|
|商品ID|关联商品档案表|
|SKUID|关联商品档案表的SKUID|
|规格|显示商品的规格，如果没有规格管理，则为空|
|订购数量|订货数量，可编辑修改|
|订购价格|根据所选择的订购商品自动携带，不可编辑|
|订购单位|根据所选择的订购商品自动携带，不可编辑|
|商品规格|可编辑|

**操作说明：**

1）选择商品

可以按商品或配件分类进行模糊查询搜索，也可以按商品品牌或标签进行过滤选择

配件订单可以根据商品进行查询（商品所包含的配件）

除了大图订货外也支持列表订货，点击订货页面右上方的转换按钮即可以实现不同订货方式的转换
 
2）加入购物车

大图订货：输入订购数量，点击【加入购物车】即可。可重复添加，数量根据加入的次数进行累加 

列表订货：输入订购数量，点击【加入购物车】即可。可重复添加，数量根据加入的次数进行累加
 
3）查看购物车
