ID: 商品类型
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E7%B1%BB%E5%9E%8B

**功能说明：**

根据商品的统一属性归纳设置为不同的属性集合，商品类型包括扩展属性、商品规格、品牌，从而增加商品更多展示点

**功能路径：**

【商品】->【商品类型】

**使用前提：**

如需设置关联商品规格、品牌，则前提需已配置商品规格、商品品牌

**字段说明：**

| **名称**    | **字段取数说明**                     |
| 类型编码      | 根据编码规则自动生成                     |
| 类型名称      | 手工填写                           |
| 描述        | 手工填写                           |
| 启用状态      | 勾选\未勾选，默认为勾选启用状态               |
| 是否启用扩展属性  | 是\否                            |
| 扩展属性                                      ||
| 属性名称      | 手工填写                           |
| 输入方式      | 选择\输入，手工选择                     |
| 属性值类型     | 字符\数字，手工选择                     |
| 属性值       | 当输入方式=选择时，手工填写                 |
| 是否必填      | 是\否                            |
| 是否启用商品规格  | 是\否                            |
| 商品规格                                      ||
| 规格编号      | 关联商品规格表，取值商品规格编号               |
| 规格名称      | 关联商品规格表，取值商品规格名称               |
| 页面显示方式    | 默认下拉显示                         |
| 页面显示类型    | 根据所选商品规则携带显示类型                 |
| 规格描述      | 根据所选商品规则携带描述信息                 |
| 是否启用关联品牌  | 是\否                            |
| 商品品牌                                      ||
| 品牌        | 取值商品品牌表，手工选择关联的品牌              |
| 操作        | 允许进行新增、修改、删除、启用、撤销启用、刷新、搜索等操作  |

**操作说明：**
  - 点击【新增】按钮弹出编辑页面，录入名称，描述，启用状态默认为是；
  - 设置类型扩展属性：勾选启用扩展属性，点击【新增行】，录入属性名称，选择输入方式、属性值类型，当输入方式=输入时，不需要输入属性值；当输入方式=选择时，手工输入属性值以逗号分隔。录入排序信息，选择是否必填
  - 设置商品规格：勾选启用商品规格，点击【新增行】，选择规格，其他信息根据所选规格携带
  - 设置关联类型：勾选启用关联品牌，勾选品牌，可单选或者多选
  - 点击【保存】按钮，系统自动生成编码，新增一条商品类型信息
  * 修改：双击商品类型，进入详细信息页面，修改保存相关数据
  * 删除：选择相应类型，点击【删除】按钮，删除此行
  * 搜索：输入类型名称或编码进行搜索 


  *  商品类型：系统预置普通商品、称重商品、服务商品、金额商品、组合商品、组装商品等类型，可以根据企业具体的商品管理属性进行维护；
  * 商品类型为称重商品，同时需要维护售卖方式：记重OR记个，称重商品同时需要与称重相关参数联用（含后台门店协同参数与POS端电子秤配置参数）；
  * 商品类型为服务商品：服务商品销售时，不校验库存，与基本页签物料属性：服务联用；
  *  商品类型为金额商品：POS端销售该类型商品时，可手工修改金额，不进行库存管理；
  * 商品类型组合商品：组合捆绑销售的商品，例如A=B+C，那销售A商品带出商品明细，冲减B和C商品库存，需制定组合商品规则；
  *  商品类型组装商品：需定义组装商品规则，POS销售，日结后生成父项商品销售出库单，同时按照规则自动生成一张组装拆卸单；
