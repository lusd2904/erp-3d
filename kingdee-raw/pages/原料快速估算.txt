======1 原料快速估算 =======
=====1.1 功能概述=====

原料快速估算的展开，是指根据零件号的次序，一次性列出用于最高层装配件的每个组件，同时也列了组件的数量。同一组件多次出现时，将其数量累加，不关心产品结构的层次关系。

常用于快速估算完成一定数量装配的总需求，或者用于估计一个组件用于几个装配件时它的变化对成本的影响。


=====1.2 使用前提=====
定义【物料清单】


=====1.3 功能路径=====
进入【餐饮加工管理】—>【加工基础数据】—>【产品BOM查询】—>【原料快速估算】


======2. 字段说明======

=====2.1 BOM展开选项 =====
^  **字段**   ^  **说明**                                      ^
|  使用组织     | 指定查询物料清单的使用组织。                               |
|  物料编码     | 指定查询的物料编码。                                   |
|  BOM版本    | 指定查询的BOM版本。                                  |
|  需求日期     | 设定BOM子项的适用范围，默认为当前日期；\\ 为空时不按生/失效日期对子项进行过滤;  |
|  数量       | 计算子项用量时的父项数量，默认为1。                           |
|  只显示外购物料  | 勾选则子项表体只外购物料。                                |


=====2.2 子项明细页签 =====
^  **字段**  ^  **说明**                                                                                                                                  ^
|  物料编码    | BOM子项的【物料编码】。                                                                                                                            |
|  物料名称    | BOM子项的【物料名称】。                                                                                                                            |
|  物料属性    | 物料的属性,比方自制件。                                                                                                                             |
|  子项类型    | BOM子项的【子项类型】。                                                                                                                            |
|  BOM版本   | BOM子项的【子项类型】。                                                                                                                            |
|  单位      | BOM子项的【单位】。                                                                                                                              |
|  累计用量    | 【物料编码+辅助属性】等相同的BOM子项的用量之和；\\ 【用量类型】为“变动”时，【用量】=父项【数量】×【用量:分子】/【用量:分母】；\\ 【用量类型】为“阶梯”时，【用量】按阶梯用量取值；\\ 【用量类型】为“固定”时，【用量】=【用量:分子】/【用量:分母】。  |
|  辅助属性    | BOM子项的【辅助属性】。                                                                                                                            |
