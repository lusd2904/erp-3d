====== 1.订货管理系统参数 ======

===== 1.1 功能概述 =====

^ 参数                                   ^ 参数说明                                                                                                   ^
| 门店收货单审核时自动生成应付单                      | 不勾选，则门店收货单审核时不会自动生成应付单\\ 保存，则门店收货单审核时自动生成创建状态的应付单\\ 提交，则门店收货单审核时自动生成审核中的应付单\\ 审核，则门店收货单审核时自动生成已审核的应付单  |
| 门店退货单审核时退货数量自动生成配送退货单                | 不勾选，则门店退货单审核不会生成配送退货单\\ 勾选，则门店退货单审核时会生成配送退货单                                                           |
| 门店收货单审核时异常数量自动生成异常通知单	布尔	           | 不勾选，则门店收货单审核时异常数量不会生成异常通知单\\ 勾选，则门店收货单审核时异常数量会自动生成异常通知单                                                |
| 门店退货单审核时自动生成门店要货申请单                  | 不勾选，则门店退货单审核时不会生成门店要货申请单\\ 勾选，则门店退货单审核时会自动生成门店要货申请单                                                    |
| 门店要货申请单审核时自动生成付款单                    | 在门店移动订货启用支付的模式下，改功能才会生效\\ 勾选则门店要货申请单审核时自动生成付款单                                                         |
| 门店要货申请单审核时自动生成付款退款单                  | 在门店移动订货启用支付的模式下，改功能才会生效\\ 勾选则门店要货申请单审核时自动生成付款退款单                                                       |
| 门店要货申请单审核时自动生成收款单                    | 在门店移动订货启用支付的模式下，改功能才会生效\\ 勾选则门店要货申请单审核时自动生成付款单                                                         |
| 门店要货申请单审核时自动生成收款退货单                  | 在门店移动订货启用支付的模式下，改功能才会生效\\ 勾选则门店要货申请单审核时自动生成付款退款单                                                       |
| 门店要货申请单允许提交的时间范围                     | 设置门店要货申请单在哪些时间段允许提交                                                                                    |
| 门店要货申请单超过截止提交时间后不可反审核不可取消            | 设置门店要货申请单不可反审核不可取消的时间段                                                                                 |
| 设置单据不更新库存\\ 门店收货单\\ 门店退货单\\ 食品材料耗用单  | 如果勾选一个或者多个后，相应的单据审核时不会更新库存                                                                             |
