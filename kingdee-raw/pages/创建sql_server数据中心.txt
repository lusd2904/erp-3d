====== 1 功能描述  ======

数据中心是业务数据的载体，支持SQL Server和Oracle两种数据库类型，并可以按数据中心设置系统时区。

**功能路径**

【数据中心列表】

====== 2 字段说明 ======

===== 2.1 数据库服务器用户信息 =====

==== 2.1.1 数据库服务器 ====
定义当前数据库服务器的机器名称或者数据库服务器IP地址。
 ​
==== 2.1.2 数据库管理员 ====

输入数据库服务器管理员名称，数据库管理员用户将会使用模板创建数据中心； ​

==== 2.1.3 管理员密码 ====

输入数据库服务器管理员密码；

==== 2.1.4 身份验证 ====

支持SQL Server身份验证和Windows身份验证。
  - 若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
  - 若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码；

==== 2.1.5 登录名 ====

输入数据连接用户的帐号； 

==== 2.1.6 密码 ====

输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户； ​

===== 2.2 数据中心 =====


==== 2.2.1 数据库实体 ====
系统自动生成数据中心实体名称，可以根据需要调整名称； ​

==== 2.2.2 数据库文件路径 ====
定义数据库文件的安装目标，建议采用英文路径； ​

==== 2.2.3 数据库日志文件路径 ====
定义数据库日志文件路径，默认跟数据库文件路径相同，可以重新选择路径，建议采用英文路径；

==== 2.2.4 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.2.5 系统时区 ====
定义数据中心的系统时区，数据中心保存后系统时区将不再允许修改；

==== 2.2.6 默认语言 ====
默认为中文简体，下拉选择中文繁体和英文；



===== 2.2.7 其他字段 =====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； 
  - 数据中心类别：提供了标准业务库、标准BOS库； 
    标准业务库是包含金蝶AI星空标准业务，比如财务、供应链等；
    标准BOS库是只有BOS平台，没有星空标准业务，主要是针对只购买BOS开发平台的二开客户。

====== 3 功能操作 ======

===== 3.1 登录管理中心平台 =====

在管理中心的登录界面，使用Administrator，登录到管理中心后，可在主页进行数据中心的创建。
    ​

===== 3.2 创建SQL Server数据中心 ​ =====

在【数据中心列表】，点击工具栏【创建】按钮组的下拉子按钮【创建SQL Server数据中心】，如果管理中心是SQLServer类型的，直接点击工具栏【创建】按钮，即可打开“创建SQL Serve数据中心”创建向导界面。

SQL Sever数据中心创建共分两步，具体创建过程如下：

  第一步：输入数据库服务器用户信息，包括数据库服务器、数据库管理员用户和密码、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效。
   
  1、数据库管理员用户将会使用模板创建数据中心。
  
  2、数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到数据中心。
    ​
     ​数据库连接用户支持SQL Server身份验证和Windows身份验证两种方式。
          
     1）若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改。
     
        使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。 
        
     2）若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码。   
       
  第二步：设置数据中心的基本信息、语言、日志中心。
  
  1、数据中心基本信息，包括：数据中心代码、名称、类别、数据库文件路径等内容；
  
           注意：请根据需要勾选“允许执行计划任务”，勾选启用后，当前数据中心相关后台服务才能定时执行。
  
  2、语言，设置当前数据中心的默认语言，一般是中文（简体/中国）；
  
  3、日志中心，设置日志中心的存放路径，勾选选项“创建日志中心”，那么在创建业务数据中心时，会同时在此路径下面创建日志库。​
    
 完成上面步骤后，点击【创建】按钮，系统即可完成数据中心的创建工作。



===== 3.3 登录数据中心 =====

  - 每个数据中心都有一个预设的系统管理员用户，用户名：Administrator。
  - 初次登录时，会弹出提示“需要使用200MB本地磁盘空间做缓存，请确认”，点击【确定】后，虽然会占用部分空间，但可以提高系统使用性能和运行速度。

====== 4 其他说明 ======

  - 用户名在SQL Server下Administrator不区分大小写，Oracle下必须是Administrator，区分大小写且要求首字母大写。
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。
