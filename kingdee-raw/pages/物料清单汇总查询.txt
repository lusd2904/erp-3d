======1 物料清单汇总查询=======
=====1.1 报表功能=====

物料清单汇总查询的展开是指根据零件号的次序，一次性列出用于最高层装配件的每个组件，同时也列了组件的数量。同一组件多次出现时，将其数量累加，不关心产品结构的层次关系。

常用于快速估算完成一定数量装配的总需求，或者用于估计一个组件用于几个装配件时它的变化对成本的影响。


=====1.2 使用前提=====
定义【物料清单】


=====1.3 功能路径=====
进入【生产制造】—>【工程数据管理】—>【物料清单查询】—>【物料清单汇总查询】


======2. 字段说明======

=====2.1 BOM展开选项 =====
^  **字段**   ^  **说明**                                      ^
|  使用组织     | 指定查询物料清单的使用组织。                               |
|  物料编码     | 指定查询的物料编码。                                   |
|  BOM版本    | 指定查询的BOM版本。                                  |
|  需求日期     | 设定BOM子项的适用范围，默认为当前日期；\\ 为空时不按生/失效日期对子项进行过滤;  |
|  数量       | 计算子项用量时的父项数量，默认为1。                           |
|  只显示外购物料  | 勾选则子项表体只外购物料。                                |
|  是否显示替代料  | 勾选则子项表体可以显示替代料。                                |
|  外购件的子项不展示  | 勾选则子项表体不展示外购件的子项物料。                                |
|  不同组织相同物料编码合并  | 勾选后若物料属于不同组织，则按照物料编码合并，不按照组织分开显示                |


=====2.2 子项明细页签 =====
^  **字段**  ^  **说明**                                                                                                                                  ^
|  物料编码    | BOM子项的【物料编码】。                                                                                                                            |
|  物料名称    | BOM子项的【物料名称】。                                                                                                                            |
|  物料属性    | 物料的属性,比方自制件。                                                                                                                             |
|  子项类型    | BOM子项的【子项类型】。                                                                                                                            |
|  BOM版本   | BOM子项的【子项类型】。                                                                                                                            |
|  单位      | BOM子项的【单位】。                                                                                                                              |
|  累计用量    | 【物料编码+辅助属性】等相同的BOM子项的用量之和；\\ 【用量类型】为“变动”时，【用量】=父项【数量】×【用量:分子】/【用量:分母】；\\ 【用量类型】为“阶梯”时，【用量】按阶梯用量取值；\\ 【用量类型】为“固定”时，【用量】=【用量:分子】/【用量:分母】。  |
|  辅助属性    | BOM子项的【辅助属性】。|   
| 累计标准用量(不考虑精度)  | 是数据库计算出的累计标准用量的值，不按单位精度四舍五入的原始值。|
| 累计实际数量(不考虑精度)  | 是数据库出的累计实际数量的值，不按单位精度四舍五入的原始值。 |
