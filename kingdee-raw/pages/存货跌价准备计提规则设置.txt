===== 功能概述 =====
存货跌价准备是指由于存货遭受毁损、全部或部分陈旧过时或销售价格低于成本等原因，使存货成本不可以收回的部分，应按单个存货项目的成本高于其可变现净值的差额提取，并计入存货跌价损失。一般在中期期末和年度终了，成本会计会依据存货账龄、可变现净值、企业计提比率进行手工计算跌价准备并记账。 存货跌价准备计提功能的推出，实现存货跌价准备计提自动化，提升成本会计工作效率。
最新版本支持两种计提模式：按照库龄计提和按照可变现净值计提

===== 存货跌价准备计提规则 =====
^ 字段       ^ 说明                                   ^
| 编码       | 单据保存时可自动生成                           |
| 名称       | 用户手工填写                               |
| 数据状态     | 暂存、创建、审核中、已审核、重新审核                   |
| 核算体系     | 用户有权可见的会计核算体系                        |
| 核算组织     | 用户有权可见的会计核算组织                        |
| 会计政策     | 核算组织对应的会计政策                          |
| 计提维度     | 仓库+库龄                                |
| :::      | 物料+可变现净值                             |
| 库龄划分     | 用户可自定义分段设置，默认最大间隔区间999天，最多10个区间      |
| :::      | 仅按库龄计提时可以设置                          |
| 可变现净值来源  | 期末加权平均价*计提比率                         |
|          | 最新销售出库单销售单价*（1-费率）：计提当期最新销售出库单的含税单价  |

===== 存货跌价准备计算 =====
^ 字段              ^ 说明                                 ^
| 库龄计算方案          | 库龄计算方案的截止日期需要与计提会计期间的最后一天一致。       |
| 计提维度            | 多选时，同一物料以“物料+单位可变现净值”为最优先计提维度。         |
| 全部物料范围          | 勾选时，计提所有物料。                        |
| :::             | 未勾选时，可通过界面选择部分物料或者部分存货类别。          |
| 覆盖现有存货的跌价准备计提单  | 勾选后，系统将会按照物料编码，以新的计提结果对现有计提结果进行覆盖  |

===== 注意事项 =====

  - 计提前需要在“存货异常余额汇总表”中把核算维度中无数量有金额的余额进行出单调整，否则会导致计提单的存货余额与存货收发存汇总表的余额不一致。
  - 跌价准备计提完成以后，如果反结账并进行了存货核算，需要重新计提存货跌价准备，否则会导致计提单的存货余额与存货收发存汇总表的余额不一致。
