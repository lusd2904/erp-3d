ID: 促销政策
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BF%83%E9%94%80%E6%94%BF%E7%AD%96

**使用前提：**已经设置促销模式资料

**功能路径:** 【分销与流通】－>【促销管理】－>【促销政策】－>【促销政策】

**字段说明：**促销政策表头—基本信息

| **字段**          || **说          明**                                                                                                 |
| 促销政策编码          || 系统自动生成或是手工填写促销政策编码                                                                                               |
| 促销政策主题          || 手工填写促销政策的主题                                                                                                      |
| 来自促销申请          || F8选择，范围为所有有效的促销申请单                                                                                               |
| 创建组织            || F8选择，范围为用户权限中的销售业务组织                                                                                             |
| 币别              || 默认为申请组织的本位币                                                                                                      |
| 促销模式            || 下拉框选择，范围为基本资料中维护的促销模式。选择不同的促销模式后可进行不同的促销信息维护。                                                                    |
| 赠品种类限制          || 包括两个选项：全赠、指定赠送品种数量；全赠是指满足促条件时只要是赠品全部赠送；\\ 指定赠送品种数量是指指定赠送品种数量，可以设置多种赠品，用户从中选择一种或多种；\\ 在选择指定赠送品种数量后，必须填写具体的赠送品种数量  |
| 多组号执行策略         || 包括两个选项：并行执行，串行执行；在政策内有多个促销分组，\\ 当促销条件满足多个分组时：并行执行支持叠加执行促销，即同时执行多组促销；\\ 串行执行则不支持叠加执行，只允许执行其中一个分组；默认为串行执行。         |
| 促销折扣是否支持折上折     || 用于指定本促销政策是否在已有折扣情况下再执行折扣，若支持，则折扣为累加处理；若不支持，则只按本政策的促销折扣进行执行。                                                      |
| 促销内容            || 手工填写，文本格式                                                                                                        |

促销政策表头—参与组织
|**字段**||**说          明**|
|销售组织编码||若选择了促销申请则默认携带促销申请中的促销组织范围，可手工通过F8选择|
|销售组织名称||根据销售组织编码携带销售组织名称|
|开始时间||若选择了促销申请，则默认携带促销申请的促销开始日期，可手工填写|
|结束时间||若选择了促销申请，则默认携带促销申请的促销结束日期，可手工填写|

促销政策表头—参与客户
|**字段**||**说          明**|
|客户编码||F8选择，范围为创建组织下的所有客户资料|
|客户名称||根据客户编码携带客户名称|
|客户类别||F8选择，范围为基础资料中维护的客户类别|
|客户类别编码||根据选择的客户类别携带客户类别编码|

促销政策表体—促销信息
（列表字段是根据表头所选促销模式定义的属性字段进行显示的）

| **字段**     || **说          明**                                                                                                                                                                                                                                                                                                                                        |
| 组号         || 每个分组代表一种具体促销实例，同一组的产品是可以进行组合促销政策的定义；若不属于组合促销场景，可以使用不同组号进行设置。\\ 例如，定义组合促销时，购买A、B、C三种商品，购买一种或多种数量达到10个时赠送赠品，则ABC三个商品就应该在同一个组号下；\\ 若购买A或B或C必须每一种都达到10 个才有赠送，则A、B、C应设置在不同的组号下。                                                                                                                                                                              |
| 组合方式       || 包括任意组合、固定组合两种方式，支持一组促销商品指定为固定搭配或是任意搭配的促销场景。\\ 例如，组合促销时，购买A、B、C三种商品，购买一种或多种数量达到10个时赠送赠品，则组合方式为任意组合；\\ 若必须购买2A+2B固定搭配数量时赠送C，则必须买2个A同时购买2个B才赠送C，组合方式为固定组合。                                                                                                                                                                                                 |
| 物料分组       || 用于按产品分类定义促销实例，与物料编码字段互斥，即一行分录只能按物料组或是按物料明细定义促销内容                                                                                                                                                                                                                                                                                                        |
| 物料编码       || 用于按产品定义促销实例，与物料分组字段互斥，即一行分录只能按物料组或是按物料明细定义促销内容。                                                                                                                                                                                                                                                                                                         |
| 物料名称       || 根据物料编码携带出物料名称                                                                                                                                                                                                                                                                                                                                           |
| 规格型号       || 根据物料编码携带出物料规格型号                                                                                                                                                                                                                                                                                                                                         |
| 计量单位       || 根据物料编码携带出物料的销售计量单位                                                                                                                                                                                                                                                                                                                                      |
| 购买数量       || 以购买数量为促销条件时，填写最小购买数量。同一个组号，若组合方式为任意组合，系统会自动将购买商品的购买数量置为相同。\\ 例如，购买A、B、C三种商品，组合数量达到10个时赠送赠品，则A、B、C三个商品的购买数量栏均为10；\\ 若组合方式为固定组合，则按促销商品填写组合搭配的要求数量。                                                                                                                                                                                                        |
| 购买金额       || 以购买数量为促销条件时，填写最小购买金额。同一个组号，系统会自动将购买商品的购买金额置为相同。                                                                                                                                                                                                                                                                                                         |
| 赠品         || 赠品促销或是换赠促销时，确定赠品的赠送状态，选项包括：赠品、换赠；其中换赠表示赠品是以优惠价促销，需填写促销价格，如一元赠、五元赠等促销活动。                                                                                                                                                                                                                                                                                 |
| 赠送数量       || 填写赠品的赠送数量                                                                                                                                                                                                                                                                                                                                               |
| 赠品赠送基数     || 若赠品是一次性赠送，则不需要填写基数，在满足促销条件时，赠品只一次性赠送，不做累加处理；若循环赠送则需要填写赠品赠送基数，\\ 如满足促销条件后按促销数量或促销金额对于赠送基数的整倍进行累计循环赠送。\\ 例如：1）按购买数量计算赠品，例如A商品买10赠2，则购买数量为10，每10个赠送2个，则需要设置基数为10，因此若购买135时，则送 【取整数（135/10）】*2=26个赠品；\\ 例如B商品买10个以上时，买一赠一，则设置购买条件为>=10，基数则设置为1，因此若购买B商品110个，则赠送【取整数（110/1）】=110个赠品。\\ 注意，对于固定组合买赠则以固定搭配数量为一个购买单位，进行赠送基数的设置，例如，2A+2B为一个固定组合，则购买1组为一个基准购买数量。  |
| 促销价格       || 填写促销产品的促销单价或换赠产品的换赠价格                                                                                                                                                                                                                                                                                                                                   |
| 折扣方式       || 折扣促销时，选择产品的折扣方式，选项包括：折扣率、折扣额两种。                                                                                                                                                                                                                                                                                                                         |
| 折扣率%       || 折扣方式为折扣率则填写产品折扣率                                                                                                                                                                                                                                                                                                                                        |
| 折扣额        || 折扣方式为折扣额则填写产品折扣额                                                                                                                                                                                                                                                                                                                                        |
| 整单折扣率%     || 整单促销模式，折扣方式为折扣率时，填写整单折扣率                                                                                                                                                                                                                                                                                                                                |
| 整单折扣额      || 整单促销模式，折扣方式为折扣额时，填写整单折扣额                                                                                                                                                                                                                                                                                                                                |
| 备注         || 用于填写备注信息                                                                                                                                                                                                                                                                                                                                                |

促销政策表体—促销例外信息
|**字段**||**说          明**|
|物料分组||用于指定促销政策中本次不参与促销的例外的物料分组|
|物料编码||用于指定促销政策中本次不参与促销的例外的物料|
|物料名称||根据物料编码携带出物料名称|
|规格型号||根据物料编码携带出物料规格型号|
|计量单位||根据物料编码携带出物料的销售计量单位|

操作说明：
  * 失效与取消失效功能
  * 用户可以通过手工失效功能将促销政策进行失效暂停使用；也可以通过取失效功能，将有效期内的促销政策恢复使用；
