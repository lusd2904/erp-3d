**功能概述**

柔性生产的工序汇报，由设备端扫描后调用后台WebAPI自动生成，柔性生产工序汇报单支持单件汇报，支持记录每道工序的投入物料，不良原因等。

**功能路径**

【智慧车间MES】－>【智慧车间】－>【车间报工执行】－>【工序汇报】

**字段说明**

| **字段**     || **说明**                                                                                                               |
| 产品跟踪号      || 工序计划的扫描特征码选择“产生单件跟踪号”时，通过智能终端汇报时，自动生成产品跟踪号，用于跟踪单件产品的加工过程。\\ 后序在工序汇报时，必须扫描相应的产品跟踪号来进行汇报；                              |
| 首检         || 工序计划上勾选了首检标识，并且首检标识为未首检的工序，下推生成的工序汇报单首检标识勾选，勾选首检标识的工序汇报单能生成检验单；                                                      |
| 是否投料完整     || 柔性产线-入库点汇报单-通过消息触发审核；\\ 入库点汇报单审核-通过“末序投料齐套检查”消息触发；\\ 投入物料检查齐套校验通过，工序汇报单所有分录.是否投料完成=是，“末序投料齐套检查”消息执行成功，自动触发该工序汇报单审核。  |

【智慧车间MES】－>【智慧车间】－>【车间报工执行】－>【工序汇报】－>【投入物料】

**字段说明**

| **字段**           || **说明**                                                                                                                              |
| 表头.产品跟踪号         || 工序计划的扫描特征码选择“产生单件跟踪号”时，通过智能终端汇报时，自动生成产品跟踪号，用于跟踪单件产品的加工过程。\\ 后序在工序汇报时，必须扫描相应的产品跟踪号来进行汇报；                                             |
| 序列号              || 表头.序列号：产品序列号，投入物料.物料类型=产品 行对应的序列号；\\ 表体分录行.序列号：产品或关键件序列号，与该产品跟踪号关联的产品SN，当前作业关键件SN，以及在当前作业拆除后重新绑定的关键件SN。                             |
| 批号               || 表头.批号：产品批号，投入物料.物料类型=产品 行对应的批号；\\ 表体分录行.批号：产品或关键件批号；                                                                                |
| 表头.产品报废          || 单件管理情况下，是：不允许继续加工该产品SN；\\ 返修中心-产品报废后，与该产品SN关联的投入物料.产品报废 自动勾选；                                                                       |
| 表体.物料类型          || 1-产品：产品SN\\ 2-标准件：该作业投入的关键件；\\ 3-替代件：已经绑定的关键件拆除后，通过关键件解绑重新绑定的关键件；\\ 4-预装件：并行序列加工的预装件，与产品SN绑定后，在投入物料中插入一条序列号的为空的预装件记录；               |
| 表体.异常投料          || 非柔性手动扫描，投料异常记录，如：投料重复等                                                                                                              |
| 表体.返修处理类型        || 柔性单件管理：\\ 1-空：该关键件投入正常，没有进行拆卸处理；\\ 2-拆除报废：该关键件已经报废，不允许继续使用；关键件解绑-拆除报废，进行关键件报废处理。\\ 3-拆除回用：该关键件已经拆除，但允许继续使用；关键件解绑-拆除回用，进行关键件拆除回用处理。  |
| 表体.物料状态          || 1-正常件：该关键件SN首次正常采集，没有进行过拆除回用或报废处理；\\ 2-回用件：该关键件SN进行过拆除回用，拆除后再次投入使用，物料状态=回用件；                                                        |
| 表体.缺陷类型          || 关键件出现不良，通过屏端“关键件解绑”进行关键件拆除回用或拆除报废时，指定对应缺陷类型；                                                                                        |
| 表体.投料作业          || 后序发现前序关键件不良，通过屏端“关键件解绑”进行关键件拆除回用或拆除报废后，重新绑定新件时，记录其原有投料作业；                                                                           |
| 表体.预装跟踪号         || 并行序列加工的预装件对应的跟踪号，与产品SN绑定后，在投入物料中插入一条序列号的为空的预装件记录，通过预装跟踪号记录该预装件；                                                                     |
| 表体.关键件不良单据编号     || 后序发现前序关键件不良，或者返工工单发现关键件不良，需要更新原有投入物料不良情况，并记录发现不良的工序汇报单编号。                                                                           |
| 表体.关键件不良单据行号     || 后序发现前序关键件不良，或者返工工单发现关键件不良，需要更新原有投入物料不良情况，并记录发现不良的工序汇报单行号。                                                                           |
| 表体.操作工           || 记录关键件采集的操作工                                                                                                                         |
| 表体.投料时间          || 记录关键件采集的投料时间                                                                                                                        |

其它字段说明见[[工序汇报|]]
