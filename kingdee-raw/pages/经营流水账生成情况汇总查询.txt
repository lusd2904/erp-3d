====== 经营流水账生成情况汇总查询 ======
====== 1.功能说明 ======

企业可以汇总查询来源单据在经营单元是否全部生成经营流水账。

**功能路径**

【管理会计】→【经营会计】→【日常处理】→【经营流水账生成情况汇总查询】

====== 2.字段说明 ======

^ 字段         |^ 说明                                                                                                                    ^
| 经营账簿     || 选择需要查询的账簿。                                                                                |
| 经营组织架构     || 选择需要查询的组织架构版本。                                                                                |
| 经营期间     || 选择需要查询的会计期间。                                                                                |
| 利润中心     || 选择需要查询的利润中心。                                                                                |
| 引入方案     || 选择需要查询的引入方案。                                                                                |
| 经营单元     || 选择需要查询的经营单元。                                                                                |
| 过滤方式：为空     || 显示全部，即“是否需要生成”为是和否的单据。                                                                                |
| 仅显示需要生成经营流水账的单据     || 显示“是否需要生成”为是的单据。                                                                               |
| 仅显示需要生成且未生成经营流水账的单据     || 仅显示“是否需要生成”为是且“是否生成”为否的。                                                                                |
| 仅显示符合条件且未生成经营账的单据     || 仅显示符合条件的单据且“是否生成”为否。                                                                                |
| 仅显示不符合引入方案所有分录条件的单据     || 显示提示信息为“不符合引入方案所有分录行条件，请检查方案是否配置正确。”。                                                                                |
| 仅显示无需生成且已生成的经营流水账     || 仅显示“是否需要生成”为否且“是否生成”为是的经营流水账。                                                                               |

====== 3.操作说明 ======
可联查经营流水账生成情况明细查询
