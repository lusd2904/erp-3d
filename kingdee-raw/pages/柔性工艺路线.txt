**功能概述**

柔性生产使用的工艺路线与普通工艺路线有区别：
  * 柔性工作单元会根据生产任务情况灵活变化，因此要求柔性工艺路线不预先指定具体的工作中心，而是在具体生产时灵活指定；
  * 柔性产线上需要指定工序数据采集类型
  * 柔性产线上需要定义首检、联动排程等信息

**功能路径**

【工程数据】－>【工艺建模】－>【柔性工艺路线】

【智慧车间MES】－>【智慧车间】－>【工艺建模】－>【工艺路线（产线）】

**字段说明**

| **字段**           || **说明**                                                                                                                                                             |
| 序列类型             || 柔性工艺路线中，暂不支持替代序列                                                                                                                                                   |
| 工作中心、加工车间        || 不需指定                                                                                                                                                               |
| 数据采集顺序           || 携带自作业                                                                                                                                                              |
| 扫描特征码            || 无/产生单件跟踪号/绑定产品；柔性产线的生产过程中，一般会从某道序开始按单件进行跟踪。\\ 选择产生单件跟踪号，意味着从该工序开始产生一个产品跟踪号，一直跟随产品进行后面工序的加工汇报，这对于扫码汇报至关重要。\\ 柔性产线在生产过程中，并非从第一道工序开始就有产品序列号，工序选择绑定产品意味着在该工序上要产生产品序列号  |
| 工序阶段             || 可将一组工序作为一个阶段，在订单排程时，基于首工序阶段做排程                                                                                                                                     |
| 联动排程             || 在触发工序开工/工序完工时，自动对之后的工序进行排程                                                                                                                                         |
| 首检               || 布尔型，确定当前工序是否启用首检                                                                                                                                                   |
| 首检控制方式           || 当首检=是 时可编辑\\ 枚举值：严格控制、非严格控制；\\ 严格控制：首检单未通过，后续不允许报工，只有首检合格，后续才允许汇报；\\ 非严格控制：不管首检单状态，后续依旧可以汇报；\\ 首检并不直接控制本序，而是控制后序，即若未生成首检单，首件工序的后序不能进行扫描作业。                         |
| 不良返修方式           || 在线返修：加工过程不良情况记录，但不需要进行不良汇报，通过“工序不良品明细”进行不良情况记录；\\ 线下返修：加工过程不良情况记录，同时进行不良汇报，通过“工序汇报单”和“工序不良品明细 ”分别进行不良汇报与不良情况记录；                                                    |
| 触摸屏录入不良启用位置号     || 产品不良详细位置号指定，启用后需要定义“位置号”                                                                                                                                           |

**过程控制页签**

| **分组**  | **字段**             || **说明**                                                                                                                                                                                  |
| MES     | 过程记录工位             || 复选框，勾选时代表本工序需要做过程记录                                                                                                                                                                     |
|         | 质量检测工位             || 复选框，勾选时代表本工序需要做检测记录                                                                                                                                                                     |
|         | 检测方案明细(过程记录)       || 来源：F8过程控制检测方案基础资料的一级分组，按参数设置中的检测方案进行过滤，指定本工序对应的过程记录方案一级分组                                                                                                                               |
|         | 检测方案明细(过程检测)       || 来源：F8过程控制检测方案基础资料的一级分组，按参数设置中的检测方案进行过滤，指定本工序对应的过程检测方案一级分组                                                                                                                               |
|         | 手动提交报工             || 适用场景：柔性单件场景下，某一件产品生产完毕后，需要进行检测，此时需要继续生产下一件，但本件产品还不能报工。\\ 不勾选时——代表达到投料条件后自动报工（兼容现有场景）；\\ 勾选时——代表即使达到投料条件后也不会自动报工，需要人工触发报工动作（组装界面的报工按钮）；\\ 备注：工时采集参数请参考柔性产线相关说明；                          |
|         | 工时采集               || 工时采集控制参数：不控制、警告、严格控制，默认严格控制；\\ 参数含义：\\ 不控制，允许实际工时大于标准工时；\\ 严格控制，实际工时必须小于等于标准工时；\\ 警告，实际工时大于标准工时，提示用户根据需要选择；                                                                             |
|         | 报工时校验本序过程记录有效性     || 复选框，只有参数“手动提交报工”勾选时才可以编辑，字段可用；\\ 勾选时，代表用户点击手动报工操作时系统校验当前工序生产过程记录的有效性；不勾选，不校验；                                                                                                           |
|         | 报工时校验本序检测记录有效性     || 复选框，只有参数“手动提交报工”勾选时才可以编辑，字段可用；\\ 勾选时，代表用户点击手动报工操作时系统校验当前工序检测结果记录的有效性；不勾选，不校验；                                                                                                           |
|         | 扫描时校验前序过程记录有效性     || 适用场景：在柔性产线单件生产模式下，可以实现在进行工序扫描时，对前序的生产过程记录和检测结果记录的有效性进行校验，以确保满足检测条件的产品才可以继续流转。\\ 系统通过2个参数开关来做控制：\\ 扫描时校验前序过程记录有效性：\\ 勾选代表对前序的生产过程记录有效性校验，不满足条件的不允许本序扫描报工，条件如下：\\ 前序所有过程记录项目齐全记录、单据复核成功；  |
|         | 扫描时校验前序检测记录有效性     || 扫描时校验前序检测记录有效性：\\ 勾选代表对前序的检测结果记录有效性校验，不满足条件的不允许本序扫描报工，条件如下：\\ 前序所有检测项目齐全记录、所有三级分组对应的检测结果必须合格（PASS）、单据复核成功；                                                                              |


其它字段说明见[[工艺路线]]。
