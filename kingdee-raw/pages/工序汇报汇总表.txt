ID: 工序汇报汇总表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%B7%A5%E5%BA%8F%E6%B1%87%E6%8A%A5%E6%B1%87%E6%80%BB%E8%A1%A8

**报表功能**

  - 统计指定生产组织下一段时间内工序汇报的加工数量、加工工时信息和合格率，为车间管理的绩效评估提供参考数据；
  - 可以从加工车间、产品、工作中心、班组、设备、操作工角度进行统计分析；
  - 报表提供最基础的统计数据，用户在此基础上可设置希望的分组汇总；默认按照加工车间+单据日期进行分组汇总；

**功能路径**

【生产制造】－>【车间管理】－>【报表分析】－>【工序汇报汇总表】

**过滤条件**

“快捷”页签：快捷设置加工组织、加工车间、汇报单单据日期、产品编码、工作中心、班组、设备、操作工等基本过滤条件。

“排序”页签：可按照用户关心的选项，设置报表中明细行的排列顺序。

“显示隐藏列”页签：设置报表的字段是否显示以及显示顺序。

“分组汇总”页签：可以按照加工车间、单据日期、工作中心、班组、设备、操作工、作业进行分组汇总，用户需要选择关心的字段、设置合理的顺序进行分组汇总。在没有任何设置的情况下，系统默认按照加工车间+单据日期进行分组汇总。

**快捷过滤**

| **字段**         || **说明**                                              |
| 加工组织           || 1.选择要统计的生产组织；\\ 2.用户有权限的具有工厂职能的组织，只能选单个组织。默认为登录组织；  |
| 加工车间           || 选择当前加工组织下的基本生产车间，可以多选；                              |
| 汇报单单据日期        || 1.指定要统计的日期范围开始日；\\ 2.默认为系统日期前一个月；                   |
| 汇报单单据日期（至）     || 1.指定要统计的日期范围的终止日；\\ 2.默认为系统日期；                      |
| 产品编码           || 1.定义要分析的产品编码范围；\\ 2.选取加工组织下的物料；                     |
| 产品编码（至）        || 1.定义要分析的产品编码范围；\\ 2.选取加工组织下的物料；                     |
| 工作中心           || 加工车间空，选取加工组织下的工作中心；加工车间不空，选取加工车间下的工作中心；可多选；         |
| 班组             || 加工车间空，选取加工组织下的班组；加工车间不空，选取加工车间下的班组；可多选；             |
| 设备             || 选取加工组织下的设备，可多选；                                     |
| 操作工            || 选取加工组织下的人员，可多选；                                     |

**报表字段**

| **加工车间**     || **报表统计的加工车间名称；**                                                |
| 单据日期         || 工序汇报单单据日期；                                                      |
| 工作中心         || 加工车间下的工作中心的名称；                                                  |
| 班组           || 加工车间下的班组名称；                                                     |
| 操作工          || 加工车间下操作工；                                                       |
| 作业           || 加工工序对应的作业名称；                                                    |
| 产品编码         || 加工车间所加工的产品的编码；                                                  |
| 产品名称         || 加工车间所加工的产品的名称；                                                  |
| 规格型号         || 加工车间所加工的产品的规格型号；                                                |
| 生产单位         || 产品的生产计量单位，工序汇报汇总以生产计量单位数量进行统计；                                  |
| 完工数量         || 1、此单据日期内此工作中心下对应班组或操作工对应作业加工此产品的完工数量；\\ 2、完工数量=合格数量+废品数量+待返工数量  |
| 合格数量         || 此单据日期内此工作中心下对应班组或操作工对应作业加工此产品的合格数量；                             |
| 合格率（%）       || 合格率=合格数量/完工数量*100%                                              |
| 废品数量         || 此单据日期内此工作中心下对应班组或操作工对应作业加工此产品产生的废品数量；                           |
| 不合格率（%）      || 不合格率=废品数量/完工数量*100%                                             |
| 待返工数量        || 此单据日期内此工作中心下对应班组或操作工对应作业加工此产品产生的待返工数量                           |
| 返工率（%）       || 返工率=待返工数量/完工数量*100%                                             |
| 实作准备工时       || 实作准备工时=工序汇报单上准备阶段活动的活动量总和                                       |
| 实作加工工时       || 实作加工工时=工序汇报单上加工阶段活动的活动量总和                                       |
| 实作拆卸工时       || 实作拆卸工时=工序汇报单上拆卸阶段活动的活动量总和                                       |

**操作说明**

设置分组汇总，报表结果默认既显示明细行也显示汇总行，用户可以点击菜单的【选项】按钮，设置查询的数据仅显示汇总行、汇总行数据不显示小计、汇总行数据不显示合计。

用户可以点击菜单的【选项】按钮，设置查询的数据列为零是否显示、数据列尾零是否显示以及查询时是否首先弹出过滤界面等。

系统支持查询结果的打印、引出和刷新等通用操作。
