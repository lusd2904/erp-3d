====== 1.餐饮存货收发存明细报表 ======
===== 1.1 功能概述 =====
餐饮存货收发存明细表是指提供存货各核算期间详细的收发存明细信息，包括期初余额、本期收入、本期发出、期末结存明细信息。


===== 1.2 字段说明 =====
| 字段名称          | 字段说明                                        |
| 不统计核算组织内调拨单据  | 如果勾选则报表不会统计核算组织内的调拨单据，如果不勾选，则会统计核算组织内的调拨单据  |
| 显示各期间明细       | 如果勾选，则会显示各个期间的明细信息，如果不勾选，则显示所有核算期间的汇总信息     |
| 无收发不显示        | 如果勾选，没有接收和发送则不会显示；如果不勾选，则不论是否有收发，都会显示。      |
| 不统计库存调整单据     |如果勾选则报表会统计库存调整单据，如果不勾选，则不会统计库存调整单据。         |
| 期初结存-数量       |启用期间由初始核算数据维护中的期初数量写入；非启用期间由上期期末结存数量结转      |
| 期初结存-单价       |（期初结存-单价）=（期初结存-金额）/（期初结存-数量）               |
| 期初结存-金额       |启用期间由初始核算数据维护中的期初金额写入；非启用期间由上期期末结存金额结转      |
| 本期收入-数量       |本期入库序列核算单据的相同物料的汇总数量                        |
| 本期收入-单价       |（本期收入-单价）=（本期收入-金额）/（本期收入-数量）               |
| 本期收入-金额       |本期入库序列核算单据的相同物料的汇总金额                        |
| 本期发出-数量       |本期出库序列核算单据的相同物料的汇总数量                        |
| 本期发出-单价       |（本期发出-单价）=（本期发出-金额）/（本期发出-数量）               |
| 本期发出-金额       | 本期出库序列核算单据的相同物料的汇总金额                        |
| 期末结存-数量       | （期末结存-数量）=（期初结存-数量）＋（本期收入-数量）—（本期发出-数量）     |
| 期末结存-单价       |（期末结存-单价）=（期末结存-金额）/（期末结存-数量）               |
| 期末结存-金额       |（期末结存-金额）=（期初结存-金额）＋（本期收入-金额）—（本期发出-金额）    |
| 期初结存-数量       |启用期间由初始核算数据维护中的期初数量写入；非启用期间由上期期末结存数量结转     |
| 期初结存-单价       |（期初结存-单价）=（期初结存-金额）/（期初结存-数量）              |
| 期初结存-金额       |启用期间由初始核算数据维护中的期初金额写入；非启用期间由上期期末结存金额结转     |
