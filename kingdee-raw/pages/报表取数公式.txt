取数公式在报表系统中有着重要的作用，在报表系统中提供的取数公式，每种都有不同的功能，本节将对一些主要的取数公式操作方法和作用进行介绍。

要编辑取数公式，我们可以通过编辑栏的 fx 或【插入】→【函数】进行操作。

===== 总账取数函数 =====

总账取数函数

| 数据项          || 说明                                                                                                                |
| ACCT         || 总账科目取数函数，从科目余额表取数                                                                                                 |
| ACCTCASH     || 现金流量项目取数函数                                                                                                        |
| ACCTEXT      || 按日从凭证取数函数                                                                                                         |
| AMBAcct      || 应用于阿米巴报表系统。\\ 适用场景：阿米巴报表中每个报表项目所对应的科目都挂了【部门】核算维度，且部门与【阿米巴报表】-【利润考核体系】中的利润中心对应，则在【阿米巴报表】中生成的各利润中心报表取科目中对应部门维度的数据。  |
| AMBJSJM      || 应用于阿米巴报表系统。\\ 适用场景：【阿米巴报表】-【利润中心间结算价目表】中设置了按物料的辅助属性设置价目，或者存在多套价目表，在【阿米巴报表】中取价目表的数据时，需要使用此函数。                      |

**ACCT取数公式参数说明：**

账簿：是指取数来源账簿。支持手工录入账簿编码或通过F8从账簿基础资料中进行选择。

科目：是指取数科目范围。支持手工录入科目编码或通过F8从科目基础资料中进行选择。

取数类型：是指取哪种类型的数据。

下拉列表选择取数类型，系统提供如下的类型供选择：

| 数据项     || 说明           |
| C       || 期初余额         |
| JC      || 借方期初余额       |
| DC      || 贷方期初余额       |
| AC      || 期初绝对余额       |
| Y       || 期末余额         |
| JY      || 借方期末余额       |
| DY      || 贷方期末余额       |
| AY      || 期末绝对余额       |
| JF      || 借方发生额        |
| DF      || 贷方发生额        |
| JL      || 借方本年累计发生额    |
| DL      || 贷方本年累计发生额    |
| SY      || 损益表本期实际发生额   |
| SL      || 损益表本年实际发生额   |
| BG      || 最高预算余额       |
| BD      || 最低预算余额       |
| BJG     || 本期最高预算借方发生额  |
| BDG     || 本期最高预算贷方发生额  |

年度：是指账簿会计年度，可直接录入，如2003，若不选则系统默认为账簿当前年。若写入数值，表示的意义如下，0：账簿当前年，-1：账簿前一年，-2：账簿前两年，依此类推。

起始、结束期间：是指会计期间，可直接录入<起始期间>和<结束期间>，若不选则系统默认为账簿当前期。若写入数值，表示的意义如下，0：账簿当前期，-1：账簿上一期，-2：账簿上两期，依此类推。

币别：是指取何种币别的数据。支持手工录入币别编码，也可通过F8从币别基础资料进行选择，可以为空，为空则表示本位币。

SY、SL一般用于利润表的取值，需要月结前的转结损益的凭证为系统制作，而非人工制作。科目初始化时，也需要对相应科目录入“实际损益发生额（原币）”。

BG、BD、BJG、BDG分别对应取科目中的科目预算对应字段的数值。

 

**ACCTCASH取数公式参数说明：**

账簿：是指取数来源账簿。支持手工录入账簿编码或通过F8从账簿基础资料中进行选择。

现金流量项目：是指取现金流量项目范围。支持手工录入科目编码或通过F8从现金流量项目基础资料中进行选择。

|数据项||说明|

|Y||原币金额|

年度：是指账簿会计年度，可直接录入，如2003，若不选则系统默认为账簿当前年。若写入数值，表示的意义如下，0：账簿当前年，-1：账簿前一年，-2：账簿前两年，依此类推。

起始、结束期间：是指会计期间，可直接录入<起始期间>和<结束期间>，若不选则系统默认为账簿当前期。若写入数值，表示的意义如下，0：账簿当前期，-1：账簿上一期，-2：账簿上两期，依此类推。

币别：是指取何种币别的数据。支持手工录入币别编码，也可通过F8从币别基础资料进行选择，可以为空，为空则表示本位币。

**ACCTEXT取数公式参数说明：**

账簿：是指取数来源账簿。支持手工录入账簿编码或通过F8从账簿基础资料中进行选择。

科目：是指取数科目范围。支持手工录入科目编码或通过F8从科目基础资料中进行选择。

凭证过滤条件：是指取数凭证的过滤条件，用于筛选凭证用。有选择项：【对方科目】、【凭证摘要】、【凭证号】、【凭证日期】、【核算维度】

取数类型：是指取哪种类型的数据。

下拉列表选择取数类型，系统提供如下的类型供选择：

|数据项||说明|
|C||期初余额|
|Y||本日余额|
|JF||借方发生额|
|DF||贷方发生额|
|QC||期初结存数量|
|QY||本日结存数量|
|QJF||收入数量|
|QDF||发出数量|

币别：是指取何种币别的数据。支持手工录入币别编码，也可通过F8从币别基础资料进行选择，可以为空，为空则表示本位币。

开始日期、结束日期：可直接录入<开始日期>和<结束日期>，若不选则系统默认取公式取数参数里的开始日期和结束日期，如果取不到，则取报表参数里的日期。








===== 报表取数函数 =====

| 数据项          || 说明           |
| ACCTITEM     || 报表项目取数函数     |
| RPTDATE      || 获取报表日期的函数    |
| RPTPAGE      || 获取指定表页页名的函数  |
| RPTINFO      || 获取报表信息的函数    |
| REF          || 跨表页取数函数      |
| REF_F        || 跨报表取数函数      |

**ACCTITEM取数公式参数说明：**

核算体系：是指取数来源核算体系，支持手工录入核算体系编码或通过F8从核算体系基础资料中进行选择。

核算组织：是指取数来源核算组织，支持手工录入核算组织编码或通过F8从核算组织基础资料中进行选择。

项目：是指取数的项目范围，支持手工录入项目编码或F8提供“从××项目至××项目”的选择。

周期：是指取哪个周期的数据，下拉列表提供：日报、月报、季报、半年报、年报、会计周期，通过下拉列表进行选择。 

币别： 是指取哪种币别的数据，支持手工录入币别编码或通过F8从币别基础资料进行选择。可以为空，为空则表示本位币。

数据类型：是指取哪种类型的项目数据。 支持手工录入项目数据类型编码或通过F8从项目数据类型基础资料中进行选择。

年度：是指报表年度，可直接录入，如2003，空则系统默认为报表年度。若写入数值，表示的意义如下，0：报表所属年度，-1：报表所属年度前一年，-2：报表所属年度前两年，依此类推。

起始、结束期间：是指报表期间，可直接录入<起始期间>和<结束期间>，空则系统默认为报表所属期间。若写入数值，表示的意义如下，0：报表所属当前期，-1：报表所属上一期，-2：报表所属上两期，依此类推。

**REF取数公式参数说明：**

除支持跨表页取某个单元格参与本单元格的简单四则运算外，也支持连续页签相同单元格求和。

例：REF（sheet1:sheet5,B5）,意思是表sheet1至表sheet5的B5单元格求和，如果要新增一页参与求和，只需要在表sheet1至表sheet5之前插入一张表页即可，在表sheet1前或表sheet5后插入无效。

另外，此公式识别的是表页的名称，因此，如果设置完公式后，表页名称发生变化，需要修改公式里的表页名称。

表页名称：所在报表的所有表页名称。

单元格：具体单元格，可录入如B5,或B5+D6等简单的四则运算。

**REF_F取数公式参数说明：**


报表模板：是指取数来源的报表模板，包含个别报表、合并报表、工作底稿等。

表页名称：是指所选报表模板中包含的各表页

年度：是指取数的年度值

期间：是指取数的期间值，通过模板+年期，可以确定从哪个报表中取数 

币别： 是指取哪种币别的数据，支持手工录入币别编码或通过F8从币别基础资料进行选择。可以为空，为空则表示本位币。

金额单位：是指报表模板的金额单位，有元、千元、万元等选择项。 

数据内容：具体单元格，可录入如B5,或B5+D6等简单的四则运算。


**RPTINFO取数公式参数说明：**

报表信息：提供了报表名称、币别、报表周期、报表年度、报表期间、核算组织、开始日期、结束日期、创建人、当前合并范围等内容，优先取公式取数参数中的数值，如没有，则取报表参数中的数值。

制单人及审核人信息为报表打印设置中页眉、页脚提供。
