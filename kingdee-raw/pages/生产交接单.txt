======1 生产交接单 ======

====== 1.1 功能概述 ======
生成生产交接单表格的各个事项。

=====1.2 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【生产交接单】

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^ **字段**      ^  **说明**                                                                         ^
| 创建组织        | 1.可选择已审核、未禁用且有权限的生产组织 \\ 2.删除、修改生产组织后，清空车间、产品编码、子项编码字段                          |
| 交接表      | F8从【交接表定义列表】中选择                                                                  |
| 车间        | 由已选择的交接表定义携带，可修改                                                                  |
| 加工产品        | 由已选择的交接表定义携带，可修改                                                          |
| 工序        | 由已选择的交接表定义携带，可修改                                                               |
| 设备        | 由已选择的交接表定义携带，可修改                                                 |
| 接收人        | F8从【员工列表】中选择，可修改                                                              |
| 移交人        | F8从【员工列表】中选择，可修改                                                              |
| 移交班组        | F8从【班组列表】中选择，可修改                                |
| 接收班组        | F8从【班组列表】中选择，可修改                                                                |

===== 2.2 交接项目明细===== 
^  **字段**      ^  **说明**                                                                                                     ^
| 项目编号         | 由已选择的交接表定义携带，不可修改  |
| 项目名称         | 由已选择的交接表定义携带，不可修改                                                                                                       |
| 标准参考值         | 由已选择的交接表定义携带，不可修改                                 |
| 移交值           | 手工录入字符串                                                                               |
| 接收值         | 手工录入字符串                                                                                                    |
| 图片         | 从本地选择一张图片                                                             |
| 异常         | 勾选框                                                                            |
| 禁用         | 勾选框                                                                            |
