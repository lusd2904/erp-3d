====== 借款利息单 ======
=====1 功能说明 =====

由资金组织发起信贷单预提计息，系统自动进行计算，计息成功产生借款利息单。
系统自动产生的借款利息单为保存状态，由用户查询确认后提交审核。 
=====2 使用前提 =====

资金组织以及成员单位出纳管理系统已经启用。 
=====3 字段说明 =====
====3.1 表头字段说明 ====
| **字段**      || **说明**                       |
| 单据编号        || 借款利息单单据编号，系统自动获取。            |
| 业务日期        || 借款利息单的业务日期，系统自动置为利息计算当天的日期。  |
| 银行          || 给企业贷款的银行。                    |
| 银行账号        || 支付利息的银行账号。                   |
| 币别          || 对应的币别信息。                     |
| 计息区间        || 利息计算时指定的计息区间。                |
| 计息天数        || 利息计算时指定的计息区间包含的天数。           |
| 断息天数        || 利息计算时指定的起始日期与上次结息日之间的天数。     |
| 积数          || 系统自动汇总表体积数。                  |
| 应计利息        || 系统自动汇总表体应计利息。                |
| 免息额         || 指定计息对象的免息额。                  |
| 摘要          || 系统自动写入。                      |
| 账面余额        || 系统自动获取内部利息后内部账号的最新余额。        |
| 借款组织        || 进行贷款利息计算的组织。                 |
| 收付组织        || 指定计息对象对应的收付组织。               |
| 本位币         || 系统自动获取本位币信息。                 |
| 汇率类型        || 系统默认或者手工修改相应的汇率类型。           |
| 汇率          || 系统默认或者手工修改相应的汇率。             |
| 应计利息本位币     || 应计利息对应的本位币金额。                |

====3.2 表体字段说明 ====
| **字段**     || **说明**         |
| 利息类型       || 系统默认为预提利息。     |
| 开始日期       || 计息区间段的开始日期。    |
| 结束日期       || 计息区间段的结束日期。    |
| 天数         || 计息区间段的天数。      |
| 积数         || 计息区间段的积数。      |
| 年利率（%）     || 计息区间段适用的年利率。   |
| 应计利息       || 计息区间段对应的利息金额。  |


=====4 操作说明 =====
【财务会计】－>【资金管理】－>【日常处理】－>【信贷单】－>【预提利息】功能，利息计算成功自动生成创建状态的借款利息单。

【财务会计】－>【资金管理】－>【日常处理】－>【借款利息单】功能，查询和确认借款组织的借款利息单，并提交审核。

【借款利息单】－>【下推】－>【付款单】功能，生成付款单进行利息支付。
