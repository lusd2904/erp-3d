======1 巡检记录 ======

====== 1.1 功能概述 ======
生成巡检记录表格的各个事项。

=====1.2 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【巡检记录】

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^ **字段**      ^  **说明**                                                                         ^
| 创建组织        | 1.可选择已审核、未禁用且有权限的生产组织 \\ 2.删除、修改生产组织后，清空车间、产品编码、子项编码字段                          |
| 表格名称      | F8从【巡检记录定义列表】中选择                                                                  |
| 车间        | 由已选择的巡检记录定义携带，不可修改                                                                  |
| 加工产品        | 由已选择的巡检记录定义携带，不可修改                                                          |
| 工序        | 由已选择的巡检记录定义携带，不可修改                                                               |
| 设备        | 由已选择的巡检记录定义携带，不可修改                                                 |
| 填报人        | F8从【员工列表】中选择，可修改                                                              |
| 操作员工        | 由已选择的巡检记录定义携带，不可修改                                                              |

===== 2.2 巡检表明细===== 
^  **字段**      ^  **说明**                                                                                                     ^
| 编号         | 由已选择的巡检记录定义携带，不可修改  |
| 名称         | 由已选择的巡检记录定义携带，不可修改                                                                                                       |
| 填报值           | 手工录入字符串                                                                               |
| 图片         | 从本地选择一张图片                                                             |
| 禁用         | 勾选框                                                                            |
