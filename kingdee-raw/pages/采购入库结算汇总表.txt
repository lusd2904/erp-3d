====== 1功能概述 ======


采购入库结算汇总表主要用于跟踪从订货、收料、入库到应付、开票的完整过程，通过该报表可以掌握采购订单执行的总体进度。此报表的数据来源于采购订单和与采购订单关联的应付单。

====== 2使用前提 ======


存在实际发生的业务数据 

====== 3功能路径 ======


【供应链】－>【采购管理】－>【报表分析】－>【采购入库结算汇总表】

====== 4报表过滤条件 ======


过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
下面针对快捷过滤页签字段进行详细说明

  * 报表快捷过滤字段说明 

| 过滤条件               || 说明                                               |
| 采购组织               || 支持多选，合法值范围：具采购职能的组织机构                            |
| 结算组织               || 支持多选，合法值范围：具采购职能的组织机构                            |
| 日期                 || 当前所查询数据的起止日期                                     |
| 供应商                || 当前查询数据的供应商范围                                     |
| 物料                 || 当前查询数据的物料范围                                      |
| 业务类型               || 当前查询数据对应的业务类型范围，目前支持物料采购，暂不支持资产、费用采购             |
| 结算方式               || 当前查询入库单、退料单的结算方式                                 |
| 单据状态            || 当前查询的采购订单对应的单据状态\\ 提供选项：“全部”、“已审核”、“创建”、“审核中”“重新审核”  |
| 包含跨组织结算\\ 生成单据  || 报表数据是否包含组织间结算所生成的中间单据                            |

====== 5报表字段说明 ======


  * 表头字段 

|字段||说明|
|采购组织||报表数据来源的采购组织范围|
|日期范围：||报表数据的起止日期|
|供应商范围||报表数据的供应商范围|
|物料范围||报表数据的物料范围|
|业务类型范围||报表数据的业务类型范围|

  * 表体综合字段 

|字段||说明|
|结算组织||报表行数据对应的结算组织|
|供应商||报表行数据对应的供应商|
|物料编码||报表行数据对应的物料编码|
|物料名称||报表行数据对应的物料名称|
|规格型号||报表行数据对应的物料规格型号|
|辅助属性||报表行数据对应的物料辅助属性|
|计价单位||报表行物料的采购计价单位|
|入库数量||入库单、退料单的入库数量合计，入库数量取正数，退料数量取负数|
|入库含税单价||入库含税单价=入库价税合计/入库数量|
|入库价税合计||入库单、退料单的价税合计总数|
|应付数量||物料的应付数量合计，入库数量取正，退料数量取负|
|应付价税合计||物料的应付价税合计总数|
|差异数量||入库数量-应付数量|
|差异价税合计||入库价税合计-应付价税合计|
