====== 1. 物料预估要货单 ======
===== 1.1 功能概述 =====

物料预估要货单是根据历史物料用量要货和历史食品销量要货计算出预估要货量，根据预估要货量生成物料预估要货单。通过物料预估要货，门店可以提前做要货计划，以防止物料短缺。
 
===== 1.2 系统应用 =====

通过智能要货模型计算物料的预估需求，生成自采或配送计划。
 
===== 1.3 使用前提 =====

定义物料预估要货单的单据类型、业务组织、物料、单位等。


===== 1.4 字段说明 =====
 

==== 1.4.1 表头基本字段说明 ====
 

^ 字段名称   ^ 字段说明                               ^
|  单据类型  | 物料预估要货单的单据类型，从物料预估要货单单据类型基础资料中选择。  |
|  单据编码  | 物料预估要货单的单据编码，具有唯一性并遵循物料预估要货单编码规则   |
|  预估日期  | 物料预估要货单的预估日期                       |
|  单据状态  | 申请单的状态                             |
|  要货组织  | 预估计划要货的要货组织                        |
|   配送组织 | 对物料需求进行配送的组织                       |
|  申请日期  | 申请物料要货的日期                          |
|  要货部门  | 申请的需求部门。从部门基础资料中选择，必须为申请组织下的部门     |
|  备注    | 补充说明                               |

==== 1.4.3 表体明细字段说明 ====
 

|**字段**||**说明**|

|物料名称||指物料的名称，根据物料编码携带。|
|规格型号||指物料的规格型号，根据物料编码携带|

|单位||指物料的单位。|

|现有库存||该物料在申请组织的现有库存|
|安全库存||该物料在申请组织的安全库存|

|备注||补充说明|

1.5 业务说明
  * 参数设置中勾选参数“物料预估要货单审核时自动生成门店要货申请单”。在审核物料预估单时系统根据预估单的单据类型自动生成对应单据类型的门店要货申请单。 
  * 参数设置中不勾选参数“物料预估要货单审核时自动生成门店要货申请单”。手工下推生成门店要货申请单，相同单据类型的物料预估单可下推生成一张门店要货申请单
  * 物料预估单生成下游单据时，取实际订货量携带到下游单据
