======付款单======
=====1 功能说明  =====
 录企业所有对外付款的业务，包括采购业务付款、工资发放付款或者其他业务付款。

支持手工新增或者关联应付系统的应付单、其他应付单生成付款单。

系统自动根据付款用途的财务属性确定是否影响应付系统的余额，是否参与应付系统的应付付款核销。

=====2 操作前提=====
1、系统已启用。

2、定义了付款组织、结算组织、单据类型、客户/供应商/部门/员工、币别、汇率体系、结算方式、收付款用途、银行、银行账号等基础数据。

3、如果是通过票据类结算方式付款，则还需要先维护了应付票据数据。

=====3 功能路径=====
【财务会计】—>【出纳管理】—>【日常处理】—>【付款单】

=====4 字段说明=====

====4.1 付款单单据头====
包括的主要页签：基本页签、整单金额页签，具体内容如下所示：

===4.1.1 基本页签 ===

| **字段**     || **说明**                                                                                                                       |
| 单据类型       || 选择录入付款单单据类型名称。根据业务类型的不同，付款单的单据类型分为三类：采购业务付款单、工资发放付款单以及其他业务付款单。\\ 注意：\\ 根据不同的业务类型需要选择不同的单据类型，不同的单据类型在后续付款业务处理上遵循不同的业务处理规则。\\  |
| 单据编号       || 付款单的编号。\\ 当【单据类型】定义为自动编号时，在保存时，系统自动生成单据编号；\\ 当【单据类型】定义为手工编号时，请在本栏位手工输入单据编号。\\                                                |
| 业务日期       || 付款业务发生的日期，也是财务入账时该笔业务所属财务期间的依据。                                                                                              |
| 往来单位类型     || 选择与企业发生债权债务或者收付款往来关系的对方单位类型。                                                                                                 |
| 往来单位       || 录入与企业企业发生债权债务或者收付款往来关系的对方单位。                                                                                                 |
| 收款单位类型     || 选择实际收款的对方单位类型。                                                                                                               |
| 收款单位       || 录入实际收款的对方单位。实际收款方与往来关系方不一定是相同的。                                                                                              |
| 币别         || 录入本次支付款项所对应的币别。                                                                                                              |
| 应付金额       || 由系统根据表体的应付金额自动计算付款单整单应付金额。                                                                                                   |
| 实付金额       || 由系统根据表体的实付金额自动计算付款单整单的实付金额。                                                                                                  |
| 期望付款日      || 提交到网银按期望付款日自动付款。                                                                                                             |
| 付款组织       || 录入执行本次付款的付款组织。                                                                                                               |
| 结算组织       || 录入执行本次付款的结算组织。                                                                                                               |
| 采购组织       || 录入本次委托付款的采购组织。                                                                                                               |
| 采购部门       || 录入本次付款业务对应的采购部门，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件。                                                                          |
| 采购组        || 录入本次付款业务对应的采购组，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件。                                                                           |
| 采购员        || 录入本次付款业务对应的采购员，该信息满足企业明细核算的需要，同时也可以作为应付付款核销时的匹配条件。                                                                           |
===4.1.2 整单金额页签=== 
| **字段**      || **说明**                                   |
| 币别          || 显示本次支付款项所对应的币别。                          |
| 应付金额        || 显示付款单整单的应付金额合计。                          |
| 付款金额        || 显示付款单整单的付款金额合计。                          |
| 实付金额        || 显示付款单整单的实付金额合计。                          |
| 本位币         || 显示本次付款的付款组织所对应的默认核算体系的核算组织默认的会计政策的本位币。   |
| 汇率类型        || 显示本次付款的付款组织所对应的默认核算体系的核算组织默认的会计政策的汇率类型。  |
| 汇率          || 付款单原币到本位币的汇率。根据对应的系统参数确定是否允许手工修改。        |
| 结算币别        || 显示本次付款所对应的结算币别。                          |
| 结算汇率        || 付款单结算币别到本位币的汇率。根据对应的系统参数确定是否允许手工修改。      |
| 应付金额本位币     || 显示付款单整单的应付金额的本位币。                        |
| 付款金额本位币     || 显示付款单整单的付款金额的本位币。                        |
| 实付金额本位币     || 显示付款单整单的实付金额的本位币。                        |
| 应付金额        || 由系统根据表体的应付金额自动计算付款单整单应付金额。               |
====4.2 付款单单据体=====

包括的主要页签：明细页签、源单明细页签、账号页签、明细金额页签、应付票据页签、应收票据页签，具体内容如下所示：

===4.2.1 明细页签===
|**字段**||**说明**|
|结算方式||选择录入付款业务对应的结算方式。|
|付款用途||选择录入付款金额对应的用途。系统将自动根据收付款用途的属性，在后续的业务以及财务处理上遵循不同的处理规则。|
|预付项目类型||如果付款用途是预付款，则录入预付项目的类型。\\ 当单据类型为工资发放或者其他业务付款时，该字段不显示。\\ |
|采购订单||如果预付款的项目类型是采购订单，则录入具体所预付的采购订单编号。\\ 当单据类型为工资发放或者其他业务付款时，该字段不显示。\\ |
|应付金额||本次交易业务应付的金额。\\ 如果付款单是关联应付单生成，则应付金额由系统根据应付单计算出来。\\ 如果付款单无应付源单，则需要手工录入。\\ |
|付款金额||如果结算币别与收款币别相同，则付款金额＝应付金额，且字段为隐藏。 如果结算币别与付款币别不相同，则付款金额根据应付金额进行汇率换算计算出来，且可以修改。|
|现金折扣||本次交易业务发生的现金折扣。\\ 当单据类型为工资发放或者其他业务付款时，该字段不显示。\\ |
| 长短款        || 本次业务发生的长短款。|
|手续费||本次付款业务发生的手续费。|
|折后金额||由系统自动计算应付金额扣除现金折扣后的金额。\\ 当单据类型为工资发放或者其他业务付款时，该字段不显示。\\ |
|实付金额||由系统自动计算本次付款业务企业实际支付的金额。|
|我方银行账号||如果本次付款业务是通过银行类的结算方式进行结算，则需要录入企业实际支出款项的银行账号。|
|现金账号||如果本次付款业务是通过现金类的结算方式进行结算，则可以录入款项所对应的现金账号。|
|内部账号||当付款组织与结算组织不同时，内部账号为必录；当付款组织与结算组织相同时，由系统参数决定内部账号是否为必录。|
|内部账户名称||内部账号对应的名称。|
|结算号||银行付款处理的结算号。|
|备注||录入本次付款业务的备注信息。|

=====5 操作说明=====

1、【付款单】—>【下推】—>【选单】，关联应付单或者其他应付单源单，生成付款单。

2、【付款单】—>【业务查询】—>【勾对记录】，查询付款单对应的银行存款对账勾对记录。

3、【付款单】—>【业务查询】—>【应付票据】，查询付款单所引用的应付票据。

4、【付款单】—>【业务查询】—>【核销记录】，查询付款单所对应的应付付款核销记录。
