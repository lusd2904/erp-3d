====== 1.报表功能 ======

总账账龄分析表主要是用来对往来科目的往来款项余额的时间分布进行分析，在总账账龄分析表中，支持按单个核算维度或者核算维度组合查询、支持选择多个账簿一起查看。

====== 2.过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置截止日期以及科目范围等基本过滤条件。在“账龄分组设置”页签，用户可以自定义各账龄分组的天数及名称。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。

^ 过滤项             |^ 说明                                                                                                                                      ^
| 截止日期            || 系统显示截止日期相关往来科目的余额。                                                                                                                      |
| 匹配方式            || 支持以下三种自动匹配（核销）方式：\\ 1）、按业务日期顺序匹配：类似“先进先出”的存货计价方法，先收回或支付老的账款，账龄分析表始终体现业务日期比较新的账款。\\ 2）、按业务编号+业务日期顺序匹配：业务编号相同的款项优先进行匹配，剩余款项按“先进先出”的方式匹配。\\ 3）、按业务编号匹配：业务编号相同的款项才进行匹配。  |
| 负数发生额不优先匹配            || 选中此项，负数发生额视为正常收付款按正常方式匹配；否则，负数发生额视为退货或退款优先跟同方向业务编号相同且业务日期较大的分录行进行匹配。|
| 相同金额优先匹配            || 按业务日期顺序匹配时选中此项，相同的金额优先匹配后剩余款项按“先进先出”的方式匹配。|
| 科目编码            || 设置科目的查询范围，只能选择往来科目。                                                                                                                     |
| 连续核算维度范围查询      || 默认选项，选中此项，则选择起始核算维度后，账表按所选核算维度编码范围内的所有核算维度查询。                                                                                           |
| 非连续核算维度范围查询     || 选中此项，账表按所勾选的核算维度查询。                                                                                                                     |
| 使用核算维度组合查询      || 选中此项，核算维度查询界面为核算维度组合选择界面，用户设置多个核算维度查询；反之，核算维度查询界面只能选择单个核算维度查询。                                                                          |
| 显示包含维度组合中任一维度的科目   || 选中此项，按核算维度组合的并集查询（显示满足维度组合中任一条件的科目数据）；反之，按核算维度组合的交集查询。  |
| 包括未过账凭证         || 选中此项，查询结果包含未过账凭证的数据。                                                                                                                    |
| 多个科目合并显示        || 选中此项，同一核算维度对应的多个科目的数据汇总显示；否则，报表显示科目信息，核算维度余额按科目分别显示。                                                                                    |
| 显示科目小计          || 选中此项，查询结果按科目排序并显示科目小计。                                                                                                                  |
| 显示核算维度小计        || 选中此项，查询结果按核算维度排序并显示第一个核算维度的小计。                                                                                                          |
| 显示账龄分组的占比       || 选中此项，查询结果显示每个账龄分组的金额占总额的百分比。                                                                                                            |
| 按凭证显示           || 选中此项，查询结果显示账龄构成的明细信息。                                                                                                                   |
| 不包含调整期凭证 || 选中此项，查询结果不包含调整期凭证数据。|
| 核销币别类型            || 支持以下三种按不同币别匹配（核销）方式：\\ 1）、同时核销原币和本位币：保持原逻辑，即会先对本位币金额进行匹配核销，核销完，再对原币金额进行匹配核销。\\ 2）、仅核销原币：仅对原币金额进行匹配核销，并只显示原币金额数据、本位币金额为空。\\ 3）、仅核销本位币：仅对本位币金额进行匹配核销，并只显示本位币金额数据、原币币金额为空。  |


====== 3.操作说明 ======

勾选“多科目合并显示”后查询结果不再显示科目信息，所以不能再显示科目小计。

====== 4.匹配逻辑 ======

  * 为了减少预收冲应收、调账等业务对账龄分布的影响，同一张凭证相同科目（勾选“多科目合并显示”时，不要求相同科目）、相同核算维度（本次查看的维度或维度组合）、相同业务编号、相同方向的分录行优先进行匹配。

  * 为了减少退货、退款等业务对账龄分布的影响，负数金额优先跟同方向业务编号相同且业务日期较大的分录行进行匹配。

  * 负数优先匹配后，剩余部分再按以下两种方式进行匹配。
（1）按业务日期顺序匹配：类似“先进先出”的存货计价方法，先收回或支付老的账款，账龄分析表始终体现业务日期比较新的账款。

（2）按业务编号+业务日期顺序匹配：业务编号相同的款项优先进行匹配，剩余款项按“先进先出”的方式匹配。

  * 相同科目、相同核算维度、相同币别的的往来业务自动匹配，勾选“多科目合并显示”选项后，匹配时不考虑科目是否相同；按“综合本位币”查询，匹配时不考虑币别是否相同。
