====== 1.报表功能 ======
日报表是以报表形式显示各个科目的上日余额、本日发生额、本日余额以及借方笔数、贷方笔数。支持按日期区间汇总显示和按日显示，支持显示数量单价。
====== 2.过滤条件 ======

在“快捷”和“更多选项”页签，用户选择需要查询的账簿，设置开始日期、结束日期以及科目范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。

^ 过滤项                      |^ 说明                                                               ^
| 科目级别                     || 设置科目显示的级别范围，按照科目级别逐级显示科目余额数据。                                    |
| 科目编码                     || 设置科目的查询范围。                                                       |
| 按日显示                  || 选中此项，查询结果的数据将按日分别列示。不勾选此项，查询结果的数据显示开始日期到结束日期区间范围科目（核算维度）的余额、发生额。                                           |
| 包括未过账凭证                  || 选中此项，查询结果包含未过账凭证的金额数据。                                           |
| 显示核算维度明细                 || 选中此项，查询结果显示科目关联的核算维度明细信息。                                        |
| 核算维度明细行显示科目信息            || 勾选“显示核算维度明细”项才能选中此项；选中此项，查询结果中的核算维度明细行显示科目信息。                    |
| 余额为零不显示                || 选中此项，在查询结束日期余额为零的科目和核算维度不显示。                                                |
| 无发生额不显示     || 选中此项，在查询日期范围内科目和核算维度无发生额不显示。                                         |
| 余额为零且无发生额的不显示            || 选中此项，在查询结束日期余额为零且查询日期范围内无发生的科目和核算维度不显示。                                               |
| 只显示明细项目           || 选中此项，仅显示核算维度或者最明细科目的数据。                                               |
| 显示禁用科目           || 选中此项，查询结果包含禁用科目的数据。                                               |
| 显示科目全名           || 选中此项，查询结果科目名称会显示科目全名。                                               |
| 显示数量单价         || 选中此项，查询结果显示单位、数量、单价列。                                               |
| 按计量单位组默认单位核算     || 勾选“显示数量单价”项才能选中此项。选中此项，查询结果单位按计量单位组默认单位显示，数量、单价以此单位折算。不勾选此项，查询结果单位按科目默认单位显示，数量、单价以此单位折算。                                             |
| 展开下级明细         || 选中此项，多选账簿时，查询结果所有账簿分别列示每个账簿的数据。不勾选此项，所有账簿仅显示所有账簿的合计数。                                               |
| 显示合计      || 选中此项，查询结果最后显示合计行。                                               |
| 不包含调整期凭证         || 选中此项，查询结果不包含调整期凭证数据。                                               |
| 不包含结转损益凭证       || 选中此项，查询结果不包含结转损益凭证，发生额为实际损益发生额。                                               |
| 余额方向与科目余额方向一致         || 选中此项，查询结果上日余额、本日余额方向与科目余额方向一致。不勾选此项，按实际余额方向显示。                                               |

====== 3.操作说明 ======

系统支持日报表联查明细分类账，用户选择需要联查的记录，点击工具栏的联查明细账按钮联查明细分类账信息。
勾选显示数量金额且科目启用了数量金额时，联查数量金额明细账；其他都联查明细分类账。

支持按所有币别多栏式查看。

支持不包含结转损益凭证，即查询实际损益发生额。

支持根据科目类别、会计要素等字段分组汇总显示。
