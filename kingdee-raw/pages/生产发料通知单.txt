======1 生产发料 ======

=====1.1 功能概述 =====
生产发料通知单，帮助企业计划员通知仓库按计划成套发料，同时计划员可以将多个生产订单的需求进行合并，仓库按合并结果发料。
=====1.2 应用场景 =====

  - 计划员依据排产情况通知仓库按计划产量成套发料
  - 计划员将多个生产订单的需求进行合并，仓库按合并结果发料



=====1.3 功能路径 =====
【生产制造】－>【生产管理】－>【生产平台】－>【生产发料】


====== 2 字段说明 ======
===== 2.1 基本信息===== 
|  **字段**       |  **说明**                                          |
|  单据编号         | 1.单据编号由系统设定的编码规则自动生成。2.具有唯一性，不允许重复。              |
|  单据类型         | 系统自动取发料通知单的默认单据类型；单据新增时可改；单据保存后不可改。              |
|  单据日期         | 新增单据时系统自动显示当前系统日期； 用户可对日期进行修改。                   |
|  生产组织         | 1.当前组织具有生产职能，默认取当前组织；2.可选择有权限的其它生产组织             |
|  生产车间         | 加工产品的生产部门。                                       |
|  优先顺序         | 1.进行发料分配的优先计算顺序；2.包括：优先级、计划开工日期、计划完工日期。          |
|  发料方式         | 包括：多次发料、一次性发料                                    |
|  剩余数量为零的生产订单  | 累计发料套数达到生产数量的生产订单，如果要再发料，勾选“剩余数量为零的生产订单”，即可能够选单  |
|  单据状态         | 不可编辑，由系统根据单据操作自动标识，包括，暂存、创建、审核中、已审核、重新审核。        |

====== 3 操作说明 ======
====选单==== 
整体前提条件

  - 生产订单的【生产组织】等于表头基本页签的【生产组织】
  - 生产订单分录的【车间】等于表头基本页签的【车间】
  - 生产订单分录的【产品类型】为“主产品”
  - 生产订单分录的【业务状态】为下达或开工或完工，且未挂起
  - 生产订单单据类型勾选“生产发料通知”

====发料==== 

1. 生产发料通知单为已审核状态

2. 生产发料通知单汇总信息分录的【计划发料数量】>【实际发料数量】

3. 点击发料按钮，调出发料界面

====删除行==== 

1.生产订单页签、子项明细页签支持删除行操作；

2. 删除生产订单分录时，一并删除子项明细页签、汇总信息页签的相关信息

3. 删除子项明细分录时，一并删除汇总信息页签的相关信息
====== 4 业务说明======

====优先顺序==== 

选择生产订单分录后，根据表头基本页签设置的【优先顺序】，将生产订单分录加载至生产订单页签；

1.优先顺序为“优先级”时，生产订单分录按【优先级】+【计划开工日期】进行排序；

2.优先顺序为“计划开工日期”时，生产订单分录按【计划开工日期】+【优先级】进行排序；

3.优先顺序为“计划完工日期”时，生产订单分录按【计划完工日期】+【优先级】进行排序。

====发料 ====

1. 点发料按钮，弹出发料界面；发料界面是双表格，上表格数据取汇总信息的未完全发料的行，下表格是库存信息

2. 勾选汇总行，点刷新根据汇总信息的子项物料及库存维度获取即时库存。仓库范围是生产发料通知单表头勾选的仓库，生产发料通知单子项明细对应的生产用料清单有仓库，则该仓库强制考虑

3. 根据实际发料数量输入库存明细页签中的发料数量

4. 汇总信息的最大可发数量需大于等于对应库存各行录入的发料数量之和

5. 子项物料库存分配到明细分录行，实际发料数量不可大于明细分录的最大可发数量，不满足条件不可生成领料单

6. 点击生成领料单，根据发料数量及领料日期生成领料单；生产领料单仍是对应到具体的生产订单

7. 点击生成领料单，根据选项中的业务参数，支持交互式领料
