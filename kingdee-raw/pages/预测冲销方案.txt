======1 预测冲销方案======
=====1.1 功能概述=====
定义来单据的冲销关系、冲销时间范围等参数。
=====1.2 使用前提=====

定义【物料】
 
维护【销售订单】

维护【预测单】

维护【组织间需求单】

计划管理参数：启用多组织预测勾选时，该冲销方案有效

=====1.3 功能路径=====

进入【生产制造】—>【计划管理】—>【预测冲销】—>【预测冲销方案】

======2. 字段说明======

=====2.1 冲销关系页签===== 
|  **字段**     |  **说明**                                      |
|  预测单来源组织    | 定义哪些组织的预测单据参与冲销  |
|  冲销单据来据源组织  | 定义哪些组织可以冲销目标组织的预测单 |

=====2.2 冲销参数页签=====
|  **字段**               |  **说明**                                                   |
|  冲销来源单据类型             | 选择哪些销售单据可以冲销预测单，可以多选。                                     |
|  手工默认冲销周期             | 默认30，当手工进行预测冲销时，界面上的冲销结束时间=冲销开始时间+【手工冲销默认周期（天）】           |
|  向前冲销                 | 以冲销单据的需求日期为终点(包含需求日期当天)，指定的向前的天数为起点，向前冲销预测单。              |
|  向后冲销                 | 以冲销单据的需求日期为起点(包含需求日期当天)，指定的向后的天数为终点，向后冲销预测单。              |
|  先向前再向后冲销             | 以冲销单据的需求日期为起点(包含需求日期当天)，先向前冲销到指定向前天数，再向后冲销到指定的向后天数内的预测单。  |
|  先向后再向前冲销             | 以冲销单据的需求日期为起点(包含需求日期当天)，先向后冲销到指定向后天数，再向前冲销到指定的向前天数内的预测单。  |
|  按周冲销(来源单据只冲销同一周的预测)  | 查找同一周范围内的预测单，在周期范围内，使用先向后再向前冲销的算法；                        |
|  按月冲销(来源单据只冲销同一月的预测)  | 查找同一月范围内的预测单，在周期范围内，使用先向后再向前冲销的算法；                        |
|  未审核来源单据参与冲销          | 没有审核的来源单据允许冲销预测单                                          |
|  关闭的销售订单参与冲销          | 已经关闭的销售订单按照出货数量参与冲销                                          |
|  未审核来源单据参与冲销          | 没有审核的来源单据允许冲销预测单                                          |
|  指定日期之前的销售订单参与冲销时只冲销未出货数量          | 勾选后可以在冲销向导指定日期，在此日期之前的销售订单参与冲销时只冲销未出货数量                                          |
