====== 入库成本维护（多单据） ======

===== 发布说明 =====

发布于2021年9月2日 ，补丁号：PT-146887（Beta）

===== 功能概述 =====
入库成本维护（多单据）是现有功能“入库成本维护”的补充。两者都是可以对未固定的入库单据进行维护（启用了产品成本核算模块后，不能维护生产入库类单据）
^  不同点         ^  入库成本维护  ^  入库成本维护 （多单据 ）  ^
| 允许同时选择多种单据   |  否       |  是              |
| 允许手工在界面上暂估   |  是       |  否，只能通过引入方式修改   |
| 是否支持按汇总数量维护  |  否       |  是，未来版本支持       |
| 是否支持按来源批量维护  |  是       |  否，未来版本支持       |

===== 维护规则 =====
^ 规则    ^ 说明                                                                                   ^
| 维护期间  | 只能维护当前期间的入库单据，后续版本将支持维护未来期间单据                                                        |
| 单据范围  | 未启用产品成本核算：采购入库单、采购退料单、物权转移单、盘盈单、其他入库单、生产入库单、生产退库单、生产线产品入库单、生产线产品退库单、简单生产入库单、简单生产退库单  |
| :::   | 启用产品成本核算以下单据不能维护：生产入库单、生产退库单、生产线产品入库单、生产线产品退库单、简单生产入库单、简单生产退库单                       |
| :::   | 以下单据不能维护：已与应付单钩稽的采购入库单、采购退料单、物权转移单以及生成凭证的单据                                          |

===== 引入模板说明 =====
^ 序号  ^ 说明                                                                                                                         ^
| 1   | 当会计政策启用“按费用项目明细核算”时，引入模板不包含单价字段，这是因为多个费用项目单价下，会导致最终汇总金额的偏差，所以建议用户录金额                                                       |
| 2   | 标颜色的引入列为必录列                                                                                                                |
| 3   | 3.1、金额必录\\ 3.2、若只维护了金额，单价按照金额除以数量计算\\ 3.3、若同时维护了单价和金额，就按如下规则处理：如果数量 * 单价 = 金额，则单价和金额都按原始数据引入，如果数量 * 单价 不等于金额，则单价=金额/数量 计算  |
| 4   | 报表精度按照会计政策本位币的单价及金额精度                                                                                                      |
| 5   | 不能修改数量字段，否则会导致单据数量*单价不等于金额                                                                                                 |
