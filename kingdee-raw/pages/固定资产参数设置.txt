ID: 固定资产参数设置
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9B%BA%E5%AE%9A%E8%B5%84%E4%BA%A7%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE

  * 功能概述：系统进行日常业务处理之前，需要确认以下系统参数是否符合企业实际业务的需求。当然，在系统使用过程中，也可以根据实际需求的变化修改这些系统参数的设置。

  * 功能路径：资产管理－>固定资产－>参数设置－>固定资产参数设置。

  * 字段说明：参数说明

| **字段**                                 || **说明**                                                              |
| 调入单汇率取数来源调出单审核日期/业务日期汇率                || 根据参数的选择调入单取调出单审核日期/业务日期的汇率。                                         |
| 资产领用部门、领用人与卡片使用部门、使用人不一致时，同步更新卡片信息     || 勾选，资产领用单审核时，如果资产领用部门与卡片使用部门不一致，则同步更新该卡片的使用部门。                       |
| 允许使用人任岗部门不在使用部门                        || 勾选，资产的使用人任岗部门可以不在使用部门                                               |
| 固定资产生成的凭证未过账不允许结账                      || 勾选，结账时要校验必须要生成凭证的单据是否生成凭证，且生成的凭证是否过账                                |
| 卡片编码与资产编码保持一致                          || 勾选，则资产卡片卡片编码锁定，保存时将资产编码直接赋给卡片编码，该参数只适用于一张卡片只管理一个实物的场景。              |
| 卡片引出数据不分行                              || 勾选，资产卡片引出时不同页签的数据不分行，直接显示在一行上。                                      |
| 引入时是否自动计算累计使用期间和累计折旧期间                 || 勾选，资产卡片引入时系统自动计算累计使用期间和累计折旧期间，不勾选则直接按照引入的数据填写到卡片上                   |
| 反结账校验总账结账状态                            || 勾选，固定资产反结账，需校验总账的结账状态                                               |
| 选单收料通知单生成卡片根据组织/资产类别过滤                 || 勾选，则资产卡片选单收料通知单会按组织及资产类别进行过滤。                                       |
| 资产调拨生成的卡片，允许沿用原资产编码                    || 勾选，资产调拨单下推生成卡片时则自动沿用原来的资产编码用以创建卡片。                                  |
| 资产调拨流程自动化                              || 勾选，资产调出单审核后自动完成资产调入单的确认，自动产生资产处置单，自动生成资产卡片（适用于不同组织资产管理员是同一个员工的场景）。  |
| 计提折旧和结账时不校验人人资产单据                                || 勾选，则固定资产折旧计提与结账不校验人人资产的单据是否已审核。                                                     |
| 启用自定义折旧                                || 可以在这里挂自定义折旧的插件。                                                     |
| 资产领用退回时，卡片状态自动更新                       || 可设置领用后资产默认的状态，及未领用时资产默认的状态，系统根据领用状态的配置及未领用时默认状态的配置去自动更新资产卡片。        |
| 资产完全处置后更新状态为                           || 可设置资产完全处置后的资产状态，仅对设置参数后再完全处置的资产卡片生效                                 |
