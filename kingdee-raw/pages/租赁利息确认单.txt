ID: 租赁利息确认单
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A7%9F%E8%B5%81%E5%88%A9%E6%81%AF%E7%A1%AE%E8%AE%A4%E5%8D%95

租赁利息确认单是在租赁过程中对租赁负债所产生的利息的确认，也就是未确认融资费用的分摊。

====== 1 操作前提 ====== 
  - 资产租入单已经审核
  - 租赁利息确认单是通过资产租入单的付款计划进行下推
====== 2 字段说明 ======

=====2.1 基本 =====
| **字段**     || **说明**                                                           |
| 单据编号       || 利息确认单的编号，系统自动生成                                                  |
| 业务日期       || 业务日期                                                             |
| 租入单编码      || 记录是由那个租入单产生的利息确认单                                                |
| 资产组织       || 携带租入单的资产组织                                                       |
| 货主组织       || 携带租入单的货主组织                                                       |
| 合同名称       || 携带租入单的合同名称                                                       |
| 合同号        || 携带租入单的合同号                                                        |
| 出租方        || 携带租入单上的出租方                                                       |
| 利息确认方式     || 根据租赁参数自动携带，如果租入单往期的利息确认方式为按期确认，后续即使更改了利息确认方式为按付款期，也是沿用以前的利息确认方式  |
=====2.2明细 =====
| **字段**        || **说明**                  |
| 付款期           || 该利息确认单对应的付款期            |
| 期初本金          || 该利息确认单对应的付款期的期初本金       |
| 实际折现率         || 租入单的折现率                 |
| 期初未确认融资费用     || 该利息确认单对应的付款期的期初未确认融资费用  |
| 本付款期利息        || 该利息确认单对应的付款期的利息         |
| 本期确认利息        || 该利息确认单本次确认的利息           |
| 开始日期          || 本次利息确认对应的所属期            |
| 结束日期          || :::                     |
| 天数            || 本次利息确认对应的天数             |
| 本付款期总天数       || 该利息确认单对应的付款期的总天数        |
