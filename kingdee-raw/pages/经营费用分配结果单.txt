[[经营会计#内部分摊|<<返回经营界面]]


====== 1.功能说明 ======

用户根据企业发生的各种费用单据、总账费用科目归集生成经营费用归集单，可以按经营单元分摊标准生成经营费用分配结果单。

**操作前提**

设置经营账簿、经营单元、经营费用归集单、经营单元分摊标准等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【内部分摊】－>【经营费用分配结果单】

====== 2.字段说明 ======
^ 字段             |^ 说明                                                                                                                                               ^
| 经营账簿             || 设置经营费用分配结果单所在经营账簿，经营账簿必须已审核且未被禁用。                       |
| 分配标准      || 经营费用分配结果单对应的经营单元分摊标准。                               |
| 业务期间             || 设置经营费用分配结果单的业务期间。                       |
| 经营单元      || 经营费用分配对应的经营单元。                                            |
| 利润中心      || 经营费用分配对应的利润中心。                                            |
| 费用录入方式      || 按费用项目或经营科目录入费用。                               |
| 费用承担类型      || 从来源归集单获取                               |
| 费用承担对象     || 从来源归集单获取                                |
| 费用项目           || 经营费用分配结果单的费用项目。                 |
| 经营科目           || 经营费用分配结果单的经营科目。                 |
| 目标核算维度          || 当经营科目+核算维度分摊时，显示分摊的核算维度，对应生成经营流水账的核算维度会从分摊结果单的核算维度处获取。                 |
| 金额      || 经营费用分配结果单的费用金额。                                                                    |
| 权重值      || 经营费用分配对应的权重值。                                            |
| 总权重      || 经营费用分配对应的总权重。                                            |
| 日期      || 经营费用发生的业务日期。                                            |
| 分摊完成      || 经营费用分配结果单按分摊标准分摊后，分摊完成字段会自动勾选。                                            |
| 已入账      || 经营费用分配结果单已生成经营流水账后，已入账字段会自动勾选。                                            |
====== 3.操作说明 ======
经营费用分配结果单为费用分配时自动生成的。
