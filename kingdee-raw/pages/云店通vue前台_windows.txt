[[云店通轻餐_Windows|>>云店通轻餐_Windows]]

===== 1）点餐收银 =====
  - 根据食品的大类进行点菜、挂单至点餐列表，设置菜品的口味、折扣、是否赠送，以及对整个订单的备注、折扣等操作
{{:win_收银_1.png?direct&400 |}}
{{:win_收银_2.png?direct&400 |}}
===== 2）副屏 =====
  - 食品下单时，副屏为半边点单收款页面，半边图片；不下单时，副屏为全屏图片
{{:win_副.png?direct&400 |}}
{{:win_副_1.png?direct&400 |}}
===== 3）订单 =====
  - 接收、处理、展示第三方订单，主要支持微信点餐订单、口碑点餐订单、外卖订单等。
{{:win_订.png?direct&400 |}}
===== 4）收银记录 =====
  - 接收、处理、展示云店通本机设备订单，支持退单、重印、查看订单详情等功能
{{:win_收1.png?direct&400 |}}
===== 5）会员 =====
  - 为门店提供会员信息查询,查看会员余额
  - 进行会员充值，支持现金充值、微信支付和支付宝支付
  - 支持激活、禁用和退订会员卡
  - 支持云店通端会员开卡，开卡后可以在对应的cloud端查看到该会员
{{:win_会员.png?direct&400 |}}
===== 6）售罄 =====
  - 设置商品的售卖状态：可售/沽清，也可以为单个商品设定库存量，当库存量降至0时，自动沽清这个商品
{{:win_售罄.png?direct&400 |}}
===== 7）日结 =====
  - 可以查看当前班次/当前营业日的营业状态，并进行日结操作，或者打开钱箱，以便收银员统计当前现金收款的金额
{{:win_日结.png?direct&400 |}}
===== 8）交班 =====
  - 可以查看当前班次/当前营业日的营业状态，并进行交班操作，以便收银员统计营业情况
{{:win_交班.png?direct&400 |}}
===== 9）全屏 =====
  - 可以设置屏幕的状态小屏或者全屏状态
{{:win_全屏.png?direct&400 |}}
===== 10）设置 =====
  - 对系统参数进行设置，如门店的绑定状态、当前营业日期、打印功能、电子秤功能、收银功能、取餐功能、抹零等
{{:win_设置.png?direct&400 |}}
