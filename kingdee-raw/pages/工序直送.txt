======1 工序直送 ======
=====1.1 功能概述 =====
金蝶AI星空工序直送，灵活应对工序生产过程中的直接流转或临时入库的业务变化，帮助企业生管人员简化生产车间的出入库操作，使用业务处理更方便、更高效。

=====1.2 应用场景 =====
产品交付周期短，涉及的车间多。上道车间完工后，将车间完工品直接交给需要的下道车间，上道车间不入库，下道车间不领料。可每单生产完汇报后立即直送到后制程 ，也可多张订单生产完汇报一批产品后集中直送后制程 。

=====1.3 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【工序直送】

===== 2.2 直送明细===== 
^  **字段**      ^  **说明**                                                                                                     ^
| 行类型          | 行类型包括入库行和领料行。\\ 入库行指根据表头过滤条件刷新出的生产汇报单，需要通过生产直送执行生产入库的分录。\\ 领料行是指自动匹配或手工指定的上一制程父项产品生产用料清单，需要通过生产直送执行生产领料的分录  |
| 订单类型         | 生产订单                                                                                                        |
| 订单编号         | 入库行：显示生产汇报单对应的生产订单号  \\ 领料行：显示生产用料清单对应的生产订单编号                                                               |
| 业务状态         | 生产订单的行状态                                                                                                    |
| 单据编号         | 入库行：生产汇报单编号，根据过滤条件刷新出符合条件的生产汇报单  \\ 领料行：生产用料清单编号，根据自动匹配或手工选单，选出符合条件的生产用料清单                                  |
| 行号           | 入库行：生产汇报单行号 \\   领料行：生产用料清单行号                                                                               |
| 单据日期         | 入库行：生产汇报单单据日期   \\ 领料行：生产订单的单据日期                                                                            |
| 物料编码         | 生产汇报单的物料编码                                                                                                  |
| 物料名称         | 生产汇报单的物料名称                                                                                                  |
| 单位           | 生产汇报单的单位                                                                                                    |
| 数量           | 入库行：根据生产汇报单的入库类型分别对应合格品数量、不合格品数量、报废数量、返工数量  \\  领料行：空。                                                      |
| 已入库数量        | 入库行：根据入库类型分别对应合格品入库选单数量、不合格品入库选单数量、报废入库选单数量、返工品入库选单数量   \\ 领料行：空。                                           |
| 已领/未领数量      | 入库行：对应已领数量，取生产汇报单的领料选单数量   \\ 领料行：对应未领数量，指生产用料清单的子项的未生成领料的数量。                                               |
| 本次可领数量       | 入库行：入库类型为合格品入库，取生产汇报的合格入库数量+本次入库数-已领数量。入库类型不为合格品入库，不可进行领料。 \\  领料行：根据入库的本次可领数量和本行的未领数综合计算逐行分配的可领数量。         |
| 本次入库/本次领料数量  | 入库行：合格数量-合格品入库选单数量，不合格数量-不合格品入库选单数量，报废数量-报废品入库选单数量，返工数量-返工品入库选单数量。   \\ 领料行：取本次可领数量与未领数量二者小值。               |
| 批号           | 生产汇报单产品的批号，手工录入。                                                                                            |
| 仓库           | 生产汇报单产品的入库仓库                                                                                                |
| 产品类型         | 生产汇报单的产品类型                                                                                                  |
| 入库类型         | 根据生产汇报单的合格品数量、不合格品数量、报废品数量、返工品数量分别对应合格品入库、不合格品入库、报废品入库、返工品入库                                                |
| 库存状态         | 生产汇报单产品要入库的库存状态                                                                                             |
| 辅助属性         | 生产汇报单产品的辅助属性                                                                                                |


====== 3 操作说明 ======
====生产完工汇报后立即直送==== 

在生产汇报单单据界面，点击【业务操作】－>【生产直送】，系统弹出生产直送界面，并返回生产汇报单数据。

自动匹配：勾选入库行，点【自动匹配】，系统根据相同需求来源规则自动匹配生产用料清单，将符合条件的生产用料清单数据填充到领料行。

手工选单：在入库行下方的领料行，生产订单字段处，F8选择生产用料清单，系统弹出生产用料清单列表供选择，选择生产用料清单返回。

一键直送：同时勾选入库行和领料行，点击表头【生产直送】，系统自动根据入库信息生成生产入库单，根据领料单信息生成生产领料单。

生产入库和生产领料也可分开操作。勾选入库行，点击表头【生产入库】，系统单独生成生产入库单。勾选领料行，点击表头【生产领料】系统单独生成生产领料单。生成生产领料单的前提是必须存在足够的已入库可领料的数量。


====集中式生产直送==== 

【生产制造】－>【生产管理】－>【生产平台】－>【生产直送】，打开生产直送界面

点击【刷新】按钮，系统根据表头的过滤条件刷新出符合条件的生产汇报单。
 
自动匹配：勾选入库行，点【自动匹配】，系统根据相同需求来源规则自动匹配生产用料清单，将符合条件的生产用料清单数据填充到领料行。

手工选单：在入库行下方的领料行，生产订单字段处，F8选择生产用料清单，系统弹出生产用料清单列表供选择，选择生产用料清单返回。

一键直送：同时勾选入库行和领料行，点击表头【生产直送】，系统自动根据入库信息生成生产入库单，根据领料单信息生成生产领料单。

生产入库和生产领料也可分开操作。勾选入库行，点击表头【生产入库】，系统单独生成生产入库单。勾选领料行，点击表头【生产领料】系统单独生成生产领料单。生成生产领料单的前提是必须存在足够的已入库可领料的数量。
