ID: 按渠道等级发布
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8C%89%E6%B8%A0%E9%81%93%E7%AD%89%E7%BA%A7%E5%8F%91%E5%B8%83

**功能说明：**

一般企业会把渠道先分成不同的等级，然后按渠道等级对应发布不同的商品

**功能路径：**

【渠道】->【按渠道等级发布】

**使用前提：**

存在发布组织、发布渠道等级、可发布商品

**字段说明：**
**名称**|**字段取数说明**|
| 发布组织  | 取值组织表                                                       |
| 渠道    | 取值渠道等级表                                                     |
| 商品发布  |                                                             |
| 商品编码  | 取值商品档案表，过滤掉已发布给该渠道的商品                                       |
| 商品名称  | 关联所选商品                                                      |
| 单位    | 关联所选商品                                                      |
| 规格型号  | 关联所选商品                                                      |
| 标准价格  | 根据商品档案自动获取，允许手工填写修改                                         |
| 折扣%   | 根据所选渠道等级携带                                                  |
| 市场价   | 关联所选商品                                                      |
| 启用状态  | 勾选\未勾选，默认为勾选启用状态                                            |
| 备注    | 手工填写                                                        |
| 发布时间  | 系统自动生成                                                      |
| 发布人   | 系统自动生成                                                      |
| 修改时间  | 系统自动生成                                                      |
| 修改人   | 系统自动生成                                                      |
| 操作    | 允许进行保存、修改、新增、删除、启用、禁用、刷新、搜索、引入EXCEL、导出EXCEL、导入模板、价格同步更新等操作  |


**操作说明：**
  - 选择发布组织和渠道等级，点击【新增】添加商品，商品信息会自动从商品档案中携带。手工填写设置商品的标准价格，启用状态设置为勾选启用状态
  - 点击【保存】后，新增一条商品发布记录，该渠道等级所包含的所有渠道前台相应生成订货商品
  * 修改：双击商品发布数据，进入详细信息页面，修改保存相关数据。注意，启用状态下的数据是不允许修改的，需要选择该条商品发布数据点击【禁用】按钮，禁用后才允许修改。修改完成后，点击【保存】可再次点击【启用】按钮启用数据
  * 删除：选择相应商品发布数据，点击【删除】按钮，删除此行
  * 搜索：输入商品名称进行搜索，点击【更多搜索条件】可进行扩展搜索
  * 导入模板：点击【其它】->【导入模板】，页面自动下载导入模板文档
  * 导出EXCEL：选择数据后点击【导出EXCEL】按钮，可以导出所选数据；直接点击【导出EXCEL】按钮，可以导出当前页面所有数据
  * 引入EXCEL：点击【引入EXCEL】，选择上传文件点击确认，可通过EXCEL批量导入商品发布数据
