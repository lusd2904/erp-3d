[[门店营业分析|>>门店营业分析]]

======1.功能概述======
营业状况一览表主要展示早市、午市、晚市营业额以及占比；堂食、外卖、外带单数以及营业额占比，除此之外，还展示了各结算方式下的结算金额和笔数，有助于商户分析经营情况并制定经营策略。
======2.使用前提======
存在实际发生的业务数据，并通过门店数据交换上传账单数据
======3.功能路径======
【餐饮门店管理】→【门店营业分析】→【营业报表分析】→【营业状况一览表】
======4.报表过滤条件======
过滤条件区域包括页签：快捷
  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间
======5.报表字段说明======
^ 字段        ^ 说明                            ^
| 门店编码      | 门店编码                          |
| 门店名称      | 门店名称                          |
| 日期        | 营业日期（清机起始日期）                  |
| 工作站       | 收银工作站                         |
| 营业额       | 账单的营业额（营业额=结账金额=折后账单金额=收入金额）  |
| 账单数（TC）   | 账单交易次数                        |
| 人数        | 消费人数                          |
| 人均消费      | 人均消费=营业额/人数                   |
| 单均消费（AC）  | 单均消费=营业额/账单数                  |
| 早市单数      | 早市账单数（05:00至10:30的账单数量）       |
| 早市营业额     | 早市营业额（05:00至10:30的账单金额之和）     |
| 早市营业额占比   | 早市营业额占比=早市营业额/营业额*100         |
| 午市单数      | 午市账单数（10:30至15:00的账单数量）       |
| 午市营业额     | 午市营业额（10:30至15:00的账单数量）       |
| 午市营业额占比   | 午市营业额占比=午市营业额/营业额*100         |
| 晚市单数      | 晚市账单数（15:00至05:00的账单数量）       |
| 晚市营业额     | 晚市营业额（15:00至05:00的账单数量）       |
| 晚市营业额占比   | 晚市营业额占比=晚市营业额/营业额*100         |
| 堂食单数      | 堂食次数=账单数-外卖次数-外带次数            |
| 堂食营业额     | 堂食营业额=营业额-外卖营业额-外带营业额         |
| 堂食营业额占比   | 堂食营业额占比=堂食营业额/营业额*100         |
| 外卖单数      | 外卖账单数                         |
| 外卖营业额     | 外卖营业金额                        |
| 外卖营业额占比   | 外卖营业额占比=外卖营业额/营业额*100         |
| 外带单数      | 外带账单数                         |
| 外带营业额     | 外带营业金额                        |
| 外带营业额占比   | 外带营业额占比=外带营业额/营业额             |
| 长短金额      | 清点金额与系统账单金额的差额                |

======6.报表操作说明======

1、报表提供冻结列设置、打印、引出功能。

2、报表提供按表头的【组织】、【营业日期】等汇总早市、午市、晚市营业额及占比；外卖、堂食等单数及占比；各种结算方式的笔数和金额
