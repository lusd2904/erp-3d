====== 业务员 ======

===== 销售员 =====

==== 1 功能概述 ====

销售员是从事销售业务的员工。销售员是一种业务角色，不直接等同于HR的员工岗位，不是销售岗位的员工也可以设置为销售员。

销售员需要选择所属的销售组，才能进行业务组的数据隔离。一个销售员可以属于多个销售组。


==== 2 使用前提 ====

  * 具有销售职能的业务组织已经建立；
  * 员工资料已经建立。

==== 3 功能路径 ====

【基础设置】－>【基础资料】－>【公共资料】－>【业务员列表】

==== 4 字段说明 ====

| **字段**     || **说明**                                                                                                                                                       |
| 业务员类型      || 业务类型选择“销售员”。                                                                                                                                                 |
| 职员         || 销售员名称，Ｆ8员工任岗信息列表中选择。                                                                                                                                         |
| 部门         || 该职员所属于部门。                                                                                                                                                    |
| 业务组织       || 该职员所属的业务组织。注意：销售员只能选到具有销售职能的业务组织。                                                                                                                            |
| 业务员编码      || 新增时，默认等于员工编码，该字段做为业务单据上销售员的编码的识别码，如果直接在已有业务员上修改为其他员工，该字段不支持变化，用来区分之前业务员所做的单据，以便销售业绩细分统计。详细可参考云社区：https://vip.kingdee.com/article/181798                      |
| 任职岗位       || 默认等于职员任岗信息中的任职岗位                                                                                                                                             |
| 业务员名称      || 新增时，默认员工名称，该字段做为业务单据上销售员名称的识别标识。如果直接在已有业务员上直接修改为其他员工，该字段不支持变化。用来区分之前业务员与新业务所做的单据，以便销售业绩，销售单据、报表等按业务员做具体细分统计。详细可参考云社区：https://vip.kingdee.com/article/181798  |
| 启用         || 针对销售员进行启用或反启用操作，没有启用的销售员无法在业务单据上引用。                                                                                                                          |
| 业务组编码      || 该业务员所属业务组编码，Ｆ8从业务组资料中选择。注意：业务组不允许重复，且允许有一个默认值。                                                                                                               |
| 业务组名称      || 业务组对应的名称                                                                                                                                                     |
| 默认         || 设置业务组是否为默认的业务组                                                                                                                                               |

===== 采购员 =====

==== 1功能概述 ====



采购员是从事具体采购业务的员工。采购员是一种业务角色，不直接等同于HR的员工岗位，不是采购岗位的员工也可以设置为采购员。

采购员需要选择所属的采购组，才能进行业务组的数据隔离。一个采购员可以属于多个采购组，即一人身兼多职。


==== 2使用前提 ====



  - 具有采购职能的业务组织已经建立；

  - 员工资料已经建立。


==== 3功能路径 ====



【基础设置】－>【基础资料】－>【公共资料】－>【业务员列表】


==== 4字段说明 ====


|字段||说      明|
|业务员类型||采购的业务员，业务员类型选择“采购员”|
|描述||录入采购员的描述性说明信息|
|职员||采购员名称，Ｆ8从职员资料中选择|
|部门||该职员所属于部门|
|业务组织||该业务员所属的业务组织，采购员只能选到具有采购职能的业务组织。|
|启用||针对业务员进行启用或反启用操作。没有启用的业务员不能被引用|
|业务组编码||该业务员所属业务组编码，从业务组资料选择，业务组不允许重复，但允许多个，只能有一个默认值。|
|业务组名称||业务组对应的名称|
|默认||设置业务组是否为默认的业务组，勾选为默认。|
