====== 1.功能说明 ======

账簿启用后，就可以对总账系统中账簿的基础参数进行设置。这些参数是总账系统的基础，它的设置关系到账簿中所有财务业务和流程的处理。

**操作前提**

相关账簿已启用。

**功能路径**

【财务会计】→【总账】→【参数设置】→【总账管理参数】

====== 2.参数说明 ======
 
===== 2.1账簿参数 =====

^ 参数                         ^ 说明                                                                                                                                    ^
| 利润分配科目                     | 设置账簿的利润分配科目。                                                                                                                          |
| 本年利润科目                     | 设置账簿的本年利润科目。                                                                                                                          |
| 账簿余额方向与科目设置的余额方向相同         | 该选项用于账簿格式的显示。选中此选项，则显示账簿时，账簿的余额方向始终是同科目的方向一致，如果不同，则是以负数来进行显示。\\ 如果不选中该项，则余额始终为正数，根据科目余额方向以及金额正负判断账簿余额的方向。                             |
| 明细账（表）摘要自动继承上条分录摘要         | 选中此选项，明细分类账、核算维度明细账等账表的凭证分录如果摘要为空，自动继承上一条摘要不为空的分录摘要；否则，摘要为空的凭证分录显示第一条分录的摘要信息。                                                         |
| 明细账科目显示所有科目名称              | 选中此选项，在查询明细分类账时， 显示该明细科目的全部级次名称；否则，只显示当前明细账分页科目所在级次的科目名称。                                                                             |
| 多栏账成本类科目期初余额从余额表取数         | 当成本类科目处于未结平的状态（余额不为零）时，选择此选项。多栏账取数时，左边多栏式与具体明细栏目的期初余额取自初始余额录入的期初余额。\\ 成本类科目已结平（余额为零）时，不选择该参数，左边多栏式余额为零，但具体明细栏目的期初余额取自初始余额录入的实际损益发生额。  |
| 多栏账损益类科目期初余额从余额表取数         | 对于采用表结法的用户来说，不是每一期都会结转损益，该选项使多栏账损益类科目期初余额从余额表取数，从而使多栏账损益类科目期初余额在表结法下能够对应正确取数。                                                         |
| 核算维度余额表非明细级核算维度的余额合并在一个方向  | 选中此选项，核算维度余额表按照其明细级核算维度的余额汇总后，如果既有借方余额又有贷方余额，需要以借贷方的差额填列。没有选中时，非明细核算维度分组的期初余额和期末余额根据其下级维度及分组的借、贷余额分别汇总求得。                             |
| 往来科目必须输入业务编号               | 选中此选项，则在凭证录入及录入期初余额往来明细时必须录入业务编号。                                                                                                     |
| 结账时要求损益类科目余额为零             | 结转损益采用账结法的企业，必须选中此项，则在结账时如果损益类科目的余额尚未结为0，将无法进行期末结账；损益结转采用表结法的企业，则不需要此项选择。                                                             |
| 不允许跨财务年度的反结账               | 选中此选项，则不允许对当前会计期间所在会计年度之前年度的会计期间反结账；否则，系统允许跨财务年度的反结账操作。                                                                               |
| 业务系统结账可与总账结账期间不一致          | 勾选该参数，则总账账簿结账时，不检查账簿所在核算组织以及其下级业务组织对应业务系统是否已经先于总账当前期间结账；\\ 如果业务系统不先于总账结账，业务系统继续录入该期的单据，有可能导致业务系统与总账对账不平。                              |
| 结账时不检查业务单据的凭证生成情况          | 选中此选项，则总账期末结账时，不检查账簿相关的业务组织的业务单据是否已经生成凭证。                                                                                             |
| 总账结账检查对账结果包含调整期凭证          | 选中此选项，则总账期末结账检查跟业务系统是否已经对账平衡时，总账取数包含调整期间的凭证。                                                                                          |

===== 2.2凭证参数 =====

^ 参数                     ^ 说明                                                                                                  ^
| 允许录入凭证的未来期间数           | 设置凭证可以录入的未来期间数，例如当前期间是1期，如果允许录入未来期间数为2，则允许录入2期、3期的凭证。                                               |
| 凭证号排列规则                | 设置账簿中的凭证的号码是按照期间还是年度排列。                                                                             |
| 凭证过账前必须审核              | 选中此选项，则凭证必须审核后才可以进行过账处理。                                                                            |
| 凭证过账前必须出纳复核            | 选中此选项，则凭证必须经出纳复核后才能过账。                                                                              |
| 允许取消复核人与出纳复核人不一致       | 选中此选项，对当前凭证有取消复核权限的用户便可以取消出纳复核；否则，只允许当前凭证的出纳复核人取消复核。【该选项默认锁定，如需使用必须通过BOSIDE修改其锁定性】                  |
| 凭证中的汇率允许手工修改           | 选中此选项，凭证编辑时允许手工修改外币分录的汇率。否则，系统自动携带汇率体系的汇率，不允许手工编辑。                                                  |
| 不允许手工修改凭证号             | 选中此选项，用户不能修改凭证号，系统按照凭证号的排列规则自动编号。                                                                   |
| 凭证查询显示科目全名             | 选中此选项，凭证录入界面科目名称显示全名。凭证查询界面可通过过滤界面的“显示隐藏列”页签显示全名字段。                                                 |
| 凭证中显示科目的最新余额           | 勾选该参数，则录入凭证时选中相关分录行的会计科目，可在凭证左上角查看该科目的最新余额；否则凭证录入界面不显示科目余额。                                         |
| 每条凭证分录必须有摘要            | 选中此选项，新增凭证会限制每条分录必须有摘要。如果是智能会计平台生成的业务凭证，系统自动为没有摘要的分录加上前一条摘要不为空的分录摘要。                                |
| 银行存款科目必须输入结算方式和结算号     | 选中此选项， 新增凭证会限制银行科目必须录入结算方式和结算号。                                                                     |
| 凭证中的单价、数量字段允许为零        | 勾选该参数，则启用数量金额辅助核算的会计科目在录入凭证时可以将数量、单价字段留空，系统仅提示“数量乘以单价不等于原币金额”并允许凭证保存；否则该业务类型的凭证不能保存。                |
| 凭证中的本位币金额字段允许为零        | 勾选该参数，则凭证允许录入本位币金额为零的分录行并允许凭证保存，但数量、原币金额、借方金额、贷方金额不能同时为零，保存时校验；不勾选该参数，则此类凭证不能保存。                |
| 现金/银行科目赤字检查        |支持设置为不检查、警告、禁止。选择后两者，则凭证保存时检查当前凭证保存后，是否会导致相关科目余额为负数。               |
| 往来科目赤字检查        |支持设置为不检查、警告、禁止。选择后两者，则凭证保存时检查当前凭证保存后，是否会导致相关科目余额为负数。               |
| 显示科目最新预算额        |勾选该参数，则录入凭证时选中相关分录行的会计科目，可在凭证左上角查看该科目的最新预算额；否则凭证录入界面不显示科目预算额。               |
| 科目余额预算        |支持设置为不检查、警告、禁止。选择后两者，则凭证保存时检查当前凭证保存后，是否会导致相关科目余额超预算。               |
| 科目发生额预算        |支持设置为不检查、警告、禁止。选择后两者，则凭证保存时检查当前凭证保存后，是否会导致相关科目本期发生额超预算。               |
| 科目累计发生额预算        |支持设置为不检查、警告、禁止。选择后两者，则凭证保存时检查当前凭证保存后，是否会导致相关科目本年累计发生额超预算。               |
| 现金流量科目必须输入现金流量项目       | 用户可以通过在凭证的现金流量科目指定现金流量项目的方法编制现金流量表。如果选中此选项，凭证包含现金流量科目时必须指定现金流量，否则系统不予保存凭证。如果不选中该项，系统保存时不予以检查。       |
| 录入凭证时指定现金流量附表项目        | 选中此选项，凭证编辑时对附表相关科目，必须指定附表项目，否则系统不予保存。如果不选中该项，系统对附表相关科目不作必录检查。                                       |
| 已审核、已过账凭证不允许修改现金流量     | 选中此选项，不允许修改已经审核或过账的凭证的现金流量，通过T型账、附表项目指定等功能也不允许修改已经审核或过账的凭证的现金流量。                                    |
| 凭证保存后自动指定现金流量          | 选中此选项，在保存凭证后如果当前凭证需要指定现金流量，则自动弹出现金流量指定界面，并根据科目上面预置的现金流量项目自动指定和保存现金流量。\\ 系统默认自动指定主表及附表，支持设置只自动指定主表。  |
| 保存凭证时支持检查凭证号        | 选中此选项，在引入凭证、手工修改凭证号，凭证号重复时，系统不自动更新凭证号，提示用户凭证号重复。不勾选该项，则自动获取新凭证号。             |
| 业务系统生成的总账凭证允许修改        | 不勾选该项，用户不能修改业务系统生成的总账凭证的下列字段：账簿、科目、核算维度和金额等关键字段。勾选该项，若手工修改了业务系统生成的总账凭证，可能导致业务系统与总账对账不平。             |
| 业务系统生成的总账凭证允许作废        | 不勾选该项，用户不能作废业务系统生成的总账凭证。勾选该项，可以作废业务系统生成的总账凭证，作废后，原业务单据可再次生成总账凭证。业务单据生成的凭证作废后不支持反作废，需谨慎操作。             |
| 数量金额核算中，凭证支持跨计量单位组的单位  | 勾选该参数，则启用数量金额辅助核算的会计科目在录入凭证时可以选择科目默认计量单位组外的其它计量单位；否则凭证不能保存，并且系统提示凭证录入单位和科目单位不在同一单位组。                |
| 维度录入时部门与员工不关联          | 不勾选该项，用户若录入了部门，则只能选择该部门的员工；若录入了员工，则只能选择该员工所属的部门。\\ 若勾选该项，部门和员工是两个完全独立的基础资料，录入不受彼此的限制。               |
| 新增凭证自动填补断号             | 不勾选该项，新增凭证时凭证号不自动填补断号，默认凭证号为当前账簿凭证录入期间的最大凭证号加一。                                                     |

===== 2.3 数据中心参数 =====
只有使用超级管理员账号登录后才允许设置数据中心级别参数

^ 参数                                  ^ 说明                                                                                                     ^
| 凭证查询使用平台通用数据规则（不受账簿数据范围的影响）         | 选中此项，凭证查询显示的数据不受账簿数据范围的影响（存在用户的凭证新增及查看账簿范围不一致时需要勾选此项）；反之，只显示符合账簿基础资料数据范围的凭证数据。                         |
| 核算维度数量限制                            | 设置核算维度的数量上限，系统允许的最大核算维度数量为80个，但出于性能考虑，建议尽量控制核算维度的数量。                                                   |
| 在科目列表分组树中显示                         | 非明细科目：在科目列表的分组树中只显示非明细科目；\\ 全部科目：在科目列表的分组树中显示全部科目。                                                     |
| 总账账表查询范围数量限制                        | 不输入任何科目条件时总账账表允许查询的数据量（凭证分录及科目余额表数量），数据范围（10,000-10,000,000），建议根据服务器情况酌情设置。                            |
| 反结账时检查报表的状态                         | 可以设置报表提交后不允许反结账或者报表审核后不允许反结账。                                                                          |
| 分页账表引出所有页数量限制                       | 明细分类账等分页账表，查询的分页数超过设置值时系统会限制引出所有页， 数据范围（100-2000），分页账表引出所有页时，需要逐页查询后再引出，一次引出大量分页耗时会比较长，建议根据服务器情况酌情设置。  |
| 总账账表启用核算维度脱敏显示（部分账表不支持对脱敏后的数据进行联查）  | 核算维度对应的维度来源资料做了脱敏设置后，勾选该选项，才能对总账账表涉及到该维度的脱敏显示生效。                                                       |

====== 3.操作说明 ======

如果账簿需要进行损益的自动结转，则必须进行本年利润科目的设置；如果不进行损益的自动结转，可以不设置本年利润科目。“利润分配科目”同“本年利润科目”。

====== 4.其他说明 ======

科目分两级，如科目编码101.01，科目全称为【现金-中国银行】，如果在参数中没有选择<明细账科目显示所有科目名称>选项，在进行明细分类账查询时，科目名称显示：【中国银行】，只显示最明细级次的科目名称；如果选中此选项，科目名称显示：【现金-中国银行】，显示所有级次的科目名称。
