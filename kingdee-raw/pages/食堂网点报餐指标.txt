====== 1.食堂网点报餐指标 ======

===== 1.1 功能概述 =====
设置每个营业网点的报餐数据，如：报餐的人数，报餐的指标荤素比预警，报餐的餐次和食品等。精准设置食堂网点的报餐人数，荤素指标，食品种类，严格把控食堂网点的报餐指标

===== 1.2 字段说明 =====
^ 字段名称       ^ 字段说明                                     ^
| 名称         | 显示食堂网点报餐指标的名称，不同的组织名称不能重复                |
| 创建组织       | 显示创建组织                                   |
| 食堂网点       | 使用该食堂网点报餐指标的组织                           |
| 费用指标分类     | 显示辅助资料中费用指标分类为食材类的分类                     |
| 费用指标项目     | 显示辅助资料中费用指标项目                            |
| 营业额指标值     | 设置每项费用指标项目的营业额指标                         |
| 占比超出控制     | 设置是否控制占比                                 |
| 超出值控制      | 如果勾选了占比超过控制则设置超出值控制数字                    |
| 费用指标分类合计   | 统计同一个费用指标分类的营业额指标总和                      |
| 收入指标分类     | 默认餐费                                     |
| 餐次/收入指标项目  | 包括早餐，午餐，晚餐，夜宵，特殊餐次                       |
| 预估营业额      | 设置每种餐次的预估营业额                             |
| 预估用餐人数     | 设置每种餐次的预估用餐人数                            |
| 占比超出控制     | 设置占比超出控制，如果勾选则需要设置超出值控制                  |
| 超出值控制      | 设置占比超出控制时则需要设置超出值控制，如果设置，则在报餐单中会自动计算并设置  |
| 人均菜品食用量    | 设置每个人的菜品食用量                              |
| 人均主食使用量    | 设置每个人的主食食用量                              |
| 单位         | 设置人均菜品食用量和人均主食食用量的单位                     |
| 档口部门       | 设置食品的档口部门，同一个食品可以设置在不同的档口部门              |
| 食品编码       | 选择食品编码                                   |
| 食品名称       | 携带食品名称                                   |
| 食品类别       | 携带食品成本卡的食品类别                             |
| 食品成本卡      | 选择食品时会自动携带该食品下的默认食品成本卡                   |
| 菜牌模式       | 菜牌模式支持固定，逢单，逢双                           |
| 食用量参与累加    | 如果不勾选则在报餐单时不会自动累加计算，通常用于像主食不能通过份数来计算的食品  |
| 每日最大供应份数   | 设置该食品该档口每日可以支持的最大供应份数                    |
| 餐标售价       | 如果食品成本卡设置了餐标售价，则会自动携带；后面没有设置则支持手工设置      |
| 每日计划营业额    | 设置每日每餐的营业额                               |
| 单份重量       | 设置每份的重量，如果食品成本卡设置了则会自动携带，反之则支持手工输入       |
| 单份重量单位     | 默认携带食品成本卡的单份重量单位，支持手工输入                  |
| 每日供应重量     | 每日供应重量 = 单份重量 * 每日最大供应份数                 |
| 每日供应重量单位   | 设置每日供应重量的单位                              |
