==== 模拟报价单 ====

（1）菜单功能说明：
|**菜单功能**||**说明**|
|保存||点击保存，模拟报价单保存到系统中|
|提交||点击提交，模拟报价单提交审批流程|
|下推||点击下推，模拟报价单支持下推到销售报价单，物料及报价信息自动携带至销售报价单|
|重算||模拟报价单是保存状态还没有提交审核时，可以对模拟报价单的报价物料的各子项物料成本、取价来源进行手工修改、调整，调整后，点击重算，系统根据重新设置的手工指导的单价、或新设置的取数源重新计算模拟报价物料的成本及报价。如下图，当价格来源设置为手工指定时，系统重算会按手工维护的价格进行重算；当价格来源设置为采购价目表时，系统重算会按新设定的采购价目表作为价格来源重新计算。 |
|业务操作-关闭||模拟报价单的关闭，是根据销售管理-系统参数-基本参数“模拟报价单执行自动关闭”进行控制的。该参数默认不勾选，不勾选的情况下，模拟报价单不会自动关闭，由用户根据业务需要，不需要再使用该模拟报价单时可以手工点击关闭，来关闭模拟报价单。当参数勾选的情况下，模拟报价单会自动触发关闭：即当模拟报价单下推完销售报价单后，模拟报价单会自动关闭|
|业务操作-反关闭||对于已经关闭的模拟报价单，用户可以通过反关闭来反关闭模拟报价单。反关闭的模拟报价，可以继续下推销售报价单。|

（2）单据头字段说明：
|**字段**||**说明**|
|单据类型||单据类型默认是标准模拟报价单|
|日期||模拟报价单的业务日期，系统默认取当前时间为报价单的日期，用户可手工调整|
|报价组织||模拟报价向导指定的报价组织|
|报价币别||模拟报价向导指定的报价币别|
|购货客户||模拟报价向导指定的客户|
|汇率类型||自动获取报价币别与本位币直接设置的汇率类型 |
|本位币||模拟报价单上报价组织所在会计核算体系下默认结算币别|
|汇率||系统根据结算币别与本位币自动获取的即时汇率|

（3）单据体"报价物料"字段说明：
| **字段**         || **说明**                                       |
| 客户物料编码         || 客户物料编码，指模拟报价物料对应的客户物料编码                      |
| 客户物料名称         || 客户物料名称，指模拟报价物料对应的客户物料名称                      |
| 物料编码           || 模拟报价的物料编码                                    |
| 物料名称           || 模拟报价的物料名称                                    |
| 规格型号           || 模拟报价物料的规则型号                                  |
| 供应组织           || 模拟报价物料的供应组织，字段值是模拟报价向导中用户指定的供应组织             |
| 单位             || 模拟报价单物料的单位，默认取模拟报价物料基础资料指定的销售单位              |
| 数量             || 模拟报价物料计算的数量，默认1                              |
| BOM版本          || 模拟报价物料计算的BOM版本，字段值是模拟报价向导中用户指定的BOM           |
| 单价             || 模拟报价物料计算的不含税单价，单价=报价成本*（1+成本上浮率），系统默认锁定不能维护  |
| 含税单价           || 模拟报价物料计算的单价，含税单价=单价*（1+税率），系统默认锁定不能维护        |
| 材料成本           || 模拟报价物料的材料成本，由该物料的下级子项物料的材料成本卷算得到             |
| 委外加工费          || 模拟报价物料的委外加工费用，由该物料的下级子项物料的委外加工费用汇总得到         |
| 制造费用           || 模拟报价物料的制造费用，由该物料的下级子项物料的制造费用汇总得到             |
| 人工费用           || 模拟报价物料人工费用，由该物料的下级子项物料的人工费用汇总得到              |
| 计件金额           || 模拟报价物料的计价金额，由该物料的下级子项物料的计价金额汇总得到             |
| 自定义待摊费用        || 模拟报价过程自定义的待摊费用/待摊数量，可维护                      |
| 报价成本           || 报价成本=材料成本+委外加工费+制造费用+人工费用+计件金额+自定义待摊费用，不可维护  |
| 成本上浮率（%）       || 根据模拟报价向导携带，可维护。                              |
| 税率（%）          || 根据模拟报价向导携带，可维护。                              |
| 自定义不计入成本费用     || 根据模拟报价向导携带，可维护。                              |

（4）单据体"子项明细"字段说明：
| 物料编码          || 根据报价物料的BOM自动展开的子项物料编码；默认锁定不可维护                                                                                                  |
| 物料名称、规格型号     || 根据物料编码自动带出，默认锁定不可维护                                                                                                             |
| 供应组织          || 根据模拟报价物料的BOM中指定的供应组织携带至该字段                                                                                                      |
| 计量单位          || 根据BOM设定的物料单位自动带出，默认锁定不可维护                                                                                                       |
| 数量            || 该项材料按模拟报价物料及BOM展开子项的材料数量                                                                                                        |
| 材料单价          || 系统根据模拟报价向导指定的材料单价来源获取和计算得到的材料单价；当材料单价来源为手工指定时，材料单价可手工维护。物料属性是自制件，但是无下层子项，则该项的材料单价按取价来源取价得到；如果当前物料有下层子项，则该项的材料单价=直接下层子项的材料成本之和/该项材料的数量。  |
| 材料单价来源        || 系统根据模拟报价向导指定的材料单价来源获取，用户可根据计算需要维护并修改，修改来源后点击菜单的重算可重新计算模拟报价物料的报价。                                                                |
| 材料金额          || 材料单价*该项用量，不可维护                                                                                                                  |
| 材料参考单价        || 系统根据模拟报价向导指定的材料参考单价来源，获取得到的材料参考单价。不可维护                                                                                          |
| 材料参考单价来源      || 系统根据模拟报价向导指定的材料单价来源获取，不可维护。                                                                                                     |
|委外加工单价||系统自动计算得到的单价，可维护；关于子项是委外件的算法：（1）由于委外件也可能存在企业自制生产，在模拟报价中取数逻辑还是按卷算材料成本。（2）如果委外属性物料有子项，则认为是企业提供材料给委外厂商进行加工，需要计算材料费用和加工费用。材料单价来源系统自动为按BOM子项卷算，材料单价=直接下层子项的材料成本之和/该项材料的数量。委外属性物料的委外加工单价，则按向导设置的取价来源进行取价。（3）如果委外属性物料没有子项，则默认这个物料整个都是委外的。则材料单价来源默认为空，材料单价也为空。只计算委外加工单价，委外加工单价按向导设置的取价来源进行取价。|
|委外加工单价来源||系统自动获取的单价来源，字段值参考模块报价过程设置的来源值，可维护|
|委外加工金额||委外加工单价*该项用量，不可维护。|
|委外加工单价参考单价||系统自动计算得到的单价，不可维护。|
|委外加工单价参考单价来源||系统根据模拟报价向导指定的来源获取，不可维护。|
|标准工时||根据模拟报价标准费率获取，按该物料维护的标准费率|
|标准工资率||根据模拟报价标准费率获取。|
|人工费用||标准工时*标准工资率，如果物料是半成品，即有下层子项物料，则该项的人工费用=本项人工费用+直接下层子项的人工费用之和。|
|变动制造费用分配率||根据模拟报价标准费率获取。|
|制造费用||标准工时*变动制造费用分配率，如果物料是半成品，即有下层子项物料，则该项的制造费用=本项制造费用+直接下层子项的制造费用之和。|
|计件单价||根据模拟报价标准费率获取。|
|计件金额||计价单价*当前项数量|
