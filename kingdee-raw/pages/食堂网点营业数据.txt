====== 1.食堂网点营业数据 ======

===== 1.1 功能概述 =====

记录每个营业网点的营业数据，包括实际的营业额，实际的用餐人数，实际的营业费用，报损的菜品，等营业数据；详细记录每个食堂网点的营业数据，方便营业者进行分析和决策
===== 1.2 字段说明 =====

^ 字段名称    ^ 字段说明                       ^
| 报餐周次    | 自动计算报餐日期对应的周次              |
| 收入指标分类  | 取报餐指标设置的值                  |
| 收入指标项目  | 取报餐指标设置的值                  |
| 档口部门    | 自动携带报餐单的档口部门信息             |
| 实际营业金额  | 手工录入                       |
| 报损金额    | 取食品报损单-团餐的金额               |
| 实际用餐人数  | 手工录入                       |
| 平均餐标    | 实际营业金额/实际用餐人数              |
| 费用指标分类  | 取报餐指标设置的值                  |
| 费用指标项目  | 取报餐指标设置的值                  |
| 参与计算    | 参与计算则食堂网点营业数据会统计，不勾选则不会统计  |
| 费用金额    | 设置每项费用指标分类花费的金额            |
