====== 5操作说明 ======


  - 采购合同单据状态说明，请参考[[单据状态通用说明]]
  - 采购合同单据操作分为整单操作与行业务操作两种 

===== 5.1整单操作 =====
 
采购合同整单操作类似于采购申请单，这边就不复述，请参考[[采购申请单]]

===== 5.2行业务操作 =====
 
==== 5.2.1业务关闭操作 ====
 

  * 正常状态 
  - 用户执行单据新增时，单据默认业务关闭字段是【正常】状态 
  - 表示合同的当前记录行未被入库单关联完成 
  * 业务关闭 
  - 业务关闭由系统自动进行 
  - 合同明细完全下推采购订单且审核后业务关闭状态为业务关闭 
  - 单据记录行为业务关闭状态时，除查看、手工反关闭、打印、引入引出等操作外，不允许进行其他操作，包括编辑和关联操作 
  - 业务关闭时系统自动将业务关闭字段设置为【业务关闭】 
  * 业务反关闭 
  - 业务反关闭由系统自动进行，或由用户手工进行 
  - 已业务关闭的采购合同下推的采购订单删除或变更数量小于合同数量后自动更新为正常状态
  - 业务反关闭时系统自动将业务关闭字段设置为【正常】 

==== 5.2.2业务终止 ====
 

  * 正常状态 
  - 用户执行单据新增时，单据默认业务终止字段是【正常】状态 
  - 表示当前单据可以正常进行业务处理和操作 
  * 终止 
  - 业务终止是由用户手动进行的业务操作 
  - 已审核、未关闭、未终止的采购合同可以进行业务终止操作 
  - 业务终止表示由当前记录行不再进行相关的业务处理；被终止的分录可以进行除查看、反终止、打印、引入引出等操作，其它操作都不允许，包括编辑和关联等 
  - 终止时系统自动将业务终止字段设置为【终止】 
  * 反终止 
  - 业务反终止是由用户手动进行的业务操作 
  - 业务终止的采购合同分录可以进行业务反终止操作 
  - 反终止时系统自动将业务终止字段设置为【正常】 
====== 6业务说明 ======


===== 6.1库存查询 =====
 
采购合同上支持库存查询功能，直接调用库存数据，具体库存查询的规则同采购申请单库存查询。

===== 6.2价格查询 =====
 
价格查询是指按照当前单据的条件从采购价目表查询采购价格信息，查询结果是符合条件的有效价格。


===== 6.3历史价格查询 =====

历史价格查询是按照指定物料从历史采购合同或采购发票中查询物料的历史价格信息。

===== 6.5采购订单折扣 =====
 
采购合同折扣管理，请参考采购折扣管理

===== 6.6采购合同预付 =====
 
采购合同支持两种预付款应用场景，并根据供应商的单次预付额度来进行预付款的金额管控。

先预付后合同即先期向供应商支付一定金额作为预付款，然后下达采购合同。在采购合同上选择预付类型的付款单，审核采购合同后占用预付款。   
先合同后预付即先下达采购合同，合同上维护预付款金额，然后根据采购合同做付款单或付款申请单。 
如果采购合同被付款单关联，则采购合同不能反审核 
采购合同关联的预付信息在下推采购订单时会携带关联信息
采购合同的预付情况可以通过【预付查询】来进行查询 

===== 6.7采购合同单据转换 =====
 
==== 6.7.1采购合同与采购订单关联转换业务 ====
 

  * 转换规则 
采购合同可以下推采购订单，也可以在采购订单界面选单采购合同生成采购订单，实现关联业务的转化，采购合同与采购订单转化的规则如下：

  - 单据状态为“已审核”，且关闭状态为“未关闭”，且业务状态为 “正常”的采购合同才能转化为采购订单 
  - 采购合同订单关联数量大于等于合同数量时，采购订单无法下推采购订单 
  - 在采购订单界面选单时，可选择的采购合同列表界面默认只过滤出符合上面条件的采购合同 
  - 选择多张采购合同合并生成采购订单时，供应商、收货组织、采购组织、需求组织、结算组织和结算币别相同的分录才能合并到一张采购订单上  
  - 采购合同下推采购订单时，采购订单的字段关联携带到采购订单上 
  - 采购订单审核时，将采购订单数量累加至采购合同【累计订单数量】字段上，采购订单反审核时，需要扣减数量。

  * 单据流程
合同类型：普通合同、框架合同、单价合同。
 1、普通合同，
 适用场景：采购合同按录入的物料明细控制后续采购业务的采购数量。当采购合同下推到采购订单的累计数量达到采购合同的合同数量时，采购合同自动关闭。
 
 支持流程：采购合同 — 采购订单 — 采购入库单 — 应付单 — 付款；或者采购合同 — 应付单—付款； 

 2、框架合同，
 适用场景：框架合同无物料明细，仅指定合同总金额，

 支持流程：采购合同 — 付款流程。

 3、单价合同
 适用场景：部分长期采购的合同，只有物料和单价，不按数量控制，允许多次下推采购订单，且不控制采购合同数量、金额，允许超额，仅携带价格。单价合同只按有效期限制，单价合同创建时仅需录入物料和单价即可，数量和金额可为空，允许多次下推采购订单，不控制数量或金额是否超额，下推采购订单后，数量和金额会反写到采购合同中，采购订单审核后数量或金额超过合同指定数量时合同不自动关闭。 

 支持流程：采购合同 — 采购订单 — 采购入库单 — 应付单 — 付款；或者采购合同 — 预付。  

====== 7供应商协同平台 ======

  * 功能说明
  - 企业的采购合同审核后，供应商可以在供应商协同中查询。
  - 对数据进行严格过滤，仅显示该供应商的采购合同。
  * 功能操作
  - 供应商登录供应商协同平台，进入供应商协同—订单协同—采购合同，设置过滤条件，查询相关数据。
