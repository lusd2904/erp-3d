====== 聚合收款 ======
=====1 功能说明 =====
  * 启用聚合收款功能，实现销售订单和应收单生成支付二维码支持微信和支付宝，提供给客户进行扫描支付，支付成功会自动生成收款单关联订单或者应收单。
=====2 操作前提 =====

用户赋权、数据中心权限设置支付回调地址、聚合收款商户号设置对应秘钥。

=====3 功能路径 =====

【财务会计】—>【出纳管理】—>【聚合收款】—>【聚合收款首页】

=====4 字段说明 =====
| **字段**     || **说明**             |
| 收款组织       || 下游单据的主业务组织。        |
| 单据编号       || 金蝶信科交易流水号。         |
| 币别         || 人民币。               |
| 收款金额       || 对销售订单应收单下推的收款金额。   |
| 微信账号       || 收款方微信账号。           |
| 支付宝账号      || 收款方支付宝账号。          |
| 二维码链接      || 根据微信或者支付宝生成对应二维码。  |
| 交易状态       || 实际交易状态。            |
| 收款时间       || 实际收款时间。            |
| 请求人        || 单据创建人。             |
| 请求日期       || 单据创建日期。            |
| 撤销人        || 单据撤销人。             |
| 撤销日期       || 单据撤销日期。            |
| 源单类型       || 上游单据类型。            |
| 源单编号       || 上游单据编号。            |



=====5 操作说明 =====
  * 【财务会计】-【出纳管理】-【聚合收款】-【聚合收款首页】设置商户号并维护用于移动收款的微信、支付宝账号，
  * 设置收款方案，对支付类型、通知方式、收款账号、收款链接有效时间等信息进行配置。
  * 对于想实现聚合收款的销售订单和应收单进行收款，生成二维码，提供扫码支付。
