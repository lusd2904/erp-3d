======1  加工订单执行汇总表=======
=====1.1 报表功能=====

1.加工订单执行汇总表能够使用户能及时地了解加工订单的整体执行情况。

2.加工订单执行汇总表支持按照产品/车间/单据类型等多维度，进行查询加工订单的执行情况。


======2. 字段说明======

=====2.1 快捷过滤 =====
^  **字段**  ^  **说明**                                     ^
|  加工组织    | 1.定义报表查询的组织范围；\\ 2.必须具有加工职能，有且只能录入一个组织。     |
|  下达日期    | 1.加工订单分录行的下达日期；\\ 2.定义报表查询的下达日期范围。          |
|  计划开工日期  | 1.加工订单分录行的计划开工日期；\\ 2.定义报表查询的计划开工日期范围。      |
|  计划完工日期  | 1.加工订单分录行的计划完工日期；\\ 2.定义报表查询的计划完工日期范围。      |
|  单据类型    | 1.加工订单的单据类型；\\ 2.定义报表查询的加工订单的单据类型。          |
|  加工订单    | 1.加工订单的编号；\\ 2.定义报表查询的加工订单范围。               |
|  加工车间    | 1.加工订单表体分录的加工车间；\\ 2.定义报表查询的加工车间范围。         |
|  产品编码    | 1.加工订单分录行的物料编码；\\ 2.定义报表查询的产品编码范围。          |
|  挂起状态    | 加工订单分录行的挂起状态。                               |
|  业务状态    | 1.加工订单分录行的业务状态；\\ 2.包含：下达、开工、完工、结案，结算五个选项。  |
|  汇总依据    | 1.报表进行汇总的分类依据；\\ 2.包含：产品，车间+产品两个选项。         |

=====2.2 报表字段 =====

^  **字段**   ^  **说明**                     ^
|  产品编码     | 加工订单表体分录对应的【物料编码】           |
|  产品名称     | 加工订单表体分录对应的【物料名称】           |
|  规格型号     | 加工订单表体分录对应的【规格型号】           |
|  加工单位     | 物料的加工单位。                    |
|  计划加工数量   | 符合过滤条件的加工订单分录中，计划加工产品的数量之和  |
|  合格入库数量   | 符合过滤条件的加工订单分录中，合格品入库的数量之和   |
|  不合格入库数量  | 符合过滤条件的加工订单分录中，不合格品入库的数量之和  |
|  返工品入库数量  | 符合过滤条件的加工订单分录中，返工品入库的数量之和  |
|  产品类型     | 加工订单分录行的产品类型，包含主产品和联副产品。    |
