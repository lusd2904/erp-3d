======1. 委外月末在制转移 ======

=====1.1 功能概述 =====
帮助车间进行委外订单跨月的在制转移业务，提高成本计算的准确性。

同时支持订单内转移与订单间转移。

=====1.3 功能路径 =====
【生产制造】－>【委外管理】－>【委外平台】－>【委外月末在制转移】

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^  **字段**  ^  **说明**                                       ^
|  单据编码    | 1.单据编号由系统设定的编码规则自动生成。\\ 2.具有唯一性，不允许重复。        |
|  单据类型    | 系统自动取委外月末在制转移的默认单据类型；\\ 单据新增时可改；\\ 单据保存后不可改。  |
|  单据日期    | 默认为当前系统日期，用户可对日期进行修改。                         |
|  单据状态    | 不可编辑，由系统根据单据操作自动标识，包括，暂存、创建、审核中、已审核、重新审核。     |
|  委外组织    | 1.当前组织具有生产职能，默认取当前组织；\\ 2.可选择有权限的其它组织。        |
| 采购组织     | 1.当前组织具有采购职能，默认取当前组织；\\ 2.可选择有权限的其它组织。        |
|  供应商     | 加工产品的委外供应商。                                   |
|  中转仓库    | 转出转入时的仓库                                      |
|  中转仓位    | 转出转入时的仓位                                      |
|  调整类型    | 可以选择订单内转移或订单间转移                               |
|  转出日期    | 产生转出退料单的业务日期                                  |
|  转入日期    | 产生转入领料单或补料单的业务日期                              |

====== 3 操作说明 ======
====转出==== 
点击“选单”，可以选择已下达未结案的委外订单；
调整类型为“订单间转移”时，转入委外订单的供应商、物料、BOM等维度必须与转出订单相同。

====转出==== 
点击“转出”，自动生成转出订单的退料单，退料仓库为中转仓。

====撤销转出==== 
点击“撤销转出”，自动删除已经生成的退料单。

====转入==== 
点击“转入”
转入数量小于等于转入订单的可领数量时，生成委外领料单，领料仓库为中转仓；
转入数量大于转入订单的可领数量时，生成委外补料单，补料仓库为中转仓。

====撤销转入==== 
点击“撤销转入”，自动删除已经生成的领料单、补料单。
