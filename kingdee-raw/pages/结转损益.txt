====== 1.功能说明 ======

本系统提供的结转损益功能，是将账簿内各损益类科目的余额转入本年利润科目，并生成一张结转损益记账凭证，以反映企业在一个会计期间内实现的利润或亏损总额。

**操作前提**

结转损益操作需满足下列前提条件：

1) 账簿系统参数已设置<本年利润科目>、<利润分配科目>；

2) 账簿当前期间不存在未过账的结转损益凭证。

**功能路径**

【财务会计】→【总账】→【期末处理】→【结转损益】
====== 2.字段说明 ======

^ 参数                    |^ 说明                                                                                                           ^
| 执行方式                  || 手动：用户选择一个或多个结转损益方案，通过点击【执行】按钮手动执行方案。\\ 自动：按方案中设置的执行频率，定时执行结转损益方案。                                            |
| 执行频率                  || 设置结转损益方案的自动执行频率。                                                                                             |
| 执行人                   || 执行方式设置为“自动”时，需要指定执行人。生成凭证的制单人为该执行人。                                                                         |
| 凭证日期方式                || 指定当前方案生成的结转损益凭证的日期获取方式。                                                                                      |
| 凭证类型                  || 选择“收益”，系统将收入类科目结转生成一张凭证；选择“损失”，系统将费用、损失类科目结转生成一张凭证；选择“损益”，系统将收入、费用和损失类科目结转生成一张凭证。                            |
| 按普通方式结转               || 系统将所有结转科目生成到一张凭证中。                                                                                           |
| 按损益科目类别结转             || 系统将损益类科目按其科目类别分别生成多张结转损益凭证。如营业收入、期间费用、其他损失等。                                                                 |
| 按核算维度结转               || 系统将按照损益类科目所挂的核算维度分别生成多张凭证。首先将相同核算维度的损益类科目按核算维度分别生成不同的凭证，然后将剩余的没有带此核算维度的科目结转生成另外一张凭证，最后将不带任何核算维度的科目结转生成一张凭证。  |
| 按科目余额的相反方向结转          || 选中此选项，结转凭证分录的余额如果为负数，则将其余额置为相反方向的正数后再转出。不勾选时，系统始终从科目本身的余额相反方向转出（如：借方科目始终从贷方转出）。                              |
| 按收益和损失的差额记入【结转科目】     || 当凭证类型为“损益”时，本选项才可见。选中此选项，结转凭证中的本年利润分录行合并显示。不勾选时，收益和损失分别转入本年利润科目。                                             |
| 暂存保存失败的凭证       || 选中此项，生成的凭证保存失败时自动进行暂存。              |
| 结转科目设置                || 设置当前方案包括的损益科目，支持指定科目结转损益。                                                                                    |


====== 3.操作说明 ======

  * 执行：用户可以选择一个或多个结转损益方案执行，每个方案单独生成一张结转损益凭证。
  * 禁用、反禁用：禁用或反禁用选中的结转损益方案。
  * 联查凭证：用户选择一个或多个结转损益方案后点击【联查凭证】按钮，系统将展示相关方案生成的凭证列表。
  * 向导式结转损益：调用向导式结转损益功能，指引用户分步完成结转损益工作。
====== 4.其他说明 ======

执行结转损益方案时，系统会对结转账簿进行结转损益前的相关检查，检查通过后，会根据方案中的设置进行结转并自动生成结转损益凭证。
