======1  生产订单排产明细=======
=====1.1 动态表单功能=====
1.生产订单排产明细能够各车间各线指定日期范围内的排产信息

2.生产订单排产明细界面支持取消排产。

======2. 字段说明======
=====2.1 表头过滤字段 =====
^  **字段**      ^  **说明**                                                                                                                                                       ^
| 生产组织        |1.定义表单查询的组织范围；2.必须具有生产职能，有且只能录入一个组织。                                                                                                                        |
| 生产车间        |1.生产订单表体分录的生产车间；2.定义报表查询的生产车间范围。                                                                                              |
| 产线        |1.生产订单排产的产线；2.定义报表查询的产线范围。                                                                                              |
|订单编号        |1.定义表单查询的生产订单范围；                                                 | 
|产品编码        |1.定义表单查询的生产订单的产品编码范围；                                                 | 
|排产日期范围       |1.定义表单查询的生产订单订单排产起始日期                                             | 
|入库数量取值      |1.定义表单入库数量的取值，包括实际入库数量和按排产明细顺序分配两个选项。   选择按实际入库数量，表单根据生产入库单表头日期匹配排产日期显示对应行的入库数量。选择按排产明细顺序分配，则将累计的入库数量按日产量逐天分配到排产明细上，直到入库数量分配完。                                         | 
=====2.2 表体数据 =====
^  **字段**  ^  **说明**                                             ^
|  销售订单    | 显示根据表头过滤条件刷新出来的生产订单对应的销售订单号                         |
|  客户      | 显示根据表头过滤条件刷新出来的生产订单对应的销售订单上的客户                      |
|  要货日期    | 显示根据表头过滤条件刷新出来的生产订单对应的销售订单上的要货日期                    |
|  单据类型    | 显示根据表头过滤条件刷新出来的生产订单的单据类型                            |
|  生产订单编号  | 显示根据表头过滤条件刷新出来的生产订单的单据编号                            |
|  订单行号    | 显示根据表头过滤条件刷新出来的生产订单的行号                              |
|  业务状态    | 显示根据表头过滤条件刷新出来的生产订单的分录的业务状态                         |
|  生产车间    | 显示根据表头过滤条件刷新出来的生产订单的分录的生产车间                         |
|  产线      | 显示根据表头过滤条件刷新出来的生产订单的排产明细的产线                         |
|  产品编码    | 显示根据表头过滤条件刷新出来的生产订单的物料编码。                           |
|  产品名称    | 物料名称。                                               |
|  规格型号    | 物料的规格型号。                                            |
|  生产单位    | 生产订单分录的对应物料的生产单位 。                                  |
| 计划开工日期   | 显示根据表头过滤条件刷新出来的生产订单分录的计划开工日期                        |
| 计划完工日期   | 显示根据表头过滤条件刷新出来的生产订单分录的计划完工日期                        |
|  日产量     | 显示根据表头过滤条件刷新出来的生产订单的排产明细的日产量                        |
|  排产日期    | 显示根据表头过滤条件刷新出来的生产订单的排产明细的排产日期                       |
|  排产数量    | 显示根据表头过滤条件刷新出来的生产订单的排产明细的排产数量                       |
|  未排数量    | 显示根据表头过滤条件刷新出来的生产订单生产数量-排产数量                        |
|  入库数量    | 显示根据表头过滤条件刷新出来的生产订单对应的入库数量，入库数量根据表头的入库数量取值设置相应的取数。  |
|  退库数量    | 显示根据表头过滤条件刷新出来的生产订单对应的退库数量。                         |
======3. 相关操作======
取消排产：在此界面查询出来的排产明细，如果需要调整重排，可以取消排产，然后到生产日排产界面重新排产。
