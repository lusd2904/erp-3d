ID: 公告新增
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%AC%E5%91%8A%E6%96%B0%E5%A2%9E

**功能说明：**

用于直接渠道对间接渠道（即下级渠道）做商品宣传、发布公司新闻、节日促销活动、服务信息等的公告创建

**功能路径：**

【公告管理】->【前台公告管理列表】->【新增】

**使用前提：**

直接渠道

**字段说明：**
| **字段**     | **字段说明**                              |
| 基本信息                                              ||
| 公告编码       | 系统按一定规则自动生成的编码                        |
| 公告主题       | 必填；显示在前台公告的标题                         |
| 公告状态       | 取值范围包括：创建、已保存、已提交、已审核、重新审核、已发布、取消发布；  |
| :::        | 根据不同的状态会有不同的处理结果                      |
| 公告分类       | 关联公告分类表                               |
| :::        | 可以新增、删除、编辑相关分类                        |
| 发布日期       | 默认系统当前日期                              |
| 详细介绍                                              ||
| 详细介绍       | 公告内容的详细介绍说明                           |
| :::        | 支持上传图片说明、支持上传附件                       |
| 发布给下级渠道                                           ||
| 下级渠道       | 关联渠道类型表，F8浏览选择。根据选择记录，直接取渠道名称                     |
| 渠道组织类型   | 根据所选择的下级渠道，自动携带出来                     |
| 渠道性质     | 根据所选择的下级渠道，自动携带出来                      |
| 所属法人       | 根据所选择的下级渠道，自动携带出来                     |

	
**操作说明：**
  - 进入前台公告管理列表，点击【新增】按钮即跳转至公告新增页面。填写相关信息
  - 增加完相关信息后，点击【保存】即新增公告成功
  - 保存后在公告只是保存在本地可查看修改，未发布。只有发布的公告下级渠道才可以查看
