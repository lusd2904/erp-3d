====== 库存检验控制码 ======
             
在库存检验前，先设置库存检验控制码；

库存检验控制码作用：

1、库存检验后，进行库存状态调整的参数设置；

2、需要库存复检到期提醒的相关参数设置；

（注意：设置库存检验控制码后，添加了仓库且该仓库需要复检提醒，需要再次设置、保存库存检验控制码）

**功能路径：**

【质量管理】-【质量管理】-【库存检验控制码】；

**字段说明**

| **字段 **                   || **说明 **                                                                                                                                                                    |
| 库存请检自动冻结                  || 参数勾选，库存请检单审核后自动生成库存状态转换单，转换后的状态一般设置为冻结。                                                                                                                                    |
| 库存检验质检完成自动库存状态转换          || 勾选后，在库存检验单质检完成后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                                  |
| 不良品处理单审核自动转换库存状态          || 勾选后，在不良品处理单审核后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                                    |
| MRB评审单审核自动转换库存状态          || 勾选后，在MRB评审单审核后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                                    |
| 库存状态转换单单据状态           || 库存检验质检完成以及不良品处理单和MRB评审单审核后自动生成的库存状态转换单，可设置的单据状态包括：保存、提交、审核                  。                                                                                                                    |
| 库存检验反质检完成自动删除库存状态转换单      || 勾选后，在库存检验单反质检后，后台自动删除库存状态转换单。                                                                                                                                              |
| 不良品处理单反审核自动删除库存状态转换单      || 勾选后，在不良品处理单反审核后，后台自动删除库存状态转换单。                                                                                                                                            |
| MRB评审单反审核自动删除库存状态转换单      || 勾选后，MRB评审单反审核后，后台自动删除库存状态转换单。                                                                                                                                              |
| 发货请检自动冻结                  || 参数勾选，发货请检单审核后自动生成库存状态转换单，转换后的状态一般设置为冻结。                                                                                                                                    |
| 发货检验质检完成自动库存状态转换          || 勾选后，在发货检验单质检完成后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                               |
| 发货不良品处理单审核自动生成库存状态转换单          || 勾选后，在不良品处理单审核后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                                  |
| 发货MRB评审单审核自动生成库存状态转换单      || 勾选后，在MRB评审单审核后，如果物料的检验结果与现有的库存状态不相符，后台自动生成库存状态转换单。                                                                                                                                                                                                |
| 库存状态转换单单据状态           || 发货检验质检完成以及不良品处理单审核后自动生成的库存状态转换单，可设置的单据状态包括：保存、提交、审核                  。                                                                                                                    |
| 发货检验反质检完成自动删除库存状态转换单      || 勾选后，发货检验单反质检后，后台自动删除库存状态转换单。                                                                                                                                              |
| 发货不良品处理单反审核自动删除库存状态转换单    || 勾选后，发货不良品处理单反审核后，后台自动删除库存状态转换单。                                                                                                                                            |
| 发货MRB评审单反审核自动删除库存状态转换单      || 勾选后，MRB评审单反审核后，后台自动删除库存状态转换单。                                                                                                                                              |
| 质检冻结库存状态                  || 设置请检单审核后自动生成的状态转换单转换后的库存状态，一般设置为冻结。                                                                                                                                        |
| 不参与核算质检冻结库存状态             || 设置不参与核算的库存，请检单审核后自动生成的状态转换单转换后的库存状态，一般设置为冻结。                                                                                                                               |
| 库存转换默认仓库和状态               || 对于细化的库存检验结果-使用决策为【合格】【不良】【报废】的物料，如果库存状态发生变换，需要转换，设置转换规则\\ 【⊙库存请检单的仓库\仓位】选中，保持原有仓库，仅仅对库存状态进行转换；\\ 【⊙统一指定：仓库_仓位_】选中，针对库存检验结果为【合格】【不良】【报废】的物料，如果库存状态发生变换，需要转仓，设置转换后的仓库及库存状态。  |
| 物料复检库存请检单生成方式             || “交互式”参数勾选后（默认勾选），【库存物料复检到期查询】界面点请检后库存请检单的生成方式为交互式，反勾选时则后台自动生成审核状态的库存请检单                                                                                                        |
| 复检提醒日期取值                  || 参数勾选“首次复检提醒取生产日期”，库存物料复检周期查询首次请检的起始日期优先取即时库存的生产日期。                                                                                                                         |
| 参与复检提醒库存状态类型              || 设置需要参与库存物料周期复检的库存状态类型。                                                                                                                                                     |
| 复检提醒仓库信息                  || 勾选的仓库，在【库存物料复检到期查询】中进行提醒和生成库存请检单。                                                                                                                                          |
