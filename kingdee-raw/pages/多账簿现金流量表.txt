====== 1.功能说明 ======

系统根据已指定现金流量情况提供多账簿现金流量表查询，用户通过【财务会计】－>【总账】－>【多账簿合并】－>【多账簿现金流量表】功能进行多账簿现金流量表查询。

====== 2.过滤条件 ======

用户在工具栏点击过滤按钮，设置现金流量表查询的过滤条件。

^ 过滤项                ^ 说明                                             ^
| 账簿隶属关系             | 设置账簿隶属关系                                       |
| 合并层级               | 设置账簿隶属关系的节点，可以选择到最明细账簿，账表根据该项展示相应层级的数据。        |
| 账簿                 | 选择现金流量表查询的账簿（账簿支持多选）。                          |
| 币别                 | 设置现金流量表查询的币别。                                  |
| 项目汇总级次             | 设置现金流量明细项目的汇总级次，系统支持3级以上项目的汇总。                 |
| 包括未过账凭证            | 选中此项，查询结果中包含未过账凭证的数据。                          |
| 显示汇率变动产生的现金流量明细项目  | 选中此项，报表中将按照用户设置的项目汇总级次显示汇率变动产生的现金流量对应级次的项目明细。  |
| 按账簿列式              | 选中此项，自动勾选并锁定“显示项目明细”，查询结果按账簿列式每个账簿的现金流量表数据。    |
| 显示项目明细             | 选中此项，查询结果在每个现金流量项目下面分行显示其构成明细。                 |
| 显示比重               | 选中此项，查询结果在每个金额后面显示相关项目的占比。                     |
| 对比期间-名称            | 设置自定义对比期间的名称（如：去年同期）。                          |
| 对比期间-开始日期          | 设置自定义对比期间的查询开始日期。                              |
| 对比期间-结束日期          | 设置自定义对比期间的查询结束日期。                              |

在现金流量表过滤结果界面增加“流量检查”按钮，用来调用现金流量检查功能。
^ 过滤项                   ^^ 说明                                             ^
| 账簿                    || 当前用户具有查询权限的账簿，默认核算体系主账簿。                                  |
| 核算组织                || 所选账簿关联的核算组织。                                  |
| 检查项目                    || 默认检查全部，下拉选择，也支持检查主表项目。                                  |
| 按期间查询                || 默认勾选。                 |
| 按日期查询               || 默认不勾选。                          |
| 会计年度     || 账簿启用年度至期间管理的最大年度。  |
| 会计期间     || 起始年度对应的期间列表以及账簿对应的调整期间。  |
| 开始日期     || 账簿会计日历内的日期。 |
| 结束日期     || 账簿会计日历内的日期。  |

====== 3.操作说明 ======

现金流量检查，支持全部、主表项目的检查。检查时根据检查项目确定范围。

流量检查主要检查以下几种现金流量指定的错误：
  * a)	需要指定主表项目的凭证未指定
  * b)	主表项目指定的金额跟需要指定的金额不平衡
  * c)	不需要指定主表项目的凭证指定了主表
  * d)	需要指定附表项目的凭证未指定
  * e)	附表项目指定的金额跟需要指定的金额不平衡
  * f)	不需要指定附表项目的凭证指定了附表
  * g)	附表项目调整合计不为零

检查以后以列表的形式显示有问题的凭证，支持凭证联查
