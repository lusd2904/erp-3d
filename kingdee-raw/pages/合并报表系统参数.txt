===== 合并报表系统参数 =====

**功能说明**

为了满足集团编制合并报表中的个性化需要，系统将针对某一业务处理的不同方式，设置为不同的系统参数，用户可以从中选择自己所需要的处理，系统参数的设置关系到以后系统的业务处理，用户在设置前要根据集团合并报表的管理制度和要求慎重考虑。

系统参数一经确定，除非相关设置发生变化，一般不要轻易改动。

**操作前提**

合并方案已启用。

**操作说明**

打开【财务会计】－>【合并报表】－>【参数设置】－>【合并报表系统参数】功能，按合并方案设置系统参数。 

**全局参数字段说明**

全局参数是指适用于各合并方案的参数

| 参数                              || 说明                                                                                                                                                                                                                                                                     |
| 持股比例精度                          || 控制股权关系、持股比例数值的小数位，默认为2位精度。                                                                                                                                                                                                                                             |
| 启用数据授权                          || 勾选，则启用合并报表数据授权，需结合合并报表数据授权方案使用，控制用户可看到合并范围。                                                                                                                                                                                                                            |
| 报前调整备份调整前报表                     || 勾选，则制作报前调整时，会将调整前的报表备份一份，用于查询及归档之用，不允许反审核及修改等操作，如需对此类备份操作，则需要删除报前调整数据。                                                                                                                                                                                                 |
| 报前调整分录只允许调整明细项目                 || 勾选，则报前调整分录录入时，只能选择明细级的报表项目                                                                                                                                                                                                                                             |
| 借贷不平的报前调整分录禁止提交              || 勾选，借贷不平的报前调整分录无法进行提交                                                                                                                                                                                                                                                   |
| 增加内部事项交易类-存货核对                  || 勾选，则内部事项交易类核对增加存货类的核对，需进行存货类内部事项核对，才能生成存货类的抵消分录。\\ 此选项适用于内部交易的存货继续应用在产品生产过程中，导致生产环节也有未实现利润。\\ 选择此参数，则抵销分录模板也发生了变化，自动禁用原有的存货类抵消分录模板，自动增加系统预设的新的抵销分录模板，用户也可以据此做修改。\\ 新的抵消分录模板为：\\ 借：主营业务收入-销售方\\ 贷：主营业务成本-销售方\\ 贷：主营业务成本-采购方\\ 贷：存货-采购方\\ 做此类核对时，将按上述模板检查内部组织间交易是否存在差异。  |
| 上报合并报表外币折算，设置历史汇率时直接取项目变动记录     || 勾选，则上报的合并报表的报表项目设置了历史汇率的，直接取折算准备-项目变动记录里的数据，按对应的合并范围的金额、币别及时间，进而从汇率体系中取对应时间和币别的汇率，然后，进行汇率的折算。\\ 此选项适用于多层级合并时，上报的合并报表中，有报表项目设置为历史汇率。                                                                                                                                    |
| 外币折算的汇率精度取汇率类型的汇率精度             || 勾选，则折算使用的汇率精度与汇率体系-汇率类型设置直接/间接精度的小数位一致\\ 不勾选，则需经过计算的汇率，如周期汇率、平均汇率等，默认精度为10位小数                                                                                                                                                                                          |
| 显示当前及下层合并范围抵消分录数据               || 此参数应用场景：多层合并，且存在跨层抵消。有效于上层合并，对底层合并无效。\\ 勾选，则上层合并的抵消分录查询会显示当前及下层的抵消分录，当有跨层抵消时，可以全局性的查看抵消数据。。                                                                                                                                                                            |
| 允许在工作底稿模板手工编辑项目公式和增减行列       || 工作底稿模板默认由模板样式方案填充而成，不能手工修改项目公式和增减行列\\ 勾选，则可在工作底稿模板上修改项目公式和增减行列                                                                                                                                                                                                         |
| 允许在汇总报表模板手工编辑项目公式和增减行列       || 汇总报表模板默认由模板样式方案填充而成，不能手工修改项目公式和增减行列\\ 勾选，则可在汇总报表模板上修改项目公式和增减行列                                                                                                                                                                                                         |

**合并方案级参数字段说明**

合并方案级参数是指分合并方案设置的参数，各合并方案参数可以不一致。

| 参数                                     | 说明                                                                                                                       |
| 合并方案                                   | 选择合并方案，针对合并方案设置具体控制参数。                                                                                                   |
| 允许手工编制调整报表数据                           | 选择该参数，在编制调整报表时，禁止用户手工修改调整报表数据，只能通过调整分录重算更新调整报表数据。\\ 不选择该参数，在编制调整报表时，支持手工修改调整报表数据，同时也支持通过调整分录重算更新调整报表数据。                  |
| 允许手工编制工作底稿数据                           | 选择该参数，则表示在编制工作底稿时，禁止用户手工修改工作底稿数据，只能通过抵销分录重算更新工作底稿数据。\\ 不选择该参数，则表示在编制工作底稿时，支持手工修改工作底稿数据，同时也支持通过抵销分录重算更新工作底稿。              |
| 调整分录允许调整非明细项目                          | 选择该参数，在编制调整分录时，未禁用的报表项目都可被使用。\\ 不选择该参数，在编制调整分录时（包括报前调整和上报后的调整），不允许选中非明细的报表项目，且如果调整分录模板中存在非明细项目时，引入至调整分录时，非明细项目控制不能引入。    |
| 抵消分录允许抵消非明细项目                          | 选择该参数，在编制抵消分录时，未禁用的报表项目都可被使用。\\ 不选择该参数，在编制抵消分录时，不允许选中非明细的报表项目，且如果抵消分录模板中存在非明细项目时，引入至抵消分录时，非明细项目控制不能引入。                   |
| 借贷不平的集团调整分录禁止提交                        | 选择该参数，借贷不平的集团调整分录无法进行提交\\ 不选择该参数，借贷不平的集团调整分录只作提示，可以进行提交                                                                  |
| 借贷不平的抵消分录禁止提交                          | 选择该参数，借贷不平的抵消分录无法进行提交\\ 不选择该参数，借贷不平的抵消分录只作提示，可以进行提交                                                                      |
| 启用内部事项往来类核对逻辑：\\ 我方的债权-债务=对方的-（债权-债务）  | 选择该参数，则往来类内部事项核对的逻辑为我方的债权-债务=对方的-（债权-债务）。核对后产生的抵消分录为差额的抵消。\\ 适用场景：我方对于对方公司的往来既有债权也有债务，或对方公司对于我方的往来既有债权也有债务，或两者都是有债权和债务。  |
| 债权债务按明细行显示                             | 选择启用内部事项往来类核对逻辑后，此参数才可选择，\\ 选择该参数，往来类内部事项核对、抵消分录的相同报表项目按债权债务方分别显示\\ 不选择该参数，往来类内部事项核对、抵消分录的相同报表项目合并显示                     |
| 上报报表报前必须检查                             | 选择该参数，则报表上报前必须先进行报表项目勾稽关系检查和表内检查，只要报表有设置表内勾稽关系或有被分配报表项目勾稽关系，则强制检查。\\ 不选择该参数，则报表上报不进行报表项目勾稽关系检查和表内检查。                     |
