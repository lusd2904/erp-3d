====== 1.食堂网点报餐单 ======

===== 1.1 功能概述 =====
根据每个食堂网点的指标;进行具体的报餐，包括报餐的食品预估,报餐的人数和营业额等；将繁琐的报餐事物简单化，标准化
===== 1.2 字段说明 =====
^ 字段名称                        ^ 字段说明                                                         ^
| 配餐组织                        | 设置该报餐的配餐组织                                                   |
| 报餐日期                        | 设置报餐日期，如果报餐日期为系统当前日期则会弹出提示；设置报餐日期会校验报餐日历中是否允许报餐，如果没有设置则不能报餐  |
| 参考日期                        | 设置报餐日期时会自动取上周同星期的报餐单作为参考日期，如果上周期没有报餐单，则会弹出提示信息；用户可以手工选择参考日期  |
| 报餐周次                        | 自动计算报餐日期的周次                                                  |
| 参考周次                        | 自动计算参日期的周次                                                   |
| 费用指标分析                      | 取报餐指标的费用指标                                                   |
| 指标类别                        | 取报餐指标的费用指标下指标类别                                              |
| 指标项目                        | 取报餐指标的费用指标下的指标项目                                             |
| 标准指标                        | 取报餐指标的费用指标下的标准指标值                                            |
| 参考指标                        | 取参考组织下的报餐指标的费用指标下的指标项目                                       |
| 实际指标                        | 计算该报餐单中所选食品的实际指标                                             |
| 收入指标分析                      | 取报餐指标的收入指标                                                   |
| 指标分类                        | 取报餐指标的收入指标分类                                                 |
| 指标项目                        | 取报餐指标的收入指标项目                                                 |
| 标准用餐人数                      | 取报餐指标下该餐次的用餐人数                                               |
| 标准预估营业额                     | 取报餐指标下该餐次的预估营业额                                              |
| 参考用餐人数                      | 取参考组织下的报餐指标的实际用餐人数                                           |
| 参考营业额                       | 取参考组织下的报餐指标的实际营业额                                            |
| 当前预估用餐人数                    | 计算该报餐单中所有的用餐人数总和                                             |
| 当前预估营业额                     | 计算该报餐单中的预估营业额总和                                              |
| 档口部门                        | 由选择的食品自动携带                                                   |
| 食品分类                        | 由选择的食品自动携带                                                   |
| 食品编码                        | 选择需要的食品，只能选择该报餐指标该餐次下设置的食品                                   |
| 食品名称                        | 由选择的食品自动携带                                                   |
| 用餐份数	设置该食品的用餐份数             |                                                              |
| 报餐重量	报餐重量=用餐份数*单位重量         |                                                              |
| 单位	报餐重量的单位                  |                                                              |
| 成本	该食品的成本，由食品成本卡中携带而来       |                                                              |
| 预估营业额	预估营业额 =  食品售价 * 报餐重量  |                                                              |
| 毛利率	成本/售价                   |                                                              |
| 可供使用人数	报餐重量/报餐指标中设置的单位份量    |                                                              |
| 生成物料预估要货单	可以按照餐次生成物料预估要货单   |                                                              |
| 生成食品销售清单	按照餐次生成食品销售清单       |                                                              |
