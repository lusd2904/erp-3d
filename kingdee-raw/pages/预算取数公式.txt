**BGdata取数公式参数说明：**

BGdata取预算数函数。

关键参数说明：
^  参数            ^  说明                                                                                                                                                ^
| 预算方案           | 指取数来源预算方案。\\ 允许为空，为空时，第一优先级：公式取数参数.预算方案。第二优先级：当前预算报表属性.预算方案。                                                                                       |
| 模板样式方案         | 指的取数来源的模板样式方案。（目的是为了精确定位到具体的预算表表页）\\ 允许为空，为空时，取公式取数参数.预算控制规则（预算控制规则中指定的模板样式方案）。                                                                    |
| 预算组织           | 取数来源的预算组织。预算组织来源于默认预算组织架构。\\ 允许为空，为空时，第一优先级：公式取数参数.预算组织。第二优先级：当前预算报表属性.预算组织。                                                                       |
| 预算周期           | 取何种预算周期的预算数。\\ 允许为空，为空时，当前预算报表属性.预算周期。\\ 支持所有明细以及非明细预算周期的取数。如：预算以“月”为单位编制，此时可取“年”度周期汇总数。                                                           |
| 预算年度           | 取哪个预算年度的预算数。\\ 允许为空，为空时，第一优先级：公式取数参数.年度。第二优先级：当前预算报表属性.预算年度。                                                                                       |
| 预算开始期间、预算结束期间  | 取哪个预算期间的预算数。\\ 允许为空，为空时，第一优先级：公式取数参数。第二优先级：当前预算报表属性.预算期间。                                                                                          |
| 维度组合           | 取哪个预算维度组合对应的预算数。\\ 允许为空，为空时返回汇总数。                                                                                                                  |
| 预算业务类型、项目数据类型  | 取哪个项目数据类型（预算业务类型）的预算数。                                                                                                                             |
| 取数类型           | 原币金额/原币折合本位币金额/综合本位币金额。                                                                                                                            |
| 币别             | 预算币别。\\ 允许为空，为空时，第一优先级取公式取数参数，如公式取数参数.币别=综合本位币时，则直接取预算报表属性。\\ **说明**\\ 当取数类型=综合本位币金额时，【币别】参数为综合本位币币别，允许任意币别作为本位币币别，系统自动换算。\\ 换算汇率来源于：预算方案.预算汇率类型。  |
| 金额单位           | 元。目前版本，仅支持“元”金额单位。                                                                                                                                 |
| 数据范围           | 原始预算数+调整数/原始预算数/仅预算调整数。                                                                                                                            |

BGdata还受公式取数参数【选项：包含未审核预算报表】影响。


**SJdata取数公式参数说明：**

SJdata取实际数函数。

关键参数说明：

^  参数            ^  说明                                                                                             ^
| 预算方案           | 取实际数是基于哪套预算方案。\\ 允许为空，为空时，第一优先级取公式取数参数.预算方案，第二优先级取预算报表属性.预算方案。                                  |
| 控制规则           | 取实际数是基于哪个预算控制规则。\\ 允许为空，为空时，取公式取数参数.控制规则。                                                       |
| 预算组织           | 取哪个或者哪些预算组织的实际执行数。\\ 允许为空，为空时，第一优先级取公式取数参数.预算组织，第二优先级取预算报表属性.预算组织。                              |
| 预算周期           | 取何种预算周期的对应的实际数。\\ 允许为空，为空时，当前预算报表属性.预算周期。\\ 支持所有明细以及非明细预算周期的取数。如：预算以“月”为单位编制，此时可取“年”度周期汇总的实际数。  |
| 预算年度           | 取哪个预算年度的对应的实际执行数。\\ 允许为空，为空时，第一优先级：公式取数参数.年度。第二优先级：当前预算报表属性.预算年度。                               |
| 预算开始期间、预算结束期间  | 取哪个或者哪段预算期间对应的实际执行数。\\ 允许为空，为空时，第一优先级：公式取数参数.开始期间、结束期间。第二优先级：当前预算报表属性.预算期间。                     |
| 维度组合           | 取哪个预算维度组合对应的实际数。\\ 允许为空，为空时返回汇总数。                                                               |
| 预算业务类型、项目数据类型  | 取哪个项目数据类型（预算业务类型）的预算数。                                                                          |
| 币别             | 币别。\\ 允许为空，为空时，第一优先级取公式取数参数，如公式取数参数.币别=综合本位币时，则直接取预算报表属性。                                       |
| 金额单位           | 元。目前版本，仅支持“元”金额单位。                                                                              |


SJdata受公式取数参数【选项：包含未审核单据】影响，该选项与报表、合并报表公用，实际对于预算取实际数是【包含已提交未审核单据】。

SJdata受公式取数参数【选项：SJdata取数时，以控制规则中维度范围/维度过滤优先】影响，勾选时，SJdata在控制规则中预算维度范围过滤结果的基础上，再进行数据汇总取数。

SJdata受公式取数参数【选项：包含预算数为空的数据行】影响，选中时，取数范围包含已编制预算对应的实际执行数以及预算数不存在（未编预算），但对应有实际数的所有数据。
