====== 1.报表功能 ======

多账簿科目余额表以报表形式逐级展开各个合并层级的科目期初余额、本期发生额、本年累计发生额以及期末余额。

====== 2.过滤条件 ======

在“快捷”页签，用户选择需要查询的账簿，设置账簿隶属关系、合并层级、会计年度期间以及科目范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。
^ 过滤项                      |^ 说明                                                                 ^
| 账簿隶属关系                   || 选择在账簿隶属关系中设置的已经审核的账簿隶属关系方案。                                        |
| 合并层级                     || 选择账簿隶属关系中需要合并到的最底层账簿节点                                             |
| 科目级别                     || 设置科目显示的级别范围，按照科目级别逐级显示科目余额数据。                                      |
| 科目编码                     || 设置科目的查询范围。                                                         |
| 包括未过账凭证                  || 选中此项，查询结果包含未过账凭证的金额数据。                                             |
| 显示核算维度明细                 || 在显示科目信息的同时，显示科目下设置的核算维度明细维度的总分类账的查询信息。                             |
| 包括余额为零的科目                || 选中此项，显示期末余额为零的科目。                                                  |
| 包括没有业务发生的科目（期初、本年累计）     || 选中此项，显示期初余额为零或本年累计为零的科目。                                           |
| 包括本期没有发生额的科目             || 选中此项，显示本期发生额为零的科目。                                                 |
| 包括本年没有发生额的科目             || 选中此项，显示本年发生额为零的科目。                                                 |
| 余额方向与科目余额方向一致            || 选中此项，余额的显示方向与科目设置的余额方向相同，可能出现余额为负数的情况。否则，当余额为负数时，在科目余额的相反方向以正数显示。  |
| 显示数量单价                   || 选中此项，科目启用了数量金额辅助核算时，显示科目的单位、数量和单价等信息。                              |
| 每行都显示科目信息                || 选中此项，查询结果每行都显示科目信息，方便引出后进行分析统计。                                    |

====== 3.操作说明 ======

  * 全部展开\全部收起：一键展开或收起所有节点，节点数较多时比较耗时，需慎用。

  * 引出（按账簿分页）：将查询结果按账簿及合并节点分页引出。
