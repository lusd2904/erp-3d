====== 网银流水生成收款单 ======
=====1 功能说明 =====

下载网银流水
=====2 操作前提 =====

已经进行了银企互联设置并且已经测试通过。

=====3 功能路径 =====

【财务会计】—>【出纳管理】—>【日常操作】—>【收款单】—>业务操作—>接收银行收款记录

=====4 字段说明 =====
====4.1 过滤项字段说明 ====

[[网银流水生成收款单过滤方案|网银流水生成收款单过滤方案]]

====4.2 参数设置说明 ====

[[网银流水生成收款单参数设置|网银流水生成收款单参数设置]]
====4.3 表体字段说明 ====

| **字段**     || **说明**                                              |
| 单据类型       || 根据参数设置单据类型取值                                        |
| 往来单位类型     || 如果单据类型是销售收款，往来单位锁定为客户；\\ 如果是其他业务收款，默认取参数设置的默认值，可修改  |
| 往来单位       || 根据参数设置往来单位匹配条件取值，可手工修改                              |
| 结算组织       || 默认等于收款组织，可修改                                        |
| 结算方式       || 取参数设置的默认值，可修改                                       |
| 收款用途       || 取参数设置的默认值，可修改                                       |
| 交易日期       || 自动取网银流水交易日期，不可修改                                    |
| 交易时间       || 自动取网银流水交易时间，不可修改                                    |
| 银行账号       || 自动取网银流水交易银行账号，不可修改                                  |
| 账户名称       || 自动取网银流水交易账户名称，不可修改                                  |
| 金额         || 自动取网银流水交易金额，不可修改                                    |
| 业务名称       || 自动取网银流水交易业务名称，不可修改                                  |
| 对方银行账号     || 自动取网银流水交易对方银行账号，不可修改                                |
| 对方账户名称     || 自动取网银流水交易对方账户名称，不可修改                                |
| 对方银行       || 自动取网银流水交易对方银行，不可修改                                  |
| 业务参考号      || 自动取网银流水交易业务参考号，不可修改                                 |
| 摘要         || 自动取网银流水交易摘要，不可修改                                    |
=====5 操作说明 =====

勾选流水记录点击确定生成对应的收款单
