======1 生产补料单 ======

=====1.1 功能概述 =====
生产补料单是处理生产部门和仓储部门之间业务关系的书面凭证，是财务人员据以记账、核算成本的重要原始凭证。



=====1.2 使用前提 =====
1.对应的生产订单分录需处于下达、开工、完工状态，且未挂起；

2.对应的生产用料清单必须处于审核状态。


=====1.3 功能路径 =====
【生产制造】－>【生产管理】－>【生产领料】－>【生产补料单】
=====1.4 生成方式=====
  - 生产订单分录或者生产退料单下推生成；
  - 生产补料单新增界面，通过选单生成。
  - 生产补料单新增界面，通过手动新增生成。

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^  **字段**  ^  **说明**                                                                                    ^
|  单据编码    | 1.单据编号由系统设定的编码规则自动生成。\\ 2.具有唯一性，不允许重复。                                                     |
|  单据类型    | 1.系统自动取生产补料单的默认单据类型；\\ 2.单据新增时可改,单据保存后不可改。                                                 |
|  单据日期    | 1、发料组织未关账：日期要求大于等于发料组织的库存启用日期；\\ 2、发料组织已关账：日期要求大于MAX（发料组织最近一次的关账日期，货主（货主类型=组织）最近一次的关账日期）。  |
|  发料组织    | 1.发放生产加工所需物料的业务组织；\\ 2.发料组织必须具有库存职能。                                                       |
|  生产组织    | 1.进行产品加工的业务组织；\\ 2.生产组织必须具有工厂职能。                                                           |
|  生产车间    | 生产过程中完成一个工序或单独生产一种产品的生产单位。\\ 生产组织下审核未禁用具有车间职能的部门。\\ 此处起过滤作用，不保存。                           |
|  仓库      | 此处起过滤作用，不保存。                                                                               |
|  货主类型    | 1.修改货主类型时，影响货主字段。\\ 2.取值范围：组织、供应商、客户。                                                      |
|  货主      | 货主为物料所有权的持有者。\\ 1.货主类型为业务组织时，货主取业务组织。\\ 2.货主类型为供应商时，货主取供应商。\\ 3.货主类型为客户时，货主取客户。            |

|  物料名称    | 根据物料代码携带物料名称；不可编辑。                                                                        |

|  单位      | 携带上游单据的单位不可修改；手动新增时，可F8选择。                                                                |
|  申请数量    | 1.申请数量为申请部门申请补领的物料数量。\\ 2.生产补料单生成时，由系统自动计算，允许手动修改；\\ 3.通过生产退料单生成时，不能超过生产退料单上面的数量控制。       |
|  实发数量    | 1.实发数量为发料部门向申请部门发放的实际物料数量。\\ 2.生产补料单生成时，由系统自动计算，允许手动修改；\\ 3.通过生产退料单生成时，不能超过生产退料单上面的数量控制。  |
|  仓库      | 1.发放生产加工所需物料的存放位置。\\ 2.允许修改，但是必须是表头发料组织下的仓库；影响仓位字段。                                       |
|  仓位      | 1.发放生产加工所需物料的存放位置。\\ 2.如果仓库启用了仓位管理，可F8或手工录入仓库可用仓位；否则，为空。                                  |

====== 3 操作说明 ======
====保存 ====

1.生产补料单保存时，影响对应生产用料清单/生产退料单的补料选单数。

2.生产补料单保存时，进行数量控制检验，需满足条件：申请数量≤可申请数量；手动新增时，不校验。

====作废 ====

生产补料单作废，影响对应生产用料清单/生产退料单的补料选单数。 
====审核/反审核 ====

1.审核更新库存时，生产补料单审核、反审核，影响对应生产用料清单的【补领数量】和【报废数量】。

2.只有对应的生产订单为下达/开工/完工状态，生产补料单才能反审核。

3.只有生产补料单不存在下游有效单据时，生产补料单才能反审核。

 只有生产用料清单为审核状态时，对应的生产补料单才能进行保存/删除/作废/提交/审核/反审核操作。 

====== 4 业务说明 ======

====选单 ====

（一）生产补料单通过选择生产用料清单分录生成。

选单条件：

1.组织校验：生产用料清单表头的【生产组织】必须是生产补料单表头的【生产组织】；

2.选单必录字段：生产领料单选单前，“发料组织”“生产组织”为必录字段。

3.生产补料单通过生产用料清单生成时，数量不受限制。

（二）生产补料单通过选择生产退料单分录生成。

选单条件：

1.组织校验：生产用料清单表头的【生产组织】必须是生产补料单表头的【生产组织】；

2.选单必录字段：生产领料单选单前，“发料组织”“生产组织”为必录字段。

3.数量限制：生产退料单的【实退数量】-【补料选单数】>0

====下推 ====

（一）生产订单下推生产补料单。

1.生产订单下推生成生产补料单时，物料信息从该生产订单对应的生产用料清单中取数；

2.生产订单支持批量下推。

下推条件：

下推分组：【发料组织】+【生产组织】+【货主】+【货主类型】相同，不同生产用料清单中的分录，可以在同一张生产补料单中进行补料。

（二）生产退料单下推生产补料单。

1.生产退料单下推生成生产补料单时，物料信息从生产退料单中取数；

2.生产退料单支持批量下推。

下推条件：

1.数量控制：对应生产退料单分录中退料类型为“作业不良退料”的【实退数量】-【补料选单数】> 0；

2.下推分组：【发料组织】+【生产组织】+【货主】+【货主类型】相同，不同生产退料单中的分录，可以在同一张生产补料单中进行补料。

====手动新增 ====

 生产补料单支持手动新增，手动新增时，必须指定对应的生产订单分录。

====库存查询==== 

调即时库存查询表，支持选择即时库存信息返回单据界面。 
====批号查询 ====

针对启用批号管理的物料，生产领料单单据界面支持对选中物料的批号查询。
