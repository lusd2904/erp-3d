======1 巡检记录定义 ======

====== 1.1 功能概述 ======
定义巡检记录表格的各个事项。

=====1.2 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【巡检记录定义】

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^ **字段**      ^  **说明**                                                                         ^
| 创建组织        | 1.可选择已审核、未禁用且有权限的生产组织 \\ 2.删除、修改生产组织后，清空车间、产品编码、子项编码字段                          |
| 表格名称      | 手工录入字符串                                                                  |
| 默认车间        | F8选择【车间列表】下的【车间】                                                                  |
| 默认加工产品        | F8选择【物料列表】下的【物料】                                                          |
| 默认工序        | F8选择【工序列表】下的【工序】                                                               |
| 默认设备        | F8选择【加工设备列表】下的【设备】                                                  |
| 默认操作员工        | F8选择【员工列表】下的【员工】                                                  |
| 表格分组        | 自定义分组                                                  |
| 表格修订人        | 修订表格时的当前登录系统的用户，不可修改                                                              |
| 修订时间        | 修订表格时的系统当前日期                                                              |
| 表格创建人        | 创建表格时的当前登录系统的用户，不可修改                                |
| 创建日期        | 创建表格时的系统当前日期                                                                |
| 表格编码      | 保存时自动生成，不可手工录入  |
| 使用组织  | 默认当前登录组织，不可修改                                                                  |

===== 2.2 交接项目明细===== 
^  **字段**      ^  **说明**                                                                                                     ^
| 项目编号         | 手工录入字符串  |
| 项目名称         | 手工录入字符串                                                                                                        |
| 填报类型         | 下拉选择：输入文本、输入日期、输入时间、输入日期+时间、输入数值、输入可选值                                                              |
| 默认值         | 下拉选择：空、当日、昨日、明日、当时、当时日、0、登录用户名                                                                                                    |
| 可选值           | 手工录入字符串                                                                               |
| 禁用         | 勾选框                                                                            |
