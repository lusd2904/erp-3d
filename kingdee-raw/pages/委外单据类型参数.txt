======1 委外单据类型参数 ======

=====1.1 功能概述 =====
因为委外领料、在制材料的扣减以及入库的材料控制方式等，在不同的企业和企业在不同的时期的有着不同的需求，所以为满足不同客户的不同的需求，委外模块提供了一系列的委外参数。

=====1.2 功能路径 =====
【基础设置】－>【基础资料】－>【单据类型】－>【单据类型】－>【委外订单】





====== 2 字段说明 ======
===== 2.1 常规页签===== 
^  **字段**             ^  **说明**                                                                                                                                                                                                                                                                                                                                                                                       ^
|  委外类型               | 1.包含标准委外和返工委外；\\ 2.当委外类型为【标准委外】时，根据BOM生成委外用料清单；\\ 3.当委外类型为【返工委外】时，生成的委外用料清单为产品本身。                                                                                                                                                                                                                                                                                                             |
|  用料清单               | 返工类型的委外订单 \\ 当选择“仅为主产品”，在产生委外用料清单时，仅显示委外订单中主产品的物料；\\ 当选择“按BOM展开”，在产生委外用料清单时，根据BOM产生子项物料。                                                                                                                                                                                                                                                                                                      |
|  启用委外用料清单变更         | 启用委外用料清单变更，则委外用料清单在审核后，不能直接反审核委外用料清单进行内容修改。                                                                                                                                                                                                                                                                                                                                                   |
|  调拨物料获取预设供应商的仓库     | 勾选后，当委外订单中指定了供应商时，则在委外订单保存时自动将“委外仓库设置”中该供应商对应的仓库更新到委外用料清单中发料方式为“调拨倒冲/调拨领料”物料的“仓库”字段。                                                                                                                                                                                                                                                                                                          |
|  调拨考虑最小包装           | 委外用料清单中的调拨物料，在进行调拨时，按照物料中设置的【最小包装量】的整数倍进行调拨。                                                                                                                                                                                                                                                                                                                                                  |
|  调拨考虑最小发料批量         | 委外用料清单中的调拨物料，在进行调拨时，按照物料中设置的【最小发料批量】的整数倍进行调拨。                                                                                                                                                                                                                                                                                                                                                 |
|  库存刷新考虑指定拨出仓库       | 勾选此参数，若委外用料清单的子项物料发料方式是“调拨领料”或“调拨倒冲”且维护了拨出仓库，点击【库存刷新】获取即时库存时，除了会考虑发料仓库的库存，还会考虑拨出仓库的库存。                                                                                                                                                                                                                                                                                                        |
|  委外订单结案考虑联、副产品的关闭   | 勾选此参数，在结案委外订单时，需要满足：委外订单联、副产品的采购订单为整单关闭、业务关闭或者业务终止，才可以结案                                                                                                                                                                                                                                                                                                                                      |
|  结案时进行子项材料损耗报失      | 系统计算已消耗时是不含损耗的，导致订单完全入库后，损耗部分的数量会一直存在于在制数量中，若勾选了该参数，委外订单结案时会自动将在制数量中的损耗数量进行扣减，记录到用料清单“结案损耗报失数量”中。 \\ 详情可参考帖子：https://vip.kingdee.com/article/509762993782057216?productLineId=1&isKnowledge=2&lang=zh-CN                                                                                                                                                                                      |
|  委外订单审核时自动下达        | 当勾选时，委外订单审核时，自动完成委外订单的下达操作。                                                                                                                                                                                                                                                                                                                                                                   |
|  委外订单下达时自动审核委外用料清单  | 当参数“委外订单下达时自动审核委外用料清单”勾选时，委外订单下达时，自动完成委外用料清单的审核操作。                                                                                                                                                                                                                                                                                                                                            |
|  委外订单自动结案           | 当勾选时，若委外订单满足结案条件，则自动执行结案操作。                                                                                                                                                                                                                                                                                                                                                                   |
|  倒冲方式               | 1）交互式倒冲：必须通过倒冲平台倒冲\\ 2）后台倒冲：在领料单生成时机后台自动倒冲                                                                                                                                                                                                                                                                                                                                                    |
|  领料单生成时机            | 1.入库单提交时；\\ 2.入库单审核时；\\ 采购入库单在提交后 还是 审核后产生对应的倒冲领料单。如果存在倒冲物料，需要在采购入库时进行材料领用控制，建议选择采购入库单提交后产生倒冲领料，采购入库单审核时进行材料领用控制；                                                                                                                                                                                                                                                                             |
|  默认领料单单据类型          | 委外倒冲领料单的默认单据类型。                                                                                                                                                                                                                                                                                                                                                                               |
|  默认退料单单据类型          | 委外倒冲退料单的默认单据类型。                                                                                                                                                                                                                                                                                                                                                                               |
|  委外领料自动计算           | 勾选后，当委外生产进行领、退、补时，自动计算委外订单的领补套数                                                                                                                                                                                                                                                                                                                                                               |
|  领补套数计算             | 包含全部物料、非倒冲物料、关键物料。作为计算委外订单领补套数的物料范围。                                                                                                                                                                                                                                                                                                                                                          |
|  领补套数考虑未审核的退料单      | 勾选则表示在计算委外订单领料套数时，扣掉未审核的退料单的数量后再计算领料套数                                                                                                                                                                                                                                                                                                                                                        |
|  委外收料材料领用控制         | 1.通过该参数可以设置采购收料时，材料的控制强度和控制范围 。\\ 2.控制强度分为“不控制”、“警告”、“严格控制”。\\ 3.控制项分为“非倒冲物料”和“关键物料”。\\ 4.基本的控制过程：\\    a）在采购收料时时，按控制范围设置检查：委外订单的累计收料的数量是不是大于控制项的领用套数；\\    b）如果没有领用任何物料或累计收料数量大于控制项物料的领用套数，则按控制强度进行相应的处理。\\      如果是“不控制”则继续收料；\\      如果是“警告”则显示提示信息，由用户选择是继续保存还是中止收料的操作；\\      如果是“严格控制”则提示用户由于物料的领用套数不足，不能收料。\\ 5.控制强度为警告或严格控制时，控制项为必填项。                                                 |
|  委外入库材料领用控制         | 1.通过该参数可以设置产品入库时，材料的控制强度和控制范围 。\\ 2.保存或审核 控制强度分为“不控制”、“警告”、“严格控制”。\\ 3.保存或审核 控制项分为“非倒冲物料”“关键物料”“全部物料”。\\ 4.基本的控制过程：\\    a）在产品入库保存或审核时,按控制范围设置检查：委外订单的累计产品入库的数量是不是大于控制项的领用套数；\\    b）如果没有领用任何物料或累计产品入库数量大于控制项物料的领用套数，则按控制强度进行相应的处理。\\      如果是“不控制”则可继续保存或审核；\\      如果是“警告”当不满足条件，则在保存或审核时显示提示信息，由用户选择是继续还是中止操作；\\      如果是“严格控制”当不满足条件，则在保存或审核时提示材料领用套数不足，不能入库。\\ 5.控制强度为警告或严格控制时，控制项为必填项。  |
|  委外入库用料清单子项为空控制     | 该参数用于控制当委外用料清单没有任何子项物料时，是否允许保存采购入库单。                                                                                                                                                                                                                                                                                                                                                          |
|  非返还件结案控制           | 1）在制材料数量为零：订单结案时，需要用料清单控制范围内物料的在制材料数量为0。\\ 2）在制材料数量在损耗范围内：订单结案时，需要用料清单控制范围内物料的在制材料数量在MAX（固定损耗，变动损耗）范围内；\\ 3）在制材料数量在损耗及最小发料批量范围内：订单结案时，需要用料清单控制范围内物料的在制材料数量在MAX（固定损耗，变动损耗，最小发料批量）范围内；\\ 4）不控制：订单结案时不判断子项物料的在制材料数量。                                                                                                                                                                             |
|  返还件结案控制            | 1.通过该参数可以设置委外订单结案时，返还件材料的控制强度和控制范围。\\ 2.控制强度分为“不控制”、“在制材料数量在耗范围内”、“在制材料数量为零”。\\ 3.基本的控制过程：在委外订单结案时,按控制强度设置检查：委外订单的在制材料数量是不是满足控制要求。                                                                                                                                                                                                                                                            |
|  未入库的委外订单需强制结案      | 勾选则表示当生产订单没有入库数量时，即使满足其他结案条件，也不允许执行至结案，但允许强制结案。                                                                                                                                                                                                                                                                                                                                               |
