====== 1.功能说明 ======

用户根据阿米巴单元的收入、支出、费用等业务录入经营流水账。

经营流水账支持手工录入。

经营流水账支持业务单据通过引入方案生成。

经营流水账支持总账科目通过引入方案生成。


**操作前提**

设置经营账簿、经营科目、阿米巴单元等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【经营流水账录入】

====== 2.字段说明 ======
^ 字段        |^ 说明                                               ^
| 账簿        || 设置经营流水账所在经营账簿，经营账簿必须已审核且未被禁用。                    |
| 日期        || 设置经营流水账日期，该日期是指业务发生日期。系统不允许录入账簿已结账期间内的日期作为凭证日期。  |
| 收支类型      || 下拉框选择项，包括收入、支出、转账。                               |
| 序号        || 记录了经营流水账录入的原始顺序，序号不会因凭证的删除而改变。                   |
| 备注        || 录入凭证分录的备注信息，可从基础资料摘要库中选择，也可手工录入。                 |
| 经营科目      || 录入经营流水账分录的经营科目。修改经营科目后，保留已经录入且新经营科目可用的核算维度。      |
| 核算维度      || 录入经营科目关联的核算维度信息，此处的核算维度是指科目属性中核算维度组包含的核算维度信息。    |
| 金额        || 录入经营科目对应的金额。                                     |
| 账户        || 录入经营科目对应的账户。                                     |
| 内部交易方     || 录入经营科目对应的内部交易方。                                  |
====== 3.操作说明 ======
经营流水账录入，支持录入当前期间和以后期间的。

结账后，经营流水账不允许反审核、删除。
