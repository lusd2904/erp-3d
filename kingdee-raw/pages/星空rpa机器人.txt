**欢迎使用金蝶RPA产品！**

在金蝶AI星空中搭建金蝶小K-RPA机器人平台，可面向云星空客户提供RPA服务。

通过RPA机器人平台，完成金蝶AI星空与小K-RPA产品的融合，用户可直接在星空平台管理机器人，包括查看机器人、运行机器人，并可在RPA运行平台进行试用和购买机器人。

====== 1 金蝶小K-RPA概述 ======

====== 1.1 金蝶小K-RPA概述 ======

RPA，即Robotic Process Automation 机器人流程自动化，通过模拟人与电脑交互的方式来自动处理大量重复性、规则明确的业务流程，代替人工处理这部分简单、事务性的工作。

金蝶小K-RPA机器人，是金蝶自主研发的一款独立产品，以金蝶小K作为产品形象，帮助企业及个人实现自动化处理。

====== 1.2 金蝶小K-RPA产品 ======

金蝶小K-RPA机器人包含控制台和客户端，其中，客户端包括设计器和运行器。

控制台是云端应用，可通过云端发布多任务并监控机器人运行情况和查看运行结果。官网地址为：http://rpa.kingdee.com。

设计器用于设计机器人业务流程并发布机器人，机器人数量不受限制。

运气器保持在线，可自动接收分配给该电脑的任务，并自动完成实际的业务操作。

====== 1.3 适用场景 ======

金蝶小K-RPA机器人可帮助您处理耗时长、效率低、数据量大的业务流程，如：数据采集、数据录入、数据核对与业务操作等，7*24小时工作，帮助企业降低人工成本。

**代替人工采集数据**

如网页数据、Excel数据、数据库、OCR识别等多种数据源的采集与数据加工等。

**代替人工录入数据**

如处理数据的填报工作，如税务申报、海关填报等。

**代替人工核对数据**

如对多个业务系统的数据进行核对分析，如往来核对，电商门店系统与财务系统数据核对等。

**代替人工操作业务**

根据设定的工作流程，自动化、智能化的模拟人工处理业务流程。

====== 3 星空RPA机器人 ======

在金蝶AI星空中搭建金蝶小K-RPA机器人平台，可面向云星空客户提供RPA服务。

通过金蝶小K-RPA机器人平台，完成金蝶AI星空与小K-RPA产品的融合，用户可直接在星空平台管理机器人，包括查看机器人、运行机器人，并可通过RPA控制台进行试用、购买机器人。

星空RPA机器人包含三大模块：RPA设置、RPA管理平台、RPA运行平台。
===== 3.1 RPA设置 =====

该功能主要用于对接金蝶小K-RPA控制平台，配置小K-RPA的服务器地址、用户名、APPID和APPSecret。

  - 配置小K-RPA的服务器地址：http://rpa.kingdee.com。
  - 登录小K控制平台：http://rpa.kingdee.com，在对应企业下的菜单“系统设置”下的“应用授权设置”中找到应用ID和应用secret。注意，第一次进入需要点击“生成”按钮生成应用secret。

{{:控制台机应用授权.png?400|}}

  - 将用户名、应用ID和应用secret填写到星空RPA机器人的RPA设置中，保存后点击启用，启用成功才可以正式使用星空RPA机器人的功能。其中，小K-RPA用户名需要输入控制台中的任一用户手机号。

{{:rpa设置.png?400|}}

===== 3.2 RPA管理平台 =====

===== 3.2.1 RPA工作台 =====

展示RPA运行概况，用户进入RPA管理平台后，可进入工作台，能查看RPA运行的整体概况，包括任务工作台和机器人工作台。点击数字，可跳转到对应功能模块界面。

{{:rpa工作台.png?400|}}



===== 3.2.2 机器人管理 =====

机器人管理用于获取小K控制平台最新的且是“启用中”的机器人数据，可以使用“快速运行”功能来快速运行机器人任务。

{{:rpa机器人管理.png?400|}}

机器人管理界面主要有刷新、导出、快速运行功能。

**刷新：**通过接口把小K控制平台的机器人数据拉取到星空机器人管理列表。

**导出：**可以导出机器人列表信息。

**快速运行：**跳转到任务新增界面（详见任务新增功能介绍），保存成功后会根据运行方式来运行任务。



===== 3.2.3 任务管理 =====

任务管理用于管理机器人运行的任务，可以查看任务的运行状态、运行结果及任务运行的过程明细。

{{:rpa任务管理.png?400|}}

任务管理界面主要有刷新、新增和删除功能。

**1. 刷新：**通过接口把小K控制平台的任务拉取到星空任务管理列表。

**2. 新增任务：**点击“新增”按钮，跳转至任务新增界面。选择好要执行的机器人、运行终端和运行方式，点击保存，保存成功后可运行任务。

{{:rpa任务新增.png?400|}}

运行终端：是指机器人运行的环境。当一个机器人处理的业务流程涉及到某个特定的软件时，该机器人也应该在这个软件所在的电脑中运行。如处理星空单据的机器人，应在安装了星空软件的电脑上运行。注意，运行器对应的企业需要和appid和appsecret对应的企业保持一致，才能运行。

运行方式：分为立即运行和计划运行。当选择立即运行时，保存后任务会立即执行；当选择计划运行时，保存后任务会根据您选择的计划时间，到点来执行。如果机器人带有一些参数信息，则会在任务新增界面下方显示参数名称和参数类型，其中参数值需要用户手动填写(根据用户电脑环境来填写)。

**3. 删除任务：**只能删除计划任务或者排队中的任务，运行中和已完成的任务不能删除。

===== 3.3 RPA运行平台 =====

RPA运行平台提供试用、使用和购买功能。在许可有效期内，**日记账登账机器人、银行对账机器人和收付款核销机器人**在任务新增界面配置好参数信息即可运行的机器人；**报税机器人-广东和网银机器人-建设银行**需要跳转至业务方界面配置好后才能运行。

**日记账登账机器人**，自动登录到星空-收款单-业务操作-接受银行收款记录，自动完成银行流水生成收款单。使用该机器人，开通对应银行的银企直联功能。

**银行对账机器人**，自动下载银行对账单，根据用户在银行存款对账中的自动勾兑设置，对系统内的银行日记账和业务单据进行自动勾兑。使用该机器人，开通对应银行的银企直联功能。

**收付款核销机器人**，自动登录星空-收款单-收款核销，根据用户设置的快速核销方案，对满足条件的应收单和收款单进行自动核销。

**报税机器人-广东**，自动填报增值税纳税申报表、附加税报表、及财务报表。需在金蝶AI星空产品内运行调度。目前只支持广东（不含深圳）地区的一般纳税人通过网页端进行自动纳税申报，支持的税种范围为： 增值税、附加税（城建税、教育费附加）、财务报表。

**网银机器人-建设银行**，自动登录建行网银账户、下载交易明细，并将下载结果导入到企业管理系统 “接收银行交易明细”中。该机器人内置在星空-财务会计-出纳管理-智能服务中，需在金蝶AI星空产品内运行调度。不同银行的交易流水下载，为不同的机器人方案。
===== 3.3.1 机器人试用 =====

从RPA运行平台进入机器人详情页，如果是第一次使用，提供试用和购买功能，机器人试用的时间为一个月。

{{:机器人试用.png?400|}}

点击试用完成试用操作，在当前界面可直接使用该机器人。试用后，可在机器人管理列表中查看到试用的机器人流程。

{{:机器人使用.png?400|}}

===== 3.3.2 机器人使用 =====

如果已经试用或购买机器人，在点击机器人时：

对于日记账登账机器人、银行对账机器人和收付款核销机器人，会直接打开新建任务界面。例如，点击星空银行对账机器人，则可以直接使用该机器人新建任务，在任务新增界面配置好参数信息即可运行机器人。

{{:机器人使用-新建任务.png?400|}}

对于报税机器人-广东和网银机器人-建设银行，则会跳转到业务应用界面，根据要求进行相关参数配置完成设置即可运行机器人。例如，点击网银机器人-建设银行，或跳转到财务会计-出纳管理-网银流水机器人界面。

{{:机器人使用-新建任务1.png?400|}}



===== 3.3.3 机器人购买 =====

当机器人的试用期过后，还需要继续使用机器人来提高工作效率，则只能购买机器人才能使用。

这时，点击相关机器人，会跳转到购买界面。

{{:机器人购买.png?400|}}

**购买流程如下：**

1. 进入RPA运行平台，直接点击“购买”。 **企业名称将作为您购买时要求开具发票的发票抬头名称。**请在首次购买前修改确认企业名称。购买时不可维护企业名称。如果您已经在使用金蝶系列的产品，并且在金蝶体系中已有正式认证的企业存在，则首次购买时会显示您所属的企业，您可以选择该企业作为正式企业应用。

{{:机器人购买1.png?400|}}

2. 点击“确定”，会进入金蝶云O2O订购平台。金蝶云O2O订购平台是金蝶旗下线上购买产品的平台。选择您购买的时长以及产品，点击“下一步”。

{{:机器人购买2.png?400|}}

3. 确认订单内容以及费用是否正确，确认无误后点击“下一步”。

{{:机器人购买3.png?400|}}

4. 完善信息后，点击“下一步”。

{{:机器人购买4.png?400|}}

5. 确认合同信息，然后点击去支付。

{{:机器人购买5.png?400|}}

6. 选择支付方式，完成支付。

7. 支付完成后，金蝶小K-RPA机器人工作台中将自动更新您购买的时长。在购买前未使用完成的时长仍可继续使用。

{{:机器人购买6.png?400|}}

8. 购买成功后可以在菜单“订购信息”中查看详细的订单信息。

{{:机器人购买7.png?400|}}
