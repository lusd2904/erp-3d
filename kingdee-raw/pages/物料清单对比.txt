======1 物料清单对比=======
=====1.1 报表功能=====

因各种管理需要对产品结构进行对比分析，包括：订单的BOM与产品标准BOM间、同一产品不同版本间、不同产品间以及标准版本与客户订制版本间等。

BOM对比查询既支持单层对比，也支持多层对比。


=====1.2 使用前提=====
定义【物料清单】


=====1.3 功能路径=====
进入【生产制造】—>【工程数据】—>【物料清单查询】—>【物料清单对比】


======2. 字段说明======

=====2.1 过滤条件 =====
^  **字段**  ^  **说明**                ^
|  BOM版本一  | 选择参与对比的第一个BOM版本        |
|  BOM版本二  | 选择参与对比的第二个BOM版本        |
|  对比方式    | 选择单层对比或汇总对比            |
|  显示替代料   | 对比时是否显示替代件             |
|  只显示外购件  | 对比方式选择汇总对比时，勾选后只显示外购件  |
=====2.2 概览页签 =====

^  **字段**     ^  **说明**                            ^
|  物料编码       | 显示子项的物料编码                          |
|  物料名称       | 显示子项的物料名称                          |
|  规格型号       | 显示子项的规格型号                          |
|  子项类型       | 1、显示子项的子项类型；\\ 2、子项类型不同的子项会按不同行显示  |
|  物料清单一&单位   | 显示子项在物料清单一中的单位                     |
|  物料清单一&分子   | 显示子项在物料清单一中的分子                     |
|  物料清单一&分母   | 显示子项在物料清单一中的分母                     |
|  物料清单一&损耗率  | 显示子项在物料清单一中的损耗率                    |
|  物料清单二&单位   | 显示子项在物料清单二中的单位                     |
|  物料清单二&分子   | 显示子项在物料清单二中的分子                     |
|  物料清单二&分母   | 显示子项在物料清单二中的分母                     |
|  物料清单二&损耗率  | 显示子项在物料清单二中的损耗率                    |
|  参考成本       | 显示子项的参考成本                          |
|  币别         | 显示子项的币别                            |
