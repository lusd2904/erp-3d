**报表功能**

物料替代建议表方便的提供了生产及计划过程中的替代料使用情况，便于计划人员对物料计划进行更好的过程控制。

**路径**

进入【生产制造】—>【计划管理】—>【报表查询】—>【物料替代建议表】

**报表字段说明**

**报表过滤条件**

|**字段**||**说明**|
|查询组织||1、选择查询单据的业务组织|
|开始日期||1、选择查询单据的开始日期|
|至||1、选择查询单据的开始日期|
|预测单||1、选择查询单据对应的预测单|
|至||1、选择查询单据对应的预测单|
|销售订单||1、选择查询单据对应的销售订单|
|至||1、选择查询单据对应的销售订单|
|主料范围||1、选择查询的主物料范围|
|至||1、选择查询的主物料范围|
|替代料范围||1、选择查询的替代料范围|
|至||1、选择查询的替代料范围|

**表头字段**

|**字段**||**说明**|
|查询组织||1、显示过滤条件设置的组织范围|
|开始日期||1、显示过滤条件设置的开始日期范围|
|主料范围||1、显示过滤条件设置的物料编码范围|
|替代料范围||1、显示过滤条件设置的物料编码范围|
|预测单||1、显示过滤条件设置的订单编号范围|
|销售订单||1、显示过滤条件设置的订单编号范围|

**表体字段**

| **字段**     || **说明**                                       |
| 单据编号       || 1、显示用料清单/计划BOM的单据编号                          |
| 行号         || 1、显示替代料/主料所在的行号                              |
| 单据类型       || 1、显示用料清单/计划BOM的单据类型                          |
| 物料编码       || 1、主料显示用料清单中主料的物料编码\\ 2、替代料显示用料清单中替代料的物料编码\\  |
| 物料名称       || 1、显示用料清单分录的物料的名称                             |
| 规格型号       || 1、显示用料清单分录的物料的规格型号                           |
| 子项类型       || 1、显示用料清单物料的子项类型，分标准件、替代件                     |
| 单位         || 1、显示用料清单分录的单位                                |
| 辅助属性       || 1、显示用料清单分录的辅助属性                              |
| BOM编号      || 1、显示用料清单分录的BOM编号                             |
| 计划跟踪号      || 1、显示用料清单分录的计划跟踪号                             |
| 需求数量       || 1、主料显示用料清单中主料的需求数量\\ 2、替代料显示用料清单中替代料的需求数量\\  |
| 领料选单量      || 1、主料显示用料清单中主料的选单数量\\ 2、替代料显示用料清单中替代料的选单数量\\  |
| 需求日期       || 1、显示用料清单分录的需求日期                              |
| 替代主料       || 1、如果物料在替代关系中是替代主料，显示为“是”，反之为“否”              |
| 根需求单据号     || 1、显示用料清单/计划BOM所对应的根需求单据编号和行号；                |
| 上级单据号      || 1、显示用料清单对应的生产订单/委外申请单号                       |
