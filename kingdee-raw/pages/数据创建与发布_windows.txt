===== 1）组织机构管理 =====
  - 在金蝶AI星空中管理云店通设备的组织机构，可以执行新建、修改、发布、禁用等操作。需登录管理员账号访问
  - 将已经勾选的组织发布到商户平台，以供云店通设备使用
{{:win_组.png?direct&400 |}}
===== 2）用户管理 =====
  - 在金蝶AI星空中管理云店通设备的用户，可以执行新建、修改、发布、禁用等操作。需登录管理员账号访问
  - 将已经勾选的用户发布到商户平台，以供用户登录云店通设备使用
  - 最大折扣率：单个食品或整个单打折的最大折扣率
{{:win_用.png?direct&400 |}}
===== 3）角色管理 =====
  - 在金蝶AI星空中管理云店通设备的角色，可以执行新建、修改、发布、禁用等操作。需登录管理员账号访问
  - 将已经勾选的角色发布到商户平台，以供用户访问所拥有角色的权限功能
{{:win_角.png?direct&400 |}}
===== 4）营业设置管理 =====
  - 在金蝶AI星空中管理商户的营业设置，设定组织的门店类型、营业日期、服务费类型、费率、税率等，还可以针对云店通设备设置抹零规则和取餐号规则。在营业设置页面中可以执行新建、修改、发布、禁用等操作，一个组织只能设置一条营业设置记录
  - 将组织的营业设置发布到商户平台，以供云店通使用
{{:win_营业.png?direct&400 |}}
===== 5）取消原因管理 =====
  - 在金蝶AI星空中管理云店通退菜、招待的原因选项，可以执行新建、修改、发布、禁用等操作
  - 将已经勾选的取消原因发布到商户平台
  - 勾选出品取消时，退单不会更新食品库存
{{:win_取消.png?direct&400 |}}
{{:win_取消_1.png?direct&400 |}}
===== 6）食品大类管理  =====
  - 在金蝶AI星空中管理云店通食品类别，可以执行新建、修改、发布、禁用等操作
  - 将已经勾选的食品类别发布到商户平台
{{:win_大类.png?direct&400 |}}
===== 7）食品管理  =====
  - 在金蝶AI星空中管理云店通食品，可以执行新建、修改、发布、禁用、编辑图片等操作
  - 将已经勾选的食品、图片发布到商户平台
  - 勾选折扣率和全单折时可参与打折
  - 图片上传要单独发布至商户平台
{{:win_食品.png?direct&400 |}}
===== 8）口味要求管理 =====
  - 在金蝶AI星空中管理云店通口味要求，可以执行新建、修改、发布、禁用等操作
  - 将已经勾选的口味要求发布到商户平台
  - 整单备注时，为了方便收银员快速的选择常用备注，会在图中箭头位置，增加常用备注，这样前台POS的整单备注会显示。
  - 注意口味加、乘计价
{{:win_口味.png?direct&400 |}}
{{:win_口味_1.png?direct&400 |}}
===== 9）常用默认项 =====
  - 设置单个食品和整单的折扣率
  - 默认项中的折扣率超出用户中设置的最大折扣率时，不允许在POS端展示
  - 将勾选的常用默认项发布到商户平台
{{:win_常用.png?direct&400 |}}
===== 10）副屏设置  =====
  - 登陆门店绑定的商户的商户平台
  - 设备管理—副屏设置---新增
  - 大图为不进行点单收银时副屏的全屏图片，可以设置多张进行轮播
  - 小图为进行点单收银时副屏显示的图片
{{:win_副屏.png?direct&400 |}}
===== 11）门店权限项管理 =====
  - 在金蝶AI星空中管理云店通门店权限项，可以执行发布、禁用等操作。
  - 将已经勾选的权限项发布到商户平台
{{:win_权限.png?direct&400 |}}
===== 12）结算方式管理 =====
  - 在金蝶AI星空中管理云店通门店可用的结算方式，可以执行新增、修改、发布、禁用等操作
  - 微信点餐的账单推送功能，需要先将结算方式发布O2O
  - 将已经勾选的权限项发布到商户平台
{{:win_结算.png?direct&400 |}}
