====== 1.微信交易账单 ======

===== 1.1 功能说明 =====
营业对账的原始流水，可以通过新增，接口上传，导入三种方式
===== 1.2 字段说明 =====
^ 字段             ^ 说明                                            ^
| 业务操作-下载交易流水    | 支持下载多个收款账户同一个日期的原始微信数据，需要配置[[收款账户设置|收款账户设置]]  |
| 单据类型           | 微信交易账单                                        |
| 营业日期           | 门店的营业日期，产生交易流水的日期                             |
| 营业组织           | 产生交易流水的组织                                     |
| 单据编号           | 微信交易账单的单据编号，支持手工输入或者自动生成，唯一值                  |
| 支付金额           | 营业日期的所有支付笔数金额汇总                               |
| 支付笔数           | 营业日期的支付笔数                                     |
| 收款账户           | 结算方式类别包含微信的所有支付方式的账户                          |
| 结算方式           | 结算方式类别包含微信的                                   |
| 交易时间           | 该笔流水产生交易的时间，是长日期                              |
| 公众号ID          | 该笔流水发生时的公众号ID                                 |
| 商户号            | 哪个商户                                          |
| 子商户号           | 哪个子商户                                         |
| 设备号            | 产生流水的硬件设备，通常是唯一值                              |
| 微信订单号          | 产生微信交易的订单号                                    |
| 商户订单号          | 商户的订单号，自动生成                                   |
| 用户标识           | 用户的标识，不是必录                                    |
| 交易类型           | 产生交易的类型                                       |
| 交易状态           | 交易成功的标识                                       |
| 商品名称           | 消费商品的名称                                       |
| 付款银行           | 如果是绑定了银行支付，则显示支付银行                            |
| 货币种类           | 显示货币的类型，比如人民币或者港币                             |
| 总金额            | 该笔交易的总金额                                      |
| 代金券或者立减优惠金额    | 该笔支付使用的代金券或者优惠金额                              |
| 微信退款单号         | 如果订单中有退款，则显示退款单号                              |
| 商户退货单号         | 如果订单中有退款，则显示商户退货单号                            |
| 退款金额           | 退款的金额                                         |
| 代金券或者立减优惠退款金额  | 退款中代码券或者优惠金额                                  |
| 退款类型           | 记录退款的类型                                       |
| 退款状态           | 显示是否退款成功                                      |
| 手续费            | 该笔交易产生的手续费                                    |
| 费率             | 费率                                            |
| 收入来源           | 记录收入的来源渠道                                     |
