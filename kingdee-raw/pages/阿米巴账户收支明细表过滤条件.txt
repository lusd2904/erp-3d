====== 阿米巴账户收支明细表过滤条件 ======
在“快捷”页签，用户选择需要查询的经营账簿、利润中心、阿米巴单元、经营科目、会计期间、起始日期、结束日期、币别基本过滤条件。其他过滤页签为系统通用设置，可设置字段列的显示隐藏属性。

快捷页签主要过滤项目说明 

| **过滤项**        || **说明**                            |
| 经营账簿           || 选择查询哪个经营账簿，单选。                    |
| 利润中心           || 选择查询哪个利润中心，单选。                    |
| 阿米巴单元          || 选择查询哪个阿米巴单元，多选。                   |
| 经营科目           || 选择需要查询的资金经营科目，多选。                 |
| 经营期间           || 选择查询期间，支持开始期间和结束期间。               |
| 起始日期           || 选择要查询数据的起始日期。                     |
| 结束日期           || 选择要查询数据的结束日期。                     |
| 币别             || 选择要查询哪个币别的报表，支持多选。目前支持人民币         |
| 包含未审核经营流水账     || 选中此项，报表取数时，会统计未审核的经营流水账；反之，则不统计。  |
| 显示合计           || 选中此项，报表会分别按期间合计和年度合计显示。           |
