====== 1 功能描述 ====== 

日志中心可以存放日志数据信息，缓解业务数据中心的容量，提供系统性能。

当数据库服务器与应用服务器分开部署时，日志中心注册便于将存放在数据库服务器上的日志中心注册到应用服务器上，另外，还提供了反注册功能，当不再使用该日志中心时，可以反注册该日志中心。

**功能路径**

【数据中心列表】 

====== 2 字段说明 ======

  - 数据中心名称：选择注册日志中心所属的数据中心； 
  - 数据库服务器：定义当前数据库服务器的机器名称； 
  - 数据库服务器用户：输入数据库服务器用户名称； 
  - 数据库服务器密码：输入数据库服务器用户密码； 
  - 数据中心实体：选数据库服务器已有的日志中心实体。 


=====  2.1 数据库服务器 ===== 


==== 2.1.1 数据中心名称 ====

定义要注册的日志库对应的数据中心名称。

=====  2.1.2 数据库服务器 ===== 
定义当前日志库所在数据库服务器的机器名称或者数据库服务器IP地址。
 
=====  2.2 数据库用户 ===== 

==== 2.2.1 身份验证 ====

支持SQL Server身份验证和Windows身份验证。
  - 若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
  - 若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码；

==== 2.2.2 登录名 ====

输入数据连接用户的帐号； 

==== 2.2.3 密码 ====

输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个帐户； ​

==== 2.2.4 数据库实体 ====
选择当前数据中心对应的日志中心实体名称； ​


 ​

====== 3 功能操作 ======

===== 3.1 注册SQL Server日志库 =====

在【数据中心列表】中，点击按钮组的下拉按钮【注册SQL Server日志库】，如果管理中心是SQLServer类型的，直接点击工具栏【注册】按钮，即可打开“注册SQL Server日志库”界面进行操作。

  SQL Sever日志库注册过程如下：
  
  1、输入数据中心名称。
  
  2、输入数据库服务器。
  
  3、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到数据中心。
  
     数据库连接用户支持SQL身份验证和Windows身份验证两种方式。
     
     1）若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
     
     2）使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
     
     3）若选择SQL Serve身份验证，请输入SQL Serve数据库用户名和密码。
     
  3、输入数据库实体。
  
     注意数据中心实体必须选择当前数据中心对应的日志中心数据库实体，不能选择业务数据中心或者管理中心类型的数据库实体。
     
  4、在注册界面中，确认相关信息后，点击【注册】按钮，系统即可完成SQL Server日志库的注册工作。



  
===== 3.2 反注册数据中心  =====   
 
在【数据中心列表】中，选中注册的日志中心，点击工具栏【反注册日志库】按钮，系统即可进行反注册。 

 
====== 4 其他说明 ======   
 
  - 日志中心注册成功后，在管理中心主页的列表界面，当前数据中心会自动显示日志库和日志库的注册时间，可供查询日志。 
  - 可以对已注册的日志中心进行反注册操作，当前数据中心的日志库和日志库的注册时间信息自动清除，反注册后不会删除日志库实体。
