====== BOS通用控件列表 ======

| 控件名称          || 功能描述                          |
| 分组标题          || 支持单据头对字段进行分组                  |
| 颜色            || 用于动态表单颜色标识                    |
| 标签            || 支持显示文本(输出)信息，不支持作为输入信息的界面     |
| 按钮            || 支持设置点击事件关联相应的操作               |
| 分割线           || 用于界面字段的区域分割                   |
| 页签控件          || 支持页签中添加字段或控件，实现对界面字段的分类       |
| 框架            || 用于界面字段的分类                     |
| 树形控件          || 用于设计动态表单树形节点                  |
| 列表控件          || 用于设计动态表单列表                    |
| 面板            || 用于单据存放字段及控件                   |
| 附件面板          || 用于单据存放附件及控件                   |
| 链接            || 通过设置点击事件跳转到指定网页               |
| 关联知识面板        || 支持动态表单添加关联知识面板控件              |
| 矩形框           || 支持动态表单添加矩形框控件                 |
| 布局表格          || 支持动态表单添加布局表格控件                |
| 分割容器          || 支持在动态表单上增加分隔容器控件，将表单分成不同的区域   |
| Office控件      || 支持动态表单添加OFFICE控件              |
| 工具栏           || 支持在动态表单上增加工具栏，通过菜单集合设置工具栏按钮   |
| 图片控件          || 支持单据上的指定区域插入图片                |
| 过滤条件表格        || 用于动态表单上增加过滤条件列表               |
| 分录选择          || 支持动态表单添加分录选择控件，列出单据上所有分录项供选择  |
| 状态过滤          || 提供状态过滤功能                      |
| 大文本编辑控件       || 用于动态表单上增加大文本编辑控件              |
| 进度条           || 提供进度条功能                       |
| 隐藏式说明按钮       || 提供隐藏式说明按钮控件                   |
| 向导标题          || 用于动态表单设计向导或标题                 |
| 导航容器          || 用于动态表单设计功能导航                  |
| 电子签章          || 用于存放流程审批人的电子签章的容器             |
| 列分页           || 用于将单据体的列分页展示                  |
| 附件控件          || 支持上传、删除附件                     |
| 附件列表          || 支持上传、批量新增、查看、修改、删除、下载、在线预览附件  |
| 印章            || 用于存放并展示印章                     |
| 轻分析           || 用于嵌入式轻分析预置建模                  |
| 批量过滤条件表格      || 用于动态表单上批量增加过滤条件               |
| 音频控件          || 支持播放音频                        |
| 二维码           || 支持将需要的信息转换生成二维码               |
| 组织架构图         || 用于动态表单显示组织架构图                 |
| 动态文本          || 支持动态获取文本信息                    |
| 串口控件          || 应用于外接串口或USB模拟串口输入设备的场景        |
| 排序设置          || 用于动态表单上进行排序设置                 |
| SQLScript     || 用于在BOS设计器中快速调整脚本，实现不同的功能      |
