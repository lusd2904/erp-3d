ID: 信用状况查询
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BF%A1%E7%94%A8%E7%8A%B6%E5%86%B5%E6%9F%A5%E8%AF%A2

  * 报表功能:

信用状况查询报表是对信用管理对象的信用额度、信用比例、单笔限额等信用状况查询的报表。

  * 报表过滤条件：

过滤条件区域包括页签：快捷、高级、显示隐藏列等。

其中快捷页签为报表的快捷过滤界面，高级页签为设置报表字段值的过滤，显示隐藏列页签为报表字段列隐藏显示。

  * 报表过滤-快捷设置字段说明：

| **过滤条件**     || **说    明**                      |
| 授信组织         || 进行信用控制的组织                       |
| 控制对象类型       || 进行信用控制的对象类型                     |
| 信用对象         || 具体进行信用控制的对象                     |
| 信用状态         || 信用对象的信用状态。内容：全部、正常检查、信用冻结、信用免检  |
| 信用检查规则       || 信用检查的规则，用户可以从信用检查规则中选择          |
| 信用超标         || 信用状况是否超标。内容：全部、正常、超标            |
| 币别           || 信用对象的授信币别                       |

  * 报表字段说明 

| **字段名称**     || **说明**                                                                                         |
| 授信组织         || 过滤条件设定的授信组织                                                                                    |
| 授信部门         || 信用档案中设置的授信部门                                                                                   |
| 信用对象编码       || 符合过滤条件设定的对应信用档案中对应的信用对象编码                                                                      |
| 信用对象         || 符合过滤条件设定的对应信用档案中对应的信用对象                                                                        |
| 币别           || 符合快捷过滤设置币别，信用对象在对应的客户信用档案的币别                                                                   |
| 有效期          || 信用对象的客户信用档案的 生效日期+复查周期，若复查周期为空，默认为2100－01－01                                                   |
| 信用等级         || 信用对象的客户信用档案的信用等级                                                                               |
| 信用检查规则       || 信用对象的客户信用档案的信用检查规则                                                                             |
| 信用额度         || 信用对象在信用档案中设置的信用额度                                                                              |
| 临时信用额度       || 信用对象对应的临时信用档案设置的额度                                                                             |
| 已使用额度        || 信用对象已占用额度的总和                                                                                   |
| 额度余额         || 额度余额=信用额度 - 已使用额度                                                                              |
| 信用比例%        || 信用对象在信用档案中设置的信用比例                                                                              |
| 信用比例额度       || 当信用对象的占用额度总和小于0时，信用比例额度＝额度余额绝对值×信用比例，否则为0                                                      |
| 单笔限额         || 信用对象在信用档案中设置的单笔限额                                                                              |
| 临时单笔限额       || 信用对象在临时信用档案中设置的单笔限额                                                                            |
| 逾期天数         || 信用对象在信用档案中设置的逾期天数                                                                              |
| 临时逾期天数       || 信用对象在临时信用档案中设置的逾期天数                                                                            |
| 实际逾期天数       || 应收单上，到期未核销应收单的最大逾期天数（系统日期-到期日）                                                                 |
| 逾期额度         || 信用对象在信用档案中设置的逾期额度                                                                              |
| 临时逾期额度       || 信用对象在临时信用档案中设置的逾期额度                                                                            |
| 实际逾期额度       || ∑（到期日<系统日期 的未核销应收款－未核销收款单＋未核销退款单）                                                              |
| 逾期比例%        || 信用对象在信用档案中设置的逾期比例                                                                              |
| 实际逾期比例%      || ∑（到期日<系统日期 的未核销应收款－未核销收款单＋未核销退款单）/ ∑（未核销应收款－未核销收款单＋未核销退款单）                                     |
| 是否超标         || 对信用对象是否超标的判断，当信用对象对应的信用检查规则超标判断依据是单项超标时，只要一项超标，该字段为是；\\ 若超标判断依据是同时超标时，则所有检查项同时超标时，该字段为是，否则为否。  |

  * 报表操作说明:

1 报表提供冻结列设置、打印、引出功能。

2 报表提供通用分组汇总、选项设置等功能。
