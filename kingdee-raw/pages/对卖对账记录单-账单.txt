====== 1.对卖对账记录单-账单 ======

===== 1.1 功能概述 =====

外卖账单对账记录单是外卖平台（美团/饿了么）上的订单与POS账单中的订单对账的明细单据。
===== 1.2 字段说明 =====

^ 字段名称         ^ 字段说明                ^
| 确认对账金额       | 外卖订单中的结算金额          |
| 自动对账金额       | 默认是外卖订单上的结算金额，可以修改  |
| 订单流水号        | 外卖订单的流水号            |
| 平台外卖订单编号     | 外卖账单编号              |
| POS外卖订单编号    | POS外卖订单的编号          |
| 平台外卖结算金额     | 外卖的结算金额             |
| POS外卖订单结算金额  | POS的结算金额            |
| 自动对账         | 点击自动对账的金额           |
| 差异状态         | 包含有和无两种             |
| 确认对账金额       | 最终确认对账的金额           |
| 差异说明         | 缺少POS账单或者缺少外卖账单     |
