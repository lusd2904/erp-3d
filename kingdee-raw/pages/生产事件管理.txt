**功能概述**

生产事件用于定义生产现场发生的各种需要记录的事件，事件类型包括现场异常类型、现场作业类、会议沟通类、临时休息类等等。

其中涉及异常报警的生产事件会根据处理时长设定不同的处理等级，每个等级可根据需求设定不同的监控条件，当等级变动后如果满足该等级下监控条件则按照监控条件对应的消息设置定向发送消息给接收人。

**2、异常处理路径**

{{:sfs_生产事件_处理路径.png?1400|}}

表头的子表，用于定义异常类型对应的处理阶段、时限参数、消息发送模板、权限控制等信息；

用户可以自由定义生产事件（异常类型）的处理阶段，也就是流程步骤，但是系统要求第一个阶段必须是“发起呼叫”，最后一个阶段必须是“验收关闭”（2条预置辅助资料数据）；

列表中每一行就是一个处理阶段（也就是步骤），由序号决定先后顺序，序号可以人为修改；

每一行处理阶段都可以定义对应的控制参数数据，具体参考下文；

列表菜单：
新增行：列表新增一行

复制行：列表复制一行

删除行：列表删除一行

批量填充：对选中字段做批量填充操作

字段说明：

| **字段**      || **说明**                                                                                                        |
| 序号          || 处理阶段顺序号，用户可以修改；                                                                                               |
| 处理阶段        || 从辅助资料“异常处理阶段”中读取，不能重复；                                                                                        |
| 签到          || 勾选时，本处理阶段必须进行HMI现场签到操作；                                                                                       |
| 时限间隔        || 用于定义安灯受理、签到、处理的间隔时间，即接收到处理通知后n分钟之内需要受理，受理后n1分钟后需要现场签到，签到后n2分钟后需要处理完成，时间单位为分钟；此例中三个时限参数分别维护n、n1、n2；            |
| 消息标题        || 定义发送消息标题的公式和内容，具体设置方法参考下文；                                                                                    |
| 消息正文        || 定义发送消息正文的公式和内容，具体设置方法参考下文；                                                                                    |
| 默认处理人角色     || 定义当前处理阶段可进行安灯处理的角色，必录，处理人参考从本角色中过滤选择；                                                                         |
| 默认通知人角色     || 用于对安灯处理时选择通知人的过滤条件限定，缩小选择通知人的范围；                                                                              |
| 处理权限        || 安灯处理时驳回和转关闭权限可以自定义，此处选择的权限才可用，不选择的权限不允许操作；                                                                    |
| 字段权限        || 安灯处理时可以对异常处理单上的部分字段进行数据修改，在此处定义的字段在对应的处理阶段上可以修改数据；                                                            |
| 三色灯指令时机     || 选择不同路径的触发时机，其中：\\ 第一行“发起呼叫”：仅用于定义HMI端发起呼叫时执行的指令；\\ 其余行：可以定义现场签到或处理完成时机执行的指令；\\ \\ 定义后系统会在相关操作时按指令规则自动触发声光报警。  |
| 三色灯指令       || 指定具体的指令                                                                                                       |


**3、异常处理人**

{{:sfs_生产事件_处理人.png?1000|}}

处理路径页签的子表，用于定义某个处理阶段的默认处理人和通知人，其中：

处理人：安灯呼叫的直接责任人，需要进行受理、签到和处理操作；

通知人：安灯呼叫的知晓人，仅做消息发送通知，不涉及业务处理；

字段说明：

| **字段**        || **说明**                                               |
| 发生部门          || 呼叫发生的部门                                              |
| 处理人角色         || 本生产事件在当前发生部门的处理人角色；                                  |
| 默认处理人         || 对应的默认处理人，优先从当前行的处理人角色挑选，如果为空则从路径对应的处理人角色中挑选，单选；      |
| 通知人角色         || 本生产事件在当前发生部门的通知人角色；                                  |
| 默认通知人         || 对应的默认通知人， 优先从当前行的通知人角色挑选，如果为空则从路径对应的默认通知人角色中挑选，可多选；  |
| 生效时间和失效时间     || 对应班次时段；                                              |

备注：

异常处理路径和异常处理人列表均有“处理人角色”和“通知人角色”字段，新增处理人行时会自动携带过来，用户可以进一步修改；

使用场景举例：

如果现场相对粗放管理，则可以把角色定义在处理路径定义；

如果现场管理相对精细，则可以按照不同部门处理人行数据中进一步定义角色；



**4、异常升级策略**

{{:sfs_生产事件_异常升级策略.png?1000|}}

定义异常处理级别的升级规则，只要异常处理时长达到对应级别的标准，则安灯呼叫自动升级为对应的级别，并向对应的“消息接收人”发送报警信息；

异常处理时长定义：从发起呼叫开始计时，直到验收关闭的时间间隔；

字段说明：

| **字段**      || **说明**                |
| 级别          || 预制一级、二级、三级三个级别        |
| 处理时长        || 维护每个级别对应的异常处理时长       |
| 单位          || 默认时间单位为分钟             |
| 消息接收人       || 选择用户或任岗员工             |
| 消息标题和正文     || 升级发送消息的内容，支持变量定义（同上）  |

**5、消息公式设置方法**

点击编辑按钮弹出定义界面，固定字符直接输入内容即可，如果需要动态读取异常处理单上的字段，则可以输入英文状态下的左大括号{，然后系统会自动弹出字段选择列表，选中后返回编辑界面；

如图：

{{:sfs_生产事件_处理路径_消息设置.png?600|}}

消息分标题和正文：

内部消息和云之家消息：标题和正文都会显示

第三方消息：仅显示正文信息

不建议文字内容过长，超过限制后系统会自动对文字做截断处理；

**6、定义三色灯控制环节和指令**

应用场景：

定义不同异常类型的三色灯控制环节和具体指令

使用说明：

a、表头：

三色灯品牌型号，F8三色灯品牌型号，指定使用的硬件系列；

b、异常处理路径页签：

三色灯指令时机：

选择不同路径的触发时机，其中：

第一行“发起呼叫”：仅用于定义HMI端发起呼叫时执行的指令；

其余行：可以定义现场签到或处理完成时机执行的指令；

定义后系统会在相关操作时按指令规则自动触发声光报警。
