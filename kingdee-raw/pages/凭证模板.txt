ID: 凭证模板

**功能概述**

凭证模板用于设置凭证各要素的取值规则，如凭证日期、凭证字、摘要、科目、借贷方向及金额等。

系统预置了日常经营活动常用的凭证模板，用户可以根据企业的实际情况修改或细化。

**使用前提**

科目表、账簿、凭证字、币别、汇率类型和结算方式已定义。

分录类型已定义。

**功能路径**

【财务会计】－>【智能会计平台】－>【基础资料】－>【凭证模板】

**字段说明**

| **字段 **           || **说明**                                                                                                                                    |
| 来源单据              || 选择业务单据。                                                                                                                                   |
| 科目表               || 选择科目表。                                                                                                                                    |
| 适用账簿              || 选择该凭证模板适用的账簿；若为空，则表示该凭证模板适用于所有账簿。                                                                                                         |
| 核算组织来源            || 选择单据上的组织字段作为凭证的核算组织来源。                                                                                                                    |
| 凭证日期              || 用于单据生成总账凭证取单据上的日期作为记账日期。                                                                                                                  |
| 业务日期              || 用于单据生成总账凭证业务日期取来源业务单据上的日期，可选单据上的单据头日期字段。凭证上的业务日期用于往来科目总账账龄分析。                                                                             |
| 凭证生成取账簿默认凭证字      || 凭证模版增加复选框“凭证生成取账簿默认凭证字”，若勾选则凭证生成时凭证的凭证字取值账簿默认凭证字，不勾选则按凭证模版设置的凭证字及凭证字取值条件执行，此参数勾选与否不影响凭证字现有的设置及控制。                                         |
| 总账凭证日期取系统当前日期     || 凭证模版增加复选框“总账凭证日期取系统当前日期”，若勾选则凭证生成时总账凭证日期取当前凭证生成操作的系统时间，不勾选时按现有处理规则执行。                                                                     |
| 总账凭证日期取期间最后一天     || 用于业务单据生成总账凭证日取最后一天。\\ 当勾选参数时，业务凭证日期还是按凭证模板凭证日期设置的来源日期字段取值，而业务凭证生生成总账凭证的凭证日期取为对应期间会计日历的最后一天。                                               |
| 总账凭证分录合并          || 默认选择值为“取智能会计平台参数”，选中此选项时总账凭证分录合并与否保持和智能会计平台参数一致；若选中“分录行合并”或者“分录行不合并”，则总账凭证分录合并与否按凭证模板的设置取值，不再考虑智能会计平台参数的设置；                               |
| 摘要不一致合并           || 默认值为“取智能会计平台参数”，若凭证模板上“总账凭证分录合并”选中为“分录行合并”时此选项可以设置；具体摘要合并控制规则有四种：显示固定摘要、显示第一行摘要、显示最后一行摘要、显示所有分录行摘要，如选中显示所有分录行摘要，则凭证生成时按总账凭证摘要字段长度限制自动截取。  |
| 凭证排序来源            || 用于单据批量生成凭证时，按单据上字段排序，可选单据头字段为文本型、基础资料、短日期和长日期（如创建日期）。                                                                                     |
| 分类条件              || 若业务单据需要拆分成不同的类别生成不同的凭证分录，则在此处进行定义。业务单据表头的任意字段均可作为分类依据。                                                                                    |
| 必须生成总账凭证          || 若该类单据必须生成总账凭证，则勾选此标识。\\ 勾选此标识，总账结账时会检查该类单据是否已生成总账凭证，若未生成总账凭证则不允许结账。                                                                       |
| 分录类型              || 选择分录类型。                                                                                                                                   |
| 科目                || 定义凭证分录行的会计科目（核算维度、现金流量项目）的取值规则以及科目影响因素的来源字段。\\ 在科目设置界面设置了现金流量项目后，生成凭证时会自动指定现金流量。                                                          |
| 分录行生成条件           || 定义凭证分录行生成的前提条件，不满足条件则不生成该分录行；\\ 一般情况下不需要设置。                                                                                               |
| 业务凭证分录合并          || 定义业务单据生成业务凭证的过程中，业务单据的分录行是否合并生成业务凭证的分录行。                                                                                                  |
| 业务编号              || 用于单据生成的凭证业务编号取单据上的字段，可选单据文本字段。凭证上的业务编号是用于往来科目总账账龄分析。                                                                                      |

 

操作说明

系统预置的凭证模板支持【恢复系统预置】功能，点击该功能按钮，凭证模板将还原成出厂时的状态。**需要注意的是如果账套实际科目与系统预设的科目差异很大时，建议不要再使用此功能。**

业务说明

凭证模板设置完成后，若用户对【科目】基础资料进行了修改，则建议对凭证模板的科目字段进行相应修改，不修改可能会导致生成凭证失败或错误。 
系统预置的应收款科目初始数据、应付款科目初始数据、现金科目初始数据、银行存款科目初始数据、资产科目初始数据和存货科目初始数据凭证模板供总账模块【科目初始数据引入】使用，在【凭证生成】向导中不生成凭证。

 存货类单据凭证模版（凭证生成）注意事项：
  * 存货对账取值业务报表为“存货收发存汇总表”，而存货收发存汇总表所涵盖的单据范围为存货核算---核算单据查询所核算到的单据，核算单据查询可以看到单据的出入库序列及调拨方向；
  * 凭证模版上存货类科目借贷方向应保持和单据在存货收发存（核算单据查询）里面的出入库序列保持一致，整体原则为：
    * 若单据出入库序列为“出库”且调拨方式为“普通”，设置凭证模版时存货科目方向设置应在贷方（出库序列但调拨方向为“退货”时凭证模版上存货科目方向仍旧为贷方，金额设置为 0 - 对应成本金额字段，此时生成贷方负金额的存货凭证分录）；
    * 若单据出入库序列为“入库”且调拨方向为“普通”，设置凭证模版时存货科目方向设置应在借方（入库序列但调拨方向为“退货”时凭证模版上存货科目方向仍旧为借方，金额设置为 0 - 对应成本金额字段，此时生成借方负金额的存货凭证分录）。
