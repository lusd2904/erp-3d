====== 报表通用控件列表 ======
 
| 控件名称       || 功能描述                                                                       |
| 子报表        || 用来在一个报表中插入另一个报表，例如，子报表包含另一个报表必需的模板信息。子报表也可以用来制作概要-明细报表                     |
| 条形码        || 用来向报表中插入不同类型的条形码                                                           |
| 图表         || 用来让你的报表数据展示出不同的视图                                                          |
| 复选框        || 用来在报表中表示真/假或者已选/未选/不确定等状态                                                  |
| 文本         || 用来向报表中插入单选或多行文本，这些文本可以是静态的（固定不变的）也可以是动态的（从数据源中即时抽取数据）                      |
| 线条         || 直线，用来向报表中插入水平直线，垂直直线以及斜线                                                   |
| 分页符        || 用来在报表中标记何时需要开始新的一页，如果你想要报表刚好在某个报表条之前或之后开始新的一页，可以通过设置报表条的PageBreak属性来代替该控件  |
| 页信息        || 用来在报表中显示一些辅助信息，例如总页数，当前页码以及用户信息等                                           |
| 面板         || 用来做为其他控件的容器，从而将几个控件组合在一起，易于操作                                              |
| 图片         || 图片框，用来在报表中显示图片                                                             |
| 形状         || 用来在报表中插入简单的图形                                                              |
| 表格         || 用来向报表中插入表格，如果你想要数据以表格的形式表现的话，这个控件有很大的用处                                    |
| 邮政编码       || 用来在报表中插入表示邮政编码的数字                                                          |
| 格式文本       || 提供有固定格式的文本字段                                                               |
| 交叉分析表格     || 用来让报表数据以行和列交叉分析的方式展示                                                       |
| 交叉条线       || 支持垮区段展示的线条                                                                 |
| 交叉条框       || 支持垮区段展示的条框                                                                 |
