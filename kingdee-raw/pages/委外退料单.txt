======1 委外退料单  ======

=====1.1 功能概述 =====
委外退料单是处理委外部门和仓储部门之间业务关系的书面凭证，是财务人员据以记账、核算成本的重要原始凭证。


=====1.2 使用前提 =====
  - 对应的委外订单分录需处于下达、完工状态，且未挂起；
  - 对应的委外用料清单必须处于审核状态。


=====1.3 功能路径 =====
【生产制造】－>【委外管理】－>【委外领料】－>【委外退料单】

=====1.4 生成方式=====
  - 委外订单分录、委外领料单、委外补料单下推生成；
  - 委外退料单新增界面，通过选单生成。

====== 2 字段说明 ======
===== 2.1 基本信息===== 
^  **字段**  ^  **说明**                                                                                                                   ^
|  单据编码    | 1.单据编号由系统设定的编码规则自动生成。\\ 2.具有唯一性，不允许重复。                                                                                    |
|  单据类型    | 1.系统自动取委外退料单的默认单据类型；\\ 2.单据新增时可改，单据保存后不可改。                                                                                |
|  单据日期    | 1、收料组织未关账：日期要求大于等于发料组织的库存启用日期；\\ 2、收料组织已关账：日期要求大于MAX（发料组织最近一次的关账日期，货主（货主类型=组织）最近一次的关账日期）。                                 |
|  收料组织    | 1.接收委外加工所退物料的业务组织；\\ 2.收料组织必须具有库存职能。                                                                                      |
|  委外组织    | 1.进行产品加工的业务组织；\\ 2.委外组织必须具有工厂职能。                                                                                          |
|  委外供应商   | 1.委外组织有采购职能，可选委外组织下的委外供应商；\\ 2.如果组织业务关系建立了委托采购，可选与委外组织建立了委托采购关系的受托方（有采购职能）的委外供应商；\\ 3.如果没有建立委托采购组织业务关系，可选择所有采购组织下的委外供应商；  |
|  仓库      | 此处起过滤作用，不保存。                                                                                                              |
|  货主类型    | 1.修改货主类型时，影响货主字段。\\ 2.取值范围：组织、供应商、客户。                                                                                     |
|  货主      | 货主为物料所有权的持有者。\\ 1.货主类型为业务组织时，货主取业务组织。\\ 2.货主类型为供应商时，货主取供应商。\\ 3.货主类型为客户时，货主取客户。                                           |
===== 2.2 明细页签===== 
^  **字段**  ^  **说明**                                                               ^
|  物料编码    | 收料组织下审核未禁用的可库存物料编码。                                                   |
|  物料名称    | 根据物料代码携带物料名称；不可编辑。                                                    |
|  规格型号    | 根据物料代码携带规格型号；不可编辑。                                                    |
|  单位      | 携带上游单据的单位，不可修改。                                                       |
|  申请数量    | 1.申请数量为申请部门申请退入仓库的物料数量。\\ 2.委外退料单生成时，由系统自动计算，允许手动修改，但是不能修改为大于下推数量。    |
|  实收数量    | 1.实收数量为收料部门实际接收的物料数量。\\ 2.委外退料单生成时，由系统自动计算，允许手动修改，但是不能超出委外用料清单的数量控制。  |
|  仓库      | 1.接收委外加工所需物料的存放位置。\\ 2.允许修改，但是必须是表头发料组织下的仓库；影响仓位字段。                   |
|  仓位      | 1.接收委外加工所需物料的存放位置。\\ 2.如果仓库启用了仓位管理，可F8或手工录入仓库可用仓位；否则，为空。              |

|  保质期     | 1.产品的有效使用时间\\ 2.启用保质期管理，必须录入物料的保质期。                                                   |

====== 3 操作说明 ======
====保存==== 

1.委外退料单保存时，影响对应委外用料清单/委外补料单/委外领料单的退料选单数。

2.委外退料单保存时，进行数量控制检验，需满足条件：申请数量<=可申请数量。

====作废==== 

委外退料单作废，影响对应委外用料清单/委外补料单/委外领料单的退料选单数。 
====审核/反审核==== 

1.审核更新库存时，委外退料单审核、反审核，影响对应委外用料清单的良品退料数量、来料不良退料数量、作业不良退料数量。

2.只有对应的委外订单为下达/完工状态，委外退料单才能反审核。

3.只有委外退料单不存在下游有效单据时，委外退料单才能反审核。

注：
只有委外用料清单为审核状态时，对应的委外退料单才能进行保存/删除/作废/提交/审核/反审核操作。
 


====== 4 业务说明 ======
====选单==== 

（一）委外退料单通过选择委外用料清单分录生成。

选单条件：

1.数量控制：委外用料清单分录的【在制品数量】> 0；

保存时校验：【实退数量】≤【已领数量】+【补领数量】-【报废数量】-【良品退料数量】-【不良品退料数量】-【消耗数量】*（1-波动消耗）-【退料选单数量】；

2.组织校验：委外用料清单表头的【委外组织】必须是委外退料单表头的【委外组织】；

3.选单必录字段：委外退料单选单前，“收料组织”“委外组织”为必录字段。

（二）委外退料单通过选择委外领料单或者委外补料单分录生成。

选单条件：

1.数量控制：【实发数量】-【退料选单数】> 0；

2.组织校验：委外领料单或者委外补料单表头的【委外组织】必须是委外退料单表头的【委外组织】；

3.选单必录字段：委外退料单选单前，“收料组织”“委外组织”为必录字段。

（三）注意事项：

 委外退料单上物料维度信息的选取范围，不能超出实际领取的物料的信息范围。 

====下推==== 

（一）从委外订单下推委外退料单

1.委外订单下推生成委外退料单时，物料信息从该委外订单对应的委外用料清单中取数；

2.委外订单支持批量下推。

下推条件：

1.数量控制：委外用料清单分录的【在制品数量】> 0；

保存时校验：【实退数量】≤【已领数量】+【补领数量】-【报废数量】-【良品退料数量】-【不良品退料数量】-【消耗数量】*（1-波动消耗）-【退料选单数量】；

2.下推分组：【收料组织】+【委外组织】+【货主】+【货主类型】相同，不同委外用料清单中的分录，可以在同一张委外退料单中进行领料。

（二）从委外领料单或者委外补料单下推委外退料单

1.委外领料单或者补料单下推生成委外退料单时，物料信息从对应的单据上面取数；

2.委外领料单和委外补料单支持批量下推委外退料单。

下推条件：

1.数量控制：对应委外l领料单/委外补料单分录的【实发数量】-【退料选单数】> 0；

2.下推分组：【收料组织】+【委外组织】+【货主】+【货主类型】相同，不同委外领料单或者委外补料单中的分录，可以在同一张委外退料单中进行退料。

（三）注意事项

 委外退料单上物料维度信息的选取范围，不能超出实际领取的物料的信息范围。 

====库存查询==== 

调即时库存查询表，支持选择即时库存信息返回单据界面。 
====批号查询==== 

针对启用批号管理的物料，委外领料单单据界面支持对选中物料的批号查询。
