====== 功能说明 ======

产品维度利润分析表可以从产品角度查看产品的销售毛利、净利情况。 

====== 功能路径 ======

【成本管理】—>【产品成本核算】—>【报表分析】—>【产品维度利润分析表】

====== 字段说明 ======
 
快捷页签主要过滤项目说明

| **字   段**     || **说 明**                  |
| 核算体系          || 当前产品维度利润分析表对应的核算体系。      |
| 核算组织          || 当前产品维度利润分析表对应的核算组织。      |
| 会计政策          || 当前产品维度利润分析表对应的会计政策。      |
| 开始会计年度        || 当前产品维度利润分析表统计成本的开始会计年度。  |
| 开始会计期间        || 当前产品维度利润分析表统计成本的开始会计期间。  |
| 结束会计年度        || 当前产品维度利润分析表统计成本的结束会计年度。  |
| 结束会计期间        || 当前产品维度利润分析表统计成本的结束会计期间。  |
| 开始日期        || 当前产品维度利润分析表统计成本的开始日期。  |
| 结束日期        || 当前产品维度利润分析表统计成本的结束日期。  |
| 产品编码          || 当前产品维度利润分析表对应的产品。        |
| 客户            || 当前产品维度利润分析表对应的客户。        |
| 销售部门          || 当前产品维度利润分析表对应的销售部门。      |
| 销售员           || 当前产品维度利润分析表对应的销售员。       |
| 客户类型           || 当前产品维度利润分析表对应的客户类型。       |
| 汇总依据          || 当前产品维度利润分析表对应的汇总依据。      |
| 按应收单获取成本         || 当前产品维度利润分析表对应的应收单上的成本价字段获取成本。      |
