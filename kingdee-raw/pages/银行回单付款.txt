ID: 银行回单付款
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%93%B6%E8%A1%8C%E5%9B%9E%E5%8D%95%E4%BB%98%E6%AC%BE

**功能概述**

  *银行回单付款扫描录单提供两个入口，这里要讲的是银行回单付款的扫描入口，点击“扫描录单”然后点击初始化扫描仪，在此之前需要将扫描仪和电脑进行正确连接并打开扫描仪。

  *选择需要的识别模版后，将银行回单按正确顺序放入扫描仪，点击扫描识别，系统将自动生成银行回单。

  *按银行回单的收款或付款类型，自动生成到对应的单据，系统预置两种单据：银行回单收款 或者 银行回单付款。

  *若识别结果无误则直接生成银行回单单据，若扫描扫描识别基础结果信息缺失或关键信息无法准确识别，系统只生成扫描识别基础而不生成银行回单收款 或者 银行回单付款，用户可手工修改自定义单据识别，保存后点击生成单据，系统将自动生成对应的银行回单收款 或者 银行回单付款。

  *用户也可通过自定义单据识别联查生成的银行回单，以及扫描影像。



**使用前提**

扫描仪已注册、已制作扫描识别模板（增值税发票无需制作模板）。

**功能路径**

【财务会计】－>【智能会计平台】－>【扫描记账】－>【银行回单付款】。

**字段说明**

| **字段**     || **说明**                                                      |
| 单据编号       || 扫描录单生成的银行回单付款单据对应的单据编号。                                     |
| 业务日期       || 扫描录单生成的银行回单付款单据上的业务日期，默认保持和交易日期一致。                          |
| 交易流水号      || 扫描录单生成的银行回单付款单据上的交易流水号，此流水号来源为银行回单对应识别字段，如无则留空。             |
| 交易日期       || 扫描录单生成的银行回单付款单据上的交易日期，日期来自银行回单上的交易日期。                       |
| 核算组织       || 扫描录单生成的银行回单付款单据上的核算组织，默认取值为银行回单上的付款人。                       |
| 币别         || 扫描录单生成的银行回单付款单据上的币别，默认取值为银行回单上的币别。                          |
| 本位币        || 银行回单付款单据上的本位币币别，默认取值为核算组织所在默认会计核算体系 + 默认会计政策下的主币别。          |
| 汇率类型       || 默认取值为核算组织所在默认会计核算体系 + 默认会计政策下的汇率类型。                         |
| 汇率         || 按业务日期 + 汇率类型获取对应的汇率。                                        |
| 收款人类型      || 通过扫描录单自动生成银行回单上的收款人类型，此字段为多类别基础资料，默认为供应商，除此之外还可以为客户、银行、员工。  |
| 收款人名称      || 扫描录单生成的银行回单付款单据上的收款人名称，系统按不同收款人类型显示其对应的基础资料。                |
| 收款人开户行     || 收款人对应银行账号的开户行。                                              |
| 收款人账号      || 收款人对应银行账号。                                                  |
| 付款人名称      || 扫描录单生成的银行回单付款单据上的付款人名称，自动与系统中的组织机构进行匹配。                     |
| 付款人开户行     || 付款人对应银行账号的开户行。                                              |
| 付款人账号      || 付款人对应银行账号。                                                  |
| 金额         || 扫描录单生成的银行回单付款单据上的金额。                                        |
| 金额本位币      || 按“金额+汇率+币别”换算后的本位币金额。                                       |
| 摘要         || 扫描录单生成的银行回单付款单据上的摘要，默认取值为银行回单上的备注字段。                        |
