===== 1.功能概述 =====
食品销售排行报表针对食品字段头进行排序，中文按首字母排序，数值按大小排序、金额按金额大小排序
====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【食品报表分析】→【食品销售排行报表】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：快捷、条件、显示隐藏列、分组汇总、排序

  * 快捷页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 分组汇总页签：支持进行不同分级汇总依据的设置
  * 排序页签：报表显示字段排序
====== 5.报表字段说明 ======
^ 字段      ^ 说明                     ^
| 组织      | 组织名称                   |
| 部门编码    | 食品部门编码                 |
| 部门名称    | 食品部门名称                 |
| 食品编码    | 食品编码                   |
| 食品名称    | 食品名称                   |
| 食品大类    | 食品大类                   |
| 食品销售均价  | 食品销售均价=销售金额/销售数量       |
| 销售数量    | 销售数量=下单数量-取消数量         |
| 净售数量    | 净售数量=下单数量-取消数量-赠送数量    |
| 销售金额    | 销售金额=下单金额-取消金额         |
| 净售金额    | 净售金额=下单金额-取消金额-食品优惠金额  |
| 优惠金额    | 食品优惠金额=赠送金额+折扣金额       |

====== 6.报表操作说明 ======
1、报表提供打印、引出功能。

2、报表提供按表头的【组织】、【营业日期】等统计分析食品编码、食品名称，食品大类、食品销售均价、销售数量、净售数量、销售金额、净售金额、优惠金额

3、报表提供过滤→分组汇总，在报表中对分组字段进行统计分析，其中分组字段包括：组织、部门名称、食品名称

4、可以通过勾选【选项】中的参数，控制数值的显示 。
