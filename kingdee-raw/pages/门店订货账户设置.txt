====== 1.门店订货账户设置 ======
===== 1.1 功能概述 =====
  * 支付储值账户，信用账户
  * 需要设置使用范围对应的组织才会生效
  * 勾选允许提现则移动端账户中心才会显示申请提现按钮
  * 勾选允许提现后需要设置提现周期
  * 提现最高限额表示可以提现的最高额度，系统默认为0，如果未设置则提现金额为0
  * 提现最低限额表示可以提现的最低额度
===== 1.2 字段说明 =====
^ 字段      ^ 说明                     ^
| 编码      | 唯一值，支持自动生成，同时支持手工输入    |
| 名称      | 单据名称                   |
| 账户类型    | 支持储值账户                 |
| 备注      | 支持输入备注信息               |
| 允许提现    | 如果勾选则允许提现，如果不允许则不允许提现  |
| 提现最高限额  | 勾选允许提现后设置单次提现的最高限额     |
| 提现最低限额  | 勾选允许提现后设置单次提现的最低限额     |
| 提现周期    | 设置每周/天/年/月允许提现的次数      |
| 提现付款组织  | 设置提现的付款组织，由组织选择        |
| 使用范围    | 设置适用于那些组织              |
