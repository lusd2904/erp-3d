======1 云之家集成概述 ======

===== 1.1 云之家集成概述 =====
 
“互联网+”时代，金蝶云移动轻应用使得客户能够充分利用碎片化时间移动办公，加快企业的经营决策和信息流转，给企业带来很大的效益。越来越多的金蝶云用户非常乐意使用云之家轻应用。

===== 1.2 系统特性 =====
 
本系统主要包含以下应用：

  - 自动启用云之家，金蝶AI星空通过【同步用户】，自动集成云之家团队，并自动映射金蝶AI星空用户和云之家用户；
  - 金蝶AI星空用户与云之家账号一体化，按需登录；
  - 通过金蝶AI星空轻应用与业务流融合，高效协同作业，让流程更顺畅。

 
====== 2 云之家集成操作手册 ======

===== 2.1 云之家集成部署 =====

==== 2.1.1 自动集成配置 ====

默认团队自动配置，不需要手工去配置云之花团队和密钥文件，系统自动会配置成企业注册默认团队。

路径1：administrator登录【查询用户-用户同步】；

路径2：administrator登录【基础管理-移动设置-云之家集成】；

路径3：后台每天自动执行配置。
==== 2.1.2 切换团队 ====

如果使用的云之家团队（移动端）不是企业默认注册团队时，可通过切换团队配置其他团队，输入团队管理员手机号码和密码，选择要配置的团队即可。


路径：administrator登录（基础管理-移动设置-云之家集成），点击“业务操作-切换团队”。


==== 2.1.3 更新密钥 ====

自动集成默认是集成了云之家通讯录，如果需要集成其他应用，则需要到云之家开启对应的应用，通过更新密码即可自动获取密钥完成对接。

云之家路径：云之家团队管理员登录云之家，【管理中心】-【系统设置】-【系统集成】勾选对应应用即会自动生成密钥。

金蝶AI星空路径：administrator登录金蝶AI星空，【基础管理】-【移动设置】-【云之家集成】，点击“业务操作-更新密钥”，输入团队管理员手机号码和密钥即可更新。


==== 2.1.4 同步用户到云之家 ====

系统管理员可在查询用户列表选择需要同步到用户，点击“同步用户”即可同步所选用户到云之家，并且建立用户映射关系。

路径：Administrator登录系统，【查询用户】-【用户同步】，即会同步所选用户到云之家。

==== 2.1.5 不同步用户到云之家 ====

分给在金蝶云平台和金蝶AI星空设置不同步参数，即可实现用户不同步到云之家。

第一步：在金蝶云平台设置人企分离，选择不同步云之家；

路径：管理员登录云平台（cloud.kingdee.com），【我的企业】-【ERP产品】-【查看详情】，在注册用户列表的【管理用户】-【人企分离】设置不同步用户到云之家。

第二步：在金蝶AI星空设置不同步新用户到云之家。

路径：administrator登录金蝶AI星空系统，【系统管理】-【查询用户】-【选项】下的用户同步参数勾选“不同步新用户到云之家”。

==== 2.1.6 查看用户同步云之家日志 ====

同步完成后，可查看用户同步云之家日志，查看用户同步情况。同步失败会显示详细的同步异常原因。

路径：Administrator登录系统，【查询用户】-【用户同步】下的“用户同步日志”。

==== 2.1.7 查看用户映射关系 ====

只有金蝶AI星空用户和云之家用户之间建立了正确的用户映射关系才可以正常应用集成业务。

路径：administrator登录金蝶云系统。【基础管理】-【移动设置】-【云之家集成】-【云之家用户映射关系】。


===== 2.2 云之家集成应用 =====

==== 2.2.1 云之家智能应用 ====

=== 2.2.1.1  云之家账号登录金蝶云系统 ===

支持云之家账号登录金蝶云系统，实现云之家账号一体化，用户可以按需登录金蝶云，步骤如下：

第一步：启用云之家身份认证

1、先在管理中心中选择数据中心启用云之家身份认证。
路径：管理中心->数据中心列表->【设置-下拉菜单认证方式】，选择数据中心，然后勾选云之家身份即可。

2、登录该数据中心，选择用户启用云之家身份认证。
路径：系统管理->查询用户->【业务操作-下拉菜单认证方式】，选择用户，启用云之家身份即可。

第二步：进行云之家集成部署；

第三步：用户登录数据中心，在登录页面，认证方式选择云之家身份，然后录入用户名和密码录入对应的云之家账号及密码即可登录金蝶云系统。



=== 2.2.1.2  云之家桌面端 ===

点击系统右侧栏的云之家图标，即可直接访问云之家桌面端，方便及时交流。

==== 2.2.2 云之家协同应用 ====


建立企业内网的沟通渠道，传统ERP仅可基于业务发起内部人员的协作，通过云之家协同可以与业务关联的外部人员（比如客户联系人、供应商联系人等）进行协作沟通，
基于业务，建立了企业内部与外部的沟通渠道，提升工作效率及客户满意度。

操作步骤：

打开具体的业务单据，比如销售订单，具体业务员旁边自动显示【联系】图标，点击该图标，即可打开云之家沟通页面及时沟通。
