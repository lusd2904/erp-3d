===== 抵消分录模板 =====

**功能说明**

抵消分录模板为后续合并报表过程中抵消分录的创建而服务。抵消分录可以手工录入，也可以通过抵消分录模板自动取数生成。这样自动创建创建抵消分录，使合并报表的抵消业务非常快速和便捷。

系统预置了一些常用的抵消分录模板，有可能会与实际中的业务有出入，在上线出期，实施可以多跟客户沟通，了解抵消分录各行的取数规则，并相应做调整。

权益类调整分录及抵消分录需要在【合并控制】-【持股比例】中设置，操作【抵消分录】-【自动抵消】时才可以自动生成抵消分录。

**操作前提**

定义抵消类型和交易种类。

**操作说明**

打开【财务会计】－>【合并报表】－>【合并准备】－>【抵消分录模板】功能，新增抵消分录模板。

**字段说明**

| 位置         || 字段         || 说明                                                                                                                                                                                                                                                                              |
| 单据头        || 模板类别       || 用来进行抵消分录模板的分组管理。                                                                                                                                                                                                                                                                |
| :::        | :::  | 抵消类型       || 从抵消类型基础资料中进行选择。\\ 注意：不同抵消类型，模板要录入的内容会有所不同，所以抵消类型需要选择正确。                                                                                                                                                                                                                         |
| :::        | :::  | 交易种类       || 如果选择的抵消类型为“交易类”，则需要录入“交易种类”。                                                                                                                                                                                                                                                    |
| :::        | :::  | 差异处理       || 抵消类型为往来类型时，后续需要进行往来核对，需要确认核对时差异处理的默认处理方式。\\ 当系统参数选择“增加内部事项交易类-存货核对”，后续需要进行存货核对，需要确认核对时差异处理的默认处理方式。                                                                                                                                                                              |
| :::        | :::  | 差异分配       || 抵消类型为往来类型时，后续需要进行往来核对，需要确认核对时差异处理的默认分配方式。\\ 当系统参数选择“增加内部事项交易类-存货核对”，后续需要进行存货核对，需要确认核对时差异处理的默认分配方式。                                                                                                                                                                              |
| 单据体        || 摘要         || 抵消分录的摘要，非必录项。                                                                                                                                                                                                                                                                   |
| :::        | :::  | 项目编码       || 抵消分录的行的报表项目，只能从抵消类型关联的报表项目中选取。                                                                                                                                                                                                                                                  |
| :::        | :::  | 数据类型       || 选择分录行的项目数据类型。\\ 此数据类型判定此行数据会传递到工作底稿的哪个报表，期末数会传递到资产负债表，本年累计数会传递到利润表。                                                                                                                                                                                                             |
| :::        | :::  | 借贷方向       || 选择分录行的借贷方向。条件判断为差额行时，系统自动判断其借贷方向。每个分录模板只允许存在一行分录的借贷方向为条件判断。                                                                                                                                                                                                                     |
| :::        | :::  | 取数方        || 抵消类型为“权益类”和“交易类”时，需要定义分录行的取数方。\\ 抵消类型为“现金流量”时，制作“现金流量附表”时，需要制作同借同贷的抵消分录，取数方可以设置为我方和对方                                                                                                                                                                                           |
| :::        | :::  | 取数来源       || 取数来源为“个别报表”“抵消表”“差额”时，系统自动取数。\\ 取数来源为“公式定义”时，需要在“抵销数”中定义好取数公式。其中定义公式ACCTITEMHBS、ACCTITEMHZS合并范围参数为空时，此参数默认为取数方所在合并范围。                                                                                                                                                           |
| :::        | :::  | 抵消数        || 取数来源为“公式定义”时，需要定义取数公式，其他则不需要特别定义。                                                                                                                                                                                                                                               |
| :::        | :::  | 股权分段计算     || 抵消类型：权益类或交易类，取数来源：公式定义，才可勾选此字段\\ 勾选，对此行分录的抵消数公式定义中的FX*EPS进行分段计算，适用本年累计数分段计算。\\ 公式定义的格式只支持FX*EPS()、####+-FX*EPS()+-####、FX*EPS()+-FX*EPS()，其中FX为单一函数，####为任意数值或公式。\\ 分段计算逻辑：[FX(Nn)-FX(N2-1)]*EPS(Nn)+FX(N2-1))*EPS(N1-1))；从本年1期间为开始期间，其中FX为函数取数结果 Nn为合并当期，N1,N2……为本年的股权变动日所在期间  |
