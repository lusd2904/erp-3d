 ====== 模板样式方案 ====== 

**功能说明**

目前报表系统编制平台仍然采用电子表格编辑器，为逐步弱化电子表格的报表编制场所这一角色，我们将各类报表的定义和取数规则设置都提前到报表模板定义之前，提供独立的模板样式填充方案，在该方案中确定报表样式，填充的内容以及各表项的取数公式。该方案被保存和管理，可方便灵活的用于后期任意报表的定义。

 ====== 报表系统-模板样式方案 ====== 

**功能路径**

【财务会计】→【报表】→【报表模板】→【模板样式方案】

 ====== 字段说明 ======

| 位置              || 字段                || 说明                                                                                                                                                                                               |
| 单据头             || 报表类型              || 提供三种报表类型，分别为：个别报表、自定义报表、阿米巴报表。每种报表类型的样式方案只适用同报表类型的报表模板使用。                                                                                                                                        |
| :::             | :::  | 样式类型              || 提供两种样式类型，分别为：固定样式报表、动态罗列样式报表。每种样式类型的样式方案只适用同样式类型的报表模板使用。                                                                                                                                         |
| “报表项目”页签        || 报表项目              || 选择报表项目基础资料，支持单选/多选报表项目。                                                                                                                                                                          |
| :::             | :::  | 报表项目填充方向          || 支持“横向”和“纵向”填充报表项目。                                                                                                                                                                               |
| :::             | :::  | 报表项目填充自动缩进        || 报表项目必须以“.”区别级次，每增加一级，报表项目填充时自动缩进2个字节。                                                                                                                                                            |
| :::             | :::  | 另起一列（行）填充         || 除第一行以外都允许选中；\\ 该选项的作用：\\ 在系统执行批量填充时（“纵向”填充方向），从“另起一列（行）填充”的报表项目开始，另起一列开始填充（填充首行不变）；\\ 在系统执行批量填充时（“横向”填充方向），从“另起一列（行）填充”的报表项目开始，另起一行开始填充（填充首列不变）；\\ 报表类型为“工作底稿”时，不提供本选项。\\ 报表样式为“动态罗列表”时，不提供本选项。  |
| :::             | :::  | 取数公式              || 选择该参数，则系统自动展示“取数公式”页签信息，并需要对此进行设置；\\ 不选择该参数，则表示不需要进行取数公式的设置。                                                                                                                                     |
| :::             | :::  | 取数公式来源于项目取数公式     || 选中“取数公式”时，可再选中此选项，在填充模板时，取数公式将填充项目取数公式中设置的公式；\\ 选中“取数公式”时，不选中此选项，将需要在取数公式页签中设置好取数函数等信息。                                                                                                          |
| :::             | :::  | 项目公式              || 选择该参数，在填充模板时，取数单元格自动填充项目公式，用于保存为报表项目值。\\ 不选择该参数，在填充模板时，取数单元格不会填充项目公式。                                                                                                                            |
| “数据类型”页签        || 数据类型              || 选择项目数据类型基础资料，支持单选/多选项目数据类型。                                                                                                                                                                      |
| :::             | :::  | 年度、期间             || 默认值0，不可编辑，表示填充项目公式期间参数为0，保存为报表所属的年度期间的报表项目值。                                                                                                                                                     |
| :::             | :::  | 自动取数              || 系统自动处理项，项目数据类型基础资料如果勾选合并数自动取数，则此处自动显示为“是”。\\ 在报表模板中执行批量填充时，本数据类型所在的行/列需要根据本项目数据类型基础资料中的取数设置来取数，\\ 通过函数ACCTITEM/CRACCTITEM结合项目数据类型基础资料中的取数参数来填充报表模板对应单元格的取数公式。                                    |
| :::             | :::  | 填充内容              || 报表类型为“个别报表”且报表样式为“固定样式”时，才提供【填充内容】设置；选中某个项目，表示在报表模板填充时需要填充此项目内容。                                                                                                                                 |
| “数据列”页签         || 预置列               || 此页签适用于报表类型为“工作底稿”，预置列为工作底稿的格式，灰显，不可修改                                                                                                                                                            |
| :::             | :::  | 填充分组依据            || 子公司个别报表数据填充时的排列次序，默认按“按数据类型分组”                                                                                                                                                                   |
| :::             | :::  | 合并数置于数据列首         || 勾选，则工作底稿的合并数这列位于数据列的第一列，子公司数变化，而这列位置不会变化。\\ 适用场景：当报表模板设置了ref()函数，取某个合并数时，其函数的取值不会因为子公司数的变化而人为调整取数单位格位置。                                                                                          |
| “报表维度”页签        || 报告维度              || 报表样式为“动态罗列样式”时才需要设置报告维度；\\ 【物料分组】、【客户分组】应用于阿米巴报表类型，当选择这两个分组，需要在模板样式方案中设置【分组级次】。\\ 【分组级次】的设置决定了阿米巴报表的数据汇总级次及展示级次，系统会从对应业务单据中获取明细数据，按此处设置的级次处理数据的加减，并填至报表单元格中。                                     |
| :::             | :::  | 包含合计项             || 选中该参数，则系统自动在模板填充时插入单元格SUM公式，用于对维度值的求和；不选中该参数，则不插入单元格SUM公式。\\ 合计项目位置可选择供表尾、表头，选择表尾，则合计项显示在维度值填充区域的最后一行，选择表头，则合计项显示在维度值填充区域的第一行。                                                                   |
| :::             | :::  | 默认插入行列数           || 允许用户设置插入空行数（>=1），系统默认10行。                                                                                                                                                                        |
| “取数公式”页签        || 取数公式              || 个别报表（固定样式）支持函数有：ACCT、ACCTCash、ACCTITEM；\\ 个别报表（动态罗列）支持函数仅有：ACCT。                                                                                                                                 |
