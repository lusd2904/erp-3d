ID: 生产订单工序进度表
URL: https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%94%9F%E4%BA%A7%E8%AE%A2%E5%8D%95%E5%B7%A5%E5%BA%8F%E8%BF%9B%E5%BA%A6%E8%A1%A8

**报表功能**

  - 查看生产订单各工序的执行进度情况，查看是否存在拖期情况，以便采取相应措施。
  - 用户可以从生产车间、加工车间、产品等角度查看订单各工序的进度情况。
  - 报表结果明细行黄色代表拖期开工；明细行橙色代表拖期完工。

**功能路径**

【生产制造】－>【车间管理】－>【报表分析】－>【生产订单工序进度表】

**过滤条件**

“快捷”页签：快捷设置生产组织、生产车间、加工组织、加工车间、产品编码、拖期状态等基本过滤条件。

“高级”页签：可设置查询结果的字段值过滤。

“排序”页签：可按照用户关心的选项，设置报表中明细行的排列顺序。

“显示隐藏列”页签：设置报表的字段是否显示以及显示顺序。

**快捷过滤**

| **字段**        || **说明**                                                                                  |
| 生产组织          || 1.定义报表查询的生产订单的生产组织范围；\\ 2.用户有权限的具有工厂职能的组织，可以选多个组织。默认为登录组织。                              |
| 生产车间          || 1.定义报表查询的生产订单分录行的生产车间。\\ 2.所选生产组织下的生产车间，可以选多个车间。                                        |
| 加工组织          || 1.定义报表查询的工序计划工序的加工组织的范围。\\ 2.用户有权限的具有工厂职能的组织，可以选多个组织。默认为登录组织。                           |
| 加工车间          || 1.定义报表查询的工序计划工序的加工车间的范围。\\ 2.所选加工组织下的生产车间，可以选多个车间。                                      |
| 计划开始日期（起）     || 1.定义报表查询的工序计划中工序的计划开始时间范围的起始日期。\\ 2.默认为当前系统日期之前15天，可以修改。                                |
| 计划开始日期（至）     || 1.定义报表查询的工序计划中工序的计划开始时间范围的终止日期 。\\ 2.默认为当前系统日期之后15天，可以修改。                               |
| 计划结束日期（起）     || 定义报表查询的工序计划中工序的计划结束时间范围的起始日期。                                                           |
| 计划结束日期（止）     || 定义报表查询的工序计划中工序的计划结束时间范围的终止日期。                                                           |
| 单据类型          || 生产订单的单据类型，枚举值，列出启用工序跟踪的单据类型 ，默认全选。                                                      |
| 工序状态          || 1.工序计划分录工序的工序状态；\\ 2.枚举值：计划确认、下达、开工、完工、关闭。                                              |
| 生产订单（起止）      || 生产订单的编号；定义报表查询的生产订单范围。\\ 可以直接录入查询范围进行模糊查询，也可以F8选取生产订单范围查询。                              |
| 产品编码（起止）      || 生产订单分录行的物料编码；定义报表查询的产品编码范围。\\ F8选取产品编码范围。                                               |
| 计划跟踪号（起止）     || 定义生产订单分录行的计划跟踪号范围；直接手工录入计划跟踪号范围进行模糊查询。                                                  |
| 销售订单号（起止）     || 定义生产订单分录行的销售订单号范围。\\ 销售订单号：委托当前生产组织生产的货主组织的销售订单编号；\\ 可以直接录入查询范围进行模糊查询，也可以F8选取销售订单范围查询。  |
| 工作中心          || 1.定义报表查询的工序计划工序的工作中心范围；\\ 2.加工组织加工车间下的所有审核未禁用的工作中心。可以F8多选。                              |
| 作业            || 1.定义报表查询的工序计划工序的作业范围；\\ 2.加工组织下的所有审核未禁用的作业。可以F8多选。                                      |
| 拖期状态          || 1.定义报表查询的工序计划中工序是否拖期。\\ 2.枚举值：正常、拖期开工、拖期完工。                                             |
| 关键工序          || 定义报表是否查询关键工序。\\ 枚举值：是、否。“是”代表只查询关键工序的进度情况。                                              |
| 生产订单挂起        || 生产订单分录行的挂起状态。\\ 枚举值：是、否。系统默认值“否”。                                                       |

**报表字段**

| **字段**     || **说明**                                                                                                              |
| 生产组织       || 生产订单分录行的生产组织，默认隐藏。                                                                                                  |
| 生产车间       || 生产订单分录行的生产组织，表示生产订单分录行的主责车间。                                                                                        |
| 单据编号       || 工序计划的单据编号，默认隐藏。                                                                                                     |
| 生产订单编号     || 符合过滤条件的所有生产订单的编号。                                                                                                   |
| 生产订单行号     || 符合过滤条件的所有生产订单行号。                                                                                                    |
| 产品编码       || 生产订单分录行对应的【物料编码】。                                                                                                   |
| 产品名称       || 生产订单分录行对应的【物料名称】。                                                                                                   |
| 规格型号       || 生产订单分录行对应的【规格型号】。                                                                                                   |
| 序列号/描述     || 工序计划的序列号和描述，默认隐藏。                                                                                                   |
| 工序号        || 工序计划相应序列号下的工序号。                                                                                                     |
| 作业         || 工序计划工序对应的作业。                                                                                                        |
| 加工组织       || 工序计划工序的加工组织，默认隐藏。                                                                                                   |
| 加工车间       || 工序计划工序的加工车间。                                                                                                        |
| 工作中心       || 工序计划工序的工作中心。                                                                                                        |
| 工序说明       || 当前工序的说明，默认隐藏。                                                                                                       |
| 关键工序       || 当前工序是否为关键工序，默认隐藏。                                                                                                   |
| 工序状态       || 当前工序的工序状态，包括：计划确认、下达、开工、完工、关闭                                                                                       |
| 计划开始时间     || 当前工序计划工序的计划开始时间，在工序任务下达之前由工序排程或人工给定。                                                                                |
| 计划结束时间     || 当前工序计划工序的计划结束时间，在工序任务下达之前由工序排程或人工给定。                                                                                |
| 实际开始时间     || 当前工序计划上工序的实际开始时间，依据当前工序的实际准备开始时间、实际加工开始时间到的，工序计划上这几个时间是工序汇报单审核时反写。                                                  |
| 实际结束时间     || 当前工序计划上工序的实际结束时间，依据当前工序的实际加工完成时间、实际拆卸完成时间到的，工序计划上这几个时间是工序汇报单审核时反写。                                                  |
| 工序数量       || 工序计划的工序数量。                                                                                                          |
| 转入数量       || 显示工序计划该工序的转入数量，由转移单审核时反写，首序在工序计划审核时写入，默认等于工序数量。                                                                     |
| 合格数量       || 当前工序的累计合格数量，由工序汇报单审核时反写到工序计划。                                                                                       |
| 废品数量       || 当前工序的累计工废+料废数量，由工序汇报单审核时反写到工序计划。                                                                                    |
| 废品率        || 废品率=废品数量/（合格数量+废品数量）                                                                                                |
| 在制数量       || 在制数量=转入数量 - 合格数量 - 废品数量 - 返工转出数量                                                                                    |
| 转出数量       || 显示工序计划中该工序的转出数量，由工序转移单审核反写。                                                                                         |
| 返工转出数量     || 通过返工序列转出的数量。                                                                                                        |
| 待交数量       || 汇报合格但是没有转移到下道工序的数量。7.3.1395.1补丁修改逻辑如果是非入库点工序，沿用待交数量=合格数量-转出数量；如果是入库点工序，待交数量=合格数量-汇总工序汇报.合格品入库选单数量-汇总工序转移单.合格入库选单数量  |
| 工序单位       || 工序计划中当前工序的工序计量单位。                                                                                                   |
| 定额工时       || 工序计划中所有工序活动计划总量之和。                                                                                                  |
| 实际工时       || 工序计划中所有工序活动已汇报量之和。                                                                                                  |
| 计划跟踪号      || 工序计划对应生产订单分录行的计划跟踪号。                                                                                                |
| 销售订单号      || 工序计划对应生产订单分录行的销售订单号。                                                                                                |
| 生产订单挂起     || 工序计划对应生产订单分录行是否挂起状态。                                                                                                |
| 拖期状态       || 工序计划当前工序是否拖期，拖期状态：正常（即未拖期）、拖期开工、拖期完工。拖期开工的数据行的底色显示为黄色，拖期完工的数据行的底色显示为橙色。                                             |
| 拖期天数       || 工序计划当前工序的拖期天数，默认隐藏。拖期状态为“拖期开工”时，拖期天数=系统日期-计划开始日期拖期状态为“拖期完工”时，拖期天数= isnull（实际完工日期，系统日期）-计划完成日期                       |
| 单据类型       || 生产订单的单据类型。                                                                                                          |

**操作说明**

  - 系统支持查询结果的打印、引出和刷新等通用操作，用户可以点击菜单的【选项】按钮，设置查询的数据列为零是否显示、数据列尾零是否显示以及查询时是否首先弹出过滤界面等。
  - 联查单据：选定查询结果某一行，点击菜单的【联查单据】，系统打开指定行的工序进度计划界面，供用户查看详细信息。用户需要有工序进度计划的查看权限。
