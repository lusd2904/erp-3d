====== 1.功能说明 ======

用户根据原始单据录入记账凭证，系统在凭证录入界面提供多个选项设置，用户自定义数据校验规则以及录入时的编辑控制等。

使用[[凭证查询|凭证查询]]功能查询和管理已录入的凭证，可以对凭证进行整理、冲销、联查单据和业务凭证等多个操作。

用户可以录入凭证时指定现金流量，具体指定的操作可参见[[凭证指定现金流量|凭证指定现金流量]]。

用户对凭证进行审核的操作参见[[凭证审核|凭证审核]]。

用户对凭证进行出纳复核的操作参见[[出纳复核|出纳复核]]。

支持凭证保存后自动指定现金流量。给期末调汇凭证指定现金流量时允许原币为0。


**操作前提**

设置账簿、科目、凭证字以及总账管理参数等基础信息。

**功能路径**

【财务会计】－>【总账】－>【凭证管理】－>【凭证录入】

====== 2.字段说明 ======
^ 字段             |^ 说明                                                                                                                                                                ^
| 账簿             || 设置凭证所在账簿，账簿必须已审核且未被禁用。                                                                                                                                            |
| 日期             || 设置凭证日期，该日期是指记账日期。系统不允许录入账簿已结账期间内的日期作为凭证日期，允许录入账簿当前期间以及以后期间的凭证。\\ 如果勾选了总账系统参数<允许录入凭证的未来期间数>，系统检查凭证日期所在期间若超过允许录入的最大期间数，则不允许保存。                                      |
| 业务日期           || 设置凭证的业务发生日期。业务日期默认与凭证日期一致，修改凭证日期后会自动更新业务日期，但修改业务日期后不会更新凭证日期。                                                                                                      |
| 凭证字            || 从基础资料凭证字中选择需要设置的凭证字，系统默认显示账簿关联的凭证字。                                                                                                                               |
| 凭证号            || 系统根据总账系统参数的凭证号排列规则自动生成凭证号。\\ 如果勾选了总账系统参数<不允许手工修改凭证号>，则用户不能修改此字段；如果允许手工修改，用户则可以修改系统自动生成的凭证号。\\ 另外，系统自动根据排列规则显示当前账簿的断号列表，用户可以手工录入凭证号也可以选择下拉列表的断号。\\ 支持对凭证编号设置编码规则。  |
| 附件数            || 设置凭证录入后以附件的形式备份原始单据的数量。                                                                                                                                           |
| 序号             || 记录了凭证录入的原始顺序，序号不会因凭证的删除而改变。                                                                                                                                       |
| 摘要             || 录入凭证分录的备注信息，可从基础资料摘要库中选择，也可手工录入。                                                                                                                                  |
| 科目编码           || 录入凭证分录的科目。  修改科目后，保留已经录入且新科目可用的核算维度。                                                                                                                              |
| 科目全名           || 录入凭证分录的科目全名。                                                                                                                                                      |
| 核算维度           || 录入会计科目关联的核算维度信息，此处的核算维度是指科目属性中核算维度组包含的核算维度信息。核算维度是否必录、录入的值范围均以核算维度组中的设置为准。核算维度维度录入支持基础资料其他字段（编号和名称以外的字段）的模糊查询。核算维度维度录入支持基础资料其他字段（编号和名称以外的字段）的模糊查询。                |
| 币别、汇率类型和汇率     || 当会计科目设置外币核算时或选中工具栏“选项”菜单组下的【外币】时，才显示该三列字段。\\ 系统默认显示账簿的记账本位币、默认汇率类型和汇率。如果勾选了总账系统参数<凭证中的汇率允许手工修改>，则用户可以修改汇率；否则，只能使用汇率体系中的汇率信息。                                      |
| 借方金额、贷方金额      || 录入科目对应的金额信息，每条凭证分录只允许录入借方金额或贷方金额。                                                                                                                                 |
| 结算方式、结算号       || 录入银行存款科目的结算方式和结算单据的号码。当勾选了总账系统参数<银行存款科目必须录入结算方式和结算号>时。用户必须录入；否则，用户根据实际情况选择是否录入。                                                                                   |
| 单位、单价和数量       || 当会计科目要进行数量金额核算时，系统会自动弹出数量格式让用户录入。单位系统会根据会计科目属性中提供的内容自动出现，用户只要录入单价和金额即可。\\ 系统会检验数量单价的乘积是否与原币金额相等，如不相等，系统会提示是否继续。                                                   |
| 业务编号           || 录入往来科目的业务编号。当勾选了总账系统参数<往来科目必须录入业务编号>时。用户必须录入；否则，用户根据实际情况选择是否录入。                                                                                                   |

====== 3.操作说明 ======
  * 在客户端进行凭证录入，支持以下快捷键:

金额列按空格键：借贷金额互换

金额列按Esc键：清空金额

金额列按等号键：自动计算（找平）

摘要列按双点号键(..)：自动复制上一行的摘要

摘要列按双斜线键(⁄⁄)：自动复制第一行的摘要

  * 【客户端】核算维度文本框按回车键后系统自动弹出核算维度录入界面，光标自动定位到第一个核算维度录入框，录入相应的维度后再按回车自动跳到下一个维度录入框或确认按钮上。

  * 体验新版：通过H5端打开凭证录入后，点击【体验新版】按钮后切换到新版凭证录入界面。

  * 返回旧版：在新版凭证录入界面，点击【返回旧版】按钮后切换回旧版的凭证录入界面。

  * 核算维度的【批量录入】：用于同一科目多个不同维度值的场景。录入科目后，点击该按钮，在核算维度批量录入界面多选维度值确定后一次性填充到各分录行，实现手工快速录入凭证的多个维度值。【V9.0新增】

====== 4.业务说明 ======
**业务编号查询**

录入凭证时，输入往来科目后可以手工录入业务编号，也可以通过调用业务编号查询界面查询并返回与当前科目、核算维度相关的业务编号。

**凭证选项**

凭证录入界面的【选项】菜单，提供了录入的公共参数以及业务参数控制。
^ 业务参数                         |^ 说明                                                                                                            ^
| 保存单一币别的凭证进行原币平衡校验                   || 选中此项，保存单一币别的凭证时系统会检查原币金额是否借贷平衡。如果不平衡，系统不予以保存凭证。                                                           |
| 每一条分录录入完成后自动检查               || 选中此项，每录入一行分录后，系统检查分录中各栏目字段的合法性。如果不合法，系统不予以保存凭证。                                                               |
| 保存检查附件数                      || 选中此项，凭证保存时系统检查附件数是否为空白。如果为空白，系统不予以保存凭证。                                                                       |
| 结算方式和结算号重复报警                 || 选中此项，凭证保存时系统检查银行存款科目分录的结算方式和结算号是否重复。如果重复，系统不予以保存凭证。                                                           |
| 自动携带                         || 设置新增分录时，需要默认携带上一条分录的字段内容。                                                                                     |
| 单价不随金额计算                     || 在单价、数量和金额已经存在时，改变金额（包括原币和本位币），单价将不随着金额的改变而改变。如果此时“单价*数量≠金额”，则在保存时给出提示：“数量乘以单价不等于原币金额！是否继续？”，由用户自己决定是否需要手工调整。  |
| 凭证修改本位币后，重算：原币/汇率/不重算             || 凭证修改本位币后，可选择重算原币、重算汇率或不重算。                                                                                        |
| 凭证修改原币（汇率）后，重算：本位币/汇率（原币）/不重算     || 凭证修改原币（汇率）后，可选择重算本位币、重算汇率（原币）或不重算。                                                                                |
| 复制凭证后，重算：原币/本位币             || 复制凭证后，可选择重算原币或重算本位币。                                                                                        |
| 凭证光标定位字段                     || 下拉列表，可选账簿、日期、附件、摘要和科目。设置此项后，凭证新增时光标会自动定位到指定的字段。                                                               |
| 新增凭证时取系统日期                   || 选中此项，新增凭证时默认取系统日期，只有当系统日期不允许录入凭证（历史期间或不允许录入凭证的未来期间的日期等）才更新日期到当前期间的最后一天；连续新增凭证也优先取系统日期，只有系统日期不合法时才携带上一张凭证的日期。  |
| 打开现金流量指定界面时自动指定现金流量          || 选中此项，如果凭证尚未指定现金流量，在打开现金流量界面时根据科目上面预置的现金流量项目自动指定现金流量。                                                          |
| 保存前自动删除金额为零的分录行          || 选中此项，保存凭证前自动删除没有录入金额的分录行，引入凭证时忽略金额为零的分录行。                                                         |
| 科目关联【物料】核算维度时，自动填充物料的基本单位           || 选中此项，录入物料核算维度会自动填充物料的基本单位。  |
