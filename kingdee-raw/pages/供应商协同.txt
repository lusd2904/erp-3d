====== 1供应商协同概述 ======

===== 1.1 供应商协同系统概述 =====
供应商协同平台是企业与供应商之间进行业务协同的基础系统。企业可以在此平台上建立自身的供应链体系，实现供需双方的在线业务协同。供应商协同平台总体目标是充分整合供应链资源，帮助供需双方进行实时高效的业务协同，不断提高供应链的竞争力。

金蝶AI星空供应商协同平台基于金蝶AI星空 BOS开发，且与金蝶AI星空采用相同的数据中心，保障了企业数据与供应商数据的实时性和一致性。同时，基于BOS强大的开发能力，为企业的个性化应用提供良好的技术支撑。

金蝶AI星空供应商协同模块主要功能包括：询报价协同、订单协同、交货协同、库存协同、信息协同等功能。

====== 2供应商协同业务专题 ======

===== 2.1 寻源协同 =====
采购寻源方式主要有询报价、招投标、在线竞价等三种方式，其中询报价是一种较常见的寻源方式。金蝶AI星空供应商协同系统支持询报价的寻源方式。

询价采购是指对几个供货商（通常至少三家）的报价进行比较以确保价格具有竞争性的一种采购方式。询价采购特点：
  * 特点一、邀请报价的供应商数量至少为三家；
  * 特点二、只允许供应商提供一个报价。每一供应商或承包商只许提出一个报价，而且不许改变其报价。不得同某一供应商或承包商就其报价进行谈判。报价的提交形式，可以采用在线报价、电传或传真形式；
  * 特点三、报价的评审应按照买方公共或私营部门的良好惯例进行。采购合同一般授予符合采购实体需求的最低报价的供应商或承包商。

===== 2.2 订单协同 =====
采购订单是指企业采购部门在选定供应商之后，向供应商发出的订货单据。采购订单是采购双方订立采购合同的重要依据，它包括了采购所需的重要细节信息，包括采购数量、商品规格、质量要求、采购价格、交货日期、交货地址等。

采购订单是存货在采购业务中流动的起点，是详细记录企业物流的循环流动轨迹。通过它可以直接向供应商订货并可查询采购订单的收货情况和订单执行状况，通过采购订单的关联跟踪，采购业务的处理过程可以一目了然。

因此，订单协同是企业与供应商之间非常重要的业务协同。金蝶AI星空订单协同的主要功能包括：采购订单协同、采购订单变更协同、采购订单执行情况查询等。

===== 2.3 交货协同 =====
在供应链运作过程中，及时准确的交货，对于保障供应链的效率起到至关重要的重要。企业制定交货计划，供应商及时知悉交货计划，并交货计划进行交货。在供应商管理库存模式（VMI模式）中，交货计划也可以由供应商发起。

交货管理包括正向的交货管理和逆向的退货管理。金蝶AI星空交货协同主要功能包括：发货通知单、采购入库单、退货通知单和采购退料单等。

===== 2.4 库存协同 =====
随着市场竞争的加剧，为了提升供应链效率，企业和供应商建立了更紧密的战略合作关系，采用更有效的库存管理模式，如VMI模式，在此模式中，供应商和用户企业按一定的方式共享企业的库存和耗用数据（对制造企业，一般指生产领用；对商贸企业，一般指销售出货），按照一定的补货策略，自主决定供货计划，对用户企业进行快速有效地补货。

在VMI模式下，供应商需要及时查询VMI物料的库存情况和出入库情况，以便进行快速有效的补货。供应商还需要查询VMI物料的消耗及结算情况，以便进行财务核算和对账。

金蝶AI星空库存协同主要功能包括：VMI即时库存查询、VMI出入库汇总表、VMI消耗汇总表、VMI消耗结算明细表等。

===== 2.5 信息协同 =====
在企业与供应商的业务协同过程中，如询报价、订单确认与变更、交货协同、财务结算等，都会产生大量的消息（任务消息、监控消息、普通消息和工作流消息等），这些消息可以集中在供应商的信息中心进行查询和处理，提高业务处理的及时性。此外，企业可以在供应商协同平台上发布公告，供应商通过协同平台在线查询，加强双方的信息共享。

金蝶AI星空信息协同主要功能包括：企业公告发布、企业公告查询、企业的信息中心管理和供应商的信息中心管理等。

====== 3供应商协同操作手册 ======

===== 3.1基础设置 =====

==== 3.1.1供应商协同系统参数设置 ====
在数据中心级设置供应商协同的系统参数，包括是否启用供应商协同模块，应用服务器的IP地址、站点名称、虚拟目录等。因为该参数影响整个供应商协同系统，所以要求以系统管理员的身份登录后再进行设置。详细介绍见[[供应商协同参数设置]]

==== 3.1.2 供应商设置 ====
在数据中心级启用供应商协同平台后，还要针对某个具体的供应商，设置其是否启用供应商协同平台。详细介绍见[[供应商]]设置
==== 3.1.3 供应商角色 ====
供应商登录协同平台后，只能操作供应商协同模块的相关功能。可以由企业统一创建供应商角色，并对角色进行授权，然后再分配给具体的供应商用户。详细介绍见[[供应商角色]]
==== 3.1.4 供应商用户 ====
各供应商登录到供应商协同平台的用户，需要由企业统一创建和管理。详细介绍见[[供应商用户]]
==== 3.1.5 供应商注册资料列表 ====
供应商注册资料的列表，包含当前用户查询权限范围内的所有供应商注册资料；详细介绍见[[供应商注册资料]]

==== 3.1.6 供应商协同用户 ====
在供应商协同平台，以供应商用户登录，该供应商设置的用户即为供应商协同用户。
===== 3.2寻源协同 =====
采购寻源方式主要有询报价、招投标、在线竞价等三种方式，其中询报价是一种较常见的寻源方式。金蝶AI星空供应商协同系统支持询报价的寻源方式。
==== 3.2.1 询价单(企业) ====
询价单是询报价流程的起点。企业手工创建询价单，或从采购申请单下推生成询价单，从而启动询报价流程。详细介绍见[[询价单]](企业)
==== 3.2.2 询价单查询(供应商) ====

企业的询价单审核后，供应商可以在协同平台进行查询和确认。确认信息将回写到询价单【适用供应商】的供应商已确认、确认日期。详细介绍见[[询价单]]列表
==== 3.2.3 报价单(供应商) ====
供应商收到企业的询价单之后，可以根据询价单下推生成报价单，一张询价单只能下推一张报价单，不支持多次下推。详细介绍见[[报价单]](供应商)
==== 3.2.4 报价单查询(企业) ====

供应商的报价单审核后，企业可以在采购管理中进行查询，并进行确认。详细介绍见[[报价单]]查询（企业）
==== 3.2.5 比价单(企业) ====
企业根据询价单、供应商报价单和采购历史价格信息，进行对比分析，确定采纳的价格和供应商。比价单审核后，相关信息自动回写询价单和报价单。经过比价后的询价单，可以下推采购订单。详细介绍见[[比价单]]（企业）
===== 3.3订单协同 =====
采购订单是企业与供应商之间最重要的业务协同媒介，订单协同是企业与供应商之间最重要的业务协同。金蝶AI星空订单协同的主要功能包括：采购订单协同、采购订单变更协同、采购订单执行情况查询等。此外，企业可在采购管理中处理采购订单、采购订单变更单、采购订单执行明细表、采购订单执行汇总表，其操作同采购管理手册，这里不再重复介绍。
==== 3.3.1 采购订单(供应商) ====
企业的采购订单审核后，供应商可以通过供应商协同平台，在线查询自己的订单，填写相关信息，并进行确认。详细介绍见[[采购订单]](供应商)
==== 3.3.2 采购订单变更单(供应商) ====
企业的采购订单变更单审核后，供应商可以通过协同平台，在线查询采购订单变更单，填写相关信息，并进行确认。详细介绍见[[采购订单变更单]](供应商)。

==== 3.3.3 采购订单新变更单(供应商) ====
企业的采购订单新变更单审核后，供应商可以通过协同平台，在线查询采购订单新变更单，填写相关信息，并进行确认。详细介绍见[[采购订单新变更单]](供应商)
==== 3.3.4 订单执行情况查询(供应商) ====
供应商通过协同平台，在线查询采购订单执行的明细情况及汇总情况。

  * 功能说明
  - 供应商可以查询采购订单执行的明细情况。
  - 供应商可以查询采购订单执行的汇总情况。
  - 对数据进行严格过滤，仅显示该供应商的订单执行数据
  * 功能操作
  - 供应商登录供应商协同平台，进入供应商协同—订单协同—采购订单执行明细表，设置过滤条件，查询相关数据。
  - 供应商登录供应商协同平台，进入供应商协同—订单协同—采购订单执行汇总表，设置过滤条件，查询相关数据。
  * 业务说明
  - 供应商随时查询订单执行情况，发现问题及时处理，提升采购订单履约率。
  - 对订单执行情况进行统计分析，为经营决策提供依据。
  - 
详细介绍见[[采购订单执行明细表]]和[[采购订单执行汇总表]]

==== 3.3.5 供应商采购追料交货报表 ====
当缺料分析产出追料计划后，会在追料计划中体现采购订单的送货计划，生成的送货计划与采购订单中的交货安排存在差异，企业按照此生产追料分析进行追料，供应商协同中供应商依据此追料计划进行送货。
详细介绍见[[供应商协同采购追料交货报表]]
==== 3.3.6 供应商评估报告 ====
对供应商评分的结果，详细介绍见[[供应商评估报告]]

==== 3.3.7 供应商交货及时率报表 ====
供应商交货及时率查询报表主要用于查询当前供应商所有订单的准时交货的情况，根据交货日期和入库/收料日期之间的关系判断订单是否逾期交货，可以根据批数和数量进行查询，查询逾期交货批数/数量和交货及时率的情况。

详细信息见：[[供应商到货及时率报表]]

===== 3.4交货协同 =====
在供应链运作过程中，及时准确的交货，对于保障供应链的效率起到至关重要的重要。企业制定交货计划，供应商及时知悉交货计划，并交货计划进行交货。在供应商管理库存模式（VMI模式）中，交货计划也可以由供应商发起。

交货管理包括正向的交货管理和逆向的退货管理。金蝶AI星空交货协同主要功能包括：发货通知单、采购入库单、退货通知单和采购退料单等。此外，企业可在采购管理中处理收料通知单、采购入库单、退料申请单和采购退料单，其操作同采购管理手册，不再重复介绍。

==== 3.4.4 采购退料单(供应商) ====
企业的采购退料单审核后，供应商通过协同平台，在线查询采购退料单，并进行确认。详细介绍见[[采购退料单]]

企业的来料检验单审核后，供应商通过协同平台，在线查询来料检验单。详细介绍见[[来料检验单]]


===== 3.5 库存协同 =====
在VMI模式下，供应商需要及时查询VMI物料的库存情况和出入库情况，以便进行快速有效的补货。供应商还需要查询VMI物料的消耗及结算情况，以便进行财务核算和对账。

金蝶AI星空库存协同主要功能包括：VMI即时库存查询、VMI出入库汇总表、VMI消耗汇总表、VMI消耗结算明细表等。此外，企业方可在采购管理中查询这些信息，其操作同采购管理手册，这里不再重复介绍。

==== 3.5.1 VMI即时库存查询 ====
供应商通过协同平台，在线实时查询VMI物料的即时库存状况，以及VMI物料的出入库汇总情况。详细介绍见[[供应商协同即时库存查询]]

==== 3.5.2VMI出入库汇总表 ====

VMI采购业务通常涉及企业采购、仓储、消耗等多个相关部门。仓库部门管理人员需要跟踪物料出入库汇总情况，及时掌握库存情况并进行必要的统计分析，VMI物料出入库汇总表即是查询VMI物料出入库汇总的报表。详细介绍见[[供应商协同VMI出入库汇总表]]
==== 3.5.3VMI出入库明细表 ====

VMI采购业务通常涉及企业采购、仓储、消耗等多个相关部门。仓库部门管理人员需要跟踪物料出入库的情况，及时掌握库存情况并进行必要的统计分析，VMI物料出入库明细表即是查询VMI物料出入库明细的报表。详细介绍见[[供应商协同VMI物料出入库明细表]]

==== 3.5.4VMI消耗汇总表 ====

企业消耗掉供应商的物料后，需要定期进行消耗统计，确定数量、价格等商务信息作为后续应付业务的依据。详细介绍见[[供应商协同VMI消耗汇总表]]

==== 3.5.5VMI消耗结算明细表 ====

VMI采购业务通常涉及企业采购、仓储、消耗、结算等多个相关部门。结算部门管理人员需要跟踪消耗物料的结算情况，及时掌握业务进展情况并进行必要的统计分析，VMI物料消耗结算表即是跟踪VMI消耗物料结算情况的报表。详细介绍见[[供应商协同VMI消耗结算明细表]]
==== 3.5.6 供应商协同VMI物料收发明细表 ====
供应商协同新增VMI物料收发明细表，支持查看物料的期初，期末结存，收入，发出库存数量，按供应商进行数据隔离查询。详细字段逻辑介绍见[[物料收发明细表]]

===== 3.6信息协同 =====
在企业与供应商的业务协同过程中，如询报价、订单确认与变更、交货协同、财务结算等，都会产生大量的消息（任务消息、监控消息、普通消息和工作流消息等），这些消息可以集中在供应商的信息中心进行查询和处理，提高业务处理的及时性。此外，企业可以在供应商协同平台上发布公告，供应商通过协同平台在线查询，加强双方的信息共享。

金蝶AI星空信息协同主要功能包括：企业公告发布、企业公告查询、企业的信息中心管理和供应商的信息中心管理。

==== 3.6.1 企业公告发布(企业) ====
企业在供应商协同平台创建企业公告，公告审核后，供应商可以在线查询相关的公告。详细介绍见[[企业公告]]
==== 3.6.2 企业公告查询(供应商) ====

企业公告审核后即发布，供应商可以在协同平台进行查询。
  * 功能说明
  - 企业公告发布后，供应商可以在供应商协同平台查询到相关的公告。
  - 对数据进行严格过滤，仅显示该供应商的相关公告。

  * 功能操作
  - 供应商登录供应商协同平台，进入 供应商协同—信息协同—企业公告。
  - 查询相关的公告，当该公告有附件时，通过 选项—附件，查看附件。
  * 业务说明
  - 企业公告方便企业与供应商之间进行高效的信息共享。

详细介绍见[[企业公告]]
==== 3.6.3 信息中心& 第三方消息服务(供应商) ====
供应商通过信息中心，集中查看和处理各项消息，提高工作效率。详细信息见[[信息中心]]

  * 功能说明
  - 供应商在询报价、订单执行等业务过程中所产生的各种信息，都会集中反映到信息中心，便于查询和处理。
  - 企业在与供应商的业务互动过程中所产生的信息，也会反映在供应商的信息中心，便于供应商查询和处理。
  - 对数据进行严格过滤，仅显示该供应商的信息。
  * 功能操作
  - 供应商登录供应商协同平台，进入 供应商协同—信息协同—信息中心。
  - 查询和处理各种信息，包括任务消息、监控消息、普通消息、工作流消息等。
  * 业务说明
  - 供应商可以实时掌握待处理任务、待处理流程以及各种消息，及时进行处理。
  - 实现企业与供应商之间的实时信息沟通，有效提升业务协同效率。

[[第三方消息]]服务配置说明详细信息请参考[[第三方消息]]服务配置
===== 3.7财务协同 =====
==== 3.7.1暂估应付单列表 ====
供应商可以通过供应商协同平台查看自己的单据类型是标准应付单，业务类型是暂估应付的应付单，用于供应商开票的依据，具体可见[[应付单]]
==== 3.7.2财务应付单列表 ====
供应商可以在供应商协同平台通过暂估应付单下推生成财务应付单，保存后企业可以通过企业端查看到这张财务应付单，用于供应商开票，具体可见[[应付单]]

==== 3.7.3应付单列表 ====

供应商可以在供应商协同平台通过应付单列表查看暂估应付单和财务应付单。
==== 3.7.4付款申请单列表 ====
企业付款之前如果需要先进行申请，付款申请单即能实现该功能。供应商协同平台可通过付款申请单列表查看对应的付款申请单。详细介绍见[[供应商协同平台付款申请单列表]]



===== 3.8对账协同 =====

==== 3.8.1采购对账方案 ====
采购对账方案由企业方创建，供应商在供应商协同平台根据采购对账方案确定的对账范围、对账方式等信息发起对账。
详见[[采购对账方案]]

==== 3.8.2采购对账单 ====
企业或供应商根据对账方案发起对账，双方通过线上数据的对账可以快速地实现对账信息的确认以及业务数据的调整，并支持由企业根据对账结果生成下游财务单据。

详见[[采购对账单]]

==== 3.8.3应付款明细表 ====
应付款明细表主要是用来反映某段时间内与往来单位的期初余额、本期应付数、本期实付数、期末余额等数据的明细信息。详情见[[应付款明细表]]
==== 3.8.4应付款跟踪表 ====

应付单跟踪表是用来查询与应付业务有关的各种信息的报表，例如应付单的订单情况、入库情况、开票情况、付款情况等等。

详细描述请见：[[应付单跟踪表]] 
==== 3.8.5往来对账明细表 ====

往来对账对账明细表所展示的数据与应付款明细表基本相同，只是当往来单位既是客户有是供应商时，往来对账对账明细表可以将与该往来单位的所有往来都列示出来。

详细描述请见：[[往来对账明细表|往来对账明细表]] 

==== 3.8.6应付未开票明细表 ====

应付未开票明细表反映企业与供应商当期应付的开票情况，包括本期未开票情况，截止日期未开票情况，支持按物料明细显示。

详细描述请见：[[应付未开票明细表]] 



==== 3.8.7应付单开票核销明细表 ====

应付单开票核销明细表反映企业与供应商当期应付单的开票核销明细情况，包括本期未开票核销情况，截止日期未开票核销情况，按应付单的明细分录显示。

详细描述请见：[[应付单开票核销明细表]] 


===== 3.9条码协同 =====
==== 3.9.1供应商协同条码打印 ====

条码生成和保存后，选择所需要打印的条码记录行，进行批量打印。在打印之前，可以进行条码预览。详细介绍见[[供应商协同条码打印]]
==== 3.9.2 供应商协同条码扫描 ====

供应商按要求送货至企业后，企业的收料人员通过扫描货物上的条码，快捷生成收料通知/请检单/采购入库单。产品入库时，也可以通过扫描产品上的条码，快捷生成产品入库单。因此，在企业很多业务场景中，都需要用到条码扫描功能。详细介绍参考[[供应商协同条码扫描]]

==== 3.9.3 供应商协同条码打印日志 ====

当条码管理系统参数设置为“自动保存生成记录”时，每批的条码生成及打印操作，都会自动保存为一张单据，该单据可以通过条码打印日志查询。此外，在条码打印界面，点“保存”，也会保存为一张单据。详细介绍参考[[条码打印]]

==== 3.9.4 供应商协同条码主档 ====

供应商协同支持供应商查询条码主档，支持对条码主档进行查询，筛选。系统强制对条码主档按供应商进行过滤，详细介绍参考[[条码主档]]
