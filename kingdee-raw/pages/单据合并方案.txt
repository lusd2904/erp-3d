====== 单据合并方案 ======

**功能概述**

用于配置不同单据合并关系，凭证生成按选择不同单据合并生成凭证时可以选择单据合并方案，实现不同单据按业务场景自动合并生成总账凭证。


**功能路径**

【财务会计】－>【智能会计平台】－>【基础资料】－>【单据合并方案】

**字段说明**


| **位置**   | **字段**  | **说明**                                                                                                                                                                                                                                                                                                                                               |
| 基本信息     | 编码      | 按编码规则自动生成                                                                                                                                                                                                                                                                                                                                            |
| :::      | 名称      | 定义方案名称                                                                                                                                                                                                                                                                                                                                               |
| :::      | 适用账簿    | 可以指定需要                                                                                                                                                                                                                                                                                                                                               |
| 单据合并设置   | 合并方式    | 目前支持以下合并方式\\ 合并方式为全部汇总：取全部汇总主单据和关联单据全部合并生成一张总账凭证\\ 合并方式为费用报销核销关系：取费用核销记录相同序号的主单据和关联单据合并生成一张总账凭证\\ 合并方式为应付付款核销关系：取应付付款核销记录相同序号的主单据和关联单据合并生成一张总账凭证\\ 合并方式为应付开票核销关系：取应付开票核销记录相同序号的主单据和关联单据合并生成一张总账凭证\\ 合并方式为应收收款核销关系：取应收收款核销记录相同序号的主单据和关联单据合并生成一张总账凭证\\ 合并方式为应收开票核销关系：取应收开票核销记录相同序号的主单据和关联单据合并生成一张总账凭证\\ 合并方式为自定义匹配关系：取符合自定义设置的匹配关系的主单据和关联单据合并生成一张总账凭证  |
| :::      | 主单据     | 选择需要合并的主单据                                                                                                                                                                                                                                                                                                                                           |
| :::      | 关联单据    | 选择需要合并的关联单据                                                                                                                                                                                                                                                                                                                                          |
| :::      | 不符合条件的单据不生成凭证      | 勾选时，主单据和关联单据找不到合并关系的单据不生成总账凭证                                                                                                                                                                                                                                                                                                                                           |
| :::      | 备注      | 对合并关系的备注描述                                                                                                                                                                                                                                                                                                                                           |
| 自定义匹配规则  | 主单据字段   | 当合并方式为自定义匹配关系，选择主单据和关联单据匹配字段，可以设置多个关联字段                                                                                                                                                                                                                                                                                                              |
| :::      | 关联单据字段  | :::                                                                                                                                                                                                                                                                                                                                                  |

选择预设关系：系统预设不同单据的合并关系，可以按需选择。

**举例说明**
同一笔费用报销单生成的费用报销应付和付款单合并生成总账凭证
