====== 1.功能说明 ======

本功能用于自定义新增经营单元费用分摊规则。

**功能路径**

【管理会计】－>【经营会计】－>【内部分摊】－>【自定义分摊规则】。
====== 2.字段说明 ======

| **位置**     || **字段**  | **说明**                                |
| 表头基本信息     || 名称      | 设置自定义分摊规则名称。                          |
| 表头基本信息     || 账簿      | 为空表示所有账簿均可使用该分摊规则，录入账簿信息则表示仅该账簿可以使用，按经营科目定义分摊规则时，账簿必录。  |
| 表头基本信息     || 分摊规则      | 可选择按经营科目定义、按已有规则组合定义、按经营科目+核算维度定义。  |
| 表头基本信息     || 交易类型      | 选择分摊规则按经营科目定义时必录，默认全部勾选，可选择按经营科目定义时权重来源的交易类型。  |
| 表头基本信息     || 取数类型      | 选择分摊规则按经营科目定义时必录。取数类型为期初余额，期末余额，本期增加，本期减少时公式只能选资产和负债类别的科目。取数类型为本期发生额，本期计划值，上期发生额，上期计划值时公式只能选损益类别的科目。 |
| 表头基本信息     || 分摊核算维度      | 分摊规则为按经营科目+核算维度定义时，需维护分摊核算维度  |
| 表头基本信息     || 分摊核算维度范围     | 可设置核算维度范围过滤条件，不设置时表示按分摊核算维度的所有值获取分摊权重。  |
| 表头基本信息     || 费用来源核算维度     | 分摊规则为按经营科目+核算维度定义时，可维护费用来源核算维度，主要用于费用归集单有费用承担对象，且费用承担对象为核算维度，需要按费用承担对象再分摊到其他核算维度的场景。  |
| 表头参数     || 分摊权重取值为负数转为正数参与分摊     | 勾选后，如果分摊权重计算结果为负数则转为正数去参与分摊；不勾选时，如果分摊权重计算结果为负数则不参与分摊，分摊权重默认为0  |
| 表体         || 分摊公式    | 用于编辑分摊规则公式，必录。                        |
| 表体         || 公式描述    | 不可编辑，系统自动处理显示为分配规则的计算公式对应的文本描述，必录。    |

====== 3.操作说明 ======

打开【管理会计】－>【经营会计】－>【内部分摊】－>【自定义分摊规则】功能，新增和维护自定义分摊规则。

已被经营单元分摊标准引用的自定义分摊规则不允许删除。\\ 已被费用分摊标准引用的自定义分摊规则，支持反审核分摊标准后，可直接反审核自定义分摊规则进行修改。

系统预置自定义分摊规则，可直接被经营单元分摊标准引用，也可新增自定义分摊规则时引用。
| **预置分摊规则**     || **说明**                                             |
| 实际收入占比         || 当前经营单元当期实际收入合计除以分配标准全部经营单元实际收入合计。                    |
| 计划收入占比         || 当前经营单元当期计划收入合计除以分配标准全部经营单元计划收入合计。                    |
| 投入时间占比         || 当前经营单元投入时间数除以分配标准全部经营单元投入时间数。                        |
| 上期实际利润占比         || 当前经营单元上期（实际收入-实际成本）除以分配标准全部经营单元上期（实际收入-实际成本）合计。                        |
| 当期实际成本占比         || 当前经营单元当期实际成本合计除以分配标准全部经营单元实际成本合计。                        |
