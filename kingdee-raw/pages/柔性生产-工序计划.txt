**功能概述**

工序计划需要支持柔性生产业务，增加现场智能终端反馈，工序计划支持动态排程；

**功能路径**

【车间管理】－>【车间作业计划】－>【工序计划列表】

【智慧车间MES】－>【智慧车间】－>【车间作业计划】－>【工序计划列表】

**字段说明**

| **字段**            || **说明**                                                                                                                                                              |
| 工作中心              || 柔性生产的工序计划，相同序列中的工序，工作中心必须相同；                                                                                                                                        |
| 数据采集顺序            || 携带自作业，用于标识此工序在智能终端的扫码类型及顺序，包括：物料、设备+物料、设备、订单;                                                                                                                       |
| 扫描特征码             || 无/产生单件跟踪号/绑定产品；柔性产线的生产过程中，一般会从某道序开始按单件进行跟踪。\\ 选择产生单件跟踪号，意味着从该工序开始产生一个产品跟踪号，一直跟随产品进行后面工序的加工汇报，这对于扫码汇报至关重要。\\ 柔性产线在生产过程中，并非从第一道工序开始就有产品序列号，工序选择绑定产品意味着在该工序上要产生产品序列号；  |
| 首检、首检状态           || 标识工序是否需要进行首检，及当前首检状态，工序计划下推工序汇报单后变为首检中，检验完成后变为首检完成；目前允许手工维护以便灵活应对异常情况。\\ 注：工序启用首检后，首检未完成时，本工序可继续加工，但后工序不能进行加工汇报；                                                    |
| 首检控制方式            || 首检控制方式：首检控制方式=不严格控制或空，本工序可继续加工，但后工序不能进行加工汇报；首检控制方式=严格控制，本工序及后工序均不能继续加工；                                                                                             |
| 不良返修方式            || 不良返修方式：空、在线返修、线下返修，根据柔性工艺路线携带；\\ 在线返修：线上直接反馈不良情况，生成“工序不良品明细”；\\ 线下返修：线上进行不良汇报，同时反馈不良情况，生成不良“工序汇报单”以及“工序不良品明细”；                                                      |
| 触摸屏录入不良启用位置号      || 触摸屏录入不良启用位置号：勾选，同时定义“零件位置号”，屏端“不良汇报”时可记录不良具体位置；                                                                                                                     |
| 活动量公式、活动汇报量公式     || 携带自柔性工艺路线，可修改；                                                                                                                                                      |
| 工序阶段              || 可将一组工序作为一个阶段，在订单排程时，如果柔性产线选择排程依据为工序计划，将基于首工序阶段做排程                                                                                                                   |
| 首序阶段              || 系统自动维护，工序序列中与首序的工序阶段值相同的连续工序；                                                                                                                                       |
| 联动排程              || 在触发工序开工/工序完工时，自动对之后的工序进行排程                                                                                                                                          |

其它字段说明见[[工序计划|]]
