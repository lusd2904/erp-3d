====== 1 业务监控预警概述 ======
===== 1.1 业务监控预警概述 =====
业务监控预警模块包括业务监控和风险预警，风险预警是V8.0新功能。业务监控是事后的提醒，根据企业自身的监控需求，事后提醒及时处理业务，保证业务的正常运作；而风险预警则是事前和事中的提醒，根据企业风险监测提前告知风险并防范。。

===== 1.2 业务监控特性 =====
业务监控提供了以下功能：
  - 简单配置与插件开发结合，可以满足不同复杂度的业务监控需求； 
  - 多维度的接收人，实现监控人群的组合 ；
  - 支持接收人按权限发送监控消息； 
  - 监控消息的合并主题支持按分组变量和汇总变量，支持四则运算； 
  - 监控消息支持发送邮件和 [[第三方消息]]；
  - 监控明细消息支持跟进方案配置动态显示信息，且明细消息列表支持列表快速过滤、批量处理；
  - 监控消息支持通过方案配置确定是否显示处理；
  - Html5端支持监控卡片和监控工作台的显示；
  - 支持业务监控轻应用接收监控消息；
  - 通过监控方案执行情况可以追溯异常问题； 
  - 监控预警消息支持定期自动清理；
  - 及时发现企业运营中的异常情况，高效解决问题。
===== 1.3 风险预警特性 =====
风险预警提供了以下功能：
  - 预警消息模板配置，消息内容支持PC端和移动端分别设置，满足不同的风险预警需求； 
  - 支持设置业务对象预警规则，规则支持配置触发操作，且支持多个操作；
  - 预警规则支持设置预警条件，为业务对象标准过滤条件； 
  - 支持设置预警方案，启用则有效； 
  - 预警方案支持设置多个预警规则；
  - 每个预警规则可分别设置触发时机、消息模板、消息通道、消息级别、消息接收人；
  - 业务设置了风险预警，则会按照触发操作触发预警规则校验并提醒；
  - 风险预警提醒消息会实时发送；
  - 消息支持发送到移动端的消息轻应用； 

====== 2 业务监控预警操作手册 ======
===== 2.1 业务监控操作手册 =====
===== 2.1.1 监控对象===== 
金蝶云预置了部分监控对象，可以直接配置对应的监控方案使用，也可以根据企业实际情况自定义监控对象。具体见【[[监控对象|监控对象]]】的介绍。

===== 2.1.2 监控方案 =====
通过设置监控方案，可以对业务进行全方位的监控，及时通知关键人员。具体见【[[监控方案|监控方案]]】的介绍。

===== 2.1.3 监控执行情况列表 ===== 
监控执行情况可以查看监控消息发送的情况，以便分析业务监控的执行效率。具体见【[[监控执行情况|监控执行情况]]】的介绍。

===== 2.1.4 业务监控异常提醒 ===== 
有异常的业务监控方案进行提醒展示。具体见【[[业务监控异常提醒|业务监控异常提醒]]】的介绍。

===== 2.1.5 业务监控轻应用 ===== 
通过监控方案的轻应用设置，提供业务监控轻应用的发布，实现业务监控轻应用接收监控消息，同时可以进行业务催收。具体见【[[业务监控轻应用|业务监控轻应用]]】的介绍。

===== 2.2 风险预警操作手册 =====
===== 2.2.1 预警消息模板===== 
风险预警消息提醒内容为消息模板配置内容，具体见【[[预警消息模板|预警消息模板]]】的介绍。

===== 2.2.2 预警规则 =====
预警规则支持业务对象操作触发校验条件，满足预警规则条件即会触发风险预警，具体见【[[预警规则|预警规则]]】的介绍。

===== 2.2.3 预警方案 ===== 
预警方案是基于业务对象的风险预警，方案启用则会按照规则设置触发风险预警，并消息提醒用户，具体见【[[预警方案|预警方案]]】的介绍。

===== 2.2.4 预警方案最新执行情况列表 ===== 
只展示最新的预警方案执行情况，包括预警方案的基本信息、方案是否执行成功和执行描述等。具体见【[[预警方案最新执行情况列表|预警方案最新执行情况列表]]】的介绍。
