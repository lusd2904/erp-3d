# G3 平台与流程需求（可直接并入《需求说明书》）

> **编写依据**：金蝶云星空帮助中心原文。【】内为来源页面名；逐页摘录见 `../kingdee-digest/` 中 G3 的 35 份摘要。
> **阶段标记**：[一期] 首版上线必做；[二期] 后续增强。
> **裁剪原则**：本项目是单工厂电子元器件 ERP，金蝶能力不照搬。不做的能力在每章末尾列为“不纳入”。
> **全局约定**：
> - 界面只用浅色主题。
> - 界面上不出现任何“演示数据”字样。
> - 所有业务表预留 `org_id`（一期固定为一个组织），二期开多组织时不用改表结构。

## 1. 组织、用户、角色与权限

### 1.1 组织
- [一期] **组织机构**：单法人、单组织。字段有编码、名称、组织形态（公司 / 工厂）和业务职能（销售、采购、库存、工厂、质检、结算）。所有单据、基础资料带 `org_id`。【组织机构】【组织管理】
- [一期] **部门**：树形结构，含编码、名称、上级部门、部门负责人、启用 / 禁用；供流程“部门负责人 / 上级部门”取人。【部门】
- [一期] **岗位与员工任岗**：岗位属于部门，有上级岗位（汇报关系）；一名员工可任多个岗位，指定一个主岗。流程参与人和数据权限的“下属”都从这里计算。【岗位信息】【员工任岗信息】
- [二期] **多组织**：核算组织 / 业务组织；组织间业务关系（委托采购、跨组织调拨等）；基础资料控制策略（共享 / 分配 / 私有）。【组织业务关系】【基础资料控制策略】

### 1.2 用户
- [一期] 用户字段：账号（唯一）、姓名（唯一）、关联员工、所属组织、角色列表、启用 / 禁用 / 锁定状态、签名图片（审批签章用）、手机、邮箱、最后登录时间和 IP。【用户】
- [一期] 管理员可以新增、禁用、重置密码（重置后首次登录强制改密）、解锁、批量分配角色。【用户】【重置密码】
- [二期] 用户类型区分内部和外部（供应商 / 客户门户账号）；锁定终端（按 MAC 地址）。【用户】

### 1.3 角色与功能权限
- [一期] **RBAC**：权限点 = 业务对象 × 权限项。通用权限项有查看、新增、修改、删除、提交、审核、反审核、关闭、作废、引入、引出、打印、附件，各单据可以增加专用权限项（例如“下推”“打印次数清零”）。【业务对象功能授权】【权限项】
- [一期] **授权规则**：用户权限是其全部角色的并集，冲突时 **禁止 > 有权 > 无权**；“查看”是其他权限的前提。【角色】【系统管理】
- [一期] **授权界面**：按角色，以子系统 → 业务对象 → 权限项三级勾选，支持批量授权、复制角色、查看“某用户最终权限”。【子系统功能授权】【业务对象功能授权】
- [一期] **字段权限**：对敏感字段（单价、金额、成本、供应商价格）按角色控制查看和编辑，默认有权。【字段授权】
- [二期] 三员分立：系统管理员、安全保密员、安全审计员。【子系统管理员功能授权模式】

### 1.4 数据权限
- [一期] **数据规则**：按业务对象定义过滤条件，可用变量有当前用户、当前用户部门、本部门及下级部门、当前组织。规则作用于查看、修改、删除、审核，再与角色绑定。默认只按表头字段过滤。【数据权限】【数据规则选项】
- [一期] **岗位体系规则**（只作用于查看）：可见本人、直接下属、所有下属、本部门、所有下级部门的单据。典型用法是业务员只看自己的订单，主管看下属的订单。【岗位体系数据规则】
- [二期] 按分录行做数据权限（由参数开启）；基础资料 F8 选择范围控制。【数据规则选项】【数据权限】

### 1.5 日志
- [一期] **上机操作日志**：用户、时间、IP、子系统、业务对象、操作、单据编号、描述；支持查询和导出；超过 5 万条自动归档（金蝶原文默认值）。【上机操作日志】
- [一期] **业务数据日志**：每类单据可选字段，记录修改前后的值（只存差异），在单据页上显示“修改记录”。【业务数据日志设置】
- [二期] 数据归档任务（不可逆，只在管理员授权后执行）；限流配置。【数据归档任务】【限流配置情况】

**不纳入**：s-HR 集成、云之家集成、星空卫士、翻译平台、隐私中心加密（如有合规要求再议，放二期以后）。

## 2. 基础资料框架

- [一期] **统一框架**（每类基础资料都具备）：
  - 编码 / 名称 / 规格，以及启用 / 禁用；状态流转为 创建 → 审核 → 禁用 / 反禁用。
  - 分组（树形分类）。
  - 引用检查：已被单据引用的资料不能删除，只能禁用。【bos通用操作列表】
  - Excel 引入 / 引出模板，分新增和覆盖两种模式。
  - 业务数据日志。
  - 通用过滤方案。
- [一期] **系统级资料**：计量单位和单位换算（基本单位与辅助单位，换算率，精度和舍入）；币别、汇率；税率；国家地区；结算方式；付款条件。【计量单位】【地区信息】
- [一期] **辅助属性**：物料上可以挂“规格维度”，例如电阻的阻值、精度、封装。【辅助属性】
- [一期] **F8 选择器**：通用的弹窗选择，带搜索、分组树、只显示已审核且未禁用的资料、最近使用记录。
- 物料、BOM、客户、供应商、仓库等业务资料的字段，由 G1 / G2 各组定义；本章只提供框架。

## 3. 编码规则

- [一期] 每个业务对象（可细分到单据类型）配置编码规则。规则由多段组成，每段类型为常量、日期（格式如 yyyyMMdd、yyMM）、基础资料或字段值（例如单据类型编码）、流水号。【编码规则】
- [一期] 流水号段可设长度、起始值、步长、补位字符；按“编码依据”分组归零，例如按日期段每日重置。【编码规则】
- [一期] 选项包括：允许手工修改；保存时生成（默认）或新增时即生成；删除后是否补号（默认不补）；一个对象设一条默认规则。【编码规则】【单据参数配置】
- [一期] 并发安全：用 MySQL 行锁或原子自增分配流水号，保证唯一；单据编号在组织内唯一。
- [二期] 段长度截断、分隔符、替代字符等高级格式。

## 4. 单据框架

### 4.1 单据结构
- [一期] 单据由单据头、单据体（分录）和可选子分录组成。每张单据都有单据编号、单据日期、单据类型、状态、创建人 / 时间、修改人 / 时间、审核人 / 时间、关闭状态、作废状态、备注、附件。【单据设计与应用】
- [一期] **单据类型**：一类单据可以有多种类型（例如标准采购和委外采购）。类型决定编码规则、默认值、必录 / 锁定字段（与单据设置叠加，从严）、可走的流程模板、打印控制（打印次数上限、审核后才能打印）。【单据类型】

### 4.2 状态与通用操作（规则见《流程引擎调研》第 2 节）
- [一期] 单据状态：暂存 → 创建 → 审核中 → 已审核 ⇄ 重新审核；另有独立维度关闭 / 反关闭、作废。删除只允许暂存或创建状态；修改只允许暂存、创建、重新审核状态。【bos通用操作列表】
- [一期] 行级业务关闭（由反写自动关闭，或手工行关闭）；生产类单据的行业务状态（计划 → 下达 → 开工 → 完工 → 关闭）由 G1 定义，框架支持“行执行 / 反执行”。【工序计划状态控制】
- [一期] 职责分离参数（按单据配置）：审核人≠创建人、反审核人=审核人、删除或修改人=创建人。【单据参数配置】
- [一期] 用户选项：保存后自动提交；提交后自动审核（只在没有挂审批流时生效）。【选项设置】
- [一期] 每个状态下各字段的可编辑性、各按钮的可用性，都由状态机配置驱动，前端统一渲染。【单据状态】【单据设计与应用】
- [一期] 网络互斥：同一单据同时只能一人编辑；有“锁定人”提示；管理员可以清除残留锁。【网络控制】
- [二期] 拆单 / 合并、红字单据（退货冲销）的统一框架；业务对象“冻结 / 终止”的自定义状态转换。

### 4.3 单据转换（下推 / 选单）
- [一期] 用转换规则配置“源单 → 目标单”，包括：
  - 字段映射：直取、常量、公式、汇总。
  - 分组合并：一对一，或按客户 / 供应商等字段合并。
  - 选单条件，例如源单已审核、未关闭、可转数量 > 0。【单据转换规则】
- [一期] 运行时：
  - 下推：选源单行后生成目标单草稿，可以修改后再保存。
  - 选单：在目标单里拉取源单行。
  - 上查 / 下查：通过关联记录表。
  - 全流程跟踪：图形化展示一条链路上的所有单据。【下推与特定下推】【bos通用操作列表】
- [一期] 可转数量 = 源单数量 − 已关联数量，按基本单位计算。【单位换算处理】
- [二期] 自动下推（审核后自动生成下游单据）；按单据类型限定业务流程路线；超过 N 行自动拆单。【自动下推】【业务流程】

### 4.4 反写
- [一期] 反写规则：下游保存或审核时累加、扣减、覆盖源单字段（例如采购订单的累计入库数量）；删除或反审核时自动回滚；和下游单据在同一事务中执行。【反写规则】
- [一期] 超额控制：禁止超额；或允许按公式超额，例如“入库数量 > 采购数量 × 1.2”时禁止。【反写规则】
- [一期] 关闭控制：例如“累计入库数量 ≥ 采购数量 × 98%”时行自动业务关闭；整单关闭可按“全部行关闭”或“任一行关闭”。【反写规则】
- [一期] 多源单时按“自上而下”分配；跨级反写，例如入库单同时反写采购申请。【反写规则】
- [二期] 按权重分配。

### 4.5 通用功能
- [一期] **列表**：通用过滤方案（个人方案和共享方案），条件含单据状态、关闭、作废；列设置；分页；合计行；导出 Excel。【过滤方案管理】
- [一期] **引入 / 引出**：Excel 引入，模式有新增或覆盖（按单据编号匹配，分录按行号匹配），校验失败时出错误报告；记录引入操作。【引入操作记录】【引出操作记录】
- [一期] **附件**：上传、预览图片和 PDF、下载；存在服务器本地目录（路径可配）。对象存储放二期。【文件服务设置】
- [一期] **防重**：用接口（WebAPI 和扫码终端）新增单据时按幂等键防止重复创建。【新增单据防重配置】
- [二期] 批量操作分批执行，每批条数可配。【单据参数配置】

## 6. 工作流引擎（功能清单与选型见《流程引擎调研》第 5、6 节）
- [一期] **流程设计器**（bpmn-js，BPMN 子集）：开始、审批节点（可标记为终审）、排他和并行网关、结束。节点属性有参与人、会签方式、可否转交 / 加签 / 撤回、驳回范围、时限、节点视图（可编辑字段）。【审批流设计】【工作流设计器】
- [一期] **流程模板**：按单据加单据类型挂接；有启动条件（例如金额 > 5 万走总经理）、生效期和版本，一张单据只挂一个模板。【流程配置中心】
- [一期] **审批动作**：
  - 同意、驳回（到发起人或已走过的任一节点）。
  - 撤回：发起人在第一个节点处理前可撤回；处理人在下一节点处理前可撤回。
  - 转交、后加签、填写审批意见、电子签章。【高级选项_页签】【电子签章】
- [一期] **会签**（全部通过 / 按比例）、**或签**（任一人通过）、**条件分支**、**并行分支**。【会签审批流程】【顺签审批流程】【条件分支流程】【并行分支流程】
- [一期] **代理（委托）**：委托人、受托人、流程范围、起止日期；待办上显示“委托”标记；委托可以撤回。【流程委托设置】
- [一期] **待办中心**：待办、已办、我发起的；在单据页上审批；审批历史时间线；流程图高亮当前节点。【信息中心_待办任务】
- [一期] **实例管理**（管理员）：查看、终止（终止不会反审核单据）、转派任务。【流程管理_流程实例】
- [一期] 终审通过即执行单据“审核”操作；驳回时单据进入重新审核。【审批流设计】
- [二期] 前加签、传阅、超时自动处理（自动通过或转交）、工作日历、自动动作节点、非审核操作审批（例如反审核、作废也要审批）、流程分析报表、邮件审批。

## 7. 消息与预警
- [一期] **站内消息**：右上角铃铛，WebSocket 实时推送。消息类型有流程待办、流程结果、业务通知、预警、公告。可以标记已读，点击跳转到单据。【消息平台】【信息中心】
- [一期] **消息模板**：标题和内容可以插入单据字段变量，例如“采购订单 {单据编号} 已审核”。【消息模板】
- [一期] **消息配置**：业务对象 + 触发操作 + 触发时机（金蝶要求保存类操作用“操作成功后”触发）+ 条件 + 接收人（固定用户、角色，或单据字段上的人，如业务员）+ 级别（紧急 / 警告 / 提醒）。【消息配置】
- [一期] **定时预警**（业务监控）：监控方案 = 业务对象 + 条件 + 执行计划（cron）+ 接收人。典型用法：物料库存低于安全库存、采购订单逾期未到货、生产工单逾期、来料检验超期。【业务监控】【监控对象】【执行计划】
- [一期] 消息保留：7 天内显示为最新消息，超过 7 天转入历史消息（按金蝶默认值，可配）。【消息平台】
- [二期] **操作前预警**（风险预警）：保存或审核前校验条件，例如信用额度超限时提示或禁止。【预警方案】【预警规则】
- [二期] 外部渠道：邮件、短信、企业微信。【短信服务配置】

## 8. 报表与套打

### 8.1 报表
- [一期] 报表框架有三类：
  - 明细或汇总的列表式报表，支持过滤、分组小计、钻取到单据。
  - 交叉（透视）报表。
  - 驾驶舱图表组件，与三维车间和驾驶舱共用数据接口。【报表管理】【账表设计】
- [一期] 报表同样受数据权限和字段权限约束；支持导出 Excel。
- 各业务报表的清单由 G1 / G2 / G4 定义。
- [二期] 用户自定义报表（选数据源、拖字段）和订阅推送。【数据源管理】

### 8.2 套打（打印模板）
- [一期] **模板设计器**：为每个业务对象维护多个模板，可放表头字段、分录表格、页眉页脚、条码 / 二维码（用于物料标签、送货单）、图片和签章；纸张尺寸和边距可设。【套打平台】【模板设计与应用】
- [一期] **打印**：预览、打印、导出 PDF；批量打印；标签连续打印。每个单据类型设默认模板。打印控制包括“审核后才能打印”和“打印次数上限”，并记录打印次数。【单据类型】
- [一期] **模板权限**：分通用、按角色、按用户。【套打模板权限控制】
- [二期] 合并打印、按组织控制模板权限。

## 9. 安全登录
- [一期] **静态密码策略**（采用金蝶默认值）：
  - 强密码，必须同时含数字、特殊字符和字母；最小长度 8 位，可设为 8–20 位。
  - 密码有效期，例如 30 天，并提前提醒。
  - 首次登录或重置后必须改密。
  - 连续输错 3 次锁定，可自动或手动解锁。
  - 规则调整后强制检查现有密码。【用户】【安全管理】
- [一期] 会话：JWT 加刷新令牌；空闲超时自动退出；同一账号多端登录可配置；登录日志记录 IP 和终端信息。
- [一期] 敏感操作二次验证（例如反审核、删除已审核资料、修改权限时再次输入密码）。【二次验权】
- [一期] 全站 HTTPS（由运维在 lustone 上配置，需要老板授权）。
