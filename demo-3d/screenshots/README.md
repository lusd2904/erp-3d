# 三维演示截图（节选）

早期三维演示的截图原目录约 197MB、1025 个文件，其中包含多轮迭代（r2–r5、nodemo、shell）以及重复解包的 `_unpack`（内含重复的 Three.js / ECharts 等）。单文件均未超过 90MB，但全部纳入体积偏大且重复多。

本仓库只收录有代表性的部分（约 59MB、203 个文件）：

- 与参考图的对比：`compare_*.png`
- 业务模块界面：`m_*.png`
- `modules/`、`devices/`、`verify/`、`ref/`
- 较新的一轮界面：`r6/`（不含 `_unpack`）

未收录：`r2/`–`r5/`、`nodemo/`、`shell/`、顶层大量迭代过程截图（`a_*`…`g_*` 等），以及所有 `_unpack` 目录。
