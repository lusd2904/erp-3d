## 1. 功能点【来源:组织间结算】
- 适用业务：跨组织库存调拨、跨组织销售(3 种模式：正常购销 / 先调拨再出货 / 直接出货即隐含调拨)、跨组织采购(3 种模式，同上)、跨组织生产领料、法人间分销购销(多套核算体系时)
- 基础：组织间结算系统参数、跨组织业务类型(含取价来源)、组织间结算价目表、结算调价表、组织间结算关系、结算价目表自定义字段匹配设置、结算业务单据选择方案、冲突操作列表、内部客户/内部供应商设置
- 业务：创建结算清单(5 步向导)、定时结算、应收/应付结算清单(物料/资产/费用)、批量创建内部交易单据、组织间结算结账检查
- 报表：组织间结算分析报告、内部交易单据报表、跨组织业务全程跟踪查询、未生成内部交易单据(跨组织业务)查询、未生成结算清单跨组织业务查询、组织间交易利润分析表、组织间结算对账明细表

## 2. 单据/资料字段（只列原文字段名）
### 2.1 组织间结算价目表【来源:组织间结算价目表】
- 表头：核算组织(供货方定价)、价目表对象(物料/物料分组)、币别、生效日、失效日、含税
- 表体：物料编码、物料分组编码、辅助属性、计划跟踪号、批号、BOM版本、定价单位(必须与结算单位一致才能取到价)、价格系数、价格、税率、含税单价(价格=含税单价/(1+税率))、免费
- 操作：失效/反失效、引入采购或销售价目表、分发
### 2.2 组织间结算关系【来源:组织间结算关系】
- 会计核算体系、供货方(核算组织)、默认应收组织、强制应收组织、接收方(核算组织)、默认应付组织、强制应付组织、应付税额计入成本、价格来源—优先级、结算价目表编号
### 2.3 跨组织业务类型【来源:跨组织业务类型】
- 结算取价类型、取价来源名称、加(减)成比例(%)(−100~100)、自定义插件；预置类型可以增减取价来源，但不能删除
- 取价公式：
  - 结算价目表
  - 销售价格减价=单价×(1−代理销售减价比例)
  - 采购价格加成=单价×(1+代理采购加成比例)
  - 结算配置价=配置金额字段×(1+加减成比例)
  - 成本价(实际成本/期初加权价/上期入库成本/上期出库成本)×(1+加减成比例)
  - 物料结算比例成本价(以上四种成本)×(1+物料"结算成本价加减价比例")
  - 自定义取价插件
  - 【来源:组织间结算取价指引】
### 2.4 应收结算清单_物料(应付清单对称)【来源:应收结算清单_物料】
- 单据编号、会计核算体系、核算组织、结算组织、结算币别、对应客户/对应供应商、物料编码、辅助属性、单位、数量、结算价格、结算金额(=结算价格/价格系数×计价数量)、应收应付关联数量
- 规则：
  - 只能由向导生成，不能手工新增
  - 修改应收清单的价格会联动修改应付清单；应付清单本身不能改价
  - 应收清单审核/反审核/删除时联动应付清单
  - "获取往来单位"按客户/供应商上的"内部对应组织"回填
### 2.5 创建结算清单向导【来源:创建结算清单】
- 第 1 步：会计核算体系、核算组织、业务组织、按供货方接收方核算组织一对一生成、供货方/接收方组织、起止日期、创建应收结算清单、创建应付结算清单、单据类型、跨组织业务类型、单据选择方案、结算价目表匹配时点(业务截止日期/系统日期/单据日期)、按跨组织结算类型分单、按跨组织业务单据编号分单、显示中间结果、结算价小于等于 0 也生成结算清单
- 第 2 步：结算业务对方组织自动生成结算清单、有结算价格的应收清单自动审核、审核应收清单联动审核应付清单、应收/应付清单审核后自动生成应收/应付单、生成的应收/应付单为已审核状态
- 第 3 步：设置取价来源
- 第 4 步：中间结果(生成结算清单分录行数、重新取价不清空已有结算价、引出/引入 0 价格的中间结果、重取成本)
- 第 5 步：完成情况和结算日志
- 规则：
  - 双方属于同一核算组织时，不生成结算清单
  - 同一核算体系下不能重复结算
  - 不同核算体系下可以分别结算
### 2.6 组织间需求单(计划模块，错放)【来源:组织间需求单】
- 需求组织、物料编码、单位、BOM编号、辅助属性、需求日期、需求数量、确认到货/完工日期、确认订单量、剩余需求数量、供应组织、预留类型、需求优先级、计划跟踪号

## 3. 流转
- 跨组织业务单据(出库单/入库单/调拨单/领料单的货主≠结算组织)审核 → 内部交易单据(参数：审核时生成或结算时生成；同步或异步)【来源:组织间结算系统参数】
- 创建结算清单(手工或定时) → 应收结算清单 + 应付结算清单 → 应收单/应付单【来源:创建结算清单】
- 月末先做结账检查(内部单据是否完整、是否重复、双方是否同期结账、成本价是否一致)，再做存货核算结账【来源:组织间结算结账检查】
- 前提：在双方组织下分别建内部客户和内部供应商(缺失时跨组织单据审核会报"没有对应的内部供应商或客户")【来源:内部客户内部供应商设置】

## 4. 参数【来源:组织间结算系统参数】
- 内部交易单据生成时点(审核生成/结算生成)、内部单据生成方式(同步/异步)
- 服务类物料参与结算、套件物料按子项或父项结算
- 分步式调拨相关 4 项
- 税额计入成本、退货类结算清单取普通类结算价、赠品默认免费
- 结算清单启用编码规则、结算调价表审核后即生效
- 按业务单据结算币别匹配价目表、结算清单审核后回填内部交易单据价格金额
- 生成应收应付单分批最大值(1–5 万)

## 5. 审批点
- 结算清单只有审核(应收和应付联动)，原文没有写审批流节点；结算调价表审核后生效【来源:应收结算清单_物料】【来源:结算调价表】

## 6. 对电子元器件 ERP 的结论
- **一期**：不实现这个模块。但出入库单和订单上保留 货主组织、结算组织、库存组织、供应组织 字段(来自销售/采购单据)，避免以后改表。
- **二期**：多组织下的内部结算。
  - 结算关系+价目表(成本加成取价)
  - 自动生成应收/应付结算清单 → 应收单/应付单
  - 对账明细表、结账检查
