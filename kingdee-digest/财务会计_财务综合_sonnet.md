# 财务会计／财务综合

## 1. 功能点

### 凭证类
- 【凭证录入】手工录入记账凭证，支持现金流量指定、外币核算、数量金额核算、结算方式录入
- 【凭证_新版】H5端新版凭证录入，界面接近纸质凭证，含摘要模糊查询、核算维度自动弹出、快捷键；字段说明指向「凭证录入」，无独立内容
- 【业务凭证查询】查询和管理业务凭证，支持查看、修改、打印、生成总账凭证、联查单据和总账凭证
- 【凭证汇总】按指定范围和条件将记账凭证汇总至科目借贷方发生额
- 【凭证字号明细报告】查询凭证汇总表范围内各凭证的凭证字、凭证张数及附件数量
- 【凭证归档单据映射设置】设置上下游单据固定关系，用于凭证归档时影像编号识别
- 【向导式期末调汇】期末对外币科目自动计算汇兑损益，生成汇兑损益结转凭证及期末汇率调整表
- 【向导式结转损益】将损益类科目余额转入本年利润科目，自动生成结转损益记账凭证
- 【调汇历史信息表过滤条件】按账簿、会计年度期间、科目范围查询外币科目调汇历史记录，展示原币金额、调整前后汇率、本位币金额及本位币差额

### 总账初始化
- 【总账初始化向导】引导完成基础资料维护、总账参数设置、科目初始余额录入、结束初始化四步操作
- 【总账反初始化】将账簿还原到未初始化状态，仅限账簿启用期间内操作

### 对账类
- 【对账】执行总账与各业务系统明细账的账账核对，支持本期发生额差异分析（含存货对账专项差异分析）
- 【对账方案】设置总账科目与业务报表之间的对账关系，配置对账项目、科目、核算维度、业务报表等
- 【对账结果查询】查询已保存的对账数据，支持总账期末结账前校验对账平衡
- 【对账管理】（B2B电商门户路径）跟踪查询网上订单执行与付款情况，按订单状态分类查询并支持导出
- 【银行存款对账条件过滤】银行存款对账的条件过滤

### 费用报销类
- 【差旅费报销单（2019新政）】开票日期在2019年4月1日之后的差旅费报销，支持从出差申请单、历史借款余额下推，审核后自动核销付款/借款；含申请付款、申请退款、实报实付、费用外部承担、多收款人等选项控制付款流程
- 【差旅费报销单（实报实付）】对应出差申请产生的报销业务与单独出差报销，不允许报销金额小于零
- 【费用报销单_实报实付】当月报销当月付款，由费用申请单（无借款）/出差申请单（无借款）下推生成；支持封面打印与影像查看
- 【我的费用报销单】过滤创建人或申请人为当前用户关联员工的费用报销单
- 【我的费用申请单】过滤创建人或申请人为当前用户关联员工的费用申请单
- 【营销费用报销单】移动端（BBC移动端）快速发起营销费用报销操作，支持附件上传
- 【营销费用申请单】移动端（BBC移动端）快速发起营销费用申请操作，支持附件上传
- 【营销费用管理系统参数】设置启用营销费用申请单默认申请人参数
- 【费用报销系统启用】费用报销系统启用日期设置与反启用

### 应收/往来类
- 【应收款参数设置】配置应收模块自动核销、自动生成发票/应收单、结账控制、汇率修改、核销差异范围等参数
- 【手工核销】支持手工匹配核销（按核销方案）和手工特殊核销（跨往来单位），生成已审核状态核销单
- 【挂账回款管理】对协议客户的挂账账单（从POS端上传）进行查看，支持下推回款单、下推挂账账单变更单、下推其他应收单
- 【应收分析】展示本期/本年应收、已收、未收、账龄分析、应收余额趋势、客户应收余额、结算组织应收余额等指标
- 【应收坏账风险监控】原文仅有外链，无正文内容

### 出纳/票据类
- 【期初未达】录入银企双方期初未达账项（企业期初未达、银行期初未达）
- 【电子回单匹配依据设置】设置电子回单与收付款单等建立匹配关系，用于电子档案归档
- 【电子票据自动签收设置】配置定时方案，系统自动查询待签收电子票据并生成签收单

### 合并报表类
- 【个别报表】子公司根据分发的报表模板编制和上报个别报表/抵消报表
- 【合并报表编制】母公司/控股公司编制合并报表，含重算表页、调整/抵消分录处理及上报
- 【合并报表管理器】向导式管理界面，完成个别报表收集、调整、抵消、汇总、合并报表编制全流程
- 【合并结构】展示当前合并范围内各组织的合并关系（含下级合并结构）
- 【持股比例】显示合并范围股权比例，配置权益抵消分录模板和权益调整分录模板
- 【报表项目勾稽关系】设置报表项目间比较公式以核对数据正确性，需分配给组织后生效

### 分析类
- 【财务分析】汇总入口，预置8张分析页面（经营大盘、损益分析、资产负债分析、经营效率、资金分析、应收分析、费用分析、科目多维度分析）
- 【损益分析】基于账簿数据，按年月区间展示营业利润、净利润等损益指标及多组织对比图表
- 【资产负债分析】偿债能力可视化分析
- 【资金分析】资金流向与余额趋势分析
- 【费用分析】基于科目余额表（含未过账凭证）及费用报销系统数据，展示财务三大费用及明细科目分析
- 【科目多维度分析】按供应商、部门、客户、员工、费用项目、资产类别、组织机构等核算维度展示科目余额表数据

### 阿米巴类
- 【阿米巴利润汇总表】查询各利润中心经营成果
- 【阿米巴利润表】查询含联查经营流水账
- 【阿米巴自定义分摊规则】维护自定义分摊规则
- 【阿米巴账户余额表】查询含联查收支明细
- 【阿米巴账户收支明细表】查询含联查经营流水账
- 【阿米巴资产负债余额表】查询含联查经营流水账
- 【服务费用（利润中心间内部结算单）】记录各利润中心之间的资金/物资/服务内部往来结算，作为阿米巴报表数据来源，不传递到财务系统

### 其他
- 【现金流量附表项目指定说明】需要指定附表项目的凭证
- 【第三方卡券核销记录】查询前端第三方卡券支付流水核销记录；同页面含礼券流水查询、礼券综合统计报表
- 【开票管理】针对会员卡充值金额进行开票处理，审核后更新会员卡已开票金额/未开票金额
- 【全面数据化的电子专用发票】仅有功能概述，无字段说明、状态流转及接口信息

## 3. 状态流转、下推和反写

### 凭证录入
- 凭证号由系统按总账系统参数凭证号排列规则自动生成；参数「不允许手工修改凭证号」控制是否可手工改号
- 不允许录入账簿已结账期间内的日期；允许录入当前期间及以后期间
- 总账系统参数「允许录入凭证的未来期间数」限制可录入的最大未来期间数

### 业务凭证 → 总账凭证
- 业务单据 → 一对一生成业务凭证 → 一对一或汇总生成总账凭证
- 业务凭证未生成总账凭证时，允许修改凭证字、摘要、科目、维度、结算方式、结算号
- 期初业务凭证不需要生成总账凭证

### 向导式结转损益
- 账簿当前期间不存在未过账的结转损益凭证，才能执行
- 账簿系统参数须设置「本年利润科目」「利润分配科目」；支持按核算维度生成多张凭证

### 总账初始化 / 反初始化
- 结束初始化：所有账簿均结束初始化后节点自动显示为已完成
- 科目初始余额确认前提：综合本位币下试算平衡；总账参数须已设置本年利润及利润分配科目
- 反初始化：仅限账簿启用期间内，将账簿还原到未初始化状态

### 对账
- 对账方案勾选「必须与总账期末对账平衡」后，总账期末结账时直接调取对账结果进行校验；对账结果不平衡则不允许总账期末结账
- 须先在智能会计平台参数启用「保存总账科目与业务报表的对账结果」，方可保存；同一对账方案多次保存只保留最后一次
- 某一对账方案已保存对账结果后，该对账方案不允许删除，只能修改

### 差旅费报销单（2019新政）
- 状态流转：创建 → 提交 → 审核通过；打回后为「重新审核」状态；支持作废
- 下推：出差申请单、历史借款余额 → 下推生成差旅费报销单（2019新政）
- 审核通过 → 自动同步生成其他应付单（已审核状态，不允许反审核；下游应付系统只可查看）
- 勾选申请付款 → 自动下推生成付款申请单（创建状态）
- 勾选申请退款 → 自动下推生成付款退款单（创建状态）
- 参数控制 → 自动下推生成进项费用增值税发票（创建状态）或手工下推
- 参数控制 → 审核时自动生成付款单（取到我方银行账户默认值为创建状态，取不到为暂存状态）
- 勾选费用外部承担 → 可下推生成付款单、其他应收单
- 反审核：同时删除已同步生成的其他应付单
- 实报实付：不产生其他应付单
- 费用外部承担：不同步生成其他应付单，不参与自动核销；源单为借款单时不允许勾选
- 关账规则：报销系统关账后不允许新增关账日期之前的单据；下游系统先于费用报销系统结账时，报销单提交/审核取系统当期日期，否则取申请日期

### 费用报销单（实报实付）
- 源单：费用申请单（无借款）/ 出差申请单（无借款）→ 下推生成费用报销单（实报实付）
- 审核通过 → 自动下推生成付款申请单（单据类型=费用报销申请，创建状态）
- 审核通过 → 自动下推生成进项费用增值税发票（创建状态）
- 审核通过 → 自动生成付款单（单据类型=费用报销付款单）；我方银行账户有默认值为创建状态，取不到值为暂存状态
- 报销单 → 可下推生成费用移转单（使用「费用金额」下推）
- 勾选费用外部承担：可下推付款单、其它应收单；不产生其它应付单，不参与自动核销
- 作废：状态为重新审核的单据可作废，作废后不参与业务
- 关账后不允许新增关账日期之前的单据

### 费用报销系统启用
- 启用后，应付系统和出纳系统涉及费用报销业务的单据（其他应付单、付款申请单、付款单、付款退款单）不允许无费用报销类源单的手动新增
- 启用日期有业务发生后不允许修改

### 手工核销
- 核销后自动判断是否生成核销单，生成的核销单为已审核状态
- 核销单的单据日期必须大于组织最近的关账日期
- 付款单「是否其他预付」为「是」时，手工核销会自动产生核销单

### 挂账回款
- 挂账账单 → 下推挂账账单变更单、挂账回款单、其他应收单
- 下推后反写至挂账账单对应字段：已回款金额（由回款单反写）、已下推到其他应收单金额
- 未回款金额 = 挂账金额 - 已回款金额（系统计算）
- 挂账回款单「是否冲销单」：默认"否"，生成冲销单时显示为"是"

### 电子票据自动签收设置
- 审核成功后可手工执行；「提交方式」控制生成签收单的状态（保存/提交/审核/审核且签收提交银企4种）；每次执行后更新「下次签收时间」

### 开票单
- 审核后更新会员卡已开票金额、未开票金额；允许反审核，反审核后还原审核前金额

### 合并报表
- 合并报表编制前提：子公司/子集团个别报表已接收；调整分录、抵消分录已审核
- 子集团合并报表上报后作为集团的个别报表参与集团合并

### 凭证归档单据映射设置
- 需提交审核才能生效
