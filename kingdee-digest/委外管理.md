# 委外管理 摘要 — G1a
> 范围：生产制造_委外管理.md 39页（含孤立9），正文139,921字。工序委外HMI/移动页（扫描委外发出、委外接收、委外入库、移动质检_委外检验）属车间/MES（G1b），委外入库核算流程图仅图。电子元器件相关度：**中**（外协电镀、外协测试、外协编带/封装）。

## 1. 功能点
- 委外订单全过程：委外计划→投料领料→委外检验→入库→结案；普通委外/返工委外（返工用料清单默认仅返工产品本身）。【来源:委外管理】【来源:委外订单】
- 委外订单下推采购订单，收货走采购的收料通知/采购入库单（委外类型）。【来源:委外管理】
- 委外用料清单及变更单；委外领料/退料/补料单；委外成套领/退/补料；委外倒冲工作台；倒冲差异分摊；月末在制转移；委外仓库设置。【来源:委外用料清单】【来源:委外领料单】
- 委外订单变更单、委外订单拆分（可拆为生产订单/委外订单）。【来源:委外订单变更单】【来源:委外订单拆分】
- 委外超耗单（供应商责任超定额消耗，下推标准应收单用于扣款/索赔）。【来源:委外超耗单】
- 委外齐套分析（委外备料单）。【来源:委外齐套分析】

## 3. 状态流转
委外订单：计划 → 计划确认（审核自动）→ 下达 → 完工 → 结案；挂起/反挂起。下达后才能下推采购订单/领料；反下达需无领退补；结案需无非审核/非作废领退补、用料清单已审核、采购订单业务关闭/整单关闭/业务终止。【来源:委外订单】

## 4. 下推/反写
- 委外订单 → 采购订单（反写采购选单数量/采购执行数量；供应商回填委外订单；领补套数同步到采购订单"委外领料套数"）。【来源:委外订单】
- 采购入库单（委外类型）审核 → 反写委外订单入库数量、触发委外倒冲（后台/交互）；反审核删除倒冲领料单。【来源:委外领料单】【来源:委外倒冲工作台】
- 采购退料单（委外）审核 → 冲减入库数量与用料清单消耗数量，生成倒冲退料单。【来源:委外退料】
- 委外订单变更单审核 → 刷新委外用料清单。委外超耗单 → 标准应收单。
- 拆分：全部拆分则原单"拆分结案"。【来源:委外订单拆分】

## 5. 关键参数
- 委外单据类型参数：委外类型(标准委外/返工委外)、用料清单(仅主产品/按BOM展开)、启用委外用料清单变更、审核自动下达、下达自动审核用料清单、自动结案、倒冲方式、委外领料自动计算领补套数、委外收料/入库材料领用控制、结案控制。【来源:委外单据类型参数】
- 委外管理参数：默认库存状态、采购数据关联(按单据转换/按采购订单编号)、领料前需审核采购订单、委外退料检验(自动退料)、执行计划(委外入库倒冲组织、采购退料倒冲组织、委外结案组织)。【来源:委外管理参数】

## 6. 审批/工作流点
委外订单审核、委外订单变更单审核、委外用料清单审核、委外超耗单审核（涉及应收扣款，建议财务会签）、委外领料（参数可要求采购订单先审核）。

## 7. 报表
委外订单执行明细/汇总表（计划完成百分比）、委外订单领料明细/汇总表（领料比例）、委外领料差异汇总表、委外入库月报表（合格入库/工废入库/料废入库/让步接收入库/不合格入库/退库数量/实际入库数量）、委外领料月报表、委外入库领料查询、生产/委外退料检验质量统计表。

## 8. 相关度
- 中：外协加工（电镀、外协测试分选、外协编带）需"委外订单+发料+收回+超耗索赔"。
- 低：工序委外HMI（G1b）、月末在制转移、倒冲差异分摊。

## 9. 字段说明逐字补读（第二轮：29 页，唯一行约 4.1 万字）

### 9.1 委外订单
- **单据类型**：保存后不可修改。
- **物料**：只能选勾选了"允许委外"的物料。
- **供应商**：
  - 只能选采购组织下、供应类别为"委外"或"综合"、已审核未禁用的供应商。
  - **下推采购订单后，更新为采购订单上的供应商。**
- **单位**：默认取委外单位。
- **计划开工时间**：默认为当前日期。
- **计划完工时间**：由系统根据开工日期和委外数量自动计算；必须落在委外车间日历的可委外日。
- **BOM版本**：**默认带出用途为"委外+通用"的最新版本。**
- **采购组织**：默认为委外组织（须有采购职能），或者选委托采购关系中的受托方。
- **领料状态**：与生产订单相同的四个值。
- **入库货主**：默认为委外组织。
- **生成方式**：手工录入、**手工分解**、MRP生成、MPS生成、拆分。
- **业务流程**：系统预设"委外直接入库流程"。【来源:委外订单】

### 9.2 委外订单变更单与拆分
- **委外订单变更单**：
  - 只能变更业务状态为计划、计划确认、下达的订单。
  - 变更类型为"新增"的行，审核后自动生成委外用料清单。
  - 入库上限 ≥ 数量，入库下限 ≤ 数量。【来源:委外订单变更单】
- **委外订单拆分**：
  - 可拆分数量 = 生产数量 − 采购选单数量。
  - 订单拆分方式：生成新的订单，或生成新的分录。【来源:委外订单拆分】

### 9.3 委外用料清单及变更单
- **委外用料清单**：
  - 需求日期 = 计划开工时间 + 偏置提前期，不能晚于计划完工时间。
  - 需求数量按单位精度向上取整。
  - 返还件的发料方式强制为"不发料"。
  - 货主类型默认为业务组织，货主默认为委外组织。
  - 系统预设"委外领退补料流程"。【来源:委外用料清单】
- **委外用料清单变更单**：
  - 新增行的默认值：分子、分母为 1；固定损耗、变动损耗率为 0；用量类型为"变动"；子项类型为"标准件"；是否发损耗为"是"；货主、供应组织、发料组织为委外组织。
  - **子项的领料、补料、退料、调拨选单数量任一大于 0 时，子项类型和发料方式锁定。**
  - 发料方式为调拨时，拨出组织和拨出仓库必录。【来源:委外用料清单变更单】

### 9.4 委外超耗单和领退补料单
- **委外超耗单**：
  - 消耗数量必须大于 0。
  - 供应商必须已审核、未禁用，且在有效期内。
  - 单据日期适用关账规则。
  - 当货主是 VMI 供应商时，标记为 VMI 业务。【来源:委外超耗单】
- **委外领料、退料、补料单**：
  - 申请数量不能大于下推数量。
  - 实收数量不能超出用料清单的数量控制。
  - 补料单从退料单生成时，数量不能超过退料单。
  - 委外供应商的取值范围受委托采购关系约束。【来源:委外领料单】【来源:委外退料单】【来源:委外补料单】

### 9.5 委外单据类型参数
- **领料单生成时机**：可选入库单提交时或审核时。原文建议提交时生成倒冲领料，审核时做材料领用控制。
- **结案相关**：
  - **结案时进行子项材料损耗报失**：结案时把在制数量中的损耗部分扣减掉，记入"结案损耗报失数量"。
  - 非返还件结案控制有四种：在制为零；在损耗范围内 MAX(固定损耗, 变动损耗)；在损耗及最小发料批量范围内；不控制。
  - 未入库的委外订单不能正常结案，只能强制结案。
- **调拨相关**：调拨物料获取预设供应商的仓库；调拨考虑最小包装或最小发料批量。
- **材料领用控制**：分收料控制和入库控制。控制强度为警告或严格控制时，控制项必填。【来源:委外单据类型参数】

### 9.6 委外管理参数
- **拆分保留原订单号**：拆出的新单号为原单号 + 001。
- **生成下级订单时创建预留**：创建的是强预留。
- **领料单计划跟踪号校验**：弱控、强控、不控制。
- **倒冲差异分摊的标准数量** = 用料清单标准用量（或应发数量）× (采购入库 − 采购退料) ÷ 委外订单数量。
- **委外退料检验**：检验完成、不良品处理审核或 MRB 评审审核后，可自动生成退料单。【来源:委外管理参数】

### 9.7 委外备料单
- 业务类型有**齐套分析、欠料分析、缺料分析三种**（第一轮摘要只写了两种，这里更正）。
- 欠料分析可以按生产数量或备料数量来分析。【来源:委外备料单】

### 9.8 报表与原文不一致处
- 委外入库月报表：实际入库 = (合格入库 + 工废入库 + 料废入库 + 让步接收入库 + 不合格入库) − 退库。
- 委外入库领料查询的领料标记分正常、异常、期初异常、本期异常四类，原文给了判定公式。
- **委外订单"开工"状态的更正**：第一轮按操作说明写成"没有开工状态"，这个说法不准确。原文在三处都包含"开工"：
  - 委外订单字段说明里，业务状态 = 计划、计划确认、下达、开工、完工、结案、结算（与生产订单相同）。
  - 委外补料单只有在订单为下达、开工或完工时才能反审核。
  - 委外领料差异等报表列出了开工。
  - 不过操作说明里没有"开工"按钮，状态如何变成开工，原文没有说明，记为待确认。【来源:委外订单】【来源:委外补料单】
