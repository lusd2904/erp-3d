# 财务会计／智能会计平台

## 1. 功能点

- **下载凭证云模板**：在线下载凭证云模板，按记账模式选择科目表、分录类型和凭证模板并引入系统；支持引入科目表（新建/引用/追加三种方式）、引入分录类型（追加或覆盖）、生成凭证模板、查看生成凭证模板报告。
- **业务凭证查询**：查询和管理业务凭证，支持查看、修改、打印、生成总账凭证、联查单据和总账凭证。
- **凭证模板**：设置凭证各要素（科目、借贷方向、金额、摘要等）的取值规则，支持系统预置模板及恢复预置。
- **凭证模板查询**：按来源单据、科目、核算维度查询凭证模板信息。
- **凭证生成**：生成业务凭证和/或总账凭证，支持一对一、全部汇总、匹配汇总三种生成方式。
- **凭证生成情况查询**：查询业务单据生成凭证情况，展示是否生成凭证、凭证号、未生成原因，支持联查单据/业务凭证/总账凭证。
- **凭证自动生成方案**：设置定时或审核触发的凭证自动生成方案，支持按账簿、单据、执行频率配置。
- **分录类型**：将会计科目按业务抽象归类，通过科目影响因素映射到具体会计科目，可被多个凭证模板引用。
- **单据合并方案**：配置不同单据的合并关系，支持按多种核销关系或自定义匹配规则将多张单据合并生成一张总账凭证。
- **增值税发票单据**：通过扫描仪 OCR 录入增值税发票，自动生成增值税发票单据；识别失败时允许手工修改后再生成。
- **增值税发票识别**：扫描录单的中间结果单据，可联查已生成的增值税发票单据及扫描影像。
- **扫描识别模板管理**：将本地制作的识别模板引入系统，管理模板元信息及自动生成/审核参数；预置银行回单（收款）、银行回单（付款）两个自定义模板。
- **业务单据对账**：执行账账核对（总账与业务系统明细账），支持发生额汇总对账及联查明细对账。
- **业务单据对账方案**：配置总账科目与业务单据之间的对账关系及取数规则。
- **业务单据对账结果查询**：查询已保存的业务单据对账结果，供总账期末结账校验使用。
- **业务报表对账**：执行总账与业务报表之间的账账核对，并提供本期发生额差异分析。
- **业务报表对账方案**：设置总账科目与业务报表之间的对账关系，支持按核算维度明细展开。
- **业务报表对账结果查询**：查询已保存的对账结果数据，支持按对账方案、年度、期间、币别过滤；控制总账期末结账时对账不平衡不允许结账。
- **自动对账方案**：按月/周/天定时自动执行业务报表对账，对账完成后自动保存结果并支持联查。
- **对账检查**：按设定检查项对业务数据规范性进行检查，对账不平时协助分析原因。
- **智能会计平台参数**：设定生成凭证过程中的控制方式与策略，含尾差处理、凭证合并、摘要规则、核算维度取值等约 20 项参数。
- **总账凭证查询**：查询和管理通过智能会计平台生成的总账凭证（详细操作指向总账帮助手册）。
- **智能会计平台**：总览页，说明平台整体定位——根据凭证模板对业务单据自动生成业务凭证和总账凭证，并提供对账管理功能。
- **自定义单据识别**：通过扫描仪扫描自定义模板，识别后归集结果并生成对应单据；识别失败时仅生成自定义扫描识别，待手工修正后再生成单据。
- **银行回单付款**：扫描银行回单后自动生成银行回单付款单据，支持联查扫描影像。
- **银行回单收款**：扫描银行回单后自动生成银行回单收款单据，支持联查扫描影像。

## 3. 状态流转、下推和反写

**凭证生成链路：**
- 业务单据 → 业务凭证（一对一生成）→ 总账凭证（一对一或汇总生成），三层链路。
- 凭证生成支持分步执行：单据→业务凭证→总账凭证，或单据同时生成业务凭证和总账凭证。
- 业务单据须已审核，才可触发凭证生成。
- 凭证自动生成方案中，"单据审核自动生成凭证"选项在单据被审核时自动调用凭证生成服务。

**业务凭证修改规则：**
- 未生成总账凭证的业务凭证允许修改：凭证字、摘要、科目、维度、结算方式、结算号。
- 期初业务凭证：自动勾选「期初业务凭证」标识，不需要生成总账凭证。

**凭证模板引入与覆盖：**
- 分录类型引入方式：追加或覆盖；覆盖引入会覆盖相同编码且未审核状态的分录类型。
- 凭证模板引入：若系统已存在相同单据、相同适用账簿、相同来源核算组织、相同科目表的凭证模板，可选择引入时自动禁用系统现有模板。

**单据合并生成凭证：**
- 合并方式包括：全部汇总、费用报销核销关系、应付付款核销关系、应付开票核销关系、应收收款核销关系、应收开票核销关系、自定义匹配关系。
- 勾选"不符合条件的单据不生成凭证"时，找不到合并关系的单据不生成总账凭证。
- 应付单和付款单合并生成总账凭证时，合并项不包含凭证模板和业务分类行号。

**对账与结账联动：**
- 对账方案勾选「原币金额必须与总账期末对账平衡」或「本位币金额必须与总账期末对账平衡」时，总账期末结账检查对账结果，不平衡则不允许结账。
- 凭证模板字段"必须生成总账凭证"勾选后，总账结账时检查该类单据是否已生成总账凭证，未生成则不允许结账。
- 对账结果保存规则：同一对账方案多次保存只保留最后一次；已保存对账结果的对账方案不允许删除，只能修改。
- 保存对账结果前提：需在智能会计平台参数启用「保存总账科目与业务报表的对账结果」。
- 自动对账方案对账完成后自动保存对账结果，支持联查。

**参数修改与删除联动：**
- 智能会计平台参数修改后仅对未来生成的凭证生效，不追溯已有凭证。
- 勾选「删除总账凭证同时删除业务凭证」时，删除总账凭证将自动删除对应业务凭证。
- 「自动覆盖异常的业务凭证」：生成总账凭证时自动覆盖上次异常的业务凭证并重新生成。
- 「凭证生成自动覆盖正常的业务凭证」：勾选时对无修改的正常业务凭证按模板重新生成；不勾选时直接取已有业务凭证生成总账凭证。

**扫描识别流程：**
- 增值税发票识别 → 增值税发票单据：识别结果无误时直接生成；识别结果缺失或关键信息无法识别时仅生成增值税发票识别，用户手工修改后保存再点击"生成单据"。
- 增值税发票识别上「已生成单据」字段为反写标识，标记是否已产生增值税发票单据。
- 抵扣联可产生增值税发票识别，但不能产生增值税发票单据；只有记账联和发票联允许记账。
- 扫描识别模板管理中勾选"单据生成之后自动审核"后可自动审核；此参数需结合凭证自动生成方案"单据审核自动生成凭证"及对应凭证模板共同生效。
- 自定义单据识别 → 银行回单收款/付款：识别结果无误直接生成；识别缺失或关键信息无法识别时仅生成自定义扫描识别，手工修改保存后点击「生成单据」生成对应单据。
- 自定义单据识别上「已生成单据」为反写标识，记录是否已产生对应单据。

## 4. 与生产、供应链的接口

**凭证生成入口分布：**
- 业务凭证查询、凭证生成、凭证生成情况查询入口均存在于：应收款管理、应付款管理、出纳管理、存货核算、产品成本核算、资产管理系统（原文列举）。
- 原文仅说明"各业务系统的单据设置凭证模板后，均可通过智能会计平台自动生成凭证"，未列举具体业务单据种类（生产领料、完工入库、采购/销售单据等）。

**对账方案来源单据与业务报表：**
- 业务单据对账方案中来源单据涵盖业务系统单据，原文举例：应收款明细表来源于应收单、其他应收单、收款单、收款退款单、应收核销单。
- 业务报表对账方案中业务报表包括：应收明细表、应付明细表、存货收发存汇总表、资产价值变动表、现金日记账、银行存款日记账、应收票据余额表、应付未开票明细表、应收按发票对账、应付按发票对账、入库勾稽汇总表、应收未开票明细表。
- 对账项目涵盖：应收款、应付款、存货、资产原值、累计折旧、减值准备、资金、应付暂估。

**存货核算与对账：**
- 存货收发存汇总表所涵盖单据范围为存货核算—核算单据查询所核算到的单据，可查看单据的出入库序列及调拨方向。
- 存货对账差异分析规则中涉及：出入库序列（出库/入库）、调拨方向（普通/退货）、存货类别。
- 存货类凭证模板借贷方向规则：出库序列普通→存货科目贷方；入库序列普通→存货科目借方；退货时方向不变但金额取 0 - 对应成本金额字段（生成负金额分录）。
- 存货核算类单据支持多会计核算体系＋多会计政策下的成本取值，可满足不同暂估模式记账及对账需求。

**核算维度与单据字段映射：**
- 对账方案中核算维度可对应单据字段（含用户自定义字段），支持多核算维度取数。
- 业务日期、币别、核算组织均从单据字段映射取值（字段名在对账方案中灵活配置）。
- 凭证模板中业务日期字段来源于来源业务单据上的日期字段，用于往来科目总账账龄分析。
- 凭证模板中业务编号取单据上的文本字段，用于往来科目总账账龄分析。

**存货类别 / 物料维度参数：**
- 「核算维度存货类别按物料对应核算组织取值」：控制凭证生成和对账时，科目核算维度取账簿核算组织的物料存货类别，还是取单据使用组织的物料存货类别。
- 「凭证生成和对账取单据使用组织的物料」：控制凭证模板科目影响因素按存货类别区分科目时，取账簿核算组织还是单据使用组织的物料存货类别；业务报表对账过滤条件同受此参数影响。
