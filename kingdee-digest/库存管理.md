## 3. 状态流转、下推和反写
- 单据状态：暂存→创建→审核中→已审核→（反审核）重新审核；暂存时不校验【来源:其他入库单】
- 库存更新时机：参数“库存更新方式”选保存时或审核时，按组织设定，产生单据后不可改【来源:库存管理系统参数】
- 关账【来源:关账_反关账】
  - 关账后不能新增、修改、审核、反审核关账日前的库存单据。
  - 关账时生成库存余额表（关账日期、库存维度id、期初、收入、发出、结余，只有数量）。
  - 历史库存=最近关账余额+收入-发出。
- 出库申请单 / 调拨申请单的反写【来源:出库申请单】【来源:调拨申请单】
  - 下游其他出库单或调拨单保存时反写“关联数量”，更新库存时反写“数量”。
  - 支持整单关闭/反关闭、行终止/反终止、行反关闭；全部行业务关闭时整单自动关闭。
- 关联路线【来源:调拨申请单】【来源:分步式调出单】
  - 调拨申请单（普通）→直接调拨单（普通/退货）
  - 调拨申请单→分步式调出单（普通）→分步式调入单（普通）→分步式调出单（退货）→分步式调入单（退货）
  - 分步式调出时扣减可用库存、增加在途；调入时增加可用库存、冲减在途；途损也冲减在途
  - 跨核算组织的调拨会产生组织间结算清单【来源:分步式调出单】
- 检验与库存的联动【来源:库存状态转换】【来源:其他入库单】
  - 库存请检单检验后关联生成库存状态转换单。例如 100 待检→95 可用+5 不良。
  - 其他检验单 / 其他检验不良品处理单 / 其他 MRB 评审单可关联生成其他入库单（受参数“不合格品允许入库”控制）。
- 盘点流转【来源:库存盘点方案】【来源:物料盘点作业】
  - 盘点方案审核→生成物料盘点作业（执行状态：确认→盘点）→作业审核→按 货主类型+货主 生成审核状态的盘盈/盘亏单→盘点方案自动关闭。
  - 反审核作业会删除盘盈/盘亏单；由作业生成的盘盈/盘亏单不允许反审核。
- 物料周期盘点表审核时生成物料盘点作业（账存数要执行【获取账存数】才取）；关联作业全部审核后自动关闭【来源:物料周期盘点表】
- 受托加工：检验后可自动生成受托加工材料入库单（合格）或退料单（不合格）（受系统参数控制）【来源:库存管理系统参数】

## 4. 参数（库存管理系统参数）【来源:库存管理系统参数】
- **库存更新方式**：保存时/审核时
- **库存异常检查**：不予控制/预警提示/严格控制
- **日期控制**：启用库存业务日期控制、库存单据允许补录期限天数、允许提前录单期限天数、控制时点、各操作的校验日期字段
- **拣货规则**
  - 批号拣货规则：顺序出库-批号顺序 / 顺序出库-入库日期 / 近效期先出 / 手工指定
  - 保质期拣货规则：手工指定 / 近效期先出 / 先进先出
  - 两者组合决定排序。例如“近效期先出+先进先出”按 有效期至+生产日期+批号主档入库日期+批号文本 排序。
  - 另有“批号拣货考虑仓库权限范围”
- **批号和效期**：不启用批号断号补号处理、组织不参与保质期作为批号附属信息的唯一性规则、批号主档追踪信息不记录入库/出库信息
- **库存检查和控制**：库存量不为零的仓库/仓位不允许禁用、库存状态类型不允许取消、即时库存允许负库存时不提示负库存信息、负库存控制不判断辅单位数量；另外仓库级有“允许负库存”开关
- **受托**：受托收料检验后合格品自动入库 / 不合格品自动退料，以及生成单据的状态
- **其他**
  - 盘点作业审核生成盘盈盘亏单状态、业务组数据隔离、即时库存校对时更新预留量
  - 库存预警生成采购申请不考虑最小包装量、生成采购申请单据类型依据（物料属性/物料的采购类型）
  - 内置参数：如自动生成物料盘点作业的最大行数默认 10000
- **单据选项通用参数**：批号范围包含作废状态、库存为0的批号F8不显示、库存匹配依据、保存时清除XX数量为零分录【来源:单据选项库存通用业务参数】

## 5. 审批点
- 原文没有专门的审批流描述。所有库存单据都走 提交→审核；审核与否决定能否更新库存（库存更新方式=审核时）以及能否关账（存在未审核单据不允许关账）【来源:关账_反关账】
- 盘点差异：物料盘点作业由“盘点完找出账、实差异提交给上级审核”，审核后才生成盘盈/盘亏单【来源:物料盘点作业】
- 建议在流程引擎中设审批节点：盘盈/盘亏（按金额分级）、跨组织调拨申请、出库申请（非生产领用）、库存状态转换（不良转可用）

## 6. 报表

- 预警：库存预警报表、库存预警分析表（考虑采购在途；可一键生成采购申请，数量按最小订货量/最小包装量取整）、安全库存预警、保质期预警（距到期 x 天）、库存负结余预警

## 7. 对电子元器件 ERP 的结论
- **一期**
  - 基础：仓库/仓位（料架-层-格）、库存状态（可用/待检/冻结/不良/废品）、即时库存（完整库存维度）
  - 单据：初始库存、其他入/出库、直接调拨单、库存状态转换单、批号调整单（卷盘拆分合并）、盘点方案+物料盘点作业+盘盈/盘亏单
  - 规则与报表：批号编码规则+批号主档；拣货规则=先进先出/近效期；关账；保质期预警、安全库存预警、物料收发汇总/明细、库龄分析、呆滞料分析
- **二期**：分步式调拨（在途）、调拨申请/出库申请、周期盘点（ABC）、锁库与预留、序列号主档、受托加工、组装拆卸、形态转换、库存预警方案、警示灯工作台
- **电子行业扩展**（原文没有，是我方设计，用原文已有的机制承载）
  - 卷盘码（Reel ID）建为“条码主档”（见条码管理），与 物料+批号+数量 绑定。
  - 湿敏等级（MSL）作为物料属性，开封时间和车间寿命作为卷盘级属性；超时后通过库存状态转换单转“冻结”，待烘烤后再转回。
  - 先进先出：用“批号拣货规则=顺序出库-入库日期”。
