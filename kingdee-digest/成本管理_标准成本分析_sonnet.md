# 成本管理／标准成本分析

## 1. 功能点

本模块整合三大功能板块：**基础数据设置**、**标准成本卷算**、**报表分析**，支持多工厂、多组织、多会计政策、多版本。

**基础数据设置类**

- 【标准成本版本设置】：设置默认版本及影响成本卷算的因素
- 【成本BOM设置】：维护成本卷算所采用的产品BOM，支持【批量维护】、【批量更新成本BOM】、【同步至其他版本】
- 【外购物料标准价目表】：设置外购物料标准价，支持分费用项目明细设置，支持【批量维护】和【同步至其他版本】
- 【产品委外加工价目表】：设置产品委外加工费标准价，支持【业务操作】→【同步至其他版本】批量维护
- 【标准工时维护】：设置产品标准工时（人员/机器，准备/实作四类），支持【批量维护】和【同步至其他版本】
- 【标准费率维护】：设置产品标准费率（人员/机器，准备/实作四类），支持分费用项目维护，支持【同步至其他版本】

**卷算执行类**

- 【标准成本卷算】：执行标准成本卷算，确定产品标准成本
- 【标准成本合法性检查报告】：查看卷算合法性问题，支持【计算操作】→【清除卷算冲突】
- 【基础资料完整性展示】：卷算前快速查询产品各项基础资料维护情况，检查0层和1层成本BOM完整性

**报表分析类**

- 【产品标准成本查询】：从不同角度查看产品标准成本数据
- 【产品标准成本多级查询】：查询多层BOM结构产品的标准成本，支持按层级展开
- 【产品成本差异分析】：查询产品标准成本与实际成本及其差异数据

## 2. 单据与关键字段

**【标准成本版本】**

- 单据头：版本号、名称、是否默认、是否使用简化BOM、考虑子项物料的生效日期、展示跳层件、考虑供料方式、通用或报价BOM仅卷算标准工费
- 影响因素页签：准备工时、变动损耗率、成品率、固定损耗

**【成本BOM设置】**

- 单据头：核算体系、核算组织、版本、单据编号
- 明细页签：产品编码、产品名称、规格型号、产品属性、基本单位、BOM版本、来源组织、数据来源、行修改用户、行修改时间

**【外购物料标准价目表】**

- 单据头：核算体系、核算组织、会计政策、版本、币别
- 明细页签：物料编码、标准单价、数据来源
- 费用项目页签：费用项目编码、标准单价

**【产品委外加工价目表】**

- 单据头：核算体系、核算组织、会计政策、版本
- 明细页签：产品编码、成本项目编码、费用项目、标准加工价、数据来源

**【标准工时维护】**

- 单据头：核算体系、核算组织、版本
- 明细页签：产品编码、人员准备工时、人员实作工时、机器准备工时、机器实作工时、数据来源

**【标准费率维护】**

- 单据头：核算体系、核算组织、会计政策、版本
- 明细页签：产品编码、成本项目编码、人员准备费率、人员实作费率、机器准备费率、机器实作费率、数据来源
- 费用页签：费用项目名称、费用项目编码、人员准备费率、人员实作费率、机器准备费率、机器实作费率

**【标准成本卷算】**

**【基础资料完整性展示】**

- 单据头：核算体系、核算组织、会计政策、版本

## 3. 状态流转、下推和反写

**版本默认状态切换**：默认版本唯一，新版本设为默认时，上一个默认版本自动设置为非默认。

**标准成本卷算**：

## 4. 与生产、供应链的接口

**成本计算逻辑**

- 自制产品标准成本根据**产品BOM**及**标准费率**、**标准工时**计算
- 委外产品标准成本根据**产品BOM**及**产品委外加工价目表**计算，成本分为材料成本和委外加工费两部分

**BOM相关接口控制参数**

- 【考虑子项物料的生效日期】：卷算时考虑BOM子项物料的生效日期
- 【考虑供料方式】：子项供料方式为委托方供料时不参与卷算
- 【通用或报价BOM仅卷算标准工费】：勾选后卷算时仅取标准工时和费率，不取委外加工价目表
- 卷算影响因素涉及BOM上的字段：变动损耗率、成品率、固定损耗、准备工时

**核算维度**：全模块一致为核算体系、核算组织、会计政策、版本。

**业务日期与期间**：【产品成本差异分析】按开始会计年度+开始会计期间至结束会计年度+结束会计期间区间统计。

## 5. 与电子元器件制造的相关度

**判断：高**

理由：

1. **多层BOM与卷算机制高度契合**：电子元器件制造的产品BOM层级深、子项物料多，本模块提供多层BOM卷算及【产品标准成本多级查询】，可按层级展开核查，与行业实际强匹配。
2. **委外加工场景覆盖**：电子元器件制造大量存在芯片封装、PCB打样等委外工序，本模块专门设置【产品委外加工价目表】，区分材料成本与委外加工费，与该场景直接对应。
3. **标准工时四类细分适用**：人员准备/实作、机器准备/实作四类工时与费率的分离设置，适配电子元器件制造中机器节拍与人工配比差异较大的特点。
4. **多版本多组织支持**：电子元器件企业通常有多工厂或多核算主体，本模块支持多工厂、多组织、多会计政策、多版本，满足集团化管理需求。

**对接本模块需在生产/供应链单据预留的字段或接口**（仅有笔记依据的）：

- 产品BOM需维护：**变动损耗率**、**成品率**、**固定损耗**、**准备工时**（作为卷算影响因素）
- 产品BOM子项需维护：**生效日期**（对应版本参数【考虑子项物料的生效日期】）
- 产品BOM子项需维护：**供料方式**（对应版本参数【考虑供料方式】，委托方供料时不参与卷算）
- 物料主数据需区分**外购**与**自制/委外**属性，分别对接【外购物料标准价目表】和【产品委外加工价目表】
- 委外加工单据需携带：**成本项目编码**、**费用项目**（对应【产品委外加工价目表】明细字段）
- 核算组织/核算体系维度需在生产订单和采购单据上贯通，以支持本模块的核算维度过滤
