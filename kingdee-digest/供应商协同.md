## 1. 功能点【来源:供应商协同】【来源:供应商协同系统特性】
- 门户与权限：
  - 供应商协同系统参数(数据中心级启用)
  - 供应商设置(逐家启用)
  - 供应商角色(预置"供应商业务员"，只能授权协同模块对象)
  - 供应商用户(必须绑定一个供应商，严格按供应商隔离数据)
  - 供应商注册资料
- 寻源协同：
  - 询价单(企业建，可由采购申请下推) → 供应商确认
  - 报价单(供应商建，一张询价单只能推一张)
  - 比价单(企业建) → 询价单下推采购订单
- 订单协同：供应商查询并确认采购订单、变更单、新变更单；查询订单执行明细/汇总表、采购追料交货报表、供应商评估报告、交货及时率
- 交货协同：
  - 送货通知单(=企业的收料通知单；供应商填写确认交货数量、确认到货日期、确认意见)
  - 采购入库单确认、退料通知单(=退料申请单)确认、采购退料单确认
  - 来料检验单查看
- 库存协同(VMI)：即时库存、VMI 出入库汇总/明细表、VMI 消耗汇总表、VMI 消耗结算明细表、VMI 物料收发明细表
- 信息协同：企业公告(可指定适用供应商，带附件)、信息中心、第三方消息
- 财务协同：暂估应付单列表、由供应商下推财务应付单(用于开票)、应付单列表、付款申请单列表
- 对账协同：采购对账方案/对账单(供应商可发起)、应付款明细表、应付款跟踪表、往来对账明细表、应付未开票明细表、应付单开票核销明细表
- 条码协同：供应商协同条码打印(一维/二维码，可设模板和打印机地址 IP\打印机名)、打印日志(可补打)、条码主档(按供应商强制过滤)、条码扫描(收料时扫码生成收料通知/请检单/入库单)

## 2. 单据字段（只列原文字段名）
### 2.1 询价单【来源:询价单】
- 基本：单据类型(参数"更新价目表")、业务类型、采购组织、采购组、采购员、单据编号、询价日期、采购部门、报价截止日期、生效日期、失效日期、单据状态
- 商务：结算币别、本位币、汇率类型、汇率、付款条件、结算方式、价格类型(采购/委外/VMI/工序委外/工序协作)、含税、询价单名称、备注
- 适用供应商：供应商编码、供应商名称、联系人、手机、邮箱、供应商已确认、确认日期、供应商已报价、报价日期(这几项由协同平台回写)
- 明细：物料编码、辅助属性、计量单位、询价数量、到货日期、交货方式、交货地点、需求组织、需求部门、源单类型、源单单号、确认数量、确认单价、确认含税单价、确认供应商、比价关联数量、订单关联数量
### 2.2 报价单(供应商)【来源:报价单】
- 单据类型、业务类型、单据编号、报价日期、询价单号、供应商、联系人、电话、邮箱、生效日期、失效日期、备注、单据状态
- 明细：物料编码…询价数量、到货日期、交货方式、交货地点(由询价单带入，不可改)、报价数量、单价、含税单价、税率、备注
- 审核后回写询价单的"供应商已报价"和"报价日期"
### 2.3 比价单【来源:比价单】
- 单据类型、业务类型、采购组织/组/员、单据编号、比价日期、采购部门
- 询价信息：确认数量、确认单价、确认含税单价、确认供应商
- 报价信息：询报价结果(只有一行可以是"更新询价单")、确认数量、确认单价、确认含税单价、确认意见
- 选单条件：报价单已审核，且供应商已全部报价或已过截止日期
- 报价按含税单价从低到高排序；"历史价格查询"带出最近 5 笔采购订单
- 审核后，询价单和报价单的状态变为"已比价"
### 2.4 送货通知单 / 退料通知单【来源:送货通知单】【来源:退料通知单】
- 字段与企业端的收料通知单/退料申请单相同(字段更少)；供应商可填写确认交货数量、确认到货日期、确认意见，并执行确认
### 2.5 来料检验单(供应商视图)【来源:来料检验单】
- 明细：质检状态、检验结果(合格/不合格/保留)、检验数量(=实收数量−检验关联数量)、合格数、不合格数、质检方案、供应商
- 检验结果页：批号、样本破坏承担方(我方/供应商)、检验次数、状态、数量、使用决策(接收/让步接收/挑选(全检)/判退/工废/料废)
- 整体抽样：抽样方案、抽样类型、检验水平、严格度、AQL、样本量、允收数、拒收数、样本不合格数、样本破坏数
- 缺陷记录：缺陷类型、缺陷数量、缺陷原因、缺陷等级(致命/重/轻)、缺陷后果
- 检验项目：分析方法、重点检查、质量标准、检验方法、检验仪器等
- (与 质量管理.md 中的检验单一致)
### 2.6 企业公告【来源:企业公告】
- 编号、发布时间、到期日期、类型(通知公告/采购资讯/企业新闻/服务资讯)、紧急度(高/中/低)、单据状态、主题(100 字)、内容(2000 字)、适用供应商
### 2.7 供应商评估报告【来源:供应商评估报告】
- 供应商、评估组织、评估日期、评估期间从/至、评估方案、综合得分、等级分组、综合评估意见、供应商反馈
### 2.8 VMI 消耗汇总表(供应商视图)【来源:供应商协同vmi消耗汇总表】
- 与采购管理中的消耗汇总表相同：审核时自动生成物权转移单，反审核时删除
- 消耗组织的取法：销售出库=结算组织、其他出库=领用组织、生产领料=生产组织、委外领料=委外组织、直接调拨=调入货主、盘亏=库存组织

## 3. 流转与回写
- 采购申请 → 询价单 → (供应商确认) → 报价单 → 比价单 → 回写询价单的确认价/确认供应商 → 询价单下推采购订单；单据类型参数可以让比价后自动更新价目表【来源:询价单】【来源:比价单】
- 采购订单/变更单审核 → 发布到门户 → 供应商确认；收料通知审核 → 送货通知 → 供应商确认交货数量/日期【来源:供应商协同】
- 消息：业务操作、审批流消息节点和广播都可以推送"第三方消息"(需要二次开发对接短信)【来源:第三方消息】

## 4. 对电子元器件 ERP 的结论
- **一期(精简门户)**：
  - 供应商用户绑定供应商并隔离数据
  - 供应商查看并确认 PO 和 PO 变更(确认交期)
  - 送货通知确认(确认交货数量、确认到货日期)
  - 供应商按我方条码规则打印来料标签(卷盘码，内容含 料号/批号/D/C/数量/MPQ)；收料时扫码生成收料通知
  - 查看来料检验结果和退料通知
- **二期**：询价/报价/比价、VMI 库存协同、对账与财务协同、企业公告、评估报告反馈、第三方消息。
- 扩展(原文没有)：供应商门户上传 CoC/RoHS 报告附件，挂在送货通知上。
