# 财务会计／票据管理

## 1. 功能点

**应收票据**
- 管理银行承兑汇票和商业承兑汇票的接收，支持多笔收款合并签发一张应收票据
- 后续结算：贴现、背书、背书退回、到期收款、退票，每次结算自动产生应收票据结算单
- 支持等分化电票拆分（应收票据拆分单），将一张票据拆分为多张子票据分别结算
- 支持取消处理，逐次回滚最近一次结算业务操作

**应付票据**
- 管理应付票据签发及付款处理，支持多笔付款合并签发一张应付票据
- 后续结算：到期付款、退票，每次结算自动产生应付票据结算单
- 支持取消处理（每次仅撤销最近一次结算业务）

**支票管理**
- 全流程管理：购置、领用、签发、报销、核销、作废与反作废

**电子票据（银企平台对接）**
- 电子票据开票单：由付款单下推生成，出票成功后自动生成应付票据
- 电子票据签收单：从银企平台查询待签收票据，签收成功后自动下推生成应收票据
- 电子票据背书单：由付款单/付款结算单/收款退款单下推生成，提交银企完成背书
- 电子票据贴现单：通过贴现申请单提交银企，贴现成功后生成应收票据贴现结算单
- 贴现申请单：未到期应收票据发起贴现申请，支持审核、提交银行、同步银行状态、撤销提交银行

**报表查询**
- 应收票据余额表、应收票据使用流水、应收票据执行明细、应收票据收发存明细表
- 应付票据余额明细表、应付票据余额明细表过滤条件

**票据池管理**
- 支持事业部下的票据池管理，结算中心代事业部成员单位收发票据
- 与资金管理联用，支持结算中心下拨并控制应收票据使用额度

## 3. 状态流转、下推和反写

### 应收票据结算状态流转

| 操作 | 前提 | 结算状态变更 |
|---|---|---|
| 到期收款 | 已审核，结算状态为空或背书退回 | → 收款 |
| 背书 | 已审核，结算状态为空或背书退回 | → 背书 |
| 背书退回 | 结算状态为背书 | → 背书退回 |
| 贴现 | 结算状态为空或背书退回 | → 贴现 |
| 退票 | 结算状态为空或背书退回，且已被收款单完全引用 | → 退票 |
| 票据拆分 | 结算状态为空或背书退回，且非质押托管状态 | — |
| 取消处理 | 结算状态不为空 | 回滚至最近一次操作前的状态 |

### 应付票据结算状态流转

| 操作 | 前提 | 结算状态变更 |
|---|---|---|
| 到期付款 | 已审核，结算状态为空 | → 付款 |
| 退票 | 已审核，结算状态为空，且已被付款单完全引用 | → 退票 |
| 取消处理 | 结算状态不为空 | 回滚至最近一次操作前的状态 |

### 自动产生下游单据

**应收票据操作：**
- 到期收款 → 应收票据结算单（单据类型：应收票据到期收款），支持生成记账凭证
- 贴现 → 应收票据结算单（单据类型：应收票据贴现），支持生成记账凭证
- 背书（冲减应付款/转预付款）→ 应收票据结算单 + 付款单；（转其他应收款）→ 应收票据结算单 + 其他应收单；支持生成记账凭证；付款单、其他应收单不需要生成记账凭证
- 背书退回（上次背书为冲减应付款/转预付款）→ 应收票据结算单 + 付款退款单；（上次背书为转其他应收款）→ 应收票据结算单 + 负数其他应收单
- 退票（选其他应收单）→ 其他应收单；（选收款退款单）→ 收款退款单；同时产生应收票据结算单，支持生成记账凭证

**应付票据操作：**
- 到期付款 → 应付票据结算单（单据类型：应付票据到期付款），支持生成记账凭证
- 退票 → 应付票据结算单（单据类型：应付票据退票）+ 其他应付单（恢复应付账款余额）；其他应付单不需要生成记账凭证

**电子票据下推链路：**
- 付款单（结算方式为银行承兑汇票/商业承兑汇票）→ 下推电子票据开票单 → 出票成功 → 自动生成应付票据
- 银企平台待签收票据 → 电子票据签收单 → 交易成功 → 自动下推生成应收票据
- 付款单/付款结算单/收款退款单（背书页签勾选银企背书）→ 下推电子票据背书单 → 提交银企 → 票据状态变为「背书」→ 生成应收票据背书结算单
- 应收票据 → 贴现申请单 → 审核 → 提交银行 → 自动生成电子票据贴现单 → 交易成功 → 自动生成应收票据贴现结算单，票据结算状态变为「贴现」；交易失败 → 可撤销提交银行 → 反审核修改后再次提交

**收款单/付款单与票据的引用关系：**
- 收款单引用应收票据（审核后），系统自动写入收款单页签字段（业务日期、单据编号、单据类型、占用票据金额）
- 付款单在表体应付票据页签录入或选择应付票据流水号，完成对应付票据的引用

**期初票据：** 需勾选「期初」标识，勾选后不能被收款类/付款类单据关联（原文未见「期初」字段在界面中的具体位置）。

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
1. 电子元器件制造企业采购量大、供应商集中，使用银行承兑汇票结算应付款是常见业务；应付票据的采购组织/采购部门匹配条件对多采购主体场景有实用价值。
2. 客户回款常含商业承兑汇票，应收票据贴现、背书用于调节资金头寸，属于制造企业高频动作；但票据管理本身不涉及生产或工艺特性，不构成制造核心需求。
3. 本模块与生产领料、完工入库、BOM、成本核算无直接接口，制造端数据不在此模块处理。
4. 若企业规模较小、票据业务简单，支票管理和电子票据银企对接功能的优先级可酌情降低；相关度"中"而非"高"的主要原因正是与生产主线的隔离。

**生产/供应链单据为对接本模块需预留的字段或接口（仅有笔记依据的）：**
- 采购单/付款单：需能下推或关联应付票据，并传递采购组织、采购部门、采购组、采购员，以满足应付票据中核销匹配条件
- 付款单：结算方式字段需支持"银行承兑汇票"和"商业承兑汇票"取值，方可触发下推电子票据开票单的流程
- 收款单：需能引用应收票据（票据流水号），并由系统写回业务日期、单据编号、单据类型、占用票据金额至应收票据的收款单页签
- 付款单/付款结算单/收款退款单：背书页签需有"银企背书"勾选项，以触发下推电子票据背书单
