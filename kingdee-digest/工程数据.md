# 工程数据（BOM/ECN/替代/工艺）摘要 — G1a
> 范围：生产制造_工程数据.md 53页（含孤立8），正文126,396字。重复页：物料清单批量维护=bom批量维护过滤界面、禁用子项查询=物料禁用查询、可禁用物料分析。非本域：中央厨房、制造云巡检/报告(仅极少文字)。电子元器件相关度：**高**。

## 1. 功能点
- 物料清单(BOM)：标准BOM/配置BOM；用途 自制/委外/通用/组装/报价；联副产品；子项有效期；阶梯用量及损耗；替代设置；BOP（生产线工位）；位置号；同步更新在制用料清单与计划BOM。【来源:物料清单】【来源:工程数据】
- BOM维护工具：批量维护（新增/更换/删除/修改子项，可生成工程变更单）、树形维护（批量提交审核、复制升版）、产品BOM分配（组织间）。【来源:物料清单批量维护】【来源:物料清单树形维护】
- 物料阶梯损耗：原文明确用于"电子行业电容电阻"阶梯损耗。【来源:物料阶梯损耗】
- 查询：正查(单级/多级)、反查、汇总查询(累计用量)、BOM对比/多BOM对比、成本查询、同步检查、物料禁用查询、BOM修改日志、可删除/可禁用物料分析、ECN呆滞分析、变更影响查询。
- 替代方案：BOM替代/订单替代；组合/非组合替代。【来源:替代方案】
- 工程变更：工程变更申请单 → 工程变更单(ECN) → 旧料清理。【来源:工程变更申请单】【来源:工程变更单】【来源:旧料清理】
- 产品配置/模型配置（建模变量、模型规则、产品模型）。
- 工作日历、日历模板、班制、班次。【来源:工作日历】
- 工艺资源（工艺路线）、网格工艺(仅图)、生产线基础数据（→G1b）。

## 3. 状态流转
- BOM：创建→审核中→已审核；禁用/反禁用；"是否变更中"标识（存在未生效ECN时）。参数：BOM存在库存或未完成单据不允许禁用、父项禁用自动禁用BOM。【来源:工程数据参数】
- 工程变更申请单 变更状态：未处理 → 处理中 → 已生效 → 已关闭（由下游ECN反写；可关闭/反关闭）。【来源:工程变更申请单】
- ECN：审核后按变更类型生效：立即变更/按生效日期/用完旧料（配合旧料清理）。

## 4. 下推/反写
- 工程变更申请单 → 工程变更单；ECN 生效反写申请单变更状态。
- ECN 审核：版本升级生成新BOM版本或直接修改；勾选"更新用料清单"则刷新在制生产/委外用料清单。【来源:工程变更单】
- BOM"同步更新"：更新在制生产/委外用料清单和计划BOM。【来源:物料清单】
- BOM批量维护可生成工程变更单。

## 5. 关键参数
损耗率处理方式（1/(1+损耗率) 或 1/(1-损耗率)）、替代料损耗率取值、BOM展开算法(精确/容错)、批量维护已审核BOM、跳层件子项工序继承、成本查询取价参数。【来源:工程数据参数】

## 6. 审批/工作流点
BOM审核（树形批量提交审核）；工程变更申请单审核→ECN审核（ECN为最关键审批：涉及研发、工艺、品质、计划、采购会签——会签角色为建议，原文未列审批人）；替代方案审核；工艺路线审核。

## 7. 报表/查询
BOM正查/反查/汇总/对比、成本查询、ECN呆滞分析、变更影响查询、BOM修改日志、可删除/可禁用物料分析。

### 9.1 物料清单
- **BOM版本**：即物料清单的编码，具有唯一性。
- **单据类型**：用来定义必录字段、打印、审核和流程控制。
- **父项与子项的关系**：
  - **父项物料属性是外购时，子项只能是外购件。**
  - 子项不能与父项相同。
- **成品率**：投入 100 套原材料能产出多少套成品。
- **父项物料单位**：默认取生产单位，可以修改。
- **是否变更中**：存在未生效且未作废的 ECN 时为是。
- **联副产品**：
  - 成本权重默认 100。
  - 勾选"倒冲领料"后，入库或汇报时会生成倒冲领料。
  - 辅助属性影响计划时必录。
- **项次**：**同一组替代关系的物料项次相同**；新增分录时项次依次递增。
- **供应组织**：原文建议存在委托加工关系时才维护；维护后，子项 BOM 版本才可以修改。
- **供应类型**：即该子项生成计划订单时的投放类型。
- **用量类型**：
  - 固定：子项用量与父项数量无关。
  - 变动：子项用量与父项数量成线性比例。
  - 阶梯：父项数量落在不同区间时，子项用量取不同的值；各区间不能重叠。
- **超发控制方式**：允许超发、最小发料批量、不允许超发、按损耗率超发。
- **BOP 页签**：同一生产线下，相同项次的分子之和必须等于子项明细页签的分子。
- **其他子项字段**（来自产品配置页同名字段）：
  - **位置号 = 子项物料的插件位置。**
  - **工序必须是正整数。**
  - 提前期偏置时间：相对第一道工序开工的时间，负数表示开工前就要备好料；单位可选天、时、分、秒。
  - 倒冲时机：只有发料方式为直接倒冲或调拨倒冲时才可维护。
  - **替代件不能手工指定，只能由替代设置产生。**
  - 父项是生产线生产模式时，子项发料方式只能是调拨倒冲或发料，倒冲时机一律为汇报倒冲。
- **必填字段**（截图上带 * 的）：单据类型、BOM分类、BOM用途、父项物料编码、父项物料单位、子项物料编码、子项类型、子项单位、用量类型。【来源:供应来源与bom中的供应组织关系-图】

### 9.2 替代方案
- **替代策略**：
  - 混用：主料和替代料同时作为供给和预计量。
  - 手工：按用户指定的供给比例产生需求。
  - 整批：同一笔需求要么全用主料，要么全用替代料。
  - **整批+混用：先按整批替代，满足不了再按混用。**
- **替代方式**：
  - 替代：需求满足不了时，产生主物料的供给。
  - 取代：需求满足不了时，产生替代物料的供给。
  - 按比例：按净需求比例同时产生主料和替代料的供给。
- **替代主料**：MRP 根据替代主料的供给判定是否触发替代；优先级相同的替代物料中只能有一个替代主料。
- **优先级**：数值越小，优先级越高。
- **生效/失效日期**：同一组替代物料的生效、失效日期必须相同。
- **物料属性限制**：主料和替代料都只能是自制、外购、委外或配置类。【来源:替代方案】

### 9.3 工程变更单（ECN）
- **BOM版本**：F8 只能选使用组织等于变更组织的 BOM，且 **BOM 父项必须勾选"启用ECN"**。
- **指定项次**：为空时，新增子项加到最后一个项次。
- **子项物料编码**：选择范围随行标示变化。新增、修改后两类行选物料列表；修改前、删除、失效三类行只能选 BOM 里现有的子项。
- **子项属性的可编辑性**：新增、修改后两类行可以维护；修改前、失效、删除三类行只显示原值。
- **阶梯用量**：起始数量（含）到截止数量的各区间不能重叠。
- **联副产品**：物料必须勾选"可为联副产品"。
- **申请单相关字段**（申请单号、申请组织、申请部门、申请人）：从申请单下推时自动携带且不可修改。【来源:工程变更单】

### 9.4 工程变更申请单
- **变更组织**：必须具有工厂职能。
- **物料**：必须勾选"可为主产品"。
- **BOM版本**：必须是已审核状态。
- **版本升级、现场更新**：两者默认都不勾选，且**不能同时勾选**。
- **需要验证**：勾选后"需要结果"变为必录。
- **ECN单号**：记录下游工程变更单的单号。【来源:工程变更申请单】

### 9.5 工艺路线（工艺资源）
- **工艺路线编码**：不可重复。
- **工艺类型**决定物料字段怎么填：
  - 物料：必须填物料编码。
  - 物料组：必须填物料分组，不能填物料编码。
  - 通用工序集：物料和物料分组都不能填。
- **工序序列**：
  - 第一行固定为 0 号主干序列，不可维护；其他行只能选并行序列或替代序列。
  - 转出、转入工序必录，且转出工序 ≤ 转入工序。
- **工序号**：同一序列内不能重复。
- **工序数量参数**：基本批量默认 1；提前期以小时为单位，默认 0；偏置时间填 −1 表示串行。
- **汇报比例**：汇报上限比例 = 允许超额汇报的比例；汇报下限比例 = 自动完工的下限。
- **首检控制方式**：严格控制时，首检合格后才能按正常方式汇报；非严格控制时不受首检单状态限制。
- **委外页签**：
  - 只有工序控制码的加工方式为"委外加工"或"厂内委外皆可"时才能维护。
  - "委外加工"时供应商必录。
  - 委外单价不填时，从采购价目表取。【来源:工艺资源】

### 9.6 工程数据参数和日历
- **损耗率处理方式**：1/(1+损耗率) 或 1/(1−损耗率)。
- **新增子项生效日期**：默认取系统日期，也可设为指定日期。
- **子项影响计划的辅助属性**：在保存时还是提交时校验必录，可配置。
- **BOM 禁用限制**：有即时库存，或有未完成的生产订单、委外订单、用料清单时，不允许禁用。
- **修改主料用量时自动修改替代料用量**：只在通过 ECN 或批量维护修改时触发。【来源:工程数据参数】
- **班制/班次**：每天的工作小时数不能超过 24。【来源:班次】
- **工作日历模板**：规则类型有固定日期、周、月、年，配合优先级使用。【来源:工作日历模板】
