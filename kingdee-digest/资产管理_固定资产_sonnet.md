# 资产管理／固定资产

## 1. 功能点

**基础资料与参数**
- 维护资产使用状态基础资料，控制卡片是否参与折旧计算（资产状态）
- 对资产增减方式进行分类管理，审核后可用，支持"税法允许一次性折旧"标记（变动方式）
- 新增资产类别，审核后被资产卡片、资产租入单引用；设置编码规则和默认计量单位（资产类别）
- 定义新增/清理当期折旧计提规则及折旧要素变动影响规则（折旧政策）
- 定义静态/动态折旧公式及最后一期处理规则，系统预置四种（折旧方法）
- 配置系统全局参数，涵盖汇率取数、领用同步、编码规则、调拨自动化等（固定资产参数设置）
- 设置资产组织与货主组织托管/代管关系（组织业务关系）
- 记录资产存放位置（资产位置）
- 配置字段自动携带规则（字段自动携带设置）（原文正文仅含外部链接，无详细内容）

**系统启用**
- 按货主组织+会计政策设置启用期间，支持反启用（启用固定资产系统）
- 录入开始使用日期早于启用期间的历史资产卡片（初始化卡片）

**卡片管理**
- 记录资产的财务信息、实物信息、附属设备信息、使用分配信息（资产卡片）
- 七种建卡途径：手工建卡、采购收货建卡、库存领用建卡、盘盈建卡、调拨建卡、拆分建卡、合并建卡
- 卡片拆分：一张卡片拆分为多张，原卡片处置情况标记为"拆分清理"
- 卡片合并：两张或以上卡片合并为一张，原卡片处置情况标记为"合并清理"
- 一张卡片管理多个实物资产，按资产编码区分（多资产管理专题）
- 实物资产按比例分配至多个使用部门/使用人，折旧费用分摊（多使用部门专题）
- 多会计政策下对同一卡片进行多价值管理（多会计政策专题）

**变更与处置**
- 通过变更单对资产卡片信息进行有记录的修改（资产变更单）
- 对多个资产卡片进行有记录的批量修改/变动（资产批量变更单）
- 批量变更支持字段（2.11节列六种）：资产名称、资产位置、资产状态、使用分配、保管人、规格型号
- 资产全部处置与部分处置（资产处置单）
- 记录资产借用（借入/借出）及归还，支持批量借用（资产借用单）

**申请与采购**
- 资产采购申请源头单据的录入与审核（资产申请单）

**租赁**
- 新增资产租入单，维护基本信息后系统自动产生付款计划、自动计算财务信息、审核后自动产生资产卡片（资产租入）

**调拨**
- 资产从其他资产组织或货主组织调入到当前组织，由资产调出单自动生成，审核后可下推建卡（资产调入/资产调入单）
- 资产从一个资产组织/货主组织调出到另一个组织，审核自动生成调入单，调入审核后可下推处置单（资产调出单）

**领用**
- 记录资产领用情况，审核后提示更新资产卡片使用分配信息（资产领用单）

**盘点**
- 定义盘点范围，审核后生成资产盘点表，支持反审核（盘点方案）
- 通过盘点方案生成资产盘点表，录入初盘/复盘数据，审核后生成盘盈盘亏单（资产盘点表）
- 通过盘盈盘亏单下推资产卡片（盘盈）或资产处置单（盘亏）（盘盈盘亏单）

**折旧**
- 按货主组织、会计政策、期间自动批量计提折旧（计提折旧）
- 支持平均年限法、双倍余额递减法、年数总和法、工作量法四种折旧方法，含一次性计提折旧
- 对当期折旧额进行手工调整，控制调整是否影响以后期间（折旧调整单）
- 为工作量法折旧资产录入本期工作量，每期间/货主/会计政策唯一（工作量管理）

**期末与账务**
- 按货主组织+会计政策执行期末结账，与总账结账存在顺序控制（固定资产结账/反结账）
- 账务处理由智能记账平台生成凭证（财务处理）

**报表查询**
- 查询单张卡片历史变动情况（变动过程记录表）
- 多维度查询各期明细资产折旧情况（折旧明细表）
- 按资产类别、资产状态、变动方式、使用部门等维度汇总查询各期折旧情况（折旧汇总表）
- 按费用项目、使用部门、变动方式等多维度查询折旧费用分摊明细（折旧费用分配表）
- 查询各资产原值、累计折旧、减值准备在指定期间的变化（资产价值变动表）
- 查询指定时点的资产价值状况，支持联查卡片（资产价值清单）
- 查询指定会计期间资产变动（增加/减少）及期末结存金额（资产变动结存表）
- 查询资产实物状况，支持多维度查看附属设备、使用分配、维修保养信息（资产实物清单）
- 查询指定入账日期内卡片的折旧到期情况（资产到期提示表）
- 反映指定会计期间内固定资产数量领用结存情况，按资产编码展现领用及归还记录（资产领用结存表）

## 3. 状态流转、下推和反写

**审核控制（基础资料）**
- 变动方式、折旧方法、折旧政策、资产状态：审核后方可被使用
- 盘点方案：提交→审核→生成资产盘点表；未生成盘点表时允许反审核

**系统启用**
- 货主组织启用会计政策后才能新增该政策下的资产卡片
- 存在资产卡片数据时不允许反启用

**资产卡片**
- 建卡来源：手工新增，或通过选单从收料通知单、其他出库单、资产调入单、盘盈单、资产租入单生成
- 领用数量由资产领用单领用时反写至实物信息页签；可领用数量 = 数量 - 领用数量
- 累计折旧、累计使用期间数、累计折旧期间数每期计提折旧后自动更新至卡片
- 拆分/合并操作清除本期已计提折旧，需重新计提；操作日期须在会计政策当期期间内
- 撤销拆分：删除拆分后的卡片；撤销合并：删除合并后的卡片

**资产变更单/资产批量变更单**
- 审核后变更内容自动同步更新至资产卡片；反审核后卡片内容自动还原，反审核后可删除
- 变更单的凭证资料信息自动读取和计算，不可手工修改

**资产处置单**
- 操作前提：资产卡片已审核
- 完全处置后，卡片处置情况标记为"完全处置"，不能再进行其他日常业务
- 部分处置后，卡片资产数量变为剩余数量，未处置资产可继续其他业务
- 反审核后清除"完全处置"标记，反审核后可删除
- 下推来源：可由资产调出单或盘盈盘亏单通过选单生成；盘亏生成时处置方式显示"盘亏"，调出生成时显示"调出"

**资产借用单**
- 新增→保存→提交→审核；已审核可反审核，反审核后可删除
- 归还在原借用单上勾选"是否归还"并填写归还日期
- 审核后可在资产卡片中联查借用记录

**资产申请单**
- 提交→审核；反审核后可修改和删除

**资产租入单**
- 审核→自动产生资产卡片；卡片保存后反写租入单的"关联卡片编码"

**资产调出单/资产调入单**
- 资产调出单审核→自动生成资产调入单；资产调入单不支持手工新增
- 资产调入单审核→自动对关联的资产调出单进行确认
- 资产调入单反审核→上游资产调出单才可执行反审核；调出单反审核成功后自动删除调入单；调入单不提供删除功能
- 资产调出单反审核前提：下游调入单未执行审核
- 资产调入单→下推资产卡片（仅支持）
- 资产调出单→下推处置单（仅支持），前提是调入单已审核

**资产领用单**
- 审核后提示更新资产卡片使用分配信息；反审核后可删除

**盘点**
- 资产盘点表操作前提：资产卡片已审核
- 资产盘点表审核后自动生成盘盈盘亏单；下游盘盈盘亏单未提交时允许反审核
- 盘盈盘亏单（盘盈）已审核→下推→资产卡片；（盘亏）已审核→下推→资产处置单

**折旧**
- 计提折旧前提：货主组织已启用固定资产系统；资产卡片已审核
- 每次计提成功后，系统自动按货主组织及会计政策当期期间产生一张折旧调整单
- 手工调整折旧调整单不会使卡片按变动进行折旧；只有变更单变更财务信息才会
- 一次性折旧触发：卡片变动方式勾选"税法允许一次性折旧"，满足第一次折旧计提条件时一次性提完

**调拨自动化**
- 资产调出单审核后，参数"资产调拨流程自动化"勾选时：自动完成资产调入单确认、自动产生资产处置单、自动生成资产卡片
- 参数"资产调拨生成的卡片是否允许沿用原卡片编码和资产编码"

**结账/反结账**
- 结账前置条件：当期资产卡片、资产变更单、资产处置单、资产调出单、资产调入单、折旧调整单全部已审核；资产调入单/盘盈单已建卡；盘亏单/调出单已处置；本期折旧已全部计提；（参数控制）凭证已过账
- 结账成功：货主组织进入下一期间日常业务；数据按期间传递至总账
- 反结账成功：返回前一期间日常业务；不建议多期间连续反结账
- 顺序控制：固定资产必须先结账，总账才允许结账；固定资产反结账期间不能小于总账期间
- 参数"反结账校验总账结账状态"控制反结账时是否校验总账状态
