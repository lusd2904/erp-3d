# 税务管理／发票管理

## 1. 功能点

**基础资料与设置**
- 单位对应表：将系统计量单位与电子发票单位进行对应
- 物料对应表：将金税系统发票上的销售方名称/税号、劳务/货物名称、规格型号、单位与系统中的往来单位、物料对应，支持收票单与应付单精准匹配
- 税收分类编码：维护国家税务局税收分类编码，物料和费用项目绑定后方可进行金税发票操作，支持手工新增修改
- 纳税信息设置：设置企业纳税信息，作为电子发票对接的企业身份识别
- 发票管理系统参数：控制自动生成、金税开票、金税收票、旗舰发票云等行为的全局/组织级参数
- 引出方案设置：定义销售发票引出金税系统的文本文件格式与字段映射
- 金税连接设置：配置金税盘连接信息，支持主副盘管理、全电发票开票校验参数、税控设备类型等
- 旗舰发票云连接设置：配置金蝶AI套件发票云连接信息、组织信息、数电账号

**采购发票（进项）**
- 采购增值税专用发票：录入/选单/下推生成，支持反向开具报废产品收购专票
- 采购普通发票：录入/选单/下推生成，支持开具纸质/电子/全电农产品收购发票
- 进项费用增值税发票：录入/选单/下推生成，支持与应付单核销
- 进项费用普通发票：录入/选单/下推生成，支持与应付单核销

**销售发票（销项）**
- 销售增值税专用发票：手工录入或由应收单下推/选单生成
- 销售普通发票：手工录入或由应收单下推/选单生成
- 销项费用增值税发票：手工录入或由应收单下推/选单生成
- 销项费用普通发票：手工录入或由应收单下推/选单生成

**收票**
- 收票单：接收采购增值税发票，支持验证、查看、勾选认证、匹配应付、申请红字信息表
- 扫一扫收票：通过二维码调用票无忧微信公众号扫描收票，自动生成收票单
- 智能收票设置：设置定时自动收票方案，系统按间隔或指定时间自动执行收票并产生收票单
- 收票（电子发票）：从电子发票过滤列表生成采购普通发票或进项费用普通发票

**匹配与核销**
- 收票单匹配应付：支持自定义匹配方案，手动或自动匹配收票单与应付单，下推生成采购发票或财务应付单
- 匹配应付执行记录：查询每张收票单匹配执行情况，包括匹配结果及使用的匹配方案

**金税接口**
- 金税开票单列表：与航天金税自动化连接，自动提交开票/作废/打印/查询，完成后反写发票号、日期等信息；支持电票批量推送
- 销售发票引出：将已审核销售发票按方案引出为文本文件至金税系统

**认证与红冲**
- 增值税发票认证：对采购增值税发票、进项费用增值税发票进行勾选、取消勾选、勾选确认
- 增值税可抵扣额维护：对四类进项发票维护可抵扣额
- 红字专票信息表：跨月红冲蓝字专用发票时，申请红字信息表并关联红字发票
- 拆分开票：销项开票金额超限额时自动拆分，提供4种拆分参数

**报表分析**
- 采购发票账龄分析表：以采购发票为基准进行账龄分析，支持自定义账龄区间
- 销售发票账龄分析表：以销售发票为基准进行账龄分析，支持自定义账龄区间
- 进项发票明细表：查询企业当期进项发票明细，支持分组汇总与显示选项过滤
- 销项发票明细表：查询企业当期销项发票明细（含价税合计、税额、可抵扣额），支持分组汇总与显示选项过滤

## 3. 状态流转、下推和反写

**自动生成发票**
- 应收单审核时，若参数「应收单审核时自动生成销售发票」启用，自动生成销售发票；必录字段完整则单据为创建状态，不完整则为暂存状态
- 应付单审核时，若参数「应付单审核时自动生成采购发票」启用，自动生成采购发票；逻辑同上

**下推与选单（采购方向）**
- 在采购发票新增界面点"选单"，从应付单列表选单带入字段，可修改单价、数量等后保存
- 从应付单列表勾选后点"下推"，选择目标单据类型为采购发票，系统带入字段；支持按明细分录合并或不按明细分录合并两种方式
- 应付单下推路径：【财务会计】→【应付款管理】→【采购应付】→【应付单列表】

**下推与选单（销售方向）**
- 在销售发票新增界面点"选单"，从应收单列表选取，字段自动携带，可修改单价、数量等
- 从应收单列表勾选后点"下推"选择目标单据类型；下推多张发票时系统返回上下分栏界面，可通过"上一行"、"下一行"逐张查看修改，最终点"生成全部"或逐一点"保存"
- 应收单下推发票时可选择按明细分录合并或不按明细分录合并
- 应收单下推路径：【财务会计】→【应收款管理】→【销售应收】→【应收单列表】

**收票单匹配与下推**
- 收票单匹配应付后，自动下推生成采购发票或财务应付单
- 智能匹配应付（扫一扫收票）：匹配成功后自动下推生成采购增值税发票/财务应付单，且自动保存、提交、审核

**核销**
- 应付单与采购发票可进行应付开票核销
- 应收单与销售发票可进行应收开票核销（细则原文未展开）
- 账龄分析表界面提供调用核销的功能

**金税接口反写**
- 金税开票完成后，系统自动将发票号、日期等信息反写回系统单据头
- 启用简化显示模式后按【发票号码（共n张）】格式显示

**收票（电子发票）**
- 生成的发票为审核状态，用户可反审核发票

**汇率**
- 下推采购/销售发票时，默认取实时汇率；启用参数后支持从上游订单、应付单/应收单或蓝字发票携带汇率

**结账限制**
- 启用参数后，所属期间业务单据必须全部为已审核状态，否则不允许结账

**智能收票设置**
- 方案需审核成功后，系统才会按时自动执行收票

**红字专票**
- 已开蓝字专用发票跨月红冲需先申请红字信息表，再创建红字发票并与信息表关联
- 参数「发票红冲时仅允许校验通过的红字专票信息表发起开票」可控制该校验

**税额计算规则（金税开票单折扣行）**
- 按含税单价录入时：税额 = 折扣行价税合计÷（1+税率）×税率
- 按不含税单价录入时：税额 = 折扣行不含税金额×税率
- 参数「金税开票单折扣行改按折扣额直接计算」可切换计算方式
