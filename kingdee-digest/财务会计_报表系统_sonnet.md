# 财务会计／报表系统

## 1. 功能点

**报表模板管理**
- 新建、编辑、查看、删除、审核、共享、禁用报表模板
- 从云端模板库下载报表模板（报表云模板）；插入系统预置模板（资产负债表、利润表、现金流量表、所有者权益变动表、财务指标分析表）
- 跨核算体系、跨组织共享已审核报表模板
- 预置表样更新：从云端下载财务报表新表样，或手工导入表样列表

**报表编制与取数**
- 基于报表模板新建报表，设置取数参数（账簿、币别、年度、期间）并执行重算取数
- 通过 ACCT、ACCTCASH、ACCTEXT、ACCTITEM、REF、REF_F、RPTINFO 等取数公式配置报表取数来源
- 设置页签（表页）级取数参数，优先级高于报表公式取数参数
- 自动计算／手动计算模式切换；重算表页／全部重算／终止计算
- 批量填充向导：自动向模板填充项目公式和取数公式
- 取数公式合法性检查

**报表项目与基础资料**
- 维护报表项目（计算项／文本项，取数类型：科目、现金流量项目、项目合计）及关系表达式
- 报表项目关系表达式查验：批量校验科目、现金流量项目、报表项目是否存在
- 维护项目数据类型（系统预设 11 种常用类型）
- 维护金额单位基础资料，支持同一报表按不同金额单位出具
- 维护报告维度（以客户、供应商等基础资料或辅助资料作为报表维度）
- 设置净值重分类方案（合同负债与合同资产、递延所得税负债与资产、应收账款与应付账款等）

**模板样式方案**
- 在报表模板定义前独立设置报表样式、填充内容及取数公式
- 支持报表类型：个别报表、自定义报表、阿米巴报表（报表系统）；另含合并报表、汇总报表、工作底稿、抵消表（合并报表系统）

**自定义报表（分析报表）**
- 不依赖报表模板，直接在报表编辑器中编制格式与取数公式，通过报表重算取数

**报表检查与审核**
- 表内勾稽关系设置与检查
- 项目勾稽关系设置、分配给组织，设置控制节点与控制强度
- 项目勾稽关系查验：左表达式、右表达式、关系表达式
- 报表检查：表内勾稽关系检查、报表项目勾稽关系检查、全部检查
- 舍位平衡设置与执行（元→千元／万元单位转换后重新平衡）
- 报表披露信息编写与引入；批注管理（插入、编辑、删除、显示／隐藏）
- 提交、审核、反审核

**报表分析**
- 结构分析、比较分析（与年初／预算／指定基期比较）、趋势分析（绝对数／定基／环比）

**自动化与数据管理**
- 报表自动生成方案：定时执行或立即执行，自动生成报表
- 报表推送邮件设置：配置发件人、收件人及关联报表模板，方案执行后触发邮件推送
- 报表邮件发送日志：查看邮件发送记录
- 报表数据授权：对用户或角色设置报表模板数据访问权限
- 项目数据归档／反归档：将历史年度项目数据归档，提升加载和计算性能
- 项目数据查询：快速查询并引出所有报表数据，用于二次复杂财务分析
- 动态项目数据查询：动态罗列项目数据，用于二次复杂财务分析
- 报表参数设置：配置数据权限控制、报表打开方式、报表编制控制、HTML5在线查看等参数

## 3. 状态流转、下推和反写

**报表模板状态流转**

| 操作 | 目标状态 |
|------|---------|
| 新建保存 | 在制 |
| 提交 | 审核中 |
| 审核 | 审核 |
| 反审核 | 重新审核 |
| 禁用（任意状态） | 禁用 |
| 反禁用（仅禁用状态） | 原文未见目标状态描述 |

- 仅「在制」和「重新审核」状态的模板允许修改内容
- 提交是审核的前置步骤；审核与反审核须在报表编辑器【审阅】菜单中完成，列表工具栏点击【审核】后仍需进入编辑器确认
- 共享给目标组织的报表模板状态为「在制」
- 禁用后报表模板不可进行任何操作

**报表状态**
- 报表存在审核状态，报表管理中提供审核操作
- 报表保存时检查：勾选「报表保存时即检查」选项后，保存时自动触发表内勾稽关系检查
- 建议在报表已审核状态下执行报表分析并保存；在未审核状态下执行分析生成的页签保存后不能删除
- 【报表编制控制】参数：「主账簿未结账，禁止提交报表」开启后，报表期间处于主账簿未结账期间的报表无法提交

**取数参数优先级**（原文明确）
单元格定义参数 → 表页取数参数 → 报表公式取数参数 → 报表属性参数

**重算触发规则**
- 自动计算模式：数据或公式变动即自动重算
- 手动计算模式：需手工执行【重算表页】或【全部重算】

**勾稽关系控制强度**
- 控制强度设为「不通过」时，勾稽关系不满足则不予保存或提交或审核
- 合并报表场景：子公司提交报表前必须通过勾稽关系检查

**报表自动生成方案**
- 新建方案后需执行【启用】才可定时运行；可点击【执行】并输入重算时间立即执行

**表内勾稽关系控制**
- 控制强度设置为「不通过」时，勾稽关系不正确则不予保存或提交或审核

**锁定**
- 锁定后的单元格禁止编辑；「锁定的报表表页允许重算」参数开启后，锁定表页仍可重算

**项目数据归档限制**
- 已归档年份的所有期间报表不能执行新增、保存、删除、接收、反接收操作
- 可对已归档年份执行【反归档】

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
1. 报表系统提供资产负债表、利润表、现金流量表、所有者权益变动表等标准财务报表，电子元器件制造企业的会计主体同样需要这些报表，直接可用。
2. 核算维度、报告维度功能可支持按物料分组、客户维度出具分析报表，对元器件制造按产品线或客户做收入成本分析有一定价值。
3. 本模块取数来源仅为总账，原文未见直接对接生产领料、完工入库、工单成本等制造核心单据的接口；制造场景核心的成本核算、存货核算需依赖其他模块先将数据过账到总账，报表系统才能取到，存在间接依赖。
4. 原文未见与 MRP、BOM、工单、质检等制造专项功能的直接集成描述，对制造执行层的直接支撑有限。

**生产／供应链单据为对接本模块需预留的字段或接口**（仅有笔记依据的）：

- 完工入库单、生产领料单：需将成本相关数据过账至总账对应科目及核算维度，报表系统才能通过 ACCT 公式按核算维度取数；具体核算维度字段与报表取数参数中「核算维度」字段对应（原文提及核算维度可在公式取数参数中指定）
- 物料分组、客户分组：阿米巴报表报告维度要求业务单据携带【物料分组】、【客户分组】标识，以支持按分组级次取数；具体业务单据范围原文未见
- 预算对比分析：若需与 BGdata／SJdata 函数对接，业务单据的实际数须归集至预算方案对应的预算组织下，预算组织字段需在成本归集链路中预留
