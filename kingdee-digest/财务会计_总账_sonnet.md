# 财务会计／总账

## 1. 功能点

### 基础设置
- 会计政策：定义主币别、会计日历、会计要素表、默认汇率类型、资产政策、成本政策
- 会计日历：自定义会计期间，支持自然月、月度、周（52周/53周/445）三种期间类型
- 会计核算体系：定义核算组织层级关系与适用会计政策，区分默认核算体系与法人核算体系
- 会计要素：定义要素余额方向、是否损益科目、是否表外科目、是否支持结转损益
- 多会计政策：按核算组织设置适用会计政策，影响总账、资产管理、存货核算系统
- 多币别核算、多账簿核算
- 币别、汇率、结算方式、摘要库、核算维度、科目表、科目、账簿、账簿隶属关系等基础资料维护
- 核算维度数据范围：设置指定账簿、指定科目的核算维度数据范围及默认值

### 凭证处理
- 凭证录入（支持模式凭证调入、核算维度批量录入、快捷键操作）
- 凭证审核／反审核、出纳复核、凭证过账（不支持反过账）
- 凭证变更：变更已审核、已复核及已过账凭证的非关键字段
- 凭证摊销、凭证预提、自动转账（定期自动生成记账凭证）
- 凭证整理（批量保证凭证号连续排号，不可撤销）、凭证冲销、凭证作废／反作废
- 凭证查询（支持联查业务凭证及业务单据）、凭证汇总表
- 业务数据自动记账：业务凭证经智能会计平台汇总或单张生成总账财务凭证
- 凭证指定现金流量（自动指定与手工调整）

### 初始化
- 科目初始数据录入／引入（含期初余额、本年累计发生额、核算维度初始数据、往来明细）
- 现金流量初始数据录入

### 账表查询
科目余额表、试算平衡表、总分类账、明细分类账、数量金额总账、数量金额明细账、日报表、总账账龄分析表、摘要汇总表、核算维度余额表、核算维度明细账、核算维度与科目组合表、多栏式明细账、T型账、调汇历史信息表；以及多账簿系列账表（明细分类账、日报表、科目余额表等多种横向/纵向展示）

### 现金流量
现金流量项目维护、凭证现金流量指定、附表项目指定与调整、项目批量预设、现金流量检查、现金流量表查询

### 期末处理
期末调汇（自动计算汇兑损益并生成凭证）、结转损益、总账期末结账、总账自动结账方案／报告、调整期间管理（新增调整期间录入调整凭证，无需反结账）、财务结账中心（H5端）

### 跨账簿
智能转存：在不同账簿间自动转存凭证，支持手动、实时、自动三种执行方式，支持外币折算转存及凭证冲销转存

### 其他
总账管理参数（账簿参数、凭证参数、数据中心参数）、总账数字看板（H5端）、财务数据项目

## 3. 状态流转、下推和反写

### 凭证主流程
```
凭证录入 → 凭证审核 → 出纳复核 → 凭证过账
```
- 审核与出纳复核无强制先后顺序，可通过参数「凭证过账前必须审核」「凭证过账前必须出纳复核」控制
- 反审核后凭证状态为"重新审核"，可修改后再提交审核
- 过账后不支持反过账，不可修改关键字段，只能补充凭证或红字冲销更正
- 过账前需完成凭证整理，存在断号不允许过账
- 凭证冲销：对已过账凭证生成红字冲销凭证，摘要默认"冲销XX字XX号凭证"
- 凭证作废：只能在可修改状态下作废；已作废凭证不参与记账，可反作废恢复正常状态；业务系统生成的总账凭证作废后不支持反作废，作废后原业务单据可再次生成总账凭证

### 凭证摊销／预提方案状态
- 已执行金额为零 → 未启用；已执行金额不为零且余额不为零 → 进行中；余额为零 → 关闭
- 已生成凭证的方案不允许删除
- 同一预提方案在同一会计期间只允许生成一张预提凭证

### 科目状态
- 审核后仍可：修改核算维度必录/可选类型、新增外币核算、新增下级科目、设置主表项目/附表项目
- 一旦使用后无法删除或修改关键属性；需删除相关凭证和余额数据后才能反审核编辑
- 共享型科目：当前组织无未过账凭证且余额为零时允许取消分配；分配型：一经使用不能取消分配

### 会计核算体系反写
- 保存后，核算组织的"适用会计政策"和"默认会计政策"反写到会计政策基础资料"适用核算组织"页签相关字段

### 期末结账前置条件
账簿已结束初始化；相关业务系统已结账；当前期间无未过账凭证；已记账凭证不存在断号；必须生成凭证的业务单据已全部生成凭证；必须对账平衡的对账方案已对账平衡；若勾选「结账时要求损益类科目余额为零」则损益科目余额需已结平

### 反结账
- 结账后可执行反结账，账簿返回上一个会计期间
- 参数「不允许跨财务年度的反结账」控制是否允许跨年反结账
- 参数「反结账时检查报表的状态」可设置为报表提交后或报表审核后不允许反结账

### 调整期间
- 状态：打开（可录入）/ 关闭（不可录入、不可过账）
- 关闭前提：该调整期间所有凭证已过账
- 过账后更新本期发生／本年累计／期末余额，以及此后所有期间的期初、期末；反过账同步更新
- 调整凭证日期默认为该会计年度会计日历最后一天，不允许修改

### 智能转存
- 同一凭证在同一目的账簿只允许转存一次
- 勾选「修改、删除源凭证后同步更新转存凭证（锁定转存凭证）」后，目的凭证不允许直接修改或删除

## 4. 与生产、供应链的接口

### 凭证生成路径
业务单据 → 智能会计平台（凭证模板） → 业务凭证 → 总账财务凭证；在【凭证查询】中可联查对应业务凭证及业务单据。凭证来源还包括集成管理平台生成的凭证。

### 存货核算
- 多会计政策影响存货核算系统：存货核算根据核算体系、核算组织及对应会计政策中的成本核算方法进行成本核算
- 会计政策参数"存货核算按费用项目明细核算"控制成本是否按费用项目分项核算及分项平行结转存货成本
- 成本反写取数：存货类单据成本金额反写时，取默认核算体系下的成本（由"默认核算体系"控制）

### 生产成本相关
- 自动转账原文举例场景：月底结转制造费用到生产成本
- 转账选项：科目关联【物料】核算维度时，转账单位取物料的基本单位
- 凭证核算维度可关联【物料】核算维度，勾选相应凭证选项参数时自动填充物料的基本单位

### 往来与开票
- 账簿字段"财务应付确认方式"涉及采购发票与应付单的做账提示关系
- 账簿字段"财务应收确认方式"涉及销售发票与应收单的做账提示关系
- 凭证分录字段：结算方式、结算号、往来科目、业务编号

### 结账联动
- 参数「业务系统结账可与总账结账期间不一致」控制总账结账时是否要求业务系统先于总账当前期间结账
- 参数「结账时不检查业务单据的凭证生成情况」控制是否检查业务组织的业务单据已生成凭证
- 参数「业务系统生成的总账凭证允许修改」：不勾选时不能修改账簿、科目、核算维度和金额等关键字段

- 价格来源、业务日期与期间的对应规则

- 费用归集的具体科目配置规则
- 期末结账前置要求的业务系统具体名称列表

## 5. 与电子元器件制造的相关度

**判断：高**

理由：
1. 电子元器件制造涉及多物料、多工序，原文自动转账功能明确举例"月底结转制造费用到生产成本"，与制造企业成本核算场景直接对应
2. 凭证核算维度支持关联【物料】核算维度并自动填充基本单位，契合电子元器件按物料进行存货核算的需求
3. 多会计政策直接影响存货核算系统的成本核算方法，制造企业对存货核算方法（如加权平均、先进先出）的选择高度依赖该设置
4. 数量金额总账／明细账支持按数量+单价+金额三维核算，适配电子元器件库存按数量和金额双重管控的场景

**生产／供应链单据为对接本模块需预留的字段或接口**（仅有笔记依据的）：

- 凭证分录的**业务编号**字段：用于关联来源业务单据，往来科目场景下须录入
- 凭证分录的**业务日期**字段：区别于凭证日期，来自业务单据的实际发生日期
- **核算维度**中的【物料】维度：生产领料、完工入库等单据生成凭证时需能传入物料编码，以支持自动转账取物料基本单位
- 智能会计平台**凭证模板**中的**科目设置**：生产、采购、销售等业务单据需按单据类型预先配置凭证模板，含现金流量项目映射
- 存货核算**默认核算体系**：成本反写取数依赖该设置，需在核算组织层面确认默认核算体系配置
