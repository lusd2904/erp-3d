# 财务会计／出纳管理

## 1. 功能点

**基础收付款**
收款单、付款单（含销售/采购/其他业务及预收/预付款）；付款申请单；付款退款单；收款退款单；支付信息变更单

**现金与银行操作**
现金存取单；现金转账单；现金购汇单；银行转账单（含购汇业务）；资金调拨单（含计息）；调拨还款单；下载电子对账单（银企互联）

**对账与结算**
银行对账单（导入/引入/手工）；银行存款对账（自动+手工勾对）；银行存款批量对账；银行存款勾对记录；银行存款智能对账报告（执行计划自动勾对）；余额调节表；余额调节表_多账号；现金盘点；出纳期末对账；明细对账

**收款认领**
收款认领单；收款认领工作台（仅H5端）

**网银与聚合收款**
网银流水生成收款单；网银流水机器人（RPA）；聚合收款（微信/支付宝二维码）

**内部账户**
内部账户（基础资料）；内部账户调整单；内部账户账龄分析表；资金内部账户期初

**银行基础资料**
银行；银行账号；开户申请单；银行账户变更单；银行账户销户单

**日记账与报表**
手工日记账；现金日记账；银行存款日记账；现金日报表；银行存款日报表；现金流水账；银行存款流水账；资金头寸表；资金调拨还款统计表

**初始化与系统设置**
出纳管理初始化；启用日期设置；系统参数设置；登帐设置；科目对应表设置；收付款用途；出纳初始化指引工作台（仅H5端）

**期末处理**
期末处理-结账；期末处理-反结账

## 3. 状态流转、下推和反写

**初始化**
- 结束初始化前提：现金期初单、银行存款期初单已审核；结束后两单不允许新增或反审核，系统更新余额表期初余额
- 反初始化前提：系统未结账
- 启用日期可反启用（条件：已启用、未结束初始化、未录入初始数据的收付组织）
- 收付内部账户期初单不支持手工新增，由资金内部账户期初单审核时自动生成
- 现金期初、银行存款期初业务日期系统自动置为启用日期前一天

**下推与选单**

| 目标单据 | 来源 |
|---|---|
| 付款单 | 应付单、其他应付单 |
| 付款申请单 | 正数应付单、正数其他应付单、负数应收单、负数其他应收单 |
| 付款退款单 | 应付单、付款单、其他应付单 |
| 收款单 | 应收单、其他应收单 |
| 收款退款单 | 应收单、收款单、其他应收单 |
| 银行账号 | 开户申请单（参数"不可以手工新增银行账号"勾选时强制走此路径） |
| 收款单 | 聚合收款（销售订单/应收单支付成功后自动生成） |

- 明细行与源单一一对应，受参数"收付款按源单页签明细生成"控制
- 其他应付单下推的付款单明细携带费用项目，受参数"收付款按源单费用项目汇总生成"控制

**自动生成（参数驱动）**
- 应收单审核 → 自动生成收款单
- 应付单审核 → 自动生成付款单
- 付款申请单审核 → 自动生成付款单或收款退款单
- 零售/现销应收单审核 → 自动生成收款单
- 现购入库单下推生成的应付单审核 → 自动生成付款单

**收款认领单状态流转**
待收款认领 → 保存 → 提交 → 审核（应收会计确认，自动生成收款单）→ 已认领确认；审核自动生成收款单失败时可手工【下推】重新生成；生成的收款单可与应收单/销售订单/其他应收单核销

**支付信息变更单**
触发条件：付款单结算方式业务分类为银行业务、结算方式支持网银、提交银行状态为空或撤销；审核后更新付款单信息，更新后可重新提交银企付款

**反写规则**
- 收款用途财务处理属性：决定是否影响应收系统余额、是否参与应收收款核销
- 付款用途财务处理属性：决定是否影响应付系统余额、是否参与应付付款核销
- 付款退款单：由原付款用途财务属性确定
- 收款退款单：由原收款用途财务属性确定

**内部账户调整单**
- 内部账户付款调整：内部账户金额减少，开设组织减少，对应组织增加
- 内部账户收款调整：内部账户金额增加，开设组织增加，对应组织减少

**资金内部账户期初**
- 审核：自动逐行生成对应成员单位内部账户期初单，更新余额，同时产生成员单位收付组织内部账户期初单据
- 反审核：同时删除成员单位的收付组织内部账户期初单据
- 成员单位内部账户期初单只允许查询，不允许手工增删改

**资金调拨单**
- 业务操作→调拨还款：支持多张合并还款
- 业务操作→利息计算：计算资金调拨单利息
- 关联查询→下查：借出组织付款单、借入组织收款单

**银行账号生命周期**
开户申请单审核 → 下推 → 银行账号；银行账户变更单审核 → 更新银行账户信息；银行账户销户单审核 → 禁用账号

**银行存款对账**
取消勾对后系统自动更新相应单据勾对标识为未勾对；取消勾对人必须与勾对人一致（参数控制）；对账码字段一致时通过执行计划"银行存款智能对账"完成自动勾对；非银企账号通过手工导入对账单生成交易明细，流水号反写单据对账码字段

**日记账登账**
通过「复核记账」登账或「引入」引入凭证生成手工日记账，不允许重复登账/引入；需删除已生成手工日记账方可重新操作；登帐设置「单据状态」可设为暂存、创建、审核

**结账与反结账**
- 存在结账日期前未审核单据不允许结账（参数控制）；凭证未过账不允许结账（参数控制）
- 已结账期间不允许新增或调整业务数据
- 反结账需逐期往前；反结账后结账日期不能小于所有核算体系下对应核算组织所有账簿最新的结账日期

## 4. 与生产、供应链的接口

**基础数据共用**
组织信息、客户、供应商、部门、职员、币别、汇率体系、结算方式、银行、银行账号、现金账号等，若已在供应链、总账系统设置，出纳管理不需再单独设置。

**收款与应收联动**
- 销售业务收款关联应收单；启用应收款管理系统时收款影响应收账款余额并参与应收收款核销
- 其他业务收款关联其他应收单；由收款用途财务处理属性确定是否影响应收账款余额、是否参与核销
- 收款认领单关联业务单据支持：销售订单、应收单、销售合同、其他应收单；认领详情中物料编码、物料名称、计量单位、含税单价、数量、费用项目、销售组织、销售部门、销售组、销售员均从关联业务单据默认带出
- 聚合收款关联销售订单、应收单（字段：源单类型、源单编号）；支付成功自动生成收款单

**付款与应付联动**
- 采购业务付款关联应付单；启用应付款管理系统时付款影响应付账款余额并参与应付付款核销
- 其他业务付款关联其他应付单；由付款用途财务处理属性确定是否影响应付账款余额、是否参与核销
- 付款单/付款退款单单据头含采购组织、采购部门、采购组、采购员，用于应付付款核销时匹配
- 预付款场景下预付项目类型可关联具体采购订单

**与生产直接相关**
- 现购入库单下推生成的应付单审核可自动生成付款单（参数控制）

**多组织**
收付组织可通过业务委托关系委托其他收付组织代本组织进行收付业务。

**账务处理接口**
凭证生成、凭证生成情况查询、业务凭证查询、总账凭证查询由智能会计平台提供；出纳期末对账中，当银行账号为核算维度时总账数据直接取科目维度数据，不作为核算维度时需设置科目对应表。

**以下内容原文未见**
存货核算如何取出入库单、产品成本如何取生产领料和完工入库、成本对象、核算维度（非银行账号维度以外）、业务日期与会计期间的映射规则、往来与开票的具体字段接口、费用归集到生产订单或成本中心的处理方式。

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
1. 电子元器件企业采购批次多、供应商数量大，付款单→应付单的核销链路及预付项目类型关联采购订单的机制直接可用，相关度较高。
2. 销售侧多为对公客户，收款认领单的"流水→应收单"认领工作台可匹配银行到账与销售订单，实用价值明确。
3. 生产联动仅覆盖现购入库单→应付单→付款单一条路径，对生产领料、工序结算、委外加工等制造核心场景原文未见接口，制造深度不足，拉低整体评级。
4. 本模块聚焦资金收付与银行对账，不涉及成本核算、BOM、工单，对制造管理本身无直接贡献，属支撑型模块而非核心模块。
