# 财务会计／资金管理

## 1. 功能点

**集团资金集中管理**
- 建立资金集中管理与监控平台，支持收支两条线模式
- 区分成员单位收入账户与支出账户，实现资金上划与下拨
- 组织业务委托关系设置，建立结算中心资金管理组织模型

**结算类**
- 集团总部集中对外付款，按结算明细下推付款单或收款退款单【付款结算单】
- 集团总部集中对外收款，按结算明细下推收款单或付款退款单【收款结算单】
- 成员单位零余额账户对外支付，母公司下拨资金后由下级账户付款【联动支付单】

**资金划拨类**
- 资金组织发起，各成员单位账户资金上划到母账户【资金上划单】
- 设置定时方案，系统自动执行资金上划【自动上划设置】
- 资金组织根据预算或资金请款单，向各成员单位账户下拨资金【资金下拨单】
- 成员单位向资金组织发起资金请款，审批后作为资金下拨单源单【资金请款单】

**信贷与利息类**
- 管理和维护借款组织与银行之间的信贷合同关键信息【信贷单】
- 由资金组织对信贷单发起预提计息，系统自动生成借款利息单【借款利息单】
- 支持内部活期计息，采用积数计息法核算各成员单位资金结余收益及占用成本【内部活期计息】
- 由资金组织发起内部活期计息，自动生成内部利息单，审核后联动生成收款单或付款单【内部利息单】
- 维护内部活期计息适用的基准利率表【基准利率】
- 维护结算中心内部活期计息的结息日期方案【结息方案】
- 维护内部活期计息的计息对象【计息对象】

**基础资料与初始化**
- 基础资料维护：银行账号、内部账户、基准利率、结息方案、计息对象
- 资金内部账户期初余额初始化【资金内部账户期初】
- 系统参数设置（数据中心级，需管理员身份）【资金管理系统参数】

**分析报表**
- 对内部利息数据进行查询和统计分析【内部利息统计表】

## 3. 状态流转、下推和反写

### 付款结算单
- 下推 → 付款单
- 下推 → 收款退款单

### 收款结算单
- 下推 → 收款单
- 下推 → 付款退款单

### 信贷单
- 下推 → 收款单（处理放款到账）；收款单金额反写信贷单「实际发放金额」
- 下推 → 付款单（处理还本付息）；付款单金额反写信贷单「实际还本金额」、「实际还利息金额」
- 「单据状态」由系统自动更新，具体状态值原文未列出

### 借款利息单
- 由信贷单【预提利息】操作自动生成，初始状态为「保存状态」（原文亦称「创建状态」）
- 用户确认后提交审核
- 下推 → 付款单（利息支付）

### 内部利息单
- 由【利息计算】操作自动生成，初始状态为「保存状态」
- 用户确认后提交审核
- 审核时：本期存款利息≠0 → 自动生成成员单位收款单（单据类型：内部利息）；本期透支利息≠0 → 自动生成成员单位付款单（单据类型：内部利息）
- 反审核时：同步删除上述自动生成的收款单或付款单（单据类型：内部利息）
- 自动生成的成员单位收款单／付款单只允许查询，不允许手工增、删、改

### 计息对象
- 「上次结息日」：新增时手工录入，之后由系统计息时自动反写

### 联动支付单
- 必须由成员单位对外付款申请单下推生成，不可手工新增
- 审核时：自动逐行产生对应成员单位收款单（单据类型：资金下拨）和成员单位账号对外付款单；更新成员单位银行账户及内部账户余额；登记银行存款日记账
- 反审核时：同时删除上述自动生成的收款单和付款单
- 成员单位资金下拨类型收款单只允许查询，不允许手工增、删、改

### 资金上划单
- 审核时：自动逐行产生对应成员单位付款单（单据类型：资金上划）；更新成员单位银行账户及内部账户余额；登记银行存款日记账
- 反审核时：同时删除上述自动生成的付款单
- 成员单位资金上划类型付款单只允许查询，不允许手工增、删、改

### 资金下拨单
- 可由资金请款单带出金额
- 审核时：自动逐行产生对应成员单位收款单（单据类型：资金下拨）；更新成员单位银行账户及内部账户余额；登记银行存款日记账
- 反审核时：同时删除上述自动生成的收款单
- 若启用系统参数「资金下拨单以票据方式下拨时只下拨票据可用额度，并按照下拨额度控制应收票据的使用」：结算方式可选票据类；审核时不产生成员单位收款单，仅下拨可用额度
- 成员单位资金下拨类型收款单只允许查询，不允许手工增、删、改

### 自动上划设置
- 审核成功后系统定时自动执行，产生资金上划单
- 提交方式支持：暂存、自动提交审核、自动提交网银

### 资金请款单
- 由成员单位发起，由资金组织审批（审核操作）
- 审批通过后可作为资金下拨单的源单（下推关系）

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
1. 电子元器件制造企业多为中小规模，集团资金集中管理（收款结算单、付款结算单、资金上划／下拨、联动支付）的核心价值在于多法人、多组织架构；若企业为单一法人，该模块大部分功能用不上。
2. 信贷单、借款利息单对应银行借款管理，电子元器件制造企业有融资需求时可用，但并非行业特有高频场景。
3. 内部活期计息（计息对象、基准利率、结息方案、内部利息单）仅在集团设立内部结算中心时才启用，单体企业无需使用。
4. 该模块与生产、采购、销售、库存无直接数据接口，对制造核心流程（BOM、工单、出入库核算）无直接依赖，制造企业落地时优先级低于存货核算、成本管理等模块。
