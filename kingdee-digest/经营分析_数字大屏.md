### 经营分析/数字大屏（补读 8 页，已全读）
- 数字大屏（V7.7）：选一个"大屏用户"通过第三方登录授权生成免登链接，链接可重复访问、不受超时和踢出影响，可多屏同时打开；V8.0 起须启用 **IP 白名单**；看板数据范围=大屏用户的数据权限；预置全渠道经营、数字零售、供应链运营、数字经营、生产运营看板。【数字大屏】
- 云服务汇总：业务云服务、数字大屏、在线客服、云瘦身、初始化实施服务。【云服务】
- 经营分析平台（ElastiCube 引擎）：用户分管理员/开发/普通；多数据源建模、表间关系、自定义 SQL 字段，构建分增量和全量；报表过滤器与图表过滤器（图表级覆盖报表级，多个过滤器为"与"）；**行级数据安全**：按字段值限定用户组可见；模型备份/恢复，数据更新频率可选立即/每天/每周/每月/间隔。【经营分析平台操作手册】
- 经营大盘公式：毛利率=(主营收入−主营成本)/主营收入；净利率；负债率=总负债/总资产；净利润增长率；净资产收益率。经营效率：现金周转天数=存货周转天数+应收周转天数−应付周转天数；存货周转天数=30×平均存货/本期主营成本（按月）；应收/应付周转天数=360/周转率。【经营大盘】【经营效率】
- 轻分析设置：取数方式推荐"返回临时表（异步）"或"返回SQL"，数据量小时才"返回数据"；**启用字段授权后，分析结果遵循业务字段权限**（任一组织无权则全部隐藏）。【轻分析设置】【轻分析应用授权】【轻分析应用授权管理】
- → 一期：老板看板含存货周转天数、应收/应付周转天数、毛利率（按上述公式，口径写进指标字典）；看板查询必须带数据权限和字段权限（成本、单价保密）。二期：大屏只读免登 token + IP 白名单 + 可吊销。
