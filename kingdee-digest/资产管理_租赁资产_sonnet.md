# 资产管理／租赁资产

## 1. 功能点

- **租赁资产生命周期管理**：以资产租入单为中心，覆盖签约、初始入账价值计算、资产卡片产生、租金支付、利息确认、租赁终止的完整流程。
- **资产租入单**：记录租入资产合同信息、支付信息、付款计划（系统自动生成可手工编辑）、财务信息（使用权资产／租赁负债／未确认融资费用）、使用分配信息；审核后自动产生资产卡片。
- **租赁利息确认单**：对租赁负债产生的利息进行确认（即未确认融资费用的分摊），由资产租入单的付款计划下推生成。
- **租金报销单**：通过资产租入单付款计划下推生成，属于费用报销单的一个单据类型，用于租金支付。
- **租赁终止单**：对审核后的租入单进行租赁终止，终止后下推资产处置单。
- **摊余成本表**：查询租入单在某一时间段内利息确认、租金支付情况，可区分一年内到期与一年后到期的租赁负债。
- **租赁参数设置**：配置日折现率取数方式、利息确认方式、自动下推规则、租入单引入规则等系统级参数。
- **启用顺序**：依次启用固定资产→基础资料设置→参数设置→日常业务→期末处理。

## 3. 状态流转、下推和反写

```
资产租入单（审核）
  ├─→ 自动产生资产卡片
  │      └─ 资产卡片保存后反写租入单的【关联卡片编码】
  │
  ├─→ 付款计划 ──┬─→ 租赁利息确认单
  │              │      （受参数【自动下推利息确认单】控制）
  │              │
  │              └─→ 租金报销单
  │                     （受参数【自动下推租金报销单】及
  │                      【付款日前（）天自动产生租金报销单】控制；
  │                      前提：付款计划的【已生成报销单】为"否"）
  │
  └─（资产租入单已审核 且 资产卡片已审核）
       └─→ 可操作租赁终止单
                └─（租赁终止单审核）→ 下推资产处置单
```

**利息确认方式**（由参数控制）：
- 按付款期确认：一个付款期全额确认一次。
- 按期确认：在付款期所属期间内平均分摊，可选直线法分摊或复利分摊。

## 5. 与电子元器件制造的相关度

**判断：低**

理由：
1. 本模块处理的是企业以承租方身份租入资产（使用权资产／租赁负债），核心是会计准则（IFRS 16／CAS 21）下的租赁负债摊销与折旧，与电子元器件制造的核心业务（生产工单、BOM、领料、工序）无直接关联。
2. 电子元器件制造企业使用的生产设备通常以采购自有为主；若存在设备租赁，才会用到本模块，属于非核心场景。
3. 本模块与库存、采购、销售、MRP 均无原文描述的接口，不影响生产供应链主流程的设计。
4. 模块输出（资产卡片、折旧）流向固定资产系统和智能会计平台，属财务域，对制造执行域影响有限。

**生产／供应链单据为对接本模块需预留的字段或接口**（仅有笔记依据的）：

- 若生产部门使用租入设备，资产租入单的使用分配中有**使用部门**和**费用项目**字段，生产部门主档需能被该字段引用（使用部门与组织关系需打通）。
- 资产租入单中有**资产组织**和**货主组织**，自研 ERP 的组织主档需同时支持这两个维度，以便与本模块对接。
- 原文未见其他与生产或供应链单据的直接字段对接要求。
