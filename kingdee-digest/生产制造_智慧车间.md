### 0.3 状态流转
- **设备状态**：加工 / 异常停机 / 空闲 / 占用 / 关机，由生产事件的“影响至设备状态”驱动，每次切换写设备状态变更日志【来源:生产事件管理】【来源:设备状态变更日志】
  - SCADA 推送时用状态代码映射：设备端“空闲”对应 MES 空闲（待料/维修/保养/午休/生产准备……）；“加工”对应加工；“异常”通过故障代码映射到生产事件，例如设备故障、程序故障【来源:复杂工序联网-场景9-设备状态实时联动_scada主动推送】
- **派工明细**：未开工 → 开工 → 完工【来源:派工明细】
- **现场异常处理单**：
  - 状态：待处理 → 处理中 → 已关闭
  - 阶段：发起呼叫 → 受理 → 签到 → 处理（处理完成/驳回/转交/转关闭/延时）→ 验收关闭；验收不合格退回处理人
  - 等级：按处理时长升级 一级 → 二级 → 三级
  - 【来源:现场异常处理单】【来源:安灯呼叫应用流程】【来源:异常升级报警机制】
- **首检**：空 → 待首检 → 首检中 → 首检完成。严格控制：合格后才能继续加工；非严格控制：送检后即可继续加工【来源:首检_柔性单件】
- **检验单（移动质检）**：质检开始 → 质检完成【来源:车间移动质检_工序检验】
- **消息队列**：不执行 / 待执行 / 执行中 → 成功或失败后移入历史；失败的消息可重置为待执行【来源:消息队列】
- **箱单**：检验状态 待检 → 已送检【来源:箱单列表】
- **HMI加密密码**：未生效 / 生效 / 失效【来源:hmi加密设置】
