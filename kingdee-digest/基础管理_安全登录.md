## 0. 精读要点
- 认证方式：
  - 静态密码（受密码策略约束）
  - 域用户
  - 动态密码（轻应用或动态密码卡）
  - CA 证书（U-Key）
  - 双因素：命名用户 + 第三方消息 / 邮箱 / 动态密码
  - 金蝶云账号
  - 第三方单点登录
  - 认证方式可以按数据中心启用，也可以按用户限制【安全管理】【双因素登录认证】【ca认证】【域用户】【动态密码】
- 密码策略：
  - 规则：强密码（数字 + 特殊字符 + 字母，不可取消）；最小长度默认 8，可设 8–20；有统一默认密码；规则调整后登录时强制校验
  - 时效：密码有效期及到期预警、修改密码有效期及预警、密码不重复周期（默认 30 天）
  - 控制：用系统生成的密码登录后必须修改，或限定可登录次数（默认 3 次）；密码错误若干次（默认 3 次）后锁定，锁定后自动解锁
  - 来源：【用户】
- 二次验权：在单据参数配置里给指定操作开启，执行时需再次输入当前用户密码【二次验权】
- 第三方系统登录授权：签名 URL 单点登录；可设链接有效时间、一次性或可重复使用、客户端白名单、允许全部用户或指定用户【第三方系统登录授权】
- 用户：
  - 账号和名称均唯一
  - 联系对象：员工 / 供应商 / 客户
  - 组织列表 + 角色列表（多组织时按组织分配角色）
  - 用户类型：内部 / 外部
  - 签名图片（用于审批签章）
  - 可设置“新增员工同步新增用户”，支持引入
  - 来源：【用户】

## 1. 功能点（每页首句，共 8 页，正文 17121 字，图片 0 张未 OCR）
- 【ca认证】安全管理中提供了CA认证（U-key），主要为了对用户密码做进一步的控制，以减少关键数据的泄露。
- 【二次验权】安全管理中提供了二次验权，主要为了对用户密码或者关键操做进一步的控制，以减少关键数据的泄露。
- 【动态密码】使用动态密码登陆金蝶云，无需购买动态密码卡设备，客户节省使用成本，第三方移动平台（云之家、企业微信等）动态密码随点随用。
- 【双因素登录认证】随着互联网的日益发展，特别是金蝶AI星空的线上模式应用，用户对使用金蝶AI星空的安全性要求越来越高，为此，金蝶AI星空提供了双因素登录认证方式，为系统安全使用保驾护航。
- 【域用户】安全管理中提供了域用户，主要为了对用户登录采用域用户方式及其密码控制。
- 【安全管理】随着互联网的日益发展，特别是金蝶AI星空的线上模式应用，用户对使用金蝶AI星空的安全性要求越来越高，为此，金蝶AI星空提供了安全登录方式，包括动态密码卡、CA认证方式登录以及双因素登录认证等。
- 【用户】金蝶云用户就是金蝶云系统的操作员，用户根据其具有的系统权限进行业务操作。
- 【认证信息】读取失败

## 3. 状态流转（含“状态”的原句）
- 【基础管理】→【公共设置】 →【单据设置】→【单据参数配置】【二次验权】
- Administrator登录金蝶云系统，进入【基础管理】→【公共设置】 →【单据设置】→【单据参数配置】，打开“单据参数配置”界面；【二次验权】
- 产品路径：管理中心->数据中心列表->【设置-下拉菜单认证方式】，选择数据中心，然后勾选动态密码身份（轻应用）即可。【动态密码】
- 产品路径：系统管理->查询用户->【业务操作-下拉菜单设置认证方式】，选择用户，启用动态密码身份（轻应用）即可；【动态密码】
- 登录管理中心，进入【设置】→【认证方式】，打开认证方式界面，针对所选的数据中心启用“域用户身份”，启用后，用户登录界面即会显示“域用户身份”的认证方式。【域用户】
- 【系统管理】→【系统管理】→【用户管理】【用户】
- 【系统管理】→【系统管理】→【用户管理】，点击【查询用户】菜单，在“用户列表”界面，点击工具栏【新增】。【用户】

## 4. 上下游：下推、选单、反写
- 以云之家为例，手机进入云之家移动端，在应用找到金蝶云【动态密码】，点击即可自动生成动态密码。【动态密码】

## 5. 参数和选项
- 选择数据中心，勾选“CA身份”来启用CA认证方式；【ca认证】
- 启用后，用户登录界面即会显示CA身份的认证方式。【ca认证】
- 【基础管理】→【公共设置】 →【单据设置】→【单据参数配置】【二次验权】
- Administrator登录金蝶云系统，进入【基础管理】→【公共设置】 →【单据设置】→【单据参数配置】，打开“单据参数配置”界面；【二次验权】
- 产品路径：管理中心->数据中心列表->【设置-下拉菜单认证方式】，选择数据中心，然后勾选动态密码身份（轻应用）即可。【动态密码】
- 启用后，用户登录界面即会显示“命名+第三方消息”“命名+邮箱身份”“命名+动态密码身份”【双因素登录认证】
- 若需要特别限制些用户的登录，也可以在用户列表中，选择一个或多个用户，通过【业务操作】—【设置认证方式】，取消勾选双因素认证方式，来限制某一或某些用户使用CA证书登录，实现不同用户的不同控制。【双因素登录认证】
- 登录管理中心，进入【设置】→【认证方式】，打开认证方式界面，针对所选的数据中心启用“域用户身份”，启用后，用户登录界面即会显示“域用户身份”的认证方式。【域用户】
- 当发生登录异常的时候可以使用第三方系统登录参数异常检测工具，请参考【安全管理】
- 批量分配许可：勾选用户后，点击“批量分配许可”，即可批量为用户分配许可。【用户】
- 前提是要在流程节点上勾选允许签章。【用户】
