# 管理会计／经营会计

## 1. 功能点

**基础资料与核算体系搭建**

- 经营账簿：设置核算体系、经营科目体系、会计政策、经营会计日历、汇率体系、启用期间、记账本位币
- 经营会计日历：自定义经营期间，支持自然月、月、周（52周/53周/445方式），已审核后不允许修改，可追加经营期间
- 经营科目：按资产账户、负债账户、销售收入、变动费用、固定费用等经营类别设置，支持核算维度录入
- 组合经营科目：通过加减乘除表达式组合多个经营科目，用于利润表特定指标分析，支持禁用/反禁用
- 经营单元：定义经营考核最小单元，将部门、员工、组织机构、工序等基础资料映射为经营单元
- 经营组织架构：按考核层级设置利润中心与经营单元上下级关系，同一期间只能存在一个版本，支持反启用
- 经营组织架构版本管理：查看各账簿组织架构版本列表及组织架构图，支持新增和修改
- 经营单元变更单：处理组织变更、部门调整、员工变动时经营单元对应基础资料的变更

**内部结算价格体系**

- 经营单元结算价目表：设置经营单元间内部结算价，支持按物料或物料分组设置双向/单向/通用价目表
- 经营单元结算折扣表：设置内部交易折扣率，支持生效/失效日期控制
- 结算价格来源方案：配置内部结算单价引入采购/销售价目表物料和取价规则（最高价、最低价、最新价）

**初始化**

- 经营科目初始化录入：录入本年累计收入、本年累计支出、期初余额及核算维度；初始化与日常录入可同时进行，期末处理前须执行结束初始化
- 结束初始化/反初始化：控制是否可进行期末处理，仅在启用期间可操作

**流水账生成**

- 业务单据生成经营流水账：手动触发，按引入方案生成，支持覆盖或追加
- 总账科目生成经营流水账：手动触发，显示检查项及状态，默认追加
- 定时生成经营流水账：配置定时计划，审核后自动到点执行，默认覆盖
- 引入业务单据方案设置：配置哪些业务单据生成经营流水账，区分收入、支出、转账，含内部交易划分规则
- 引入总账科目方案设置：配置总账科目（含阿米巴费用归集单、总账凭证）生成经营流水账，支持权重分摊
- 经营流水账录入：手工录入经营单元日常业务流水账
- 经营流水账生成情况明细查询/汇总查询：查询单据是否已生成流水账及未生成原因

**费用处理**

- 经营费用归集单：手工录入、业务单据引入、总账科目引入三种方式归集费用
- 经营费用分配结果单：由经营费用归集单下推按经营单元分摊标准自动生成
- 经营单元分摊标准：设置公摊费用按权重分摊的标准，支持固定权重或自定义分摊规则，可分摊到经营单元或利润中心
- 自定义分摊规则：支持按经营科目、已有规则组合、经营科目+核算维度三种定义方式
- 经营费用分摊方案：配置分摊方、接收方、分摊标准、目标费用科目、交易类型、资金科目、多期间分摊方案
- 经营费用分摊：按已设方案执行，支持覆盖或追加
- 多期间分摊方案：设置费用跨多个会计期间的分摊比例，分摊比例总和必须为1，支持自动平均计算

**内部结算**

- 经营单元内部结算单：录入经营单元之间内部交易或服务的结算，同时生成供货方收入类和接收方支出类经营流水账
- 经营单元投入时间：录入经营单元投入时间，同一账簿和业务期间只能对应一个经营单元投入时间
- 经营计划单：录入经营单元收入、费用计划与预算
- 内部交易核对表：检查内部交易方数据是否遗漏

**报表**

- 经营利润表、经营利润汇总表、经营利润横向展示表、经营利润期间横向展示表
- 经营核算维度利润表：按核算维度展示收入、成本、利润
- 经营账户收支明细表、经营账户余额表、经营资产负债余额表
- 多维经营对比分析表：对比不同经营单元、不同期间的经营科目实际值、计划值和计划达成率

**阿米巴体系**

与经营会计平行的另一套术语体系，涵盖：阿米巴单元、阿米巴组织架构、阿米巴变更单、阿米巴投入时间、阿米巴初始化录入、阿米巴计划单、阿米巴内部结算单、阿米巴结算价目表、阿米巴结算折扣表、阿米巴自定义分配标准、阿米巴费用归集单、阿米巴费用分配结果单、阿米巴利润期间横向展示表、阿米巴利润横向展示表、阿米巴核算维度利润表。各单据字段结构与经营会计对应单据基本一致。

**期末**

- 期末结账：对经营账簿当前期间执行结账，前提是已结束初始化；结账后不允许录入经营流水账，不允许反审核或删除经营单元内部结算单、经营流水账录入、经营费用归集单、阿米巴内部结算单、阿米巴费用归集单；结账时若下一会计期间不存在，系统自动追加下一年经营会计期间

## 3. 状态流转、下推和反写

**账簿与日历**

- 经营账簿须已审核且未被禁用，才可用于经营流水账、多期间分摊方案、经营单元内部结算单、经营计划单、经营费用分摊方案、阿米巴变更单、阿米巴计划单、阿米巴费用归集单、阿米巴费用分配结果单等单据
- 经营会计日历已审核后不允许修改，可追加经营期间
- 经营组织架构同一期间只能存在一个版本；截止期间由下一版本启用期间自动获取；支持反启用

**初始化流程**

```
经营科目初始化录入（与日常录入可并行）
    → 结束初始化
        → 期末处理（方可执行）
可反向：结束初始化 → 反初始化 → 还原至未初始化状态（仅启用期间可操作）
```

**流水账生成执行方式**

| 触发方式 | 默认执行方式 |
|---------|------------|
| 业务单据生成经营流水账 | 追加 |
| 总账科目生成经营流水账 | 追加 |
| 定时生成经营流水账 | 覆盖 |
| 经营费用分摊 | 覆盖 |

- 系统参数可控制生成的经营流水账状态为「创建」或「已审核」，参数修改仅对未来生成的经营流水产生影响
- 定时生成经营流水方案须经过审核后，系统才会自动到点执行
- 生成失败的单据，根据系统提示原因修改后可重新执行

**费用分摊下推链**

```
经营费用归集单
    → 下推生成 → 经营费用分配结果单（按经营单元分摊标准）
        → 分摊完成字段自动勾选
        → 生成经营流水账后已入账字段自动勾选
        核算维度取自目标核算维度

阿米巴费用归集单
    → 自动生成 → 阿米巴费用分配结果单（按自定义分配标准，非手工新增）
```

- 经营费用分摊执行方式分覆盖/追加；多方案顺序执行时前一方案结果单可能被后续方案覆盖

**内部结算单生成流水账**

- 经营单元内部结算单 → 同时生成供货经营单元的收入类经营流水账 + 接收经营单元的支出类经营流水账
- 阿米巴内部结算单 → 同时生成供货阿米巴收入类 + 接收阿米巴支出类经营流水账

**变更单规则**

- 经营单元变更单：变更记录不允许删除；若需回退须继续做变更单选原经营对象；不允许变更前后经营对象完全相同
- 阿米巴变更单：变更记录不允许删除；撤销变更须新增变更单变回原阿米巴对象

**结账控制**

- 前提：经营账簿已结束初始化
- 结账后不允许录入经营流水账
- 结账后不允许反审核或删除：经营单元内部结算单、经营流水账录入、经营费用归集单、阿米巴内部结算单、阿米巴费用归集单
- 系统参数「存在未审核的经营流水账时允许结账」：勾选则允许结账并给出未审核单据列表，不勾选则阻止结账
- 若下一会计期间不存在，结账时系统自动追加下一年经营会计期间

**其他约束**

- 自定义分摊规则：已被经营单元分摊标准引用时不允许删除；支持反审核分摊标准后再反审核自定义分摊规则进行修改
- 多期间分摊比例总和必须为1

**价格接口**

## 5. 与电子元器件制造的相关度

**判断：中**

理由：

1. 工序可作为经营对象类型映射为经营单元，这与电子元器件制造的多工序生产形态（贴片、焊接、测试、封装等）直接契合，可在工序级别做利润核算和费用归集。
2. 电子元器件制造涉及大量内部半成品流转（晶圆→芯片→封装→测试），经营单元内部结算单的内部交易机制可支撑此类内部转移定价。
3. 该模块以阿米巴/利润中心为核心考核颗粒度，适合电子元器件制造企业按产线、车间或产品族做经营绩效分析；经营核算维度利润表可支持多维度（产品、客户、工序）损益展示。
4. 但该模块本质是管理会计核算层，不直接处理物料、库存、生产工单的业务逻辑；与制造成本核算（生产领料、完工入库、工单成本）的接口原文未见，自研ERP需自行设计对接路径，存在较大开发工作量。

**生产/供应链单据为对接本模块预留的字段或接口（仅有笔记依据的）**

- 生产工序基础资料：需支持被引用为`经营对象类型`=工序的`经营对象编码`，建议预留与经营单元的关联标识字段
- 物料基础资料：经营单元结算价目表和阿米巴结算价目表按`物料编码`+`规格型号`+`计价单位`设价，物料档案需保证这三个字段的完整性
- 采购价目表/销售价目表：结算价格来源方案可引入这两类价目表，自研ERP的价目表需兼容`生效日期`、`失效日期`、`物料编码`字段，以支持取价规则（最高价/最低价/最新价）
- 业务单据通用：被配置为`来源单据`的业务单据（如采购入库单、销售出库单、生产领料单等）需有`业务日期`字段，以对应引入方案中的`日期来源`配置；需有经营单元归属标识，以支持`经营单元来源`取值
