# 员工服务／人人报销

## 1. 功能点

- 支持先申请（可借款或不借款）后报销、直接报销、通过历史借款余额报销、费用移转等多种业务模式【人人报销】
- 人人报销工作台作为员工报销入口，支持新增单据、查看各状态单据、维护收款信息（银行账号）【人人报销工作台】
- 工作台首页按状态归集单据：审核中、待收款、待报销、草稿、已完成【人人报销工作台】
- 按费用类型报销，通过单据类型参数控制不同单据类型可选费用项目【人人报销】
- 费用移转支持先报销后移转、先分配后报销，支持跨核算组织、跨业务组织、跨往来单位、跨费用项目移转【人人报销】
- 借款转移用于员工离职等场景的借款移交，仅支持组织内员工间互转【借款转移单】
- 出差申请单一单二用：勾选申请借款则为借款单据，不勾选则为出差申请单据【出差申请单】
- 出差申请单支持关闭/反关闭、退款、变更接手人、查看借款功能【出差申请单】
- 批量生成付款申请单到出纳模块，可指定申请日期【生成付款申请单】
- 费用报销单支持直接新增或由费用申请单、历史借款余额下推生成【费用报销单】
- 费用报销单勾选「申请付款」后申请付款金额必录，审核后自动下推生成付款申请单【费用报销单】
- 费用报销单勾选「申请退款」后审核自动下推生成付款退款单【费用报销单】
- 费用报销单勾选「实报实付」审核不产生其他应付单，须同时勾选申请付款【费用报销单】
- 费用报销单勾选「多收款人」显示多收款人页签，支持多收款人银行信息录入【费用报销单】
- 费用报销单勾选「费用外部承担」费用承担组织为外部单位，可下推付款单、其他应收单，不参与自动核销【费用报销单】
- 费用报销单收票信息页签支持手机端/PC端多方式导入发票，选择后自动填写相关信息【费用报销单】
- 费用报销单审核后支持下推负数报销单进行费用冲回及退款【费用报销单】
- 费用报销单支持作废功能，作废后单据留存系统但不参与业务【费用报销单】
- 费用报销单支持财务共享，提交时启用打印封面和查看影像功能【费用报销单】
- 费用报销单查看借款：录入往来单位后可查看该往来单位借款状况【费用报销单】
- 费用报销单查看付款：审核后可查看银行付款情况（仅限网银支付）【费用报销单】
- 费用报销单自动核销：借款付款单与报销单审核时自动核销【费用报销单】
- 费用申请单费用申请与费用借款一单两用，勾选「申请借款」切换为借款单【费用申请单】
- 费用申请单支持一对多、多对一、多对多下推费用报销单【费用申请单】
- 费用申请单支持关闭/反关闭功能，满足条件的已审核申请单可禁止后续下推【费用申请单】
- 费用申请单支持退款按钮，借款全额退回时可直接退款【费用申请单】
- 费用申请单支持变更接手人，适用员工离职/换岗场景【费用申请单】
- 费用申请单查看借款按钮，取数规则与借款跟踪表一致【费用申请单】
- 费用移转单对费用进行二次分配，支持同组织内转移及跨组织转移【费用移转单】
- 费用移转单跨核算组织转移通过供应链组织间结算生成「应收结算清单_费用」、「应付结算清单_费用」【费用移转单】
- 报销确认费用统一传送到应付系统的其他应付单【人人报销】

## 3. 状态流转、下推和反写

**事由申请单**
- 受系统参数【事由申请单报销次数】控制：设为一次时只能下推一次报销单，下推时检查下游存在报销单则不允许再次下推；设为多次时可无限次下推

**出差申请单**
- 下推费用报销单支持一对多、多对一、多对多
- 合并下推时源单首行「费用项目」携带到报销单「费用项目」，源单申请金额汇总填入报销单「费用金额」
- 关闭条件：已审核且未下推付款单/付款申请单且未完全下推报销单（已下推报销/退款金额 < 核定金额 且 已下推付款申请/付款金额 = 0）
- 列表中实际借款金额、已报销金额、已退款金额、冲销金额、借款余额由系统根据下游单据审核或核销状态自动填列

**费用申请单**
- 允许关闭条件：已审核 且 未下推付款单/付款申请单 且 未完全下推报销单（已下推报销/退款金额 < 核定金额，且已下推付款申请/付款金额 = 0）
- 合并下推报销单时：源单首行「费用项目」携带至报销单「费用项目」，源单申请金额汇总填入报销单「费用金额」
- 支持一对多、多对一、多对多下推费用报销单

**费用报销单**
- 状态：创建 → 审核（通过）；支持反审核；支持作废（限新增或重新审核状态）
- 审核后同步生成应付模块「其他应付单」，状态为审核，不允许反审核；反审核报销单时系统同时删除已同步的其他应付单
- 勾选申请付款 → 审核后自动下推「付款申请单」（创建状态）
- 勾选申请退款 → 审核后自动下推「付款退款单」（创建状态）
- 配置勾选后 → 审核自动生成「进项费用增值税发票」（创建状态）；不勾选则手工下推
- 配置勾选后 → 审核自动生成「付款单」；我方银行账户有默认值为创建状态，取不到值为暂存状态
- 审核后支持下推「负数报销单」：原单未付款则与负数报销单核销；已付款则负数报销单需下推付款退款单退款
- 费用报销单下推「费用移转单」时使用「费用金额」下推
- 关账后不允许新增关账日期之前的单据

**业务日期规则**
- 下游系统与费用报销模块同一期间：提交/审核取申请日期
- 下游系统早于费用报销系统结账：提交/审核取系统当期日期

**核销机制**
- 系统通过申请到报销的下推、历史借款到报销的下推自动完成绝大部分应付付款核销
- 另支持自动核销向导、尾差核销、手工核销
- 费用申请借款 → 下推付款单获取借款 → 做报销单 → 审核时付款单与其他应付单自动核销

**费用移转单**
- 跨核算组织转移通过供应链组织间结算生成「应收结算清单_费用」、「应付结算清单_费用」，需维护「组织间结算关系」
- 核算组织内费用移转支持转账凭证生成
- 移转费用可在以后任意期间移转到其他实际费用承担对象

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
- 电子元器件制造企业存在差旅、研发费用报销、部门间费用分摊等通用需求，人人报销模块的借款-报销-核销流程和费用移转功能可直接对应这些场景，属于基础财务模块。
- 费用移转单支持跨核算组织转移，对于多工厂/多组织的电子元器件制造企业有实际意义，可将共用费用（如总部管理费用、共享研发费用）分配到各生产组织。
- 但原文未提及任何与生产领料、完工入库、采购入库、销售出库等核心制造单据的直接接口，本模块本质是费用报销与资金管理，与生产计划、车间执行、物料管理等核心制造环节无直接关联。
- 费用报销审核后生成「其他应付单」并进入应付系统，是自研 ERP 财务应收应付模块需要对接的接口点；费用移转生成「应收结算清单_费用」「应付结算清单_费用」是跨组织结算的接口点。

**一期生产/供应链单据为对接本模块需预留的字段或接口：**

基于笔记中可见的接口关系，自研 ERP 需预留以下对接点：

- 应付模块需支持接收来自报销模块的「其他应付单」：费用报销单审核后自动生成，状态为审核，单据内容包含费用金额、税率、税额等字段。自研应付模块应设计对应的数据接收接口。
- 供应链组织间结算需支持「应收结算清单_费用」「应付结算清单_费用」两种结算清单类型，用于费用移转单跨核算组织转移场景。
- 付款模块需支持接收「付款申请单」（费用报销单勾选申请付款后自动下推，创建状态）和「付款退款单」（勾选申请退款后自动下推，创建状态）。
- 需预留「组织间结算关系」基础数据维护功能，作为跨组织费用移转的前置配置。
- 费用承担维度需支持到员工个人、部门、供应商、客户及其他往来单位，与生产/供应链单据的费用归集维度保持一致或可映射。
