## 1. 功能点
- 业务类型：标准销售(报价→订单→发货通知→出库→应收)、寄售、直运、服务类、套件、客户多方交易、销售退货、销售发货检验、销售退货检验、跨组织销售、销售保证金【来源:销售管理】【来源:标准销售业务】
- 订单单据类型：标准销售订单(6.0 起默认自由流程)、寄售、受托加工销售、直运、退货订单、分销购销、分销调拨、VMI销售、现销订单(出库审核后自动生成应收单和暂存收款单)【来源:销售订单】

- 控制：交货数量控制(发货上下限)、可销控制(客户-物料/销售员-物料/销售员-客户)、预收控制(收款计划控制环节)、信用控制(见信用管理)、可发量控制【来源:销售管理】【来源:可销控制】【来源:收款计划及预收】

## 2. 单据和关键字段（只列原文字段名）
### 2.1 销售报价单【来源:销售报价单】
- 表头：客户、客户地点、销售组织、销售部门、销售组、销售员、生效日期、失效日期、单据状态、是否含税
- 财务：结算币别、收款条件、结算方式、价目表、折扣表、本位币、汇率类型、汇率
- 明细：物料编码、物料名称、规格型号、单位、数量、单价、税组合、税率、税额、金额、价税合计、起订量
- 规则：可以失效和反失效；可多次下推订单，不控制关联数量(要控制需另行配置)
### 2.2 销售订单【来源:销售订单】
- 表头基本：单据类型、业务类型(普通/寄售/直运)、单据编号、日期、客户、销售组织、销售部门、销售组、销售员、交货地点、交货方式、单据状态、结算币别
- 客户信息：收货方、收货方地址、收货方联系人、结算方、付款方
- 财务：收款条件(预收比例不为 0 时自动勾选"是否预收")、结算方式、价目表、折扣表、税额、金额、价税合计、是否含税、本位币、汇率类型、汇率
- 收款计划：是否预收、应收比例(%)、应收金额、到期日、关联单号(预收收款单)、实收金额、控制环节(订购/发货/出库/生产)
- 订单条款：条款编码、条款名称
- 明细：物料编码、物料名称、规格型号、销售单位、销售数量、计价单位、计价数量、单价、含税单价、税组合、税率、税额、金额、价税合计、要货日期、库存组织(可为空，下推时再选)、结算组织、备注
- 物料数据：货主(用于判断是否组织间交易)、供应组织(下推生产/采购订单时带出)、批号、辅助属性、BOM编号、保质期单位、保质期、生产日期、有效期至
- 交货明细：控制发货比例、发货上限=数量×(1+上限比例)、发货下限=数量×(1−下限比例)
- 其他：业务关闭、业务冻结、冻结人、冻结日期、业务终止、终止人、终止日期、源单类型、源单单号、累计发货通知数量、累计出库数量、累计退货通知数量、累计退货数量、剩余未出数量(=订单数量−累计出库数量)、关联调拨数量、累计采购申请数量、累计采购订单数量、累计应收数量、变更标志、业务流程
- 操作：整单关闭/反关闭、行关闭/行反关闭、业务冻结、业务终止、获取最新订单价格、信用查询、预收查询、应收查询、变更查询、获取库存、获取用量(可承诺量)、锁库/解锁、预留创建/修改/释放/综合查询
- 期初销售订单：通过"是否期初单据"区分；可下推期初销售出库单/期初退货单(不更新库存)
### 2.3 发货通知单【来源:发货通知单】
- 发货组织、发货部门、承运商、运输单号、出货仓库/仓位(带到出库单)、备货仓库/仓位(先调拨再出库)、货主、控制出库比例(没有上游订单时用)、出库下限=数量×(1−下限比例%)、出库上限=数量×(1+上限比例%)、源单类型/单号、订单单号、累计出库数量、未出库数量(=数量−关联出库数量)、关联调拨数量、业务流程
- 所有行的关联出库数都达到数量下限时，整单自动关闭；单据类型参数【发货通知单执行出库即关闭】；"变更数量"操作会改写订单的可出数量(之后需要信用重算)
### 2.4 销售出库单【来源:销售出库单】
- 表头：日期(必须晚于 max(库存组织关账日期, 货主关账日期))、承运商、运输单号、发货组织、发货部门、库存组、仓管员、汇率
- 明细：应发数量(=上游数量−关联出货数量；按交货计划取当前日期前的计划数量)、实发数量、仓库、仓位、库存状态(只能选"可用")
- 物料数据：BOM编号、货主、批号、生产日期、保质期单位、保质期、有效期至(到期日规则：按日=生产日期+保质期；按年/月则顺延，不反算)、辅助单位、辅助单位数量
- 财务：价格字段只在零售出库单中显示；赠品
- 其他：累计退货通知数量、累计退货数量、累计应收数量
- 操作：批号库存、批号主档、到货确认、检验确认(是否确认/确认人/确认日期)
### 2.5 退货通知单【来源:退货通知单】
- 库存组织、部门、库存组、仓管员、退货客户、退货原因；数量、退货类型(退货/退货补货)、货主、累计退货数量、业务流程
- 来源：手工、销售订单(订单必须已有出库数量)或销售出库单
### 2.6 销售退货单【来源:销售退货单】
- 库存组织、库存部门、库存组、仓管员、退货客户、退货原因；应退数量、实退数量、退货类型、仓库、仓位、库存状态、货主、销售成本价(成本核算后反写)、累计应收数量
### 2.7 寄售结算单【来源:寄售结算单】
- 单据类型、日期、结算币别、发货组织、客户、交货地点、价目表、销售组织等；结算明细：结算类型(发出/退回)、物料、结算数量、结算单价、结算含税单价、仓库(客户属性仓)、仓位；匹配发货：调拨发出数量、未结算数量、本次结算数量、发出单价、源单行号、已出库数量
### 2.8 基础/业务资料
- 销售价目表：销售组织、价目表对象、生效日期、失效日期、含税、限定客户(空/客户/客户类别)、限定销售员(空/销售员/销售组/部门)、价格类型；表体：物料编码、计价单位、价格系数、至(数量段)、价格、最低限价【来源:销售价目表】
- 销售折扣表：折扣对象(物料/物料分组)、折扣类型(折扣/附加)、计算方式(折扣率/折扣额)、折扣依据(数量折扣/金额折扣)、从…至、折扣率、折扣额、自动应用折扣【来源:销售折扣表】
- 销售调价方案：价目表、物料范围(从/至)、调价类型(单价/最低限价)、调价方法(数额/百分比)、调价幅度、调整有效期；调整前/后单价、调整前/后最低限价、调后生效/失效日期【来源:销售调价方案】
- 客户物料对应表：销售组织、客户、客户物料编码、客户物料名称、物料编码、辅助属性、启用【来源:客户物料对应表】
- 可销控制：销售组织、可销对象、可销范围、客户地点【来源:可销控制-客户物料】
- 物料销售页：销售单位、销售计价单位、订货批量、最小批量、最大批量、超发上限、超发下限、允许退货、退货检查、不参与可发量统计；质量页：来料检验、产品检验、抽样方案、质检方案【来源:物料】

## 3. 状态流转、下推和反写
- 单据状态：暂存 → 创建 → 审核中 → 已审核 → 重新审核；行状态：业务关闭(系统自动)、业务冻结、业务终止(都由人工操作)；整单关闭【来源:销售订单】
- 主链：报价单 →(多次，不控数量) 订单 → 发货通知单 → 出库单 → 应收单；订单也可直接推出库单【来源:标准销售业务】
- 反写：
  - 发货通知审核 → 订单"累计发货通知数量"
  - 出库审核 → 订单"累计出库数量"和通知单"累计出库数量"
  - 退货通知审核 → 订单/出库单"累计退货通知数量"
  - 退货单审核 → "累计退货数量"
  - 应收审核 → "累计应收数量"
  - 采购申请/采购订单审核 → 订单"累计采购申请/订单数量"
  - 调拨保存 → "关联调拨数量"
  - 寄售出库审核 → 结算单"已出库数量"
  - 【来源:销售订单】【来源:发货通知单】【来源:销售出库单】
- 关闭规则：出库数量不能超过上限；达到下限后订单/通知单自动关闭；全部发货后再退货换货时自动反关闭；退货类型为"退货补货"时，保存退货单会自动反关闭原订单，为"退货"时需要手工处理【来源:销售出库单】【来源:销售退货单】
- 超发控制单位可以选销售单位或库存单位【来源:销售订单】
- 发货检验：物料启用发货检验后，检验单"判出"的数量才能带到出库单；参数【发货检验合格自动出库】【来源:销售发货检验】【来源:销售管理系统参数】
- 退货检验：检验"判退"的数量才能带到退货单；物料没启用退货检验时，由通知单直接推退货单；参数【退货检验后自动退货】【来源:销售退货检验】
- 锁库：只能锁已审核、未关闭、未冻结、未终止的订单；锁库后不能反审核或变更；出库时先出锁库部分，出完自动解锁；冻结/终止/手工关闭前必须先解锁【来源:销售订单锁库和预留】
- 预留：可以预留预计入库量和 BOM 子项；单据转换时预留关系会转移；需要计划模块的预留参数【来源:销售订单锁库和预留】
- 未生成应收前，出库和退货可以冲销：按客户+币别+物料+销售组织+结算组织匹配，数量相同才能冲；已冲销的单据不能反审核【来源:销售出库退货未应收冲销】
- 跨组织：出库单/退货单上货主≠结算组织(且属于不同核算组织)时，生成组织间结算清单【来源:跨组织销售的应用】
- 寄售：寄售订单 → 发货通知 → 寄售直接调拨(到客户仓，货主不变) → 寄售结算单 → 寄售出库 → 应收【来源:寄售业务】
- 直运：直运销售订单 → 直运采购订单；应收依据订单生成，默认没有出入库【来源:直运销售业务】
- 变更：推荐用新变更单(支持审批流)；变更单审核后需要"生效"(有参数可自动生效)，生效后不能反生效；可选版本管理【来源:销售订单新变更单】

## 4. 参数（销售管理系统参数）【来源:销售管理系统参数】
- 参数分四层：组织级 / 单据类型级(如【参考交货计划执行】【发货通知单执行出库即关闭】) / 单据参数(反审核人=审核人) / 操作选项(提交后自动审核)
- 基本：启用客户物料对应表、仅按默认携带、控制发货数量、业务组数据隔离、业务员资料按组织隔离、发货检验合格自动出库、退货检验后自动退货、销售订单 BOM 版本携带规则、单据转换强制携带上游汇率
- 锁库：库存不足时允许部分锁库、手工关闭时自动释放锁库、锁库信息携带到发货通知单(仅按锁库数量携带)、按订单仓库锁库
- 寄售：寄售业务支持非寄售类型客户、寄售结算仅匹配结算日期之前的调拨单
- 可销：强制销售员等于制单员、三种可销范围控制(允销/限销/允销范围)、根据可销范围控制单据查询权限
- 订单变更：启用订单变更单(将被取消)/启用订单新变更单/直接订单变更、启用版本管理、变更单审核后即生效、已关闭订单可以变更物料、变更时不校验关联采购/生产数量、新变更判断关联数量时扣减退货数量、新变更单同步更新下游单据单价
- 价格：限价控制(按单据名称+单据类型，强度为不予控制/预警提示/禁止交易，另有密码特批)、控制时点、检查价格来源(强制价目表)、自动应用优先级取价、按客户物料价目表取价、自动获取销售折扣、整单折扣分摊方式(按价税合计比例/平均)
- 套件：启用套件管理等 10 项(二期)

## 5. 审批点
- 销售订单、发货通知单、出库单、退货单都有 创建→审核中→已审核 的状态，可以挂审批流【来源:销售订单执行明细表】
- 低于最低限价时：预警、禁止或密码特批；要让限价走审批流，需要在表头加一个"低于限价"标识字段，审批流按这个字段分支【来源:销售价格管理】
- 订单新变更单走审批流【来源:销售管理系统参数】
- 信用超标时的审批见信用管理【来源:销售管理】

## 7. 对电子元器件 ERP 的结论
- **一期**：
  - 客户、客户物料对应表(客户料号)、销售价目表(数量段+最低限价)、销售报价单
  - 销售订单(含收款计划/预收、发货上下限、交货计划)、订单新变更单+审批
  - 发货通知单、销售出库单(批号/生产日期/有效期至、库存状态=可用)、退货通知单、销售退货单
  - 发货检验(OQC)和退货检验的衔接，锁库
  - 订单执行明细、发货及时率、可发量
- **二期**：寄售、直运、套件、折扣表折上折、调价方案、可销控制、模拟报价、预留(随 MRP)、跨组织/分销、保证金、销售看板。
- **扩展(原文没有，属于我们的设计)**：
  - 出库时按条码/卷盘拣货并执行 FIFO(复用条码管理的先进先出严格控制)
  - 按客户要求的 D/C(生产日期)上限拦截出库：这是对原文"有效期至"的扩展
  - MSL 物料出库前检查暴露时长(复用库存状态/条码主档扩展)
