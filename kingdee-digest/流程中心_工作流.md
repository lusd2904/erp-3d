## 0. 精读要点
- 设计器有两种：审批流设计器（开始 / 审批 / 终审 / 消息 / 人工服务 / 结束节点），工作流设计器（流程 → 节点 → 动作三层，动作包括审批、消息、脚本、自动单据转换、自动单据提交、服务）【流程设计器】【工作流设计器】【审批流设计】
- 只有终审节点改单据状态，执行终审即完成审核【审批流设计】【顺签审批流程】
- 顺签：逐级审批；一个节点可以有多个参与人，任一人处理即节点完成（全站没有“或签”一词，语义等同）【顺签审批流程】
- 会签：按票数（确定票数 / 比例票数）或按投票人数（比例人数）判定，可以要求顺序处理；会签节点不支持超时处理；“支持会签”与“指定下一步处理人”不能同时勾选【会签审批流程】【工作流设计器-审批-字段说明】【高级选项_页签】
- 并行与条件：出入模式分并行（等全部前序）和串行（任一到达，其余分支丢弃）；条件分支可以放在模板启动条件上，也可以放在连线条件上【并行分支流程】【条件分支流程】
- 驳回：工作流必须画驳回线，不能驳回到开始节点；审批流靠“选择驳回节点”选项在运行时选择【工作流设计器】【审批流设计器-字段说明】
- 节点选项：允许转发（转交）、加签（前加签 / 后加签，受加签规则约束）、传阅、批量处理、指定下一步处理人、允许追加参与人（前置条件是允许指定下一步处理人）【高级选项_页签】【工作流加签规则】
- 允许撤销：处理后、后续任务未处理前，可以从已办撤销，回到原提交节点，并执行“撤销操作”关联的补偿操作；参数“流程任务撤销回本人”【工作流设计器-审批-字段说明】【流程中心系统参数】
- 超时：按小时设置时长，超时策略为自动执行审批项或转交指定处理人，时间按工作流日历计算【工作流设计器-审批-字段说明】【工作流日历】
- 委托与移交：委托按流程模板设置，可以分岗位，有生效 / 失效日期，支持“委托任务撤回”；移交只按用户维度【流程委托设置】【流程委托规则】【流程移交】
- 审核以外的操作也能走流程：通过“提交 XX”操作绑定状态字段，操作上勾选“是否检验流程”就禁止绕过；一张单据只有一个流程模板，按启动条件区分不同流程【工作流对其他操作的支持】
- 生命周期：设计 → 发布版本 → 流程配置中心做模板配置（组织、单据、启动条件、节点视图）→ 启用 → 实例；实例状态有运行中 / 暂停 / 挂起 / 终止 / 完成，终止不会反审核单据【流程配置中心】【流程管理_流程实例】
- 运行参数：处理模式有消息队列（推荐）和同步两种；邮件通知可以用虚拟邮箱；另有 4 张流程分析报表和流程日志、流程归档【流程中心系统参数】【工作流归档】

## 1. 功能点（每页首句，共 48 页，正文 73192 字，图片 35 张未 OCR）
- 【人工单据转换流程】业务单据在单据转换的流转过程中，并非所有目标单据的字段值都可以从源单中取到，或者在单据转换过程中需要人工调整目标单数据，此种情况下，也可以通过工作流调出单据下推菜单项，人工完成下推操作，即而实现通过流程对业务的驱动。
- 【会签审批流程】会签审批：一种联合审批的特殊审批节点，可理解为一种多人投票机制，一个任务需要多个人同时处理，然后汇总多个人的意见，决定流程下一步该如何执行。
- 【出库成本核算业务流程图】（正文无说明文字，25字）
- 【单据下推】销售订单下推生成采购申请单或采购订单时，销售订单会生成与采购申请单/采购订单的预留关系。
- 【审批意见管理】审批意见管理是流程任务审批时快捷录入意见的意见集合，支持按单据类型、审批类型设置审批意见 ，支持配置共享、私有审批意见，这样在任务处理时选择审批意见会找到更适合的意见内容。
- 【审批流设计】设计中心新建流程若选择新建审批流，则进入审批流设计器，在审批流设计器中可以完成审批流程的设计，通过在流程图中添加审批节点，再对审批节点设置参与人等属性，即完成审批流的设置。
- 【审批流设计器-字段说明】1.基本信息-名称：该节点的名称；
- 【客户中心业务流程】（正文无说明文字，21字）
- 【工作流】工作流(Workflow)，是“业务过程的部分或整体在计算机应用环境下的自动化”，它主要解决“使在多个参与者之间按照某种预定义的规则传递文档、信息或任务的过程自动进行，从而实现某个预期的业务目标，或者促使此目标的实现”。
- 【工作流加签规则】流程运行时，在流程的某个节点上，流程处理人在处理流程任务时或者处理任务后，需要添加处理人，并在流程中可以体现添加处理人的动作和意见，使工作流更丰富。
- 【工作流对其他操作的支持】除了审核操作以为，业务单据、基础资料上的一些其他业务操作，例如：禁用、作废、整单关闭等操作需要进行流程处理时，可以通过工作流进行配置完成。
- 【工作流归档】工作流流程实例已经完成，相应的已办任务信息和流程实例信息都可以进行归档，归档后的数据和未归档数据可进行分开查询，提供查询效率。
- 【工作流操作手册】新建流程：定义流程名称、入口单据等信息；
- 【工作流日历】工作流日历设置提供了工作流运行时，流程处理时间、流程超时提醒、流程超时处理等时间计算的依据。
- 【工作流移交】当有员工离职、换岗等原因不再处理之前的一些流程，需要将这些流程的处理人有当前处理人移交给其他处理人；
- 【工作流角色】工作流角色是工作流节点参与人的一个新维度，工作流角色独立于工作流模型设计之外，有员工、岗位、部门三个维度来定义，当流程处于运行中，还没到达的节点时如果配置了工作流角色维度，工作流角色定义的数据发生变化时，流程可以实时获取角色的变化的值，而不用对工作流模型的设计信息进行发布。
- 【工作流角色组】工作流角色组是对工作流角色进行分组，例如A组织下的岗位维度的角色可以归为一组，在流程节点上参与人维度工作流角色组上选择该组，相当于在工作流角色维度中选择了该组所有的数据。
- 【工作流设计器】设计中心新建流程若选择新建工作流，则进入工作流设计器，在工作流设计器中可以完成较为复杂流程的设计，通过在流程图中添加节点、动作，再对节点、动作设置相关属性，即完成工作流的设置。
- 【工作流设计器-审批-字段说明】工作流设计器-审批-字段说明
- 【工作流设计器-自动单据提交】一个流程中如涉及到多张单据，流程中除了入口单据是通过发起流程进行提交，其余单据也需要实现自动启动工作流，因此可通过单据提交动作自动提交工作流。
- 【工作流设计器-自动单据转换】单据转换动作可以自动根据流程入口单据设置的单据转换，将入口单据下推生成目标单据；
- 【工作流附录】流程模型：按照企业实际的业务流程过程，在工作流设计器中进行抽象实现的一套电子化系统化的流程运行轨迹描述，其中包括抽象化的分支路线描述、各个节点的处理人、每一流程节点下的处理的逻辑规则等等，组合成为一整套的企业业务流程的系统化描述，技术上也可称为流程定义。
- 【并行分支流程】并行分支流程：同一流程中会出现同时运行的多条流程分支，这些并行分支同时处理完成后，才可以激活流程汇合节点生成汇合节点的待办任务。
- 【条件分支流程】条件分支流程：在实际业务中，同一业务对象在不同条件下会使用不同的流程，或者同一流程中会按照不同条件流向不同分支，例如：金额报销单，当金额较大时，需要主管、经理、总监三级审批，但是小额报销，则只需主管、经理二级审批即可。
- 【流程中心系统参数】工作流参数设置提供了与流程运行相关的几个参数，一般企业在工作流正式上线前需要确认系统参数。
- 【流程委托设置】用于满足由于参与人不在岗或者权限移交等情况下，需要将个人的流程处理权限转移给他人的业务，支持按照流程模板进行委托设置，支持分岗位进行委托设置.
- 【流程总体状况分析报表】普通列表项目流程总体状况分析表主要是从全局的角度监控流程运行的状况和运行的效率，展示组织级别流程模板的数量，流程运行状况以及流程参与的情况。
- 【流程总体状况分析报表过滤】普通列表项目流程总体状况分析表主要是从全局的角度监控流程运行的状况和运行的效率，展示组织级别流程模板的数量，流程运行状况以及流程参与的情况。
- 【流程日志】介绍：流程日志默认记录流程节点发送邮件的详细情况，以及流程运行中错误的信息，如果参数设置中勾选记录工作流的详细信息参数，流程日志会记录流程每个步骤的详细日志。
- 【流程时间耗费分析报表】普通列表项目流程时间耗费分析表主要是通过展示流程实例从开始到结束、流程节点从开始到结束的平均耗时以及最长、最短耗时情况，给予流程管理员对流程运行效率的分析给予数据支撑。
- 【流程移交】当有员工离职、换岗等原因不再处理之前的一些流程，需要将这些流程的处理人有当前处理人移交给其他处理人；
- 【流程管理_待办任务】在流程管理中心可对流程产生的任务进行集中监控管理，主要功能为任务转发。
- 【流程管理_流程实例】通过流程模板建立组织、单据、流程的具体关系后，实际进行业务操作发起流程时，产生的依托于模板的流程即为一个流程实例，即每次发起流程都会产生一个流程实例；
- 【流程管理中心】用于监控管理流程的运行状况，便于流程管理人员对流程进行集中管理，包括：监控流程实例运转的情况、流程实例的状态变化、以及各个流程实例对应任务的状态变化。
- 【流程节点时间耗费分析表】通过流程节点时间耗费分析表可以查看流程的每个节点处理的时间耗费，以及整个流程运行开始到结束的整体时间，可以查看某个业务对象的流程或者某个流程实例的节点和整体运行时间。
- 【流程设计中心】流程设计中心为流程设计者提供一个集中对流程进行设计的平台，通过设计中心可以进入设计器对流程进行设计，通过流程设计器可以将抽象的业务流程以具象的流程结构图的形式进行展现，有利于企业业务流程的梳理，也可以将定义好的流程进行发布、管理、修改。
- 【流程设计器-批量设置】流程设计器界面点击批量设置按钮，打开批量设置界面
- 【流程设计器-消息】消息动作用于在工作流中自动发送消息，发送的消息可以通过信息中心消息查询查看。
- 【流程运行状况分析报表】普通列表项目流程运行状态分析表主要是分组织展示各种状态流程的情况以及所占比例，从流程管理员进一步分析，便于后续流程设计和运行的改进。
- 【流程运行状况分析报表过滤】普通列表项目流程运行状态分析表主要是分组织展示各种状态流程的情况以及所占比例，从流程管理员进一步分析，便于后续流程设计和运行的改进。
- 【流程配置中心】流程配置中心主要用于配置发起流程的适用单据、组织、条件等，同时也可以设置流程节点的配置界面，一方面通过模板提高流程配置的复用程度；
- 【电子签章】电子签章是在工作流审批时，将审批人的个人签名图片显示在单据上，实现审批人自动签章的功能。
- 【自动单据转换流程】业务流程中不同单据之间具有流转关系，同时不同单据也要进行不同级次的审批，工作流可以通过单据转换、单据提交动作将不同单据设置的审批流链接起来，从而实现通过流程对业务的驱动。
- 【邮件审批】概述：邮件审批主要应用在工作流在进行超时醒发送邮件时，用户可以在查看提醒邮件时，通过点击链接直接进行任务处理。
