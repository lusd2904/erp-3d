## 1. 功能点
- 检验类型：来料检验（采购/委外）、产品检验、库存检验、自制工序检验、委外工序检验、工序巡检、生产线检验、发货检验、退货检验、受托材料检验、生产退料检验、委外退料检验、其他检验【来源:检验单】【来源:质量管理】
- 特性：多种使用决策、来料/产品检验确定辅助属性、按序列号检验、可配置检验报告、二次及多次检验、国标抽样（GB/T2828.1-2012）、合并检验、不良品处理、MRB 评审、调整型抽样（按供应商/车间质量自动转宽严）、产品首检【来源:质量管理】
- 请检单据：库存请检单（库存请检/发货请检）、生产退料请检单、委外退料请检单、其他请检单【来源:库存请检单】【来源:生产退料请检单】【来源:委外退料请检单】【来源:其他请检单】
- 后续判定：不良品处理单（含质量折让→负应付/负应收）、MRB评审单（多部门会签判定）【来源:不良品处理单】【来源:mrb评审单】
- 基础资料：抽样方案、检验项目、质检方案、质量标准、检验方法、检验仪器、检验依据、缺陷类型、缺陷原因、缺陷后果、检测值、检验项目对应检测值、AQL / 样本字码表 / 抽样方案检索表（国标资料）、库存检验控制码、宽严度转换规则、物料来源质检规则【来源:辅助基础资料】【来源:质量管理】
- 复检：库存物料复检到期查询，可用执行计划自动请检，并通过监控方案“库存请检单待检验预警”发消息【来源:库存物料复检到期查询】
- 质量工作台：待办卡片（今日新到检验单、未完成检验单、待不良处理的检验单、待MRB评审的检验单、本月完成的检验单、待审核的不良品处理单、待审核的MRB评审单）；异常播报（物料、供应商、生产车间的不合格率排行榜）【来源:质量工作台】
- 移动质检（HMI 首检、巡检、工序检验、委外检验）：工序汇报单单据类型勾选“审核自动生成检验单”【来源:移动质检_参数设置】

## 2. 单据和关键字段
### 2.1 检验单（核心）【来源:检验单】

| 生产汇报单 | 产品检验 |
| 库存请检单 | 库存检验（发货类型为发货检验） |
| 工序汇报单 | 自制工序 |
| 工序转移单 | 委外工序 |
| 退货通知单 | 退货检验 |
| 发货通知单 | 发货检验 |
| 生产线产品完工汇报单 | 生产线检验 |
| 受托加工材料收料单 | 受托材料检验 |
| 生产退料请检单 | 生产退料检验 |
| 工序计划单 | 工序巡检 |
| 无源单 / 其他请检单 | 其他检验 |
| 委外退料请检单 | 委外退料检验 |
| 检验单 | 继承源检验单的业务类型 |

- **明细**：序号、物料编码、物料名称、规格型号、质检状态、单位、检验结果（合格/不合格/保留）、检验数量、合格数、不合格数、质检方案、供应商、客户、生产车间、仓库、仓位
- **检验数量默认值**：来料检验 = 采购收料单“实收数量”-“检验关联数量”；产品检验 = 生产汇报单“完成数量”-“检验选单数量”；其余类型同理。
- **检验结果页签**：批号（仅来料检验可改）、时间单位、耗用时间、样本破坏承担方（我方/供应商）、检验次数（源单为检验单时=源检验次数+1）；使用决策子表：序号、状态、数量、使用决策
- **参考页签**：质检开始日期、质检完成日期、检验单关联标志、源单类型、源单行号、订单号、订单行号、合格品/不合格品/报废品入库选单数量、保质期、保质期单位、生产日期、有效期至、新有效期至
- **整体抽样**：抽样方案、抽样类型、检验水平、严格度、AQL、样本量、允收数、拒收数、样本不合格数、样本破坏数
- **缺陷记录**：缺陷类型、缺陷数量、缺陷原因、缺陷等级（致命缺陷/重缺陷/轻缺陷）、缺陷后果
- **检验项目**：检验项目代码、检验项目名称、分析方法（定量/定性/其他）、缺陷等级、破坏性检验、重点检查、质量标准、检验方法、检验仪器、检验依据、抽样方案、抽样类型、检验水平、严格度、AQL、样本量、允收数、拒收数、样本不合格数、样本破坏数、检验结果、启用样本检测值、0值无效
- **使用决策枚举与合格数口径**（【来源:检验单】）：

| 检验类型 | 使用决策 | 合格 | 不合格 |
|---|---|---|---|
| 采购来料 | 接收、让步接收、挑选（全检）、判退 | 接收 | 其余 |
| 委外来料 | 上面四种 + 工废、料废 | 接收 | 其余 |
| 产品检验 | 接收、不良、返修、返工、报废、挑选（全检） | 接收 | 其余 |
| 库存 / 退货 / 发货 / 其他 | 接收、报废、不良、挑选（全检） | 接收 | 其余 |
| 自制工序 / 委外工序 | 接收、让步接收、返修、挑选（全检）、工废、料废 | 见下注 | 见下注 |

## 3. 状态流转、下推和反写
- 通用单据状态：暂存→创建（保存）→审核中（提交）→已审核；反审核→重新审核。各单据字段说明均有此描述。
- **检验单行质检状态**：计划→质检开始→质检完成。检验单审核后才能执行质检开始/完成；质检完成时把结果反写到源请检单据（采购收料单、生产汇报单、库存请检单、工序汇报单、工序转移单、退货通知单、发货通知单等）【来源:检验单】
- 使用决策勾选“不良处理”或“MRB评审”的数量，质检完成时**不反写上游**，要先下推不良品处理单或MRB评审单【来源:检验单】
- 检验结果为“保留”或使用决策为“挑选（全检）”时下推二次检验单（检验次数+1），可多次循环；如果同时有 MRB，必须等 MRB 全部完成【来源:检验单】【来源:来料检验】
- **来料检验**【来源:来料检验】
  - 采购收料单→检验单。接收+让步接收数量控制采购入库数；判退数控制采购退料数。
  - 通过参数，退料/工废/料废数量也可以作为不良品入库。
  - 紧急放行：收料单不经检验直接入库，以后可补做检验。
- **产品检验**【来源:产品检验】
  - 生产汇报单→产品检验，合格、不良、报废、返修、返工数反写生产汇报单和生产订单。
  - 生产入库按检验结果控制合格品、不合格品、报废品、返工品的入库数量。
  - 参数“产品检验后自动入库”“不良品处理单审核后自动入库”。
- **首检**【来源:产品检验】
  - 首检状态：检验合格→首检完成；不合格→空；保留→首检中。
  - 严格控制：首检完成（或首检状态为空）才允许汇报，首检完成才允许入库。
- **发货检验**：发货通知单→库存请检单（发货）→检验单（发货）→销售出库（按合格数量+不良可销售数量出库）【来源:发货检验】
- **退货检验**：使用决策勾选【判退】的数量才能继续办理销售退货（合格退货/不合格退货/报废退货）【来源:退货检验】
- **库存检验**【来源:库存检验】【来源:库存请检单】
  - 使用决策对应库存状态：接收→可用，报废→报废，不良→不良。
  - 通过库存状态转换单调整；请检审核后可自动冻结（库存状态转换单），检验结束后再解冻并转换。
- **生产/委外退料检验**：接收→良品退料，作业不良→作业不良退料，来料不良→来料不良退料；有参数控制自动生成退料单【来源:生产退料检验】【来源:委外退料检验】
- **工序巡检**：反写工序计划的巡检状态（巡检中/巡检合格/巡检不合格）；巡检合格才能继续下推工序汇报【来源:工序巡检】
- **不良品处理单**【来源:不良品处理单】
  - 保存：更新检验单使用决策和合格/不合格数，不良品处理状态改为进行中。
  - 审核：不良数量按不良处理类别累加到源请检单据（收料单/库存请检单/退货通知单/生产汇报单/工序汇报单/工序转移单/受托收料单/退料请检单/其他请检单），状态改为已完成；反审核时扣减。
  - 来料类下推负金额费用应付单，退货类下推负金额应收单；累计折让达到折让金额时自动关闭，不足时自动反关闭；也可手工关闭/反关闭。
  - 勾选“标准应付抵扣”后，审核时把折让金额反写到收料通知单。
- **MRB评审单**【来源:mrb评审单】
  - 保存：MRB评审状态改为进行中。
  - 审核：使用决策数量累加到检验单上游源单，MRB 状态改为已完成；决策和原检验单不一致时改写源检验单的使用决策。
  - 审核后可执行【再次检验】、【不良品处理】。
- **合并检验**【来源:检验单】【来源:质量管理参数】
  - 合并键（来料）：供应商+物料+批号+BOM版本+计划跟踪号+辅助属性+生产日期。
  - 产品、自制工序、库存、委外工序、退货检验各有自己的合并键。
  - 结果按源单数量权重或自上而下反写（顺序：接收、让步接收、判退、样本破坏）。

## 7. 对电子元器件 ERP 的结论
- **一期**
  - 检验单（来料 IQC、产品 FQC、发货 OQC、退货、库存复检）和库存请检单（含发货请检）
  - 不良品处理单（不含财务折让下推，二期再接应付）
  - 抽样方案（国标 GB/T2828.1 AQL：检验水平+严格度+AQL→样本量字码/Ac/Re）、质检方案、检验项目、缺陷类型/原因
  - 紧急放行、二次检验、质检冻结/解冻
  - 报表：供应商质量统计表、物料待检明细表、缺陷原因分析表
- **二期**：MRB评审单（流程引擎会签）、调整型抽样（宽严度转换规则+物料来源质检规则）、合并检验、样本检测值/X-R、不良率控制图、自制工序检验/工序巡检（IPQC，依赖车间工序）、首检、生产/委外退料检验、受托材料检验
- **电子行业要点**
  - 湿敏器件（MSL）的车间寿命和烘烤，可以借“库存物料复检到期查询+复检周期+提醒提前期”和“新有效期至”（库存检验合格后可延长有效期）实现；原文没有 MSL 概念，属于我方扩展。
  - AOI/SPI 判定结果作为自制工序检验的样本检测值来源。

- 【首检】HMI 主控台：
  - 检验单在报工时自动下推生成；扫条码(工序计划单编号-序列号-行号)找到任务；"开始检验"即审核检验单，状态变为"质检开始"
  - 首检录入：单据头为工单/工序/产品、作业指导书、拍照上传(存为 PC 端检验单附件)
  - 按抽样序号逐个录入检测值：定性分析取默认值，定量分析自动与目标值比较，判"合格/不合格"并提示不合格项数
  - 判"返修"时返修数+1、接收数−1；数据实时保存；点"质检完成"结束
  - 【来源:首检】
- 【工序检验】HMI 车间检验：只用于"工序控制码.检验方式=车间检验"的工序；提交时修改报工生成的工序汇报单【来源:工序检验】
- 【移动质检_工序检验】：工序汇报后自动下推检验单；默认抽样 1 份，可改；整体送检数默认等于完工数量，按抽样结果自动推算整体结果【来源:移动质检_工序检验】
- 【移动质检_委外检验】：由委外转移单自动下推检验单，其余同上(补丁 7.7.0.202108)【来源:移动质检_委外检验】
- 【工序不良品原因分析】：
  - 维度：产品+工序+缺陷原因 / 作业+缺陷原因 / 责任部门+缺陷原因 / 加工车间+缺陷原因
  - 检验数量=合格数量+废品数量+待返工数量；缺陷率=缺陷数量/检验数量
  - 【来源:工序不良品原因分析】
- 【柔性生产_报不良】：按不良分组或不良代码汇报多种缺陷；线上返修只录待返工数，线下返修可录待返工/工废/料废；支持多次返修【来源:柔性生产_报不良】
- 【柔性生产_批次上料】：
  - 序列号类关键件扫码绑定；非序列号件扫码或批次上料
  - 可上料数量=领料单数量+补料单数量−已上料数量，实时校验防止上错料
  - 按用料比例自动绑定扣减，生成投入物料表
  - **这是电子 SMT 上料防错和追溯的直接依据**
  - 【来源:柔性生产_批次上料】
- 【生产_委外退料检验质量统计表】：
  - 合格率%=合格数/检验数量
  - 不良率%=(来料不良+作业不良)/检验数量
  - 使用决策有：接收/来料不良/作业不良/挑选(全检)
  - 【来源:生产_委外退料检验质量统计表】
- 结论：
  - IPQC 首检和工序巡检的移动端录入(扫码→抽样→检测值自动判定→拍照)放进一期
  - 批次上料防错放进一期(与条码/追溯联动)
  - 柔性产线报不良放进二期
