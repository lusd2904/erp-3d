## 0. 精读要点
- 权限模型：按角色授权。用户权限是多个角色权限的并集，但“禁止”优先；优先级为 禁止 > 有权 > 无权，“禁止”用于职责分离【子系统功能授权】【业务对象功能授权】
- 授权方式：
  - 子系统功能授权：按权限组（查询、编辑、审核、其他、业务操作）授权，适合粗放管理
  - 业务对象功能授权：业务对象 + 权限项，适合精细管理
  - 批量授权：全功能、业务领域、子系统、业务对象、字段
  - 字段授权：查看和编辑两组，默认有权
  - 查看是其他权限的前置；查看无权时其他不能为有权，查看禁止时其他全部禁止
- 数据权限：
  - 数据范围（适用于查看、修改、删除、审核权限项），用数据规则配置，可用变量：当前组织、当前用户及其部门、业务组等
  - 默认只用表头字段；参数可开启明细级数据权限
  - 基础资料权限：控制新增单据时 F8 选择的范围，支持按单据类型和选单范围控制
  - 分组数据权限；V8.2 起可直接给员工授权物料、供应商、客户、仓库
  - 来源：【数据权限】【数据规则选项】
- 岗位体系数据规则：按岗位汇报关系向下取数，选项有直接下属 / 所有下属 / 其他业务员 / 本部部门 / 直属部门 / 所有下级部门 / 其他部门；只对查看有效；一个角色只能有一套【岗位体系数据规则】
- 角色：
  - 类型有普通角色和系统管理员（子管理员，可设授权范围）
  - 多组织下分公有 / 私有
  - 有预置角色、全功能角色、全员角色（可设新增用户时自动加上）
  - 角色被授权时不能删除；禁用后权限失效
  - 来源：【角色】
- 子系统管理员授权模式：三员分立思路，预置安全保密员和安全审计员【子系统管理员功能授权模式】
- 日志：
  - 上机操作日志：记录用户、时间、组织、子系统、业务对象、场景、操作、描述、IP、机器、单据编码；超过 5 万条自动归档，可定时清理成 Excel 备份
  - WebAPI 日志、执行计划日志、插件监控日志、应用性能监控日志
  - 业务数据日志：指定单据和字段，按差量记录修改前后的值
  - 来源：【上机操作日志】【业务数据日志设置】
- 数据归档：分表归档已结束的历史单据，不可逆，按任务定时分批执行【数据归档任务】
- 其他：
  - 新增单据防重配置：按单据头文本字段建唯一索引，供 WebAPI 接入防止重复【新增单据防重配置】
  - 限流配置【限流配置情况】
  - 过滤方案管理（隐藏预设方案）【过滤方案管理】
  - 权限报表：按用户 / 角色 × 子系统 / 业务对象 / 字段查询【用户权限报表】等

## 1. 功能点（每页首句，共 56 页，正文 48246 字，图片 3 张未 OCR）
- 【webapi日志】记录Web API的执行情况，输出执行耗时、执行明细情况等各类信息，同时还提供了自动清理，减少日志记录的表空间占用。
- 【上机操作日志】上机操作日志用来记录用户操作金蝶云系统的情况，以备系统管理员查看，同时还提供了归档或者情况处理，以减少日志记录日渐增长对系统性能造成影响。
- 【上机操作日志备份文件列表】上机操作日志清理完成，会在上机操作日志备份文件列表生成记录，方便系统管理员查看和下载已清理的历史久远的上机操作日志。
- 【业务对象功能授权】业务对象功能授权是角色按照【业务对象+权限】的组合模式进行授权，适用于精细型管理的企业。
- 【业务对象批量授权】业务对象批量授权是针对系统全部功能按照所选业务对象、业务对象权限组、业务对象单个权限进行批量授权的处理。
- 【业务数据日志明细表】通过查看明细、对比差异操作，打开“业务数据日志”等方式，都会打开数据日志的明细界面，按照不同方式传入的条件，展示对应的修改记录。
- 【业务数据日志汇总表】业务数据日志汇总表查询修改记录。
- 【业务数据日志设置】在系统使用过程中，单据可能多人具备修改权限，当关键数据出现被人修改的异常时，通过上机操作日志记录仅能知道多人对此单据都有过修改操作，无法准确的追溯问题。
- 【业务领域批量授权】业务领域批量授权是针对系统全部功能按照所选领域、领域权限组、领域单个权限进行批量授权的处理。
- 【云瘦身】金蝶云系统运行一段时间后，数据库日渐庞大，金蝶云推出数据瘦身服务，通过订阅实现数据库优化、临时表和日志的清理，缩小数据库的容量。
- 【全功能批量授权】全功能批量授权是针对系统全部功能按照所选对象、权限组、单个权限进行批量授权的处理。
- 【分配角色】方便系统管理员，批量选择多个用户，同时授予组织和角色权限。
- 【启用岗位体系规则】岗位体系规则必须启用后才可以使用。
- 【子系统功能授权】子系统功能授权是角色按照【子系统+权限组】的组合模式进行授权，适用于粗放型管理的企业。
- 【子系统批量授权】子系统批量授权是针对系统全部功能按照所选子系统、子系统权限组、子系统单个权限进行批量授权的处理。
- 【子系统管理员功能授权模式】企业信息化系统中的管理员权限由一人承担，对企业信息安全存在很大的安全隐患，为了避免系统管理员拥有过度集中的权利带来高风险，金蝶AI星空提供了“子系统管理员授权模式”，可以将系统管理员的权限进行细分，子系统管理员只能负责自己的管理范畴，满足企业精细化管理的同时，系统管理员无法越权处理，可以有效满足ERP信息安全管理需要。
- 【字段批量授权】在采购或者销售等一些业务场景下，系统管理员需要对某些用户所有单据的（金额、单价、数量、折扣率、折扣额）敏感类字段批量设置无权。
- 【字段授权】字段权限是指对业务对象的字段操作权限。
- 【岗位体系数据规则】岗位体系数据规则是指按照岗位汇报关系的上下级关系，通过向下钻取的方式实现查询数据的隔离。
- 【岗位体系数据规则概述】岗位体系数据规则是指按照岗位汇报关系的上下级关系，通过向下钻取的方式实现查询数据的隔离。
- 【岗位汇报体系】根据汇报类型下岗位的上下级关系组合而成，可以展示每个汇报类型的岗位整体关系。
- 【岗位规则业务对象】配置岗位汇报体系数据规则的应用业务对象。
- 【应用性能监控日志】企业的信息化系统在日常使用过程中，难免会碰到性能变慢的情况发生。
- 【引入操作记录】引入操作的日志，支持记录引入操作的操作人、操作时间、操作的业务对象和引入的数量。
- 【引出操作记录】引出操作的日志，支持记录引出操作的操作人、操作时间、操作的业务对象和引出的数量。
- 【执行计划日志】记录执行计划过程中各项服务的执行情况，以备系统管理员查看，同时还提供了自动清理，减少日志记录的表空间占用。
- 【插件监控日志】从插件层面，监控F8事件及其实体服务的调用情况，掌握调用前后的数据变化，为开发分析提供数据辅助，同时还提供了自动清理，减少日志记录的表空间占用。
- 【数据归档任务】部分企业的业务单据流水特别大，单表数据量超过千万级，因数据量过大影响到正常业务操作性能。
- 【数据权限】数据权限是基于有功能权限内容的进一步数据范围控制，以缩小关键数据范围，从而保证敏感数据的安全性。
- 【数据瘦身】金蝶云系统运行一段时间后，数据库日渐庞大，金蝶云推出数据瘦身服务，通过订阅实现数据库优化、临时表和日志的清理，缩小数据库的容量。
- 【数据规则选项】数据权限是基于有功能权限内容的进一步数据范围控制，以缩小关键数据范围，从而保证敏感数据的安全性。
- 【新增单据防重配置】异构系统接入星空业务单据涉及支付需要设置唯一索引，通过“新增单据防重配置”实现指定字段的唯一索引管控。
- 【智能创建用户】大部分企业的权限体系是根据岗位体系来设计的，本次补丁支持员工的权限、许可随着业务的调整而实时动态调整，实现用户创建、授权、禁用的全链条智能化管理，提升企业系统管理效率。
- 【权限对象】列表展示系统所有的权限对象，新增的权限对象必须在某个子系统下进行新增。
- 【权限项】列表展示系统所有功能权限所包含的权限项。
- 【用户业务对象字段权限报表】用户和业务对象角度，进行字段权限的审计和查询，查询业务对象所有字段的有权和无权。
- 【用户业务对象权限报表过滤】用户业务对象权限报表主要从用户和业务对象的维度来查询用户的组织+业务对象+权限项+角色的情况，即展示用户具有哪些业务对象的哪些权限，是由哪个组织下的哪个角色带来的，便于管理员对用户的具体业务功能权限进行有效管控和综合分析。
- 【用户在线情况相关报表】为帮助企业了解员工的工作效能，提升许可利用率，V8.0提供用户在线相关数据报表，并优化数据统计逻辑，帮助管理员了解系统使用情况。
- 【用户基础资料权限范围报表】查询用户直接授权的基础资料数据，哪些基础资料数据是通过数据范围授权你的，哪些是通过数据直接授权的。
- 【用户子系统权限报表过滤】用户子系统权限报表主要从用户和子系统维度来查询用户的组织+子系统+权限组+角色的情况，即展示用户具有哪些子系统的哪些权限，是由哪个组织下的哪个角色带来的，便于管理员对用户的功能权限进行有效管控和综合分析。
- 【用户字段权限报表过滤】用户字段权限报表主要从用户和业务对象的字段维度来查询用户的组织+业务对象+字段+权限+角色的情况，即展示用户没有哪些业务对象字段的哪些权限，是由哪个组织下的哪个角色带来的，便于管理员对用户的字段功能权限进行有效管控和综合分析。
- 【用户所属组织角色报表】用户综合查询是查看用户具有角色及其使用状态的信息，便于系统管理员对用户进行有效管控和综合分析。
- 【用户权限报表】用户权限报表，从用户所属组织、角色、功能权限、数据权限、字段权限全局查看用户授予的权限情况。
- 【第三方系统登录授权】第三方系统与金蝶AI星空无缝集成，第三方系统直接单点登录。
- 【系统管理】系统管理既是系统运行的基础，又是支撑业务运作的基石。
- 【系统管理使用流程】数据中心创建后，默认系统管理员用户，用户名：Administrator（SQL Server下Administrator不区分大小写，Oracle下必须是Administrator，区分大小写且要求首字母大写）。
- 【缓存内容】系统提供缓存管理功能，支持即时清除系统缓存数据。
- 【角色】金蝶云的角色既是用户的职责体现，同时也是权限的载体，起到很重要的桥梁作用。
- 【角色业务对象字段权限报表】角色和业务对象角度，进行字段权限的审计和查询，查询业务对象所有字段的有权和无权。
- 【角色业务对象权限报表过滤】角色业务对象权限报表主要从角色和业务对象的维度来查询角色的业务对象+权限项的情况，即展示角色具有哪些业务对象的哪些权限，便于管理员对角色的具体业务功能权限进行有效管控和综合分析。
- 【角色子系统权限报表过滤】角色子系统权限报表主要从角色和子系统维度来查询角色的子系统+权限组的情况，即展示角色具有哪些子系统的哪些权限，便于管理员对角色的功能权限进行有效管控和综合分析。
- 【角色字段权限报表过滤】角色字段权限报表主要从角色和业务对象的字段维度来查询角色的业务对象+字段+权限的情况，即展示角色没有哪些业务对象字段的哪些权限，便于管理员对角色的字段功能权限进行有效管控和综合分析。
- 【设置批量授权字段】管理员可以提前设置常用的批量授权字段有权或者无权，包含：单价、金额、数量、折扣率、折扣额。
- 【过滤方案管理】为了方便企业管理员统一管理 金蝶预设过滤方案 ，隐藏不适用当前企业的应用场景的方案，在【系统管理】下增加“过滤方案管理”，支持 隐藏系统预设过滤方案 。
- 【重置密码】Administrator登录管理中心后，可以为业务数据中心管理员重置密码，进入【设置】→【重置密码】，即可打开重置密码界面进行设置。
- 【限流配置情况】为确保系统稳定运行，系统针对大数据量操作设有限流管控机制，以平衡资源负载并保障核心业务的高可用性。

### 系统管理/系统管理（补读 36 页，已全读）
- 实施顺序：登录数据中心→建组织体系（默认单体组织，多组织须先启用）→建角色（预置按岗位角色；公有/私有，只有 Administrator 能建公共角色；系统管理员角色可设授权范围）→建用户（先指定组织再分配角色，可批量）→授权（功能、批量、字段）→权限报表核查。【系统管理使用流程】
- 智能创建用户：按岗位自动分配角色和许可，员工/业务调整时权限实时联动，自动+手动结合，有用户角色许可报表。【智能创建用户】
- 批量授权四级：全功能/业务领域/子系统/业务对象，每级可按"整体/权限组（默认）/权限项"授权，**追加模式**，可"查询权限""查询受影响用户"。**字段批量授权**：按领域(+子系统)+角色，把单价、金额、数量、折扣率、折扣额等敏感字段一次设为无权/禁止；"设置批量授权字段"预设默认状态，查看无权时编辑联动无权，按基础资料设置则所有引用它的单据字段同步，禁止优先。【全功能批量授权】【业务领域批量授权】【子系统批量授权】【业务对象批量授权】【字段批量授权】【设置批量授权字段】
- 分配角色：批量选用户→选组织→分配角色；可把某组织的角色复制到其他组织。【分配角色】
- 权限报表补充：用户权限报表（一张表看用户→组织→角色（含禁用状态）→子系统→业务对象→权限项→**数据规则、岗位数据规则、是否设过字段权限**）；用户/角色业务对象字段权限报表（每个字段最终查看/编辑有权无权+来源角色）；**用户基础资料权限范围报表**（客户/物料/仓库/供应商哪些来自数据范围、哪些直接授权）；用户所属组织角色报表。非 Administrator 默认只看当前组织。【用户权限报表】【用户业务对象字段权限报表】【角色业务对象字段权限报表】【用户基础资料权限范围报表】【用户所属组织角色报表】【用户子系统权限报表过滤】等
- 权限基础设置：权限项（预置查看/新增/修改/删除/审批等，可自定义）→挂到权限对象→权限对象在 BOS 中与业务对象绑定后生效。【权限项】【权限对象】
- 岗位体系数据规则：须先"启用岗位体系规则"，与查看数据规则组合方式可选**交集（and，默认）或并集（or）**；岗位汇报体系按汇报类型（预置行政汇报）展示岗位树，可添加岗位、引入下级、调整汇报关系、添加任岗；岗位规则业务对象配置哪些单据按"业务员/部门"字段套用规则。【启用岗位体系规则】【岗位汇报体系】【岗位规则业务对象】
- 日志体系：WebAPI 日志、执行计划日志（任务编号、跟踪码）、插件监控日志——字段含开始/结束时间、总耗时、执行状态、日志类型（错误强制记录，业务/调试可选）、内容；记录范围按业务对象/执行计划选择；**按保留天数自动清理**；日志库与业务库分离。上机操作日志备份文件列表（文件名 logBackup+YYYYMM+…，大小，起止日期说明，存储位置，可下载）。【webapi日志】【执行计划日志】【插件监控日志】【上机操作日志备份文件列表】
- 应用性能监控：快捷键开启监控工具栏，记录每次交互的服务端方法调用，耗时≥1秒逐级标红。【应用性能监控日志】
- 缓存管理（按区段刷新/清除缓存）；数据瘦身/云瘦身（数据量超阈值推送预警，规则同前）。【缓存内容】【数据瘦身】【云瘦身】
- → 一期：批量授权（按模块/对象/权限项，追加模式+影响用户预览）；**敏感字段一键批量无权**（单价/金额/成本，对元器件报价保密很关键）；用户权限总览报表含数据规则；岗位规则与数据规则交集/并集可选；后台任务日志含跟踪码（trace id）与耗时，按天数自动清理。二期：智能创建用户（按岗位自动授权）、前端性能追踪。
