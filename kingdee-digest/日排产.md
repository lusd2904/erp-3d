# 日排产 摘要 — G1a
> 范围：生产制造_日排产.md 22页（含孤立11，多为APS集成/排程模型/排程日志，路径在车间管理），正文22,685字。重复页：aps配置信息/aps集成配置=aps配置。电子元器件相关度：**中**（SMT线体按日产能排产有价值；一期可简化）。

## 1. 功能点
- JIT日计划：按产线日产能与负荷，对生产订单按优先级/计划开工时间顺排；不支持倒排。【来源:日排产】
- 排产、调整（日产能/日期/数量/产线）、插单（锁定+顺延）、重排、取消排产、排产确认。【来源:生产日排产】
- 更新已排：用生产汇报单或生产入库单更新上线数量；或手工上线。【来源:更新已排】
- 日排产齐套分析（按齐套分析模板逐日计算齐套数量）、日排产发料（建议发料数量=当前日期~截止日期累计排产）、材料预留。【来源:生产日排产齐套分析】【来源:生产日排产查询】
- 委外日排产：按供应商产线日产量排委外订单（须已生成采购订单且有采购执行数量）。【来源:委外日排产】
- APS集成：APS配置、启动APS排程、查看APS排程、排程模型(不排程/标准正排/标准倒排/标准偏置时间正排)、排程日志。【来源:aps配置】【来源:排程模型】

## 2. 单据/资料与字段
| 对象 | 字段（原文） |
|---|---|

| 供应商产线日产量 | 同上，增加供应商【来源:供应商产线日产量】 |
| 生产订单排产明细 | 销售订单、客户、要货日期、生产订单、产线、日产量、排产日期、排产数量、未排数量、入库数量、退库数量【来源:生产订单排产明细】 |
| 生产日排产查询 | 排产数量、齐套数量、上线(完工)数量、发料数量【来源:生产日排产查询】 |
| 日排产参数 | 不允许删除当前日期之前的排产明细、不允许删除已执行的排产明细、生产排产不更新生产订单的计划完工日期【来源:日排产参数】 |

## 3. 状态流转
排产明细：未确认 → 已确认（排产确认）；锁定/解锁；取消排产回到未排数量。【来源:生产日排产】

## 4. 下推/反写
- 排产结果回写生产订单计划完工日期（除非参数禁止）。【来源:日排产参数】
- 汇报单/入库单 → 更新排产明细上线数量。【来源:更新已排】
- 日排产发料 → 生成领料（按建议发料数量）。【来源:生产日排产查询】

## 5–7. 参数/审批/报表
- 参数见上；排产确认可作为计划主管确认节点（建议）。
- 报表：生产日排产查询、销售订单排产查询（按销售订单/预测单视角）。【来源:销售订单排产查询】

## 8. 相关度

## 9. 字段说明逐字补读（第二轮）
- **产线日产量**：
  - 创建组织和使用组织都必须具有生产职能。
  - 单位默认取生产单位。
  - 调整比例 = 调整后日产量 ÷ 原日产量。【来源:产线日产量】
- **日排产参数**：
  - "不允许删除已执行排产明细"中，"已执行"指已有上线数量、齐套数量或发料数量。
  - "生产排产不更新计划完工日期"有生效条件：原计划没有拖期，且最早排产日期不大于计划完工时间。【来源:日排产参数】
- **生产订单排产明细**：
  - 未排数量 = 生产数量 − 排产数量。
  - 入库数量有两种取值方式：按实际入库（按入库单日期匹配排产日期），或按排产明细顺序逐天分配。【来源:生产订单排产明细】
- **生产日排产查询**：
  - 生产组织有且只能选一个。
  - 今天之前的日期可以显示上线数量、发料数量；今天及以后可以显示齐套数量1和齐套数量2。【来源:生产日排产查询】
- **APS**：
  - 每个组织只能有一个默认排程模型。
  - 排程方法：不排程、正排、倒排、偏置时间正排。
  - 排队、移动、等待时间三项各自可选：不考虑、标准、最小。
  - 排程日志的排程状态：进行中、正常结束、异常结束。【来源:排程模型设置】【来源:排程日志查询】
