# 财务会计／应收款管理

## 1. 功能点

应收款管理分四个业务环节：应收款确认、到期收款、收款核销、期末处理，处理销售应收和其他应收两方面业务。支持暂估应收与业务应收两种立账模式。预收款支持针对客户预收和针对订单预收两种场景。

**单据管理**
- 应收单：管理销售应收，支持快速新增、自动生成、多到期日、客户多方交易、内部结算
- 其他应收单：管理销售以外的其他应收业务
- 应收核销单：应收收款核销后自动产生，仅系统生成不可手工录入，反核销后自动删除

**核销**
- 应收开票核销：包括关联关系核销、匹配条件核销、手工核销、特殊核销、反核销、定时核销
- 应收收款核销：包括关联关系核销、匹配条件核销、手工核销、定时核销、快速核销、反核销
- 应收开票核销方案：为匹配条件核销设置核销关系与匹配条件
- 应收收款核销方案：设置核销关系、匹配条件、核销顺序
- 应收开票核销记录：记录各分录行当次核销金额，支持反核销
- 应收收款核销记录：列表展示核销记录，支持反核销
- 定时核销：按设定频率（每日/每周/每月）自动批量核销，支持禁用/反禁用
- 快速核销：在应收单及收款单的单据/列表工具栏增加「收款核销」按钮，快速匹配并核销对方单据；支持参数设置，可配置查找条件字段、是否弹出核销界面、默认核销方案
- 核销字段自动化配置：支持一键自动化生成自定义核销字段配置，可用于手工核销界面、转销界面、内部清理界面的显示及核销方案匹配

**内部应收清理**
- 内部应收清理：对组织间交易产生的内部往来进行无需收款清理、无需开票清理，支持反清理
- 内部应收清理记录：列表查询清理情况，支持反清理操作
- 内部应收清理单：内部应收清理后生成，作为总账做凭证的依据

**转销与坏账**
- 应收转销：支持应收单、预收单、其他应收单、费用应收单的转销，支持反转销
- 坏账处理：支持自动计提坏账，生成总账凭证；包括坏账损失处理、月末计提坏账准备、坏账收回

**期末处理**
- 应收期末调汇：期末将外币余额按期末汇率折算，计算汇兑损益
- 期末调汇单：查看期末调汇完后自动产生的应收期末调汇单
- 应收结账：按结算组织勾选结账，结账后可反结账
- 应收反结账：对已结账组织执行反结账
- 应收反初始化：结束初始化后、结账前可反初始化
- 应收业务云巡检：自动检查指定项目错误，支持邮件发送结果、定时执行

**初始化**
- 应收款启用日期：设置结算组织使用应收款管理模块的启用日期
- 业务初始化流程：启用日期设置 → 录入期初单据 → 结束初始化 →（可反初始化）

**收款条件**
- 收款条件：设置预收比例、到期日计算日期、收款方式及到期日确认方式

**报表**
- 到期债权表：反映截止指定日期已到期/未到期的未核销应收款及天数
- 客户对账单：展示原始金额、已收款金额、未收款金额及账龄分析，支持传递客户对账
- 应收单开票核销明细表：反映当期应收单开票核销明细，含本期及截止日期未开票核销情况
- 应收单跟踪表：查询应收单的订单、出库、开票、收款等关联情况
- 应收未开票明细表：反映当期应收未开票情况，支持按物料明细显示
- 应收款明细表：反映某段时间内与往来单位的期初余额、本期应收数、本期实收数、期末余额等明细信息
- 应收款汇总表：反映某段时间内与往来单位的期初余额、本期应收数、本期实收数、期末余额等汇总信息
- 应收款账龄分析表：反映往来款项余额的时间分布，支持自定义账龄分组，按业务日期或到期日计算账龄
- 往来对账明细表：展示往来单位的往来数据，当往来单位既是客户又是供应商时可合并列示；支持核销、分组功能

## 3. 状态流转、下推和反写

**应收单状态**
- 创建状态：必录字段完整时
- 暂存状态：必录字段不完整时
- 出库单审核时可自动生成应收单（需勾选对应参数）
- 应收单与销售发票彻底分离，应收单是债权成立的标志

**下推关系**
- 其他应收单 → 收款单（收款组织由其他应收单的收款组织决定）
- 应收单 → 收款单（收款组织由应收单的收款组织决定）
- 应收单 → 销售增值税专用发票或普通发票（应收单审核时自动生成，依据客户基础资料中的发票类型）
- 内部应收单必须由供应链的组织间结算清单下推生成，不可手工新增

**关联关系核销**
下游单据审核时系统自动执行，优先级最高。示例：应收单→收款单审核时自动核销；应收单→销售增值税专用发票审核时自动核销。应收单与发票自动核销（有关联关系时）；支持无关联关系的应收单与发票匹配条件核销。

**反核销**
在应收开票核销记录、应收收款核销记录界面均提供反核销功能。应收核销单反核销后自动删除。

**内部应收清理**
清理后生成内部应收清理单；支持反清理（在内部应收清理记录界面操作）。

**应收转销**
转销产生转出客户的已审核负向应收单和转入客户的已审核正向应收单；预收单转销产生转出客户的已审核收款退款单和转入客户的已审核预收款单；可通过反转销取消。

**立账模式**
- 暂估应收：未开票确认暂估应收，开票后确认财务应收同时红冲暂估应收
- 业务应收：货物转移即确认应收账款，不记暂估应收，开票后差异生成差异应收单

**初始化与启用日期**
- 应收款启用日期设置后如未有业务发生可修改，否则不可修改
- 结束初始化后不可再录入期初单据；结束初始化后尚未结账前可反初始化

**结账与反结账**
- 业务日期必须大于结账日期（无结账日期则大于等于启用日期）
- 应收结账：开始日期默认为最新结账日期+1且不可修改，结束日期默认为当月最后一天可手工修改；结账后可反结账
- 应收反结账：开始日期默认为上次结账日期+1，结束日期默认为最新结账日期，锁定不可修改
- 勾选"存在未审核的单据时不允许结账"则必须全部审核才可结账，不勾选则允许结账但提示未审核单据

**定时核销方案**
支持禁用、反禁用操作；表体单据字段只允许选择"应收单"、"收款单"；支持应收单（正）VS应收单（负）、应收单VS收款单定时核销；保存时校验不允许单据重复设置。

**快速核销**
- 核销关系涵盖三种：应收单-收款单、应收单-预收单、应收单（正）-应收单（负）
- 本次核销金额默认等于收款计划金额 - 已核销金额，可手工修改
- 未勾选「快速核销弹出核销界面」时，查找到对方单据后自动按默认核销方案执行匹配核销，不弹出界面
- 菜单入口：应收单工具栏「下推」按钮之后增加「收款核销」；收款单工具栏「选单」按钮之后增加「收款核销」

**期末调汇单**
期末调汇完后自动产生期末调汇单（原文未描述更多状态流转细节）。

## 4. 与生产、供应链的接口

**销售出库与应收生成**
- 应收单快速新增时，系统展示所有还未生成应收单的销售出库单、销售退货单和销售订单
- 出库单审核时可自动生成应收单（需勾选对应参数）

**组织间交易与内部结算**
- 内部结算的应收单必须由供应链的组织间结算清单下推生成

**应收单跟踪与报表关联**
- 应收单跟踪表可查询应收单的订单情况、出库情况、开票情况、收款情况

**应收与应付互核**

**账务处理**

- 暂估应收模式下通过财务应收单生成"应收账款"凭证

## 5. 与电子元器件制造的相关度

**相关度：中**

判断理由：
1. 电子元器件制造企业有大量销售出库业务，出库单审核自动生成应收单、应收单跟踪表查询出库情况等功能直接对接销售环节，需求明确。
2. 电子元器件行业客户集中度较高、账期管理要求强，收款条件的到期日计算日期（订单日期/出库日期/应收单业务日期）、账龄分析表、到期债权表等功能有实际使用场景。
