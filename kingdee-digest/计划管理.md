# 计划管理（MRP/MPS）摘要 — G1a
> 范围：生产制造_计划管理.md 100页（含孤立32），正文215,730字；其中约10页非本域误归（会员流失/消费预测表、例外信息查询(信用)、要货计划、门店自采/要货、订单表头-收款计划页签、基础资料执行计划）。重复页：物料供需状态汇总/详细、缺料分析单/子项明细、运算数据分析、物料替代查询。电子元器件相关度：**高**。

## 1. 功能点
- 计划方式：集中计划/协同计划；分层计划、重复生产计划、ROP计划；MPS 与 MRP 两级。【来源:计划方案】
- 计划模式：MTS(10/11/12/13/14)、部件预测(20/21)、ATO/MTO(30/31/32/33)；MTO物料自动启用计划跟踪号，库存按跟踪号隔离；MTO件子项可为MTO/MTS，MTS件子项只能MTS。【来源:计划模式】【来源:计划管理】
- 选单计划(LRP)与全局计划：LRP 需求来源 销售订单/预测单/MPS计划订单/组织间需求单。【来源:选单计划与全局计划】
- 需求优先级：按优先级而非时间占用供给；优先级计算参数(客户优先级、时间紧迫系数、数量负荷系数、权重)。【来源:计划管理】【来源:优先级计算参数】
- 物料预留网络：强预留(专用料不可他用)/弱预留(可被抢占)；来源 计划运算、单据转换、手工、预留单；关闭或出库自动释放；预留数据检查与修复。【来源:预留】【来源:预留单】
- 预测：预测单/预测单变更单、均化、拆分(复制式/分摊式)、预测冲销(向前/向后/先前后后/先后后前)、多组织预测冲销、ATO物料冲销。【来源:预测单】【来源:预测冲销】
- 计划运算：计划运算向导(MRP/MPS、计划区检查、优先级计算、低位码运算、直接/调度运算)、批量计划运算向导；入口：全重排/选单/插单。【来源:计划运算向导】
- 计划订单：需求确认、供应确认、投放（生产订单/采购申请/委外订单/组织间受托/生产线）、合并、拆分、展开/还原、批量维护、清理。【来源:计划订单】
- 主计划(MPS)：主计划方案(排产顺序、排产规则、产能分配策略、排产连续性)、编制向导、主计划核准(能力中心负荷)、能力中心(日产量、最小排产批量、产能变动)。【来源:主计划方案】【来源:能力中心】
- 生管平台：齐套状况、材料明细(未领A−预留库存B−预留预计入C=待分配D)、缺料明细/汇总、预留、行拆分、确认调整替代、追料。【来源:生管平台】
- 缺料分析单 + 追料报告：先库存后预计入逐单分配，审核后下推采购申请单。【来源:缺料分析】【来源:追料报告】
- 例外处理：例外信息调整、订单级联调整、MTO库存调整/释放。【来源:例外信息调整】【来源:订单级联调整】
- 计划员工作台/计划员主页（待办、风险、预警：交货/生产/采购拖期、缺料）。【来源:计划员工作台】【来源:计划员主页】

## 3. 状态流转
- 计划订单：计划 → 需求确认 → 供应确认 → 关闭（手工关闭/投放关闭/合并关闭/拆分关闭）；可反需求确认/反供应确认/反关闭。【来源:计划订单】
- 预测单：关闭状态；可被预测冲销、下推销售订单。【来源:预测单】
- 单据状态通用：暂存/创建/审核中/已审核/重新审核。

## 4. 下推/反写
- 计划订单投放 → 生产订单 / 采购申请单 / 委外订单 / 组织间需求 / 生产线计划，按投放类型；投放后计划订单"投放关闭"。【来源:计划订单】
- 预测单 → 销售订单（反写执行数量）；预测冲销用销售订单冲减预测。【来源:预测单】【来源:预测冲销】
- 缺料分析单审核 → 下推采购申请单，生成追料报告。【来源:缺料分析】
- 例外信息调整：对计划订单/采购申请直接调整；采购/生产/委外订单生成变更单（参数：例外调整生成变更单状态）。【来源:例外信息调整】【来源:计划管理参数】
- 主计划核准保存 → 生成计划订单及预留。【来源:主计划核准】

## 5. 关键参数/公式
- 净需求 = 毛需求×(1+损耗率) − 现有库存 + 安全库存 − 预计入库 + 已分配；计划订单量 = 净需求/成品率。【来源:计划方案】【来源:制造策略】
- 运算参数：替代物料、供给优先顺序(按单据优先/按日期优先)、提前/延后宽限期、精确选单计算、预留释放方式。【来源:计划方案】
- 其他参数：自动关闭拖期预测单、低位码、只生成采购件计划、运算前自动预测冲销、MTO考虑空计划跟踪号库存、考虑保质期、不检查BOM完整性。【来源:计划方案】
- 计划管理参数：启用预留、计划运算是否保留预留关系、启用动态需求优先级、安全库存需求优先级、BOM版本未审核时终止。【来源:计划管理参数】
- 例外代码：6过去的开始日期、7过去的结束日期、8建议推迟交货日期、10部分提前、11整单提前、15整单延后、16部分延后、20整单取消、21部分取消、25超出最高存量、50不存在BOM、96低于安全库存。【来源:mrp例外信息查询表】

### 9.1 计划订单
- **单据类型**：MPS 物料默认为 MPS 计划订单，MRP 物料默认为 MRP 计划订单。
- **单据编号**：不可重复，保存后不可修改。【来源:计划订单】【来源:计划订单批量维护】
- **投放类型**：
  - 生产订单类：投放生成标准生产订单。
  - 采购申请类。
  - 委外订单类。
  - 组织间受托类。
  - 生产线类：只能作为生产线的需求来源，不可投放。
- **物料**：生产订单类要求供应组织允许生产，采购类要求允许采购，委外类要求允许委外。
- **BOM编号**：投放类型为生产或委外时必录。BOM 用途要匹配：生产用自制或通用，委外用委外或通用。
- **辅助属性**：影响计划时必录。
- **需求组织**：默认为当前组织。
- **建议字段**（建议采购/生产日期、建议到货/完工日期、建议订单量）：
  - 需求确认后不可修改。
  - 日期必须落在供应组织的工作日历内。
  - 建议到货/完工日期 = 建议采购/生产日期 + 固定提前期 + 建议订单量 ÷ 变动提前期批量 × 变动提前期。
  - 订单量必须大于 0。
- **确认字段**（确认采购/生产日期、确认到货/完工日期、确认订单量）：供应确认后不可修改，订单量必须大于 0。
- **货主**：
  - 货主类型：生产订单类、采购申请类锁定为业务组织。
  - 货主锁定为供应组织。
- **计划跟踪号**：只有制造策略的计划模式为 MTO 或 IHT 时才可维护。
- **按投放类型才可维护的字段**：
  - 供应商：采购申请类只能选供应类别不为委外的供应商，委外类只能选供应类别为委外的。
  - 采购申请部门：仅采购申请类可维护。
  - 生产车间、计划员：仅生产订单类或委外类可维护。
- **计划BOM**：
  - 子项从 BOM 携带，不可修改；虚拟件自动取下层物料。
  - 手工新增的子项不能与主产品相同；只有通用件和返还件可以互换；新增行的用量类型只能选固定或变动。
  - 使用比例：无替代时 100%；非组合替代时主料加替代料合计 100%；组合替代时关键料合计 100%。
  - 阶梯用量：按表头数量匹配阶梯行，匹配不到取子项明细的分子分母。
  - 需求日期 = 确认开工日期 + 偏置提前期；如果晚于确认完工日期，取确认完工日期；必须落在车间日历内。
  - 返还件的标准用量为 0。
  - 应发数量：是否发损耗为"是"时取计划投料数量，否则取标准用量。
  - 发料组织锁定为生产组织。
  - 倒冲时机：BOM 上为空时取物料上的值。
  【来源:计划订单】

### 9.2 预测单
- **单据编号**：不可重复。
- **供应组织**：不允许维护。
- **BOM版本**：影响计划时必录。
- **日期**：预测开始日期必须大于系统日期；结束日期不能早于开始日期。
- **需求优先级**：取值 1–99，预留类型为强预留或弱预留时才可维护。
- **计划跟踪号**：只有 MTO 或 IHT 时才可维护。
- **关闭状态**（**新增状态机**）：
  - 默认为未关闭。
  - 用户点关闭按钮：手工关闭。
  - MRP 运算中关闭：自动关闭。
  - 下推销售订单后执行数量大于预测数量：下推关闭。
  - **只有手工关闭的预测单可以反关闭。**
  【来源:预测单】
- **预测单变更单**：
  - 变更类型分新增和变更两种。
  - 新增行的默认值：开始日期为当前日期；单位为生产单位；库存组织、货主为预测组织；货主类型为业务组织；预留类型取物料上的值；需求优先级和计划跟踪号为空。【来源:预测单变更单】

### 9.3 计划方案：需求和供给的取数口径（原文逐条）
- **需求**：
  - 计划BOM：非暂存，业务状态为需求确认或供应确认，子项非返还件。
  - 生产用料清单：对应生产订单为计划确认、下达、开工或完工且未作废；需求 = 需求数量 − 已领 + 良品退料 + 来料不良。
  - 委外用料清单：对应委外订单为计划确认、下达或完工。
  - 生产/委外补料单：取非暂存、未审核、未作废单据的申请数量。
  - 退料单：取来料不良。
  - 其他出库单、分步式调出、出库申请、调拨申请、委外超耗单也作为需求，原文没有逐条写取数条件。
  - 其他入库、分步式调入作为供给。
  【来源:计划方案】
- **供给**（主计划方案）：
  - 生产订单：计划确认、下达或开工的订单；供给 = 数量 − 合格品入库 − 不合格品入库 − 报废品入库。
  - 委外订单：供给 = 数量 − 采购选单数量。
  - 采购申请单：取剩余数量。
  - 采购订单：取剩余入库数量。
  【来源:主计划方案】
- **重复生产计划：原文写明"不支持"。**【来源:计划方案】
- **需求时界和计划时界**：
  - 需求时界之前：只取销售订单。
  - 需求时界到计划时界之间：取销售订单和预测单中较大的一方。
  - 计划时界之后：只取预测单。
- **供给优先顺序**：按单据优先时，顺序为生产订单 > 委外订单 > 采购订单 > 采购申请 > 计划订单 > 其他入库 > 调拨入库。
- **预留释放方式**（原文建议）：全重排用"全部释放"；净改变用"只释放弱预留"；选单运算和紧急插单用"不释放"。
- **投放参数**：运算完成直接投放；投放时间范围 X 天；默认生产单据类型；采购申请单投放后的状态可选创建或审核；采购申请单最大分录数。

### 9.4 制造策略、参数和其他公式
- **制造策略**：
  - 编码不能重复；名称必录。
  - "考虑安全库存"必须先选"考虑现有库存"。
  - IHT 模式：上级物料按 MTO 号运算时，本物料也按 MTO 号运算。【来源:制造策略】
- **计划管理参数**：
  - 安全库存需求优先级默认为**最高**。
  - 不勾选"库存供应日期记录系统日期"时，库存供应日期默认为 1993 年。
  - 例外信息调整生成的变更单状态可选"审核"或"保存"（保存即创建状态）。
  - 无有效 BOM 时的控制：严格控制、警告、不控制三档。【来源:计划管理参数】
- **能力中心**：
  - 日产量 = 人/机数量 × 计划工时 ÷ 单件工时；可以手工修改，修改后不反算其他字段。
  - 一个车间只能对应一个能力中心；物料只能选 MPS 物料。【来源:能力中心】
- **期末可用量** = 期初可用库存 + 预计入可用量 − 安全库存 − 总需求 + 计划订单 + 组织间需求单。【来源:mrp周期计划】
- **追料报告**：
  - 追料日期 = 需求日期 − 1 − 物料的检验提前期。
  - 追料数量 = min(缺料数量, 剩余入库数量 − 已收料未入库数量)。【来源:追料报告】
- **生管平台**：
  - 缺料 = 应发 − 已领 − 预留库存 − 预留预计入 − 分配库存 − 分配预计入。
  - 齐套优先级：数字越大优先级越高。【来源:生管平台】
- **预留单**：
  - 系统日期超过"预留至"日期时，自动释放预留。
  - 预留数量不能大于可供应数量。
  - 需求组织必须具有库存职能。【来源:预留单】
- **订单供需状态**：平衡（需求 = 供应）、不足（需求 > 供应）、异常（需求 < 供应）。【来源:订单供需状态】
