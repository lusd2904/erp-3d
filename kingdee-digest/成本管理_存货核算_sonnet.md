# 成本管理／存货核算

## 1. 功能点

**业务初始化**
启用存货核算系统、初始核算数据录入、存货核算初始化／结束初始化／反初始化、启用分步式调出未调入、启用即时成本核算、启用成本库。

**入库核算**
采购入库核算（含自动钩稽核算、采购费用分配、钩稽日志查询）、入库成本维护、入库成本维护（多单据）、委外入库核算。

**出库核算**
出库成本核算（支持加权平均法、移动平均法、先进先出法、个别计价法）、出库成本维护、零成本批量维护、定时核算。

**采购费用**
采购费用分配、跨组织交易费用分配、钩稽日志查询、入库勾稽明细表、入库勾稽汇总表。

**其他核算**
其他存货核算（库存状态转换、形态转换、批号调整、组装拆卸）、合同履约成本分配（含反分配）、套件子项权重维护。

**成本调整**
成本调整单（采购入库调整单、出库成本调整单两种子类型）、期初库存维度余额调整、期末库存维度余额调整。

**即时成本**
即时成本重算、即时成本重算报告、即时成本对比分析表、即时收发明细表、即时收发汇总表。

**存货跌价准备**
按库龄计提、按可变现净值计提；相关页面：存货跌价准备计提规则设置、存货跌价准备计提单、存货跌价准备计算。

**期末处理**
存货核算期末关账／反关账、存货核算期末结账／反结账、存货核算结账向导、存货智能结账。

**成本监控**
目标成本计算、物料目标成本列表、成本预警设置。

**基础设置**
核算组织、核算范围设置、物料计价方法／物料计价方法变更、费用项目、退料残值率设置。

**综合工具**
成本工作台、成本性能、业务云巡检服务配置／业务云巡检报告。

**报表**
存货核算汇总报告、存货核算明细报告、存货收发存汇总表、存货收发存明细表、存货业务分类汇总表、存货异动汇总表、异常余额汇总表、合法性检查报告、先进先出法计价明细账、核算单据查询、核算单据成本对比分析表、生产发料明细表、委外发料明细表、采购明细表、销售明细表、杂项出入库明细表、分步式调出未调入明细表、物料成本库、成本价趋势分析表、物料加权价对比分析表。

## 2. 单据与关键字段

**核算范围**
关键字段：核算体系、核算组织、会计政策、计价方法、核算范围划分依据（货主、库存组织、仓库、货主+库存组织、货主+仓库）。

**物料计价方法**
关键字段：核算范围、设置依据（单个物料、存货类别、物料属性）、计价方法（移动平均法、加权平均法、先进先出法）。

**费用项目**
关键字段：编号、名称、存货核算类别（材料类、采购类、委外类、组装类、拆卸类、生产类、其他类）、是否默认。

**成本调整单**
关键字段：单据类型、调整原因、币别、业务类型、调整金额、调整金额（原币）、原币币别、价格差异、汇率差异。

**期初库存维度余额调整**
关键字段：期初数量、库存维度期初单价、库存维度期初金额、核算维度期初单价、按核算维度期初单价重算期末余额、金额差异；调整单字段：调整单类型、调整单调整原因、调整单来源类型、是否需要生成凭证。

**期末库存维度余额调整**
关键字段：期末数量、库存维度期末单价、库存维度期末金额、核算维度期末单价、按核算维度期末单价重算期末余额、金额差异；调整单字段同上。

**存货跌价准备计提规则**
关键字段：编码、名称、数据状态、核算体系、核算组织、会计政策、计提维度、库龄划分、可变现净值来源。

**入库勾稽明细表**
关键字段：总成本、成本调整金额、已钩稽金额、未钩稽金额、已钩稽数量。

**入库勾稽汇总表**
关键字段：期初余额、本期收入、本期勾稽、期末结存。

**存货收发存汇总表**
关键字段：期初结存-数量/单价/金额；本期收入-数量/单价/金额；本期发出-数量/单价/金额；期末结存-数量/单价/金额。

**合同履约成本分配**（涉及多单据）
应付单字段：立账类型、可分配金额；销售出库单字段：基本单位数量、总成本(本位币)；物料基本信息字段：毛重、净重、体积。

**各单据通用字段**
赠品、存货类别、成本价、总成本、计入成本、业务日期、创建日期、审核日期。

**存货核算汇总报告**
核算状态取值：核算成功、警告、核算失败、核算异常、未核算。

## 3. 状态流转、下推和反写

**初始化**
- 结束初始化前检查：存货核算系统已启用；核算范围覆盖所有货主组织及仓库；初始核算数据库存数量与取数来源一致。
- 取数来源规则：所有库存组织启用日期属于启用会计年度及会计期间 → 初始库存列表；否则 → 库存余额表。
- 结束初始化后只读，修改须先反初始化；非启用会计期间不允许反初始化。
- 初始核算数据录入反写库存：仅在取数来源为初始库存列表且在"默认核算体系+核算组织+默认会计政策"下可执行。

**采购入库核算链路**
- 入库单（退料单）审核 → 下推生成应付单 → 应付单确定入库成本 → 反写入库单总成本。
- 自动钩稽核算仅针对"法人核算体系+核算组织+默认会计政策"；多体系多政策须在各体系政策下分别执行。
- 应付单与发票核销有差异：启用"计入存货成本"时计入存货成本，否则计入总账采购成本差异；差额补差生成应付调整单，据此调整入库成本。
- 补差规则：
  - 入库单日期属于当期且未生成凭证 → 直接更新入库成本。
  - 入库单日期属于当期且已生成凭证，或日期属于以前期间 → 生成采购入库调整单。
  - 入库单下推应付单后已生成凭证，应付单反审核修改金额再重新审核 → 不更新入库单成本，直接补差生成入库成本调整单。
- 入库单支持多次下推应付单。

**入库成本维护**
- 在"法人核算体系+核算组织+默认会计政策"下保存后，才反写对应库存单据。
- 启用产品成本核算模块后，生产入库成本由成本计算结果自动反写，此界面不允许修改。
- 不能维护已与应付单钩稽的采购入库单、采购退料单、物权转移单以及已生成凭证的单据。

**委外入库核算**
- 未与应付单钩稽时才允许手工维护；保存后才反写对应库存单据。
- 材料成本仅在未启用产品成本核算模块时可手工维护或外部引入。
- 加工费由应付单与委外入库单（退料单）钩稽核算所得。

**出库成本核算**
- 核算单据已生成业务凭证时，根据差额自动生成出库成本调整单；每次核算将上次产生的出库成本调整单删除后重新生成。
- 参数"遇到成本核算错误时停止核算当前物料"：勾选后遇前端计算异常终止，产生"未核算"状态。
- 合法性检查项：是否存在未审核库存单据；入库序列单据单价是否为0。
- 合法性检查结果为"错误"、"异常"、"不通过"时，须处理后重新成本计算。

**成本调整单生效规则**
- 手工新增须审核才生效。
- 采购入库调整单及有关联源单（源单为以前期间库存单据）的出库成本调整单 → 调整当期期初余额。
- 无源单的出库成本调整单 → 调整当期发生额。
- 业务类型为异常余额调整的出库成本调整单 → 调整当期期末余额。
- 异常余额汇总表出单生成的出库成本调整单，不允许在成本调整单列表修改删除，只能在异常余额汇总表反出单处理。

**退料下推关系**
- 销售出库单 → 退货通知单 → 销售退货单（通过退货通知单获取销售出库单成本，参数控制）。
- 生产领料单 → 生产退料请检单 → 生产退料单（取源单成本，参数控制）。
- 委外领料单 → 委外退料请检单 → 委外退料单（取源单成本，参数控制）。

**物料计价方法变更**
- 对应物料存在期初或期末存货余额时不允许直接修改，须通过物料计价方法变更处理。
- 变更后须在变更的当前会计期间重新进行出库成本核算。

**期末关账**
- 检查：关账日期大于等于库存启用日期且大于上一次关账日期；关账日之后至本次关账日无未审核未作废库存单据；存货核算关账日期不能早于库存组织关账日期；关账日期以内的物料盘点作业无创建、审核中的单据。

**期末结账**
- 前提：当期已关账且关账后已进行出库成本核算或成本计算。
- 结账前检查：当前会计期间已关账；核算单据单价不≦0；无负库存；所有核算单据已参与存货核算；结账时点汇总金额等于明细金额。
- 反结账将核算期间返回上一期；反结账后若重新进行存货核算，需重新计提存货跌价准备。

**期末库存维度余额调整操作顺序**
存货核算期末关账 → 核算 → 期末库存维度余额调整 → 存货核算期末结账 → 生成凭证；出单后若进行核算将自动删除调整单；若调整单已生成凭证则核算中断。

**定时核算**
当设定计划为第3期成本计算，用户在第3期结账后，定时核算服务自动识别进行第4期成本计算。

**基础资料审核要求**
核算范围、物料计价方法、费用项目均需审核才生效；费用项目默认项不支持批量审核。

## 4. 与生产、供应链的接口

**核算维度**
- 总核算维度：核算体系 + 核算组织 + 会计政策。
- 反写／自动钩稽核算限定：法人核算体系 + 核算组织 + 默认会计政策。
- 物料成本库：仅支持核算组织的默认体系默认会计政策。

**货主归属规则（成本对象归集）**
- 领料单：按单据上的货主归集。
- 入库单、退料单、销售出库单、销售退库单：按结算组织确定货主。

**采购／应付接口**
- 采购入库核算前提：入库单（退料单）必须已与应付单钩稽。
- 费用应付单分录行勾选"计入成本"后，入库单据审核时自动按入库数量或金额分配采购费用；前提：该入库单下推的应付单已审核。
- 组织间交易产生的分步式调入单没有成本时，需检查并创建审核应付结算清单后重新采购入库核算。
- 跨组织交易费用分配支持单据：采购入库单、采购退料单、分步式调入单、分步式调出单（退货）。
- 跨组织交易费用分配标准字段：数量、金额、毛重、净重、体积、自定义分配权重。

**生产接口**
- 生产发料明细表取数来源：生产领料单、生产补料单、生产退料单、简单生产领料单、简单生产退料单、生产线领料单、生产线退料单。
- 车间投入产出数据来自工序汇报单或工序计划单（工序委外、工序协同无工序汇报单时用工序计划单）。
- 副产品投入材料成本计算依据：投入产量或完工产量。
- 主联产品来源：订单（制造）/ 产品组（成本）；来源为订单（制造）时分配权重取自生产订单。
- 组装业务：组装成品成本 = 子件成本 + 组装费用。
- 拆卸业务：拆卸成品成本 + 拆卸费 = 拆卸子件成本。
- 简单生产无期末在产不结转：期末在产品数量、金额均为0时不结转下期，下期有入库时重新计算累计完工值。
- 启用产品成本核算模块后，生产入库成本由成本计算结果自动反写入库成本维护界面。

**委外接口**
- 委外发料明细表取数来源：委外领料单、委外补料单、委外退料单（对应其他出库单与其他入库单）；查询前提是已进行出库成本核算。
- 委外入库成本：加工费由应付单钩稽核算所得；材料成本由产品成本核算计算得出。

**出库／销售接口**
- 采购明细表查询范围：采购入库单、采购退料单、分步式调入、分步式调出（退货）、物权转移单。
- 销售明细表查询范围：销售出库单、销售退货单、分步式调出、分步式调入（退货）。
- 可变现净值来源之一：最新销售出库单销售单价 × （1-费率），取计提当期最新销售出库单的含税单价。

**成本暂估场景**
- 入库单／退料单未下推应付单但有维护金额或从采购订单携带的金额。
- 其他入库单、盘盈单有维护成本，根据业务单据上的金额或成本写入存货核算入库成本数据表。

**组织间交易**
- 同一核算组织内：存货价值按出库成本价结转，不需结算。
- 不同核算组织间：按协商的交易价格结算；组织间交易单据可在组织间结算模块检查是否生成。

**退料残值率**
出库成本核算时按单据类型优先取物料明细残值率，无则取综合残值率。

**往来与开票**
核算单据生成会计凭证供总账处理；详细展开内容原文未见。

**费用归集**
费用项目分七类（材料类、采购类、委外类、组装类、拆卸类、生产类、其他类），采购费用分配支持按入库数量或金额分配；具体分配公式或权重规则原文未见。

## 5. 与电子元器件制造的相关度

**判断：高**

理由：
1. 电子元器件制造涉及大量采购物料（原材料、元件），采购入库核算、应付钩稽、采购费用分配是核心日常业务，本模块对此有完整链路支撑。
2. 电子元器件生产多有委外加工（如封装、测试），委外入库核算、委外领退料单与应付单钩稽的设计与该场景高度匹配。
3. 电子元器件品种多、批次管理要求高，先进先出法、个别计价法、批号调整单等功能均有直接用途；存货跌价准备（按库龄计提）对元器件库存管理同样适用。
4. 组装拆卸业务（半成品拆解、套件）以及多级核算维度（核算体系+核算组织+会计政策）符合该类企业多工厂、多组织的核算结构需求。

**需排除的低相关功能**
食品成本核算系列（食品成本卡、食品成本明细报告、口味及要求成本卡，功能路径含【门店经营】字样）：与电子元器件制造无关，自研ERP可不实现。

**生产／供应链单据为对接本模块需预留的字段或接口（仅有笔记依据的）**

| 单据 | 需预留字段／接口 | 依据 |
|------|----------------|------|
