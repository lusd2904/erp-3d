# 员工服务／人人资产

## 1. 功能点

本模块以员工为操作主体，围绕固定资产的日常自助管理提供以下能力：

**工作台入口**
- 人人资产工作台：卡片式展示员工个人资产，聚合"我的在办"（申领中、退转中、处置中、盘点中四类未完成单据数量）和"我的资产"（个人资产卡片，支持快捷新增领用、转移、退库、处置单）。

**员工自助操作**
- 资产领用：员工发起领用申请，审核后更新资产卡片保管人。
- 资产转移／退库：一单两用（单据类型区分），员工在工作台或我的资产列表中发起，审核后分别更新或清空保管人。
- 处置申请：员工提交处置申请，审核后下推资产处置单，完成实际处置。
- 个人自盘：员工对名下资产提交自盘数据，与固定资产盘点表联动。

**查询入口**
- 我的资产列表：查询当前用户关联员工的资产明细，支持新增资产退转单、处置申请单。

## 3. 状态流转、下推和反写

### 个人自盘状态
流转路径：**未提交 → 已提交 → 已确认**
- 提交后更新为已提交，已提交数据不允许修改和反提交。
- 确认后更新为已确认，不允许反确认。
- 个人自盘表与资产盘点表联动：固定资产-资产盘点表单据状态同步更新个人自盘表单据状态；个人自盘状态不影响资产盘点表的提交和审核。

### 人人资产领用单
操作链路：保存 → 提交审核 → 重新审核
- 审核后：系统根据"申请人"更新资产卡片保管人。
- 反审核后：领用单可修改和删除。
- 锁定规则：单据状态为保存、提交审核或重新审核时，资产编码被锁定，其他领用单无法领用该资产编码。
- 保管人变更限制：仅全部领用（可领用数量=0）或全部未领用的资产编码允许变更保管人。

### 人人资产退转单
操作链路：新增 → 保存 → 提交 → 审核 → 反审核
- 审核行为：
  - 单据类型为"人人资产转移"时，根据"接收人"更新"保管人"
  - 单据类型为"人人资产退库"时，清空"保管人"
- 反审核后：退转单可以修改和删除。
- 参数控制：受固定资产参数"资产领用部门，领用人与卡片使用部门，使用人不一致时，同步更新卡片信息"控制。
- 默认值参数：单据类型为"人人资产退库单"时，接收部门、接收人、接收后资产位置均可在人人资产参数中设置默认值。

### 处置申请单
- 审核后：资产卡片实物信息页签资产状态更新为**处置中**；反审核则回退为**使用中**。
- 若已下推资产处置单，则不允许反审核。
- 下推关系：处置申请单下推资产处置单，资产处置单审核后将处置状态修改为**已处置**。
- 反写：处置申请单审核后，"已关联处理数量"由资产处置单实际处置数量反写。
- 处置状态默认值：处置中；下推资产处置单并审核后修改为已处置。

### 个人资产状态
枚举值：使用中、转移中、退库中、处置中
- 使用中才允许发起转移、退库、处置操作；处于转移中／退库中／处置中时不允许重复操作。

## 5. 与电子元器件制造的相关度

**判断：中**

理由：

1. **设备与工装适配（支持）** 电子元器件制造企业通常持有较多固定资产性质的生产设备、检验仪器和工装夹具；本模块的员工自助领用、退库、转移、盘点能力可覆盖此类资产的日常流转管理，有实际应用场景。

2. **非生产核心流程（限制）** 本模块处理的是固定资产的人员保管关系变更，不涉及物料的出入库、BOM、生产工单、成本核算等制造核心业务，与电子元器件生产主线无直接数据交换。

3. **人员规模依赖（条件）** 模块价值随员工人数和人均持有资产量正相关。规模较小的制造企业若资产卡片数量有限，实际收益有限；规模较大或资产分散管理的企业收益更明显。

4. **与供应链无接口（限制）** 原文中未见本模块与采购入库、领料出库、生产工单等供应链单据的直接接口，自研 ERP 若需打通固定资产与生产成本归集，需自行设计集成层。
