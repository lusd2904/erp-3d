# 生产管理 摘要（G1a）

- 范围：生产制造_生产管理.md 共 54 页（含孤立页 12 页），正文 210,573 字；去重后 50 页（成套领/退/补料、生产发料通知单与同名页内容相同）。
- 与电子元器件制造的相关度：**高**。SMT 贴片、插件、测试、编带都要走生产订单→用料清单→领退补料→汇报→入库这条主线。

## 1. 功能点
- **生产订单全过程管理**：支持普通生产、返工生产、受托加工，以及联副产品、无 BOM、产品配置、批号/辅助属性、下级订单。用单据类型对业务做差异化管控。【来源:生产订单】
- **生产用料清单**：生产订单保存时，按 BOM 自动生成。它是领料、发料的依据，作为已分配量参与 MPS/MRP，也是直接材料成本的取数来源。【来源:生产用料清单】
- **领料、退料、补料**：
  - 生产领料单、生产退料单、生产补料单。
  - 成套领料、成套退料、成套补料。
  - 生产领料申请单，带拣货。
  - 生产发料通知，用于合并发料。
  - 倒冲领料，分后台和交互式两种。
  - 倒冲差异分摊。
  - 生产挪料。
  - 月末在制转移。
  【来源:生产管理】
- **汇报和入库**：生产汇报单、生产入库单、生产退库单、生产直送（V7.3 起）。【来源:生产管理】【来源:生产直送】
- **齐套和备料**：生产齐套分析（生产备料单，旧版）和齐套分析模板。【来源:生产齐套分析单】【来源:生产备料单】
- **订单拆分和变更**：
  - 生产订单拆分，可拆成生产订单或委外订单。
  - 生产订单变更单。
  - 生产用料清单变更单。
  【来源:生产订单拆分】【来源:生产订单变更单】
- **简单生产**：简单生产入库、领料、退料、退库四张单，V7.3 起从供应链移入生产制造。【来源:简单生产入库单】
- **生产订单执行机器人**：批量做倒冲、完工、结案。【来源:生产订单执行机器人】
- **基础资料**：班组（所属车间）、汇报类型（有效工时、无效工时、中性工时）。【来源:班组】【来源:汇报类型】

## 3. 状态流转
- **生产订单分录业务状态**：计划 → 计划确认 → 下达 → 开工 → 完工 → 结案（→ 结算）。另有挂起和反挂起。
  - 审核时，所有分录自动计划确认。
  - 可以用"执行"或"反执行"跳着改状态。
  - 下达后才能下推下游单据。
  - 反下达要求没有有效的领、退、补单据。
  - 反开工要求没有有效的汇报单和入库单。
  - 自动完工：主产品累计入库达到入库下限。
  - 结案要求没有非审核、非作废的下游单据。
  - 结算后不能反结案。
  【来源:生产订单】
- **领料申请单**：
  - 创建，提交后进入审核中（仓管员此时可以"拣货修改"），再到已审核，最后发料生成领料单。
  - 关闭状态有三种：未关闭、手工关闭、自动关闭（拣货未领数量≤0 时自动关闭）。
  【来源:生产领料申请单】
- **月末在制转移明细**：部分转移、全部转移。【来源:生产月末在制转移】

## 4. 上下游：下推与反写
- **生产订单下推**：生产领料单、补料单、退料单、汇报单、入库单、领料申请单、用料清单变更单。【来源:生产领料单】【来源:生产汇报单】
- **生产领料单**：
  - 保存时，反写用料清单的领料选单数量。
  - 审核时，反写已领数量。
  - 选单条件：应发数量 − 领料选单数量 + 良品退料数 + 来料不良退料数 > 0。
  - 返还件不能领。
  【来源:生产领料单】
- **生产退料单**：
  - 可以从用料清单（在制品数量 > 0）、领料单或补料单（实发数量 − 退料选单数 > 0）下推。
  - 审核时，反写三类退料数量。
  【来源:生产退料单】
- **生产补料单**：
  - 可以从订单或退料单下推（退料类型为作业不良，且实退数量 − 补料选单数 > 0）。
  - 审核时，反写补领数量和报废数量。
  【来源:生产补料单】
- **生产汇报单**：
  - 保存时，反写订单的汇报选单数量。
  - 审核时，反写合格、不合格、返修、报废、返工数量。
  - 控制条件：入库上限 − 汇报选单数量 + 返修数量 > 0。
  【来源:生产汇报单】
- **生产入库单**：
  - 单据类型为"直接入库"时从生产订单选单；为"汇报入库"时从汇报单选单。
  - 保存时，反写入库选单数。
  - 审核时，反写四类入库数量，扣减在制品，触发自动完工和倒冲。
  【来源:生产入库单】
- **生产退库单**：只支持从生产入库单生成。【来源:生产退库单】
- **生产齐套分析单**：
  - 审核时，反写用料清单的使用比例和备料数量（整批替代时为 100% / 0%）。
  - 可以生成生产领料单和直接调拨单。
  【来源:生产齐套分析单】
- **生产订单变更单**：
  - 审核时，反写生产订单，并刷新用料清单的标准用量、需求数量、应发数量、需求日期。
  - 可以自动生成暂存状态的生产退料单。
  【来源:生产订单变更单】
- **用料清单变更单**：审核即执行变更，并重算已消耗数量和在制材料数量。【来源:生产用料清单变更单】
- **生产订单拆分**：按生成类型拆成生产订单或委外订单，同时生成新的用料清单。【来源:生产订单拆分】
- **生产直送**：一键生成入库单和领料单，自动匹配规则是"同需求来源"。【来源:生产直送】

## 5. 关键参数和选项
- **单据类型参数（生产订单）**：
  - 生产类型：标准生产、返工生产。
  - 组织间受托加工。
  - 序列号控制。
  - 启用生产用料清单变更。
  - 在制材料扣减：入库时扣减、汇报时扣减。
  - 自动执行：审核自动下达；下达时自动审核用料清单、工序计划、SMT上料表；下达自动开工；领料自动开工；自动完工；自动结案。
  - 生产发料通知。
  - 启用工序跟踪、按工序领料。
  - 默认倒冲时机：入库倒冲、汇报倒冲。
  - 倒冲方式：交互式倒冲、后台倒冲。
  - 汇报倒冲：按检验结果、按完成数量。
  - 汇报和入库的材料领用控制：控制强度分不控制、警告、严格控制；控制范围分全部物料、关键物料、非倒冲物料。
  - 结案控制。
  【来源:生产单据类型参数】
- **生产管理参数**：
  - 拆分、变更时的领料套数检查。
  - 生成下级订单时创建预留（强预留）。
  - 领料状态判断依据。
  - 领料单校验计划跟踪号。
  - 产品检验自动入库：检验完成、不良品处理、MRB评审。
  - 生产退料检验。
  - 默认库存状态。
  - 序列号控制。
  - 替代件消耗顺序：平行计算、按领料+替代优先级。
  - 执行计划：自动倒冲、自动完工、自动结案的组织和条件（订单数量、入库上限、入库下限）。
  【来源:生产管理参数】
- **超发控制方式**：允许超发、最小发料批量、不允许超发、按损耗率超发，每种都有对应的校验公式。【来源:生产领料单】
- **用量公式**：
  - 标准用量 = 生产订单数量 × 使用比例 × 分子 / 分母。
  - 需求数量有两种损耗公式：1 + 损耗率，或 1 / (1 − 损耗率)。
  - 应发数量取决于"是否发损耗"。
  - 在制材料数量 = 已领 + 补领 − 三类退料 − 报废 − 已消耗。
  【来源:生产用料清单】

## 6. 审批和工作流相关点
- 原文的单据状态都含"审核中"和"重新审核"，说明有提交审核流程。原文没有给出具体审批人链。【来源:生产订单样例】
- **领料申请单写明了两个角色**：车间领料员负责新增和提交；仓管员负责审核和拣货修改。可以给仓库配数据规则。【来源:生产领料申请单】
- 齐套分析单在提交前必须先分析；分析后又改过订单的，要重新分析。【来源:生产齐套分析单】
- 用料清单启用变更后，审核后不能反审核，只能通过变更单修改，必须留下变更原因。【来源:生产用料清单变更单】
- 生产订单变更单在单据状态"创建"时可以撤销提交。【来源:生产订单变更单】

## 8. 与电子元器件制造的相关度
- **高**：生产订单、用料清单、领退补、汇报、入库、齐套分析、超发控制、倒冲。SMT 物料多数可以按"直接倒冲 + 入库倒冲"处理。
- **高**：用料清单的"位置号"字段可以承接 SMT 贴片位号。原文中，下达时可以自动审核"SMT上料表"。【来源:生产单据类型参数】
- **中**：生产领料申请单（含拣货）、生产发料通知（合并发料）、挪料、月末在制转移、生产直送（SMT 到测试、编带等多段制程直接流转）。
- **低**：简单生产、执行机器人。

## 9. 字段说明逐字补读（第二轮：生产补料单之后的 24 页，其中 16 页有字段表，唯一行约 2 万字）

### 9.1 生产订单
- **单据类型**：新增时可以改，保存后不可改。
- **委托组织**：只有单据类型勾选了"组织间受托加工"才可维护。
- **物料编码**：只能选勾选了"允许生产"的物料；联副产品的物料由 BOM 携带。
- **生产车间**：**下达前必录**。
- **计划开工时间**：新增时默认为系统当前日期，必须落在车间日历的可生产日。
- **计划完工时间**：由系统根据开工日期和生产数量自动计算。
- **BOM版本**：
  - **默认带出用途为"自制+通用"的最新 BOM 版本。**
  - 只能选审核未禁用的标准 BOM。
  - BOM 版本影响计划时必录。
- **领料状态**（**新增四值规则**）：
  - 未领料：领料套数为 0 且没有关联领料单。
  - 部分领料：领料套数为 0 但已关联领料单，或 0 < 领料套数 < 生产数量。
  - 全部领料：领料套数 = 生产数量。
  - 超额领料：领料套数 > 生产数量。
- **入库上限/下限**：
  - 入库上限按物料的入库超收比例自动算出，可以改，但必须 ≥ 数量。
  - 入库下限按入库欠收比例自动算出，可以改，但必须 ≤ 数量。
- **入库货主**：默认为生产组织。
- **入库组织**：来源是销售订单时取销售订单的库存组织；手工新增时取生产组织。
- **成本权重**：主产品默认 100，联产品取 BOM 上的值，副产品固定为 0。
- **生成方式**：手工录入、MRP生成、MPS生成、拆分。
- **业务流程**：系统预设"生产直接入库流程"和"生产汇报入库流程"两种。【来源:生产订单】
- **原文笔误**：计划组、计划员两个字段的说明里写成了"委外申请单的委外组织"，判断是复制错误。

### 9.2 生产订单变更单
- 只能变更业务状态为**计划、计划确认、下达、开工**的订单。
- 变更类型为"变更"时，以下字段锁定：物料、订单编号、单位、BOM、工艺路线。
- 变更类型为"新增"时，计划开工和计划完工都默认为当前日期；审核后按 BOM 自动生成用料清单，并锁定 BOM 版本。【来源:生产订单变更单】

### 9.3 生产订单拆分
- 可拆分数量 = Min(生产数量 − 已汇报数量, 生产数量 − 已入库数量)。
- 订单拆分方式：一单一分录、一单多分录。
- 新订单状态：创建、审核、审核中。
- 继承原用料清单：勾选则复制原用料清单，不勾选则按 BOM 重新生成。【来源:生产订单拆分】

### 9.4 领料、退料、退库
- **单据日期的关账规则**（退料、退库、补料、入库单通用）：
  - 组织未关账：日期须 ≥ 库存启用日期。
  - 组织已关账：日期须 > MAX(组织最近关账日, 货主最近关账日)。
- **生产领料单**：申请数量由系统自动算出，可以改但不能大于下推数量；物料从上游携带，不可修改。
- **生产退料单**：实收数量不能超出用料清单的数量控制。
- **生产退库单**：应退、实退数量不能超出生产入库单的数量控制。
- **"仅过滤、不保存"的表头字段**：生产车间、仓管员。【来源:生产退料单】【来源:生产退库单】【来源:生产领料单】

### 9.5 生产领料申请单（逐字）
- **单据编号**：LLSQ + 8 位流水号。
- **默认值**：申请日期为当天；申请人为当前用户；申请组织和申请部门取自用料清单。
- **数量字段**：
  - 待申请总数 = 应发 − 领料选单数 + 良品退 + 来料不良退 − 申请中数量，结果小于 0 时取 0。
  - 本次申请数默认等于待申请总数；须满足超发控制方式；单据在"审核中"时仓管员不能修改。
  - 拣货数量默认为 0，可以通过"自动拣货"自动填充。
  - 已领数量：领料单**保存**时就反写。
  - 欠领数量 = 本次申请数 − 已领数量。
- **关闭状态**：
  - 所有明细的欠领数量都 ≤ 0 时，自动关闭。
  - 修改领料单后不再满足这个条件，自动回到未关闭。
  - 手工关闭的不会自动回到未关闭。【来源:生产领料申请单】

### 9.6 齐套分析和报表
- **生产齐套分析单**：
  - 目前只支持标准齐套分析单。
  - 调拨策略：补足车间库存、补齐调拨数量、按齐套数调拨。
  - 原文里"预计齐套数量"和"库存齐套数量"两个字段的说明写反了，以生管平台的定义为准：库存齐套按现有库存算，预计齐套按库存加预计量算。
- **报表公式**：
  - 领料比例 = 已领套数 ÷ 计划领料套数。
  - 领料差异数 = 应领 − 已领。
  - 倒冲差异数 = 应倒冲 − 已倒冲。
  - 实领 = 领料 + 补料 − 三类退料。
  - 完工数量 = 合格入库 + 不合格入库。
  - 合格率 = 合格入库 ÷ 完工数量。
- **生产订单执行机器人**：完工、结案条件可选"入库数量等于订单数量/入库上限/入库下限"。

### 9.7 补充：用料清单的取值规则（复核原文）
- **需求数量**：自动按单位精度**向上取整**。
- **倒冲时机**：
  - 发料方式为倒冲时必录。
  - 取值顺序：BOM → 物料 → 单据类型参数。
- **返还件**：发料方式强制为"不发料"。
- **子项类型的修改限制**：标准件、返还件不能改成替代件；替代件也不能改回来；标准件和返还件之间可以互换。
- **默认值**：
  - 货主默认为生产组织。
  - 发料组织取值顺序：BOM → 生产组织（须有库存职能）→ 跨组织领料关系中的默认目标组织。
  - 是否展开：虚拟件默认为是。
- **实领数量** = 已领 + 补领 − 三类退料 − 报废。【来源:生产用料清单】
