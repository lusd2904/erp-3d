# 财务会计／费用管理

## 1. 功能点

**初始化与期末**
- 录入启用系统前已借出未归还的费用类借款余额（历史借款余额），支持 Excel 引入和下推报销单
- 结束初始化后进入日常业务；支持反初始化
- 关账：指定结束日期，关账日期前的费用单据不允许新增，可提交、审核、反审核；支持任意日期关账
- 反关账；可配置反关账时校验总账账簿结账状态

**核销管理**
- 申请单→报销单下推自动核销；历史借款→报销单下推自动核销；实报实销
- 自动核销向导：对不存在关联关系的报销单与付款单通过向导完成核销
- 尾差核销：将存在尾差的单据直接核销并生成已审核状态的核销单
- 手工核销：手工匹配核销和手工特殊核销
- 反核销：取消已进行的核销；通过尾差核销产生的核销单在反核销时自动删除

**报表分析**
- 借款跟踪表：多维度展现借款的实际付款、报销、退款及冲销情况
- 借款到期预警分析：汇总表形式展示已到期未归还借款及过期天数、未到期借款及未过期天数
- 借款账龄分析表：对已到期未核销借款按时间段分布分析，支持自定义账龄区间
- 费用报销跟踪表：展现费用报销的实际付款、报销、退款及冲销情况
- 费用明细表：展示期间内各组织/部门/产品的明细费用，支持联查费用报销单
- 费用汇总表：展示期间内各组织/部门/产品所承担的费用汇总状况
- 报销与付款汇总分析表：展示员工对应费用项目报销金额与付款金额的比较

**跨系统集成**
- 与应付系统集成：报销单审核自动产生费用报销其他应付单
- 与出纳系统集成：下推费用报销付款申请单、费用报销付款单、费用报销付款退款单
- 与发票云集成：收票自动填报报销单费用明细
- 与总账关联：核销单生成总账凭证；反关账时可校验总账账簿结账状态

**差旅标准**
- 对不同报销级别和出差地域设置差旅标准（住宿补助标准）
- 对员工出差城市进行分级划分（出差地域）
- 对不同员工设置不同报销级别（员工报销级别设置）
- 差旅标准映射设置（原文仅一段说明加外部链接，无字段正文）

**智能填报管理**
- 发票类型映射：将发票云发票类型映射到报销单发票类型
- 发票与费用项目对应设置：根据发票类型、税收分类编码配置对应的费用项目/差旅费类型
- 发票合并生成明细规则：对不同发票类型设置合并规则

**参数与维护**
- 费用云巡检服务配置：设置检查项及执行时间；费用云巡检结果报告：显示检查结果

## 3. 状态流转、下推和反写

**下推链路**

```
费用申请单（审核）
  ├─→ 费用报销单（一对一或合并，由"费用申请一对一报销规则"/"费用申请合并报销规则"控制）
  └─→ 付款申请单（参数"借款/报销付款应用付款申请流程"勾选时）→ 付款单
       └─→ 付款单（参数未勾选时，直接下推）

出差申请单（审核）
  └─→ 差旅费报销单（一对一或合并，由"出差申请一对一差旅报销规则"/"出差申请合并差旅报销规则"控制）

费用报销单（审核）
  ├─→ 费用报销其他应付单（应付系统，自动产生）
  ├─→ 付款申请单 → 付款单（参数控制，同上）
  └─→ 进项费用增值税发票（参数控制，自动生成）

申请单（点击退款）→ 付款退款单

历史借款余额（审核）→ 下推差旅费用报销单或费用报销单（带相关信息并自动核销）
```

**同步时机（参数控制）**
- 其他应付单同步：勾选"提交"时生成提交状态；勾选"审核"时生成审核状态
- 付款申请单自动下推状态：可选"创建"或"提交"（提交时自动走到审批，为审核中状态）

**核销方案中定义的 6 种核销关系**
1. 报销单（正数）与付款单（费用报销类）（正数）
2. 报销单（负数）与退款单（费用报销类）
3. 历史借款余额与报销单（正数）
4. 历史借款余额与退款单（费用报销类）
5. 付款单（费用报销类）与退款单（费用报销类）
6. 报销单（正数）- 报销单（负数）

**核销单生成逻辑**
- 尾差核销 → 自动生成已审核状态核销单 → 生成总账凭证
- 参数"借款核销时自动产生核销单"勾选后：费用申请单/出差申请单借款时，下游付款单的"是否其他预付"置为"是"；该类付款单与其他应付单核销时自动产生核销单 → 生成凭证

**反写**
- 费用报销跟踪表使用前需完成核销；核销时反写报销单上相关字段（已付款、冲借款等）
- 历史借款余额上的已报销金额、已退款金额、冲销金额、借款余额由系统根据下游单据审核或核销状态自动填列；借款余额 = 历史借款余额 - 已报销 - 已退款 - 冲销金额

**关账控制**
- 关账后，关账日期前的费用单据不允许新增；下游单据业务日期规则：下游系统未结账取原单据申请日期，下游系统已结账取系统当期日期
- 参数可配置：申请单未审核不允许关账、报销单未审核不允许关账、转移单未审核不允许关账
- 参数"不允许反审核已关帐的单据"勾选时，已关账单据不允许反审核
- 费用报销系统启用后，应付系统的费用报销其他应付单、出纳系统的费用报销付款申请单/费用报销付款单/费用报销付款退款单均不允许手动新增，必须从费用报销系统发起

## 5. 与电子元器件制造的相关度

**判断：中**

理由：
1. 电子元器件制造企业存在研发、差旅、采购相关费用报销场景，本模块的差旅费报销单、费用报销单、借款管理可直接覆盖，相关度较高。
2. 本模块的费用归集维度包含"费用承担产品"，可在自研 ERP 中对应产品线或生产项目做费用分摊，对制造企业有实用价值。
3. 本模块与生产、供应链（生产领料、完工入库、存货核算、成本核算）无直接接口，制造企业核心的产品成本归集需依赖其他模块（如存货核算、产品成本），本模块仅覆盖间接费用/期间费用部分，不能独立支撑制造成本管理。
4. 核销、关账、凭证生成的完整链路对财务规范化有价值，但对制造执行层影响有限。

**生产/供应链单据为对接本模块需预留的字段或接口**（仅有笔记依据的）

- 生产订单/工单头部：预留**费用承担产品**字段，与费用汇总表、费用明细表、费用报销跟踪表、借款跟踪表的同名汇总维度对齐
- 生产/采购相关费用单据：发起路径须从费用报销系统发起（原文规定：系统启用后，应付/出纳相关单据类型不允许手动新增），自研 ERP 在供应链模块中需预留跳转或关联入口
- 下游凭证接口：核销单生成总账凭证的接口，自研 ERP 总账模块需预留对应凭证来源类型
