# 管理会计／预算管理

## 1. 功能点

- **三类预算体系**：费用预算、资金预算（费用支出付款、采购付款、其他付款）、自定义预算
- **预算编制**：普通预算报表、主维度预算报表、预算汇总表（周期性/非周期性）、实际数报表；支持H5在线编辑、Excel引出/引入、维度值填充、维度组合设置、公式取数
- **预算控制**：对除凭证外任意单据进行预算控制；通过【预算管理系统参数】总开关启用；按预算控制规则+预算控制台分配到预算组织生效；支持保存/提交/审核三个时点控制、多币别、多汇总方式（本期/按期累计/跨年累计/跨年汇总）；支持"预算数为空时通过"和"实际数仅来源于实际数报表"选项
- **预算调整与调剂**：预算调整单（实质原因偏差调整）、预算调剂单（总额不变的跨组织/跨期/跨维度调剂）、预算调整表（H5联动调整）
- **执行分析**：预算执行分析、维度汇总预算执行分析、预算执行交叉分析、预算执行明细表、预算数据查询、可用预算余额查询、费用预算执行排行（H5主页）
- **组织与周期管理**：预算组织架构（基于业务组织和部门）、预算日历（7种周期类型）、预算方案监控（执行/关闭状态切换）、执行状态自动切换、未来预算组织架构及启用切换
- **权限与流程集成**：预算数据授权（角色/用户对组织/维度/方案/模板权限）、流转条件方案（预算控制结果作为工作流流转条件）、预算API工具（第三方系统集成）
- **辅助功能**：预算控制提示语自定义、预算控制日志、预算控制检测（22个检测点+自动修复）、报表自动创建方案（定时创建实际数报表）

### 计算关系（原文逐字）
- 实际执行 = 【申请占用】-【申请冲回】+【预算执行】-【执行冲回】
- 调整后预算数 = 原始预算数+预算调整数
- 可用预算 = 【调整后预算数】-【实际执行】
- 预算执行进度% = （实际执行/调整后预算数）%
- 实际执行数（明细表）= 单据发生数 −（单据下推回写/冲销源单数）
- 关闭释放 = 已关闭的申请占用类单据的【申请占用】-【申请冲回】
- 当预算影响类型=【预算冲回】时，单据发生数 = −【单据字段值】

## 3. 状态流转、下推和反写

### 预算报表状态流转
- 新建 → 提交 → 审核；支持反提交、反审核
- 处于"执行中"/"已关闭"状态年期下的预算报表**不允许反审核**；需在【预算方案监控】中先对该预算组织该年期操作"反执行"/"反关闭"
- 处于"执行中"/"已关闭"状态的预算期间**不允许新增预算报表**（主维度预算表除外，允许随时新增）
- 参数选中"已分发预算表未完编，仍允许预算组织切换到执行中状态"时，处于"执行中"的预算期间可对已创建的预算表提交、审核，但禁止反向操作
- 分发下来的预算模板默认为"已审核"状态，用户可反审核后修改
- 非周期性/周期性预算汇总表提交后，可配置参数禁止取数来源预算表执行反审核

### 实际数报表状态流转
- 分发的实际数报表模板默认为**已审核**状态；用户可**反审核**后修改
- 实际数报表需经**提交、审核**，审核后数据可通过预算执行分析查询

### 预算模板状态流转
- 保存 → 提交 → 审核；操作入口为预算报表客户端【审阅】菜单或预算模板列表工具栏
- 已分发的预算模板仍可反审核

### 预算期间状态流转
- 【预算方案监控】支持"执行"/"反执行"/"关闭"/"反关闭"状态切换
- 执行前提：某预算期间下，该预算组织所有需要编制的预算表处于已审核状态，才能置为【执行中】
- 关闭前提：预算组织须处于【执行中】状态，才可切换为【关闭】
- 只有预算期间处于"执行中"状态，对应受控单据才可成功提交
- 预算期间需处于"执行中"状态，预算调剂单/预算调整单方可操作
- 删除已使用的预算组织前，系统强制要求将所有正在执行中的预算期间先执行「关闭」操作

### 下推与反写
- 预算调整表审核后自动生成预算调整单
- 预算控制规则配置【单据下推回写/冲销源单字段】，在预算执行明细表中显示下推回写/冲销源单数
- 预算执行分析支持联查预算执行明细表，进而联查业务单据
- 原文未说明预算报表向业务单据的下推或业务单据向预算报表的反写

## 5. 与电子元器件制造的相关度

**（判断）相关度：中**

理由：
1. **费用预算与资金预算是电子制造企业核心需求**：原文支持费用预算、费用支出付款、采购付款预算，与电子元器件制造企业的原材料采购（晶圆、封装材料、芯片）、制造费用、研发费用预算管理需求匹配
2. **多维度预算控制符合精细化管理要求**：原文支持部门、项目、成本中心等多维度预算控制；电子制造企业典型需要按产品线、项目、工单进行预算管控，但原文未明确与生产工单、项目成本核算的直接接口
3. **实际数来源与业务单据脱节**：原文实际数报表主要取自总账凭证（ACCT），或手工录入，未说明如何从采购订单、生产领料单、完工入库单直接取实际发生数；电子制造企业需要业务单据实时反馈预算执行，需二开接口
4. **缺少成本核算接口说明**：原文未说明与产品成本核算、工单成本、BOM成本的关联；电子制造企业需要将预算数与标准成本、实际成本联动分析，需自研接口

**期生产/供应链单据需预留的字段或接口**（基于笔记依据）：
- **采购订单**：预留【预算组织】【预算维度值】（如部门、项目、成本中心）【预算影响类型】字段，用于预算控制规则取数；预留【申请占用】【预算执行】字段，用于回写预算执行数
