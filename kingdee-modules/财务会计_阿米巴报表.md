## 【页面】利润中心报表模板
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%A9%E6%B6%A6%E4%B8%AD%E5%BF%83%E6%8A%A5%E8%A1%A8%E6%A8%A1%E6%9D%BF

===== 利润中心报表模板 =====

**功能说明**

企业除了对组织有考核要求外，还需要考核到各组织下的利润中心（也即部门），每个利润中心在持续经营阶段都需要按期来汇报利润报表，也需要制订统一的利润中心报表模板。

统一的利润中心报表模板体现了总公司在财务管理报告中对其下属企业中的各利润中心的考核要求。

利润中心报表模板与普通的报表模板最大的区别在于，利润中心报表模板多了一个利润中心属性，在即在普通报表模板的基础上再细化考核到利润中心（实质为部门）。 

**功能路径**

【财务会计】－>【阿米巴报表】－>【利润中心报表管理】－>【利润中心报表模板】


**操作说明**

1、报表模板编制 

利润中心报表模板的制作流程同组织级的报表模板一增，详见[[报表模板管理|报表模板管理]]

2、报表模板管理 

**模板修改、提交、审核、反审核、禁用、反禁用**

利润中心报表模板的修改、提交、审核、反审核、禁用、反禁用控制同组织级的报表模板一样，详见[[报表模板管理|报表模板管理]]。

**模板共享**

编制并审核完毕的模板，可跨核算体系、跨组织、跨利润中心进行共享。

在报表模板列表界面选中需要共享的报表模板，单击工具栏中的【共享】，在弹出的“请选择共享利润中心”对话框中，选择目标核算体系-核算组织-利润中心。

共享给目标利润中心的报表模板为“在制”状态。

## 【页面】利润中心报表自动生成方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%A9%E6%B6%A6%E4%B8%AD%E5%BF%83%E6%8A%A5%E8%A1%A8%E8%87%AA%E5%8A%A8%E7%94%9F%E6%88%90%E6%96%B9%E6%A1%88

===== 利润中心报表自动生成方案 =====

**功能说明**

根据利润中心报表模板设置利润中心报表自动生成方案，系统自动生成利润中心报表。

**功能路径**

【财务会计】－>【阿米巴报表】－>【利润中心报表管理】－>【利润中心报表自动生成方案】

**操作说明**

新建方案后，需【启用】，方案才可定时执行。

新建方案后，点击【执行】，输入重算时间，可立即执行方案。

报表自动生成结果，详见【自动生成记录】。

**字段说明**

| 字段           || 说明                                                                                                          |
| 报表模板         || 选择报表模板，会自动带出核算体系、核算组织、取数账簿、币别、样式类型。\\ 其中，取数账簿默认显示为主账簿，可修改为副账簿                                               |
| 刷新核算维度       || 对于动态表，勾选，则会在生成报表时刷新核算维度。\\ 例如，核算维度为物料，本期有新增物料，如勾选，则生成报表时会增加新增物料的行及取数公式，不需要再修改报表模板。\\ 此勾选项对于维度值经常变动的用户比较适用。  |
| 核算维度         || 当样式类型为【动态样式】时，核算维度可以设置，可以设置报表中的维度在某个区域内刷新。                                                                  |
| 设置定时重算时间     || 设置执行方案的时间。                                                                                                  |

## 【页面】利润考核体系
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%A9%E6%B6%A6%E8%80%83%E6%A0%B8%E4%BD%93%E7%B3%BB

===== 利润考核体系 =====

**功能说明**

针对核算体系下的核算组织设置利润中心考核单元，这些利润中心考核单元可以设置上下级关系，只有最明细的利润中心才需设置对应的部门或成本中心（成本中心的业务对象实际是部门），非明细级利润中心的数据来源于属于其下级的最明细的利润中心。

也即利润考核体系目前细化考核到部门。

**操作说明**

打开【财务会计】－>【阿米巴报表】－>【利润中心】－>【利润考核体系】功能，新增利润考核体系。

**其他说明**

利润考核体系设置完成，在【业务操作】按钮组中提供了【指定下游利润中心】功能按钮，单击此功能按钮可以设置本考核体系下的利润中心的上下游关系。

利润考核体系设置完成，将可以按核算体系+核算组织+利润中心编制报表模板及报表。

核算组织在明细的利润中心上指定，则利润考核体系可以跨组织设置，支持设置多套利润考核体系，体系之间不判断部门的重复使用，体系之内部门不得重复使用。


**字段说明**

| 位置            || 字段         || 说明                                                                 |
| 单据头           || 编码         || 利润考核体系的编码，手工录入。                                                    |
|               || 名称         || 利润考核体系的名称，手工录入。                                                    |
|               || 核算体系       || F8选择会计核算体系基础资料，支持单选返回核算体系名称。                                       |
| 左边“利润中心”页     || 编码         || 利润中心的编码，编码需保持唯一                                                    |
|               || 名称         || 利润中心的编码，名称需保持唯一                                                    |
|               || 上级利润中心     || 没有设置部门或成本中心的利润中心可以成为上级利润中心。                                        |

====== 报表编制管理 ====== 

**功能说明**

**功能路径**

【财务会计】→【报表】→【报表管理】→【报表编制】

===== 报表制作 ===== 

用于管理和分析的报表都需要有完整的数据。根据模板建好的报表是没有数据的，这就需要完成报表的取数过程。

还是以报表模板管理中提到的利润表为例，简单介绍如何利用报表编辑器来完成报表的取数过程。

**设置取数参数**

在新建报表时我们已经设置了一些属性参数：取数账簿、币别、年度、期间。

我们也可以通过【公式取数参数】来指定参数。具体参见报表业务处理中的【公式取数参数】的操作说明。

公式中的参数在取数过程中的优先级：先单元格定义的参数，再公式取数参数中定义的参数，最后才是报表属性中的参数。

**设置报表取数公式**

用于编制报表的模板如果没有预设取数公式，那么我们还需要在编制报表时单独完成取数公式的设置。

如上述提到的利润表，该表中的数据一般情况下来自总账，所以我们可以通过总账取数公式ACCT进行取数。具体操作参见报表取数公式。

**报表重算**

系统提供了【重算表页】、【全部重算】功能用于报表数据的取数。只需单击操作，系统会根据定义好的取数公式以及公式参数进行取数。

===== 报表管理 ===== 

报表制作完成，可以对其进行查看、修改、删除、检查、审核、禁用、检查等操作。这些操作与报表模板中的类似，可参见报表模板管理。

其中报表检查，可参见报表业务处理中的报表检查功能说明。

工具栏菜单中【打开】－>【报表】

按照上述路径都可以进入报表列表。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%98%BF%E7%B1%B3%E5%B7%B4%E6%8A%A5%E8%A1%A8

====== 1 阿米巴概述 ======

===== 1.1 阿米巴概述 =====

目前很多企业在进行利润考核时不仅仅关注组织级的利润，还关注部门甚至个人为企业创造的利润。

也即管理大师稻盛和夫的阿米巴管理理念。

利润中心报表管理就是为了满足这种考核需求而增设的功能，但目前考核只细化至部门。

通过增加利润中心考核对象，并将所要考核的利润中心与成本中心匹配，通过定义利润中心报表模板，定期编制和出具各期利润中心报表，如部门利润表、收入明细表、成本明细表等。

各利润中心考核数据可以来源于业务系统的单据、基础资料、报表。


===== 1.2 总体流程图 =====

[图:amb_手册_总体结构图.png]
===== 1.3 系统特性=====

基于阿米巴经营模式的核心理念，支持阿米巴利润考核体系的构建以及阿米巴利润报表的出具；

支持从粗粒度核算组织（事业部）级到细粒度部门（成本中心）级的阿米巴利润表；满足企业逐步管理精细化的应用实际；

自定义取数平台，满足企业编制任意多管理角度财务、业务报表的需求；支持任意单据取数，核心业务报表取数。
