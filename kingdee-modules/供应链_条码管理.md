## 【页面】gs1条码解析规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=gs1%E6%9D%A1%E7%A0%81%E8%A7%A3%E6%9E%90%E8%A7%84%E5%88%99

====== 1功能说明 ======
1）支持金蝶AI星空标准的新增、删除、修改、查看、提交、审核、反审核功能，支持权限控制及记录操作日志；
2）控制规则内容单据体至少需存在一行记录；
3）控制同一单据中，规则内容单据体的条码属性值不允许重复；
4）支持在条码物料管理中批量分配。
====== 2操作说明 ======

1）点击GS1条码解析规则，打开GS1条码解析界面；
2）添加条码属性：物料编码必须为标准标识符(01)并且为必填项，不允许截取；
3）替代标识符：标准标识符未在条码中找到相应的标识符时，则使用替代标识符，同一物料的替代标识符不能与标准替代符一致，可以为条码规则里面的标准标识符，也可以为条码规则中不存在的标识符；
4）截取值：起始位必须小于终止位。标准与替代截取值一样。例如：(11)20122323,日期的截取为1-6，则取201223；
5）条码属性添加完毕，点击保存提交审核；
6）审核成功后规则编码自动填充。

5）栏位解析，将对应的值根据前缀长度，截取长度，后缀长度，进行解析

## 【页面】库位条码
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BA%93%E4%BD%8D%E6%9D%A1%E7%A0%81

====== 1功能说明 ======
通过选择对应的仓库，根据库位条码规则，将对应的库位条码生成到条码主档。

====== 2应用场景 ======
为了方便仓库中的上架、出库、调拨移位、盘点等作业，一般会将具体的仓库仓位形成条码再打印粘贴到对应的位置。现场人员通过扫描对应的库位条码实现仓库仓位的快速录入。
====== 3功能操作 ======
  - 条码规则：关联条码规则基础数据。仅允许选择规则类型为条码主档、条码类型为“库位条码”，且已审核、未禁用的条码规则。且条码规则中必须包含系统预设的条码属性：仓库、仓位。
  - 仅允许选择使用组织为当前组织、已审核、未禁用且已启用仓位管理的仓库。
  - 点击生成条码按钮，系统自动在条码主档中生成库位条码；
  - 在条码主档中进行打印。

==== 单据生成参数 ====
|校验模式||启用时，当前扫描配置视为校验模式，PDA端根据此配置扫描条码时支持与对应的目标单据分录进行校验及核对，防止扫描错误。|
|是否强制校验数量||仅在勾选【校验模式】时，才允许修改此参数。勾选【是否强制校验数量】时，PDA扫描条码数量回车时，校验扫描数量不允许超过源单数量，点OK提交数据时控制所有源单数据必需扫描完全才允许提交，否则不控制扫描、提交数量。|
|部分校验||依赖“校验模式”，不允许与“是否强制校验数量”同时启用。启用时，允许部分物料分录不扫描条码。一般应用于在同一目标单据中，既存在启用条码进行管理的物料，又存在未启用条码管理的物料的情况，支持校验核对已启用条码管理的物料分录，未启用的物料分录则数据保持不变。|
|校验扫描提交状态单据||启用时，源单列表仅返回创建、重新审核、审核中三种状态单据。|
|校验扫描审核状态单据||启用时，校验模式允许扫描已审核的单据。(仅适用于对已审核单据做收发料校验的场景，参数勾选时，强制要求目标单据分录配置自定义字段名FScanQty的扫描数量。)|
|仅校验审核中状态单据||当【校验扫描提交状态单据】参数勾选时，才允许勾选此参数；仅用于返回显示审核中状态的单据。|
|校验模式过滤源单数据||仅针对出入库校验模式，结合现场作业需求，对业务单据进行获取源单的条件过滤设置，则安卓PDA端获取源单列表时，按照过滤条件进行数据查看显示。|
|校验核对分录数量比例||针对校验模式下，现场作业时希望能对部分校验的分录数量达到一定比例，PDA提交时判断分录已扫数量/应扫数量是否达到了设置的比例，前提条件为物料必须启用序列号管理。|
|校验模式更新扫描数量||结合用户场景，同一类型单据有的业务需要多次扫描校验操作，有的业务需要一次性校验且直接按实际扫描结果修改单据标准数量，为了区分现场不同作业场景，可通过启用该参数加上单据表体自定义字段扫描数量【FScanQty】进行多次扫描校验更新。|
|是否整单扫描||启用时，扫描源单单据编号即可支持生成目标单据，不需要扫描物料明细条码|
|部分扫描生成单据||启用时，支持同一单据中仅扫描部分物料分录，与未扫描的分录共同生成对应的目标单据。一般适用于同一单据存在启用条码管理的物料及未启用条码管理的物料，且需要通过PDA扫描生成目标单据的场景。|
|同步装箱||适用于单种产品的简单生产入库且需要打包装箱的场景。启用时，支持在PDA扫描界面进行扫描装箱及入库。|
|忽略批号拣货服务||启用时，支持忽略“当前源单-目标单据”的单据转换规则中的批号拣货服务。|
|生成出货清单||需要根据提示的字段名，在出库单上增加相应的文本字段。适用于目标单为“销售出库单”时，PDA扫描生成/更新销售出库单成功后，按扫描的条码生成对应的出货清单。|
|整单扫描指定仓库仓位||勾选了“整单扫描”参数后允许勾选该参数，启用后允许在整单扫描的基础上，指定统一的仓库仓位|
|更新单据扫描标识||启用时，支持在生成目标单时自动在单据上更新【条码扫描】标识，适用于需要区分单据是否通过条码扫描生成的场景。注：【条码扫描】字段需在目标单单据头自定义增加，字段标识需命名为“FIsBarcodeScan”，字段名需命名为“FISBARCODESCAN”，实体绑定属性“IsBarcodeScan”，字段类型为复选框。|
|相同对象单据生成模式||针对其他出库、其他入库和直接调拨单，结合金蝶的退货方向业务扫描操作场景，支持把相同的业务对象作为源单模式下推生成目标单据。|
|盘点校验库存状态||适用于唯一码的应用场景。启用时，异步生成数据执行更新时自动将盘点扫描的条码中不为“入库”状态的条码视为异常。|
|按盘点数量更新条码主档||启用时，支持按实际盘点数量值更新到对应的条码主档的“数量”字段，并清空“出库数量”字段值|
|自动建档||启用时，扫描外部条码支持自动创建条码主档。|
|仅序列号管理物料自动建档||勾选自动建档参数时，才允许勾选此参数。当PDA扫描物料条码解析出物料信息判断是启用了序列号管理时，则PDA的扫描界面才允许扫描序列号条码，提交后系统在条码主档里建立序列号条码档案信息，反之，没启用序列号管理的物料，不需要扫描建档。|
|自动建档调用条码解析||针对没有包含物料信息的外部条码，又需要读取条码其他的信息时，则可以勾选该参数，并另外配置条码解析规则，在移动端建档扫描时即可读取条码属性信息，如扫描外部条码读取批次、生产日期。|
|自动建档调用条码解析||针对没有包含物料信息的外部条码，又需要读取条码其他的信息时，则可以勾选该参数，并另外配置条码解析规则，在移动端建档扫描时即可读取条码属性信息，如扫描外部条码读取批次、生产日期。|
|动态解析条码建档||一般适用于扫描外部条码入库的场景。启用时，支持将扫描解析成功的条码自动创建保存到条码主档中。|
|支持建档条码覆盖更新||勾选了“自动建档”参数后允许勾选该参数，启用后允许建档条码覆盖更新条码主档中已存在的条码数据内容|
|普通扫描备货确认||启用时，通过非扫描任务的方式扫描提交的条码数据自动生成对应的条码备货清单。|
|自动生成条码备货汇总||启用时，支持自动将扫描提交的条码数据在【条码备货汇总】中进行汇总显示。|
|包装条码扫描控制||（1）如果选择【按条码管理系统参数】时，则按照【包装条码扫描控制】参数设置来控制对应操作。（2）如果选择【按扫描配置】，这支持按当前扫描配置参数【扫描提交解除装箱关系】来控制是否解绑当前流程扫描的条码对应装箱关系|
|扫描提交控制方式||（1）如果选择【扫描提交解除装箱关系】时，如果扫描的明细或者包装条码存在上下级装箱关系，提交时需要整体解除|
==== 条码扫描参数 ====
|扫描携带即时库存数量||启用时，PDA扫描条码时，系统自动根据条码的作为条件查询出该批次的库存数量返回到给PDA。（参数生效条件：条码必须是批次条码，即一个批次只对应一个条码，且条码主档中记录有该条码的批次）|
|扫描携带即时库存的库存量||参数【扫描携带即时库存数量】已启用时才允许启用此参数，启用后，支持在PDA扫描条码时自动将条码的信息作为查询条件查询出该批次物料的库存量量(主单位)返回显示到PDA扫描界面。（参数应用场景：条码必须是批次条码，即一个批次只对应一个条码，且条码主档中记录有该条码的批次。）|
|根据条码自动匹配源单信息||基于物料根据一个或多个源单一起摆放时，不好直接区分源单去扫描匹配的情况下，启用此参数时，PDA直接扫描物料条码或物料包装条码提交生成单据时，Cloud端自动根据条码匹配对应的源单信息生成目标单据。（参数生效条件：物料条码是根据对应的源单生成的。）|
|按条码扫描物料管理进行控制||启用时，支持按照【条码扫描物料管理】中维护的物料来控制PDA提交条码数据时，如果存在未完全扫描完成的分录，则给出相应提示。注：结合【部分扫描生成单据】参数一起使用。|
|扫描条码对比分录数量||扫描条码携带出的数量跟源单分录数量进行对比，取最小值显示在PDA界面上，减少操作人员进行修改编辑。|
|控制先入库再出库||针对出库类单据，勾选时，控制条码必须扫描入库之后才允许做扫描出库的业务|
|根据条码自动获取源单数据||勾选【根据条码自动获取源单数据】，PDA打开此扫描配置对应的扫描界面时，焦点自动默认在“扫描条码”处，当扫描的条码包含单据编号时，自动根据单据编号获取源单信息。此参数一般可用于采购入库、生产入库环节。|
|异步盘点是否在线解析条码||启用时，异步盘点扫描时，支持在线解析条码信息。|
|解析或主档条码重复扫描||该参数目的是当同一种业务对象需要分不同场景（如半成品批次销售出库允许重复、产成品序列号销售出库不允许）控制条码是否允许重复扫描时，可以配置不同的扫描配置来启用参数局部控制。而且该参数需要结合条码系统管理参数中的是否重复扫描的参数（根据单据对象维度全局控制）一起控制，当这2个参数设置为一致勾选或一致不勾选时，则任意一个都生效，如果两个参数任意一个不勾选，则以不勾选的参数为准控制。|
|出入库扫描同时补打标签||勾选该参数时，则出入库扫描条码时，在PDA扫描界面确定数量后，会针对当前扫描的条码再次补打一个新的条码标签跟随货物流转。（补打标签前提是PDA链接便携式打印机）|
|先进先出扫描控制||启用时，按“当前组织+物料编码+辅助属性+仓库+仓位”维度比较当前扫描条码与即时库存的有效期至（存在多个时取最小的日期）进行比较，如果条码的有效期至小于等于匹配的即时库存的有效期至，则允许扫描，反之则不允许扫描。此功能仅适用于每次仅发最近的到日期物料的场景（扫描时不会扣减库存），且会降低扫描条码时的速度，非必要不建议使用此功能。（注：如果扫描的条码类型为包装条码，则以当前包装条码所包含的每一个明细条码都与即时库存的有效期至进行比较）|
|是否启用客户料号比对||动态解析条码时，检查客户料号与条码主档的客户料号是否一致。|
|APP辅单位与主单位固定换算||启用该参数时，则APP端扫描界面必须配置辅单位数量与库存单位数量，安卓PDA扫描条码返回了辅单位和主单位数量后，操作员在界面上进行修改库存主单位数量或辅单位数量时，自动根据固定换算比率换算出另外一个字段的数量。|
|仓库仓位组合码主档解析||适用于仓位多维度且仓位数据量很大，需要把仓库仓位组合码生成到条码主档的场景，PDA在仓库或仓位扫描框扫描组合码时直接从条码主档中获取仓库仓位值返回给PDA。|
|允许包装条码重复扫描||针对产品在进行装箱打包后，希望能控制当前流程在收发货扫描时不允许重复扫描相同包装条码的场景。|
|扫描携带库位选项||针对当前扫描配置的采集业务，可设置PDA扫描物料条码根据参数的选项设置的条件，为空则保留以前逻辑（从条码主档或者源单、即时库存取值），也可设置从物料基础资料取值或者从根据VMI单据类型判断仓库属性进行过滤取值。|
|外部条码数量默认为1||启用后，扫描外部条码时，条码数量默认为1。|
|源单分录汇总合并||针对有源单生成模式和校验模式，如果勾选此参数，则安卓PDA端获取源单分录数据后，会根据字段映射里勾选的字段合并条件，对源单数据进行合并展示，方便前端合并数据一起扫描采集收发货。（需特定版本才支持）|
|指定仓库查询库存||勾选上时，PDA扫描界面进行即时库存查询时，根据当前登录用户查询对应表中绑定的是哪些仓库，作为查询条件返回库存数据信息。|
|尾箱指引||只针对安卓PDA1.2版本2021.8月份补丁生效，只适应于启用条码主档生成条码，并通过PDA进行收发货扫描生成单据，不走ERP手工单据的场景，在出库条码进行拆包拆箱后，下次出库需要优先出尾箱，则可按照分录的物料+生产日期作为条件，查询尾数箱条码作为拣货指引，除此之外其他场景不支持。|
|按用户物料对应返回源单数据||结合用户与物料对应表，设置不同的物料归属不同的仓管员进行收发料管控，在通过安卓PDA进行有源单模式采集时，通过PDA选择源单返回分录数据的时候根据用户与物料对应关系进行隔离返回，实现PDA源单分录数据隔离查看的场景。|
|离线扫描||适用无网络状态下，无源单模式，或仅启用根据条码自动匹配源单信息的源单模式的扫描场景。（仅安卓1.2以上版本支持）|
|多类源单条码混合扫描入库||启用时，支持在同一界面扫描多个不同类型的源单业务对象生成的物料条码，提交数据后系统自动根据条码获取对应的源单生成同一类型目标业务对象的单据，适用于部分特殊的入库扫描场景。约束条件：条码在条码主档中需包含单据类型、单据编号、物料编码等关键信息。|
|出库先进先出管控||如果值为“预警提示”或“严格控制”，支持在出库环节扫描物料条码后界面数据确认时，与即时库存对比是否满足先进先出要求。仅适用安卓端应用1.2及以上版本。|
|扫描条码检查源单号||结合根据条码自动匹配源单信息的场景，为了避免扫描条码过程中，电脑端源单号被删除，导致扫描完毕后提交引起异常，通过启用该参数支持扫描物料条码即时检查岀单单号是否存在。|
|条码状态扫描控制||针对现场作业经常出现未入库就误扫描出库，或者已出库又误扫描入库等场景，通过参数进行控制当前条码必须为某个状态时，才能进行下一步的出入库作业扫描。|
|外箱条码不参与控制|||
|标记条码扫描||基于物料条码不允许重复扫描出入库的控制，对正在扫描的物料条码进行已扫描标记，适用于安卓PDA多个用户同时操作时误扫描相同条码的场景，该参数与序列号选项的相关参数互斥。(仅支持条码主档中的条码)|
|按物料的库存组属性返回源单数据||适用于按库存组分别管理各自物料的扫描场景。校验模式应用时，建议在单据分录增加FScanQty数量类型字段来确保支持多库存组扫描同一单据。（应用前配置要求：①在物料自定义增加基础资料字段（基础资料类型选择业务组）用于指定所属库存组；②在条码属性【库存组】中映射物料的库存组字段；③对PDA用户对应的职员分配库存组。）|
|按位置用户对应返回源单数据||启用后，在PDA获取源单信息时支持按【位置-用户表】过滤返回当前用户负责的仓库对应的分录信息。（注：扫描配置中需设置分录的仓库字段。）|
|同一业务对象扫描同一条码控制||用于控制同一条码是否允许重复扫描生成/更新同一业务对象的单据。例如，可支持控制同一条码已扫描入库、扫描出库后，是否允许再次扫描此条码进行入库。|
|扫描包装条码时仓库仓位填充方式||1.未选择或选择“按条码解析结果”，PDA扫描包装条码时按原有的方式处理，即：仓库仓位字段值按条码解析的结果进行填充；2.选择“按扫描界面值”，PDA扫描包装条码时仓库仓位字段值按扫描界面的值进行填充。注：仅支持安卓端1.2及以上版本。|
|扫描包装条码时字段值填充方式||①未选择或选择“条码解析结果优先”，PDA扫描包装条码时，各明细条码的信息优先以条码携带的信息为准，若条码携带的值为空时，则以界面的值进行填充；②选择“按扫描界面值”，则各明细条码的信息固定按扫描界面的值进行填充。③此参数仅对除“批号、生产日期、有效期至、仓库、仓位、辅助属性、数量类型字段、单据头字段”以外的字段生效。注：仅支持安卓端1.2及以上版本。|
|出库先进先出管控维度||结合参数【出库先进先出管控】进行控制，值选择“位置-用户表”时，则仅匹配查询当前用户所负责的仓库；值选择“位置-库存组表”时，则仅匹配查询当前用户所属库存组所负责的仓库；值选择“不限制”时，则匹配所有仓库。|
|按条码管理物料过滤返回源单信息||启用时，PDA获取源单信息时支持仅返回【条码物料管理】中不勾选“不启用条码管理”的物料分录信息。|
|提交校验明细是否重复||勾选此参数后不允许勾选重复扫描，提交时校验明细条码是否存在重复。|
|扫描携带库存数PDA处理选项||①选择“按相同条码扣减已扫数量”，则在同一次扫描过程中，PDA端按携带的库存数量自动扣减同一条码的已扫数量计算剩余数量；②选择“不自动计算”，则PDA端按携带的库存数量进行处理，不作扣减计算。③仅在安卓端1.2及以上版本支持。|
|修改条码数量大于原数量||下拉：不控制、预警提示、授权控制、严格控制，默认不控制，如果设置了授权控制，则另外一个参数字段：授权码可编辑，只允许输入字母和数字且采用掩码显示。|

  - 选择需要打印的记录行，进行预览和打印。

====== 2字段说明 ======

===== 2.1默认条码模板 =====

打印或预览时，如果没有设置条码记录行的条码模板，则采用默认条码模板。

  - 预览条码：预览选中的记录。
  * 业务说明
  - 条码打印日志保留每次打印的情况，便于查询哪些业务单据已经打印过条码。
  - 对于部分丢失或损坏的条码，可以在打印日志中重新打印。

## 【页面】条码扫描
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%9D%A1%E7%A0%81%E6%89%AB%E6%8F%8F

<<返回[[条码管理]]界面

====== 1功能说明 ======

  - 填写扫描所需信息：如条码规则、源单信息和目标单据信息等。
  - 条码扫描及解释：扫描物料/设备/单据上的条码，并进行解释，带出相应的信息。
  - 扫描数据修改和完善：可以修改扫描结果的部分信息。
  - 匹配源单：自动将扫描信息与源单进行匹配，以便关联源单来生成目标单据。在匹配源单时，要求源单与目标单据已建立单据转换路线。
====== 2字段说明 ======

===== 在此扫描条码 =====

此处为条码扫描和录入框，可以在此扫描或录入条码。
===== 条码规则 =====

当采用动态解释条码时，需要设置条码规则，才能解释。但如果条码包含了规则，则无需设置条码规则。
===== 扫描默认数量 =====

每次扫描条码时，带出的扫描数量。默认值为1，可以修改。
===== 扫码删除 =====

当勾选时，起到通过扫描条码来删除条码的作用。
===== 匹配源单 =====

是否需要与源单进行匹配，以关联源单生成下游单据。
===== 源单单据名称 =====

当匹配源单时，需要选择源单名称。
===== 源单单据编号 =====

当匹配源单时，需要选择源单单号。

===== 生成单据名称 =====

选择目标单据的单据名称。
===== 生成单据类型 =====

选择目标单据的单据类型。
===== 其他字段 =====

  - 扫描明细字段：基本上[[条码主档]]的字段。
  - 扫描汇总字段：基本上同[[条码主档]]的字段。
  - 物料数据字段：基本上同[[条码主档]]的字段。
  - 单据信息字段：条码扫描单据的表头信息，包括单号、日期、制单人员等常规字段。
====== 3功能操作 ======

  - 点击【条码管理—条码扫描】菜单，进入扫描界面，进行时为新增状态。
  - 当需要动态解释时且条码不含规则时，通过F8选择条码规则。
  - 当需要匹配源单时，通过F8选择源单单据名称，并选择源单单据编号。
  - 设置每次扫描时默认带出的扫描数量。
  - 做好上述准备工作后，将光标放在“在此扫描条码”处，开始扫描条码。
  - 扫描一个条码后，系统自动进行解释，带出相关信息，填写到【扫描明细】。
  - 无法解释的条码，也会将条码填写到【扫描明细】，但没有其他信息，并以红色的字体显示。
  - 扫描后，点“保存”，将保存本批扫描的【扫描明细】，同时生成【扫描汇总】信息。
  - 可以在【物料数据】查询【扫描汇总】的每一行信息。
  - 当在条码管理系统参数设置“自动保存扫描记录”时，在退出此界面时，也会自动执行保存操作。
====== 4业务说明 ======

  - 通过扫描来录入信息，提高录入效率和录入准确性；
  - 扫描时可以自动与源单进行校验，提高数据的准确性。
====== 5条码扫描日志 ======

  * 功能说明
  - 查询条码扫描及生成目标单据的历史记录。
  - 进行过滤、查看详情，以及批量删除日志。
  - 针对某次扫描结果，重新生成目标单据。
  * 字段说明
条码扫描日志和条码扫描，为同一个元数据，后台表结构也是一样的。字段说明同“条码扫描”。
  * 功能操作
  - 过滤：根据条件查找日志记录。
  - 删除：将所选的日志记录批量删除。
  - 生成单据：对于生成目标单据失败的扫描日志，可以在这里重新生成目标单据。
  * 业务说明
  - 条码扫描日志保留每次扫描的详细情况，便于查询条码扫描的历史信息，如扫描了哪些条码，生成哪些目标单据等。
  - 对于生成目标单据失败的扫描日志，可以在这里重新生成目标单据。

===== 6单据生成 =====

  * 功能说明
  - 当匹配源单时，可以关联生成目标单据，并建立源单与目标单据之间的关联关系。
  - 当没有匹配源单时，也可以生成目标单据，但没有上下游单据间的关联关系。

  * 功能操作
  - 选择目标单据的单据名称，选择目标单据的单据类型。
  - 点“保存”，先保存扫描单据后，才能生成目标单据。
  - 点“生成单据”，根据是否匹配源单，生成相应的目标单据。
  * 业务说明
  - 以扫描结果为中转载体，将源单下推生成目标单据，实现扫描与推单的有效结合，减少数据录入工作量。
  - 调用已设置好的单据转换路线来生成下游单据，保证生成数据的准确性。

## 【页面】条码接口服务
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%9D%A1%E7%A0%81%E6%8E%A5%E5%8F%A3%E6%9C%8D%E5%8A%A1

<<返回[[条码管理]]界面

====== 1条码生成 ======

系统提供条码生成的公共程序，用于生成条码。根据单据信息、条码规则和单据实体行信息，生成相应的条码，如果是主档对照模式，则将条码写到条码主档。
===== 1.1功能说明 =====

  - 读取条码规则档案信息。
  - 按条码规则判断待生成条码的数据是否完整。如果不完整，返回失败信息。
  - 按条码规则组合出条码字段信息，得到 基本条码 。
  - 条码规则没有进行流水号控制时，先判断该基本条码在条码主档是否存在，如果存在，则直接返回成功信息。
  - 条码规则进行流水号控制时，则按条码生成数拆分为多行，生成多个条码（基本条码+流水号）。
  - 在主档对照的模式下，将生成的条码及相关信息写到条码主档，保证 条码规则+条码 唯一。
  - 返回条码生成是否成功信息。
===== 1.2 接口说明 =====

public BarCodeCreateResult GetResultByCodeRule (Context ctx, BusinessInfo billInfo, long sRuleId, ExtendedDataEntity[] barCodeDataEntity)
参数：上下文, 单据信息, 条码规则, 单据实体行信息, 条码实体行信息
返回：条码生成成功或失败标识
====== 2条码解释 ======

系统提供条码解释的公共程序，用于解释条码。传入条码及相关参数，返回解释后的数据包。支持主档对照模式和动态解释模式。
===== 2.1功能说明 =====

  - 根据条码值检索条码主档，如果存在，则返回数据包及解释成功标识。
  - 如果在条码主档中不存在，则按条码规则进行解释。这时，先要判断条码规则是否有效，如果条码规则为空或无效，则返回失败信息。
  - 按条码规则，拆分条码值，形成多个条码属性字段。
  - 判断这些字段信息的有效性：如果是基础资料字段，则必需在基础资料档案中存在。如果是单据字段，也需要在单据中存在。如果信息无效，则返回失败信息。
  - 如果条码规则的模式为主档对照模式，则将解释成功的条码信息回写到条码主档。
  - 返回数据包及成功信息。
===== 2.2 接口说明 =====

public DynamicObject ExplainBarCode (BOS.Context ctx, string barcode, int barcodeRule, string billTypeName, string billNo)
参数：上下文，条形码，条码规则，单据名称，单据编号
返回：条码解析结果的数据包

====== 3功能操作 ======

  - 选择待生成条码的记录。
  - 根据需要，修改条码生成数。
  - 合并生成条码：系统按条码规则中的“参与分组”项目，对所选的源单记录进行汇总，根据汇总后的生成数生成相应的流水号和条码。
  - 逐行生成条码：系统根据源单信息的记录行，逐行生成条码，不进行生成数的汇总处理。
====== 4业务说明 ======

  - 支持合并生成条码和逐行生成条码两种模式。
  - 可以选择哪些源单记录行参与生成条码。

====== 1条码管理概述 ======
===== 1.1条码管理概述 =====

条码管理是以一维码或二维码为载体，将源单信息打印成可扫描识别的条码，再通过扫描设备扫描条码，快速生成下游单据的功能。一维码（传统条码）具有简单、易用、低成本和高效率等特点，已经有非常广泛应用。二维码作为一种新的数据存储和数据传递的方式，本身具有易打印、好识别、数据容量大等特点，也具有非常广阔的应用前景。

===== 1.3系统特性 =====

金蝶AI星空条码管理系统设计目标是：
  - 可以从任意业务对象的任意字段取数和生成条码；
  - 可以将扫描识别后的信息回写到任意业务对象；
  - 通过简单配置即可实现任意业务对象的条码应用；
  - 方便各业务领域及第三方的二次开发。
因此，本系统具有以下各种特性。
  * 精细化条码参数控制
  - 可以按组织机构来分别设置条码管理参数，并为整个组织机构设置默认的条码管理参数。
  - 还可以按组织机构+业务对象来分别设置控制参数，实现更精细化控制。
  * 任意扩展的条码属性
  - 引入”条码属性”概念，条码属性可以任意扩展。
  - 通过条码属性进行信息标准化处理：将各业务单据及基础资料的字段信息，转换为标准的条码信息，便于条码的生成、打印和解释。
  - 建立条码属性与业务对象字段之间的映射关系，便于从业务对象获取数据，以及将数据回写到业务单据（或生成业务单据）。
  * 丰富灵活的条码规则
  - 通过条码规则的条码属性组合，可以生成任意类型的条码，实现灵活的条码管理。
  - 当条码信息复杂多变时，可以采用主档对照模式，以快速准确地解释条码。
  - 当条码信息简单且较有规律时，可以采用动态解释模式，以减少条码数据存储量。
  * 完整的条码主档信息
  - 管理系统中所有的条码主档信息，包括本系统生成的条码及外部导入的条码。
  - 可以进行查询、追溯和批量打印条码。
  - 支持条码主档的批量引入和批量引出。
  - 支持条码的禁用和反禁用。
  * 强大的条码生成与打印
  - 支持从金蝶AI星空大部分的业务单据和基础资料上获取数据生成条码。
  - 支持合并生成条码和逐行生成条码两种模式。
  - 支持一维码打印和二维码打印。
  * 可关联生成下游单据
  - 扫描时可以自动与源单进行校验，提高数据的准确性。
  - 以扫描结果为中转载体，调用系统已有的单据转换关系，将源单下推生成目标单据，保证下推单据的准确性，并减少开发工作量。
  * 简便的条码功能配置
  - 已将“条码打印”抽象为一种通用的操作类型，方便在业务单据或基础资料中配置出“条码打印”功能。
  - 支持大部分业务单据和基础资料的条码打印。
  - 通过简单的配置即可实现条码打印功能，有效降低开发工作量。方便各领域及客制化开发，实现按需配置。
  * 开放的条码服务接口
  - 将条码系统中重要的程序抽象为通用的公共程序，便于各领域及第三方调用。
  - 提供条码生成公共程序，用于生成条码。
  - 提供条码解释公共程序，用于解释条码。

====== 2业务类型及应用 ======

===== 2.1 PC业务模式(扫描枪) =====

条码PC业务模式，可使用扫描枪进行操作。市面上能解析条码的扫描枪即可，没有型号的限制，如果是无线扫描枪，则对使用范围有一定要求，具体根据扫描枪的性能而定。
另外需要配备条形码打印机。如果需要打印出来的条码可以直接贴在物料上，则需要使用带标签纸的专业条码打印机；如无此要求，也可以使用普通打印机打印条码。对打印机的型号无限制。

===== 2.2 移动业务模式(PDA) =====

条码移动业务模式，使用PDA进行操作。目前只支持指定型号款的PDA，需要向金蝶配套购买，其他渠道购买的PDA或是非指定型号的PDA都无法正常使用。

PDA是由安卓手机经过加工改造而成，本身是安卓原生系统，符合大多数人的操作习惯，成本也相对以前的条码采集器要低一些，同样具备工业级的扫描能力。PDA通过WIFI与K/3服务器连接，数据实时传递，直接与服务器数据交互，没有延迟，网络配置也比较简单。对于企业在仓库、生产现场的一些业务人员来说，通过PDA实现移动办公可以有效的提升工作效率，保证数据准确性，所以无线PDA的业务模式，也是我们最为推荐用户使用条码的方式。

===== 2.3 条码应用场景 =====

金蝶AI星空条码管理提供物流条码管理、库存条码管理、工序条码管理、包装条码管理等系统功能，条形码的应用贯穿于企业原材料、成品管理的始终，从原材料入库到生产领用，车间工序跟踪，再到产成品入库、销售出库、盘点等全过程都可通过条形码帮助企业实现快速、准确录单，提高企业工作效率，减少出错几率。条形码报表分析可帮助企业对物料进行跟踪追溯，为管理者决策实时提供真实有效的依据。

  * 采购环节
  - 供应商在线打印物料的条码，贴在需要送货的包装箱上，送货至企业，企业的收料人员通过扫描物料的条码直接进行收料业务处理。
  - 收料之后通知质检人员进行检验，检验合格的和不需要检验的，则送至仓库进行入库。仓管员直接扫描物料的条码进行入库业务处理。
  * 仓库环节
  - 仓管员根据备料计划进行备料，扫描实物上的条码进行核对发料。
  - 仓管员通过扫描成品条码进行入库，核对成品及存放的仓库、仓位。
  - 仓管员扫描物料上条码进行调拨和盘点。
  * 生产环节
  - 生产任务单下达，并打印条码，车间作业人员完工后，扫描任务单条码进行完工汇报。
  - 产线的班组长，扫描任务单条码进行工序汇报。
  * 销售环节
  - 销售人员根据销售订单的条码，扫描生成发货通知单，通知仓库发货。
  - 仓库人员根据接收的发货通知单，扫描实物上的条码进行核对发货。
  * 质量环节
  - 某批次原材料有问题，查询该批次原材料的库存状况，禁用该批次条码的原材料进行生产。
  - 该批次条码原材料生产的产品禁止出库。
  - 产成品条码追溯，产成品召回。
  - 原材料条码追溯，联系原材料供应商。

===== 4.1基础设置 =====

==== 4.1.1 系统参数设置 ====

不同的业务组织，对于条码应用需求可能有所不同。同时，在不同的应用场景中（如入库、出库、盘点、工序流转等），对条码应用需求也可能会有所不同，因此，需要通过系统参数进行控制，金蝶AI星空提供“条码管理系统参数”功能来设置条码应用参数。具体详见[[条码管理系统参数]]设置
==== 4.1.2 条码属性设置 ====
条码属性是组成条码的字段信息，包括组成条码的编码项信息，以及非编码项的其他信息。通过条码属性，可以对条码信息进行标准化处理：将各业务单据及基础资料的字段信息，转换为标准的条码信息，便于条码生成、打印和解释。具体介绍详见[[条码属性]]设置
==== 4.1.3 条码规则设置 ====

条码规则是条码生成和条码解释的依据，是非常重要的基础数据。应用时，应选择合适的条码属性及设置相关的参数来建立条码规则。通过条码属性组合，可以生成任意类型的条码，实现灵活的条码管理。具体详见[[条码规则]]设置
==== 4.1.4 条码主档管理 ====

管理条码系统中所有的条码主档信息，包括本系统生成的条码，以及外部系统导入的条码。条码主档便于用户对所有条码进行集中管理。具体介绍详见[[条码主档]]管理
==== 4.1.5 扫描配置 ====
扫描配置用于定义PDA的功能，PDA根据扫描配置的内容显示菜单项、扫描界面的字段信息及实现对应的功能。具体介绍详见[[扫描配置]]管理

==== 4.1.6 GS1条码解析规则 ====
在部分客户的扫描GS1条码的应用场景中，存在需要从同一应用标识符（如(21)）内容获取多个信息（批号、生产日期、序列号）的场景，而现有条码标准功能对GS1条码的解析处理，仅支持从同一应用标识符获取一个信息。此外，部分客户还存在扫描不同物料的GS1条码时，需按照不同的规则解析获取对应的信息。具体介绍详见[[GS1条码解析规则]]管理

==== 4.1.7 PC装箱设置 ====
用于定义PC装箱扫描平台、协同条码数据导入功能中，扫描外箱码时解析取数的字段，以及建档、重复装箱控制。具体介绍详见[[PC装箱设置]]管理

==== 4.1.8 PDA条码模板设置 ====
用于定义PDA打印时可选择的模板打印条码标签。具体介绍详见[[PDA条码模板设置]]管理

===== 4.2条码打印平台 =====

==== 4.2.1 数据获取 ====

生成条码时，往往需要从业务单据或基础资料中批量获取原始数据，根据这些原始数据和条码规则去生成条码，然后再根据条码标签模板打印出条码。详细介绍见[[数据获取]]
==== 4.2.2 条码生成 ====

从业务单据或基础资料中批量获取数据后，如果有必要，可以修改源单的部分信息，然后选择需要生成条码的记录，根据条码规则生成条码。详细介绍见[[条码生成]]
==== 4.2.3 条码打印 ====

条码生成和保存后，选择所需要打印的条码记录行，进行批量打印。在打印之前，可以进行条码预览。详细介绍见[[条码打印]]
==== 4.2.4 条码模板设置 ====

利用BOS套打设计器，在条码打印、自定义条码打印、条码主档等业务对象中设计条码打印模板。详细介绍见[[条码模块设置]]
==== 4.2.5 条码功能配置 ====

在业务单据和基础资料的列表或维护界面，配置条码打印功能。点击【条码打印】时，弹出条码打印界面，并带出相应的信息，便于条码生成和打印。金蝶AI星空将条码打印抽象为标准的操作，便于在业务单据和基础资料上配置此功能。详细介绍见[[条码功能配置]]
==== 4.2.6 条码打印日志 ====

当条码管理系统参数设置为“自动保存生成记录”时，每批的条码生成及打印操作，都会自动保存为一张单据，该单据可以通过条码打印日志查询。此外，在条码打印界面，点“保存”，也会保存为一张单据。详细介绍见[[条码打印]]日志
==== 4.2.7 自定义条码打印 ====
单据条码打印是以单据为依据，取单据中的字段进行条码打印；而自定义条码打印则是与单据无关，可自由录入字段的内容进行打印。详细介绍见[[自定义条码打印]]

==== 4.2.8 电子秤型号 ====
用于设置条码称重打印中电子秤参数是否为默认型号选择。详细介绍见[[电子秤型号]]

==== 4.2.9 条码拆分 ====
用于将已存在主档中条码通过拆分功能拆分子条码生成至主档记录。详细介绍见[[条码拆分]]

==== 4.2.10 条码称重打印 ====
支持有源单模式通过称重打印功能生成目标单据。[[条码称重打印]]

==== 4.2.11 条码称重打印日志 ====
用于记录已生成的条码称重打印日志。

===== 4.3 条码扫描平台 =====

==== 4.3.1 扫描录入 ====

供应商按要求送货至企业后，企业的收料人员通过扫描货物上的条码，快捷生成收料通知/请检单/采购入库单。产品入库时，也可以通过扫描产品上的条码，快捷生成产品入库单。因此，在企业很多业务场景中，都需要用到条码扫描功能。详细介绍见[[条码扫描]]
==== 4.3.2 单据生成 ====

条码扫描的一个主要目的，就是快捷生成业务单据，以减少手工录入工作量。生成业务单据有两种方式，一种是通过源单下推生成目标单据，源单与目标单据之间有着内在的关联关系。另一种是将扫描结果暂存为目标单据，此时，目标单据与源单没有关联关系。这两种方式适用于不同的应用场景。详细介绍见[[条码扫描]]
==== 4.3.3 条码扫描日志 ====

当条码管理系统参数设置为“自动保存扫描记录”时，每批的条码扫描操作，都会自动保存为一张单据，该单据可以通过条码扫描日志查询。此外，在条码扫描界面，点“保存”，也会保存为一张单据。详细介绍见[[条码扫描]]日志
==== 4.3.4 异步生成数据 ====
若盘点的数据量很大，建议使用异步盘点方式，PDA仅扫描采集条码，不解析条码，提交数据后，由Cloud端异步处理，这种处理方式可以有效及准确地支持大数据量盘点扫描。
结合企业的盘点场景，建议使用异步盘点方式进行盘点。详细介绍见[[条码盘点清单]]

## 【页面】条码规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%9D%A1%E7%A0%81%E8%A7%84%E5%88%99

[[条码管理|<<返回条码管理界面]]

====== 1功能说明 ======

1)	条码规则是条码生成和条码解释的依据，选择合适的条码属性来建立条码规则。
2)	首先设置条码规则的内容（即条码所需的信息），包括编码项信息和其他信息。
3)	再设置条码规则适用的业务对象范围。
====== 2字段说明 ======

===== 规则类型 =====

下拉选择，有两个选项：（1）主档对照：生成的条码保存到条码主档，扫描时从条码主档检索并解释。系统默认采用“主档对照”的方式。（2）动态解释：生成的条码不保存到条码主档，扫描时根据条码规则动态解释。
===== 条码类型 =====

下拉选择，有以下选项：物品条码，批号条码，序列号条码，箱号条码，库位条码，单号条码，基础资料条码，其他条码。条码类型信息目前仅供参考。
===== 校验码长度 =====

默认为0，不生成校验码； 当不为0时，按“校验码生成规则”生成相应的校验码，并附加在生成条码的最右边；当校验码长度大于1时，因为生成的校验码只有1位，所以要加0补齐，0加在左边，例如：校验码长度3位，生成校验码为8，结果为：008。
===== 条码示例 =====

条码规则中参与编码的项目形成的条码示例，255位文本。
===== 规则参与编码 =====

当勾选时，规则编号将作为条码的一部分，附加在条码的最后面，如条码规则编码为GZ01，则生成的条码为：条码<GZ01>。
===== 属性项目、属性名称、属性类型 =====

来自条码属性档案，通过F8选择。
===== 长度 =====

默认为0；若长度为0，则不论数据项的长度为多少，都不进行截取或补位操作，而将数据项完整显示；若长度大于零，则可能会进行 截取或补位。
===== 格式 =====

日期型、数值型、文本型的项目，需要设置格式；格式由系统预设，用户只能选择，不能新增修改。
===== 设置值 =====

固定符号、起始流水号等，都填写在该栏位；流水号的步长默认为1，不需要特别设置。
===== 补位符 =====

当数据项字符位数小于设定的项目长度时，以补位字符占位。
===== 对齐方式 =====

设置补位和截断的处理方式；右对齐（如数字）—补位在左边，截断也在左边；左对齐（如字符串）—补位在右边，截断也在右边。
===== 参与编码 =====

当主档对照时，条码规则所有设置的属性，都会被写入到条码主档；但只有 参与编码的项目才会参与生成 条形码 信息。
===== 参与分组 =====

在生成流水号条码时，往往需要先进行汇总，再根据汇总后的总数量分别生成流水号，所以要指定分组项作为汇总依据。
===== 适用业务对象 =====

设置该条码规则适用于那些业务对象。
===== 默认规则 =====

每种业务对象可以将一个条码规则设置为默认规则。



===== 其他字段 =====

|字段||说明|
|规则编码||条码属性的编码，30位文本，系统中唯一。|
|规则名称||条码属性名称，50位文本，系统中唯一。|
|描述||用于备注说明，255位文本。|
|备注||用于备注说明，50位文本。|

	
====== 3功能操作 ======

  - 通过“新增行”、“删除行”、“插入行”等操作来设置条码规则内容；
  - 条码属性通过F8进行选择，选择范围为已审核的条码属性；
  - 设置条码属性的长度、格式、设置值、补位符、对齐方式、参与编码、参与分组、备注等信息。
  - 通过“新增行”、“删除行”、“插入行”等操作来设置适用业务对象；
  - 业务对象可以通过F8进行选择，支持大部分业务单据和基础资料的业务对象；
  - 条码规则审核后，只能修改业务对象设置，不能更改其他内容。
====== 4业务说明 ======

  - 通过条码属性组合，可以生成任意类型的条码，实现灵活的条码管理。
  - 当条码信息复杂多变时，可以采用主档对照模式，以快速准确地解释条码。
  - 当条码信息简单且较有规律时，可以采用动态解释模式，以减少条码数据存储量。

====== 5参数说明 ======

|字段||说明|
|规则参与编码||启用时，自动将当前规则参与显示条码中。|

==== 1.功能说明 ====
（1）扫描条码
在扫描条码字段栏位中扫描条码时，调用解析接口对条码进行解析，如果扫描的条码属于明细条码，则控制数量为空时界面数据不允许确认成功并提示“条码数量必需录入大于0的值”，校验通过时将条码、数量更新到已扫列表中；

====== 1功能说明 ======

  - 自定义条码打印与业务单据无关，可自由录入字段的内容进行打印。
  - 已有条码时直接扫描条码，获取相关信息，可以进行修改，然后重新打印条码。
  - 没有条码时，手工新增行，录入相关数据，选择条码规则，生成条码、打印条码。
====== 2字段说明 ======

===== 在此扫描条码 =====

此处为条码扫描录入框，可以扫描或录入条码。
===== 扫描默认数量 =====

每次扫描时带出的数量，默认值为1，可以修改。
===== 扫码删除 =====

当勾选时，起到通过扫描来删除条码的作用。
===== 扫描后立即打印 =====

当勾选时，扫描后的条码，将立即打印出来。
===== 默认条码规则 =====

当手工录入数据生成条码时，需要设置条码规则。

设置条码打印时所采用的打印模板。

同[[条码主档]]的字段。

  - 没有条码时，可以新增行，直接录入物料、数量、批号等信息。点“条码生成”，生成新的条码，并根据条码规则中设置是否写到条码主档，进行相应的处理。
  - 条码打印：打印数 默认等于 扫描数，生成数 默认为1；当勾选 扫描后立即打印（适用于有条码主档的情况），扫描后立即将扫描结果打印出来，并清空列表，以待下一次扫描；可在此界面打印和预览条码。
====== 4业务说明 ======

自定义条码打印支持手工录入数据、生成条码和打印条码，也支持扫描带出相关信息、修改数据和重新打印条码，非常灵活方便，满足零散随机的的条码生成及打印应用场景。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BE%85%E5%8A%A9%E8%B5%84%E6%96%99-%E6%9D%A1%E7%A0%81%E6%A8%A1%E6%9D%BF%E5%AF%B9%E5%BA%94%E5%85%B3%E7%B3%BB%E8%A1%A8

====== 1功能说明 ======
用于定义当前数据中心中辅助资料与条码模板对应关系设置，通过此设置，可在条码系统管理参数中设置条码模板过滤维度为客户或辅助资料，设置完成后，可在条码打印选择已对应关系的辅助资料条码模板。

====== 2操作说明 ======
  - 新增辅助资料条码模板设置；
  - 点击选择辅助资料类型；
  - 点击选择辅助资料；
  - 选择模板，然后保存即可
