====== 1.交易对账工作台 ======

===== 1.1 功能概述 =====
交易对账工作台是门店营业对账的核心单据，是第三方交易流水账单和门店POS账单进行对账的主页面

通过门店和时间查询出需要对账的数据，通过自动对账的条件（[[对账字段配置|对账字段配置]]）自动对账

一键对账，简单方便

**对账步骤：勾选某一方或者多行数据，点击对账即可**

===== 1.2 字段说明 =====
^ 字段           ^ 说明                                    ^
| 营业组织名称       | 对账的组织                                 |
| 营业日期         | 营业日期                                  |
| 结算方式编码       | 结算方式的编码                               |
| 结算方式名称       | 结算方式的名称，包括微信和支付宝                      |
| 门店POS账单笔数    | 门店POS的账单笔数                            |
| 第三方交易流水账单笔数  | 第三方交易流水账单的笔数                          |
| 门店POS营业金额    | 门店POS的营业金额总和                          |
| 第三方交易流水账单金额  | 微信/支付宝的交易流水账单金额                       |
| 差异对账金额       | 前台POS和第三方交易流水金额之差                     |
| 自动对账金额       | 自动对账时前台POS和第三方交易流水金额相等的金额和            |
| 确认对账金额       | 对账完成后最终的金额和，有差异时默认确认对账金额为第三方交易流水账单金额  |
| 差异状态         | 包括差异未审核，无差异已审核，有差异已审核，未对账，无差异未审核      |
| 查看明细         | 对账完成后，点击查看明细跳转到交易对账记录单                |
| 差异数据批量处理     | 对账完成后对于有差异的金额可以批量赋值                   |

[[门店营业对账|<< 返回门店营业对账]]

====== 1.收款账户设置 ======

===== 1.1 功能概述 =====
  * 设置门店营业对账和门店外卖管理的收款账户信息，支持美团，饿了么，微信，微信支付，支付宝，线上支付宝等多种支付方式。
  * 选择美团或者饿了么结算方式时，收款账户字段显示为名称，编码，结算方式，执行定时下载任务，账户标识，账户秘钥，账单服务器地址，账单到账间隔天数，第三方中台，第三方中台标识，第三方中台服务器地址，外卖平台服务器地址，外卖订单到账间隔天数，组织，第三方平台门店id
  * 选择微信/支付宝的结算方式时，收款账户字段显示为名称，编码，结算方式，执行定时下载任务，设置子账户和秘钥，账户标识，账户秘钥，账单服务器地址，账单到账间隔天数，原始单字段，区分方式，区分条件
  * 把金蝶云餐饮提供给企业的账户在Cloud收款账户页面进行相应的配置。主要包括结算方式，账户标识，账户秘钥，以及该账户所要绑定的组织，一个账户可以同时绑定多个门店。
  * 收款账户中除了账户标识和账户秘钥，还需要设置每个门店支付流水的区分条件设置
  * 客户通过收款账户来设置不同平台的账户信息
  * 多个门店可以设置同一个收款账户
  * 不同的支付平台可以使用相同的收款账户

====== 1.门店现金存款查询 ======

===== 1.1 门店现金对账操作流程 =====

[图:门店现金对账操作流程.png]

===== 1.2 门店现金对账操作步骤 =====

一、总部财务人员在金蝶食神注册用户，注册网址为shishen.kingdee.com

[图:门店现金对账1.png]

二、用手机号注册账户

[图:门店现金对账2.png]

三、点击商户注册页面，填写必填信息即可

[图:门店现金对账3.png]

四、用上面注册的账户重新登录金蝶云食神平台，点击商户信息，查看商户编码

[图:门店现金对账4.png]

五、登录金蝶云Cloud，打开金蝶食神开发者参数设置，在商户参数配置中输入上述查看到的金蝶食神商户编号

## 【页面】门店线上对账操作流程
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%97%A8%E5%BA%97%E7%BA%BF%E4%B8%8A%E5%AF%B9%E8%B4%A6%E6%93%8D%E4%BD%9C%E6%B5%81%E7%A8%8B

[[门店营业对账|<< 返回门店营业对账]]

====== 1.门店线上对账操作流程 ======

一、获取收款账户

（一）账户标识和账户秘钥的生成步骤如下：

1、企业根据申请的不同类型的账号，提供不同的参数给金蝶云餐饮在服务端配置。

[图:门店线上对账1.png]

2、金蝶云餐饮把配置的账户标识和账户秘钥提供给企业进行收款账户的配置。

[图:门店线上对账2.png]

3、企业根据自己的账户类型提交不同的参数给金蝶云餐饮。

（1）金蝶子商户：通过金蝶注册的账号

（2）第三方子商户：通过在其他第三方平台注册注册的账号

（3）直连模式：自主在微信、支付宝上注册的账号

二、配置收款账户

把金蝶云餐饮提供给企业的账户在Cloud收款账户页面进行相应的配置。主要包括结算方式，账户标识，账户秘钥，以及该账户所要绑定的组织，一个账户可以同时绑定多个门店。

收款账户中除了账户标识和账户秘钥，还需要设置每个门店支付流水的区分条件设置

[图:门店线上对账2.2.png]

三、配置对账字段页面

各流水原始单格式都不一样，需要设置用来对账的统一字段，以便完成POS账单和支付原始单的对账功能。系统已经预置这些字段对应关系，用户可根据各自情况进行相应修改。

[图:门店线上对账3.png]

四、下载原始的支付流水

选择需要下载的原始单对应的账户和日期，下载流水原始单。在交易流水对账页面，也可以下载原始的支付流水。

[图:门店线上对账4.png]

五、获取POS账单

前台营业结束之后，通过清机上传营业数据，同时通过数据交换同步到POS账单中。POS账单同时提供开放式接口，没有使用金蝶食神POS收银系统的用户，可通过接口导入生成POS账单

[图:门店线上对账5.png]

六、自动对账

通过门店和时间查询出需要对账的数据，通过自动对账的条件（结算方式，金额，流水号）自动对账。

[图:门店线上对账6.png]

七、查看对账记录

成功对账之后，生成创建状态的对账记录，提交审核。发现对账结果不对时，可以取消对账，重新回到对账那边再次勾对。

[图:门店线上对账7.png]

====== 1.门店营业对账 ======
===== 1.1 门店营业对账概述 =====

门店营业对账模板主要包括两大部分，一部分是门店的现金对账模块，另一部分主要是门店线上的包括微信与支付宝的对账。门店的现金对账是门店人员把当天或者若干天的收入现金存入到银行中，获取到银行流水凭证后，在云之家输入门店缴款单，以方便总部财务人员及时掌握和核对门店的现金收入情况。门店线上的对账功能主要解决微信和支付宝产生的原始交易流水与数据交换或者第三方接口上传的POS账单的对账，以便用户能够快速的查看对账情况和对账差异。门店线上对账分为自动对账和手工对账，对于对账成功的部分生成对账记录，而没有对上的数据可以生成POS差异账单调整单

====== 1.门店营业对账系统参数 ======

===== 1.1 功能概述 =====

  * 设置对账时门店POS账单笔数或门店POS营业金额为空时是否允许对账
  * 如果勾选，则允许门店POS账单笔数 或者 门店POS营业余额为空
  * 如果不勾选，这门店POS账单笔数或者门店POS营业余额为空，不允许对账
