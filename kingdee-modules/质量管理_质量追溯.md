====== 批号序列号关系 ======

**功能描述**

批号序列号关系是用来记录实际业务中单个产品所使用的具体批号或序列号的半成品和原材料，为后续的单品追溯提供依据。

**使用前提**

生产及委外的产品及生产领用的子项物料存在批次/序列号管理。

**功能路径**

【质量管理】－>【质量追溯】－>【批号序列号关系】

=====3.3质量追溯===== 

====3.3.1批号追溯====

**功能描述**

当子项物料、父项产品存在批次管理，通过批号追溯物料的来龙去脉，可展示一个产品树在销售、生产、采购、库存各个环节批号物料相应业务单据。

在批号质量追溯过滤界面，设置追溯对象、追溯条件、追溯组织范围、追溯方向、追溯方案等进行追溯

**快捷过滤：** 
| **字段**               || **说明**                                                                                                      |
| 查询组织                 || 查询明细单据的组织范围（追溯根节点物料不受组织限定）。\\ 可选择已审核未禁用的组织，默认勾选当前组织。                                                        |
| 追溯树方案                || 选择已审核未禁用的追溯树方案，系统预插的追溯树方案，追溯方向包括：溯源、去向。                                                                     |
| 追溯方案                 || 选择已审核未禁用的追溯方案，默认选择系统预插的追溯方案。                                                                                |
| 追溯方向                 || 显示追溯树方案中的追溯方向，包括溯源追溯、去向追溯；\\ 溯源追溯时，按照物料从父到子的原则，自上而下追溯某一产品所用的子项物料；\\ 去向追溯时，按照物料从子到父，从下到上的原则追溯某一材料被使用到哪些产品上。|
| 物料代码                 || 追溯根节点物料代码；\\ 选择创建组织下已审核未禁用的进行批号管理或进行序列号管理的物料。                                                               |
| 批号                   || 追溯物料的批号范围；从主菜单“批号追溯”进入时，批号为必录；\\ 批号取数来源于批号主档；批号为质量追溯左边树根节点物料的批号。                                            |
| 日期范围                 || 查询明细信息单据的单据日期范围；\\ 默认截止日期取系统当前日期，开始日期按前日期往前推一个月。                                                            |
| 供应商编码                || 查询明细信息的供应商范围；\\ 供应商过滤条件适用于质量追溯右边明细表格采购类单据取数的过滤。                                                             |
| 生产车间编码               || 查询明细信息的生产车间范围；\\ 生产车间过滤条件适用于质量追溯右边明细表格生产类单据取数的过滤。                                                           |
| 客户编码                 || 查询明细信息的客户范围；\\ 客户过滤条件适用于质量追溯右边明细表格销售类单据取数的过滤。                                                               |

| 追溯层级   || 追溯界面左侧的产品树展开最大层级数根据此参数取值，默认值是100，允许录入1-100的正整数                                                         |

在批号追溯过滤界面中，追溯树方案中追溯方向为“溯源追溯”，在批号追溯界面，左侧展示区按照产品树由父项物料追溯子项物料展开，根节点为父项物料；追溯树方案中追溯方向为“去向追溯”，在批号追溯界面，左侧展示区按照产品树由子项物料追溯父项物料展开。

**批号追溯界面介绍**

  * 产品树：
追溯界面的左侧，按照“去向追溯”或者“溯源追溯”，展示某物料及批次在实际业务中，构成的产品结构。产品结构是多层次的，包括对应的父项材料批次、子项材批次。

当一个批次物料使用于多个批次的父项产品时，或一个批次父项产品使用多个批次原材料时，树形产品结构中对应物料显示蓝色，点击物料批次右边三个小点处，可弹出所使用的批次列表，双击批号列表中任一批次，即可展开此批次的追溯。

  * 明细信息：
追溯界面右侧，显示产品树中某物料及批次节点对应的实际业务单据；

系统预设的质量追溯方案中，包括销售、生产、委外、采购、车间、质量、库存等等业务单据，用户可以依据自己的需要，优化质量追溯方案，提高查询效率；

明细信息中显示的单据，按照快捷过滤中的时间范围和其他条件进行过滤。

**基本操作：**

  * 去向：
选择产品树中某节点的物料及批次，点击【去向】，可以查询该批次物料用在哪些批次父项半成品、产品中。

  * 溯源：
选择产品树中某节点的物料及批次，点击【溯源】，可以查询该批次物料用到哪些批次的子项物料。

====== 1 质量追溯概述 ======

企业生产产品在销售出去后发生客户质量投诉、售后服务发现严重质量问题批次或者单品、物流和加工过程中发现原料批次质量问题时，质量问题分析人员要对成品的质量问题进行追溯分析，对企业业务过程各个环节的历史数据进行逐步分析，定位发生问题的材料批次或者单品。同时，质量问题分析人员对原材料的质量问题批次、产品进行去向分析，分析其库存、销售流向、生产产品的批次、序列号，对受到质量影响的产品进行召回，对相关库存进行冻结。

质量追溯系统打通企业内采购、生产、物流、销售、质量各个环节的业务数据，综合展示各业务环节相关单据，进行综合的分析，帮助企业进行质量问题分析以及确定质量问题影响范围。

通过质量追溯，质量分析人员能方便快捷的根据批号或序列号查询到销售客户、原材料供应商、生产等环节信息，方便定位产生质量问题的环节以及召回存在质量隐患的产品。

===== 1.1 产品介绍 =====
金蝶云中的质量追溯，针对批次管理物料、序列号管理物料，主要从两个方向进行追溯：1、溯源追溯，即从父项产品向下追溯半成品、子项物料；2、去向追溯，即从半成品或子材物料向上追溯父项半成品和产成品。

金蝶云中的质量追溯包括：批号追溯、序列号追溯、批号序列号综合追溯、单品序列号追溯。

=====1.1使用流程=====
日常业务操作

1、批号追溯：

进入【质量管理】->【质量追溯】->【批号追溯】

2、序列号追溯：

进入【质量管理】->【质量追溯】->【序列号追溯】

3、批号序列号综合追溯：

进入【质量管理】->【质量追溯】->【批号序列号综合追溯】

4、批号序列号有关系：

进入【质量管理】->【质量追溯】->【批号序列号有关系】
  
5、单品序列号追溯：

进入【质量管理】->【质量追溯】->【单品序列号追溯】
=====1.2基础设置===== 

====1.2.1质量追溯方案===== 


**功能描述**     

用于定义追溯哪些业务单据、显示哪些字段内容，质量追溯界面右侧进行相应的追溯内容展示。

系统预设完整质量追溯方案，涵盖大部分供应链、生产管理、质量管理、车间管理单据，如果企业某些业务没有用到，可根据需要对方案内容删减、优化。

温馨提示：系统预设方案不建议直接修改，可以复制一份再修改使用，以免改错无法还原。 

**功能路径**

【质量管理】->【质量追溯】->【质量追溯方案】

====1.2.2质量追溯树方案===== 

**功能描述**      

系统预设溯源追溯树方案和去向追溯树方案。

用于定义父项找子项或子项找父项追溯业务单据的追溯关系，质量追溯界面左侧进行相应的追溯内容展示。

**功能路径**

【质量管理】->【质量追溯】->【质量追溯树方案】

====1.2.3单据追溯逻辑=====
**功能描述**      

开放的追溯逻辑单元。

用户二次开发的单据及流程，如果需要追溯，通过单据追溯逻辑进行配置即可。

**功能路径**

【质量管理】->【质量追溯】->【单据追溯逻辑】
