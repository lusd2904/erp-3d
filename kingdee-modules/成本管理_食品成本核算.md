====== 1.成本卡替代方案 ======
===== 1.1 功能概述 =====
  * 在生产过程中，由于某种原因，需要使用其它的物料替代某种物料来满足生产的需求，可以通过定义替代方案来实现。替代方案主要用于设置物料之间的替代关系，包括：替代策略、替代方式、用量关系等。

  * 唯一性校验：替代方案中，不允许出现物料编码+辅助属性（影响计划）+BOM版本（影响计划）相同的分录

  * 物料替代是处理替代应用的基础资料。

 
  * 物料替代中，主物料页签设置被替代物料；替代物料页签设置替代物料。
 
 
  * 一个替代方案，只能对一个或者一组主物料设定替代关系。

  * 替代方案可以设置组合替代和非组合替代。
  
 
  * 主物料有且只能有一个替代主料；优先级相同的替代物料，有且只能有一个替代主料。在食品销售清单以及食品报损单生成食品材料耗用单，依据主物料、替代物料的替代主料的供给来判断替代逻辑，非替代主料跟随对应的替代主料成套进行替代或被替代。

===== 1.2 字段说明 =====

| 字段     | 字段说明                                                                |
| 替代编码   | 替代方案的编码                                                             |
| 名称     | 替代方案的名称                                                             |
| 替代策略   | 物料替代的控制策略，包含：混用替代、手工替代、整批替代。                                        |
| 混用替代   | 主物料和替代物料同时作为供给和预计量；供给比例由库存和预计量决定；                                   |
| 手工替代   | 按照用户指定的供给比例，产生需求量；                                                  |
| 整批替代   | 满足同一笔需求时，要么使用主物料，要么使用替代物料。                                          |
| 替代方式   | 物料替代的控制策略，包含：替代和取代；\\ 替代：需求无法满足时，产生主物料的供给；\\ 取代：需求无法满足时，产生替代物料的供给。  |
| 替代主料   | 替代主料的作用：在MPS/MRP计算时，按照替代主料的供给来判定是否产生替代。\\ 优先级相同的替代物料有且只能有一个替代主料。    |
| 优先级    | 被替代物料的优先等级 MRP计算时，物料计算的优先等级；数值越小，优先级越高。                             |
| 物料编码   | 被替代物料的编码被替代物料的物料属性只能为自制类、外购类或委外类物料。                                 |
| 物料名称   | 被替代物料的名称                                                            |
| 规格型号   | 被替代物料的规格型号                                                          |
| 物料属性   | 被替代物料的物料属性                                                          |
| 辅助属性   | 启用辅助属性管理的物料，可设置辅助属性。                                                |
| BOM版本  | 被替代物料的BOM版本                                                         |
| 单位     | 被替代物料的单位                                                            |
| 分子     | 被替代物料的分子                                                            |
| 分母     | 被替代物料的分母                                                            |
| 替代主料   | 替代主料的作用：在MPS/MRP计算时，按照替代主料的供给来判定是否产生替代。主物料有且只能有一个替代主料               |

===== 1.3 业务说明 =====
 
* 单据体分为两块：主物料和替代物料。字段同食品成本卡中的替代设置。主物料中只可有一个主物料，不可选多个。 替代物料中，不可存在优先级同样的物料。   

* 食品成本卡的替代设置时，替代物料增加优先级设置

* 替代方案中，替代物料增加优先级设置

 * 成本卡批量修改中增加优先级批量修改

====== 1.门店收货单成本勾稽 ======
==== 1.1 功能概述 ====

勾稽功能是标准的功能，餐饮接入了门店收货单，勾稽金额取值规则如下：


* 门店收货单的应付单接入钩稽日志


* 门店收货单的应付单根据会计政策---成本政策的选项：成本以含税金额进行核算，勾选选项后，门店收货单的成本以应付单的含税单价进行核算并成本钩稽日志


* 门店收货单金额与应付单金额由差异时，按应付单金额进行成本核算


* 门店收货单对应的发票金额与应付单金额有差异时，按发票金额进行成本核算


* 门店收货单的应付单或发票跨期后,如有差异，则生成入库成本调整单

====== 2.食品成本卡列表 ======
===== 2.1 功能概述 =====

食品成本卡列表会显示所有食品成本卡的单据。除了过滤界面常用的功能外，食品成本卡列表中还有批量替代成本卡物料和成本卡批量修改的功能。


**一、批量替换成本卡物料**

主要用于修改多个成本卡中相同的物料。选择多个成本卡，输入替代前的物料和替代后的物料，点击确定后会把选中的成本卡中匹配的物料进行批量修改。

**二、成本卡批量修改**

在成本卡列表，选择行返回时，则只返回该成本卡的该行信息。如果需要选择整个成本卡，则需要选择整个成本的所有行；在批量修改页面，支持批量填充，在首行某个字段录入数据后，则将该字段的值，批量填充至下面。食品成本卡修改页面，数据来源为成本卡列表中选择的数据；食品成本卡页面可修改字段为“订货、毛料数量、出成率、净料数量，其他字段锁定不可编辑；修改订货字段时，同样控制同一个项次号物料，只可选择一个物料勾选订货字段。设置互斥，勾选另外一个物料时，原勾选的物料自动取消勾选；毛料数量、出成率、净料数量根据设置的计算规则联动计算，根据净料计算毛料数量或者出成率。设置完成后，保存。保存后，同步修改所选择且被修改的成本卡对应字段的值。

====== 1. 食品成本核算======



===== 1.1 食品成本核算概述 =====
食品成本核算是指根据物料的入库成本以及期初余额按照确定的计价方案核算出食品的实际成本的过程。
食品成本核算取前台帐套销售数据时：取销售数量+取消销售但已出品数量，因为这两种属性商品都已消耗原材料。食品成本核算时，支持核算体系下有多个核算组织的核算。
===== 1.2 食品成本核算总体流程图 =====

[图:食品成本核算总体业务流程图.png]

===== 1.3 系统特性 =====
==== 1.3.1 字段说明 ====
| 字段    | 字段说明              |
| 核算体系  | 当前食品成本核算单对应的核算体系  |
| 核算组织  | 当前食品成本核算对应的核算组织   |
| 会计政策  | 当前食品成本核算对应的会计政策   |
| 会计年度  | 当前食品成本核算的会计年度     |
| 会计期间  | 当前食品成本核算的会计期间     |

==== 1.3.2 操作说明 ====


食品成本核算流程：**选择核算组织——选择部门——进行核算——核算结果查看（食品成本核算报告）**.可参考入库成本核算界面。


**1）食品成本核算范围**


选择核算组织，核算单据（食品材料耗用单，简单领料单，报损出库单，其他出库单，盘盈单，盘亏单）；在食品成本核算时先要进行出库成本核算，计算原材料的出库成本后才能核算出食品实际成本。


** 2） 检查结果**


食品成本核算会检测核算期间销售的食品的食品成本卡是否设置，未建立时，提示食品未建立成本卡，是否继续。点击继续时，继续核算；会检测核算期间的食品销售清单是否已经生成食品材料耗用单，如有未生成的，不允许继续核算会检测核算期间的存货核算是否已经进行，未核算时，不允许进行食品成本核算，需核算后方可进行核算；会取食品销售清单为取消单的业务，当食品销售清单为取消单时，食品成本核算的食品销售数量、物料的标准用量都要减掉这部分数据。   


** 3）核算结果查看**

食品成本核算完成后会生成食品成本核算报告。


==== 1.3.3 业务逻辑 ====
  * 取得核算范围下本期食品出品数量（包括销售数量及取消销售出品数量），出品金额，取消损耗数量，取消损耗金额，赠送数量，赠送金额，折扣金额。
  * 计算本期领料及标准用量
  * 根据食品原材料用量分摊材料消耗并计算材料实际成本， 标准成本，及成本差异。
  * 由销售额及成本计算出食品毛利额，毛利率

====== 食品成本核算报告 ======

食品成本核算报告是记录展示食品成本核算产生的结果，供用户查询分析使用。
===== 1.1 功能概述 =====

食品成本核算报告是食品成本核算过程中生成的结果。反应了食品在使用过程中的标准成本和实际成本的数值。用户可以通过食品成本核算报告查看在食品成本核算期间，不同的物料的标准成本和实际成本的差额，实时把控物料在使用过程的成本。

===== 1.2 使用前提 =====


已进行食品成本核算。

===== 1.3 功能路径 =====


【成本管理】->【餐饮成本核算】->【报表分析】->【食品成本核算报告】

===== 1.4 字段说明 =====


|**字段**||**说明**|
|组织机构||食品所属部门对应的组织机构|
|会计年度||食品成本核算报告查询会计年度|
|会计期间||食品成本核算报告查询会计期间|
|部门名称||食品所属出品或销售部门|
|食品大类||食品所属食品大类|
|食品名称||核算范围下食品名称|
|销售数量||食品正常销售的数量，扣减掉取消的数量|
|出品后取消数量||取消原因为出品取消的数量|
|收益金额||折算后的帐单明细实际收入|
|出品单价||销售单价|
|出品数量||销售数量+出品后取消数量|
|出品金额||销售单价*出品数量|
|标准成本单价||食品与其原材料的标准成本，取核算时即时库存明细上的参考单价|
|标准成本金额||标准成本单价*原材料耗用数量（包含口味要求及规格成本）|
|实际成本单价||食品与其原材料的实际成本，根据存货核算算法算出|
|实际成本金额||标准成本单价*原材料耗用数量（包含口味要求及规格成本）|
|实际标准成本比||实际成本与标准成本之比|
|利润额||收益金额-实际成本|

===== 1.5 操作说明 =====


按“核算体系+核算组织+会计政策+会计期间”维度查询。

成本数量=出品数量*规格系数

标准成本计算：数量按成本卡上的单位数量展开，物料的单位成本*物料单位数量*食品的销售份数。

辅料计算：辅料（物料属性中为辅料），如果实际用量比用在主料的标准量少，则按实际/标准比计算作为主料的实际用量，辅料分摊为0。如果实际用量比作为主料的标准多，则主料的实际用量等于标准用量，剩余量作为辅料分摊。按部门、成本数量分摊。


===== 1.6 业务说明 =====


食品成本核算报告应用价值:

1.展示每一食品的标准成本、实际成本及其差异

2.计算出每一食品的利润额及利润率

3.间接统计部门物料耗用成本及部门利润

====== 1.餐饮核算单据查询 ======
===== 1.1 功能概述 =====
核算单据查询将所有参与核算的核算单据按“核算体系+核算组织+会计政策”汇总，以供用户查询各单据的成本。

===== 1.2 字段说明 =====
| 字段         | 字段说明             |
| 异常单据查询     | 如果勾选则显示异常的单据     |
| 出入库是否相差汇总  | 如果勾选则会显示出入库相差汇总  |


===== 1.3 操作说明 =====

  * 支持按“核算体系+核算组织+会计政策”查询核算单据成本，还包括对异常单据的查询，如未审核或单价为0的核算单据； 
  * 若核算单据为未审核状态，可通过工具栏功能按钮“查看单据”调出原单进行审核的操作； 
  * 支持对核算单据成本进行修改：选中核算单据，点击工具栏“成本修改”按钮进行成本修改； 
  * 会计政策支持存货核算按费用项目核算时，可以点击工具栏“费用项目查询”，查看费用项目明细及金额。
