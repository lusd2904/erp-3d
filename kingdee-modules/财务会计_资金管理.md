## 【页面】付款结算单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BB%98%E6%AC%BE%E7%BB%93%E7%AE%97%E5%8D%95

====== 付款结算单 ======

=====1 功能说明 =====
  
记录企业资金总部集中对外付款。可以按结算明细下推付款单或收款退款单。

主要适应于集团总部集中对外付款，不同结算组织或者不同往来单位结算。

=====2 操作前提 =====

1、系统已启用。

2、定义了资金组织、收付组织、结算组织、单据类型、客户/供应商/部门/员工、币别、汇率体系、结算方式、收付款用途、银行、银行账号等基础数据。

3、如果是通过票据类结算方式付款，则还需要先维护了应付票据数据。

=====3 功能路径 =====

【财务会计】—>【资金管理】—>【日常处理】—>【付款结算单】

=====4 字段说明 =====

3、【付款结算单】—>【业务查询】—>【勾对记录】，查询收款结算单对应的银行存款对账勾对记录。

4、【付款结算单】—>【业务查询】—>【应付票据】，查询付款结算单所引用的应付票据。

## 【页面】信贷单

====== 信贷单 ======
=====1 功能说明 =====

信贷单，管理和维护的是收付组织与银行之间的信贷合同的关键信息。 
=====2 使用前提 =====

资金组织以及成员单位出纳管理系统已经启用。 
=====3 字段说明 =====
====3.1 表头字段说明 ====
|**字段**||**说明**|
|单据编号||信贷单单据编号，手工录入或者自动获取。|
|业务日期||信贷单的业务日期，手工录入。|
|银行||借款的银行，F8选择。|
|银行账号||借款入账的银行账号，F8选择。|
|单据状态||信贷单的单据状态，系统自动更新。|
|币别||选择对应的币别信息。|
|借款金额||借款的总金额，手工录入。|
|起始日||借款的起始日期，手工录入。|
|到期日||借款的到期日期，手工录入。|
|利率（%）||借款的利率，手工录入。|
|担保方式||借款的担保方式，手工选择。|
|担保单位||借款的担保单位，F8选择或者手工录入。|
|借款组织||信贷单的主业务组织，手工录入。|
|备注||备注信息，手工录入。|

====3.2 发放信息字段说明 ====
|**字段**||**说明**|
|计划发放日期||计划放款的日期，手工录入。|
|计划发放金额||计划放款的金额，手工录入。|
|实际发放金额||实际放款的金额，系统根据收款单自动反写。| 

====3.3 还款信息字段说明 ====
|**字段**||**说明**|
|计划还款日期||计划还款的日期，手工录入。|
|计划还本金额||计划还本的金额，手工录入。|
|实际还本金额||实际还本的金额，系统根据付款单自动反写。|
|实际还利息金额||实际还利息的金额，系统根据付款单自动反写。| 
====3.4 特殊说明 ====

信贷单记录的是借款组织与银行之间的信贷合同的关键信息，其本身相当于信贷合同，因此信贷单本身不会导致系统资金的实际流转。

=====4 操作说明 =====

 打开【财务会计】－>【资金管理】－>【日常处理】－>【信贷单】功能，管理和维护借款组织的信贷单。
 
 1、信贷单支持下推收款单，处理信贷放款到账的业务。

 2、信贷单支持下推付款单，处理信贷到期还本付息的业务。


 信贷单-收款单

 系统支持通过信贷单发放计划，下推收款单，处理信贷放款到账的业务。
 系统自动根据收款单金额，反写信贷单的实际发放金额信息。

 信贷单-付款单

 系统支持通过信贷单还款计划，下推付款单，处理信贷到期还本或者付息的业务。
 系统自动根据付款单金额，反写信贷单的实际还本或者付息的金额信息。

====== 内部利息单 ======
=====1 功能说明 =====

由资金组织发起内部活期计息，系统自动进行计算，内部活期利息的结果产生内部利息单。
系统自动产生的内部利息单为保存状态，由用户查询确认后提交审核。 
=====2 使用前提 =====

资金组织以及成员单位出纳管理系统已经启用。 
=====3 字段说明 =====
====3.1 表头字段说明 ====
|**字段**||**说明**|
|单据编号||内部利息单单据编号，系统自动获取。|
|业务日期||内部利息单的业务日期，系统自动置为利息计算当天的日期。|
|计息对象编号||计息对象编号，利息计算时指定的计息对象对应的编号。|
|计息对象名称||计息对象名称，利息计算时指定的计息对象对应的名称。|

|币别 ||对应的币别信息。|
|计息区间||利息计算时指定的计息区间。|
|计息天数||利息计算时指定的计息区间包含的天数。|
|断息天数||利息计算时指定的起始日期与上次结息日之间的天数。|
|存款积数||系统自动汇总表体存款积数。|
|本期存款利息||系统自动汇总表体存款利息。|
|透支积数||系统自动汇总表体透支积数。|
|本期透支利息 ||系统自动汇总表体透支利息。|
|免息额 ||指定计息对象的免息额。|
|摘要||系统自动写入。|
|账面余额||系统自动获取内部利息后内部账号的最新余额。|
|资金组织 ||进行内部利息计算的资金组织。|
|收付组织||指定计息对象对应的收付组织。|
|本位币||系统自动获取本位币信息。|
|汇率类型 ||系统默认或者手工修改相应的汇率类型。|

|本期透支利息本位币||本期透支利息对应的本位币金额。|

====3.2 表体字段说明 ====
|**字段**||**说明**|
|利息类型||系统自动标识为存款利息还是透支利息。|
|开始日期||计息区间段的开始日期。|
|结束日期||计息区间段的结束日期。|
|天数||计息区间段的天数。|
|积数||计息区间段的积数。|
|年利率（%）||计息区间段适用的年利率。|
|本期利息||计息区间段对应的利息金额。|

====3.3 特殊说明 ====

  - 由资金组织来执行计算内部活期利息，计息结果产生内部利息单。内部利息单的主业务组织为资金组织，记录各个成员单位的存款利息以及透支利息。
  - 内部利息单审核时，系统会自动根据存款利息产生对应成员单位的收款单（对应的单据类型：内部利息），根据透支利息产生对应成员单位的付款单（对应的单据类型：内部利息）。自动产生的成员单位内部利息类型的收款单和付款单，供成员单据查询内部利息数据，并更新成员单位内部账户余额，登记成员单位内部账户的银行存款日记账。
  - 成员单位的内部利息收款单、付款单，由内部利息单联动控制，只允许成员单位查询，不允许成员单位进行手工增、删、改等维护操作。

=====4 操作说明 =====

打开【财务会计】－>【资金管理】－>【日常处理】－>【内部利息单】功能，查询和确认资金组织的内部利息单，并提交审核。

 审核
  - 内部利息单审核时，如果存款利息不为0，则存款利息会同时产生成员单位的收款单（单据类型：内部利息）。
  - 内部利息单审核时，如果透支利息不为0，则透支利息会同时产生成员单位的付款单（单据类型：内部利息）。
  - 内部利息单审核成功后系统的结果为成员单位的内部账户发生一笔利息收入或者一笔利息支出。
 反审核
内部利息单反审核时，会同时删除成员单位对应的收款单或者付款单（单据类型：内部利息）。

  - 联动支付单审核时，系统会自动逐行产生对应成员单位的收款单（对应的单据类型：资金下拨）和成员单位账号对外的付款单，供成员单据查询资金下拨数据和对外付款数据，并更新成员单位银行账户以及内部账户余额，登记成员单位银行账户以及内部账户的银行存款日记账。

联动支付单审核成功后系统的结果为资金由成员单位的银行账户下拨到资金组织的母账户。

2、反审核

联动支付单反审核时，会同时删除成员单位对应的收款单（单据类型：资金下拨）和成员单位账号对外的付款单。

====== 资金管理 ======
=====1 资金管理系统概述 =====

====1.1 资金管理系统概述 ====
 资金管理系统帮助企业建立资金集中管理和资金集中监控的平台，实现账户集中管控和实时监控，并实现收支两条线的资金管理模式。通过资金收支两条线管理，加强对下属公司资金的监控，盘活企业存量资金，提高资金使用效率和使用效果，并降低资金运作成本和风险，保证资金安全。

====3.1 资金管理系统特性 ====
本系统主要包含以下应用：
===3.1.1 支持结算中心收支两条线资金管理模式 ===

金蝶云资金管理系统，支持结算中心收支两条线资金管理模式，明确划分成员单位收入资金和支出资金的流动，严禁坐支，并实行有效的集中管理，减少现金持有成本，加速资金周转。

成员单位银行账户管理，需要区分收入账户和支出账户，收入账户的资金按时上划到资金组织母账户，而资金组织根据资金计划或者成员单位的请款把资金下拨到成员单位的支出账户，由成员单位对外进行付款结算。

===3.1.2 支持内部活期计息 ====

金蝶云资金管理系统，支持内部活期计息，明细核算各成员单位资金结余收益以及资金占用成本，完全满足企业利润考核需要。

内部活期计息采用积数计息法，其与银行活期存款的计息方法一致。
