====== 1 内部往来协同概述 ======

===== 1.1 内部往来协同概述 ===== 

内部往来协同以往来通知单为载体统一管理企业的内部往来业务，实现对内部往来的通知、沟通、勾稽、核对及控制。

本产品主要实现了一个数据中心下多个组织间的内部往来协同，依赖于总账及多组织特性。
 
===== 1.2 内部往来协同系统总体流程图 =====

内部往来协同系统的业务流程图如下所示：

[图:内部往来协同系统业务流程图.png]
===== 1.3 系统特性 =====

本系统主要包含以下应用：

  - 设置内部往来协同方案；
  - 设置内部往来科目；
  - 内部往来凭证提交或审核后自动发送往来通知单；
  - 接收的往来通知单自动生成凭证并自动勾稽；
  - 接收的往来通知单退回；
  - 往来通知单勾稽（自动及手动勾稽）； 
  - 内部往来核对表； 
  - 总账结账时检查内部往来通知单的勾稽情况。

## 【页面】内部往来协同参数
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%86%85%E9%83%A8%E5%BE%80%E6%9D%A5%E5%8D%8F%E5%90%8C%E5%8F%82%E6%95%B0

内部往来协同参数用来设置通知单发送及勾稽的相关选项。

  * 凭证发送往来通知单时机：可以设置为提交时或者审核时发送通知单，默认是提交时发送；

  * 结账时不检查往来通知单的勾稽情况：勾选后结账时会跳过往来通知单勾稽检查；

  * 勾稽方式：原币勾稽（通知单勾稽时要求原币相同）；原币或本位币勾稽（不同币别的通知单支持根据账簿的本位币进行勾稽）

  * 勾稽规则：勾稽时支持检查通知单的科目、期间、业务日期是否相同。

## 【页面】内部往来协同方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%86%85%E9%83%A8%E5%BE%80%E6%9D%A5%E5%8D%8F%E5%90%8C%E6%96%B9%E6%A1%88

====== 1.功能说明 ======

内部往来协同方案主要用来确定内部往来协同的启用日期及参与往来协同的账簿。

  - 为了保证往来通知单接收方核算组织的唯一性，一个核算体系只允许新增一个内部往来协同方案。
  - 在一个方案中同一个核算组织允许指定一个账簿参与内部往来协同（默认是主账簿参与）。
  - 指定账簿时，新增的核算组织需要手动指定参与往来协同的账簿。
  - 凭证日期大于等于启用日期的凭证才会发送通知单。
  - 已审核且未禁用的内部往来协同方案才会触发内部往来通知单的发送。

**应用场景**

启用内部往来通知并指定往来通知单的启用日期；

指定参与内部往来通知的账簿。

**功能路径**

【财务会计】→【内部往来协同】→【基础资料】→【内部往来协同方案】

## 【页面】内部往来核对表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%86%85%E9%83%A8%E5%BE%80%E6%9D%A5%E6%A0%B8%E5%AF%B9%E8%A1%A8

====== 1.报表功能 ======

内部往来核对表：根据指定的内部往来核对方案直接查询并核对内部各组织间的往来科目余额是否平衡。

**应用场景**

子公司定期核对内部往来科目金额，以便及时发现异常。

集团在出具合并报表前检查各方的内部往来是否已经平衡。


====== 2.过滤条件 ======

在“快捷”页签，设置账簿、会计年度期间以及币别范围等基本过滤条件。其他过滤页签为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。

^ 字段              |^ 说明                           ^
| 本方账簿            || 指定查看的本方账簿（账簿支持多选）。           |
| 对方账簿            || 指定查看的对方账簿（对方账簿为空则查看所有相关账簿）。  |
| 核对方案            || 指定核对表的核对方案。                  |
| 按本方账簿分页显示       || 选中此项，查询结果按本方账簿分页展示。          |
| 仅显示不平衡的对账结果     || 选中此项，查询结账忽略已核对平衡的内部往来数据。     |
| 仅显示对账项目小计       || 选中此项，查询结果不显示科目明细。            |

## 【页面】内部往来科目
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%86%85%E9%83%A8%E5%BE%80%E6%9D%A5%E7%A7%91%E7%9B%AE

====== 1.功能说明 ======

内部往来科目是用来记录内部往来业务的专用科目，通过【内部往来科目】菜单可以查看到所有内部往来科目。

新增或修改内部往来科目可以通过点击【科目列表】菜单打开科目列表进行维护。

**字段说明**

  * 内部往来科目：需要进行内部往来通知或核对的科目必须设置为内部往来科目（建议新增专用科目记录内部往来业务）。
  * 往来核算维度：往来核算维度是用来确定对方组织的核算维度，可以指定为组织机构、客户或者供应商，科目的核算维度必须包含往来核算维度。系统根据往来核算维度的对应组织及会计核算体系来确定内部往来通知单的接收方核算组织。


**功能路径**

【财务会计】→【内部往来协同】→【基础资料】→【内部往来科目】

## 【页面】往来通知单勾稽
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BE%80%E6%9D%A5%E9%80%9A%E7%9F%A5%E5%8D%95%E5%8B%BE%E7%A8%BD

====== 1.功能说明 ======

往来通知单勾稽用来对接收的通知单和发送的通知单进行手工或自动勾稽。

**往来通知单勾稽条件**

（1）对方账簿及币别相同、金额相反且方向相同或金额相同且方向相反。

（2）根据内部往来协同参数中的勾稽规则设置检查科目、期间、业务日期是否相同。

**往来通知单自动勾稽的顺序** 

（1）发送方来自同一凭证的通知单优先勾稽。

（2）发送方的冲销凭证跟被冲销凭证的通知单优先勾稽。

（3）根据接收方及发送方通知单的显示顺序（可以通过过滤界面调整显示顺序）依次勾稽。

**功能路径**

【财务会计】→【内部往来协同】→【日常处理】→【往来通知单勾稽】

对接收的通知单执行退回操作。
