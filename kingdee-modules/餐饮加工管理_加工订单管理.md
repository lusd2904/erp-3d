======1 加工汇报单 ======

=====1.1 功能概述 =====
加工汇报是加工车间在执行加工订单时，对加工情况的实时进度反应。加工任务单汇报用于汇报加工任务的开工和完工时间、加工数量、加工工时、加工质量等数据。


=====1.2 使用前提 =====
对应的加工订单分录需处于开工、完工状态，且未挂起。

=====1.3 功能路径 =====
【餐饮加工管理】－>【加工订单管理】 －>【完工入库】－>【加工汇报单】。


=====1.4 生成方式 =====
  - 加工订单分录下推生成。
  - 加工汇报单新增界面，通过选择加工订单生成。

====== 3 操作说明 ======

====保存==== 

1.只有当加工订单为开工或者完工，加工汇报单才能进行保存操作；

2.加工汇报单保存时，影响对应加工订单的【汇报选单数量】；

3.加工汇报单保存时，进行数量控制检验，需满足条件：累计【合格品汇报数量-返修数量】不能超过入库上限。

====作废 ====

加工汇报单作废时，扣减对应加工订单的【汇报选单数量】。 

====审核/反审核==== 

1.加工汇报单审核、反审核时， 影响对应加工订单的【合格数量】、【不合格数量】、【返修数量】和【报废数量】。

2.只有当加工订单为开工或者完工状态，且无有效下游单据时，加工汇报单才能进行反审核操作。

====倒冲领料==== 

调出加工倒冲领料工作台，查看汇报单对应的倒冲情况及进行倒冲操作。

====== 4 业务说明 ======

====选单==== 

加工汇报单支持通过选择加工订单分录生成。

选单条件：

1.数量控制：加工订单分录的入库上限-汇报选单数量+返修数量>0；

2.组织校验：加工订单表头的【加工组织】必须是加工汇报单表头的【加工组织】；

3.选单分组：【加工组织】相同，不同加工订单中的分录，可以在同一张加工汇报单中进行汇报；

4.选单必录字段：加工汇报单选单前， “加工组织”为必录字段。

====下推 ====

加工订单下推生成加工汇报单时，支持批量下推。

下推条件：

1.数量控制：加工订单分录的入库上限-汇报选单数量+返修数量>0；

2.下推分组：【加工组织】相同，不同加工订单中的分录，可以在同一张加工汇报单中进行汇报。

====在制品扣减==== 

1.在制品扣减时机参数为“汇报时扣减”时，加工汇报单审核时，扣减在制品数量；

2.加工订单中的联副产品的入库数量不影响在制品的扣减。


====新增联副产品==== 

1.支持手工新增汇报单行并录入物料编码、产品类型及加工订单号；

2.手工新增行会反写加工订单，生成相应的联副产品行。

======1 加工用料清单变更单 ======

=====1.1 功能概述 =====
加工订单在执行生产后，需要对生产用到的材料进行调整，对于生产加工过程严格管理的企业，需要管控变更，并保留变更依据、变更原因，通过加工用料清单变更单来实现。

=====1.2 使用前提 =====


加工用料清单对应的加工订单的单据类型勾选了“启用加工用料清单变更”。
加工订单的业务状态为：下达、开关、完工。


=====1.3 功能路径 =====


【餐饮加工管理】－>【加工订单管理】－>【加工订单】－>【加工用料清单变更单】

====== 3 操作说明 ======
====新增==== 

在生产用料清单变更单中先点击【新增】按钮，在子项明细中增加一行，“变更类型”为“新增”，录入需要添加的物料及相关信息，再关联生产用料清单；

====选单、变更 ====

在生产用料清单变更单中先点击【选单】或者【变更】按钮，选择生产用料清单中需要变更的行，每一行生产用料清单，在变更单中自动追加成两行，第一行的变更类型为“变更前”，第二行的变更类型为“变更后”；在“变更后”行中修改需要变更的信息。 

====下推 ====

从生产用料清单下推生产用料清单变更单；每一行生产用料清单，在变更单中自动追加成两行，第一行的变更类型为“变更前”，第二行的变更类型为“变更后”；在“变更后”行中修改需要变更的信息. 
====审核==== 

生产用料清单变更单审核后，执行变更功能，变更生产用料清单。

  * 【变更类型】为“新增”
生产用料清单变更单审核后，在对应生产用料清单的最后一行后追加变更的物料及相关信息；
  * 【变更类型】为“变更后”
生产用料清单变更单审核后，用“变更后”的信息刷新对应的生产用料清单。

生产用料清单变更单变更后，会联动影响生产用料清单中的相关信息。
例如：变更单中修改“分子”，在变更单审核后，首先变更生产用料清单中的“分子”，再按照更新后的“分子”，重新计算生产用料清单中的“已消耗数量”、“在制材料数量”。
====== 4 业务说明 ======

====新增 ====

生产用料清单变更单提供【新增】和【变更】功能；
通过【新增】分录，在已经执行的生产用料清单中增加物料及相关信息；
通过【变更】分录，实现变更生产用料清单中物料信息。

根据生产加工需求，将原有加工订单分录拆分为新的加工订单或委外订单。

=====1.2 应用场景 =====

  - 计划员依据排产情况，由于本组织产能不足，拆分部分订单委托其他组织生产或委外供应商生产。

=====1.3 功能路径 =====
【餐饮加工管理】－>【加工订单管理】－>【加工订单】－>【加工订单拆分】

3 功能操作

拆分前置条件

1. 生产订单未作废；

2. 生产订单分录的业务状态为计划、计划确认、下达、开工，且未挂起；

3. 生产订单分录产品类型为主产品；

4. 生产订单分录 min{【数量】-【已汇报数量】，【数量】-【已入库数量】}>0

拆分处理

1. 根据生成类型，将原生产订单分录，拆分不同的生产订单/委外订单。

生成类型是生产订单，根据拆分明细指定的单据类型、数量、生产车间、生产组织等生成新的生产订单。

生产类型是委外订单，根据拆分明细指定的单据类型、数量、供应商，委外组织等生成新的委外订单。

2. 根据原分录的生产用料清单及拆分数量，生成新生产订的生产用料清单/新委外订单的委外用料清单。

3. 拆分主产品的同时自动拆分联副产品。

4. 可批量拆分，一次性将一张生产订单拆分成多张生产订单或委外订单。
