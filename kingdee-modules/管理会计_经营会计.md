## 【页面】业务单据生成经营流水账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E7%94%9F%E6%88%90%E7%BB%8F%E8%90%A5%E6%B5%81%E6%B0%B4%E8%B4%A6

[[经营会计#日常处理|<<返回经营界面]]



====== 1.功能说明 ======

本功能主要用于业务单据生成经营流水账，并显示执行的结果。

使用前提

业务单据引入方案已设置；
业务单据已审核。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【业务单据生成经营流水账】。
====== 2.字段说明 ======


| **位置**     || **字段**    | **说明**                                                                                                                                       |
| 选择账簿       || 经营账簿        | 选择要生成经营流水账的经营账簿。                                    |
|            || 会计期间      | 选择要生成经营流水的期间。                                        |
|            || 执行方式      | 选择生成经营流水账的方式，可以为覆盖或追加，默认为追加。                                      |
| 选择单据      || 来源方案号      | 选择要生成经营流水账的引入方案。                                         |
|            || 经营单元范围    | 选择要生成经营流水账的经营单元范围。                                                       |
====== 3.操作说明 ======

经营流水账生成结束后将弹出经营流水账生成报告，显示执行的结果；对于生成失败的单据，用户可以根据系统提示的原因进行修改，重新执行经营流水账生成。

## 【页面】多期间分摊方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A4%9A%E6%9C%9F%E9%97%B4%E5%88%86%E6%91%8A%E6%96%B9%E6%A1%88

[[经营会计#内部分摊|<<返回经营界面]]


====== 1.功能说明 ======

企业发生的各种费用，用户根据企业内部管理分摊规则，需要将这些费用分摊到多个不同期间而设置的各期间分摊比例的方案。


**操作前提**

设置经营账簿、经营单元、经营单元分摊标准等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【内部分摊】－>【多期间分摊方案】

====== 2.字段说明 ======
|位置       || 字段         || 说明                                                                            |
| 表头       || 经营账簿       || 设置费用分摊方案适用的经营账簿，经营账簿必须已审核且未被禁用。                                               |
| 表头       || 期间类型      || 目前仅可选会计期间。将按会计期间设置每一期分摊的比例           |
| 分摊期间     || 会计期间      || 设置费用所需要分摊的会计期间。                                                                     |
|  分摊期间     || 分摊比例        || 设置每一期需要分摊的比例                                                    |

====== 3.操作说明 ======
计算比例：点击计算比例，将会按已维护的会计期间自动计算并填写分摊比例平均值。

所有期间比例的总和必须为1.

## 【页面】定时生成经营流水账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AE%9A%E6%97%B6%E7%94%9F%E6%88%90%E7%BB%8F%E8%90%A5%E6%B5%81%E6%B0%B4%E8%B4%A6

[[经营会计#经营流水账来源设置|<<返回经营界面]]



====== 1.功能说明 ======

本功能主要用于业务单据和总账凭证定时生成经营流水账，并显示执行的结果。

使用前提

业务单据引入方案已设置；
总账凭证引入方案已设置；
经营流水账定时生成执行计划已启用。

**功能路径**

【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【定时生成经营流水账】。
====== 2.字段说明 ======


| **位置**     || **字段**    | **说明**                                     |
| 表头基本信息 || 经营账簿        | 选择要生成经营流水账的经营账簿。                 |
|            || 会计期间      | 选择要生成经营流水的期间。                                        |
|            || 执行方式      | 选择生成经营流水账的方式，可以为覆盖或追加，默认为覆盖。          |
|            || 执行时间点      | 设置首次执行时间点，执行成功后自动更新执行时间点。                                        |
|            || 执行间隔单位      | 设置执行间隔单位。                                        |
|            || 执行间隔     | 设置间隔时间。                                        |
| 表体       || 引入业务单据方案     | 选择要自动执行的引入业务单据方案。                   |
|            || 经营单元范围    | 选择要生成经营流水账的经营单元范围。               |
|            || 引入总账科目方案    | 选择要自动执行的引入总账科目方案。               |
====== 3.操作说明 ======

打开【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【定时生成经营流水账】功能，管理和维护定时生成经营流水方案。

定时生成经营流水方案审核成功后，系统将到点自动执行，并产生相应的经营流水账。

====== 1 经营会计概述 ======
===== 1.1 经营会计概述 =====
经营会计是将集团各组织分成小的经营单元，通过与市场直接联系的独立核算制进行运营，培养具有管理意识的领导，让全体员工参与经营管理，从而实现“全员参与”的经营方式。

**经营会计目的**：

  * 用以衡量小经营团队的业绩和贡献，以实现激励员工为目的。

  * 核算规则和制度简单易懂，非专业财务人员也可以掌握。

  * 侧重于不足的分析与改进，更加有利于经营业绩的提升。

===== 1.2 经营会计系统总体流程图 =====

[图:经营会计流程图.png] 


===== 1.3 系统特性 =====

经营会计通俗易懂

  *  经营会计数据采用经营流水账方式录入，操作简单。
   
  * 流水账清晰明了，非财务人员也能看懂。
   
支持多层级经营单元

  * 经营单元来源支持所有基础资料包含：核算组织、业务组织、部门、人员、工序等。
   
  * 经营单元支持设置上下级关系，方便内部抵消处理。
   
数据来源支持多种

  * 支持业务数据生成经营流水账，经营流水账可以联查业务单据，数据更真实可靠。
  
  * 支持总账科目数据生成经营流水账，经营流水账可以联查总账凭证，数据更真实可靠。
  
支持费用分配生成流水账

  * 费用归集及分配

  * 费用归集单支持手工录入和业务单据导入。

  * 支持自动按权重分配到产品和经营单元。

支持内部交易抵消处理
 
支持资金账户收支管理

| 期间类型           || 选择“自然月”，经营会计日历与实际的公历日期一致，一年为4个季度，每个季度包含三个自然月，每个经营期间的日期范围都在实际公历日期所属的自然月内。                                                                                                                   |
| :::            | :::  | 选择“月”，经营会计日历为12个会计期间，一年为4个季度，每个季度三个包含三个月度。用户可自定义每个会计期间的开始日期和结束日期，每个经营期间的日期范围不一定在实际公历日期所属的自然月内。                                                                                             |
| :::            | :::  | 选择“周”，生成经营会计日历时可根据52周、53周或445方式生成。用户可手工修改每周的开始日期。\\ 如果选择52周，则一年为4个季度，每个季度包含13周，一年共52个经营期间，每个经营期间为一周；\\ 如果选择53周，规则同52周，只是最后一周计算到最后一个季度中；\\ 如果选择445方式，则一年为4个季度，每个季度包含3个经营期间，其长度分别是4周、4周和5周。  |
| 开始日期           || 经营会计日历的起始日期，系统根据起始日期设置经营会计日历。                                                                                                                                                                |
| 选择追加的年数        || 用户使用了已审核的经营会计日历之后，还可以在经营会计日历中按照既定规则追加年数。                                                                                                                                                     |
====== 3 功能操作 ======

当用户手工修改经营会计日历的日期导致会计期间前后不连续时，系统自动刷新经营期间的首尾日期，以保证经营期间的前后连续性。

已审核后的经营会计日历不允许修改，但系统提供追加经营会计日历的功能。用户打开已审核的经营会计日历，选择需要追加的年度，然后点击“追加经营期间”，则可自动追加经营期间，经营期间生成的规则同已保存的经营会计日历生成规则一致。


======4 业务说明 ======
第一个经营账簿指定一个经营会计日历。

系统已预设经营会计日历，用户可以修改预设会计日历的名称和内容。

期末结账时，如果经营账簿的会计日历下一个会计期间不存在，系统结账会自动根据当前规则追加下一年的经营会计期间。

====== 经营单元（原阿米巴单元） ======
====== 1.功能说明 ======

企业根据自己的内部管理考核方式，设置经营单元，可以将一个部门、几个部门、一个员工、几个员工等任意基础资料设置为一个经营单元。

**操作前提**

已定义经营账簿、核算体系、会计日历、经营科目、经营组织架构。

**功能路径**

【管理会计】→【经营会计】→【经营组织架构】→【经营单元】

====== 2.字段说明 ======

^ 字段         |^ 说明                                                                                                                    ^
| 编码     || 定义经营单元的编码。                                                                                |
| 名称     || 定义经营单元的名称。                                                                                            |
| 核算体系     || 定义经营单元所属核算体系。                                                                                |
| 核算组织     || 定义经营单元所属核算组织。                                                                                |
| 经营对象类型       || 定义经营单元对应的基础资料类型，可以是部门、员工、组织机构、工序等。                     |
| 经营对象编码       || 定义经营单元对应的具体基础资料，如销售一部、张三等基础资料                                  |
====== 3.操作说明 ======

同一个经营单元不能选择重复相同的基础资料，在保存时会进行校验。
同一个经营单元可以用于不同的组织架构中，也可以在组织架构中变更所属上级利润中心。
已经使用过的经营单元，如需变更，需要使用经营单元变更单进行变更经营对象。

====== 1.功能说明 ======

用户根据经营单元之间的交易、服务录入经营单元内部结算单。

经营单元内部结算单支持生成供货经营单元的收入类经营流水账。

经营单元内部结算单支持生成接收经营单元的支出类经营流水账。

**操作前提**

设置经营账簿、经营单元、物料、费用项目等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【内部交易】－>【经营单元内部结算单】

====== 2.字段说明 ======
^ 字段        |^ 说明                               ^
| 经营账簿      || 设置经营单元内部结算所在经营账簿，经营账簿必须已审核且未被禁用。  |
| 业务日期      || 设置经营单元内部结算的业务日期，该日期是指业务发生日期。      |
| 供货经营单元     || 设置供货或服务输出的经营单元。                 |
| 接收经营单元     || 设置收货或服务接受的经营单元。                 |
| 结算类型      || 结算类型可以选择为物料或服务，默认为物料。            |

| 费用项目      || 当结算类型为服务时，可以录入费用项目。                |
| 金额        || 录入经营单元内部结算的金额。                    |
| 备注        || 录入经营单元内部结算的备注信息。                  |
====== 3.操作说明 ======
经营单元内部结算单录入，支持录入当前期间和以后期间的。

结账后，经营单元内部结算单不允许反审核、删除。

====== 1.功能说明 ======

本功能主要用于经营费用分摊时使用，公摊费用按分摊标准设置的权重进行分摊。

**功能路径**

| **位置**     || **字段**  | **说明**                  |

|            || 接收方类型    | 可选择经营单元或利润中心。  |
|  表体        || 经营单元   | 分摊目标为经营单元时，可选择需要设置权重的经营单元。         |

====== 经营单元变更单（原阿米巴变更单） ======
====== 1.功能说明 ======

由于组织变更、部门调整、员工变动，在企业内部考核的过程中，存在经营单元对应的部门、员工、项目等对象需要变更的应用。用户可以录入经营单元变更单，支持经营单元对应的基础资料进行变更。


**操作前提**

设置经营账簿、经营单元、经营科目等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【经营组织架构】－>【经营单元变更单】

====== 2.字段说明 ======
^ 字段             |^ 说明                                                                                                                                               ^
| 核算体系             || 选择经营单元所属的核算体系。               |
| 备注             || 填写进行经营单元变更的原因备注。                       |
| 经营单元             || 选择需要进行变更的经营单元。                       |
| 变更后经营对象            || 选择经营单元变更后对应的经营对象。                                                     |

====== 3.操作说明 ======
1、按钮【全加】可以将原有的经营对象加入到变更后经营对象中然后进行修改。

2、按钮【加入】可以将所选的经营对象加入到变更后经营对象中然后进行修改。

3、点击经营单元单据头处【执行变更】按钮会自动跳转到经营单元变更单，并自动填充获取原经营单元信息，只需填写变更后经营单元对象即可。

4、经营单元变更单不允许变更前经营对象与变更后经营对象完全相同。

5、经营单元变更单对经营单元进行变更后，变更记录不允许删除，如需变更回变更前的经营单元对象，需要继续做变更单选择原来的经营对象。

## 【页面】经营流水账

[[经营会计#日常处理|<<返回经营界面]]


====== 1.功能说明 ======

用户根据经营单元的收入、支出、费用等业务录入经营流水账。

经营流水账支持手工录入。

经营流水账支持业务单据通过引入方案生成。

经营流水账支持总账科目通过引入方案生成。


**操作前提**

设置经营账簿、经营科目、经营单元等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【经营流水账】

====== 2.字段说明 ======
^ 字段        |^ 说明                                               ^
| 账簿        || 设置经营流水账所在经营账簿，经营账簿必须已审核且未被禁用。                    |
| 组织架构        || 根据录入的日期自动获取该期间的组织架构名称。                    |
| 日期        || 设置经营流水账日期，该日期是指业务发生日期。系统不允许录入账簿已结账期间内的日期作为凭证日期。  |

| 备注        || 录入凭证分录的备注信息，可从基础资料摘要库中选择，也可手工录入。                 |

====== 经营科目初始化录入（原阿米巴初始化录入） ======
====== 1.功能说明 ======

经营科目初始化录入分两种情况进行处理：

第一种是经营账簿的启用时间是会计日历所在会计年度的第一个期间，只需录入资产负债类经营科目的初始余额。

**功能路径**

【管理会计】→【经营会计】→【初始化/结账】→【经营科目初始化录入】

====== 2.字段说明 ======

^ 字段         |^ 说明                                       ^
| 经营账簿       || 选择需要录入初始数据的经营账簿。                         |
| 币别         || 根据经营账薄自动携带出来，不可以选择。                      |

====== 4.其他说明 ======

初始数据录入工作可以和日常单据录入工作同时进行，只要在期末处理前关闭初始化即可。

====== 经营组织架构 ======
====== 1.功能说明 ======

企业根据自己的经营考核规则，设置经营组织架构，根据企业实际的经营单元考核层级关系，定义经营组织架构的上级经营单元及其下的经营单元。

**操作前提**

已定义经营账簿、核算体系、会计日历、经营科目。

**功能路径**

【管理会计】→【经营会计】→【经营组织架构】→【经营组织架构】

====== 2.字段说明 ======

^ 字段         |^ 说明                                                                                                                    ^
| 经营账薄       || 定义经营组织架构的核算体系、经营会计日历、经营科目。                                                                                  |
| 经营单元编码     || 选择经营单元编码。                                                                                |
| 经营单元名称     || 自动填充经营单元名称。                                                                                            |
| 经营单元对象类型       || 展示经营单元对应的基础资料类型，可以是部门、员工、组织机构、工序等。                     |
| 经营单元对象名称       || 展示单元对应的具体基础资料，如销售一部、张三等基础资料                                  |
| 启用状态       || 展示该经营组织架构是否启用中，如需反启用，点击表头反启用按钮即可。                                  |
| 启用期间       || 展示该经营组织架构版本启用的期间。一个期间只能存在一个组织架构版本                                  |
| 截止期间       || 展示该经营组织架构版本截止期间。截止期间根据下一个组织架构版本的启用期间自动获取                                  |
====== 3.操作说明 ======

一个经营账簿可以新增多个经营组织架构，组织架构版本会自动获取，同一个期间只能存在一个经营组织架构版本。

上级利润中心不允许有具体的经营单元。

===== 3.1经营组织架构变更 =====

点击【调整】按钮，可调整利润层级。
1、可选的上级利润中心为相同核算组织下的利润中心。排除了存在经营单元的底层利润中心和自己的下级利润中心。	
2、一级利润中心不可调整至其他利润中心。
3、调整后利润中心的下级利润中心以及对应的经营单元会一并携带过去。

点击【删除】--》【删除当前层级】
1、只删除选择的层级，下级层级不删除。
2、删除的层级为底层层级且存在经营单元时，会将对应的经营单元也一起从组织架构中移除。
3、如为第一层级不能只删除当前层级。

点击【删除】--》【删除全部】
将该层级以及下级利润中心和经营单元都删除。

选择经营单元，点击【变更所属利润中心】
可将该经营单元调整至其他利润中心下，可选目标利润中心范围为：不存在下级利润中心的底层利润中心，且在同一核算组织内。

## 【页面】结束初始化

系统还提供了反初始化的功能，当需要维护或修改结束初始化前的相关资料（如经营科目初始化录入）时，可以进行反初始化，将经营账薄还原到未初始化状态。

  * 选择需要进行反初始化工作的经营账簿，点击反初始化菜单，系统首先会检查经营账簿是否符合反初始化的条件，检查通过后，经营账簿则会返回到未初始化状态。

[[经营会计#日常处理|<<返回经营界面]]


====== 1.功能说明 ======

由于组织变更、部门调整、员工变动，在阿米巴经营考核的过程中，存在阿米巴单元对应的部门、员工、项目等对象需要变更的应用。用户可以录入阿米巴变更单，支持阿米巴对应的基础资料进行变更。


**操作前提**

设置经营账簿、阿米巴单元、经营科目等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【阿米巴变更单】

====== 2.字段说明 ======
^ 字段             |^ 说明                                                                                                                                               ^
| 经营账簿             || 设置阿米巴变更单所在经营账簿，经营账簿必须已审核且未被禁用。               |

| 阿米巴对象（变更前）            || 阿米巴单元变更前对应的阿米巴对象。                                                     |

====== 3.操作说明 ======
阿米巴变更单不允许阿米巴对象（变更前）与阿米巴对象（变更后）完全相同。
阿米巴变更单对同一个阿米巴多次变更后，阿米巴变更记录不允许删除，需要做变更单变回原来的阿米巴。
备注：该功能由V7.3提供。

本功能主要用于总账凭证生成经营流水账，公摊费用按设置的权重进行分摊。

**功能路径**

【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【阿米巴自定义分配标准】。
====== 2.字段说明 ======

| **位置**     || **字段**  | **说明**                  |
| 表头基本信息     || 经营账簿    | 选择需要定义分配标准的经营账簿。        |
|            || 分摊规则    | 可选择按固定权重分摊或者自定义分摊规则分摊。  |
|  表体        || 阿米巴单元   | 选择需要设置权重的阿米巴单元。         |
|            || 权重值     | 录入权重值。                  |

====== 3.操作说明 ======

打开【管理会计】－>【经营会计】－>【经营流水账来源设置】－>【阿米巴自定义分配标准】功能，管理和维护定阿米巴自定义分配标准。

## 【页面】阿米巴计划单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%98%BF%E7%B1%B3%E5%B7%B4%E8%AE%A1%E5%88%92%E5%8D%95

[[经营会计#日常处理|<<返回经营界面]]


====== 1.功能说明 ======

用户根据企业经营预算与计划，可以录入阿米巴计划单，根据录入的计划与实际发生金额进行比较、考核。


**操作前提**

设置经营账簿、阿米巴单元、经营科目等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【阿米巴计划单】

====== 2.字段说明 ======
^ 字段        |^ 说明                                ^
| 经营账簿      || 设置阿米巴费用归集单所在经营账簿，经营账簿必须已审核且未被禁用。  |
| 期间        || 设置阿米巴计划单的业务期间。                    |
| 阿米巴单元     || 设置阿米巴计划单的阿米巴单元。                   |
| 经营科目      || 设置阿米巴预算与计划的经营科目。                  |
| 计划金额      || 设置阿米巴预算与计划的计划金额。                  |
====== 3.操作说明 ======
支持录入当前期间和以后期间的。

## 【页面】阿米巴费用分配结果单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%98%BF%E7%B1%B3%E5%B7%B4%E8%B4%B9%E7%94%A8%E5%88%86%E9%85%8D%E7%BB%93%E6%9E%9C%E5%8D%95

[[经营会计#日常处理|<<返回经营界面]]


====== 1.功能说明 ======

用户根据企业发生的各种费用单据、总账费用科目归集生成阿米巴费用归集单，可以按阿米巴自定义分配标准生成阿米巴费用分配结果单。

**操作前提**

设置经营账簿、阿米巴单元、阿米巴费用归集单、阿米巴自定义分配标准等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【阿米巴费用分配结果单】

====== 2.字段说明 ======
^ 字段             |^ 说明                                                                                                                                               ^
| 经营账簿             || 设置阿米巴费用分配结果单所在经营账簿，经营账簿必须已审核且未被禁用。                       |
| 业务期间             || 设置阿米巴费用分配结果单的业务期间。                       |
| 费用承担对象             || 设置阿米巴费用归集单费用承担对象。                       |
| 费用项目           || 阿米巴费用分配结果单的费用项目。                 |
| 金额      || 阿米巴费用分配结果单的费用金额。                                                                    |
| 权重值      || 阿米巴费用分配对应的权重值。                                            |
| 总权重      || 阿米巴费用分配对应的总权重。                                            |
| 分配标准      || 阿米巴费用分配结果单对应的阿米巴自定义分配标准。                               |
| 阿米巴单元      || 阿米巴费用分配对应的阿米巴单元。                                            |
| 日期      || 阿米巴费用发生的业务日期。                                            |
====== 3.操作说明 ======
阿米巴费用分配结果单为费用分配时自动生成的。

## 【页面】阿米巴费用归集单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%98%BF%E7%B1%B3%E5%B7%B4%E8%B4%B9%E7%94%A8%E5%BD%92%E9%9B%86%E5%8D%95

[[经营会计#日常处理|<<返回经营界面]]


====== 1.功能说明 ======

用户根据企业发生的各种费用，生成阿米巴费用归集单。

阿米巴费用归集单支持手工录入、业务单据引入、总账科目引入自动生成。

阿米巴费用归集单支持按阿米巴自定义分配标准生成阿米巴费用分配结果单。

**操作前提**

设置经营账簿、阿米巴单元、阿米巴自定义分配标准等基础信息。

**功能路径**

【管理会计】－>【经营会计】－>【日常处理】－>【阿米巴费用归集单】

====== 2.字段说明 ======
^ 字段         |^ 说明                                ^
| 经营账簿       || 设置阿米巴费用归集单所在经营账簿，经营账簿必须已审核且未被禁用。  |
| 费用承担类型     || 设置阿米巴费用归集单费用承担对象类型。               |
| 费用承担对象     || 设置阿米巴费用归集单费用承担对象。                 |
| 费用录入方式     || 可选择按费用项目或经营科目录入费用。                |
| 日期         || 设置阿米巴费用归集单的业务日期，该日期是指业务发生日期。      |
| 费用项目       || 支持手工录入费用项目。                       |
| 金额         || 录入阿米巴发生的费用金额。                     |
====== 3.操作说明 ======
阿米巴费用归集单录入，支持录入当前期间和以后期间的。

结账后，阿米巴费用归集单不允许反审核、删除。
