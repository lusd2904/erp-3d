## 【页面】个人任务排名表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E4%BA%BA%E4%BB%BB%E5%8A%A1%E6%8E%92%E5%90%8D%E8%A1%A8

====== 个人任务排名表 ======

===== 1.1报表功能 =====
用来查询共享服务中心业务员处理任务的数量和效率的综合评分报表。

===== 1.2过滤条件 =====

快捷条件：
  * 共享中心：选择要统计的共享中心，可多选；
  * 流程模板：选择要统计的流程模板，可多选；
  * 开始时间：选择统计开始日期，必录；
  * 结束时间：选择统计结束日期，必录；
  * 取名次：默认取前10名，可自定义输入；

=====1.3字段说明 =====

  * 处理人：显示共享服务中心处理任务的用户；
  * 完成任务数：处理人所处理的任务总数；
  * 效率（单/小时）:每小时处理人所处理的任务数；
  * 综合得分：【参数设置】-共享服务中心目录下默认任务量占70%，效率占30%，也可自定义其他比例，这样综合得分为：任务数*70%+效率*30%；
  * 个人排名：综合得分高的排在第一名，以此类推进行排名；

共享服务中心，通过流程设计、任务分配规则的配置，可以实现为企业内部各业务单位及外部企业提供专业化的共享服务。可以将企业各业务单位“分散式”进行的某些重复性业务整合到共享服务中心进行统一处理。

====== 普通消息 ======
[[信息中心|返回信息中心]]

1.功能概述

在信息中心可以发消息给系统的其他用户，这样方便产品用户之间的沟通，在单据上加了发消息操作，当该操作被触发时，也会发普通消息。

2.字段说明

  * 发送人：发送消息的用户信息；
  * 状态：有已读、未读两种状态，可以通过菜单【标为已读】、【标为未读】来改变消息的状态值，当收到一条消息后，点【查看消息】菜单查看消息后，消息状态也会刷新为已读。
  * 单据：如果发消息的动作有单据上的操作来触发，这里会显示消息来源的单据；
  * 主题：显示消息的主题；
3.操作说明

  * 新建消息：可以新建一个消息进行发送；
  * 回复消息：选择一条消息，点击回复消息，进行回复，消息接收人默认为发送人；
  * 转发消息：选择一条消息，转发给其他人；
  * 查看单据：选择一条消息，点查看单据，查看和消息关联的单据信息；
====== 流程消息 ======

1.功能概述

流程消息是在流程的运行过程中发送的消息，流程中的消息节点和流程节点设置中的超时提醒功能都会触发发送流程消息。

2.字段说明

  * 发送人：发送消息的用户信息；流程中的消息节点发送人可以是administrator或者上一步处理人；
  * 状态：有已读、未读两种状态，可以通过菜单【标为已读】、【标为未读】来改变消息的状态值，当收到一条消息后，点【查看消息】菜单查看消息后，消息状态也会刷新为已读。
  * 单据：流程所关联的单据信息；
  * 主题：显示消息的主题；主题显示内容可以在消息节点上配置，或者在流程节点上配置。

====== 分配策略 ======
概述：

分配策略决定了任务是按什么样的频率、什么样的策略分配到共享任务中心。

操作说明：

【共享服务中心】-【任务共享中心】-【分配策略】，在分配策略列表界面点击【新增】，新增分配策略。

字段说明：
  - 共享中心：具有共享中心职能的组织；
  - 共享中心分类：所选共享中心的类别，在辅助资料中维护；例如可以设置HR共享、财务共享等；
  - 共享中心职责：所选共享中心类别的职能，在辅助资料中维护，例如：财务共享中心的票据核对职责、对账职责等；
  - 普通任务时限：默认24小时以内处理，任务到达处理人的待办任务列表中开始倒计时，24小时候未处理的是否超时记为超时；
  - 加急任务时限：默认4小时以内处理，任务到达处理人的待办任务列表中开始倒计时，4小时候未处理的是否超时记为超时；
  - 分配模式：
    - 抢单模式：分配策略默认为抢单模式，所有符合条件的任务全部发送到符合分配规则的业务员的待办任务列表中，待办任务被打开处理时其他用户看到任务为锁定状态，任务处理完后在待办任务列表中消失；
    - 均衡模式：分为按时分配和按数量分配，按时分配默认按每隔1小时分配一次；按数量分配则是按任务累积的数量进行分配，默认累积10个分配一次；例如累积10个分配一次，符合的处理人有3个，则第一处理人会收到4个待办任务、第二、三个处理人会收到3条待办任务；先依次均衡分配，剩余的任务再从新分，所以第一个处理人会收到的多一个任务；
    - 智能分配：智能分配是按均衡分配的基础上，会优先考虑当前任务少的用户进行先分配，作到分配完成后每个业务员手里的任务的均衡性。
  - 单据类型：设置分配策略只使用与某些单据类型，如果不设置单据类型，则分配策略适合所有的单据类型。

====== 分配规则 ======

分配规则决定了进入共享任务中心的任务是按什么样的规则找到处理人。
字段说明：
  - 共享中心：具有共享中心职能的组织；
  - 共享中心分类：所选共享中心的类别，在辅助资料中维护；例如可以设置HR共享、财务共享等；
  - 共享中心职责：所选共享中心类别的职能，在辅助资料中维护，例如：财务共享中心的票据核对职责、对账职责等；
  - 单据类型：设置分配规则适用于的单据类型，如果不设置则该分配规则适用于所有业务单据类型；
  - 条件：设置规则的条件，对应的共享中心的任务处理人，当共享任务符合此处的条件时，任务就会发送给任务处理人；设置多个条件时，系统会逐个解析，直到解析到符合的条件为止。

## 【页面】待办任务
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BE%85%E5%8A%9E%E4%BB%BB%E5%8A%A1

====== 待办任务 ======
===== 1.功能概述 =====
【共享服务中心】-【任务共享中心】-【待办任务】节点下显示了工作流、审批流运行时有共享服务节点产生的待处理任务，通过处理这些任务即可完成审批事项。
===== 2.操作步骤 =====
  * 方法一：进入【共享服务中心】-【任务共享中心】-【待办任务】，选择要处理的任务点击【处理】； 
  * 方法二：若单据关联流程实例，支持在单据或者列表中，通过点击相关操作，如：审核，对实例产生的任务进行处理。
===== 3.字段说明 =====
 
  * 主题：待处理任务的主题，数据来源于流程节点审批动作中设置的标题。
  * 优先级： 分为普通和加急，有共享服务中心管理在我管理的任务中进行设置；
  * 接收时间：记录当前用户收到待处理任务的时间。 
  * 任务状态：【待处理】【已处理】【未分配】【需手工分配】【挂起】【重扫影像】
  - 【待处理】状态：待办任务已经找到处理人，还未被处理；
  -  【已处理】状态：任务已被处理，显示在已办任务列表下；
  -  【未分配】状态：待办任务未找到准确的处理人，显示在待分配任务列表下；
  -  【需手工分配】状态：共享服务中心未设置分配策略和分配规则，任务需要手工分配才能找到处理人。
  -  【暂挂】状态：待办任务列表中选择任务点击暂挂按钮，可以将任务暂挂，暂挂的任务不能处理，其他处理人也无法处理，取消暂挂后才可以处理；
  -  【重扫影像】状态：待办任务列表，查看影像，在查看影像界面选择了影像重扫后，待办任务列表中的任务状态会变为重扫影像状态；

  * 是否超时：超过了分配策略中设置的任务时限后，待办任务未被处理，则显示超时；
  * 剩余时间：在分配策略中设置，默认普通任务时限24小时，加急任务时限4小时，从任务到达待办任务列表开始倒计时。
  * 单据：待办任务关联的单据名称
  * 单据摘要：列示流程设计时流程设置中设计的单据摘要的信息
  * 流程实例编码：列示产生待处理任务的流程实例编码
  * 锁定者：抢单模式的分配规则，待办任务被一个用户打开处理，其他用户在待办任务列表中可以看到锁定者的值为任务处理用户名称
  * 共享中心：任务所属的共享中心名称
  * 职责：任务所在共享中心的职责
 ===== 4.操作说明 =====
    * 处理：选择待办任务，点击处理按钮，进行任务处理；
  *   查看单据：选择待办任务，点击查看单据按钮，查看任务关联的单据信息；
  *   查看影像：选择待办任务，点击查看影像按钮，查看单据上关联的影像；
  *   查看流程图：查看所选任务的流程图；
  *   暂挂：可以将选择任务进行暂时挂起和取消暂时挂起；
其他操作可参看信息中心的[[信息中心_待办任务|待处理任务]]中的操作说明

## 【页面】批退原因统计表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%89%B9%E9%80%80%E5%8E%9F%E5%9B%A0%E7%BB%9F%E8%AE%A1%E8%A1%A8

====== 批退原因统计表 ======
===== 1.1报表功能 =====
统计共享服务中心任务处理时选择驳回审批项，且选择驳回意见时，以批退原因为主要维度的报表。

===== 1.2过滤条件 =====

快捷条件：
  * 共享中心：选择要统计的共享中心，可多选；
  * 流程模板：选择要统计的流程模板，可多选；
  * 处理人：选择要统计的处理人名称，可多选；
  * 开始时间：选择统计开始日期，必录；
  * 结束时间：选择统计结束日期，必录；

排序字段：
  * 选择统计报表的排序字段，支持按共享中心、流程模板、处理人、批退原因进行升、降排序；


=====1.3字段说明 =====

  * 共享中心：报表中流程模板所属的共享中心；
  * 流程模板：显示统计的流程模板名称；
  * 处理人：显示共享服务中心处理任务的用户；
  * 任务总数：按流程模板统计，已处理的任务总数，包括审核同意、驳回、终止的任务；
  * 批退总数：按流程模板统计，选择驳回审批项的任务总数；
  * 批退率：批退总数/任务总数
  * 批量原因：显示选择驳回审批项时，快捷选择意见，在【工作流】-【流程设计】-【审批意见管理】中维护快捷审批意见
  * 批退数量：按不同的原因和流程模板统计数量；
  * 占比：批退数量/批退总数；

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%87%AA%E5%8A%A8%E5%88%86%E9%85%8D%E6%97%A5%E5%BF%97

====== 自动分配日志 ======
用来记录共享服务中心任务分配成功和不成功的日志，任务分配成功的日志记录了使用的分配规则和分配策略。

  * 采用的分配策略：显示使用的分配策略名称；如不设置分配策略，使用保底的策略每隔1小时分配一次或者任务数量达到10个分配一次，则此处的分配策略为空；
  * 分配时间：任务分配到任务池的时间；
  * 分配任务数量：分配的任务数量；
  * 采用的分配规则：分配时使用的分配规则；
  * 详细描述：分配成功时显示：分配成功，使用的条件；分配不成功时显示原因；
