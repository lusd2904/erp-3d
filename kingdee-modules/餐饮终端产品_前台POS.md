## 【页面】2.3.1_点菜

====== 点菜 ======
===== 功能简介 =====

根据食品的大类、组进行点菜以及对菜品的口味和顾客位置的设置。 

===== 操作说明 =====

^按钮    ^说明                                                          ^
| +   | 点击【+】按钮，增加食品的份数。                                         |
| -   | 点击【-】按钮，减少食品的份数。                                         |
| 取消    | 点击【取消】按钮，取消所有已点的食品。                                      |
| 清除    | 点击【清除】按钮，清除当前所选的食品或口味、要求。                                |
| 口味    | 选择所点的食品，点击【口味】按钮，选择口味，可以给食品添加口味。                         |
| 要求    | 选择所点的食品，点击【要求】按钮，显示要求信息，选择所需的要求，给食品添加要求。                 |
| 食品单位  | 选择所点的食品，若有设置好食品单位则点击后会出现红色色块，显示相应设置好的食品单位。               |
| 位置    | 点击【位置】按钮，可以所选的食品，增加位置信息。                                 |
| 先送    | 选择所要先送的食品，点击【先送】按钮，所选食品变成红色。先送成功。                        |
| 数量    | 选择所要增加数量的食品，点击【数量】按钮，弹出“食品数量”框，输入数量，点击【确定】按钮，为食品增加份数成功。  |
| 查看    | 点击【查看】按钮，可以查看所点的所有食品。                                    |
| 送单    | 点击【送单】按钮，传菜至相应部门。                                        |

## 【页面】2.3.2_取消

====== 取消 ======
===== 功能简介 =====

对所点的菜应顾客的要求，可以退回或其他原因取消以及对食品数量和价格的更改，取消的菜品会以红色字体显示在列表最后一行。 

===== 操作说明 =====

^按钮    ^说明                                                          ^
| 取消 | 选择所需取消的食品，点击【取消】按钮，如果食品数量大于1，则弹出“取消食品数量”框，输入数量，进入取消界面，选择不同的取消原因按钮，即取消成功。生成一条红色的对冲记录。                                         |
| 招待  | 选择食品，点击【招待】按钮。如果此食品不可招待，则弹出提示框。                                         |
| 改数量    | 选择食品，点击【改数量】按钮。如果此食品不可改数量，则弹出提示框。                                      |
| 改价钱    | 选择食品，点击【改价钱】按钮。如果此食品不可改价钱，则弹出提示框。                                |

====== 折扣 ======
===== 功能简介 =====

根据公司的营销策略，为顾客打折。 

===== 操作说明 =====

^按钮    ^说明                                                          ^
| 全单折 | 帐单的折扣率，应付金额=食品总价*全单折。                                         |
| 折扣率  | 按百分比给顾客打折，应付金额=食品总价*（1-折扣率）。                                         |
| 折扣价    | 给顾客一打折数，应付金额=食品总价-折扣价。                                      |
| 服务费    | 根据要求收取或不收服务费情况。                                |
| 会员    | 根据不同的会员的折扣率给予不同的优惠。                                      |
| 大类折扣    | 大类折扣是指按其大类、分部门进行打折。注：该员工要有相应部门的最大打折率。                                |

====== 厨房 ======

===== 操作说明 =====

^按钮    ^说明                                                          ^

====== 账单 ======
====== 1.分单 ======
===== 功能简介 =====

是指将此房台转至另一房台，其相应的消费情况也转至过去。如转入的房台为已开房台，可进行并台。

===== 操作说明 =====

^ 按钮  ^ 说明                                             ^
| 1   | 点击【1】按钮，表示一次传送一份食品。确认后点击【完成】按钮，分单成功。           |
| 数量  | 点击【数量】按钮，表示直接输入传送菜品的份数。确认后点击【完成】按钮，分单成功。       |
| 一项  | 点击【一项】按钮，表示此项菜品不论多少份数全部传送过去。确认后点击【完成】按钮，分单成功。  |

====== 2.复制 ======
===== 功能简介 =====

复制是把一个房台的菜复制到另一个房台。						

===== 操作说明 =====

^ 按钮  ^ 说明  ^
|一项 |点击【一项】按钮，表示此项菜品不论多少份数全部复制过去。确认后点击【送单】按钮。传送成功。 |
|全部 |点击【全部】按钮，表示将所选台的所有食品都复制到另一房台。确认后点击【送单】按钮。传送成功。 |
|修改 |选择另一房台的某项菜品，点击【修改】按钮，输入数量，点击【确定】按钮，数量修改成功。确认后点击【送单】按钮。传送成功。 |
|全修改 |点击【全修改】按钮，输入数量，点击【确定】按钮，将另一房台的所有菜品数量修改为输入值。确认后点击【送单】按钮。传送成功。 |
|取消 |点击【取消】按钮，取消另一房台的所选的某项菜品。 |
|全取消 |点击【全取消】按钮，取消另一房台的所有菜品。 |

====== 数据交换下载 ======
====== 1.功能简介 ======

下载总部的餐饮基础资料，包括基础设置、食品资料、房台资料、会员关系管理。

〖综合服务〗→〖数据交换-客户端〗→〖下载〗

前提门店的后台中的营业设置成功通过连锁认证

====== 2.操作详解 ======

  * 连接配置：客户端在分店使用，只需设置连接配置的总部服务器IP与端口
  * 任务设置：调整对应数据的交换设置，如数据任务的名称、发生的频率、持续时间等
  * 启动：启动所有勾选数据的上传与下载
  * 停止：关闭所有勾选数据的上传与下载
  * 启动调度：右键左侧树形对应数据，表示此资料可以下载
  * 关闭调度：右键左侧树形对应数据，表示此资料关闭下载

====== 4.出品监控 ======

===== 4.1 出品监控界面 =====

**功能简介**：反映已开房台的综合出菜情况。

状态说明：

  * 蓝色图标：该房台有菜品未上。
  * 橙色图标：该房台所有菜品已上或没有菜品要上。				

**操作详解**：

在<已开房台信息>点击某一房台，就可以在<未上菜>和<已上菜>看到菜品是否已上的情况。最下面<房台类型栏>可以过滤相应类型的房台。

===== 4.2 未上菜信息 =====

**功能简介**：查询某房台有哪些菜未上。
		
**操作详解**：

点击<未上菜信>中的菜品，出现黄色操作菜单。如图4-3-1所示。
^按钮 ^字段 ^
|全上菜 |点击【全上菜】按钮，按菜品的所有分量全上，同时该菜品变为已上状态出现在<已上菜信息栏>。`|
|分量上 |点击【分量上】按钮，弹出“输数量”窗口中输入数量，且数量不能大于总数量，点击【OK】按钮，该菜品对应输入数量会显示在<已上菜信息栏>。 |
|催菜 |点击【催菜】按钮，催菜成功。 |
|暂停 |点击【暂停】按钮，停止该菜品的销售，同时该菜会变成红色。 |
|恢复 |点击【恢复】按钮，恢复改菜品的销售。 |
|返回 |点击【返回】按钮，退出操作。 |

|暂停 |点击【催菜】按钮，停止该菜品的销售，同时该菜会变成红色。 |

======附录A 术语说明 ======

叫  起：  表示为先准备，暂时不做这项菜。

全叫起：  表示暂时不做所有的菜。

来  得：  为菜的状态，表示先前叫起的菜，可以送上来了。

全来得：  表示客人所点的所有菜现在可以送上来了。

免  做：  厨房已出品的，不用再做，补单操作。

全免做：  表示所有菜都是做好的，都不用再做了。

外  卖：  带走的食品。

招  待：  免费为客人所提供的。

出品沽清： 在销售完该项食品后，会显示沽清状态。

追  单：   催促厨房快上某一样菜。

整单加快： 催促厨房快上所点的全部菜。

折  扣：  为客人打折，其中有折扣率、折扣价、服务费、会员卡、大类折扣几种不同的打折类型。

大类折扣： 分大类进行打折，即部分折扣。

更  次：  表示今天是第几班。

客  付：  客人实付金额。

总  价：  客人应付金额。

小  账：  结余，客付-总价=小账。

消  单：  取消账单。① 对已付款的账单作消单处理；② 对末付款账单进行消单。

扣  炖：  表示限量供应的食品，如10/20 ，10表示还剩多少份，20表示总供应数。

找  赎：  应找给客人的金额数。

埋  脚：  表示确定付款方式并已付款，并打印出确认收款单。

时  价：  表示根据每天来货价定价。

价  钱1、2、3 ：表示不同时段的价格，可分为三个不同时段的价钱。

转  更：  表示交接班次。

清  机：  营业结束，把账单列表清空，并打印出当天营业报表。

====== 附录B 基本印单含义 ======


  * 当客人在点菜送单后，分别会在厨房、传菜部打印出总单，在相应档口打印出出品单。

**总  单**：

在印单上会有“总单”二字，在左上角会显示部门名称（如：中厨、传菜），右上角显示所属楼层，“101（8人）”表示是101房台有8位客人，“10—小王”表示10号印机，操作员小王操作，“10.10 12:00”表示当时点菜的日期：10月10日和时间：12点钟，以下便是所点菜的列表，前面的数字为所点菜的份数，其次是菜名，后面为菜价。

如对菜有要求、口味的选择，在菜名下面会打印出来。

若某菜是可免做或外卖的，在菜名下面也会打印出来。

**出品单**：

应所点的菜在各个不同的档口会打出“出品单”，印单上会有“出品单”三个字，以下部分与总单类似，也有房号、操作员名、时间，但只是一种菜出一张单，所以一张出品单上只会显示一种菜。

如对此菜有要求、口味的选择，在菜名下面会打印出来。

若此菜是可免做或外卖的，在菜名下面也会打印出来。

  * 若客人因某原因要取消某菜，分别在传菜部门打印出取消总单，在相应档口打印出取消单。

**取消总单**：

在印单上会有“取消总单”四字，左上角会有部门名称（如：中厨），右上角显示所属楼层，在“取消总单”下会有取消原因（如“出品沽清”），“101（8人）”表示是101房台有8位客人， “11—小王”表示11号印机，操作员工小王操作，“10、10  12：00”表示取消的日期：10月10日和时间：12点钟，下面即是所取消的菜，“-1”表示取消的份数，其后是菜名。

**取 消 单**：

在印单上会有“取消单”三个字，其它与取消总单类似，只是在房台号下会显示“—小王    --取消   12：00”表示操作员工小王在12点取消此菜，“11—小王  10、10  10：00”表示是11号印机，操作员工小王在10月10日10：00点此菜。

**分  单**：

此单分别会在厨房部和传菜部打印出来。在印单上会有“分单”两字，“101->102”表示是由101房台的菜转至102房台，以下是操作员工、日期、时间和转到102房台去的菜。

**转房单**：

客人要求转房，分别会在各部门和档口打印出转房单。在印单上会有“转房单”三字，“102”表示转至到102房，“11—小王”表示11号印机，操作员工小王操作，“10.10    13:00”表示转房日期：10月10日和时间：13点钟，“101==>102”表示是从101房台转至102房台。

  * 一些要求单：

**叫 起**：

分别在厨房和传菜部打印出“叫起总单”，在相应档口打印出“叫起单”。

**叫起总单**：

表示印单上的菜暂时不做。在印单上显示“叫起总单”四字，在左上角显示部门名称，右上角显示所属楼层，以下就是房台号、客人数和操作员工、操作日期和时间以及所叫起的菜。

**叫起单**：

表示暂时不做印单上的这项菜。在印单上会有“叫起单”三字，以下是房台号、客人数。“—小王  --叫起   11：30”表示是操作员工小王在11：30叫起此菜，下面的时间表示点此菜的时间，以下便是所叫起的菜。

**全叫起**：

表示客人所点的所有菜可暂时不做，印单上会打印出所有的菜。

**来 得**：

先前叫起的菜，现在可以上了，便会打出来得单，分别在厨房和传菜部打出“来得总单”，在相应档口打出“来得单”。

**来得总单**：

此印单与叫起总单类似，只是印单上有“来得总单”四字，表示印单上所有的菜现在可以上了。

**来得单**：

此印单与叫起单类似，只是印单上显示“来得单”三字，表示印单上这项菜现在可以上了。

**全来得**：

表示客人点的所有菜都可送上来了。

**追 单**：

分别在厨房和传菜部打印出“追单总单”，在相应档口打出“追单”。

**追单总单**：

表示催促厨房快上印单上的所有菜。在印单上有“追单总单”四个字，“101（8人）”表示是101房台有8位客人，其后是印机号、操作员工、追单日期、时间，下面是所催促的所有菜。

**追单**：

表示催促各档口快上印单上的这项菜。在印单上有“追单”二字，此印单与追单总单类似，只是在房台号下有“小王  --追单   11：30”表示操作员工小王在11：30追单一次，以下日期时间是点此项菜的时间。

**追 台**：

分别在厨房和传菜部打印出“追台总单”，在相应档口打印出“追台单”。

**追台总单**：

表示催促厨房快上客人所点的全部菜。在印单上会有“追台总单”四字，“101（8人）”表示是101房台有8位客人，“10—小王   10、10  12：00”表示在10号印机，操作员工小王在10月10日12点操作，以下列出的是此房台所点的全部菜。

**追台**：

表示催促档口快上印单上的这项菜。在相应档口出追台单，一种菜只出一张单，上面时间为追台时间，下面时间为点此菜的时间。
