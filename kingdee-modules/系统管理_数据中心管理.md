## 【页面】k_3_cloud配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=k_3_cloud%E9%85%8D%E7%BD%AE

**功能说明：**

实现BBC全渠道营销平台与金蝶云系统的对接，管理配置入口

**功能路径：**

【系统】—>【系统设置】—>【K3Cloud配置】

**使用前提：**

无

**字段说明：**
|**名称**|**字段取数说明**|
|用户名|金蝶云管理员用户|
|密码|金蝶云管理员用户密码，非明文显示|
|数据库ID|金蝶云系统数据库ID，定位连接具体的ERP数据库|
|金蝶云网址|金蝶云服务访问地址|

**操作说明：**
  - 进入金蝶云配置页面，填写金蝶云相关连接账户信息，保存；
  - 保存后，可查看是否连接成功。

## 【页面】云激活
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%91%E6%BF%80%E6%B4%BB

======1 功能说明 ======


金蝶产品定期或不定期进行产品的正版云验证，保障正版客户使用金蝶正版产品的权益。

产品验证提供了以下功能：

正版验证：产品环境在使用在一段时间内从未进行正版验证，在管理员登录产品时，会提示管理员进行产品正版验证或购买许可。

激活验证：产品会随机选择核心业务功能进行产品激活验证，只有在特定的时间内完成激活验证后才能继续使用核心业务功能，如果超过特定时间，未完成产品的激活，将不能使用核心业务功能。

**功能路径**

【数据中心管理】→【许可中心】→【产品激活】 

======2 功能操作 ======

=====2.1 正版验证 =====
 

正式许可，限时许可，试用许可产品环境在使用在一段时间内从未进行正版验证，在管理员登录产品时，提示管理员进行产品正版验证或购买许可。如果超过一定时间仍未经正版验证和购买，到达使用期限后，将不允许再使用产品，需执行正版验证。操作步骤如下：

第一步：联系金蝶，购买正式版。

第二步：链接到金蝶官方正版验证网站，进行正版验证。

=====2.2 激活验证 =====
 
产品会随机选择核心业务功能进行激活验证，只有在特定的时间内完成激活验证后才能继续使用核心业务功能，如果超过特定时间，未完成产品的激活，将不能使用核心业务功能，需联系系统管理员进行产品激活验证。操作步骤如下：

第一步：记录下激活识别码，同时保存激活验证文件；

第二步：访问金蝶官方正版验证网站输入激活识别码获取激活验证码，或致电联系金蝶公司或当地销售代表来获取激活验证码，金蝶公司售后服务热线：4008-836-836；

第三步：输入获取到的激活验证码，点击“激活验证”按钮完成激活。

**特别说明：当许可版本升级到V8.1后，无需进行产品激活，导入许可将会自动完成正版验证。**

*(产品版本号). *(SP版本号). ***（编译第N天） . *  (编译当天第N个包)

## 【页面】创建oracle数据中心
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%9B%E5%BB%BAoracle%E6%95%B0%E6%8D%AE%E4%B8%AD%E5%BF%83

====== 1 功能描述  ======

数据中心是业务数据的载体，支持SQL Server和Oracle两种数据库类型，并可以按数据中心设置系统时区。

**功能路径**

【数据中心列表】

====== 2 字段说明 ======


===== 2.1 数据库服务器信息 =====

==== 2.1.1 数据库服务器 ====
定义当前数据库服务器的机器名称或者数据库服务器IP地址； ​

==== 2.1.2 实例名 ====

采用默认实例名即可；

==== 2.1.3 端口 ====

采用默认端口即可；

==== 2.1.4 数据库管理员 ====

输入数据库服务器管理员名称，数据库管理员用户将会使用模板创建数据中心；

==== 2.1.5 管理员密码 ====

输入数据库服务器管理员密码；

===== 2.2 数据库用户 =====

==== 2.2.1 使用现有用户 ====
  - 数据库用户：输入数据连接用户的帐号，数据库服务器中必须存在这个账户； ​
  - 密码：输入数据连接用户的帐号密码； ​
==== 2.2.2 新建用户 ====

  - 数据库用户：输入数据连接用户的帐号，数据库服务器中尚不存在这个账户；
  - 密码：输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户；
  - 确认密码：新增用户需要输入确认密码；
  - 默认表空间：需指定一个默认表空间；
  - 临时表空间：需指定一个临时表空间；​

===== 2.3 数据中心 =====

==== 2.3.1 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.3.2 系统时区 ====
定义数据中心的系统时区，数据中心保存后系统时区将不再允许修改；

==== 2.3.3 默认语言 ====

默认为中文简体，下拉选择中文繁体和英文，数据中心保存后默认语言将不再允许修改；

==== 2.3.4 其他字段 ====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； ​
  - 数据中心类别：提供了标准业务库、标准BOS库； ​

====== 3 功能操作 ======

===== 3.1 登录管理中心平台 =====

在管理中心的登录界面，使用Administrator，登录到管理中心后，可在主页进行数据中心的创建。
    ​

=====3.2 创建Oracle数据中心 =====

在【数据中心列表】，点击工具栏【创建】按钮组的下拉子按钮【创建Oracle数据中心】，如果管理中心是Oracle类型的，直接点击工具栏【创建】按钮，即可打开“创建Oracle数据中心”的向导界面。

Oracle数据中心创建共分三步，具体创建过程如下：

  第一步：输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码；
  
  第二步：选择数据库用户，可以选择“使用现有用户”或“新建用户”，这两种方式分别介绍如下：
  
       1、选择“使用现有用户”，需要输入Oracle数据库中已存在的用户名及其密码。
     
          注意采用“使用现有用户”方式需要提前使用Oracle系统自带工具创建用户，在Oracle数据库中创建用户后，应授予该新建用户DBA的权限，还需为新建用户关联数据库表空间，以保证该用户创建出来的数据中心各个功能正常；
        
       2、选择“新建用户”，需输入在数据库中新建的用户名称、密码以及确认密码，还需选择默认表空间和临时表空间。
     
  第三步：设置数据中心的基本信息、语言、日志中心。
  
        1、数据中心基本信息，包括：数据中心代码、名称、类别、数据库文件路径等内容；
  
           注意：请根据需要勾选“允许执行计划任务”，勾选启用后，当前数据中心相关后台服务才能定时执行。
  
        2、语言，设置当前数据中心的默认语言，一般是中文（简体/中国）；
  
        3、日志中心，设置日志中心的存放路径，勾选选项“创建日志中心”，那么在创建业务数据中心时，会同时在此路径下面创建日志库。​
  
完成上面所有步骤后，点击【创建】按钮，系统即可完成数据中心的创建工作。


===== 3.3 登录数据中心 =====

  - 每个数据中心都有一个预设的系统管理员用户，用户名：Administrator。
  - 初次登录时，会弹出提示“需要使用200MB本地磁盘空间做缓存，请确认”，点击【确定】后，虽然会占用部分空间，但可以提高系统使用性能和运行速度。

====== 4 其他说明 ======

  - 用户名在SQL Server下Administrator不区分大小写，Oracle下必须是Administrator，区分大小写且要求首字母大写。
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

## 【页面】创建sql_server数据中心

====== 1 功能描述  ======

数据中心是业务数据的载体，支持SQL Server和Oracle两种数据库类型，并可以按数据中心设置系统时区。

**功能路径**

【数据中心列表】

====== 2 字段说明 ======

===== 2.1 数据库服务器用户信息 =====

定义当前数据库服务器的机器名称或者数据库服务器IP地址。
 ​
==== 2.1.2 数据库管理员 ====

输入数据库服务器管理员名称，数据库管理员用户将会使用模板创建数据中心； ​

输入数据库服务器管理员密码；

==== 2.1.4 身份验证 ====

支持SQL Server身份验证和Windows身份验证。

输入数据连接用户的帐号； 

==== 2.1.6 密码 ====

输入数据连接用户的帐号密码，使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户； ​

===== 2.2 数据中心 =====


==== 2.2.1 数据库实体 ====
系统自动生成数据中心实体名称，可以根据需要调整名称； ​

==== 2.2.2 数据库文件路径 ====
定义数据库文件的安装目标，建议采用英文路径； ​

==== 2.2.3 数据库日志文件路径 ====
定义数据库日志文件路径，默认跟数据库文件路径相同，可以重新选择路径，建议采用英文路径；

==== 2.2.4 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.2.5 系统时区 ====
定义数据中心的系统时区，数据中心保存后系统时区将不再允许修改；

==== 2.2.6 默认语言 ====
默认为中文简体，下拉选择中文繁体和英文；



===== 2.2.7 其他字段 =====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； 
  - 数据中心类别：提供了标准业务库、标准BOS库； 
    标准业务库是包含金蝶AI星空标准业务，比如财务、供应链等；
    标准BOS库是只有BOS平台，没有星空标准业务，主要是针对只购买BOS开发平台的二开客户。

====== 3 功能操作 ======

===== 3.1 登录管理中心平台 =====

在管理中心的登录界面，使用Administrator，登录到管理中心后，可在主页进行数据中心的创建。
    ​

===== 3.2 创建SQL Server数据中心 ​ =====

在【数据中心列表】，点击工具栏【创建】按钮组的下拉子按钮【创建SQL Server数据中心】，如果管理中心是SQLServer类型的，直接点击工具栏【创建】按钮，即可打开“创建SQL Serve数据中心”创建向导界面。

SQL Sever数据中心创建共分两步，具体创建过程如下：

  第一步：输入数据库服务器用户信息，包括数据库服务器、数据库管理员用户和密码、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效。
   
  1、数据库管理员用户将会使用模板创建数据中心。
  
  2、数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到数据中心。
    ​
     ​数据库连接用户支持SQL Server身份验证和Windows身份验证两种方式。
          
     1）若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改。
     
        使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。 
        
     2）若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码。   
       
  第二步：设置数据中心的基本信息、语言、日志中心。
  
  1、数据中心基本信息，包括：数据中心代码、名称、类别、数据库文件路径等内容；
  
           注意：请根据需要勾选“允许执行计划任务”，勾选启用后，当前数据中心相关后台服务才能定时执行。
  
  2、语言，设置当前数据中心的默认语言，一般是中文（简体/中国）；
  
  3、日志中心，设置日志中心的存放路径，勾选选项“创建日志中心”，那么在创建业务数据中心时，会同时在此路径下面创建日志库。​
    
 完成上面步骤后，点击【创建】按钮，系统即可完成数据中心的创建工作。



===== 3.3 登录数据中心 =====

  - 每个数据中心都有一个预设的系统管理员用户，用户名：Administrator。
  - 初次登录时，会弹出提示“需要使用200MB本地磁盘空间做缓存，请确认”，点击【确定】后，虽然会占用部分空间，但可以提高系统使用性能和运行速度。

====== 4 其他说明 ======

  - 用户名在SQL Server下Administrator不区分大小写，Oracle下必须是Administrator，区分大小写且要求首字母大写。
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

====== 1 数据中心管理概述 ======

===== 1.1 数据中心管理概述 =====

金蝶云数据中心管理是数据中心的管理平台，也叫管理中心，主要提供以下功能：

[图:bd_数据中心.png]

（1）创建数据中心，支持SQL Server和Oracle两种数据库类型的创建；

（2）注册与反注册数据中心，支持SQL Server和Oracle两种数据库类型的注册与反注册；

（3）备份数据中心，支持SQL Server类型的备份；

（4）恢复数据中心，支持SQL Server类型的恢复；

（5）删除数据中心，支持SQL Server类型的删除；

（6）升级数据中心，支持SQL Server和Oracle两种数据库类型的升级；

（7）数据库优化，支持SQL Server和Oracle两种数据库类型的优化；

（8）管理中心高可用部署完成后，打开管理中心，进行高可用设置与监控设置，定期查阅预警邮件与日志； 

（9）管理员看板，建立系统健康指标，综合评估影响性能的关键指标状况，图表化显示，帮忙系统管理员掌握系统运行状况；


另外，管理中心还可以进行许可的引入、控制以及许可使用状况的查询。

数据中心管理业务流程如下：

====== 2 数据中心帮助手册 ======

===== 2.1 使用流程 =====

数据中心管理的操作流程：

第一步：创建管理中心

  - 管理中心用来创建并维护数据中心。
  - 金蝶云产品安装完成后，系统自动进入金蝶云管理中心的创建向导，引导管理中心的创建和注册，[[管理中心创建|创建]]或者[[管理中心注册|注册]]完成后，便可登录管理中心创建和维护数据中心。
  - 金蝶云初始是演示版，可在管理中心中进行许可的进入、控制以及进行许可使用状况的查询。

第二步：创建数据中心

  - 数据中心是业务数据的载体，在数据中心可以进行各种业务操作。
  - 登录管理中心后，在【数据中心列表】中可进行数据中心创建和数据中心管理。

===== 2.2 管理中心 =====

==== 2.2.1 管理中心创建 ====

产品安装后，首先须完成管理中心的创建，然后在管理中心中对数据中心进行管理和维护。

具体见【[[管理中心创建|管理中心创建]]】的介绍。

==== 2.2.2 管理中心注册 ====

产品使用一段时间后，由于企业的实际需求，在新的服务器进行同版本产品安装和部署，把原有环境的管理中心数据库的注册过来，继续使用。

具体见【[[管理中心注册|管理中心注册]]】的介绍。
==== 2.2.3 管理中心主页 ====

管理中心主页提供实时、形象地反馈系统整体运行状况，对服务器关键性能指标CPU和内存使用率进行图表展示，帮助系统管理员及时发现问题，更好解决问题，提供优质的系统运维服务。

具体见【[[部署监控概览|管理中心主页]]】的介绍。

==== 2.2.4 管理中心高可用 ====

管理中心高可用采用双节点主备模式的高可用方案，确保主节点出现问题后，可自动切换到备用节点使用，确保管理中心服务的高可用的特性，满足客户对管理中心高可用的需求。

具体见【[[管理中心创建|管理中心高可用]]】的介绍。

==== 2.2.5 管理中心数据库连接密码修改 ====

在数据库服务器上更改了管理中心账套对应的数据库连接密码后，管理中心将不能正常登录，为了星空系统能够正常使用，则需修改星空本地环境存储的数据库连接密码。

具体见【[[管理中心维护|管理中心数据库连接密码修改]]】的介绍。

数据中心是业务数据的载体，支持SQL Server和Oracle两种数据库类型，并可以按数据中心设置系统时区。

对建立后的数据中心以及已经存在的数据中心，可以通过管理中心进行管理，主要功能介绍如下：

在系统运行中，数据中心需要及时备份，以避免机器故障、病毒等原因造成数据丢失或者损坏，最好可以定期备份。目前提供数据中心的完全备份处理，保证数据的完整性。同时提供备份日志的查询。

具体见【[[数据中心备份|数据中心备份]]】的介绍。

==== 2.4.2 恢复  ====

具体见【[[数据中心恢复|数据中心恢复]]】的介绍。

在管理中心中可以对数据中心进行删除处理。

具体见【[[数据中心删除|数据中心删除]]】的介绍。

具体见【[[注册sql_server数据中心|数据中心反注册]]】的介绍。

将数据中心升级到最新版本。

具体见【[[数据中心升级向导|数据中心升级]]】的介绍。

系统运行一段时间后，由于频繁的插入，删除，更新等操作，会造成索引的碎片，导致查询速度的下降，需定期进行索引的重建和优化。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%95%B0%E6%8D%AE%E4%B8%AD%E5%BF%83%E6%81%A2%E5%A4%8D

====== 3.1 恢复SQL Server数据中心 ======
 
在【数据中心列表】中，点击工具栏【恢复】按钮，即可打开“恢复SQL Server数据中心”界面进行恢复。

    SQL Sever数据中心恢复过程如下：
    
    1、输入备份文件信息，包括数据库服务器、数据库管理员、管理员密码以及备份文件，输入后，可以进行【测试连接】确保输入信息有效。
    
    2、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到数据中心。
    
       数据库连接用户支持SQL身份验证和Windows身份验证两种方式。
     
       1）若选择Windows身份验证，默认从数据中心站点的应用程序池获取运行账户，数据中心站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS数据中心站点的应用程序池中修改；
    
       2）使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
    
       3）若选择SQL Serve身份验证，请输入SQL Serve数据库用户名和密码。
    
   3、输入恢复数据中心信息，包括数据中心代码、数据中心名称，并选择要恢复到的数据库文件路径。注意数据中心的代码和名称不能重复；
   
   4、在恢复界面中，确认相关信息后，点击【执行恢复】按钮，系统即可完成数据中心恢复工作。
   
====== 3.2 注意事项 ======   
   
仅支持恢复SQL Server数据中心，恢复Oracle数据中心请先使用Oracle据库提供的EM工具进行恢复，再将该数据中心注册到产品中进行使用。

====== 2 字段说明 ======

定义当前数据库服务器的机器名称或者数据库服务器IP地址； ​

==== 2.1.2 实例名 ====

==== 2.1.3 端口 ====

采用默认端口即可；

==== 2.1.4 数据库管理员 ====

输入数据库服务器管理员密码；

===== 2.2 数据库用户 =====

==== 2.3.1 允许执行计划任务 ====

允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

==== 2.3.2 其他字段 ====

  - 数据中心代码：输入1-50个字符；
  - 数据中心名称：输入1-50个字符； ​


====== 3 功能操作 ======

===== 3.1 注册Oracle数据中心  =====  
  
注册Oracle管理中心需先在Oracle系统自带工具创建用户，然后再使用系统的注册Oracle数据中心功能。

在【数据中心列表】中，点击工具栏【注册】按钮组的下拉子按钮【注册Oracle数据中心】，如果管理中心是Oracle类型的，直接点击工具栏【注册】按钮，即可打开“注册Oracle数据中心”的界面。

  Oracle数据中心注册过程如下：
    
  1、输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码，输入后，可以进行【测试连接】确保输入信息有效。
  
  2、选择数据库用户，包括数据库用户和密码。
  
     数据库用户需录入Oracle数据库中已存在的用户名及其密码，并且该用户必须是注册数据中心对应的用户，而不能是注册管理中心对应的用户，输入后，可以进行【测试连接】确保输入信息有效。
     
  3、输入数据中心相关信息，包括数据中心代码、名称等。
  
  4、在注册界面中，确认相关信息后，点击【注册】按钮，即可注册管理中心。


 
===== 3.2 反注册数据中心  =====   
 
在【数据中心列表】中，选中注册的数据中心，点击工具栏【反注册】按钮，系统即可进行反注册。 

 
====== 4 其他说明 ======   
 
  - 数据中心注册成功后，在管理中心主页的列表界面会增加一条数据中心记录，可供选择登录和使用。 
  - 可以对已注册的数据中心进行反注册操作，反注册后将不在列表中显示，用户也不能登录及使用该数据中心，反注册后不会删除数据库实体。 
  - 允许执行计划任务用来控制当前数据中心在当前管理中心控制下是否执行后台计划，以免该管理中心多次注册后，该数据中心重复执行多次计划导致业务错乱。

## 【页面】清除第三方集成配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B8%85%E9%99%A4%E7%AC%AC%E4%B8%89%E6%96%B9%E9%9B%86%E6%88%90%E9%85%8D%E7%BD%AE

====== 1 功能描述 ======

清除第三方集成配置，主要是为了避免客户或者实施人员在开展测试、备查等非正式开展业务用途时，恢复数据库后未及时清理第三方集成配置导致影响正式数据中心数据的问题。比如：实施人员为了帮客户做测试，备份客户正式数据中心，然后把客户的正式数据中心注册到测试环境。 然后实施人员在测试环境中同步用户，把测试用户直接同步到客户的正式云之家工作圈，造成了很严重的非法授权用户同步到云之家。通过注册或者恢复数据中心时清除配置，可以避免类似问题发生，不过系统管理员需根据需要重新配置云之家。

**功能路径**

数据中心在注册或恢复的时候，点击【注册】或者【恢复】

====== 2 功能操作 ======
===== 2.1 须知阅读及选择 =====

1、数据中心在注册或恢复的时候，点击【注册】或者【恢复】打开界面的同时，弹出须知界面，引导清除集成配置；

2、勾选【我已阅读】；

说明：

如果注册或恢复的数据中心是作为测试、备查等非正式开展业务用途，请选择数据中心清除第三方配置；

如果注册的数据中心将作为正式开展业务用途，请选择数据中心不清除第三方配置选项，注册或者后恢复后此数据中心将不会清除第三方系统配置；

3、勾选后，会自动携带勾选项；

4、注册完成后勾选“清除第三方系统配置”默认携带上面的勾选,支持调整勾选。
    
===== 2.2 日志查看 =====
1、查看第三方系统集成清理日志，详细见[[第三方系统集成清理日志|第三方系统集成清理日志]]
2、查看用户上机操作日志

为了避免客户或者实施人员在开展测试、备查等非正式开展业务用途时，恢复数据库后未及时清理第三方集成配置导致影响正式数据中心数据的问题，系统提过了清除第三方集成配置功能，同时也提供了第三方系统集成清理日志，以便可以追溯分析。

**功能路径**

【系统管理】->【日志管理】->【第三方系统集成清理日志】

====== 2 功能操作 ======

administrator登录后，打开第三方系统集成清理日志菜单，可以查看相应信息，包括清除项、业务影响说明、清除数据说明、恢复配置说明、创建时间、记录数。

## 【页面】管理中心创建
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%AE%A1%E7%90%86%E4%B8%AD%E5%BF%83%E5%88%9B%E5%BB%BA

====== 1 功能描述 ====== 

金蝶云产品安装完成后，系统自动进入金蝶云管理中心库创建向导，引导管理中心库的创建，创建完成后，便可登录管理中心创建和维护业务数据中心。

管理中心支持SQL Server和Oracle两种类型的数据库。

**功能路径**

  - 首次登录管理站点会自动进入管理中心创建和注册界面； 
  - 登录管理中心后，使用功能：管理中心库维护，点击跳转到管理中心创建和注册界面；

 ====== 2 功能操作 ======

金蝶云安装完毕后，系统自动进入金蝶云管理中心的创建，可以分别进行SQL Server或Oracle管理中心的创建或注册。如部署了管理中心高可用，可进行管理中心高可用的设置与监控配置。


===== 2.1 创建SQL管理中心 =====

SQL Sever管理中心创建过程如下：

  1、选择SQL Sever数据库，并选择操作类型为创建，右边会显示SQL Sever管理中心的创建界面。
  
  2、输入数据库服务器。
  
  3、输入数据库管理员用户信息，包括数据库管理员用户和密码，输入后，可以进行【测试连接】确保输入信息有效，数据库管理员用户可以用来创建管理中心实体。
  
  4、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到管理中心。
  
     数据库连接用户支持SQL Server身份验证和Windows身份验证两种方式。
     
     1）若选择Windows身份验证，默认从管理站点的应用程序池获取运行账户，管理站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS管理站点的应用程序池中修改。
        使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
        
     2）若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码。
     
  5、输入数据库文件，包括数据库实体、数据库文件路径以及数据库日志文件路径。
  
  6、在创建界面中，确认相关信息后，点击【创建】按钮，即可创建管理中心。



===== 2.2 创建Oracle管理中心 =====

Oracle管理中心创建过程如下：

  1、选择Oracle数据库，并选择操作类型为创建，右边会显示Oracle管理中心的创建界面。
  
  2、输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码。
  
  3、输入数据库用户信息，数据库用户需选择“使用现有用户”或“新建用户”，两种方式分别介绍如下：
  
   1）选择“使用现有用户”，需要输入Oracle数据库中已存在的用户名及其密码；
   
      注意采用“使用现有用户”方式需要提前使用Oracle系统自带工具创建用户，且在Oracle数据库中创建用户时，应授予该新建用户DBA的权限，
      还需为新建用户关联数据库表空间，以保证使用该用户创建出来的管理中心各个功能正常；
      
   2）选择“新建用户”，需输入在数据库中新建的用户名称、密码以及确认密码，还需选择默认表空间和临时表空间。
   
  输入后，可以进行【测试连接】确保输入信息有效。
  
  4、在创建界面中，确认相关信息后，点击【创建】按钮，即可创建管理中心。


 ===== 2.3 登录管理中心平台 ===== 

  - 管理中心创建完成后，单击【完成】按钮，可自动进入管理中心的登录界面，输入用户名和密码即可登录，用户名是Administrator（SQL Server下不区分大小写，Oracle下区分大小写）， 登录管理中心后，即可进行数据中心创建和数据中心管理。
  - 金蝶云安装后，桌面会建立“金蝶云管理站点”的快捷方式，双击即可进入管理中心，也可以通过站点“机器IP:端口号/”登录。 
  - 管理中心的版本和管理站点的产品版本需保持一致，用户登录系统时会自动检查管理中心和版本，若管理中心版本低于或高于产品版本，须相应升级后才能正常进行管理站点的登录和使用。

 ===== 2.4 配置管理中心高可用 ===== 

  - 访问主管理中心，打开高可用设置，填入主管理中心地址和备用管理中心地址，进行检测，获取到组合唯一码，检测通过后，启用管理中心高可用。
  - 配置邮件服务器和邮件虚拟账户，设置高可用监控。
  - 定期关注高可用预警邮件和日志情况，如是凌晨IIS回收时候出现的短暂高可用异常，可无需关注。


 ====== 3 其他说明 ====== 

  - Oracle数据库中每个用户只能对应一个管理中心，不能重复使用； 
  - 建议数据库文件路径以及数据库日志文件路径采用英文路径； 
  - 如果系统管理员要进行管理数据中心的快速重建或注册，可登录管理中心后，使用功能：管理中心库维护，点击跳转到管理中心创建和注册界面；
  - 有关管理中心注册，详见【[[管理中心注册|管理中心注册]]】的介绍。

## 【页面】管理中心创建和注册
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%AE%A1%E7%90%86%E4%B8%AD%E5%BF%83%E5%88%9B%E5%BB%BA%E5%92%8C%E6%B3%A8%E5%86%8C

====== 1 功能描述 ====== 

金蝶云产品安装完成后，系统自动进入金蝶云管理中心库创建向导，引导管理中心库的创建，创建完成后，便可登录管理中心创建和维护业务数据中心。

产品使用一段时间后，由于企业的实际需求，在新的服务器进行同版本产品安装和部署，把原有环境的管理中心数据库的注册过来，继续使用。注册完成后，若管理中心的版本过低，需对注册过来的管理中心进行升级处理。

管理中心支持SQL Server和Oracle两种类型的数据库。

**功能路径**

  - 首次登录管理站点会自动进入管理中心创建和注册界面 
  - 浏览器直接访问：管理站点IP或域名:8000/Silverlight/CMC.aspx会进入到管理数据中心创建界面。 

 ====== 2 功能操作 ======

金蝶云安装完毕后，系统自动进入金蝶K3 Cloud管理中心的创建，可以分别进行SQL Server或Oracle管理中心的创建或注册。

===== 2.1 创建管理中心 ===== 

==== 2.1.1 创建SQL管理中心 ====

SQL Sever管理中心创建过程如下：

  1、选择SQL Sever数据库，并选择操作类型为创建，右边会显示SQL Sever管理中心的创建界面。
  
  2、输入数据库服务器。
  
  3、输入数据库管理员用户信息，包括数据库管理员用户和密码，输入后，可以进行【测试连接】确保输入信息有效，数据库管理员用户可以用来创建管理中心实体。
  
  4、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到管理中心。
  
     数据库连接用户支持SQL Server身份验证和Windows身份验证两种方式。
     
     1）若选择Windows身份验证，默认从管理站点的应用程序池获取运行账户，管理站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS管理站点的应用程序池中修改。
        使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
        
     2）若选择SQL Server身份验证，请输入SQL Server数据库用户名和密码。
     
  5、输入数据库文件，包括数据库实体、数据库文件路径以及数据库日志文件路径。
  
  6、在创建界面中，确认相关信息后，点击【创建】按钮，即可创建管理中心。



==== 2.1.2 创建Oracle管理中心 ====

Oracle管理中心创建过程如下：

  1、选择Oracle数据库，并选择操作类型为创建，右边会显示Oracle管理中心的创建界面。
  
  2、输入数据库服务器信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码。
  
  3、输入数据库用户信息，数据库用户需选择“使用现有用户”或“新建用户”，两种方式分别介绍如下：
  
   1）选择“使用现有用户”，需要输入Oracle数据库中已存在的用户名及其密码；
   
      注意采用“使用现有用户”方式需要提前使用Oracle系统自带工具创建用户，且在Oracle数据库中创建用户时，应授予该新建用户DBA的权限，
      还需为新建用户关联数据库表空间，以保证使用该用户创建出来的管理中心各个功能正常；
      
   2）选择“新建用户”，需输入在数据库中新建的用户名称、密码以及确认密码，还需选择默认表空间和临时表空间。
   
  输入后，可以进行【测试连接】确保输入信息有效。
  
  4、在创建界面中，确认相关信息后，点击【创建】按钮，即可创建管理中心。

===== 2.2 创建管理中心 ===== 

==== 2.2.1 注册SQL管理中心 ====

SQL Sever管理中心注册过程如下：

  1、选择SQL Sever数据库，并选择操作类型为注册，右边会显示SQL Sever数据库的注册界面。
  
  2、输入数据库服务器。
  
  3、输入数据库连接用户信息，包括身份验证方式、数据库连接用户登录名和密码。输入后，可以进行【测试连接】确保输入信息有效，应用服务器将使用数据库连接用户连接到管理中心。
  
     数据库连接用户支持SQL身份验证和Windows身份验证两种方式。
     
     1）若选择Windows身份验证，默认从管理站点的应用程序池获取运行账户，管理站点的运行账户在产品安装过程高级中进行设置，在安装后也可在IIS管理站点的应用程序池中修改。
        使用Windows身份验证不需要输入密码，但是数据库服务器中必须存在这个账户。
        
     2）若选择SQL身份验证，请输入SQL数据库用户名和密码。
     
  4、输入数据库文件，主要是选择数据库实体，且必须选择管理中心类型的数据库实体，不能选择数据中心类型的数据库实体。
  
  5、在注册界面中，确认相关信息后，点击【注册】按钮，即可注册管理中心。

==== 2.2.2 注册Oracle管理中心 ====

Oracle管理中心注册过程如下：

  1、选择Oracle数据库，并选择操作类型为注册，右边会显示Oracle数据库的注册界面。
  
  2、输入数据库服务器相关信息，包括数据库服务器、实例名、端口、数据库管理员及管理员密码。
  
  3、输入数据库用户信息，包括数据库用户和密码。
  
     数据库用户需录入Oracle数据库中已存在的用户名及其密码，并且该用户必须是注册管理中心对应的用户，而不能是注册数据中心对应的用户，输入后，可以进行【测试连接】确保输入信息有效。
  
  4、在注册界面中，确认相关信息后，点击【注册】按钮，即可注册管理中心。

===== 2.3 升级管理中心 =====
 
  - 在注册完成后，若管理中心的版本过低，会提示注册过来的管理中心的版本过低，需要进行升级。点击升级按钮后，进行管理数据中心的升级，升级完成并重启应用服务器的IIS服务后，即可登录管理站点。 
  - 管理中心升级支持SQL Server和Oracle两种类型的数据库。

 ===== 2.4 登录管理中心平台 ===== 

  - 管理中心创建完成后，单击【完成】按钮，可自动进入管理中心的登录界面，输入用户名和密码即可登录，用户名是Administrator（SQL Server下不区分大小写，Oracle下区分大小写）， 登录管理中心后，即可进行数据中心创建和数据中心管理。
  - 金蝶云安装后，桌面会建立“金蝶K3 Cloud管理站点”的快捷方式，双击即可进入管理中心，也可以通过站点“机器IP：端口号/”登录。 
  - 管理中心的版本和管理站点的产品版本需保持一致，用户登录系统时会自动检查管理中心和版本，若管理中心版本低于或高于产品版本，须相应升级后才能正常进行管理站点的登录和使用。


 ====== 3 其他说明 ====== 

  - Oracle数据库中每个用户只能对应一个管理中心，不能重复使用； 
  - 建议数据库文件路径以及数据库日志文件路径采用英文路径； 
  - 如果系统管理员要进行管理数据中心的快速重建或注册，可直接访问：管理服务器IP或计算机名:8000/silverlight/CMC.aspx

======1 功能描述 ======


用户应该准确记录自己登录系统的密码，同时根据密码规则设置自己的个人密码以及控制规则调整个人密码，以避免密码被盗用造成信息泄露。对此，提供了修改密码的处理。

**功能路径**

管理中心：
【数据中心列表】→【设置】→【重置密码】
【其用户下拉菜单】→【修改密码】

数据中心：
用户修改个人密码：【主控台用户下拉菜单】→【修改密码】     
系统管理员为用户重置密码：【系统管理】→【系统管理】→【查询用户】 

======2 功能操作 ======

=====2.1 管理中心 =====

管理中心中重置密码，操作如下：
  - Administrator登录管理中心后，可以为业务数据中心管理员重置密码，进入【设置】→【重置密码】，即可打开重置密码界面进行设置；
  - 管理中心的Administrator修改自己的密码，需在【其用户下拉菜单】→【修改密码】进行设置；
  - 管理中心默认唯一用户Administrator，可以重置密码，不可新增用户。

=====2.2 数据中心 =====

数据中心中有关重置密码，操作如下：


  * 用户修改个人登录密码 
  - 进入【主控台用户下拉菜单】→【修改密码】，点击【修改密码】菜单，打开修改密码界面；
  - 输入旧密码、新密码、新密码确认后，点击【确认】，即完成用户个人密码的修改。

  * 系统管理员为用户重置密码 
  - 进入【系统管理】→【系统管理】→【用户管理】，点击【查询用户】，打开“用户列表”界面；
  - 选中用户并点击【密码策略】下面的【重置密码】按钮，打开重置密码界面，即可为用户重置密码。



======3 业务说明 ======

数据中心中提供两种修改方式：
  - 用户修改个人密码，受密码策略的控制和影响，用户需要及时按照要求调整，避免无法使用系统的情况；
  - 系统管理员为用户重置密码，适用于用户遗忘密码的情况；重置密码后用户及时按照密码策略的控制改为个人密码，避免被盗用。新密码受密码策略的密码规则控制，详见【[[用户#密码策略|密码策略]]】的介绍；
  - 重置密码的适用情况，还可以参考【[[用户#重置密码|重置密码]]】描述。

## 【页面】金蝶云配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%87%91%E8%9D%B6%E4%BA%91%E9%85%8D%E7%BD%AE

**功能说明：**

实现BBC全渠道营销平台与金蝶云系统的对接，管理配置入口

**功能路径：**

【系统】—>【系统设置】—>【金蝶云配置】

**使用前提：**

无

**字段说明：**
|**名称**|**字段取数说明**|
|用户名|金蝶云管理员用户|
|密码|金蝶云管理员用户密码，非明文显示|
|数据库ID|金蝶云系统数据库ID，定位连接具体的ERP数据库|
|金蝶云网址|金蝶云服务访问地址|

**操作说明：**
  - 进入金蝶云配置页面，填写金蝶云相关连接账户信息，保存；
  - 保存后，可查看是否连接成功。
