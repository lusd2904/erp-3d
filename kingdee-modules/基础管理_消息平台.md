## 【页面】消息发送日志
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B6%88%E6%81%AF%E5%8F%91%E9%80%81%E6%97%A5%E5%BF%97

====== 1 消息平台概述 ======
===== 1.1 消息平台概述 =====
消息平台是V8.0系统新功能，通过定义消息模板和消息发送机制，可通过业务对象的操作触发并实时发送消息给用户，并且支持发送到第三方消息、邮箱和移动端，满足企业协作场景需求。消息平台实现了消息的即时发送和接收，从而提升企业内部的协作效率。

===== 1.2 消息平台特性 =====
  - 消息平台为系统免费的基础功能，无需购买即可应用；
  - 消息平台功能可授权管理员或是普通业务人员配置应用；
  - 管理员可设置接收哪些类型的消息，用户可配置消息的接收方式，满足用户个性化需求；
  - 消息模板可统一定义，支持消息通知（PC端铃铛）、消息轻应用（移动端）、第三方消息、邮件四个通道的消息内容配置；
  - 按业务需求定制消息配置的发送机制，配置消息触发操作和触发条件；
  - 消息实时发送和接收，操作触发即可触发并到达接收用户；
  - 消息级别智能处理，紧急级别消息必须手工干预，而警告和提醒级别消息会默认关闭；
  - 用户可从消息列表查看消息并标识消息是否已读，并且可查看历史消息；
  - 管理员或是授权用户可查看消息发送日志和消息配置执行情况；
  - 消息会按照清理规则自动清理。

====== 2 消息平台操作手册 ======
===== 2.1 消息设置 =====
消息设置提供了个性化设置功能，管理员可统一配置消息接收类型和消息清理规则，用户可设置不同消息类型的提醒方式。
===== 2.1.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息设置】
===== 2.1.2 关键功能 =====
  - 管理员设置接收消息类型：默认接收所有类型，管理员可取消勾选不接收该类型消息，管理员取消后则所有用户都收不到该类型的消息；
  - 管理员设置消息清理规则：默认保留7天内消息记录，超过7天的记录会归档到历史消息；历史消息默认保留30天，超过30天会自动清除；管理员可根据需要设置清理规则；
  - 用户设置消息提醒方式：消息提醒方式有：弹窗、闪烁、红点、语音，用户可根据自己需要设置提醒方式，默认是四种方式提醒。
===== 2.1.3 关键参数 =====
  - 单据后台操作触发消息发送机制：勾选该参数，在指定单据配置了[操作成功即触发]的消息配置时，单据操作执行成功会触发消息发送，也包括WebApi调用的单据操作成功触发消息发送；
  - 存在未读的紧急级别消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读的紧急级别消息就会弹窗提醒，提醒用户有多少条未读的紧急级别消息；
  - 存在未读消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读消息就会弹窗提醒，提醒用户有多少条未读消息，其中有多少条未读的紧急消息。

===== 2.2 消息模板 =====
消息模板是发送消息内容的基础信息，所有消息都会根据所选消息模板配置内容发送，方便用户维护消息内容。
===== 2.2.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息模板】

===== 2.2.2 关键字段说明 =====
  - 模板类型: 模板类型包括业务消息、预警消息、运营消息、公告消息；
  - 业务对象: 支持选择系统所有单据和基础资料；
  - 元数据: 业务对象的元数据字段；
  - 消息样式: 消息提醒的样式，目前支持了纯文本和表格；
  - 标题：消息标题，可选择元数据变量；
  - 内容：消息的详细内容，可选择元数据变量。

===== 2.2.3 主要功能操作 =====
  - 新增：选择模板类型和业务对象，设置消息通道的消息内容，消息内容目前只支持纯文本，消息内容支持选择元数据变量；    
    - 模板类型：业务消息、预警消息、运营消息、公告消息；
    - 消息通道：PC端消息通知、第三方消息、邮箱和消息轻应用；
    - 消息样式：纯文本和表格，后续会支持其他样式比如图片等；
    - 消息内容：消息数据可设置元数据变量，运营消息和公告消息支持设置链接地址；    
  - 删除：删除时校验是否有被引用，如被引用不允许删除；
  - 禁用/反禁用：禁用时校验是否被引用，如被引用不允许禁用。

===== 2.2.4 其他业务说明 =====
  - 业务消息和预警消息模板类型业务对象是必录字段，运营消息模板类型业务对象是非必录字段，公告消息模板类型无需选择业务对象；
  - 运营消息和公告消息模板类型的消息内容支持设置链接地址；
  - 消息内容样式目前支持了纯文本和表格（后续会支持其他样式）。

具体见【[[消息模板|消息模板]]】的介绍。

===== 2.3 消息配置 ===== 
根据业务协作需求配置操作成功发送消息，提醒协作团队业务处理进度以及处理事项，提升企业协作效率。
===== 2.3.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息配置】

===== 2.3.2 关键字段说明 =====
  - 消息类型: 消息类型包括业务消息、预警消息、运营消息、公告消息；
  - 消息级别：消息级别由高到低分别是紧急、警告、提醒；
  - 业务对象: 支持选择系统所有业务对象；
  - 触发操作: 业务对象的标准操作，支持多选；
  - 消息设置：选择消息模板和消息通道，消息模板是对应消息类型和业务对象对应模板，消息通道是模板定义了内容的通道；
  - 消息接收人：消息接收人可选择基础用户、变量用户、预置接收人、手机号码、邮箱地址和业务员，支持随时维护；
  - 发送条件：业务对象条件设置，满足条件的数据才会发送消息。
  - 消息查看设置：可以设置接收到消息后直接通过点击消息打开业务对象的单据，方便快速处理业务。

===== 2.3.3 主要功能操作 =====
  - 新增：选择消息类型、消息级别、业务对象、触发操作、消息模板、消息通道、消息接收人，并且设置消息发送条件，启用即生效；    
  - 删除：只能删除无效的配置信息，已审核数据不允许删除；
  - 禁用/反禁用：只能禁用已审核数据；
  - 重复发送：可以设置消息重复发送，仅支持PC端，该设置是基于当前消息配置进行设置的，启用后只有该消息配置发送的消息会按重复发送设置中的规则重复发送消息。

===== 2.3.4 其他业务说明 =====
  - 所选消息模板没有设置消息通道内容则通道灰显不允许选择；
  - 启用生效后操作成功即会按照设置发送消息；
具体见【[[消息配置|消息配置]]】的介绍。

===== 2.4 消息发送 ===== 

  - 操作业务，根据消息配置的发送条件和触发操作，操作成功即会发送消息；
  - 消息发送后，接收人会立即收到消息；
  - 紧急级别消息弹窗会一直显示在界面，需要用户手工关闭并置为已读，
  - 警告级别消息默认会10秒关闭并置为未读；
  - 提醒级别消息默认会8秒关闭并置为未读；
  - 手工关闭都会置为已读。

===== 2.5 消息接收 ===== 

  - 操作业务，根据消息配置的发送条件和触发操作，操作成功即会发送消息； 
  - 消息接收人会在对应的消息通道收到消息通知；
  - 消息提醒方式会按照用户设置方式提醒，如弹窗、红点、闪烁；
  - 铃铛红点代表有新消息或是未读消息；
  - 鼠标移上去会提示有多少条未读消息；
  - 弹窗消息如果设置了链接地址，则会优先打开链接内容；
  - 点击铃铛进入消息通知列表，显示当前用户接收消息。

===== 2.6 消息查看 ===== 

  - 管理员和授权用户可查看全部消息通知；
  - 普通用户点击铃铛查看发送给自己的所有消息通知；
  - 可选择未读消息标记为已读；
  - 消息通知默认保留7天内消息，超过7天内消息会自动归档到历史消息；
  - 可通过查看历史来读取历史消息，历史消息默认保留30天，超过30天的消息会自动清理；
  - 可点击消息查看消息详细信息。

===== 2.7 消息清理 ===== 

  - 管理员可通过消息设置来设置消息清理规则；
  - 默认会保留30天，超过30天的消息为自动清理。

===== 2.8 消息发送日志查看 ===== 

  - 消息发送日志列表记录了所有通道所有类型的消息发送日志；
  - 日志详细记录了发送和接收信息，以及消息内容等；
  - 日志记录了消息发送状态。

===== 2.9 消息配置最新执行情况列表 ===== 

  - 消息配置执行情况只记录最后一次执行情况；
  - 可通过查看消息配置执行情况详细信息查看执行记录。

====== 1 消息平台概述 ======
===== 1.1 消息平台概述 =====
消息平台是V8.0系统新功能，通过定义消息模板和消息发送机制，可通过业务对象的操作触发并实时发送消息给用户，并且支持发送到第三方消息、邮箱和移动端，满足企业协作场景需求。消息平台实现了消息的即时发送和接收，从而提升企业内部的协作效率。

===== 1.2 消息平台特性 =====
  - 消息平台为系统免费的基础功能，无需购买即可应用；
  - 消息平台功能可授权管理员或是普通业务人员配置应用；
  - 管理员可设置接收哪些类型的消息，用户可配置消息的接收方式，满足用户个性化需求；
  - 消息模板可统一定义，支持消息通知（PC端铃铛）、消息轻应用（移动端）、短信、邮件四个通道的消息内容配置；
  - 按业务需求定制消息配置的发送机制，配置消息触发操作和触发条件；
  - 消息实时发送和接收，操作触发即可触发并到达接收用户；
  - 消息级别智能处理，紧急级别消息必须手工干预，而警告和提醒级别消息会默认关闭；
  - 用户可从消息列表查看消息并标识消息是否已读，并且可查看历史消息；
  - 管理员或是授权用户可查看消息发送日志和消息配置执行情况；
  - 消息会按照清理规则自动清理。

====== 2 消息平台操作手册 ======
===== 2.1 消息设置 =====
消息设置提供了个性化设置功能，管理员可统一配置消息接收类型和消息清理规则，用户可设置不同消息类型的提醒方式。
===== 2.1.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息设置】
===== 2.1.2 关键功能 =====
  - 管理员设置接收消息类型：默认接收所有类型，管理员可取消勾选不接收该类型消息，管理员取消后则所有用户都收不到该类型的消息；
  - 管理员设置消息清理规则：默认保留7天内消息记录，超过7天的记录会归档到历史消息；历史消息默认保留30天，超过30天会自动清除；管理员可根据需要设置清理规则；
  - 用户设置消息提醒方式：消息提醒方式有：弹窗、闪烁、红点、语音，用户可根据自己需要设置提醒方式，默认是四种方式提醒。
===== 2.1.3 关键参数 =====
  - 单据后台操作触发消息发送机制：勾选该参数，在指定单据配置了[操作成功即触发]的消息配置时，单据操作执行成功会触发消息发送，也包括WebApi调用的单据操作成功触发消息发送；
  - 存在未读的紧急级别消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读的紧急级别消息就会弹窗提醒，提醒用户有多少条未读的紧急级别消息；
  - 存在未读消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读消息就会弹窗提醒，提醒用户有多少条未读消息，其中有多少条未读的紧急消息。

===== 2.2 消息模板 =====
消息模板是发送消息内容的基础信息，所有消息都会根据所选消息模板配置内容发送，方便用户维护消息内容。

  - 元数据: 业务对象的元数据字段；
  - 消息样式: 消息提醒的样式，目前支持了纯文本和表格；
  - 标题：消息标题，可选择元数据变量；
  - 内容：消息的详细内容，可选择元数据变量。

===== 2.2.3 主要功能操作 =====
  - 新增：选择模板类型和业务对象，设置消息通道的消息内容，消息内容目前只支持纯文本，消息内容支持选择元数据变量；    
    - 模板类型：业务消息、预警消息、运营消息、公告消息；
    - 消息通道：PC端消息通知、短信、邮箱和消息轻应用；
    - 消息样式：纯文本和表格，后续会支持其他样式比如图片等；
    - 消息内容：消息数据可设置元数据变量，运营消息和公告消息支持设置链接地址；    
  - 删除：删除时校验是否有被引用，如被引用不允许删除；
  - 禁用/反禁用：禁用时校验是否被引用，如被引用不允许禁用。

===== 2.2.4 其他业务说明 =====
  - 业务消息和预警消息模板类型业务对象是必录字段，运营消息模板类型业务对象是非必录字段，公告消息模板类型无需选择业务对象；

具体见【[[消息模板|消息模板]]】的介绍。

===== 2.3.1 功能路径 =====

  - 重复发送：可以设置消息重复发送，仅支持PC端，该设置是基于当前消息配置进行设置的，启用后只有该消息配置发送的消息会按重复发送设置中的规则重复发送消息。

====== 1 消息平台概述 ======
===== 1.1 消息平台概述 =====
消息平台是V8.0系统新功能，通过定义消息模板和消息发送机制，可通过业务对象的操作触发并实时发送消息给用户，并且支持发送到第三方消息、邮箱和移动端，满足企业协作场景需求。消息平台实现了消息的即时发送和接收，从而提升企业内部的协作效率。

===== 1.2 消息平台特性 =====
  - 消息平台为系统免费的基础功能，无需购买即可应用；
  - 消息平台功能可授权管理员或是普通业务人员配置应用；
  - 管理员可设置接收哪些类型的消息，用户可配置消息的接收方式，满足用户个性化需求；
  - 消息模板可统一定义，支持消息通知（PC端铃铛）、消息轻应用（移动端）、第三方消息、邮件四个通道的消息内容配置；
  - 按业务需求定制消息配置的发送机制，配置消息触发操作和触发条件；
  - 消息实时发送和接收，操作触发即可触发并到达接收用户；
  - 消息级别智能处理，紧急级别消息必须手工干预，而警告和提醒级别消息会默认关闭；
  - 用户可从消息列表查看消息并标识消息是否已读，并且可查看历史消息；
  - 管理员或是授权用户可查看消息发送日志和消息配置执行情况；
  - 消息会按照清理规则自动清理。

## 【页面】消息配置最新执行情况
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%B6%88%E6%81%AF%E9%85%8D%E7%BD%AE%E6%9C%80%E6%96%B0%E6%89%A7%E8%A1%8C%E6%83%85%E5%86%B5

====== 1 消息平台概述 ======
===== 1.1 消息平台概述 =====
消息平台是V8.0系统新功能，通过定义消息模板和消息发送机制，可通过业务对象的操作触发并实时发送消息给用户，并且支持发送到第三方消息、邮箱和移动端，满足企业协作场景需求。消息平台实现了消息的即时发送和接收，从而提升企业内部的协作效率。

===== 1.2 消息平台特性 =====
  - 消息平台为系统免费的基础功能，无需购买即可应用；
  - 消息平台功能可授权管理员或是普通业务人员配置应用；
  - 管理员可设置接收哪些类型的消息，用户可配置消息的接收方式，满足用户个性化需求；
  - 消息模板可统一定义，支持消息通知（PC端铃铛）、消息轻应用（移动端）、第三方消息、邮件四个通道的消息内容配置；
  - 按业务需求定制消息配置的发送机制，配置消息触发操作和触发条件；
  - 消息实时发送和接收，操作触发即可触发并到达接收用户；
  - 消息级别智能处理，紧急级别消息必须手工干预，而警告和提醒级别消息会默认关闭；
  - 用户可从消息列表查看消息并标识消息是否已读，并且可查看历史消息；
  - 管理员或是授权用户可查看消息发送日志和消息配置执行情况；
  - 消息会按照清理规则自动清理。

====== 2 消息平台操作手册 ======
===== 2.1 消息设置 =====
消息设置提供了个性化设置功能，管理员可统一配置消息接收类型和消息清理规则，用户可设置不同消息类型的提醒方式。
===== 2.1.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息设置】
===== 2.1.2 关键功能 =====
  - 管理员设置接收消息类型：默认接收所有类型，管理员可取消勾选不接收该类型消息，管理员取消后则所有用户都收不到该类型的消息；
  - 管理员设置消息清理规则：默认保留7天内消息记录，超过7天的记录会归档到历史消息；历史消息默认保留30天，超过30天会自动清除；管理员可根据需要设置清理规则；
  - 用户设置消息提醒方式：消息提醒方式有：弹窗、闪烁、红点、语音，用户可根据自己需要设置提醒方式，默认是四种方式提醒。
===== 2.1.3 关键参数 =====
  - 单据后台操作触发消息发送机制：勾选该参数，在指定单据配置了[操作成功即触发]的消息配置时，单据操作执行成功会触发消息发送，也包括WebApi调用的单据操作成功触发消息发送；
  - 存在未读的紧急级别消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读的紧急级别消息就会弹窗提醒，提醒用户有多少条未读的紧急级别消息；
  - 存在未读消息则用户登录成功会弹窗提醒：勾选该参数则用户每次登录成功后系统检查到该用户有未读消息就会弹窗提醒，提醒用户有多少条未读消息，其中有多少条未读的紧急消息。

===== 2.2 消息模板 =====
消息模板是发送消息内容的基础信息，所有消息都会根据所选消息模板配置内容发送，方便用户维护消息内容。
===== 2.2.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息模板】

===== 2.2.2 关键字段说明 =====
  - 模板类型: 模板类型包括业务消息、预警消息、运营消息、公告消息；
  - 业务对象: 支持选择系统所有单据和基础资料；
  - 元数据: 业务对象的元数据字段；
  - 消息样式: 消息提醒的样式，目前支持了纯文本和表格；
  - 标题：消息标题，可选择元数据变量；
  - 内容：消息的详细内容，可选择元数据变量。

===== 2.2.3 主要功能操作 =====
  - 新增：选择模板类型和业务对象，设置消息通道的消息内容，消息内容目前只支持纯文本，消息内容支持选择元数据变量；    
    - 模板类型：业务消息、预警消息、运营消息、公告消息；
    - 消息通道：PC端消息通知、第三方消息、邮箱和消息轻应用；
    - 消息样式：纯文本和表格，后续会支持其他样式比如图片等；
    - 消息内容：消息数据可设置元数据变量，运营消息和公告消息支持设置链接地址；    
  - 删除：删除时校验是否有被引用，如被引用不允许删除；
  - 禁用/反禁用：禁用时校验是否被引用，如被引用不允许禁用。

===== 2.2.4 其他业务说明 =====
  - 业务消息和预警消息模板类型业务对象是必录字段，运营消息模板类型业务对象是非必录字段，公告消息模板类型无需选择业务对象；
  - 运营消息和公告消息模板类型的消息内容支持设置链接地址；
  - 消息内容样式目前支持了纯文本和表格（后续会支持其他样式）。

具体见【[[消息模板|消息模板]]】的介绍。

===== 2.3 消息配置 ===== 
根据业务协作需求配置操作成功发送消息，提醒协作团队业务处理进度以及处理事项，提升企业协作效率。
===== 2.3.1 功能路径 =====
  - 功能路径：【基础管理】-【消息平台】-【消息配置】

===== 2.3.2 关键字段说明 =====
  - 消息类型: 消息类型包括业务消息、预警消息、运营消息、公告消息；
  - 消息级别：消息级别由高到低分别是紧急、警告、提醒；
  - 业务对象: 支持选择系统所有业务对象；
  - 触发操作: 业务对象的标准操作，支持多选；
  - 消息设置：选择消息模板和消息通道，消息模板是对应消息类型和业务对象对应模板，消息通道是模板定义了内容的通道；
  - 消息接收人：消息接收人可选择基础用户、变量用户、预置接收人、手机号码、邮箱地址和业务员，支持随时维护；
  - 发送条件：业务对象条件设置，满足条件的数据才会发送消息。
  - 消息查看设置：可以设置接收到消息后直接通过点击消息打开业务对象的单据，方便快速处理业务。

===== 2.3.3 主要功能操作 =====
  - 新增：选择消息类型、消息级别、业务对象、触发操作、消息模板、消息通道、消息接收人，并且设置消息发送条件，启用即生效；    
  - 删除：只能删除无效的配置信息，已审核数据不允许删除；
  - 禁用/反禁用：只能禁用已审核数据；
  - 重复发送：可以设置消息重复发送，仅支持PC端，该设置是基于当前消息配置进行设置的，启用后只有该消息配置发送的消息会按重复发送设置中的规则重复发送消息。

===== 2.3.4 其他业务说明 =====
  - 所选消息模板没有设置消息通道内容则通道灰显不允许选择；
  - 启用生效后操作成功即会按照设置发送消息；
具体见【[[消息配置|消息配置]]】的介绍。

===== 2.4 消息发送 ===== 

  - 操作业务，根据消息配置的发送条件和触发操作，操作成功即会发送消息；
  - 消息发送后，接收人会立即收到消息；
  - 紧急级别消息弹窗会一直显示在界面，需要用户手工关闭并置为已读，
  - 警告级别消息默认会10秒关闭并置为未读；
  - 提醒级别消息默认会8秒关闭并置为未读；
  - 手工关闭都会置为已读。

===== 2.5 消息接收 ===== 

  - 操作业务，根据消息配置的发送条件和触发操作，操作成功即会发送消息； 
  - 消息接收人会在对应的消息通道收到消息通知；
  - 消息提醒方式会按照用户设置方式提醒，如弹窗、红点、闪烁；
  - 铃铛红点代表有新消息或是未读消息；
  - 鼠标移上去会提示有多少条未读消息；
  - 弹窗消息如果设置了链接地址，则会优先打开链接内容；
  - 点击铃铛进入消息通知列表，显示当前用户接收消息。

===== 2.6 消息查看 ===== 

  - 管理员和授权用户可查看全部消息通知；
  - 普通用户点击铃铛查看发送给自己的所有消息通知；
  - 可选择未读消息标记为已读；
  - 消息通知默认保留7天内消息，超过7天内消息会自动归档到历史消息；
  - 可通过查看历史来读取历史消息，历史消息默认保留30天，超过30天的消息会自动清理；
  - 可点击消息查看消息详细信息。

===== 2.7 消息清理 ===== 

  - 管理员可通过消息设置来设置消息清理规则；
  - 默认会保留30天，超过30天的消息为自动清理。

===== 2.8 消息发送日志查看 ===== 

  - 消息发送日志列表记录了所有通道所有类型的消息发送日志；
  - 日志详细记录了发送和接收信息，以及消息内容等；
  - 日志记录了消息发送状态。

===== 2.9 消息配置最新执行情况列表 ===== 

  - 消息配置执行情况只记录最后一次执行情况；
  - 可通过查看消息配置执行情况详细信息查看执行记录。

## 【页面】短信服务配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%9F%AD%E4%BF%A1%E6%9C%8D%E5%8A%A1%E9%85%8D%E7%BD%AE

======1 功能描述 ======

注意：V8.2以后版本下架云短信相关内容。

在实际业务运行中，经常需要短信服务的支持，例如：付款需要发送短信验证码，审批流审批通过后发送短信消息等。
使用短信服务需进行短信服务配置。

每个数据中心可分别设置短信服务，主要有两个短信服务：一个是金蝶云短信服务，另一个是维那多短信服务（购买后提供企业的用户帐号和密码）。

**功能路径**

【基础管理】→【公共设置】→【短信服务】→【短信服务配置】

======2 功能操作 ======

=====2.1 金蝶云短信 =====

Administrator登录数据中心，选择功能路径：【基础管理】→【公共设置】→【短信服务】→【短信服务配置】，在短信服务配置界面，勾选“金蝶云短信”，点击【启用】即可完成配置。

  - 使用短信服务前需要先启用，若禁用短信服务，系统将无法使用短信服务；
  - 【查询套餐余额】可以查询短信套餐的余额情况，包括：购买可用数量、累计使用数量（各数据中心使用数量合计）、未使用数量；
  - 【申请自定义签名】可以申请企业自定义的短信签名，提交后需要人工审核（1个工作日即可审核完成），审核通过即自动更新为新签名发送；
  - 需要购买金蝶云短信套餐才可以使用，非正式许可下提供200条云短信免费使用；
  - 要求金蝶云所在服务器可以访问云平台短信服务接口api.kingdee.com。


=====2.2 维那多短信 =====
Administrator登录数据中心，选择功能路径：【基础管理】→【公共设置】→【短信服务】→【短信服务配置】，在短信服务配置界面，勾选“维那多短信”。

  - 购买金蝶短信点卡（维那多短信），即可获取企业的用户帐号和密码，短信服务配置界面输入帐号和密码，点击【启用】按钮即可启用短信服务；
  - 使用短信服务前需要先启用，若禁用短信服务，系统将无法使用短信服务；
  - 点击【修改密码】，可进行密码修改；
  - 点击【查询余额】，可以查询短信套餐的余额情况；
