## 【页面】pos账单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=pos%E8%B4%A6%E5%8D%95

[[门店营业分析|>>门店营业分析]]

===== 1.功能概述 =====
POS账单统计分析账单信息，包括账单编号、人数、房台、折扣价、折扣率、开台时间、收银员、工作站编码、数据状态、账单金额、账单数据来源、账单类型
====== 2.使用前提 ======
存在实际发生的业务数据，并通过门店数据交换或门店日结上传账单数据
====== 3.功能路径 ======
【餐饮门店管理】→【门店营业分析】→【财务集成】→【POS账单】
====== 4.报表过滤条件 ======
过滤条件区域包括页签：高级、条件、显示隐藏列、排序

  * 高级页签：报表的快捷过滤界面，限定报表的区间取数范围，一个字段支持一个区间 
  * 条件页签：为快捷页签的补充，支持同一字段的分段区间并集 
  * 显示隐藏列页签：可设置报表显示界面字段列是否隐藏 
  * 排序页签：报表显示字段排序
====== 5.报表字段说明 ======
^ 字段    ^ 说明          ^
| 营业组织  | 组织          |
| 营业日期  | 营业时间        |
| 账单金额  | 账单金额        |
| 账单类型  | 1.外卖；2.堂食等  |
| 结算方式  | 结算方式        |
| 客付金额  | 顾客支付金额      |
| 找赎    | 找赎金额        |
| 食品名称  | 食品名称        |
| 食品部门  | 部门          |
| 下单数量  | 下单数量        |
| 销售金额  | 销售金额        |

====== 6.报表操作说明 ======
1、报表提供冻结列设置、打印、引出功能。

2、报表提供按表头的【组织】汇总合计每一个POS账单的详细信息

3、报表提供过滤->分组汇总，在报表中对分组字段进行小计且对【数量】、【金额】进行合计，其中分组字段包括：组织、营业日期、部门等

4、可以通过勾选【选项】中的参数，不显示分录行的合计、小计 。

|单折扣||对应营业日期的账单单折扣之和，单折扣包括：折扣率、全单折、食品类别折扣|

|礼券面额||对应营业日期的账单礼券面额之和|
|账单进位差|| 账单进位差=账单进位差-（食品费+服务费+房费-折扣价-单折扣-礼券折扣） |
|账单金额||对应营业日期的账单金额之和|
|实收金额||对应营业日期的账单实收金额之和|
|找赎||对应营业日期的账单找赎之和|
|收入净额||收入净额=实收金额-找赎|
|现金净额||对应营业日期的账单结算方式类别为“现金”的结算方式收入之和|
|发票金额||对应营业日期的账单发票金额之和|
|营收金额||对应营业日期的账单为“营收”的结算方式收入之和|

|人均消费||对应营业日期的人均消费，人均消费=收入净额/人数，人数为0时人均消费等于0|
|食品类别统计||对应营业日期的各食品类别的收入金额汇总|
|结算方式||对应营业日期的各结算方式的收入金额汇总|



======6.报表操作说明======
