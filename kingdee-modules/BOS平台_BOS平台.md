====== 1 概述 ======

金蝶AI星空BOS（Business Operating System，业务操作系统），是一个开放的集成与应用平台，是金蝶ERP 解决方案、合作伙伴解决方案以及客户定制应用的技术基础。

金蝶AI星空BOS能够为企业灵活而迅速的设计、构建、实施和执行一套随需应变的ERP系统；并能够与现有的IT基础设施无缝地协同运作；为不同行业不同企业的不同的应用阶段，提供随需应变的ERP解决方案。

企业用户通过BOS可以方便的进行业务配置，也可以通过BOS集成开发平台高效的进行个性化、行业化定制，使金蝶AI星空持续满足客户的需要，打造企业客户随需应变的ERP 系统，为客户带来持久的信息化投资收益。

====== 3 系统特性 ======

金蝶AI星空BOS关注于客户应用中业务逻辑部分：包括业务对象设计、界面定义、流程定义、业务规则设计、报表设计、部署等环节，同时允许通过插件开发来扩展BOS现有的功能。

金蝶AI星空BOS平台主要包括以下功能：

  * [[基础资料设计|基础资料设计]]

  * [[业务单据设计|业务单据设计]]

  * [[动态表单设计|动态表单设计]]

  * [[系统参数设计|系统参数设计]]

  * [[弹性域设计|弹性域设计]]

  * [[账表设计|账表设计]]

基于以上业务对象设计，金蝶AI星空BOS提供丰富的常规字段、通用控件、表单服务、插件及接口支持等。

金蝶AI星空BOS相关特性如下：

  * BOS集成开发平台全面支持各业务应用需求，支持定义动态表单、基础资料、业务单据、过滤条件等，抽象出丰富的表单逻辑，便于业务扩展自定义；

  * 灵活易用的BOS运行平台，支持用户在运行时根据个人习惯设置运行效果；

  * 单据转换提供全程跟踪表，轻松实现跨级携带跨级反写，并支持跨组织转换、分组合并转换；

  * 报表支持企业用户自定义形式多样的报表，以满足用户在统计方面的业务需求；

  * 易用完善的部署功能，可方便进行异地开发；

## 【页面】单据状态
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8D%95%E6%8D%AE%E7%8A%B6%E6%80%81

======1 功能概述 ======

  * 单据状态字段添加至单据头，用于配置单据状态以及各个状态下的字段控制、菜单控制。
  * 单据状态字段添加至单据体，用于配置表体行状态，控制各状态下表体字段的锁定性，及表体菜单的锁定性。
  * 运行时单据状态的取值，根据设计时操作绑定的状态取值，在操作执行时自动刷新。

======2 操作步骤 ======


  - 点击单据状态字段属性状态列表按钮，打开单据状态信息窗口； 
  - 通过【新增行】操作，输入状态值、状态名称等内容； 
  - 设置字段控制，控制当前状态下字段是否可编辑； 
  - 设置菜单控制，控制当前状态下菜单按钮是否可用； 
  - 设置操作与单据状态关联，通过相应的操作实现单据状态的变更；
 
======3 字段说明 ======

  - 状态值: 设置一个状态值，同一个状态列表中不允许重复 
  - 状态名称: 设置状态名称，支持多语种 
  - 是否锁定界面控制: 设置是否锁定界面，对其进行操作会批量设置字段控制、菜单控制当前所有项的“是否控制”选项 
  - 是否清空操作字段: 设置是否情况操作字段。例如，上图重新审核设置操作人字段、操作日期字段，并勾选“是否清空操作字段”，表示单据状态为“重新审核”时，单据头审核人、审核日期字段的值被清空 
  - 字段控制: 设置字段控制的明细内容 
  - 菜单控制: 设置菜单控制的明细内容

## 【页面】单据设计与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8D%95%E6%8D%AE%E8%AE%BE%E8%AE%A1%E4%B8%8E%E5%BA%94%E7%94%A8

[[BOS平台|<<返回BOS平台]]

====== 1 业务场景 ======

业务单据是BOS应用最为广泛的业务对象，用于保存业务流程中发生的数据，承载各个业务流程之间的逻辑关系。

====== 2 操作步骤 ======

  - 登录BOS集成开发平台； 
  - 选择业务领域和子系统； 
  - 点击工具栏【新建】按钮，打开业务对象新建向导，选择新建方式； 
  - 拖动所需常规字段、通用控件至单据模板界面； 
  - 通过属性窗口对整单属性、字段属性，控件属性进行个性化设置，包括菜单集合、编码规则、单据状态等； 
  - 点击菜单栏【编辑】-【网络控制】按钮，设置单据网络控制； 
  - 单据模板设计完成之后，点击工具栏【保存】按钮，业务单据创建完成，可通过输出窗口查看元数据校验情况，也可通过F5、F8对单据进行测试； 
  - 点击视图栏【新建】按钮，创建单据视图； 
  - 点击工具栏【文件】-【单据转换】按钮，设置单据转换； 
  - 点击工具栏【发布】-【发布到主控台】按钮，将业务单据发布到客户端主控台； 
  - 点击工具栏【部署】-【制作部署包】按钮，将业务单据制作部署包； 
  - 登录套打设计平台，为业务单据新建套打模板； 
  - 登录客户端主控台，选择【基础管理】-【基础资料】-【单据类型】，为业务单据创建单据类型； 
  - 主控台选择【流程中心】-【工作流】、【业务流程】，为业务单据新建工作流、业务流程； 
  - 主控台选择已发布的业务单据，通过工具栏按钮，对业务单据进行通用操作； 
  - 为方便用户快速查询到需要的业务单据数据，用户可使用通用过滤功能； 
  - 为满足用户个性化操作需求，用户可自定义选项设置； 
  - 通过单据附件管理功能，用户可维护单据附件； 
  - 通过单据引入引出功能，用户可将数据引入系统，也可从系统引出数据；

## 【页面】发布
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8F%91%E5%B8%83

======1 系统概述 ======

发布功能将对象发布到主控台，用户登录主控台后，可通过该功能生成的链接调用BOS业务对象相应功能。

======2 操作步骤 ======

  - 打开BOS设计器菜单栏【发布】下拉菜单，点击【发布到主控台】按钮，打开【功能发布管理】窗口； 
  - 依次选择业务领域、子系统、子功能、子功能明细，如果需要可编辑子功能和子功能明细； 
  - 点击子功能明细区域工具栏【新增】按钮，打开【主控台菜单明细功能维护】窗口，选择要发布业务对象，发布类型等信息； 
  - 勾选【发布状态】复选框，点击【保存】按钮，业务对象即可发布到主控台菜单； 

====== 字段说明 ======

  - 编码： 功能明细编码，为必填项 
  - 名称： 功能明细名称，为必填项 
  - 业务对象： 选择要发布的业务对象 
  - 权限项： 选择业务对象权限项，发布后需要授权，才能查看业务对象 
  - 发布类型： 选择业务对象发布类型 
  - 页面显示类型： 选择业务对象在主控台显示类型 
  - 子定义参数： 支持设置自定义参数 
  - 显示序号： 明细功能列表中的显示顺序 
  - 发布状态： 勾选后表示业务对象已发布

## 【页面】实体服务配置与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AE%9E%E4%BD%93%E6%9C%8D%E5%8A%A1%E9%85%8D%E7%BD%AE%E4%B8%8E%E5%BA%94%E7%94%A8

**业务场景**

实体服务规则是在单据头、单据体等实体属性中配置，实现按自定义条件执行相关的服务。

**实体服务配置与应用**

  - 点击单据头属性【实体服务规则】，在弹出界面中点击新增，输入规则描述； 
  - 点击规则条件，配置服务规则的执行条件，可双击字段，自动填写字段关键字id，点击右侧的符号，配置条件公式。 
  - 新增服务，包括条件成立时执行的服务和条件不成立时执行的服务，可以对服务进行曾删改操作，多条服务时可调整服务的执行顺序，默认从上到下依次执行。 
  - 选择服务类型，选择执行的服务，不同服务，编辑界面是不同的，根据具体的服务进行配置。

## 【页面】引入引出
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BC%95%E5%85%A5%E5%BC%95%E5%87%BA

======1 系统概述 ======

系统提供引入引出功能，是针对基础资料和单据数据，提供的一个供用户引入和引出功能的工具，这样方便用户快速实施、快速上线。

=====1.1 引出模板管理 =====
 
**系统概述**

引出模板在产品发版时都已经设置完成，只是在和第三方系统集成，或者有二次开发的情况下，需要改变模板才进行相关的模板改动，此功能不建议一般用户使用。 

**操作步骤**

  - BOS设计器中打开单据，选择字段的功能控制属性，取消勾选“不允许引出”选项，所有不勾选该选项的字段自动添加至该单据的引出模板； 
  - 单据保存时引出模板在系统后台自动生成； 
  - 引出模板内以多页签的形式列出单据实体内支持引出的字段； 
  - 引出模板适用于按引出模板引出数据；

===== 1.2 按列表引出 =====
 
**系统概述**  

运行时在单据列表界面工具栏提供【按列表引出】功能按钮，支持按列表引出数据，引出内容与列表展示保持一致，所见即所得。

**操作步骤**

  - 打开单据列表界面，设置过滤条件； 
  - 点击【按列表引出】按钮，引出过滤结果展示的所有数据，保存文件至本地路径；
 
=====1.3 按引出模板引出 =====
 
**系统概述** 

运行时在单据列表界面工具栏提供【按引出模板引出】功能按钮，支持按单据引出模板的形式引出数据，引出文件中采用多页签的形式展示，页签与单据实体一一对应。

**操作步骤**

  - 打开单据列表界面，设置过滤条件； 
  - 点击【按引出模板引出】按钮，引出过滤结果展示的所有数据，保存文件至本地路径； 

=====1.4 引入模板管理 =====
 
**系统概述**

引入模板在产品发版时都已经设置完成，只是在和第三方系统集成，或者有二次开发的情况下，需要改变模板才进行相关的模板改动，此功能不建议一般用户使用。
 
引入模板内单据头实体、子单据头实体、单据体、子单据体等实体内的字段统一放入单据头实体页签内，其中相邻实体字段采用不同颜色底色标识。

**操作步骤**

  - BOS设计器中打开单据，选择字段的功能控制属性，勾选“允许引入”选项，所有勾选该选项的字段自动添加至该单据的引入模板； 
  - 单据保存时引入模板在系统后台自动生成； 
  - 引入模板适用于追加引入、覆盖引入；

=====1.5 引入模板配置 =====
 
**系统概述**

引入模板支持运行时配置，引入模板配置界面按实体展示BOS IDE中设置允许引入和允许引出的所有字段，用户可以在其中去除不需要引入的字段，其中必录字段以“*”号标识，引入模板配置方案按用户保存。

**操作步骤**

  - 打开单据列表界面，点击工具栏【引入模板配置】按钮，打开引入模板配置界面； 
  - 选择相应的实体,设置实体内需要在引入模板内展示的字段，模板内允许引入的字段，支持引入数据，允许引出但不允许引入的字段仅作为参考字段，不支持引入引入设置完成后保存当前单据的引入方案，引入模板配置方案按用户保存； 
  - 点击列表工具栏【引入】按钮，打开引入窗口，点击【引入模板】链接，即可下载引入模板，适用于追加引入； 

=====1.6 按引入模板引出数据 =====
 
**系统概述** 

运行时在单据列表界面工具栏提供【按引入模板引出】功能按钮，支持按单据引入模板的形式引出数据，引出文件中含有系统数据，字段布局与引入模板一致。

**操作步骤**

  - 打开单据列表界面，设置过滤条件； 
  - 点击列表工具栏【按引入模板引出数据】按钮，即可下载含有当前过滤数据的引入模板，用于覆盖引入； 
  - 如果列表含有分组信息，则第一个页签包含所有的分组信息，第二页签为列表数据信息；

=====1.7 追加引入 =====
 
**系统概述**

引入界面系统默认选择追加引入模式，引入过程采用数据追加的方式将引入模板内的数据新增到系统数据库中，支持引入时仅暂存处理。

**操作步骤**

  - 点击列表工具栏【引入】按钮，打开引入窗口； 
  - 点击【引入模板】链接，下载引入模板； 
  - 根据模板内的使用说明填写模板； 
  - 通过引入窗口选择编辑好的模板文件，点击【引入数据】按钮，进行数据引入； 

**注意**

  * 页签内的数据通过单据头序号、子单据头序号、单据体序号、子单据体序号来实现对应关系，追加引入时单据头、子单据头序号可以不填，单据体序号与子单据体序号需要正确填写；
  * 引入模板内单据所有实体内的字段统一放入单据头实体页签内，各实体间采用实体间隔列隔开，相邻实体采用不同颜色区分；

=====1.8 覆盖引入 =====
 
**系统概述**

引入界面支持选择覆盖引入模式，系统以模板内单据的单据编号为依据，检索数据库中具有相同单据编号的的单据，进行覆盖引入，检索不到的部分不进行引入，如果勾选【引入时允许追加】选项，则检索不到的部分进行追加引入。
支持追加引入新的分录行，在已有单据的基础上，覆盖引入修改单据信息，如果匹配到分录序号和现有序号相同，则修改对应行数据，如果没有匹配到的分录序号，则新增行。

**注意**

  * 普通列表项目引入模板内无单据编号时，使用单据内码作为检索校验依据。 

**操作步骤** 

  - 打开单据列表界面，设置过滤条件； 
  - 点击【按引入模板引出数据】按钮，保存文件至本地路径，对文件进行编辑； 
  - 点击列表工具栏【引入】按钮，打开引入窗口，选择【覆盖引入】模式，支持设置覆盖引入时允许追加引入； 
  - 在引入窗口选择编辑好的模板文件，点击 【引入数据】按钮，进行数据引入； 

=====1.9 分组引入 =====

**系统概述**

分组引入是指含有分组信息的基础资料或辅助资料，引入时可以连同分组信息一起追加引入，分组信息支持按引入模板引出并作为覆盖引入模板。

**操作步骤** 

  - 打开单据列表界面，下载引入模板或按引入模板引出数据，保存文件至本地路径； 
  - 对文件内分组页签进行编辑，分别录入单据头序号、分组的父节点编码、分组编码、分组名称，含有父节点的分组需要填写父节点编码，不含父节点的分组，父节点为空，追加引入时以分组编码做唯一性校验，已存在的分组不允许引入，覆盖引入时以编码父节点编码和分组编码作为依据，已存在的分组信息进行覆盖引入； 
  - 点击列表工具栏【引入】按钮，打开引入窗口，选择引入模式； 
  - 在引入窗口选择编辑好的模板文件，点击 【引入数据】按钮，进行数据引入；

## 【页面】操作列表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%93%8D%E4%BD%9C%E5%88%97%E8%A1%A8

======1 功能概述 ======

在单据属性中可以通过操作列表定义业务对象的操作类动作、并根据所选操作设置业务对象的权限项、及其单据校验规则，用户可根据需要将单据菜单集合、单据体菜单集合、列表菜单的操作，统一设置并添加到操作列表。

======2 操作步骤 ======

1、点击单据属性【操作列表】选项按钮，打开操作列表窗口，支持新增、编辑、删除操作； 

2、点击【新增】按钮，打开操作编辑界面，点击【操作类型】按钮，打开操作选择窗口，选择一个操作，点击【确定】后返回操作编辑； 

3、操作编辑界面可编辑已选操作的操作代码及名称、参数设置、其他控制等，使同一个操作关联不同的参数和控制，并以不同的名称展示在操作列表中； 
  * 参数设置页签，支持设置操作与单据状态字段绑定，并设置该操作执行时，单据状态取值； 
  * 其他控制页签，支持设置操作的校验规则、权限项，以及是否写操作日志等； 

4、操作编辑完成后，点击【确定】，返回操作列表，继续新增、编辑下一个操作； 

======3 操作说明 ======

=====3.1 单据菜单 =====
 
====3.1.1 功能概述 ====

通过单据的【菜单集合】属性，可以设置单据上显示的菜单项或工具栏。

===3.1.2 操作步骤 ===

  - 单击单据【菜单集合】属性，弹出菜单编辑界面； 
  - 选中树型结构中的【菜单集】项，单击鼠标右键选择新增工具条； 
  - 选中新增的工具条，单击鼠标右键新增按钮和下拉按钮，选中新增的下拉按钮，点击鼠标右键选择新增按钮； 
  - 选中新增的按钮或下拉按钮，可以设置按钮属性，参见字段说明表； 
  - 点击【点击事件】按钮，打开【点击事件】窗口，点击【新增操作】按钮，打开【服务编辑】窗口，在操作列表中选择相应的操作，即可实现按钮的操作功能； 

===3.1.3 字段说明 ===

  - 标题： 设置工具栏按钮设计时的标题名称
  - 工具栏提示： 鼠标移到工具栏按钮后显示的tips提示
  - 快捷键： 设置工具栏按钮的快捷键
  - 图标键： 设置工具栏按钮的图标
  - 描述： 设置工具栏按钮运行时的描述
  - 是否可用： 设置工具栏按钮在查看、新增和修改三种状态下是否可用
  - 提交时校验： 设置是否提交时校验
  - 是否可见： 设置工具栏按钮在查看、新增、修改、初始加载等状态下是否可见
  - 序号： 设置工具栏按钮的序号
  - 是否勾选： 设置是否勾选
  - 是否显示标题： 设置工具栏按钮是否显示标题
  - 标题位置： 设置标题位置
  - 显示进度条： 设置是否显示进度条
  - 进度条提示信息： 设置进度条提示信息
  - 点击事件: 新增服务：从内置表单服务中选择服务并进行设置；新增操作：从操作列表中选择操作
 
=====3.2 单据体菜单 =====

====3.2.1 功能概述 ====

通过单据体的【菜单集合】属性，可以设置单据体工具栏。

====3.2.2 操作步骤 ====

  - 单击单据体【菜单集合】属性，弹出菜单编辑界面； 
  - 选中树型结构中的【菜单集】项，单击鼠标右键选择新增工具条； 
  - 选中新增的工具条，单击鼠标右键选择新增按钮； 
  - 选中新增的按钮，设置按钮属性； 
  - 点击【点击事件】按钮，打开【点击事件】窗口，点击【新增操作】按钮，打开【服务编辑】窗口，在操作列表中选择相应的操作，将操作参数设置为相应的单据体； 

=====3.3 列表菜单===== 

====3.3.1 功能概述 ====

通过单据的【列表菜单】属性，可以设置单据列表上显示的菜单项或工具栏。

====3.3.2 操作步骤 ====

  - 单击单据【列表菜单】属性，弹出菜单编辑界面； 
  - 选中树型结构中的【菜单集】项，单击鼠标右键可以新增工具条； 
  - 选中新增的工具条，单击鼠标右键可以新增按钮和下拉按钮，选中新增的下拉按钮，击鼠标右键可以新增按钮； 
  - 选中新增的按钮或下拉按钮，可以设置按钮属性； 
  - 点击【点击事件】按钮，打开【点击事件】窗口，点击【新增操作】按钮，打开【服务编辑】窗口，在操作列表中选择相应的操作，即可实现按钮的操作功能； 
  - 点击【可用性】按钮，可设置按钮在普通列表、上下查列表、选单列表的可用性； 
  - 点击【可见性】按钮，可设置按钮在普通列表、上下查列表、选单列表、初始加载时的可见性；

## 【页面】文件服务地址
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%96%87%E4%BB%B6%E6%9C%8D%E5%8A%A1%E5%9C%B0%E5%9D%80

====== 文件服务器 ======

  - 协议类型：和部署的IIS服务器设置有关，可以是http方式也可以是https方式，默认是http；
  - 金蝶云地址：当前登陆金蝶云应用服务器站点的IP地址；
  - 文件服务器地址：当前部署文件服务器的IP地址；
  - 端口：当前部署应用服务器端口，可为空；
  - 虚拟目录：当前安装应用服务器虚拟目录站点名称，默认为K3CloudFileServer;
  - 检测文件服务器是否可用：点击按钮进行测试，如果文件服务没有部署，则测试不能通过，保存也不会成功，也可用于检测其他已部署的文件服务是否可用；


====== 亚马逊云存储 ======

  - 线下用户配置好亚马逊信息之后，设置“启用”状态，则可把文件上传至亚马逊云盘。
  - 文件存储在“桶名”下与当前上传文件的dbId同名目录下

====== 腾讯云存储 ======

  - 线下用户配置好腾讯云存储信息之后，设置“启用”状态，则可把文件上传至腾讯云对象存储。
  - 文件存储在“桶名”下与当前上传文件的dbId同名目录下

====== 华为云存储 ======

  - 线下用户配置好华为云存储信息之后，设置“启用”状态，则可把文件上传至华为云对象存储服务。
  - 文件存储在“桶名”下与当前上传文件的dbId同名目录下

====== 阿里云存储 ======

  - 线下用户配置好阿里云存储信息之后，设置“启用”状态，则可把文件上传至阿里云对象存储。
  - 文件存储在“桶名”下与当前上传文件的dbId同名目录下

## 【页面】文件服务设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%96%87%E4%BB%B6%E6%9C%8D%E5%8A%A1%E8%AE%BE%E7%BD%AE

====== 功能概述 ======

文件服务设置用于配置当前系统启用何种文件服务实例。
目前支持的存储类型为数据库、文件服务器、亚马逊云存储、腾讯云存储、阿里云存储、华为云存储，同时也支持对接第三方文件服务实例。金蝶个人云存储、金蝶企业云存储即将关闭，目前不再支持;
线下环境推荐使用文件服务器，更方便对文件进行管理，公有云环境统一由运维配置。

====== 业务场景 ======

部署文件服务器之后，新增附件不再存储到数据库，而是存放在应用服务器的文件系统里，同时提供了附件在线预览的体验，这种体验就像是百度文库，公司发文系统一样，将附件下载与附件在线预览集成到星空权限体系，这样企业管理人员可以根据需要，为不同用户分配不同附件权限,极大降低数据库存储压力，提升DB吞吐性能，在线预览功能，解决企业信息安全隐患的同时，为操作员提供另一种更安全的方式阅览附件。

## 【页面】新建方式
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%96%B0%E5%BB%BA%E6%96%B9%E5%BC%8F

======1 系统概述 ======

单据支持通过新建向导，新建空白对象或继承、复制现有业务对象，支持对现有单据进行扩展.

======2 操作说明 ======

=====2.1 空白对象 =====
 
基于空白对象创建，不受任何约束，灵活度高，元素需要自行添加，可以将新建的业务对象作为模板后续进行继承新增。

=====2.2 继承 =====
 
1、继承原对象的元数据、界面元素以及相关属性，创建出新的业务对象。 
  * 对新对象的改动、增加字段，不影响原对象； 
  * 原对象的改动、增加字段，新对象会感知并体现出来 ； 
  * 原对象字段不得删除，关键属性不得修改； 
2、继承基对象模板，可快速自定义BOS单据。 
  * 基对象模板存放在BOS领域基对象模板和应用框架子系统下； 
  * 基对象模板类型包括：基础资料模板、业务单据模板、辅助资料模板、账表模板； 
  * 模板内已经内置了简单的字段及控件，包括单据编号、单据状态、单据体、单据菜单等 ；   
  * 模板内单据状态字段已经内置了五中类型的状态控制，菜单集合内置了BOS通用操作按钮；

=====2.3 复制 =====
 
基于原对象复制出新的业务对象，对原对象与新对象的改动不会相互影响，新建过程与继承方式相同。

=====2.4 扩展 =====
 
项目窗口中选择单据，鼠标右键菜单中选择扩展，新建源对象的一个扩展对象。

  * 新对象的字段、控件不允许删除，新增字段、控件不影响原对象； 
  * 原对象的改动、增加字段，新对象会感知并体现出来 ； 
  * 单据多次扩展后运行时的效果，是每次扩展后的差量叠加；

## 【页面】权限控制与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%9D%83%E9%99%90%E6%8E%A7%E5%88%B6%E4%B8%8E%E5%BA%94%E7%94%A8

**业务场景**

自定义单据及基础资料，默认没有做权限控制，需要做权限控制时要自定义权限对象，权限对象是单据权限的载体，它包含了单据功能操作的权限项，定义权限对象之后，才可以对单据进行功能权限授权。

**权限控制与应用**

  - 用Administrator用户登录主控台，点击【系统管理】-【权限基础设置】-【权限对象列表，在打开的权限对象列表中点击工具栏【新增】，打开权限对象新增界面，输入权限对象基本信息，并在权限项单据体中增加权限项，权限项是系统预置的用来控制功能操作的权限，根据单据模板预置的操作选择相应的权限项，包括：查看、复制、删除、新增、修改、提交、审核、反审核、附件、引入、引出、打印等，然后点击【保存】完成权限对象创建。 
  - BOS设计器中打开新建的【采购订单】，点击菜单栏【编辑】-【权限控制设置】，在弹出的权限控制设置界面【整体控制】页签，勾选控制功能权限和控制字段权限复选框，分别用于控制业务对象的功能权限和字段权限，在权限对象栏选择已创建的权限对象“采购订单”，退出界面并保存单据完成设置。 
  - 点击菜单栏【发布】-【发布到主控台】，打开功能发布管理界面，发布采购订单时，选择权限项为采购订单权限对象的“查看”权限项。 
  - 用系统管理员账户登录主控台，点击【系统管理】-【授权】-【业务对象功能授权】，打开业务对象功能授权界面，选择角色，勾选【显示全部业务对象】复选框，在业务对象列表中找到已创建的采购订单，在右侧的功能权限列表中将权限项设置为有权，点击工具栏【授权】，完成角色的业务对象功能权限授权。含有该角色的用户登录主控台，可以对采购订单进行相关的的操作。 
  - 系统管理员账户登录主控台，进入【系统管理】-【授权】，点击【字段授权】菜单，打开“字段授权”界面，选择角色，勾选【显示全部业务对象】复选框，在业务对象列表中找到已创建的采购订单，右侧字段权限列表中所有字段默认是有权的，在字段权限设置列表中通过下拉选择“无权/禁用”方式来设置字段的查看权和编辑权，点击工具栏【授权】，完成角色的业务对象字段权限授权。

## 【页面】模糊查询
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A8%A1%E7%B3%8A%E6%9F%A5%E8%AF%A2

**功能概述**

运行时基础资料字段，手动录入数时可根据已经录入的内容进行快速模糊查询，用户只需要录入部分数据，系统自动根据录入的数据进行左匹配检索，并列出检索结果，支持勾选【启用全模糊匹配】的方式进行全匹配方式检索，弹出的选择框中显示5个备选数据供用户选择，点击【更多】增加5条备选数据。可以更改匹配数据的字段，如编码、名称；也可以更改展示的数量为10、15、20。

**操作步骤**

  - 登录BOS设计器打开单据，选中基础资料字段属性【支持下拉模糊查询】； 
  - 登录主控台【系统管理】-【单据参数配置】； 
  - 选择一个基础资料，在模糊查询页签中勾选支持查询的基础资料属性，保存后退出； 
  - 打开单据选项设置界面，清空“禁止基础资料弹出列表自动显示”选项； 
  - 单据录入时相应的基础资料字段，可通过录入信息进行模糊查询，并弹出查询列表；

## 【页面】编码规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%BC%96%E7%A0%81%E8%A7%84%E5%88%99

====== 功能概述 ======

单据及单据编号字段的编码规则属性项，可以设置业务对象的单据编号生成规则，运行时单据保存时，可根据既定的规则自动生成单据编码，编码经过唯一性校验后，展示在单据编号字段上。

====== 操作步骤 ======

  - 单击编码规则属性弹出编码规则设置界面： 
  - 在规则列表中新增规则命名并保存； 
  - 选中新增的规则，定义编码规则明细，包括元素来源、编码依据、编码元素等； 
  - 选择一套规则，设置为默认规则，并设置是否编码可编辑、是否支持补号； 

====== 字段说明 ======

 
1、名称： 设置编码规则名称 

2、描述： 设置编码规则描述 

3、允许修改： 支持手工输入编号
 
4、默认规则： 设置默认的一套规则 

5、支持补号： 运行时支持手动补号，勾选后【允许修改】复选框自动勾选，当流水号步长或起始值为小数时不支持补号 

6、类型： 支持将单据上的文本字段、日期字段、基础资料及流水号和常量 

7、元素来源： 类型选择为文本字段、日期字段、基础资料时，元素来源可以选择单据中对应类型的字段 

8、来源属性： 类型选择为基础资料时，来源属性可选择代码或名称 

9、长度： 设置对应类型的长度 

10、右侧截断： 当长度超过指定长度后，右侧自动进行截断 

11、分隔符： 标识文字分割位置的字符 

12、替代符： 编码生成时取不到元素值时的替代字符 

13、补位符： 长度不够时的补位字符 

14、右侧填充： 当长度小于指定长度后，将自动在右侧进行补充。如果不勾选，表示默认从左侧填充。

15、格式： 当元素类型=日期字段时，格式必须选择一个日期格式；当元素类型=常量、流水号字段时，格式字段无法设置；当元素类型=文本字段、基础资料时，可以设置字母格式，设置方式包括：
  * 大写即将字母全部转换为大写字母； 
  * 小写即将字母全部转换为小写字母； 
  * 为空即保留取值的正常状态； 
 
16、设置值： 如果类型选择常量，可以设置常量的值 

17、起始值： 设置流水号的起始值，支持整数和小数 

18、步长： 设置流水号的步长，支持整数和小数 

19、编码依据： 设置对应的类型为编码依据来控制流水号，支持设置基础资料、文本、日期类型，支持设置多个编码依据，设置组织为编码依据时，做组织内编码唯一性校验 

20、编码元素： 设置对应的类型为编码组成元素

## 【页面】网络控制
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%BD%91%E7%BB%9C%E6%8E%A7%E5%88%B6

======1 功能概述 ======

为了保证Cloud系统的性能以及数据的正确性和独立性，对一些大量占用系统资源的功能或者相互之间同时运行会影响数据正确性的功能，设置功能互斥，进而对这些功能实施控制。

======2 操作说明 ======

=====2.1 系统独占 =====
 
**功能概述**

用户打开某个系统，系统即被锁定，其他人打开这个系统会提示已被人锁定。

**操作步骤**

  - 点击BOS设计器菜单栏【编辑】菜单中的【网络控制设置】按钮，弹出网控设置窗口； 
  - 网控类型列表中，选择系统独占，点击【新增】按钮，打开网控对象列表； 
  - 点击【新增】按钮，打开系统独占设置窗口，勾选系统（业务领域）后点击【确定】返回网控对象列表，点击【保存】按钮，将所选系统添加至网控列表； 
  - 选中已添加至网控列表的系统，点击多组织列表【新增】按钮，打开多组织隔离新增窗口； 
  - 勾选需要设置多组织隔离的业务组织，点击【确定】，即可完成系统独占设置； 

=====2.2 子系统独占 =====
 
**功能概述**

用户打开某个子系统A，子系统A即被锁定，其他人打开这个子系统A会提示已被人独占。

**操作步骤**

  - 点击BOS设计器菜单栏【编辑】菜单中的【网络控制设置】按钮，弹出网控设置窗口； 
  - 网控类型列表中，选择子系统独占，点击【新增】按钮，打开网控对象列表； 
  - 点击【新增】按钮，打开子系统独占设置窗口，勾选子系统，点击【确定】返回网控对象列表，点击【保存】按钮，将所选子系统添加至网控列表； 
  - 选中已添加至网控列表的系统，点击多组织列表【新增】按钮，打开多组织隔离新增窗口； 
  - 勾选需要设置多组织隔离的业务组织，点击【确定】，即可完成子系统独占设置；
 
=====2.3 子系统互斥 =====
 
**功能概述**

用户打开某个子系统A，关联的子系统B会被锁定，其他人打开这个子系统B会提示已被人锁定。注意：子系统A与子系统B可为同一个子系统。

**操作步骤**

  - 点击BOS设计器菜单栏【编辑】菜单中的【网络控制设置】按钮，弹出网控设置窗口； 
  - 网控类型列表中，选择子系统互斥，点击【新增】按钮，打开网控对象列表； 
  - 点击【新增】按钮，打开子系统独占设置窗口，勾选子系统，点击【确定】返回网控对象列表，点击【保存】按钮，将所选子系统添加至网控列表； 
  - 选中已添加至网控列表的系统，点击多组织列表【新增】按钮，打开多组织隔离新增窗口，勾选需要设置多组织隔离的业务组织； 
  - 选中已添加至网控列表的子系统，点击互斥列表【新增】按钮，打开网控互斥列表，勾选互斥的子系统后，点击【保存】即可完成子系统互斥设置； 

=====2.4 子功能明细互斥 =====
 
**功能概述**

用户打开某个子系统子功能A的明细功能A1，关联的子系统子功能B的明细功能B1会被锁定，其他人打开这个子系统子功能B的B1功能会提示已被人锁定。

**操作步骤**

  - 点击BOS设计器菜单栏【编辑】菜单中的【网络控制设置】按钮，弹出网控设置窗口； 
  - 网控类型列表中，选择子功能明细互斥，点击【新增】按钮，打开网控对象列表； 
  - 点击【新增】按钮，打开子功能明细互斥设置窗口，勾选子功能明细（业务单据），点击【确定】返回网控对象列表，点击【保存】按钮，将所选子功能明细添加至网控列表； 
  - 选中已添加至网控列表的系统，点击多组织列表【新增】按钮，打开多组织隔离新增窗口，勾选 需要设置多组织隔离的业务组织； 
  - 选中已添加至网控列表的子功能明细，点击互斥列表【新增】按钮，打开网控互斥列表，勾选互斥的子功能明细后，点击【保存】即可完成子功能明细互斥设置； 

=====2.5 业务操作互斥 =====

**功能概述**

用户打开某个子系统子功能A某张单据，使用明细功能A1，子系统子功能A的这张单据明细功能A2会被锁定，其他用户打开这个子系统子功能A的这张单据使用A2功能会提示已被人锁定，用户打开其他子系统下的子功能B的一张单据使用B1功能会提示已被人锁定。

**操作步骤**

  - 点击BOS设计器菜单栏【编辑】菜单中的【网络控制设置】按钮，弹出网控设置窗口； 
  - 网控类型列表中，选择子功能明细互斥，点击【新增】按钮，打开网控对象列表； 
  - 点击【新增】按钮，打开网控操作列表窗口，点击【新增】，打开单据选中界面，选择业务单据后返回，勾选业务单据的业务操作，点击【确定】返回网控对象列表，点击【保存】按钮，将所选业务操作添加至网控列表； 
  - 选中已添加至网控列表的业务操作，点击互斥列表【新增】按钮，打开网控互斥列表，勾选互斥操作，这里可以勾选本单据和其他单据的操作，点击【保存】即可完成业务操作互斥设置；

## 【页面】视图设计与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%A7%86%E5%9B%BE%E8%AE%BE%E8%AE%A1%E4%B8%8E%E5%BA%94%E7%94%A8

**业务背景**

单据视图可以理解为单据上的控件，做了功能定制之后的展现形式，一张单据支持配置多个视图，设置的单据视图，可以支持在工作流、单据类型、快速录单中调用，无需再设置界面控制方式，而是直接选取合适的视图来实现界面控制。

**视图设计与应用**

  - 登录BOS集成开发平台； 
  - 选择业务领域和子系统； 
  - 打开业务单据，点击视图栏【新建】按钮，编辑区显示视图界面，通过视图属性可编辑视图名称等信息； 
  - 通过视图内的字段、控件属性可设置字段、控件的必录性、可见性、锁定性、位置等信息，通过菜单集合可设置菜单的可见性、所定性等信息； 
  - 单据扩展后的单据可携带原来单据的视图，扩展的单据支持新建视图，扩展的单据增加的字段、控件展示在扩展对象栏，扩展单据新增视图时，可从扩展对象栏添加控件、字段； 
  - 视图栏内当前展示的视图，可通过视图栏【删除】按钮，进行删除； 
  - 视图支持在单据类型中应用，支持单据类中单据布局方案调用视图； 
  - 视图支持在工作流中应用，支持流程节点界面配置调用视图； 
  - 视图支持作为单据快速录单视图，运行时单据新增界面支持切换快速录单视图界面；

## 【页面】账表设计
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%A6%E8%A1%A8%E8%AE%BE%E8%AE%A1

======1 功能概述 ======

账表是账簿记录与报表内容的统称。依据账表的不同展现形式，系统提供简单账表、树形账表、分页账表、直接SQL账表、透视表、简单报表这六种类型报表。

======2 操作步骤 ======

  - 在金蝶AI星空系统登录界面选择数据中心，登录BOS 设计器； 
  - 进入BOS设计器之后，在系统视图窗口，选择业务领域和子系统； 
  - 点击BOS设计器工具栏【新建】按钮，通过业务对象新建向导新建账表； 

 ======3 操作说明 ======

=====3.1 简单账表 =====
 
**功能概述**

一种报表，直接显示报表数据，通过构建插件设置报表数据源。

**操作步骤**

  - 通过新建向导建立简单账表； 
  - 通过插件设计简单账表功能；

=====3.2 树形账表 =====
 
**功能概述**

一种报表，支持以树形结构显示报表数据，通过构建插件设置报表数据源。

**操作步骤**

  - 通过新建向导建立树形账表； 
  - 通过插件设计树形账表功能；

=====3.3 分页账表===== 

**功能概述**

一种报表，支持分页显示报表数据，通过构建插件设置分页报表数据源。

**操作步骤**

  - 通过新建向导建立分页账表； 
  - 通过插件设计分页账表功能；

=====3.4 直接SQL账表===== 

**功能概述**

 一种报表，使用直接SQL方式来制作较为复杂的关联报表，熟悉SQL SERVER的用户可以用它来制作本企业的个性化报表。本版本支持将直接SQL报表发布到主控台查看。

**操作步骤**

  - 在金蝶AI星空系统登录界面选择数据中心，登录BOS 设计器； 
  - 进入BOS设计器之后，在系统视图窗口，选择业务领域和子系统； 
  - 点击BOS设计器工具栏【新建】按钮，通过业务对象新建向导新建直接SQL报表； 
  - 在新建的直接SQL报表属性中点击【数据源】，打开自定义报表向导界面； 
  - 点击下一步进入关键字维护和SQL语句输入界面，点击【关键字维护】按钮，进入【报表关键字】界面，可新增、删除、修改关键字； 
  - 在SQL语句输入框内输入要生成报表的SQL语句，点击下一步，系统进行SQL语句校验，若不正确，系统会提示语法错误，若正确，向导进入下一步； 
  - 定义显示列信息界面，可设置报表显示列，及列名称，设置完成后点击下一步； 
  - 向导界面显示完成信息，包含报表总列数、显示列数及隐藏列数，点击完成，建立直接SQL报表结束； 
  - 运用BOS平台发布功能，可将新建的直接SQL报表发布至主控台查看，功能参见发布； 
  - 主控台打开已发布的直接SQL报表，打开过滤界面，可设置报表查询关键字； 

=====3.5 透视表=====

**功能概述**

一种报表，支持类似Excel中数据透视图样式的交叉分析报表，通过构建插件设置透视表表数据源。

**操作步骤**

  - 通过新建向导建立分透视表； 
  - 通过插件设计透视表表功能；

=====3.6 简单报表=====

**功能概述**

简单报表是以基础资料、业务单据为数据源，通过向导设置字段的分组、汇总、排序实现单据列表式的简单报表功能，包括明细账表、汇总账表、明细账表，账表发布后，主控台可调用。

**操作步骤**

  - 在金蝶AI星空系统登录界面选择数据中心，登录BOS 设计器； 
  - 进入BOS设计器之后，在系统视图窗口，选择业务领域和子系统； 
  - 右键点击基础资料或单据，在弹出的菜单列表中点击【新建报表】按钮，打开报表生成向导； 
  - 选择报表类型，添加数据源字段后，根据向导实现报表功能；

====3.6.1 明细账表==== 

**功能概述**

明细账表是，取单据上的字段作为数据源并设定字段排列顺序，得出的单据明细业务报表。

**操作步骤**

  - 选择参与排序的字段，以列表的形式展示已添加的数据源字段，支持多选和单选数据源字段作为排序字段，支持设置排序字段的先后展示顺序，排序字段默认为升序排序； 
  - 设置完成后点击【下一步】，展示已经生成的简单报名称，点击【完成】即可完成向导；

====3.6.2 汇总账表==== 

**功能概述**

汇总账表是，取单据上的字段作为分组依据进行分组，并指定相应的字段进行汇总，得出的简单汇总业务报表；

**操作步骤**

  - 分组列页签，以列表的形式展示已添加的数据源字段，支持单选数据源字段作为分组字段，支持对分组字段进行排序，运行时按分组字段顺序显示分组信息； 
  - 统计列页签，以列表的形式展示已添加的数据源字段，支持单选数据源字段作为统计字段，支持对分组字段进行排序，运行时按统计字段顺序显示分组汇总信息； 
  - 分组列、汇总列字段设置完成后，返回上一步变更数据源字段时，分组列、汇总列字段自动清空； 
  - 设置完成后点击【下一步】，展示已经生成的简单报名称，点击【完成】即可完成向导；

====3.6.3 交叉账表==== 

**功能概述**

交叉账表，是取单据上的字段，并选定行汇总字段和列汇总字段，然后进行交叉汇总，得出的简单交叉分析报表。

**操作步骤**

  - 行标题字段页签，以列表的形式展示已添加的数据源字段，支持单选数据源字段作为行标题字段，支持对行标题字段进行排序，运行时报表行按行标题字段顺序展示； 
  - 列标题字段页签，以列表的形式展示已添加的数据源字段，支持单选数据源字段作为列标题字段，支持对列标题字段进行排序，运行时报表列按列标题字段顺序展示； 
  - 统计字段页签，以列表的形式展示已添加的数据源字段，支持单选数据源字段作为统计字段，支持对分组字段进行排序，运行时按统计字段顺序显示分组汇总信息； 
  - 设置完成后点击【下一步】，展示已经生成的报表名称，点击【完成】即可完成向导；

## 【页面】选项设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%80%89%E9%A1%B9%E8%AE%BE%E7%BD%AE

======1 系统概述 ======

用户可根据操作习惯进行相应的参数设置，并支持按用户保存，用户下次登录系统时，无需再次设置相关参数。

=====1.1 单据选项设置 =====
 
**系统概述**

单据选项设置中，用户可进行单据相关的公共参数设置、元素可见性设置，所有参数支持按用户保存；

**操作步骤**

  - 点击单据工具栏【选项设置】按钮，打开选项设置界面； 
  - 根据用户需要可进行公共参数设置； 
  - 元素可见性设置，可设置单据界面的字段、控件在新增、查看、修改状态下的可见性； 

**参数说明**

  - 保存后自动新增： 选中后单据保存后可自动打开单据新增界面 
  - 保存后自动提交： 选中后单据保存后可自动提交，单据状态刷新为“审核中” 
  - 提交后自动审核： 选中后单据在未启用工作流的情况下，提交后可自动审核，单据状态刷新为“已审核” 
  - 批量填充只填充本列为空的行： 选中后进行批量填充操作时，只填充该单元格下方所有空行 
  - 禁止基础资料下拉列表自动显示： 选中后单据界面基础资料类字段录入时，不弹出模糊查询下拉列表 
  - 启用自动加载/保存界面调整： 选中后单据界面布局调整后，关闭窗口字段保存界面布局，下次登录时打开界面自动加载调整后布局。
  - 启用按视图自动加载/保存界面调整：选中后会根据单据类型所对应的视图，按视图记录界面布局信息，下次登录时打开界面按当前单据的视图加载对应布局。
  - 隐藏电子签章：单据界面不显示电子签章内容。
  - F8自动携带关键字到快捷过滤：打开F8列表时，将之前控件中已录入内容携带到快捷过滤条件里面。

=====1.2 列表选项设置 =====

**系统概述**

列表选项设置中，用户可进行列表相关的公共参数设置，所有参数支持按用户保存。

**参数说明**

  - 查询合并同一张单据的单据头项目： 选中后进行列表查询时，合并同一张单据的单据头项目 
  - 下推/选单操作时整单转换： 选单/下推操作时，列表上勾选单据任意一行数据就代表勾选整单数据进行转换 
  - 基础资料弹出列表查询显示明细项目： 选中后进行F8查询时，弹出界面显示明细项目 
  - 列表查询弹出过滤界面： 选中后列表查询时弹出过滤界面，如果设置了过滤 
  - 列表前冻结列： 选中后冻结列表前*列（0-最大列数） 
  - 列表后冻结列： 选中后冻结列表后*列（0-最大列数） 
  - 禁止过滤界面基础资料下拉列表自动显示： 选中后过滤界面基础资料类字段录入时，不弹出模糊查询下拉列表 
  - 不同单据采用颜色区别： 选中后列表界面相邻的两行分录采用不同的颜色区别 
  - 显示序号列： 选中后列表分录显示序号列 
  - 显示分录行号： 选中后列表自动增加一列，显示每一分录行的行号 
  - 数量列尾零不显示： 选中后数值型字段列，如果数值小数部分末尾有零，则不显示零 
  - 禁止列表操作后刷新数据： 选中后列表操作后不自动刷新列表数据，需要手动刷新 
  - 列表查询显示单据数量： 选中后光标移至列表下方指定区域，弹出提示展示当前列表单据数量 
  - 提交后自动审核： 选中后列表提交的单据自动进行审核
  - 上查、下查、全流程跟踪时按整单查询：选中后，列表选择单据数据行进行上查、下查、全流程跟踪操作时按整个单据进行联查。 
  - 下推操作默认单据：下推操作打开选择单据界面时默认选中某个单据。
  - 选单操作默认单据：选单操作打开选择单据界面时默认选中某个单据。
  - 快捷过滤查询所有数据：切换快捷过滤方案时，重置列表左侧分组项为全部，显示全部分组的过滤结果。（仅基础资料列表可使用）
=====1.3 报表选项设置 =====

**系统概述**

报表选项设置中，用户可进行报表相关的公共参数设置，所有参数支持按用户保存。

**参数说明**

  - 数值为零显示为空： 选中后报表查询结果中数值为零的单元格显示为空值 
  - 数量列尾零不显示： 选中后报表查询结果中数量列末尾为零时则不显示 
  - 进入报表时弹出过滤界面： 选中后进行报表查询时，先弹出过滤界面，过滤后再查询 
  - 仅显示汇总行数据： 选中后报表查询结果仅显示汇总行的数据 
  - 汇总行数据不显示小计： 选中后报表过滤结果汇总行数据不显示小计 
  - 汇总行数据不显示合计： 选中后报表过滤结果汇总行数据不显示合计 
  - 前冻结列： 选中后冻结列表前*列（0-最大列数） 
  - 后冻结列： 选中后冻结列表后*列（0-最大列数） 
  - 显示序号列： 选中后列表分录显示序号列 
  - 不引出没有数据页： 选中后分页帐表引出所有页时仅引出含有有数据的页

## 【页面】通用过滤
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%80%9A%E7%94%A8%E8%BF%87%E6%BB%A4

======1 系统概述 ======

运行时单据列表及报表界面想快速获得需要的信息，可通过工具栏【过滤】功能，设置相关的过滤条件进行数据筛选。

=====1.1 列表过滤 =====
 
**系统概述**

列表过滤界面提供过滤方案、过滤条件、排序方式、显示隐藏列等设置。 

**操作步骤**

1、点击列表工具栏【过滤】按钮，打开过滤界面； 

2、设置过滤条件： 
  * 设置可选组织：默认为当前组织； 
  * 设置 过滤字段：默认选择单据头字段，可选择单据体字段（单据体间互斥）； 
  * 设置字段表格：手动设置字段、比较、值、逻辑； 
  * 单据状态（默认值为全部）、关闭状态（默认值为全部）、作废状态（默认值为全部）； 

3、点击【排序】页签，设置排序方式：

## 【页面】部署包管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%83%A8%E7%BD%B2%E5%8C%85%E7%AE%A1%E7%90%86

======1 系统概述 ======

部署功能可以支持将业务对象发布到任意区域主控台的任意位置，可以将BOS设计的业务对象通过制做部署包的方式，传递给远程用户使用，从而实现跨领域、跨地域的资源共享。

======2 操作步骤 ======

1、打开BOS 设计器菜单栏【解决方案】下拉菜单，点击【部署包管理】按钮。打开部署向导界面；
 
2、输入部署包名称，选择部署包输出路径，点击下一步，打开部署对象选择界面； 

3、选择要部署的业务对象，支持选择多个业务对象，包括自定义单据、扩展单据、工作流、审批流、业务流程；
 
4、设置【功能部署】，通过【功能数据信息】设置业务对象在目标数据中心中的路径； 
  * 选择业务对象，点击【添加】按钮，将业务对象发布至目标数据中心主控台； 
  * 选择添加的业务对象，点击【修改】按钮，支持编辑业务对象的发布信息；

5、最后选择需要部署的文件，包括SQL脚本、其他文件、项目工程、程序集；

## 【页面】附件管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%99%84%E4%BB%B6%E7%AE%A1%E7%90%86

======1 系统概述 ======

附件管理是通用的对系统单据附件进行管理的功能，附件管理界面可以新增、查看、在线预览、修改和删除、下载附件功能。

====== 2 操作步骤 ======
=====2.1 单据附件管理 =====
 
**操作步骤**

  - 单据保存后，点击单据工具栏【附件】按钮，打开附件管理界面； 
  - 附件管理界面点击新增按钮，打开附件明细-新增界面； 
  - 附件管理界面点击批量新增按钮，打开附件明细批量新增界面，支持同时上传多个附件； 
  - 选择文件后点击保存，完成附件上传； 
  - 单据附件数字段取值自动刷新，记录单据附件数量；

=====2.2 单据体附件管理 =====
 
**操作步骤**

  - 单据暂存或保存后，选择单据体一行分录，点击单据体工具栏【附件】按钮，打开附件管理界面； 
  - 附件管理界面点击新增按钮，打开附件明细-新增界面； 
  - 附件管理界面点击批量新增按钮，打开附件明细批量新增界面，支持同时上传多个附件； 
  - 选择文件后点击保存，完成附件上传； 
  - 单据体附件数字段取值自动刷新，记录单据体分录附件数量；

=====2.3 列表附件查看 =====
 
**操作步骤**

  - 单据列表界面选择一张单据，点击单据体工具栏【附件】按钮，打开附件查看界面； 
  - 支持附件查看、下载功能； 

======3 操作说明 ======

===== 3.1 附件菜单控制 =====
通过BOS设计器打开单据，在单据整体属性中进入“附件菜单控制”，可以设置不同单据状态下附件管理的列表和单据界面上哪些菜单按钮可以使用。

注意：附件列表是有强制管控前提的，单据以查看方式打开，则附件管理中只允许查看，不允许新增、修改、删除附件；单据以修改方式打开，则附件管理中允许查看、新增、修改、删除附件。在此前提下，再读取附件菜单控制的设置。

===== 3.2 附件快传 =====
在按钮点击事件中，绑定操作时，可以使用“附件快传”操作。通过该操作可以实现单据界面快速、批量上传附件的需求。

===== 3.3 附件列表 =====
通过BOS设计器打开单据，可以在单据头使用“附件列表”控件，从而在单据界面的一个页签里嵌入附件管理的附件列表，快速进行查看、增删改等附件操作。
