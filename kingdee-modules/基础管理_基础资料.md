## 【页面】bos平台参数配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=bos%E5%B9%B3%E5%8F%B0%E5%8F%82%E6%95%B0%E9%85%8D%E7%BD%AE

====== 功能概述 ======

系统提供对BOS平台相关参数设置。


====== 参数说明 ======
===== 基本参数 =====
【基本选项】
  *    启用套打设置应用到所有用户： 启用套打设置中应用到所有用户参数，启用后需要对此参数做功能权限授权，授权后可以使用此参数。
  *   启用Sql关键字合法性验证：开启Sql关键字的合法性验证。
  *   启用脚本关键字合法性验证：开启脚本关键字合法性验证。
  *   允许按引入模版引出分组字段：开启后按引入模版引出，会将分组字段同时引出。
  *   最多允许打开15个页签：控制最多打开15个页签窗口。
  *   手动发送邮件使用虚拟邮箱：配置“发送邮件”操作实现的手动发送邮件功能，可以配置发件人使用虚拟邮箱。
  *   用户在列表开启不同单据行采用颜色区别时，间隔颜色为：配合“列表-选项”中的参数“不同单据行采用颜色区别”，这里可以自定义设置间隔行的具体颜色。
  *   启用按整单排序：列表显示单据体时，可以开启同一个单据相同单据头显示空白行，此时使用表头字段标题的点击排序会把单据打散排序。勾选该选项，会按单据为整体进行排序。
  *   不同单据状态下列表打开单据详情方式：系统默认是修改优先方式，具备修改权限时优先用修改方式打开。勾选该选项，可以自定义不同单据状态下列表打开单据详情的方式。使用查看方式打开单据，可以避免误占据修改操作的网控控制。
  *   单据详情界面隐藏尾零（保留格式）：数据中心级开关，开启单据界面隐藏尾零（保留千分位、币别符号等格式）。
  *   启用物料块粘贴自动申请分配：启用物料字段开启块粘贴自动申请分配的功能，实现录单场景下按需自动申请分配。
  *   单据详情界面数值字段隐藏尾零（保留格式）：单据详情界面数量、金额、单价等数值类型字段隐藏尾零，保留千分位、币别符号等格式显示。
  *   列表界面数值字段隐藏尾零（保留格式）：序时簿列表界面数量、金额、单价等数值类型字段隐藏尾零，保留千分位、币别符号等格式显示。
  *    单据体删除行后焦点行保持不动：单据体删除行后默认焦点是定位到上一行，开启参数后默认焦点行保持不动，方便连续删除当前行及下面的行。

===== 查询参数 =====
【列表查询】
  * 单据列表过滤时限制查询范围：只限制单据对象的普通列表，对选单、上查、下查、基础资料F8列表都无影响。开启后会在列表过滤界面附加后台固定的过滤条件约束查询范围。
  * 单据列表过滤时，至少包含1个非空过滤条件查询：只限制单据对象的普通列表，开启后必须包含一个以上过滤条件才允许查询数据，在过滤界面点击确定时提醒用户。
  * 过滤条件支持含有通配符的内容检索：英文的“中括号[]”、“下划线_”、“百分号%”等通配符，在查询时是具有功能参数含义的。如果需要转义作为普通字符串查询，可开启参数。
  * 多关键字的模糊查询，空格作为条件分隔符：系统默认支持用%分隔进行多关键字查询，开启后用空格也视作触关键字查询的条件分隔符。
  * 基础资料字段在F8列表多选模糊下，隐藏右侧已选列表：基础资料字段在F8列表界面如果属于开启多选，右侧会自动显示已选区域。需要默认折叠收起已选区域，可开启参数。
  * 列表查询时显示总行数：开启参数，系统在列表查询结果返回后，会异步处理进行总行数统计与更新。一些列表数据量特别大时，可能会先看到列表数据后，滞后几秒更新总行数。
  * 业务对象列表首次进入时每页行数的默认值：可以强制限制列表首次进入时的每页行数值。避免用户设置超大的每页行数，浪费不必要的流量。

【过滤方案】
  * 启用验证共享过滤方案权限：启用列表过滤方案的共享功能的权限管控，开启后拥有系统管理员类型角色的用户才可以共享过滤方案。
  * 允许简单账表共享过滤方案：默认不开启，简单账表的过滤方案是在过滤条件的可选范围上进行插件处理的，共享过滤方案可能导致查询到权限之外的报表数据。需要管理员根据企业实际情况，进行开启或临时开启。
  * 过滤方案的每周起始日为星期一：系统默认每周起始日为星期天，开启选项后，星期一作为每周起始日计算。
  * 共享过滤方案时，隐藏共享所有用户的选项：启用后表示共享过滤方案只允许指定用户共享，不允许直接共享所有用户。
  * 禁止列表拖拽方式调整的列宽、列顺序自动保存：系统默认对于本人自建过滤方案，在列表拖拽列宽、列顺序后，点击退出列表或快捷过滤切换时自动保存到过滤方案。开启选项后，将禁止触发自动保存列宽、列顺序。
  * 允许列表打开非本人自建的过滤方案时，拖拽列宽、列顺序自动保存：开启选项后，对于系统统一创建、他人共享等非本人自建过滤方案，在当前用户使用时，拖拽列宽、列顺序会自动按当前用户为其自动保存记忆。

【模糊查询】
  * 模糊查询的匹配方式，按基础资料对象隔离记忆用户参数：按不同基础资料对象，分开记忆匹配方式。匹配方式是指全模糊、左包含、右包含。
  * 设置模糊查询的条件匹配方式：分为匹配方式与默认方式设置，匹配方式表示限制模糊查询只能使用哪些匹配方式。例如，系统支持“左匹配、右匹配、全模糊查询”，出于性能考虑，可以设置不允许使用全模糊查询。
  * 模糊查询显示最近使用记录：启用该选项，基础资料字段输入空格会优先显示最近使用记录。并且，在模糊查询下拉列表选中返回的数据会更新到最近使用记录中。
  * 允许F8弹窗选择的数据记忆到最近使用记录：系统默认只将模糊查询下拉列表选中返回的数据会更新到最近使用记录中，启用该选项，对应F8弹出列表中选中返回的数据，也会更新到最近使用记录中。

===== WebAPI参数 =====
  * 禁用WebAPI：勾选后，则禁止使用WebAPI接口。
  * 启用WebAPI功能权限控制：勾选后，则会校验WebAPI登录用户的操作权限。
  * 启用WebAPI字段权限控制：勾选后，则会校验WebAPI登录用户的字段权限。
  * 查询接口启用WebAPI数据权限控制：勾选后，WebAPI单据查询接口会应用数据权限控制。
  * WebAPI接口不校验辅助属性有效性：勾选后，WebAPI单据保存时候不再校验数据包里面所传的辅助属性是否有效。
  * 允许调用WebAPI接口用户：用于限定哪些用户才允许使用WebAPI。
【白名单设置】
  * 可访问IP：设置可以访问的IP，使用";"分割。参考: 127.0.0.1;192.168.0.0/24;
  * 允许调用客户端：设置允许访问的客户端标识, 一旦设置客户端标识,接口必须自行添加对应标识,否则不能调用WebAPI。
  * 允许调用接口：设置允许访问的接口,例如只允许通过第三方密钥登录和使用保存接口。
===== 弹性域参数 =====
注意：该参数设置后需要清除缓存才会生效
 
辅助属性字段显示格式设置
  * 辅助属性显示格式：控制单据列表上的辅助属性内容显示格式，编码，选择编码，单据列表上辅助属性列显示每个维度的编码；选择名称：单据列表上辅助属性列显示每个维度的编码；选择名称/编码，单据列表上辅助属性列显示每个维度的编码/名称。
  * 辅助属性维度分隔符：控制单据列表上的辅助属性内容显示格式，如果不设置，默认为点，可设置为分号，则单据列表上辅助属性列，每个维度之间的分割符为设置的符号。
  * 辅助属性维度显示格式：在单据体上辅助属性维度列头名称显示格式，例如显示辅助属性.颜色；颜色.辅助属性；或者直接显示颜色。

仓位字段显示格式
  * 仓位值集显示格式：编码，选择编码，单据列表上仓位值集列显示每个维度的编码；选择名称：单据列表上仓位值集列显示每个维度的编码；选择名称/编码，单据列表上仓位值集列显示每个维度的编码/名称。
  * 仓位值集分隔符：如果不设置，默认为点，可设置为分号，则单据列表上仓位值集列，每个维度之间的分割符为设置的符号。
  * 仓位值集维度显示格式：单据体上仓位维度列头名称显示格式设置；

核算维度字段显示格式

  * 核算维度显示格式：编码，选择编码，单据列表上核算维度列显示每个维度的编码；选择名称：单据列表上核算维度列显示每个维度的编码；选择名称/编码，单据列表上核算维度列显示每个维度的编码/名称。
  * 核算维度维度分隔符：如果不设置，默认分号，可设置为点，则单据列表上核算维度列，每个维度之间的分割符为设置的符号。
  * 核算维度维度显示格式：单据体上核算维度维度列头名称显示格式。

维度关联字段支持块粘贴

  * 启用后，单据体上的多维字段支持块粘贴和批量填充，参数启用后需要清理缓存才会生效。
===== 文件服务参数 =====
【基本选项】
  * 上传文件白名单：添加了文件格式的扩展名后，才会支持上传该类型的文件。
  * 文件名非法字符：添加了为非法字符的字符后，文件名称中包含这个字符的不允许上传。
  * 在线预览窗口最大化显示：勾选，附件列表在线预览图片文件时，预览界面最大化显示；不勾选，则预览窗口会按比例缩放。
  * 图片在线预览默认自适应显示：勾选，附件列表在线预览图片文件时，预览界面按图片大小自适应显示，不勾选，则会按比例缩放。
  * 文件上传白名单：显示附件列表中可以上传的文件类型，可以添加新的类型，保存后生效。
  * 文件名非法字符：附件文件名称强制不允许包含的字符，输入后，包含该字符的文件名文件不允许上传。
  * 移动单据附件读取来源单据附件列表权限，同时隐藏”禁止下载“的附件，勾选后来源单据的附件列表权限，在移动端会校验。
  * 附件上传安全扫描：勾选后会校验excel格式文件中是否包含公式，pdf格式文件是否包含危险脚本，zip格式压缩文件是否压缩比率大于20%等。


【预览服务】

  * 说明：附件在线预览仅支持office文档和图片
  * 使用flash方式预览：勾选后，文件将被转换为SWF格式的文件，客户端需要安装flash插件，文件服务器上需要安装office，配置好DCOM权限才可以在线预览，随着Win10系统对flash的禁用，客户端为Win10的操作系统已不能再使用flash方式预览；
  * 使用Pdf方式预览：勾选后，文件将被转换为pdf格式，在线预览打开的是pdf格式文件，文件服务器上需要安装office，配置好DCOM权限才可以在线预览。
  * 使用本地文件服务预览：勾选后，附件的在线预览会使用下载到本地使用本地的软件进行预览。勾选支持图片选项，图片在线预览也会使用本地预览，如果不勾选，图片预览按在线预览方式进行预览。
  * 使用第三方预览服务：勾选后，支持配置第三方预览服务，目前支持officeWeb365服务预览、协同云预览（仅限公有云租户可用）、其他预览服务（自定义接入）。

===== 引入引出参数 =====

==== 引入参数设置 ====


  * 引入单据每批次处理数：单据引入时对引入数据分批处理，建议按默认值，如果应用服务器性能比较高，可以适当调高；

=== 引出参数设置 ===
  * 允许按引入模板引出分组字段：勾选后，按引入模板引出单据时，单据上的基础资料的分组属性如果勾选，则会引出基础资料的分组字段，不建议勾选。
  * 列表引出保留日期格式（强制生效）：勾选后，单据列表引出时，列表上的日期字段引出为日期格式，忽略单据列表引出格式设置界面的选项设置。
  * 列表引出保留币别格式（强制生效）：勾选后，单据列表引出时，列表上的币别字段引出为币别格式，忽略单据列表引出格式设置界面的选项设置。
  * 引出单据每批次处理数：单据列表引出或按引入模板引出时，对数据按批次处理，建议按默认值使用，如果应用服务器性能比较好，可以适度调高。

===== 套打参数 =====
  * 禁用套打持久化：套打打印过程中，超过一定的页数（100页），会将计算产生的页面文件数据临时放到数据库里面，以便降低大数据量打印时候内存使用量。 勾选后，则套打计算产生的页面数据全部放到内存里面。
  * 万能报表加载全字段：勾选后，标准报表模板打印（万能报表单据类报表），设计套打模板时候，数据源节点树会将单据上面所有的字段列出来。
  * 套打设置不显示禁用的单据类型：勾选后，禁用的单据类型将不在套打设置页面显示。
  * 分批打印失败后允许继续发送下一批数据：勾选后，套打大数据量分批发送数据，在其中一批数据打印机返回异常情况下，会弹出提示框询问是否继续下发下一批打印数据。否则的话直接打印终止。
  * 后台打印批次打印页数：使用后台打印时候，每次发送给打印机的最大页数。例如要打印250页数据，批次打印页数设置为100，那么系统将分三次将要打印的数据发送给打印机，第一次1到100页，第二次101到200页，第三次201-250页。

## 【页面】业务流程系统参数
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E6%B5%81%E7%A8%8B%E7%B3%BB%E7%BB%9F%E5%8F%82%E6%95%B0

======= 功能概述 ======
根据业务流程的使用场景，提供数据中心级的业务流程参数设置。

====== 操作入口 ======
【基础管理->公共设置->参数设置】，在参数设置界面展开“流程中心->业务流程”。

====== 参数说明 ======
=====  定期对业务流程数据进行归档 =====
  * 表示定期对业务流程数据进行归档，归档依据来自下面3个参数的设置。归档原理是将业务流程数据所在表看做正式表，依据数据的前提条件检查，依次将数据从正式表->历史表->归档表->压缩文件的顺序进行归档处理。归档数据激活规则是：当处于历史表/归档表/压缩文件的业务流程数据出现流程查询、流转(下推、选单等)情况时，则该数据使用后表示激活，重现回到正式表。
  * N个月以前的数据，迁移到历史表：默认为2，表示2个月没有进行流程查询、流转的数据，迁移到历史表。
  * N个月以前的数据，迁移到归档表：默认为6，表示6个月没有进行流程查询、流转且处于历史表的数据，迁移到归档表。
  * N个月以前的数据，压缩为文件：默认为6，表示6个月没有进行流程查询、流转且处于归档表的数据，压缩为文件。
===== 全流程跟踪支持跨实体查询 =====
  * 勾选此参数，当单据全流程跟踪时依据所选数据行进行全流程跟踪，依据关联关系追溯到末端下游单据后，再以此末端单据进行跨实体数据联查，生成最终的全流程跟踪结果。
===== 上查、下查、全流程跟踪打开联查列表时，验证列表的查看功能权限及数据范围 =====
  * 由于关联查询仅可查看有转换关系的单据，所以系统默认打开联查列表时不验证查看权限，从联查列表打开单据界面时才验证功能权限及数据范围。勾选该参数，可以在打开联查列表时开启对列表查看功能权限及数据范围的验证。
===== 单据转换支持多语言携带 =====
  * 多语言字段在单据转换携带映射字段时，默认仅携带当前登录语言对应的内容，开启后会按照不同语言对应关系，分别进行携带。
===== 单据转换部分携带失败返回提示信息 =====
  * 单据转换时，系统默认是所有关联行都不符合转换规则条件要求时，返回转换失败的提示信息。开启该选项后，只要出现部分行不符合转换携带要求时，系统会进行提示信息。
===== 启用尾差策略 =====
  * 表示系统全面开启尾差策略功能的开关，开启后，系统运行时会按照转换规则的【尾差策略】设置，进行对应的尾差修正处理，避免系统因多次分批携带与换算而产生小数级尾差。
===== 单据转换携带失败时，不显示逐个条件的分析结果 =====
  * 单据转换携带失败时，默认会按选单条件策略的配置，逐个遍历分析每一个条件哪些数据是不符合的。该选项勾选后，可关闭解析，改善性能。
===== 选单列表允许切换其他实体查询 =====
  * 使用选单操作时，系统会打开选单列表，该列表首次默认加载的实体是按照转换规则配置强制约束的，用户在该界面的过滤方案如果配置查询其他单据体，需要再次查询才会生效。目的是让用户默认可以按列表选中行，实现按行返回数据。
  * 开启该选项后，系统打开选单列表时，如果识别到对应过滤方案的单据体与转换规则关联携带的单据体不同时，优先按过滤方案勾选实体展示选单列表。但是，此时选单列表勾选数据返回时，由于关联携带实体未展示，系统会按勾选所在单据的整单视作选中范围，返回数据携带。

======1 云之家集成概述 ======

===== 1.1 云之家集成概述 =====
 
“互联网+”时代，金蝶云移动轻应用使得客户能够充分利用碎片化时间移动办公，加快企业的经营决策和信息流转，给企业带来很大的效益。越来越多的金蝶云用户非常乐意使用云之家轻应用。

===== 1.2 系统特性 =====
 
本系统主要包含以下应用：

  - 自动启用云之家，金蝶AI星空通过【同步用户】，自动集成云之家团队，并自动映射金蝶AI星空用户和云之家用户；
  - 金蝶AI星空用户与云之家账号一体化，按需登录；
  - 通过金蝶AI星空轻应用与业务流融合，高效协同作业，让流程更顺畅。

 
====== 2 云之家集成操作手册 ======

===== 2.1 云之家集成部署 =====

==== 2.1.1 自动集成配置 ====

默认团队自动配置，不需要手工去配置云之花团队和密钥文件，系统自动会配置成企业注册默认团队。

路径1：administrator登录【查询用户-用户同步】；

路径2：administrator登录【基础管理-移动设置-云之家集成】；

路径3：后台每天自动执行配置。
==== 2.1.2 切换团队 ====

如果使用的云之家团队（移动端）不是企业默认注册团队时，可通过切换团队配置其他团队，输入团队管理员手机号码和密码，选择要配置的团队即可。


路径：administrator登录（基础管理-移动设置-云之家集成），点击“业务操作-切换团队”。


==== 2.1.3 更新密钥 ====

自动集成默认是集成了云之家通讯录，如果需要集成其他应用，则需要到云之家开启对应的应用，通过更新密码即可自动获取密钥完成对接。

云之家路径：云之家团队管理员登录云之家，【管理中心】-【系统设置】-【系统集成】勾选对应应用即会自动生成密钥。

金蝶AI星空路径：administrator登录金蝶AI星空，【基础管理】-【移动设置】-【云之家集成】，点击“业务操作-更新密钥”，输入团队管理员手机号码和密钥即可更新。


==== 2.1.4 同步用户到云之家 ====

系统管理员可在查询用户列表选择需要同步到用户，点击“同步用户”即可同步所选用户到云之家，并且建立用户映射关系。

路径：Administrator登录系统，【查询用户】-【用户同步】，即会同步所选用户到云之家。

==== 2.1.5 不同步用户到云之家 ====

分给在金蝶云平台和金蝶AI星空设置不同步参数，即可实现用户不同步到云之家。

第一步：在金蝶云平台设置人企分离，选择不同步云之家；

路径：管理员登录云平台（cloud.kingdee.com），【我的企业】-【ERP产品】-【查看详情】，在注册用户列表的【管理用户】-【人企分离】设置不同步用户到云之家。

第二步：在金蝶AI星空设置不同步新用户到云之家。

路径：administrator登录金蝶AI星空系统，【系统管理】-【查询用户】-【选项】下的用户同步参数勾选“不同步新用户到云之家”。

==== 2.1.6 查看用户同步云之家日志 ====

同步完成后，可查看用户同步云之家日志，查看用户同步情况。同步失败会显示详细的同步异常原因。

路径：Administrator登录系统，【查询用户】-【用户同步】下的“用户同步日志”。

==== 2.1.7 查看用户映射关系 ====

只有金蝶AI星空用户和云之家用户之间建立了正确的用户映射关系才可以正常应用集成业务。

路径：administrator登录金蝶云系统。【基础管理】-【移动设置】-【云之家集成】-【云之家用户映射关系】。


===== 2.2 云之家集成应用 =====

==== 2.2.1 云之家智能应用 ====

=== 2.2.1.1  云之家账号登录金蝶云系统 ===

支持云之家账号登录金蝶云系统，实现云之家账号一体化，用户可以按需登录金蝶云，步骤如下：

第一步：启用云之家身份认证

======1 云之家集成概述 ======

===== 1.1 云之家集成概述 =====
 
“互联网+”时代，金蝶云移动轻应用使得客户能够充分利用碎片化时间移动办公，加快企业的经营决策和信息流转，给企业带来很大的效益。越来越多的金蝶云用户非常乐意使用云之家轻应用。

===== 1.2 系统特性 =====
 
本系统主要包含以下应用：

  - 自动启用云之家，金蝶AI星空通过【用户同步】，自动集成云之家团队，并自动映射金蝶AI星空用户和云之家用户；
  - 金蝶AI星空用户与云之家账号一体化，按需登录；
  - 通过金蝶AI星空轻应用与业务流融合，高效协同作业，让流程更顺畅。

 
====== 2 云之家集成操作手册 ======

===== 2.1 云之家集成部署 =====

==== 2.1.1 自动集成配置 ====

默认团队自动配置，不需要手工去配置云之家团队和密钥文件，系统自动会配置成企业注册默认团队。

路径1：administrator登录【查询用户-用户同步】；

路径2：administrator登录【基础管理-移动设置-云之家集成】；

路径3：后台每天自动执行配置。
==== 2.1.2 切换团队 ====

如果使用的云之家团队（移动端）不是企业默认注册团队时，可通过切换团队配置其他团队，输入团队管理员手机号码和密码，选择要配置的团队即可。


路径：administrator登录（【基础管理】-【移动设置】-【云之家集成】-【云之家集成配置】），点击“业务操作-切换团队”。


==== 2.1.3 更新密钥 ====

自动集成默认是集成了云之家通讯录，如果需要集成其他应用，则需要到云之家开启对应的应用，通过更新密码即可自动获取密钥完成对接。

云之家路径：云之家团队管理员登录云之家，【管理中心】-【系统设置】-【系统集成】勾选对应应用即会自动生成密钥。

金蝶AI星空路径：administrator登录金蝶AI星空，【基础管理】-【移动设置】-【云之家集成】-【云之家集成配置】，点击“业务操作-更新密钥”，输入团队管理员手机号码和密码即可更新。


==== 2.1.4 同步用户到云之家 ====

系统管理员可在查询用户列表选择需要同步的用户，点击“同步用户”即可同步所选用户到云之家，并且建立用户映射关系。

路径：Administrator登录系统，【查询用户】-【用户同步】，即会同步所选用户到云之家。

==== 2.1.5 不同步用户到云之家 ====

分别在金蝶云平台和金蝶AI星空设置不同步参数，即可实现用户不同步到云之家。

第一步：在金蝶云平台设置人企分离，选择不同步云之家；

路径：管理员登录云平台（cloud.kingdee.com），【我的企业】-【ERP产品】-【查看详情】，在注册用户列表的【管理用户】-【人企分离】设置不同步用户到云之家。

第二步：在金蝶AI星空设置不同步新用户到云之家。

路径：administrator登录金蝶AI星空系统，【系统管理】-【查询用户】-【选项】下的用户同步参数勾选“不同步新用户到云之家”。

==== 2.1.6 查看用户同步云之家日志 ====

同步完成后，可查看用户同步云之家日志，查看用户同步情况。同步失败会显示详细的同步异常原因。

路径：Administrator登录系统，【查询用户】-【用户同步】下的“用户同步日志”。

==== 2.1.7 查看用户映射关系 ====

只有金蝶AI星空用户和云之家用户之间建立了正确的用户映射关系才可以正常应用集成业务。

路径：administrator登录金蝶云系统。【基础管理】-【移动设置】-【云之家集成】-【云之家用户映射关系】。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%91%E4%B9%8B%E5%AE%B6%E9%9B%86%E6%88%90%E9%85%8D%E7%BD%AE%E8%AF%8A%E6%96%AD

====== 功能概述 ======

云之家集成配置涉及人员映射、应用映射、以及相关参数等众多配置，配置完毕后轻应用打不开，往往很难排查配置差错所在。

云之家配置诊断是针对集成配置的常见问题进行诊断检测，从而降低实施云之家集成的难度，精准定位问题，提供原因分析和解决方案，引导用户自行解决问题，并极大缩短用户排查配置问题的时间。

路径：【所有功能-基础管理-公共设置】

====== 操作说明 ======

  - 选择“云之家集成配置”，则显示“云之家用户手机”字段，必录。输入手机号后点击【诊断】按钮，则以此手机号为目标，检查云之家配置、及其该用户映射的相关设置。
  - 选择“业务审批轻应用配置”，则显示“云之家用户手机”“单据”字段，必录。输入手机号、单据后点击【诊断】按钮，检查云之家集成配置，并以单据为对象检查业务审批相关配置。
  - 诊断结果以表格展示，列字段包括：序号、诊断项、诊断描述、诊断结果、处理。
  - 处理方式：提供自动修复、手动修复。点击自动修复则自动更新设置，点击手动修复则弹出对应设置的路径提示。

## 【页面】单据参数配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8D%95%E6%8D%AE%E5%8F%82%E6%95%B0%E9%85%8D%E7%BD%AE

**功能概述**

系统提供单据级参数配置功能，系统管理员可对单据进行参数配置。

**操作步骤**

  - 系统管理员登录主控台【基础管理】-【公共设置】-【单据参数配置】； 
  - 对单据或基础资料的整体参数、字段参数、模糊查询参数、操作二次验权参数进行设置；
 
**参数说明** 

【整体参数】

  - 支持设置工作流： 控制单据或基础资料是否在流程新增界面单据列表是否可见 
  - 删除人与创建人一致： 控制单据或基础资料只允许创建人进行删除 
  - 反审核人与审核人一致： 控制单据或基础资料只允许审核人进行反审核 
  - 审核人与创建人不为同一人： 控制单据或基础资料不允许创建人进行审核 
  - 修改人与创建人一致： 控制单据或基础资料只允许创建人进行修改 
  - F8弹出列表支持快捷过滤行： 控制基础资料的F8弹出界面显示快捷过滤行 
  - 追加引入模板： 引入界面支持按追加引入模式进行数据引入 
  - 覆盖引入模式： 引入界面支持按覆盖引入模式进行数据引入 
  - 控制打印次数： 控制单据或基础资料套打打印次数 
  - 审核后才允许打印： 控制单据或基础资料审核后才允许打印 
  - 操作二次验权： 控制单据或基础资料上的操作按钮，在执行操作时进行用户权限验证，需输入当前登录用户的密码 
  - 引入模式： 控制单据或基础资料引入时只能采用追加模式或只能采用覆盖模式 
  - 单据类型布局不可见： 控制字段在单据类型布局设置中的字段列表内是否可见 
  - 支持查询： 控制基础资料属性是否支持作为模糊查询的检索项 
  - 新增即生成单据编号：新增界面显示生成的单据编号
  - 列表查询弹出过滤方案（用户参数）：打开列表时先弹出过滤方案，原本是有个人用户参数设置是否弹出，这里表示管理员勾选后，点击“保存并更新用户参数”。可以将管理员的勾选状态更新给所有用户的该参数
  - 批量下推【生成全部】操作失败的单据自动暂存：批量下推生成多张下游单据时，会有专门的批量生成界面，在该界面点击“生成全部”按钮，如果保存失败的单据则会自动暂存单据
  - 上查、下查预加载第三方下推：制造模块较多单据应用了第三方下推，在上查、下查时第三方下推的单据无法显示具体关联数据条数（会显示*替代），勾选该参数对于第三方下推会执行额外的处理，显示关联数据具体条数
  - 下推生成当前单据时，单据分录超过此行数自动拆单，行数默认值为X：系统生成下游单据时有隐含控制，如果下游单据分录超过1万行则会强制拆分单据，超出分录填入新单据。勾选该参数，可以允许用户在下推时自由指定拆分单据的分录上限值
  - 启用并行查询：更充分利用硬件性能，采用多线程方式加快列表查询和QueryService的效率
  - 基础资料弹出F8列表界面时显示分组：仅在基础资料对象上配置使用。表示基础资料字段在弹窗选择数据的界面上，左侧显示基础资料的分组树
  - 列表批量操作（每批执行数据数量)： 控制单据或基础资料列表选择多条数据进行批量操作时，控制后台每批次执行的条数，默认20条。此选项可以提升批量处理的性能，但是同一批数据中有1张单据不满足管控要求，则同一批的20条数据都会返回操作失败
  - 列表批量分配（每批执行数据数量)：控制列表批量分配操作时，每批次执行的条数
  - 列表批量分配（每批执行组织数量）：控制列表批量分配操作时，每批次执行组织的数量
  - 快速录入时，重新指定检索依据：快速录入是指基础资料字段快速录入编码，不等待触发模糊查询功能的浮窗之前，快速敲击回车返回基础资料数据。此时称为快速录入时机，系统默认按照基础资料的编码字段，使用“等于”方式检索，匹配到唯一一条数据则返回；匹配不到或匹配到多条满足条件的数据则不返回。该设置为空表示按编码字段匹配，允许配置单据头的其他文本字段调整匹配依据字段，例如，物料上有些企业助记码是唯一管控的，可以改为“助记码”字段作为匹配依据。
  - 快速录入时，设置检索匹配方式：默认使用“等于”方式检索，可以修改为“包含”方式检索，但是匹配数据的原则是不变的"匹配到唯一一条数据则返回；匹配不到或匹配到多条满足条件的数据则不返回"。
  - 批量填充时填充所有行：批量填充操作时，默认是从当前行序号向后填充空行。勾选参数后，会对整列数据进行处理，不依赖序号大小。
  - 批量下推生成当前单据，在生成多单界面启用分批批量保存：与列表批量操作类似，在单据转换批量下推生成多单界面，点击“生成全部”操作时使用按批次批量保存。

【模糊查询】
  - 模糊查询只允许按单个字段查询： 控制模糊查询只允许按单个字段查询，不再对多列支持查询的字段一起查。
  - 支持查询：设置字段支持模糊查询。
  - 下拉列表显示：控制模糊查询下拉浮窗界面显示的字段。
  - 下拉列表宽度：控制模糊查询下拉浮窗界面的字段列宽。
注：基础资料对象可以设置模糊查询，单据对象不可设置。

【列表查询】
  - 单据列表过滤时限制查询范围：默认不开启，可控制单据列表的过滤策略，附加自定义的强制过滤。
  - 此单据例外不做过滤限制：如果平台参数开启了数据中心级列表过滤策略，该选项可以管理当前单据例外不受控。
  - 按指定条件限制：平台参数开启列表过滤策略，是按创建日期管控的，该选项可以自定义当前单据的过滤条件。

## 【页面】单据类型
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8D%95%E6%8D%AE%E7%B1%BB%E5%9E%8B

======1 功能说明 ======

单据类型支持业务单据的布局、字段必录和锁定属性、业务流程以及打印的设置。

======2 使用前提 ======

只有包含单据类型字段的单据，才可使用单据类型。

======3 功能路径 ======

【基础管理】→【基础资料】→【单据类型】 

======4 字段说明 ======

=====4.1 基本信息主要字段说明 =====
 
  - 单据： 选择设置单据类型的具体单据 
  - 编码： 单据类型的编码，不能重复 
  - 名称： 单据类型的名称 
  - 描述： 单据类型的描述 
  - 编码规则： 单据类型使用的编码规则方案，若为空则会自动读取单据的默认编码规则，详见编码规则介绍 
  - 默认单据类型： 一个单据只能对应一个默认单据类型 

=====4.2 布局设置主要字段说明 =====

  - 单据布局方案： 从BOS平台中为每张单据所定义的布局中选择，单据类型加载新的单据布局时，将会同步下面的字段属性，然后在此基础上设置字段属性，有关单据布局的定义详见[[视图设计与应用|视图]]介绍 
  - 字段名称： 单据中所包含的字段名称 
  - 必录： 控制字段是否必录；可以对非必录字段设置为必录；对于系统已经锁定的关键字段不可修改 
  - 新增时不可维护： 控制字段在新增时不可维护；对于系统已经锁定的关键字段不可修改 
  - 修改时不可维护： 控制字段在修改时不可维护；对于系统已经锁定的关键字段不可修改 

=====4.3 业务流程设置主要字段说明 =====

  - 名称： 业务流程的名称，来自业务流程设计中心中配置的业务流程，有关业务流程配置，请参考[[业务流程设计中心|业务流程设计中心]]的介绍 
  - 版本: 业务流程对应的版本号，详见[[业务流程设计中心|业务流程设计中心]]有关版本介绍 
  - 生效日期: 业务流程的启用日期，该日期会同步业务流程配置中心的生效日期 
  - 失效日期: 业务流程的截止日期，该日期会同步业务流程配置中心的失效日期 
  - 默认业务流程: 若单据类型配置业务流程并设置了设置默认业务流程，单据加载单据类型时，携带默认业务流程，可选择单据类型支持的其他业务流程。若单据类型未配置业务流程，单据将走自由流程
 
=====4.4 打印控制主要字段说明 =====

  - 控制打印次数: 有2个选项：选中、未选中。选中则表示要控制打印次数 
  - 最大打印次数: 选中控制打印次数选项后，才能设置最大打印次数，最大打印次数为（1-100） 
  - 审核后才允许打印: 单据处于审核状态后才允许打印 
  - 默认套打模板: 从单据支持的套打模板中选择，有关单据的套打模板定义，请参[[套打平台|考套打平台]]的介绍

======5 操作说明 ====== 

=====5.1 单据类型设置规则 =====

  - 单据类型的设置，是加载了BOS平台的设置后，对字段的必录、维护（新增时和修改时）进行再修改；
  - 如果BOS平台已设定字段为必录状态，将不允许在单据类型中将该字段修改为不必录，同样，如果BOS平台已设定字段为“新增锁定”或“修改锁定”状态，将不允许设置“新增时不可维护”或者“修改时不可维护”选项；
  - 如果BOS平台未设定字段为必录、“新增锁定”、“修改锁定”状态，则可以在单据类型中设置对该字段的这三个选项进行设置；
  - 若BOS平台中某个字段没有设定这三个选项，单据类型加载BOS平台的设置保存后，BOS平台调整字段的对应选项后会同步到单据类型的选项上。

=====5.2 单据界面加载规则 =====

1、单据界面加载单据类型

     打开单据界面，单据首先读取默认单据类型，然后根据默认单据类型加载界面，用户可以更改单据类型，更改后会刷新界面；

2、单据界面可加载内容

     1）单据界面加载时，首先读取单据类型对应的布局方案，如果单据类型没有选定一个布局方案，则取BOS平台的默认布局；
     
     2）取得布局方案后，会将 BOS设计器对字段属性的设置、单据类型对字段属性的设置、用户个性化选项方案的设置，三者叠加形成单据界面；

3、单据界面加载优先级

     1）对于“必录”，BOS平台设置、单据类型设置，二者只要有一个地方设置为必录，该字段则为必录；
     
     2）对于“新增时不可维护”、“修改时不可维护”，BOS平台设置、单据类型设置，二者只要有一个地方设置为不可维护，该字段则为不可修改；
     
     3）对于可见性，以BOS平台设置、用户选项设置，二者只要一个地方设置为不可见，该字段则为不可见；
     
     4）对于布局（比如字段位置），应该以BOS设置为准；

=====5.3 单据类型状态变化的影响 =====

1、单据新增

     1）默认单据类型如果被反审核或者禁用，打开新增单据界面，单据类型字段显示为空，可以通过F8选择；
     
     2）新增单据界面，F8选择单据类型时，被反审核、禁用的单据类型不可选；

2、下推方式生成单据

     因为单据类型会用在单据转换的“单据类型转换对应表”中，被禁用或反审核的单据类型是不可选择出来的。但是，如果后来单据类型被禁用，下推方式生成单据时，下游单据不会去检查单据类型状态是否合法，为了避免这个禁用或反审单据类型也被下推出来，建议企业改一下单据类型转换对应表的对应关系。

3、已使用的单据

     1）单据类型被禁用、反审核，不影响原有单据的控制逻辑。也就是说，单据界面不受单据类型被禁用或者反审核的影响；
     
     2）当单据保存后，BOS平台或者单据类型设置修改字段的控制，单据将以BOS平台、单据类型修改后最新的为准，倘若单据类型反审核修改某个字段的控制逻辑，是直接生效的，不是审核后才起作用； 
     
=====5.4 业务流程应用 =====

对于业务流程，单据中一旦加载了对应单据类型的流程，之后修改流程版本，对当前已有单据的流程无影响；

=====5.5 打印应用 =====

系统预置的标准单据类型已定义了默认套打模板，实际使用时，每个单据可以在套打设置中重新选择定义默认套打模板，且以此为准；

=====5.6 权限控制 =====

单据类型提供权限控制，单据类型本身作为一个业务对象，普通用户授权后才能使用，Administrator不用授权就可以维护单据类型。

## 【页面】参数设置

====== 1 功能描述 ======

【基础管理】→【公共参数】→【参数设置】


 ====== 2 字段说明 ======

 ====== 3 功能操作 ======

====== 3.1 参数差异分析 ======

  - 展示业务领域参数在各个组织下，手工配置与系统预置的状态比较；
  - 通过这个差异分析，可以分析哪些数据的差异是参数引发的。

====== 3.2 复制 ======

  - 同一数据中心下某个组织的参数同步到其他组织。
  - 参数设置界面点击【复制】按钮，打开系统参数复制界面，选择源组织和目标组织后，点击复制，即可将源组织的组织级参数内容（支持F8选择的内容除外）覆盖到目标组织组织的对应内容。
  - 注意：若所选目标组织的参数内容已保存过，则不允许复制。

====== 3.3 批量同步（V7.7 PT-146884 新增） ======

  - 经常有企业由于业务扩张或者业务调整，需要更新多个组织的参数内容，但目前调整了数据中心级别参数，只影响未保存过的组织级别的参数，不会影响已经保存的组织级别参数；这样，对于已保存过的组织的参数需要逐一调整，当组织数量较多时，操作非常麻烦，因此，特提供了参数批量同步功能，以解决此类问题，具体请参考https://vip.kingdee.com/article/212499408959843072


====== 3.4 参数迁移 ======

支持不同数据中心对应组织下参数迁移。例如：测试环境的参数数据迁移到正式环境，测试环境组织和正式环境组织的对应根据组织编码来对应，要求两个数据中心的组织编码一致。

具体操作流程如下：

**构建包**
  - 在BOSIDE里面新建一个解决方案，输入方案名称、目录（例如：C:\参数迁移）、业务领域，勾选模板方案，点击确定即完成创建，右边的项目中可以看到所构建的方案。
  - 确定该数据中心下要导出参数的组织，右键点击“预插数据”节点下面的“系统参数预插数据”，打开系统参数引出界面，填写名称并选择要导出参数的组织，点击【保存】即可。
  - 对解决方案进行构建，右键点击“数据包”节点，点击【构建】，BOS中即会输出相关的构建过程及完成信息。

**执行包**
  - 双击构建出来的扩展包，C:\参数迁移\Bin\Output找到所构建的部署包，然后双击即可打开执行界面
  - 输入扩展包信息并执行
  - 数据要导入的管理数据中心的地址，选择要导入的数据中心，点击【确定】即可执行。

**迁移规则**
迁出和迁入两个数据中心的组织编码一致，否则无法迁移。


 ====== 4 业务说明 ======

**参数应用**
  - 参数设置界面中，若组织字段为【数据中心级】字样的，表示是数据中心级别的参数，其他表示是组织级别的参数
  - 组织级别的参数继承数据中心级别的（数据中心级别参数除外）；
  - 数据中心级别参数的调整只影响未保存过的组织级别的参数，不会影响已经保存的组织级别参数；若是组织级别参数的调整，不会影响其他组织的参数； 

**权限控制**
  - 参数设置提供权限控制，规则： 1）Administrator设置数据中心和组织级别的参数；2）管理员角色的用户设置所管辖组织范围内的组织级别参数；3）普通角色用户设置组织范围内和授权范围内的组织级别参数； 
  - 参数设置平台便于管理员统一设置参数，还可以从不同子系统进入，对当前子系统的参数进行设置；
  - 多组织应用模式下，只能选择当前用户组织范围内的参数，但不论组织和账簿禁用与否，不影响参数的查看和设置。

====== 区域格式 ======
===== 功能说明======

国际化设置中区域格式的参数设置，便于统一管理，用户也可根据实际业务设置所需的区域格式。
===== 使用前提 =====

系统已预置了国际标准的区域格式列表，国际化设置中区域格式默认为中文（简体，中文）。用户也可根据实际业务需要设置对应的区域格式。
===== 功能路径 =====

国际化设置：【基础管理】→【公共设置】→【国际化设置】

区域格式列表：【基础管理】→【基础资料】→【区域格式列表】

===== 字段说明 =====
1.数字分组主要字段说明 
  * 小数点： 数字按照小数点分隔整数部分和小数部分，与数字分组符号互斥，不允许为空值。 
  * 数字分组符号： 数字按照数字分组符号分组，与小数点符号互斥，不允许为空值。
  * 数字分组： 定义数字分组，下拉选择。
  * 负号： 定义数字的负号。
  * 负数格式 定义数字的负号格式，下拉选择。
2.日期分组的主要字段说明 
  * 日期： 定义日期格式，下拉选择 
  * 时间： 定义时间格式，下拉选择 
===== 操作说明 =====
区域格式设置 

  - 进入数据业务中心，点击主控台【国际化设置】菜单，打开国际化设置界面，点击【区域格式】按钮或者F8，弹出的区域格式设置列表中选择所需的区域格式作为系统级默认区域格式；
  - 点击【保存】按钮，设置成功。 
我的格式和时区设置 

  - 进入数据业务中心，当前用户下拉菜单中的【我的格式和时区】菜单，打开我的格式和时区设置界面，点击【我的格式】按钮或者F8，弹出的区域格式列表中选择所需的区域格式作为用户级的区域格式，
  - 点击【保存】按钮，设置成功。

注意：各业务系统单据、列表等所有界面上使用到数字、日期、货币、时间类型的字段需要首先按照我的格式设置中设定的格式输入和输出显示，如果我的格式未进行设置则按照系统格式的设置进行输入和输出显示。

====== 1 基础设置概述 ======
===== 1.1 概述 =====
  - 基础设置包括基础资料、公共设置以及业务初始化三部分，基础设置是各业务应用的公共平台，是各领域的应用基础。
  - 基础资料是在系统中使用的各种基础数据的总称。用户在录入凭证或者录入单据时，都毫无例外地需要输入一些业务资料信息，如科目、币别、商品、客户、金额等等。可以这么说，所有的凭证、单据都是由一些基础资料信息和具体的数量信息构成的。对于这些基础的数据，为了便于进行统一的设置与管理，我们提供了基础资料管理这样一个功能。
  - 系统设置平台为各业务领域及其子系统提供了基础参数设置的入口，系统设置各选项包括整个系统的重要信息，这些设置关系到所有业务和流程的处理。
  - 系统初始化平台为各领域提供了初始化设置的入口，初始化设置是进行业务操作的第一步，在完成相关基础设置之后，所有用户都需要进行初始化的工作。
  - 系统出厂提供了5个预置基础资料，方便特别业务应用需要。

===== 1.2 系统特性 =====
本系统主要包含以下应用：
  - 主档资料提供了批改功能；
  - 辅助资料采用统一的界面来管理，支持自定义并可以根据上级类别实现再次分组；
  - 基础资料分组支持配置只查看当前分组节点下明细数据、排除冗余数据干扰、提高使用效率；
  - 公共平台和业务初始化平台为各业务领域的设置提供了统一入口，以便管理员集中设置，统一管理；
  - 预置基础资料都是分配型，保存校验按组织内编码唯一来进行校验，适用多组织应用场景。

1.使用前提

系统预设了ISO语言列表，默认启用已安装并启用的语言，不支持客户自定义，仅支持对某一种语言启用和禁用操作。

3.功能路径

  * 语言设置：【管理中心】→【数据中心列表】→【设置】→【语言设置】
  * 登录语言选择：【登录主页】→【语言列表下拉框】
  * 语言列表查看：【基础管理】→【基础资料】→【公共资料】→【语言列表】
4.操作步骤

如何安装和启用语言包： 

第一步：安装多语言包

金蝶AI星空安装包中已包括英文和繁体多语言包，在安装选择中勾选语言包即可安装。同时也可以在已安装金蝶AI星空的应用服务器上安装单独的多语言补丁。


第二步：管理中心添加语言

如果正在创建数据中心，可在“默认语言”下拉列表中选择其它语言，在创建数据中心的时候同步添加和安装语言包；
如果修改创建完成的数据中心使用语言，选择数据中心点击[设置] -[语言设置]按钮，在“设置语言”界面点击[添加语言]按钮，会弹出语言包列表，下拉列表的语言来自于应用服务器中授权许可安装的语言包。在复选框中选择需要安装的语言，一般语言包包含BOS语言包和标准产品语言包，由于产品以BOS平台为基础，所以建议选择一起安装。例如安装英文语言包，K3Cloud BOS ML-US和K3Cloud ML-US文件包应同时选择安装。

第三步：管理中心启用语言包

安装好的语言包会出现在“设置语言”列表界面中，勾选语言签的复选框后再点击[保存]按钮后，语言包启用成功。


5.操作说明

系统默认安装启用中文（简体）语言包，在登录主页时，语言下拉框默认显示为中文（简体）。用户也可以安装其它语言包，安装了语言包之后才能在管理中心启用对应的语言。

## 【页面】基础资料系统参数
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9F%BA%E7%A1%80%E8%B5%84%E6%96%99%E7%B3%BB%E7%BB%9F%E5%8F%82%E6%95%B0

====== 1 功能描述 ====== 
定义基础资料的参数设置。

**功能路径**
【基础管理】→【系统参数】→【参数设置】→【基础管理】→【基础资料】

 ====== 2 系统参数 ======
 ===== 2.1 存在子分组的分组可以新增明细基础资料 =====
  - 默认勾选，允许在基础资料子分组的上级分组直接新增基础资料；取消勾选，则不允许新增基础资料，必须在子分组下新增。
  - 若当前基础资料分组存在基础资料，取消勾选后，该分组不能新增基础资料，对于已存在的基础资料，可以通过手动批改或者修改物料分组的方式调整到其他分组下。

  举例：物料有产成品分组，产成品下分为半成品和成品分组，如果勾选选项则可以在产成品分组下新增物料；如果不勾选，则产成品分组下不能新增物料，只能在半成品和成品分组下新增 。
  
===== 2.2 存在即时库存或未完成单据不允许禁用 =====
  - 默认不勾选，物料存在即时库存或未完成单据时允许禁用；
  - 勾选该参数，物料存在即时库存或未完成单据时不允许禁用
===== 2.3 同步采购员、计划员、质检员到分配组织 =====
  - 默认不勾选，物料分配后在创建组织修改采购员、计划员、质检员不能同步修改分配组织中的采购员、计划员、质检员
  - 勾选该参数，物料分配后在创建组织修改采购员、计划员、质检员需要同步修改分配组织中的采购员、计划员、质检员。需要同时满足条件：物料基础资料控制策略中采购员、计划员、质检员设置为携带+可修改；业务员中职员已经设置到分配组织
===== 2.4同步禁用时不进行禁用检查 =====
  - 默认不勾选，物料基础资料控制策略中勾选“同步禁用”，物料在创建组织中被禁用后会同步禁用分配组织，在禁用分配组织中的物料时，会检查分配组织中的物料是否存在即时库存或未完成单据，不会直接禁用分配组织物料
  - 勾选该参数，物料基础资料控制策略中勾选“同步禁用”，物料在创建组织中被禁用后会同步禁用分配组织，在禁用分配组织中的物料时，不会检查分配组织中的物料是否存在即时库存或未完成单据，直接禁用分配组织物料
===== 2.5存货类别变化时进行提示 =====
  - 默认不勾选，物料中存货类别发生变化时不进行任何提示
  - 勾选该参数，物料中存货类别发生变后物料保存时进行提示
存货类别作为科目影响因素或者核算维度时，一旦变更将会影响财务对账。



 ===== 2.6启用税组合 =====
  - 默认不勾选，基础资料中“税组合”菜单不可见，不能维护税组合资料，且涉税单据中也将不显示“税务明细”页签。
  - 勾选后，主控台菜单的基础资料中显示“税组合”的内容，可通过税组合来维护超过一种税种组合的定义；同时，在涉税单据中将显示“税务明细”的页签；
  - 启用税组合后，税组合将直接作为各业务单据计算税的基础资料；
  - 在业务应用过程中，启用税组合一旦启用，则不允许取消勾选。

## 【页面】岗位信息
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%B2%97%E4%BD%8D%E4%BF%A1%E6%81%AF

====== 1 功能描述 ====== 
  - 在没有HR职位体系支撑的情况下可以通过岗位信息功能实现相关业务管理，以支撑ERP业务流程的运转。
  - 可维护岗位上下级汇报关系，及对应角色。

**使用前提**
维护了组织机构、部门信息。


**功能路径**
【基础管理】→【基础资料】→【公共资料】→【岗位信息】


 ====== 2 字段说明 ======
  - 创建组织：默认携带当前登录组织；如当前登录组织不是岗位信息控制策略中的创建组织，则显示为空，通过F8选择岗位信息控制策略中的创建组织；
  - 编号：数据中心唯一；保存时自动生成；
  - 名称：岗位的名称；
  - 所属部门：岗位所在的部门；控制同一部门下不能存在相同名称的岗位；
  - 上级汇报关系：依据不同汇报关系选择不用的岗位上级；同一汇报关系只有一个上级岗位；
  - 下级汇报关系：不可维护；系统自动根据上级汇报关系自动回填的；
  - 岗位对应角色：选择岗位所对应的角色，只是展示，没有后续业务控制。
 

 ====== 3 功能操作 ======
  -分配：岗位的控制策略为分配型，可以通过【分配】操作将当前组织的岗位手工分配到其他组织；
  -查看汇报关系：点击后，可以查看当前岗位节点的下级岗位内容。
  -岗位汇报关系解析：流程审批异常，汇报关系明明存在，通过申请人、发起人等的岗位汇报关系的直接上级都无法解析到对应的上级领导，分析起来很困难，工作流要花费大量精力帮助用户查汇报关系哪里，解析不到岗位的问题，手工排查流程繁重，效率低，现在增加了岗位汇报关系解析，方便排查。具体请参考https://vip.kingdee.com/knowledge/720692954431532800?productLineId=1&isKnowledge=2&lang=zh-CN
  
 ====== 4 业务说明 ======
**s-HR集成**
对应与s-HR集成同步到金蝶云的岗位信息记录，有以下控制：
  - 仅限于同步接口用户进行操作删除；
  - 不能修改同步字段；
  - 通过同步置为禁用状态的记录默认仅限于同步接口用户进行操作删除反禁用；
  - 同步时s-HR集成选择的金蝶AI星空业务组织编码对应的金蝶云组织，必须是岗位信息控制策略中的创建组织，否则不能同步；
  - s-HR集成同步到金蝶云的岗位信息记录，不能被在金蝶云手工新增的员工引用。

====== 时区 ======
===== 功能说明 =====
系统时区是由创建数据中心时数据库服务器的时区所决定的，不能更改。本地化客户端默认时区的参数设置，便于统一管理，用户也可根据实际业务设置所需的时区。
===== 使用前提 =====
系统预置了国际标准的时区列表，国际化设置中客户端默认时区初始值为空，用户默认时区与系统时区一致。用户可根据实际业务需要设置其他时区。
===== 功能路径 =====
国际化设置：【基础管理】→【公共设置】→【国际化设置】

时区列表：【基础管理】→【基础资料】→【时区列表】


===== 字段说明 =====
  * 编码： 预设的时区编码 
  * 名称： 预设的时区名称 
  * 时区标准： UTC 
  * 时差： 定义时区的时差 
  * 系统时区： 来源于预设的时区列表的基础资料 
  * 客户端默认时区： 来源于预设的时区列表的基础资料 
===== 操作说明 =====
系统时区设置 

创建数据中心时，系统时区默认为数据库服务器设置的时区，默认不可更改。 
  * 客户端默认时区设置 

  - 进入数据业务中心，点击主控台【国际化设置】菜单，打开国际化设置界面，点击【客户端默认时区】按钮或者F8，弹出的时区列表中选择所需的时区作为客户端默认时区；

  * 我的格式和时区设置 
  - 进入数据业务中心，当前用户下拉菜单中的【我的格式和时区】菜单，打开我的格式和时区设置界面，点击【我的时区】按钮或者F8，弹出的时区列表中选择所需的时区作为用户的时区；
  - 点击【保存】按钮，设置成功。

**注意：系统提供统一的函数进行时区的计算转换，转换的规则依国际标准时区的规则进行：以GMT为基准0，东加西减。**

## 【页面】税务规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A8%8E%E5%8A%A1%E8%A7%84%E5%88%99

====== 1功能说明 ======

设置税务规则，可以定义销售和采购业务使用缺省税率或税组合；也可以定义必要逻辑，以进一步确定税率、税组合应用于业务的范围。

税务规则设置的复应用分成两种场景 

不需要税务规则：
税务机关以相同税率征收所有销售和采购业务的税。税适用性和税率及退税率均不随以下因素变化：业务处理中的交易方；业务处理中包括的产品或服务；业务处理中涉及到的业务流程。此时，可简单定义销售和采购业务使用缺省税率和税组合。
需要税务规则：
1) 需要简单税务规则。税务机关采用相同的税率对业务处理征税，并具有简单可确定例外情况。例外仅应用于业务处理的一部分，如某些交易方，或应用于可通过一种简单方式进行汇总的交易方、产品和业务处理流程组合。。
2) 需要设置复杂税收制度的税务规则。某些国家（地区）的税收制度具有复杂逻辑，以确定业务处理的适用税和税率。例如，税适用性和税组合/税率可随原产地、目标地、交易方、业务类型、产品或因素组合而变化。对于所有这些和类似情况，您可以设置税务规则，定义必要逻辑，以确定税率、税组合应用于业务的范围。 

使用前提：

用户设置了税率/税组合。
系统针对采购、销售业务，预置了常用的税务规则，用户可结合企业实际业务需要，生效相应的税务规则进行应用。

===== 2功能路径 =====

【基础管理】→【基础资料】→【税务管理】→【税务规则】

===== 3字段说明 =====

  * 编码： 定义税务规则的系统编码，可以手工录入也可在保存时由系统自动生成。注意：编码不允许重复。 
  * 名称： 定义税务规则的系统名称 。
  * 税收制度： 定义税务规则的适用的税收制度。 
  * 生效日期： 本税务规则的生效日期，系统在应用税务规则时，会根据生效日期进行有效期的判断。 
  * 失效日期： 本税务规则的失效日期，系统在应用税务规则时，会根据失效日期进行有效期的判断。 
  * 决定性因素分类： 系统预置的税务规则影响因素分类，可按业务类型、产品、交易方进行设置。 
  * 决定性因素名称： 系统预置的税务规则影响因素，分类为业务类型，决定性因素可选择单据或单据类型进行设定；分类为产品，决定性因素可选择物料的税分类或物料进行设定；分类为交易方，决定性因素可选择供应商、供应商的税分类、客户、客户的税分类进行设定。 
  * 运算符： 提供了按范围、等于、不等于的逻辑判断方式进行设置。 
  * 值/范围： 可根据运算符，进行相应的条件设置。当选择范围时，其值支持多选。 
  * 税率/税组合： 根据前面设置的条件，其对应结果的来源。为四选一的参数，如选择了”物料的税率”，则在此税务规则应用时，会根据物料属性中的”税率”字段，自动获取单据/单据行对应税率。 
  * 物料的税率： 定义税务规则的适用的税收制度。 
  * 供应商的税率： 根据前面设置的条件，其对应结果的来源。为四选一的参数，如选择了”供应商的税率”，则在此税务规则应用时，会根据供应商属性中的”税率”字段，自动获取单据/单据行对应税率 。
  * 客户的税率： 根据前面设置的条件，其对应结果的来源。为四选一的参数，如选择了”客户的税率”，则在此税务规则应用时，会根据客户属性中的”税率”字段，自动获取单据/单据行对应税率 。
  * 费用项目的税率： 根据前面设置的条件，其对应结果的来源。为四选一的参数，如选择了”费用项目的税率”，则在此税务规则应用时，会根据费用项目属性中的”税率”字段，自动获取单据/单据行对应税率 。
  * 缺省税率/税组合： 当结果中选择了”税率/税组合”参数时，对于多个税率/税组合的情况，可设置缺省的税率/税组合，以减少单据录入过程中的税率获取操作次数。
 
===== 4操作说明 =====

考虑到国际化企业的应用需要，税务规则出厂预置为分配型的基础资料，如企业是一国的应用，且不涉及不同州有不同税规则的情况，则可在实施时将税务规则设置为共享型的进行应用。

## 【页面】税种
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A8%8E%E7%A7%8D

====== 1功能说明 ======
税种指一税收制度内的具体税收种类，是基本的课税单元。如对增值额课税的税种，称为增值税；对资源课税的税种，称为资源税等。您可以在此设置企业经营活动过程中需要缴纳的各种税。。

====== 2使用前提 ======

需要先定义税收制度。
系统预置了适用于中国税制下的增值税。用户可根据实际业务需要设置适用的其它税种。

====== 3功能路径 ======

【基础管理】→【基础资料】→【税务管理】→【税种】

====== 4字段说明 ======

  * 编码： 定义税种的系统编码，可以手工录入也可在保存时由系统自动生成。注意：编码不允许重复。
  * 名称： 定义税种的系统名称。 
  * 税收制度： 定义税种所属的上级税收制度 。
  * 地理位置： 定义税种适用的地理位置信息 。
  * 纳税币种： 定义此税种的默认纳税币种信息 。
  * 默认汇率类型： 定义此税种的默认汇率类型信息 。
  * 申报机关： 定义此税种的默认申报机关信息 。
  * 征收机关： 定义此税种的默认征收机关信息 。
  * 税额精确度： 税额精确度将指明计税时采用的小数位数，在此需要输入一个 1 位数的数字。输入精确度 0 表示舍入为整个币种单位。例如，要将税额为 1.466 舍入为 1.47，则将税额精确度定义为 2，将舍入规则定义为向上舍入或四舍五入。 
  * 最小会计单位： 最小会计单位是税额可以精确到的最小单位；系统可以向上舍入或向下舍入，使结果成为最小单位的倍数。例如，币种为 CNY，计算的税额为 5.541，舍入规则为“四舍五入”。如果最小会计单位为 0.01，系统将输入 5.54；如果最小会计单位为 0.05，则系统将输入 5.55。请注意，此最小会计单位可能与精确度不一致 。
  * 舍入规则: 舍入规则是指用于将税额舍入为最小会计单位的方法，预设值包括向上舍入、向下舍入、四舍五入。 
  * 生效日期: 本税种的生效日期，系统在应用税种时，会根据生效日期进行有效期的判断 。
  * 失效日期: 本税种的失效日期，系统在应用税种时，会根据失效日期进行有效期的判断。 
  * 允许改写税率: 允许改写税率，选中后允许用户手工输入或者改写单据上的税率值 。
  * 允许改写和录入税额: 允许改写和录入税额 ，选中后允许用户改写单据上的自动计税结果。 
  * 纳税允差百分比: 选择“允许改写和录入税额”选项后亮显。输入纳税允差百分比，可以以定义用户改写可与自动计税额不同的最大百分比。与纳税允差范围额设置互斥，二者只能选择录入其中之一。 
  * 纳税允差范围额: 选择“允许改写和录入税额”选项后亮显。输入纳税允差范围额，可以定义用户改写可与自动计税额不同的最大金额。与纳税允差百分比设置互斥，二者只能选择录入其中之一。
====== 5操作说明 ======

税种维护之前需要先定义好税收制度。税种将作为税率的关键字段之一，在税率维护中引用。

## 【页面】税组合
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A8%8E%E7%BB%84%E5%90%88

====== 功能说明 ======

在某些情况下，一种税的应纳税额可能取决于相同业务处理上另一种税的税额。通过税组合设置参与复合过程的各个税及其计税纳税公式。税组合作为单据上调用的基础资料。标准税计算公式是税额 =（应纳税额基准）x（税率）。如果设置了应纳税额基准修正值，则使用修正后的应纳税额基准进行税额的计算。

====== 使用前提 ======

在基础设置的基础资料税组合参数设置中，基础资料的税组合页签中勾选了启用税组合选项。系统将17%的增值税预设为单一税组合，用户可根据实际业务需要设置适用的其它税组合。

====== 功能路径 ======

【基础管理】→【基础资料】→【税务管理】→【税组合】

====== 字段说明 ======

  * 编码： 定义税组合的系统编码，可以手工录入也可在保存时由系统自动生成。注意：编码不允许重复。 
  * 名称： 定义税组合的系统名称 。
  * 应纳税额基准： 定义参与复合的税率记录的应纳税额基准，系统预设单价、单价+之前的单位税额合计。 
  * 应纳税额基准修正值： "输入行金额增加或减少的百分比。例如：要将应纳税额基准从 1000 增加到 1500，请输入 50%。要将应纳税额基准从 1000 减少到 400，请输入-60%。" 

====== 操作说明 ======

应纳税额基准字段系统控制了单价+之前的单位税额合计后面不允许再选择单价，即只允许单价在前面的行，单价+之前的单位税额合计在后面的行。
税组合的主要应用场景是：在处理一笔业务时，需要同时计算并处理超过一种税的情况。如，进口商品时，涉及关税、增值税等，希望在业务单据中及时计算这两种税，计算时，增值税需要基于完税价格及关税的基础上进行计算，在这种应用需求下，即可启用税组合。

|  换算关系：换算分子  | 以当前单位做为换算分子。例：米为基准单位，则厘米的换算分子为1，换算分母为100。\\ 备注：换算分子、换算分母是正整数                                                                          |
|  换算关系：基准单位  | 基准单位动态取当前单所属组别中的基准单位                                                                                                                  |

====== 3 业务说明====== 

  - 基准计量单位：最小包装单位，不同包装单位之间换算的基准，在K3Cloud中也是作为核算单位；
  - 定义物料时需要指定物料使用的基本单位、常用单位（采购单位、销售单位、库存单位、生产单位）等；
  - 同步物料换算率：将计量单位的换算分子、换算分母同步到引用该计量单位的物料的对应字段上。

======1 辅助属性值组合 ======
=====1.1 功能概述=====
假如物料启用了多个辅助属性，可以定义多个辅助属性值的组合范围。


=====1.2 功能路径 ===== 

【基础管理】→【基础资料】→【辅助属性】→【辅助属性值组合列表】

====== 2 业务说明 ======

同一类物料一般辅助属性相同，但是由于需求的一些特性，各物料的辅助属性值存在差异。

辅助属性值组合的用途，举例说明：
辅助属性：辅助资料-颜色：红色、黑色、黄色；辅助资料-尺寸：S、M、L；
物料X启用辅助属性颜色、尺寸及这2种辅助属性组合。
这2种辅助属性值组合的全集有：
  * 红色/S、红色/M、红色/L；
  * 黑色/S、红色/M、红色/L；
  * 红色/S、红色/M、红色/L；
针对物料X可以从这组合的全集中挑出需要使用到的组合。比如：
  * 红色/S、红色/M、红色/L；
  * 黑色/S、红色/M；
  * 红色/L；
备注：在单据上应用辅助属性时，会根据物料指定的辅助属性值、物料辅助属性值组合来自动筛选有效值。

选项：不考虑非空的辅助属性维度值。

## 【页面】需求发布
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%9C%80%E6%B1%82%E5%8F%91%E5%B8%83

====== 1 功能描述 ====== 
对企业内部没有足够开发资源处理的需求，可修改企业需求单的处理方式为立项发布，审核后，发布到协同开发云平台open.kingdee中招标处理。

**使用前提**
维护了企业需求单。

**功能路径**
【基础管理】→【基础资料】→【企业需求】→【需求发布单】

 ====== 2 字段说明 ======
  - 企业需求单：F8选择需要发布的企业需求；
  - 产品版本：系统自动携带当前环境的产品版本，不可编辑；
  - 公司名称：系统自行携带填写的公司名称，在列表的【设置】中填写；
  - 所属领域：携带企业需求填写的所属领域；
  - 所属行业：系统自行携带填写的所属行业，在列表的【设置】中填写；
  - 其他内容：携带企业需求的对应内容，允许修改。

====== 3 功能操作 ======
===== 3.1 发布 =====
  - 需求发布单保存后才触发；
  - 点击后将该需求发布到open.kingdee协同开发云平台进行招标；
  - 发布后，需求发布单的发布状态刷新为已发布；
  - 发布后的需求，可直接到协同开发云平台中查看需求；
  - 发布的需求有效期默认是3个月。

===== 3.2 撤销发布 =====
  - 企业系统管理员可撤销需求发布；
  - 撤销发布后，需求发布单的发布状态刷新为未发布
  - 撤销发布的需求，在open.kingdee协同开发云平台中会下架，不会显示出来。

===== 3.3 设置 =====
维护公司名称和所属行业，以便需求发布后显示对应信息。
