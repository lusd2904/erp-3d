## 【页面】公有云移动bos
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%AC%E6%9C%89%E4%BA%91%E7%A7%BB%E5%8A%A8bos

[[移动平台|<<返回移动平台]]

====== 1 功能概述 ======

基于HTML5打造公有云移动BOS，让移动开发设计所见即所得，开发、管理、部署、发布云之家一气呵成。通过预置标准的UE设计，智能转换为金蝶云移动BOS的组合控件，降低用户UE设计难度，初学者也可以轻松设计出符合人机规范的移动应用界面。从而将移动开发化繁为简，极大减少移动表单的界面设计工作量。

====== 2 操作步骤 ======

1. 登录公有云移动BOS（http://cloudbos.kingdee.com），点击【创建新应用】，创建一个移动应用，作为分类；
  * 移动应用删除时，不会删除里面的移动表单对象，已有的表单会移入未分组中，可以再移动到其他移动应用下。

2. 点击创建的应用图标，进入应用管理界面，点击【创建表单】，创建一个移动表单，进入移动BOS设计器界面；
  * 拖拽字段控件，并设置字段相关属性。 

3. 开发完成后，点击【保存】，然后使用【部署】操作，可以将公有云的表单部署到企业的金蝶云数据中心里。
  * 公有云移动BOS的控件会根据目标金蝶云系统环境及版本，智能转换为对应的元数据。
  * 如果目标环境版本较低，那么高版本才具有的控件或控件属性会部署不过去，表单呈现出元素缺失或属性为设置的现象，但不会导致整个表单部署失败。 

4. 发布云之家；
  * 部署到金蝶云数据中心的同时，可以选择发布到对应的云之家团队中，基于公共号（轻应用）集成方式应用。

====== 3 字段说明 ======

===== 3.1 常规字段 =====

  - 文本：提供对文本的维护功能。
  - 小数：提供对小数的维护功能。
  - 整数：提供对整数的维护功能。
  - 多行文本：提供多行文本的维护功能。
  - 移动列表：字段可以拖入移动列表，以卡片样式显示多行数据。
  - 日期：提供对日期的维护功能。
  - 时间:设置时、分的控件。
  - 复选框：提供复选功能。
  - 下拉列表：提供下拉列表功能，支持设置枚举类型。
  - 多选下拉列表：允许选择多个枚举值返回。
  - 基础资料：打开基础资料列表，返回选择的基础资料。
  - 多选基础资料：允许选择多个基础资料返回。
  - 组织：提供选择组织机构的字段。

== 3.2 通用控件 =====

  - 标签:显示文本信息(输出)，不作为输入信息的界面。 
  - 按钮:设置点击事件关联相应的操作。

移动应用客户端安装在移动设备上，通过此客户端访问发布在移动主控台的移动应用内容。金蝶提供预置的移动应用客户端——金蝶云 移动工作台。包括各类移动平台的版本，例如Andriod版、IOS版等主流平台。而且移动平台的开发成果不仅可以发布到移动工作台，无须任何修改，还可以直接发布到云之家、微信端进行集成应用。

客户可基于金蝶云 BOS中的移动对象开发功能进行移动表单和移动单据的开发，开发成果可以直接发布到移动主控台，通过金蝶云 移动工作台访问，也可以依据提供的SDK开发移动客户端应用。而金蝶云 移动工作台就是为了帮助客户及伙伴快速定义移动开发而设计，它具有以下特点：
  * 移动对象随需定制、扩展、组合，打造属于企业特有的移动工作台； 
  * 支持按用户定义常用功能列表，支持九宫格展示； 
  * 可以低成本、高效率的开发移动应用功能。只需基于金蝶云 移动开发平台设计移动应用内容，不再需要基于任何原生的移动应用平台开发客户端。

====== 移动工作台介绍 ======
  * 金蝶云 移动工作台主要包括常用功能界面、侧滑菜单界面。 
  * 常用功能界面展示用户自定义的常用应用入口。通过点击“+”可以打开添加应用界面，选择需要设为常用的应用。 
  * 常用功能界面长按图标可以进入编辑模式，允许调整图标位置、从常用功能删除图标。 
  * 常用功能界面从左向右滑动可以打开侧滑菜单。 
  * 侧滑菜单界面提供所有应用（按分组展示）、设置，可以快速切换应用。

====== 1 功能概述 ======

移动应用设计平台基于金蝶AI星空BOS平台构建，抽象了开发移动应用所需的业务对象，用户通过可视化的设计器快速创建移动单据，使用发布功能就能在客户端实时展现，所见即所得让设计变得更为轻松。

====== 2 操作步骤 ======

1. 登录BOS集成开发平台，点击【新建】选择新建方式，创建一个移动业务对象；
  * 【移动业务】模型封装两种业务对象：移动表单、移动单据。依据需要选择对应业务对象。 
  * 移动表单类似动态表单，常用于设计移动应用中的过滤条件、导航栏、系统参数等界面。 
  * 移动单据类似普通单据，设计分为“单据”“列表”界面，基于移动应用特性而专门封装的业务对象，可以为基础资料、普通单据等设计出用于移动端的单据。 
  * 新建空白对象方式，在命名后会进入创建向导界面，选择空模板则是创建空白界面；若选择模板，则进入多步骤的配置界面，具体参见“移动对象创建向导”专题

2. 通过拖拽常规字段、通用控件等进行界面设计；
  * 【移动单据】可以在单据总体属性“来源单据”中绑定一个取数来源，支持基础资料、单据。绑定来源单据后，该单据的字段就可以在此移动单据上直接使用。 
  * 【移动单据】可以设计列表界面。因为移动端的特点是屏幕小，列表界面展示需要聚焦关键内容，所以列表界面展示上有更多个性化要求。 
  * 点击“运行->预览移动表单”，可以打开预览界面，检查界面设计的效果。

3. 配置单据属性、控件属性等，例如添加快捷过滤、设置操作交互、注册插件进行特殊处理。

4. 发布移动业务对象到移动端的主控台；
  * 将设计完成的【移动表单】或【移动单据】作为访问入口发布到移动端的主控台。 
  * 已发布的单据在修改并保存后即可生效，无须再次发布移动端主控台。

====== 4 操作说明 ======

===== 4.1 新建方式 =====

新建空白单据：基于空白对象创建，不受任何约束，灵活度高，元素需要自行添加，也可以将新建的业务对象作为模板后续进行继承新增。

继承：继承原对象的元数据、界面元素以及相关属性，创建出新的业务对象；
  * 对新对象的改动、增加字段，不影响原对象； 
  * 原对象的改动、增加字段，新对象会感知并体现出来 ； 
  * 原对象字段不得删除，关键属性不得修改，继承向导界面； 

复制：基于原对象复制出新的业务对象，对原对象与新对象的改动不会相互影响，新建过程与继承方式相同。

===== 4.2 修改方式 =====

扩展：项目窗口选择已有单据，鼠标右键菜单选择扩展，就可以基于标准产品进行编辑。
  * 扩展是对已有单据的一种修改操作，修改内容会以单据增量包的形式存储。 
  * 用户前台访问单据是会先加载单据，然后加载扩展的增量包，将差量化叠加后的结果呈现给用户。 
  * 已经发布过的单据扩展后，不需要再次发布。

===== 4.3 部署 =====

移动表单、移动单据支持制作成部署包，安装到其他数据中心，具体步骤参见BOS平台的部署功能介绍。

===== 4.4 发布 =====

目前金蝶AI星空移动平台的移动终端采用集成第三方移动平台方式，系统标准产品支持发布云之家、企业微信、钉钉，基于HTML5进行集成应用。

因此在金蝶AI星空移动平台的开发成果，一次开发可以分别发布到多种种终端应用：发布发布云之家、发布企业微信、发布钉钉。
  - 发布云之家：发布到云之家公共号菜单。（前提条件：依赖云之家集成配置）
  - 发布微信：发布到微信端，支持企业微信、服务号。（前提条件：依赖微信集成配置）
  - 发布钉钉：发布到钉钉端。（前提条件：依赖钉钉集成配置）
