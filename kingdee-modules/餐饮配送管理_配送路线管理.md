====== 1.订货排班表 ======
===== 1.1 功能概述 =====
订货排班表自动生成助手会生成订货排班表，订货排班表可以根据配送路线与门店来过滤订货排班表。门店订货排班表会根据配送路线与门店订货规则设置进行计算来过滤符合条件的数据

===== 1.2 关键字段 =====
^ 字段名称  ^ 字段说明                                       ^
| 报表类型  | 支持按配送路线查看以及按照门店查询，如果选择按配送路线查询则门店不可选，反之亦然。  |

===== 1.3 业务说明 =====
  * 按路线及门店订货规则生成订货排班表，设置后台服务，自动生成，生成后，通过排班报表查询。
  * 订货排班时，订货周期取门店订货规则中符合条件的规则，并根据有效期来生成对应的排班。
  * 每个有效期的最后一次的订货时间为下一个订货期间有效期的起始日期。
  * 门店按照配送路线下设置的顺序显示

====== 1.车辆管理 ======

===== 1.1 功能概述 =====
  * 车辆管理是管理每条配送路线的车辆信息的，配送出库单和门店收货单会携带满足条件的车辆管理信息。
  * 车辆管理基础资料，受组织策略控制，为共享类型。
  * 判断同一个配送组织同一个配送路线，不可出现有效期重叠的车辆管理信息       
  * 在配送出库单单据有配送信息上增加“配送路线、车牌号，驾驶员，驾驶员联系方式”等字段。
  * 配送出库单生成时，获取车辆管理有效期内的车辆信息。
  * 在门店收货单单据头上增加配送信息页签，并且增加“配送路线、车牌号，驾驶员，驾驶员联系方式”等字段，字段值由配送出库单上携带而来。

====== 1.配送路线 ======
===== 1.1 功能概述 =====
  * 配送路线可以配置有效期内（有效期从与有效期至）集配中心与门店的路线，配送
  * 配送路线管理基础资料，受组织策略控制，为共享类型。   
  * 有效期从默认当前操作时间，有效期至默认2100-1-1.4. 允许门店可在多个配送路线下，也可在同一配送路线下，但是有效期不可重叠。不允许同一配送组织下同一门店的有效期重叠。
  * 有效期不能重叠
  * 当配送路线中的门店及订货周期变更时，需手工点击业务操作下的更新订货排班表来更新订货排班表，更新时，保留更新日期之前的排班，只更新该日期之后排班
  * 门店对应的地址，自动获取组织信息中维护的地址。可手工修改
===== 1.2 字段说明 =====

| 字段名称  | 字段说明                                       |
| 路线名称  | （相同配送组织下）重复时，保存时提示用户：存在相同的名称的配送路线，是否继续保存？  |
| 有效期从  | 从哪一天开始生效                                   |
| 有效期至  | 哪一天开始不生效                                   |
| 门店    | 该配送路线用于哪个门店                                |

====== 1.配送路线管理系统参数 ======

===== 1.1 功能概述 =====

配送路线管理参数中表明了门店订货受订货排班控制的单据，如果勾选相应单据前的复选框，则在订货排班表期才可以订货，在订货排班表之外的时间打开这些单据会提示无法订货。
===== 1.2 字段说明 =====
^ 字段        ^ 说明                                                          ^
| 门店要货申请单   | 勾选则表示门店要货申请单受订货排班表的控制，只有订货排班表上允许订货的日期才能新增门店要货申请单，否则不允许订货    |
| 历史物料用量要货  | 勾选则表示历史物料用量要货受订货排班表的控制，只有订货排班表上允许订货的日期才能进行历史物料用量要货，否则不允许订货  |
| 历史食品销量要货  | 勾选则表示历史食品销量要货受订货排班表的控制，只有订货排班表上允许订货的日期才能进行历史食品销量要货，否则不允许订货  |
| 门店周期要货    | 勾选则表示门店周期要货受订货排班表的控制，只有订货排班表上允许订货的日期才能进行门店周期要货，否则不允许订货      |

====== 1.门店订货日规则设置 ======

===== 1.1 功能概述 =====
  * 门店订货日规则设置完之后，执行订货排班助手，则可在订货排班中查询到排班结果
  * 类型包括固定周期、固定日期、单双日、星期
  * 类型选择固定周期后，规则默认固定周期，灰色锁定。
  * 类型选择固定日期时，规则默认为固定日期，灰色锁定。
  * 类型选择单双日时，规则有两个可选：双数日、单数日，两个选项为单选。类型选择星期时，规则可选择星期，可多选。
  * 当类型为周期时，该字段是可填且为必填，只可填入数字类型，不可填入0或者负数。最大可填3位数。当类型不为周期时，该字段锁定，不可编辑。
  * 同一个门店在同一个有效期内只能设置一个规则
  * 同一个门店在不同的有效期内支持设置不同的规则
  * 当订货订货日规则变更时，需手工点击业务操作下的更新订货排班表来更新订货排班表，更新时，保留更新日期之前的排班，只更新该日期之后排班

===== 1.2 字段说明 =====
^ 字段名称  ^ 字段说明                           ^
| 规则类型  | 支持固定周期，固定日期，单双日，星期四种选择         |
| 门店名称  | 设置后表示该规则对该门店有效                 |
| 批量添加  | 设置选中门店适应于多个订货规则                |
| 固定周期  | 多久订一次货，（有限期至-有限期从+1）/订货周期必须整除  |
| 固定日期  | 在每个月的某一天订货                     |
| 单双日   | 设置每个月的单双日进行订货，不可同时勾选           |
| 星期    | 根据星期进行订货，支持多选                  |
