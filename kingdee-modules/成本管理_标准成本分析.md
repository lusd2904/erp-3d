## 【页面】基础资料完整性展示
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9F%BA%E7%A1%80%E8%B5%84%E6%96%99%E5%AE%8C%E6%95%B4%E6%80%A7%E5%B1%95%E7%A4%BA

======功能说明======

通过基础资料完整性展示界面，用户能够快速查询产品各项基础资料的维护情况，以便在执行卷算前预先维护好相关资料。

====== 使用前提 ======

产品成本核算已经启用、标准成本版本已经设置、产品BOM已经设置。

====== 功能路径 ======

【成本管理】—>【标准成本分析】—>【基础数据】—>【基础资料完整性展示】

====== 单据头 ======

^ 字段    ^ 说明                    ^
| 核算体系  | 当前基础资料完整性展示对应的核算体系。   |
| 核算组织  | 当前基础资料完整性展示对应的核算组织。   |
| 会计政策  | 当前基础资料完整性展示对应的会计政策。   |
| 版本    | 当前基础资料完整性展示对应的标准成本版本  |

====== 操作说明 ======

  * 支持按物料属性查询或按BOM用途查询，查询条件二选一
  * 成本BOM设置是否完整，是按物料清单属性来判断下一级成本BOM是否有维护，如果有一个不维护就判断为不完整（考虑性能问题，此处只对0层和1层的进行检查，2层及以上出现未维护的不会提示）
  * 物料清单存在替代物料的，替代物料基础资料是否维护不影响其完整性

## 【页面】标准成本分析
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E6%88%90%E6%9C%AC%E5%88%86%E6%9E%90

====== 1 标准成本分析概述 ======

本章主要包含以下内容:   

===== 1.1 标准成本分析概述 =====

标准成本分析是对企业标准成本的计量，用于企业的标准成本资料维护、标准成本卷算、标准成本报表查询、与实际成本差异分析。

===== 1.2 标准成本分析总体流程图 =====
 
[图:标准成本分析总体流程图.png]
===== 1.3 系统特性 =====

标准成本分析系统以支持多工厂、多组织、多会计政策、多版本灵活准确地计算产品标准成本为目标，通过与生产制造、产品成本核算系统的无缝集成，为企业成本管理提供精确的成本分析数据，其主要功能包括：
  * 标准成本基础数据设置 
  * 标准成本卷算 
  * 报表分析

 

支持标准成本的维度：
  * 支持多工厂多组织标准成本计算 
  * 支持标准成本设置多个版本
  * 支持产品标准成本多级查询

====== 2 业务类型及应用 ======


本章主要包含以下内容:

===== 2.1 自制产品标准成本 =====

自制产品是指企业为满足客户的需求，由计划部门向生产车间下达，并要求生产车间执行的生产任务，车间管理人员根据计划部门下达的生产订单，领用物料和组织生产。自制产品标准成本根据产品BOM及标准费率、标准工时计算。 

===== 2.2 委外加工标准成本 =====

委外加工是指在委托供应商进行产品加工，加工所需的材料由企业提供，或主要材料由企业提供，完工的产品其产权上属于委托加工企业。委外产品成本分为材料成本和委外加工费两部分。委外产品标准成本根据产品BOM及产品委外加工价目表计算。 
====== 3 标准成本分析系统操作手册 ======


本章主要包含以下内容:

===== 3.1 使用流程 =====


下面针对主要的标准成本卷算业务处理流程进行详细的说明。

**第一步，基础数据**

01. 设置产品成本核算的相关基础数据。

在系统开始正式应用前，需要先进行以下基础数据的设置，以保证成本卷算正常执行。包括：标准成本版本设置、外购物料标准价目表、成本BOM设置、标准工时维护、标准费率维护、产品委外加工价目表。

  * 维护标准成本版本：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【标准成本版本设置】。
  * 维护外购物料标准价目表：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【外购物料标准价目表】。
  * 维护产品成本BOM：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【成本BOM设置】。
  * 维护标准工时：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【标准工时维护】。
  * 维护标准费率：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【标准费率维护】。
  * 维护产品委外加工价目表：进入【成本管理】—>【标准成本分析】—>【基础数据】—>【产品委外加工价目表】。 

02. 如果有联副产品，则需要设置对应的产品组及副产品定额成本维护

**第二步，标准成本卷算**

标准成本卷算确定产品的标准成本，包括：标准成本卷算、标准成本卷算合法性检查报告。

执行标准成本卷算：进入【成本管理】—>【标准成本分析】—>【标准成本计算】—>【标准成本卷算】。 

查询标准成本卷算合法性检查报告：进入【成本管理】—>【标准成本分析】—>【标准成本计算】—>【标准成本卷算合法性检查报告】。   

**第三步，报表分析**

报表分析可以从不同角度查询产品标准成本卷算结果，包括：产品标准成本查询、产品标准成本多级查询、产品成本差异分析。

  * 查询产品标准成本表：进入【成本管理】—>【标准成本分析】—>【报表分析】—>【产品标准成本查询】。 
  * 查询产品成本多级查询：进入【成本管理】—>【标准成本分析】—>【报表分析】—>【产品标准成本多级查询】。  
  * 查询产品单位标准成本差异分析：进入【成本管理】—>【标准成本分析】—>【报表分析】—>【产品成本差异分析】。

## 【页面】标准成本卷算
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E6%88%90%E6%9C%AC%E5%8D%B7%E7%AE%97

====== 功能说明 ======

成本卷算通过产品标准成本计算确定产品的标准成本。 
====== 功能路径 ======

【成本管理】—>【标准成本分析】—>【标准成本计算】—>【标准成本卷算】
====== 参数说明 ======
1、按成本BOM卷算：勾选时，仅卷算在“成本BOM设置”中设置了成本BOM的物料。不勾选时，如果有未设置成本BOM的物料时，卷算过程直接中断并在合法性检查中提示。

2、卷算物料不反查：勾选时，向下卷算目标物料的成本。

3、未设置外购价格给予警告：在卷算过程中出现未维护外购价格的物料时，如果勾选此参数则会继续进行卷算，并在合法性检查报告中提示，不勾选时，直接中断。
===== 单据头 =====


| **字   段**       || **说 明**               |
| 指定物料卷算          || 选中则只对指定的物料进行卷算        |
| 仅进行合法性检查报告      || 选中则只进行合法性检查。          |
| 损耗率处理方式         || 支持1/（1-损耗率）           |
| 卷算时删除历史卷算结果     || 勾选时重新卷算删除当前版本的全部卷算结果  |

====== 操作说明 ======

1、成本卷算执行完后点击合法性检查报告，或者点击系统菜单【成本管理】—>【标准成本分析】—>【标准成本计算】—>【标准成本卷算合法性检查报告】，可以按“核算体系+核算组织+会计政策+版本”查看当次成本卷算的合法性检查报告。

2、合法性检查报告中点击“明细”，可以查看详细的提示信息。

## 【页面】标准成本合法性检查报告
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E6%88%90%E6%9C%AC%E5%90%88%E6%B3%95%E6%80%A7%E6%A3%80%E6%9F%A5%E6%8A%A5%E5%91%8A

====== 标准成本合法性检查报告 ======


1、成本卷算执行完后点击合法性检查报告，或者点击系统菜单【成本管理】—>【标准成本分析】—>【标准成本计算】—>【标准成本卷算合法性检查报告】，可以按“核算体系+核算组织+会计政策+版本”查看当次成本卷算的合法性检查报告。

2、合法性检查报告中点击“明细”，可以查看详细的提示信息。

3、增加"计算操作->清除卷算冲突"按钮。

## 【页面】标准成本版本
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E6%88%90%E6%9C%AC%E7%89%88%E6%9C%AC

====== 1 功能说明 ======

标准成本版本设置可以设置默认版本、影响成本卷算的因素。
 
====== 2 使用前提 ======

无。 

====== 3 功能路径 ======

【成本管理】—>【标准成本分析】—>【基础数据】—>【标准成本版本设置】

====== 4 字段说明 ======


===== 4.1 单据头 =====


| **字   段**           || **说 明**                        |
| 版本号                 || 当前版本的编码。                       |
| 名称                  || 当前版本的名称。                       |
| 是否默认                || 是否作为默认的标准成本版本。                 |
| 是否使用简化BOM           || 简化bom是新的BOM展示方法，勾选后能提升性能，建议勾选  |
| 考虑子项物料的生效日期         || 勾选后卷算时考虑子项物料的生效日期              |
| 展示跳层件               || 勾选后多级成本查询将展示跳层件                |
| 考虑供料方式              || 勾选后当时子项的供料方式为委托方供料，则不参与卷算      |
| 通用或报价BOM仅卷算标准工费     || 勾选后卷算时仅取标准工时和费率，不取委外加工价目表      |

===== 4.2 影响因素 =====


| **字   段**     || **说 明**                 |
| 准备工时          || 人员准备工时、机器准备工时是否影响成本卷算。  |
| 变动损耗率         || 物料清单上的变动损耗率是否影响成本卷算。    |
| 成品率           || 物料清单上的成品率是否影响成本卷算       |
| 固定损耗          || 物料清单上的固定损耗是否影响成本卷算。     |

====== 5 操作说明 ======

默认版本只有一个，将新的版本设置为默认时，上一个默认版本自动设置为非默认。

## 【页面】标准费率维护
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%87%E5%87%86%E8%B4%B9%E7%8E%87%E7%BB%B4%E6%8A%A4

====== 功能说明 ======

标准费率维护设置产品的标准费率。 
====== 使用前提 ======

产品成本核算已经启用、标准成本版本已经设置。 
====== 功能路径 ======

【成本管理】—>【标准成本分析】—>【基础数据】—>【标准费率维护】
====== 字段说明 ======

主要字段说明 

===== 单据头 =====


|**字   段**||**说 明**|
|核算体系  ||当前标准费率维护对应的核算体系。|
|核算组织 ||当前标准费率维护对应的核算组织。|
|会计政策 ||当前标准费率维护对应的会计政策。|
|版本 ||当前标准费率维护对应的标准成本版本|

===== 明细页签 =====


|**字   段**||**说 明**|
|产品编码 ||当前产品的编码|
|成本项目编码 ||当前产品标准费率对应的成本项目|
|人员准备费率 ||当前产品标准人员准备费率|
|人员实作费率 ||当前产品标准人员实作费率|
|机器准备费率 ||当前产品标准机器准备费率|
|机器实作费率 ||当前产品标准机器实作费率|
|数据来源 ||当前产品标准费率维护的数据来源|

===== 费用页签 =====

|**字   段**||**说 明**|
|费用项目名称 ||当前产品标准费率对应的费用项目名称|
|费用项目编码 ||当前产品标准费率对应的费用项目编码|
|人员准备费率 ||当前产品的费用项目标准人员准备费率|
|人员实作费率 ||当前产品的费用项目标准人员实作费率|
|机器准备费率 ||当前产品的费用项目标准机器准备费率|
|机器实作费率 ||当前产品的费用项目标准机器实作费率|
====== 操作说明 ======

可以通过标准费率维护报表界面点击【业务操作】—>【同步至其他版本】进行产品标准费率批量维护。
