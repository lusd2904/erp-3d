## 【页面】摊余成本表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%91%8A%E4%BD%99%E6%88%90%E6%9C%AC%E8%A1%A8

* 报表功能：摊余成本表用于查询租入单在某一个时间段租入资产利息确认、租金支付的情况，可以查看一年内到期的租赁负债与一年后到期的租赁负债，便于企业预测未来现金流出金额。
  * 过滤条件字段说明：

| **过滤项**     || **说明**                                                               |
| 资产组织        || 资产选择的范围，根据组织基础资料里的资产组织过滤，默认显示的是当前组织，也可以是该用户有权限的其他组织。                 |
| 货主组织        || 资产选择的范围，如果设置了资产委托关系，将根据委托关系过滤，如果没有设置，可以选择有权限的货主组织，一个资产组织可以对应多个货主组织。  |
| 开始日期        || 查询开始日期。                                                              |
| 结束日期        || 查询结束日期。                                                              |
| 显示明细        || 勾选显示明细，可以将对应租入单相关的付款单、利息确认单等明细数据均显示出来                                |

## 【页面】租赁利息确认单

租赁利息确认单是在租赁过程中对租赁负债所产生的利息的确认，也就是未确认融资费用的分摊。

  - 租赁利息确认单是通过资产租入单的付款计划进行下推

| 租入单编码      || 记录是由那个租入单产生的利息确认单                                                |
| 资产组织       || 携带租入单的资产组织                                                       |
| 货主组织       || 携带租入单的货主组织                                                       |
| 合同名称       || 携带租入单的合同名称                                                       |
| 合同号        || 携带租入单的合同号                                                        |
| 出租方        || 携带租入单上的出租方                                                       |
| 利息确认方式     || 根据租赁参数自动携带，如果租入单往期的利息确认方式为按期确认，后续即使更改了利息确认方式为按付款期，也是沿用以前的利息确认方式  |
=====2.2明细 =====
| **字段**        || **说明**                  |
| 付款期           || 该利息确认单对应的付款期            |
| 期初本金          || 该利息确认单对应的付款期的期初本金       |
| 实际折现率         || 租入单的折现率                 |
| 期初未确认融资费用     || 该利息确认单对应的付款期的期初未确认融资费用  |
| 本付款期利息        || 该利息确认单对应的付款期的利息         |
| 本期确认利息        || 该利息确认单本次确认的利息           |
| 开始日期          || 本次利息确认对应的所属期            |
| 结束日期          || :::                     |
| 天数            || 本次利息确认对应的天数             |
| 本付款期总天数       || 该利息确认单对应的付款期的总天数        |

## 【页面】租赁参数设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A7%9F%E8%B5%81%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE

* 功能概述：系统进行日常业务处理之前，需要确认以下系统参数是否符合企业实际业务的需求。当然，在系统使用过程中，也可以根据实际需求的变化修改这些系统参数的设置。

  * 功能路径：资产管理－>租赁资产－>参数设置－>租赁参数设置。

  * 字段说明：参数说明

| **字段**                   || **说明**                                                                                     |||||
| 日折现率取数方式                 || 可以选择【年折现率/365】的取数方式，也可以选择【(1+年折现率) (1/365)-1】的取数方式。                                        ^||||
| 自动下推利息确认单                || 勾选上之后，则按执行计划会自动下推利息确认单。                                                                    |||||
| 利息确认方式按付款期确认/按期确认        || 按付款期确认利息，即是一个付款期只全额确认一次利息；按期确认利息，则是在该付款期所属的期间内平均分摊确认该付款期的利息。                               |||||
| 利息按期确认时采用直线法分摊/复利分摊时     || 采用直线法分摊，即使利息按直接分摊相应期间；采用复利分摊，则按复利方式分摊到相应期间。                                                |||||
| 自动下推租金报销单                || 勾选上之后，则会按执行计划自动下推租金报销单。                                                                    |||||
| 付款日前（）天自动产生租金报销单         || 填写之后，则会按执行计划在付款日前相应的天数产生租金报销单。                                                             |||||
| 租入单引入规则设置                || 可自行选择以下三种引入方式：1、引入自动产生付款计划及计算其他数据；2、引入不自动产生付款计划但计算其他数据；3、引入不自动产生付款计划及不计算其他数据。              |||||

## 【页面】租赁终止单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A7%9F%E8%B5%81%E7%BB%88%E6%AD%A2%E5%8D%95

系统提供租赁终止单对租入资产因为发生影响租赁负债的事项而需要终止租赁，重新新增新租入单的场景。

====== 1 操作前提 ====== 
  - 资产租入单已经审核且资产卡片已审核

====== 2 字段说明 ======

=====2.1 基本 =====
|**字段**||**说明**|
|单据编号||变更的资产所在资产组织|
|业务日期||变更的资产所属货主组织|
|资产组织||选择需要变更的资产卡片，只支持对单张卡片进行变更。|
|货主组织||变更业务发生的日期，必须在会计政策当前期间范围内。|
|本位币||资产所在组织的会计政策本位币。|
|处置单编码||记录租赁资产终止之后，产生对应卡片的资产处置单。|
|备注||记录说明。|
=====2.2明细 =====
租入单编码，选择需要终止的租入单，除了这个字段外，其余都是系统自动带出。
=====2.3租赁终止单下推资产处置单 =====
 租赁终止单审核后需要下推资产处置单处置原租入的资产。

## 【页面】租赁资产
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A7%9F%E8%B5%81%E8%B5%84%E4%BA%A7

===== 1 租赁资产系统概述 ======

===== 1.1 租赁资产概述 ===== 
   
租赁资产系统以资产租入单管理为中心，从签订租赁合同维护资产租入单计算初始入账价值开始，再由租入单审核自动产生资产卡片至固定资产系统进行后续的实物管理及折旧计提；在租入资产的使用过程中通过租入单付款计划下推租金报销单进行租金的报销并付款，通过资产租入单付款计划下推利息确认进行利息确认（即未确认融资费用的分摊），租赁结束后通过租赁终止单对租入单进行终止，完成租入资产整个生命周期的管理，实现租入资产管理工作的信息化、规范化与标准化、自动化，全面提升企业租入资产管理工作的工作效率与管理水平，使租入资产的管理变得轻松、准确，快捷和全面。 

===== 1.2 租赁资产系统总体流程图 =====

租赁资产系统的业务流程图如下所示（图)

[图:租赁资产流程.png]
===== 1.3 系统特性 =====


  - 支持自动计算租入资产的初始入账价值（使用权资产、租赁负债、未确认融资费用）。  
  - 支持自动产生租金付款计划进行租金的支付。 
  - 支持自动计算每个付款期的利息。 
  - 支持灵活的租金支付频率（可以以月、季、半年、年为单）
  - 与固定资产系统无缝集成，产生资产卡片进行后续的实物及价值管理。    
  - 提供摊余成本表实时查询租赁资产的租赁负债，清晰的了解一年内到期及一年后到期的租赁负债，便于资金规划。

## 【页面】租赁资产使用流程
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%A7%9F%E8%B5%81%E8%B5%84%E4%BA%A7%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B

第一步，启用固定资产

    租赁资产的启用依赖于固定资产，所以在使用租赁资产之前要先启用固定资产。
【资产管理】－>【固定资产】－>【启用期间设置】－>【启用固定资产系统】

第二步，基础资料设置

   1、设置资产类别：系统有预置名称为“使用权资产”的资产类别，用户如果需要细分使用权资产，则需要自行设置新的资产类别。路劲：固定资产－>基础资料－>资产类别
   2、设置会计政策：系统有在会计政策-资产政策处预置资产类别名为“使用权资产”的资产政策，如果有自行新加的资产类别，需要维护到资产政策处，并设置相关的折旧方法为“使用权资产折旧政策”。路径：固定资产－>基础资料－>会计政策
第三步，参数设置  
   设置租赁资产参数，【资产管理】－>【租赁资产】－>【参数设置】－>【租赁参数设置】

第四步，日常业务操作
  1、资产租入单 
  
  2、租金报销单 
  
  3、租赁利息确认单 
  
  4、租赁终止单
 
第五步，期末处理
  1、租赁资产盘点（在固定资产系统进行）

  2、折旧管理（在固定资产系统进行）

  3、账务处理（在智能会计平台处理）

  4、结账（在固定资产系统进行）

## 【页面】租金报销单

  - 租金报销单实际是费用报销单的一个单据类型
====== 2 字段说明 ======
参考人人报销系统的费用报销单

## 【页面】资产租入单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E7%A7%9F%E5%85%A5%E5%8D%95

资产租入单是用来记录租入资产相关信息的单据，在租入单上可以记录租入资产的租赁合同相关信息（比如合同编号、合同名称、出租方、起租日、租赁结束日等信息），可以记录该项租赁的支付信息（发票类型、税率、租金总额、付款频率、付款期数等）、付款计划（系统自动生成，生成后可手工编辑）、其他费用信息，以及使用分配信息,系统通过维护好的资产租入单信息自动计算财务信息（即使用权资产、租赁负债、未确认融资费用）。本节主要实现以下功能：新增资产租入单、维护租入单的基本信息后系统自动产生付款计划、自动计算财务信息、租入单审核自动产生资产卡片。

====== 1 操作前提 ====== 

  - 定义资产类别基础资料，划分使用权资产的种类
  - 定义折旧政策基础资料   
  - 在会计政策中完成资产政策的定义
  - 定义资产位置基础资料

 ====== 2 字段说明 ======

=====2.1 基本信息 =====
| **字段**       || **说明**                                                                      |
| 业务日期         || 维护租入单的日期。                                                                   |
| 租赁负债确认日期     || 确认该项租赁负债的日期，比如2021年之前的租入合同，租赁负债确认日期为2021年1月1日，2021年之后的租入合同，租赁负债确认日期为租赁开始日。  |
| 资产组织         || 资产的管理组织，只能输入组织职能为资产职能的组织。                                                   |
| 货主组织         || 资产的所有权的归属组织，货主组织必须为业务组织。                                                    |
| 合同号          || 租入资产对应的合同信息                                                                 |
| 合同名称         || 租入资产对应的合同名称                                                                 |
| 出租方          || 出租固定资产的供应商                                                                  |
| 免租开始日期       || 如果存在免租，需要维护免租开始及结束的日期                                                       |
| 免租结束日期       || 如果存在免租，需要维护免租开始及结束的日期                                                       |
| 免租期（月）       || 系统自动根据免租开始日期与结束日期进行计算，可手工编辑                                                 |
| 起租日期         || 正式产生租金的日期                                                                   |
| 租赁结束日期       || 合同约定的租赁结束日期                                                                 |
| 租赁期（月）       || 租赁结束日期-租赁负债确认日期（这个租赁期是指按照新准则执行后还剩下的租赁期，即租赁负债确认日距离租赁结束日期的月数）                 |
| 资产类别         || 实物资产所属的资产类别。                                                                |
| 资产名称         || 实物资产的名称。                                                                    |
| 存放位置         || 租入资产存放的位置                                                                   |
| 计量单位         || 实物资产的计量单位。                                                                  |
| 资产数量         || 本次租赁资产的数量                                                                   |
| 关联卡片编码       || 租入单审核后会产生资产卡片，卡片保存后反写租入单的关联卡片编码                                             |
| 备注           || 按需维护想要备注的内容即可                                                               |

=====2.2支付信息 =====
| **字段**           || **说明**                               |
| 发票类型             || 该项租赁合同约定的出租方开给租入方的发票类型               |
| 税率               || 该项租赁合同约定的出租方开给租入方的发票对应的税率            |
| 是否可抵扣            || 根据发票类型，系统自动识别是否可抵扣，也可手工编辑            |
| 原币别              || 租入合同约定的支付币别                          |
| 租金总额（含税）         || 针对该项租赁所有已经支付及将要支付的含税租金               |
| 租金总额（不含税）        || =租金总额（含税）/（1+税率/100）                 |
| 免租金额             || 合同约定的免租金额（由于是免租，就不会存在有税）             |
| 免租金额（含税）         || =免租金额*（1+税率/100）                     |
| 付款频率单位           || 可选择月付、季付、半年付、年付                      |
| 付款频率             || 与付款频率相匹配（比如5个月付，付款频率单位选择月付，付款频率维护5）  |
| 总付款期数            || 该项租赁合同总共的付款期数                        |
| 未付款期数            || 维护租赁负债确认日后需要付款的期数                    |
| 预付租金（含税）         || 填写预付的属于租赁负债确认日之后的租金                  |
| 确认日之前的租金（含税）     || 填写确认日之前的所有租金含税金额                     |
| 租赁负债（租赁付款额）      || 系统自动计算（租赁负债确认日之后将要支付的租金总额）           |
| 历史租入             || 勾选历史租入，显示入账前已确认利息、入账前已支付租金（含税）字段     |
| 入账前已确认利息         || 维护入账前已确认的利息                          |
| 入账前已支付租金（含税）     || 维护入账前已支付的含税租金                        |

=====2.3其他费用 =====
| **字段**       || **说明**                                                           |
| 初始直接费用       || 与该项租入资产相关的发生的初始直接费用，比如运输费、保险费等。                                  |
| 租赁激励         || 出租人为达成租赁向承租人提供的优惠。                                               |
| 预计复原成本       || 承租人为拆卸及移除租赁资产、复原租赁资产所在场地或将租赁资产恢复至租赁条款约定状态预计将发生的成本                |
| 预计担保余值       || 租入方保证在租赁结束时租赁资产的价值至少为某指定金额。                                      |
| 预计行权费用       || 购买选择权的行权价格，前提是承租人合理确定将行使该选择权。                                    |
| 预计终止费用       || 行使终止租赁选择权需支付的款项，前提是租赁期反映出承租人将行使终止租赁选择权。                          |
| 租赁结束费用现值     || =（预计复原成本+预计担保余值+预计行权费用+预计终止费用）/（1+日折现率）∧（租赁结束日-租赁负债确认日），该字段默认隐藏  |


=====2.4财务信息 =====
| **字段**            || **名称**                                                                                                                                                                                                                                                |
| 本位币               || 系统自动获取                                                                                                                                                                                                                                                |
| 汇率类型              || 系统自动获取                                                                                                                                                                                                                                                |
| 汇率                || 系统根据支付信息的原币别与财务信息本位币及汇率类型自动获取                                                                                                                                                                                                                         |
| 使用权资产             || 系统自动计算,历史合同，税可抵扣时，=租赁负债+预付租金(含税)/（1+税率/100）+租赁结束费用现值\\                        税不可抵扣时，= 租赁负债+预付租金（含税）+租赁结束费用现值\\ 非历史合同，税可抵扣时，=租赁负债+预付租金(含税)/（1+税率/100）+初始直接费用+租赁结束费用现值-租赁激励，\\                            税不可抵扣时，= 租赁负债+预付租金（含税）+初始直接费用+租赁结束费用现值-租赁激励  |
| 使用权资产（本位币）        || 系统自动计算                                                                                                                                                                                                                                                |
| 租赁负债              || 系统自动计算,=∑ 付款计划的每期折现值                                                                                                                                                                                                                                  |
| 租赁负债（未确认融资费用）     || 租赁负债（租赁付款额）-租赁负债                                                                                                                                                                                                                                      |
=====2.5付款计划 =====
| **字段**        || **名称**                                                       |
| 首次付款日期        || 租赁负债确认日后第一次付款的日期                                             |
| 年折现率          || 可以获取租赁内含利息的，应当采用租赁内含利率作为折现率；无法确定租赁内含利率的，应当采用承租人增量借款利率作为折现率。  |
| 日折现率          || 根据租赁系统参数取值，=年折现率/365或者（1+年折现率）/（1/365）-1                     |
| 付款期次          || 付款的期次                                                        |
| 计划付款日期        || 租赁负债确认日后将要支付租金的日期                                            |
| 付款金额（含税）      || 含税的计划付款金额                                                    |
| 税率            || 携带支付信息的税率                                                    |
| 税额            || =付款金额（含税）/（1+税率/100）                                         |
| 付款金额（不含税）     || =付款金额（含税）-税额                                                 |
| 付款币别          || 携带支付信息的原币别                                                   |
| 本付款期利息        || =期初本金*（1+日折现率）∧(本期折现天数-上期折现天数)-期初本金,取计算的值与期初未确认融资费较小者        |
| 折现天数          || =计划付款日期-租赁负债确认日期                                             |
| 折现系数          || =（1+日折现率）∧折现天数                                               |
| 现值            || 税可抵扣时，=付款金额（不含税）/折现系数，\\ 税不可抵扣时，=付款金额（含税）/折现系数               |
