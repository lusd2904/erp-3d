## 【页面】星空工作台
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%98%9F%E7%A9%BA%E5%B7%A5%E4%BD%9C%E5%8F%B0

====== 1 星空工作台与轻表单概述 ======
  * 星空工作台(Galaxy Workbench)，是金蝶AI星空为移动设备使用轻应用和业务单据打造的访问入口应用，与轻表单结合，可配置轻表单在移动端进行使用。星空工作台同时支持云之家、钉钉、企业微信、小程序等移动平台，也可以用于发布自建的移动应用、移动表单或移动单据，解决第三方平台移动应用入口配置集成难的问题。
  * 轻表单，是为移动端录入相关业务单据打造的通用配置工具。它支持用户将PC端的部分相关业务单据通过自定义配置，发布到移动端进行使用，而不需要使用代码进行开发。

## 【页面】星空工作台配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%98%9F%E7%A9%BA%E5%B7%A5%E4%BD%9C%E5%8F%B0%E9%85%8D%E7%BD%AE

====== 星空工作台配置 ======
====== 1 概述 ======
星空工作台配置是面向星空工作台轻应用的相关配置功能，可以支持用户配置星空工作台上的显示内容。
====== 2 功能说明 ======
用户选择星空工作台配置，打开后进行反审核，即可编辑。目前星空工作台支持添加：标准轻应用、自建移动应用、轻表单。
===== 2.1应用列表 =====
  * 应用名称：当前添加的应用名称，添加后自动带出，不可修改。
  * 别名：应用在星空工作台移动端显示的名称，可自定义修改。
  * 应用类型：区分应用属于标准应用、自建应用、轻表单中的哪一类别。
  * 子系统：系统中业务单据所属的子系统分类。添加自建应用和轻表单后，若有子系统信息，会自动带出。

===== 3 业务说明 =====
已审核且未禁用状态下，星空工作台配置才会生效。

## 【页面】轻表单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BD%BB%E8%A1%A8%E5%8D%95

====== 轻表单 ======
====== 1 概述 ======
轻表单是将金蝶AI星空业务单据转换为移动端单据的配置工具。
====== 2 功能说明 ======
  * 源单据：选择系统中的业务单据，选择后可以针对此单据进行配置。
  * 子系统：选择的源单据在系统中对应的子系统。自动带出，不可编辑。
  * 主单据体：由于移动设备当前无法支持多单据体录入，因此需要选择希望加载的主单据体。选择的主单据体决定着后续可配置的单据体字段。
  * 单据编码：根据系统编码规则生成。
  * 列表发布：勾选此参数，发布到移动端后可查看单据列表，同时支持新增。
  * 新增发布：勾选此参数，发布到移动端后可直接新增单据。
  * 启用附件上传：勾选此参数，移动端单据可支持上传附件。
  * 描述：对此轻表单的描述信息。
===== 2.1 单据头字段 =====
在此编辑需要在移动端显示的单据头字段相关配置信息。
  * 字段名称：来自选择的源单据携带的字段名称。
  * 字段类型：字段的业务类型。
  * 字段高亮显示：勾选此选项，该字段在移动设备上会高亮显示，用于需要强调显示的重要字段。
  * 字段固定可见：勾选此选项，该字段在初始加载时，不用展开单据头也可看到。
===== 2.2 单据体字段 =====
在此编辑需要在移动端显示的单据体字段相关配置信息。
  * 字段高亮显示：同上单据头字段。
  * 明细预览显示：移动端录单添加明细行后，会显示对应的明细预览行，勾选此选项的字段会显示在明细预览行中。
  * 明细预览关键字段：勾选此选项，该字段会在明细预览行中首行强调显示。同时只能有一个字段勾选此选项。
===== 2.3 单据操作 =====
在此编辑需要在录单时显示的操作。
  * 操作名称：操作在移动端页面显示的名称。可自定义修改，默认会带出操作类型的名称。
  * 操作类型：系统中支持操作的名称。
  * 操作代码：系统中支持操作的标识。
===== 2.4 列表显示 =====
轻表单在移动端支持查看单据列表，在此处编辑移动端单据列表显示的字段和效果相关配置。
  * 字段名称：目前此处只支持添加单据头字段。
  * 字段类型：同上述字段类型。
  * 字段高亮显示：同上述字段高亮显示。
  * 列表关键字段：勾选此选项，该字段会在单据列表中首行强调显示。同时只能有一个字段勾选此选项。
===== 2.5 详情操作 =====
轻表单在移动端支持查看单据详情，在此处编辑单据详情支持的操作相关配置。
对于不同单据状态下支持的操作，系统内置的操作已经有相关的逻辑处理，因此会根据单据状态显示可支持的操作。
  * 操作名称：操作在移动端页面显示的名称。可自定义修改，默认会带出操作类型的名称。
  * 操作类型：系统中支持操作的名称。
  * 操作代码：系统中支持操作的标识。
  * 操作参数：某些操作可能会有具体的配置项，在此配置。
