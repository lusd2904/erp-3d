## 【页面】在制品盘点单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9C%A8%E5%88%B6%E5%93%81%E7%9B%98%E7%82%B9%E5%8D%95

======1 在制品盘点单 ======

=====1.1 功能概述 =====
应用场景：系统在制数量与生产现场实际在制数量不一致时进行调整，以达到系统数据与现场情况实时统一。

=====1.2 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【在制品盘点单】

======2 操作说明 ======

应用介绍：
1、通过目录菜单“工序在制盘点单”创建盘点单，加载数据界面可按需选择盘点范围，
实际在制数量默认值：枚举值：0、按系统在制数量，默认为0；
转入数量=0不参与盘点：勾选项，默认勾选；
禁用物料不参与盘点：勾选项，默认勾选；
包含已审核盘点数据：勾选项，默认勾选；

2、通过加载数据设置过滤条件确定盘点工序计划分录，可通过界面删除部分工序，点击创建盘点单生成单据。

3、生成工序在制盘点单后，默认为创建状态，可进行打印下发车间进行盘点工作，当工序计划分录目前处于正在盘点中状态时（非审核态工序在制盘点单包含此工序），再次创建工序在制盘点单时将自动去除；
现场进行实际盘点完成后，回收单据进行录入实际在制数量，系统将自动计算工序盘点差异，工序在制盘点单审核后累计反写到工序计划分录；
工序计划分录反写工序盘点差异后，严格控制时将影响后续可汇报数量校验；
拆卡时，工序盘点差异保留在母单中；
修改生产订单工序进度表增加工序盘点差异字段显示；
审核后工序在制盘点单不允许反审核，要调整需从新生成工序在制盘点单。

======1 工序生产汇报 ======

=====1.1 功能概述 =====
工序生产汇报是生产车间在执行生产订单时，对生产情况的实时进度反应。生产任务单汇报用于汇报生产任务的开工和完工时间、生产数量、生产工时、生产质量等数据。


=====1.2 使用前提 =====
对应的生产订单分录需处于开工、完工状态，且未挂起。

=====1.3 功能路径 =====
【餐饮加工管理】－>【加工车间管理】－>【工序执行】－>【工序生产汇报】


=====1.4 生成方式 =====
  - 生产订单分录下推生成。
  - 生产汇报单新增界面，通过选择生产订单生成。

====== 3 操作说明 ======
====保存==== 

1.只有当生产订单为开工或者完工，生产汇报单才能进行保存操作；

2.生产汇报单保存时，影响对应生产订单的【汇报选单数量】；

3.生产汇报单保存时，进行数量控制检验，需满足条件：累计【合格品汇报数量-返修数量】不能超过入库上限。

====作废 ====

生产汇报单作废时，扣减对应生产订单的【汇报选单数量】。 
====审核/反审核==== 

1.生产汇报单审核、反审核时， 影响对应生产订单的【合格数量】、【不合格数量】、【返修数量】和【报废数量】。

2.只有当生产订单为开工或者完工状态，且无有效下游单据时，生产汇报单才能进行反审核操作。

====倒冲领料==== 

调出生产倒冲领料工作台，查看汇报单对应的倒冲情况及进行倒冲操作。

====== 4 业务说明 ======

====选单==== 

生产汇报单支持通过选择生产订单分录生成。

选单条件：

1.数量控制：生产订单分录的入库上限-汇报选单数量+返修数量>0；

2.组织校验：生产订单表头的【生产组织】必须是生产汇报单表头的【生产组织】；

3.选单分组：【生产组织】相同，不同生产订单中的分录，可以在同一张生产汇报单中进行汇报；

4.选单必录字段：生产汇报单选单前，“生产组织”为必录字段。

====下推 ====

生产订单下推生成生产汇报单时，支持批量下推。

下推条件：

1.数量控制：生产订单分录的入库上限-汇报选单数量+返修数量>0；

2.下推分组：【生产组织】相同，不同生产订单中的分录，可以在同一张生产汇报单中进行汇报。

====在制品扣减==== 

1.在制品扣减时机参数为“汇报时扣减”时，生产汇报单审核时，扣减在制品数量；

2.生产订单中的联副产品的入库数量不影响在制品的扣减。


====新增联副产品==== 

1.支持手工新增汇报单行并录入物料编码、产品类型及生产订单号；

2.手工新增行会反写生产订单，生成相应的联副产品行。
