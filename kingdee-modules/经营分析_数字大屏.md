## 【页面】数字大屏

====== 1 数字大屏概述（V7.7新增） ======
===== 1.1 数字大屏概述 =====
 
为满足企业的数字看板投放、展示需求，方便管理层、客户及时了解业务数据，V7.7新增数字大屏相关功能，用户可通过设置生成大屏链接，复制到浏览器打开即可免登看板。

===== 1.2 系统特性 =====
 
本系统主要包含以下特点：

  - 大屏链接是通过第三方系统登录授权生成的。选择一个用户作为大屏用户（即使用这个用户生成免登链接），选择这个用户有权的看板即可生成大屏链接。
  - 复制链接到浏览器打开即可免登查看数字看板，链接可重复访问，不受用户超时退出和踢出影响，一直保持在线。
  - 一个大屏用户可生成多个大屏链接，同一个大屏链接可在多个屏幕上同时打开。
  - 基于安全考虑，大屏链接第三方系统登录授权需要启用白名单，并把大屏设备的IP地址加入到IP白名单。（V8.0新增）
  - 数字大屏功能是免费的，支持用轻分析自定义看板生成大屏链接，大屏用户有轻分析许可即可。
  - 数字看板由轻分析应用生成，大屏用户需要看板的权限，可以在轻分析应用授权里面修改看板的指定角色和指定用户。
  - 看板展示的数据范围取决于大屏用户的数据权限。
  - 可通过“轻分析应用授权管理”调整看板的指定角色和用户。

===== 2 预置看板 =====
 
V7.7预置以下看板：

  - 全渠道经营分析看板；
  - 数字零售看板；
  - 供应链运营看板；
  - 数字经营看板；
  - 生产运营看板。

====== 1 功能描述 ====== 

**系统介绍**
  * 经营分析平台通过对数据模型和页面进行设计和管理，创建满足企业个性化需求的报表。
  * 主要包括三个方面的功能：数据处理、分析页面设计和管理工具。
  * 使用经营分析数据设计对数据模型进行设计和修改；使用经营分析界面设计对图表进行设计以及发布等操作；使用经营分析管理工具对模型进行控制，如备份、恢复、切换账套、服务管理、许可服务等操作。


**使用前提**
  * 使用前需安装“经营分析平台”模块，并且获得有效的许可，才能使用。


**功能路径**
  * 【经营分析平台】→【经营分析数据设计】
  * 【经营分析平台】→【经营分析界面设计】
  * 【经营分析平台】→【经营分析管理工具】
 ====== 2 概念和术语说明 ======

=====2.1 用户 =====

经营分析平台设置三种用户类型：管理员、开发用户、普通用户，分别用于以下权限：

[图:jyfxpt_yhjs.jpg]
   *  管理员 

  - 创建和管理用户、用户组；
  - 管理已连接的ElastiCubes；
  - 定义web配置；
  - 连接活动目录；
  - 更多操作权限。

  *  开发用户

  - 创建、设计、编辑和分享分析页面（即报表）；
  - 决定用户对他们所分享的报表的操作权限：编辑权限（该用户是开发用户或管理员）、浏览权限（该用户是普通用户）。

  *  普通用户

  - 浏览、钻取、过滤由设计者分享的报表；
  - 不能创建新的报表或编辑已有报表。


=====2.2 ElastiCubes =====

  * ElastiCubes是经营分析平台为商业智能分析而设计的、专有的超高速数据存储结构。
  * ElastiCubes支持TB级别的大数据，且整合不同数据源的数据，比如：
      - 传统的关系型数据库，如：SQL Server、MySQL、Oracle、postgreSQL等；
      - 本地数据文件，如：Excel、CSV、Access文件；
      - 在线Web Services，如：Salesforce.com、Google AdWords、Google Analytics、Zendesk等。
  * ElastiCubes是在经营分析平台数据设计中创建和管理的。


=====2.3 图表 =====

图表即一个动态展示数据的图形，用户可以选择数据类型和图表类型来展示数据，这些图表包括：仪表盘、饼图、交叉表、条形图、折线图、散点图、中国地图等，用户也可以自定义开发图表。

=====2.4 分析页面 =====

   *分析页面即报表，包含了一个或多个可视化数据的图表。
   
     - 可以定义哪些图表显示分析页面上；
     - 可以访问自己创建的以及其他人分享的分析页面；
     - 允许创建你所需要的尽可能多的分析页面，没有限制。
   
   [图:jpgjyfxpt_fxym..jpg]
   
 
=====2.5 字段 =====

     * 每一个字段代表了ElastiCube中的一列数据。图表是由数据源中的字段组成的，用户可通过简单地从数据浏览器中选择字段来创建图表。

     * 设计图表时，字段会被分成两种类型：
         - 数值型字段：数字（量化的数据）可以计算的数据，如工资、销售额、分数、点击数等。
         - 描述型字段：用来标记或分类，例如产品、位置、类别等。

     * 一般来说，图表结合了这两种类型的字段。例如：展示一个产品在一段时间内的销售额，其中销售额是数值型字段，而产品和时间是描述型字段。

 ====== 3 功能操作 ======

=====3.1 连接数据源 =====

  * 经营分析平台的数据设计支持连接多种数据源：数据库服务器、本地文件、Web Services、自定义SQL表达式等。
[图:jyfxpt_ljsjy2.jpg]

   * 操作步骤如下： 
     - 打开【经营分析数据设计】；
     - 点击快速启动下的“新建ElastiCube”并命名（当本地已有ElastiCube文件时，可以选择“打开文件”，对该文件进行编辑）；
     - 选择工具栏中的“添加数据”，选择数据源类型，并确定添加即可：
           * 若添加Excel文件，则选择【文件】**->**【Microsoft Excel文件】，在弹出的窗口选择Excel文件，并确定添加；
           * 若添加SQL Server，则选择【数据库服务器】**->**【Microsoft SQL Server】，在弹出的窗口选择输入数据库服务器位置和登录信息，连接成功后选择需要的数据库列表，并确定添加；
           * 若添加MySQL，则选择【数据库服务器】**->**【MySQL数据库】，在弹出的窗口选择输入数据库服务器位置和登录信息，连接成功后选择需要的数据库列表，并确定添加；
           * 若添加自定义表，则选择【自定义】**->**【自定义SQL表达式】，在弹出的窗口中输入自定义表的表名后，编辑SQL语句来访问已有的表和字段，完成编辑后，点击【编译SQL表达式】菜单进行验证，最后确定保存即可；
              * 注：可以保存一个不完整的或无效的SQL表达式，但不能构建这个自定义表达式。为了预览效果，必须至少完成一个相关的基本表的构建。
           * 添加更多其他数据类型，根据提示进行操作即可。


=====3.2 处理数据表和字段 =====

==== 3.2.1 搜索表和字段 ==== 

    * 在 ElastiCube 模型中可能有很多包含各式各样字段的表，为了便于查看和使用这些表和字段，可以通过搜索相关的表和字段来解决。
      - 在模型的右上角点击放大镜图标；
      - 在输入框中输入字母或字段的名称进行搜索；
      - 根据输入列出搜索结果；
      - 点击某个结果将突出其相关的字段或表。
[图:jxfxpt_ssbzd.jpg]


==== 3.2.2 创建表间关系 ====

  * 关系指定表之间的连接方式，并使数据有意义地整合在一起。
      * 例如，当需要了解客户的每个订单情况时，订单信息比客户信息更重要；
      * 但是您不需要将客户信息和订单信息存储在同一张表，而可以将客户数据和订单数据存储在两个相关联的表中，指定这两个表之间的关系来同时查看每个订单以及相应的客户信息。
      * 实际上，您可以通过在报表中建立关联关系来查询和整合来自多个表的数据。

  * 表间关系的处理主要分为创建和删除：
      * 创建表间关系：
          - 找到每个表中需要指定关系的字段。例如，两个表都有CustomerID这个字段；
          - 确保用来创建关系的这两个字段的类型相同，例如十进制字段；
          - 检查或者修改字段类型：点击相关字段，会出现一个字段类型的菜单列表，点击下拉选项改变字段类型；
          - 切记确保字段中的数据与字段类型一致。例如，文本数据需要一个字段类型的文本；
          - 单击字段右侧，按住“关联”图标，同时移动鼠标链接到相应的表的对应字段直到鼠标的光标在相关字段中消失；
          - 关系建立后，连线会变绿色，并显示 “删除关联”的提示消息。松开鼠标按钮，这两个字段之间就会出现一个连线。
 
[图:jyfxpt_cjgx1.jpg] [图:jyfxpt_cjgx2.jpg]

      * 删除表间关系：
          - 点击已有关系的任意一部分，连线会突出显示；
          - 在连线上会出现一个删除的图标，点击该图标，确认删除操作即可。

[图:jyfxpt_scgx.jpg]


==== 3.2.3 数据表处理 ====

    * 在经营分析数据设计中对数据表的处理主要包括5个操作按钮：预览、添加自定义字段、复制数据表、删除数据表、附加选项。
[图:jyfxpt_sjbcl.png]    [图:jxfxpt_sjbcl2.jpg]

==== 3.2.4 字段处理  ====

     * 在经营分析数据设计面板中，对字段的处理主要包括：添加新字段、定义和编辑字段公式。
    
       *** 添加新字段：**
       - 单击需要添加字段的数据表；
       - 将鼠标光标放置在在数据表名上，直到出现选择图标；
       - 单击【添加新的自定义字段】图标；
       - 新字段将被添加到表中，并打开字段设置窗口：
             * 字段名称：在设置窗口中双击字段名称来重命名或编辑字段名。
             * 设置字段类型：从下拉框选择字段类型。字段类型应该基于该新字段中存储的数据类型。例如，文本数据的字段类型必须设置为文本类型，而日期数据的字段类型必须设置为日期类型。
             * 编辑字段表达式：SQL语句可以用来定义新字段中的数据。

       *** 删除自定义字段：**单击字段，再单击字段的设置菜单底部的删除菜单便能删除自定义字段。

       *** 定义和编辑字段公式：**
       - 单击自定义字段直到设置菜单打开，选择【编辑】；
       - 表编辑器将打开，可以在此处输入SQL语句来访问已存在于ElastiCube模型管理器中的数据表和字段；
       - 完成SQL语句的编辑后，点击【编译SQL表达式】菜单进行验证；
       - 点击编辑器右上方的【预览表结果】菜单，查看基于SQL语句的执行结果（注意：预览前必须完成至少一个相关的基本表的构建）；
       - 点击编辑器上的保存按钮进行保存。
            * 提示1：按下Ctrl+Space键快速完成SQL语句；
            * 提示2：使用别名来访问表字段，并引用别名来调用相关字段会更容易，例如：Select A. From table as A；
            * 提示3：可以在表达式使用“–”为单行或者使用/*…*/为块添加注释。

=====3.3 构建ElastiCubes =====

     * 定义好一个ElastiCube的架构后，需要对其进行构建。构建会从选定的数据源中获取到数据，然后导入到架构中。
     * 构建一个ElastiCube的步骤：
         - 打开【经营分析数据设计】，选择工具栏的【构建】；
         - 定义以下选项：
             * **目标服务器**：选择ElastiCube发布的服务器地址；
             * **发布选项**：选择导入哪种数据：
                            * 发布变动的ElastiCube：数据仅导入到与前一次构建有改变的表和字段中。
                            * 发布完整的ElastiCube：数据导入到所有表中，并覆盖已有的ElastiCube中的数据。
             * **更多设置**：包含两个相关的设置：
                            * 发布日志：选择在存储在构建日志中的明细情况；
                            * 示例数据：选择一页显示的数据行数。
         - 点击【构建】，开始执行构建过程；
         - 在界面底部会出现一个日志面板，记录着构建过程中的每一个细节。当构建完成时，会出现构建成功的消息：Build successfully ended。
[图:jyfxpt_gj1.png]

     * 构建日志：构建日志会记录所有的步骤、活动和在构建过程中发生的警报。
[图:jyfxpt_gj2.png]

=====3.4 修改ElastiCube模型 =====

     * 经营分析数据设计可以对已有的ElastiCube模型进行修改，步骤如下：
         - 在【经营分析数据设计】打开已有模型有两种方式：
             * 选择工具栏的【快速启动】**->**【打开文件】，选择所需修改的ElastiCube模型；
             * 选择工具栏的【服务器】**->**【本地】，鼠标悬停在所需修改的ElastiCube模型名称上，待右侧出现编辑图标后，点击编辑图标即可。
         - 现在就可以对模型进行修改，添加数据、字段、表等操作；
         - 操作完成后，点击工具栏的【构建】，等待构建完成后，保存即可（需要构建一次才能将这些修改应用于ElastiCube中）。

=====3.6 图表设计 =====

==== 3.6.1 添加图表 ====

     * 一个分析页面（报表）包含一个或多个图表。
     * 为了快速并直观地创建图表，可以使用图表向导。图表向导会为用户数据提供一个最佳建议，自动地指引用户通过一个简单的进程来创建图表。
     * 通常，根据图表向导的建议，会帮助用户创建一个不错的图表但是，如果你想要设置图表的更多选项，可以点击图表向导左下方的“高级设置”，进行更丰富的设计。

     ***使用图表向导添加图表** 
               - 如果这是报表中的第一个图表，则点击“选择数据”选项，数据浏览器会打开，然后你可以从这个报表的ElastiCube中选择一个字段（即列）。如果报表中已有图表了，则点击工具栏上的“添加图表”的选项；
                   * 注：在弹出界面的右上角选择数据源，即模型。
               - 选择数据后，设置图表标题；
               - 在数据浏览器界面，为图表选择字段。这个字段会自动以最佳建议图表的形式展示。你可以在界面中选择所需的图表类型，进行修改；
               - 如果想要对图表进行更多设置，则点击数据浏览器右下角的“高级设置”，进行更多设置。
[图:jpgjyfxpt_tjtb1.jpg]
           

         *** 数据浏览器**：可以为图表选择和添加字段（列）。
            - 每个字段的左边符号表示字段的类型：日期、数值型数据、字母数字字符串等类型；
            - 搜索：输入搜索条件后，自动过滤出匹配的字段结果；
            - 鼠标悬停在某个字段时，会出现该字段默认的计算方式，点击“更多”可以选择其他的快速函数和筛选选项；
            - 点击函数图标，进入函数编辑界面。

==== 3.6.2 图表设计器 ====

==== 3.6.3 更多设计选项 ====

==== 3.6.5 报表和图表过滤 ====

     * 经营分析界面设计中，如果用户拥有报表编辑权限，那么该用户可以定义报表过滤器和图表过滤器。
       * 报表过滤器：该过滤器将影响报表中的所有图表（除非图表被设置为依赖图表），开发用户可以创建报表过滤器，普通用户可以浏览和使用它；
       * 图表过滤器：该过滤器仅影响当前图表，在分析页面是不可见的，且在分析页面无法直接对它们进行编辑，只能在图表设计器中设置。开发用户可以定义在突变中显示哪些数据子集，普通用户无法看到这些过滤器并且无法改变它们；
       * 注意：报表编辑权限是由拥有该报表的编辑权限的开发用户分配的。

     *** 创建报表过滤器**：
          - 点击分析页面（报表）右侧面板中的“添加过滤条件”；
          - 选择要过滤的字段；
          - 在过滤面板中选择过滤类型，如列表、文本、排名等，这些选项是根据所需的字段类型而有所不同（日期、数字型数值、描述型数值）；
          - 点击“收藏”即可保存当前设置的过滤器（注意：收藏的过滤器对共享用户是可见的）；
          - 点击“确认”保存该过滤器。
          * 报表过滤器设置成功后，会在分析页面的右侧展示出来，它的任何改变都会立即影响到整个分析页面。
          * 提示：你可以在过滤器面板中通过拖动过滤器来重新布局。

     *** 编辑报表过滤器**：

          - 在图表设计界面，打开（编辑）图表；

===== 3.7 发布分析页面 =====

     * 经营分析平台可以将创建的分析页面发布到K3 Cloud的业务系统中，方便用户在K3 Cloud中浏览报表。
     * 发布分析页面的步骤如下：
         - 打开【经营分析界面设计】，输入用户名/邮箱、密码登录；
         - 在分析页面列表中，点击所需发布的分析页面；
         - 点击报表上方工具栏中的分享到K3的图标，在弹出的窗口中设置好业务系统以及报表名称，并点击“分享到K3”确定发布；
         - 点击该报表上方工具栏中分享图标，分享给K3用户组；
         - 打开K3 Cloud客户端，选择前一步骤中发布的账套，输入管理员的账户密码进行登录；
         - 打开【系统管理】**->**【系统管理】**->**【授权】**->**【业务功能对象授权】；
         - 在“授权角色”中输入“全能角色”，得到全能角色的结果，双击该全能角色；
         - 勾选全能角色后的“显示全部业务对象”，在过滤条件框中输入“经营分析”；
         - 经营分析相关的报表会罗列出来，选中步骤3中发布的报表名称，此时该报表权限为“无权”，设置为“否。”在右侧的功能权限下，勾选“有权”；
         - 点击上方工具栏中的“授权”，等待授权操作完成；
         - 授权成功后，步骤9中的报表变为“有权”，且设置为“是”；
         - 再次打开K3 Cloud客户端，以对应的账套和非管理员用户、密码登录，在发布的业务系统下即可看到该报表名称，单击该报表即可浏览。

=====3.9 数据安全 =====

     * 经营分析平台是围绕一个强大而灵活的安全架构建立的，既全面又直观。
     * 经营分析界面设计可以对数据安全进行设置，能够针对某个数据模型或字段设置访问权限和数据安全权限，限定用户或用户组的访问权限，加强数据安全的管理。
        *** 分配ElastiCube服务器访问权限**：默认情况下，当增加一个ElastiCube服务器时，所有用户都有权访问它；分配权限后，仅有权用户才能访问该ElastiCube服务器上的ElastiCube。
            - 以管理员用户登录经营分析界面设计，点击【管理中心】**->**【数据安全】；
            - 鼠标悬停在ElastiCube服务器名称上，然后点击“访问权限”；
            - 在弹出的窗口中，输入需要授权的用户或用户组；
            - 点击“确认”即可。
[图:jxfxpt_sjaq1.jpg]

        *** 分配ElastiCube访问权限**：
            - 以管理员用户登录经营分析界面设计，点击【管理中心】**->**【数据安全】；
            - 在所需设置授权的ElastiCube模型右侧，选择“访问权限”；
            - 在弹出的窗口中，输入需要授权的用户或用户组；
            - 点击“确认”即可。
[图:jxfxpt_sjaq2.jpg]

        *** 定义数据安全权限**：每个数据安全规则应用于ElastiCube中一个指定的字段，也指定用户或用户组。数据安全所定义的数值必须包含在指定字段中，且跟此数值有关的数据只对某个用户或用户组有效。
            - 以管理员用户登录经营分析界面设计，点击【管理中心】**->**【数据安全】；
            - 在所需设置授权的ElastiCube模型右侧，选择“数据安全”；
                * 如果该ElastiCube还未设置任何数据安全规则，则打开的界面中会提示：数据安全尚未设定。
            - 点击“添加字段”，将出现一张列出该ElastiCube中所有字段的清单；
            - 选择一个字段，例如：部门。选择的字段会出现在数据安全的规则列表中。
                * 注：不能选择日期类型的字段。
            - 在规则表的左侧可以添加定义访问该数据的用户和用户组，点击“添加限制”；
            - 在规则表的右侧可以定义指定的用户或用户有权访问的数值；
                * 注：可以选择多个数值；
                * 若选择的是数值型字段，必须输入完整的字段名，不支持自动匹配；
                * 可以选择“所有”或“无”：“所有”指定无论该字段包含哪些数值，所选择的用户或用户组都可以查看该数据；“无”指定无论该字段包含哪些数值，所选择的用户或用户组都无法看到该数据。

         - 切换成功后，该模型的模型名称更新为步骤2中的账套名称，模型右侧出现“成功”。
             * 若切换失败，则模型名称不会更新，模型右侧出现“失败”，点击“失败”查看详情。

         - 等待数据更新操作完成,若更新成功则会在模型右侧出现“成功”，若更新失败则会出现“异常”，点击即可查看详情。

## 【页面】经营效率

===== 1 经营效率 ===== 

[图:jxfxpt_jyxl.jpg]
 
===== 2 数据说明 =====

  - 数据来源为：科目余额表。
  - 金额单位：元/万元，默认万元。
  - 按月核算现金周转天数、存货周转天数、应收账款周转天数、应付账款周转天数。
  - 公式说明：
             * 现金周转天数＝存货周转天数+应收账款周转天数-应付账款周转天数

             * 应收账款周转率=当期销售净收入/(（期初应收账款余额 + 期末应收账款余额）/ 2)
             * 应收账款周转天数=360/应收账款周转率
             * 应付账款周转率=（主营业务成本（本期数）+期末存货成本-期初存货成本）/[(应付账款期初余额+应付账款期末余额)/2]×100%
             * 应付账款周转天数=360/应付账款周转率

===== 3 图表说明 =====

  * 现金周转天数、存货周转天数、应收账款周转天数、应付款周转天数：采用指示器，直观展示指标。

===== 4 功能与价值 =====

  * 主要功能：展现现金周转天数、存货周转天数、应收账款周转天数、应付款周转天数等关键营运能力分析指标。
  * 业务价值：帮助企业分析其利用资金效率，为企业管理者深入认识企业盈利能力和风险水平提供有用的信息，提高企业管理水平。

## 【页面】轻分析设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BD%BB%E5%88%86%E6%9E%90%E8%AE%BE%E7%BD%AE

====== 1 概述 ======

针对私有化部署客户在使用星空系统的轻分析功能时，需要根据不同的部署方式调整轻分析设置。

====== 2 操作入口 ======

路径：基础管理 => 公共设置 => 轻分析设置

====== 3 配置项说明 ======

  - 轻分析服务器地址（HTTP）：客户端访问轻分析服务的HTTP地址。若未填写，则默认使用当前客户端星空系统地址的域名加上端口1800，且会根据客户端星空系统的请求协议进行匹配，即星空的地址为http，则轻分析的地址也会匹配为http。
  - 轻分析服务器地址（HTTPS）：客户端访问轻分析服务的HTTPS地址。若未填写，则默认使用当前客户端星空系统地址的域名加上端口1950。
  - 星空服务器地址：客户端访问星空的HTTP地址。若未填写，则默认使用当前客户端星空系统地址。
  - 轻分析内网服务地址：星空服务器访问轻分析服务的地址。若未填写，则默认为http://localhost:1800。
  - 星空内网服务地址：轻分析服务器访问星空服务的地址。若未填写，则默认为http://localhost/k3cloud。
  - 轻分析取数方式：指定轻分析单据取数的方式。推荐使用“返回临时表（异步）”或“返回SQL语句”。仅在系统数据量较小时，可以使用“返回数据”。
  - 轻分析发布菜单排序设置：默认按发布时间顺序升序排列。可根据业务需求选择支持的排序方式。
  - 记录轻分析详细日志：启用该选项可在排查问题时记录关键信息到服务器日志文件中。平时使用时建议停用，以减少服务器资源浪费。
  - 不需动态加载组件：用于处理浏览器兼容性问题，平时使用无需调整。
  - 嵌入式轻分析按列表取数：当单据列表通过星空表单插件干预时，启用该选项以支持插件。若无此情况，无需启用，避免不必要的服务器资源浪费。
  - 启用字段授权：默认未启用时，轻分析数据根据建模时设计字段全量展示。启用后，轻分析将参考星空系统的字段授权设置，不展示用户无权访问的字段数据。若客户任何一个组织无权限查看某字段，则其他组织该字段的值在轻分析中也无法查看。
