## 【页面】返利余额使用规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E4%BD%99%E9%A2%9D%E4%BD%BF%E7%94%A8%E8%A7%84%E5%88%99

**功能概述：**返利管理使用返利账户时提供账户使用规则的设置。

**使用前提：**设置不同返利账户类型的资料。

**功能路径:** 【电商与分销】－>【返利管理】－>【基础资料】－>【返利余额使用规则】

**字段说明：**按返利账户、按客户分别设置对返利账户余额使用的规则，

表头字段说明如下：

| **  字段**     || **说          明**                                                   |
| 规则编码         || 手工填写，用于设置返利账户的规则编码                                                 |
| 规则名称         || 手工填写，用于设置返利账户的规则名称                                                 |
| 结算组织         || 用于指定本规则的创建和使用组织                                                    |
| 返利账户         || 用于指定返利规则使用的返利账户                                                    |
| 币别           || 用于设置返利账户的使用币别                                                      |
| 禁用状态         || 返利账户禁用后记录禁用状态，不允许使用                                                |
| 描述           || 手工填写，对本账户信息进行相应的描述和说明                                              |
| 是否指定商品范围  |   | 若为是，则参与使用返利账户的商品为指定范围内的商品；在明细中设置具体商品；\\ 若为否，则参与使用返利账户的商品为订单上的所有商品  |
| 是否支持促销活动  |   | 若为是，则在促销执行后仍可正常使用返利规则；\\ 若为否，则在订单执行促销后不允许使用本返利规则                   |

返利余额使用规则表体明细字段：
|**字段**||**说          明**|
|客户类别||用于指定使用返利规则的订货客户类别|
|客户编码||用于指定使用返利规则的订货客户编码|
|客户名称||用于显示使用返利规则的客户名称|
|订单金额>=||用于设置使用返利账户余额的条件，只有订单金额满足时才能使用返利账户的金额|
|订单金额使用比例||在允许客户使用返利账户余额抵扣货款时，对使用的条件以及订货金额的使用比例进行设置，网上订单下单时，若使用返利账户支付货款，则在返利使用金额确定后，将使用额度做为分录商品的折扣扣减应付货款。。例如：订货金额必须大于1000时，订单金额允许20%的额度可以使用账户金额，则参数设置为返利账户使用条件为>=1000元，使用返利账户的订单金额比例则设置为20%。|
|开始日期||根据定义返利规则有效使用的起始时间|
|结束日期||根据定义返利规则有效使用的截止时间|

## 【页面】返利余额流水账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E4%BD%99%E9%A2%9D%E6%B5%81%E6%B0%B4%E8%B4%A6

**功能概述：**返利余额流水用于记录客户的每一笔返利账更新明细，及时掌握返利账户余额的使用情况。

**使用前提：**客户已有返利账户余额，返利业务发生影响返利余额

**功能路径：**【电商与分销】－>【返利管理】－>【返利余额】－>【返利余额流水】

**返利流水明细字段说明：** 

|**字段**||**说          明**|
|客户||显示返利账户对应的客户。|
|核算组织||显示返利结算组织。|
|返利账户||显示返利明细发生对应的返利账户。|
|更新来源||显示发生返利账户余额更新的来源业务单据|
|单据编号||显示更新账户余额的业务单据编号|
|事务类型||显示更新账户余额的业务操作类型|
|币别||显示返利组织的结算币别，当前置为人民币。|

|结余账户余额||显示每一笔流水发生后的当前账户余额|
|操作人||显示发生每一笔流水的操作人员|
|更新日期||显示每一笔更新账户余额的流水发生时间|

**业务说明：**
  * 返利余额流水记录了每一笔更新返利余额的信息，方便及时查询和掌握客户返利账户的使用情况，对异常情况也能及时追溯。

## 【页面】返利管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E7%AE%A1%E7%90%86

======1 返利管理概述======

**返利管理概述**
  * 返利是销售政策中的重要内容，为激励经销商，企业制定返利奖励政策，通过返利来调动其积极性。根据一定的评判标准，以现金或实物的形式对经销商进行奖励，使企业通过对销售返利的处理降低销售收入，从而降低销售利润。
  * 返利管理模块支持经销商/大客户的年度、月度、季度返利管理，及自定义周期返利管理。并根据返利政策和销售数据，进行返利计算，形成客户的返利结算数据，客户返利结算支持冲账、返现、返物。

**返利管理系统特性**

  * 返利政策灵活设置：支持多种个性化返利模式的设定，灵活制定返利政策，满足各种返利场景的应用； 
  * 返利数据全面：支持按返利政策及返利周期进行销售数据准备，同时支持按实际情况做部分调整；同时对终端门店的销售数据进行手工录入，做为返利计算的依据；
  * 返利计算便捷：在返利数据准备完成后，直接通过返利计算平台完成返利计算。

## 【页面】返利管理使用流程
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E7%AE%A1%E7%90%86%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B

返利管理的应用流程如下：
  * 第一步：设置返利基础数据
进入【电商与分销】－>【返利管理】－>【基础资料】
  * 第二步：设置返利政策
进入【电商与分销】－>【返利管理】－>【返利政策】
  * 第三步：进行返利数据准备
进入【电商与分销】－>【返利管理】－>【返利数据准备】
  * 第四步：进行返利计算
进入【电商与分销】－>【返利管理】－>【返利计算平台】
根据返利计算结果，对符合返利条件的记录自动生成返利结算单
  * 第四步，进入返利计算平台进行返利结算
进入【电商与分销】－>【返利管理】－>【返利结算】

通过返利结算单的返还方式进行相应的返利结算处理，生成下游单据或是增加到客户的账户余额。

## 【页面】返利类型

**功能概述：**
在返利管理基础资料中进行返利类型的维护。

**使用前提：**

**功能路径：**【电商与分销】－>【返利管理】－>【基础资料】－>【返利类型】
**字段说明：**
系统已预置了一种返利类型：直接售后返利，是对经销商或客户的直接销售返利。用户也可以定义和维护其它返利类型。主要字段来源如下表：

**功能概述：**返利活动结束后，对返利进行结案分析，通过填写返利实际结果的数据，对返利效果进行评估和分析。

**使用前提：**返利申请已经审核。

**功能路径:**【电商与分销】－>【返利管理】－>【返利结算】－>【返利结算单】

**字段说明：** 返利结算单表头

|**字段**||**说          明**|
|单据编号||显示结算单的单据编号。|
|单据日期||显示结算单的业务日期，默认为返利计算生成时的系统日期。|
|币别||显示返利组织的结算币别，当前置为人民币。|
|结算组织||根据返利计算结果生成，显示返利结算的结算组织。|
|返利返还方式||根据返利计算结果生成，携带返利方式，包括：冲减应收款、其他应付款、赠品出库返还、返还到账户余额。 |
|业务员||F8选择，可手工选择销售员。|
|部门||F8选择，可手工选择销售员。|
|返利账户 ||在返利方式为返还到账户余额时，用于指定具体使用的返利账户，结算后返利金额将累计到客户在该返利账户下的返利余额中。|

返利结算单表体

|**字段**||**说          明**|
|返利对象类型||根据返利计算结果生成时，携带返利对象类型，目前为客户类型|
|返利对象||根据返利计算结果生成时，携带返利客户的名称|
|返利金额||根据返利计算结果生成时，显示返利客户的本次应返金额|
|返利政策||显示返利政策的主题信息|
|返利周期||根据返利计算结果生成时，携带本次返利计算的返利周期|
|开始时间||显示返利周期对应的开始时间|
|结束时间||显示返利周期对应的结束时间|
|费用项目编码||可手工设置本次返利费用对应的费用项目编码|
|费用项目名称||显示费用项目名称|
|赠品编码||返还方式为赠品返还时，显示赠品的物料编码|
|赠品名称||显示赠品的物料名称|
|规格型号||显示赠品的规格型号|
|计量单位||显示赠品的计量单位|
|赠送数量||根据返利计算结果，携带本次返利的赠品赠送数量|

**操作说明：**

结算：
  * 普通列表项目用户选中一张返利结算单后进行结算，则进入生成下游单据的选择页面，根据返利的返还方式选择生成不同的下游单，包括：其他应收单、其他应付单或其它出库单以及客户返利账户余额、返利流水明细。
业务说明：
  * 如返利结算单的返还方式为冲减应收，则生成红字的其他应收单，进入其他应收单的编辑页面；
  * 若返还方式为其他应付单，则为返现方式，生成其他应付单，进入其他应付单的编辑页面；
  * 若返还方式为赠品出库，则生成其他出库单，进入其他出库单编辑页面。
  * 若返利方式为返还到账户余额，则累加结算金额到客户的返利账户余额中。

## 【页面】返利计算之返利政策选择
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E8%AE%A1%E7%AE%97%E4%B9%8B%E8%BF%94%E5%88%A9%E6%94%BF%E7%AD%96%E9%80%89%E6%8B%A9

**功能概述：**返利政策制定后，根据返利政策及返利周期进行返利计算，计算出客户的应返利金额或是应返赠品数据

**使用前提：**返利数据准备完成，且数据已经核对无误，在返利周期下进行返利计算

**字段说明：**计算结果，按返利政策显示返利对象的返利金额或赠品信息，

**字段说明如下：**

|**字段**||**说          明**|
|返利组织||显示本次返利计算的返利结算组织|
|返利政策编码||按返利计算结果显示返利政策对应编码|
|返利政策主题||按返利计算结果显示返利政策主题|
|返利对象类型||返利对象为客户|
|返利对象||显示返利计算的客户名称|
|返利金额||按返利计算结果显示应返客户的返利金额|
|赠品编码||按返利计算结果显示应返客户的商品编码|
|赠品名称||根据商品编码显示商品名称|
|规格型号||根据商品编码显示商品规格型号|
|计量单位||根据商品编码显示商品计量单位|
|赠送数量||按返利计算结果显示应返客户的商品数量|

**操作说明：**
返利计算执行按以下分步式引导处理：
  * 第一步：返利政策选择
根据返利结算组织、返利周期选择本次执行的返利政策，可选择本次返利需要执行的返利政策
  * 第二步：返利销售数据准备
确定返利政策后，系统自动化调取符合条件下的返利准备数据进入下一步的返利计算
  * 第三步：返利计算
根据返利政策的返利条件，及返利的处理方式进返利计算。若返利方式为返利率方式：应返利金额＝实际销售金额×返利率；若返利方式为单位返利额：应返利金额＝实际销售数量×单位返利额；若返利方式为赠品：计算赠品数量=（实际销售数量/赠送基数）*赠送数量
根据返利政策定义的累计方式，计算返利金额时有两种处理情况下：全额累进方式及超额累进方式
  * 第四步：返利结果确定
返利计算完成后，点完成按钮则系统自动生成返利结算单，返利计算结束。返利完成生成结算单后销售准备数据中的对应行会打上已完成返利计算的标记，不允许重复计算。

## 【页面】销售数据准备
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%94%80%E5%94%AE%E6%95%B0%E6%8D%AE%E5%87%86%E5%A4%87

**功能概述：**返利政策制定后，按返利周期进行客户返利计算前，进行业务数据准备，按返利模式的返利依据从系统中统计销售出库单或应收单的数据。

**使用前提：**返利政策已经启用，按返利组织、返利政策、返利周期的起止日期统计客户的返利数据，统计购买数量、购买金额进行返利数据准备。

**字段说明：**返利数据准备字段

|**字段**||**说          明**|
|返利组织||按返利结算进行返利的销售数据准备|
|返利政策编码||正次返利数据准备的返利政策对应编码|
|返利政策主题||返利政策对应的返利政策主题|
|返利对象类型||根据返利模式显示返利对象类型本版暂只支持返利对象为客户|
|返利对象||显示客户名称|
|组号||根据返利政策显示政策明细的组号（每个组号只有一条，系统进行汇总）|
|物料分类||根据返利政策+返利期间携带物料分类名称|
|物料编码||根据返利政策+返利期间携带物料编码|
|物料名称||根据物料编码携带物料名称|
|规格型号||根据物料编码携带物料规格型号|
|计量单位||根据返利政策显示物料的计量单位|
|实际销售数量||按统计维度计算出的销售数量合计值（或应收数量），按同一组的物料或物料分类进行合计|
|实际销售金额||按统计维度计算出的价税合计金额合计值（或应收金额），按同一组的物料或物料分类进行合计|
|实际指标完成率||计算得出，若返利政策按指标数量返利，则=（实际数量/指标数量）*100%,取两位小数计算得出，若返利政策按指标金额返利，则=（实际数金额/指标金额）*100%,取两位小数|
|开始日期||根据返利政策+返利期间显示返利开始日期|
|结束日期||根据返利政策+返利期间显示返利结束日期|
|备注||显示备注信息|

返利数据统计生成—返利字段选择

|**字段**||**说          明**|
|返利组织||选择本次进行销售数据统计的返利结算组织|
|返利模式||选择本次进行销售数据统计的返利模式（按数量或按金额等）|
|返利周期||选择本次进行销售数据统计的返利周期|

**业务说明：**
  * 新增销售准备数据-启用了返利管理参数，在销售订单保存或提交后，可进行返利匹配操作，返利匹配的结果会在弹出的窗口中显示，
  * 根据客户、销售组织及业务日期匹配后，显示出符合条件的返利政策及其它所有的返利政策，确定匹配记录后，返利政策的折扣、赠品及返利价格会返回到订单上。
  * 统计生成销售准备数据-根据返利准备的统计条件，选择返利政策，从系统中根据销售出库单或是应收单生成相应的销售数据，包括实际销售数量、实际销售金额等。
