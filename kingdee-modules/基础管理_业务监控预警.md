## 【页面】业务监控
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E7%9B%91%E6%8E%A7

====== 1 业务监控预警概述 ======
===== 1.1 业务监控预警概述 =====
业务监控预警模块包括业务监控和风险预警，风险预警是V8.0新功能。业务监控是事后的提醒，根据企业自身的监控需求，事后提醒及时处理业务，保证业务的正常运作；而风险预警则是事前和事中的提醒，根据企业风险监测提前告知风险并防范。。

===== 1.2 业务监控特性 =====
业务监控提供了以下功能：
  - 简单配置与插件开发结合，可以满足不同复杂度的业务监控需求； 
  - 多维度的接收人，实现监控人群的组合 ；
  - 支持接收人按权限发送监控消息； 
  - 监控消息的合并主题支持按分组变量和汇总变量，支持四则运算； 
  - 监控消息支持发送邮件和 [[第三方消息]]；
  - 监控明细消息支持跟进方案配置动态显示信息，且明细消息列表支持列表快速过滤、批量处理；
  - 监控消息支持通过方案配置确定是否显示处理；
  - Html5端支持监控卡片和监控工作台的显示；
  - 支持业务监控轻应用接收监控消息；
  - 通过监控方案执行情况可以追溯异常问题； 
  - 监控预警消息支持定期自动清理；
  - 及时发现企业运营中的异常情况，高效解决问题。
===== 1.3 风险预警特性 =====
风险预警提供了以下功能：
  - 预警消息模板配置，消息内容支持PC端和移动端分别设置，满足不同的风险预警需求； 
  - 支持设置业务对象预警规则，规则支持配置触发操作，且支持多个操作；
  - 预警规则支持设置预警条件，为业务对象标准过滤条件； 
  - 支持设置预警方案，启用则有效； 
  - 预警方案支持设置多个预警规则；
  - 每个预警规则可分别设置触发时机、消息模板、消息通道、消息级别、消息接收人；
  - 业务设置了风险预警，则会按照触发操作触发预警规则校验并提醒；
  - 风险预警提醒消息会实时发送；
  - 消息支持发送到移动端的消息轻应用； 

====== 2 业务监控预警操作手册 ======
===== 2.1 业务监控操作手册 =====
===== 2.1.1 监控对象===== 
金蝶云预置了部分监控对象，可以直接配置对应的监控方案使用，也可以根据企业实际情况自定义监控对象。具体见【[[监控对象|监控对象]]】的介绍。

===== 2.1.2 监控方案 =====
通过设置监控方案，可以对业务进行全方位的监控，及时通知关键人员。具体见【[[监控方案|监控方案]]】的介绍。

===== 2.1.3 监控执行情况列表 ===== 
监控执行情况可以查看监控消息发送的情况，以便分析业务监控的执行效率。具体见【[[监控执行情况|监控执行情况]]】的介绍。

===== 2.1.4 业务监控异常提醒 ===== 
有异常的业务监控方案进行提醒展示。具体见【[[业务监控异常提醒|业务监控异常提醒]]】的介绍。

===== 2.1.5 业务监控轻应用 ===== 
通过监控方案的轻应用设置，提供业务监控轻应用的发布，实现业务监控轻应用接收监控消息，同时可以进行业务催收。具体见【[[业务监控轻应用|业务监控轻应用]]】的介绍。

===== 2.2 风险预警操作手册 =====
===== 2.2.1 预警消息模板===== 
风险预警消息提醒内容为消息模板配置内容，具体见【[[预警消息模板|预警消息模板]]】的介绍。

===== 2.2.2 预警规则 =====
预警规则支持业务对象操作触发校验条件，满足预警规则条件即会触发风险预警，具体见【[[预警规则|预警规则]]】的介绍。

===== 2.2.3 预警方案 ===== 
预警方案是基于业务对象的风险预警，方案启用则会按照规则设置触发风险预警，并消息提醒用户，具体见【[[预警方案|预警方案]]】的介绍。

===== 2.2.4 预警方案最新执行情况列表 ===== 
只展示最新的预警方案执行情况，包括预警方案的基本信息、方案是否执行成功和执行描述等。具体见【[[预警方案最新执行情况列表|预警方案最新执行情况列表]]】的介绍。

## 【页面】业务监控轻应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E7%9B%91%E6%8E%A7%E8%BD%BB%E5%BA%94%E7%94%A8

====== 1 业务监控轻应用概述 ======
===== 1.1 概述 =====
业务监控轻应用可以实现多个监控方案的消息统一展示，同时支持消息的分类汇总，方便用户统揽业务的异常情况。另外还支持通过监控消息转发云之家待办消息，实现业务跟催。

===== 1.2 业务特性 =====
业务监控轻应用提供了以下特色功能：
  - 主页的九宫格可以展示用户的全部监控方案及其监控消息；
  - 用户可以对监控方案进行取消订阅，不接收监控消息；
  - 监控方案的汇总消息支持分类统计；
  - 监控方案的明细消息支持字段选择，并支持分类统计以及汇总；
  - 支持选择明细监控消息发送云之家待办消息，实现业务跟催。
 

====== 2 业务监控轻应用操作手册 ======
===== 2.1 轻应用设置 =====
产品路径：监控方案—>轻应用设置

==== 2.1.1 汇总消息设置 ====

**消息标题**
  - 消息标题是监控方案在轻应用展示的名称，启用轻应用是必填的；
  - 支持手工输入，控制最多录入9个字段。

**汇总字段**
  - 汇总字段是监控方案明细消息的统计依据，可以按其进行分类统计；
  - 汇总字段最多选择3个，通过点击“…”调出字段列表进行选择；

**汇总消息**
  - 汇总消息针对汇总字段的统计结果进行展示；
  - 支持编辑，添加文本内容；通过“{”添加汇总字段变量；
  - 汇总消息最多三行；
  - 对于汇总结果较长的内容（例如：金额），建议作为第一行；

**预览**
  - 点击“预览”，预览区域根据汇总消息的行数显示不同的布局；

==== 2.1.2 明细消息设置 ====

**选择字段**
  - 选择需要在明细消息中展示的字段；
  - 控制最多选择5个，以保证手机上的展示效果；

**字段列表**
  - 根据选择字段回填内容；
  - 通过“显示位置”调整在明细消息中的位置；控制每行只展示两个字段内容；
  - 配置好后，预览界面可以看到效果； 

**分类汇总**
  - 可以对明细消息进行分类汇总，以便更好的查看明细消息；
  - 一般是选择客户/供应商、部门、组织等之类的字段。

**统计字段**
  - 就是对分类汇总的字段进行统计；
  - 一般是选择数量、金额字段；
  - 对于监控对象是单据行时，一般是选择明细行的数量、金额字段。

===== 2.2 业务监控轻应用 ===== 

==== 2.2.1 轻应用部署 ====

云之家按照轻应用方式部署则可以直接使用【业务监控轻应用】。云之家按照公共号方式部署则还需要在云之家公共号列表中添加业务监控的公共号账号以及公共号密钥才能使用【业务监控公共号】

轻应用方式部署，参考：http://club.kingdee.com/forum.php?mod=viewthread&tid=1314623&page=1&extra=#pid3709605

==== 2.2.2 业务监控轻应用 ====
登录云之家团队后，点击业务监控轻应用，即可：
  - 通过轻应用主页的九宫格直接查看每个监控方案的汇总消息；
  - 监控方案有“new”图标的，说明该监控方案有新的监控消息；
  - 通过“设置”，用户可以自行决定监控方案的展示；
  - 点击监控方案，则可以查看明细消息；

==== 2.2.3 业务跟催 ====
  - 点击“批量跟催”，可以选择具体的监控消息，发送云之家待办消息给指定的团队人员。

## 【页面】监控对象
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%9B%91%E6%8E%A7%E5%AF%B9%E8%B1%A1

====== 1 功能描述 ====== 
在预置的监控对象不能满足企业的业务监控范围时，可以自定义监控对象，支持从业务监控的监控对象直接新增，也支持通过BOS开发平台新增，开发和配置插件实现个性化的业务监控需求。（建议通过前台创建，易用性好）

**使用前提**
  - 下载【BOS设计器】并安装；
  - 如果需要添加自定义业务对象，并使其成为监控对象，需要购买BOS运行平台的站点。

**功能路径**
  - 【基础管理】→【业务监控】→【监控对象】
  - 【登录BOS集成开发平台】→【业务领域】→【子系统】→【监控对象】

 ====== 2 字段说明 ======
监控对象内容：
  - 数据来源: 就是监控对象是来源哪些业务对象；可以选择现有的业务对象，也可以选择自定义的业务对象；
  - 监控方案解析插件: 自行开发的监控方案插件，支持选择；
  - 监控消息解析插件: 对于监控消息的展示以及后续的业务操作都可以在此处通过插件解决；支持选择；
  - 监控条件窗体: 就是监控方案中监控条件的配置内容；默认携带业务对象的单据头字段；如果需要更多内容，需要通过插件解决；支持选择；
  - 监控方案编辑插件：就是插件的编写入口。

 ====== 3 功能操作 ======
=====3.1 新增=====
  - 在BOS集成开发平台找到监控对象节点
  - 点击工具栏的【新增】；
  - 如若选择现有的业务对象进行监控，在新建类型窗口选择“新增-空白对象”节点，在模板窗口选择“监控对象”；
  - 系统自动产生监控对象的窗口，在数据来源选择现有的业务对象；
  - 如没有插件内容，直接保存即可；如有插件，则选择所需插件；
  - 监控对象创建后，登录数据中心的监控方案，在监控对象选择新创建的监控对象，系统自动携带监控对象的过滤条件内容，进行其他配置即可完成监控方案的设置。

 ====== 4 业务说明 ======
  - 业务监控的使用不依赖BOS运行时许可，需要购买了业务监控平台的特性（无站点控制）
  - 使用BOS集成设计平台进行业务监控对象的自定义以及插件开发，无需购买BOS运行时的站点。

## 【页面】监控执行情况
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%9B%91%E6%8E%A7%E6%89%A7%E8%A1%8C%E6%83%85%E5%86%B5

====== 1 功能描述 ====== 
启用的业务监控方案手工执行或者后台按照执行周期定时执行后，会生成监控执行记录。
监控执行情况列表以监控方案为对象，可查看其监控执行情况和执行历史，同时提供归档处理等。

**使用前提**
  - 监控方案已经启用；
  - 管理中心的当前数据中心属性中，选项【允许执行计划任务】必须勾选，同时还需要在数据中心的执行计划列表中把【业务预警服务提供者】设置为准备状态，这两处影响监控方案的定时执行。

**功能路径**
监控执行情况列表：【基础管理】→【业务监控】→【监控执行情况】
监控执行情况历史记录列表：【基础管理】→【业务监控】→【监控执行情况】→【监控执行情况列表】→【历史查询】按钮

 ====== 2 字段说明 ======
  - 监控名称:以监控方案为对象显示监控执行情况；
  - 开始时间:监控方案开始执行的时间；
  - 耗时:显示监控方案执行所需的时长；
  - 执行方式:手动（监控方案列表点击【手工执行】）、自动（系统按照监控方案的执行周期定时执行）；
  - 执行状态：显示执行监控方案的情况，包括：成功、失败、超时、缺少设置、缺少接收人、监控数超上限等；
  - 备注：显示监控方案执行不成功的原因。

 ====== 3 功能操作 ======
=====3.1 选项=====
  - 提供归档规则：监控执行情况记录超过（30条）时，将自动全部归档到历史记录中。
  - 条数允许手工调整；
  - 通过归档规则的设置，可以减少当前显示的执行情况记录，提升查询效率；
  - 设置好后，系统自动根据设置数量自行执行归档操作。

=====3.2 历史查询 =====
  - 点击后调出历史记录列表；
  - 可以查询已经归档的监控执行记录。

=====3.3 删除 =====
  - 监控执行情况列表以及历史记录列表的记录均可删除；
  - 在系统运营过程，如果觉得金蝶云数据库膨胀厉害，且执行情况记录的重要性已经降低，可以删除不需要的记录，以降低数据库的大小。

 ====== 4 业务说明 ======
  - 监控消息未正常发送，请按下列步骤进行检查和解决：
  - 在执行情况列表中有执行记录，查看监控方案是否执行成功，如果不是，根据备注中提示信息查找原因和解决问题。 
  - 在执行情况列表中没有执行记录，请检查应用服务器K3CloudJobProcess服务是否正常启用。

## 【页面】预警方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E8%AD%A6%E6%96%B9%E6%A1%88

====== 1 功能描述 ====== 
预警方案是基于业务对象的风险预警，预警方案支持多个预警规则，触发风险预警时及时消息提醒用户，及时预防风险。

**功能路径**
  - 【基础管理】-【业务监控预警】-【预警方案】；

 ====== 2 关键字段说明 ======
  - 业务对象: 支持选择系统所有业务对象；
  - 预警规则: 预警规则必须是业务对象对应的已审核预警规则，支持选择多个预警规则；
  - 触发时机: 触发时机可以是操作成功前也可以操作成功后；
  - 预警级别：预警级别有紧急、警告、提醒；
  - 消息通道：消息从哪里发送给用户；
  - 消息模板：该业务对象对应预警消息类模板；
  - 消息接收人：消息要发送给哪些用户，接收人支持变量用户；

 ====== 3 主要功能操作 ======
  - 新增：选择业务对象和预警规则，并且设置触发时机、预警级别、消息通道、消息模板、消息接收人；
  - 删除：已审核状态的方案不允许删除；
  - 禁用/反禁用：方案禁用即为无效方案；
  - 触发风险提醒：业务对象操作会根据设置规则校验并触发风险提醒，发送消息给接受人；

 ====== 4 其他说明 ======
  - 风险预警为业务监控平台功能，只要购买了业务监控平台即可应用风险预警功能；
  - 风险预警为系统新功能，后续会支持指标、检查项等风险校验；

## 【页面】预警方案最新执行情况
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E8%AD%A6%E6%96%B9%E6%A1%88%E6%9C%80%E6%96%B0%E6%89%A7%E8%A1%8C%E6%83%85%E5%86%B5

====== 1 业务监控预警概述 ======
===== 1.1 业务监控预警概述 =====
业务监控预警模块包括业务监控和风险预警，风险预警是V8.0新功能。业务监控是事后的提醒，根据企业自身的监控需求，事后提醒及时处理业务，保证业务的正常运作；而风险预警则是事前和事中的提醒，根据企业风险监测提前告知风险并防范。。

===== 1.2 业务监控特性 =====
业务监控提供了以下功能：
  - 简单配置与插件开发结合，可以满足不同复杂度的业务监控需求； 
  - 多维度的接收人，实现监控人群的组合 ；
  - 支持接收人按权限发送监控消息； 
  - 监控消息的合并主题支持按分组变量和汇总变量，支持四则运算； 
  - 监控消息支持发送邮件和短信；
  - 监控明细消息支持跟进方案配置动态显示信息，且明细消息列表支持列表快速过滤、批量处理；
  - 监控消息支持通过方案配置确定是否显示处理；
  - Html5端支持监控卡片和监控工作台的显示；
  - 支持业务监控轻应用接收监控消息；
  - 通过监控方案执行情况可以追溯异常问题； 
  - 监控预警消息支持定期自动清理；
  - 及时发现企业运营中的异常情况，高效解决问题。
===== 1.3 风险预警特性 =====
风险预警提供了以下功能：
  - 预警消息模板配置，消息内容支持PC端和移动端分别设置，满足不同的风险预警需求； 
  - 支持设置业务对象预警规则，规则支持配置触发操作，且支持多个操作；
  - 预警规则支持设置预警条件，为业务对象标准过滤条件； 
  - 支持设置预警方案，启用则有效； 
  - 预警方案支持设置多个预警规则；
  - 每个预警规则可分别设置触发时机、消息模板、消息通道、消息级别、消息接收人；
  - 业务设置了风险预警，则会按照触发操作触发预警规则校验并提醒；
  - 风险预警提醒消息会实时发送；
  - 消息支持发送到移动端的消息轻应用； 

====== 2 业务监控预警操作手册 ======
===== 2.1 业务监控操作手册 =====
===== 2.1.1 监控对象===== 
金蝶云预置了部分监控对象，可以直接配置对应的监控方案使用，也可以根据企业实际情况自定义监控对象。具体见【[[监控对象|监控对象]]】的介绍。

===== 2.1.2 监控方案 =====
通过设置监控方案，可以对业务进行全方位的监控，及时通知关键人员。具体见【[[监控方案|监控方案]]】的介绍。

===== 2.1.3 监控执行情况列表 ===== 
监控执行情况可以查看监控消息发送的情况，以便分析业务监控的执行效率。具体见【[[监控执行情况|监控执行情况]]】的介绍。

===== 2.1.4 业务监控异常提醒 ===== 
有异常的业务监控方案进行提醒展示。具体见【[[业务监控异常提醒]]】的介绍。

===== 2.1.5 预警方案最新执行情况列表 ===== 
只展示最新的预警方案执行情况，包括预警方案的基本信息、方案是否执行成功和执行描述等。具体见【[[预警方案最新执行情况列表]]】的介绍。

===== 2.4 业务监控轻应用 ===== 
通过监控方案的轻应用设置，提供业务监控轻应用的发布，实现业务监控轻应用接收监控消息，同时可以进行业务催收。具体见【[[业务监控轻应用|业务监控轻应用]]】的介绍。

===== 2.2 风险预警操作手册 =====
===== 2.2.1 预警消息模板===== 
风险预警消息提醒内容为消息模板配置内容，具体见【[[预警消息模板|预警消息模板]]】的介绍。

===== 2.2.2 预警规则 =====
预警规则支持业务对象操作触发校验条件，满足预警规则条件即会触发风险预警，具体见【[[预警规则|预警规则]]】的介绍。

===== 2.2.3 预警方案 ===== 
预警方案是基于业务对象的风险预警，方案启用则会按照规则设置触发风险预警，并消息提醒用户，具体见【[[预警方案|预警方案]]】的介绍。

## 【页面】预警消息模板
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E8%AD%A6%E6%B6%88%E6%81%AF%E6%A8%A1%E6%9D%BF

====== 1 功能描述 ====== 
预警方案的预警规则提醒消息会根据消息模板设置发送消息内容，所以要先建立预警对象对应的预警消息模板。消息模板是消息平台功能，可到消息平台的消息模板下去创建预警消息类型模板。

**功能路径**
  - 【基础管理】-【消息平台】-【消息模板】；

 ====== 2 关键字段说明 ======
  - 模板类型: 模板类型选择预警消息，只有预警消息模板才能应用到风险预警方案；
  - 业务对象: 支持选择系统所有业务对象；
  - 元数据: 业务对象的元数据字段；
  - 消息样式: 消息提醒的样式，目前只支持纯文本；
  - 标题：消息标题，可选择元数据变量；
  - 内容：消息的详细内容，可选择元数据变量；

 ====== 3 主要功能操作 ======
  - 新增：选择模板类型和业务对象，设置消息通道的消息内容，消息内容目前只支持纯文本，消息内容支持选择元数据变量；    
    - 模板类型：业务消息、预警消息、运营消息、公告消息；
    - 消息通道：PC端消息通知、移动端消息轻应用；
    - 消息样式：纯文本，后续会支持其他样式比如图片等；
    - 消息内容：消息数据可设置元数据变量，运营消息和公告消息支持设置链接地址；    
  - 删除：删除时校验是否有被引用，如被引用不允许删除；
  - 禁用/反禁用：禁用时校验是否被引用，如被引用不允许禁用；

 ====== 4 其他说明 ======
  - 消息平台为基础平台功能，无需购买即可应用；

## 【页面】预警规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A2%84%E8%AD%A6%E8%A7%84%E5%88%99

====== 1 功能描述 ====== 
预警规则是针对风险设置预警条件，预警规则支持业务对象的操作触发规则校验。

**功能路径**
  - 【基础管理】-【业务监控预警】-【预警规则】；

 ====== 2 关键字段说明 ======
  - 业务对象: 支持选择系统所有业务对象；
  - 触发操作: 业务对象操作，支持配置多个操作都触发校验；
  - 预警条件: 所选业务对象的元数据条件；

 ====== 3 主要功能操作 ======
  - 新增：选择业务对象和触发操作，并设置预警条件，保存审核即可；    
  - 删除：删除时校验是否有被引用，如被引用不允许删除；
  - 禁用/反禁用：禁用时校验是否被引用，如被引用不允许禁用；
