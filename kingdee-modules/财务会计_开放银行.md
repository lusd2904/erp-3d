====== 开放银行 ======
=====1 开放银行系统概述 =====

====1.1 开放银行系统概述 ====
开放银行，借助应用程序编程接口（API）、符合信息通信安全的加密算法等，在保障安全和隐私前提下,推动数据有序共享与综合应用。提供一种低成本、易开通、易上线、免银行前置机的模式，实现银行数据与星空业务流程打通。

能够快捷的获得银行交易明细和实时余额等数据，实现通过及时准确、智能的生成业务单据等。

====1.2 系统特性 ====
本系统主要包含以下应用：
  * 易开通，易上线。用户可以直接在星空申请签约，线上与各银行协议开通
  * 支持查询银行账户的交易流水明细
  * 支持查询银行账户实时余额
  * 支持下载银行存款对账单
  * 支持付款单审核时通过实时余额进行余额判断
  * 支持下载银行交易明细，通过智能登账方案、手工确认等多种方式生成业务单据
  * 支持通过执行计划自动的进行流程下载、生成单据、下载对账单等

  
=====2 开放银行系统操作手册 =====
====2.1 使用流程 ====

在日常业务处理过程中，用户随时可以通过开放银行相关接口，进行银行账户余额以及交易明细的查询。

下面对开放银行系统整体的使用流程进行详细说明：

第一步，系统设置

在系统开始正式应用前，需要先进行以下设置，保证日常业务正常执行。

进行开放银行设置：

进入【财务会计】—>【开放银行】—>【系统设置】—>【开放银行设置】

进行系统参数设置：

进入【财务会计】—>【开放银行】—>【系统设置】—>【开放银行参数设置】

第二步，日常处理

进入【财务会计】—>【开放银行】—>【日常处理】—>【接收银行交易明细】，获取银行交易明细，并生成业务单据。

进入【财务会计】—>【开放银行】—>【日常处理】—>【电子对账单】，显示所有从银行系统下载的电子对账单记录。

## 【页面】开放银行设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BC%80%E6%94%BE%E9%93%B6%E8%A1%8C%E8%AE%BE%E7%BD%AE

=====开放银行设置=====
=====1 功能说明=====    
希望使用开放银行模式获取银行账户余额、交易明细功能的用户，通过此功能申请与金蝶信科、银行进行开放银行多方授权签约。支持申请签约和查询签约状态。

=====2 功能路径====

【财务会计】—>【开放银行】—>【系统设置】—>【开放银行设置】


=====3 字段说明====
列表字段无需手工维护，都是在进行申请签约、同步签约状态后系统自动处理。
| **字段**         || **说明**                                                       |
| 银行账号       || 显示银行账号。进行申请签约后有值                     |
| 账户名称        || 显示银行账户名称。进行申请签约后有值                                      |
| 支持网银         ||是否支持网上银行。进行同步签约状态时更新，当存在功能开通状态为已开通时，更新为是。                                             |
| 网银类型        || 分为开放银行、银企互联。                                            |
| 签约银行       || 显示签约的银行。进行申请签约后有值                                                |
| 余额查询开通状态         || 和银行的余额查询功能开通状态。进行同步签约状态时更新，接口获取开通状态                                              |
| 交易明细查询开通状态       || 和银行的交易明细查询功能开通状态。进行同步签约状态时更新，接口获取开通状态                                                 |


=====4 业务操作=====

====4.1 申请签约 ====

申请与金蝶信科、银行进行开放银行多方授权签约。点击申请签约，选择要签约的银行账号，选择要签约的银行，点击立即申请。

说明：签约银行列表初始为空，点击同步签约银行信息，可获取截止当前已接通的银行。

====4.2 同步签约状态====

申请签约后，根据金蝶信科、银行相关提示完成操作后。进行同步签约状态。

同步签约状态为已开通后，系统自动勾选支持网银。就可以在本模块的日常处理、网银查询进行对应银行账户的业务操作和查询了。

## 【页面】接收银行交易明细
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8E%A5%E6%94%B6%E9%93%B6%E8%A1%8C%E4%BA%A4%E6%98%93%E6%98%8E%E7%BB%86

=====1 功能说明 =====
  * 企业可以通过银企下载网银所有交易明细（包括银行代扣付款记录和银企平台发起的付款记录）。
  * 支持同步非网银账号银行对账单生成交易明细。
  * 支持自动匹配不同业务类型生成对应业务单据。

=====2 过滤条件 =====

在“快捷”页签，用户设置需要查询的账号、币别以及日期范围，选择需要查询的交易明细，即可进行已下载的交易明细的查询。

快捷页签主要过滤项目说明 

| **过滤项**     || **说明**                        |
| 币别          || 交易明细对应的币别。                    |
| 开始日期        || 日期范围的起始日期。                    |
| 结束日期        || 日期范围的结束日期。                    |
| 交易类型        || 可以只查询收入明细或者支出明细，也可以查询全部交易明细。  |


=====3 下载交易明细 =====

如果需要下载新增的交易明细，可以点击下载交易明细按钮，选择需要下载的账号、币别等信息进行下载，已经下载的交易明细不会重复下载。

=====4 同步银行存款对账单 =====

系统支持同步银行存款对账单生成交易明细。


=====5 自动匹配 =====

点击自动匹配会弹出自动匹配选择窗口，根据选择的对方单位类型和对方单位匹配规则去自动匹配对方单位类型、对方单位和业务类型。

=====6 手工确认 =====

|**字段**||**说明**|
|收付组织||交易明细对应的收付款组织。|
|结算组织||交易明细对应的结算组织。|
|业务类型||自定义收付款业务类型。|
|往来单位类型||交易明细对应的往来单位类型。|
|往来单位||交易明细对应的往来单位。|
|结算方式||交易明细的结算方式。|
|收付款用途||自定义收付款用途。|

=====7 生成单据 =====

确认了交易明细的业务组织，往来单位、收付款用途等信息时，点击“生成单据”按钮，会生成业务单据，并反写单据编号到交易明细中。

=====8 银企付款 =====

如果是用业务单据提交银企付款或者是不想用该付款类的交易明细生成业务单据，可以选中交易明细，点击“银企付款”，即可对交易明细进行标记，不允许下推业务单据。

=====9 关联查询 =====

支持通过交易明细联查业务单据。

## 【页面】认证账号
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%AE%A4%E8%AF%81%E8%B4%A6%E5%8F%B7

=====认证账号=====
=====1 功能说明=====    
星空与金蝶信科集成，平台认证账号的信息。依赖此基础资料的功能主要有：聚合收款（需用户手工新增）、开放银行（系统自动生成）

=====2 功能路径====

【财务会计】—>【开放银行】—>【基础资料】—>【认证账号】

【财务会计】—>【出纳管理】—>【聚合收款首页】—>【商户号】

=====3 字段说明====
聚合收款使用平台认证账号，需要先申请商户号，然后根据金蝶信科提供的值，手工录入进行填写。

开放银行使用平台认证账号，在进行申请签约后，星空系统自动生成认证信息，并填写相关字段值。

| **字段**         || **说明**                                                       |
| 账号类型          || 枚举，可选金蝶信科-聚合收款、金蝶信科-开放银行               |
| 账号        || 认证账号，由金蝶信科提供                                       |
| 名称         || 认证账户名称，由金蝶信科提供                                          |
| 授权密码         || 授权密码，由金蝶信科提供                                               |
| 描述       || 文本，自定义录入                                            |
| 金蝶AI星空公钥   || 金蝶AI星空公钥 ， 聚合收款类型点击生成秘钥；开放银行系统自动生成                                       |
| 金蝶信科公钥    || 金蝶信科公钥，由金蝶信科提供         |
