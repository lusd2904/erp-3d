## 【页面】上报报表进度看板

===== 上报报表进度看板 =====

**功能说明** 

HTML5模式下，提供合并范围内上报报表进度指标看板，通过此看板，您将清晰掌握所有合并范围往期或当期的报表上报情况

**操作说明**

进入【合并报表】→【上报报表进度看板】，通过【切换】选择合并方案、合并期间

**上班报进度看板内容说明**

^ 内容       ^ 字段     ^ 说明                                                                                 ^
| 未报监控     | 未上报    | 所选期间合并范围，所有组织的分发类报表模板，未编制和编制中的报表数                                                  |
| :::      | 未编制    | 所选期间+合并范围，所有组织的分发类报表模板，未创建的报表数                                                     |
| :::      | 编制中    | 所选期间+合并范围，所有组织的分发类报表模板，已创建未上报的报表数                                                  |
| 效率监控     | 总报表数   | 所选期间+合并范围，所有组织分发的报表模板总数                                                            |
| :::      | 打回次数   | 所选期间+合并范围，所有组织的报表撤消上报和打回的总次数                                                       |
| :::      | 打回报表数  | 所选期间+合并范围，所有组织的报表撤消上报和打回的报表数                                                       |
| 明细列表     | 未上报    | 所选期间+合并范围，所有组织的分发类报表模板，未编制和编制中的报表明细                                                |
| :::      | 未编制    | 所选期间+合并范围，所有组织的分发类报表模板，未创建的报表明细                                                    |
| :::      | 待接收    | 所选期间+合并范围，所有组织的分发类报表模板，已上报未接收的报表明细                                                 |
| 未编制报表排名  | -      | 展示所选期间各组织未编制的报表数                                                                   |
| 上报及时率    | 趋势     | 展示所选期间及往前5个期间的各期间的上报及时率\\ 上报及时率=按时上报的报表/总报表数\\ 按时上报：上报时间不晚于看板【上报报表进度看板设置】设置的上报截止日  |
| :::      | 组织     | 展示所选期间各组织上报及时率                                                                     |
| 打回次数     | 趋势     | 展示所选期间及往前5个期间的各期间的打回次数                                                             |
| :::      | 组织     | 展示所选期间各组织的打回次数                                                                     |

===== 上报报表进度看板设置 =====

**功能说明** 

通过【上报报表进度看板设置】，定义上报报表进度看板统计和展示的数据范围，及定义报表上报的截止时间

**操作说明**

进入【合并报表】→【上报报表进度看板】→【设置】

**上报报进度看板设置说明**

^ 字段          ^ 说明                                                                                                   ^
| 上报截止日       | 用于计算报表上报是否逾期，单选\\ 下期开始：下一期间从第一天顺数的第几天截止\\ 本期结束前：当前期间从最后一天倒数的第几天截止                                    |
| 监控合并范围层级    | 用于看板数据统计的合并范围，单选\\ 当前合并范围：选择此项，看板统计和展示所选合并范围（不含子级范围）的数据\\ 当前合并范围及其所有下级：选择此项，看板只统计和展示所选合并范围及其下级范围的数据  |
| 监控报表类型范围    | 多选，看板统计和展示报表类型的数据范围                                                                                  |
| 无需要编制的报表模板  | 此处添加的报表模板，不会纳入看板统计和展示的数据中                                                                            |

===== 个别报表催报 =====

**功能说明** 

在未编制、编制中报表列表，提供发送消息提醒、邮件提醒通知【催报设置】所设的催报对象上报报表

**操作说明** 

在【上报报表进度看板】，选择合并方案，在未编制、编制中的报表列表，勾选需要催报的报表，执行【消息提醒】或【邮件提醒】给催报对象发送消息，发件人为当前操作的用户

执行【消息提醒】，则系统会发送星空平台消息，被催报人可在【信息中心】-【普通消息】查看

执行【邮件提醒】，则系统会发送邮件至【催报设置】催报人的邮葙地址

【消息提醒】【邮件提醒】的发件人都为当前执行此操作的用户

## 【页面】个别报表上报
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E5%88%AB%E6%8A%A5%E8%A1%A8%E4%B8%8A%E6%8A%A5

**功能说明**

子公司在完成个别报表（抵消报表）的编制、审核之后，需及时通过“上报”功能，将报表上报到上级总公司。

**操作前提**

上报前提：报表已审核。

撤销上报前提：报表已上报未接收。

**操作说明**

1. 在编辑器中，使用【审阅】-【上报】/【撤销上报】；

2. 批量上报：

1) 在【财务会计】-【报表系统】-【报表】列表，选中一个或者多个报表，使用【上报】；

2) 在【财务会计】-【合并报表系统】-【合并控制】-【个别报表】，选中一个或者多个报表，使用【上报】；

3）目前实现了一张固定报表可以上报给多个合并方案，以解决同一集团需要制作多套合并方案的需求，因此在报表列表上将同一个报表模板同一期间同一组织个别报表集中显示，可直观了解此张固定报表上报了哪些个合并方案。


**其他说明**

报表检查功能，受【合并报表参数设置】中选项【上报报表前必须检查】影响。

当个别报表中有使用REF()函数时，至少需要重算两次，因此上报时，系统会提醒，包含了REF()的报表是否已经重算过。（也可以在【公式取数参数】修改重算顺序，将有REF()函数的表页放在后面计算，这样只需要重算一次）

在【合并报表参数设置】中勾选【报前调整保存调整前报表】。则上报前的报表做了报前调整（即在报表编辑中编制了调整分录）之后，系统会产生一个调整前的报表，【调整备份】字段为【是】，并显示【关联报表编码】。调整备份报表不可编辑及删除，只能查看，用于子公司自己使用，不影响合并报表数据；如需对合并报表数据产生影响，则需调整关联报表。

## 【页面】个别报表接收
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E5%88%AB%E6%8A%A5%E8%A1%A8%E6%8E%A5%E6%94%B6

===== 个别报表上报 =====

**功能说明**

合并范围接收子公司上报的个别报表，接收的个别报表数据会应用于后续报表合并或汇总。

**操作前提**

个别报表的上报状态为：上报。

**操作说明**

 在【财务会计】-【合并报表】-【合并控制】-【报表接收】，选中列表一个或者多个报表，点击【接收】；

===== 个别报表反接收 =====

**功能说明**

合并范围退回已接收的子公司个别报表，个别报表返回在制的上报状态

**操作前提**

个别报表的上报状态为：接收。

**操作说明**

1）反接受当前合并方案已接收个别报表 在【财务会计】-【合并报表】-【合并控制】-【个别报表】，选中列表一个或者多个报表，点击【反接收】。
 
2）针对一表多报，反接收所有方案的个别报表，：在【财务会计】-【合并报表】-【合并控制】-【个别报表】，选中列表一个或者多个报表，点击【反接收所有方案】。

## 【页面】个别报表模板修改
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E5%88%AB%E6%8A%A5%E8%A1%A8%E6%A8%A1%E6%9D%BF%E4%BF%AE%E6%94%B9

**功能说明**

在【财务会计】－>【报表】－>【报表模板】中，对“允许修改”个别报表模板/抵消报表模板，根据实际需要，进行模板的修改。

注意：在合并报表系统，未针对具体的编制组织，提供修改模板功能。

**操作前提**

合并报表系统成功下发的个别报表模板/抵消报表模板，对当前组织置为“允许修改”。

**操作说明**

反审核报表模板，打开“重新审核”状态的报表模板，进行修改。

修改完毕后，重新【提交】-【审核】，当前模板方可编制相应报表。

**其他说明**

修改抵消报表模板/动态样式的个别报表模板，可通过编辑模板，在报表编辑器中，进行【维度值填充】操作。

在模板中即完成维度值填充，一般适用于动态罗列项目在一段时期内相对稳定的动态样式报表（包含抵消报表）。

## 【页面】个别报表编制
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E5%88%AB%E6%8A%A5%E8%A1%A8%E7%BC%96%E5%88%B6

**功能说明**

系统有三个编制个别报表/抵消报表入口：

入口一：【财务会计】－>【报表】－>【报表模板】，选择从合并报表系统分发的报表模板，使用工具栏中【新增】-【新增报表】。

入口二：【财务会计】－>【报表】－>【报表】，使用工具栏中【新增】。

入口三：【财务会计】－>【合并报表】－>【合并控制】－>【个别报表】，使用工具栏中【新增】。

**操作前提**

报表模板已审核。 

**操作说明**

1、编制固定样式报表：

新建报表，确定报表相关属性（年期、周期、币别、金额单位）。

打开已创建的报表，在报表编辑器中，使用并设置【公式取数参数】。

通过F9/【数据】菜单-【重算】，重算并保存报表。

提交并审核报表。

2、编制动态样式报表：

新建报表，确定报表相关属性（年期、周期、币别、金额单位）。

打开已创建的报表，如未在报表模板中填充维度值，则需要使用【开始】-【维度值填充】，完成维度值的相关设置；系统根据所选维度值，批量填充到单元格。

通过F9/【数据】菜单-【重算】，重算报表。

提交并审核报表。

## 【页面】交易抵消
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%A4%E6%98%93%E6%8A%B5%E6%B6%88

内部交易事项主要表现为集团内母公司与子公司、子公司相互之间的购销活动。

**操作说明：**

第一步：基础设置（集团行为）

打开【财务会计】－>【合并报表】－>【基础资料】－>【抵消类型】，系统已预设了往来类抵消类型，只需设置与往来类抵消相关联的报表项目。

打开【财务会计】－>【合并报表】－>【基础资料】－>【交易种类】，系统已预设了三种常见的交易种类，用户可以根据实际情况自行设置。

打开【财务会计】－>【合并报表】－>【合并准备】－>【抵消分录模板】，新增交易类抵消分录模板。

打开【财务会计】－>【合并报表】－>【报表模板】－>【模板样式方案】，定义交易类抵消表样式方案。

打开【财务会计】－>【合并报表】－>【报表模板】－>【抵消报表模板】，新增交易类抵消报表模板，填充交易类抵消表模板样式方案，保存并分发给子公司。

第二步：上报内部交易明细报表数据

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【个别报表】功能，新增交易类抵消报表，编制报表数据保存并上报。销售方填报内部销售收入及成本，购买方填报内部采购未实现外销的存货。（子公司行为）

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【报表接收】功能，选择需要接收的交易抵消报表进行接收。（集团行为）

第三步：往来数据查询与核对（集团行为）

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的【查询与核对】－>【内部交易查询】功能，可以查询当前合并范围内部交易明细情况。

第四步：自动生成抵消分录（集团行为）

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【抵消分录】－>【自动抵消】功能，单击【自动生成】系统自动生成内部交易数据的抵消分录。

如选择了参数“增加内部事项交易类-存货核对”，则交易类-存货的抵消不在【自动抵消】里处理，而在【内部事项核对】－>【交易类-存货】中处理。

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的【内部事项】－>【内部事项核对】－>【交易类-存货】功能，单击【核对】，系统自动完成内部往来数据的核对。当核对结果不平时，单击【差异处理】，确定对账不平时，抵消分录的生成规则。

抵消分录审核后，就可以参与合并报表的计算。

## 【页面】交易种类

===== 交易种类 =====

**功能说明**
在进行交易类的抵消时，不同种类的交易涉及的抵消分录不同。

例如：存货的购销需要抵消的项目是存货，固定资产的购销需要抵消的项目是固定资产。

所以对于交易类的抵消类型还需要根据交易种类来确定其适应的抵消分录模板，并生成准确的抵消分录。

**操作说明**

打开【财务会计】－>【合并报表】－>【基础资料】－>【交易种类】功能，新增交易种类。

**字段说明** 

|字段||说明|
|编码||交易种类的编码，唯一标识，手工录入。|
|名称||交易种类的名称，手工录入。|

===== 内部事项 =====

**功能说明**

查询及核对集团合并关联公司间往来类、交易类、权益类、现金流量类的报表项目数据

**功能路径**

内部事项有两个入口，两者调用的是同一功能，区别在于主菜单内部事项可单独设置用户权限

**功能说明**

===== 内部事项核对 =====

**功能说明**

内部事项核对默认包含往来类、现金流量类，交易类-存货则需启用合并报表参数设置-增加内部事项交易类-存货核对

内部事项核对可根据抵消分录模板的设置，生成关联公司的核对记录、对核对记录做差异处理及生成对应的抵消分录

**操作说明**

进入【内部事项】-【业务操作】

点击【核对】，选择需核对公司组织，点【确认】，系统根据抵消分录模板设置自动生成对应核对记录

选择单条核对记录,点【差异处理】，系统根据抵消分录模板设置对该条核对记录进行差异处理，

选择多条核对记录,点【批量处理】，系统根据抵消分录模板设置对多条核对记录进行差异处理，

点【自动生成抵消分录】，系统对已审核的核对记录，根据抵消分录模板设置自动生成对应的抵消分录。

====== 合并报表编制 ====== 

**功能说明**

合并报表由企业集团中对其他企业由控制权的控股公司或母公司编制，它是在对纳入合并范围的个别报表的数据进行加总的基础上，通过编制调整、抵销分录将企业集团内部的经济业务对个别报表的影响予以抵销，然后合并个别报表各项目的数据编制而成的。

**操作前提**

子公司和子集团的个别报表已接收；调整分录、抵消分录已审核。

**操作说明**

【新增】：打开【财务会计】－>【合并报表】－>【合并报表】功能，选择某个合并报表模板新增合并报表。

合并报表重算：打开新建的合并报表，单击【数据】－>【重算表页】或【全部重算】（使用快捷键F9），系统会自动对各项目进行调整、抵消后计算出合并数，保存即完成合并报表的编制。

如果用户不需要查看各项目的具体调整、抵消情况，可以不需要编制工作底稿，合并报表重算时会对各项目的数据进行调整、抵消后汇总，从而得出各项目的合并数。

【上报】：子集团的合并报表将作为集团的个别报表参与集团的合并。

====== 1 系统概述 ======

===== 1.1 合并报表系统概述 =====

本产品的合并报表系统，是基于会计核算体系，帮助集团企业构建和规范对外合并财务报告和对内管理报告体系，简单、快速地完成各子公司个别数的采集和调整、内部会计事项的自动抵消、多汇报口径合并报表的并行出具。

全面满足企业法人组织架构、责任中心考核架构等多种维度、多种合并方式的报表合并要求，及时、真实、准确地反映集团整体的运营状况。

===== 1.4 操作说明=====

==== 1.4.1 使用流程====

合并报表系统的使用流程如下：

**第一步，基础设置**

在系统使用前，我们需要先进行基础设置。 包括公用基础资料和合并报表系统专用基础资料。

具体为：供应商、客户、币别、物料、费用项目、组织信息、会计核算体系、账簿信息、汇率体系、会计政策、报表项目、项目数据类型、金额单位、抵消类型、交易种类、报告维度等。

这里只介绍合并报表系统本身基础资料设置路径：

进入【财务会计】－>【合并报表】－>【基础资料】对报表项目、项目数据类型、金额单位、抵消类型、交易种类、报告维度基础资料进行设置。

**第二步，合并准备**

为了编制合并报表数据，还需要准备如下在合并过程中直接用到的资料：股权关系、合并方案、调整分录模板、抵消分录模板、项目勾稽关系以及项目勾稽关系分配。

进入【财务会计】－>【合并报表】－>【合并准备】对上述提到的用于报表合并的资料进行设置。

**第三步，报表模板**
 
编制报表的首要前提，必须先有报表模板。

进入【财务会计】－>【合并报表】－>【报表模板】进行个别报表模板、合并报表模板、抵消报表模板的设置。

**第四步，折算准备**

在合并过程中，如果存在币别不一致的报表，还需要经过折算才能进行合并，对于需要进行外币折算的报表还需要进行折算前的基础资料准备。

进入【财务会计】－>【合并报表】－>【折算管理】对外币折算方法、项目外币折算方案、项目变动记录进行设置；

**第五步，系统参数**

进入【财务会计】－>【合并报表】－>【参数设置】－>【合并报表参数设置】进行参数设置。

**第六步，个别报表编制**

纳入合并范围的组织都需要根据母公司分发的报表模板编制个别报表。

进入【财务会计】－>【合并报表】－>【合并控制】－>【个别报表】新增个别报表，编辑报表内容。完成提交、审核、上报操作后，集团层面负责接收个别报表。

**第七步，调整、抵消分录编制**

母公司接收子公司上报的个别报表后，如果存在调整事项，需要对个别报表进行调整，还需要对权益、内部往来、内部交易等事项进行抵消。

进入【财务会计】－>【合并报表】－>【合并控制】－>【调整分录】－>【集团调整】新增调整分录，支持手工新增和自动生成。

进入【财务会计】－>【合并报表】－>【合并控制】－>【抵消分录】－>【手工抵消】进行抵消分录的手工新增。

进入【财务会计】－>【合并报表】－>【合并控制】－>【抵消分录】－>【自动抵消】进行抵消分录的自动生成。

进入【财务会计】－>【合并报表】－>【合并控制】－>【抵消分录】－>【选项】－>【引入】进行抵消分录的引入新增。

**第八步，汇总、合并**

母公司接收子公司上报的个别报表，经过调整、抵消处理后，就可以开始汇总、合并工作。

进入【财务会计】－>【合并报表】－>【合并控制】－>【汇总报表】新增汇总报表。

进入【财务会计】－>【合并报表】－>【合并控制】－>【工作底稿】新增工作底稿。

进入【财务会计】－>【合并报表】－>【合并控制】－>【合并报表】新增合并报表。

==== 1.4.4 合并准备====

在正式编制合并报表之前，我们需要做一些合并前的准备工作：

1) 明确纳入合并的公司范围及合并层次，合并采用的权益核算规则，适用会计政策等；

3) 确定合并过程中统一的报表模板格式、调整及抵消分录模板格式；

==== 专题2：动态罗列表====

**功能说明**

现代企业的管理当中，企业财务报表的作用只是一部分，更多的作用来自于管理报表，管理报表信息需要对财务报表信息和非财务报表信息进行加工。

管理报表对编制管理报表无具体法规要求，其格式完全由管理层决定，能够专注于企业经营活动的特定范围和维度。

这类报表的特点在于报表项目在各个公司都不相同，而且即使在同一公司中在不同期间也可能是不同，例如，按客户统计的应收账款明细表，每个公司由于面向的客户不一样，因此集团无法像资产负债表一样，在一开始就能确定好报表项目和格式。

合并报表系统提供的动态罗列表，子公司即可根据自己的业务实际情况，填报各项数据；系统将对这些动态变化的报表数据进行汇总，极大简化了集团合并报表人员编制管理报表的工作量。

报表模板中，大量的财务附表及管理报表的行或列是无法固定的（不同于资产负债表），子公司在填制报表时根据自身公司的情况动态填列，集团公司可对这些不定行或列的报表进行汇总。

===== 合并方案 =====

**功能说明**

母公司在编制合并会计报表时，应当将其所控制的境内外所有子公司纳入合并会计报表的合并范围，这是编制法定合并报表的要求。但在合并时，除了按控股的层次结构进行合并外，集团还可能从行业、区域、事业部等不同角度进行合并，以满足管理分析的需要。

**操作前提**

会计核算体系已审核

**操作说明**

【新增】：打开【财务会计】－>【合并报表】－>【合并准备】－>【合并方案】功能，新增合并方案。

【启用】：对未启用的合并方案进行启用操作，合并方案的“启用状态”标记为‘已启用’。已启用的合并方案才可以使用。

【反启用】：允许对已启用的合并方案进行反启用操作，反启用操作成功后，合并方案的“启用状态”标记为‘未启用’。

【股权关系检查】：检查当前合并方案中每个合并范围中的控股公司与其同合并范围的其他公司以及当前范围的下级范围的控股公司是否建立股权关系。

【版本管理】：合并方案版本管理。

版本变更为向导式，当合并方案已启用，且已编制报表，这时当需要调整合并结构时，先做合并结构的调整，然后再执行【变更】，进入向导式变更，步骤如下。


1）设置新版本变更的启用日期，录入变更原因（可选），一般情况下不能早于旧版本的启用日期，如果有需要必须要早于旧版本的启用日期，则后续不支持方案回滚。

2）系统对调整的结构进行数据，自动列出新版本启用日期当期及之后期间的汇总报表、工作底稿、合并报表，用户需要手工点击【删除】，删除列表中的报表（删除的报表不能恢复，需要谨慎操作），列表为空时方可执行下一步。

3）完成，友谊提醒：合并方案变更，涉及组织变动。删除的组织对应的报表模板将被删除或者禁用，新增的组织需要重新分发合并报表相关模板。

注：合并方案的合并结构变更、权益核算变更，系统将生成新的合并方案版本。版本管理中，提供当前合并方案多个版本的查询。提供版本比较，版本差异对比。提供报表回滚，回滚到上个版本。

===== 合并构成分析 =====

**功能说明**

母公司的合并报表、汇总报表数据通过对子公司上报的报表进行调整抵消后得来的。

这样母公司合并报表、汇总报表的数据来源可能是子公司上报的原始数据，也可能是子公司上报的数据经过调整抵消得来，调整了多少，抵消了多少，调整的是哪些公司的哪些数据，这就需要对母公司合并数和汇总数进行构成分析。

**操作前提**

合并报表、汇总报表已编制完成。

**操作说明**

打开【财务会计】－>【合并报表】－>【查询分析】－>【项目构成分析】功能，设置过滤条件查询所需合并数或汇总数的项目构成。


**过滤条件字段说明**

|字段||说明|
|合并方案||指所查询的合并方案，F8选择到所有已启用的合并方案。|
|合并范围||指所查询的合并范围，F8选择到所选合并方案下的所有合并范围。|
|报表周期||所要查询的报表数据的周期。|
|币别||所要查询的报表数据的币别。|
|年度、期间||所要查询的报表数据的年度、期间。|
|报表项目||指所查询的报表项目数据范围。为空，查询全部报表项目。有数据的全部会显示。|
|数据类型||指所查询的项目数据类型。|
|数据来源||提供“合并数、汇总数”两种数据来源。|
|数据属性||提供“金额、数量”两数据属性。|


**报表界面重要字段说明**

|字段||说明|
|原始数据||展示上报后的调整前数据|
|借方调整||展示当前合并范围各组织及子合并范围对应的调整分录的借方合计数。展开至组织级数据时，则显示对应组织及子合并范围的明细调整分录的借方数据。|
|贷方调整||展示当前合并范围各组织及子合并范围对应的调整分录的贷方合计数。展开至组织级数据时，则显示对应组织及子合并范围的明细调整分录贷方数据。|
|借方抵消||展示当前合并范围各组织及子合并范围对应的抵消分录的借方合计数。|
|贷方抵消||展示当前合并范围各组织及子合并范围对应的抵消分录的贷方合计数。|

===== 外币折算方案 =====

**功能说明**

将下级子公司或者子集团的外币报表折算为币别与母公司记账本位相一致的报表。

**操作前提**

在合并控制下，进行外币折算之前，请检查并保证以下信息完整：

1. 参加折算的个别报表（含抵消表）都已接收；

2. 折算使用的汇率类型，在当前期间下存在原币与目标币别的汇率记录。

3. 折算使用的项目外币折算方案中所包含的报表项目，已覆盖本次要折算报表中包含的报表项目；

4. 参加折算的报表，存在报表数据的单元格都存在ITEM公式；

5. 动态罗列表的折算，不支持按历史汇率折算的项目，故需检查并保证参加折算的动态罗列表中不存在按历史折算的项目；

6. 按历史汇率折算的项目，在“项目变动记录”中已做严格的记录和维护，并保证项目变动记录中的数据与账面数据一致。

===== 外币折算方法 =====

**功能说明**

外币折算所使用的折算方法。系统已预置常用的折算方法：【期末汇率】、【平均汇率】、【历史汇率】、【本年累计数折算金额】；

除预置方法外，允许用户自定义外币折算方法，主要作用于企业使用的平均汇率，其计算公式不尽相同。

如：系统中预置（月报）平均汇率，计算公式为“(期初汇率+期末汇率)/2”；

而也有企业使用的（月报）平均汇率，计算公式为“周期内各次变动汇率之和/变动次数”。

**操作说明**

打开【财务会计】－>【合并报表】－>【折算准备】－>【外币折算方法】功能，新增外币折算方法。


**字段说明**

| 字段                        || 说明                                                                                                                                                                                                                                                                |
| 周期类型                      || 下拉选择具体的周期类型，包含：月度、季度、半年度、年度，需针对不同的周期类型，维护相应的计算公式。\\ 【同步到其他周期】，将维护好计算公式应用到其他周期                                                                                                                                                                                     |
| 计算公式                      || 从计算元素中选择并维护计算公式。                                                                                                                                                                                                                                                  |
| 计算元素   | 说明                | 系统预置的计算元素，通过计算元素的自定义组合定义折算的计算公式                                                                                                                                                                                                                                   |
| :::    | 期初汇率/期末汇率         | 主要用于资产负债表中【期末数】的折算。一般选择一种即可，用户可以根据自己的业务状况，选择一种合适的计算方法。\\ 期初汇率：当期第一个有效汇率；\\ 期末汇率：当期最后一个有效汇率。                                                                                                                                                                       |
| :::    | 上年年末汇率/本年年初汇率     | 主要用于资产负债表中【年初数】的折算。一般选择一种即可，用户可以根据自己的业务状况，选择一种合适的计算方法。\\ 上年年末汇率：上年最后一个有效汇率；\\ 本年年初汇率：本年第一个有效汇率。                                                                                                                                                                   |
| :::    | 周期内各月末之和          | 折算期间内的各月最后一个有效汇率相加                                                                                                                                                                                                                                                |
| :::    | 周期内各次变动汇率之和/变动次数  | 折算期间内的每一个有效汇率相加/期间内有效汇率个数                                                                                                                                                                                                                                         |
| :::    | 上期折算后金额+本期发生数*汇率  | 预置【本年累计数折算金额】方法的元素构成部分\\ 【本年累计数折算金额】主要用于利润表中【本年累计数】的折算。\\ 原理：上期折算后金额+本期发生数*本期平均汇率，其中本期平均汇率的公式是固定的，等于本期各次变动汇率之和/变动次数。                                                                                                                                              |
| 自定义元素  | 说明                | 可自定义的计算元素，通过计算元素的自定义组合定义折算的计算公式                                                                                                                                                                                                                                   |
| :::    | 取数周期              | 包含：月度、季度、半年度、年度，折算使用的汇率期间类型                                                                                                                                                                                                                                       |
| :::    | 开始期间              | 折算使用的汇率开始期间                                                                                                                                                                                                                                                       |
| :::    | 结算期间              | 折算使用的汇率截止期间                                                                                                                                                                                                                                                       |
| :::    | 取数类型              | 期初汇率：所选期间第一天有效汇率\\ 期末汇率：所选期间最后一天有效汇率\\ 平均汇率（期初和期末）：所选期间的“每期的（期初汇率+期末汇率）/2”的汇率之和，计算结果=1月（期初汇率+期末汇率）/2+2月（期初汇率+期末汇率）/2+N月（期初汇率+期末汇率）/2\\ 平均汇率（各次变动）：所选期间的“每期的有效汇率之和/汇率个数”的汇率之和，计算结果=1月有效汇率之和/汇率个数+2月有效汇率之和/汇率个数+N月有效汇率之和/汇率个数\\ 各次变动汇率：所选期间的（每个一个有效汇率之和）/期间内有效汇率个数  |

以下通过简单案例说明不同权益核算方法，对持股比例计算结果的影响：

A集团公司的股权关系以及合并结构：

[图:crrpt_手册_多种权益计算方法图.png]

权益抵消核算方法=统一在控股公司进行核算。则自动计算的持股比例为： 

| 投资公司     || 被投资公司     || 持股比例     || 计算逻辑                                                       |

## 【页面】工作底稿

====== 工作底稿编制 ====== 

**功能说明**

在工作底稿中，对母公司和纳入合并范围的子公司的个别报表各项目的数据进行汇总和调整、抵销处理，最终计算出合并报表各项目的合并数，在工作底稿中能清楚了解到各个项目的调整、抵消情况。

**操作前提**

子公司和子集团的个别报表已接收；调整分录、抵消分录已审核。 

**操作说明**

【新增】：打开【财务会计】－>【合并报表】－>【工作底稿】功能，选择某个工作底稿模板新增工作底稿报表。

工作底稿重算：打开新建的工作底稿，单击【数据】－>【重算表页】或【全部重算】（使用快捷键F9），重算得出汇总数、调整数、抵消数、合并数，保存即完成工作底稿的编制。

【公式取数参数】：选项“根据明细项目更新父级项目”，用于调整及抵消分录直接调整及抵消明细项目，系统根据非明细项目的关系表达式，直接计算和更新到父级项目上。

例如：报表项目基础资料中“应收账款”项目属性“关系表达式=应收账款A+应收账款B+应收账款C”。

抵消分录中，直接抵消其明细项，贷：应收账款A 1000 贷：应收账款B 2000 贷：应收账款C 3000，

则在工作底稿中，勾选“根据明细项目更新父级项目”，重算工作底稿，工作底稿上“应收账款”贷方调整数=6000（1000+2000+3000）。

注意:勾选时，工作底稿重算，系统优先查找当前报表上的报表项目对应的调整以及抵消数，如果不存在，会继续根据报表上报表项目属性中的关系表达式（报表项目），找到明细报表项目对应的调整以及抵消数。

**其它说明**

模板样式方案的“报表类型”选择“工作底稿”时，在数据列有参数“合并数置于数据列首”，选择此参数，则合并数列将在数据列的第一列；

适用场景：报表模板有REF()函数取合并数某个单元格数据时，不会因为子公司数不同而需人为调整单元格位置

===== 抵消类型 =====

所以，抵消类型对实现自动抵消有至关重要的作用，抵消类型需要贯穿在报表项目、抵消分录模板、抵消查询核对各功能中。

打开【财务会计】－>【合并报表】－>【报表模板】－>【模板样式方案】，定义权益类抵消表样式方案。

打开【财务会计】－>【合并报表】－>【报表模板】－>【抵消报表模板】，新增权益抵消报表模板，填充权益类抵消表模板样式方案保存并分发给子公司。

第二步：上报内部权益投资明细报表数据

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【个别报表】功能，集团新增用于抵消的权益投资明细报表，编制报表数据保存并上报。子公司编制资产负债表并上报。

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【报表接收】功能，选择需要接收个别报表进行接收。（集团行为）

第三步：维护持股比例（集团行为）

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的【持股比例】，系统自动生成当前范围用于权益抵消的持股比例，用户也可以手工修改持股比例。用户还需对每条持股比例记录指定对应的权益调整分录模板及抵消分录模板。

第四步：自动生成抵消分录（集团行为）

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【抵消分录】－>【自动抵消】功能，单击【自动生成】即自动生成内部投资与权益的抵消分录。

打开【财务会计】－>【合并报表】－>【合并控制】，进入所属合并范围的的【抵消分录】－>【抵消查询】功能，可以查询当前合并范围的投资与权益抵消分录情况。

抵消分录审核后，就可以参与合并报表的计算。

====== 汇总报表编制 ====== 

**功能说明**

汇总报表由子集团或总集团在接收了子公司的个别报表数据后进行编制，实现对纳入合并范围的子公司的个别报表的项目数据的加总，得出各个项目的合并数。

**操作前提**

子公司和子集团的个别报表已接收。

**操作说明**

【新增】：打开【财务会计】－>【合并报表】－>【汇总报表】功能，选择某个汇总报表模板新增汇总报表。

汇总报表重算：打开新建的汇总报表，单击【数据】－>【重算表页】或【全部重算】（使用快捷键F9），对报表进行重算来实现项目数据汇总，保存即完成汇总报表的编制。 

汇总报表有两种报表样式：固定样式和动态样式。固定样式的汇总报表只汇总固定样式的个别报表的数据，动态样式的报表只汇总动态样式的数据

【上报】：子集团的汇总报表将作为集团的个别报表参与集团的汇总。

 ====== 汇总报表导出 ====== 

**功能说明**

汇总报表支持EXCEL格式、Fml格式的批量导出，支持多个合并范围的汇总报表批量导出。

**操作说明**

【财务会计】－>【合并报表】－>【合并控制】－>【合并报表】－>【汇总报表】－>【选项】－>【引出】。

汇总报表列表默认显示当期合并范围的汇总报表，打开【过滤】，新增条件“合并范围不等于空”，可过滤出所有合并房范围的汇总报表。

**自定义Sql取数说明：**

1、  自定义Sql必须符合KSQL语法；

2、  多选类型的参数，在Sql中需要使用表变量，（表变量的使用，参考KSQL语法）；

自定义SQL取数设置说明：

1、  打开自定义函数新增界面，取数来源类型选择“自定义Sql”，弹出“自定义SQL”界面，分别在SELECT、FROM、WHERE 填入相应的字句，点击“解析”按钮（分析当前sql是否符合KSql语法），点击“确定”返回；

2、  在取数参数界面设置Sql用到的参数。（如果在参数列表没有找到对应的参数，需要到“取数参数管理”添加参数）；

3、  自定义sql参数为空时，默认取所有；

自定义Sql例子：

获取应收单某段时间内某些物料的价税合计

SELECT

SUM(t1.FALLAMOUNTFOR)

FROM

t_AR_receivable t0  INNER JOIN  t_AR_receivableEntry t1

ON  (t0.FID = t1.FID )  LEFT JOIN

T_BD_DEPARTMENTst013  ON (t0.FSALEDEPTID=st013.FDEPTID) LEFT JOIN

T_BD_MATERIAL st11  ON (t1.FMATERIALID=st11.FMATERIALID)

WHERE

t0.FCANCELSTATUS='A'  AND   (st013.FNumber>=@BeginDeptNumberAND st013.FNumber<=@EndDeptNumber)

AND t0.FDATE>=@StartData AND t0.FDATE<@EndDate AND  st11.FNUMBER>=@BeginMateNumberAND st11.FNUMBER<=@EndMateNumber  

** 自定义接口取数说明**

自定义取数实现类编写说明：

1、自定义接口的类需要继承AbstractCustomServicePlugIn，该类的完整路径是

Kingdee.BOS.App.KDSCaculateService.Function.AbstractCustomServicePlugIn；

2、基类AbstractCustomServicePlugIn包含MinArgs（最少参数个数），MaxArgs（最多参数个数）两个抽象属性，必须在取数实现类进行重写并设置取数函数需要的参数个数，如果取数公式传递的参数个数不符合条件直接返回错误；

3、基类AbstractCustomServicePlugIn包含GetFunctionValue（计算公式值）抽象函数，在取数实现类通过该函数实现具体的取数逻辑；

4、基类AbstractCustomServicePlugIn包含SetDefaultValue（设置默认参数），Validate（校验参数有效性）两个虚函数，调用顺序为先“设置默认参数”再“校验参数有效性”。

3、      在取数参数设置该接口需要的参数，（如果在参数列表没有找到对应的参数，需要到“取数参数管理”添加参数）注意参数的顺序要和接口中使用的参数顺序一致

## 【页面】调整报表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B0%83%E6%95%B4%E6%8A%A5%E8%A1%A8

**功能说明**

合并报表编制工作中，要求统一母子公司的会计政策、统一母子公司的资产负债表日及会计期间，对上报个别报表进行调整，从合规性角度，对报表数据的调整，应通过编制调整分录完成。

该调整可以由下级子公司自主调整，或者统一由集团合并报表编制人员统一调整。

报前调整功能，用于子公司在报表上报之前，自主进行报表数据的调整。

**操作前提**

为简化每期编制调整分录工作，应提前整理并完成调整分录模板的定义和分配，在每期报表调整时，只需引入分录模板即可快速生成调整分录。

**操作说明**

在报表编辑器中，使用【合并】菜单-【调整分录管理】；

在【调整分录列表】管理界面，可完成调整分录的新增、查询、修改、删除、审核以及重算；

使用【调整分录列表】-【重算】，将当前报表中已审核的所有调整分录，重算到当前报表。

已做了报前调整的报表需要谨慎使用报表客户端的【重算】，会覆盖掉调整分录的重算结果，一般的操作是先做报表重算，确认数据无误后，再执行报前调整，做调整分录界面的重算，然后，再保存、审核此张报表。

**其他说明**

反审核已重算到报表的调整分录，可通过【重算】，系统将自动扣减相应报表项目数据。

===== 项目变动记录 =====

**功能说明**

在外币折算时，不同的报表项目，使用的汇率折算方法不同的。如：资产和负债项目，采用期末汇率折算，所有者权益除“未分配利润”外，都采取历史汇率折算。

对于按历史汇率折算的项目，则必须将每次项目变动金额（包括初始金额）进行保存，并根据各次变动日期对应的汇率，折算出该项目的折算后的汇总金额。

注意：按历史汇率折算的项目，请务必在“项目变动记录”中做严格的记录和维护，以保证项目变动记录中的数据与账面数据一致。

**操作说明**

打开【财务会计】－>【合并报表】－>【折算准备】－>【项目变动记录】功能，新增项目变动记录。

**字段说明**

固定报表项目变动：作用于固定报表无维度的报表项目数的历史汇率折算

抵消报表项目变动：作用于抵消报表的有维度报表项目数的历史汇率折算

## 【页面】项目外币折算方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A1%B9%E7%9B%AE%E5%A4%96%E5%B8%81%E6%8A%98%E7%AE%97%E6%96%B9%E6%A1%88

===== 项目外币折算方案 =====

**功能说明**

会计准则中要求对不同性质的报表项目需采用不同的折算方法。

为此，通过“项目外币折算方案”功能，定义报表项目在外币折算过程所使用的折算方法。

注意：一个项目外币方案，应包含所有可能需外币折算报表对应的报表项目。

**操作说明**

打开【财务会计】－>【合并报表】－>【折算准备】－>【项目外币折算方案】功能，新增项目外币折算方案。



**字段说明**

| 字段            || 说明                                                        |
| 方法编码、方法名称     || 选择外币折算方法。                                                 |
| 项目编码、项目名称     || 选择适用该外币折算方法的报表项目，支持批量选中多个报表项目，系统自动批量填充折算方法。               |
| 项目数据类型        || 为空，则报表项目对应的数据类型都用一种折算方法；\\ 为具体值，如期末数，则表示报表项目+期末数用一种折算方法。  |
