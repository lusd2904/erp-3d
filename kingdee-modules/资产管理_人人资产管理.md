## 【页面】人人资产管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%BA%E4%BA%BA%E8%B5%84%E4%BA%A7%E7%AE%A1%E7%90%86

====== 1 人人资产管理系统概述  ======

===== 1.1 人人资产管理概述 ===== 

人人资产管理系统依赖固定资产和人人资产系统，以人人资产工作台数据为基础，对人人资产单据进行统一管理，提供实物分类，单据审核、审批，盘点确认等功能，实现资产实物的规范化、标准化管理，提升企业资产实物管理水平，使资产管理更准确和全面。

===== 1.2 系统特性 =====

  - 支持资产领用单提交自动匹配资产编码。  
  - 支持卡片实物信息按资产编码进行实物分类。 
  - 支持对历史卡片批量指定实物类别。
  - 支持对员工自盘数进行确认。
  - 支持人人资产单据分类统一查询管理。
  - 支持历史已领用资产编码维护保管人便于员工资产管理。 
  
====== 2 人人资产管理、人人资产系统操作手册  ======

===== 2.1 人人资产管理、人人资产系统使用流程=====

第一步，基础设置

人人资产工作台用户需维护联系对象

    以管理员身份登录，【系统管理】－>【查询用户】－>【用户分录】－>【联系对象类型】－>选择员工类型－>【联系对象】－>选择员工
    
    员工需设置任岗信息，【基础管理】－>【基础资料】－>【员工列表】－>【用户-修改】－>【员工任岗信息】－>选择就任岗位
    
    设置人人资产参数，【资产管理】－>【人人资产管理】－>【参数设置】－>【人人资产参数】 

第二步，基础资料维护 包括实物类别、实物类别批量指定、变更保管人等

变更保管人，【资产管理】－>【固定资产】－>【资产卡片】－>【变更保管人】

第三步，日常业务操作

  1、资产领用
  
  2、资产转移或退库
  
  3、处置申请
  
  4、资产查询
  
  5、个人自盘

===== 2.2 基础设置=====

**人人资产参数**

资产退转单-人人资产退库单参数，设置资产退库时默认接收人、接收部门和接收后资产位置，默认值为空，空值时由管理员审核单据时手工维护。

[[实物类别|实物类别]]

===== 2.3 人人资产管理=====

包括资产领用、资产退转、处置申请、个人自盘表、实物类别批量指定管理，其中，资产领用、资产退转、处置申请、个人自盘表通过人人资产工作台相应单据发布，用于管理员工人人资产相关单据。

**资产领用**

人人资产领用单列表，支持修改、审核、反审核、查询员工人人资产领用单。

**资产退转**

资产退转单列表，支持修改、审核、反审核、查询员工资产退转单。

**处置申请**

处置申请单列表，支持修改、审核、反审核、查询员工处置申请单，支持审核完的处置申请单下推生成资产处置单。

**个人自盘表**

个人自盘表列表，对员工个人自盘表提交初盘数据进行确认等管理。

====== 实物类别 ======


====== 1 功能说明 ======

实物类别是对实物资产进行分类，同一类型的实物资产可分为一个类别。实物类别也是员工领用资产时进行智能匹配分配资产的依据。


====== 2 功能路径 ======

【资产管理】-->【人人资产管理】-->【基础资料】-->【实物类别】


====== 3 主要字段说明 ======

^ 字段名       ^ 说明                                            ^
| 创建组织      | 默认携带当前组织，不允许修改。                               |
| 使用组织      | 默认携带当前组织，不允许修改。                               |
| 编码        | 实物类别的编码。                                      |
| 名称        | 实物类别的名称，用户输入。                                 |
| 启用智能匹配    | 默认不勾选，勾选后则该实物类别启用智能匹配，在资产领用单提交时进行智能匹配分配实物资产。  |
| 匹配条件      | 来源于资产卡片上的字段，可根据此字段设置智能匹配时实物资产的排序依据。           |
| 匹配方式      | 包含升序和倒叙两种方式。                                  |
| 来源字段      | 根据字段进行模糊智能匹配，来源字段主要是人人资产下资产领用单上的申请资产名称和备注。    |
| 匹配字段      | 根据资产卡片上的资产名称，资产卡片上实物信息页签的规格型号与备注进行匹配。         |
| 智能匹配实物明细  | 根据所选的实物类别可联查到该类别下包含的实物资产明细。                   |



====== 4 操作说明 ======

新增实物类别，操作步骤：
  - 【资产管理】–>【人人资产管理】–>【基础资料】–>【实物类别】下点击新增；
  - 在单据新增界面可输入名称，勾选启用智能匹配，设置智能匹配规则下的排序字段，设置字段智能匹配下的匹配字段；
  - 单击保存按钮完成人人资产实物类别的保存；
  - 单击提交按钮完成人人资产实物类别的提交。


====== 5 使用说明 ======
  - 新增实物类别，设置匹配规则与匹配字段后，启用智能匹配。
  - 在实物类别批量指定中，可对已有的所有实物资产进行批量指定实物类别。
  - 员工新增人人资产的资产领用单，选择实物类别，输入申请的资产名称与数量。
  - 提交资产领用单，系统根据该实物类别下的所有实物资产，对未领用完的实物资产，按照实物类别所设置的匹配字段进行智能匹配，符合匹配结果的实物资产有多个的情况下，按照匹配规则下的排序依据分配实物资产至资产领用单上。
  - 智能匹配采用字段匹配的情况下，根据一定的算法进行判断，计算出最接近用户申请的资产，对于用户输入的资产名称与资产卡片的资产名称相差较大的情况下，匹配结果准确性可能会存在一定的偏差。

====== 实物类别批量指定 ======


====== 1 功能说明 ======

实物类别批量指定是对已有的所有实物资产，批量指定所属的实物类别。


====== 2 功能路径 ======

【资产管理】-->【人人资产管理】-->【人人资产管理】-->【实物类别批量指定】


====== 3 主要字段说明 ======

^ 字段名   ^ 说明                                ^
| 当前实物资产类别  | 批量指定界面，显示所选择的实物资产当前所属的实物类别。  |
| 修改实物资产类别  | 可选择新的实物类别，保存后更新实物资产所属实物类别。可多次修改。  |


====== 4 操作说明 ======

实物资产批量指定界面，操作如下：
  - 【资产管理】–>【人人资产管理】–>【人人资产管理】–>【实物类别批量指定】下选择多个实物资产后点击批量指定；
  - 在实物类别批量指定弹出界面中，选择新的实物类别，可批量填充后保存；


====== 5 使用说明 ======
  - 在资产卡片的实物信息页签下有实物类别字段，可在新增资产卡片时录入实物资产所属的实物类别。
  - 对于历史已有的所有实物资产，可在实物类别批量指定界面分别进行过滤后进行批量指定。
