====== 下载经营报表云模板 ======
====== 1.功能说明 ======

提供各种经营报表在线模板，不受产品版本限制，可以随时发布和更新报表模板。 用户可在经营会计分析模块预览经营报表云模板，选择并下载所需的模板快速应用到系统，减少经营报表模板设置工作量。

**功能路径**

【管理会计】→【经营会计分析】→【自定义经营报表】→【下载经营报表云模板】

====== 2.操作说明 ======
1、订阅云服务：H5环境管理员登录--》星空云服务---》增值云服务---》经营会计云服务---》经营报表云模板服务申请订阅

2、下载经营报表云模板：管理会计---》管理会计报表---》下载经营报表云模板（目前支持H5，后续可能会支持客户端）----》点击试用

3、操作以上两步后，在H5端可以查看到云模板，可模糊搜索报表名称，点击报表图片可以预览报表样式以及报表说明。

4、点击下载经营报表云模板后，会自动下载到经营报表模板里，在经营报表模板打开下载好的模板，维护使用的经营账簿后即可使用。

====== 1 经营会计分析概述 ======
===== 1.1 经营会计分析概述 =====
经营会计分析提供了一个企业内部管理经营会计分析平台，人人都可以制作适合各自企业的自定义报表，满足不同行业、不同企业、不同岗位等个性化的经营分析报表需求，提升企业内部管理效率。

====== 2 经营会计分析操作手册 ======
===== 2.1 自定义经营报表 ===== 
==== 2.1.1 经营报表维度 ====
经营报表维度按数据主体、数据范围和时间范围定义3种维度类型，用于定义经营主体、时间维度和经营指标的取数来源。

详细描述请见：[[经营报表维度|]]

==== 2.1.2 经营报表模板 ====
经营报表模板用于定义行和列展示的维度，按经营主体、经营指标和时间维度3种维度组合展示。

详细描述请见：[[经营报表模板|经营报表模板]]

==== 2.1.3 经营报表查询 ====
经营报表查询按已选经营报表模板展示经营数据查询结果。

详细描述请见：[[经营报表查询|经营报表查询]]

==== 2.1.4 经营数据授权 ====
经营数据授权可按用户或者角色分别授权，授权后，经营报表查询仅显示当前用户经营数据授权范围内的数据。（如未设置任何权限，将查看不到自定义经营报表的数据）。

详细描述请见：[[经营数据授权|经营数据授权]]

==== 2.1.5 下载经营报表云模板 ====

详细描述请见：[[下载经营报表云模板|下载经营报表云模板]]

====== 经营报表查询 ======
=====1 功能说明=====

经营报表查询根据已选的经营报表模板获取经营流水数据展示经营数据查询结果。

=====2 功能路径 =====

【管理会计】－>【经营会计】－>【自定义经营报表】－>【经营报表查询】。

=====3 过滤条件=====
[[经营报表查询过滤条件|经营报表查询过滤条件]]
=====4 操作说明 =====

系统支持选中报表单元格联查单元格数据对应的经营流水账明细。

系统支持查询结果的打印、引出和刷新等通用操作，用户可以点击菜单的【参数设置】按钮，设置查询的数据列为零是否显示、数据列尾零是否显示以及查询时是否首先弹出过滤界面等。

系统设置列宽，报表查询时列宽可根据模板设置的列宽展示。

=====4 操作说明 =====

1.层级控制

1）计算项不允许新增下级。

2）维度项目前最多只能设置三层级。

3）选择一级层级上下移时，整个层级包括下层级将会一起移动至下一个节点。非一级层级只能在当前节点的同层级中上下移。


2.行列设置

表头行列设置选择确定后，表体对应的行列设置维度项必须包含相应的维度。

例如：

^ 列维度        ^ 保存控制                       ^
| 经营主体+时间维度  | 每个节点维度项必须包含经营主体和时间维度。      |
| 经营指标+时间维度  | 每个节点维度项必须包含经营指标和时间维度。      |
| 时间维度       | 此节点只能选择一种维度项且维度来源只能是时间维度。  |


3.系统预置几个报表模板样式，可供参考，也可以复制新增该模板修改后即可用。

====== 经营报表维度 ======
=====1 功能说明=====

经营报表维度用于定义经营主体、时间维度和经营指标的取数来源。

=====2 功能路径 =====

【管理会计】－>【经营会计】－>【自定义经营报表】－>【经营报表维度】。

=====3 字段说明=====
主要字段说明
| **位置**       || **字段**          || **说明**                                                                        |
| 表头           || 维度类型            || 可选经营主体、时间维度、经营指标。                                                             |
|              || 维度来源            || 维度类型为经营主体时，可选核算维度、阿米巴单元、利润中心。\\ 经营类型为时间维度时，可选业务日期。\\ 经营类型为经营指标时，可选经营科目、投入时间。  |
|              || 经营账簿            || 指定使用报表维度的经营账簿，为空表示都可以使用。当设置维度来源为固定范围，经营账簿必录。                                  |
|              || 交易类型            || 可选择报表获取数据的不同交易类型。                                  |
|              || 维度显示           || 维度可选按名称、编码、名称+编码的展示方式 。                                |
| 维度来源设置页签     || 按报表过滤界面选择范围     || 选择此项，表示按经营报表过滤界面选择的数据进行取数和显示。                                                 |
|              || 按固定范围分项取值       || 选择此项，表示维度类型为经营主体或经营指标时，按已选择值分别统计显示。                                           |
|              || 按固定范围分项取值       || 选择此项，表示维度类型为经营主体或经营指标时，按已选择值汇总统计显示。                                           |
|              || 定义周期类型          || 维度类型为时间维度时，可选天、月、年、会计期间、会计年度、为空。                                              |
|              || 定义取数期间          || 维度类型为时间维度时，可选查询范围所有期间、查询范围最大期间、查询范围最小期间、截止到查询范围的最大日期、为空。                      |

=====4 操作说明 =====

定义周期类型:

1.当周期类型为会计期间时，按经营账簿的会计日历的会计期间划分周期取值和显示。

2.当周期类型为月时，按自然月划分周期取值。

3.当周期类型为年时，按年划分周期取值。

4.当周期类型为天时，按天划分周期取值。

5.当周期类型为空时，按查询时间范围汇总取值。

定义取数期间:

1.查询范围所有期间：查询结果取查询范围所有期间（如：周期类型为月，查询范围为2021年1月到2021年2月份，则分别显示2021年1月和2021年2月）。

2.查询范围最大期间：查询结果只取查询范围最大期间（如：周期类型为月，查询范围为2021年1月到2021年5月份，则取2021年2月的数据）。

3.查询范围最小期间：查询结果只取查询范围最小期间。

4.截止到查询范围最大日期：查询结果取最大年度的开始日期截止到查询范围最大日期（如：周期类型为年，查询范围为2021年2月到2021年2月，则取2021年1月到2月的数据）。

5.定义取数期间输入项：用于定义查询范围期间的对比期间（如：当周期类型为月，定义查询期间最大期间为当月，则-1为上月，查询期间-12为上年同月；当周期为年时，定义查询期间最大期间为当年，则-1为上年。)。

====== 经营数据授权 ======
=====1 功能说明=====

经营数据授权方便用户设置自定义经营报表中阿米巴单元数据的查看权限，可按用户或角色分别设置。

=====2 功能路径 =====

【管理会计】－>【经营会计】－>【自定义经营报表】－>【经营数据授权】。

=====3 字段说明=====
主要字段说明
| **位置**     || **字段**      || **说明**                                            |
| 基本页签       || 阿米巴组织架构     || 选择需要授权的阿米巴组织架构。                                   |
|            || 经营账簿        || 选择需要授权的经营账簿。                                      |
|            || 授权类型        || 可选择按角色授权或者按用户授权。                                  |
|            || 授权范围        || 目前授权范围仅为阿米巴单元。                                    |
| 表体         || 用户账号        || 当授权类型选择用户时，选择需要授权的用户账号。                           |
|            || 角色编码        || 当授权类型选择角色时，选择需要授权的角色编码。                           |
|            || 阿米巴单元编码     || 选择该用户或者角色可查看的阿米巴单元，授权后该用户或者角色即可查看该阿米巴单元的自定义报表数据。  |

=====4 操作说明 =====

如未设置任何权限，将无法查看自定义经营报表的数据。

当用户和用户对应的角色都设置了授权，该用户自定义经营报表查询的查看权限范围为授权的并集。
