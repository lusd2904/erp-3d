## 【页面】个人自盘表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%AA%E4%BA%BA%E8%87%AA%E7%9B%98%E8%A1%A8

[[人人资产#个人自盘表|<<返回人人资产界面]]


====== 个人自盘表 ======


====== 1 功能说明 ======

个人自盘表是员工对个人名下资产进行盘点提交自盘数据的单据。


====== 2 功能路径 ======

【员工服务】-->【人人资产】-->【我的资产工作台】-->【人人资产工作台】


====== 3 主要字段说明 ======

| **字段**      || **说明**                                                                        |
| 盘点方案           || 固定资产-资产盘点表相应字段。                                                      |
| 资产组织           || 固定资产-资产盘点表相应字段。                                                      |
| 货主组织           || 固定资产-资产盘点表相应字段。                                                      |
| 资产类别           || 固定资产-资产盘点表相应字段。                                                      |
| 资产编码           || 固定资产-资产盘点表相应字段。                                                      |
| 卡片编码           || 固定资产-资产盘点表相应字段。                                                      |
| 资产名称           || 固定资产-资产盘点表相应字段。                                                      |
| 账存数量           || 固定资产-资产盘点表相应字段。                                                      |
| 初盘数量           || 默认为0，手工录入实际盘点数量。                                                     |
| 差异             || 初盘数量与账存数量的差异，取初盘数量-账存数量。                                             |
| 初盘变动位置         || 盘点方案勾选“盘点资产位置”则资产盘点表列示该列。默认为空，表示资产实际存放位置与账存位置一致。不一致时手工录入资产实际存放位置。    |
| 初盘变动使用部门       || 盘点方案勾选“盘点使用部门”则资产盘点表列示该列。默认为空，表示资产实际使用部门与账存使用部门一致。不一致时手工录入资产实际使用部门。  |
| 初盘变动使用人        || 盘点方案勾选“盘点使用人”则资产盘点表列示该列。默认为空，表示资产实际使用人与账存使用人一致。不一致时手工录入资产实际使用人。      |
| 个人自盘状态         ||枚举值：未提交、已提交、已确认。默认值为未提交，自盘表提交后更新为已提交，自盘表确认后更新为已确认。 |

====== 4 操作说明 ======

资产管理员在固定资产生成资产盘点表后，按资产编码保管人自动产生个人自盘表至人人资产，操作步骤：

  - 【资产管理】–>【固定资产】–>【资产盘点】–>【盘点方案】资产管理员新增盘点方案生成资产盘点表后，自动按资产盘点明细保管人在人人资产模块生成保管人个人自盘表；
  - 【员工服务】–>【人人资产】–>【我的资产工作台】–>【人人资产工作台】选择个人自盘表或盘点中数字，进入个人自盘表列表，打开个人自盘表单据，在个人自盘状态值为未提交的明细录入盘点数据；
  - 单击保存按钮完成个人自盘表盘点数据的保存，保存的数据自动同步到资产盘点表；
  - 单击提交按钮完成个人自盘表盘点数据的提交，提交后个人自盘状态值为已提交，已提交的数据不允许修改，不允许反提交。

确认：在【资产管理】-->【人人资产管理】-->【个人自盘表】，在列表界面选中已提交的个人自盘表或盘点明细，单击确认按钮，完成确认操作。确认后更新单据上个人自盘状态值为已确认，不允许反确认。


====== 5 特殊说明 ======
  - 个人自盘表单据状态为创建状态及重新审核状态才允许保存和提交操作。
  - 【资产管理】-->【人人资产管理】-->【个人自盘表】仅支持对已提交的盘点数据进行确认。
  - 个人自盘表“个人自盘状态”不影响固定资产-资产盘点表的提交和审核操作。
  - 固定资产-资产盘点表单据状态同步更新个人自盘表单据状态。

## 【页面】人人资产
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%BA%E4%BA%BA%E8%B5%84%E4%BA%A7

====== 1 人人资产系统概述 ======

===== 1.1 人人资产概述 ===== 

   人人资产系统，是面向企业普通员工，提供员工个人资产管理的系统，支持资产申领、转移、退库、处置申请、盘点和个人资产查询。

===== 1.2 人人资产系统特性 =====

  * **特性**：人人资产工作台
  - 为HTML5环境下独立的员工资产管理入口。
  - 直观展示各类单据未完成单据数量。
  - 卡片式展示员工个人资产。
  - 卡片支持快捷新增资产领用、转移、退库、处置申请单，界面简洁易操作。

====== 2 人人资产工作台操作手册 ======

===== 2.1 我的应用 =====

[[我的资产列表|我的资产列表]]

[[人人资产领用单|人人资产领用单]]

[[资产退转单|资产退转单]]

[[处置申请单|处置申请单]]

[[个人自盘表|个人自盘表]]

===== 2.2 我的在办 =====

**功能概述**

为便于员工了解个人资产单据未完成情况，提供我的在办信息，包括申领中、退转中、处置中、盘点中四类在办信息。

**操作前提**

  - 用户有人人资产工作台查看权限。
  - 用户有相应单据查看权限。

**功能路径**

【员工服务】－>【人人资产】－>【人人资产工作台】－>【我的在办】

**操作说明**

点击数字打开相应单据未完成单据列表。

申领中：点击数字，打开当前用户单据状态不等于已审核的人人资产领用单列表。

退转中：点击数字，打开当前用户单据状态不等于已审核的资产退转单列表。

处置中：点击数字，打开当前用户单据状态不等于已审核的处置申请单列表。

盘点中：点击数字，打开当前用户单据状态不等于已审核的个人自盘表列表。

===== 2.3我的资产 =====

**功能概述**

将我的资产列表所列资产以卡片形式展示，第一个卡片为资产新增功能，第二个卡片开始一个资产编码一个卡片。

资产卡片信息：左侧显示资产相应实物类别图片，右侧上方显示资产“资产名称”、“资产编码”、“规格型号”、“资产位置”信息，右侧下方提供转移、退库、处置功能，便于用户快速处理个人资产。

**操作前提**

  - 有人人资产工作台查看权限。
  - 有人人资产领用单、资产退转单、处置申请单上我的组织（货主组织）对应新增权限。

**功能路径**

【员工服务】－>【人人资产】－>【人人资产工作台】－>【我的资产】

**操作说明**

点击新增领用卡片，打开资产领用单新增界面，单据类型为人人资产领用，我的组织默认携带当前登陆组织。

资产卡片点击转移，携带卡片资产信息打开资产退转单新增界面，单据类型为人人资产转移单，我的组织携带资产货主组织。

资产卡片点击退库，携带卡片资产信息打开资产退转单新增界面，单据类型为人人资产退库单，我的组织携带资产货主组织。

资产卡片点击处置，携带卡片资产信息打开处置申请单新增界面。

**特殊说明**

我的资产列表“个人资产状态”值为使用中的资产，允许进行转移、退库、处置操作。

我的资产列表“个人资产状态”值为转移中、退库中、处置中的资产，不允许进行转移、退库、处置操作。

## 【页面】人人资产领用单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%BA%E4%BA%BA%E8%B5%84%E4%BA%A7%E9%A2%86%E7%94%A8%E5%8D%95

[[人人资产#人人资产领用单|<<返回人人资产界面]]


====== 人人资产领用单 ======


====== 1 功能概述  ======
人人资产领用单是员工领用资产的单据，用以记录资产领用情况。
====== 2 功能路径  ======
【员工服务】-->【人人资产】-->【我的资产工作台】-->【人人资产工作台】

 ====== 3 主要字段说明 ======
| **字段**      || **说明**                                                                        |
| 领用日期        || 进行资产领用的日期，默认为系统日期，可以修改。                                                       |
| 我的组织        || 申请领用固定资产的货主组织。                                                                |
| 实物类别        || 来源于人人资产基础资料**实物类别**，当实物类别启用智能匹配后，在**人人资产领用单**选择该分类后，在提交单据时自动调用实物类别的匹配规则进行分配。  |
| 申请资产名称      || 需要申请的资产说明。                                                                    |
| 申请数量        || 需要申请的资产数量。                                                                    |
| 申请部门        || 需要申请资产的部门。默认为当前组织的主任岗部门，无主任岗时，按照任岗信息的顺序取得。允许手工修改，手工修改的取值范围为员工的任岗信息下的部门。       |
| 申请人         || 当前用户对应的员工。                                                                    |
| 资产编码        || 选择需要领用资产的资产编码，且要求该资产编码未被部分领用。                                                 |
| 领用数量        || 资产卡片上资产编码对应的数量，人人资产不允许对一条资产编码下的数量部分领用。                                        |
| 领用部门        || 默认为申请部门。允许手工修改，手工修改的取值范围为员工的任岗信息下的部门。                                         |
| 领用人         || 默认为申请人。                                                                       |
| 领用前资产位置     || 领用前固定资产所处位置。                                                                  |
| 领用后资产位置     || 领用后固定资产所处位置。                                                                  |

====== 4 操作说明 ======
新增领用单，操作步骤：
  - 【员工服务】–>【人人资产】–>【我的资产工作台】–>【人人资产工作台】 点击**新增领用**，打开资产领用单新增界面；
  - 在**[申请]页签**输入所要申请资产的实物类别、申请资产名称和申请数量等信息；
  - 单击保存按钮完成人人资产领用单的保存；
  - 单击提交按钮完成人人资产领用单的提交。

审核领用单：在【资产管理】-->【人人资产管理】-->【资产领用】，在列表界面选中领用单，在**[资产]页签**，对智能匹配或手工指定的资产编码等信息进行维护，单击审核，完成审核操作，系统根据单据上“申请人”更新资产卡片的实物信息下对应资产编码的“保管人”。

反审核领用单：在【资产管理】-->【人人资产管理】-->【资产领用】，在列表界面选中领用单，单击反审核 ，完成反审核操作。进行反审核操作后，资产领用单可以进行修改和删除。 


====== 5 特殊说明 ======
  - 单据状态为保存、提交审核或重新审核时，单据上存在的资产编码，其他领用单无法领用。
  - 领用人和领用部门受**固定资产参数**“资产领用部门，领用人与卡片使用部门，使用人不一致时，同步更新卡片信息”控制。

## 【页面】处置申请单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A4%84%E7%BD%AE%E7%94%B3%E8%AF%B7%E5%8D%95

[[人人资产#处置申请单|<<返回人人资产界面]]


====== 处置申请单 ======


====== 1 功能说明 ======

处置申请单是员工对个人名字资产提交处置的申请单据。


====== 2 功能路径 ======

【员工服务】-->【人人资产】-->【我的资产工作台】-->【人人资产工作台】


====== 3 主要字段说明 ======

^ 字段名   ^ 说明                                ^
| 申请日期  | 进行处置申请的日期，默认为系统当前日期，允许修改。  |
| 资产组织  | 实物资产所属资产卡片上的资产组织，自动携带，不可修改。  |
| 货主组织  | 实物资产所属资产卡片上的货主组织，自动携带，不可修改。  |
| 处置原因  | 用户填写提交处置申请的原因。  |
| 资产编码  | 实物资产的资产编码，自动携带，不可修改。  |
| 卡片编码  | 实物资产所属资产卡片的卡片编码，自动携带，不可修改。  |
| 资产名称  | 实物资产所属资产卡片的资产名称，自动携带，不可修改。  |
| 可处置数量  | 根据实物资产在资产卡片中实物页签的‘数量’字段进行携带，不可修改。  |
| 申请处置数量  | 默认等于可处置数量，可根据实际需要处置的数量进行修改，但不可超过可处置数量。  |
| 已关联处理数量  | 处置申请单下推资产处置单后，根据资产处置单中实际处置的数量进行反写。  |
| 处置状态  | 实物资产的状态，默认为处置中，当处置申请单下推资产处置单并审核后，修改状态为已处置。  |

====== 4 操作说明 ======

新增处置申请单，操作步骤：
  - 【员工服务】–>【人人资产】–>【我的资产工作台】–>【人人资产工作台】 工作台界面选择个人资产或我的资产列表中选择个人资产，点击处置，打开处置申请单新增界面；
  - 在单据新增界面可输入处置原因与申请处置数量信息；
  - 单击保存按钮完成人人资产处置申请单的保存；
  - 单击提交按钮完成人人资产处置申请单的提交。

审核处置申请单：在【资产管理】-->【人人资产管理】-->【处置申请】，在列表界面选中处置申请单，单击审核，完成审核操作。审核后会根据单据上实物资产在资产卡片上实物信息页签上的资产状态为处置中。

反审核处置申请单：在【资产管理】-->【人人资产管理】-->【处置申请】，在列表界面选中处置申请单，单击反审核 ，完成反审核操作。反审核会更新实物资产在资产卡片上实物信息页签上的资产状态为使用中。如果处置申请单已经下推过资产处置单，则不允许反审核。

====== 5 特殊说明 ======
  - 当实物资产处于退转中时，不允许提交处置申请。
  - 固定资产中对于资产的处置有控制要求，即同一张资产卡片在一个会计期间内只允许处置一次。当某个实物资产所属的资产卡片在当前期间已有资产处置单时，该实物资产不能提交处置申请。

  - 全部未领用的资产编码变更保管人后，自动更新为全部领用（可领用数量=0）。
  - “个人资产状态”值为使用中的资产，允许进行转移、退库、处置操作。
  - “个人资产状态”值为转移中、退库中、处置中的资产，不允许进行转移、退库、处置操作。

## 【页面】资产退转单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E9%80%80%E8%BD%AC%E5%8D%95

[[人人资产#资产退转单|<<返回人人资产界面]]


====== 人人资产退转单 ======
 ====== 1 功能概述 ======
人人资产退转单是员工退库或移交固定资产时使用的单据，一单两用。
 ====== 2 功能路径 ======
【员工服务】–>【人人资产】–>【我的资产工作台】–>【人人资产工作台】 
 ====== 3 主要字段说明 ======
| **字段**      || **说明**                                                    |
| 业务日期        || 进行资产退转的日期，默认为系统日期，可以修改。                                   |
| 我的组织        || 退库或转移固定资产的货主组织。                                           |
| 单据类型        || 系统预设两种单据类型：人人资产转移单和人人资产退转单，分别用以处理移交资产和资产退库业务。             |
| 资产编码        || 选择需要退库或转移的资产编码。同一资产编码，不允许部分退库或者部分转移。                      |
| 数量          || 需要退库或转移的资产数量。                                             |
| 接收部门        || 需要接收固定资产的部门。取值范围为所有组织下的部门。单据类型为人人资产退库单时，可在人人资产参数进行设置默认值。  |
| 接收人         || 需要接收固定资产的员工。单据类型为人人资产退库单时，可在人人资产参数进行设置默认值。                |
| 资产位置        || 退库或转移前固定资产所处位置。                                           |
| 接收后资产位置     || 退库或转移后固定资产所处位置。单据类型为人人资产退库单时，可在人人资产参数进行设置默认值。             |

====== 4 操作说明 ======
新增退转单，操作步骤：
  - 【员工服务】–>【人人资产】–>【我的资产工作台】–>【人人资产工作台】 工作台界面选择个人资产或我的资产列表中选择个人资产，点击**转移**或**退库**，打开退转单新增界面；
  - 在页签输入接收部门和接收人等信息；
  - 单击保存按钮完成人人资产退转单的保存；
  - 单击提交按钮完成人人资产退转单的提交。

审核退转单：在【资产管理】-->【人人资产管理】-->【资产退转】，在列表界面选中退转单，单击审核，完成审核操作。单据类型为人人资产转移时，根据“接收人”更新“保管人”；单据类型为人人资产退库时，清空 “保管人”。

反审核退转单：在【资产管理】-->【人人资产管理】-->【资产退转】，在列表界面选中退转单，单击反审核 ，完成反审核操作。进行反审核操作后，资产退转单可以进行修改和删除。 


====== 5 特殊说明 ======
  - 接收人和接收部门受**固定资产参数**“资产领用部门，领用人与卡片使用部门，使用人不一致时，同步更新卡片信息”控制。
