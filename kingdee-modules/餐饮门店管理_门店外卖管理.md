====== 1.外卖对账工作台-订单 ======
===== 1.1 功能概述 =====
外卖订单对账工作台是订单对账的核心单据，外卖订单对账是第三方平台（美团/饿了么） 的平台单号，外卖渠道与POS账单的外卖订单号，外卖渠道匹对的过程。外卖订单对账支持多个组织，多个日期同时对账。
===== 1.2 字段说明 =====
^ 字段名称         ^ 字段说明                                     ^
| 对账           | 点击对账会自动匹配外卖订单与POS账单中符合条件的数据生成已审核状态的对账记录  |
| 账单来源渠道       | 包括饿了么外卖和美团外卖                             |
| 门店POS外卖账单笔数  | 统计符合账单来源渠道的POS账单数                        |
| 平台外卖账单数      | 统计下载或者导入的美团/饿了么外卖订单数                     |
| 门店POS外卖金额    | 统计符合订单来源渠道的POS外卖金额                       |
| 平台外卖订单金额     | 统计符合订单来源渠道的平台外卖金额                        |
| 差异对账金额       | 平台外卖订单金额与门店POS外卖金额的差值                    |
| 自动对账金额       | 门店POS外卖订单和平台外卖订单符合条件的金额总和                |
| 确认对账金额       | 已审核状态的外卖订单对账记录单的确认对账金额总和                 |
| 差异状态         | 包括无差异已审核，有差异未审核，有差异已审核，无差异未审核，未对账五种状态    |
| 查看明细         | 点击明细界面跳转到外卖订单对账记录单界面                     |

====== 1.外卖管理系统参数 ======

**外卖账单对账关联外卖订单对账差异数据：** 设置外卖账单对账是否关联外卖订单对账差异数据的，如果勾选，则外卖账单对账界面会自动取外卖订单对账调整后的数据；如果不勾选，则外卖账单对账界面会取原始的外卖账单和POS账单的数据，默认不勾选。

**POS账单金额为0不参与对账：** 如果勾选则POS账单金额为0不参与对账。否则参与对账

====== 1.门店外卖管理 ======

==== 1.1 整体概述 ====
门店外卖管理包括门店外卖账单对账和门店外卖订单对账两部分。其中门店外卖账单对账包括美团外卖账单对账和饿了么外卖账单对账。美团外卖账单支持新增，导入功能，饿了么外卖账单支持新增，导入功能和下载功能。门店外卖订单也包括美团外卖订单和饿了么外卖订单，美团外卖订单和饿了么外卖订单只支持导入和下载功能。

===== 1.2 整体流程图 =====
[图:门店外卖管理工作流.png]

===== 1.3 操作说明 =====

**门店订单对账使用步骤： 收款账户设置 -》 对账字段配置 --》外卖对账参数设置 -》 下载外卖订单原始数据（美团/饿了么）—>POS账单 —》外卖对账工作台_订单**

**门店账单对账使用步骤： 收款账户设置 -》 对账字段配置 --》外卖对账参数设置 -》 下载外卖账单原始数据（美团/饿了么）—>POS账单 —》外卖账单工作台_订单**
