## 【页面】收款方式
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%94%B6%E6%AC%BE%E6%96%B9%E5%BC%8F

====  收款方式 ====
  *  系统预置了多种收款方式，系统预置收款方式不可修改；
  *  用户可自定义新增收款方式，用于门店记录其他收款金额，新增的收款方式，编码必须从10001起始；
  *  收款方式可定义是否开票、是否积分、是否赠券等参数；
  *  收款方式的POS机快捷码在POS端键盘设置中维护，在该地方设置无效；
  *  新增银联商务、翼支付、和包支付等收款方式，若配置旺POS收银，可直接调用微信、支付宝支付；
注意：现金收款方式的币别必须与组织的本位币保持一致。系统预制的收款方式不允许反审核修改。

  *  收银员权限组：共享型基础资料，可定义多种权限类型，类似于用户的角色管理；根据零售门店的权限管理要求定义不通的权限组：如店长、收银员等角色。不同的权限组赋予不同的权限：如退货权限、折扣权限；

====== 连锁档案 ======
====== 1 连锁档案整体应用======


===== 1.1 连锁档案概述 ===== 
   
连锁档案是整个零售系统运营的基础条件，在启用零售系统之前，需要设置连锁档案相关基础信息。同时零售系统启用需要标准金蝶AI星空系统基础数据作为基础设置，包括物料、客户、岗位信息、部门、币别、汇率类型、税务规则、会计核算体系、班次等零售业务涉及的基础资料。 零售基础资料的管理；包括门店信息、POS机、收银员、商品零售特性等。


===== 1.2 其他资料 =====
  * 品牌：商品的品牌划分,例如（蒙牛、伊利……）；
  * 商品经营目录：门店销售商品范围；
  * 商品类型：可分为普通商品、称重商品、金额商品、服务商品、组合商品、组装商品；
  * 商品条形码生成规则设置：可定义条形码生成规则设置；
  * 商品辅助属性条码；
  * 收款方式列表：门店系统的收款方式列表，可自定义新增收款方式；
  * 公共参数设置：IC卡、磁条卡刷卡参数配置、称重商品设置、门店支付信息配置。

===== 1.4 基础资料说明 ===== 

  * 组织机构：组织机构是零售门店启用的必选基础资料，搭建数据中心之前，需要确认零售门店的组织搭建关系，需要根据零售企业的业务管理和财务核算需求选择门店是按照一个组织一个门店搭建还是一个组织下建立多个门店模式；
  * 基础资料控制策略：控制商品、品牌、税务规则等的分配资料以及对应基础资料的的修改、携带关系；
  *  会计核算体系：会计核算体系是零售引用本位币的基础资料，必须先建立会计核算体系。若是门店按照利润中心组织设置，建议所有门店组织都设置一个法人组织核算体系里；
  * 币别：应用于对应组织下门店收款方式的结算币别；
  * 汇率：对于需要进行外币核算的业务，零售结算之后的财务处理可以进行汇率结算；
  * 税务规则：零售单配置对应的税务规则，零售单日结时，获取税务规则；
  * 仓库：门店信息\POS机引用仓库资料，确认门店收货仓库以及发货仓库、退货仓库。注意：POS端无法按照仓位选择商品，若启用标准产品的仓位管理，零售单日结时，需要按照批号拣货带出仓位-（门店协同参数：日结是否自动匹配批号要选择为是）；
  * 部门：POS端库存管理，会调用门店的信息的默认部门，因此需要启用POS端库存管理的客户，需要在门店信息设置默认部门；
  * 岗位：人员信息定义对应岗位信息；
  * 销售员：零售单选择业务员时，需要获取销售员信息；
  * 客户：就版本中。零售特性包安装完成之后，系统预置：零售客户（LSKH）；需要将该基础资料分配到各个组织，并在门店协同参数中维护默认的销售.客户为：零售客户。

## 【页面】重点参数设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%87%8D%E7%82%B9%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE

====  重点参数设置 ====
  * POS机授权方式：本版本只支持手输账户。账户为有权限的收银员账户和密码；
  * 有挂单是否允许退出系统：处理门店POS机存在挂单业务，若参数值为是，则有挂单不允许退出系统，建议默认设置为否。有强烈管控需求的，才需要设置成是；
  * 促销是否可选择：POS开单收银，可通过促销选择，选择对应的赠品。目前促销选择只支持，赠品选择，不支持其他折扣方式选择；
  * POS付款自动填入金额：POS端结算时，选择收款方式，则自动填上整单的金额，若为否，则需要手工填写金额；
  * 是否记录营业员，参数为是时，POS开单收银时，输入商品之后必须选择营业员；
  * POS端是否启用图片商品，启用后，在物料的零售页签上传商品图片，POS端选择商品会弹出商品图片；

[图:门店参数2.jpg]

  * 商品售价小于进价控制：商品销售价格是否允许小于供货价。若选择不允许，在POS端进行折扣时，最低折扣不能低于供货价；
  * 商品无库存销售控制：即是否允许POS端进行负库存销售。与参数：库存扣减未日结零售单、销售库存扣减未日结数量、销售开单实施扣减库存等连用，若商品无库存销售控制改为不允许，其他参数都要设置为是；
  * 日结销售出库单先暂存：该参数可与：零售日结出库单自动审核这个参数联用，将两个参数同时设置为是，对于日结生成的销售出库单存在问题的，可以先暂存，后续手工处理，若是没有问题的，则系统可自动审核；
  * 日结自动匹配批次号：该参数为是时，则零售单日结时，会调用批号拣货规则。对于启用了批次管理的商品，该参数为是，则POS端不需要选择批号，若为否，则需要选择批号；
  * 是否允许零售单整单金额为零进行结算，非赠品是否允许零单价销售，若为是，则可以直接设置为赠品出库；

==== 零售门店系统参数 ====
  * 门店系统参数设置按照组织进行隔离设置，不按照门店区分；
  * 条码设置参数：条码规则校验、条码唯一性校验、条码必录校验；
  * 基本参数：主要是控制POS收银的基本信息：如POS授权方式、是否允许无销售开钱箱、促销是否可选择、POS付款自动填入金额、取消销售是否打印小票、默认零售客户、是否记录营业员（销售员）、电子秤格式、称重商品重量小数位、金额小数位、抹零方式、前台保留小数位、微信、支付宝混合支付；
  * 小票打印参数：打印地址、联系方式、应收金额、折扣金额、打印会员信息等；
  * 销售控制参数：控制POS端商品销售的相关参数，如：无库存不允许销售，库存扣减未日结零售单等；
  * 会员参数：定义会员相关的参数，主要适用于POS收银调用；
[图:门店参数1.jpg]

  * POS机授权方式：本版本只支持手输账户。账户为有权限的收银员账户和密码；
  * 有挂单是否允许退出系统：处理门店POS机存在挂单业务，若参数值为是，则有挂单不允许退出系统，建议默认设置为否。有强烈管控需求的，才需要设置成是；
  * 促销是否可选择：POS开单收银，可通过促销选择，选择对应的赠品。目前促销选择只支持，赠品选择，不支持其他折扣方式选择；
  * POS付款自动填入金额：POS端结算时，选择收款方式，则自动填上整单的金额，若为否，则需要手工填写金额；
