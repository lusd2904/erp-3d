来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%9D%E5%A7%8B%E5%8C%96%E5%BF%AB%E9%80%9F

====== 1.功能说明 ======

在产品上线实施阶段，需录入上线前的基本基础资料，快速建设期初单据，【初始化快速引入】工具是在数据初始话阶段，帮助企业快速完成上线工作，提高企业实施效率。适应于企业版和标准版客户。
需要说明的是：在实施阶段做初始化数据引入功能的场景是不支持复杂单据的引入的，例如多单据体的单据是不支持用该功能引入的。

**功能路径**

【基础管理】→【实施平台】→【初始化数据快速引入】

====== 2.支持引入的业务对象有24个，其他单据不支持 ======

  * 基础资料：员工、业务员、部门、供应商、客户、物料
  * 期初单据：期初采购入库单、期初退料单、期初销售出库单、期初销售退货单、初始库存、期初应收单、期初其他应收单、期初收款单、期初收款退款单、期初应付单、期初其他应付单、期初付款单、期初付款退款单、科目初始数据、现金期初、银行存款期初、期初应收票据、期初应付票据

====== 3.操作步骤 ======

  * 1 选择引入对象--》2 选择引入模板--》3 选择数据状态--》4 字段映射（引入字段与星空字段）--》5 指定关键字段--》6 引入数据--》7 引入结果

======5.初始化快速引入设计原理======

将引入的模板字段与星空字段做映射，按映射关系引入数据，所以在映射字段之前，最关键的是弄清楚维护的Excel表中的字段与星空字段的关系。

映射规则：

  - 引入的字段名称与星空字段名称一样，则自动映射；
  - 名称不一样，则手动映射；
  - 提供智能映射功能：当映射过一次，下次再引入该对象时，会保存前一次的映射关系；
  - 一个系统字段只能映射一次，不允许重复映射;
  - 单据字段与字段间是携带关系的，只需要映射无携带关系的字段，被携带的字段无需映射，引入后，自动携带出来。如，单据上有物料代码和物料名称，只需对物料代码进行映射，无需对物料名称映射，引入后，自动携带出物料名称。

引入数据规则：

  - 按映射关系进行引入数据；
  - 引入数据时，提供引入对象后两种状态：暂存、保存；
  - 当选择按“暂存状态”引入，引入时，会已对引用基础资料、逻辑字段等进行基本的数据判断，无必录项要求，引入后，为暂存状态；
  - 当选择按“保存状态”引入，引入时，会按对象新增保存时进行判断，包含必录项的检测等，引入后，为保存状态。

## 【页面】实施平台信息
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AE%9E%E6%96%BD%E5%B9%B3%E5%8F%B0%E4%BF%A1%E6%81%AF

﻿====== 1 实施平台概述 ======

===== 1.1 实施平台概述 =====

快速实施，是决定项目交付成本的关键，也是金蝶云快速推向市场赢得客户的关键所在；而项目交付质量，往往决定了ERP产品的口碑。

实施平台的目的就在于：根据实施范围，动态为用户提供一个实施工作路线图，同时在每个实施任务节点提供相应的实施说明。引导用户按步骤来配置系统、导入初始化数据。

===== 1.2 系统特性=====

本系统主要包含以下特性：

  - 自助实施总工作台：通过自助实施一张图的看板形式展示当前系统各模块的实施完成进度，并指引用户通过自助学习各模块相关知识，逐步完成整个系统的实施初始化工作；
  - 用户权限实施指引工作台：用户可以通过工作台快速获取用户权限初始化相关知识，逐步熟悉用户权限实施内容，并按指引完成初始化；并且支持通过点击菜单直接打开相关功能，实现初始化菜单的集中管理。

====== 2 实施平台操作手册 ======

本章主要介绍自助实施工作台相关功能的操作步骤。

 

===== 2.1  使用流程 =====

为用户提供自助实施工作台，引导用户通过自助学习各模块相关知识，逐步完成整个系统的实施初始化工作。

## 【页面】用户权限实施指引工作台
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%94%A8%E6%88%B7%E6%9D%83%E9%99%90%E5%AE%9E%E6%96%BD%E6%8C%87%E5%BC%95%E5%B7%A5%E4%BD%9C%E5%8F%B0

====== 1.功能说明 ======

用户权限实施指引工作台，以任务列表的方式指引新用户学习用户权限视频课件、微课件、向导式课件以及相关知识，并逐步完成初始化工作。

**功能路径**

【基础管理】→【实施平台】→【自助实施工作台】→【用户权限实施指引工作台】

====== 2.操作说明 ======

用户通过点击每个任务后面的超链接，学习相关课件、知识或者调用相关初始化功能。

完成每个任务后，通过点击任务列表后面的【完成】按钮来标记相关任务的完成状态。

====== 3.其他说明 ======

该功能基于Html5技术开发，目前仅支持通过H5端登录后使用。

## 【页面】自助实施总工作台
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%87%AA%E5%8A%A9%E5%AE%9E%E6%96%BD%E6%80%BB%E5%B7%A5%E4%BD%9C%E5%8F%B0

====== 1.功能说明 ======

自助实施总工作台，通过自助实施一张图的看板形式展示当前系统各模块的实施完成进度，并指引用户通过自助学习各模块相关知识，逐步完成整个系统的实施初始化工作。

**功能路径**

【基础管理】→【实施平台】→【自助实施工作台】→【自助实施总工作台】

====== 2.操作说明 ======

用户通过自助实施总工作台查看各模块中子项完成情况以及模块整体完成进度；

点击右上角组织切换图标，可切换其他组织；

点击卡片下方【进入工作台】打开对应模块初始化指引工作台页面。

====== 3.其他说明 ======

该功能基于Html5技术开发，目前仅支持通过H5端登录后使用。
