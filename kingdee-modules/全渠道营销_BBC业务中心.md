======1 BBC全渠道营销概述 ======
=====1.1 BBC全渠道营销介绍说明=====
  * BBC全渠道营销在供应链的基础上，为帮助企业全方位的、高效的营销，实现产业链上下游的完整互动而规划的一个企业与外部客户的全渠道营销平台。
  * BBC全渠道营销可建立企业与经销商之间的业务往来通道，实现业务的快速协同。实现经销的快速订货、交货、经销商库存/内部渠道库存监控、销量统计。
  * BBC全渠道营销平台可独立安装部署使用，企业后台与其它ERP系统进行集成。

===== 2.7 网点管理=====
**2.7.1 网点管理概述**

企业在进行外部渠道营销业务（包括：分货、目标管理业务）时，参与业务的人员不一定都是员工，业务管控的层级关系与组织关系也不完全相同。因此，系统提供了一套全新的营销人员、营销网点、营销关系树的管理体系来支撑全渠道网点管理业务。
营销人员：为参与渠道营销业务的业务人员。
营销网点：为参与渠道营销业务的各个管控节点，营销人员在营销网点上进行工作。
营销关系树：为渠道营销业务的管控、分配关系，由营销网点通过建立具有上下级关系的树来实现。

===== 2.8 分货管理===== 

==== 2.8.1控制渠道可订货量业务概述 ====

企业在进行渠道的订货控制时，一般可选择四种方式：人工分货控制、自动计算控制、可用库存控制、不控制；

  * 人工分货控制：主要用于库存不足的商品，通过人工逐级分货实现。根据分货力度不同又可分为以下两种情况： 

 A）明细分货：主要适用于库存紧缺的畅销商品，需要人为根据商品的销量情况，由总公司向分公司、业务人员、渠道逐级分货，严格控制每个渠道的商品可订货量；

 B）总量分货：主要适用于库存较少的尾货商品，也需要人为控制渠道的可订货量，但仅需对某个管理单元下的所有渠道的订货总量作控制，没有必要控制每个渠道的订货量。

  * 自动计算控制：主要适用于库存充足的常规商品，无需人为分货，由系统根据渠道过往销量情况自动计算建议订货量及最大可订货量，建议并控制渠道进行订货。

  * 可用库存控制：适用于所有商品，根据可用库存控制渠道订货量；可用库存控制最大订货量和人工分货或自动计算控制最大订货量可以并行存在；

  * 不控制：主要适用于库存充足或渠道订货权限很大，无需控制其订货量的商品或渠道；

==== 2.8.2人工分货控制渠道可订货量 ====

=== 概述 ===

分货是指通过分货单根据分货树逐级向下级节点手工分货的功能；分货结果在启用“启用最大订货量控制”参数时用于控制渠道对商品的最大可订货量；

分货支持两种控制方式。一种是分细分货：逐级分货至渠道，精确控制每个渠道的可订货量；另一种是总量分货：分货至某个中间节点，对该节点下包括的渠道进行可订货总量控制；

人工分货主要应用在控制渠道对库存不足商品的可订货量；

==== 2.8.4不控制渠道可订货量 ====

**功能说明**

支持设置例外商品和例外渠道，被设置成例外的商品或渠道不管是否启用“启用最大订货量控制”参数，均不受分货或自动计算产生的渠道最大可订货量的控制；

**功能路径**

【营销】→【例外渠道设置】

【营销】→【例外商品设置】

**功能介绍**

例外商品设置：

1、建议订货不显示：设置订购该商品时是否显示建议订货量； 

2、最大订货量不控制：设置订购该商品时，其最大可订货量是否受分货或自动计算结果——“渠道商品可订货表”或“渠道订货总量控制表”的剩余订货量控制；

3、可用量不显示：设置订购该商品时是否显示库存可用量；

4、可用量不控制：设置订购该商品时，其量大可订货量是否受库存可用量的控制；

例外渠道设置：

1、建议订货不显示：设置该渠道订货时，是否显示商品的建议订货量；
 
2、最大订货量不控制：设置该渠道订货时，其最大可订货量是否受分货或自动计算结果——“渠道商品可订货表”或“渠道订货总量控制表”的剩余订货量控制；

3、可用量不显示：设置渠道订货时，是否显示库存可用量；

4、可用量不控制：设置渠道订货时，其最大可订货量是否受库存可用量的控制；

## 【页面】bbc公告管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=bbc%E5%85%AC%E5%91%8A%E7%AE%A1%E7%90%86

**功能说明：**

用于企业或渠道商做宣传、发布公司新闻、促销活动、服务信息等。

**功能路径：**

【B2B】->【公告】->【公告列表】

**使用前提：**

所属渠道为企业或直接渠道允许发布

**字段说明：**
| **字段**   | **字段说明**                              |
| 基本信息                                            ||
| 公告编码     | 系统按一定规则自动生成的编码                        |
| 公告主题     | 必填；显示在前台公告的标题                         |
| 公告状态     | 取值范围包括：创建、已保存、已提交、已审核、重新审核、已发布、取消发布；  |
| :::      | 根据不同的状态会有不同的处理结果                      |
| 公告分类     | 关联公告分类表                               |
| :::      | 可以新增、删除、编辑相关分类                        |
| 发布日期     | 默认系统当前日期                              |
| 详细介绍                                            ||
| 详细介绍     | 公告内容的详细介绍说明                           |
| :::      | 支持上传图片说明、支持上传附件                       |
| 发布信息                                            ||
| 发布B2C用户  | 勾选后公告将发布给B2C商城用户                      |
| 发布B2B用户  | 勾选后公告将发布给B2B所有门户用户                      |
| 序号       | 系统自动生成流水号                             |
| 渠道类型编码   | 关联渠道类型表，F8浏览选择                        |
| :::      | 根据选择的渠道类型编码，发布给不同的渠道                  |
| 渠道类型名称   | 关联渠道类型表，F8浏览选择                        |
| :::      | 根据选择的渠道类型编码，系统自动携带                    |
| 创建人      | 根据创建时的登录用户，系统自动记录                     |
| 创建时间     | 根据创建时的系统时间，系统自动记录                     |
| 发布人      | 根据发布时的登录用户，系统自动记录                     |

	
**操作说明：**
  - 新增公告：进入公告列表，点击【新增】按钮即跳转至公告新增页面。填写相关信息
  - 发布公告：新增的公告默认是未发布，需要手工点击发布。发布后，对应的发布渠道BBC商城前台可查看到公告。公告的发布日期为点击发布后取的系统即时日期；
  - 取消发布：会将发布状态置为否，对应的发布渠道BBC商城前台将不再看见公告；
  - 删除：只有未发布的公告才允许删除，已发布的公告删除时提示【发布中的公告不允许删除】并删除失败；
  - 查看公告：在公告列表里选择对应的公告双击即可查看公告详情

## 【页面】分货单分货
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%86%E8%B4%A7%E5%8D%95%E5%88%86%E8%B4%A7

====== 分货单——分货 ======

===== 功能说明 =====

通过分货单进行人工明细或总量分货；

明细分货：即通过分货单按营销关系树结构逐层分货至营销关系树的末级节点（渠道），严格控制每个渠道的商品可订货量；

总量分货：即通过分货单对某个节点下的所有渠道的订货总量进行总量控制；

===== 功能路径 =====

【BBC业务中心】→【营销】→【分货单】

===== 使用前提 =====

分货体系管理政策

===== 字段说明 =====

**基本信息：**

^ 字段名称    ^ 说明                                                                                                           ^
| 单据编码    | 通过编码规则自动生成；唯一；                                                                                               |
| 单据类型    | 分货单，不可编辑；                                                                                                    |
| 单据日期    | 分货的日期，不可编辑；                                                                                                  |
| 关联管理政策  | 取值范围为：所有已启用的管理体系为分货体系的管理政策；不可编辑；                                                                             |
| 营销关系树   | 根据关联管理政策默认携带，不可编辑；                                                                                           |
| 分货营销网点  | 由用户在创建分货单时选择营销关系树中的一个节点作为分货业务发的起的网点；一般选择顶级节点开始分货，也可以从中间节点开始分货；\\ 用户只能选到他作为营销人员的营销关系树节点，即用户只能在他负责的节点下面创建分货单；  |
| 分货状态    | 取值范围为：待下达，已下达；不可编辑；                                                                                          |

**明细信息：**

^ 商品编码      ^ 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        ^
| 商品名称      | 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        |
| 规格型号      | 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        |
| SKU编码     | 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        |
| SKU名称     | 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        |
| 订货单位      | 根据管理政策携带分货商品分类下的所有商品，不可编辑；                                                        |
| 总量控制      | 默认为否，不可编辑；                                                                        |
| 可分配数量     | 如果是顶级分货单，由用户手工编辑，支持批量导入；\\ 如果不是顶级分货单，不可编辑；                                        |
| 已分配数量     | 由系统自动汇总按商品分货操作下分给各下级节点的分货数量，不可编辑；                                                 |

| 回收状态      | 取值范围：未回收，已回收；默认为未回收；                                                              |

**按商品分货信息：**

^ 字段名称    ^ 说明                              ^
| 目标营销网点  | 根据管理政策携带政策内定义的当前网点的所有下级网点；      |
| 分货比例    | 根据网点取对应的分货比例值；                  |
| 分配数量    | 由用户手工输入分配数量或者根据分货比例计算分配数量；      |
| 是否总量控制  | 表示是否对这个节点下的渠道订货进行总量控制；默认为否；     |
| 渠道销量    | 如果目标营销网点为渠道，则显示渠道的平均销量作为分货的参考；  |
| 分货等级    | 如果目标营销网点为渠道，则显示渠道的分货等级作为分货的参考；  |

| 关联分货单  | 顶级分货单默认为空，下达分货单携带上级分货单编号为值；  |

===== 操作说明 =====

**明细分货操作步骤：**

1）创建分货单：在起始分货的营销关系树节点上创建分货单；

2）按商品分货：按商品逐一分货至下级网点，直至所有商品的可分配数量＝已分配数量；

3）下达：下达分货，自动生成下级网点的分货单；

4）下级网点的营销人员进入分货单管理界面可以看到他作为营销人员所在网点的分货单；

5）下级网点的营销人员重复2，3步骤分货，继续下达生成下级网点分货单。

6）持续重复2，3，4，5步骤，直到分货单中的下级分货网点为最末级的叶子节点（渠道），下达时不再生成分货单，而是将叶子节点（渠道）的分货结果（分货量）生成“渠道商品可订货表”；

**总量分货操作步骤：**

1）创建分货单：在起始分货的营销关系树节点上创建分货单；

2）按商品分货：按商品逐一分货至下级网点，直至所有商品的可分配数量＝已分配数量；

在“按商品分货”操作界面，可以选择对某个下级网点启用“总量控制”；

3）下达：下达分货，对于启用了“总量控制”的下级网点，不再生成它的分货单，而是将分货结果生成“渠道订货总量控制表”；对于未启用“总量控制”的下级网点，则继续生成它的下级分货单；

4）下级网点的营销人员进入分货单管理界面可以看到他作为营销人员所在网点的分货单；

5）下级网点的营销人员重复2，3步骤分货，在分货单的编辑界面，营销人员可以看见上级网点分货时已经对哪些商品作了总量控制，哪些没有作总理控制；对于已作总量控制的商品，不需要再继续分货，且不会继续生成下级网点的分货单；对于未作总量控制的商品，则会继续生成下级网点的分货单；

6）持续重复2，3，4，5步骤，直到分货单中的下级分货网点为最末级的叶子节点（渠道），下达时不再生成分货单，而是将叶子节点（渠道）的分货结果（分货量）生成“渠道商品可订货表”；

**注：**从总量分货操作步骤可以看出，总量分货和明细分货是可以同时存在的，可以选择对部分商品部分网点进行总量分货控制；

## 【页面】分货单回收分货
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%86%E8%B4%A7%E5%8D%95%E5%9B%9E%E6%94%B6%E5%88%86%E8%B4%A7

====== 回收分货 ======

**功能说明**

第一次分货后，如果渠道没有订完，企业可以将分货数量回收，再分给其它渠道订货订货；

**功能路径**

【BBC业务中心】→【营销】→【分货单】

**使用前提**

第一次分货及订货结束；

**功能特性**

支持整单回收和按商品回收；

回收之后，在分货单中能看见本次回收操作回收的数量，回收的数量等于当前分货结果表中这个商品在当前分货节点下的所有末级节点未订购完的数量之和；被回收的商品，渠道将不可以再订购此商品，直至再次分货给它；

支持携带回收数量进行二次分货；

对于总量控制的商品需要到设置总量控制的节点分货单进行回收；

1、在【BBC业务中心】→【商品】→【商品分类标准】中定义一个专门用于分货的商品分类标准（如：分货用商品分类）；

2、在【BBC业务中心】→【商品】→【商品分类】中定义分货用的商品分类标准（如：分货用商品分类）下具体的分类内容；

3、在【BBC业务中心】→【商品】→【平台商品分类】中定义分货管理业务将要应用的商品分类标准（即第1步在【商品分类标准】中定义的分类标准）；这里也可以直接选择其它已存在的分类标准（如：主分类等），如果选择其它已存在分类标准，则可跳过第1，2步；

**操作说明**

新增：通过新增操作在分货商品分类下添加商品，只能在叶子节点下添加商品；

删除：通过删除操作在分货商品分类

禁用：禁用分货商品分类下的商品，被禁用的商品不能参与分货；

启用：启用分货商品分类下的商品，启用的商品才能参与分货；

用于维护管理参与渠道营销业务的各个节点（营销网点）的档案资料；例如：处理总公司向分公司，向业务员，最后到门店层层分货业务时，总公司、分公司、业务员、门店就是营销网点，必须定义它的网点档案；

营销网点只是一个管控节点，并不具体处理业务，网点档案下必须维护营销人员，营销人员才是具体处理业务的操作员；

**2、功能路径**

禁用：禁用营销网点，营销网点的启用状态变成“已禁用”，营销网点不可以被其它业务引用，且不能编辑；

更新网点组织：如果生成营销网点的渠道或者营销人员的所属组织发生了变化，可以通过更新网点组织操作更新最新的网点对应组织信息；

## 【页面】营销关系树
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%90%A5%E9%94%80%E5%85%B3%E7%B3%BB%E6%A0%91

====== 营销关系树 ======

**1、功能概述**

渠道营销业务一般是按一定的层级关系进行的。如：从总公司到分公司、业务人员，最后到门店层层进行分货或销售目标分解，这种层次关系就是一棵树；

本功能即用于定义营销关系树的树结构。组成树的节点为营销网点，每个树节点上需指定具体负责业务的营销人员；

**2、功能路径**

【BBC业务中心】→【网点】→【营销关系树】

**3、使用前提**

营销人员、营销网点、关系树类型；

**4、字段说明**

^ 字段名称        ^ 说明                                         ^
| 关系树类型       | 根据当前选中的营销关系树类型取值；                          |
| 节点编码        | 根据规则自动编码，唯一；                               |
| 网点编码        | 当前节点对应的营销网点编码值；                            |
| 网点名称        | 根据网点编码携带；                                  |
| 网点类型        | 根据网点编码携带；                                  |
| 网点对应渠道是否门店  | 根据网店对应渠道是否是门店取值；                           |
| 上级节点编码      | 当前节点所属的上级节点编码；                             |
| 上级网点编码      | 上级节点对应的营销网点编码值；                            |
| 上级网点名称      | 根据上级网点编码携带；                                |
| 营销人员        | 通过修改营销人员操作选择这个节点的营销人员，只能在营销网点下维护的营销人员内选择；  |
| 叶子节点        | 根据当前节点是否是叶子节点取值；                           |
| 层级          | 当前节点在整棵树中所属的层次，顶级节点为1级；                    |

**5、操作说明**

增加节点：用于新增树节点；

删除节点：用于删除选中的树节点及其所有下级节点；

移动节点：用于将某个树节点及其所有下级节点移动到另外一个树节点下。一般在营销组织上下级关系大幅调整时会用到；

替换节点：用一个新的营销网点替换某个树节点所引用的原有营销网点。一般在树结构不变，但是树节点上引用的营销网点产生变化时会用到，如：某个营销经理的离职，暂由分公司接管他的业务，等待新人到岗再转手，只需先将营销经理的营销网点替换成分公司的营销网点，等到新人到岗再替换回去；

修改营销人员：用于修改树节点上负责业务的营销人员。如果树节点上负责业务的人员变了（离职或调岗），可以使用修改营销人员进行修改；

上级下关系查询：针对某个节点查询它的上下级；

分货树检查：检查某棵树是否合法，是否符合分货业务。不合法的数据会在检查结果中提示出来，由用户根据实际情况删除不合法数据；

导入：支持导入EXCEL建树，在EXCEL中的维护数据时，上级节点必须在下级节点的前面，否则导入会报错；

导入模板：导出用来导入营销关系树的EXCEL模板；

导出数据：导出营销关系树结构至EXCEL文件；不选中节点的导出表示导出整棵树；

====== 分货结果对订货的控制 ======

**功能说明**

通过分货单分货后，分货结果可用于进行渠道的订货控制；

**功能路径**

【BBC分销商门户】→【采购订货】

**使用前提**

启用参数“启用最大订货量控制”、“启用建议订货量查询”；

启用建议订货量查询：启用此参数仅表示渠道在BBC经销量平台订货时能看见商品的建议订货量，对实际订货数量不作控制；

启用最大订货量控制：启用此参数表示渠道在BBC经销量平台订货时，可订货量受到“渠道商品可订货表”、“渠道订货总量控制表”中的记录的剩余订货量控制，不允许超出剩余订货量；

**操作说明**

渠道用户在BBC分销商门户进行采购订货时，如果启用参数“启用最大订货量控制”、“启用建议订货量查询”，则其订货量受到分货数量的控制；

从【BBC业务中心】→【分析】→【渠道商品可订货表】/【渠道订货总量控制表】中可以查询可订货数量、剩余订货数量和累计订货数量；

**注：**【渠道商品可订货表】、【渠道订货总量控制表】中分货结果对采购订货控制的有效期并不等于表中的日期，而是日期前一天的15：00之后至日期当天的15：00之前；例如：2018年7月10日的分货结果，可用于控制2018年7月9日15：00之后至2018年7月10日15：00之前的采购订货量；

  *    自定义时间：开始日期、结束日期
 开始日期：默认为当月第一天
 
 结束日期：默认当前日期。
  *   今年以来：从当前年度的1月1日；
  *   最近1年：当前日期倒退1年，如当前日期是2016-11-16，则最近一年，的时间范围是2015-11-17~2016-11-16。
  *   本周：从星期天开始到当天；
  *   今天：系统当天日期
 
**操作说明：**
  - 进入门店销售金额排名表，默认显示数据为本周销售数据；
  - 选择排名方式，可支持按金额排名或按数据排名显示
  - 筛选：查看不同的需求数据可以根据筛选条件进行过滤查询，点击相应筛选条件则可直接查询显示出相关数据；
  - 自定义条件：如果页面所列筛选条件满足不了需求，可以打开自定义条件，转入自定义开始日期和结束日期，点击【确认】后可直接查询显示出相关数据；

## 【页面】首页设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A6%96%E9%A1%B5%E8%AE%BE%E7%BD%AE

**功能说明：**
实现商城门店首页的个性化设置，目前仅支持设置广告轮播图片的修改

**功能路径：**
【B2B】—>【BBC电商门户】—>【首页设置】

**使用前提：**
无

**字段说明：**
| **名称**  | **字段说明**                       |
| 模版编码    | 系统预置，不可修改                      |
| 模版名称    | 系统预置，不可修改                      |
| 门户类型    | 系统预置，不可修改                      |
| :::     | 包含：直接渠道门户、间接渠道门户、终端门店门户、B2C门户  |

| 模板状态    | 默认为‘是’                         |

**操作说明：**

  -   进入首页，双点击选择需要设置的门户类型进入编辑页面
  -  点击【新增行】或【删除行】或【+】或【-】进行对广告图片轮播的新增、删除操作，上传图片支持网络图片或本地图片
