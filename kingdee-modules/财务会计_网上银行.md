## 【页面】人民币交易种类
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BA%BA%E6%B0%91%E5%B8%81%E4%BA%A4%E6%98%93%E7%A7%8D%E7%B1%BB

=====人民币交易种类=====
=====1 功能说明=====    
想在系统中完成境外支付业务，需先维护基础资料——人民币交易种类。如不涉及境外支付，则无需维护。

付款单、收款退款单、付款结算单勾选境外支付，需在单据上选择填写此基础资料。提交银行时会传给银企

=====2 功能路径====

【财务会计】—>【网上银行】—>【系统设置】—>【人民币交易种类】

=====3 字段说明====

| **字段**         || **说明**                                                       |
| 交易种类代码          ||需与银行定义的交易种类代码保持一致                     |
| 交易种类名称         ||需与银行定义的交易种类名称保持一致                                        |
| 描述         ||文本，可录入交易种类的银行、适用币别等，便于区分。                                           |
| 人民币交易种类         ||交易种类是否适用人民币业务。可选是、否                                             |

## 【页面】接收银行交易明细单据
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8E%A5%E6%94%B6%E9%93%B6%E8%A1%8C%E4%BA%A4%E6%98%93%E6%98%8E%E7%BB%86%E5%8D%95%E6%8D%AE

====== 接收银行交易明细 ======
=====1 功能说明 =====
  * 企业可以通过银企下载网银所有交易明细（包括银行代扣付款记录和银企平台发起的付款记录）。
  * 支持同步非网银账号银行对账单生成交易明细。
  * 支持自动匹配不同业务类型生成对应业务单据。

=====2 过滤条件 =====

在“快捷”页签，用户设置需要查询的账号、币别以及日期范围，选择需要查询的交易明细，即可进行已下载的交易明细的查询。

快捷页签主要过滤项目说明 

| **过滤项**     || **说明**                        |
| 币别          || 交易明细对应的币别。                    |
| 开始日期        || 日期范围的起始日期。                    |
| 结束日期        || 日期范围的结束日期。                    |
| 交易类型        || 可以只查询收入明细或者支出明细，也可以查询全部交易明细。  |


=====3 下载交易明细 =====

如果需要下载新增的交易明细，可以点击下载交易明细按钮，选择需要下载的账号、币别等信息进行下载，已经下载的交易明细不会重复下载。

=====4 同步银行存款对账单 =====

系统支持同步银行存款对账单生成交易明细。


=====5 自动匹配 =====

点击自动匹配会弹出自动匹配选择窗口，根据选择的对方单位类型和对方单位匹配规则去自动匹配对方单位类型、对方单位和业务类型。

=====6 手工确认 =====

|**字段**||**说明**|
|收付组织||交易明细对应的收付款组织。|
|结算组织||交易明细对应的结算组织。|
|业务类型||自定义收付款业务类型。|
|往来单位类型||交易明细对应的往来单位类型。|
|往来单位||交易明细对应的往来单位。|
|结算方式||交易明细的结算方式。|
|收付款用途||自定义收付款用途。|

=====7 生成单据 =====

确认了交易明细的业务组织，往来单位、收付款用途等信息时，点击“生成单据”按钮，会生成业务单据，并反写单据编号到交易明细中。

=====8 银企付款 =====

如果是用业务单据提交银企付款或者是不想用该付款类的交易明细生成业务单据，可以选中交易明细，点击“银企付款”，即可对交易明细进行标记，不允许下推业务单据。

=====9 关联查询 =====

支持通过交易明细联查业务单据。

====== 智能登账设置 ======
=====1 功能说明 =====

通过自动接收银行设置实现自动下载收款记录生成收款单据。

=====2 操作前提 =====

已经进行了银企互联设置并且已经测试通过，自动接收银行收款记录执行计划启用。

=====3 功能路径 =====

【财务会计】—>【网上银行】—>【系统设置】—>【自动接收银行收款记录设置】

=====4 字段说明 =====
====4.1 表头字段说明 ====

|**字段**||**说明**|
|方案编码||自动上划方案的编码，手工录入或者自动获取。|
|方案名称||自动上划方案的名称，手工录入。|
|收款组织||生成收款单的收款组织，手工录入。|
|币别||选择对应的币别信息。|
|单据状态||定义生成收款单的单据状态，系统支持暂存、创建和已审核三种状态。|
|执行人||定义接收收款的执行人，手工录入。|
|结算方式||生成收款单的的结算方式，手工录入。|
|摘要||摘要信息，手工录入。|



====4.2 表体字段说明 ====

| **字段**|| **说明**|
| 银行账号|| 选择需要自动接收收款的银行账号|
| 单据类型|| 选择生成收款单按的单据类型，可选销售收款单、其他业务收款单和收款结算单|
| 往来单位类型|| 如果单据类型是销售收款，往来单位类型锁定为客户；\\ 如果是其他业务收款，可选员工、客户、供应商、其他往来单位、组织机构等。|
| 往来单位|| 可选按对应银行账号匹配或者对方户名匹配 |
| 收款用途|| 如果单据类型是销售收款，可选销售业务类型的收付款用途；\\ 如果是其他业务收款，可选 其他业务类型的收款用途|
| 结算组织|| 生成收款单的结算组织|
| 开始日期|| 录入自动接收银行收款的记录的开始日期|



=====5 操作说明 =====

手工执行可以根据方案接收银行收款生成收款单。

====== 电子回单 ======
=====1 功能说明 =====
  * 是企业所有通过银企互联方式直接下载的电子回单的留档。
  * 为了用户操作简便，系统支持下载、查询、打印电子回单。
  * 用户可以通过电子回单匹配交易明细和业务单据。

=====2 操作前提 =====

已经进行了银企互联设置并且已经测试通过。

=====3 功能路径 =====

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单】

=====4 字段说明 =====
| **字段**       || **说明**            |
| 单据编号         || 自动生成电子回单的单据编号。    |
| 业务单据类型       || 匹配到的业务单据的类型。      |
| 业务单据编号       || 匹配到的业务单据编号。       |
| 业务参考号        || 交易流水里的业务参考号。      |
| 币别           || 电子回单币别。           |
| 银行           || 银行账号对应的银行。        |
| 银行账号         || 电子回单要下载的银行账号。     |
| 银行账户名称       || 银行账号对应的账户名称。      |
| 借方（付款）金额     || 电子回单上的付款金额。       |
| 贷方（收款）金额     || 电子回单上的收款金额。       |
| 金额           || 付款金额减去收款金额。       |
| 电子回单编号       || 下载到的电子回单的编号。      |
| 交易流水号        || 匹配成功的交易明细的流水号。    |
| 关联标记         || 银企传值，与交易明细做匹配用。   |
| 验证码          || 电子回单验证码。          |
| KD标识         || 通过银企付款的单据会有KD标识。  |

=====5 操作说明 =====

电子对账单与银行系统进行交互的业务操作，详细说明如下：

【财务会计】—>【网上银行】—>【日常处理】—>【电子回单】—>【下载银行对账单】，下载所需要日期范围的银行电子回单。

也支持通过“执行计划列表”中的“自动下载电子回单”任务，定时自动下载电子回单。

====== 网上银行 ======
=====1 网上银行系统概述 =====

====1.1 网上银行系统概述 ====
网上银行是通过金蝶BOS银企平台以实现企业ERP系统与商业银行系统直联应用的子系统。网上银行系统支持企业用户直接在ERP系统中把付款指令提交到银行系统，直接在ERP系统中下载银行电子对账单，以及在ERP系统中直接查询银行账户余额以及银行账户交易明细。

====1.2 网上银行系统总体流程====
[图:wb_网上银行系统总体流程.png]
====1.3 系统特性 ====

  * 本系统主要包含以下应用：
  * 支持国内一百多家银行的银企直联，以及与支付宝的直联。
  * 目前支持境内人民币支付业务以及中行、浦发、汇丰、渣打、中银香港、花旗、恒生银行的境内外币支付业务，不支持境外支付和跨境支付。
  * 支持付款单提交银行付款。 
  * 支持收款退款单提交银行付款。
  * 支持银行转账单提交银行付款。 
  * 提交银行时支持第三方消息验证
  * 支持付款单、收款退款单以及银行转账单同步银行交易状态。
  * 支持下载银行电子对账单。
  * 支持下载电子回单。
  * 支持查询银行账户余额。
  * 支持查询银行账户交易明细。
  * 支持下载交易明细生成业务单据。

====== 银行付款单 ======
=====1 功能说明 =====

  * 是企业所有通过银企互联方式提交银行进行付款的付款请求的留档。
  * 为了用户操作简便，系统不需要切换到银行付款单界面提交银行付款，而是直接在出纳系统选择相应的付款单、收款退款单或者银行转账单后提交银行付款即可。系统会自动同步产生相应的银行付款单，并直接将银行付款单提交银行进行付款处理。
  * 用户可以通过银行付款单查询所有提交银行的付款请求，以及这些付款请求提交或者被撤销的痕迹。

=====2 操作前提 =====

=====5 操作说明 =====

银行付款单与银行系统进行交互的业务操作，均在出纳系统，银行付款单由系统根据出纳系统相关单据的提交银行动作自动产生，并自动提交银行进行付款。因此银行付款单本身只是出纳系统付款请求的留档文件，供查询。

银行付款单与银行系统进行交互的业务操作，详细说明如下：

1、【财务会计】—>【出纳管理】—>【日常处理】—>【付款单】—>【业务操作】—>【提交银行】，选择相应的付款单提交银行付款。

2、【财务会计】—>【出纳管理】—>【日常处理】—>【付款单】—>【业务操作】—>【撤销提交】，选择已经提交银行但银行交易未成功的付款单撤销提交。

3、【财务会计】—>【出纳管理】—>【日常处理】—>【付款单】—>【业务操作】—>【同步银行状态】，同步付款单的银行处理状态。

=====银行网点 =====

银行网点基础资料支持手工新增、同步云端网点信息、同步银企网点信息。

1、手工新增：根据相关人员提供的网点信息，新增银行网点基础资料，填写相关信息；

2、同步云端网点信息：无需购买EAS银企平台，能连接外网即可同步云端网点信息。云端网点信息来源于某商业银行提供的网点信息，每天更新一次；

3、同步银企网点信息：必须购买EAS银企平台并在银企平台中维护好网点信息后，才能同步到金蝶AI星空。
