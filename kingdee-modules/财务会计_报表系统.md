====== 净值重分类方案 ====== 

**功能说明**

设置报表项目需要根据不同科目相加减后的结果进行重分类的计算公式，比如合同负债与合同资产、递延所得税负债与递延所得税资产、应收账款与应付账款的重分类。

**功能路径**

【财务会计】→【报表】→【基础资料】→【净值重分类】

**操作说明**

查阅社区知识https://vip.kingdee.com/article/210422588345247744

## 【页面】报表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8A%A5%E8%A1%A8

====== 报表 ====== 

**功能说明**

报表模板制作完成，我们可以开始选择模板制作报表。

**功能路径**

【财务会计】→【报表】→【报表管理】→【报表编制】

===== 报表制作 ===== 

用于管理和分析的报表都需要有完整的数据。根据模板建好的报表是没有数据的，这就需要完成报表的取数过程。

还是以报表模板管理中提到的利润表为例，简单介绍如何利用报表编辑器来完成报表的取数过程。

**设置取数参数**

在新建报表时我们已经设置了一些属性参数：取数账簿、币别、年度、期间。

我们也可以通过【公式取数参数】来指定参数。具体参见报表业务处理中的【公式取数参数】的操作说明。

公式中的参数在取数过程中的优先级：先单元格定义的参数，再公式取数参数中定义的参数，最后才是报表属性中的参数。

**设置报表取数公式**

用于编制报表的模板如果没有预设取数公式，那么我们还需要在编制报表时单独完成取数公式的设置。

如上述提到的利润表，该表中的数据一般情况下来自总账，所以我们可以通过总账取数公式ACCT进行取数。具体操作参见报表取数公式。

**报表重算**

系统提供了【重算表页】、【全部重算】功能用于报表数据的取数。只需单击操作，系统会根据定义好的取数公式以及公式参数进行取数。

===== 报表管理 ===== 

报表制作完成，可以对其进行查看、修改、删除、检查、审核、禁用、检查等操作。这些操作与报表模板中的类似，可参见报表模板管理。

其中报表检查，可参见报表业务处理中的报表检查功能说明。

报表列表功能路径：

WEB界面：【财务会计】－>【报表】－>【报表管理】－>【报表列表】

登录财务报表平台后：【文件】菜单－>【打开】－>【报表】

工具栏菜单中【打开】－>【报表】

按照上述路径都可以进入报表列表。

## 【页面】报表业务处理

====== 报表批量填充向导 ====== 

此功能暂时适用于报表模板、分析报表。

单击【批量填充向导】，系统提供模板样式方案列表供选择，选择具体的模板样式方案进行填充。

如果需要填充ACCT取数公式，还得有个前提，就是需要在报表项目中设置好对应的关联科目。

单击【填充】，系统开始自动填充项目公式和取数公式到报表模板上。

单击【完成】，系统开始自动填充项目公式和取数公式到报表模板上。

 ====== 维度值填充 ======

在“维度值填充”界面，根据模板样式方案中已确定的报告维度，选择具体的维度值；

注意：本界面受当前模板样式方案中【维度值允许手工录入】选项影响。

如需要通过ACCT取数公式获取报表数据，则维度值应直接从系统中选取。

在“维度值填充”界面完成维度值相关设置后，【确定】，系统自动完成所选维度值信息以及单元格取数公式、单元格ITEM公式的填充。

 ====== 取数公式检查 ======

检查当前报表的所有表页的取数公式合法性，Excel公式如：IF、SUM，COUNT等不参与检查。

^ 公式合法性             ^
| 公式完整且可被系统解析       |
| 公式参数长度小于等于4000字符  |
| 取数公式间必须存在运算符号     |
| 公式核算维度编码必须正确      |
| 公式必录项不能为空         |
| 公式参数个数必须与公式定义一致   |
| 公式参数格式必须与基础资料一致   |
| 公式参数不能存在空格        |

 ====== 设置页签取数参数（表页） ======

在报表客户端中，左下角选中某表页页签→【右键】→在右键菜单中选择【页签取数参数】，设置仅用于当前表页的取数参数。当表页设置了“页签设置参数”，则当前表页页签背景色将特殊显示（深红色）。

页签取数参数设置中，提供了公用参数以及核算维度相关参数选项设置，具体详见【公式取数参数】。

当需要取消页签取数参数设置时，请【恢复原始设置】。

**取数参数设置，对报表重算取数的影响：**

报表单元格取数公式重算时，第一优先级以单元格取数公式参数设置为准。当单元格取数公式参数为空时，取表页取数参数设置。当表页取数参数未设置时，取报表的公式取数参数设置。当报表的公式取数参数未设置时，取报表的相应属性。


 ====== 表内勾稽关系设置 ======

表内勾稽关系设置这个功能是针对具体的报表来设置一些报表内的检查关系。

用于对报表内数据的正确性检查。

这个功能对报表模板、报表、自定义报表均适用。

表内勾稽关系的设置方法如下：单击【工具】→【表内勾稽关系设置】，在“表内勾稽关系”界面中针对不同表页设置不同的表内勾稽关系。

举例说明如下：如建立一张资产负债表，通常资产负债表有个最基本的表内勾稽关系：资产=负债+所有者权益。我们就可以对资产负债表设置这个勾稽关系。

1）“报表及表页”栏列示当前报表名及当前报表中所有的表页；

2）选中需要设置表内勾稽关系的表页，单击【新增】，在“表内勾稽关系新增”页签中填入设置的勾稽关系；

3）在“显示信息”中填入当表内勾稽关系不满足时显示的信息；

4）单击【确定】，即完成一个表内勾稽关系设置；

5）如果属于报表数据正确性检查的提示，需要在报表保存时即检查，可以选择上“报表保存时即检查”的选项，这样在保存报表时，会利用表内检查公式对报表数据进行检查，如果有错会立即给与提示；

6）当需要修改表内勾稽关系时，选中需要修改的记录，单击【修改】，即可进行修改；

7）当需要删除表内勾稽关系时，选中需要删除的记录，单击【删除】，即可进行删除。

 ====== 舍位平衡 ======

以“元”为单位编制的报表，由于报告对象的不同，可能需要转换为以“千元”或“万元”为单位的报表。报表经舍位后，重新调整平衡关系的公式称为舍位平衡公式。

【工具】→【舍位平衡设置】。设置舍位平衡公式。在报表模板中设置的舍位平衡设置，将自动携带到报表中。

【工具】→【舍位平衡】。系统根据舍位平衡设置，执行报表舍位平衡，生成舍位平衡报表。


^  字段       ^^  说明                                                                                                            ^  设置适用范围    ^
| 金额单位      || 设置转换的目标金额单位                                                                                                    | 所有表页       |
| 小数位数      || 根据目标金额单位与“元”的转换公式，转换后的单元格数值，需要保留到小数点后几位                                                                        | 所有表页       |
| 平衡公式      || 设置单元格平衡公式。\\ 如：现金流量表中“经营活动现金流入小计”，应该等于“销售商品、提供劳务收到的现金”、“收到的税费返还”、“收到其他与经营活动有关的现金”之和。                           | 当前表页/所选表页  |
| 选项        || 【只对存在ITEM公式的单元格进行舍位平衡】：对存在ITEM公式的单元格，进行舍位平衡操作。\\ 【除ITEM公式外，只对未锁定的单元格进行舍位平衡】：除ITEM公式单元格以及锁定的单元格外，其他单元格都参与舍位平衡。  | 所有表页       |



 ====== 使用新模板 ======

【使用新模板】功能只适用于报表，当前报表对应的模板发生变化时，如果不想重新新建报表，可以使用【工具】→【使用新模板】功能，单击【使用新模板】，系统会将报表对应的最新模板内容更新至报表内容中。
 ====== 报表计算 ======

在【数据】菜单中提供两种报表计算模式：【自动计算】和【手动计算】。计算模式只适用于报表和自定义报表。如果选择选择自动计算模式，则当报表中的数据或是公式发生变动时，系统将自动进行报表的重新计算；如果选择手工计算模式，则当报表中的数据或是公式发生变动时，需要选择【数据】→【重算表页】或【全部重算】，对报表进行重新计算，报表数据才会改变。单击【重算表页】，系统将只对当前表页进行重算操作。单击【全部重算】，系统将对当前报表所有表页进行重算。选择【数据】→【终止计算】，可以将正在计算中的报表强行终止计算。 

 ====== 报表检查 ======

报表检查，包括：表内勾稽关系检查和报表项目勾稽关系检查。

其中，表内勾稽关系检查，适用于报表和分析报表的检查。而报表项目勾稽关系检查，仅适用于报表。

在报表编辑器中的【审阅】菜单中以及WEB界面列表功能中，都有提供检查功能入口。

【审阅】菜单→【报表检查】→【表内勾稽关系检查】

检查表内勾稽关系。

系统根据当前报表中设置的表内勾稽关系对报表进行检查。若没有设置表内勾稽关系或表内勾稽关系全部通过，系统将给出检查通过的提示。若表内勾稽关系未全部通过，系统将给出检查结果，检查结果内容显示的是不通过表页的勾稽关系及不通过提示信息。将光标定位至勾稽关系表达式，系统能将光标定位至错单元格，方便查找错误原因。

【审阅】菜单→【报表检查】→【报表项目勾稽关系检查】

检查报表项目勾稽关系。

系统根据分配到当前组织的报表项目勾稽关系，以及当前报表中各单元格项目公式所涉及的报表项目勾稽关系，进行报表中报表项目数据的检查。

若勾稽关系全部通过，系统将给出检查通过的提示。若勾稽关系未全部通过，系统将给出检查结果，检查结果内容显示的是不通过表页的勾稽关系及不通过提示信息。将光标定位至勾稽关系表达式，系统能将光标定位至错单元格，方便查找错误原因。

【审阅】菜单→【报表检查】→【全部检查】

检查表内勾稽关系、报表项目勾稽关系。

| 比较分析         || 与指定基期比较      || 分析表会在分析列前增加一列【与指定基期比较】，取选项中指定基期期间的数据；\\ 在分析列后增加【本期金额】列，取选项中设置的期间数；\\ 后续增加【趋势%】列，取本期金额/指定基期数的百分比；\\ 后续增加【增减额】列，取本期金额-指定基期数的值；\\ 后续增加【增减%】，取增减额/指定基期数的百分比       |

由于报表分析是由后台插入报表公式计算所得，新建单独的页签，如果在报表未审核状态下执行【报表分析】且保存，则会保存此页签，且不能删除，建议在报表已审核的状态下执行【报表分析】，所得数据如果需要保存，可以导出至EXCEL。

## 【页面】报表参数设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8A%A5%E8%A1%A8%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE

===== 报表参数设置 =====

**功能说明** 

**数据权限控制**

选择【启用数据授权】，才可以进行数据授权设置，可以分核算体系设置。

通过新增数据授权方案，对角色设置拥有哪些报表模板的权限，从而间接控制到拥有哪些报表的数据权限。

报表数据权限需要配合报表功能权限一起使用。如：有报表新增权限，但不具A报表模板的权限，则该用户在新增报表时选择不至A报表模板。 

**报表打开方式**

选择【启用多窗口打开报表】，则打开多个报表时，为多个窗口，一般在核对数据时使用。

**报表编制控制**

选择【主账簿未结账，禁止提交报表】，则报表期间处于主账簿未结账期间的报表，无法进行提交。

选择【ACCTEXT函数的取数类型为Y、QY时，按结束日期来计算】，则使用此函数时，按结束日期来计算期末余额或期末数量，否则，是按开始日期来计算期末余额或期末数量。

选择【报表重算不验证账簿查询权限】，则用户在报表重算时，总账函数可取到无账簿查询权限的账簿科目数据

**HTML5在线报表查看**

选择【使用新H5报表控件在线查看报表】，则HTML5模式下，在线报表查支持在线编辑报表，目前仅星空公有云租户可直接启用该参数，其他私有云客户需免费申请并上传SpredJS控件许可，如有需要，请联系在线客服或KSM提单。

**其他参数设置**

选择【报表计算时启用内存数据库】，则优化报表计算性能，可提升报表计算的速度。

选择【锁定的报表表页允许重算】，则已锁定的报表表页可进行重算表页、全部重算，使得锁定只允许查看不能编制的表页也能计算更新数据。

选择【动态罗列报表不保存零值项目数据】，则系统不保存动态罗列报表的零值项目数据，提升有项目数据的动态报表加载、保存、接收的性能

**ACCTITEM取数公式参数说明：**

核算体系：是指取数来源核算体系，支持手工录入核算体系编码或通过F8从核算体系基础资料中进行选择。

核算组织：是指取数来源核算组织，支持手工录入核算组织编码或通过F8从核算组织基础资料中进行选择。

项目：是指取数的项目范围，支持手工录入项目编码或F8提供“从××项目至××项目”的选择。

周期：是指取哪个周期的数据，下拉列表提供：日报、月报、季报、半年报、年报、会计周期，通过下拉列表进行选择。

**REF取数公式参数说明：**

除支持跨表页取某个单元格参与本单元格的简单四则运算外，也支持连续页签相同单元格求和。

例：REF（sheet1:sheet5,B5）,意思是表sheet1至表sheet5的B5单元格求和，如果要新增一页参与求和，只需要在表sheet1至表sheet5之前插入一张表页即可，在表sheet1前或表sheet5后插入无效。

另外，此公式识别的是表页的名称，因此，如果设置完公式后，表页名称发生变化，需要修改公式里的表页名称。

表页名称：所在报表的所有表页名称。

单元格：具体单元格，可录入如B5,或B5+D6等简单的四则运算。

**REF_F取数公式参数说明：**


报表模板：是指取数来源的报表模板，包含个别报表、合并报表、工作底稿等。

表页名称：是指所选报表模板中包含的各表页

年度：是指取数的年度值

期间：是指取数的期间值，通过模板+年期，可以确定从哪个报表中取数 

币别： 是指取哪种币别的数据，支持手工录入币别编码或通过F8从币别基础资料进行选择。可以为空，为空则表示本位币。

金额单位：是指报表模板的金额单位，有元、千元、万元等选择项。 

数据内容：具体单元格，可录入如B5,或B5+D6等简单的四则运算。


**RPTINFO取数公式参数说明：**

报表信息：提供了报表名称、币别、报表周期、报表年度、报表期间、核算组织、开始日期、结束日期、创建人、当前合并范围等内容，优先取公式取数参数中的数值，如没有，则取报表参数中的数值。

制单人及审核人信息为报表打印设置中页眉、页脚提供。

 ===== 报表模板编制 =====

==== 编制操作 ====
报表模板新建后还只是一张空的模板，还需要编辑报表模板中的报表格式，设置单元格的项目公式、取数公式等。

报表编辑器是一个类似Excel的工具，如果您经常使用Excel，就会觉得非常熟悉，接下来我们以下面这张利润表为例，简单介绍如何利用报表编辑器来完成报表模板的设计。
 
**文字及格式编辑**

进入报表编辑器后，首先按照案例中利润表的样式，录入空白表单元格上的所有文字。

**表页格式设置**

在左下角，【sheet1】表页上单击鼠标右键，在弹出的菜单上单击【重命名表页】，在界面中的“工作表名”中录入“利润表”。在右键菜单中再单击【工作表大小】，将“工作表行数”设为20，“工作表列数”设为4。

**使用批量填充功能完成报表项目和公式设置**

在报表系统中，基本数据是按报表项目存储的，要建立起报表上的单元格数据与报表项目间的关联，也就是为单元格指定项目公式。同时报表要从账簿中取到数据的话，还必须定义取数公式。

这些我们都可以通过【报表批量填充】功能完成。详见报表批量填充。

除了批量填充功能完成项目公式和取数公式定认外，我们也可以针对单元格逐一进行定义。

单击【插入】菜单中的【函数】，选择所需函数进行定义，完成取数公式设置。

定义单元格取数公式，用于确定当前单元格数据值的来源；

单击【插入】菜单中的【项目公式】，在弹出的单元格项目公式对话框中可以根据需要输入项目编码、项目取数类型及指定相应的年度、期间，完成项目公式设置。

为保证报表模板的通用性，这里的“年度”、“期间”参数，建议保持默认“0”，即：当前年度，当前期间。或者相对数，如上一期“-1”，上一年“-1”。具体在保存报表项目数据时，“年度”、“期间”系统自动从报表属性中获取。

定义单元格项目公式，用于标识当前单元格数据的含义（如：定义单元格C4为：货币资金 期末数）。

借助该单元格项目公式，系统才能将报表中系统完全无法识别的单元格数据，保存为可查询可分析的格式化数据（如：南海公司 2012年1期 货币资金 期末数 10，000，000）。保存后的数据可通过查询与分析中项目数据查询功能浏览。

==== 插入预制报表模板 ====

系统提供了多张报表模板，由于报表系统的报表与合并报表的个别报表共用一个界面操作，因此，报表模板中也会有适用于个别报表的模板。例如【个别报表（利润及分配表）】适用于个别报表-利润表的制作，里面填充了年初未分配利润、年末未分配利润等合并报表适用项目。

鼠标右键表页标签（表页标签，如：sheet1），选择【插入表页】，在弹出的“插入表页”对话框的【报表样式】页签中，选择需要插入的报表样式。

===== 报表模板管理 =====

报表模板制作完成，可以在报表模板列表对其进行查看、修改、删除、审核、禁用等操作。

报表模板列表是按左树右表的结构进行展示的，左边树结构展示的是核算体系+核算组织的一个分类，右边列表展示的是各核算体系+核算组织分类下各自的报表模板。

在列表工具栏提供了相关的操作按钮，下面对主要的按钮进行介绍 

状态说明：

报表模板的状态有：在制、审核中、审核、重新审核、禁用。

状态显示在报表模板的左下方。新建模板保存后的状态是“在制”，进行“提交”操作后报表模板的状态为审核中，进行“审核”操作后的报表模板的状态为审核，进行“反审核”操作后的报表模板的状态为重新审核。

报表模板列表功能路径：

工具栏菜单中【打开】－>【报表模板】

按照上述路径都可以进入报表模板列表。  

**模板修改**

只有“在制”和“重新审核”状态的报表模板才允许对其中的内容进行修改。在报表模板列表选中需要修改的报表模板记录，单击【修改】，系统将会打开所选报表模板，此时可对其进行内容修改。

**模板提交、审核、反审核**

新建模板保存成功后，需要进行提交操作才能进行审核操作。在报表模板列表选中目标模板，单击工具栏中的【提交】即完成提交操作。如果报表模板已处于打开状态，也可单击报表编辑器中的【审阅】菜单→【提交】完成提交操作。

在报表模板列表界面选中需要审核的报表模板，单击工具栏中的【审核】，系统会打开选中模板，需要单击【审阅】菜单→【审核】才能完成报表模的审核操作。

审核后的报表模板可以进行反审核操作，在报表模板列表选中需要反审核的报表模反，单击工具栏的【反审核】，系统会打开选中模板，需要单击【审阅】菜单→【反审核】才能完成报表模板的反审核操作。

**模板共享**

 编制并审核完毕的模板，可跨核算体系、跨组织共享。

在报表模板列表界面选中需要共享的报表模板，单击工具栏中的【共享】，在弹出的“请选择共享组织”对话框中，选择目标核算体系-核算组织。

共享给目标组织的报表模板为“在制”状态。   

**模板禁用、反禁用**

任何状态的报表模板都可以禁用。禁用后的报表将不可对其进行任何操作。只有禁用状态的报表模板才可反禁用。

**操作说明**

系统预设了新会计准则的报表项目。报表项目不需要进行审核等流程控制，保存即可被报表模板或报表引用。
 ====== 字段说明 ======
| 字段          || 说明                                                                                                                                                                                                                 |

## 【页面】项目勾稽关系
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A1%B9%E7%9B%AE%E5%8B%BE%E7%A8%BD%E5%85%B3%E7%B3%BB

====== 项目勾稽关系 ======

===== 报表系统的项目勾稽关系 =====

**功能说明**

报表项目勾稽关系是通过设置报表项目间的比较公式，来核对报表项目数据的正确性；

由于报表项目可被多个报表所引用，因此报表项目勾稽关系检查实际是与具体报表无关的。


**功能路径**

【财务会计】→【报表】→【基础资料】→【项目勾稽关系】

**报表项目勾稽关系分配列表**

项目勾稽关系定义完成后，需要将勾稽关系分配给需要进行相应检查的组织。

功能路径：【财务会计】－>【报表】－>【基础资料】－>【项目勾稽关系分配列表】

在报表项目勾稽关系分配列表界面，点击【新增】来将勾稽关系分配给需要检查的组织。

可以通过【控制节点】、【控制强度】来实现勾稽关系的控制，如果需要强控制，则将【控制强度】设置为【不通过】，当报表数据不满足勾稽关系检查时，该报表不能通过审核或上报（按【控制节点】来处理）

在“报表项目勾稽关系分配列表”中，还可以进行勾稽关系分配的删除、打印、引出等操作。

 ====== 字段说明 ======
| 字段                  || 说明                                                                                                                                                                                                     |
| 编码                  || 报表项目勾稽关系编码，唯一标识，手工录入。                                                                                                                                                                                  |
| 名称                  || 报表项目勾稽关系名称。                                                                                                                                                                                            |
| 左表达式、右表达式、关系表达式     || 定义勾稽关系的左右表达式，以及左右表达式的关系。\\ 通过【编辑公式】，定义表达式。\\ 如：Item("6001.01.03",0,0,"2","管理费用","期末数")=Item("6002.01",0,0,"2","办公费","期末数")+Item("6002.02",0,0,"2","差旅费","期末数")+Item("6002.03",0,0,"2","管理人员工资","期末数")  |
| 提示内容                || 报表项目数据检查不满足勾稽关系时，提示的内容。\\ 如：管理费用明细不等于管理费用总和。                                                                                                                                                           |

在“报表项目勾稽关系”列表中，还可以进行勾稽关系的分配、删除、打印、引出、禁用/反禁用等操作。


===== 合并报表系统的项目勾稽关系 =====

**功能说明**

为提高报表数据的准确性及可靠性，避免发生数据错漏、不一致的问题，系统提供了报前检查功能，子公司在提交数据前，都必须经过勾稽关系检查才能提交报表。

检查是依据用户设置的勾稽关系公式来进行的，勾稽关系是通过设置报表项目间的比较公式，来核对项目数据、检查报表的正确性，它可以用于不同报表间数据的检查，也可以用于对重点项目的合理性分析检查。

**操作说明**

【新增】：打开【财务会计】－>【合并报表】－>【合并准备】－>【项目勾稽关系】功能，新增项目勾稽关系。

【分配】：打开【财务会计】－>【合并报表】－>【合并准备】－>【项目勾稽关系】功能，单击工具栏的【分配】按钮，将项目勾稽关系分配给需要进行勾稽关系检查的报表模板。

在分配界面也可以设置【控制节点】、【控制强度】。

**字段说明**

| 字段                  || 说明                                            |
| 左表达式、右表达式、关系表达式     || 定义勾稽关系的左右表达式，以及左右表达式的关系。\\ 通过【编辑公式】，定义表达式。    |
| 提示内容                || 报表项目数据检查不满足勾稽关系时，提示的内容。\\ 如：管理费用明细不等于管理费用总和。  |

====== 项目数据类型 ====== 

**功能说明**

对于报表中的同一报表项目可能需要区分多种数据类型，例如“应收账款”项目，就可能有：年初数、期初数、本期增加数、本期减少数、期末数等，因此系统提供“项目数据类型”功能，供用户自定义报表项目的数据类型，从多个角度反映某个报表项目的情况。用户根据需要使用项目数据类型来标识报表的行或列，方便取数公式选择正确的取数类型。


**功能路径**

【财务会计】→【报表】→【基础资料】→【项目数据类型】

【管理会计】→【预算管理】→【基础资料】→【项目数据类型】

**操作说明**

系统预设了11种常用的项目数据类型：年初数、本期发生数、期末数、本年累计数、本年增减变动金额等。项目数据类型不需要进行审核等流程控制，保存即可被报表模板或报表引用。
