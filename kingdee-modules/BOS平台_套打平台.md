## 【页面】套打应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A5%97%E6%89%93%E5%BA%94%E7%94%A8

======1 功能概述 ======

套打设计平台中建立的套打模板支持在客户端调用，支持通过单据类型及单据套打设置进行配置；

======2 操作步骤 ======

1、运行时可通过单据类型选择单据的套打模板及打印次数控制； 

2、运行时可通过工具栏按钮【套打设置】调整单据的套打模板； 
  * 【使用套打模板打印】选项是设置当前打印使用套打设计器设计的套打模板作为打印模板，支持高级设置； 
  * 【使用标准报表模板打印】选项是设置当前打印使用万能报表设计的单据类报表作为打印模板，支持高级设置条件； 
  * 【使用Excel模板打印】选项是设置当前打印使用Excel设计打印模板作为打印模板，支持高级设置；
  * 【默认】页签用于设计单据类型对应的默认套打模板，如果单据没有启用单据类型，或者是账表、基础资料、动态表单等没有单据类型的业务对象，可以设置业务对象对应的套打模板； 
  * 【高级】页签用于设计套打方案，每个方案可以设置满足一定条件时使用某个套打模板和打印机进行打印，支持启用多个多个方案，每个启用的方案满足条件时可进行打印；
  * 【参数设置】页签用于设置不同的套打方案及效果，支持设置不同的参数，如批次打印页数，套打显示选择模板界面等；
  * 【Excel模板设计】页签用于设计Excel打印模板；
  * 【套打导出默认设置】页签用于设置套打导出的格式和方式的默认值；
3、运行时支持单张单据套打、支持多张单据连续套打及合并套打，支持选择分录套打，支持引出套打数据；

## 【页面】套打模板权限控制
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A5%97%E6%89%93%E6%A8%A1%E6%9D%BF%E6%9D%83%E9%99%90%E6%8E%A7%E5%88%B6

====== 套打模板权限控制 ======
[[套打平台|返回套打平台主页]]

按组织、角色、用户多个维度对套打模板进行权限控制。

===== 套打模板权限控制操作步骤 =====

1.管理员用户登录系统，打开【系统管理】【系统管理】【打印模板权限控制】页面

[图:打印模板权限控制详情.png]


2.选择要控制打印模板权限的单据，定义模板权限控制策略

 模板权限控制策略有四种类型：通用、用户、组织、角色，四种类型也可以组合使用
  * 通用，选择通用的话，该控制策略无条件生效
  * 用户，控制某个用户可以使用哪些套打模板，点击【名称】列单元格后面的按钮弹出用户选择页面。
  * 组织，控制某个组织下面哪些套打模板可用，点击【名称】列单元格后面的按钮弹出组织选择页面。 
  * 角色，控制某个角色哪些套打模板可用，点击【名称】列单元格后面的按钮弹出角色选择页面。
  [图:打印模板权限控制设置.png]
 
3.定义打印模板权限控制策略以后，套打设置页面默认页签和高级页签以及套打模板选择页面仅能看到有权限的套打模板。

注意事项：
a.一旦启用了某个单据的套打模板权限控制，那么就是从严控制策略，登录用户不在所配置的组织、角色、用户范围内，那么就看不到该单据下面的套打模板。
b.存在多个维度控制的情况下，套打可用模板的是这些维度的集合，如某个用户有101、102两个组织的权限，其中101组织控制A、B两个模板可用，102组织控制C、D两个模板可用，那么该用户登录以后，无论切换到101组织还是切换到102组织，A、B、C、D四个模板都可用。

## 【页面】套打设置与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A5%97%E6%89%93%E8%AE%BE%E7%BD%AE%E4%B8%8E%E5%BA%94%E7%94%A8

====== 业务背景 ======

运行时单据工具栏提供【套打设置】菜单,点击打开套打设置界面，套打设置界面按用户保存方案，不同用户的套打设置，彼此互不影响。

====== 套打设置与应用 ======

**以采购订单为例，通过套打设置配置套打方案，需要以下步骤：**

1、点击工具栏套打设置按钮，弹出套打设置界面，选择使用套打模板打印； 
  * 使用套打模板打印：打印时使用该单据类型对于的套打模板进行打印； 
  * 选择使用套打模板打印：打印时使用该单据类型对于的套打模板进行打印； 
2、根据单据类型选择对应的套打模板，无单据类型时直接选择套打模板； 
  * 单据类型：列出当前单据所有的单据类型； 
  * 对应套打模板：使用套打设计器设计的套打模板； 
  * 对应标准报表模板：使用万能报表设计的单据类报表作为标准打印模板； 
3、点击套打设置高级菜单，支持设置用户级套打高级方案，支持按条件设置套打模板（不支持标准报表模板打印模式）； 
  * 启用：启用该套打方案，支持启用多个方案，打印时每个启用的方案都执行一次； 
  * 条件：支持根据单据上的字段取值设置条件，目前只支持单据头字段，点击条件字段编辑按钮，弹出条件设置界面，设置方式和过滤界面类似，输入名称后点确定按钮返回套打设置界面； 
  * 套打模板：展示使用套打设计器设计的套打模板； 
  * 打印机名称：支持设置按指定的打印机进行打印，打印机默认是根据本地安装的打印机名称，进行右模糊匹配查询（在打印机名称前输入*为全模糊匹配），查询到的打印则从该打印机打印，查询不到则弹出打印机选择界面； 
  * 套打排序：支持设置按单据体分录字段进行排序打印，点击排序字段编辑按钮，弹出套打排序界面，支持设置多个排序字段，如果套打模板也设置了排序字段，则以此次设置的排序方案为准；
4、应用到所有用户：将当前设置的单据类型对应套打模板的方案应用到所有用户； 

5、点击确定按钮，保存当前套打设置方案，打印时加载该方案进行打印；

## 【页面】新建套打
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%96%B0%E5%BB%BA%E5%A5%97%E6%89%93

======1 功能概述 ======

套打设计平台提供套打模板新建向导，支持为基础资料、业务单据建立套打模板。

**操作步骤**

新建步骤参见[[模板设计与应用|模板设计与应用]]。

=====1.1 数据表格向导 =====
 
**功能概述**

以向导的方式快速实现数据表格的数据源字段及分组功能，向导共有四个步骤。

**操作步骤**

  - 选择数据表格需绑定的数据源； 
  - 选择数据表格中数据行中所需要打印的字段；
  - 选择数据表格中分组依据字段；
  - 选择数据表格中分组统计字段；

=====1.2 数据统计 =====
 
  - 分组小计：  统计本分组内的数据，如果是普通行中的单元格，则该统计即为总计所有数据。 
  - 区域小计：  统计当前页内本分组内的所有数据，如果是普通行中的单元格，则该统计即为统计本页的所有数据。 
  - 累计：  累计当前页前所有页加当前页内本分组内的所有数据，如果是普通行中的单元格，则该统计即为累计当前页前所有页加当前页内的所有数据。 

=====1.3 系统变量 ===== 

  - 变量名称： 功能描述 
  - 当前用户： 获取当前用户的数据源 

=====1.4 常用公式 =====
  - 页码： 获取当前页页码的数据源
  - 总页数： 获取总页数的数据源
  - 第X/Y页： 获取当前页及总页数的数据源，以第X/Y页方式展示，X为页码，Y为总页数
  - 第X页，共Y页： 获取当前页及总页数的数据源，以第X页，共Y页方式展示，X为页码，Y为总页数
  - 当前时间： 获取当前时间的数据源
  - 数据行行号： 获取数据行当前行号的数据源

=====1.5 工作流 =====
 
  - 工作流： 单据启用工作流时获取工作流节点审批意见数据源 
  - 审批流： 单据启用审批流时获取审批流节点审批意见数据源 

=====1.6 附件信息 =====
 
  - 单据包含附件时获取附件信息相关数据源

## 【页面】模板设计与应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A8%A1%E6%9D%BF%E8%AE%BE%E8%AE%A1%E4%B8%8E%E5%BA%94%E7%94%A8

======1 业务背景 ======

套打设计平台支持维护业务单据的套打模板，运行时可以将单据内容打印到印刷好的表格当中。

======2 模板设计与应用 ======

**以采购订单为例，通过套打设计器新建套打模板，需要以下步骤：**

1、登录套打设计器，选择子系统后点击工具栏【新建】按钮，打开套打模板新建向导，选择业务对象为采购订单，打开套打设计界面，提供项目、导航树、数据源等设置； 
  * 项目栏展示当前子系统下的所有套打模板，支持复制、删除功能； 
  * 导航树栏展示设计区当前套打模板界面元素，支持删除元素； 
  * 数据源栏展示当前单据界面的所有元素，支持拖放至文本单元格、数据表格单元格； 
2、添加文本、数据表格、布局表格至套打设置界面，用于显示表头信息,通过以下方式添加数据源； 
  * 选中数据表格单元格、文本单元格，通过工具栏【属性】功能，绑定单元格数据源及字段； 
  * 通过项目窗口数据源页签，鼠标拖放字段至数据表格单元格、文本，数据表格单元格支持拖放多个数据源合并； 
  * 添加文本至布局表格单元格，然后绑定文本数据源； 
3、选中表头数据表格首行，在菜单栏【表格】下拉菜单中点击【数据表格向导】按钮，打开数据表格向导； 

4、数据源下拉列表中选择“采购订单-单据头”点击【下一步】继续； 

5、在备选字段列，将需要打印的单据头字段添加至创建列，点击【下一步】继续； 

6、在备选字段列，将需要设置分组的字段添加至创建分组列，点击【下一步】继续； 

7、点击【完成】后，所选单据头字段将自动与采购订单单据头字段进行数据关联； 

8、添加数据表格至套打界面，用于显示表体信息，选中表体数据表格行，在菜单栏【表格】下拉菜单中点击【数据表格向导】按钮，打开数据表格向导； 

9、数据源下拉列表中选择单据体，如“采购订单-采购订单明细”点击【下一步】继续； 

10、依次重复操作第四、五、六步骤； 

11、选择数据表格首行、首列，点击【属性】按钮，设置行属性、列属性，以及多页打印时每页显示行数； 

12、完成后点击设计器工具栏【保存】按钮，即完成“采购订单”套打模板设置； 

13、登录BOS设计器，打开采购订单，通过单据属性，在【默认套打模板】下拉列表中选择新建的套打模板，保存单据后，该模板将作为单据默认的套打模板，实现运行时可调用；
