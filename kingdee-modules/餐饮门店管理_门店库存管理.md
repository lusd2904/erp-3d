====== 1.报损出库单 ======

===== 1.1 功能概述 =====
配送给门店的食品或物料，因质量问题或其他原因退货导致物品不能使用，需要进行报损处理。

===== 1.2 字段说明 =====

^ 字段名称  ^ 字段说明                    ^
| 选单    | 上游单据有采购入库单，配送退货单，其他入库单  |

===== 1.3 业务说明 =====

**一、库存查询** 

报损出库单上支持库存查询功能，直接调用库存数据。

**二、保质期检查** 

报损出库单上支持保质期检查功能，具体规则同外购直拨单，请参考外购直拨单。

**三、即时库存更新** 

报损出库单会影响库存数据，规则如下：

（一）库存管理系统参数【库存更新方式】为“保存时”：报损出库单保存、反作废时减少库存，删除、作废时增加 库存 

（二）库存管理系统参数【库存更新方式】为“审核时”：外购直拨单审核时减少库存，反审核时增加库存 

（三）更新后库存的库存状态以报损出库单上的【库存状态】为准 

（四）用报损出库单实收数量更新即时库存，同时将报损出库单上物料、辅助属性、批号、保质期（生产日期、保质期、到期日）、仓库、仓位等等信息携带至即时库存表 

**四、报损出库单批号相关业务**

报损出库单行操作菜单上提供批号相关操作，有以下三种

（一）批号库存，以批号为维度查询物料库存 

（二）批号主档，查询当前物料的批号主档 

（三）获取批号，为采购订单分录的物料按照批号编码规则获取批号

**五、报损出库单与其他入库单关联转换业务** 

（一）下推规则

其他入库单可以下推报损出库单，也可以在报损出库单界面选单其他入库单生成报损出库单，实现关联业务的转化，报损出库单与其他入库单转化的规则如下：

1、单据状态为“已审核”的其他入库单才能下推报损出库单。
2、在报损出库单界面选单时，可选择的其他入库单列表界面默认只过滤出符合上面条件的其他入库单。

**六、报损出库单与外购入库单关联转换业务** 

（一）下推规则

外购入库单可以下推报损出库单，也可以在报损出库单界面选单外购入库单生成报损出库单，实现关联业务的转化，报损出库单与外购入库单转化的规则如下：

1、单据状态为“已审核”的外购入库单才能下推报损出库单。

2、在报损出库单界面选单时，可选择的外购入库单列表界面默认只过滤出符合上面条件的其他入库单。

**七、报损出库单与销售退货单关联转换业务** 

（一）下推规则 

销售退货单可以下推报损出库单，也可以在报损出库单界面选单销售退货单生成报损出库单，实现关联业务的转化，报损出库单与销售退货单转化的规则如下：

1、单据状态为“已审核”的销售退货单才能下推报损出库单。

2、在报损出库单界面选单时，可选择的销售退货单列表界面默认只过滤出符合上面条件的其他入库单。

====== 1.盘点方案模板 ======

===== 1.1 功能概述 =====

盘点方案模板支持临时盘点，日盘，月盘，周盘四中模式，同时支持后台自动生成物料盘点作业表的后台执行计划。
需要在物料中设置   
  * 日盘，每天盘点
  * 周盘：每周第几天盘点（第4天表示周四），只能输入1~7
  * 月盘：每月第几天盘点（28表示第28号），只能输入1~31
  * 周盘/月盘是，设置后面的第几天的同时还需要勾选周/月前面的勾选框后才会生效

====== 1. 部门间调拨单 ======

===== 1.1 功能概述 =====
调拨申请单是物料调拨的依据，支持组织内调拨和跨组织调拨
===== 1.2 字段说明 =====
^ 字段名称  ^ 字段说明                                                                                  ^
| 申请组织  | 调用已审核、未禁用、有权限的组织机构基础资料。如果当前组织符合条件，则默认等于当前组织。\\ 申请组织是单据的主业务组织。                         |
| 物料编码  | 调用已审核、未禁用、有权限、使用组织等于录入的申请组织的物料基础资料。\\ 业务类型=标准：物料允许库存。\\ 业务类型=VMI：物料允许库存、勾选“是否VMI业务”。  |
| 类型    | 支持组织内调拨与跨组织调拨                                                                         |
| 选单    | 上游单据为加工入库单，生产用料清单，直接调拨单                                                               |
| 下推    | 下游单据为配送出库单，直接调拨单                                                                      |

===== 1.3 业务说明 =====

支持以下关联路线： 
  * 直接调拨表示一步式调拨，不需要管理在途。直接调拨更新即时库存表会同时扣减调出方可用库存量、增加调入方可用库存量。 
  * 直接调拨根据调拨方向分普通和退货类型。 
  * 普通调拨表示货物从调出方调拨到调入方这种正常调拨业务。退货调拨表示调入方收到货物后再部分或全部退还给调出方，调出方原来处理的那笔调拨业务的调出数量减少了。
  * 直接调拨支持组织内调拨：表示货物只是在不同仓库之间移转，库存组织、货主都不变。
  * 直接调拨支持跨组织调拨：允许调出库存组织、调出货主和调入库存组织、调出货主不同。对于跨组织调拨，调出货主和调入货主在同一核算体系下上级核算组织不同，支持组织间结算。 
  * 获取往来单位：获取对应供应商和对应客户。对应供应商取供应商资料中使用组织=调入货主，对应组织=调出货主的已审核、未禁用的供应商；对应客户取客户资料中使用组织=调出货主，对应组织=调入货主的已审核、未禁用的客户。

企业在实施ERP系统前，通过手工记录的库存余额和已入库未开票的库存单据，需要平移到ERP系统中，同时在系统做初始化的过程中，业务持续发生，保持业务上线的平滑过渡。

入库单会影响库存数据，规则如下 

  *   库存管理系统参数【库存更新方式】为“保存时”：入库单保存、反作废时增加库存，删除、作废时扣减库存 

  *   库存管理系统参数【库存更新方式】为“审核时”：入库单审核时增加库存，反审核时扣减库存 

  *   更新后库存的库存状态以入库单上的【库存状态】为准 

  *   用入库单实收数量更新即时库存，同时将入库单上物料、BOM编号、辅助属性、批号、保质期（生产日期、保质期、到期日）、计划跟踪号、项目编号、仓库、仓位等等信息携带至即时库存表 

  *   若入库单与收料单相关联，则在更新库存的时候还需要扣减收料库存 

**四、	入库单批号相关业务**

入库单行操作菜单上提供批号相关操作，有以下三种 

  * 批号库存，以批号为维度查询物料库存 

  * 批号主档，查询当前物料的批号主档 

  * 获取批号，为采购订单分录的物料按照批号编码规则获取批号

**五、	入库单的倒冲领料功能**

委外类的入库单在入库单列表中能进行倒冲领料操作，具体请参看制造相关手册
 
**六、	采购费用**

采购入库单支持查询与入库单相关联的采购费用，采购费用来自费用应付单数据。具体请参看应付管理手册。 

**七、	入库单单据转换**

入库单可以下推退料单，也可以在退料单界面选单入库单生成退料单，实现关联业务的转化，入库单与退料单转化的规则如下： 

  * 单据状态为“已审核”，且实收数量大于退料关联数量的入库单才能下推退料单 

  * 在退料单界面选单时，可选择的入库单列表界面默认只过滤出符合上面条件的入库单 

  * 可以选择多张入库单合并生成退料单，合并条件是供应商，收料组织、采购组织、货主、结算组织和结算币别相同 

  * 入库单下推的退料单，【退料类型】只能是“库存退货” 

  * 入库单下推退料单时，入库单的字段关联携带到退料单上 

  * 入库单下推的退料单数量不能大于【实收数量】与【退料关联数量】之差

  * 食品报损单生成时，先去判断该食品是否有对应的食品成本卡，如有默认的食品成本卡，则根据默认的食品成本卡展开物料。                                                      
  * 如未找到默认的食品成本卡，则判断该食品是否是由物料转为食品的，如是，则去找对应的物料展开，食品的报损数量，则是物料的用量。

  * 若有替代料，替代料库存足够时，扣完主料库存数后再扣替代料库存，替代料库存不足时，主料应发数量=主物料库存数，替代料应发数量=替代料库存数。

  * 当食品销售清单上为取消单时，退回库存时，查找当天前面该食品扣减食材库存时，是否使用替代料，若使用了替代料，优先退货替代料，剩余数量退回标准料。
  * 食品销售清单--食品材料耗用单单据转换规则中的单据类型映射，类型为食品销售清单对应食品材料耗用单；类型为员工餐清单对应员工餐耗用单,控制不同的单据类型不可同时选择下推下游单据’
  * 在门店库存管理系统参数中盘点方案控制上方增加参数：食品材料耗用单扣减库存方式：按库存可用量、按标准用量。默认按库存可用量。 参数旁边问号解释，解释语：按库存可用量，在库存不足时，按生成食品材料耗用单时的即时库存可用量扣减库存；
  * 按标准用量，按食品成本卡计算得出的标准用量扣减库存，库存不足时，扣减失败

====== 1.食品销售清单 ======

===== 1.1 功能说明 =====

食品销售清单是反应门店食品的销售情况的列表，可以通过数据交换销售报数，食品销售清单接口，以及POS账单接口上传自动生成。食品销量清单是销量预测计算助手的原始数据来源。食品销售清单单据类型包括员工清单和食品销售清单，类型分为正常单和取消单。

===== 1.2 字段说明 =====
^ 字段名称  ^ 字段说明                                                 ^
| 单据类型  | 分为食品销售清单以及员工餐清单                                      |
| 数据来源  | POS账单生成、接口生成、POS上传，手工录入                              |
| 类型    | 正常单与取消单                                              |
| 是否清机  | 如果勾选，表示已经清机，默认勾选                                     |
| 下推    | 下游单据为食品材料耗用单                                         |
| 更新数据  | 需要根据不同的POS账单类型生成食品销售清单。员工餐的生成员工餐清单，其他非员工餐的，生成食品销售清单  |

===== 1.3 业务说明 =====
  * 食品销售清单生成时，先去判断该食品是否有对应的食品成本卡，如有默认的食品成本卡，则根据默认的食品成本卡展开物料。                                                     
  * 如未找到默认的食品成本卡，则判断该食品是否是由物料转为食品的，如是，则去找对应的物料展开，食品的销售数量，则是物料的用量。		
  * 食品销售清单列表排序规则改为营业日期+单据编号排序
  * 上传食品销售清单中加入出品取消数量	
  * POS账单上传时，每次上传成功后，将数据形成一个数据包，调用更新数据功能，将POS账单数据汇总合并生成食品销售清单。同步生成，并返回生成结果消息。POS账单反审核时，校验是否生成食品销售清单。若已生成时，不可反审核。提示：已生成食品销售清单，请先删除食品销售清单！手工删除食品销售清单及POS账单时，控制必须删除当日所有POS账单和食品销售清单。当删除食品销售清单时，同时删除与POS账单的关联标识			
  * POS账单生成食品销售清单按账单类型分单。类型为员工餐的，生成单据类型为员工餐的食品销售清单。其他类型的POS账单，全部生成单据类型为食品销售清单
  * 食品销售清单列表中，点击更新数据时，需要根据不同的POS账单类型生成食品销售清单。员工餐的生成员工餐清单，其他非员工餐的，生成食品销售清单			
  * POS账单生成食品销售清单按类型分单。正数合并生成类型为正常单。负数合并生成类型为取消单。但是招待、出品取消的，按照正常单生成。  
  * 食品销售清单列表上，更新数据之后，食品销售清单数量与POS账单不一致。原因是客户存在出品取消的单，而食品销售清单未考虑出品取消

  * 普通列表项目数字列表项目没有设置业务委托关系：材料出库时，默认发料组织与出品组织/报损组织一致，发料仓取出品部绑定的部门仓库，无论仓库是否设置了对应组织，都获取出品部绑定的仓库

====== 1.分步式调入单 ======
===== 1.1 功能概述 =====

使用前提：必须设定了库存组织、库存组织启用日期、计量单位、物料、仓库。

功能路径：【供应链】－>【库存管理】－>【库存调拨】－>【分步式调入单】 

【餐饮门店管理】–>【门店库存管理】－>【库存调拨】－>【分步式调出单】

字段说明参考[[分步式调出单|分步式调出单]]。

===== 1.2 业务说明 =====

  * 调拨类型：组织内调拨、跨组织调拨。组织内调拨表示货物只是在不同仓库之间移转，库存组织、货主都不变。跨组织调拨表示业务组织之间的货物移转，可以是不同库存组织之间的调拨，也可以是不同货主之间的调拨。 

  * 在途库存：调出方先做分步式调出单，表示货物发出，调入方在确认收货后再做分步式调入单，表示货物接收，调出数量和调入数量可以不同。分步式调入单更新即时库存表除了增加调入方可用库存量，还根据在途归属扣减调出方或调入的在途状态的库存量。 

  * 调拨方向：根据调拨方向分普通和退货类型。 

  * 组织间结算处理：在同一个核算体系下，调出货主、调入货主对应的核算组织不同才产生结算清单。

  * 途损：在分步式调入单中输入途损数量，途损责任方。途损数量会冲减分步式调出产生的在途库存量。

  * 获取往来单位：获取对应供应商和对应客户。对应供应商取供应商资料中使用组织=调入货主，对应组织=调出货主的已审核、未禁用的供应商；对应客户取客户资料中使用组织=调出货主，对应组织=调入货主的已审核、未禁用的客户。

===== 1.3 在途归属 =====
表示在途的货物物权归属。 

在途归属对业务日期合法性检查库存组织关账日期的影响：

1、分步式调出单：

在途归属=调出方：业务日期合法性只检查调出组织的关账日期；

在途归属=调入方：业务日期合法性检查调出和调入组织的关账日期；

2、分步式调入单：

在途归属=调出方：业务日期合法性检查调出和调入组织的关账日期；

在途归属=调入方：业务日期合法性只检查调入组织的关账日期；

在途归属对关账检查分步式调出、调入单审核状态的影响：

1、关账检查分步式调出单的范围：

调出组织=关账组织；

或者在途归属=调入方，调入组织=关账组织；

2、关账检查分步式调入单的范围：

调入组织=关账组织；

或者在途归属=调出方，调出组织=关账组织。

=====1.4 业务说明=====
  * 调拨类型：组织内调拨、跨组织调拨。

  * 组织内调拨表示货物只是在不同仓库之间移转，库存组织、货主都不变。

  * 跨组织调拨表示业务组织之间的货物移转，可以是不同库存组织之间的调拨，也可以是不同货主之间的调拨。 

  * 分步式调拨用于处理货物在途管理。货物从调出方发出后，在调入方未确认收货前，货主处于在途状态，而且根据在途归属是调出方还是调入方来决定物权所有。

  * 分步式调出单更新即时库存表除了扣减调出方可用库存量，还根据在途归属增加调出方或调入的在途状态的库存量。
  
  * 分步式调出单调拨方向分普通和退货类型。普通表示货物从调出方调拨到调入方这种正常调拨业务，退货表示调入方收到货物后再部分或全部退还给调出方，调出方原来处理的那笔调拨业务的调出数量减少了。

  * 比如从A调出一笔货物（调拨数量100）给B，然后再从B调出一笔货物（调拨数量20）给A，可以通过调拨方向来区分从B到A的调拨业务是正常调拨还是退货：调拨方向是“退货”表示这20个是B退回给A的，实际A调拨给B的货物数量是80；调拨方向是“普通”表示这20个是B正常调拨给A的。 

  * 分步式调拨的在途归属：用来定义在途货物的物权归属。 
 
  * 组织间结算处理：在同一个核算体系下，调出货主、调入货主对应的核算组织不同才产生结算清单。
 
  * 分步式调拨支持VMI物料调拨。 
 
  * 获取往来单位：获取对应供应商和对应客户。对应供应商取供应商资料中使用组织=调入货主，对应组织=调出货主的已审核、未禁用的供应商；对应客户取客户资料中使用组织=调出货主，对应组织=调入货主的已审核、未禁用的客户。、

====== 1.即时库存校对 ======
===== 1.1 功能概述 =====

即时库存校对用来重算即时库存表，纠正由于一些异常原因导致单据未成功更新即时库存表的数据错误。

使用前提：仅对结束初始化的库存组织执行即时库存校对。

功能路径：【餐饮门店管理】－>【门店库存库存管理】－>【库存查询】－>【即时库存校对】

【供应链】－>【库存管理】－>【库存查询】－>【即时库存校对】

===== 1.2 业务说明 =====

  * 校对规则：

已关账：即时库存=期初库存+（上一次关账日期至今）入库数量-（上一次关账日期至今）出库数量。

尚未关账：即时库存=结束初始化的期初库存+（库存启用日期至今）入库数量-（库存启用日期至今）出库数量。 
 
  * 如果用户修改系统当前日期小于库存启用日期或上一次关账日期，则不执行校对功能。 

  * 可指定物料执行库存校对。

====== 1.盘亏单 ======

===== 1.1 功能概述 =====

盘盈、盘亏单用来做库存调整，保证货物的账、实库存量一致。实际库存比账存数量少就用盘亏单。

使用前提：库存组织结束初始化。

功能路径：【供应链】－>【库存管理】－>【定期盘点】或【周期盘点】－>【盘亏单】

【餐饮门店管理】－>【餐饮盘点】－>【盘亏单】


===== 1.2 字段说明 =====

参考[[盘盈单|盘盈单]]的字段说明。


===== 1.3 业务说明 =====


盘亏单的盘点数量需大于0，且盘点数量小于账存数量。 

盘亏单保存或审核时减少即时库存量。 

由物料盘点作业生成的盘亏单控制不允许反审核。 

同一张单据上单据分录不允许重复。

非VMI类型的盘亏单，取消货主或保存者至少有一个等于库存组织的限制。

======1.盘盈单 ======
===== 1.1 功能概述 =====
盘盈、盘亏单用来做库存调整，保证货物的账、实库存量一致。实际库存比账存数量多就用盘盈单

使用前提：库存组织结束初始化。

功能路径：

【供应链】－>【库存管理】－>【定期盘点】或【周期盘点】－>【盘盈单】
          
【餐饮门店管理】－>【餐饮盘点】－>【盘盈单】


===== 1.2 字段说明 =====

^ 字段        ^ 说明                                                                                                                                                                                     ^
| 来源        | 字段锁定。\\ 来源包括：手工录入、定期盘点、周期盘点，餐饮盘点\\ 盘盈单或盘亏单根据物料盘点作业生成，那么携带源单的对应字段\\ 盘盈单或盘亏单手工新增，那么来源=手工录入                                                                                               |
| 物料盘点作业编码  | 字段锁定\\ 空或携带源单（物料盘点作业）单据编号                                                                                                                                                              |
| 账存数量      | 物料盘点作业审核生成盘盈单时携带对应字段\\ 手工录入时， 根据录入的库存组织和物料信息自动匹配即时库存的基本单位库存量，录入的单位和基本单位不同时，转换为对应单位的库存量\\ 注意：物料数据、仓库、仓位、库存状态、货主、保管者等改变，账存数量会改变。比如物料001，仓库1，库存量：100；仓库2，库存量：80。由仓库1更改为仓库2时，账存数量从100变为80  |
| 盘点数量      | 物料盘点作业审核生成盘盈单时携带对应字段\\ 手工录入时，盘点数量大于等于0，且盘点数量大于账存数量                                                                                                                                     |
| 盘盈数量      | 物料盘点作业审核生成盘盈单时携带对应字段\\ 字段锁定，盘盈数量=盘点数量-账存数量                                                                                                                                             |
==== 1.3 业务说明 ====

盘盈单保存或审核时增加即时库存量。 

由物料盘点作业生成的盘盈单控制不允许反审核。 

同一张单据上单据分录不允许重复。 

盘盈单，取消货主或保存者至少有一个等于库存组织的限制。

====== 1.餐饮物料收发汇总表 ======

===== 1.1 功能概述 =====

餐饮物料收发汇总表统计各物料在一段时间内的期初结存、收入、发出、结存的汇总数据。 此报表的数据来源于各库存单据，按库存组织+货主类型+货主的不同分页展示。 

===== 1.2 字段说明 =====
^ 字段名称      ^ 字段说明                                                                                                                                                                                                                                                                                                                                                                                           ^
| 期初数量（基本）  | 1、日期取过滤条件设置的起始日期。\\ 2、库存组织结束初始化，还未关账：期初结存取库存组织结束初始化的数量结余+库存组织启用日期到起始日期之前这段时间的收入数量-库存组织启用日期到起始日期之前这段时间的发出数量。\\ 3、库存组织已关账，那么取起始日期最近的一次关账日期的数量结余+关账日期到起始日期之前这段时间的收入数量-关账日期到起始日期之前这段时间的发出数量。                                                                                                                                                                                                       |
| 期初单价（基本）  | 1、期初单价来源：最新入库价，单价根据对应库存组织、货主的所有入库列表中同物料+批号+辅助属性中，最新一次有金额的入库类型单据的单价，这里注意单价币别的换算，即引入后的本位币单价=入库单上原币单价*原币与主账簿本位币的汇率。\\ 2、期初单价来源：最新出库价，单价根据对应库存组织、货主的所有出库列表同物料+批号+辅助属性中，最新一次有金额的出库类型单据的单价，这里注意单价币别的换算，即引入后的本位币单价=出库单上原币单价*原币与主账簿本位币的汇率。\\ 3、期初单价来源：期初加权平均价，是指期初余额中的单价=期初余额/基本单位数量。（期初余额和数量来自：根据过滤的起始日期查找库存组织在默认会计核算体系中的上级核算组织是在哪个会计期间，取这个期间的期初结存金额、单价。）\\ 4、期初单价来源：期末加权平均价，是指期初余额中的单价=期末余额/基本单位数量。  |
| 收入单价（基本）  | 1、如果收入发出单价来源选择期初单价来源，那么收入单价取数同期初单价（参考期初结存单价的取数）。收入金额=收入单价（基本）*收入数量（基本）。\\ 2、如果收入发出单价来源选择库存单据的成本价，那么收入金额根据过滤条件取过滤时间范围内的对应物料的所有收入总成本的合计（注意是本位币总成本）。收入单价（基本）=收入金额/收入数量（基本）。                                                                                                                                                                                                                       |
| 发出单价（基本）  | 1、如果收入发出单价来源选择期初单价来源，那么发出单价取数同期初单价（参考期初结存单价的取数）。发出金额=发出单价（基本）*发出数量（基本）。\\ 2、如果收入发出单价来源选择库存单据的成本价，那么发出金额根据过滤条件取过滤时间范围内的对应物料的所有发出总成本的合计（注意是本位币总成本）。发出单价（基本）=发出金额/发出数量（基本）。                                                                                                                                                                                                                       |
| 发出金额      | 1、如果收入发出单价来源选择期初单价来源，那么发出单价取数同期初单价（参考期初结存单价的取数）。发出金额=发出单价（基本）*发出数量（基本）。\\ 2、如果收入发出单价来源选择库存单据的成本价，那么发出金额根据过滤条件取过滤时间范围内的对应物料的所有发出总成本的合计（注意是本位币总成本）。发出单价（基本）=发出金额/发出数量（基本）。                                                                                                                                                                                                                       |
