## 【页面】库存查询显示设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BA%93%E5%AD%98%E6%9F%A5%E8%AF%A2%E6%98%BE%E7%A4%BA%E8%AE%BE%E7%BD%AE

====== 库存查询显示设置 ======
====== 1 概述 ======
库存查询显示设置是面向库存查询轻应用的相关功能及显示配置。
====== 2 功能说明 ======
===== 2.1 显示设置 =====
  * 库存查询轻应用版本切换：2.0为新版，1.0为旧版。以下所有功能相关配置，都只针对2.0版本生效。
  * 默认显示数量：选择以哪种维度来显示库存数量。
  * 默认显示单位：选择显示库存数量的单位。
  * 库存明细字段相同时合并显示：勾选此参数，当物料库存详情页的明细行字段值相同时，将库存数量合并显示。
  * 汇总字段：配置库存查询物料列表所显示的字段，添加在列表的字段可以支持显示与搜索。注意：只有列表上显示的字段才能支持搜索，若未添加显示，则无法搜索出结果。
  * 明细字段：配置库存查询物料详情页所显示的字段。
===== 2.2 筛选项设置 =====
  * 筛选项：选择启用库存查询筛选页中展示和支持的筛选项，勾选“启用筛选”即可启用。
===== 操作说明 =====
保存：所有更改需要进行保存操作后生效。

====== 1 移动设置概述 ======
===== 1.1 概述 =====
移动应用面向移动端设备使用，各个移动应用可针对不同的业务场景在移动端快速便捷地完成业务。移动设置是各移动应用的基础配置，用来支撑移动应用的正常运行。

===== 1.2 系统特性 =====
本系统主要包含以下特性：

  - 支持与云之家、企业微信、钉钉、WeLink、飞书等多个移动平台进行配置，实现移动应用与金蝶AI星空数据互联；
  - 支撑标准轻应用和自定义的配置。

## 【页面】轻应用标准集成参数设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BD%BB%E5%BA%94%E7%94%A8%E6%A0%87%E5%87%86%E9%9B%86%E6%88%90%E5%8F%82%E6%95%B0%E8%AE%BE%E7%BD%AE

====== 轻应用标准集成参数设置 ======
====== 1 概述 ======
轻应用标准集成参数设置是控制标准集成安装的轻应用进行消息发送的相关参数管理功能。
====== 2 功能说明 ======
  * 发送轻应用消息：控制是否开启发送轻应用消息。
  * 发送消息失败后补发：控制当发送轻应用消息失败后，是否自动再补发。
  * 消息补发时间范围：控制手动更新补发时的消息时间范围，即时间范围内的消息会被重新补发。
  * 消息日志保留：控制轻应用标准集成消息日志保留的时间范围。
  * 启用待办不同时发送消息通知：此参数仅适用于WeLink平台，启用后，发送待办不会再同时发送消息通知消息。
  * 飞书审批消息通过待办任务推送：启用后，飞书的待办审批任务发送到飞书的审批中心。
  * 企业微信待办消息显示处理状态：启用后，企业微信收到的待办任务消息可以显示是否已处理。

## 【页面】轻应用标准集成配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BD%BB%E5%BA%94%E7%94%A8%E6%A0%87%E5%87%86%E9%9B%86%E6%88%90%E9%85%8D%E7%BD%AE

====== 轻应用标准集成 ======
轻应用标准集成是提供给用户将轻应用集成到不同移动平台的快捷功能。通过此功能，用户可以快捷访问轻应用集成的相关信息，将移动应用集成到手机端进行使用。
目前已支持云之家、企业微信、钉钉、WeLink、飞书平台，用户根据自己所使用的平台查看对应信息，并按说明进行安装集成即可。
