====== 1 发票管理概述  ======


===== 1.1 发票管理概述  =====

发票是指购销商品、提供或者接受劳务和其他经营活动中开具、收取的收付款凭证。发票管理系统记录企业开具和收取的发票，一方面作为会计核算的原始凭证，准确地反映经济活动；另一方面也是缴纳税款的依据，同时为配合审计和税务机关执法检查提供全面综合的信息。

===== 1.2 发票管理总体流程图  =====

本产品中是根据应收单、应付单生成发票，所以流程图请参照应收款管理流程图、应付款管理流程图。

===== 1.3 系统特性 =====

本产品发票管理系统的主要功能包括：

  * 提供多种发票，分别对应实际业务中的不同种发票，包括销售增值税专用发票、销售普通发票、采购增值税专用发票、采购普通发票、费用发票；
  * 销售增值税专用发票、销售普通发票、采购增值税专用发票支持按照含税单价或者不含税单价不同的录入方式；
  * 支持应收应付单据一对一或合并开票；
  * 支持应付开票核销和应收开票核销；
  * 提供与金税系统的对接；
  * 提供与电子税务局的对接。

====== 2 发票管理业务专题 ======

企业从供应市场购买产品或服务并收取供应商开具的发票；同时销售产品或劳务并开具发票给客户。采购发票会分为采购增值税专用发票、采购普通发票和费用发票；销售会分为销售增值税专用发票、销售普通发票。各种发票都如何使用，他们之间有什么区别，本章节将重点阐述以上问题。

===== 2.1 采购发票 =====

采购增值税专用发票、采购普通发票、费用发票都是从供应商处取得的发票。一般供应商如果是增值税一般纳税人，则可以提供增值税专用发票；小规模纳税人则只能提供采购普通发票。用户只有收到采购增值税专用发票，相应的税额才可以作为进项税额抵扣，收到的采购普通发票一般情况下是不可以抵扣税额的，但是根据税法，购买农产品等收到的普通发票允许抵扣。

费用发票适用于采购或者销售过程中发生的一些费用，例如材料采购过程中同时发生了一些运费等。


===== 2.2 销售发票 =====

销售发票包括：销售增值税专用发票和销售普通发票。如用户的客户为一般纳税人，则一般开具销售增值税专用发票；如用户的客户为小规模纳税人，则开具销售普通发票。用户无论开具哪种销售发票，都是按照相同的方法缴纳增值税。目前，通过销售发票单据，已支持开

具下述特定业务类型的数电发票：成品油发票 、建筑服务发票、货物运输服务发票、旅客运输服务发票、不动产销售服务发票、不动产租赁服务发票 、卷烟发票、差额征税-差额开票、差额征税-全额开票、机动车、自产农产品销售发票。

====== 发票管理系统参数 ======


发票管理系统的参数主要有如下几个：

**【基本选项】**

  ***__启用客户物料对应表__**

该参数用于发票单据上，根据单据上的客户+物料自动带出客户物料字段相关字段值。启用该参数后，发票单据才显示客户物料相关字段；不启用则不显示。  属于组织级参数。

  ***__发票成本取数核算体系__**

该参数用于选择发票获取成本的核算体系，可以勾选多个会计核算体系，默认勾选为默认会计核算体系，属于组织级参数。

**【自动生成】**

  ***__应收单审核时自动生成销售发票__**

勾选该参数，应收单审核时系统自动生成销售发票。系统会根据客户基础资料中的发票类型决定生成增值税专用发票还是普通发票。
如果生成的销售发票必录字段完整，则单据为创建状态；如果必录字段不完整，则单据为暂存状态。


  ***__应付单审核时自动生成采购发票__**

勾选该参数，应付单审核时系统自动生成采购发票。系统会根据供应商基础资料中的发票类型决定生成增值税专用发票还是普通发票。
如果生成的采购发票必录字段完整，则单据为创建状态；如果必录字段不完整，则单据为暂存状态。

**【其他参数】**

  ***__发票只校验金额__**

启用该参数后，销售增值税专用发票、销售普通发票允许物料数量为0或者空，仅根据红蓝字发票校验金额是否合规。若不启用该参数，则物料数量为必填。

  ***__存在未审核的单据时不允许结账__**

启用该参数后，结账所属期间的业务单据必须全部是已审核状态，否则结账提示不允许。

  ***__销售发票开票限行__**

支持设置单张销售发票单据最多允许的行数限制，销售发票单据明细行若超过设置的行数，不允许保存。不启用该参数时，保存不限制明细行数。当明细行数超出8行时，执行金税开票自动开具销货清单。

  ***__销售发票开票限额__**

支持设置单张销售发票单据最多允许的金额限制，销售发票单据明细不含税金额合计超过设置的限额，不允许保存。不启用该参数时，保存不限制明细行的不含税金额合计，超出金税开票系统的限额时，系统自动进行拆分预览。

  ***__下推采购发票支持汇率携带__**

参数默认不启用。下推红蓝字采购发票（共4张）时，自动取实时汇率。启用参数后，支持从上游订单、应付单或蓝字采购发票，携带汇率。

  ***__下推销售发票支持汇率携带__**

参数默认不启用。下推红蓝字销售发票（共4张）时，自动取实时汇率。启用参数后，支持从上游订单、应收单或蓝字销售发票，携带汇率。

  ***__电票批量推送同一收票人时取消校验购货方是否一致__**

参数默认不启用。启用后，金税开票单列表【电票批量推送】时，会取消强制校验所选发票的购货方纳税识别号一致。

**【金税开票】**

  ***__分录行折扣按行打印__**

勾选该参数，金税开票时，发票可以显示独立折扣行，以满足在发票上体现出价格优惠信息的需求。

  ***__开票时弹出开票信息__**

勾选该参数，金税开票时，支持预览，保证金税开票的准确性。

  ***__启用获取开票信息__**

数据中心级参数，勾选该参数后，可在客户基础资料及销售发票单上使用【获取开票信息】功能。客户基础资料的名称中，至少需要维护四个字段，点击按钮后自动根据名称调用接口查询符合条件的企业名称、税号、银行账号、地址电话等信息。选中目标行返回信息后，客户基础资料或发票开票信息自动完成信息填充，减少手工录入。

  ***__列表支持批量拆分开票__**

启用参数后，支持在销售发票单据列表批量选中多张单据执行金税开票。（目前批量开票不支持预览）   

  ***__超离线限额或时长导致金税开票失败时，自动重开__**

受税局设置的离线开票限额或时长的限制，企业批量发起开票后会出现离线开票失败的情况，需要手动发起重开。启用该参数后，执行计划【自动发起离线金税开票失败的重开】生效，若金税开票单或销售发票单据因离线开票返回开票失败，系统自动对标记离线标识的单据重新发起开票，无需人工反复多次重新发起。   

  ***__发票代码、号码字段启用简化显示模式__**

销售发票单据完成开票后，实际开出的发票代码、号码字段会反写至单据头，多个代码号码按照逗号隔开显示。启用该参数后，简化显示模式，对启用参数后返回的开票结果，按照【发票号码（共n张）】的格式显示，且支持点击查询按钮查看全部发票明细。

  ***__简化模式下拆分开票最大允许张数__**

受发票号码及代码字段长度的限制，原金税开票拆分后台默认拆分上限为15张，现当发票代码、号码字段启用简化显示模式时，开票拆分张数的上限支持通过修改参数来设置，简化模式下拆分开票最大允许张数缺省值：300。

  ***__发票红冲时，仅允许校验通过的红字专票信息表发起开票__**

启用参数后，销售增值税发票开具红字发票时，对信息表的状态进行强校验。 

  ***__剩余发票份数＞0且少于拆分发票份数时，允许提交开票__**

建议启用。  启用参数后，若拆分份数大于剩余可用，优先完成部分发票开具，剩余未开的发票待购买新的空白发票后继续完成开具即可。  若不启用该参数，当拆分份数大于剩余可用时，会导致拆分中断，无法开票。

  ***__单价*数量与不含税金额不一致时，自动反算单价__**

为了减少开票校验不通过的情况，单价*数量与不含税金额不一致时，生成金税开票单会自动反算不含税单价。取消该参数后，金税开票单不再反算单价，发票会按照上游单据原始单价进行开票。

  ***__销售开票相邻负数行合并计算折扣额__**

启用该参数后，销售发票存在多行相邻相同税率负数行，生成金税开票单时先自动合并负数行金额，然后再进行折扣分摊。
 
  ***__金税开票单折扣行改按折扣额直接计算__**

启用该参数后，按含税单价录入时，金税开票单折扣行税额直接通过折扣行价税合计/（1+税率）*税率计算，按不含税单价录入时，税额=折扣行不含税金额*税率计算。

**【金税收票】**

  ***__收票时智能匹配应付__**

当勾选发票管理参数“扫一扫收票时智能匹配应付”，通过扫一扫收票生成的“收票单”自动智能匹配业务应付单，自动生成“采购增值税发票”，
1、匹配具体规则如下：

结算组织匹配：按购货方的纳税识别号在“金税连接识别”自动匹配“结算组织”；
供应商匹配：按销货方的纳税识别号在“供应商-纳税识别号”自动匹配“供应商”；
物料匹配：按物料对应表中，按“供应商+物料名称“自动匹配“物料”；
单位匹配：按单位对应表中，按“单位名称”自动匹配“单位”；


2、按“结算组织+供应商+物料+数量+单位”智能查找对应的“业务应付单/暂估应付单”，按业务日期的先后顺序，自动下推生成采购增值税发票/财务应付单，且自动保存、提交、审核；

3、当不勾选发票管理参数“扫一扫收票时智能匹配应付”，通过扫一扫收票生成的“收票单”不需要智能匹配业务应付单，仅生成收票单

  ***__已使用过的发票不允许导入__**
可参见 https://vip.kingdee.com/article/14988 发票管理模块新增的四个参数说明

  ***__发票抬头与企业名称不一致的发票不允许导入__**
可参见 https://vip.kingdee.com/article/14988 发票管理模块新增的四个参数说明

  ***__发票抬头与税号不一致发票不允许导入__**
可参见 https://vip.kingdee.com/article/14988 发票管理模块新增的四个参数说明

  ***__发票查验不通过的发票不允许导入__**
可参见 https://vip.kingdee.com/article/14988 发票管理模块新增的四个参数说明

  ***__扫一扫收票按组织生成二维码__**

数据中心级参数。 启用参数后，按照当前组织生成唯一的二维码，切换不同组织后生成对应组织的二维码。用户扫码收取的发票，来源组织自动带出二维码中记录的组织。

====== 进项发票明细表 ======

====== 1 报表功能 ======

进项发票明细表反映了企业当期的进项发票的明细情况，包括进项发票的价税合计、税额、可抵扣额等情况。

====== 2 操作说明 ======


===== 2.1 分组汇总 =====


系统提供分组汇总功能。分组汇总依据包括：往来单位编码、原币、单据类型、业务日期、发票日期。

===== 2.2 显示选项 =====


报表显示选项包括：

  * 包括未审核单据，默认不勾选
  * 按单据显示，默认不勾选
以上选项用户可以根据自己的应用选择。

====== 进项费用增值税发票 ======


====== 1 使用前提 ======

公共资料已设置，包括供应商、币别、结算方式、物料、费用项目、单位、采购部门、采购组、采购员、组织信息、账簿信息、汇率体系等。

====== 2 功能路径 ======

【税务管理】－>【发票管理】－>【采购发票】

====== 3 字段说明 ======

主要字段说明

^ 字段名   ^ 说明                                ^
| 业务日期  | 定义当前业务发生的日期；默认取当前日期。  |
| 发票号  | 填写向供应商收取的纸质发票上的发票号码，便于查询和对账。  |
| 发票日期  | 填写向供应商收取的纸质发票上的发票日期，便于查询和对账。  |
| 按含税单价录入  | 采购增值税专用发票字段。定义不同的报价方式。若勾选，报价为含税单价，录入含税单价，相关金额字段根据含税单价换算；若不勾选，报价为不含税单价，录入不含税单价，相关金额字段根据不含税单价换算。  |
| 税额  | 采购增值税专用发票、采购普通发票、进项费用增值税发票、进项费用普通发票字段  |
| 可抵扣税额  | 采购增值税专用发票、采购普通发票、进项费用增值税发票、进项费用普通发票字段  |
====== 4 操作说明 ======

===== 4.1 选单 =====

  * 第一步，在采购发票-新增界面点“选单”，弹出选择单据的窗口，选择应付单点“确认”；
  * 第二步，在弹出的应付单列表中勾选要生成发票的应付单，然后点“返回”，回到采购发票的新增界面；
  * 第三步，采购发票的字段会从应付单自动携带过来，可以修改单价、数量等；
  * 第四步，点击“保存”。

===== 4.2 应付单下推 =====

  * 第一步，进入【财务会计】－>【应付款管理】－>【采购应付】－>【应付单列表】；
  * 第二步，在列表中勾选要生成发票的应付单点 “下推”，弹出选择单据的窗口，选择采购发票，点“确认”；
  * 第三步，若只生成一张发票，系统返回采购发票的新增界面，字段从应付单自动携带过来，可以修改单价、数量等，点击“保存”；若生成多张发票，系统返回的界面分成上下两部分，上面是发票的列表，下面是采购发票的新增界面，可以通过点击“上一行”、“下一行”查看和修改多张发票的内容，修改完成后点击“生成全部”或在新增界面一一点击“保存。

说明：应付单下推发票可以选择按明细分录合并或者不按明细分录合并。

===== 4.3 应付开票核销 =====

应付单与发票可以进行核销，具体请参照应付开票核销。

====== 5 业务说明 ======

===== 5.1 不同发票逻辑说明 =====

采购增值税专用发票、进项费用增值税发票的税额采用价外税的逻辑；进项费用普通发票的税额采用价内税逻辑，采购普通发票支持价内价外两种计算逻辑。

====== 金税开票单 ======

Cloud系统能够与金税系统自动化连接，自动提交开票，开票完成后，系统自动将发票号、日期等信息反写回系统，真正实现Cloud和航天金税的无缝连接。

===== 1 功能路径 =====

【财务会计】－>【发票管理】－>【金税接口】－>【金税开票单列表】

===== 2 金税开票 =====

===== 2.1 操作说明 =====

销售普通发票、销售增值税专用发票、销项费用普通发票、销项费用增值税发票的单据或列表的【业务操作】下包含金税发票相关操作菜单。

  *金税发票开具：生成金税开票单，自动提交金税开票，完成纸质发票开具。

  *金税发票作废：自动提交金税发票作废请求。

  *金税发票打印：自动提交金税发票打印请求。

  *金税发票打印清单：自动提交金税发票打印清单请求。

  *金税发票查询：自动提交金税发票查询请求。

  *获取普通发票信息：自动提交查询请求，获取对应税盘的剩余纸质普通发票份数。

  *获取专用发票信息：自动提交查询请求，获取对应税盘的剩余专用发票份数。

  *电子发票开具：生成金税开票单，自动提交金税开票，完成电子发票开具。

  *电子发票查询：自动提交金税发票查询请求。

  *获取电子普通发票信息：自动提交查询请求，获取对应税盘的剩余电子普通发票份数。

  *获取电子专用发票信息：自动提交查询请求，获取对应税盘的剩余电子专用发票份数。
 
金税开票单列表上【电票批量推送】操作。

  * 列表勾选需要操作【电票批量推送】的金税开票单，满足多张发票的来源组织、购货方纳税识别号、购货方收票手机号、购货方电子邮箱一致校验条件的方可允许批量推送。

  * 弹出【发票接收方信息确认】界面，确认本次推送手机号、电子邮箱，如信息有误，进行修改处理，电子邮箱支持最多输入2个邮箱，中间用英文状态下的分号隔开。

  * 确认后，点击【提交】。

====== 金税连接设置 ======

每个需要开具金税发票的组织都需要设置对应的金税连接。


===== 1 功能说明 =====

金税连接地址为金税盘的ip地址及接口。
     
获取金税盘信息：直接获取金税盘上的企业名称、纳税人识别号及发票限额、剩余发票份数，企业电话及开户行账号需手工录入。

主副盘管理：支持一个组织设置多个税盘，需在金税连接设置中设置主副盘标识。

是否托管电票：电子普通发票为托管开票时，需勾选托管电票标识，否则默认调用本地税盘开票，获取不到本地税盘信息时，开票报错。

无盘收票：向税局申请了软证书的企业，无需插入税盘，可直接通过云端获取进项发票数据。

税控设备类型：按照现有的税盘全种类，目前将税盘按照服务商区分为：百望、航天信息、税务ukey    据实设置即可，不同类型的金税设备，在开票时执行不同的校验规则。

显示发票卷：勾选参数后，若税盘存在多个发票卷，则弹窗显示，用户可指定票卷进行开票。 目前仅航信盘支持，其他2种暂不支持，该参数默认灰显。

启动全电发票：针对未启用全电发票的用户，无需勾选，已启用全电发票的用户，则由用户自行手动勾选，该参数将影响开具发票时，系统校验【单价*数量-不含税金额】与【不含税金额*税率-税额】的逻辑，勾选后，开票校验取【开票校验参数】中全电发票的校验规则。

开票校验参数：根据不同开票软件的开票校验规则配置不含税金额差异校验范围、税额差异校验范围，在开票时按此参数设置执行不同的校验规则。

校验取数规则：默认参数不勾选，如果勾选了校验取数规则的参数，则按照实际值校验，不通过校验时，需触发单价反算（前提：勾选了强制反算单价的参数）。

开票校验参数详细说明：[[https://vip.kingdee.com/article/453214375738730240|优化销售开票不含税金额及税额的差异校验规则]]

【财务会计】－>【发票管理】－>【金税接口】－>【销售发票引出】

====== 3 字段说明 ======

^ 字段名   ^ 说明                                ^
| 方案编码  | 选择引出的方案。  |
| 其他过滤条件  | 指定界面已有字段之外的过滤条件,F8查询返回。   |

  * 第四步，在主界面查看引出报告。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%94%80%E5%94%AE%E5%8F%91%E7%A5%A8%E8%B4%A6%E9%BE%84%E5%88%86%E6%9E%90%E8%A1%A8

[[发票管理#销售发票账龄分析表|<<返回发票管理界面]]

====== 销售发票账龄分析表 ======

====== 1 报表功能 ======

销售发票账龄分析表主要提供给以发票作为生成应收账款凭证单据的客户，用于进行以发票为基准的账龄分析。

====== 2 操作说明 ======


===== 2.1 核销 =====


因为核销会影响报表数据的准确性，因此系统在报表展示界面提供了调用核销的功能。

===== 2.2 分组汇总 =====


系统提供分组汇总功能。分组汇总依据包括：客户名称、币别、结算组织。

===== 2.3 账龄分组设置 =====


系统提供用户自定义账龄分组功能。通过该功能用户可以自由定义自己需要报表显示的账龄区间。

===== 2.4 账龄计算标准 =====


账龄计算标准分为按照业务日期计算和按照发票日期计算。
===== 2.5 显示选项 =====


报表显示选项包括：

  * 包括未审核单据，默认不勾选
  * 按单据显示，默认不勾选
以上选项用户可以根据自己的应用选择。

## 【页面】销售增值税专用发票
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%94%80%E5%94%AE%E5%A2%9E%E5%80%BC%E7%A8%8E%E4%B8%93%E7%94%A8%E5%8F%91%E7%A5%A8

[[发票管理#销售发票|<<返回发票管理界面]]

====== 销售增值税专用发票 ======

====== 1 使用前提 ======

公共资料已设置，包括客户、币别、结算方式、物料、单位、销售部门、销售组、销售员、组织信息、账簿信息、汇率体系等。

====== 2 功能路径 ======

【税务管理】－>【发票管理】－>【销售发票】

====== 3 字段说明 ======

主要字段说明

^ 字段名   ^ 说明                                ^
| 业务日期  | 定义当前业务发生的日期，默认取当前日期。  |
| 开票方式  | 提供选项：手工和税控；由金税接口引入的发票开票方式默认为税控，手工录入或由应收单下推生成的发票开票方式默认为手工。  |
| 发票号  | 填写开具给客户的纸质发票上的发票号码，便于查询和对账。  |
| 发票日期  | 填写开具给客户的纸质发票上的发票日期，便于查询和对账。  |
| 录入含税单价  | 定义不同的报价方式。若勾选，报价为含税单价，录入含税单价，相关金额字段根据含税单价换算；若不勾选，报价为不含税单价，录入不含税单价，相关金额字段根据不含税单价换算。  |
====== 4 操作说明 ======

===== 4.1 选单 =====

  * 第一步，在销售发票-新增界面点“选单”，弹出选择单据的窗口，选择应收单点“确认”；
  * 第二步，在弹出的应收单列表中勾选要生成发票的应收单，然后点“返回”，回到销售发票的新增界面；
  * 第三步，销售发票的字段会从应收单自动携带过来，可以修改单价、数量等；
  * 第四步，点击“保存”。
===== 4.2 应收单下推 =====

  * 第一步，进入【财务会计】－>【应收款管理】－>【销售应收】－>【应收单列表】；
  * 第二步，在列表中勾选要生成发票的应收单，点 “下推”，弹出选择单据的窗口，选择销售发票点“确认”；
  * 第三步，若只生成一张发票，系统返回销售发票的新增界面，字段从应收单自动携带过来，可以修改单价、数量等，点击“保存”；若生成多张发票，系统返回的界面分成上下两部分，上面是发票的列表，下面是销售发票的新增界面，可以通过点击“上一行”、“下一行”查看和修改多张发票的内容，修改完成后点击“生成全部”或在新增界面一一点击“保存”。

应收单下推发票可以选择按明细分录合并或者不按明细分录合并。
===== 4.3 应收开票核销 =====

应收单与发票可以核销，具体请参照应收开票核销。

====== 5 业务说明 ======

===== 5.1 逻辑说明 =====

销售增值税专用发票、销项费用增值税发票的税额采用价外税的逻辑；销项费用普通发票、销售普通发票的税额支持价内价外两种计算逻辑。

应收单下推发票可以选择按明细分录合并或者不按明细分录合并。
===== 4.3 应收开票核销 =====

应收单与发票可以核销，具体请参照应收开票核销。

====== 5 业务说明 ======

===== 5.1 逻辑说明 =====

销售增值税专用发票、销项费用增值税发票的税额采用价外税的逻辑；销项费用普通发票、销售普通发票的税额支持价内价外两种计算逻辑。

====== 4 操作说明 ======

===== 4.1 选单 =====

  * 第一步，在销售发票-新增界面点“选单”，弹出选择单据的窗口，选择应收单点“确认”；
  * 第二步，在弹出的应收单列表中勾选要生成发票的应收单，然后点“返回”，回到销售发票的新增界面；
  * 第三步，销售发票的字段会从应收单自动携带过来，可以修改单价、数量等；
  * 第四步，点击“保存”。
===== 4.2 应收单下推 =====

  * 第一步，进入【财务会计】－>【应收款管理】－>【销售应收】－>【应收单列表】；
  * 第二步，在列表中勾选要生成发票的应收单，点 “下推”，弹出选择单据的窗口，选择销售发票点“确认”；
  * 第三步，若只生成一张发票，系统返回销售发票的新增界面，字段从应收单自动携带过来，可以修改单价、数量等，点击“保存”；若生成多张发票，系统返回的界面分成上下两部分，上面是发票的列表，下面是销售发票的新增界面，可以通过点击“上一行”、“下一行”查看和修改多张发票的内容，修改完成后点击“生成全部”或在新增界面一一点击“保存”。

应收单下推发票可以选择按明细分录合并或者不按明细分录合并。
===== 4.3 应收开票核销 =====

应收单与发票可以核销，具体请参照应收开票核销。
