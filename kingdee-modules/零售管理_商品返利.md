====== 商品返利 ======
====== 1 商品返利整体应用 ======
===== 1.1  商品返利概述 =====
在连锁零售业务中，企业向供应商采购商品时，供应商会提供各种返利政策给予企业，企业需要在内部能统计出，相关的返利数据，以便与供应商进行准确的对账管理。一般商品返利主要分为：返利赠品、冲抵应付货款，直接返利现金三种模式。
===== 1.2 商品返利特性 =====


  *    支持返利赠品、返利现金、冲抵应付账款等模式；
  *    返利商品基础数据可来源于采购入库单、应付单、销售出库单；
  *    商品返利管理与财务应付管理、采购管理集成，返利结算可生成其他应付单、付款单或赠品采购订单。

## 【页面】商品返利政策
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E8%BF%94%E5%88%A9%E6%94%BF%E7%AD%96

==== 商品返利政策 ====
1.  支持多销售组织、多供应商按返利周期编制返利政策；

2.  支持全额累进和超额累计两种返利计算的累进方式；

3.  设置明细返利政策，设置返利条件及返利的处理方式等。

应用场景：

1.  根据营销策略，设置详细可执行的返利政策；

2.  确定返利客户、返利商品、返利条件、返利处理方式等内容。

## 【页面】商品返利模式
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E8%BF%94%E5%88%A9%E6%A8%A1%E5%BC%8F

==== 商品返利模式 ====

1.  返利模式由返利类别和返利方式组合完成；

2.  返利对象：可以按照供应商或供应商分类设置；

3.  返利依据：可以定义为采购入库单、应付单，或者销售出库单。定义销售出库单，商品上需要填写默认供应商；

4.  返利属性：根据返利需求，以及返利依据勾选相应的参数值：如购买数量、购买金额、指标完成率等。

## 【页面】返利账户维护
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%BF%94%E5%88%A9%E8%B4%A6%E6%88%B7%E7%BB%B4%E6%8A%A4

==== 返利账户维护 ====

1.  返利账户；利账户是用于定义促销结算时存储返利金额的返利账户类型，每个供应商在不同的返利类型上有不同的返利账户；

2.  系统预设基本账户。

应用场景：

1.  系统初始化时，需要对不同供应商商品进行返利账户初始化。商品返利余额查询中进行初始化操作；

2.  针对不同的供应商及返利类型需要定义不同的商品返利账户。
