## 【页面】住宿补助标准
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BD%8F%E5%AE%BF%E8%A1%A5%E5%8A%A9%E6%A0%87%E5%87%86

**功能概述** 

对不同的报销级别不同的出差地域设置差旅标准。
   
**功能路径** 

【财务会计】－>【费用管理】－>【差旅标准】－>【住宿补助标准】   

**操作说明**
 
  - 编码：根据需要手工维护，也可系统自动生成。
  - 名称：根据需要手工维护。 
  - 报销级别：选择报销级别。
  - 描述：根据需要手工维护。
  - 差旅费类型：选择差旅费类型，一般情况下选择系统预置的差旅费类型为“住宿费、出差补助”。
  - 标准类型：可选择住宿标准或者补助标准，便于当企业有自定义的差旅费类型时，也能进行标准的设置。
  - 出差地域：选择出差地域。
  - 币别：自动获取本位币。
  - 标准（人/天）：企业根据自身的标准进行维护。

## 【页面】借款到期预警分析
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%80%9F%E6%AC%BE%E5%88%B0%E6%9C%9F%E9%A2%84%E8%AD%A6%E5%88%86%E6%9E%90

**报表功能**

借款到期预警分析以汇总表的形式反映截止到指定日期，已到期的未归还的借款及过期天数、未到期的借款及未过期天数。通过借款到期预警分析，可以协助企业监督往来单位的还款（报销）进度。

**功能路径**

【财务会计】－>【费用报销】－>【报表分析】－>【借款到期预警分析】

**过滤条件**

快捷页签说明
|**过滤项**||**说明**|
|费用承担组织||必须是有结算职能的业务组织，支持多选。|
|隶属方案||可选“结算职能”的隶属方案。如选择了隶属方案，则需要显示该隶属方案下所有组织的借款情况。|
|预警计算日期||到期借款的过期天数和未过期天数通过“预警计算日期”与“预计还款日期”的比较得出。即以预警计算日期 －预计还款日期来计算，正数即为过期天数，负数即未过期天数。|
|包含未到期单据||勾选该选项报表中会列示“预警计算日期+提前天数*天”内将到期的借款单据。需要注意的是，未到期借款只显示提前天数*天内将到期的借款，超过*天的不显示。|
|提前天数||只有勾选“包括未到期”之后，“提前天数”才可以填列。|
分组汇总页签说明：

通过该功能用户可设置报表汇总的统计方式，系统提供按费用承担组织、费用承担部门、往来单位、币别进行汇总，允许多选进行组合汇总。

条件、排序、显示隐藏列页签说明：

为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性

**报表查询**

过滤条件过滤完毕进入“借款到期预警分析”界面，报表展示的内容包括：费用承担组织、费用承担部门、往来单位、币别、单据类型、单据编号、申请组织、申请部门、申请人、费用项目、申请日期、预计还款日期、尚未还款日期、过期天数和未过期天数；这些数据来源于历史借款余额、申请借款的费用申请单以及申请借款的出差申请单。其中尚未还款金额取自这些单据的【借款余额】。

## 【页面】借款账龄分析表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%80%9F%E6%AC%BE%E8%B4%A6%E9%BE%84%E5%88%86%E6%9E%90%E8%A1%A8

**报表功能**

借款账龄分析表主要是对已到期的未核销借款的时间分布进行分析，便于企业对不同时间段内的逾期账款采取不同对策，提高借款回收率。

**功能路径**

【财务会计】－>【费用报销】－>【报表分析】－>【借款账龄分析表】

**过滤条件**

快捷页签说明
| **过滤项**     || **说明**                                                                                                                                                   |
| 费用承担组织      || 必须是有结算职能的业务组织，支持多选。                                                                                                                                      |
| 隶属方案        || 可选“结算职能”的隶属方案。如选择了隶属方案，则需要显示该隶属方案下所有组织的借款账龄。                                                                                                             |
| 账龄计算日期      || 通过预计还款日/实际付款日与账龄计算日来计算过期天数，报表的“尚未还款余额”为账龄计算日当天的值                                                                                                         |
| 数据来源        || 按预计还款日计算天数，到期借款的过期天数通过“账龄计算日期“与“预计还款日”的比较得出，即以账龄计算日期-预计还款日来计算，正数为过期天数。根据过期天数来判断所属的账龄分组\\ 按实际付款日计算天数，到期借款的过期天数通过“账龄计算日期”与“实际付款日”的比较得出，即以账龄计算日期-实际付款日来计算。  |
| 按单据显示       || 勾选该选项，报表按具体的单据列示；不勾选该选项，则根据分组汇总字段汇总显示。                                                                                                                   |
账龄分组设置说明

通过该功能用户可以自由定义账龄区间，下面以系统预置的分组为例进行说明：

|**账龄分组**||**天数**||**控制含义**|
|0-30天||30||账龄在30天之内的借款|
|31-60天||60||账龄在大于31天小于60天之内的借款|
|61-90天||90||账龄在大于61天小于90天之内的借款|
|91天以上||>90||账龄大于90天的借款|

## 【页面】关账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%B3%E8%B4%A6

**功能概述**

为避免数据随意变更，系统提供关账功能。关账期间的业务数据不允许再次新增，但可以提交、审核、反审核。

**操作前提**

  - 已经结束初始化。
  - 如果选中系统参数“申请单未审核不允许关账”、“报销单未审核不允许关账”和“转移单未审核不允许关账”，则要求对应的业务单据均已审核。

**功能路径**

【财务会计】－>【费用报销】－>【期末处理】－>【关账】

**操作说明**

用户录入结束日期，点击【关账】功能按钮进行系统结账处理。支持任意日期进行关账。

现有的关账控制修改：关账日期以前的费用单据不允许新增，可以提交、审核、反审核。

关账日期以前的费用单据，在提交/审核时产生下游单据，需根据下游业务系统的结账日期，判断下游单据的业务日期：

下游系统未结账，则直接取原单据的申请日期；下游系统结账，则取系统当期日期。

## 【页面】初始化
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%88%9D%E5%A7%8B%E5%8C%96

结束初始化条件：组织未结束初始化、历史借款余额已经审核。
反初始化条件：组织未关帐、未结束初始化。

## 【页面】历史借款余额
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8E%86%E5%8F%B2%E5%80%9F%E6%AC%BE%E4%BD%99%E9%A2%9D

**功能概述**

用于启用费用报销系统前，将企业实际业务中已借出未归还的费用类借款余额，进行统一的录入，用于日后报销业务的平账。类似于应付系统的期初付款单。

**功能路径**
【员工服务】－>【人人报销】－>【历史借款余额】－>【历史借款余额】

**字段说明**
| **字段**     || **说明**                       |
| 申请组织       || 原借款的申请组织                     |
| 付款组织       || 原借款的付款组织                     |
| 借款日期       || 必须早于费用报销系统的启用日期              |
| 预计还款日期     || 必须晚于费用报销系统的启用日期（含启用当日）       |
| 往来单位类型     || 包括客户、供应商、员工、部门、其他往来单位        |
| 往来单位       || 借款方，即债务人。                    |
| 原申请人       || 原借款的申请人                      |
| 原申请部门      || 原借款的申请部门                     |
| 历史借款余额     || 截止系统启用日，往来单位借支尚未偿还的费用类借款金额。  |

**特殊说明**
历史借款余额列表，增加了几个重要字段：已报销金额、已退款金额、冲销金额（尾差核销的金额）、借款余额（借款余额=历史借款余额-已报销-已退款-冲销金额），这些字段由系统根据下游单据的审核或核销状态自动填列，能直观地反映历史借款余额的后续跟踪信息，也是相关报表的数据分析来源。


**操作说明**
下推：在单据或列表界面点击【下推】可选择下推差旅费用报销单或费用报销单，该操作将历史借款余额单据的相关信息带入下游单据，一方面简化单据录入工作，另一方面会将这种存在关联关系的上下游单据自动核销。
引入：历史借款余额支持从EXCEL文件引入功能，具体操作为列表界面【选项】——【引入】。

## 【页面】发票合并生成明细规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%8F%91%E7%A5%A8%E5%90%88%E5%B9%B6%E7%94%9F%E6%88%90%E6%98%8E%E7%BB%86%E8%A7%84%E5%88%99

**功能概述** 

对不同的发票类型，设置合并的类型，比如对增值税专用发票设置单张发票合并、对定额发票设置为跨发票合并、对机票、火车票设置为不合并。
   
**功能路径** 

【财务会计】－>【费用管理】－>【智能填报管理管理】－>【发票合并生成明细规则】   

**操作说明**
 
  - 编码：根据需要手工维护，也可系统自动生成。
  - 名称：根据需要手工维护。 
  - 描述：根据需要手工维护。
  - 发票类型：选择发票云的发票类型。   
  - 合并类型：可选择不合并、单张发票合并、跨发票合并。
  - 备注：根据需要手工维护。

 **合并类型说明**

 1、不合并：一条发票明细生成一行费用明细；

 2、单张发票合并：对单张发票按照税率、费用项目、差旅费类型、是否实名一致的合并生成费用明细；

 3、跨发票合并：按照发票类型、差旅类型、费用项目、税率、是否实名一致的合并生成费用明细（针对当次导入的发票满足条件的合并生成明细）

===== 1.1费用管理概述 ===== 
   
费用管理系统，是面向企业财务，提供员工报销的后端管理系统，包括初始化、核销管理、报表分析、期末处理、账务处理、参数设置、智能填报管理。与出纳、应付系统无缝集成，帮助企业费用合理统筹，防止不必要的浪费和支出。

===== 1.3 费用管理系统特性 =====
  * **特性1**：全面核销管理，精准跟踪费用借款与报销
  - 通过申请到报销的下推、历史借款到报销的下推、实报实销，系统自动完成绝大部分应付付款的核销工作，向导核销、尾差核销、手工核销功能，帮助企业费用报销人员、报销申请人精准的跟踪每一笔费用借款、费用报销的报销、付款、退款情况。
  
  * **特性2**：多方位报表分析
  - 提供借款跟踪表、账龄分析表、费用汇总表、费用明细表、报销与付款汇总分析表、费用报销跟踪表、借款到期预警分析表分析借款、费用的具体情况。

  * **特性3**：与出纳、应付系统无缝集成
  - 报销单审核自动产生应付系统的费用报销其他应付单，申请单借款/需付款报销单支持下推出纳的费用报销付款申请单/费用报销付款单进行付款

  * **特性4**：与发票云集成，支持收票自动填报
  - 在报销单上进行收票，可自动填写费用明细

  * **特性5**：提供差旅标准功能，精准控制所有员工的费用
  - 在差旅费报销时，对住宿费、出差补助费提供标准控制

====== 2.1费用管理、人人报销系统使用流程======
[[费用报销使用流程|费用管理、人人报销使用流程]]

第一步，基础设置

在系统使用前，我们需要先做基础设置。

首先，设置公用资料。与费用报销紧密相关的有：费用项目、员工、部门、供应商、客户、币别、组织机构、会计核算体系、账簿信息、汇率体系等。

在金蝶AI星空正式进行日常业务操作前，首先需要完成费用报销申请组织的启用日期设置，再将上系统前还未归还的费用历史借款余额进行统一的整理和录入，最后进行结束初始化操作。进入【财务会计】－>【费用管理】－>【初始化】对上述提到关于费用报销系统初始化工作。
第三步，日常业务操作

企业费用管理人员，根据企业实际需要，进行费用承担对象的移转操作。
企业费用管理人员，根据企业实际需要，对于零星尾差无法核销的借款、报销，进行尾差核销处理；

第四步，期末处理

目前，建议只在费用管理系统，进行费用移转单、费用核销单的凭证处理。而费用申请时的借款、费用报销，都直接在应付系统以及出纳系统进行凭证处理。期末进行关账处理，进入【财务会计】－>【费用管理】－>【账务处理】、【期末处理】。

  * 企业费用管理人员，根据企业实际需要，对于零星尾差无法核销的借款、报销，进行尾差核销处理；
  * 进入【财务会计】－>【人人报销】－>【人人报销首页】－>【费用申请】（或者进入人人报销直接新增费用申请单）、【费用报销】、【费用移转】；【财务会计】－>【费用管理】－>【核销管理】对上述提到关于费用报销系统的日常业务操作。
**第四步，期末处理**
  * 目前，建议只在费用管理系统，进行费用移转单、费用核销单的凭证处理。而费用申请时的借款、费用报销，都直接在应付系统以及出纳系统进行凭证处理。期末进行关账处理，进入【财务会计】－>【费用管理】－>【账务处理】、【期末处理】。

## 【页面】费用报销手工核销
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E6%8A%A5%E9%94%80%E6%89%8B%E5%B7%A5%E6%A0%B8%E9%94%80

**功能概述** 

手工核销包括手工匹配核销、手工特殊核销。手工匹配核销是根据系统设定的核销方案进行核销（例如往来单位一致、币别一致、承担部门一致）。手工特殊核销可以针对不同往来单位的付款单与报销单进行核销。
   
**功能路径** 

【财务会计】－>【费用报销】－>【核销管理】－>【费用报销手工核销】   

**操作说明**
 
  - 通过【报销过滤】和【付款过滤】，将目标需要手工核销的单据过滤出来。 
  - 设置将生成核销单的单据日期。（核销单的单据日期，必须大于组织最近的关账日期） 
  - 设置需要核销单据的核销金额。进行【核销】，系统会根据单据情况自动判断是否生成核销单。该核销单为已审核状态。   

**特殊说明**

过滤出来的付款单“是否其他预付”标识为“是”，通过手工核销与报销单进行核销时，会自动产生核销单。

## 【页面】费用报销系统启用日期设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E6%8A%A5%E9%94%80%E7%B3%BB%E7%BB%9F%E5%90%AF%E7%94%A8%E6%97%A5%E6%9C%9F%E8%AE%BE%E7%BD%AE

**功能概述**

需要进行费用报销的业务组织，统一进行各组织费用报销系统的启用日期设置。或由于误操作等原因，需要将已启用的业务组织，进行反启用。

**功能路径**

【财务会计】－>【费用报销】－>【初始化】－>【启用日期设置】。

**业务说明**

启用日期设置后如果有业务发生（含初始数据），则启用日期不再允许修改。勾选组织所在行的复选框，选择启用日期，点击启用则完成。

**特殊说明**

费用报销系统一旦启用，应付系统、出纳系统相关单据涉及费用报销业务，将不允许费用报销类单据的手动新增。涉及单据有：

应付系统：其他应付单（单据类型=费用报销其他应付单）

出纳系统：付款申请单（单据类型=费用报销申请）、付款单（单据类型=费用报销付款单）、付款退款单（单据类型=费用报销付款退款单）。即：费用报销系统一旦启用，所有费用报销业务都必须从费用报销系统发起。

## 【页面】费用明细表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E6%98%8E%E7%BB%86%E8%A1%A8

**报表功能**

费用明细表用于展示某一段期间内各组织、部门或产品所承担的明细费用状况。企业可以根据实际需要按不同维度分析费用的构成。
费用明细表支持联查到具体的费用报销单单据，也支持通过费用汇总表进行联查明细。

**功能路径**

【财务会计】－>【费用报销】－>【报表分析】－>【费用明细表】

**过滤条件**
快捷页签说明:
| **过滤项**     || **说明**                                                                    |
| 费用承担组织      || 必须是有结算职能的业务组织，支持多选。                                                       |
| 隶属方案        || 可选“结算职能”的隶属方案。如选择了隶属方案，则需要显示该隶属方案下所有组织的费用情况。                              |
| 申请日期（至）     || 参与费用明细表统计的单据日期范围，日期范围以外的单据不参与报表分析计算。\\ 申请日期对应于费用报销单的“申请日期”或费用转移单的“转移日期”。  |
| 包含费用转移单     || 不勾选该选项，报表仅对费用报销单、差旅费报销单进行分析；\\ 勾选该选项，报表对费用报销单、差旅费报销单和费用转移单进行分析。           |
| 包含未审核单据     || 不勾选该选项，报表仅对已审核的费用报销单、差旅费报销单和费用转移单进行分析；\\ 勾选该选项，报表对所有非作废的费用报销单、差旅费报销单和费用转移单进行分析。           |

分组汇总页签说明:

条件、排序、显示隐藏列页签:

为系统通用设置，可设置查询结果的字段值过滤、显示列排序以及字段列的显示隐藏属性。

过滤条件过滤完毕进入“费用明细表”界面，报表展示的内容包括：费用承担组织、费用承担产品、费用承担部门、往来单位、费用项目、单据类型、单据编码、事由、币别、费用发生额。
若不勾选“包含费用转移单”，数据来源于费用报销单和差旅费报销单，其中费用发生额取费用报销单、差旅费报销单的核定报销金额；若勾选“包含费用转移单”数据来源于费用报销单、差旅费报销单和费用转移单，其中费用发生额取费用报销单、差旅费报销单的核定报销金额+费用转移单的转入金额-费用转移单的转出金额。

双击查询到的明细行，即可打开具体的单据，供进一步查看详情。

## 【页面】费用核销单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E6%A0%B8%E9%94%80%E5%8D%95

**功能概述**

1、尾差核销，会自动生成的核销单。财务人员基于核销单，生成总账凭证；
例如：
某报销单还剩下0.1元未付，该报销人已离职，此时，通过尾差核销生成核销单，基于该核销单生成总账凭证，一方面确认收益，一方面确认其他应收款增加。
某费用借款还剩下1元未归还，该报销人已离职，此时，通过尾差核销生成核销单，基于该核销单生成总账凭证，一方面确认损失，一方面确认其他应收款减少。

2、借款为预付款的核销，自动产生的核销单。这个核销单是针对借款如果勾选了系统参数“借款核销时自动产生核销单”，则费用申请单/出差申请单借款时，下游单据“付款申请单/付款单”单据头字段“是否其他预付”值为“是”，否则为“否”，“是否其他预付”字段为“是”的付款单产生的凭证是：借：其他应收  贷：银行存款，此类付款单与其他应付单（凭证为：借：费用  贷：其他应付）核销时，就会产生核销单，财务人员基于此核销单生成凭证：借：其他应付  贷：其他应收


**功能路径**

【财务会计】－>【费用管理】－>【核销管理】－>【核销单】
