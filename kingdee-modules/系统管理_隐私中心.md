## 【页面】密钥管理
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AF%86%E9%92%A5%E7%AE%A1%E7%90%86

[[隐私中心|<<返回隐私中心]]

====== 1 概述 ======

通过【密钥设置】，创建用于加密存储的密钥，然后加密设置时可以为字段选择创建的密钥，绑定加密解密关系。

====== 2 功能说明 ======
新增密钥设置，就是创建一套用于字段存储加密解密的配置。密钥由系统自动创建，用户仅需要设置密钥的相应参数即可。
  * 启用加盐：更高安全要求的密钥防盗设置。
  * 启用密钥文件分段存储：一旦启用该参数，必须妥善自行备份保管密钥文件。如果丢失密钥文件或环境迁移时，可通过在备份账套的相应密钥设置中，通过引入密钥文件自动装载到指定路径。如果对应环境下缺少密钥文件，将导致对应历史加密数据无法解密读取识别。

## 【页面】脱敏字段
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%84%B1%E6%95%8F%E5%AD%97%E6%AE%B5

[[隐私中心|<<返回隐私中心]]

====== 1 概述 ======

通过【脱敏字段】，将业务对象上的字段设为加入允许脱敏的白名单。

====== 2 功能说明 ======
新增脱敏字段，目的是将业务对象上的字段设为加入允许脱敏的白名单，同时以【脱敏类型】作为维度，将字段归纳到对应脱敏类型下，便于统一管理。

例如，新增脱敏字段界面，业务对象选择“供应商”、脱敏类型选择“邮箱”，则系统检查脱敏类型“邮箱”的数据类型=文本类型，将供应商的文本类型字段列示为可选字段。勾选对应记录邮箱信息的文本字段，点击保存，则表示此字段属于脱敏类型“邮箱”，允许脱敏配置（参见脱敏方案配置介绍如何开启脱敏）。

## 【页面】脱敏方案配置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%84%B1%E6%95%8F%E6%96%B9%E6%A1%88%E9%85%8D%E7%BD%AE

[[隐私中心|<<返回隐私中心]]

====== 1 概述 ======

通过【脱敏方案配置】，进行脱敏开启设置，给业务对象的字段设置脱敏策略，可选项有查询脱敏、引出脱敏、打印脱敏、WebAPI查询脱敏，按需要开启。

====== 2 功能说明 ======

===== 2.1 脱敏策略 =====

脱敏策略分为表单脱敏、引出脱敏、打印脱敏、WebAPI脱敏。

表单脱敏：指在列表、表单等界面显示该字段时进行脱敏。

引出脱敏：指通过标准引出功能，输出数据时进行脱敏。

打印脱敏：指通过打印、套打导出等依据打印功能，输出数据时进行脱敏。

WebAPI脱敏：指通过WebAPI接口查询数据时，输出数据时进行脱敏。

**注意，开启引出脱敏时，如果使用“按引入模版引出”时不进行脱敏，避免用户误操作引入时，直接将脱敏字符串引入系统覆盖原有数据。**
===== 2.2 脱敏选项 =====

点击查看明文：该字段默认是脱敏显示，在列表或表单界面上脱敏字段会提供小眼睛图标，点击图标时显示真实明文；单据上编辑该字段时，必须点击小眼睛更新真实数据后才可以编辑。

脱敏显示：该字段一直脱敏显示，不可以查看明文。

明文显示：该字段明文显示，不进行脱敏处理。


其中，表单脱敏的管控方式有三个选项，分别是点击查看明文、脱敏显示、明文显示。其他脱敏策略没有点击查看明文的交互。

## 【页面】脱敏类型
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%84%B1%E6%95%8F%E7%B1%BB%E5%9E%8B

[[隐私中心|<<返回隐私中心]]

====== 1 概述 ======

对脱敏数据进行业务归类，设置【脱敏类型】，便于从敏感数据角度对同类数据进行批量管理。例如，系统预置常用脱敏类型标签有身份证、银行卡、手机号、联系电话等；


====== 2 功能说明 ======
新增脱敏类型，主要是维护数据类型（可选文本、数值、日期）。
不同数据类型在后续关联脱敏规则时支持的脱敏规则有所差异，而且关联脱敏字段时，仅允许选择数据类型匹配的字段。

## 【页面】脱敏规则
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%84%B1%E6%95%8F%E8%A7%84%E5%88%99

[[隐私中心|<<返回隐私中心]]

====== 1 概述 ======

通过【脱敏规则】，将脱敏类型与脱敏规则算法建立对应关系。

====== 2 功能说明 ======
新增脱敏规则，目的是为脱敏类型指定一个脱敏配置，每一个脱敏类型仅允许设置一种脱敏配置。

脱敏配置目前支持掩码方式脱敏，通过配置掩码方式、掩码位置、掩码字段，实现脱敏配置的自定义组合。

## 【页面】隐私中心
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%9A%90%E7%A7%81%E4%B8%AD%E5%BF%83

﻿
====== 1 概述 ======

《中华人民共和国个人信息保护法》自2021年11月1日起施行，需要针对软件中涉及个人隐私的数据进行脱敏处理，确保产品符合国家个保法规。
在隐私中心模块，您可以通过对数据从存储、查询、显示、打印、引出等阶段涉及到的敏感数据进行加密、脱敏等处理，防止敏感数据遭到有意或无意的误用、泄漏或盗窃，从而帮助企业采取合理措施来保护其敏感数据的机密性和完整性、可用性。

====== 2 系统特性 ======

入口：【系统管理】-【隐私中心】，分为脱敏管理与加密管理两块功能。

隐私中心相关特性如下：

  * 脱敏类型定义，配置字段对应的脱敏类型标签；

  * 脱敏规则定义，配置隐私类型使用不同的脱敏算法规则；

  * 隐私字段、加密字段白名单管理，按需开启隐私管控；

  * 查询脱敏、打印脱敏、引出脱敏、WebAPI查询脱敏；

  * 提供密钥管理，支持对字段进行数据库加密存储；
====== 3 功能说明 ======

===== 3.1 脱敏管理 =====
系统将敏感数据处理从功能应用角度进行划分：脱敏管理与加密管理。
脱敏管理主要是处理系统中各个功能应用层面对数据进行脱敏处理，而加密管理主要是从数据库存储角度，对数据进行加密存储处理。
目前系统仅提供文本、数值、日期类型字段可以进行脱敏与加密管理。

操作步骤：
  - 对脱敏数据进行业务归类，设置【脱敏类型】，便于从敏感数据角度对同类数据进行批量管理。例如，系统预置常用脱敏类型标签有身份证、银行卡、手机号、联系电话等；
  - 通过【脱敏字段】，将【脱敏类型】与业务对象的字段建立对应关系；
  - 同时通过【脱敏规则】，将【脱敏类型】与脱敏规则算法建立对应关系；
  - 最后，在【脱敏方案】中进行脱敏开启设置，给业务对象的字段设置脱敏策略，可选项有查询脱敏、引出脱敏、打印脱敏、WebAPI查询脱敏，按需要开启。

===== 3.2 加密管理 =====
操作步骤：
  - 设置【密钥管理】，选择加密算法、加盐、密钥文件等，自定义加密配置。注意，如果生成密钥文件，需要对该文件进行妥善保管及备份，后续数据解密时会依赖该密钥文件。
  - 设置【加密字段】，系统采用白名单管理方式，需要开启加密管控功能的字段必须先加入加密字段中。金蝶标准产品预置字段由金蝶进行原厂评估后，放入到加密字段白名单，二开字段可以视需要添加。
  - 启用加密存储，对基础资料或单据对象的字段进行加密启用设置，开启后通过向导界面，对系统已有数据进行加密升级。
  - 由于加密存储会清空原有字段的历史数据，转为加密方式存储，开启加密前时需注意所有的二开取数方式需要进行检查，未采用平台标准接口读取数据的功能将受到影响（例如SQL直接查询字段，数据库表中的原始字段值已获取不到）需要考虑调整相关原有二开功能，采用标准接口读取解密后的数据应用与业务功能。
