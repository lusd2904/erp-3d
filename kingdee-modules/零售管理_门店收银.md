## 【页面】esc功能键简介
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=esc%E5%8A%9F%E8%83%BD%E9%94%AE%E7%AE%80%E4%BB%8B

==== ESC功能键简介====
ESC功能键简介，开单收银界面按ESC键弹出功能列表：

1. 销售挂单处理：客户选择商品后，暂时不进行结算，可以通过挂单方式，先收银下一客户零售单，待客户需要结算时，调出挂起的零售单，重新进行收银结算处理。（受后台参数控制，挂单是否允许退出收银界面）;

2. 重打销售小票：对于需要重新打印零售单的，可以通过该功能实现；进入后，选择当日需要重打的小票，若是历史小票，需要进入门店收银-选择零售单打印;

3. 班次交接打印：门店收银员班次交接时，可以选择班次交接，打印出上一个收银员的收银情况;

4. 更改用户密码：更改收银员登录密码。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E9%A2%84%E5%AE%9A

==== 商品预定 ====


支持门店商品预订、收取预订尾款、取订等业务：

1. 连锁门店支持客户商品预定，可以先登记顾客信息，预订单需要填写顾客信息；收取订金（根据后台参数设置，是否需要完全收取） ；

2. 商品预订后，生成预订单，可以在POS端和后台中查询；

3. 商品预订之后，可以在开单收银中进行收取预订单尾款，以及取订操作；

4. 预订单支持可部分退订，部分转销售的单也支持退订；

5. 预定单转销售单后退货只能使用红冲模式，不能对预订单进行修改处理；

6. 商品预订页支持聚合支付，可后台设置。

## 【页面】开单收银
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%BC%80%E5%8D%95%E6%94%B6%E9%93%B6

==== 开单收银 ====

1. 进入开单收银界面，首先确认是否会员消费，若是，选择会员，刷会员卡（支持刷卡、手输手机号、卡号、会员姓名等方式查询会员）；

2. 确认会员后，输入商品（支持扫码、手输商品条码、编码、支持从商品查询中查询后确认）；

3. 输入商品后，系统自动根据会员政策和促销政策，匹配商品价格；

4. 支持手工折扣（单品折扣、整单折扣、单品定价、整单定价）受收银员权限控制；

5. 选择收款方式，支持与支付宝、微信、旺POS、银联商务联用等；

6. 完成结算，根据参数设置可以进行自动结算或手工点击结算；

7. 结算完成，系统自动打印小票，注意打印小票收后台参数与POS机打印设置影响；

8. 若是要增删或者浏览购物详情等，可以在中间工具栏中进行操作，同时可以在更多中寻找需要的功能。数据录入后，不能退出开单收银系统；

9. 零售开单系统自动获取后台参数默认零售客户。顾客信息只作为参考记录使用；

10. 零售开单支持单据辅助类型， POS小票打印详细折扣信息后台可控制；

11. 提交到POS的导购订单支持合并支付，支持多张零售单同时支付，支付完成后生成多张零售单，并生成多张小票，其零售单的销售员信息不会因合并收款而改变，合并收款支持多付款方式；

12. 系统还支持挂账、礼券功能，积分支付、抹零、赠送、线上APP功能承接、退货（后续详细展开）等功能；

13. 以上所有的操作均可通过设置相关快捷键完成，详见参数设置；

## 【页面】退货模式
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%80%80%E8%B4%A7%E6%A8%A1%E5%BC%8F

==== 退货模式 ====
1. POS端支持零售退货，支持的退货类型包括：红冲，凭小票退货、无源单退货；

2. 红冲：不能修改退货单的数量、退款方式，所有信息按照源单进行退货操作；

3. 凭小票退货：退货时，需要输入零售单号，根据零售单选择需要退货的商品以及退货结算方式；

4. 微信、支付宝、银联卡集成结算的只能进行红冲退货；

5. 以上两种退货，退货数量不能超过源单；

6. 无小票退货：没有系统凭据直接退货，受后台参数控制，是否允许无小票退货；

7. 提全屏模式下，在开单收银通过ESC快捷键调出退货模式选择，触屏模式，在更多里面点击退货模式。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%97%A8%E5%BA%97%E6%94%B6%E9%93%B6%E5%BA%94%E7%94%A8%E4%BB%8B%E7%BB%8D

==== 门店收银应用介绍 ====

应用介绍：

1. 功能主要包括：开单收银、现在业务数据、商品预定、门店导购单、门店缴款单、备用金单、客户销售发票申请单、

门店客诉登记表、预定订单尾款、门店单品销售报表、团购、挂账还款；

2. 在查看中可以查询：商品档案、门店（后台）库存、开单收银（零售单查询）、传输监控、商品预定、门店导购、收

银员日报、缴款单、备用金、发票申请、挂账流水。

应用场景：

1. 门店收银版块主要处理门店前端进行零售款开单、客户商品预订、导购业务、以及门店收银缴款业务、客户发票申请、客户投诉以及预订单尾款处理等业务；

2. 门店收银是多端POS系统的核心业务功能，涵盖了大部分门店零售业务的日常操作。
