## 【页面】wise业务单据映射
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=wise%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E6%98%A0%E5%B0%84

======1 功能描述 ======

WISE业务单据映射用来配置WISE系统与金蝶云系统对应业务单据的字段对应关系，然后执行并同步数据。 业务单据执行同步时会自动检查，如果是基础资料字段则调用基础资料映射关系进行处理，如果是其他字段则直接插入具体数据。

集成平台专门提供了WISE升级金蝶云的解决方案, 针对WISE财务和供应链的关键单据预设了集成方案。可以支持WISE业务单据集成和财务凭证的集成。

WISE集成方案区分未完成业务和历史数据：
1）未完成业务：主要针对出入库、收付款、票据业务执行；集成数据只关注未完成部分；
2）历史数据：与源系统数据一致，上下游关联关系信息不考虑。

预设WISE业务单据映射方案是没有源系统连接的，且预设方案不能修改，仅供参考。

**功能路径**

【系统管理】→【集成平台】→【WISE数据集成】→【WISE业务单据映射】


======2 功能操作 ======

 ===== 2.1 新增 =====

WISE业务单据映射新增，可参考【[[业务单据映射#新增|业务单据映射]]】的新增介绍。

新增WISE业务单据映射方案，还可以采用复制方式来新增映射方案，即：选中要复制的方案，点击【复制】按钮，复制方案时需要先指定源系统字段，然后根据自身需要调整方案内容。

预设的映射方案不能修改，不可指定源系统连接，所以是不能直接用作集成数据同步的，仅供用户参考。

 ===== 2.2 启用 =====


WISE业务单据映射启用，可参考【[[业务单据映射#启用|业务单据映射]]】的启用介绍。

 ===== 2.3 手动执行 =====


WISE业务单据映射手动执行，可参考【[[业务单据映射#手动执行|业务单据映射]]】的手动执行介绍。

 ===== 2.4 引出方案 =====

WISE业务单据映射引出方案，可参考【[[业务单据映射#引出方案|业务单据映射]]】的引出方案介绍。

 ===== 2.5 引入方案 =====


WISE业务单据映射引入方案，可参考【[[业务单据映射#引入方案|业务单据映射]]】的引入方案介绍。

======3 相关说明 ======

  - 具体关于业务单据映射，参见【[[业务单据映射|业务单据映射]]】的介绍。
  - 具体关于业务单据集成情况，参见【[[业务单据集成查询|业务单据集成查询]]】的介绍；
  - 针对关键单据提供预设方案，中间单据不考虑，例如：收料通知单、质检单之类。

    注意：
    
    1、需区分未完成业务和历史数据：
    1）未完成业务：针对出入库、收付款、票据业务执行；集成数据只关注未完成部分；
    2）历史数据：与源系统数据一致，上下游关联关系信息不考虑； 
    
    2、未完成业务和历史数据强烈推荐集成到不同的Cloud数据中心，这样做的好处是两块业务可以分步进行，不互相影响。

## 【页面】wise基础资料映射
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=wise%E5%9F%BA%E7%A1%80%E8%B5%84%E6%96%99%E6%98%A0%E5%B0%84

======1 功能描述 ======

WISE基础资料映射用来匹配WISE系统和金蝶云系统基础资料以及基础资料值的对应关系，以作为后续业务单据集成的对应关系。

集成平台专门提供了WISE升级金蝶云的解决方案, 针对WISE财务和供应链的关键单据预设了集成方案。可以支持WISE业务单据集成和财务凭证的集成。

WISE基础资料映射方案是整个WISE升级金蝶云的解决方案的基础部分，主要提供了关键单据同步时将会引用到的所有WISE基础资料映射内容。

预设WISE基础资料映射方案是没有源系统连接的，且预设方案不能修改。

**功能路径**

【系统管理】→【集成平台】→【WISE数据集成】→【WISE基础资料映射】

**前提**

需要配置人员有一定的开发经验，并且对源系统的表结构有一定的掌握。
======2 功能操作 ======

===== 2.1 新增 =====

WISE基础资料映射新增，可参考【[[基础资料映射#新增|基础资料映射]]】的新增介绍。

新增WISE基础资料映射方案，还可以采用复制方式来新增映射方案，即：选中要复制的方案，点击【复制】按钮，复制方案时需要先指定源系统字段，然后根据自身需要调整方案内容。

预设的映射方案不能修改，不可指定源系统连接，所以是不能直接用作集成数据同步的，仅供用户参考。

===== 2.2 执行 =====

基础资料映射方案新增后，点击【执行】，系统就按照匹配规则执行映射。

===== 2.3 映射查询 =====

主要查询基础资料映射结果，必须完成执行操作后，才可以进行映射查询，详见【[[基础资料映射查询|基础资料映射查询]]】的介绍。

  - 按照映射字段显示基础资料值的映射结果；
  - 匹配不上的，则Cloud处显示为空，支持F8选择进行手工指定；
  - 如果觉得匹配结果不对，可以【清除Cloud数据】进行清除Cloud的基础资料，支持批量清除，清除后再进行手工指定；也可以直接手工调整；
  - 如果觉得匹配结果很多不合要求，可以【清空映射数据】进行删除，再重新执行映射。

======3 相关说明 ======

具体关于基础资料映射，参见【[[基础资料映射|基础资料映射]]】的介绍。

## 【页面】wise方案配置向导
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=wise%E6%96%B9%E6%A1%88%E9%85%8D%E7%BD%AE%E5%90%91%E5%AF%BC

====== 1 功能描述 ====== 

针对WISE数据集成提供了专门的入口和配置向导，引导用户将WISE数据同步同步到金蝶云。

**功能路径**

【系统管理】→【集成平台】→【数据集成】→【WISE数据集成】→【WISE方案配置向导】

**前提**

  - 确定好源系统数据库，并已建立【[[源系统数据连接|源系统数据连接]]】；
  - 已梳理所有引用的基础资料，并准确定义所有【[[wise基础资料映射|wise基础资料映射]]】方案；
  - 已确定好同步的业务单据，并准确定义所有【[[wise业务单据映射|wise业务单据映射]]】方案；

====== 2 功能操作 ====== 

===== 2.1 建立源系统数据连接 =====

详见【[[源系统数据连接|源系统数据连接]]】的介绍。

===== 2.2 WISE映射方案 =====

  - 梳理并确定需同步哪些业务单据，并梳理所有引用的基础资料；
  - 为所有引用的基础资料建立WISE基础资料映射方案，详见【[[wise基础资料映射#新增|wise基础资料映射]]】的介绍；
  - 为所有需同步的业务单据建立WISE业务单据映射方案，详见【[[wise业务单据映射|wise业务单据映射]]】的介绍；

===== 2.3 WISE方案配置向导 =====

集成平台采用配置向导引导完成WISE升级金蝶云，点击打开WISE方案配置向导。具体步骤如下：

  第一步：选择源系统连接
  输入方案编码、方案名称、源系统连接。多组织的应用场景下，要选择组织机构。
  
  第二步：基础资料映射范围
  基础资料映射范围界面默认显示的是该源系统连接对应的WISE基础资料映射方案系统预设的WISE基础资料映射方案，在这里勾选所需要用到基础资料映射方案即可。
  前提是要根据实际业务梳理调整基础资料映射方案，并指定方案对应的源系统连接。
  
  第三步：业务单据映射范围
  业务单据映射范围界面默认显示的是该源系统连接对应的WISE业务单据映射方案，这里勾选所需要同步的业务单据映射方案，点击【完成】，即会提示：保存方案成功，是否马上执行方案？再点击【确定】按钮就可。
  
  第四步：后台任务执行集成
  后台执行可以降低对当前操作的影响，同时高效利用资源。可以在【当前用户】下面【我的后台计划】查看业务单据的集成情况。

===== 2.4 WISE集成查询 =====

查询已创建的WISE集成方案和集成结果，未执行的可以点击【执行】按钮再次执行，详见【[[wise集成方案|WISE集成方案]]】的介绍。

====== 3 补充说明 ====== 
    1、需区分未完成业务和历史数据：
    
    1）未完成业务：针对出入库、收付款、票据业务执行；集成数据只关注未完成部分；
    2）历史数据：与源系统数据一致，上下游关联关系信息不考虑； 
    
    2、未完成业务和历史数据强烈推荐集成到不同的Cloud数据中心，这样做的好处是两块业务可以分步进行，不互相影响。

## 【页面】wise集成方案
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=wise%E9%9B%86%E6%88%90%E6%96%B9%E6%A1%88

====== 1 功能描述 ====== 

WISE数据集成查询所有通过【[[wise方案配置向导|WISE方案配置向导]]】生成的方案，对于未完成的向导，可以继续执行。

**功能路径**

【系统管理】→【集成平台】→【数据集成】→【WISE数据集成】→【WISE集成方案】

 ====== 2 功能操作 ======

 

===== 2.1 WISE集成查询=====

点击【WISE集成方案】菜单，即可打开“WISE集成方案”界面查看已创建的WISE集成方案和集成结果。

===== 2.2 新增=====

点击【新增】按钮，即可打开【[[wise方案配置向导#新增|WISE方案配置向导]]】界面进行新增。

===== 2.3 复制=====

选择某个WISE集成的配置方案，点击【复制】按钮，即可复制该方案，并在已有配置的基础上调整方案并执行。

===== 2.4 执行=====

对于未执行的方案，可以点击【执行】按钮再次执行。

===== 2.5 删除=====

可以删除未成功同步的方案。


 ====== 3 业务说明 ======

  - 针对关键单据提供，中间单据不考虑，例如：收料通知单、质检单之类；
  - 区分未完成业务和历史数据 1）未完成业务：针对出入库、收付款、票据业务执行；集成数据只关注未完成部分；2）历史数据：与源系统数据一致，上下游关联关系信息不考虑； 
  - 未完成业务和历史数据强烈推荐集成到不同的金蝶云数据中心，这样做的好处是两块业务可以分步进行，不互相影响。

## 【页面】业务单据同步
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E5%90%8C%E6%AD%A5

====== 1 功能描述 ====== 

业务单据同步用来配置源系统与金蝶云系统对应业务单据的字段对应关系，然后执行并同步数据。
业务单据执行同步时会自动检查，如果是基础资料字段则调用基础资料映射关系进行处理，如果是其他字段则直接插入具体数据。

支持执行周期的选择，提供了自动执行（通过执行周期控制）和手工执行两个方式，支持业务单据映射方案导出和导入，实现跨库应用。

映射规则：业务单据映射规则不支持业务单据的关联关系，只集成单据本身。


**功能路径**

【系统管理】→【集成平台】→【数据集成】→【业务单据同步】

**前提**

需要配置人员有一定的开发经验，并且对源系统的表结构有一定的掌握。

 ====== 2 功能操作 ======

 ===== 2.1 新增 =====

点击【业务单据同步】菜单，打开业务单据映射列表界面，点击【新增】按钮，即可打开“业务单据同步”界面进行创建。

  1、需要先确定源系统连接，这样源系统的表和表字段才可以出来；
  
  2、选择金蝶云系统的业务单据，系统自动携带金蝶云该单据的字段情况；
  
  3、金蝶云组织机构，多组织情况下，确定集成数据在哪个组织下；
  
  4、执行周期，业务单据集成后台执行的时间计划；
  
  5、业务单据表映射，需要确定两个系统的表对应关系；需要确定两个系统的唯一标识；金蝶云的单据实体是按照BOS IDE中实体展示，与单据页签不一定一一对应的；
  
  6、业务单据表字段映射
     1）按照需要设置字段级别的映射关系，主要是配置源系统的表字段
     2）需要确定源系统的主键和外键
     3）金蝶云字段默认显示，包括必填以及默认值
     4）源字段规则表达式：支持将源系统字段运算结果集成到金蝶云指定字段，这个在未完成业务的应用场景会频繁应用到
     5）源字段过滤条件：可以针对字段直接配置过滤条件，省去通过视图或者自定义SQL的处理
     
  7、点击工具栏的【保存】按钮，则业务单据同步创建完成。
  
  使用小窍门：
     1）业务单据映射前，需要先确定集成的范围；
     2）业务单据表字段映射手工逐一操作琐碎，可以利用【业务操作】->【引出】，在EXCEL中手工维护后再【引入】。

 
 ===== 2.2 启用 =====

业务单据同步方案需要【启用】后才可以执行业务单据映射创建后，点击工具栏的【启用】按钮，则业务单据映射启用完成。

启用会自动判断：

1）金蝶云必填字段的相关内容是否齐全；

2）校验源系统字段的长度比金蝶云的长，则会自动截断；

3）校验源系统字段的类型与金蝶云不一致，会做相应处理。

系统提供了自动执行（通过执行周期执行）和手工执行两个同步方式。启用后，默认情况下，系统会按照执行周期控制，对执行时点的源系统最新内容进行自动同步，Administrator也可以点击【手工执行】按钮，这样就会在手工执行的执行时点将源系统的内容同步。

若启用的业务单据同步方案正在执行同步，则该方案不能被删除。

 ===== 2.3 手动执行 =====

业务单据同步启用后，点击【手动执行】，执行完成后，会看到同步的提示信息，还可以在业务单据集成查询中查看集成结果。

 ===== 2.4 引出方案 =====

系统提供了业务单据同步方案引入和引出功能，以便实现业务单据同步方案的跨业务库应用，例如：在测试库完成测试业务单据同步方案可以部署到正式库，这样减少业务单据映射方案的多次维护。

点击工具栏【选项】->【引出方案】按钮，即可将业务单据同步方案选择的数据库连接方案以及应用到基础资料映射方案均合并打包导出。

 ===== 2.5 引入方案 =====

点击工具栏【选项】->【引入方案】按钮，选择引入文件，即可将业务单据同步方案以覆盖的方式引入。若系统存在正在执行的业务单据同步方案，是不能引入的。

通过【引出/引入方案】实现业务单据及其基础资料映射方案的跨库应用。
 ====== 3 其他说明 ======

  - 业务单据集成不考虑上下游的关联关系及其信息，只管自身；
  - 业务单据同步方案启用时，会判断合法性、字段长度、字段类型等； 
  - 需要配置人员有一定的开发经验，并且对源系统的表结构有一定的掌握；
  - 具体关于业务单据集成情况，参见【[[业务单据集成查询|业务单据集成查询]]】的介绍。

## 【页面】业务单据同步查询
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E5%90%8C%E6%AD%A5%E6%9F%A5%E8%AF%A2

====== 1 功能描述 ====== 
业务单据同步查询可以查看业务单据的集成结果，按照业务单据同步方案查看明细情况；

通过【业务单据同步查询】可以查看同步过程中出现的错误信息，以便分析成功失败情况。


**功能路径**

【系统管理】→【集成平台】→【集成执行情况】→【业务单据同步查询】

 ====== 2 功能操作 ======

业务单据同步查询的执行状态包括成功、部分成功、失败；执行情况是按同步方案显示同步结果，本方案成功多少条，失败多少条，并可以打开查看明显数据。

## 【页面】业务单据数据查询
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E6%95%B0%E6%8D%AE%E6%9F%A5%E8%AF%A2

====== 1 功能描述 ====== 

系统提供独立的业务单据数据查询入口，供用户查看集成数据内容，同时支持删除数据。

**功能路径**

【系统管理】→【集成平台】→【数据集成】→【业务单据数据查询】 

 ====== 2 功能操作 ======

 ===== 2.1 查询集成数据 =====

## 【页面】业务单据映射
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%B8%9A%E5%8A%A1%E5%8D%95%E6%8D%AE%E6%98%A0%E5%B0%84

====== 1 功能描述 ====== 

业务单据同步用来配置源系统与金蝶云系统对应业务单据的字段对应关系，然后执行并同步数据。
业务单据执行同步时会自动检查，如果是基础资料字段则调用基础资料映射关系进行处理，如果是其他字段则直接插入具体数据。

支持执行周期的选择，提供了自动执行（通过执行周期控制）和手工执行两个方式，支持业务单据映射方案导出和导入，实现跨库应用。

映射规则：业务单据同步时映射规则不支持业务单据的关联关系，只集成单据本身。


**功能路径**

【系统管理】→【集成平台】→【数据集成】→【业务单据同步】

**前提**

需要配置人员有一定的开发经验，并且对源系统的表结构有一定的掌握。

 ====== 2 功能操作 ======

 ===== 2.1 新增 =====

点击【业务单据同步】菜单，打开业务单据映射列表界面，点击【新增】按钮，即可打开“业务单据同步”界面进行创建。

  1、需要先确定源系统连接，这样源系统的表和表字段才可以出来；
  
  2、选择金蝶云系统的业务单据，系统自动携带金蝶云同步该单据的字段情况；
  
  3、金蝶云组织机构，多组织情况下，确定集成数据在哪个组织下；
  
  4、执行周期，业务单据集成后台执行的时间计划；
  
  5、业务单据表映射，需要确定两个系统的表对应关系；需要确定两个系统的唯一标识；金蝶云的单据实体是按照BOS IDE中实体展示，与单据页签不一定一一对应的；
  
  6、业务单据表字段映射
     1）按照需要设置字段级别的映射关系，主要是配置源系统的表字段
     2）需要确定源系统的主键和外键
     3）金蝶云字段默认显示，包括必填以及默认值
     4）源字段规则表达式：支持将源系统字段运算结果集成到金蝶云指定字段，这个在未完成业务的应用场景会频繁应用到
     5）源字段过滤条件：可以针对字段直接配置过滤条件，省去通过视图或者自定义SQL的处理
     
  7、点击工具栏的【保存】按钮，则业务单据映射创建完成。
  
  使用小窍门：
     1）业务单据映射前，需要先确定集成的范围；
     2）业务单据表字段映射手工逐一操作琐碎，可以利用【业务操作】->【引出】，在EXCEL中手工维护后再【引入】。

 
 ===== 2.2 启用 =====

业务单据同步方案需要【启用】后才可以执行，点击工具栏的【启用】按钮，则业务单据同步方案启用完成。

启用会自动判断：

1）金蝶云必填字段的相关内容是否齐全；

2）校验源系统字段的长度比金蝶云的长，则会自动截断；

3）校验源系统字段的类型与金蝶云不一致，会做相应处理。

系统提供了自动执行（通过执行周期执行）和手工执行两个同步方式。启用后，默认情况下，系统会按照执行周期控制，对执行时点的源系统最新内容进行自动同步，Administrator也可以点击【手工执行】按钮，这样就会在手工执行的执行时点将源系统的内容同步。

若启用的业务单据映射方案正在执行同步，则该方案不能被删除。

 ===== 2.3 手动执行 =====

业务单据同步方案启用后，点击【手动执行】，执行完成后，会看到同步的提示信息，还可以在业务单据集成查询中查看集成结果。

 ===== 2.4 引出方案 =====

系统提供了业务单据同步方案引入和引出功能，以便实现业务单据映射方案的跨业务库应用，例如：在测试库完成测试业务单据映射方案可以部署到正式库，这样减少业务单据同步方案的多次维护。

点击工具栏【选项】->【引出方案】按钮，即可将业务单据映射方案选择的数据库连接方案以及应用到基础资料映射方案均合并打包导出。

 ===== 2.5 引入方案 =====

点击工具栏【选项】->【引入方案】按钮，选择引入文件，即可将业务单据同步方案以覆盖的方式引入。若系统存在正在执行的业务单据同步方案，是不能引入的。

通过【引出/引入方案】实现业务单据及其基础资料映射方案的跨库应用。
 ====== 3 其他说明 ======

  - 业务单据集成不考虑上下游的关联关系及其信息，只管自身；
  - 业务单据映射方案启用时，会判断合法性、字段长度、字段类型等； 
  - 需要配置人员有一定的开发经验，并且对源系统的表结构有一定的掌握；
  - 具体关于业务单据集成情况，参见【[[业务单据集成查询|业务单据集成查询]]】的介绍。

## 【页面】基础资料映射
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%9F%BA%E7%A1%80%E8%B5%84%E6%96%99%E6%98%A0%E5%B0%84

====== 1 功能描述 ====== 

基础资料映射用来匹配源系统和金蝶云系统基础资料以及基础资料值的对应关系。以作为后续业务单据集成的对应关系。
例如：WISE的物料对应金蝶云的物料，WISE物料的001.02对应金蝶云物料的001.02，这样在同步WISE的销售订单时，物料明细上就是金蝶云的001.02这个物料。

**功能路径**

【系统管理】→【集成平台】→【数据集成】→【基础资料映射】

**前提**

  - 本版本不支持基础资料的集成，请确保金蝶云的基础资料数据与源系统保持一致，建议使用金蝶云数据引入引出工具或者基础资料引入引出功能完成，以减少手工录入的工作量。
  - 多组织模式的需要做好基础资料控制策略以及分配处理。
  - 基础资料映射在基础资料都维护好的前提下开展。

 ====== 2 功能操作 ======

 ===== 2.1 新增 =====

点击【基础资料映射】菜单，打开基础资料映射列表界面，点击【新增】按钮，即可打开“基础资料映射”界面进行创建。

  第一步：选择“源系统连接方案”，以确定源系统基础的表来源；
  
  第二步：基础资料的对应
          1、确定源数据类型，有3个内容（表/视图/自定义SQL），按需选择使用
          2、根据类型确定源基础资料（支持选择）及其主键
          3、确定目标系统对应的基础资料
          4、确定使用组织，就是与金蝶云哪个组织下的这个基础资料对应
       
  第三步：基础资料值的对应
          1、设置映射字段，默认显示编码和名称，还支持组织和版本
          2、勾选匹配规则，系统按选择内容以完全匹配规则进行自动映射
       
  第四步：点击【执行】，系统就按照匹配规则执行映射
  
  第五步：查询映射结果
          1、业务操作-映射查询可以查看结果
          2、按照映射字段显示基础资料值的映射结果
          3、匹配不上的，则金蝶云处显示为空，支持F8选择进行手工指定
          4、如果觉得匹配结果不对，可以【清除金蝶云数据】进行清除金蝶云的基础资料，支持批量清除，清除后再进行手工指定；也可以直接手工调整
          5、如果觉得匹配结果很多不合要求，可以【清空映射数据】进行删除，再重新执行映射
       
  第六步：点击工具栏的【保存】按钮，则基础资料映射创建完成。
  
  使用小窍门：
  
  1、在测试数据中心验证基础资料映射方案已经OK，可以在列表通过【引出】，然后【引入】到正式数据中心，实现基础资料映射方案的快速跨库应用。  
  2、如果未匹配的数据太多，可以在映射查询界面通过【引出】，在EXCEL手工维护好对应内容，再【引入】 。



 ===== 2.2 执行 =====

基础资料映射方案新增后，点击【执行】，系统就按照匹配规则执行映射。

===== 2.3 映射查询 =====

主要查询基础资料映射结果，必须完成执行操作后，才可以进行映射查询，详见【[[基础资料映射查询|基础资料映射查询]]】的介绍。

  - 按照映射字段显示基础资料值的映射结果；
  - 匹配不上的，则金蝶云处显示为空，支持F8选择进行手工指定；
  - 如果觉得匹配结果不对，可以【清除金蝶云数据】进行清除金蝶云的基础资料，支持批量清除，清除后再进行手工指定；也可以直接手工调整；
  - 如果觉得匹配结果很多不合要求，可以【清空映射数据】进行删除，再重新执行映射。
        
        
===== 2.4 查询 =====

点击【基础资料映射】菜单，即可打开“基础资料映射”界面查看已创建的基础资料映射方案。

## 【页面】映射关系设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%98%A0%E5%B0%84%E5%85%B3%E7%B3%BB%E8%AE%BE%E7%BD%AE

====== 1 功能描述 ====== 
基于源主键和源唯一标识设置源系统与目标系统的映射关系。


**功能路径**

【系统管理】→【集成平台】→【数据集成】→【映射关系设置】


 ====== 2 操作步骤 ======

1、设置基本信息

1）选择“源系统连接方案”，以确定源系统表的来源；

2）【源数据类型】和【源系统资料】
确定源数据类型，有3个内容（表/视图/自定义SQL），按需选择使用；

3）【源主键】和【源唯一标识】是唯一标识一个WISE资料的字段（若一个字段不能保证唯一，可以新增行，使得字段组合唯一）
【星空唯一标识】为唯一标识一个星空基础资料的字段或字段组合。它是判断同步到星空的数据是否重复的标识
【源查看字段】和【星空查看字段】为查看映射关系结果时，作为补充显示的字段；

4)、一个源数据连接，同一对象只能设置一个【映射关系设置】方案；

2、实体关键信息设置

在实体关键信息设置页签，星空系统资料相关的其他实体信息会自动带出，如果该实体也需要进行同步，则需要进行相应的设置；
例如:科目基础资料同步的时候，除了同步基本信息之外，还需要同步核算维度数据，外币核算数据。核算维度数据和外币核算数据是通过FAccountID识别为同一个科目的信息，因此，【对应源父表字段】均设置为FAccountID。另外，存在同一个科目下挂多个核算维度的情况，因此，需要添加FItemClassID来标识不同的核算项目。

3、其他实体信息同步，需进行相应设置
比如：科目除了同步基本信息外，还需要同步核算维度数据、外币核算数据，
设置“源表字段、对应源父表字段=FAccountID”识别为归属同一个科目的信息，
设置“源表字段=FItemClassID”识别同一科目下挂的不同核算项目

====== 1 集成平台概述 ======

===== 1.1 集成平台概述 =====

集成平台，通过数据库连接，配置异构ERP系统与金蝶AI星空系统的基础资料、业务单据的映射关系，使用后台服务定时执行或手工执行的方式，实现异构ERP系统的数据同步。

支持的业务场景：

1、  第三方异构ERP系统+金蝶云财务混搭模式

支持第三方异构ERP系统的业务数据集成到金蝶云查询，以便于利用会计智能平台进行凭证处理，间接实现财务业务数据一体化。

2、  金蝶云替换第三方异构ERP系统模式

支持第三方异构ERP系统的历史数据同步到金蝶云进行备查；
支持第三方异构ERP系统的未完成数据同步到金蝶云进行后续的业务操作。


集成平台通过配置集成方案，后台定时执行，实现业务单据和财务凭证的无缝集成，并支持对未完成业务继续执行，以及进行历史数据的查询。集成平台还提供了WISE V12.2升级金蝶云的预置解决方案。

## 【页面】集成平台准备工作
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%9B%86%E6%88%90%E5%B9%B3%E5%8F%B0%E5%87%86%E5%A4%87%E5%B7%A5%E4%BD%9C

在做系统集成前，要做好以下准备工作：

（一）其他ERP系统的相关准备工作如下（以WISE为例）：
  
  1、【期末结账】：务必每个子系统都要关账和结账，以保证余额数据的出具。
  
  2、【备份数据】：务必每个账套都要做好备份、存放到指定存储路径；最好在备份数据的名称上做文章，以避免后续选择错误。
  
  3、【梳理基础资料】：
     1）如果是多个源系统的账套数据，建议以一个主要账套的基础资料为基准，将全部基础资料进行合并梳理，以避免出现重复内容。
     2）对于多个账套使用同一基础资料值的，可以用基准账套的编码替换WISE中其他账套对应的基础资料编码（使用SQL语句处理）。
     
  4、【使用小窍门】：
     1）WISE V12.2的账套，直接使用数据迁移工具将基础资料直接导入金蝶云 V3.0/V5.0/V5.1；
     2）梳理时，如有基础资料需要调整，建议先维持源系统的“编码”不变（其他内容可以直接调整，但是务必保证业务的延续性），在金蝶云引入模板通过自定义字段维护新编码内容，等完成全部的集成工作后，利用update语句后台完成编码的更新；
     3）如果需要对WISE自定义核算项目或者基础资料进行映射，需要购买金蝶云的BOS运行时站点（控制基础资料维护，业务单据的F8调用不占用站点），在金蝶云进行自定义基础资料。





（二）金蝶云系统的相关准备工作

  1、【安装部署】：安装好金蝶云产品，并做好相关部署工作，尽量不要让金蝶云与WISE安装在同一台应用服务器。
  
  2、【确定基础资料控制策略】：
     1）如果是多组织应用的，需要维护组织机构；再维护基础资料控制策略，确定基础资料的创建组织和使用组织。
     2）确定基础资料自动分配方案。
     
  3、【维护基础资料】：
     1）按照WISE的基础资料进行维护，两个系统的基础资料应当保持一致；
     2）确定基础资料的维护顺序，可以参照WISE的导入顺序进行；
     3）可以利用金蝶云引入模板，WISE引出基础资料数据，手工黏贴WISE基础资料内容到金蝶云引入模板，再引入到金蝶云解决；引入时务必保证基础资料的前后顺序；
     4）在创建组织维护好基础资料后，需要按照基础资料控制策略进行对应的分配操作或者使用基础资料自动分配；
     5）金蝶云的基础资料都要审核（切记，因为WISE的基础资料可不用审核的）。
     
  4、【使用小窍门】：
     基础资料的维护方式：
     1）利用金蝶云的引入引出功能；
     2）利用BOS 平台的WebAPI接口；
     3）手工录入。
