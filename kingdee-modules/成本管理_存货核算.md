## 【页面】入库成本维护
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%A5%E5%BA%93%E6%88%90%E6%9C%AC%E7%BB%B4%E6%8A%A4

[[存货核算|《返回]]

====== 1 概述 ======


入库成本维护是指对采购入库或其他入库的存货进行成本暂估以及对生产入库的存货进行成本维护（启用产品成本核算模块后，生产入库成本不需维护，统一由成本计算结果自动反写）。

入库成本维护的取价来源支持期初加权平均价、最新入库价、最新出库价、最新采购订单成本、组织间交易结算价、零成本批量维护等，还支持手工维护及系统外批量引入。

入库成本维护主要是指对采购入库、采购退料单、盘盈单、其他入库的成本估价以及未启用产品成本核算模块情况下生产入库产品的成本维护。

====== 2 使用前提 ======


存货核算系统已结束初始化。

====== 3 功能路径 ======


【成本管理】－>【存货核算】－>【存货核算】－>【入库成本维护】 

====== 4 字段说明 ======
 
| **字   段**     || **说 明**                                                            |
| 查看单据          || 可以联查对应库存单据                                                         |
| 成本批量维护        || 支持引入“期初加权平均价”、“最新入库价”、“最新出库价”、“物料参考成本”、“最新采购订单成本”、“组织间结算价目表”：      |
|               || 1、期初加权平均价，是指期初余额中的单价=期初余额/基本单位数量。                                  |
|               || 2、最新入库价是指同物料按照入库序列配置表里面的所有入库单中最新一次有金额的入库类型单据的单价。                   |
|               || 3、最新出库价是指同物料按照出库序列配置表里面的所有出库单中最新一次有金额的出库类型单据的单价。                   |
|               || 4、物料参考成本，是指物料主档资料中的参考成本。                                           |
|               || 5、最新采购订单价格，是指同物料在最新采购订单中的单价。                                       |
|               || 6、组织间结算价目表是指专对核算组织间交易的入库序列调拨单从组织间交易结算清单上获取结算价格作为入库成本。              |
|               || 7、产品标准成本查询结果（默认版本）是从标准成本分析模块的“产品标准成本查询”结果（默认版本）中获取物料的标准成本作为入库暂估成本  |
|               || 8、外购物料标准价目表（默认版本）是从标准成本分析模块的“外购物料标准价目表”（默认版本）中获取物料的标准成本作为入库暂估成本    |
|               || 注：这里注意单价币别的换算，即引入后的本位币单价=入库单上原币单价*会计政策默认汇率类型下原币与主币别的汇率。            |
| 费用项目金额维护      || 当会计政策支持存货核算按费用项目核算时，可以按费用项目暂估成本。                                   |
|               || 维护成本后保存时会根据费用项目的默认设置自动赋予费用项目，点击费用项目金额维护可以查看和修改费用项目明细及金额。           |
|               || 核算单据上的金额=∑各费用项目金额。                                                 |

====== 5 操作说明 ======

A.入库成本维护是按“核算体系+核算组织+会计政策”及单据类型过滤数据的，不支持按所有单据类型进行综合过滤，因此实际操作过程中要按各单据类型分别过滤出单据进行成本维护。

B.不管原单据上是否具有成本，都需在入库成本维护中过滤出来进行保存操作，否则出库成本核算视同无单价处理。

====== 6 业务说明 ======


若未启用产品成本核算模块，生产入库产品的成本只能通过此功能进行维护；若启用产品成本核算模块，此处只能查询生产入库产品的成本，不允许修改。另外，只有在“法人核算体系+核算组织+默认会计政策”下，保存成本数据才会反写对应库存单据。

## 【页面】入库钩稽明细表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%A5%E5%BA%93%E9%92%A9%E7%A8%BD%E6%98%8E%E7%BB%86%E8%A1%A8

====== 1 概述 ======



入库勾稽明细表是指入库序列的单据，比如采购入库单、采购退料单 、委外入库单、委外退料单、物权转移单、期采购入库单、跨组织结算产生的采购入库单/采购退料单/分步式调入单/分步式调出单（退货），与关联应付单的勾稽情况展示。

====== 2 使用前提 ======


查询的期间已进行出库成本核算。


====== 3 功能路径 ======

【成本管理】－>【存货核算】－>【报表分析】－>【入库勾稽明细表】

====== 4 操作说明 ======

按“核算体系+核算组织+会计政策”维度查询；选择需要查询的期间或者日期范围。

支持对未勾稽的数据点击按钮“生成入库暂估单据”，进而支持生成凭证暂估处理。

支持对已关闭应付单且未勾稽完的的入库点击按钮“应付关闭出单”，进而生成成本调整单。
====== 5 业务说明 ======

  * 总成本+成本调整金额-已钩稽金额=未钩稽金额
  * 已钩稽金额等于过滤条件范围内相同库存单据钩稽金额之和。
  * 已钩稽数量等于过滤条件范围内相同库存单据钩稽数量之和。
  * 成本调整金额等于过滤条件范围内相同库存单据成本调整金额之和。
  * 按库存单据日期展示分录行数据，按期间展示钩稽数据。

## 【页面】其他存货核算
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%85%B6%E4%BB%96%E5%AD%98%E8%B4%A7%E6%A0%B8%E7%AE%97

[[存货核算|《返回]]

====== 1 概述 ======


其他存货核算是指对企业日常经营活动中的一些特殊业务进行存货出入库成本核算，如库存状态转换、形态转换、批号调整、组装拆卸等业务。

其他存货核算也即其他存货成本核算：是指对库存状态转换、形态转换、批号调整、组装拆卸等特殊业务的出入库成本核算。

====== 2 功能路径 ======


【成本管理】－>【存货核算】－>【存货核算】－>【其他存货核算】

====== 3 操作说明 ======


出库成本核算时会自动进行其他存货核算。进入其他存货核算列表，可以查询成本，也可对成本进行修改，修改成本会自动更新对应物料存货余额。

====== 4 业务说明 ======


1.会计政策支持存货核算按费用项目明细核算时，可以查询或修改费用项目明细金额。

2.组装拆卸单的费用需在“法人核算体系+核算组织+默认会计政策”维度下维护，其他维度下的费用由该维度下的费用金额按币别汇率进行换算。

## 【页面】出库成本核算
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%87%BA%E5%BA%93%E6%88%90%E6%9C%AC%E6%A0%B8%E7%AE%97

[[存货核算|《返回]]


====== 1 概述 ======


出库成本核算是指根据物料的入库成本及期初余额按照确定的计价方法核算出其出库成本。

出库成本核算支持加权平均法、移动平均法、先进先出法以及个别计价法，核算流程参见下图： 

业务流程图

[图:出库成本核算业务流程图.png]

 
====== 2 功能路径 ======

【成本管理】－>【存货核算】－>【存货核算】－>【出库成本核算】

====== 3 操作说明 ======


第一步：在向导界面一选择核算体系、核算组织及会计政策，点“下一步”进入下一步操作，退出界面点击“取消”。

若要执行合法性检查，请在向导界面一勾选“是否进行合法性检查”：勾选，点“下一步”执行合法性检查，进入向导界面二；不勾选，直接进入向导界面三。

若要对核算组织下的某个或几个核算范围进行单独核算，请去掉“是否核算所有核算范围”前复选框中的“√”，并在其下方表体中选择核算范围；

若要对核算组织下的某些物料进行单独核算，请去掉“是否核算所有物料”前复选框中的“√”，下拉选择“物料选择范围”，并在其下方表体中选择物料代码或存货类别。

第二步：合法性检查结果查询，合法性检查后在向导界面二的表体中显示错误信息。

检查项：1、是否存在未审核的库存单据；2、入库序列单据单价是否为0

检查成功，点击“下一步”进入向导界面三，退出操作，点击“取消”。

第三步：进入向导界面三，进行核算参数设置，然后点“下一步”进行核算。

**参数说明**

| 写成本计算过程                 | 成本计算过程输出的结果表有存货核算明细报告及费用分配过程表，不勾选时，成本核算后不存储过程数据，并有利于提高成本核算性能。                                                                                                                                                                       |
| 出库核算不更新已修改成本的核算单据成本     | 用于成本核算后修改出库单据成本重算的场景，即出库成本核算后，需对部分出库单据的成本进行修改，在重新核算时又想保留已修改的成本不被更新覆盖。                                                                                                                                                               |
| 单据生成凭证后重新核算不生成成本调整单     | 用于核算单据已生成凭证重算的场景，单据生成凭证后，重算后的成本很可能会与之前的成本存在差异，这种差异怎么处理呢？一种是对核算单据补差生成成本调整单，一种是将差异结转到期末余额中，普遍处理方式是选择结转到期末余额中。                                                                                                                         |
| 零成本单据自动取价               | 支持多种取价来源并设置优先取价顺序进行零成本取价。解决的场景主要是正常核算没有计算出成本的出库序列单据，如负库存导致的无出库成本、售后仓销售退货等特殊情况；还有一个场景是入库成本维护中存在零成本单据没有暂估成本，也可以通过这个参数对入库序列零成本单据进行估价。勾选此参数情况下，成本核算过程中首先对入库序列零成本单据进行取价，然后再进行常规核算，核算过程中存在未能正常核算出成本的出库序列单价再做成本取价，若仍没取到价格的，则合法性检查报告中给予提示。  |
| 生成组织间调拨单据               | 因存货核算是按货主（即业务组织）进行核算的，当存在多业务组织且存在跨组织业务，又没购买组织结算模块的情况下，跨组织业务单据不能产生组织间的分步式调出调入单，导致单个货主存货余额存在差异情况。此参数就是在这个场景下补充生成分步式调出调入单，与组织间结算不冲突，也不会重复生成分步式调出调入单。                                                                                   |
| 自动进行采购入库核算              | 成本核算前自动调用采购入库核算。                                                                                                                                                                                                                    |
| 出库核算自动进行期末余额差异调整        | 出库核算后结存存在无数量有几分钱余额的情况，这是因为出库成本没有进行尾差调整导致，通过此参数可以将这种差异调整到出库单据的成本中，避免期末异常余额。增加此参数主要考虑对性能的影响，若应用此参数存在很大性能影响，那只能建议在成本核算完毕后在期末异常余额中出单处理了。                                                                                                |
| 重新获取核算单据                | 用于提高成本核算性能，存货关账后业务数据已稳定，若每次成本核算都重新获取核算单据的话会浪费资源，因此系统在判断已关账且已执行过成本核算的情况下重新核算不再重新获取核算单据。通常情况下此参数没有多大意义，但在一些特殊情况下，如二开单据在关账逻辑控制中存在遗漏，或者关账后后台人工插入业务单据，这时需勾选此参数重新获取核算单据进行核算。                                                              |
| 出库单据有单价但是总成本为零时按0.01暂估  | 在实际业务场景下，由于出库数量极少，当用该数量乘以单价进行计算时，所得金额经精度处理（四舍五入至两位小数）后可能归零。举例而言，若出库数量为0.001、单价为1元，则计算出的金额仅为0.001元，保留两位小数即显示为0元。为解决这一问题，部分用户会选择以0.01元作为暂估成本来录入出库单据，从而确保业务流程能够顺利推进。                                                                   |
| 出库加权平均价为负数时出库单据成本处理     | 1、不处理：不做任何处理，当加权价为负数时，合法性检查报告提示不通过，用户需要检查负单价原因，并及时调整使出库价为正数\\ 2、按零成本处理：当加权价为负数时，统一按照0进行处理\\ 3、按暂估来源取价：当出现负单价时，仍然需要进行暂估，暂估来源为“零成本单据自动取价”设置的规则                                                                                        |
| 核算检查金额或单价是否超出范围         | 主要是为了解决越南币核算时，物料单价和单据成本过大导致单价溢出的问题。\\ 当您在合法性检查报告提示存在单价溢出或者金额溢出时，勾选此参数重新核算，合法性检查报告会提示具体的物料及单据成本超出系统的数值范围                                                                                                                             |



第四步：核算完成后，显示核算报告：存货核算汇总报告、存货核算明细报告、存货核算收发存汇总表、存货核算收发存明细表、异常余额汇总表、合法性检查报告。 


第五步：出库核算完成后可以点击合法性检查报告，或者点击系统菜单【成本管理】—>【存货核算】—>【存货核算】—>【合法性检查报告】，可以按“核算体系+核算组织+会计政策”查看当前期间存货核算的合法性检查报告，点击明细可以联查详细的提示信息。

====== 分步式调出未调入明细表 ======

===== 功能概述 =====
由于分步式调出单存在跨月下推分步式调入单的情况，因此，会导致存货收发存汇总表在分步式调出单核算以后直接扣减了当期的存货余额。
实际上这部分存货是结转到了在途物资中，并没有减少总账中的账面余额，因此我们提供了“分步式调出未调入明细表”统计当期做了分步式调出没有做分步式调入的存货。



===== 操作流程 =====

  - 启用“分步式调出未调入”，路径：存货核算-初始化-启用分步式调出未调入
  - 打开“分步式调出未调入明细表”

===== 关键应用 =====
  * 出单

当物料全部调入完成后，会出现金额计算导致的尾差，可以点击“出单”处理。

===== 业务说明 =====

当存在本期做分步式调出单，但未下推分步式调入单的情形，会导致报表对账不平：账务上将这一部分存货作为存货-在途物资处理，在存货报表过滤界面勾选“不统计组织内调拨”单据，可以使当期报表不统计此笔存货出库记录，但是下月期初结存是统计此笔出库记录的。

因此需要启用分步式调出未调入后，并勾选“不统计组织内调拨”，才会使存货报表对账平衡。

勾选此参数后，会使下月期初结存仍然不统计此笔出库记录。

【成本管理】－>【存货核算】－>【初始化】－>【初始核算数据录入】

====== 3 操作说明 ======


点新增按钮，选择核算体系、核算组织及会计政策就可获取期初库存数量，维护对应期初成本，然后点保存按钮保存。

====== 4 工具栏按钮说明 ======


A.获取库存期初数据：根据表头所填条件获取库存期初数量，库存组织、仓库为非必录条件，不录时引入核算组织下所有库存组织、所有仓库数量；

E.内部引入：当其他核算体系下已经维护过初始核算数据录入，可以通过内部引入直接引用已维护的数据。

## 【页面】委外入库核算
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A7%94%E5%A4%96%E5%85%A5%E5%BA%93%E6%A0%B8%E7%AE%97

[[存货核算|《返回]]

====== 1 概述 ======


委外入库核算是指企业接收委外加工产品入库后，需要对该部分产品核算成本。委外加工产品的成本包括两大部分：一是耗用委外发出物料的材料成本；二是支付给加工厂商的加工费用以及附加费用，如运费、装卸费用等等。

介于委外业务的特殊性，即经过外部生产加工及采购流程，因此，加工费的核算采用采购入库核算的逻辑，通过委外入库单（退料单）与应付单的钩稽核算得出，材料成本采用自制产品核算的流程计算当期完工与期末在产耗用的材料成本。

 

===== 1.1 委外入库核算流程图 =====


[图:委外入库核算流程图.png]

====== 2 功能路径 ======

====== 3 字段说明 ======
 
|**字   段**||**说 明**|
|查看单据 ||可以联查对应库存单据|
|费用项目 ||当会计政策支持存货核算按费用项目明细核算时，此字段才可见。维护成本后保存时会根据费用项目的默认设置自动赋予费用项目，点击费用项目维护可以查看和修改费用项目明细及金额。|


====== 4 操作说明 ======

====== 5 业务说明 ======


加工费是由应付单与委外入库单（退料单）钩稽核算所得，材料成本是由产品成本核算计算得出。委外入库核算可以通过外部引入或手工维护材料成本及加工费。委外入库单（退料单）没有与应付单钩稽核算时，才允许维护；材料成本只有在未启用产品成本核算模块情况下才能手工维护或外部引入。另外只有在“法人核算体系+核算组织+默认会计政策”下，保存成本数据才后会反写对应库存单据。

====== 1 存货核算系统概述 ======


===== 1.1 存货核算概述 =====

存货核算是指企业存货价值（即成本）的计量，用于工商业企业存货出入库核算，存货出入库凭证处理，核算报表查询，期初期末库存余额处理及相关资料的维护。
 
===== 1.2 存货核算系统总体流程图 =====

[图:存货核算流程图.png] 

===== 1.3 系统特性 =====

存货核算系统以支持多工厂、多组织、多会计核算制度灵活准确地核算存货成本为目标，通过与供应链、生产制造、应收应付、资产管理、总账等系统的无缝集成，为企业成本管理提供精确的成本分析数据，其主要功能包括：

  * 存货核算 
  * 成本调整 
  * 报表分析 
  * 账务处理 
  * 期末处理

支持成本核算维度：

  * 支持多工厂多组织成本核算 
  * 支持存货成本按费用项目分项核算  
  * 支持符合会计准则的多种计价方法核算，如移动平均法、加权平均法、先进先出法等 
  * 支持灵活的个别计价方法核算，如按批号、仓库、仓位、BOM编号、辅助属性等物料维度核算 
  * 支持按货主、库存组织、仓库三要素划分核算范围

====== 3 存货核算业务专题 ======

本章就存货核算体系架构和业务专题进行了探讨，并介绍了如何在存货核算系统中进行特殊业务的处理。

===== 3.1 会计核算体系 =====

会计核算体系简称核算体系，是对企业业务核算范围和口径的标准划分，也是用于确定成本核算主体的体系架构。基于每个核算体系，可以对所有业务组织按照核算的需要划分若干核算组织（也就是会计主体）。透过核算体系，可以清晰的看到核算体系、核算组织、业务组织的上下层级关系，此层级关系通常也是企业组织架构。

可以同时存在多个核算体系，核算体系间相互独立，每个核算体系是单独的成本池。通常企业可以基于财务核算与企业管理的双重目的建立两套彼此独立的核算体系。
 
===== 3.2 核算组织 =====
 

核算组织即会计主体，是成本核算的基本单元，具有法人或利润中心基本属性，通常是一个独立的公司，或独立核算的利润中心。核算组织下挂下级业务组织，决定参与成本核算的业务组织范围；

在不同核算体系下，可以将业务组织划分不同的核算组织，但在同一个核算体系下，业务组织只属于一个核算组织。业务组织记录业务的发生，通过业务组织—核算组织的关系确定财务数据归属。

===== 3.3 会计政策 =====


会计政策是指企业依据国家（地区）会计准则建立的企业财务会计核算制度，如固定资产折旧方法、折旧年限，成本核算方法等。如在华美资企业的固定资产依据中国会计准则及美国会计准则有不同的折旧方法及折旧年限要求，在这两个会计准则下计提折旧的不同，相应会导致成本核算数据的不同。

成本核算是将“核算体系+核算组织+会计政策”作为总的核算维度，三者之间的联系及应用通过如下案例来说明：

[图:存货会计政策.png]

接上面那个案例，在华美资企业在深圳有三家工厂，都是利润中心，企业财务要求每月按法人整体出具符合中国会计准则及美国会计准则的两套财务账，同时还要一套符合中国会计准则的按利润中心考核的内部管理账。

案例中三家工厂是三个业务组织，同属于美资企业这家法人，按财务的要求，建立两个核算体系：法人体系及责任中心体系。法人体系下，三家工厂归属于同一核算组织，按中美两套会计政策核算，即“法人体系+核算组织+会计政策（中）”及“法人体系+核算组织+会计政策（美）”；

责任中心体系下，三家工厂各为核算组织，按中国会计政策核算，即“责任中心体系+核算组织（工厂A）+会计政策（中）”、“责任中心体系+核算组织（工厂B）+会计政策（中）”及“责任中心体系+核算组织（工厂C）+会计政策（中）”。

===== 3.6 货主组织确定核算主体 =====

存货成本核算是按存货所有权持有方（即货主组织，也就是核算组织下的业务组织）为核算主体。如某核算组织X有A、B两个业务组织，现有领料单01、02、03上的货主分别为A、B、C。那么核算组织X纳入存货核算的单据只能是01和02。

 

注意：存货成本核算整体是按核算单据上的货主归集数据来核算的，但入库单、退料单、销售出库单、销售退库单是按结算组织来确定货主的。

===== 3.7 存货成本按费用项目核算 =====

存货成本按费用项目分项核算是指存货成本可以按成本动因细化其成本结构，按费用项目分项核算及结转，给企业提供精确详细的成本管理数据。

例如：从A供应商采购一笔货物，未税价款是100万，委托物流公司B运输，运输费是2万。传统核算的入库成本就是102万，没有细分其成本结构。按成本动因划分的话，入库成本102万，其中材料成本100万、采购附加费用2万。

费用项目基础资料中有预设费用项目，用户可以按预设费用项目进行存货成本核算，也可按类别自定义费用项目。

===== 3.8 存货成本核算维度 =====

存货核算维度的粗细度是由核算范围、物料核算维度及费用项目来决定。

核算范围按货主、库存组织、仓库、货主+库存组织、货主+仓库等五个维度划分存货核算的空间范围；

物料核算维度即个别计价方法的应用：存货成本支持按物料维度如批号、仓库、仓位、BOM编号、辅助属性等核算；

费用项目：存货成本支持按费用项目分项核算。

===== 3.9 存货成本调整 =====

成本调整主要是对因财务上的时间和人为等因素导致的以前期间的存货成本差异而在当前期间进行成本调整，以还原成本真实面貌。

主要应用场景如下：

A.入库成本补差：以前期间采购入库，当期收到采购发票，且采购发票金额与入库成本存在差异，进行钩稽核算时将差异产生采购入库调整单调整期初存货余额。

B.入库成本补差追溯调整：上期存货采购入库后按暂估价发出，当期入库成本补差按比例生成出库成本调整单追溯调整上期的发出成本，以较真实的反应当期的期初存货成本余额。

C.因人为或系统原因导致以前期间存货成本差异，通过出库成本调整单手工调整。

D.存货核算过程由于计价方法或其他原因导致存货余额出现无数量有金额，或有数量无金额，或存货成本结构中费用项目金额同时存在正负数的异常情况，也需通过出库成本调整单来处理，以调整期末余额。

===== 3.10 特殊业务成本核算 =====

特殊业务成本核算都在“其他存货核算”中处理。特殊业务是指库存状态转换、形态转换、批号调整、组装拆卸等业务。

  * 1.库存状态转换
库存状态转换业务一般是指某种存货在存储过程中，由于超过保质期、报废、预留等管理上的原因，使其状态发生变化，即由一种库存状态转换为另一种库存状态，此时需要库存状态转换业务来调整库存账。例如：将销售退货单的冻结状态库存转换为可用状态库存。同时存货成本也要相应调整，库存状态转换前的存货成本=库存状态转换后的存货成本。

  * 2.形态转换
形态转换业务一般是指某种存货在存储过程中，由于环境或存货本身的原因，使其形态发生变化，即由一种形态转换成另一种形态，此时需要形态转换业务调整库存账。例如：在制盐企业中，海盐放置一段时间后就会凝固成固体盐。同时存货成本也要相应调整，形态转换前的存货成本=形态转换后的存货成本。

  * 3.批号调整
批号调整业务一般是指由于库存管理的需要，将物料的某个批号进行拆分或合并，以调整库存管理维度的库存账。同时存货成本也要相应调整，批号调整前存货成本=批号调整后存货成本。

  * 4.组装业务
组装业务是指将多个散件组装成一个配套件的过程。如有些企业中的某些存货既可以单独销售，又可以与其他存货组装在一起进行销售。例如：计算机销售企业公司既可以将显示器、主机、键盘等单独销售，又可按客户的要求将显示器、主机、键盘等组装成计算机进行销售，这时就需要对计算机进行组装。组装成品成本＝子件成本+组装费用。

  * 5.拆卸业务
拆卸业务是与组装业务相对应，是指将一个配套件拆卸成散件的过程。例如：企业库存中只存有组装好的计算机，但客户只需要购买显示器，此时又需将计算机进行拆卸，然后将显示器卖给客户。拆卸成品成本＋拆卸费＝拆卸子件成本。

===== 3.11 组织间交易存货成本核算 =====

组织间交易是指企业各业务组织之间存货的流转。若业务组织是按利润中心或责任中心（也就是核算组织）来考核的话，就会涉及内部结算。如下图：

[图:存货组织间交易.png]

如上图：蓝海公司下各业务组织间存货的流转都属于组织间交易，铸造车间、组装车间属于同一核算组织，不需结算，存货价值按出库成本价结转；而铸造车间、组装车间与精密制造属于不同核算组织，那么铸造车间与精密制造之间的交易得按协商的交易价格进行结算。


存货成本核算得区分业务组织间交易是核算组织间交易还是核算组织内交易，然后按各自原则核算入库成本。

## 【页面】存货核算初始化
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AD%98%E8%B4%A7%E6%A0%B8%E7%AE%97%E5%88%9D%E5%A7%8B%E5%8C%96

初始化是指在企业采用存货核算系统前，为了将企业已有的信息，如库存余额，体现在系统中所做的各种数据、单据的初始值设置，使系统的起始状态与企业的实际情况相符合。

====== 1 功能路径 ======


【成本管理】－>【存货核算】－>【初始化】－>【存货核算初始化】。

====== 2 操作说明 ======


在存货核算初始化界面选择“核算体系”及“核算组织”，勾选需结束初始化的“会计政策”，执行结束初始化；

若要反初始化，在存货核算初始化界面选择“核算体系”及“核算组织”，勾选需反初始化的“会计政策”，执行反初始化。

====== 3 业务说明 ======


执行初始化前会进行如下合法性检查：

A.是否已启用存货核算系统；

B.核算范围是否覆盖了对应核算组织的所有货主组织及仓库；

C.初始核算数据库存数量与取数来源是否一致；

以上三项检查均无问题，则成功结束初始化。结束初始化后，初始核算数据维护只能查看，若要修改，先进行反初始化操作。

注意：非启用会计期间，不允许反初始化。

## 【页面】存货核算期末关账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AD%98%E8%B4%A7%E6%A0%B8%E7%AE%97%E6%9C%9F%E6%9C%AB%E5%85%B3%E8%B4%A6

====== 关账 ======


通过关账功能可截止本期的出入库单据的录入和其他处理，有利于为期末结账前的核算处理创造稳定的数据环境。 

====== 功能路径 ======


【成本管理】－>【存货核算】－>【期末处理】－>【期末关账】

====== 操作说明 ======

选择核算体系及核算组织，并设置关账日期，点“关账”执行该核算组织下所有业务组织的关账。若关账失败，请查看错误日志进行处理。存货核算关账日期不能早于库存组织的关账日期 

====== 业务说明 ======

  * 关账检查上次关账日之后至本次关账日是否有未审核未作废的库存单据。
  * 关账日期大于等于库存启用日期和大于上一次关账日期。
  * 关账时检查物料内码是否与使用组织一致。
  * 关账时检查账存日期小于等于关账日期的物料盘点作业，是否存在创建、审核中的单据，如果有，提示，是否继续关账。   

====== 反关账 ======

可以恢复关账前状态。反关账后，用户可以补充录入或修改当前期间的单据。 

====== 功能路径 ======

【成本管理】－>【存货核算】－>【期末处理】－>【期末关账】

====== 操作说明 ======

选择核算体系及核算组织，点“反关账”执行该核算组织下所有业务组织的反关账。存货核算反关账日期不能早于库存组织的关账日期。

## 【页面】存货核算期末结账
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AD%98%E8%B4%A7%E6%A0%B8%E7%AE%97%E6%9C%9F%E6%9C%AB%E7%BB%93%E8%B4%A6

====== 结账 ======

截止本期核算单据的处理，计算本期的存货余额，并将其转入下一期，同时系统当前期间下置。期末结账前，会对本期的核算单据进行检查，判断是否已处理完整，若不完整，会给出相应的提示。 

====== 使用前提 ======


当期期间已关账且关账后已进行出库成本核算或者成本计算。

====== 功能路径 ======

【成本管理】－>【存货核算】－>【期末处理】－>【期末结账】

====== 操作说明 ======

选择核算体系、核算组织及会计政策，点“结账”进行结账处理。

====== 业务说明 ======

结账前合法性检查如下：

A.检查当前会计期间是否已关账；

B.检查当前核算单据单价是否≦0；

C.检查是否出现负库存； 

D.检查当期所有核算单据是否都已参与存货核算；

E.检查结账时点汇总金额不等于明细金额。

====== 反结账 ======

将核算期间返回至上一期。

====== 功能路径 ======


【成本管理】－>【存货核算】－>【期末处理】－>【期末结账】

====== 操作说明 ======

选择核算体系、核算组织及会计政策，点“反结账”进行反结账处理。

## 【页面】存货核算汇总报告
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%AD%98%E8%B4%A7%E6%A0%B8%E7%AE%97%E6%B1%87%E6%80%BB%E6%8A%A5%E5%91%8A

存货核算汇总报告是指将存货出库成本核算过程状况提供汇总报告，包括核算成功、失败、异常等信息，以便用户了解及分析原因。

====== 使用前提 ======


已进行出库成本核算。

====== 功能路径 ======

【成本管理】－>【存货核算】－>【报表分析】－>【存货核算汇总报告】

====== 操作说明 ======

1.按“核算体系+核算组织+会计政策”查询存货核算汇总报告；

2.核算状态为警告、核算失败、核算异常时，可以点击工具栏“错误日志查询”查询详细错误信息；

3.若要联查存货成本计算过程，可以点击工具栏“明细报告查询”进行查询。

====== 业务说明 ======

核算状态包括核算成功、警告、核算失败、核算异常、未核算五种：

A.核算成功是指核算单据按照核算规则成功结算存货成本；

B.警告是指核算单据在核算过程中检测到未审核的核算单据；

C.核算失败是指核算过程中出现负库存、单价≦0等情况而不能成功结转存货出库成本；

D.核算异常是指核算单据在核算过程中出现系统异常情况而不能正常结转存货出库成本。

E.未核算是指出库核算向导三勾选“遇到成本核算错误时停止核算当前物料”参数，在核算过程中因前端计算异常就终止了核算。

存货核算系统以支持多工厂、多组织、多会计核算制度灵活准确地核算存货成本为目标，通过与供应链、生产制造、应收应付、资产管理、总账等系统的无缝集成，为企业成本管理提供精确的成本分析数据，其主要功能包括：

====== 1 概述 ======

定时核算是指，对出库核算或成本计算，设置时间计划执行核算。

====== 2 功能路径 ======

【成本管理】－>【存货核算】－>【存货核算】－>【定时核算】


====== 3 操作说明 ======

1、新增定时核算界面；

2、当用户点击定时出库核算和定时成本计算时调出目前出库核算和成本计算的界面；

3、支持用户按分、天、周、月、年设定核算计划。执行时间点为第一次运行核算的时间，之后将按执行间隔单位和执行间隔数值计算循环执行点，如执行时间点为2016年3月11日15：05：49，执行间隔单位为天，那么第一次是在2016年3月11日15：05：49执行核算任务，第二次将在2016年3月12日15：05：49执行核算任务。

4、已设定的计划可以查看运行状态，也可以删除计划。

5、当设定的计划为第3期成本计算，用户在第3期结账后，定时核算服务自动识别进行第4期的成本计算。

====== 4 业务说明 ======

一般定时核算应该避开用户集中操作系统时间，设置为晚上比较好。

| :::                     | - 应用场景：1、做完异常余额出单后，重新核算系统自动删除了异常余额调整单的情况；2、月末要做存货跌价准备，把无数量有金额的存货余额出单调整后，跌价计提库存金额与存货收发存汇总表一致                                                                                                                                                                                                                                                            |
| 生产退料单通过生产退料请检单取源单成本     | - 应用场景：生产领料单下推生产退料请检单，再通过生产退料请检单下推生产退料单的业务，在成本核算的时，生产退料单可以获取关联生产领料单的成本。                                                                                                                                                                                                                                                                                |
| 委外退料单通过委外退料请检单取源单成本     | - 应用场景：委外领料单下推委外退料请检单，再通过委外退料请检单下推委外退料单的业务，在成本核算的时，委外退料单可以获取关联委外领料单的成本。                                                                                                                                                                                                                                                                                |

## 【页面】成本调整单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%88%90%E6%9C%AC%E8%B0%83%E6%95%B4%E5%8D%95

成本调整是指对存货成本进行调整的一项业务操作，包括采购入库调整单、出库成本调整单。

====== 功能路径 ======


【成本管理】－>【存货核算】－>【成本调整】－>【成本调整单】

====== 字段说明 ======
 
|**字   段**||**说 明**|
|单据类型 ||包含采购入库调整单和出库成本调整单两种类型。|
|调整原因 ||单据类型为采购入库调整单时，调整原因为采购入库调差；|
| ||单据类型为出库成本调整单，且是手工新增成本调整单时，调整原因为手工调差；|
| ||单据类型为出库成本调整单，且由异常余额汇总表出单生成成本调整单时，调整原因为异常余额调整；|
| ||出库成本核算按系统参数“采购入库调整单生成出库成本调整单”生成的出库成本调整单，调整原因为采购入库调整。|
|币别 ||取当前会计政策的主币别。|
|业务类型 ||1、单据类型为采购入库调整单时，业务类型为入库调整；|
| ||2、手工新增出库成本调整单时，业务类型为生产出库调整或销售出库调整或委外出库调整或其他出库调整；|
| ||3、异常余额汇总表出单生成出库成本调整单时，业务类型为异常余额调整；|
| ||4、出库成本核算按系统参数“采购入库调整单生成出库成本调整单”生成的出库成本调整单，调整原因为采购入库调整，业务类型为生产出库调整。|
|调整金额 ||本位币金额，可以为正负数。|
|调整金额（原币） ||1、单据类型为采购入库调整单时，采购入库单（退料单）与应付单钩稽核算时结算币别的差额；|
| ||2、单据类型为出库成本调整单时，不需维护原币调整金额。|
|原币币别 ||1、单据类型为采购入库调整单时，原币币别为采购入库单（退料单）的结算币别；|
| ||2、单据类型为出库成本调整单时，原币币别不需维护。|


====== 操作说明 ======


手工新增成本调整单必须审核才生效。

====== 业务说明 ======


1.采购入库调整单及有关联源单（源单为以前期间的库存单据）的出库成本调整单调整的是当期期初余额；

2.无源单的出库成本调整单调整当期的发生额；

3.业务类型为异常余额调整的出库成本调整单调整的是当期期末余额；

4.成本调整单列表提供了价格差异、汇率差异的处理,以方便有必要的用户进行成本分析。调整金额（本位币价）=价格差异+汇率差异。

===== 举例说明 =====
 

4月采购入库单A物料数量10个，单价1USD，金额10USD，5月应付单A物料10个，单价1.5USD,金额15USD,主账簿本位币为RMB,勾稽核算参考如下表：

成本调整单调整金额（本位币）为45，其中：

价格差异=（应付单原币单价-入库单原币单价）*数量*应付单汇率=（1.5-1）*10*7=35；

汇率差异=入库单原币单价*数量*（应付单汇率-入库单汇率）=1*10*（7-6）=10.

  * 其次，用用户账号进入数据中心依次设置会计政策、会计核算体系、核算范围、物料计价方法、参数设置及费用项目，路径如下：

进入成本管理－>存货核算－>初始化－>启用存货核算系统

其他存货成本核算：进入成本管理－>存货核算－>存货核算－>其他存货核算

## 【页面】核算组织
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%B8%E7%AE%97%E7%BB%84%E7%BB%87

核算组织即会计主体，是成本核算的基本单元，具有法人或利润中心基本属性，通常是一个独立的公司，或独立核算的业务组织（利润中心）。核算组织分为标准类型和合并类型，只有标准类型的核算组织具有下级业务组织，参与成本核算；合并类型的核算组织只作为标准类型核算组织的账务合并主体，不参与成本核算。

在不同核算体系下，可以将业务组织划分不同的核算组织，但在同一个核算体系下，业务组织只属于一个核算组织。业务组织记录业务的发生，通过业务组织—核算组织的关系确定财务归属。

## 【页面】核算范围设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%A0%B8%E7%AE%97%E8%8C%83%E5%9B%B4%E8%AE%BE%E7%BD%AE

核算范围是指在“核算体系+核算组织+会计政策”的总核算维度下，将存货划分为若干个空间范围，每个空间范围都有单独的计价方法，从而形成若干个价值序列分别进行存货核算。划分依据有：货主、库存组织、仓库、货主+库存组织及货主+仓库。

====== 1 使用前提 ======


必须已设置好会计核算体系、核算组织及会计政策。

====== 2 功能路径 ======


【成本管理】－>【存货核算】－>【基础资料】－>【核算范围】

====== 3 操作说明 ======


新增核算范围时，选择核算体系、核算组织及会计政策，设置计价方法及核算范围划分依据，核算范围必须审核才生效。

划分依据为货主时，选择的货主为当前核算组织下的业务组织，核算范围覆盖整个核算体系下的库存组织及仓库。

划分依据为库存组织时，库存组织的选择范围只为当前核算组织下的所有库存组织；

划分依据为仓库时，仓库选择范围只为当前核算组织下所有库存组织下的仓库；

划分依据为货主+库存组织时，货主为当前核算组织下的业务组织，库存组织可选范围为当前核算体系下的所有库存组织；

划分依据为货主+仓库时，货主为当前核算组织下的业务组织，仓库的可选范围为当前核算体系下的所有仓库。

====== 4 业务说明 ======


1、同一“核算体系+核算组织+会计政策”维度下的所有核算范围划分依据必须一致。另，若存在A组织的存货存储在B组织下仓库的情况，包括跨组织采购、跨组织领料、跨组织销售及跨组织调拨，请务必按货主或货主+库存组织或货主+仓库的划分依据划分核算范围。

2、核算范围作为一个大的核算维度，当只建立一个核算范围时为总仓核算即一个核算范围编码下包含所有的货主+仓库，当建立多个核算范围即每个核算范围编码下只有一个货主+仓库时为仓库间的分仓核算；

## 【页面】物料计价方法
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%89%A9%E6%96%99%E8%AE%A1%E4%BB%B7%E6%96%B9%E6%B3%95

[[存货核算|《返回]]

====== 1 物料计价方法概述 ======


物料计价方法支持按单个物料、存货类别、物料属性分别设置计价方法。计价方法支持移动平均法、加权平均法、先进先出法三种。

 

个别计价法的应用：通过物料基础资料“物料维度”页签影响成本的因素，如批号、BOM编号、仓库、仓位、辅助属性等，结合物料计价方法来实现。例如：物料基础资料中批号勾选“影响成本”，则存货成本按物料编码+批号+物料计价方法的维度核算。

 

成本核算时物料计价方法优先取价顺序：单个物料->存货类别->物料属性->核算范围

 

注意：同一核算范围内，一个物料编码在不同业务组织下设置为不同存货类别（或物料属性），且按存货类别（或物料属性）设置物料计价方法。例如：核算组织X有A、B两个业务组织，有相同物料编码01.001，但在A组织下物料属性为自制、存货类别为半成品，在B组织下物料属性为委外、存货类别为成品。这种场景下，若将A、B放在同一核算范围下，则物料01.001存货核算时直接获取核算范围中的计价方法。

====== 2 使用前提 ======


必须已设置好核算范围。若无特殊要求，物料计价方法可以不设置，直接采用核算范围的计价方法。

====== 3 功能路径 ======


【成本管理】－>【存货核算】－>【基础资料】－>【物料计价方法】

====== 4 操作说明 ======


新增物料计价方法时，选择核算范围及设置依据：支持按单个物料、物料属性、存货类别设置计价方法。设置完毕后审核才生效。

====== 5 业务说明 ======


核算范围及物料计价方法都涉及计价方法的设置，存货出库成本核算时获取计价方法的优先顺序为：单个物料→存货类别→物料属性→核算范围。进行存货核算后，对应物料存在期初或期末存货余额时不允许修改物料计价方法。若要变更计价方法，请做物料计价方法变更处理。

来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%87%AA%E5%8A%A8%E9%92%A9%E7%A8%BD%E6%A0%B8%E7%AE%97

**自动钩稽核算**

自动钩稽核算是指由标准应付单审核时自动建立与对应入库单（退料单）的钩稽关系，并根据钩稽关系核算入库成本。

**使用前提**

存货核算系统必须已结束初始化，且已勾选参数“采购应付单审核时自动进行入库成本核算”。

**操作说明**

入库单（退料单）下推标准应付单后审核时自动进行钩稽核算。以及当勾选系统参数“应付单与发票核销产生的差异计入存货成本”时，应付单与采购发票核销产生的应付调整单自动钩稽关联入库单（退料单）并重新核算入库成本。

**业务说明**

自动钩稽触发的核算只是针对“法人核算体系+核算组织+默认会计政策”下入库成本核算。

## 【页面】自定义食品成本卡
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%87%AA%E5%AE%9A%E4%B9%89%E9%A3%9F%E5%93%81%E6%88%90%E6%9C%AC%E5%8D%A1

在食品成本核算之前，要先进行自定义食品的成本卡设置（若有销售自定义食品）,即设置每份自定义食品所用物料及其重量。

**使用前提**

若要核算的范围内有销售自定义食品，建议录入自定义食品成本卡，否则制作出品自定义食品的物料将会分摊至别的食品成本上，造成其他食品成本不准确。

**字段说明**
|**主表字段**||**说明**|
|销售组织||自定义食品对应销售组织，由查询条件过滤得到|
|销售日期||过滤条件取到的自定义食品对应的销售日期|
|食品组别||过滤条件取到的自定义食品对应的食品组别|
|食品编码||过滤条件取到的自定义食品对应的食品编码|
|食品名称||过滤条件取到的自定义食品对应的食品名称|
|成本卡状态||过滤条件取到的自定义食品对应的成本卡状态，该字段由子表数据更新，当自定义食品在子表中已录入过成本卡，这该食品状态为：已补录成本卡；否则状态为：未补录成本卡。|

|**子表字段**||**说明**|
|物料编码||手工维护，调出通用物料列表查询框|
|物料名称||由物料编码带出，不允许维护|
|规格型号||由物料编码带出，不允许维护|
|基本单位||由物料编码带出，不允许维护|
|数量||手工维护录入，支持小数|
|所属部门||默认该食品所属部门，可手工维护|

**功能路径**

【成本管理】->【餐饮成本核算】->【基础资料】->【自定义食品成本卡】

**操作说明**

通过查询条件过滤出未补录成本卡的自定义食品。点击【修改】按钮后即可维护所选自定义食品的成本卡。

**业务说明**

自定义食品成本卡用于维护各组织下各销售出品部门销售的自定义食品（菜谱上没有的食品）的成本卡，以便进行食品成本核算。由于销售的自定义食品也需要耗用部门物料，若食品核算前自定义食品不维护成本卡，则其耗用的部门物料将分摊至其他需要这些物料制作的食品成本上，导致成本误差。

## 【页面】费用项目
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B4%B9%E7%94%A8%E9%A1%B9%E7%9B%AE

====== 1 费用项目 ======


费用项目是存货成本结构中的构成项目，既可根据成本动因进行划分和设置，也可按经济用途进行划分和设置。

====== 2 功能路径 ======


【基础管理】－>【基础资料】－>【【公共资料】－>【费用项目】 

====== 3 字段说明 ======


|**字   段**||**说 明**|
|编号 ||费用项目编码，手工录入或系统自动产生。|
|名称 ||费用项目名称，手工录入。|
|存货核算类别 ||下拉选择项：材料类、采购类、委外类、组装类、拆卸类、生产类及其他类。|
| ||材料类：指存货的原物料成本，如材料采购价款；|
| ||采购类：指材料采购所发生的需计入存货成本的费用，如关税、运费、装卸费等等；|
| ||委外类：指委外加工支付供应商的加工费用；|
| ||组装类：指供应链组装业务所发生的费用，如组装费用；|
| ||拆卸类：指供应链拆卸业务所发生的费用，如拆卸费用；|
| ||生产类：指生产过程所发生的费用，如人工工资、折旧费用等；|
| ||其他类：指不计入存货成本的费用，如业务招待费、差旅费、交通费、电话费、团队活动费、办公费、折旧费用。|
|是否默认 ||每一类别有且只有一个默认项，目的是在初始核算数据维护、入库成本核算、入库成本暂估、其他存货核算时系统会自动区分类别根据默认项生成费用项目。|


====== 4 操作说明 ======


系统已预设费用项目，若想使用自定义费用项目，新增时维护好“名称“、设置好“类别”和“是否默认“。费用项目审核才生效。

====== 5 业务说明 ======


费用项目基础资料中有预设费用项目，用户可以按预设费用项目进行存货成本核算，也可按类别自定义费用项目，根据需要设置为默认。各类别只有一个默认项，初始核算数据维护、入库成本核算、入库成本维护、其他存货核算会按类别及默认的费用项目自动赋予核算单据费用项目。初始核算数据维护、入库成本维护、其他存货核算自动赋予费用项目后，还可在费用项目明细表中修改新增费用项目及值。费用项目的处理支持存货成本分项核算。

注意：  默认费用项目一经确定下来，不要随意变动，否则会造成存货成本明细结构异常。默认费用项目不支持批量审核。

## 【页面】跨组织交易费用分配
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B7%A8%E7%BB%84%E7%BB%87%E4%BA%A4%E6%98%93%E8%B4%B9%E7%94%A8%E5%88%86%E9%85%8D

[[存货核算|《返回]]

====== 跨组织交易费用分配 ======

===== 功能概述 =====

金蝶AI星空支持跨组织交易业务，在集团中发生两个核算组织间的采购、销售、调拨业务时，归于调入组织的运费需要分配到调入组织产生内部交易单据进行核算。
用户可以通过此功能进行分配费用，目前支持分配的库存单据为跨核算组织采购、销调拨业务产生的采购入库单、采购退料单、分步式调入单、分步式调出单（退货）。
:!:不支持核算组织内调拨费用的分配。

===== 发布补丁 =====
2021年3月25日，PT-146869

===== 业务流程 =====

  * 分配流程：打开“跨组织交易费用分配”—>选择应付单->选择库存单据->点击分配->在“跨组织交易费用分配结果列表”查询分配结果
  * 取消分配流程：打开“跨组织交易费用分配结果”—>选择分配编号—>点击“取消分配”

===== 分配标准说明 =====
^ 分配标准     ^ 说明                                                          ^
| 数量       | 取参与分配库存单据分录行的实收数量（库存单位数量），分配权重=分录行实收数量/∑各分录行实收数量            |
| 金额       | 取参与分配库存单据分录行的总成本，分配权重=分录行金额/∑各分录行总成本                        |
| 毛重       | 取参与分配物料基本信息中的毛重作为分配权重，分配权重=毛重*分录行数量。如果毛重单位非基准单位将会换算成基准单位重量  |
| 净重       | 取参与分配物料基本信息中的净重作为分配权重，分配权重=净重*分录行数量。如果净重单位非基准单位将会换算成基准单位重量  |
| 体积       | 取参与分配物料基本信息中的体积作为分配权重，分配权重=体积*分录行数量。如果体积单位非基准单位将会换算成基准单位体积  |
| 自定义分配权重  | 手工输入各分录行的分配权重，为大于0的数值。                                      |

===== 功能说明 =====
  * 支持对跨核算组织产生的采购入库单、采购退料单进行费用分配。
  * 对于跨组织产生交易产生的分步式调入单与分步式调出单（退货），系统允许分配，但是在核算时，会判断分步式调入单和分步式调出单（退货）与关联单据是否在同一个核算组织，如果是在同一个核算组织，则不会把分配的费用加到分步式调入单、分步式调出单（退货）的成本上。
  * 对于已分配费用的跨组织产生的采购入库单、采购退料单、分步式调入单、分步式调出单（退货）的成本构成为：应付清单的结算价格加上分配的费用。

## 【页面】退料残值率设置
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%80%80%E6%96%99%E6%AE%8B%E5%80%BC%E7%8E%87%E8%AE%BE%E7%BD%AE

退料残值率设置是指生产过程中由于作业不良导致材料损坏或报废，退回仓库后需重新评估其价值。

====== 1 使用前提 ======


无

====== 2 功能路径 ======


【成本管理】－>【存货核算】－>【基础资料】－>【退料残值率设置】

====== 3 操作说明 ======


点击退料残值率设置，打开“核算体系+核算组织+会计政策”退料残值的维护界面，按单据类型设置综合残值率，若要对具体物料设置残值率，请在设置单据类型的综合残值率的前提下，再设置具体物料的明细残值率。设置完毕后，请保存！

====== 4 业务说明 ======


退料残值率主要是解决作业不良或者废品的生产退料场景，例如生产A产品，领用B物料10个，因作业导致材料不良2个，若重估不良退库的材料价值为正常的40%（残值率），正常材料的出库成本为20元/个，则退库的材料成本为20*40%=8元/个。出库成本核算时根据单据类型优先取物料的明细残值率，无物料明细残值率时再取综合残值率。

[[存货核算|《返回]]

====== 1 概述 ======


采购入库核算是指将企业日常经营活动中采购物料或商品所发生的费用，包括购买价款、及可归属于存货成本的相关采购费用，如关税、运输费、装卸费、保险费等等，按照核算规则计入对应物料或商品的入库成本。

计入存货成本的购买价款为不含税价款，其核算逻辑见“采购价款核算业务流程图”；采购费用的核算逻辑见“采购费用分配业务流程图”。

[图:采购价款核算业务流程图.png]
 
===== 1.2 采购费用分配业务流程图 =====


[图:采购费用分配业务流程图.png]

====== 2 使用前提 ======

入库单（退料单）必须已与应付单钩稽。

====== 3 功能路径 ======


【成本管理】－>【存货核算】－>【存货核算】－>【采购入库核算】

====== 4 操作说明 ======

第一步，进入入库成本核算向导界面一，选择核算体系、核算组织及会计政策，然后执行下一步进行核算。

## 【页面】采购入库核算应用
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%87%87%E8%B4%AD%E5%85%A5%E5%BA%93%E6%A0%B8%E7%AE%97%E5%BA%94%E7%94%A8

* 采购入库核算应用介绍：

  - 采购入库（退料）的成本由应付单确定，即采购入库（退料）单必须关联生成应付单，由应付单确定入库成本，采购过程发生的可归属存货成本的费用通过费用应付单记录，分摊至入库成本中。
  - 金蝶云引入业务应付（系统中载体为应付单）的概念，即只要物权已转移就可确定债务，并独立出发票模块，还原发票原本票据的角色，这就使得入库单的成本确定不再依赖发票的开票时间，采购费用分配也不再受采购发票的限制（即费用应付单将费用分配给入库单的前提条件是该入库单下推的应付单已审核）。
  - 标准流程是入库（退料）单审核时下推一次性下推应付单，确定入库(退料)单的成本。实际收到发票时，应付单与发票进行核销，应付单与发票存在差异时进行补差生成应付调整单，采购入库核算根据应付调整单调整入库成本；
  - 非标准流程是应付单当发票用，即实际收到发票时，才下推应付单。这种场景下存在一批货分几个月开票的情况，因此需入库单支持多次下推应付单。应付单当发票用的核算逻辑：根据入库单当期下推的部分应付单平均单价确定全部入库单的成本，以后月份再开票时，根据下推应付单的累计金额与入库单的总成本比较大小决定是否补差。因此，应付单当发票用有两个缺点：一是不能根据开票数量进行补差，只能等全部开票后才能调整差异；二是应付单当发票用，但毕竟不是发票，没有红蓝字之分，也不支持据应付单下推应付单。
  - 采购费用分摊至入库成本有两种方式，一是在费用应付单分录行勾选“计入成本”，选择需要分摊费用的入库单；二是通过采购费用分配匹配费用应付单及入库单进行手工分配。不管哪种方式，都只能选择已下推应付单的入库单号，费用应付单与发票核销存在差异补差生成应付调整单，采购入库核算根据应付调整单调整入库成本。
  - 因支持多核算体系多会计政策的成本核算，入库单下推应付单自动核算只能在默认核算体系默认会计政策下执行。存在多核算体系多会计政策时，需由“采购入库核算”根据入库单与应付单的勾稽关系在各核算体系会计政策下执行核算。
  - 采购入库核算除了根据应付单核算入库单、退料单的成本，还支持根据入库序列单据上的金额进行成本暂估。主要场景是入库单、退料单没有下推应付单，但有维护金额或者从采购订单携带的金额；其他入库单、盘盈单有维护成本，采购入库核算会根据业务单据上的金额或成本写入存货核算入库成本数据表中。
  - 采购入库核算支持跨组织间交易，并由应付结算清单的金额确定入库成本。

  * 常见问题如下：
问题1:入库单有下推应付单，但入库单成本为0？

答:应付单与入库单不在同一会计期间，对于当期入库单来说，仍没有下推应付单，且入库单上金额也为0，只能通过入库成本维护进行成本维护；还有一种情况是，入库单下推应付单之前，已生成凭证（取入库单金额），然后当期下推应付单，这时因为入库单已记账，不能更新入库单成本，直接补差生成入库成本调整单。

问题2:入库单上的金额与总成本有什么区别？

答：: 入库单上的金额一般是有采购订单携带下来，为合约采购金额，是确定应付的主要参考数据，总成本是根据入库单下推应付单的金额确定入库成本反写的，如果涉及采购费用的话，也会包含在内。凭证取数只能取总成本。

问题3:入库单与应付单都在同一期，但为什么怎么核算入库单的成本都不等于应付单呢？

答: 入库单下推应付单后生成凭证，然后应付单反审核后再修改金额，这种情况下应付单重新审核重新核算不会更新入库单成本，直接补差生成入库成本调整单。

问题4:退料单有下推应付单，但退料单成本为0？

答: 检查下勾稽日志。

问题5:入库单没有下推应付单但有金额，为什么采购入库核算后，入库单成本不等于金额？

答:首先要检查入库有没有生成凭证，没有凭证的话，可能是入库单有修改金额导致，这种情况下将入库成本维护中的成本清0，重新采购入核算即可。

问题6:组织间交易产生的分步式调入单没有成本？

答:检查有没应付结算清单，确定创建并审核应付结算清单后，重新采购入库核算，在入库成本维护中检查结果 。

会计核算体系简称核算体系，是对企业业务核算范围和口径的标准划分，也是用于确定成本核算主体的体系架构。基于每个核算体系，可以对所有业务组织按照核算的需要划分若干核算组织（也就是会计主体）。透过核算体系，可以清晰的看到核算体系、核算组织、业务组织的上下层级关系，此层级关系通常也是企业组织架构。

可以同时存在多个核算体系，核算体系间相互独立，每个核算体系是单独的成本池。通常企业可以基于财务核算与企业管理的双重目的建立两套彼此独立的核算体系。

第二步，在向导界面二点击食品成本核算报告，查看核算结果。
	检查自定义食品成本卡：勾选该选项后，系统自动检查核算范围内是否存在没有设置成本卡的自定义食品，若存在，则停止核算，必须先设置自定义食品成本卡；不勾选该选项，则系统不检查自定义食品。

## 【页面】食品成本核算概述
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A3%9F%E5%93%81%E6%88%90%E6%9C%AC%E6%A0%B8%E7%AE%97%E6%A6%82%E8%BF%B0

食品成本核算是根据某组织某出品部门在一段时间内出品销售的所有食品与其所耗用的全部原材料,通过设置各销售食品的成本卡，利用食品成本核算算法核算得到。但不能单独核算某个食品的成本或通过某些原材料核算某个或某些食品。因为实际业务中并不知道某个或某些原材料具体用在哪个食品中。

## 【页面】食品成本核算系统特性
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A3%9F%E5%93%81%E6%88%90%E6%9C%AC%E6%A0%B8%E7%AE%97%E7%B3%BB%E7%BB%9F%E7%89%B9%E6%80%A7

食品成本核算以核算各销售组织下各出品销售部门所销售的食品成本为目标，通过销售数据，食品成本卡，原材料耗用等将食品标准成本及实际成本核算出来，便于经验管理者对企业经营数据进行分析。

应用价值有：

    既支持多门店多组织多出品部门食品成本核算，也支持单体组织食品成本核算；
    支持多核算体系多会计政策成本核算下的食品成本核算；
    支持不同核算范围不同计价方法核算下食品成本核算；
    同时核算出每个食品的标准成本及实际成本，以及计算出两者之间的差额；
    取各销售终端销售数据，对比标准成本，实际成本及销售单价，一般管理者能及时调整营销策略；
    统计部门用料成本，以及部门销售金额，计算部门利润。

## 【页面】餐饮成本核算使用流程
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A4%90%E9%A5%AE%E6%88%90%E6%9C%AC%E6%A0%B8%E7%AE%97%E4%BD%BF%E7%94%A8%E6%B5%81%E7%A8%8B

第一步：基础设置

在食品成本核算系统使用前，需要先设置组织机构（核算组织）、会计政策、会计核算体系、食品成本卡、口味及要求成本卡、自定义食品成本卡等基础资料（其中组织机构（核算组织）、会计政策、会计核算体系在存货核算前就已经设置好，由于食品成本核算需要使用到，这里再重复说明）。
首先，用系统管理员（administrator）进入数据中心设置组织机构；
进入基础管理－>系统管理－>组织机构－>组织机构列表，新增组织机构。
其次，用用户账号进入数据中心依次设置会计政策、会计核算体系，路径如下：

进入基础管理－>基础资料－>公共资料－>会计政策
进入财务会计－>总账－>基础资料－>会计核算体系


进入门店经营－>门店数据管理－>食品管理－>食品

进入门店经营－>门店数据管理－>食品成本卡管理－>食品成本卡

进入门店经营－>门店数据管理－>食品管理－>口味要求

 

第二步：食品成本核算

首先，采购入库核算
审核应付单：进入财务会计－>应付管理－>应付确认－>应付单
采购费用分配：进入成本管理－>存货核算－>存货核算－>采购费用分配
钩稽日志查询：进入成本管理－>存货核算－>存货核算－>钩稽日志查询
采购入库核算：进入成本管理－>存货核算－>存货核算－>入库成本核算
其次，成本暂估及成本调整
入库成本暂估：进入成本管理－>存货核算－>存货核算－>入库成本暂估

成本调整：进入成本管理－>存货核算－>成本调整－>成本调整单
再次，出库成本核算
出库成本核算：进入成本管理－>存货核算－>存货核算－>出库成本核算
其他存货成本核算：进入成本管理－>存货核算－>存货核算－>其他存货核算

最后，根据出入口核算出来的物料的准确成本来核算食品成本

食品成本核算：进入成本管理－>餐饮成本核算－>食品成本核算－>食品成本核算

 

第三步：报表分析

食品成本核算报告：进入成本管理－>餐饮成本核算－>报表分析－>食品成本核算报告
