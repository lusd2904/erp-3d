====== 1.历史物料用量要货 ======

===== 1.1 功能概述 =====

  * 通过历史物料用量要货的计算维度满足企业企业不同的预估要货需求。根据历史同期时间范围内：最近一天要货、上周同期、上月同期、上年同期、固定日期等要素计算门店的要货需求，生成预估要货单。
  * 历史物料用量要货是用于门店参考自己以往的某一个时间段的要货情况对后期的要货数量进行预估的过程.
  * 生成的物料预估要货单根据物料的配送和自采属性选择下推的单据。
  * 只具有配送属性的物料预估要货单只能下推到门店要货申请单；只具有自采属性的物料预估要货单只能下推到采购申请单/采购订单。

===== 1.2 历史物料用量要货流程图 =====


根据历史同期时间范围内：最近一天要货、上周同期、上月同期、上年同期、固定日期等要素计算门店的要货需求，生成预估要货单。

[图:历史物料用量要货流程图.png]

===== 1.3 使用前提 =====
**使用前提：需要门店要货申请，采购申请单，采购订单**

| 要货日期            | 门店预估要货的日期。                            |
| 最近一天要货          | 根据要货组织最近一天的要货申请单的要货物料和数量生成历史同期数据。     |

| 生成预估要货单（汇总）   | 点击生成汇总的物料预估要货单                        |

===== 1.5 业务说明 =====
  * 在历史物料用量要货中增加物料分组，来精确选择某类物料，根据选择的物料过滤数据。
  * 计算历史同期数据；
  * 根据历史同期数据生成物料预估要货单。

====== 1. 物料预估要货单 ======
===== 1.1 功能概述 =====

物料预估要货单是根据历史物料用量要货和历史食品销量要货计算出预估要货量，根据预估要货量生成物料预估要货单。通过物料预估要货，门店可以提前做要货计划，以防止物料短缺。
 
===== 1.2 系统应用 =====

通过智能要货模型计算物料的预估需求，生成自采或配送计划。
 
===== 1.3 使用前提 =====

定义物料预估要货单的单据类型、业务组织、物料、单位等。

1.5 业务说明
  * 参数设置中勾选参数“物料预估要货单审核时自动生成门店要货申请单”。在审核物料预估单时系统根据预估单的单据类型自动生成对应单据类型的门店要货申请单。 
  * 参数设置中不勾选参数“物料预估要货单审核时自动生成门店要货申请单”。手工下推生成门店要货申请单，相同单据类型的物料预估单可下推生成一张门店要货申请单
  * 物料预估单生成下游单据时，取实际订货量携带到下游单据

====== 1.门店周期要货 ======
===== 1.1 功能说明 =====
门店周期要货是参考盘盈单，盘亏单，食品材料耗用单的历史数据来生成物料预估用量单。根据订货的周期和历史营业销售数据（预估营业总额，物料万元用量，食品成本卡），算出各物料的预估销售数量。




===== 1.2 门店周期要货流程图 =====
**使用前提：盘盈单，盘亏单，食品材料耗用单**

**盘盈单，盘亏单，食品材料耗用单三种类型的单据在来源时间段内至少有一种单据有数据才行**

**门店周期要货中预估营业额取的是用户手工新增的预估营业额，而不会取销售预测自动计算的预估营业额**

[图:门店周期要货流程图.png]

===== 1.3 操作步骤 =====

**新增门店预估营业额 --》 门店周期要货选择参考日期 --》 门店周期要货生成物料预估要货单**

===== 1.4 业务说明 =====
  * 有物料类别和过滤方案保存功能 
  * 历史时间段默认为当前日期的前一个月
  * 默认赋值给界面上的“组织”上
  * 安全系为只读状态，实际订货数）可以进行修改，默认取(预估数量）的值
  * 门店周期要货时，输入组织，参考的历史起止日期之后，取门店对应的数据，更新右边数据

===== 1.2 业务说明 =====

一、预估单自动生成门店要货申请单 

（一）参数设置中勾选参数“物料预估要货单审核时自动生成门店要货申请单”。在审核物料预估单时系统根据预估单的单据类型自动生成对应单据类型的门店要货申请单。  
                                                                    
（二）参数设置中不勾选参数“物料预估要货单审核时自动生成门店要货申请单”。手工下推生成门店要货申请单，相同单据类型的物料预估单可下推生成一张门店要货申请单。

二、历史食品销量要货按部门生成物料预估

参数中如果勾选了“历史食品销量要货按部门生成物料预估”，那么历史食品销量要货生成的物料预估会携带部门信息，并且会按照部门进行分单。

三、门店食品预估方案上传按部门分单

参数中如果勾选了“门店食品预估方案上传按部门分单”，那么门店食品预估方案生成的物料预估单会携带部门信息。

====== 1.门店订货预估 ======
===== 1.1 整体功能介绍 =====
通过历史同期用量和单位用量计算门店的要货需求，提前补充物料，防止物料短缺，优化运营流程，提高企业运转效率及管理水平。

K/3 Cloud餐饮智能平台提供多维度的智能要货管理，连锁餐饮企业门店根据智能要货提前补充物料，减低门店运营成本。

K3Could 餐饮智能要补货支持历史同期用量要货和单位用量要货，通过不同维度计算门店的预要货物料数量，生成门店的要货需求，帮助企业更加透明的运营管控，降低企业整体库存水平及运营成本。
