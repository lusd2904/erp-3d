## 【页面】启用固定资产系统
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%90%AF%E7%94%A8%E5%9B%BA%E5%AE%9A%E8%B5%84%E4%BA%A7%E7%B3%BB%E7%BB%9F

货主组织需要分会计政策来设置启用期间。会计政策中的会计日历有期间，从那个期间启用会计政策，用户根据具体业务情况进行选择。

  * 操作说明：

   - 选择货主组织，系统自动根据货主组织找到其适用的会计政策； 
  - 选择需要启用的会计政策，设置具体的启用期间；   
  - 单击启用按钮即完成启用设置。

  * 业务说明： 货主组织启用了某个会计政策，才允许新增该会计政策下的资产卡片数据。某个会计政策下如果存在了资产卡片数据，则不允许反启用。没有资产卡片数据，则允许反启用。单击 启用列表 可以查看所有货主组织的启用设置情况。
               反启用时，需检查该货主组织下是否存在卡片。存在时，不允许反启用。需注意，卡片列表是按资产组织进行过滤，当资产组织与货主组织不同时，列表会按登录组织=资产组织进行过滤，则该货主下的卡片无法显示出来。这种情况下，需勾选列表过滤界面所有的组织进行过滤。

====== 1 固定资产系统概述 ======

===== 1.1 资产概述 ===== 
   
固定资产系统以资产卡片管理为中心，从资产购入企业开始到资产退出的整个生命周期的管理，能针对资产实物进行全程跟踪、能够记录、计量资产的价值变化，能够记录资产的使用情况和折旧费用的分配情况。实现资产管理工作的信息化、规范化与标准化管理，全面提升企业资产管理工作的工作效率与管理水平，使资产的管理变得轻松、准确，快捷和全面。

===== 1.3 系统特性 =====


  - 资产的多会计政策计量、计价。  
  - 单张卡片的多资产管理。 
  - 灵活的资产类别设置。 
  - 强大的资产多折旧方法应用。 
  - 完整的固定资产业务处理，包括多组织间的交易和临时的借用归还等。 
  - 单个资产的多部门使用。 
  - 多个来源建卡。 
  - 多角度的报表查询与分析功能。

====== 2 固定资产业务专题 ======

===== 2.1 多会计政策 ===== 

固定资产系统支持多会计政策核算，同一张卡片支持多价值管理。

会计政策，是系统化企业财务管理的方针政策，依据国家（地区）会计准则建立。资产管理相关的会计政策有：各资产类别的资产折旧方法、资产折旧年限、折旧政策等等。

从资产卡片维度看，同一张卡片支持多会计政策，不同政策下财务信息不同，但实物信息共享。

从会计政策维度看，在同一个会计政策下，各资产类别采用的折旧方法、折旧政策、折旧年限原则上是相同的，但具体到每个卡片时允许修改。一个会计政策下管理的各资产卡片价值，类似于一个独立于总账的虚拟资产账。

===== 2.2 多数量建卡管理 ===== 

对于批量购买的资产，可采用多数量卡片建卡的模式。即先建立一张多数量的卡片，待卡片建好后，在入账当期再将其拆分为单数量卡片。这种模式主要目的是减少建卡工作量，避免因逐个数量手工建卡而耗费大量时间与精力。
===== 2.3 多使用部门 ===== 
一个实物资产供多个部门使用，多个费用承担部门。
实物资产按比列分配给不同的使用部门、使用人，实现折旧费用在多个使用部门、使用人之间进行分摊。
===== 2.4 多折旧方法 ===== 
多折旧方法，平均年限法、双倍余额递减法、年数总和法和工作量法。
一个折旧方法两种计算公式：以原值为起点静态折旧计算方法，以及以净值为起点的动态折旧计算方法。

支持一次性计提折旧：若卡片需要一次性计提折旧，则可在会计政策资产政策处维护“一次性折旧原值”字段（该字段需去BOS放开可见）；当卡片的变动方式有勾选“税法允许一次性折旧”，则在满足第一次折旧计提的条件时，将折旧一次性提完。
===== 2.5 多来源建卡 ===== 
根据来源提供八种建卡途径：手工建卡、采购收货建卡、库存领用建卡、盘盈建卡、调拔建卡、拆分建卡、合并建卡、租入建卡。 
  - 手工建卡：手工建立资产卡。 
  - 采购收货建卡：资产采购后不入库直接建卡。建卡来源单据：收料单。新增资产卡片，选择资产类别后，点击选单按钮，选择收料单建卡。
  - 库存领用建卡：作为普通的物料进行采购入库的，日后被领作固定资产用，需要从仓库领用建卡。建卡来源单据：其他出库单。
  - 盘盈建卡：进行资产盘点后，根据盘盈资产建卡。建卡来源单据：盘盈单。
  - 调拨建卡：资产调拨，资产调入后建卡。建卡来源单据：资产调入单。
  - 拆分建卡：资产拆分建卡。建卡来源单据：资产卡片。
  - 合并建卡：资产合并建卡。建卡来源单据：资产卡片。
  - 租入建卡：使用资产租赁模块，审核资产租入单后自动产生资产卡片（也可手工下推）。建卡来源：租入建卡。

  * 功能路径：【基础管理】-->【系统管理】-->【组织业务关系】

  * 操作前提：启用多组织管理

  * 字段说明：
  
|**字段**||**说明**|

|委托方||选择拥有固定资产所有权的货主组织。|

  * 操作说明：一个资产组织可以管理多个货主组织的资产，一个货主组织的资产也被多个资产组织管理。系统中只要设置了管资产的托管关系，则固定资产系统所有同时存在资产组织和货主组织的单据都得遵循这种托管关系。未设置，则同时存在资产组织和货主组织的单据不受托管控制。

设置固定资产参数，【资产管理】－>【固定资产】－>【参数设置】－>【固定资产参数设置】

【资产管理】－>【固定资产】－>【启用期间设置】－>【启用固定资产系统】

第三步，基础资料维护
包括资产类别、资产状态、变动方式、折旧方法、资产位置、折旧政策、会计政策等

第四步，维护初始化卡片

第五步，日常业务操作

  1、资产申请
  
  2、资产入账（建资产卡片）
  
  3、资产处置
  
  4、资产变更
  
  5、资产借用
  
  6、资产领用
  
  7、资产批量变更
  

第六步，期末处理

  1、资产盘点
  
  2、折旧管理
  
  3、账务处理
  
  4、结账

您的足迹: • start • 总账 • 固定资产 • 费用报销 • 费用报销使用流程

## 【页面】折旧政策
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8A%98%E6%97%A7%E6%94%BF%E7%AD%96

折旧政策是用于描述资产折旧的规则与策略的基础资料。
系统预置了常用折旧政策及使用权资产折旧政策，
1、常用折旧政策适用于企业自行购买的资产，企业如果有特殊需求，可根据自身需要设置其他的折旧政策；
2、按照新租赁准则，租赁资产满足使用权资产确认条件的，需要在使用期间内计提折旧，所以系统预置了使用权资产折旧政策，折旧政策为“新增当期计提折旧，处置当期计提折旧”。 企业可根据自身需要设置的使用权资产的折旧政策。
  * 操作前提：应用资产管理系统。

  * 字段说明：
  
|**字段**||**说明**|
|新增当期不提折旧，清理当期计提折旧||表示卡片在新增的当期不参与折旧计算，在清理的当期参与折旧计算。卡片如果在新增的当期就发生了清理，则该卡片新增当期参与折旧计算。|
|新增当期不提折旧，清理当期不提折旧||表示卡片在新增的当期不参与折旧计算，在清理的当期也不参与折旧计算。卡片如果在新增的当期就发生了清理，则该卡片新增当期不参与折旧计算。|
|新增当期计提折旧，清理当期不提折旧||表示卡片在新增的当期参与折旧计算，在清理的当期不参与折旧计算。卡片如果在新增的当期就发生了清理，则该卡片新增当期参与折旧计算。|
|新增当期计提折旧，清理当期计提折旧||表示卡片在新增的当期参与折旧计算，在清理的当期也参与折旧计算。卡片如果在新增的当期就发生了清理，则该卡片新增当期参与折旧计算。|
|财务信息和分配信息变动当期即影响折旧||选中该参数，变动财务信息或者折旧费用承担组织或部门时，在变动的当期就会采用新的财务信息计算折旧，将费用分配给变动后的组织或部门。|
|折旧要素变动时按静态折旧方法计算||选中该参数，卡片发生财务信息变更时，仍采用静态的折旧公式。|
 
  * 操作说明：折旧政策审核即可使用，会计政策的资产政策页签中需要对每个资产类别设置具体的折旧政策。折旧政策一经设定，将会影响卡片新增和清理当期的折旧计算。

折旧调整单是计提折旧的结果。每次计提成功系统自动按货主组织及会计政策当期期间产生一张折旧调整单。资产管理员及资产会计可根据实际需要对当期的折旧额进行调整。

====== 2 固定资产业务专题 ======

===== 2.1 多会计政策 ===== 

固定资产系统支持多会计政策核算，同一张卡片支持多价值管理。

会计政策，是系统化企业财务管理的方针政策，依据国家（地区）会计准则建立。资产管理相关的会计政策有：各资产类别的资产折旧方法、资产折旧年限、折旧政策等等。

从资产卡片维度看，同一张卡片支持多会计政策，不同政策下财务信息不同，但实物信息共享。

从会计政策维度看，在同一个会计政策下，各资产类别采用的折旧方法、折旧政策、折旧年限原则上是相同的，但具体到每个卡片时允许修改。一个会计政策下管理的各资产卡片价值，类似于一个独立于总账的虚拟资产账。

===== 2.2 多资产管理 ===== 

支持一张卡片管理多个实物资产，每个实物资产通过资产编码来区分，使用分配和附属设备信息可直接针对资产编码来管理。
===== 2.3 多使用部门 ===== 
一个实物资产供多个部门使用，多个费用承担部门。
实物资产按比列分配给不同的使用部门、使用人，实现折旧费用在多个使用部门、使用人之间进行分摊。
===== 2.4 多折旧方法 ===== 
多折旧方法，平均年限法、双倍余额递减法、年数总和法和工作量法。
一个折旧方法两种计算公式：以原值为起点静态折旧计算方法，以及以净值为起点的动态折旧计算方法。

7.3版本支持一次性计提折旧。
如果卡片需要一次性计提折旧，则要去会计政策资产政策维护“一次性折旧原值”字段（该字段需去BOS放开可见）；当卡片的变动方式有勾选“税法允许一次性折旧”，则在满足第一次折旧计提的条件时，将折旧一次性提完。
===== 2.5 多来源建卡 ===== 
根据来源提供七种建卡途径：手工建卡、采购收货建卡、库存领用建卡、盘盈建卡、调拔建卡、拆分建卡、合并建卡。 
  - 手工建卡：手工建立资产卡。 
  - 采购收货建卡：资产采购后不入库直接建卡。建卡来源单据：收料单。新增资产卡片，选择资产类别后，点击选单按钮，选择收料单建卡。
  - 库存领用建卡：作为普通的物料进行采购入库的，日后被领作固定资产用，需要从仓库领用建卡。建卡来源单据：其他出库单。
  - 盘盈建卡：进行资产盘点后，根据盘盈资产建卡。建卡来源单据：盘盈单。
  - 调拨建卡：资产调拨，资产调入后建卡。建卡来源单据：资产调入单。
  - 拆分建卡：资产拆分建卡。建卡来源单据：资产卡片。
  - 合并建卡：资产合并建卡。建卡来源单据：资产卡片。

  - 资产卡片已审核

====== 2 字段说明 ======

=====2.1 基本 =====
|**字段**||**说明**|
|单据类型||系统提供两种类型：资产借入、资产借出。借入方填制单据时选择“资产借入”，借出方填制单据时选择“资产借出”。|
|借用日期||资产借用业务发生的日期。|
|货主组织||借用资产所属货主组织。|
|借用组织||需要借用资产的组织。|
|借用部门||需要借用资产的部门。|
=====2.2资产 =====
  - 选择具体需要借用的资产卡片，支持批量借用卡片资产。 

=====2.3使用及实物信息 =====
  - 显示借用资产原资产位置、使用部门、使用人信息。 
 
 


====== 3操作说明 ======
===== 3.1新增借用单 =====

操作步骤：
  - 单击**固定资产-->资产借用**，进入**资产借用单列表**界面； 
  -      单击**新增**按钮，打开资产借用单新增界面；
  -        输入所要借用的资产的资产组织、货主组织、借用原因等信息；      
  - 选择需要借用的资产卡片（在卡片编码字段手工录入要借用资产的卡片编码，或在卡片编码按F8调出资产卡片列表，通过过滤进行查找选择所要借用资产的卡片）。
  -        单击**保存**按钮完成资产借用单的保存。
 
===== 3.2审核借用单 =====
在资产借用单列表界面，选中借用单，单击提交-->审核即完成审核操作，在资产卡片中可以联查借用记录。 
 
===== 3.3反审核借用单 =====
在资产借用单列表界面，选中已审核借用单，单击反审核即完成反审核操作。进行反审核操作后，资产借用单可以进行删除。 

===== 3.4资产归还 =====
若后续借用的资产已经归还，则打开原资产借用单，勾选是否归还，并选择归还日期。

## 【页面】资产卡片
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E5%8D%A1%E7%89%87

资产卡片是用来记录资产信息的单据，在卡片上可以记录资产的财务信息、实物信息、附属设备信息、使用分配信息等。本节主要实现以下功能：新增卡片、卡片拆分、卡片合并、卡片变更、查询变更记录、查询借用记录。

====== 1 操作前提 ====== 

  - 定义资产类别基础资料
  - 定义折旧政策基础资料   
  - 在会计政策中完成资产政策的定义
  - 在组织业务关系中定义资产组织与货主组织的业务委托关系
  - 定义资产位置基础资料

 ====== 2 字段说明 ======

=====2.1 基本信息 =====
| **字段**     || **说明**                                                                                                                              |
| 资产组织       || 资产的管理组织，只能输入组织职能为资产职能的组织。                                                                                                           |
| 货主组织       || 资产的所有权的归属组织，货主组织必须为业务组织。                                                                                                            |
| 资产类别       || 实物资产所属的资产类别。                                                                                                                        |
| 卡片编码       || 资产卡片的编号，具有唯一性。如果对应的资产类别有设置卡片编码规则，系统会自动根据卡片编码规则递增编码，如果对应的资产类别没有设置卡片编码规则，则自动从1递增编码。允许手工修改。如果更改资产类别的卡片编码规则，则需反审核资产类别，重新选择新的编码规则，方能生效。  |
| 资产名称       || 实物资产的名称。                                                                                                                            |
| 计量单位       || 实物资产的计量单位。                                                                                                                          |
| 资产状态       || 实物资产的使用状态。                                                                                                                          |
| 变动方式       || 实物资产的取得方式。                                                                                                                          |
| 开始使用日期     || 实物资产的开始使用日期，建议小于等于资产的入账日期。                                                                                                          |
| 卡片来源       || 卡片来源由系统根据卡片的来源途径自动处理。                                                                                                               |

=====2.2会计政策 =====
|**字段**||**说明**|
|会计政策||进行资产核算的财务制度，系统自动默认携带|
|币别||会计政策对应的币别。|
|相关折旧信息||在资产卡片中输入资产类别信息后，这里自动显示资产类别对应的会计政策中折旧年限、残值、折旧方法等信息。方便查看对应的折旧财务核算制度。|

=====2.3财务信息 =====
| **字段**      || **说明**                                                                        |
| 会计政策        || 下拉框列示会计政策页签中的记录，财务信息页签的所有信息均需要针对会计政策录入，在财务页签中，会计政策相当于一个标题。                    |
| 币别          || 会计政策对应的币别。                                                                    |
| 入账日期        || 资产卡片的记账日期。入账日期必须大于或者等于固定资产的启用期间                                               |
| 未税成本        || 构成资产原值的不含税金额。                                                                 |
| 进项税额        || 购买资产的进项税额，当对应资产类别设置了“原值包含进项税”时，则原值包含进项税额，否则不包含。                               |
| 费用金额        || 构成资产原值的费用金额。                                                                  |
| 费用税额        || 购买资产产生的费用的进项税额，当对应资产类别设置了“原值包含进项税”时，则原值包含费用税额，否则不包含。                          |
| 资产原值        || 资产类别设置“原值包含进项税”，则 资产原值=未税成本+进项税额+费用金额+费用税额；资产类别未设置“原值包含进项税”，则资产原值=未税成本+费用金额。  |
| 累计折旧        || 新增卡片时，录入建卡时的累计折旧额。累计折旧是个变动值，每期折旧额都会更新至对应的卡片中累计折旧。始终保持的是最新的累计折旧额。              |
| 资产净值        || 资产净值=资产原值-累计折旧                                                                |
| 累计减值准备      || 新增卡片时，录入建卡时的累计减值准备额，累计减值准备是个变动值，每次新增的累计减值准备都会更新至对应的卡片中。始终保持的是最新的累计减值额。        |
| 账面价值        || 账面价值=资产净值-累计减值准备                                                              |
| 预计残值        || 根据会计政策中的资产类别适用的残值类型不同来处理：残值类型为百分比时，预计残值=资产原值×残值比率                             |
| 预计使用期间数     || 根据会计政策中的资产类别的折旧年限结合会计政策的会计日期的期间类型自动计算出来，支持手工修改。                               |
| 累计使用期间数     || 新增卡片时，录入建卡时的累计已使用期间数。累计使用期间数是个变动值，每期计提折旧成功会自动增加一期。                            |
| 累计折旧期间数     || 新增卡片时，录入建卡时的累计已计提折旧期间数。累计使用期间数是个变动值，每计提一次折旧，累计折旧期间数会自动增加一期。                   |
| 折旧方法        || 根据会计政策中的资产类别自动带出，支持手工修改。                                                      |
| 按变动进行折旧     || 此选项只有新增卡片时可手工设置。其余时候如果有变更单变更财务信息，系统会自动勾选“按变动进行折旧”。选中表示会按最新的折旧要素数据计算折旧。        |
| 购进原值        || 用于记录二手资产的原始入账价值。                                                              |
| 购进累计折旧      || 用于记录二手资产的累计折旧。                                                                |
| 折旧年期        || 最近一次的计提折旧的年度期间。                                                               |
| 折旧金额        || 最近一次的计提折旧的折旧金额。                                                               |
| 本年累计折旧      || 本年计提的累计折旧金额（如果卡片在本年刚入账，则还包含入账时的本年累计折旧）。                                       |
| 未提折旧金额      || 最近一次的计提折旧后的未提折旧金额。                                                            |

=====2.4实物信息 =====
|**字段**||**名称**|
|资产编码||实物资产的编号，具有唯一性。如果对应的资产类别有设置资产编码规则，系统会自动根据资产编码规则递增编码，如果对应的资产类别没有设置资产编码规则，则自动从1递增编码。允许手工修改。|

|数量||实物资产的数量。|
|供应商||实物资产的供应商。|

|产地||实物资产的产地。|
|制造商||实物资产的制造商。|
|是否保险||实物资产是否参与保险。|
|备注||实物资产的备注。|
|保管人||实物资产的保管人。|
|实物类别||实物资产的实物类别。|
=====2.5使用分配 =====
|**字段**||**名称**|

|使用部门||资产的使用部门。|

=====2.6附属设备 =====

=====2.7发票 =====
在这个页签中可以输入每个具体实物资产的发票信息。可以手工录入，也可以F8选择采购发票。发票信息任何时候都可以补充填写。
=====2.8维修保养 =====
在这个页签中可以输入每个具体实物资产的维修记录。发生维修时补充填写。 

=====2.9卡片拆分 =====
卡片拆分主要是根据企业管理需要，将一张资产卡片的资产拆分成多张资产卡片进行管理。

拆分界面展示为一个表头，两个表体：拆分前卡片信息、拆分后卡片信息。

**表头信息说明如下**：
|**字段**||**说明**|
|资产组织||进行资产卡片拆分的资产组织。|
|货主组织||进行资产卡片拆分的资产卡片的货主组织，只能选择组织业务关系中定义资产托管关系的货主组织。|
|日期||拆分业务发生的日期，默认系统日期，可修改。必须在会计政策当期期间内。|
|拆分前卡片||显示用户选中的要进行拆分的资产卡片。|
|资产数量||显示被拆分卡片的资产数量。|
|卡片拆分数量||用户录入拆分后的卡片张数。|
|拆分原因||用户录入进行卡片拆分的原因。|
**表体信息--拆分前卡片**：显示被拆分卡片的主要的实物信息和财务信息。

**表体信息--拆分后卡片主要信息说明如下**：

|**字段**||**说明**|
|拆分后卡片--卡片编码||拆分后卡片的编号，具有唯一性。如果对应的资产类别有设置卡片编码规则，系统会自动根据卡片编码规则递增编码，如果对应的资产类别没有设置卡片编码规则，则自动从1递增编码。允许手工修改。|
|拆分后卡片--资产名称||继承拆分前卡片的资产名称，允许修改。|
|拆分后卡片--资产数量||系统计算，等于“拆分前卡片的资产数量/卡片拆分数量”，允许修改。|
|实物信息--资产编码||拆分后卡片的实物资产编号，具有唯一性。如果对应的资产类别有设置资产编码规则，系统会自动根据资产编码规则递增编码，如果对应的资产类别没有设置资产编码规则，则自动从1递增编码。允许手工修改。|

 拆分后卡片的财务信息中的金额系统会自动计算，均按拆分前卡片对应的金额字段除以卡片拆分数量来计算，允许修改。拆分后卡片中的数量和金额字段相加必须与拆分前的保持一致。
=====2.10卡片合并 =====
卡片合并主要是根据企业管理需要，将多张资产卡片的资产合并成一张资产卡片进行管理。

合并界面展示为一个表头，两个表体：合并前卡片信息、合并后卡片信息。

**表头信息说明如下**：

|**字段**||**说明**|
|资产组织||显示被合并卡片的资产组织。|
|货主组织||显示被合并卡片的货主组织。|
|日期||合并业务发生的日期，默认系统日期，可修改。必须在会计政策当期期间内。|
|合并原因||用户录入进行卡片合并的原因。|

**表体信息--合并前卡片**：显示被合并卡片的主要的实物信息和财务信息。

**表体信息--合并后卡片主要信息说明如下**：

|**字段**||**说明**|
|合并后卡片--卡片编码||合并后卡片的编号，具有唯一性。如果对应的资产类别有设置卡片编码规则，系统会自动根据卡片编码规则递增编码，如果对应的资产类别没有设置卡片编码规则，则自动从1递增编码。允许手工修改。|

合并后卡片的财务信息中的金额系统会自动计算，等于合并前各卡片对应的金额字段之和。不允许修改。实物信息为合并前的所有信息的汇总。
=====2.11卡片批量变更 =====

系统提供批量变更功能，支持批量变更：资产名称、资产位置、资产状态、使用分配、保管人、规格型号六种信息。



 ====== 3操作说明 ======
=====3.1手工新增资产卡片 =====
操作步骤：点击**资产卡片-->新增**，可以新增历史卡片，也可以新增正常业务期间的卡片。 

=====3.2通过其他单据新增卡片 =====
系统提供【选单】功能建卡，可以通过该功能选择以下**四种**单据：“收料通知单”、“其他出库单”、“资产调入单”、“盘盈单”、“资产租入单”作为建卡的来源单据。系统自动匹配来源单据和目标单据“资产卡片”的字段。
操作步骤：
  - 单击**资产卡片-->新增-->选单**，进入选择单据界面；
  - 选择一个具体的来源单据；
  - 单击** 确定** 按钮，系统自动将来源单据中与卡片相关的字段携带至资产卡片中，用户只需补充完资产卡片中的字段即可完成资产卡片新增。
  - 用户手工修改卡片上的资产数量与源单不一致时，卡片中相关字段的值，会根据资产数量占源单数量的比例进行自动计算。 
=====3.3卡片拆分操作 =====
**拆分**：系统提供【拆分】功能，支持将一张卡片的资产拆分成多张卡片进行管理。拆分操作将清除本期已计提的折旧，本期的折旧需要重新计提才能生效。操作步骤：
  - 打开资产卡片，选中需要进行拆分的卡片，单击**拆分-->拆分**，进入资产拆分界面；   
  - 输入“卡片拆分数量、拆分原因、日期”信息；  
  - 单击** 拆分** 按钮，系统按输入的卡片拆分数量自动进行资产卡片拆分，拆分后的卡片数据部分支持修改，具体见上述的卡片拆分； 
  - 单击** 保存** 按钮，系统按输入的信息自动进行拆分，生成新的卡片。拆分拆分之后原卡片的处置情况为拆分清理。
**撤销拆分** ：拆分生成的卡片不可以手工修改，提供撤销拆分功能删除拆分后的卡片 。操作步骤：
  - 打开资产卡片，选中拆分前的卡片（可以通过在过滤条件中输入“处置情况=拆分清理”快速找到拆分前的卡片），单击**拆分-->撤销**，系统自动删除拆分后的卡片。
**上查拆分前的卡片** ：拆分后的卡片可以联查拆分前的卡片信息。操作步骤：
  - 打开资产卡片，选中拆分后的卡片，单击**拆分-->上查**，可以查看拆分前的卡片信息。

=====3.4卡片合并操作 =====
**合并**：系统提供【合并】功能，支持将两张或以上卡片合并成一张卡片进行管理。合并操作将清除本期已计提的折旧，本期的折旧需要重新计提才能生效。操作步骤：
  - 打开资产卡片，选中需要进行合并的卡片，单击**合并-->合并**，进入资产合并界面；
  - 单击** 合并** 按钮，系统自动进行资产卡片的合并，合并后的卡片数据部分支持修改，具体见上述的卡片合并；
  - 单击**保存** 按钮，系统按输入的信息自动进行合并，生成新的卡片。
**撤销合并** ：合并生成的卡片不可以手工修改，提供撤销合并功能删除合并后的卡片 。

操作步骤：
  - 打开资产卡片，选中合并前的卡片的一张卡片（可以通过在过滤条件中输入“处置情况=合并清理”快速找到拆分前的卡片），单击**合并-->撤销**，系统自动删除合并后的卡片。
**上查合并前的卡片**：合并后的卡片可以联查合并前的卡片信息。

操作步骤：
  - 打开资产卡片，选中拆分后的卡片，单击**合并-->上查**，可以查看合并前的卡片信息。
**合并说明：**
   -仅支持一模一样的资产进行合并，即资产名称、开始使用日期、入账日期、预计使用年限、累计折旧期间数、累计使用期间数、资产原值、未税成本等都是一样的资产，相当于将多个同样的资产合并一个卡片上进行管理，所以合并后数量是卡片原数量的汇总；
   -不适用于将多个资产合并成一个数量的场景。
=====3.5卡片批量变更操作=====
系统支持批量变更：资产名称、资产位置、资产状态、使用分配四种信息。操作步骤：
  - 打开资产卡片，选中需要进行变更的卡片，单击变更-->资产位置（资产名称、资产状态、使用分配），进入批量变更界面；  
  - 输入变更后的信息，不需要输入信息的记录行可以通过删除行来删除；
  - 单击 保存 按钮即完成变更操作，系统按输入的变更后的信息自动更新的卡片上对应字段信息。
=====3.6联查变更记录====
系统支持针对单张卡片联查历史变更记录。操作步骤：
  - 打开资产卡片，选中需要查询变更记录的卡片并打开，单击变更记录，即可查询到该卡片所有的变更情况。     
=====3.7联查借用记录===
系统支持针对单张卡片联查借用记录。操作步骤：
  - 打开资产卡片，选中需要查询借用情况的卡片，单击借用记录，即可查询到该卡片所有的借用情况。  
 

=====3.8其他说明===
1、初始卡片的相关说明请点击该链接[[初始化卡片|初始化卡片]]

2、资产卡片建卡**不建议一直沿用多数量管理**，因为多数量卡片在后续的业务处理中有很多不便，多数量卡片仅适用于批量购买的资产建在一张卡片上，审核后再对卡片进行拆分，详情可参考帖子:https://vip.kingdee.com/knowledge/713317953193732096?productLineId=1&isKnowledge=2&lang=zh-CN

===== 3.3变更单反审核 =====

资产处置是固定资产日常业务的一种，由于报废、出售、盘亏等原因，资产已经不存在了，需要对资产进行处置。本节主要实现以下功能：手工新增资产处置单、进行盘亏资产的处置、进行调出资产的处置。

====== 3操作说明 ======
===== 3.1手工新增处置单 =====

系统支持对资产卡片中的资产进行全部处置，也支持对资产卡片中的部分资产进行处置。全部处置后的资产卡片其处置情况为“完全处置”，不能再进行其他任何业务处理。部分处置后的资产卡片其资产数量变为处置后剩余的资产数量，未处置的资产还可以进行其他日常业务。处置资产的折旧根据会计政策来计算，折旧政策为“清理当期计提折旧”的，则处置资产的累计折旧会包括当期的折旧数据。折旧政策为“清理当期不提折旧”的，则处置资产的累计折旧不包括当期的折旧数据。这里的累计折旧由系统自动计算。操作步骤：

  -  单击** 保存** 按钮完成资产处置单的保存。 
途径二：
  - 单击**固定资产-->资产处置**，进入**资产处置单列表**界面；   
  - 单击**新增** 按钮，打开资产处置单新增界面；
  - 点击选单按钮，选择资产调出单或者盘盈盘亏单，确定之后，弹出满足资产组织和货主组织过滤条件的调出单或者盘亏单。
  - 选择要处置的单据，单击** 保存** 按钮完成资产处置单的保存。

===== 3.2审核处置单  =====
资产处置单进行提交、审核操作后，如果是完全处置，系统自动将已处置的资产卡片的处置情况标记为“完全处置”。完全处置的卡片将不能继续其他日常业务处理。

===== 3.3反审核处置单  =====
资产处置单进行反审核操作后，清除资产卡片的“完全处置”的处置情况标记，反审核后的资产处置单可以删除。

 ===== 3.4盘亏资产处置  =====
详见盘盈盘亏单 

===== 3.5调出资产处置   =====

详见资产调出单

## 【页面】资产批量变更单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E6%89%B9%E9%87%8F%E5%8F%98%E6%9B%B4%E5%8D%95

系统提供通过建立批量变更单同时对多个资产卡片的各种信息进行有记录的修改、变动。

====== 1 操作前提 ====== 
  - 资产卡片已审核

====== 2 字段说明 ======

=====2.1 基本 =====
|**字段**||**说明**|
|业务日期||变更业务发生的日期，必须在会计政策当前期间范围内。|
|资产组织||变更的资产所在资产组织|
|货主组织||变更的资产所属货主组织|
|变更原因||手工录入变更原因。|
=====2.2资产 =====
  - 选择需要变更的“卡片编码”，自动带出“资产名称”。 

=====2.3实物信息 =====
  - 实物信息支持变更“资产位置”、“规格型号”、“产地”、“供应商”、“制造商”、“备注”。选中变更内容进行变更，支持同次变更多个信息，且支持将某个卡片变更的信息批量变更应用到其他卡片上。

=====2.4财务信息 =====
  - 财务信息支持变更“资产原值”、“累计折旧”、“累计减值准备”、“预计残值”、“折旧方法”及“预计使用期间数”、“预计工作总量”、“已使用工作量”、“工作量单位”、“未税成本”、“进项税额”、“费用金额”、“费用税额”。选中变更内容进行变更，支持同时变更多个信息。 
 
=====2.5使用分配信息   =====
  - 使用分配信息的变更支持变更使用部门、使用人、分配比例。变更后的每个实物资产的使用分配比例相加必须为100%。 

=====2.6附属设备信息   =====

  - 附属设备信息的变更支持修改和删除原有附属设备信息，也支持新增新的附属设备信息。 

=====2.7凭证资料   =====
  - 凭证资料信息为自动读取和计算，不可手工修改。
  - 变更前显示发生变更前的数据，变更后显示发生变更的最新数据。
  - 凭证模板界面，用户可以选到凭证资料页签的字段生成凭证。

====== 3操作说明 ======
===== 3.1手工新增批量变更单 =====

操作步骤：
  - 单击**固定资产-->资产批量变更**，进入**资产变更单列表**界面；  
  -  单击**新增**按钮，打开资产批量变更单新增界面；
   - 输入需要变更的资产的资产组织和货主组织，在资产页签选择需要变更的资产卡片（在卡片编码字段手工录入要变更资产的卡片编码，或在卡片编码按F8调出资产卡片列表，通过过滤进行查找选择要变更资产的卡片。）。
  -   选择需要变更的信息进行变更，允许同时选中多个内容进行变更。
  -    单击**保存**按钮完成资产变更单的保存。

===== 3.2变更单审核 =====
资产批量变更单进行提交、审核操作后，系统自动并将变更内容同步更新至资产卡片对应的信息。 
===== 3.3变更单反审核 =====
资产批量变更单进行反审核操作后，系统自动将更新至资产卡片中的变更内容还原。反审核后的资产变更单可以进行删除。

## 【页面】资产状态
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E7%8A%B6%E6%80%81

本节提供资产状态功能，满足用户对资产的使用状态进行标识。是资产管理过程中必要的基础资料。
  * 操作前提：用户确定有多少种使用状态。

  * 字段说明：
  
|**字段**||**说明**|
|上级组||进行分类管理时，需要设置上级组|
|计提折旧||选中，则表示该资产状态的卡片参与折旧计算，未选中，则表示该资产状态的卡片不参与折旧计算|
 
  * 操作说明：资产状态审核后即可被使用，资产状态如果设置需要计提折旧，那么选了该资产状态的卡片将会参与计提折旧。资产状态如果不需要计提折旧，那么选了该资产状态的卡片将不会参与计提折旧。

## 【页面】资产申请单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E7%94%B3%E8%AF%B7%E5%8D%95

资产申请单是资产采购的源头单据。用于各业务部门或计划部门根据资产购置计划或资产使用需求等实际情况，向资产管理部门提出资产申请要求。
====== 1 操作前提 ====== 

  - 定义资产类别基础资料
  - 定义折旧政策基础资料   
  - 在会计政策中完成资产政策的定义
  - 在组织业务关系中定义资产组织与货主组织的业务委托关系
  - 定义资产位置基础资料

 ====== 2 字段说明 ======

|**字段**||**说明**|
|业务日期||进行资产申请的日期，默认为系统日期，可以修改。|
|需求组织||需要申请固定资产的组织。|
|需求部门||需要申请固定资产的部门。只能是需求组织属下的部门。|
|需求人||需要申请固定资产的员工。|
|资产名称||选择需要申请的资产，F8选择“允许资产”的物料。|
|资产说明||默认为资产名称，可以修改。作为固定资产用名称。|
|申请数量||手工录入需要申请的资产数量。|
====== 3操作说明 ======
新增申请单，操作步骤：
  - 单击固定资产-->资产申请单，进入资产申请单列表界面；
  - 单击** 新增** 按钮，打开资产申请单新增界面；
  - 在基本页签输入所要申请资产的需求组织、需求部门等信息；     
  - 在资产页签选择需要申请的资产，输入申请数量等信息；
  - 单击** 保存** 按钮完成资产申请单的保存。

审核申请单：在** 资产申请单列表**界面，选中申请单，单击提交-->审核 即完成审核操作。

反审核申请单：在** 资产申请单列表**界面，选中已审核申请单，单击反审核 即完成反审核操作。进行反审核操作后，资产申请单可以进行修改和删除。

## 【页面】资产盘点表
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E7%9B%98%E7%82%B9%E8%A1%A8

资产盘点表是通过盘点方案生成的，用来进行初盘数据和复盘数据录入。
====== 1 操作前提 ====== 
资产卡片已审核
====== 2 字段说明 ======
| **字段**       || **说明**                                                               |
| 初盘数量         || 默认为0，手工录入实际盘点数量。支持按账存批量填充初盘数量。                                       |
| 初盘变动位置       || 盘点方案勾选“盘点资产位置”则资产盘点表列示该列。默认为空，表示资产实际存放位置与账存位置一致。不一致时手工录入资产实际存放位置。    |
| 初盘变动使用部门     || 盘点方案勾选“盘点使用部门”则资产盘点表列示该列。默认为空，表示资产实际使用部门与账存使用部门一致。不一致时手工录入资产实际使用部门。  |
| 初盘变动使用人      || 盘点方案勾选“盘点使用人”则资产盘点表列示该列。默认为空，表示资产实际使用人与账存使用人一致。不一致时手工录入资产实际使用人。      |
| 复盘           || 勾选，表示选中记录需要进行复盘。资产盘点表审核前进行复盘确认。                                      |
====== 3操作说明 ======
===== 3.1生成资产盘点表 =====
操作步骤：单击固定资产-->盘点方案，进入盘点方案列表界面，单击生成盘点表按钮，系统自动按照盘点方案定义的盘点内容和范围生成资产盘点表。
===== 3.2审核资产盘点表 =====
资产盘点表进行提交、审核操作后，系统自动根据盘点结果生成盘盈盘亏单。 
===== 3.3反审核资产盘点表 =====
资产盘点表下游的盘盈盘亏单如果为进行提交操作，允许进行反审核，单击反审核即完成资产盘点表的反审核。反审核的资产盘点允许修改或删除。

## 【页面】资产租入
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E7%A7%9F%E5%85%A5

资产租入单是用来记录租入资产相关信息的单据，在租入单上可以记录租入资产的租赁合同相关信息（比如合同编号、合同名称、出租方、起租日、租赁结束日等信息），可以记录该项租赁的支付信息（发票类型、税率、租金总额、付款频率、付款期数等）、付款计划（系统自动生成，生成后可手工编辑）、其他费用信息，以及使用分配信息,系统通过维护好的资产租入单信息自动计算财务信息（即使用权资产、租赁负债、未确认融资费用）。本节主要实现以下功能：新增资产租入单、维护租入单的基本信息后系统自动产生付款计划、自动计算财务信息、租入单审核自动产生资产卡片。

====== 1 操作前提 ====== 

  - 定义资产类别基础资料，划分使用权资产的种类
  - 定义折旧政策基础资料   
  - 在会计政策中完成资产政策的定义
  - 定义资产位置基础资料

 ====== 2 字段说明 ======

=====2.1 基本信息 =====
| **字段**       || **说明**                                                                      |
| 业务日期         || 维护租入单的日期。                                                                   |
| 租赁负债确认日期     || 确认该项租赁负债的日期，比如2021年之前的租入合同，租赁负债确认日期为2021年1月1日，2021年之后的租入合同，租赁负债确认日期为租赁开始日。  |
| 资产组织         || 资产的管理组织，只能输入组织职能为资产职能的组织。                                                   |
| 货主组织         || 资产的所有权的归属组织，货主组织必须为业务组织。                                                    |
| 合同号          || 租入资产对应的合同信息                                                                 |
| 合同名称         || 租入资产对应的合同名称                                                                 |
| 出租方          || 出租固定资产的供应商                                                                  |
| 免租开始日期       || 如果存在免租，需要维护免租开始及结束的日期                                                       |
| 免租结束日期       || 如果存在免租，需要维护免租开始及结束的日期                                                       |
| 免租期（月）       || 系统自动根据免租开始日期与结束日期进行计算，可手工编辑                                                 |
| 起租日期         || 正式产生租金的日期                                                                   |
| 租赁结束日期       || 合同约定的租赁结束日期                                                                 |
| 租赁期（月）       || 租赁结束日期-租赁负债确认日期（这个租赁期是指按照新准则执行后还剩下的租赁期，即租赁负债确认日距离租赁结束日期的月数）                 |
| 资产类别         || 实物资产所属的资产类别。                                                                |
| 资产名称         || 实物资产的名称。                                                                    |
| 存放位置         || 租入资产存放的位置                                                                   |
| 计量单位         || 实物资产的计量单位。                                                                  |
| 资产数量         || 本次租赁资产的数量                                                                   |
| 关联卡片编码       || 租入单审核后会产生资产卡片，卡片保存后反写租入单的关联卡片编码                                             |
| 备注           || 按需维护想要备注的内容即可                                                               |

=====2.2支付信息 =====
| **字段**          || **说明**                               |
| 发票类型            || 该项租赁合同约定的出租方开给租入方的发票类型               |
| 税率              || 该项租赁合同约定的出租方开给租入方的发票对应的税率            |
| 是否可抵扣           || 根据发票类型，系统自动识别是否可抵扣，也可手工编辑            |
| 原币别             || 租入合同约定的支付币别                          |
| 租金总额（含税）        || 针对该项租赁所有已经支付及将要支付的含税租金               |
| 租金总额（不含税）       || =租金总额（含税）/（1+税率/100）                 |
| 免租金额            || 合同约定的免租金额（由于是免租，就不会存在有税）             |
| 免租金额（含税）        || =免租金额*（1+税率/100）                     |
| 付款频率单位          || 可选择月付、季付、半年付、年付                      |
| 付款频率            || 与付款频率相匹配（比如5个月付，付款频率单位选择月付，付款频率维护5）  |
| 总付款期数           || 该项租赁合同总共的付款期数                        |
| 未付款期数           || 维护租赁负债确认日后需要付款的期数                    |
| 预付租金（含税）        || 填写预付的属于租赁负债确认日之后的租金                  |
| 初始已付租金（含税）      || 填写已付的属于租赁负债确认日之前的租金                  |
| 租赁负债（租赁付款额）     || 系统自动计算（租赁负债确认日之后将要支付的租金总额）           |

=====2.3其他费用 =====
| **字段**       || **说明**                                                   |
| 初始直接费用       || 与该项租入资产相关的发生的初始直接费用，比如运输费、保险费等。                          |
| 租赁激励         || 出租人为达成租赁向承租人提供的优惠。                                       |
| 预计复原成本       || 承租人为拆卸及移除租赁资产、复原租赁资产所在场地或将租赁资产恢复至租赁条款约定状态预计将发生的成本        |
| 预计担保余值       || 租入方保证在租赁结束时租赁资产的价值至少为某指定金额。                              |
| 预计行权费用       || 购买选择权的行权价格，前提是承租人合理确定将行使该选择权。                            |
| 预计终止费用       || 行使终止租赁选择权需支付的款项，前提是租赁期反映出承租人将行使终止租赁选择权。                  |
| 租赁结束费用现值     || =（预计复原成本+预计担保余值+预计行权费用+预计终止费用）/（1+日折现率）∧（租赁结束日-租赁负债确认日）  |


=====2.4财务信息 =====
| **字段**            || **名称**                                                                                                                                                                                                                                                |
| 本位币               || 系统自动获取                                                                                                                                                                                                                                                |
| 汇率类型              || 系统自动获取                                                                                                                                                                                                                                                |
| 汇率                || 系统根据支付信息的原币别与财务信息本位币及汇率类型自动获取                                                                                                                                                                                                                         |
| 使用权资产             || 系统自动计算,历史合同，税可抵扣时，=租赁负债+预付租金(含税)/（1+税率/100）+租赁结束费用现值\\                        税不可抵扣时，= 租赁负债+预付租金（含税）+租赁结束费用现值\\ 非历史合同，税可抵扣时，=租赁负债+预付租金(含税)/（1+税率/100）+初始直接费用+租赁结束费用现值-租赁激励，\\                            税不可抵扣时，= 租赁负债+预付租金（含税）+初始直接费用+租赁结束费用现值-租赁激励  |
| 使用权资产（本位币）        || 系统自动计算                                                                                                                                                                                                                                                |
| 租赁负债              || 系统自动计算,=∑ 付款计划的每期折现值                                                                                                                                                                                                                                  |
| 租赁负债（未确认融资费用）     || 租赁负债（租赁付款额）-租赁负债                                                                                                                                                                                                                                      |
=====2.5付款计划 =====
| **字段**        || **名称**                                                       |
| 首次付款日期        || 租赁负债确认日后第一次付款的日期                                             |
| 年折现率          || 可以获取租赁内含利息的，应当采用租赁内含利率作为折现率；无法确定租赁内含利率的，应当采用承租人增量借款利率作为折现率。  |
| 日折现率          || =年折现率/365                                                    |
| 付款期次          || 付款的期次                                                        |
| 计划付款日期        || 租赁负债确认日后将要支付租金的日期                                            |
| 付款金额（含税）      || 含税的计划付款金额                                                    |
| 税率            || 携带支付信息的税率                                                    |
| 税额            || =付款金额（含税）/（1+税率/100）                                         |
| 付款金额（不含税）     || =付款金额（含税）-税额                                                 |
| 付款币别          || 携带支付信息的原币别                                                   |
| 本付款期利息        || =期初本金*（1+日折现率）∧(本期折现天数-上期折现天数)-期初本金,取计算的值与期初未确认融资费较小者        |
| 折现天数          || =计划付款日期-租赁负债确认日期                                             |
| 折现系数          || =（1+日折现率）∧折现天数                                               |
| 现值            || 税可抵扣时，=付款金额（不含税）/折现系数，\\ 税不可抵扣时，=付款金额（含税）/折现系数               |

=====2.6使用分配 =====
| **字段**      || **名称**                         |
| 使用部门        || 资产的使用部门。                       |
| 使用人         || 资产的使用人。                        |
| 分配比例（%）     || 资产使用部门在所有使用部门所占比例，是折旧费用分配的依据。  |
| 费用项目        || 资产折旧费用对应的项目。                   |
=====2.6租入单产生资产卡片 =====
资产租入单审核自动产生资产卡片，产生的资产卡片字段携带关系如下：
| **资产卡片字段**     || **租入单字段**        |

| **字段**     || **说明  **                      |

## 【页面】资产调入
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E8%B0%83%E5%85%A5

资产调入主要完成资产从其他资产组织或货主组织调入到当期资产组织或货主组织。

====== 1 操作前提 ====== 
 调入的资产必须先进行调出。
====== 2 字段说明 ======
资产调入单是由资产调出单自动生成，调入单的字段不能修改。对应的财务数据依据不同的会计政策对应携带。
====== 3操作说明 ======
===== 3.1调入单生成 =====
资产调入单不支持手工新增，资产调出单审核即自动生成资产调入单。 
===== 3.2审核调入单 =====
可以直接在资产调入单单据界面执行提交、审核操作，也可以在**资产调入单列表**界面，选中调入单，单击**提交-->审核**执行审核操作。资产调入单审核会自动对关联的资产调出单进行确认。 
===== 3.3反审核调入单 =====
在资产调入单单据界面可以直接执行反审核操作，也可以在**资产调入单列表**界面，选中已审核调入单，单击**反审核**执行反审核操作。进行反审核操作后，上游的资产调出单才可以进行执行反审核操作。资产调入单不提供删除功能。上游的资产调出单反审核成功即自动删除下游的资产调入单。
===== 3.4调入资产建卡管理 =====
  * 操作前提：资产调入单已经审核。 
  * 操作步骤：
  - 单击**固定资产-->资产调入**，进入资产调入单列表界面；  
  - 单击**下推**按钮，打开选择单据界面，调入单只支持下推资产卡片；
  - 在选择单据界面单击**确定**弹出资产卡片编辑界面；   
  - 在资产卡片界面补充完相关信息，单击**保存**按钮完成资产卡片的保存。即完成调入资产的建卡管理。       
  * 参数控制：管理员登录系统，公共设置-参数设置-固定资产：资产调拨生成的卡片，是否允许沿用原卡片编码和资产编码。勾选此参数，调入该组织下的卡片，将沿用原有的卡片编码和资产编码。

## 【页面】资产调出单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E8%B5%84%E4%BA%A7%E8%B0%83%E5%87%BA%E5%8D%95

资产调拨可以是资产从一个资产组织调出，调入到另外一个资产组织，也可以是资产从一个货主组织调出，调入到另外一个货主组织，主要是满足集团内组织间资产调拨，减少资产的重复采购。资产从一个资产组织调出，调入到另外一个资产组织，货主组织未发生变动，则只需要更新资产卡片的资产组织。资产从一个货主组织调出，调入到另外一个货主组织，调入资产组织对调入单进行确认后，调出资产组织需要对调出资产进行处置，调入资产组织需要对调入资产建卡管理。

====== 1 操作前提 ====== 
  - 资产卡片已审核
  - 启用多组织管理

====== 2 主要字段说明 ======
=====2.1 基本 =====
|**字段**||**说明**|
|调出资产组织||调出资产对应的资产组织，支持F8从组织机构基础资料中进行选择。|
|调出货主组织||调出资产对应的货主组织，支持F8从组织机构基础资料中进行选择，只能选择与调出资产组织建立组织业务关系的货主组织。|
|调出日期||调出资产的日期。默认为系统当前日期，可以修改。|
|调入资产组织||调入资产对应的资产组织，支持F8从组织机构基础资料中进行选择。|
|调入货主组织||调入资产对应的货主组织，F8从组织机构基础资料中进行选择，只能选择到与调入资产组织建立组织业务关系的货主组织。|
|调出原因||资产调出的原因。|

=====2.2资产 =====
在这个页签中选择调出资产所在卡片编码。目前只支持针对卡片所有资产的调出，尚不支持卡片中部分资产的调出。可以同时调出多张卡片的资产。 

=====2.3财务 =====
这个页签显示的是调出资产的财务信息。 

=====2.4附属设备 =====

这个页签显示的是调出资产的附属设备信息。 

=====2.5实物 =====
这个页签显示的是卡片中所调出资产的实物信息。 
 ====== 3操作说明 ======
===== 3.1新增调出单 =====
操作步骤：
  - 单击**固定资产-->资产调出**，进入**资产调出单列表**界面；   
  - 单击**新增**按钮，打开资产调出单新增界面；
  - 输入所要调出资产的资产组织、货主组织，调出资产被调入到的资产组织、货主组织等信息；   
  - 选择需要调出的资产卡片（在卡片编码字段手工录入要调出资产的卡片编码，或在卡片编码按F8调出资产卡片列表，通过过滤进行查找选择所要调出资产的卡片）；
  - 单击**保存**按钮完成资产调出单的保存。
===== 3.2审核调出单 =====
资产调出单保存后，可以直接在单据界面执行提交、审核操作，也可以在**资产调出单列表**界面，选中调出单，单击**提交-->审核**即完成审核操作。资产调出单审核自动生成资产调入单。  
===== 3.3反审核调出单 =====
在单据界面可以直接执行反审核操作，也可以在**资产调出单列表**界面，选中已审核调出单，单击**反审核**即完成反审核操作。进行反审核操作后，资产调出单可以进行删除。对资产调出单进行反审核的前提条件，下游的资产调入单未执行审核操作。
===== 3.4处置调出单 =====

操作前提：下游的资产调入单已经审核。

操作步骤：  
单击**固定资产-->资产调出**，进入**资产调出单列表**界面，具体步骤如下：   
单击**下推**按钮，打开选择单据界面，调出单只支持下推处置单；
在选择单据界面单击**确定**弹出资产处置单；   
在资产处置单界面补充完相关信息，单击**保存**按钮完成资产处置单的保存。即完成调出资产的处置。

参数控制：固定资产—参数设置—固定资产参数设置：资产调拨流程自动化。调出/调入任意组织勾选该参数，调拨会自动进行调入确认、调出处置、调入建卡。
