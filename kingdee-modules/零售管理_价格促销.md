## 【页面】价格促销
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E4%BB%B7%E6%A0%BC%E4%BF%83%E9%94%80

====== 价格促销 ======
====== 1 价格促销整体应用 ======
===== 1.1  价格促销概述 =====
在连锁零售业务中，企业在门店会进行商品促销，以此吸引消费者，增加门店客流量。通过价格与促销管理，为连锁零售企业提供灵活的商品价格管理机制和丰富的促销管理政策，满足零售企业实际业务发展需求，帮助企业适应不同业务场景的价格与促销管理需求。
促销政策的执行结果分析，满足零售企业对商品促销情况的数据收集与结果分析，指导企业指定更精准的销售政策。
===== 1.2 价格促销特性 =====
  *    支持零售销售过程促销管理：含促销政策制定、POS前端执行、以及促销结案各环节紧密集成；
  *    促销管理模式平台化，支持多种个性化模式设定，灵活制定促销方案、政策，满足不同促销业务场景；
  *    促销方案准确执行，按日期、时间、门店、商品、品牌、商品分组等各类条件在POS收银端智能匹配；
  *    可满足第三方集成使用，如，自建线上商城集成，会员促销、会员促销积分管理等；
  *    促销策略分级控制，实现总部管控与门店灵活设置相结合满足各种促销管理的要求。

## 【页面】商品价格调整单
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%95%86%E5%93%81%E4%BB%B7%E6%A0%BC%E8%B0%83%E6%95%B4%E5%8D%95

======商品价格调整单 ======

===== 功能概述 =====

  * 零售商品价格需要进行永久调价，调价对象包括：零售价、会员价、以及门店供货价；
  * 零售商品价格调整可以定义具体的调价范围：按照组织过滤对应的门店；
  * 商品价格调整可以反写到商品资料的条形码页签的价格中
  * 商品价格调整单支持，选择商品同时带出多个条形码的价格记录，同时对一个商品编码，多个条形码进行调价。

**应用场景**
  * 零售门店需要永久调整商品零售价、会员价或供货价；
  * 指定某一个日期开始进行价格调整
**操作路径**

零售管理—>价格促销—>商品价格调整单

**字段说明**

| 商品名称   | 取商品-商品名称                                    |

| 原供货价   | 取商品-条形码页签-门店供货价字段                           |

## 【页面】大数据关联商品推荐
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E5%A4%A7%E6%95%B0%E6%8D%AE%E5%85%B3%E8%81%94%E5%95%86%E5%93%81%E6%8E%A8%E8%8D%90

## 【页面】折扣码类型
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%8A%98%E6%89%A3%E7%A0%81%E7%B1%BB%E5%9E%8B

====== 功能概述 ======


  - 折扣码可定义折扣的商品范围。
  - 折扣码扫完即作废，不能二次使用。
  - 折扣码可以设置有效期。 
  - 使用了折扣码不参与手工折扣及促销。

  * 操作路径：零售管理—>价格促销—>折扣码
  * 应用场景：PC POS —>开单收银

====== 应用流程 ======


**后台cloud定义折扣码基础资料，定义折扣值和适用的商品**
  - 折扣码按商品分组或商品定义范围，支持多选
  - 同一商品支持设置多个折扣码，全局通用，不区分门店
  - 定义折扣码的编码规则，举例：ZKM+5位流水，每个折扣码系统内唯一

**零售单商品明细增加折扣码字段，记录商品行的折扣码对应的折扣值**
  - 开单收银支持先扫商品也支持先扫折扣码，如果扫了两次折扣码，则按最后一次扫的折扣码计算最终价格；
  - 折扣码扫完开单结算完成后即作废，不能二次使用；
  - 扫折扣码时需判断折扣码的有效期是否已过期，过期后扫码提示折扣码无效，在有效期内的折扣码才可正常使用；

**商品销售时扫了折扣码又点了单品折扣、整单折扣、促销、会员价/会员折扣：**
  - 使用了折扣码不参与手工折扣及促销

## 【页面】综合促销平台
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E7%BB%BC%E5%90%88%E4%BF%83%E9%94%80%E5%B9%B3%E5%8F%B0

===== 总体流程图 =====
[图:平台总体流程.png]
===== 功能概述 =====
  *    支持多样促销类型；包括买送、买减、买换、整单促销、打折赠券返还优惠、商品折扣、会员优惠促销、单品促销、组合促销、赠品促销、时点促销、限量促销、数量促销等；
  *    可以定义促销方案，根据促销方案进行促销平台定义，以便后续按照促销方案进行销售分析；
  *    促销政策执行可总部统一定义管理，也可以门店独立维护；通过执行门店可进行促销组织门店范围定义；
  *    促销政策可提前定义，执行计划任务根据开始时间自动执行生效。生效后，POS进行数据更新。前台调用新的促销政策；
  *    指定特价商品，支持数量限购；
  *    促销政策中的货品清单，支持按照品牌，商品分组定义，适用于某些品牌，某类商品进行折扣、或者买赠；
  *    促销政策终止后，多端POS系统中需要进行数据更新，才能终止前台的继续执行；
  *    对于任选的促销政策，系统支持按照组合进行定义，以此满足A+B,或者2A+B的促销政策；
  *    满足条件后的：成倍累加、成倍不累加条件适用于是否进行成倍促销，如：选上成倍累加、买二赠一，如果一单中顾客买4，那则赠送二，如果勾选成倍不累加，则一单中顾客买4，也只赠送1。

===== 应用场景 =====
  *    可以分时段、分阶段、分日期、分星期指定促销政策；
  *    可以分会员促销、非会员促销；
  *    促销可提前终止。
