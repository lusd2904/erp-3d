====== 1 产品成本核算概述 ======

===== 1.1 产品成本核算概述 =====

产品成本核算是指企业产品成本的计量，用于企业的费用归集分配、在产完工分配、核算报表查询及相关资料的维护。

产品成本核算总体流程图

===== 1.3 系统特性 =====

产品成本核算系统以支持多工厂、多组织、多会计政策灵活准确地核算产品本为目标，通过与供应链、生产制造、应收应付、资产管理、总帐等系统的无缝集成，为企业成本管理提供精确的成本分析数据，其主要功能包括：

费用分配 

产品成本核算 

报表分析 

账务处理 

期末处理 


支持成本核算维度：

支持多工厂多组织成本核算 

支持一个辅助生产部门提供多个作业活动

支持逐步综合结转成本法、逐步分项结转法、订单法、分类法、品种法、分步法核算。

自制产品成本核算

简单生产是指小型制造企业或加工过程简单的车间，对结构简单、BOM变动不频繁的产品进行简化生产流程的加工生产。产品成本核算以产品为成本核算对象，按产品计算成本。

===== 2.4 数据库优化 =====

SqlServer创建维护计划优化数据库对提升数据库性能有很大帮助，下面介绍怎样创建一个常用的维护计划用于优化数据库。

1、启动【sql server Management Studio】，在【对象资源管理器】窗口里选择【管理】——【维护计划】选项。如果SQL Server 代理没有启用请先启用。 

2、右击【维护计划】，在弹出的快捷菜单里选择【维护计划向导】选项弹出如图所示的【维护计划向导】对话框，单击【下一步】按钮。

3、弹出【选择维护任务】对话框，在该对话框里可以选择多种维护任务:检查数据库完整性、收缩数据库、重新生成或组织索引、更新统计信息、清除历史记录、执行sqlServer代理作业、备份数据库等。

例如：选择【重新组织索引】、【重新生成索引】、【更新统计信息】、【收缩数据库】，其他维护任务的设置都大同小异。 
   
4、单击【下一步】按钮，弹出【选择维护任务顺序】对话框，如果有多个维护任务，在此可以通过【上移】和【下移】两个按钮来设置维护任务的顺序，设置完毕后单击【下一步】按钮。

例如顺序可设置为【重新组织索引】->【重新生成索引】->【更新统计信息】->【收缩数据库】。
   
5、弹出【定义任务】对话框，在【数据库】下拉列表框里可以选择要优化的数据库名；设置完毕后单击【下一步】按钮。

6、弹出【选择计划属性】对话框，单击【更改】按钮。可以根据实际情况来设置计划的执行情况，本例建议每周执行一次，执行时间放在空闲时间，例如周日凌晨。

7、弹出【完成向导】对话框，单击【完成】按钮完成维护计划创建操作。创建好维护计划之后就会按照计划属性中的设置执行，强烈建议立即执行一次，可以右键该维护计划->执行。

8、请查看日志确保执行成功。


===== 2.5 零成本管理方案 =====

企业零成本管理的业务主要有：费用类物料、资产类物料、赠品、不良品或废品、配套件

一、费用类物料

费用类物料一般是指企业采购的办公用品、包装材料，采购回来即全部费用化，最多是进行库存数量管理、不统计其成本。金蝶云中规划此类物料为“费用”属性（见物料基础资料中的物料属性），存货核算不纳入此类物料进行成本核算。

二、资产类物料

资产类物料是指企业采购的固定资产，在资产化之前存放在仓库中，仅进行库存数量管理，不核算其成本。金蝶云中规划此类物料为“资产”属性（见物料基础资料中的物料属性），存货核算不纳入此类物料进行成本核算。

三、不良品或废品

不良品或废品是指企业生产过程中的产生的不良退料、废品退料或生产的不良品或废品，以及库存管理过程中报废的料品，这些都有可能是零成本处理。

这类应用在金蝶云通过库存状态类型进行归类识别，即库存状态类型为不良的，系统定义为不良品；库存状态类型为废品的，系统定义为废品。库存状态类型是预设数据，不允许新增，库存状态可以自定义。成本管理通过库存状态的类型进行不良、废品识别，零成本管理应用方案如下：

不良&废品需单独设置仓库进行存放管理，不良废品仓库设置类型为“不良”或“废品”的库存状态，存货核算时需将正常品仓与不良废品仓设置不同的核算范围，或者将物料基础资料中的物料维度”仓库“勾选影响成本，这样存货核算时会将相同物料编码的不同仓库数据分为不同核算维度分开核算，以达到不良品或废品零成本入库零成本出库的目的，同时在成本管理系统参数中勾选“赠品、不良或废品零成本允许结账”。

注意：因在存货核算系统启用后，核算范围的划分依据不允许修改，请实施前务必调研客户的此类需求，如果不确定可以按“货主+仓库”进行划分。

四、赠品

赠品是指供应商赠送或赠送给客户的原物料或产品。采购过程的赠品一般是零成本入库或与普通料品均摊成本，销售过程的赠品收入为零，但成本不一定为零，因为销售的赠品有可能是企业自产的料品，也可能是之前供应商赠送的料品。

企业如果不需对赠品进行单独跟踪管理，可以视普通料品处理，即不管来源，核算出的成本是多少就结转多少成本；若需单独跟踪管理，则需设置仓库单独管理分仓核算，以达到零成本入库零成本出库的目的。

金蝶云对赠品的成本处理方式：

通过单据上的赠品标识进行识别控制，目前只有采购入库单（退料单）、销售出库单上有“赠品"标识，成本核算允许赠品零成本入库零成本出库，但在业务处理上存在一些局限，比如调拨、其他出库、生产领料单据都没有赠品标识。

经过现有客户应用的探索，通过不良废品的解决方案可以完美处理赠品零成本管理，解决方案同不良或废品，库存状态因可以自定义，可以命名为赠品，类型选择“不良”或“废品”即可

五、配套件

配套件一般是只能与主件进行配套使用或买卖的低价值零部件，成本可以忽略。

这类物料因与正常业务混在一起，成本核算难以区分，目前只能进行粗放管理，因其有特殊性，存货核算又不能排除不进行核算，只能顺其自然，允许出入库成本为0，合法检查报告给予提醒，由用户识别其成本的合理性，期末结账时需BOS中勾选成本管理系统参数“零成本单据允许结账”进行结账处理。

此处理方式为粗放的控制模式，系统没法控制成本的正确性，需用户进行识别。


===== 2.6 负库存原因查找 =====

一、系统在关账或者结账的时候提示有负库存”，下面提供两种查找负库存的方法。

场景1：关账时提示“更新即时库存时，出现负库存，即时库存更新不成功”

请参考【使用心得】关账与物料收发报表不一致的问题 http://club.kisdee.com/forum.php?mod=viewthread&tid=691979

场景2：关账成功且未提示有负库存，结账时“负库存检查，不通过” 

查找方法：使用存货核算下的【存货收发存明细表】，过滤条件-快捷页签-显示维度选择“按库存维度显示”，显示隐藏列页签勾选全部字段，确认后在报表工具栏点击“后一”查看其他维度数据。

二、【物料收发存明细表】没有负库存，为什么在【存货收发存明细表】上会显示有负库存？

答：【物料收发存明细表】属于供应链领域开发的报表，主要是从物料的角度出发，如VMI、待检状态、服务类、资产类物料在【物料收发存明细表】包含，但在【存货收发存明细表】不包含。因此，负库存原因的查找请使用【成本管理】【存货核算】下的【存货收发存明细表】。 

三、已知的出现负库存的原因

3.1  物料的出库日期大于入库日期，例如A物料8月期初结存数量为50，8月10日销售出库数量为100，8月11日生产入库数量为200，8月期末结存数量为150。但是在8月10日销售出库时已产生-50的负库存。

3.2  存在组织间交易，未创建或者未成功创建组织间结算清单，未成功创建包含只生成了调入单未生成调出单或者调入调出单重复生成。

3.3  出库核算或者成本计算的合法性检查报告中检查结果有“错误”、“不通过“、”异常”提示。

3.4  期初出现负库存，原因是以前期间有勾选成本管理系统参数“存在负库存时允许结账”。

3.5  从后台修改或者其他原因导致物料的仓库维度未启用。

3.6  生产领用VMI物料，未批量创建销耗汇总。


===== 2.7 存货对账差异查找 =====

一、前期准备

1.1  如果有组织间业务，核算前要成功创建组织间结算清单。

1.2  出库核算或者成本计算的合法性检查报告没有错误或者不通过。

1.3  存货单据已全部成功生成凭证。

二、对账

2.1  在【财务会计】-【智能会计平台】-【对账管理】-【对账方案】，设置存货对账方案.

2.2  在【财务会计】-【智能会计平台】-【对账管理】-【对账】，选择对应的账簿、对账方案、期间并勾选包含未过账凭证。

2.3  从对账结果可以看到期初余额、本期增加、本期减少、期末余额是否有差异。

三、差异原因查找

3.1  期初余额有差异，如果属于启用第一期，请对比存货核算的【初始核算数据录入】与总账的【科目初始数据录入】，否则属于以前期间存货对账不平衡，需要从以前期间开始存货对账。

3.2  本期增加和本期减少有差异，选中有差异的科目，在对账结果中点击联查明细账（如下图）并导出文件至EXCEL。

3.3  在存货核算【核算单据查询】中选择会计科目应对的存货类别过滤，显示隐藏列将凭证字号勾选查询并导出文件至EXCEL。

3.4  使用EXCEL的透视表功能按单据编号或者凭证字号进行汇总并对比，找出产生差异数据的单据编号。

四、已知差异原因

4.1  凭证未成功生成或者凭证生成重复。

4.2  凭证模板设置错误。

4.3  组织间结算取价来源为成本价且两个业务组织间存在业务数据嵌套。


===== 2.8 常见问题解答 =====

1.有时进行出库成本核算或者成本计算的时候进度条一直在某个位置不动。

建议方案：首先打开合法性检查报告，看合法性检查报告的开始时间和结束时间，开始时间是否正确，结束时间是否大于开始时间，如果是说明已经核算完成。如果结束时间为空,请参考sql server数据库优化进行处理。

2.存在零成本物料可以生成凭证吗？

建议方案：请检查零成本的原因，如果是赠品、废品、不良品单据成本为零，在成本管理系统参数勾选“赠品、不良品、废品单据成本为零时允许结账”，可以生成凭证。

3.核算单据查询不到单据，核算单据查询的价格没有变化。

建议方案：无论做出库核算还是成本计算，计算完首先看合法性检查报告是不是有不通过项，如果不通过会存在看不到某些单据、也查询不到对应的价格。

4.进行产品成本核算，成本计算异常提示截断字符串或二进制数据。

原因：这种原因多数是因为订单号过长导致（如销售订单号、生产订单号等等）。

5.存货核算生产领料单不能核算出单价。

建议方案：成本计算是否成功，如果成功，请勾选参数“出库成本核算不更新已修改成本的核算单据成本”重算下。

6.（存货核算）核算单据查询 增加供应商字段。

建议方案：二次开发。报表临时表中有fbillfromid和fbillentryid。通过这个去关联单据取数。

7.入库核算为什么选不到组织？

原因：是否启用存货核算，是否结束初始化！

8.什么情况下会产生出库成本调整单？

说明：①.成本管理系统参数“采购入库调整单自动生成出库成本调整单”，选择按上期出库/结存或全部生成两种情况下生成出库成本调整单；

②.手工新增出库成本调整单；

③.异常余额汇总表出单生成调整期末结存的出库成本调整单；

④.出库单据生成凭证后重新成本计算，重算后成本与原出库单成本不一致时有可能生成针对原出库单的成本调整单（这个是有成本计算参数来决定是否要生成，默认是不生成的，差异结转到当期期末余额）。

9. 存货核算期末结账时出现当前期间还未关账，或者关账时间小于当前期间最后一天或者负库存。

建议方案：正确操作流程是先关账，然后成本计算，看合法性检查报告的提示，提示负库存，要先查看负 库存形成的原因。直到成本计算合法性检查报告通过，最后才是结账。

10.成本核算不成功，违反约束‘PK_HS_EXPENSEC’。

建议方案：检测索引是否被损坏，然后重新核算。

11.合法性检查警告，存在“成本中心[设备研发部]共耗材料没有费用分配标准设置！

建议方案：在BOS IDE 中其他出库单表体有个“参加费用分配”字段，把可见性设置为“可见”， 然后做单的时候去掉勾选。备注：（影响：做为共耗材料分配将在成本项目‘间接材料’下面展示具体的物料，不做为共耗材料将在成本项目‘费用’下面展示没有具体的物料信息）。

12.成本计算异常抛出关于ORA-00600的错误。

 参考方案：多数是因为恢复的时候数据库被损坏，网上分析是ora的bug，建议打oracle的最新补丁recover database一下。

13.存货核算中-存货收发汇总表和库存管理中-物料收发汇总表，期末库存数量一样，结存金额不一样。请问是怎么回事，月末核对数据时，应该以那份为准？

参考方案：请以存货的为准，供应链的物料收发存是根据物料的参考价计算的，成本管理的存货收发存是以物料财务角度核算出来的单价计算的。

14.成本计算出现异常 网络问题或者请求 URL失败

参考方案：① 打开iis管理 查看是否存在K3CloudApp这个虚拟目录如果不存在的话，建立一个，指向和K3Cloud的虚拟目录，应用程序池要单据建立一个，和K3Cloud一样的配置即可。

② 检查下安装完Website的bin目录下的Kingdee.BOS.ScheduleService.exe.config里面的这一行<add key="ComputeSiteUrl" value="http://localhost/K3CloudApp/"/> 需要确认这个value的指向是可访问的，直接拷贝出来放到ie中看能不能打开界面，如果修改了端口号的话，此处一定需要修改。

③ 检查下WebSite下的app_data下的common.config里面的appsettings里面是否存在这个<add key="ComputeSiteUrl" value="http://localhost/K3CloudApp/"/>如果没有加上。

④ 最后重启iis。

===== 3.1 成本核算对象 =====

**成本核算对象**

成本核算对象也叫成本对象，是指计算产品成本过程中，确定归集与分配生产费用的承担对象，如产品品种、生产订单、生产工序等。生产简单的单步骤、大批大量生产企业，较适宜以产品品种作为核算对象；对小批量生产或按订单组织生产的企业，一般以生产订单作为核算对象。

产品成本核算对简单生产的产品按产品品种作为核算对象；对于普通生产的产品按生产订单作为核算对象。

备注：不需创建成本对象基础资料！ 


===== 3.2 作业活动 =====

**作业活动**

作业活动是指企业成本中心间相互协作而提供的劳务或服务，是相对实体产品而言的虚拟产品，因此作业活动作为成本中心输出的成果，可以用来作为费用承担的主体，最后也可以根据最终受益者将费用通过作业活动及成本动因准确的转移到产品成本中。

成本管理秉承作业成本管理的思想：“成本核算对象消耗作业，作业消耗资源”。


===== 3.3 间接费用分配 =====

**间接费用分配**

企业在日常经营过程中发生的，不能确定具体受益对象的费用，为间接费用，也叫共耗费用。成本会计在进行成本计算时需要按照一定的分配标准计算分配比率将共耗费用分配到具体对象上去。

产品成本核算系统的费用分配会根据规则识别归集的费用是直接费用还是间接费用，若是直接费用，费用分配时直接将费用写入费用分配结果表，若是间接费用，费用分配需按设置的费用分配标准统计分配权重计算分配率，再按费用分配率分配至具体的受益对象上，最后将结果写入费用分配结果表。

===== 3.4 成本计算 =====

**成本核算方法**

成本核算方法分为品种法、分批（订单）法、分类法、分步法。

品种法：以产品品种作为成本核算对象的一种成本核算方法。适用于大批大量、单步骤生产的企业，如发电、采掘业等。 

分批法：以产品批别作为成本核算对象的一种成本计算方法。适用于单件、小批生产企业、按照客户定单组织生产的企业——因而也称“订单法”。 

分类法：以“产品组”作为成本核算对象、归集费用、核算成本的一种方法。适用于生产过程多产出或产品等级多的企业，如：服装、化工、酿酒等企业。
 
分步法：以产品生产阶段、步骤作为成本核算对象，核算成本的一种方法。适用于批量多步骤多阶段生产的企业，管理上要求按照生产阶段、步骤、车间计算成本，如冶金、纺织、造纸企业、电子制造等企业。 

**成本结转方式**

逐步综合结转法：是指各生产步骤耗用上一步骤的半成品成本，以其综合成本(不分成本项目)记入下一步骤成本计算单中的“直接材料”项目，或是设立“半成品”项目。成本计算单按成本项目显示为综合结转结果。如图：

[图:逐步综合结转.png]

逐步分项结转法：是指将各生产步骤所耗上一步骤的半成品成本，按其费用项目分别记入各生产步骤产品成本计算单中相同的费用项目内，以计算按费用项目反映的各步骤产品成本的方法。

当勾选会计政策-成本政策参数“存货核算按费用项目明细核算”时，产品成本按费用项目分项核算及结转，成本计算单按费用项目显示为分项结转结果；不勾选此参数，产品成本按费用项目综合结转。

**主联副产品成本核算**

主联副产品是指用相同原料，经过同一个生产过程，生产出两种或两种以上的不同性质和用途的产品。主/联产品在经济上有不同性质和用途，属于企业生产的主要目的；副产品是企业生产过程中产生的附带产品，价值低、不是企业生产活动的主要目标。

工程数据BOM（物料清单）支持主联副产品多产出结构，支持按主联副产品统计投入产出，成本管理基于这种结构创建主联副产品组，成本分配权重可以来源生产订单上的成本权重也可以手工指定，但副产品只能按定额成本核算。成本分配时扣减副产品的成本后按主、联产品的投入产量及成本权重加权计算分配率分摊成本。

注意：主联副产品成本分配在成本计算之前进行，并统计主联副产品的完工与期末在产成本

**等级品成本核算**

等级品指使用相同原材料，在同一生产过程中生产相同品种但在质量或规格上有差别的产品。等级品同联产品、副产品不同。虽然它们都是使用相同原材料在同一生产过程中生产的，但联产品、副产品生产出来的是不同品种的产品，而等级品则为同一品种的产品，只在质量或规格上有所差别。

成本管理可以按库存状态划分合格品、不良品及废品设置等级品，也可以按辅助属性值组合区分设置等级品，如颜色、尺寸。等级品的设置由划分依据为等级的产品组来实现，并可以按等级设置成本分配权重，成本计算时，将总完工成本按各等级品完工产量及分配权重加权计算的分配率进行分摊。

备注：等级品成本分配是在成本计算后进行。



====== 4 产品成本核算系统操作手册 ======

===== 4.1 使用流程 =====


产品成本核算业务流程说明 

下面针对主要的产品成本核算业务处理流程进行详细的说明。

**第一步，基础设置**

首先，设置产品成本核算的相关基础资料。

在系统开始正式应用前，需要先进行以下基础数据的设置，以保证日常业务正常执行。包括：成本中心、作业活动、产品组、费用分配标准。

维护成本中心：进入【成本管理】—>【产品成本核算】—>【基础资料】—>【成本中心】。

维护作业活动：进入【成本管理】—>【产品成本核算】—>【基础资料】—>【作业活动】。

维护产品组：进入【成本管理】—>【产品成本核算】—>【基础资料】—>【产品组】。

维护费用分配标准：进入【成本管理】—>【产品成本核算】—>【基础资料】—>【费用分配标准】。

其次，设置产品成本核算的分配标准。

在进行费用分配、成本计算前，需要先进行分配标准设置，以确定费用分配、成本计算所取用的具体方法。

包括：费用分配标准设置、分类法分配标准设置、在产品分配标准设置。

维护费用分配标准设置：进入【成本管理】—>【产品成本核算】—>【分配标准设置】—>【费用分配标准设置】。

维护分类法分配标准设置：进入【成本管理】—>【产品成本核算】—>【分配标准设置】—>【分类法分配标准设置】。

维护在产品分配标准设置：进入【成本管理】—>【产品成本核算】—>【分配标准设置】—>【在产品分配标准设置】。

**第二步，初始化**

首先，启用产品成本核算系统

进入【成本管理】—>【产品成本核算】—>【初始化】—>【启用产品成本核算】

其次，期初在产品成本录入（存在期初在产品时才需维护）

进入【成本管理】—>【产品成本核算】—>【初始化】—>【期初在产品成本录入】

再次，产品成本核算初始化

进入【成本管理】—>【产品成本核算】—>【初始化】—>【产品成本核算初始化】

初始化后，期初在产品成本数据是不能再维护的，若需修改初始核算数据，进入“产品成本核算初始化”中进行反初始化处理。 

**第三步，分配标准值维护**

在进行费用分配、成本计算前，需要先进行分配标准值维护，以保证费用分配、成本计算可以取到相应的计算因子。

包括：实际工时归集、作业数量维护、自定义费用分配标准值维护、副产品定额成本维护、约当系数维护。

维护实际工时：进入【成本管理】—>【产品成本核算】—>【分配标准值维护】—>【实际工时归集】。 

维护作业数量：进入【成本管理】—>【产品成本核算】—>【分配标准值维护】—>【作业数量维护】。 

维护自定义费用分配标准值：进入【成本管理】—>【产品成本核算】—>【分配标准值维护】—>【自定义费用分配标准值维护】。 

维护副产品定额成本：进入【成本管理】—>【产品成本核算】—>【分配标准值维护】—>【副产品定额成本维护】。

维护在产品约当系数：进入【成本管理】—>【产品成本核算】—>【分配标准值维护】—>【约当系数维护】。

**第四步，产量归集**

产量归集确定当期费用分配、成本计算相关的产量数据，包括：投入产量归集、完工入库数量、在产品盘点数量录入、投入产出表。

维护投入产量：进入【成本管理】—>【产品成本核算】—>【产量归集】—>【投入产量归集】。 

查询完工入库数量：进入【成本管理】—>【产品成本核算】—>【产量归集】—>【完工入库数量】。  

维护在产品盘点数量：进入【成本管理】—>【产品成本核算】—>【产量归集】—>【在产品盘点数量录入】。 

查询投入产出表：进入【成本管理】—>【产品成本核算】—>【产量归集】—>【投入产出表】。  

**第五步，费用归集**

费用归集确定当期各成本中心发生的费用，包括：费用引入方案设置、执行费用引入、费用归集、材料耗用成本查询、委外加工费查询。

维护费用引入方案：进入【成本管理】—>【产品成本核算】—>【费用归集】—>【费用引入方案】。 

执行费用引入：进入【成本管理】—>【产品成本核算】—>【费用归集】—>【执行费用引入】。 

查询及维护生产费用归集：进入【成本管理】—>【产品成本核算】—>【费用归集】—>【费用归集】。 

查询材料成本：进入【成本管理】—>【产品成本核算】—>【费用归集】—>【材料耗用成本查询】。 

查询委外加工费：进入【成本管理】—>【产品成本核算】—>【费用归集】—>【委外加工费查询】。 

**第六步，产品成本核算**

成本计算确定当期产品的成本，包括：成本计算、合法性检查报告。

执行成本计算：进入【成本管理】—>【产品成本核算】—>【产品成本核算】—>【成本计算】。 

查询成本计算合法性检查报告：进入【成本管理】—>【产品成本核算】—>【产品成本核算】—>【合法性检查报告】。  

**第七步，报表分析**

报表分析可以从不同角度查询产品成本核算结果，包括：费用分配明细表、材料费用分配明细表、成本计算单、完工入库成本查询、销售订单利润分析表、销售订单成本跟踪表、产品期间成本对比分析。

查询生产费用分配明细表：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【费用分配明细表】。 

查询材料费用分配明细表：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【材料费用分配明细表】。  

查询成本计算单：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【成本计算单】/【成本计算单（横向展示）】/【车间成本计算单】。 

查询完工入库成本：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【完工入库成本查询】。  

查询销售订单利润分析表：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【销售订单利润分析表】。  

查询销售订单成本跟踪表：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【销售订单成本跟踪表】。  

产品期间成本对比分析：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【产品期间成本对比分析】。  

产品成本还原对比分析：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【产品成本还原对比分析】。

产品维度利润分析表：进入【成本管理】—>【产品成本核算】—>【报表分析】—>【产品维度利润分析表】。

| 核算组织   | 当前共耗材料分配范围设置的对应的核算组织。                  |

| 接收方范围  | 当前共耗材料分配范围设置的接收方是按物料/存货类别/物料分组中的某一类设置  |

===== 单据体 =====

^ 字段      ^ 说明           ^
| 发送方     | 指定对应的发送方     |
| 费用分配标准  | 指定对应的费用分配标准  |
| 接收方     | 限定对应的接收方     |
| 材料耗用周期  | 限定材料耗用周期     |

====== 操作说明 ======

  * 按“核算体系+核算组织+会计政策”设置，发送方范围设置，从物料、存货类别、物料分组中选择一种。接收方范围设置，从空（指全部范围）、物料、存货类别、物料分组中选择一种，支持多选基础资料。
  * 此处设置的费用分配标准，优先级高于费用分配标准设置。
  * 费用分配标准为完工入库数量、完工入库数量（辅助单位）及其复合分配标准时，允许设置材料耗用周期。规则：当设置材料耗用周期为1天时，当天共耗领料分配给当天的入库产品，比如领料日期为1月3日，则可分配产成品的入库日期为（1月3日0点， 1月4日0点），以此类推，耗用结束日期最大不超过当前期间的结束日期。
  * 费用分配标准为其他时，支持设置不同于费用分配标准设置_共耗材料的分配标准。

## 【页面】成本计算
来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=%E6%88%90%E6%9C%AC%E8%AE%A1%E7%AE%97

====== 功能说明 ======


成本计算通过费用分配、产品成本计算确定当期产品的成本。 

====== 功能路径 ======


【成本管理】—>【产品成本核算】—>【产品成本核算】—>【成本计算】

====== 参数说明 ======


===== 选择核算类型 =====


|**字   段**||**说 明**|
|合法性检查 ||选中则进行产品成本核算合法性检查。|
|费用分配 ||选中则进行生产费用、材料成本分配。|
|成本计算 ||选中则进行完工产品、在产品成本的计算。|

===== 参数设置 =====


|**字   段**||**说 明**|
|写成本计算过程 ||成本计算过程输出的结果表有存货核算明细报告及费用分配过程表，不勾选时，成本核算后不存储过程数据，并有利于提高成本核算性能。|
|出库核算不更新已修改成本的核算单据成本 ||用于成本核算后修改出库单据成本重算的场景，即出库成本核算后，需对部分出库单据的成本进行修改，在重新核算时又想保留已修改的成本不被更新覆盖。|
|单据生成凭证后重新核算不生成成本调整单 ||用于核算单据已生成凭证重算的场景，单据生成凭证后，重算后的成本很可能会与之前的成本存在差异，这种差异怎么处理呢？一种是对核算单据补差生成成本调整单，一种是将差异结转到期末余额中，普遍处理方式是选择结转到期末余额中。|
|零成本单据自动取价 ||支持多种取价来源并设置优先取价顺序进行零成本取价。解决的场景主要是正常核算没有计算出成本的出库序列单据，如负库存导致的无出库成本、售后仓销售退货等特殊情况；还有一个场景是入库成本维护中存在零成本单据没有暂估成本，也可以通过这个参数对入库序列零成本单据进行估价。勾选此参数情况下，成本核算过程中首先对入库序列零成本单据进行取价，然后再进行常规核算，核算过程中存在未能正常核算出成本的出库序列单价再做成本取价，若仍没取到价格的，则合法性检查报告中给予提示。|
|生成组织间调拨单据 ||因存货核算是按货主（即业务组织）进行核算的，当存在多业务组织且存在跨组织业务，又没购买组织结算模块的情况下，跨组织业务单据不能产生组织间的分步式调出调入单，导致单个货主存货余额存在差异情况。此参数就是在这个场景下补充生成分步式调出调入单，与组织间结算不冲突，也不会重复生成分步式调出调入单。|
|自动进行采购入库核算 ||成本核算前自动调用采购入库核算。|
|出库核算自动进行期末余额差异调整 ||出库核算后结存存在无数量有几分钱余额的情况，这是因为出库成本没有进行尾差调整导致，通过此参数可以将这种差异调整到出库单据的成本中，避免期末异常余额。增加此参数主要考虑对性能的影响，若应用此参数存在很大性能影响，那只能建议在成本核算完毕后在期末异常余额中出单处理了。|
|重新获取核算单据 ||用于提高成本核算性能，存货关账后业务数据已稳定，若每次成本核算都重新获取核算单据的话会浪费资源，因此系统在判断已关账且已执行过成本核算的情况下重新核算不再重新获取核算单据。通常情况下此参数没有多大意义，但在一些特殊情况下，如二开单据在关账逻辑控制中存在遗漏，或者关账后后台人工插入业务单据，这时需勾选此参数重新获取核算单据进行核算。|
|成本计算时不更新手工修改的费用分配权重 ||费用分配后可以通过联查费用分配过程表人工干预修改权重影响分配结果，此参数就是决定在重新费用分配时保留已修改的权重不会被更新覆盖。|
|计算产品成本还原系数 ||产品成本还原对比分析表支持动态的还原产品成本，但存在一个缺点就是若某半成品某会计期间没有完工入库的话，无法计算出还原系数，导致产品成本无法彻底还原，此参数的目的就是每期计算自制品最新还原系数构建所有自制品的还原系数库，确保还原系数完整连续。|

====== 操作说明 ======


1、成本计算执行完后点击合法性检查报告，或者点击系统菜单【成本管理】—>【产品成本核算】—>【产品成本核算】—>【合法性检查报告】，可以按“核算体系+核算组织+会计政策”查看当次成本计算的合法性检查报告。

2、合法性检查报告中点击“明细”，可以查看详细的提示信息。

3、合法性检查报告中检查结果为“错误”、“异常”、“不通过”时，说明成本计算未全部完成，请不要在这种情况下去分析数据的准确性，一定要进行相应处理并重新成本计算。
