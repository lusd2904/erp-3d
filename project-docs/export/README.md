# 本地 export 打包说明（去重）

本目录复制自 `/workspace/erp-3d/fullsys/export/`，是当时为上传云盘而打的一包：

- `各模块详细设计.zip`、`界面设计图.zip`、`规划原文件md.zip`
- `平台开发约定.md` 以及 `src/` 下的规划 Markdown

与仓库其他位置的关系：

- 三个 zip 与 `docs/erp设计/` 中的 `06`、`07`、`08` 体积一致，视为同一批文件；界面图和模块设计的展开版分别在 `ui/`、`design/`
- `src/` 与根目录 `project-docs/*.md`、以及 `docs/平台开发约定.md` 是同一类文稿的拷贝

续做开发时优先阅读 `project-docs/` 的 md、`docs/平台开发约定.md` 和已展开的 `design/`、`ui/`；本目录主要作归档。
