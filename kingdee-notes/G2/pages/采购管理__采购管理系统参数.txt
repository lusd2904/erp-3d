#1功能概述 #定义采购系统参数，在数量、货源、退料、变更等方面设定采购规则。
采购参数设置后可以修改，以参数修改时间为时间点，只影响参数修改后新增的单据。
参数分为两种，一种是组织层面的参数，一种是单据类型层面的参数。前者影响整个采购组织的规则，后者只影响对应的单据类型。
#2使用前提 #无
#3功能路径 #组织层面参数：【供应链】－>【采购管理】－>【参数设置】－>【采购管理系统参数】
单据类型层面参数：【基础设置】－>【基础资料】－>【单据类型】－>【参数设置】
#4采购参数明细说明 ##4.1基本参数 ##4.1.1允许超申请数量采购 #* 选项：
复选框
 * 参数说明：
用以控制能否超采购申请下达采购订单
 - 勾选，采购订单数量不受采购申请单数量的控制，订单数量允许超过申请
 - 不勾选，采购订单数量超过采购申请单数量时不允许保存。
#4.1.2保质期检查强度 #* 选项：
 - 不予控制
 - 预警提示
 - 禁止交易
 * 参数说明：
用以控制收货单、入库单保存时检查保质期不在合理时间范围内的处理方式
 - 不予控制，则不检查保质期即允许保存单据。
 - 预警提示，则检查发现保质期不合理后给用户提示，用户确认后可用保存。
 - 禁止交易，则保质期不在合理时间范围内则不允许保存单据。
#4.1.3 订单变更方式选择 #* 选项：
单选
 * 参数说明：
 -启用订单变更单：允许使用采购订单变更单进行采购订单变更，详情可参考采购订单变更单
 -直接订单变更（不支持审批流）：直接通过采购订单中功能修改变更对订单进行修改，可修改已审核的单据。
 -启用订单新变更单（支持自定义字段变更和审批流）：通过采购订单新变更单对单据进行变更，详情可参考采购订单新变更单
#4.1.4采购退料时自动创建补货订单 #* 选项：
复选框
 * 参数说明：
用以控制补料方式为【创建补料订单】的退料单审核时是否自动生成补料采购订单
 - 勾选，则退料单审核时自动生成补货采购订单。
 - 不勾选，则退料单审核时不自动生成补货采购订单。
#4.1.5业务组数据隔离 #* 选项：
复选框
 * 参数说明：
用以控制采购员查询权限是否要按所在采购组别进行隔离
 - 勾选，则采购员只能看到自己组别或无组别的采购数据
 - 不勾选，则采购员可以看到所有的采购数据
#4.1.6调价表审核时自动生效 #* 选项：
复选框
 * 参数说明：
用以控制调价表审核时是否自动生效
 - 勾选时，调价表审核即生效
 - 不勾选时，调价表需要手动生效
#4.1.7允许不合格品入库 #* 选项：
复选框
 * 参数说明：
用以控制采购入库单是否允许不合格品入库
 - 勾选时，则采购入库单上可以自动生成所有入库类型的分录；
 - 不勾选时，则采购入库单只会自动生成合格入库和让步接收入库类型的分录；
注意：物料启用质量检验时，可以根据质量检验结果在采购入库单上自动生成各种入库类型的分录，包括合格品入库、让步接收入库、工废入库、料废入库、不合格入库五种类型，具体入库类型与收料单上的检验结果有关。
#4.1.8已关闭的订单可以变更 #* 选项：
复选框
 * 参数说明：
用以控制已经业务关闭的采购订单是否可以变更
 - 勾选时，则采购订单关闭还可以下推变更单
 - 不勾选时，则采购订单关闭不可以下推变更单
#4.1.9配额物料只能配额生成订单 #选项：
复选框
 * 参数说明：
用以控制基础资料物料勾选配额管理是否只能通过配额下单生成订单
 - 勾选时，则物料勾选配额管理，这个物料只能通过配额下单生成订单
 - 不勾选时，则物料勾选配额管理，这个物料可以通过配额下单生成订单，也可以通过其他途径或手工现在订单
#4.1.10收料检验后合格品自动入库 #* 选项：
复选框
 * 参数说明：
用以控制收料通知单中的合格品在检验单审核时自动生成采购入库单
 - 勾选时，则收料通知单下推检验单后合格品自动生成采购入库单
 - 不勾选时，则收料通知单下推检验单后合格品不会自动生成采购入库单，需要手工通过收料通知单下推生成
#4.1.11收料检验后不合格品自动退料 #* 选项：
复选框
 * 参数说明：
用以控制收料通知单中的不合格品在检验单审核时自动生成采购退料单
 - 勾选时，则收料通知单下推检验单后不合格品自动生成采购退料单
 - 不勾选时，则收料通知单下推检验单后不合格品不会自动生成采购退料单，需要手工通过收料通知单下推生成
#4.1.12入库取即时汇率 #* 选项：
复选框
 * 参数说明：
用以控制采购订单到入库单时汇率携带还是取即时汇率
 - 勾选时，入库单由上游单据下推时取即时汇率
 - 不勾选时，入库单由上游单据下推时携带上游单价的汇率
#4.1.13收料取即使汇率 #* 选项：
复选框
 * 参数说明：
用以控制采购订单到收料通知单时汇率携带还是取即时汇率
 - 勾选时，收料通知单由上游单据下推时取即时汇率
 - 不勾选时，收料通知单由上游单据下推时携带上游单价的汇率
#4.1.14订单变更审核不自动生效 #* 选项：
复选框
 * 参数说明：
用以控制采购订单变更单审核时是否自动生效
 - 勾选时，采购订单变更单审核不自动生效，需要手工点击生效按钮
 - 不勾选时，采购订单变更单审核自动生效
#4.1.15合同变更审核不自动生效 #* 选项：
复选框
 * 参数说明：
用以控制采购合同变更单审核时是否自动生效
 - 勾选时，采购合同变更单审核不自动生效，需要手工点击生效按钮
 - 不勾选时，采购合同变更单审核自动生效
#4.1.16配额下单可选择无价目表和货源清单的采购申请单 #* 选项：
复选框
 * 参数说明：
用以控制配额下单是否可以选择无价目表和货源清单的采购申请单
 - 勾选时，配额下单可以选择无价目表和货源清单的采购申请单
 - 不勾选时，配额下单不能选择无价目表和货源清单的采购申请单
#4.1.17货源清单支持辅助属性 #* 选项：
复选框
 * 参数说明：
用以控制货源清单是否支持辅助属性
 - 勾选时，货源清单支持辅助属性，创建货源清单时检查辅助属性是否相同，并在采购订单和配额下单都支持辅助属性
 - 不勾选时，货源清单不支持辅助属性，创建货源清单是不检查辅助属性是否相同
#4.1.18启用变更查询 #* 选项：
复选框
 * 参数说明：
用以控制采购订单是否支持变更查询
 - 勾选时，在采购订单列表和详细页的业务查询下增加变更查询按钮，点击可以查询此张采购订单的变更记录，用于采购订单新变更单
 - 不勾选时，不能使用变更查询
#4.1.19启用套件采购 #* 选项：
复选框
 * 参数说明：
用以控制采购订单或采购申请单新增时是否可以使用套件采购快捷下单服务
 - 勾选时，在采购订单或采购申请单新增时，在明细菜单栏会增加套件采购按钮，点击按钮可弹出套件采购选父项物料和bom，输入要采购套数，点击返回数据，即可携带子项物料到采购订单或采购申请上，并根据分子分母损耗之间的关系计算出采购数量和申请数量
 - 不勾选时，在采购订单或采购申请单上无法使用套件采购服务
#4.1.20启用齐套检查 #* 选项：
复选框
 * 参数说明：
用以控制当启用齐套采购时，采购订单和采购申请保存时对子项是否齐套的检查
 - 勾选时，采购订单或采购申请单保存时，检查此父项下的子项是否齐套，此检查是为了防止操作员误删除子项行，导致子项物料缺少
 - 不勾选时，采购订单或采购申请单保存时，不检查是否齐套
#4.1.21启用最小包装量，最小最大订货量 #* 选项：
复选框
 * 参数说明：
用于控制采购订单的采购数量是否符合物料主数据计划属性页签中最小包装量，最小最大订货量的设置，并进行数量的调整。
 - 勾选时，采购订单会自动的获取物料中设置的最小包装量，最小最大订货量，采购数量必须是包装量的整数倍，或采购数量大于等于最小订货量，小于等于最大订货量。
 - 不勾选时，采购订单不检查是否需要满足最小包装量，最小最大订货量的设置。
此参数需要与参数【允许超申请数量采购】搭配使用，在采购订单采购数量调整时，会出现修改后采购数量大于申请数量的情况。
#4.1.22采购申请单指定供应商和价格时考虑辅助属性 #* 选项：
 复选框
 * 参数说明：
用于控制采购申请单列表菜单【指定供应商】在查询价目表时，按选择行查找是否考虑辅助属性维度。
 - 勾选，通过指定供应商按钮查询价目表时，按指定行数据中的辅助属性维度查询采购价目表价格和供应商。
 - 不勾选，通过指定供应商按钮查询价目表时，不考虑指定行数据中的辅助属性维度查询采购价目表价格和供应商。
#4.1.23订单是否默认控制交货数量 #* 选项：
 下拉列表单选
 * 参数说明：
 - 不处理，字段不通过参数控制是否需要强制控制，由用户手工修改采购订单中的控制交货数量字段是否默认勾选。
 - 控制，通过参数控制采购订单中的控制交货数量字段默认勾选。
 - 不控制，通过参数控制采购订单中的控制交货数量默认不勾选。
#4.1.24采购订单显示付款视图 #* 选项：
 复选框
 * 参数说明：
用于控制采购订单中是否显示付款明细页签视图。显示视图时，在采购订单按物料明细付款，按订单付款的付款条件时，支持显示采购订单关联的付款申请单，预付款单，付款单。并在表头财务信息页签汇总显示付款金额，付款申请总金额。
 - 勾选，采购订单显示付款明细信息页签，并执行付款申请，付款关联查询，并显示相关单号信息在页签中。查询有一定的性能风险。
 - 不勾选，采购订单不显示付款明细信息页签，并执行付款申请，付款关联查询，并显示相关单号信息在页签中。
#4.1.25行号不参与列表默认排序 #* 选项：
 多选下拉列表
 * 参数说明：
设置行号在单据列表是否参与排序，参与排序时，列表按过滤条件设置的排序规则以及行号进行排序，不参与排序列表按过滤条件设置的排序规则进行排序。一般列表数据量较大时，不建议行号参与排序。行号参与排序有一定的性能风险。
支持按指定单据设置行号是否参与排序。
#4.1.26启用货源清单分配 #* 选项：
 复选框
 * 参数说明：
货源清单是否可作为基础资料进行跨组织分配，后台新增了货源清单基础资料数据，数据来源于货源清单表单，支持使用基础资料的分配方式进行数据跨组织分配。
#4.1.27货源清单审核后有效 #* 选项：
 复选框
 * 参数说明：
货源清单是否将审核状态作为数据有效性控制，勾选后，货源清单通过审核后，才可在配额下单中使用。
#4.1.28申请单修改数量不更新提前期 #* 选项：
 复选框
 * 参数说明：
用于控制采购申请单修改数量时是否自动触发提前期值更新，提前期中包含变动提前期默认会物料的数据更新提前期。如果勾选该参数，采购申请单修改数量时，不更新提前期并重算建议采购日期。
#4.1.29 启用货源清单/价目表控制采购范围 #* 选项：
 列表新增行
 * 参数说明：
用于控制业务单据在创建时，物料和供应商的选择范围。
#4.1.30 自动修正采购订单变更状态、标识 #* 选项：
 复选框
 * 参数说明：
当采购订单变更后，如果变更中状态未正常反写，此参数启用后可以在采购订单下推时查询关联变更单状态并自动修正变更状态。如果勾选该参数，采购订单下推操作时，自动修正变更状态、变更标志。
#4.2VMI参数 ##4.2.1可选VMI物料消耗单据 #* 选项：
多选下拉列表
 * 参数说明：
根据业务需要选择创建VMI消耗汇总时需要统计的业务单据。注意：如果选择不正确，可能导致VMI消耗汇总数据也不准确。
#4.2.2VMI结算价格来源 #* 选项：
多选下拉列表
 * 参数说明：
创建VMI消耗汇总时默认的结算价格来源
 - 采购价目表，选择此选项则VMI消耗汇总表的价格来自采购价目表；
 - 采购订单，选择此选项则VMI消耗汇总表的价格来自采购订单；
#4.2.3VMI消耗数据合并选项 #* 选项：
多选下拉列表
 * 参数说明：
指定消耗汇总表上表体汇总页签的合并依据
#4.2.4按批次取价 #* 选项：
复选框
 * 参数说明：
用以控制当vmi结算价格来源选择采购订单时，获取价格时可以根据采购订单入库的批次进行获取价格，价格来源为采购价目表和手工录入不支持
 - 勾选时，创建消耗汇总表获取价格时，根据出库的批次查找这一批次入库采购订单的价格
 - 不勾选时，创建消耗汇总表获取价格根据采购订单由下而上获取价格
#4.2.5批量创建消耗汇总网控隔离方式 #* 选项：
复选框
 * 参数说明：
用于指定在多人同时创建消耗汇总表时的隔离方案。用于隔离用户操作的业务数据，可同时对不同隔离区间业务数据创建消耗汇总表
 - 1、只允许单一示例允许: 无数据隔离，但不允许多人同时创建消耗汇总表。
 - 2、按消耗组织隔离: 按批量创建消耗汇总参数中消耗组织字段值进行隔离。
 - 3、按供应商隔离: 按批量创建消耗汇总参数中供应商字段值进行隔离。
 - 4、按消耗组织+供应商隔离:按批量创建消耗汇总参数中消耗组织和供应商字段值同时进行隔离。
#4.3对账管理 ##4.3.1批量对账最大显示行数 #* 选项：
 - 文本框，默认值2000

控制在批量对账页面中最大可显示行数，对账单据行数超过此参数值时，批量对账页面仅加载指定行数。
#4.3.2生成应付最大同步行数 #* 选项：
 - 文本框，默认值50
 * 参数说明：
控制在对账单生成应付单时，前台同步支持的最大行数，当单据的行数超过参数值时，会通过异步方式处理，后台执行完成后可以在应付列表查看。
#4.3.3对账单生成应付单不校验权限 #* 选项：
 - 复选框
 * 参数说明：
控制在对账单生成应付单时，是否校验当前操作人是否有创建应付单的用户权限。
 - 勾选，不校验用户是否有创建应付单权限，忽略权限校验。
 - 不勾选，校验用户创建应付单权限。无权限则生成应付单失败。

 - 审核
 - 创建
 - 提交
 * 参数说明：
控制在对账单生成应付单后，应付单单据状态。当单据有配置审批流时，仅支持提交审批流。
#4.4价格管理 ##4.4.1参考价来源 #* 选项：
 - 手动录入
 - 最近订单价
 * 参数说明：
用以控制采购订单取参考价操作的价格来源
 - 手动录入，则不进行取参考价，完全手动录入
 - 最近订单价，取日期最近的采购订单的价格
#4.4.2采购限价控制强度 #* 选项：
 - 不予控制
 - 预警提示
 - 强制
 - 密码特批
 * 参数说明：
用以控制采购单据保存时价格超出限价控制的处理方式
 - 不予控制，选择此选项则不检查价格即允许单据保存。 
 - 预警提示，选择此选项则检查发现单据价格不在价格上下限中时，进行提示，用户确认后可以保存。 
 - 强制，选择此选项则检查发现单据价格不在价格上下限中时，单据不允许保存。 
 - 密码特批，选择此选项则需要预先输入特批用户和特批密码，单据上验证特批用户和特批密码。
注意：选择不予控制时，采购价目表不能设置价格上下限；选择其它选项时，采购价目表可以设置价格上下限。
#4.4.3参与采购自动取价单据 #- 被选中的单据，进行自动取价
 - 没有被选中的单据，表头价目表可以选
 - 从上游单据到下游单据时，默认携带单价，但不携带“价目表”， 默认不重新取价,当客户手工更新“价目表”时，再重新取价。
#4.4.4强制价目表定价 #字段说明
 * 单据名称:选择需要对价目表控制的单据，比如采购订单，采购入库单等
 * 条件：这里需要写入表达式，通过表达式可以排除某种情况不受参数控制，表达式配置可参考论坛帖http:club.kingdee.com/forum.php?mod=viewthread&tid=1310448
 * 检查价格来源：这里包括不予控制、预警提示、强制价目表定价
#4.4.5整单折扣分配方式 #字段说明
 -选项
按价税合计比例分摊
平均分摊
 * 该参数影响单据范围包括采购订单、收料通知单和采购入库单。
按价税合计比例分摊: 分录行折扣额=[该行分录的价税合计/∑(分录行价税合计]]*整单折扣额.
平均分摊: 分录行折扣额=整单折扣额分录行数。
#4.4.6比价单更新价目表不验证权限 #参数说明
 * 控制比价单审核后更新价目表时，是否校验当前审核比价单的操作人员的采购价目表新增，修改权限
#4.4.7是否采用按物料分组取价 #参数说明
 * 控制是否启用按物料分组进行采购取价。启用后，采购价目表中支持维护物料分组。并在采购取价时支持按物料分组自动取价，当物料同时存在物料分组定价和物料定价时，已物料定价优先取价。
#4.4.8采购价目表审核自动分发 #参数说明
 * 用于控制采购价目表审核后是否自动分发。如果勾选该参数，采购价目表审核后，系统会自动根据分发方案分发至目标组织。
 * 自动分发的前提是有配置采购价目表分发方案。
#4.5 移动采购 ##基本配置 #移动采购应用列表：用于设置移动采购中的可显示应用，系统默认全部未选择，当需要使用移动采购时，需要勾选此应用列表中需要展示的值。
#5单据类型参数说明 #|参数|选项|参数说明|
·参考交货明细执行：布尔 / 采购订单是否参照交货明细执行 勾选，则采购订单后续收货会参照采购订单交货明细进行。 不勾选，则采购订单后续收货不会参照采购订单交货明细进行。
·允许修改交货比例：布尔 / 采购订单是否允许修改交货比例相关字段 勾选，则采购订单能够修改交货比例相关字段。 不勾选，则采购订单不能修改交货比例相关字段。
·允许修改时间控制：布尔 / 采购订单是否允许修改时间控制相关字段 勾选，则采购订单能够修改时间控制相关字段。 不勾选，则采购订单不能修改时间控制相关字段。
·关联生成：布尔 / 单据是否必须关联生成 勾选，若“所有分录关联生成”，那单据所有分录必须都有上游的源单单据；若“关联后允许手工新增分录”，则关联新增单据之后可以手动新增没有上游源单的分录。 不勾选，则不控制单据是否有源单。
