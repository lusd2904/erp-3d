## 0. 通用规则

### 0.1 单据状态（单据状态通用说明 / 各单据页）
暂存 → 创建（保存）→ 审核中（提交）→ 已审核（审核）→ 重新审核（反审核/驳回）。
另有几个独立的状态维度：
- 作废状态：未作废/作废。
- 关闭状态：未关闭/关闭（整单），行级的「业务关闭」由系统自动置位。
- 业务冻结（采购订单、销售订单有）。
- 业务终止。

### 0.2 单据关联（业务流程 / 单据转换规则 / 反写规则）
- **单据转换（下推/选单）**：配置源单→目标单的字段映射、分组策略和选单条件。
- **反写**：下游单据保存或审核时，按规则回写上游的累计数量字段，例如关联数量、累计入库数量。也可以按「关闭控制」把上游行置为已关闭。还可以做「超额控制」，超额时终止本次反写。
- 跨级反写举例：采购订单→收料单→入库单，入库单跨级反写采购订单，按「自上而下」分配。

### 0.3 库存维度（库存业务专题_库存维度）
库存维度是「更新库存及负库存判断的唯一值组合」，包括：
物料、批号、生产日期、有效期至、辅助属性、BOM版本、计划跟踪号、库存状态、货主类型、货主、保管者类型、保管者、仓库、仓位。

库存状态类型：可用、待检、冻结、退回冻结、在途、收货冻结、废品、不良。库存状态上可以勾选的属性有：可使用、不可销售、不可领用、可锁库、MRP可用、参与预警。

## 1. 生产管理（生产管理 / 各单据页）

### 1.1 总体流程（生产管理概述 1.4、2.1）
1. 先建基础数据：
   - 公共档案：计量单位、仓库、部门、物料。
   - 工程数据：工作日历、BOM、作业、资源、工作中心、工艺路线。
   - 生产基础资料：汇报类型等。
2. 再设生产参数。
3. 日常业务：生产订单 → 生产领料 → 生产汇报 → 完工入库。

普通生产业务包括：生产订单维护、用料清单维护、生产领料、生产退料、生产补料、生产汇报、生产入库。其中：
- 「齐套分析」：生管员在订单投放前做齐套和缺料分析；仓库员在投放后做欠料分析。
- 「下达」：根据车间产能、材料、设备治具和要求日期判断能否投产，把符合条件的订单发放给车间。

返工生产的流程与普通生产相同。

生产管理下的单据清单（3.2 节）：
- 订单类：生产订单、生产订单变更单、生产用料清单、生产用料清单变更单、生产订单拆分。
- 领料类：生产领料申请单、生产领料单、生产退料单、生产补料单、生产倒冲、成套领/退/补料、生产倒冲差异分摊、生产挪料、生产发料、生产直送。
- 汇报入库类：生产汇报单、生产入库单、生产退库单。
- 齐套与在制：齐套分析模板、生产齐套分析、生产月末在制转移。
- 简单生产：简单生产领料单、退料单、入库单、退库单。

查询报表（3.3 节）：生产订单执行明细表、生产订单执行汇总表、生产订单领料汇总表、生产订单领料明细表、生产领料差异汇总表、生产领料异常表、生产入库领料查询、生产入库月报表、生产领料月报表。

### 1.2 生产订单（生产订单）
- **表头**：单据编号、单据类型、生产组织、委托组织、单据日期、计划组、计划员、单据状态（暂存/创建/审核中/已审核/重新审核）。
- **明细**：产品类型（主产品/联产品/副产品）、物料编码（只能选勾了「允许生产」的物料）、物料名称、规格型号、生产车间（下达前必录）、单位、数量、业务状态、计划开工时间、计划完工时间、BOM版本、领料状态（未领料/部分领料/全部领料/超额领料）。
- **生产页签**：工艺路线、批号、入库上限、入库下限、挂起状态、入库货主、入库组织、仓库、仓位、辅助属性、产品检验（勾选=必须做产品检验）、产出工序、成本权重。
- **执行页签**：计划确认日期、排产日期、下达日期、开工日期、完工日期、结案日期、核算日期。以及累计数量：汇报选单数量、合格品数量、不合格品数量、报废数量、返修品数量、备料数量、领料套数、合格品入库选单数量、合格品入库数量、不合格品入库数量……
- **序列号页签**：序列号、汇报选单数量、入库选单数量。
- **参考页签**：生成方式（手工录入、MRP生成、MPS生成、拆分等）、来源单据类型（销售订单/空）、来源单据编号/行号、销售订单、销售订单行号、业务流程（预设「生产直接入库流程」「生产汇报入库流程」）。
- **业务状态（分录级）**：计划 → 计划确认 → 下达 → 开工 → 完工 → 结案（列举里还有「结算」）。
  - 审核时自动把所有分录计划确认。
  - 未审核时只能处于计划或计划确认。
  - 用「执行」和「反执行」推进或回退状态，也可以跳跃。
  - 可以挂起、反挂起；挂起后不能产生下游单据。
- **规则**：
  - 保存时按 BOM 生成生产用料清单。
  - 下达后才可以下推下游单据。
  - 有下游有效的领退补料单时不能反下达。
  - 有下游汇报或入库单时不能反开工。
  - 生产入库单审核后，累计入库达到入库下限时可以自动完工。
  - 结案时不能存在「非审核非作废」的下游单据（领退补、汇报、入库）。
  - 结算后不能反结案。
  - 参数：审核时自动下达、下达时自动开工、领料时自动开工、自动完工。
- **拆分行**：业务状态为计划、计划确认、下达或开工，未挂起的主产品才能拆分，按拆分数量生成新分录的用料清单。

### 1.3 生产订单变更单
- 前提：生产订单已审核，分录处于计划确认、下达或开工，且未挂起。
- 字段：变更原因、变更类型（新增/变更）、数量、计划开工时间、计划完工时间、BOM版本、工艺路线、批号、入库组织、仓库、入库上下限。
- 审核时把变更同步反写到生产订单，并刷新用料清单的标准用量、需求数量、应发数量和需求日期。可以设置「订单数量变小自动生成生产退料单」。

### 1.4 生产用料清单（PPBOM）
- **常规页签**：单据编号、产品编码/名称/规格、生产组织、车间、BOM版本、数量、单位、生产订单类型、生产订单编号、生产订单行号、生产订单状态、单据状态。
- **明细页签**：子项物料编码、子项类型（标准件/替代件/返还件）、用量类型（固定/变动/阶梯）、使用比例、分子、分母、子项单位、固定损耗、变动损耗率、需求日期、标准用量、需求数量、应发数量、供应组织、发料组织。
  - 标准用量（变动）= 生产订单数量 × 使用比例 × 分子 / 分母。
  - 需求数量 = 标准用量 × (1 + 变动损耗率) + 固定损耗。另一种损耗公式为 /(1 − 损耗率)。
  - 应发数量：「是否发损耗」为是时取需求数量，否则取标准用量。
- **物料控制页签**：BOM版本、货主、批号、位置号、偏置提前期、工序、作业编码、是否发损耗、倒冲时机、仓库、仓位、拨出组织、拨出仓库、是否关键件、是否展开、需求日期、预留类型、需求优先级。还有以下几个带取值的字段：
  - 发料方式：直接领料、直接倒冲、调拨领料、调拨倒冲、不发料。
  - 超发控制方式：允许超发、最小发料批量、不允许超发、按损耗率超发。
  - 替代策略：混用、手工、整批、整批+混用。
  - 替代方式：替代、取代、按比例。
- **数量控制页签**（系统反写）：调拨数量、已领数量、补领数量、报废数量、良品退料数量、来料不良退料数量、作业不良退料数量、已消耗数量、在制材料数量、实领数量、领料选单数量、退料选单数量、补料选单数量。
  - 在制材料数量 = 已领 + 补领 − 良品退料 − 来料不良退料 − 作业不良退料 − 报废 − 已消耗。
  - 实领数量 = 已领 + 补领 − 三类退料 − 报废。
- **规则**：
  - 生产订单保存时自动生成用料清单，没有整单删除。
  - 主产品分录唯一对应一张用料清单。
  - 标准件和返还件不能删除行（不领时可以把分子设为 0）。
  - 变更流程下，审核后只能用「生产用料清单变更单」修改。
  - 用料清单是领料、退料、补料的数据来源，作为已分配量参与 MPS/MRP，也是成本计算直接材料的取数来源。

### 1.5 领料 / 退料 / 补料
- **生产领料单**
  - 前提：生产订单分录处于下达、开工或完工，未挂起；用料清单已审核。
  - 生成：由生产订单下推，或选择用料清单分录。
  - 表头：单据编码、单据类型、单据日期、发料组织、生产组织、生产车间、货主类型、货主。
  - 明细：物料编码、单位、申请数量、实发数量、仓库、仓位。
  - 库存页签：BOM版本、辅助属性、库存状态、生产日期、保质期、有效期至、保管者、批号、退料选单数量。
  - 数量控制：应发数量 − 领料选单数量 + 良品退料数 + 来料不良退料数 > 0。
  - 审核时反写用料清单的「已领数量」。返还件不允许领料。
  - 倒冲领料有两种方式：后台倒冲、交互式倒冲；两种时机：汇报倒冲、入库倒冲。
- **生产领料申请单**
  - 车间提出申请，仓管自动拣货，审核后「发料」生成领料单。
  - 关闭状态：未关闭、手工关闭、自动关闭。
  - 字段：本次申请数、拣货数量、已领数量、欠领数量。
- **生产退料单**
  - 由生产订单、领料单或补料单下推生成。
  - 表头有收料组织；明细有申请数量、实收数量。
  - 审核时反写用料清单的良品退料数量、来料不良退料数量、作业不良退料数量。
  - 退料类型（从用料清单和参数页看）：良品退料、来料不良退料、作业不良退料。
- **生产补料单**
  - 由生产订单或生产退料单下推生成，也可以手工新增（必须指定生产订单分录）。
  - 退料单下推补料单的条件：退料类型为「作业不良退料」，且 实退数量 − 补料选单数 > 0。
  - 审核时反写用料清单的「补领数量」和「报废数量」。

### 1.6 生产汇报单
- 前提：生产订单分录处于开工或完工，未挂起。由生产订单下推生成。
- 明细字段：物料编码、生产车间、单位、汇报类型（有效工时/无效工时/中性工时）、产品类型、完成数量、合格数量、不合格数量、返修数量、报废数量、返工数量、责任部门。其中完成数量 = 合格 + 不合格 + 返修 + 返工 + 报废。
- 控制页签：人数、机台数、开始时间、结束时间、单位标准工时、人员准备工时、人员实作工时、机器准备工时、机器实作工时、批号、班组。
- 参考页签：生产订单编码、行号，以及合格品、不合格品、报废品、返工品的入库选单数量。
- 规则：
  - 保存时反写生产订单的「汇报选单数量」，校验累计（合格 − 返修）≤ 入库上限。
  - 审核时反写生产订单的合格、不合格、返修、报废、返工数量。
  - 可选单条件：入库上限 − 汇报选单数量 + 返修数量 > 0。

### 1.7 生产入库单 / 生产退库单
- **生产入库单**
  - 来源：
    - 单据类型为「直接入库」时，由生产订单下推。
    - 单据类型为「汇报入库」时，由生产汇报单下推。
  - 表头：入库组织、生产组织、货主（固定为生产组织）。
  - 明细：入库类型（合格品/不合格品/返工品/报废品）、应收数量、实收数量、仓库、仓位、批号、班组、生产订单号/行号、源单类型/编号/行号。
  - 规则：
    - 累计入库 ≤ 入库上限。
    - 审核时反写生产订单的各类入库数量。
    - 可以按入库下限自动完工。
    - 「入库时扣减」参数下扣减在制材料。
- **生产退库单**
  - 现阶段只支持「生产入库单 → 生产退库单」这一条路线。
  - 字段：退库类型（四类）、应退数量、实退数量、退库原因。

### 1.8 生产订单拆分 / 缺料分析
- **生产订单拆分**
  - 订单拆分方式：一单一分录、一单多分录。
  - 生成类型：生产订单、委外订单。
  - 新订单状态：创建、审核、审核中。
  - 可以选择「继承原用料清单」。
- **缺料分析**（计划管理页；「生产齐套分析」页读不到，齐套逻辑参照此页）：
  - 表头：物料替代、生产/委外组织、生产车间、优先顺序（优先级/计划开工日期/计划完工日期）、匹配供应考虑货主。
  - 方案页签（供给范围）：即时库存、生产订单、采购订单、委外采购订单、采购申请单、收料通知单……
  - 订单明细：齐套数量。
  - 子项明细：应发数量、已领数量、可领数量、可用供应数量、即时供应数量、在途供应数量、缺料数量。
  - 缺料清单：其他订单需求数量、采购申请选单数量。
  - 规则：按顺序先分配库存，再分配预计入；审核后可以下推采购申请单，也可以生成追料报告。
- **齐套分析模板**：把优先顺序、调拨策略、仓库范围等常用参数存成模板。

### 1.9 参数要点（生产管理参数 / 生产单据类型参数）
- 生产类型：标准生产、返工生产。
- 自动类参数：审核自动下达、下达自动开工、领料自动开工、自动完工、自动结案。
- 在制材料扣减时机：入库时扣减、汇报时扣减。
- 倒冲时机：入库倒冲、汇报倒冲。倒冲方式：交互式、后台。
- 检验联动：
  - 产品检验完成后自动入库。
  - 不良品处理审核后自动入库。
  - MRB 评审审核后自动入库。
- 默认库存状态：来料不良退料、作业不良退料、不合格品入库、报废品入库、返工品入库各有一个默认库存状态。

## 2. 工程数据 / 基础资料

- **物料清单（BOM）**
  - 表头：BOM版本、BOM分类（标准/配置）、BOM用途、父项物料编码、成品率。
  - 联副产品：类型、数量、成本权重。
  - 子项：项次、子项物料编码、子项BOM版本、子项类型（标准/替代/返还）、用量类型、用量（分子/分母）、固定损耗、变动损耗率、阶梯用量（起始数量/截止数量）、超发控制、最小发料批量、是否发损耗、提前期偏置、是否关键件、工序、作业编码、位置号、货主类型、替代策略、替代方式、替代优先级。
    - 发料方式：直接领料、直接倒冲、调拨领料、调拨倒冲、不发料。
    - 倒冲时机：汇报倒冲、入库倒冲。
  - 查询：正查、反查、汇总、对比、BOM修改日志。
- **工艺路线**
  - 表头：工艺路线编码/名称、工艺类型、生产车间、物料。
  - 工序：工序号、加工组织、工作中心、加工车间、作业、工序说明、工序控制码、关键工序、提前期、工序拆分、工序重叠、标准排队时间、标准等待时间、标准移动时间、委外（供应商、委外单价）。
  - 原文说明：「一条流水线就是一条工艺路线」。
- **工作中心**：编码、名称、所属部门、工作中心组、工序控制码、作业、工作日历、关键工作中心、基本活动、资源（资源类别：机器/工装/人员/物料/其他）、效率、排队/等待时间。
- **物料**
  - 页签：基本、库存、销售、采购、计划、生产、质量。
  - 基本：编码、名称、规格型号、物料属性（自制/委外/虚拟/外购/特征/费用/一次性/模型等）、存货类别、允许采购/销售/库存/生产/委外、基本单位。
  - 库存：库存单位、仓库、仓位、启用批号管理、启用保质期控制、启用序列号管理、最小库存、最大库存、安全库存、再订货点、单箱标准数量。
  - 采购：采购单位、默认供应商、采购批量、最小订单数、收货上下限比例、配额管理。
  - 销售：销售单位、超发上下限、允许退货。
  - 生产：生产车间、生产单位、入库超收/欠收比例、默认工艺路线、发料方式、倒冲时机、超发控制方式、最小发料批量、关键件、齐套件、日产量、默认产线。
  - 质量：来料检验、产品检验、抽样方案、质检方案。
  - 计划：计划策略、制造策略、订货策略、固定/变动提前期、检验提前期、最大/最小订货量、批量增量、安全库存、需求时界、计划时界、预留类型。
- **仓库**：仓库属性、库存状态类型（可用/待检/冻结/退回冻结/在途/收货冻结）、默认库存状态、允许负库存、允许锁库、参与预警、启用仓位管理、仓位。
- **其他基础设置页列出的档案**（本次只抓了部分详情页）：部门、员工、供应商、客户、币别、计量单位组/计量单位、存货类别、工作日历、班制、班次、单据类型、税率、辅助属性。
- **班组**：所属车间。单据上要先录生产车间才能录班组。
- **汇报类型**：汇报属性（有效工时/无效工时/中性工时）、默认汇报类型。
- **设备（车间管理/智慧车间）**
  - 页签：基本信息、常规、仪表、状态映射、图片。
  - 当前状态枚举：**加工、异常停机、空闲、占用、关机**。
  - 状态映射里有「Scada状态代码」，一个系统状态可以对应多个 Scada 代码，用 `;` 分隔。

## 3. 供应链

### 3.1 采购（采购管理）
- **单据链**：采购申请单 → 采购订单 → 收料通知单 → （来料检验）→ 采购入库单 → 采购退料单。另有退料申请单、采购订单变更单、采购合同。
- **采购申请单**
  - 表头：单据类型、申请类型、申请组织、申请日期、单据状态、申请人、申请部门、币别。
  - 明细：需求组织、物料、申请数量、批准数量、到货日期、收料组织、采购组织、建议供应商、单价、含税单价、提前期、建议采购日期。
  - 关联：关联数量、订单数量、剩余数量（= 批准数量 − 关联数量）、源单类型/单号、计划跟踪号、需求跟踪号。
  - 状态：作废状态、关闭状态、业务关闭、业务终止。
  - 规则：已审核、业务关闭正常、业务终止正常时才能转采购订单。采购订单保存时反写申请单的「关联数量」，审核时反写「订单数量」。
- **采购订单**
  - 表头：单据编号、采购日期、供应商、采购部门、结算币别、汇率、价目表、价税合计、是否预付、版本号、变更人。
  - 明细与交货：交货上限、交货下限、控制交货时间、最早/最晚交货日期、交货日期、数量、已交货数量、剩余数量、税率、折扣率、净价。
  - 执行：累计收料数量、剩余收料数量、累计入库数量、剩余入库数量、累计退料数量、源单类型/单号、合同单号、需求跟踪号、变更标志。
  - 状态：业务关闭、业务冻结、业务终止。
  - 下游转换：已审核、未关闭、业务状态正常时，可以转收料单；不需来料检验时可以直接转入库单；也可以转退料申请单或退料单。收料单合并的条件是供应商、收货组织、采购组织、需求组织、结算组织、结算币别都相同。勾选「控制交货数量」时按上下限控制。
- **收料通知单**
  - 表头：收料组织、收料员、供应商、日期。
  - 明细：交货数量、实到数量、实收数量、拒收数量、拒收原因、仓库、库存状态、批号、供应商批号、生产日期、有效期至、来料检验、紧急放行。
  - 检验反写：检验数量、合格数量、判退数量、让步接收数量、工废数量、料废数量、样品破坏数量。
  - 累计：累计入库数量、累计退料数量。
  - 规则：已审核才能下推入库单。需要检验时以「接收数量」控制；收料单下推的退料单，退料类型只能是「检验退货」。
- **采购入库单**
  - 入库类型（启用来料检验时）：合格入库、不合格入库、让步接收入库、工废入库、料废入库。
  - 字段：应收数量、实收数量、仓库、仓位、库存状态（只能为「可用」或「冻结」）、批号、供应商批号、单价、金额、价税合计、成本价（由存货核算反写）、源单类型/编号、订单单号、退料关联数量。
  - 规则：审核时反写收料单和采购订单的累计入库数量。入库单下推的退料单，退料类型只能是「库存退货」。
- **采购退料单**
  - 字段：退料类型、退料方式、补料方式、退料原因、订单单号、源单类型/单号/行号、关联数量。
  - 补料方式为「创建订单补货」时，可以下推采购订单。

### 3.2 销售（销售管理 / 标准销售业务）
- **标准流程**：销售报价单 → 销售订单 → 发货通知单 → 销售出库单。退货链：退货通知单 → 销售退货单。
- **销售报价单**
  - 字段：客户、销售组织、销售部门、销售员、生效日期、失效日期、单据状态、是否含税、结算币别、物料、数量、单价、税率、价税合计、起订量。
  - 「失效」后不能下推。可以不限次数下推销售订单。
- **销售订单**
  - 单据类型：标准销售订单、寄售、受托加工、直运、退货、VMI、现销等。
  - 表头：单据编号、日期、客户、销售组织、销售部门、销售组、销售员、交货方式、单据状态、结算币别、收货方、收款条件、价目表、是否含税、是否预收。
  - 明细：物料编码、销售单位、销售数量、单价、含税单价、税率、金额、价税合计、要货日期、库存组织、货主、供应组织、批号、BOM编号、控制发货比例、发货上限、发货下限。
  - 反写字段：累计发货通知数量、累计出库数量、累计退货通知数量、累计退货数量、剩余未出数量、累计采购申请数量、累计采购订单数量、累计应收数量、变更标志。
  - 状态：业务关闭、业务冻结、业务终止、整单关闭、行关闭。
  - 下推生产订单、采购订单时会携带「供应组织」。
- **发货通知单**
  - 字段：发货组织、承运商、运输单号、出货仓库/仓位、备货仓库、货主、控制出库比例、出库上下限、源单类型/单号、订单单号、累计出库数量、未出库数量（= 数量 − 关联出库数量）。
  - 关联出库数量 ≥ 下限时自动关闭。可以下推直接调拨单做备货。
- **销售出库单**
  - 字段：发货组织、仓管员、承运商、应发数量、实发数量、仓库、仓位、库存状态（必须是可用类）、批号、BOM编号、累计退货数量、累计应收数量。
  - 出库达到订单下限时，订单和通知单自动关闭。
- **退货通知单 / 销售退货单**
  - 字段：库存组织、退货客户、退货原因、应退数量、实退数量、退货类型（预设：退货、退货补货）、库存状态、销售成本价（成本核算后反写）。

### 3.3 库存（库存管理）
- **单据清单**：初始库存、其他入库单、调拨申请单、直接调拨单、库存状态转换单、批号调整单、盘点方案、物料盘点作业、周期盘点计划、库存调整、锁库、库存关账。
- **报表清单**：即时库存、库存汇总统计表、物料收发汇总/明细表、库存台账、库存账龄分析表、库存预警报表、库存流水表。
- **其他入库单**
  - 字段：库存组织、日期、库存方向、部门、供应商、货主类型、单据状态、物料编码、实收数量、收货仓库、仓位、库存状态、批号、BOM版本、保质期、生产日期。
  - 分普通和退货两类。可以由「其他检验」的检验单关联生成。
- **初始库存**：库存组织、仓库、货主、物料、期初数量、年初数量、仓位、库存状态、入库日期、批号、供应商批号。
- **物料盘点作业**
  - 必须由盘点方案审核生成。
  - 字段：账存日期、来源（定期盘点/周期盘点）、账存数量、盘点数量、盘盈数量、盘亏数量、盘点误差%。
  - 执行状态：确认、盘点。
  - 审核时自动生成盘盈单或盘亏单，反审核时删除。
- **批号主档**：按「业务组织 + 物料 + 批号」创建，记录批号流转的出入库单据，支持按入库日期先进先出。只能查看。
- **序列号主档**
  - 字段：物料编码、序列号、批号、供应商、生产部门、客户、仓库、仓位、生产日期、保修结束日期。
  - 在库状态：待入库、在库、待出库、出库。
  - 流转记录：跟踪方向（来源/去向）、单据名称、单据编码、订单类型、订单编码。
- **其他出库单**：处理非销售出库、非生产领料、非委外的出库，字段同其他入库单（原文写法）。

## 4. 质量管理

- **检验类型**（质量管理页）：来料检验、产品检验、库存检验、自制工序检验、委外工序检验、生产退料检验、退货检验、发货检验、生产线检验、受托材料检验、其他检验、工序巡检、委外退料检验。
- **基础资料**：抽样方案、检验项目、质检方案、质量标准、检验方法、检验仪器、检验依据、缺陷类型、缺陷原因、缺陷后果、检测值、物料来源质检规则。
- **单据**：库存请检单、生产退料请检单、其他请检单、检验单、不良品处理单、MRB评审单。
- **报表**：缺陷原因分析表、供应商质量统计表、生产车间质量统计表、工序检验质量统计表、物料不良率控制图……
- **检验单**
  - 源单：来料检验来自采购收料单；产品检验来自生产汇报单；自制工序检验来自工序汇报单；发货检验来自发货通知单（或库存请检单）；退货检验来自退货通知单；工序巡检来自工序计划单。
  - 表头：单据类型、业务类型、单据日期、来源组织、质检组织、检验部门、单据状态、质检组、质检员。
  - 明细：物料编码、质检状态（计划/质检开始/质检完成）、单位、检验结果、检验数量、合格数、不合格数、质检方案、供应商、客户、生产车间、仓库、批号、检验次数、源单类型、源单行号、订单号。
  - 抽样：抽样类型（全检、固定数量、按百分比、GB/T2828.1-2012、自定义）、检验水平、严格度、AQL、样本量、允收数、拒收数、样本不合格数、样本破坏数。
  - 缺陷：缺陷类型、缺陷数量、缺陷原因、缺陷等级（致命/重/轻）、缺陷后果。
  - 检验项目：检验项目代码/名称、分析方法、质量标准、检验方法、检验仪器、检验结果。
  - 使用决策（按检验类型不同）：
    - 来料检验：接收、让步接收、判退（退料）、挑选（全检）、工废、料废。
    - 产品检验：接收、返修、返工、报废、挑选、不良。
    - 工序巡检：接收、报废、返修。
    - 生产退料检验：接收、来料不良、作业不良、挑选。
  - 后续处理：使用决策可以勾「不良处理」，下推不良品处理单；勾「MRB评审」，下推MRB评审单。勾了的数量在质检完成时不反写源单。
  - 支持合并检验、二次检验和多次检验。
- **来料检验业务**：收料单 → 检验单。质检完成后把接收数、退料数反写回收料单，收料单再按接收数量生成入库单。支持紧急放行、调整型抽样（严格度转换）。
- **产品检验业务**
  - 生产汇报单 → 检验单。合格、不良、报废、返修、返工数量反写到汇报单和生产订单，生产入库依据检验结果控制。
  - 可以设置「产品检验后自动入库」。
  - 支持产品首检，首检状态包括首检中、首检完成。
- **发货检验**：发货通知单 → 库存请检单（发货类型）→ 检验单 → 按合格数量生成销售出库单。
- **不良品处理单**
  - 字段：单据类型（按检验类型区分）、业务类型、物料、批号、供应商、客户、检验单使用决策、检验不良数量、不良处理、不良数量、MRB评审、是否折让、折让金额、源单编号/行号、订单编号。
  - 采购类可以下推费用应付单（负金额）做质量折让。
- **MRB评审单**
  - 字段：缺陷描述、生产计划意见（退货是否影响生产、上线日期、急料数量）、采购意见（后续供应商是否满足计划、处理意见）、工程评估。
  - 审核时把判定结果累加到源单，并把检验单的 MRB 状态置为已完成。
- **质量追溯**
  - 方向：溯源追溯（父找子，从上到下查子项材料及采购、生产、库存、质检单据）、去向追溯（子找父，查用于哪些父项产品，以及父项的销售、生产、库存、质检、出入库流水）。
  - 方式：批号追溯、序列号追溯、批号序列号综合追溯、单品序列号追溯。
  - 配置：质量追溯方案（追溯哪些单据和字段）、追溯树方案、单据追溯逻辑。
  - 原文未述：追溯结果的具体字段明细（追溯界面只有截图说明，没有字段表）。

## 5. 计划（计划管理 / MRP）

- **页面清单**：预测单、计划方案、计划运算向导、计划订单、预留单、缺料分析、追料报告、订单进度跟踪、主计划（MPS）、能力中心、MRP 运算结果明细/汇总表、物料供需汇总/明细表、MRP 例外信息。
- **计划方案**
  - 字段：方案编码、方案名称、计划展望期、计划方式、需求组织、供应组织。
  - 需求来源：预测单、销售订单、冲销结果、计划订单。
  - 供需单据：生产订单、委外订单、采购申请单、采购订单、其他入库单、生产补料/退料单、其他出库单、调拨申请单……
  - 计算参数：考虑损耗率、考虑成品率、考虑现有库存、考虑安全库存、考虑预计入库和已分配数量、按订货策略和批量调整。
  - 投放默认：运算完成直接投放计划订单、默认生产单据类型、默认采购单据类型等。
- **计划运算向导**：运算编号、计划方案、MRP计划/MPS计划、需求范围选择、低位码运算、优先级计算。
- **计划订单**
  - 投放类型：生产订单类、采购申请类、委外订单类、组织间受托类、生产线类（不可投放）。
  - 字段：物料编码、BOM编号、单位、净需求、需求日期、计划订单量、建议采购/生产日期、建议到货/完工日期、建议订单量、确认订单量、采购/生产组织、生产车间、供应商、计划员、计划跟踪号、数据来源、运算编号、业务状态。
  - 计划 BOM 子项：分子、分母、标准用量、应发数量……
  - 业务状态：计划、需求确认、供应确认、关闭（手工关闭、投放关闭、合并关闭、拆分关闭）。

## 6. 成本（存货核算 / 产品成本核算）

- **产品成本核算**
  - 功能：费用分配、产品成本核算、报表分析、账务处理、期末处理。
  - 核算方法：逐步综合结转、逐步分项结转、订单法、分类法、品种法、分步法。
  - 「订单生产的成本核算」以生产订单为成本核算对象。
  - 基础资料：成本中心、成本项目、成本项目匹配方案。
  - 单据与报表：成本计算单、车间成本计算单、完工入库成本查询、销售订单利润分析表、销售订单成本跟踪表。
  - 成本计算的核算类型：合法性检查、费用分配、成本计算。
  - 生产用料清单是直接材料费用的取数来源（见 1.4）。
- **存货核算**
  - 功能：采购入库核算、入库成本维护、出库成本核算、委外入库核算、物料计价方法、成本调整单、即时成本、目标成本、成本预警。
  - 采购入库单的「成本价、总成本」由存货核算反写（见 3.1）。
  - 原文未述：具体计价公式（只列了功能名）。

## 7. 系统管理 / 权限

- **用户**：用户创建与维护、联系对象（员工/供应商/客户）、密码策略、认证方式。
  - 密码策略：默认强密码，8–20 位，包含数字、特殊字符和字母；有效期；锁定后自动解锁。
  - 认证方式：命名用户、域用户、动态密码、CA、双因素。
- **角色**
  - 角色类型：普通角色、系统管理员（子管理员，可以设置授权范围）。
  - 角色属性：公有、私有（启用多组织后才有）。
  - 原文定义：「角色既是用户的职责体现，同时也是权限的载体」。
- **授权方式**：子系统功能授权、业务对象功能授权（业务对象 + 权限项）、全功能/业务领域/子系统/业务对象批量授权、字段授权、数据权限（数据规则、岗位体系数据规则）。
  - 权限状态：有权、无权、禁止，优先顺序为 禁止 → 有权 → 无权。「禁止」用于职责分离。
- **日志**：上机操作日志、WebAPI 日志、业务数据日志。
- **组织管理**：启用多组织、组织机构、组织隶属关系、组织业务关系、基础资料控制策略（多组织才需要）。
- **车间调度汇报权限**：要先对工作中心授权，才能做工序汇报。

## 8. 车间 / 智慧车间（二期参考）

- **工序计划**
  - 分录业务状态：创建 → 计划 → 计划确认 → 下达 → 开工 → 完工 → 关闭。
  - 只有工序计划已审核、分录处于下达/开工/完工时，才能工序领料。
- **工序汇报**
  - 来源：由工序计划下推。
  - 内容：生产数量、废品数量、工时，支持返修汇报。
  - 前提：已在「车间调度汇报权限」中对工作中心授权。
- **生产 SMT 上料表**
  - 表头：单据编号、组织、产线、生产订单编号、生产订单行号、产品编码、生产订单数量、作业、生产订单状态、单据状态。
  - 站位表：站位表版本、贴片机位置、贴片机型号、程序名称。
  - 上料明细：Table（A/B 面）、轨道、启用、上料状态（待上料/已上料/已下线）。
  - 用途：PDA 上料校验，同时是完工冲销的依据。
- **其他**：工序转移单、工序委外、设备采集执行计划配置、生产事件管理（设备异常/切换事件），本次只读了目录和设备页。
