# 精读笔记 委外管理（d_委外管理.txt 全部 + 单据类型参数抽查）
- 概述：委外订单全过程(委外计划→投料领料→委外检验→入库→结案)；普通委外/返工委外(用料清单默认仅返工产品本身)；流程 委外备料→下达→用料清单处理→委外领料→采购入库→委外退料(退供应商)。【委外管理】
- 委外订单：表头 单据编号 单据类型 委外组织 单据日期 计划组 计划员 单据状态；明细 产品类型 物料 供应商(下推采购订单后更新) 单位 数量 业务状态 计划开工/完工时间 BOM版本 采购组织 领料状态；委外页签 批号 挂起状态 入库货主 入库组织 仓库 仓位 辅助属性 成本权重；执行页签 计划确认日期 下达日期 完工日期 结案日期 核算日期 采购选单数量 采购执行数量 入库数量；参考页签 生成方式 来源单据 销售订单 采购订单/行号 业务流程。状态：计划→计划确认→下达→完工→结案（无开工）；审核自动计划确认；下达后才可下推(采购订单/领料)；反下达需无领退补；结案需无非审核非作废领退补、用料清单已审核、采购订单业务关闭/整单关闭/业务终止；拆分行(数量-采购选单数量>0)；生成下级订单；领补套数同步到采购订单【委外领料套数】；新增联副产品。【委外订单】
- 委外订单(变)变更单：订单已审核且计划确认/下达未挂起；数量≥采购选单数；审核刷新委外用料清单。【委外订单变更单】【委外订变更单】
- 委外订单拆分：拆为生产订单/委外订单；全部拆分则原单数量0结案(拆分结案)。
- 委外用料清单/变更单：同生产用料清单结构(含数量控制页签)；变更前提单据类型启用变更+订单下达/完工。
- 委外领料单/退料单/补料单：与生产三单同构，组织字段为 委外组织/委外供应商；前提订单下达/完工 + 用料清单已审核；倒冲：委外类型采购入库单审核时后台倒冲或交互式；采购入库单反审核删除倒冲领料单；分仓领料；超发控制4种。
- 委外退料(采购退料)：委外加工采购退料单审核影响委外订单入库数量、用料清单消耗数量；倒冲物料自动/交互生成倒冲退料单。
- 委外超耗单：供应商责任超定额消耗，记录以扣加工费/索赔；字段 库存组织 委外组织 采购组织 供应商 申请数量 消耗数量；下推标准应收单；需求参数中可参与MRP。【委外超耗单】
- 委外齐套分析(委外备料单)：业务类型 齐套分析/缺料分析；调拨策略(补足委外库存/补齐调拨数量/按齐套数调拨)；缺料清单按供应商分组；委外齐套分析模板。
- 委外成套领/退/补料：订单下达/完工 + 存在下游采购订单。
- 委外倒冲工作台(来源 委外入库单/采购退料单)、委外倒冲差异分摊(订单下达/完工)、委外月末在制转移、委外仓库设置(同委外组织同供应商一个仓库/仓位)。
- 委外单据类型参数：委外类型(标准委外/返工委外) 用料清单(仅主产品/按BOM展开) 启用委外用料清单变更 调拨获取供应商仓库 审核自动下达 下达自动审核用料清单 自动结案 倒冲方式 领料单生成时机 委外领料自动计算 领补套数 委外收料材料领用控制 委外入库材料领用控制 结案控制…
- 委外管理参数：默认库存状态；采购数据关联(按单据转换/按采购订单编号)；拆分/变更检查；领料前需审核采购订单；委外退料检验(自动退料)；执行计划(委外入库倒冲组织、采购退料倒冲组织、委外结案组织)。
- 报表：委外订单执行明细/汇总表、领料明细/汇总表、委外入库领料查询、领料差异汇总表、入库月报表(合格入库 工废入库 料废入库 让步接收入库 不合格入库)、领料月报表、生产/委外退料检验质量统计表。
- 工序委外HMI(属车间/MES)：扫描委外发出(生成工序转移单)、委外接收、委外入库、移动质检_委外检验。委外入库核算流程图=仅图。
- 关键事实：委外订单下推采购订单，收货走采购的收料通知单→采购入库单(委外类型)【委外管理】操作手册列表；委外日排产需采购执行数量。
